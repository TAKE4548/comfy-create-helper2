## 1. 概要

保存済みスナップショットの一覧表示・アルバム管理を提供するページ。  
各ワークフローで保存したスナップショットを閲覧し、アルバムへの整理・表示順の並び替えができる。

---

## 2. 機能一覧

| 機能 | 説明 |
|---|---|
| スナップショット一覧 | 保存済みスナップショットを一覧表示（新しい順・古い順のソート対応） |
| ワークフローフィルタ | ワークフロー選択でフィルタリング |
| アルバム作成 | 任意のスナップショットを選択してアルバムを生成。Ctrl/Shift/長押しでの複数選択および一括追加に対応 |
| アルバム並び替え | アルバム内の表示順を D&D（カスタム順）で変更・保存。複数選択時の「グループ移動」に対応 |
| アルバム内ソート・整列 | アルバム内の画像をカスタム順、古い順、新しい順で並び替えて表示 |
| アルバム一括編集 (Bulk Mode) | 共通ツールバーによる複数選択、一括削除 |
| スナップショット詳細 | 保存時のプロンプト・パラメータを確認 |
| スナップショット削除 | 個別スナップショットの削除 |

## 4. スナップショット表示

- 保存画像サムネイルをグリッドで表示
- 表示順トグル: 「新しい順（降順）」「古い順（昇順）」でグリッド内の表示順を変更可能
- ホバー時: 保存日時・ワークフロー名を表示
- クリック: 詳細モーダル（`HistoryModalPreview`）を開く

### HistoryModalPreview コンポーネント

`components/HistoryModalPreview.tsx`（228行）

- 画像の拡大表示
- 保存時のパラメータ（`params`）を整形表示
- **LoRA Stack の検出とグループテーブル表示**:
  - `params` 内のフラットキー（`${role}_lora_count`, `${role}_lora_name_X`, `${role}_lora_wt_X`, `${role}_model_str_X`, `${role}_clip_str_X`）をスキャンして自動検出。
  - 各 LoRA Stack（`role`）ごとにテーブルとしてグループ化して一覧表示（Model名、Weight、Model Str、Clip Str を表示）。
  - LoRAモデルの表示名は、登録済みの LoRA マスタ情報と照合し、`description`（説明文）がある場合は説明文を優先表示し、無ければ物理パス（`file_path`）をそのまま表示。
- 紐づいている LoRA・TagSet 情報を表示
- スナップショット削除ボタン

## 5. アルバム管理

### 5-1. アルバム作成

- スナップショットにチェックを入れて「アルバムを作成」
- アルバム名を入力して `POST /api/albums` で登録
- 既存アルバムへの追加も可能

### 5-2. アルバム内並び替え（ドラッグ&ドロップ）

- @dnd-kit/sortable を使用したドラッグ&ドロップ（カスタム並び替え）
- ※「カスタム順」選択時にのみ有効。
- 誤動作防止として、マウス操作時は `8px` 以上の移動（`MouseSensor`）、タッチ操作時は `500ms` の長押し（`TouchSensor`）後にドラッグを開始する。
- 並び替え確定後に `PATCH /api/albums/{id}/order` で保存

### 5-3. アルバム内自動ソート

アルバム詳細画面のヘッダーで、以下の表示ソート順を切り替えることができる（表示のみで順序は保存されない）。
- **カスタム順**: 5-2 で設定された独自の表示順
- **古い順**: スナップショットの作成日時が古いものから順に並び替え
- **新しい順**: スナップショットの作成日時が新しいものから順に並び替え

### 5-4. 一括選択と削除 (Bulk Mode)

共通の `useMultiSelect` フックの導入により、以下のように一括操作機能が強化されています。
- **スナップショット一覧タブ**:
  - `Ctrl + クリック` / `Shift + クリック` / 長押しによる複数選択に対応。
  - 選択中、画面上部に `MultiSelectToolbar` が表示され、「Add to Album」ボタンから選択した複数スナップショットを一括でアルバムへ追加可能。
- **アルバム詳細ビュー**:
  - 従来の「選択モード」ボタンを `MultiSelectToolbar` に統合。
  - `Ctrl + クリック` / `Shift + クリック` / 長押しで複数選択して「一括削除実行」（`POST /api/albums/{id}/items/delete`）を呼び出し可能。
  - 複数選択状態でのドラッグ＆ドロップ時に `+N` バッジ表示による「グループ移動」に対応。カスタム表示順を一括で並び替えて保存可能。

## 6. API 呼び出し

| 操作 | エンドポイント |
|---|---|
| スナップショット一覧 | `GET /api/snapshots?workflow_id={id}` |
| スナップショット削除 | `DELETE /api/snapshots/{id}` |
| アルバム一覧 | `GET /api/albums` |
| アルバム作成 | `POST /api/albums` |
| アルバム表示順更新 | `PATCH /api/albums/{id}/order` |
| アルバム削除 | `DELETE /api/albums/{id}` |
