# REQ-040: 生成履歴とスナップショットの並び替え機能 テスト計画書

本テスト計画は、REQ-040 (生成履歴とスナップショットの並び替え機能) の各受け入れ基準 (AC) が正しく満たされているかを検証するためのものです。

---

## 1. 自動テスト計画

フロントエンドのみの変更であるため、UI動作を中心とした手動検証を行います。

---

## 2. 手動検証計画 (フロントエンド)

ブラウザ上で以下のシナリオを実行し、挙動を確認します。

### シナリオ1: 生成ページでのソート機能の動作確認 (AC-1, AC-3, AC-4, AC-5)
1. 生成ページ (`GeneratePage`) を開く。
2. 履歴サムネイルストリップに画像が表示されていることを確認する。
3. 初期表示状態（リロード直後）で、「履歴」および「スナップショット」の並び順が「新しい順」になっていることを確認する（AC-3）。
4. 「新しい順」ボタンがアクティブ状態（背景色が暗くハイライトされるなど）になっていることを確認する（AC-5）。
5. 「古い順」ボタンをクリックする。
6. 履歴・スナップショットのサムネイルが、古い画像から新しい画像の順（作成日時の昇順）に正しく並べ替わることを確認する（AC-4）。
7. 「古い順」ボタンがアクティブ状態として視覚的に強調され、「新しい順」ボタンが非アクティブ状態になることを確認する（AC-5）。
8. タブを「履歴」から「スナップショット」に切り替え、同様に「新しい順」「古い順」の切り替えが正しく動作することを確認する（AC-1）。
9. モバイル表示（ブラウザの幅を狭める、またはF12でモバイルビューにする）においても、履歴とスナップショットの切り替えボタン、および「新しい順」「古い順」のトグルボタンが正しく表示・機能することを確認する。

### シナリオ2: スナップショット一覧ページでのソート機能の動作確認 (AC-2, AC-3, AC-4, AC-5)
1. Historyページ（スナップショット一覧ページ）を開く。
2. 初期表示状態で、並び順が「新しい順」になっていることを確認する（AC-3）。
3. 「新しい順」ボタンがハイライトされていることを確認する（AC-5）。
4. 「古い順」ボタンをクリックする。
5. スナップショットのグリッド表示が古い順（作成日時の昇順）に正しく切り替わることを確認する（AC-4）。
6. ライトボックス（画像クリックによる拡大プレビュー）を開く。
7. ライトボックス内の左右矢印キー（`←`, `→`）またはクリックによって、ソートした順序（古い順なら古い画像から順に）画像が切り替わることを確認する。
8. ワークフローフィルターで特定のワークフローを選択した場合でも、ソート順の切り替え（新しい順・古い順）が正しく適用されることを確認する。
