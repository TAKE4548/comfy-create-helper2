## 3. ブラウザ検証 (Browser Agent Verification)
### シナリオ1: 生成ページでのソート機能の動作確認 (AC-1, AC-3, AC-4, AC-5)
1. **初期状態確認 (新しい順/降順)**:
   - 生成ページ (`GeneratePage`) を開く。
   - 「新しい順」ボタンがアクティブ状態であることを、CSSクラス名に `bg-surface-2 text-zinc-200` が含まれていることで確認する。
   - サムネイル画像（履歴）の順序が最新のものが先頭に並んでいることを確認する。
2. **ソート切り替え (古い順へ)**:
   - 「古い順」ボタンをクリックする。
   - 「古い順」ボタンのCSSクラス名に `bg-surface-2 text-zinc-200` が含まれるようになり、「新しい順」ボタンからは除去されている（`text-zinc-550` などになっている）ことを確認する（AC-5）。
   - サムネイル画像の配列が反転し、古い画像から順に表示されていることを確認する（AC-4）。
3. **詳細モーダルとの整合性確認**:
   - 並び替わった状態でサムネイルをクリックし、詳細プレビュー (`HistoryModalPreview`) を開く。
   - モーダル内の「次へ」または「前へ」ボタンで移動した際、ソートされた順序（古い順）に従って切り替わることを確認する。
4. **モバイルレスポンシブ検証**:
   - `viewport width = 375px` にエミュレートした状態で、サムネイルストリップが表示され、「新しい順」「古い順」のセグメントボタンが画面外にはみ出さずに正しくタップ可能であることを確認する。

### シナリオ2: スナップショット一覧ページでのソート機能の動作確認 (AC-2, AC-3, AC-4, AC-5)
1. **初期状態確認 (新しい順/降順)**:
   - スナップショット一覧ページ (`HistoryPage`) を開く。
   - 初期状態で「新しい順」がハイライト（`bg-surface-2 text-zinc-200`）されていることを確認する。
2. **ソート切り替え (古い順へ)**:
   - 「古い順」ボタンをクリックする。
   - 各スナップショットカードのDOM順序が切り替わり、作成日時（`snap.created_at`）が昇順（古いものが先頭）に並び替わっていることを確認する。
3. **ライトボックス検証**:
   - スナップショットカードをクリックしてライトボックスを開く。
   - ライトボックスの左右矢印キー（`←`, `→`）を押し、遷移する画像が古い順の並びに一致していることを確認する。
4. **ワークフローフィルター連動確認**:
   - ワークフローフィルターで任意のワークフローを選択する。
   - 絞り込まれた状態でも「新しい順」「古い順」の切り替えによって表示順が昇順・降順に正しくソートされることを確認する。
