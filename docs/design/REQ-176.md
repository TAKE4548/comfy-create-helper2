# REQ-176: セリフプリセット一覧の区分・ソート・検索フィルタ機能および表示設定の永続化

## 1. 背景と目的
セリフ（吹き出し）編集機能において、登録プリセット数が増加した際に以下の課題が発生している：
1. **混在と一覧性低下**: 「テキストを含むプリセット」と「スタイルのみのプリセット」が同一の一覧に混在し、項目が増えると目的のプリセットを探す負担が増加する。
2. **並び順の不便さ**: プリセット一覧のソート順を選択できず、名前順や登録順で整理して探すことができない。
3. **検索・フィルタの欠如**: 名前での絞り込み検索や、縦書き/横書き種別に応じたフィルタリング機能が存在しない。
4. **状態の非永続化**: 検索条件、ソート順、折り畳み状態が保持されず、別の画像や吹き出しの編集時に毎回初期状態に戻ってしまう。

本設計では、プリセット一覧を「テキスト付き」と「テキストなし（スタイルのみ）」の2セクションに明確に区分・折り畳み可能にし、検索・縦横フィルタ・ソート機能を提供するとともに、設定状態を `localStorage` で永続化する。

## 3. 詳細設計

### 3-1. 永続化キーと設定インターフェース
```typescript
const PRESET_SETTINGS_KEY = 'speech_bubble_preset_filter_settings'

export type PresetSortOption = 'name-asc' | 'name-desc' | 'created-asc' | 'created-desc'
export type PresetDirectionFilter = 'all' | 'vertical' | 'horizontal'

export interface PresetFilterSettings {
  searchQuery: string
  directionFilter: PresetDirectionFilter
  sortBy: PresetSortOption
  isWithTextOpen: boolean
  isWithoutTextOpen: boolean
}

const DEFAULT_PRESET_FILTER_SETTINGS: PresetFilterSettings = {
  searchQuery: '',
  directionFilter: 'all',
  sortBy: 'name-asc',
  isWithTextOpen: true,
  isWithoutTextOpen: true,
}
```

### 3-2. 状態管理 (`SpeechBubbleControls.tsx`)
- `presetSearchQuery`: string（デフォルト `""`）
- `presetDirectionFilter`: `'all' | 'vertical' | 'horizontal'`（デフォルト `'all'`）
- `presetSortBy`: `'name-asc' | 'name-desc' | 'created-asc' | 'created-desc'`（デフォルト `'name-asc'`）
- `isWithTextOpen`: boolean（デフォルト `true`）
- `isWithoutTextOpen`: boolean（デフォルト `true`）

各状態の変更時に `localStorage.setItem(PRESET_SETTINGS_KEY, JSON.stringify(...))` を実行し、マウント時に復元する。

### 3-3. フィルタリング & ソートロジック
1. **フィルタリング**:
   - `orientation` チェック: `presetDirectionFilter === 'all'` または `p.orientation === presetDirectionFilter`
   - `searchQuery` チェック: `p.name`（または `p.text`）に検索文字列が含まれるか（大文字小文字区別なし）
2. **ソート**:
   - `'name-asc'`: `a.name.localeCompare(b.name, 'ja')` (デフォルト)
   - `'name-desc'`: `b.name.localeCompare(a.name, 'ja')`
   - `'created-asc'`: 作成日時古い順
   - `'created-desc'`: 作成日時新しい順
3. **区分分割**:
   - `withTextPresets`: `preset.text !== undefined && preset.text !== null && preset.text.trim() !== ''`
   - `withoutTextPresets`: 上記以外（テキストなし／スタイル専用）

### 3-4. UIレイアウト
- **コントロールバー**:
  - 検索入力フィールド（`data-testid="preset-search-input"`）+ クリアボタン
  - 縦横フィルタボタン群（`すべて` / `縦書き` / `横書き`）
  - ソートセレクトボックス（`data-testid="preset-sort-select"`）
- **セクション表示**:
  - `💬 テキスト付きプリセット ({件数})` [開閉トグルボタン `data-testid="toggle-with-text-section"`]
    - 展開時: チップ一覧を表示。0件時は「該当するテキスト付きプリセットはありません」を表示。
  - `🎨 スタイル専用プリセット ({件数})` [開閉トグルボタン `data-testid="toggle-without-text-section"`]
    - 展開時: チップ一覧を表示。0件時は「該当するスタイル専用プリセットはありません」を表示。

## 4. テスト・検証設計

### 4-1. フロントエンド ユニットテスト (`SpeechBubbleControls.test.tsx`)
- テキスト付きとテキストなしのプリセットがそれぞれの区分に分離して表示されること。
- セクションヘッダークリックで折り畳み／展開ができること。
- ソート順（名前順昇順・降順、登録順昇順・降順）の変更で表示順が正しく並び変わること。
- 検索キーワード入力で名前に一致するプリセットのみが絞り込まれること。
- 縦書き／横書きフィルタで該当する向きのプリセットのみが表示されること。
- フィルタ条件・ソート順・開閉状態が `localStorage` に保存され、初期ロード時に復元されること。
