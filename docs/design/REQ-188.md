# REQ-188 設計書: セリフ編集のパス軌道およびスケール変化カーブの不具合修正

## 1. 概要 (Overview)
セリフ編集の「漫画テキスト演出（MangaTextEffects）」において発生している、パス軌道制御点の同期不備、パス反転無効、およびスケール変化・パス配置時の字間ギャップ破綻を解消するための詳細設計。

---

## 2. アーキテクチャと変更点 (Architectural Changes)

### 2.1 パス制御点の初期化・同期モデル
1. **初期値のクリーン化**:
   - `DEFAULT_MANGA_EFFECTS` の `pathPoints` を空配列 `[]` または未指定扱いとする。
2. **コントロール側の同期（`SpeechBubbleControls.tsx`）**:
   - 軌道タイプ変更（`onChange`）時、常に選択されたプリセットと吹き出しの文字方向（`vertical` / `horizontal`）に対応するデフォルト制御点をセットする。
   - 文字方向切り替え時、`pathPreset !== 'none'` の場合は新しい文字方向に対応する制御点に更新する。
3. **レンダラー側の安全フォールバック（`speechBubbleRenderer.ts`）**:
   - 各プリセットに必要な点数（`line: 2`, `arc: 3`, `wave: 4`, `stepped: 2`）が不足している場合、または制御点配列が空の場合は、常に `getDefaultPathPoints(preset, bubble.orientation)` を取得して描画する。

### 2.2 パス軌道反転（`flipPathPoints` & `handleFlipPath`）
1. **`handleFlipPath`**:
   - 現在の `fx.pathPoints` がプリセットの要求点数を満たしているかを検証し、満たしていない場合は `getDefaultPathPoints(currentPreset, bubble.orientation)` をベースとして反転を行う。
2. **`flipPathPoints` の挙動**:
   - 縦書き: X座標ミラー `pt.x = 1.0 - pt.x`
   - 横書き: Y座標ミラー `pt.y = 1.0 - pt.y`
   - 直線（`line`）等の点対称形状の反転対応:
     - 全点の座標が中心線上（x=0.5 または y=0.5）で変化しない場合、配列の順序を反転（始点・終点スワップ）することで進行方向を反転させる。

### 2.3 可変文字送り（Proportional Character Advancement）
1. **通常レイアウト（`drawBubbleText`）**:
   - 事前に各文字の `trans.scale` を計算。
   - **縦書き**:
     - 各文字の高さ: $h_i = \text{fontSize} \times \text{lineHeightRatio} \times \text{scale}_i + \text{letterSpacing}$
     - 列の総高さ $H_{\text{total}} = \sum h_i$
     - 各文字の中心Y座標: $\text{topY} + \sum_{k=0}^{i-1} h_k + \frac{h_i}{2}$
   - **横書き**:
     - 各文字の幅: $w_i = \text{charBaseWidth} \times \text{scale}_i + \text{letterSpacing}$
     - 行の総幅 $W_{\text{total}} = \sum w_i$
     - 各文字の中心X座標: $\text{leftX} + \sum_{k=0}^{i-1} w_k + \frac{w_i}{2}$
2. **パス軌道レイアウト（`drawBubbleText` & `calculatePathPositions`）**:
   - 弧長サンプリング（Arc-Length Parameterization）:
     - ベジェ曲線を微小区間に分割（$M = 100$）して累積弧長テーブル $S[k]$ を事前構築。
     - 各文字 $i$ に必要な占有長さ（$\text{fontSize} \times \text{scale}_i + \text{letterSpacing}$）を計算。
     - 文字列の総必要長さに応じて、曲線上の弧長位置 $s_i$ を決定し、対応するパラメータ $t_i \in [0, 1]$ を補間計算。
   - `stepped`（階段）:
     - 各段（ステップ）内に複数文字が存在する場合、段内での微小送りオフセットを適用して重なりを解消。
   - 縦書きグリフ置換:
     - パス軌道描画時、`bubble.orientation === 'vertical'` の場合は `verticalCharMap` による文字変換（`ー` → `｜` 等）を適用する。

## 3. 影響ファイルと詳細仕様

### 3.1 `frontend/src/types/speechBubble.ts`
- `DEFAULT_MANGA_EFFECTS`: `pathPoints` を空配列 `[]` に変更。

### 3.2 `frontend/src/components/SpeechBubbleControls.tsx`
- `handleFlipPath`: プリセットの要求点数に応じた制御点取得・反転・保存ロジックの修正。
- `onChange` (軌道タイプ): プリセット変更時に `pathPoints` をデフォルト点に同期更新。
- 文字方向（`orientation`）変更ハンドラ: パス有効時の制御点同期。

### 3.3 `frontend/src/utils/speechBubbleRenderer.ts`
- `flipPathPoints`: 中心対称時の順序反転フォールバック追加。
- `calculateCharacterTransform`: 制御点の点数バリデーションと `bubble.orientation` フォールバックの堅牢化。
- `drawBubbleText`:
  - 通常レイアウト時の Proportional Character Advancement（スケール考慮の文字送り）実装。
  - パスレイアウト時の弧長・文字スケール・`letterSpacing` を考慮した位置計算ヘルパー関数の導入。
  - 縦書き時のパス描画での `verticalCharMap` 適用。
