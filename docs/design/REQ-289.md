# REQ-289 詳細設計: Windows環境でのGPU/VRAM取得是正およびモバイルヘッダーリソース監視表示対応

## 1. 概要とアーキテクチャ

本改修は、Windows 11 ホスト環境における GPU/VRAM メトリクス取得の失敗（`gpu_pct` / `vram_pct` が常に `null`）およびモバイルレイアウトにおけるリソース監視チップ（`ResourceGaugeChips`）の非表示障害を解消するための設計である。

```
┌─────────────────────────────────────────────────────────────┐
│  FastAPI Backend (Windows 11 Host)                          │
│                                                             │
│  ResourceMonitorService                                     │
│  ├─ CPU/RAM: psutil.cpu_percent / virtual_memory            │
│  └─ GPU/VRAM:                                               │
│      WindowsGpuMonitor                                      │
│        ├─ 起動時1回: DXGI API (CreateDXGIFactory1 / EnumAdapters1)
│        │   └─ DedicatedVideoMemory (VRAM総容量) を動的検出  │
│        └─ 定期ループ: PDH API (PdhOpenQueryW / AddEnglishCounterW)
│            - 専用VRAM使用量: \GPU Adapter Memory(*)\Dedicated Usage
│            - 3D使用率: \GPU Engine(*engtype_3D)\Utilization Percentage
│      Linux環境 (フォールバック): rocm-smi                   │
└─────────────────────────────────────────────────────────────┘
                             │ WebSocket (/api/ws)
                             ▼
┌─────────────────────────────────────────────────────────────┐
│  React Frontend (MobileLayout.tsx)                          │
│                                                             │
│  1. マウント時: useSystemStats() フックを呼び出し           │
│     → systemWsService.connect() で WebSocket 接続を確立     │
│  2. レイアウト是正:                                         │
│     - 1段目ヘッダー (Generate タイトル行, justify-between)  │
│       右側に <ResourceGaugeChips /> を移設                  │
│     - 2段目ヘッダー (フォーム行) から Chips を除去し、      │
│       select (flex-1) との幅競合 (幅 0px 圧迫) を根本解消   │
└─────────────────────────────────────────────────────────────┘
```

## 2. バックエンド詳細設計 (`resource_monitor.py`)

### 2.1 DXGI + PDH ハイブリッド方式による完全動的化
1. **総容量の動的検出 (DXGI)**:
   - 起動時（`__init__`）に `ctypes.windll.dxgi` の `CreateDXGIFactory1` を呼び出し、アダプター一覧を列挙（`EnumAdapters1`）。
   - ソフトウェアレンダラー（`Flags & 2`）を除外した上で最大の `DedicatedVideoMemory` を持つプライマリ GPU を検出し、総 VRAM 容量（GB）としてキャッシュ。
   - ハードコードリテラルを完全に排除し、ハードウェア換装や別 PC 環境でも自動追従。
2. **使用量のリアルタイムサンプリング (PDH)**:
   - 常駐ハンドルで `\GPU Adapter Memory(*)\Dedicated Usage` および `\GPU Engine(*engtype_3D)\Utilization Percentage` をサンプリング。
   - サブプロセス起動オーバーヘッドなし（サンプリング負荷 0.1ms 未満）。
3. **リソース解放**:
   - `stop()` 時に `PdhCloseQuery` を安全に呼び出し、OS ハンドルリークを防止。

## 3. フロントエンド詳細設計 (`MobileLayout.tsx`)

1. **フック呼び出しの追加**:
   - `frontend/src/hooks/useSystemStats` をインポートし、コンポーネント先頭で `useSystemStats()` を実行。
2. **ヘッダー1段目への移設**:
   - 1段目（`justify-between` を持つタイトル行）の右端に `<ResourceGaugeChips />` を配置。
   - 2段目のフォーム行から除去することで、幅 360〜414px でも幅 0px への押し潰しや描画外はみ出しを解消。

## 4. SSoT 影響分析 (`SPEC_GENERATE.md`)
- `docs/specs/SPEC_GENERATE.md` 2-10項において、バックエンド配信基盤の収集方式に「DXGI（VRAM総容量動的検出）＋ PDH（リアルタイム使用量取得）」を反映し、モバイル表示位置を「1段目ヘッダー右側」へ同期する。
