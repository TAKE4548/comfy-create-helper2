# REQ-247 Detailed Design Specification: useGalleryInteraction

## 1. 概要 (Overview)
DesktopLayout.tsx および MobileLayout.tsx に直接埋め込まれているギャラリー・サムネイル操作（サムネイル選択、モーダルプレビュー起動、useMultiSelect 連携、スナップショット選択、および将来の REQ-023 ホバーズーム・ホイール横スクロール）のステートとイベントハンドラを、カスタムフック useGalleryInteraction に抽出・一元化する。
これにより表示コンポーネント（Layout）をプレゼンテーション層として純化し、重複コードの排除および将来の機能拡張（REQ-023 等）に対する開閉原則（OCP）を担保する。

## 2. アーキテクチャと責務分離 (Architecture & Responsibilities)

### 2.1 現状の課題 (Current Issues)
- DesktopLayout.tsx と MobileLayout.tsx にサムネイルクリック時の選択判定（通常クリック、Ctrl/Shift/Metaクリック、モーダルプレビュー起動）、useMultiSelect（長押し・チェックボックス）のイベントバインドがそれぞれ直接インラインで実装されている。
- 今後予定される REQ-023（ホバーズーム・ホイール横スクロール）や REQ-240（複数端末リアルタイム同期）を追加する場合、DesktopLayout と MobileLayout の両コンポーネントに個別のリスナー追加やリファクタが必要となり、差分不整合やデグレのリスクが高い。

### 2.2 改善後の構成 (Target Architecture)
`
[useGeneratePageState / useGenerateDisplayState]
        │
        ▼ (displayImages, sortedSnapshots, multiSelectState, etc.)
[useGalleryInteraction] (新設 hook)
   - サムネイルクリックハンドラ (isMobile に応じたモーダル自動オープン制御)
   - スナップショット選択ハンドラ
   - ホバーズーム状態管理 (REQ-023 拡張スロット: hoverPreviewImg, setHoverPreviewImg)
   - ホイール横スクロール参照・イベント (REQ-023 拡張スロット: scrollContainerRef, handleWheelScroll)
   - 複数選択一括操作・プロパティ束縛 (getThumbnailItemProps)
        │
        ├─────────────────────────────┐
        ▼                             ▼
[DesktopLayout]                [MobileLayout]
(isMobile: false)              (isMobile: true)
- プレゼンテーション表示に特化     - プレゼンテーション表示に特化
- 横スクロール・ホバー有効       - タッチ操作・タッププレビュー有効
`

## 3. インターフェース設計 (Interface Specification)

### 3.1 useGalleryInteraction フック定義
- ファイルパス: frontend/src/pages/GeneratePage/hooks/useGalleryInteraction.ts

`	ypescript
import { useRef, useState, useCallback } from 'react'
import type { UseMultiSelectReturn } from '../../../hooks/useMultiSelect'

export interface UseGalleryInteractionOptions {
  isMobile?: boolean
  selectedImg: string | null
  setSelectedImg: (img: string | null) => void
  multiSelect: UseMultiSelectReturn<string>
  onOpenModalPreview?: (index: number) => void
  onLoadSnapshot?: (snapshotId: number) => void
}

export interface UseGalleryInteractionReturn {
  // サムネイルクリック
  handleThumbnailClick: (img: string, index: number, event: React.MouseEvent) => void
  // サムネイル要素にバインドする全イベントハンドラ生成
  getThumbnailItemProps: (img: string, index: number) => {
    onMouseDown: (e: React.MouseEvent) => void
    onMouseUp: () => void
    onMouseLeave: () => void
    onTouchStart: (e: React.TouchEvent) => void
    onTouchEnd: () => void
    onContextMenu: (e: React.MouseEvent) => void
    onClick: (e: React.MouseEvent) => void
  }
  // スナップショットクリック
  handleSnapshotClick: (snapshotId: number) => void
  // REQ-023 拡張スロット (ホバープレビュー状態)
  hoverPreviewImg: string | null
  setHoverPreviewImg: (img: string | null) => void
  // REQ-023 拡張スロット (ホイール横スクロールコンテナ ref & ハンドラ)
  scrollContainerRef: React.RefObject<HTMLDivElement>
  handleWheelScroll: (e: React.WheelEvent<HTMLDivElement>) => void
}
`

### 3.2 クリック・インタラクションロジック仕様
1. handleThumbnailClick(img, index, event):
   - multiSelect.handleItemClick(img, event) を実行（Ctrl/Shift/Meta や長押し後の複数選択ロジック）。
   - もし !multiSelect.isMultiSelectMode && !event.ctrlKey && !event.metaKey && !event.shiftKey の場合:
     - setSelectedImg(img) を実行。
     - isMobile === true の場合、onOpenModalPreview?.(index) を呼び出して即座にフルプレビューを開く。
     - isMobile === false の場合、中央のメインプレビューエリアで即座に表示されるためモーダルは開かない。
2. getThumbnailItemProps(img, index):
   - multiSelect.getLongPressHandlers(img) の各ハンドラ（onMouseDown, onMouseUp, onMouseLeave, onTouchStart, onTouchEnd, onContextMenu）と onClick: (e) => handleThumbnailClick(img, index, e) をひとまとめに提供し、コンポーネント側の JSX を大幅にスリム化。
3. handleSnapshotClick(snapshotId):
   - onLoadSnapshot?.(snapshotId) を安全に実行。
4. REQ-023 拡張インターフェース準備:
   - hoverPreviewImg / setHoverPreviewImg: デスクトップホバー時に拡大画像を保持するスロット。
   - scrollContainerRef / handleWheelScroll: コンテナ内のマウスホイール（deltaY）を scrollLeft に変換するハンドラを提供。

## 4. 既存コンポーネントのリファクタリング設計

### 4.1 DesktopLayout.tsx
- サムネイル描画ループ内で gallery.getThumbnailItemProps(img, i) をスプレッド展開。
- スナップショットのクリックも onClick={() => gallery.handleSnapshotClick(snap.id)} で統一。

### 4.2 MobileLayout.tsx
- DesktopLayout と同様に gallery.getThumbnailItemProps(img, i) をスプレッド展開。
- モバイルタップ時のプレビューオープンを onOpenModalPreview コールバックに集約。

## 5. テスト計画・品質検証 (Test Strategy)
- frontend/src/pages/GeneratePage/hooks/__tests__/useGalleryInteraction.test.ts を新設し、以下を網羅的に検証:
  1. 通常クリック時の setSelectedImg 呼び出し（Desktop ではモーダルが開かず、Mobile では onOpenModalPreview が呼ばれること）。
  2. 複数選択モード中、または修飾キー（Ctrl, Shift, Meta）押下時に setSelectedImg が呼ばれず multiSelect.handleItemClick のみが呼ばれること。
  3. getThumbnailItemProps が返すハンドラ群が正しく multiSelect の各イベントを中継すること。
  4. スナップショット選択時の委譲が正しく行われること。
  5. REQ-023 拡張スロット（ホイールスクロール、ホバープレビュー）の動作確認。
- 既存の MobileLayout.test.tsx の全テストが引き続き GREEN であることを確認。
