# REQ-187: アルバム詳細画面におけるカスタム順・降順でのドラッグ＆ドロップ並び替え対応 テスト設計書

## 1. テスト概要
本テスト計画は、REQ-187 で定義された「アルバム詳細画面におけるカスタム順・降順時の DnD 並び替え」の要件および受入基準（AC-1 〜 AC-4）を網羅的に検証するための自動テストおよび手動検証手順を定義します。

---

## 2. 自動テスト計画 (Unit / Integration Tests)

### 対象テストファイル
- `frontend/src/pages/__tests__/HistoryPage.test.tsx`

### テストケース一覧

| ID | テストケース名 | 検証内容 | 対応AC |
|---|---|---|---|
| TC-187-01 | カスタム順・降順でのドラッグハンドル表示検証 | アルバム詳細画面で「カスタム順」かつ「降順」選択時、各アイテムカードに `GripVertical` 並び替えハンドルが表示されることを確認 | AC-1 |
| TC-187-02 | カスタム順・降順での単一アイテム移動時のAPIペイロード検証 | 降順表示でアイテムをドラッグ移動した際、`albumsApi.updateOrder` に画面上の並び順を反転した（昇順 sequence_order 用）ID 配列が渡されることを確認 | AC-2 |
| TC-187-03 | カスタム順・降順での複数選択グループ移動時のAPIペイロード検証 | 複数選択モードかつ降順表示時に複数アイテムを移動した際、画面上の並び順通りの順序が正しく API に渡されることを確認 | AC-3 |
| TC-187-04 | カスタム順・昇順および登録日時ソート時の既存動作維持 | 昇順時および登録日時ソート時にドラッグハンドル・API 呼び出しが正常に動作することを確認 | AC-4 |

### テスト実行コマンド
```bash
cd frontend && npm test -- HistoryPage.test.tsx
```

---

## 3. 手動検証計画 (Manual Verification)

### 手順
1. アプリケーションを起動し、ブラウザで履歴・アルバム画面（`/history`）を開く。
2. 「Albums」タブを選択し、複数（3枚以上）の画像が含まれるアルバムを開く。
3. ソートを「カスタム順」かつ「降順」に設定する。
4. アイテムカードの左上にドラッグハンドルが表示されていることを確認する。
5. 任意のアイテムをドラッグして別の位置へドロップする。
6. ドロップした位置にアイテムが移動し、画面をリロードしてもその順序が保持されていることを確認する。
7. 「選択モード」を有効化し、複数アイテムを選択してドラッグ移動した際にもグループ移動が正常に行われることを確認する。
8. ソートを「昇順」に切り替えて、昇順での DnD 移動も問題なく動作することを確認する。
