# REQ-290 詳細設計: リソース監視 GPU使用率算出是正 (3D偏重解消および全エンジンMAX採用)

## 1. 概要と背景 (Background & Objectives)

REQ-289 において Windows 環境における DXGI（VRAM動的検出）＋ PDH（サンプリング）ハイブリッド方式を導入したが、以下の実運用上の障害が報告された（詳細は `docs/incident_report.md` および `tmp/Prompt_Surgeon_リソース監視_GPU使用率算出是正_調査報告書および改修計画書.pdf` 参照）。

1. **障害現象**:
   - ComfyUI のバッチ生成中やローカル LLM（LM Studio / Ollama）推論中、タスクマネージャー上の GPU 全体使用率が 90〜100% で稼働しているにもかかわらず、Prompt Surgeon リソースゲージ（`gpu_pct`）が 0.0%〜数% のまま推移する。
2. **根本原因**:
   - **PDH カウンターの 3D 固定**: 登録カウンターが `\GPU Engine(*engtype_3D)\Utilization Percentage` となっており、Compute エンジンを含む非 3D 演算ユニットが最初からクエリから完全に除外されていた。
   - **推論ワークロードとエンジン種別の不一致**: DirectML / Vulkan / ROCm / PyTorch による行列演算・テンソル推論は汎用計算ユニット（`engtype_Compute` や `Compute 0`, `Compute 1`）で実行される。3D グラフィックス描画パイプライン（ラスタライザ・ジオメトリシェーダ）を使用しないため、推論フル稼働時でも 3D は 0% となる。
   - **集計ロジックの不整合**: タスクマネージャーの「GPU 全体使用率 (Overall GPU Utilization)」は全エンジンのうち最も稼働率が高いエンジンの値（**MAX**）を採用しているのに対し、Prompt Surgeon は全プロセスの 3D インスタンスを単純合算（**SUM**）していた。
3. **改修方針**:
   - カウンター登録を `\GPU Engine(*)\Utilization Percentage`（全エンジン対象）へ拡張。
   - プライマリ GPU（DXGI で検出した LUID）に合致するカウンターインスタンスのみを抽出し、他アダプターのノイズを除外。
   - 物理エンジン種別ごとにプロセス使用率を合算し、全エンジンの中での「最大値（MAX across all engines）」をタスクマネージャー準拠で算出する。

## 2. アーキテクチャと集計ロジック設計 (Architecture & Aggregation)

### 2.1 新旧集計方式の比較

| 項目 | 既存実装 (REQ-289) | 是正後設計 (REQ-290) |
|---|---|---|
| **PDH カウンター** | `\GPU Engine(*engtype_3D)\Utilization Percentage` | `\GPU Engine(*)\Utilization Percentage` (全エンジン網羅) |
| **対象エンジン** | 3D 描画エンジンのみ | 3D, Compute 0/1, Copy, Video 等の全エンジン |
| **集計ロジック** | 3D インスタンスの全プロセス単純合算 (SUM) | 物理エンジン別プロセス合算の最大値 (MAX) |
| **ComfyUI 画像生成時** | 0.0% 〜 数%（Compute 負荷が捕捉不能） | **80% 〜 100%（Compute のピーク負荷を正確に反映）** |
| **ローカル LLM 推論時** | 0.0%（未検出） | **推論処理（Prefill/Decode）の稼働率を即座に反映** |
| **マルチアダプター分離** | アダプター不問で全 3D を合算 | **DXGI で特定したプライマリ GPU の LUID で厳密フィルタリング** |

## 3. 実装詳細仕様 (`backend/app/services/resource_monitor.py`)

### 3.1 DXGI LUID 保持の実装
`WindowsGpuMonitor` クラスのメンバに `self.primary_luid_hex: str | None = None` を追加。
`_detect_total_vram_gb` 内で最大 VRAM を持つアダプタを確定した際、以下のように LUID をフォーマットして保存する：
```python
# LUID のフォーマット: PDHインスタンス名は "0x00000000_0x00011e9f" のように HighPart_LowPart の形式
self.primary_luid_hex = f"0x{desc.AdapterLuid.HighPart:08x}_0x{desc.AdapterLuid.LowPart:08x}".lower()
```

### 3.2 PDH カウンター登録
`_init_pdh` 内で以下のようにカウンターパスを変更する：
```python
self._pdh.PdhAddEnglishCounterW(
    self._h_query, r"\GPU Engine(*)\Utilization Percentage", 0, ctypes.byref(h_gpu)
)
```

### 3.3 `_get_engine_max` 集計メソッドの新設
```python
def _get_engine_max(self, h_counter) -> float:
    """各物理エンジンのプロセス合算値を集計し、全エンジンの最大値 (MAX) を算出する"""
    if not self._initialized or not h_counter:
        return 0.0
    try:
        buf_size, item_count = ctypes.c_uint32(0), ctypes.c_uint32(0)
        self._pdh.PdhGetFormattedCounterArrayW(
            h_counter, self.PDH_FMT_DOUBLE, ctypes.byref(buf_size), ctypes.byref(item_count), None
        )
        if buf_size.value == 0:
            return 0.0
        buf = ctypes.create_string_buffer(buf_size.value)
        status = self._pdh.PdhGetFormattedCounterArrayW(
            h_counter, self.PDH_FMT_DOUBLE, ctypes.byref(buf_size), ctypes.byref(item_count), ctypes.cast(buf, ctypes.c_void_p)
        )
        if status != 0:
            return 0.0

        items = ctypes.cast(buf, ctypes.POINTER(self.ItemStruct))
        engine_totals: dict[str, float] = {}
        for i in range(item_count.value):
            item = items[i]
            if item.FmtValue.CStatus == 0:
                name = item.szName or ""
                # プライマリGPUの LUID が判明している場合は他アダプターのカウンターを除外
                if self.primary_luid_hex and self.primary_luid_hex not in name.lower():
                    continue
                # インスタンス名から物理エンジン種別 (engtype_Compute 0, engtype_3D 等) を抽出
                eng_id = name.split("engtype_")[-1] if "engtype_" in name else "default"
                engine_totals[eng_id] = engine_totals.get(eng_id, 0.0) + item.FmtValue.val.doubleValue

        if not engine_totals:
            return 0.0
        # タスクマネージャー仕様: 全エンジンのうち最も高い使用率 (MAX) を採用
        return round(min(100.0, max(engine_totals.values())), 1)
    except Exception:
        return 0.0
```

### 3.4 `collect` メソッドの更新
`self._get_sum(self._h_gpu, self.PDH_FMT_DOUBLE, is_double=True)` の呼び出しを `self._get_engine_max(self._h_gpu)` へ置換。
