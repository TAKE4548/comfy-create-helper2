# REQ-170: 吹き出し自体の回転および吹き出し複製・コピー機能 - 詳細設計書

## 1. 概要 (Overview)
セリフ編集機能において、吹き出し全体の回転制御（`rotation`）および吹き出しの複製・コピー＆ペースト（UIボタン・`Ctrl+C` / `Ctrl+V`）操作を提供し、SE（効果音）などの同一テキスト・装飾の複数配置やダイナミックな配置表現の作業効率を向上させる。

## 2. 影響範囲・アーキテクチャ (Architecture & Scope)
本改修はフロントエンド完結の機能拡張であり、バックエンドのスキーマ変更は不要（既存の `params.speech_bubbles` JSON構造に新規フィールド `rotation` が自然に追加・永続化される）。

### REQ-171 (縦書きパス軌道レイアウト) との整合性と前提条件
- 本設計は **REQ-171（縦書き時のパス軌道追従・接線回転補正）が先行または適用されている前提** で整合性を担保しています。
- REQ-170 による吹き出し全体の回転は `drawSpeechBubble` において最外周で `ctx.translate(cx, cy)` -> `ctx.rotate(rad)` として適用されるため、REQ-171 で実装される縦書き・横書き双方のパス軌道計算および文字の局所接線回転と干渉せず、パス軌道を描くテキストも含めて吹き出し全体が一体として指定角度へ正しく回転します。

### 変更対象ファイル
- `frontend/src/types/speechBubble.ts`: `BubbleStyleConfig` / `SpeechBubble` への `rotation` 定義追加およびスタイル抽出・初期値の更新。
- `frontend/src/utils/speechBubbleRenderer.ts`: Canvas描画時の回転変換（`ctx.save()`, `ctx.translate()`, `ctx.rotate()`, `ctx.restore()`）の実装。

  - 「複製」アクションおよびキーボードショートカット（`Ctrl+C` / `Ctrl+V`）によるクリップボード保持・新規吹き出し生成・自動オフセット配置・フォーカス制御。

### 3.2 Canvas 描画ロジック (`utils/speechBubbleRenderer.ts`)
`drawSpeechBubble` において、吹き出しの中心座標 `(cx, cy)` を基準に回転を適用：
```typescript
export function drawSpeechBubble(
  ctx: CanvasRenderingContext2D,
  bubble: SpeechBubble,
  isSelected = false,
  scaleX = 1,
  scaleY = 1,
  activeFontFamily?: string
): void {
  const rotation = bubble.rotation || 0
  const cx = (bubble.x + bubble.w / 2) * scaleX
  const cy = (bubble.y + bubble.h / 2) * scaleY

  ctx.save()
  if (rotation !== 0) {
    ctx.translate(cx, cy)
    ctx.rotate((rotation * Math.PI) / 180)
    ctx.translate(-cx, -cy)
  }

  drawBubbleShape(ctx, bubble, scaleX, scaleY)
  drawBubbleText(ctx, bubble, scaleX, scaleY, activeFontFamily)

  if (isSelected) {
    // 選択枠、リサイズハンドル、尻尾ハンドルも回転コンテキスト内で描画
    // ...
  }
  ctx.restore()
}
```

### 3.3 回転対応ヒットテスト (`SpeechBubbleEditorModal.tsx`)
マウス座標 `(x, y)` を吹き出し中心 `(cx, cy)` まわりに `-\theta` 回転させたローカル座標 `(localX, localY)` に変換してヒット判定：
```typescript
function getLocalPoint(x: number, y: number, bubble: SpeechBubble, scaleX: number, scaleY: number): { x: number; y: number } {
  const rotation = bubble.rotation || 0
  if (rotation === 0) return { x, y }
  const cx = (bubble.x + bubble.w / 2) * scaleX
  const cy = (bubble.y + bubble.h / 2) * scaleY
  const rad = (-rotation * Math.PI) / 180
  const dx = x - cx
  const dy = y - cy
  return {
    x: cx + (dx * Math.cos(rad) - dy * Math.sin(rad)),
    y: cy + (dx * Math.sin(rad) + dy * Math.cos(rad)),
  }
}
```

### 3.4 複製およびコピー＆ペースト仕様
- **UIボタン**: コントロールパネルに「📋 複製 (Duplicate)」ボタンを配置。
- **ショートカット**: `Ctrl+C` (Mac: `Cmd+C`) で選択中の吹き出しを内部クリップボード `copiedBubbleRef` に保持。
- **ペースト**: `Ctrl+V` (Mac: `Cmd+V`) でクリップボードの吹き出しをベースに新規IDを生成し、`x + 20`, `y + 20` のオフセット位置に配置して選択状態にする。
- **誤爆防止**: `document.activeElement` が `INPUT`, `TEXTAREA`, `SELECT` の場合はキーボードショートカットを無効化し、通常のテキスト操作を優先する。

## 4. 非機能要件・パフォーマンス
- Canvas 描画での `ctx.save()` / `ctx.restore()` のオーバーヘッドは極小であり、60fpsでのドラッグ移動・回転プレビューを維持。
- クリップボード情報はメモリ内の React Ref / State で管理し、ブラウザの外部クリップボード権限要求なしで安全・軽快に動作。
