# REQ-157 詳細設計書: 生成画面の各設定セクション（Parameters, ParamSync, Bypass等）の折りたたみ対応

## 1. 概要 (Overview)
生成画面（GeneratePage）において、プロンプト入力エリア以外（Parameters、ParamSync、Bypass）のセクションを個別に折りたたみ（Collapse）・展開（Expand）可能にし、特にモバイル画面や狭小画面での縦スクロール負担を軽減し、作業効率と視認性を向上させます。また、各セクションの開閉状態は `localStorage` に永続化され、再訪時や画面操作中もユーザーの好みの状態が維持されます。

---

## 2. 影響分析・対象範囲 (Scope & SSoT Impact)

### 影響を受けるファイル
1. **`frontend/src/utils/localStorageKeys.ts`** (MODIFY):
   - `LS_KEYS.GENERATE_SECTIONS_EXPANDED` 定数を追加。
2. **`frontend/src/pages/GeneratePage/components/ParamPanel.tsx`** (MODIFY):
   - `Parameters`、`Param Sync`、`Bypasses` の各セクションヘッダーに開閉トグルボタン（`ChevronDown` / `ChevronRight`）を導入。
   - セクション開閉状態（`isExpanded`）の管理と `localStorage` 永続化ロジックの実装。
   - `Param Sync` および `Bypass` のヘッダー部において、折りたたみ時にも `Settings` ボタンが利用可能なレイアウトを設計。
3. **`frontend/src/pages/GeneratePage/components/__tests__/ParamPanel.test.tsx`** (NEW):
   - 各セクションの開閉動作、初期状態、`localStorage` への保存・復元、設定ボタンのクリック動作を検証する単体テストを追加。

## 3. 詳細設計 (Detailed Design)

### 3.1 LocalStorage キー定義 (`frontend/src/utils/localStorageKeys.ts`)
```typescript
export const LS_KEYS = {
  ...
  GENERATE_SECTIONS_EXPANDED: 'prompt-surgeon-generate-sections-expanded',
} as const;
```

### 3.2 状態モデル (`ParamPanel.tsx`)
```typescript
export interface GenerateSectionsExpandedState {
  parameters: boolean;
  paramSync: boolean;
  bypass: boolean;
}

const DEFAULT_EXPANDED_STATE: GenerateSectionsExpandedState = {
  parameters: true,
  paramSync: true,
  bypass: true,
};
```

### 3.3 コンポーネント構造とUI仕様

#### 1. Parameters セクション
- **ヘッダー**:
  - クリック可能なトグルボタン（`<button type="button" onClick={() => toggleSection('parameters')}>`）。
  - アイコン: 開時 `ChevronDown` (size=14)、閉時 `ChevronRight` (size=14)。
  - ラベル: `Parameters`（テキスト色: `text-zinc-400 hover:text-zinc-200`）。
- **ボディ**:
  - `isExpanded.parameters === true` のときのみ `paramMappings` の各コントロール、`Batch Size`、`Seed` を表示。

#### 2. Param Sync セクション
- **ヘッダー**:
  - 左側: トグルボタン（`<button type="button" onClick={() => toggleSection('paramSync')}>`）。
    - アイコン: 開時 `ChevronDown` (size=12)、閉時 `ChevronRight` (size=12)。
    - ラベル: `PARAM SYNC`。
  - 右側: `Settings` ボタン（折りたたみ中も設定モーダルを起動可能）。
- **ボディ**:
  - `isExpanded.paramSync === true` のときのみ各グループのトグル一覧（または "No sync groups" メッセージ）を表示。

#### 3. Bypass セクション
- **ヘッダー**:
  - 左側: トグルボタン（`<button type="button" onClick={() => toggleSection('bypass')}>`）。
    - アイコン: 開時 `ChevronDown` (size=12)、閉時 `ChevronRight` (size=12)。
    - ラベル: `BYPASSES`。
  - 右側: `Settings` ボタン（折りたたみ中も設定モーダルを起動可能）。
- **ボディ**:
  - `isExpanded.bypass === true` のときのみ各プロファイルのトグル一覧（または "No profiles" メッセージ）を表示。

## 4. トレードオフ・リスク評価 (Trade-off & Risk Disclosure)
- **状態管理の局所性 vs グローバル性**:
  - `ParamPanel` の折りたたみ状態は当該パネル内部のUI表示状態であり、他のページやグローバルストアで直接参照する必要がないため、`ParamPanel` 内部で `useState` + `localStorage` を用いてカプセル化します。これにより不要なプロップバケツリレーや再レンダリングの波及を防ぎます。
- **デフォルト値の選定**:
  - 初回利用時やすべてのセクションを一覧したいユーザーのために、デフォルトはすべて `true`（展開状態）とし、ユーザーの明示的な折りたたみ操作によってのみコンパクト化されます。
