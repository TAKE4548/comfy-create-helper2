# Design Specification: REQ-106 ノードマッピングにおけるBoolean型のサポート

本ドキュメントは、ノードマッピングのデータ型として `Boolean` 型をサポートし、生成画面上のパラメータパネルで直感的なトグルスイッチ操作を可能にするための設計仕様を定義する。

## 1. 目的・背景
現在、ノードマッピングで定義できるデータ型（`input_type`）には `textarea`, `int`, `float`, `select`, `lora_stack`, `select_sampler`, `select_scheduler` が存在するが、真偽値（`true` / `false`）を扱う型が存在しない。
Boolean型のパラメータを扱う場合も他の型で代用する必要があり、設定時に選択肢がない問題や、入力UIとしてテキストフィールド等が表示されてしまうためON/OFFのスイッチ操作が行えない問題がある。
これらを解消し、直感的なトグルスイッチUIを通じてBoolean型の値を扱えるようにする。

## 2. 要件仕様
1. **データ型 `boolean` の追加**
   - マッピングマスター（`MappingMaster`）の `input_type` として `'boolean'` を追加する。
   - 設定画面（`SettingsPage` および `SettingsComponents.tsx`）のマッピングマスター作成・編集・一括更新画面において、「boolean」をデータ型（Input Type）として選択可能にする。
2. **トグルスイッチUIの提供**
   - 生成画面のパラメータ編集パネル（`ParamPanel.tsx`）において、マッピングの `input_type` が `'boolean'` の場合、数値入力やテキストボックスの代わりに、ON/OFFの状態を表すトグルスイッチUIを表示する。
3. **パラメータのシリアライズ・パース処理**
   - パラメータ初期値取得時（`getInitialParams`）は、ワークフローJSONから取得した真偽値（`true` / `false`）を `String()` によって `"true"` / `"false"` の文字列として管理する。
   - パラメータ保存時（`useWorkflowParams.ts` 内の `handleSaveDefaultParams`）および生成実行時（`useGenerateAction.ts` 内の `val` 構築部）において、`input_type === 'boolean'` の場合は `paramValues[m.role] === 'true'` で評価した真の真偽値（`boolean`型）をパラメータ値としてセットし、ワークフローJSON/ペイロードに反映する。

## 3. 画面設計・UIプロトタイプ

### 3-1. パラメータパネルにおけるトグルスイッチUI
```
+---------------------------------------+
| Parameters                            |
+---------------------------------------+
|  Enable Detailer  [      o- ] (ON)   |
|  Use Secondary    [ -o      ] (OFF)  |
+---------------------------------------+
```
- スイッチ全体は角丸のピル形状（`rounded-full`）。
- ON状態（値が `"true"` の場合）は、背景色がアクセントカラー（`bg-accent-green`）になり、丸いノブが右側にスライドする。
- OFF状態（値が `"false"` または未定義の場合）は、背景色が暗いグレー（`bg-zinc-700`）になり、丸いノブが左側に配置される。
- ノブの移動は CSS Transition を用いてスムーズにアニメーションさせる。

## 4. 影響範囲と実装方針

### 4-1. フロントエンドの型定義の更新
- **ファイル**: `frontend/src/api/types.ts`
  - `MappingMaster` の `input_type` ユニオン型に `'boolean'` を追加。

### 4-2. マッピングマスター作成・編集UIの更新
- **ファイル**: `frontend/src/components/SettingsComponents.tsx`
  - `MappingMasterFormState` の `inputType` に `'boolean'` を追加。
  - `MappingMasterModal` の選択肢（`option`）に `'boolean'` を追加。
- **ファイル**: `frontend/src/pages/SettingsPage.tsx`
  - `bulkUpdateMasters` の `input_type` オプションに `{ id: 'boolean', name: 'boolean' }` を追加。

### 4-3. パラメータ入力UIの更新
- **ファイル**: `frontend/src/pages/GeneratePage/components/ParamPanel.tsx`
  - `m.input_type === 'boolean'` のハンドリングを追加。
  - トグルスイッチ風の `<button>` 要素と `<span className="thumb">` を用いたスタイリッシュなトグルスイッチをレンダリングする。ON/OFFの切り替え時に `setParamValues` を用いて `"true"` または `"false"` 文字列を切り替えてストアに格納する。

### 4-4. 保存および生成APIへの値マッピングの更新
- **ファイル**: `frontend/src/pages/GeneratePage/hooks/useWorkflowParams.ts`
  - `handleSaveDefaultParams` にて、`m.input_type === 'boolean'` の場合、`val = paramValues[m.role] === 'true'` (Boolean型) としてワークフローJSONに書き込む。
- **ファイル**: `frontend/src/pages/GeneratePage/hooks/useGenerateAction.ts`
  - シーン生成実行ペイロードを作成する際、`m.input_type === 'boolean'` の場合、同様に `val = paramValues[m.role] === 'true'` として値をセットする。
