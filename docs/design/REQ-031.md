# 設計書 - REQ-031: ComfyUIキュー内のジョブ数表示機能の追加

## 1. 目的と概要
生成画面において、ComfyUIのサーバー負荷状況や自身のキュー待機列をリアルタイムで視覚的に把握できるよう、キュー待機ジョブ数と進捗率を常時表示するインジケーターを追加します。
「自セッションのみ」フィルターと連動し、チェックボックスの状態に応じて表示件数を切り替えます。

## 2. 詳細設計

### 2.1 状態管理の拡張 (`useGenerationStore.ts`)

#### 状態フィールドの追加
`GenerationState` に以下の状態を追加します。
- `queueRunning`: 現在実行中のジョブ一覧（clientIdなどのメタデータを含む）
- `queuePending`: 待機列に入っているジョブ一覧

```typescript
export interface GenerationState {
  // ...既存のフィールド...
  queueRunning: Array<[number, string, any, { client_id?: string }, any]>
  queuePending: Array<[number, string, any, { client_id?: string }, any]>
  fetchQueue: () => Promise<void>
}
```

#### キュー情報の取得・同期ロジック
1. **`fetchQueue` の実装**:
   `/queue` エンドポイントから最新のキュー情報を取得し、`queueRunning` と `queuePending` に格納します。
2. **WebSocketイベントとの同期**:
   以下のタイミングで `fetchQueue` を呼び出し、リアルタイムにキュー数を同期します。
   - WebSocket接続が確立された時 (`ws.onopen`)
   - `status` イベント受信時 (キュー情報が更新された時)
   - `execution_start` / `executed` / `execution_complete` / `execution_error` イベント受信時
   - ジョブが正常にキューに投入された時 (`queuePrompt` 完了時)
   - ジョブがキャンセルされた時 (`cancelGeneration` 完了時)

### 2.2 フロントエンドUI表示 (`GeneratePage.tsx`)

#### モバイルビュー・サイドバー
`Progress Line` 領域を、生成中か否かに関わらず常時表示するように変更します。
- 表示テキスト: `Ready` (待機時) / `Generating...` (生成中)
- キュー数: `Queue: {件数}`
  - 「自セッションのみ」フィルターが有効な場合、`clientId` が一致するジョブ数のみを集計。
  - 無効な場合は、全ジョブ数を集計。
- 進捗率: 生成中は進捗のパーセンテージ、未生成時は `0%` を表示。

#### デスクトッププレビュー領域
プレビュー画像の下部に、控えめで洗練されたステータスバーを常時表示します。
- 構造:
  - 上部: 進捗表示用スリムゲージ (4px)
  - 下部: ステータスバー (`Ready` / `Generating...` / `Queue: {件数}` / `進捗率%`)

## 3. 影響範囲
- `frontend/src/store/useGenerationStore.ts`: キューの状態管理および同期ロジックの追加
- `frontend/src/pages/GeneratePage.tsx`: UIコンポーネントの表示切り替え・レイアウトの統合
