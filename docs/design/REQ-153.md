# REQ-153 詳細設計書: タッチ操作端末における並び替えドラッグ操作とOS標準挙動の競合解消（PC全域ドラッグ＋タッチ専用ハンドル＋生成履歴ロングタップ対応）

## 1. 概要 (Overview)
`TagsPage`、`LoRAsPage`、`HistoryPage`、`PresetManagerPanel`、`SettingsPage`、`TagChipEditor` などの並び替え対応UI、および `GeneratePage`（生成画面の履歴サムネイルバー）における一括選択ロングタップにおいて、操作環境（PCマウス操作 vs モバイル/タブレットのタッチ操作）の特性に合わせた最適なインタラクション体験を実現する。

### 基本方針
1. **PC（マウス操作環境）**:
   - 誤爆やスクロール競合の心配がないため、カード型一覧では**カード全体をドラッグ判定領域**として維持する（`MouseSensor` / `distance: 8px`）。
   - クリック（移動なし）は詳細モーダル表示、複数選択（Ctrl/Shift+Click）も従来通りシームレスに機能する。
2. **タッチ操作環境（スマートフォン・タブレット）**:
   - カード型一覧では、タッチ操作時のみ有効となる**明示的なドラッグハンドル（`<GripVertical>`）**を提供し、ハンドルに `touch-action: none` を常時適用する。
   - カード本体のタッチではD&Dを発動させず、「スワイプによる画面スクロール」「タップによる詳細表示」「長押しによる一括選択」に専念させる。
   - ドラッグハンドルをタッチした時のみ、即時（`distance: 5px`）にD&Dが発動し、Android Chromeでのスクロール誤奪取を防止する。
3. **生成画面の履歴サムネイルバー（GeneratePage）および共通長押し（useMultiSelect）のOSメニュー競合解消**:
   - `GeneratePage`（`DesktopLayout.tsx`, `MobileLayout.tsx`）の履歴サムネイル画像、および各画面のカードに対して、`-webkit-touch-callout: none`、`user-select: none`、`onContextMenu={(e) => e.preventDefault()}` を適用。
   - モバイルOS（iOS / Android）の画像長押しコンテキストメニュー（「画像を保存」「画像をコピー」等）によるロングタップ一括選択の割り込み・中断を防止する。

## 3. 詳細設計 (Detailed Design)

### 3.1 ハイブリッド・リスナー分離アーキテクチャ
```tsx
function SortableCard({ id, children, disabled }: SortableCardProps) {
  const { attributes, listeners, setNodeRef, transform, transition, isDragging } = useSortable({ id, disabled });

  const mouseListeners = {
    onMouseDown: listeners?.onMouseDown,
    onKeyDown: listeners?.onKeyDown,
  };

  const touchHandleListeners = {
    onTouchStart: listeners?.onTouchStart,
    onMouseDown: listeners?.onMouseDown,
  };

  const style = {
    transform: CSS.Transform.toString(transform),
    transition,
    opacity: isDragging ? 0.5 : 1,
    zIndex: isDragging ? 50 : 1,
  };

  return (
    <div ref={setNodeRef} style={style} {...attributes} {...mouseListeners}>
      {children({ dragHandleProps: { ...touchHandleListeners, isDragging } })}
    </div>
  );
}
```

### 3.2 履歴サムネイル・長押し選択のOSメニュー抑止
```tsx
// GeneratePage DesktopLayout / MobileLayout 履歴サムネイル
<button
  key={i}
  type="button"
  id={`thumb-${i}`}
  onMouseDown={longPressHandlers.onMouseDown}
  onMouseUp={longPressHandlers.onMouseUp}
  onMouseLeave={longPressHandlers.onMouseLeave}
  onTouchStart={longPressHandlers.onTouchStart}
  onTouchEnd={longPressHandlers.onTouchEnd}
  onContextMenu={(e) => e.preventDefault()}
  style={{ WebkitTouchCallout: 'none', userSelect: 'none' }}
  onClick={(e) => { ... }}
  className="select-none ..."
>
  <img src={img} alt={`Generated ${i + 1}`} className="w-full h-full object-cover pointer-events-none" />
</button>
```

## 4. 期待される効果
- **PCユーザー**: カード全域ドラッグによる軽快な操作感をそのまま維持。
- **タッチ/モバイルユーザー**:
  - D&D並び替えが画面スクロールに邪魔されず、ドラッグハンドルで100%確実に発動。
  - 生成画面の履歴サムネイルや一覧画面のカードで、OS標準メニュー（画像保存等）に邪魔されず、長押し一括選択が安定して動作。
