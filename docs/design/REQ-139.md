# REQ-139 詳細設計書: 画像保存時のアルバム選択状態の保持

## 1. 概要 (Overview)
生成画像のスナップショット保存時（GeneratePage 上での AddSnapshotToAlbumModal 表示時）、モーダルを開くたびに選択アルバムがリセットされ、毎回目的のアルバムを選び直す必要がありました。
本設計では、ユーザーが最後に選択・保存したアルバムIDを localStorage に保持し、次回モーダル表示時に前回選択したアルバムを自動的に初期選択状態とする仕組みを導入します。

---

## 2. 影響分析・対象範囲 (Scope & SSoT Impact)

### 影響を受けるファイル
1. frontend/src/utils/localStorageKeys.ts (MODIFY):
   - 保存先アルバムID用のストレージキー定数 LAST_SAVE_ALBUM_ID を定義。
2. frontend/src/components/AddSnapshotToAlbumModal.tsx (MODIFY):
   - storageKey?: string プロパティを受け取れるように拡張。
   - モーダルオープン時、storageKey が指定されていれば localStorage から保存値を取得して selectedAlbumId に初期反映。
   - アルバム一覧取得後、保持されていたアルバムIDが存在しない（削除済み等）場合は安全に未選択（またはデフォルト）へフォールバック。
   - 保存確定時（handleConfirm）、選択中のアルバム状態（ID数値または未選択）を localStorage に更新。
3. frontend/src/pages/GeneratePage.tsx (MODIFY):
   - AddSnapshotToAlbumModal 呼び出し箇所に storageKey={LS_KEYS.LAST_SAVE_ALBUM_ID} を設定。
4. frontend/src/components/__tests__/AddSnapshotToAlbumModal.test.tsx (NEW):
   - 前回選択の復元、削除済みアルバムへのフォールバック、保存時のlocalStorage更新に関する単体テストを追加。

## 3. 詳細設計 (Detailed Design)

### 3.1 キー定数の追加 (localStorageKeys.ts)
`	s
export const LS_KEYS = {
  ...
  LAST_SAVE_ALBUM_ID: 'prompt-surgeon-last-save-album-id',
} as const;
`

### 3.2 モーダルへの状態復元・永続化ロジック追加 (AddSnapshotToAlbumModal.tsx)
`	sx
interface AddSnapshotToAlbumModalProps {
  isOpen: boolean
  onClose: () => void
  onConfirm: (data: { albumId: number | null; newAlbumName?: string }) => Promise<void> | void
  isPending?: boolean
  confirmText?: string
  title?: string
  allowNone?: boolean
  storageKey?: string
}
`

- **初期化ロジック**:
  `	sx
  useEffect(() => {
    if (isOpen) {
      if (storageKey) {
        const saved = localStorage.getItem(storageKey)
        if (saved === '' || saved === 'none') {
          setSelectedAlbumId(allowNone ? '' : 'new')
        } else if (saved !== null && !isNaN(Number(saved)) && Number(saved) > 0) {
          setSelectedAlbumId(Number(saved))
        } else {
          setSelectedAlbumId(allowNone ? '' : 'new')
        }
      } else {
        setSelectedAlbumId(allowNone ? '' : 'new')
      }
      setNewAlbumName('')
      setSearchQuery('')
      setIsDropdownOpen(false)
    }
  }, [isOpen, allowNone, storageKey])
  `

- **存在チェックとフォールバック**:
  `	sx
  useEffect(() => {
    if (isOpen && albums && albums.length > 0 && typeof selectedAlbumId === 'number') {
      const exists = albums.some((a) => a.id === selectedAlbumId)
      if (!exists) {
        setSelectedAlbumId(allowNone ? '' : 'new')
      }
    }
  }, [isOpen, albums, selectedAlbumId, allowNone])
  `

- **保存確定時の更新**:
  `	sx
  const handleConfirm = () => {
    if (selectedAlbumId === 'new' && !newAlbumName.trim()) return
    if (storageKey) {
      if (typeof selectedAlbumId === 'number') {
        localStorage.setItem(storageKey, String(selectedAlbumId))
      } else if (selectedAlbumId === '') {
        localStorage.setItem(storageKey, '')
      }
    }
    onConfirm({
      albumId: typeof selectedAlbumId === 'number' ? selectedAlbumId : null,
      newAlbumName: selectedAlbumId === 'new' ? newAlbumName.trim() : undefined,
    })
  }
  `

## 4. 非機能要件・アクセシビリティ
- ローカルストレージが無効な環境（プライベートブラウズ等）でも例外を発生させず安全に動作。
- 既存の HistoryPage 等で storageKey を渡さない場合は従来通りの動作を保ち、リグレッションを防止。
