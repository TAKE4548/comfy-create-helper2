# REQ-108 設計書: Scene Generator – Animaモード & シーン名プロファイル保存

## 1. 概要

Scene Generator に以下の2つの機能を追加する。

1. **シーン名フィールド（共通）**: 各シーン入力行に「シーン名」テキストフィールドを追加し、保存時にそのシーン名をプロファイル名として使用する。
2. **Animaモード**: Qwen系CLIPを搭載したAnimaチェックポイント向けに、日本語のシーン概要から文脈を理解しつつ、Animaに解釈されやすい英語表現へ翻訳する専用モードを追加する。推論に使用するLLMはLM Studio（既存の設定）を継続使用し、専用のシステムプロンプトを設定画面で管理する。

---

## 2. アーキテクチャ概要

```
[SceneGeneratorModal (FE)]
  ├─ シーン名 input (新規) → save時にプロファイル名として使用
  ├─ Animaモード トグル (新規) → anima_mode フラグをリクエストに付与
  └─ Generate Drafts ──→ POST /api/llm-prompts/scene-generate
                             payload: { ..., anima_mode: bool }
                                  ↓
[llm_prompts router (BE)]
  └─ run_scene_generate( anima_mode=True/False )
                                  ↓
[llm_service (BE)]
  ├─ anima_mode=False → DBキー "scene_generate" のシステムプロンプトを使用
  └─ anima_mode=True  → DBキー "scene_generate_anima" のシステムプロンプトを使用
                                  ↓
[Settings Page (FE/BE)]
  └─ "scene_generate_anima" キーがプロンプト設定エリアに表示される (PROMPT_LABELS追加)
```

## 3. 変更対象ファイルと詳細

### 3.1 Backend: スキーマ拡張

**ファイル**: `backend/app/schemas/audit.py`

- `SceneGenerateRequest` に `anima_mode: bool = False` フィールドを追加する。
- `SceneItem` はバックエンド側では変更不要（`name` はフロント専用）。

```python
# Before
class SceneGenerateRequest(BaseModel):
    target_fields: list[str]
    base_params: dict[str, str]
    scenes: list[SceneItem]

# After
class SceneGenerateRequest(BaseModel):
    target_fields: list[str]
    base_params: dict[str, str]
    scenes: list[SceneItem]
    anima_mode: bool = False          # 新規追加
```

### 3.2 Backend: サービス層

**ファイル**: `backend/app/services/llm_service.py`

- `run_scene_generate` 関数に `anima_mode: bool = False` 引数を追加。
- `anima_mode=True` の場合、DBキー `"scene_generate_anima"` を参照してシステムプロンプトを取得する。
- フォールバック用 `_default_scene_generate_anima_prompt()` を追加。
  - Animaモードのデフォルトプロンプトは「Danbooru短縮タグでなく自然言語に近い説明的な英語表現を優先する」旨を指示する。

```python
# run_scene_generateのシグネチャ変更
async def run_scene_generate(
    target_fields: list[str],
    base_params: dict[str, str],
    scenes: list[dict],
    system_prompt_override: str | None = None,  # 既存（通常モード用）
    anima_mode: bool = False,                    # 新規追加
) -> list[dict]:
    # anima_mode=True なら anima_prompt_override を優先
    if anima_mode:
        sp = anima_prompt_override or _default_scene_generate_anima_prompt()
    else:
        sp = system_prompt_override or _default_scene_generate_prompt()
```

**注意**: 呼び出し元（router）から `anima_mode` に応じた DBレコードを取得して渡す形に変更する（後述）。

### 3.3 Backend: ルーター

**ファイル**: `backend/app/routers/llm_prompts.py`

- `scene_generate` エンドポイントで `payload.anima_mode` を見て適切なDBキーを選択する。

```python
@router.post("/scene-generate", response_model=list[schemas.SceneDiffParams])
async def scene_generate(payload: schemas.SceneGenerateRequest, db: Session = Depends(get_db)):
    from app.services.llm_service import run_scene_generate
    
    prompt_key = "scene_generate_anima" if payload.anima_mode else "scene_generate"
    prompt_record = db.query(models.LlmPrompt).filter(models.LlmPrompt.key == prompt_key).first()
    system_prompt_override = prompt_record.content if prompt_record else None
    
    try:
        scenes_list = [{"id": s.id, "summary": s.summary} for s in payload.scenes]
        results = await run_scene_generate(
            target_fields=payload.target_fields,
            base_params=payload.base_params,
            scenes=scenes_list,
            system_prompt_override=system_prompt_override,
            anima_mode=payload.anima_mode,
        )
        return results
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))
```

## 4. データフロー（Animaモード ON の場合）

```
1. ユーザーがSceneGeneratorを開き「Animaモード」をONにする
2. 各シーン行に「シーン名」を入力（例: "夕暮れカフェ"）
3. 日本語でシーン概要を入力（例: "雨の日の夕方、カフェの窓際で..."）
4. 「Generate Drafts」ボタン押下
5. FE: POST /api/llm-prompts/scene-generate
      { ..., anima_mode: true }
6. BE router: DBキー "scene_generate_anima" のプロンプトを取得
7. BE service: LM Studio に Anima専用システムプロンプトで呼び出し
8. 結果: Animaに解釈しやすい英語表現でJSON返却
9. FE: ドラフト確認画面へ遷移（編集可能）
10. 「プロファイルを作成」ボタン押下
11. FE hook: scene.name="夕暮れカフェ" → プロファイル名として保存
12. workflowPresetsApi.create({ name: "夕暮れカフェ", ... })
```

## 5. トレードオフ開示（Trade-off Disclosure）

| 項目 | 内容 |
|------|------|
| **シーン名の必須化** | シーン名を任意フィールドとしたため、未入力時は概要文の先頭40文字がプロファイル名になる。ユーザーが空欄のまま保存した際の名前が長くなる可能性がある。 |
| **anima_modeのDB管理なし** | Animaモードのフラグはリクエスト毎にFEから送信する設計であり、DBでモードを永続化しない。次回起動時にはデフォルト(OFF)に戻る。一貫性よりシンプルさを優先した。 |
| **seed_data追加の再実行** | `scene_generate_anima` キーはseedデータとして追加するが、既存DBに自動反映されない。初回起動時のseed挿入ロジック（`init_db`）に依存するか、手動でDB更新が必要になる場合がある（既存の`upsert`挙動を確認要）。 |
| **_default promptのみで品質確保は難しい** | Animaモードの初期品質はデフォルトプロンプトに依存する。ユーザーが設定画面でプロンプトをカスタマイズすることで品質を向上させる想定。 |
