# REQ-046 設計書: プレビューのウィンドウフルサイズ対応

## 1. 概要
本設計は、生成画面のメインプレビューおよびスナップショット一覧画面（アルバム含む）において、画像の細部確認や快適な画像送りを実現するため、ウィンドウ全体に合わせたアスペクト比維持のフルサイズプレビュー機能（モーダル表示）を提供します。
また、スナップショット一覧やアルバムなどのメタデータが存在する画面においては、フルサイズ表示と現行の「メタ情報表示＋縮小画像」モードをトグルスイッチで切り替え可能にします。

## 2. 変更方針

### 2.1 モーダルプレビュー (`HistoryModalPreview.tsx`) のモード追加
プレビューモーダルに、以下の2つの表示モードをサポートさせます。
- **Mode A (フルサイズ表示 - `full`):**
  - 画像をアスペクト比維持のまま、ウィンドウの長辺（縦または横）いっぱいまで拡大表示します。
  - 背景は暗めの半透明（`bg-black/90` などのオーバーレイ）。
  - メタ情報パネルは非表示。
  - 左右の画像送りボタン、右上の閉じるボタン、およびタッチ環境でのスワイプ操作を提供します。
  - メタデータ（スナップショットID）が存在する場合、右下に「情報表示用アイコン（Infoアイコン）」を表示し、クリックすることで Mode B に切り替えます。
- **Mode B (メタ情報＋縮小プレビュー表示 - `info`):**
  - 現行のレイアウト（上部60vhに画像プレビュー、下部にメタ情報パネル）。
  - 右上の閉じるボタン、左右の画像送りボタン、スワイプ操作を提供します。
  - 画像表示エリアの右下に「フルサイズ表示アイコン（Maximize/Infoトグル）」を表示し、クリックすることで Mode A に戻します。

### 2.2 初期状態の制御
- モーダルが開いたとき (`isOpen` が `true` に遷移したとき)、デフォルトの表示モードを **Mode A (フルサイズ表示 - `full`)** に初期化します。
- スナップショットIDなどのメタデータが存在しない画像（一時生成画像など）の場合、メタ情報の表示・トグル切り替えアイコンは非表示（または無効化）とし、常時 Mode A とします。

### 2.3 生成画面のメインプレビューとの連携
- 生成画面 (`GeneratePage.tsx`) のメインプレビュー画像（デスクトップ・モバイル双方）をクリック・タップした際に、該当画像インデックスを指定して `HistoryModalPreview` モーダルを開くように変更します。

## 3. フロントエンド変更

### 3.1 プレビューモーダルコンポーネント (`frontend/src/components/HistoryModalPreview.tsx`)
- `viewMode` 状態 (`'full' | 'info'`) を追加。
- `isOpen` が変化した際に `viewMode` を `'full'` にリセットする `useEffect` を追加。
- 表示モードに応じた条件付きレンダリングと CSS クラスの制御：
  - **Mode A (`full`):**
    - 全画面表示用のラッパーレイアウト。画像表示エリアを `h-[100vh]` または `flex-1 h-full` に拡張し、メタ情報パネルを非表示にします。
    - 右下に `lucide-react` の `Info` アイコンを表示。クリックで `viewMode` を `'info'` に設定。
  - **Mode B (`info`):**
    - 画像表示エリアを `h-[60vh]` に制限し、下部にメタ情報パネルを表示（現行通り）。
    - 画像表示エリアの右下に `lucide-react` の `Maximize2` または `Image` アイコンなどを表示。クリックで `viewMode` を `'full'` に戻す。

### 3.2 生成画面 (`frontend/src/pages/GeneratePage.tsx`)
- メインプレビュー画像（デスクトップ/モバイル）のラッパー要素に `cursor-pointer` クラスと `onClick` ハンドラを追加。
- `onClick` ハンドラ内で、現在表示中の画像 (`previewImage || selectedImg`) が `sortedDisplayImages` の中で何番目か（インデックス）を算出し、`modalPreviewIndex` に設定した上で `setIsModalPreviewOpen(true)` を呼び出す。
- ダウンロードボタンや画像送りボタン、読み込み中表示などの子要素に対して `e.stopPropagation()` を追加し、モーダルが開くイベントの伝搬を防ぐ。

### 3.3 スナップショット一覧・アルバム画面 (`frontend/src/pages/HistoryPage.tsx`)
- 既存の画像クリックからモーダルを開く処理はそのまま維持（モーダル側がデフォルトで Mode A (フルサイズ) で起動するため、追加の変更は最小限）。
