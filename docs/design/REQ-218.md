# REQ-218: 生成プリセット一括編集におけるプロンプト先頭・末尾追加時のデリミタ付与不具合の修正 詳細設計書

## 1. 概要 (Overview)
生成画面のプロファイル一括編集（`ProfileBulkEditModal`）において、プロンプトタブから操作種別「先頭に追加（`prefix`）」または「末尾に追加（`suffix`）」を指定して適用した際、既存プロンプトと追加プロンプトがデリミタなしで単純結合（`op.value! + current` / `current + op.value!`）され、既存の先頭/末尾タグと結合して破損する不具合を解消する。

具体的には、プロンプト文字列操作ユーティリティ（`frontend/src/utils/promptUtils.ts`）に `prependToPrompt` および `appendToPrompt` を新設し、カンマおよび空白の正規化を行いながら安全に結合する処理を実装した上で、`frontend/src/pages/GeneratePage/hooks/usePresetState.ts` の `handleBulkEditApply` でこれらを利用するように改修する。

## 3. 詳細ロジック設計 (Detailed Logic Design)

### 3.1 結合ユーティリティ (`promptUtils.ts`)
プロンプト文字列の先頭・末尾へのタグ追加において、以下の仕様を満たす純粋関数を定義する。

```typescript
/**
 * Trims leading/trailing commas and whitespace from a prompt snippet.
 */
function cleanPromptSnippet(str: string): string {
  if (!str) return ''
  return str.trim().replace(/^[\s,]+|[\s,]+$/g, '').trim()
}

/**
 * Prepends a prefix string to an existing prompt with proper comma delimiter.
 */
export function prependToPrompt(prompt: string, prefix: string): string {
  const cleanPrefix = cleanPromptSnippet(prefix)
  const cleanExisting = cleanPromptSnippet(prompt)
  if (!cleanPrefix) return cleanExisting
  if (!cleanExisting) return cleanPrefix
  return `${cleanPrefix}, ${cleanExisting}`
}

/**
 * Appends a suffix string to an existing prompt with proper comma delimiter.
 */
export function appendToPrompt(prompt: string, suffix: string): string {
  const cleanSuffix = cleanPromptSnippet(suffix)
  const cleanExisting = cleanPromptSnippet(prompt)
  if (!cleanSuffix) return cleanExisting
  if (!cleanExisting) return cleanSuffix
  return `${cleanExisting}, ${cleanSuffix}`
}
```

### 3.2 一括編集適用ロジック (`usePresetState.ts`)
`usePresetState.ts` の `handleBulkEditApply` における該当箇所を改修：

```typescript
// 改修前:
} else if (op.op === 'prefix') {
  newParamValues[field] = op.value! + current
} else if (op.op === 'suffix') {
  newParamValues[field] = current + op.value!
}

// 改修後:
} else if (op.op === 'prefix') {
  newParamValues[field] = prependToPrompt(current, op.value ?? '')
} else if (op.op === 'suffix') {
  newParamValues[field] = appendToPrompt(current, op.value ?? '')
}
```

## 4. トレードオフおよびリスク開示 (Trade-off Disclosure)
- **既存の空白・改行の扱い**:
  - `cleanPromptSnippet` は先頭・末尾の空白およびカンマを除去（trim）して `, ` で結合する。タグの内部にある改行や空白（例: `quality, \n 1girl`）は維持されるが、文字列全体の先頭/末尾にあった改行は除去される。AI画像生成プロンプトにおいて先頭・末尾の改行・カンマは意味をなさないため、この正規化は品質向上に寄与し副作用はない。
- **既存の空文字プリセットへの適用**:
  - プリセットの該当フィールドが空文字列 `""` の場合、デリミタは付与されず追加テキストのみが設定されるため、ゴミデータ（`, tag` など）が生成される懸念はない。

## 5. 受け入れ基準 (Acceptance Criteria) とテスト方針
- [ ] **AC-1**: `prefix` 操作時、既存プロンプトが存在する場合に追加テキストとの間にカンマ区切り（`, `）が付与される。
- [ ] **AC-2**: `suffix` 操作時、既存プロンプトが存在する場合に既存テキストとの間に追加テキストがカンマ区切り（`, `）で付与される。
- [ ] **AC-3**: 既存プロンプトが空文字（または空白・カンマのみ）の場合、追加テキストのみが設定され前後に不要なカンマが付与されない。
- [ ] **AC-4**: 既存プロンプトや追加テキストの前後にカンマや空白が含まれていても、重複カンマ（`, , `）にならず正規化されて結合される。
- [ ] **AC-5**: 単体テスト（`promptUtils.test.ts` および `useGeneratePageState.test.tsx`）がすべてパスする。
