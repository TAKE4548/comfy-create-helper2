# REQ-049 テストプラン: JobManagementModal 黒画面バグ修正

## 1. テスト戦略

本修正は純粋な React hooks 順序の修正であるため、ブラウザ上での手動確認が主体。
単体テストは hooks の副作用を検証するよりも、実際のモーダル表示確認が適切。

## 2. 手動確認シナリオ

### TC-01: モーダル正常表示確認（基本）
- **手順**:
  1. 生成ページを開く
  2. Progress Line 内「Queue: N」テキストをクリックする
- **期待結果**: `JobManagementModal` が正常にオーバーレイ表示される（黒画面にならない）
- **AC対応**: AC-1

### TC-02: React コンソールエラーなし確認
- **手順**:
  1. ブラウザ DevTools > Console を開く
  2. TC-01 を実行する
- **期待結果**: "Rendered more hooks than during the previous render" / "change in the order of Hooks" エラーが出ない
- **AC対応**: AC-2

### TC-03: 再開閉テスト
- **手順**:
  1. TC-01 を実行（モーダルを開く）
  2. 「閉じる」ボタンまたはオーバーレイをクリックして閉じる
  3. 再度「Queue: N」をクリックして開く
- **期待結果**: 2回目以降も正常表示される
- **AC対応**: AC-3

### TC-04: 生成中のモーダル表示
- **手順**:
  1. 画像生成を開始する（Generate Batch）
  2. 生成中に「Queue: N」をクリックする
- **期待結果**: progress 更新中でもモーダルが正常表示される
- **AC対応**: AC-4

### TC-05: キャンセル操作確認
- **手順**:
  1. ComfyUI でジョブがキューに存在する状態でモーダルを開く
  2. 個別ジョブの削除ボタンをクリックする
  3. 「一括キャンセル」ボタンをクリックする（確認ダイアログで OK）
- **期待結果**: ジョブがキューから削除される
- **AC対応**: AC-5

## 3. 実行コマンド（開発サーバー起動）

```bash
cd frontend
npm run dev
```

ブラウザで `http://localhost:5173` を開いてテストを実施する。

## 4. 回帰テスト範囲

本修正は `JobManagementModal.tsx` 1ファイルのみの変更であり、影響範囲は限定的。
以下を念のため確認する：

- モーダルのレイアウト崩れがないこと（useMemo 移動による副作用がないこと）
- 「実行中のジョブ」「待機中のキュー」の表示フィルターが正常に動作すること
