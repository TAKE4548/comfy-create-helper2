# PBI-REQ-007 実行可能テスト計画 (AI耐性強化版)

## 1. 自動テスト・ビルド検証 (CLI Verification)
- **ビルド確認**: フロントエンドのTypeScriptビルドが正常に通ることを検証します。
  - コマンド: `npm run build` (frontend ディレクトリ内)
  - 判定基準: エラー出力が0件、警告が許容範囲内であること。
- **静的解析**: ESLintまたは型チェックを実行します。
  - コマンド: `npm run lint` または `npx tsc --noEmit`
  - 判定基準: エラー出力が0件であること。

## 2. ブラウザ検証 (Browser Verification)
- **対象URL**: `http://localhost:5173/tags` (Vite 開発サーバー起動時)
- **テストケース一覧**:

  ### A. レイアウト構造検証 (DOM構造確認必須)
  - **判定基準**: 開発者ツールのElementsタブ等で、タグセットの一覧コンテナ要素にグリッドクラス `grid` およびレスポンシブ用のカラム幅定義（`grid-cols-2 md:grid-cols-3` 等）が適用されていることを確認する。
  - **判定基準**: リスト用の `ul/li` タグによる縦一列配置ではなく、カード型要素がグリッドコンテナ内に配置されていることを確認する。

  ### B. コンテンツ表示検証 (テキスト・属性確認必須)
  - **判定基準**: 各カード内のタイトルにタグセット名が配置され、その直下等にタグ数を表示するテキスト（例: "X tags"）が配置されていることを確認する。
  - **判定基準**: チップ要素として `font-mono` および `bg-[rgba(124,111,221,0.06)]` 等のスタイルが適用されたタグチップが最大5個表示され、超過分は `+X` の形式でプレビュー表示されていることを確認する。

  ### C. インタラクション検証 (イベントリスナー確認必須)
  - **詳細モーダル起動**:
    - **判定基準**: 各カード要素に `onClick` ハンドラーが設定されており、クリック時に詳細モーダルがDOM上にレンダリングされることを確認する。
    - **判定基準**: 詳細モーダル内の全タグコピーボタンをクリックした際、クリップボードの内容がカンマ区切りの全タグ文字列と一致し、ボタンの表示が一時的にチェックマーク表示に変更されることを確認する。
  - **編集アクション**:
    - **判定基準**: カード内の「編集」ボタン要素（Pencilアイコン）をクリックした際、親要素のカード全体クリック（詳細モーダル）のイベントが発火せず（`stopPropagation()` の正常動作）、編集モーダルがDOM上に描画されることを確認する。
    - **判定基準**: 編集モーダル内の入力フォーム（名前、説明、カテゴリ、タグリスト）に、対象カードの既存値が初期設定されていることを確認する。
  - **削除アクション**:
    - **判定基準**: カード内の「削除」ボタン要素（Trash2アイコン）をクリックした際、`confirm` ダイアログが表示されることを確認する。

  ### D. 状態変化検証
  - **判定基準**: 編集モーダルで内容を変更して保存ボタンをクリックした際、または削除を確定した際、`tag-sets` のキャッシュが無効化されて最新の情報がグリッド上に即時反映されることを確認する。
