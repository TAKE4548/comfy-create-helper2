# REQ-155 詳細設計書: タグチップサブメニュー内でのタグ単語編集機能の追加

## 1. 概要 (Overview)
タグチップのサブメニュー（ポップオーバー）内で、タグの単語（ベーステキスト）を直接インライン編集できる入力欄を提供し、重み（weight）や有効状態を保持したまま単語の変更を即座に行えるようにする。

---

## 2. 影響分析・対象範囲 (Scope & SSoT Impact)

### 影響を受けるファイル
1. **`frontend/src/components/TagChipEditor/TagChip.tsx`** (MODIFY):
   - サブメニュー内にタグ名（ベーステキスト）編集用の入力フィールド（`wordInput`）を追加。
   - 単語変更確定ハンドラ（`handleWordSubmit`）およびキーボードハンドラ（`handleWordKeyDown`）の実装。
   - `onEdit` 呼出時に既存の `weight` を保持したまま `formatTagWeight(newBase, weight)` を適用して更新。
   - `wordInput` フォーカス時のキーボードイベント（Space, Delete等）が親チップのショートカットを発火させないようガード。
2. **`frontend/src/components/TagChipEditor/__tests__/TagChip.test.tsx`** (MODIFY):
   - サブメニュー内での単語編集、確定（Enter）、重み保持、キャンセル/エスケープの各挙動に対するユニットテストを追加。

## 3. 詳細設計 (Detailed Design)

### 3.1 状態管理とイベントハンドリング (`TagChip.tsx`)

#### ステート追加
```typescript
const { baseText, weight } = parseTagWeight(text);
const [wordInput, setWordInput] = useState(baseText);
const [weightInput, setWeightInput] = useState(weight !== null ? weight.toString() : '1.0');

useEffect(() => {
  const { baseText: currentBase, weight: currentWeight } = parseTagWeight(text);
  setWeightInput(currentWeight !== null ? currentWeight.toString() : '1.0');
  setWordInput(currentBase);
  setEditValue(text);
}, [text]);
```

#### 単語編集ハンドラ
```typescript
const handleWordSubmit = () => {
  const trimmed = wordInput.trim();
  if (!trimmed) {
    // 空文字の場合は元の単語にロールバック
    setWordInput(baseText);
    return;
  }
  if (trimmed !== baseText) {
    const { weight: currentWeight } = parseTagWeight(text);
    const newFormatted = formatTagWeight(trimmed, currentWeight);
    onEdit(id, newFormatted);
  }
};

const handleWordKeyDown = (e: React.KeyboardEvent<HTMLInputElement>) => {
  e.stopPropagation();
  if (e.key === 'Enter') {
    e.preventDefault();
    handleWordSubmit();
  } else if (e.key === 'Escape') {
    e.preventDefault();
    setWordInput(baseText);
    setIsMenuOpen(false);
  }
};
```

## 4. トレードオフ・リスク開示 (Trade-off Disclosure)
- **Trade-off**: ヘッダーの静的表示からインプットボックスへの変更により、サブメニューの横幅がわずかに拡張（`min-w-[200px]` → `min-w-[220px]`）されますが、タッチデバイスおよびデスクトップでの操作性向上と視認性のバランスが最適化されます。
- **Risk**: サブメニュー内のインプットにフォーカスがある状態でスペースやバックスペースを押した際に、親のチップキーボードショートカット（タグ削除やトグル）が誤発火するリスクがあるため、`e.stopPropagation()` を確実に設定します。
