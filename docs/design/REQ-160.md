# REQ-160 詳細設計書: セリフの口調・言い回しLLM再生成および口調プロンプトプリセット管理機能

## 1. 概要 (Overview)
同一シチュエーションでキャラクター差分を展開する際、画像差し替えは容易に行えるものの、セリフの骨子（意図やシチュエーション）を保ったまま各キャラクターの口調・言い回し・語尾に合わせて変更する作業が手動入力となっており作業負担が大きい。
本設計では、キャラクターごとの口調や話し方の特徴を定義する「口調プロンプトプリセット」の管理機能（CRUD）を提供し、セリフ編集画面（`SpeechBubbleControls`）において既存セリフと指定した口調プリセットに基づきLLMでセリフの骨子を保ったまま口調を再生成・プレビュー・適用できるようにする。

---

## 2. アーキテクチャとデータモデル設計 (Architecture & Data Model)

### 2.1 Backend Data Model: `SpeechTonePreset` (`backend/app/models.py`)
```python
class SpeechTonePreset(Base):
    __tablename__ = "speech_tone_presets"

    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    name: Mapped[str] = mapped_column(String, nullable=False, unique=True)
    prompt: Mapped[str] = mapped_column(Text, nullable=False)
    description: Mapped[str | None] = mapped_column(Text, nullable=True)
    sort_order: Mapped[int] = mapped_column(Integer, nullable=False, default=0)
    created_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.utcnow)
```

### 2.2 Pydantic Schemas (`backend/app/schemas.py`)
```python
class SpeechTonePresetBase(BaseModel):
    name: str
    prompt: str
    description: str | None = None
    sort_order: int = 0

class SpeechTonePresetCreate(SpeechTonePresetBase):
    pass

class SpeechTonePresetUpdate(BaseModel):
    name: str | None = None
    prompt: str | None = None
    description: str | None = None
    sort_order: int | None = None

class SpeechTonePresetRead(SpeechTonePresetBase):
    id: int
    created_at: datetime

    class Config:
        from_attributes = True

class SpeechToneRewriteRequest(BaseModel):
    text: str
    tone_prompt: str | None = None
    preset_id: int | None = None
    model: str | None = None
    llm_params: dict | None = None

class SpeechToneRewriteResponse(BaseModel):
    rewritten_text: str
```

### 2.3 API Endpoints (`backend/app/routers/speech_tone_presets.py`)
- `GET /api/speech-tone-presets`: プリセット一覧取得 (`sort_order asc, id asc`)
- `POST /api/speech-tone-presets`: プリセット新規作成
- `PUT /api/speech-tone-presets/{preset_id}`: プリセット更新
- `DELETE /api/speech-tone-presets/{preset_id}`: プリセット削除
- `POST /api/speech-tone-presets/rewrite`: LLMによるセリフ口調書き換え実行

#### 口調書き換えプロンプト仕様 (Rewrite Prompt Spec)
- **System Prompt**:
  ```
  あなたはセリフの言い回しや口調を変換する専門家です。
  元のセリフの意味、状況、感情、意図は一切変えずに、指定された口調・話し方・キャラクター特徴に合わせて自然なセリフに書き換えてください。
  
  【ルール】
  1. セリフの意味内容・文脈・伝達したい情報は忠実に維持すること。
  2. 指定された口調、語尾、一人称・二人称、キャラクターの性格ニュアンスを的確に反映すること。
  3. 出力は書き換えたセリフのみを返してください。挨拶、前置き、引用符（「」等）、解説は一切含めないでください。
  ```
- **User Prompt**:
  ```
  【口調・キャラクター設定】
  {tone_prompt}

  【元のセリフ】
  {text}
  ```

## 3. フロントエンド設計 (Frontend Design)

### 3.1 API Client & Types (`frontend/src/api/`)
- `types.ts`: `SpeechTonePreset`, `SpeechTonePresetCreate`, `SpeechTonePresetUpdate`, `SpeechToneRewriteRequest`, `SpeechToneRewriteResponse`
- `client.ts`: `speechTonePresetsApi` (`list`, `create`, `update`, `delete`, `rewrite`)
- `staleTimes.ts`: `SPEECH_TONE_PRESETS: 5 * 60 * 1000`

### 3.2 セリフ編集画面でのUI/UX (`frontend/src/components/SpeechBubbleControls.tsx`)
- セリフ入力エリアの下部に「口調変換 (LLM)」アコーディオンまたはドロップダウンを展開可能。
- プリセット選択プルダウン（「ツンデレ」「お嬢様」「丁寧語」等）＋「口調指示プロンプト」編集用テキストエリア。
- 「✨ 口調変換を実行」ボタン（実行中はスピナー＋ローディング表示）。
- 変換結果プレビューエリア：
  - 変換前テキストと変換後テキストを視覚的に比較可能。
  - 「セリフに適用」（ワンクリックで現在の吹き出しテキストを変換結果で置換）
  - 「再試行」 / 「破棄」
- その場で現在の口調指示を新しいプリセットとして保存するクイック追加ボタン。

### 3.3 設定画面での管理 (`frontend/src/pages/SettingsPage.tsx`)
- 設定ページに「セリフ口調プリセット設定」セクションを追加。
- 登録済み口調プリセットの一覧、追加、編集、削除（CRUD）モーダル/インラインUIを提供。

---

## 4. 非機能要件・エラーハンドリング
- LLM APIサーバー未起動時やタイムアウト時は、適切なトーストまたはインラインエラーメッセージを表示し、UIをブロックしない。
- 元のセリフが空の場合は変換ボタンを無効化。
- プリセット名は重複不可（一意制約エラー時は明確なエラー通知）。
