# 設計書: 生成中の進捗更新によるモーダル再生成・操作不能問題の修正 (REQ-047)

## 1. 概要
画像生成中に進捗（progress）が更新されて親コンポーネントが再レンダリングされる際、モーダルがアンマウントされて状態が破棄される問題を修正します。

## 2. 詳細設計
### 根本原因の排除
`GeneratePage.tsx` 内に存在する `Modals` 関数コンポーネントを完全に廃止します。
代わりに、モーダルを配置していた箇所（モバイル用・デスクトップ用それぞれのJSXリターン部）に、モーダルの描画用JSXを直接埋め込む（インライン展開する）ことで、親コンポーネントの再レンダリング時にReactコンポーネント定義が再生成されることを防ぎます。

### 変更対象
* **ファイル**: `frontend/src/pages/GeneratePage.tsx`
* **変更内容**:
  * `function Modals()` の定義を削除する。
  * `Modals()` の戻り値として返されていた各種モーダルの JSX を、`GeneratePage` の JSX 中にある `<Modals />` と置き換える。

## 3. テスト計画
### 手動検証
1. 画像生成（Generate Batch）を開始する。
2. 画像生成中に「Save Snapshot」ボタンを押してモーダルを表示し、適当な文字を入力する。
3. 進捗が更新されても、入力された文字やフォーカスが保持され、モーダルのアニメーションが再トリガーされないことを確認する。
