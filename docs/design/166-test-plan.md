# PBI-166 テスト計画書: ジョブ管理におけるキュー削除と全ジョブ中断の機能・UIボタン分離および中断状態同期の堅牢化

## 1. 自動テスト計画 (Automated Tests)

### 1.1 単体テスト (Frontend Unit Tests)
- **対象ファイル**: `frontend/src/store/__tests/useGenerationStore.test.ts`
- **テストケース**:
  1. `clearPendingQueue()`:
     - `comfyApi.deleteQueue({ clear: true })` が呼ばれ、`comfyApi.interrupt()` は呼ばれないことの検証。
     - 待機中ジョブ（`pendingIds`）のみ履歴削除が呼ばれ、実行中ジョブ（`running`）のステートおよび生成中フラグ（`isGenerating: true`）が維持されることの検証。
  2. `cancelAllJobs()`:
     - `comfyApi.deleteQueue({ clear: true })` と `comfyApi.interrupt()` の双方が正しく呼ばれることの検証。
     - 全ステートがクリアされ `isGenerating: false` になることの検証。
  3. WebSocket `execution_interrupted`:
     - `execution_interrupted` イベント受信時に `isGenerating: false`, `currentPromptId: null` にリセットされることの検証。
- **実行コマンド**:
  ```bash
  npm --prefix frontend test -- useGenerationStore.test.ts
  ```

## 2. 手動検証計画 (Manual Verification Plan)

### 2.1 シナリオ 1: 「キューのみクリア」の動作検証 (AC-1, AC-2, AC-5, AC-6)
1. 4枚バッチ生成を開始する。
2. 1枚目の生成中に「ジョブ管理」モーダルを開く。
3. フッターの「キューのみクリア」ボタンをクリックする。
4. 確認ダイアログ「待機中のキュー（3件）をクリアしますか？※現在生成中の1枚は中断せず最後まで生成されます。」が表示され、「OK」を押下する。
5. **期待結果**:
   - 処理完了後、**ジョブ管理モーダルが自動的に閉じること**。
   - 待機中キューの3件が即座に消滅する。
   - 実行中の1枚目は停止せず、サンプリングおよび画像生成が最後まで完了し、画面に生成画像が表示される。
   - 2枚目以降の後続生成は実行されない。

### 2.2 シナリオ 2: 「すべて中断」の動作検証 (AC-1, AC-3, AC-4, AC-5, AC-6)
1. 4枚バッチ生成を開始する。
2. 1枚目の生成中に「ジョブ管理」モーダルを開く。
3. フッターの「すべて中断」ボタンをクリックする。
4. 確認ダイアログ「実行中の生成を中断し、待機中のすべてのジョブを削除しますか？」が表示され、「OK」を押下する。
5. **期待結果**:
   - 処理完了後、**ジョブ管理モーダルが自動的に閉じること**。
   - 実行中ジョブが即座に停止し、ComfyUIのコンソール等でも中断が確認できる。
   - 待機中の全キューがクリアされる。
   - プログレスバーが待機（Ready）状態になり、勝手に「生成中」へ復帰しないこと。

### 2.3 シナリオ 3: 個別ジョブ中断・削除の検証
1. 複数ジョブが存在する状態で、実行中ジョブのゴミ箱ボタン（「中断」）をクリックし、1件のみが中断されること。
2. 待機中ジョブのゴミ箱ボタン（「キューから削除」）をクリックし、対象の1件のみがキューから削除されること。
