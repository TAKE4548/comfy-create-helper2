# Design Doc: REQ-232 server-managerにおけるWSLディストリビューション未検出不具合の修正

## 1. 概要と背景
`tools/server-manager/server-manager.ps1` において、ComfyUI の起動・停止・ログ取得処理で `wsl -d $distro ...` を実行する際、`config.json` の設定値または未設定時のフォールバックとして固定文字列 `"Ubuntu"` がハードコードされている。
Windows の WSL では、ディストリビューション名が `Ubuntu-24.04` や `Ubuntu-22.04` 等のバージョン付き名称でインストールされている環境が多く、`Ubuntu` という名称が存在しない場合に `WSL_E_DISTRO_NOT_FOUND` エラーとなり、起動や操作が失敗する。

一方、WSL CLI は `-d <distro>` 引数を省略した場合、システム既定（`wsl -l -v` で `*` マークが付いたデフォルト）のディストリビューションでコマンドを実行する仕様となっている。ユーザーが手動でディストリビューションを指定せずに `wsl` を利用している環境に対応するため、未指定時は `-d` を省略してデフォルトディストリビューションを利用可能とし、かつ明示的指定や存在チェック・親切なエラー案内を行えるように設計する。

## 2. 要件と設計方針
1. **ディストリビューション未指定時のデフォルトディストリビューション自動利用**:
   - `config.json` で `"distro": ""` またはキーが未定義・空白の場合、WSL 呼び出し時に `-d` オプションを付与せず実行する（WSL の既定ディストリビューションで起動）。
2. **明示的なディストリビューション指定のサポート**:
   - `config.json` で `"distro": "Ubuntu-24.04"` などのディストリビューション名が指定されている場合は、指定されたディストリビューションに対して `-d` を付与して動作する。
3. **事前検証と分かりやすいエラーハンドリング**:
   - 起動前にディストリビューションの疎通を確認し、指定されたディストリビューションが存在しない場合（`WSL_E_DISTRO_NOT_FOUND` 等）には、直ちに分かりやすいエラーメッセージと、`wsl -l -v` の確認および `config.json` の空文字設定（デフォルト利用）を促す案内を表示する。
4. **設定ファイルの初期値**:
   - `tools/server-manager/config.json` のデフォルト `"distro"` を `""`（空文字＝WSL既定ディストリビューション利用）に変更し、インストール直後の初回起動時の摩擦を解消する。
   - `docs/specs/server_manager_guide.md` の記述を更新し、空文字指定で既定ディストリビューションが使用される旨を明記する。

## 3. 変更対象ファイルとアーキテクチャ詳細

### 3-1. `tools/server-manager/server-manager.ps1`
- ヘルパー関数の導入:
  - `Get-WslDistroPrefix`:
    - `$cfg.wsl.distro` が設定され、かつ空白文字でない場合は `"-d $($cfg.wsl.distro.ToString().Trim()) "` を返す。
    - 未設定または空文字の場合は `""`（空文字）を返す。
  - `Test-WslAvailability`:
    - 指定ディストリビューション（または既定ディストリビューション）に対して `wsl ... echo "OK"` を実行し、利用可能か事前チェック。
    - 失敗時は「WSLディストリビューションが見つかりません。`wsl -l -v` で名称を確認するか、`config.json` の `distro` を空にして既定ディストリビューションをご利用ください。」等の案内を表示して安全に中断。
- 呼び出し箇所の修正:
  - `Start-ComfyUIProcess`:
    - `Test-WslAvailability` を実行。
    - バックグラウンド実行:
      `wsl $wslPrefix bash -c "nohup ..."`
    - フォアグラウンド実行:
      `Start-Process "cmd.exe" -ArgumentList "/k title ComfyUI (WSL2) && wsl $wslPrefix bash -c ..."`
  - `Stop-ComfyUIProcess`:
    - `wsl $wslPrefix bash -c "pkill ..."`
  - `Show-Logs`:
    - `wsl $wslPrefix tail -n 50 ~/comfyui.log`

### 3-2. `tools/server-manager/config.json`
- `"distro": ""` に変更（デフォルトで既定ディストリビューションを使用）。

### 3-3. `docs/specs/server_manager_guide.md`
- 設定項目の説明に `wsl.distro` の空文字指定（既定ディストリビューション使用）についての説明を追加。
