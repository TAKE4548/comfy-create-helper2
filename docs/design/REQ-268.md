# 設計書 - REQ-268: リポジトリ全体（root/docs/tmp）のレガシードキュメント・一時ファイル整理およびGit除外設定

## 1. 目的と概要

本設計は、Prompt Surgeon リポジトリ内において長期運用および機能追加の過程で蓄積した「リポジトリの認知負荷増大（Context Bloat）」および「Git ワーキングツリー汚染（Repository Noise）」を解消し、SSoT ガバナンス基準に適合したクリーンなリポジトリ構造を確立することを目的とします。

ユーザー方針（完全クリーンアップ方針）に基づき、Git 履歴で完全に保持されている移行済み旧仕様書や不要な一時生成物はアーカイブに残さず完全削除し、AI エージェントおよび開発者の検索・認知ノイズを根本から排除します。

1. **Git ワーキングツリー汚染の根本解消**:
   - サムネイルキャッシュディレクトリ（`db/thumbnails/`）および作業ディレクトリ（`scratch/`）が `.gitignore` に含まれておらず、常に未追跡ファイルとして `git status` に表示されている。
   - バックアップファイル（`tools/server-manager/config.json.bak`）や誤生成された複製ファイル（`frontend/src/pages/GeneratePage/components/SettingsPopover (1).tsx`）の混入。
2. **リポジトリ root 直下の重複・旧仕様書の完全削除**:
   - `Prompt Surgeon FEデザイン・実装仕様書.md`、`api_spec_draft.md`、`spec_and_migration.md` など、既に `docs/specs/` 配下の SSoT に統合完了している旧仕様書（root）を完全削除。
3. **`docs/` 直下のドキュメント階層化・完全整理**:
   - `docs/` 直下の移行済み旧仕様書（`FEデザイン...`, `api_spec_draft.md`, `spec_and_migration.md`, `spec_tag_chip_editor.md`）および外部スタブ（`.gdoc` / `.gsheet`）を完全削除。
   - 過去の調査レポート（`refactor_report*.md`, `prompt_surgeon_pbi_dashboard.html`）は `docs/archive/reports/` を新設して退避。
   - 現在進行中の不具合調査レポート（`docs/incident_report.md`）および SSoT 正本（`docs/specs/*`）は保護・維持する。
4. **`tmp/` 配下の滞留一時ファイル・過去レポートの全量パージ**:
   - 検証用一時スクリプト（`verify_api.py`, `verify_migration.py`）、実行ログ（`uvicorn.log`）、過去の調査 PDF 等の滞留ファイル（全23件）を全量パージし、一時領域を初期化。

## 2. 領域別設計（Architecture & Target Zones）

### 2.1 Zone 1: `.gitignore` 及び Git ワーキングツリーの正常化
- `.gitignore` に以下を明示追加:
  - `db/thumbnails/` (生成サムネイルのキャッシュ領域)
  - `scratch/` (エージェント・開発者の作業用スクラッチ領域)
  - `*.bak` (一般的なバックアップファイル)
- ワーキングツリーに混入した明らかなゴミファイルの除去:
  - `frontend/src/pages/GeneratePage/components/SettingsPopover (1).tsx` (誤操作による複製ファイル)
  - `tools/server-manager/config.json.bak` (バックアップファイル)

### 2.2 Zone 2: リポジトリ root 直下の整理
- 以下の 3 ファイルは既に `docs/specs/` に統合済みであり、root から完全削除する:
  1. `Prompt Surgeon FEデザイン・実装仕様書.md` -> 削除
  2. `api_spec_draft.md` -> 削除
  3. `spec_and_migration.md` -> 削除
- 保持対象:
  - `README.md`
  - `SKILL.md`
  - `.gitignore`
  - 構成ディレクトリ群

### 2.3 Zone 3: `docs/` 配下の階層化・整理
`docs/` 直下のファイルを精査し、以下のように処置する:
- **完全削除（旧仕様・移行完了済み）**:
  - `docs/Prompt Surgeon FEデザイン・実装仕様書.md`
  - `docs/api_spec_draft.md`
  - `docs/spec_and_migration.md`
  - `docs/spec_tag_chip_editor.md`
- **完全削除（外部スタブ）**:
  - `docs/Prompt Surgeon — 完了PBI分析・可視化ダッシュボード.gsheet`
  - `docs/refactor_pbi_proposals.md.gdoc`
  - `docs/thumbnail_optimization_proposal.md.gdoc`
- **アーカイブ退避 (`docs/archive/reports/`)**:
  - `docs/refactor_report.md`
  - `docs/refactor_report_backend.md`
  - `docs/prompt_surgeon_pbi_dashboard.html`
- **保護対象**:
  - `docs/incident_report.md`: REQ-267 作業中のためそのまま維持。
  - `docs/specs/*`: SSoT 正本として完全維持。
  - `docs/backlog/*`: PBI/Task 管理領域として完全維持。
  - `docs/design/*`: 設計書領域として完全維持。

### 2.4 Zone 4: `tmp/` 配下のクリーンアップ
`tmp/` 配下の滞留ファイル全 23 件を一括パージする。
