# REQ-172: セリフ生成（吹き出しエディタ）の作業性・操作性向上

## 1. 背景と目的

現在の吹き出しエディタ（SpeechBubbleEditorModal / SpeechBubbleControls）において、以下の操作性・作業効率上の課題が存在している：
1. **プリセットのテキスト再利用性**: プリセットには装飾設定のみが保存されテキストが含まれないため、効果音（SE：「ドンッ」「ゴゴゴ」など）の定型テキストを再利用できない。また、キャラクターごとの装飾プリセット適用時に既存の入力テキストが消去・上書きされない非破壊動作が求められる。
2. **操作導線の分断**: 画像ごとに頻繁に変更・調整する「枠サイズ自動調整」「回転」「文字方向（縦/横）」がテキスト入力エリアから離れた下部に散在しており、視線移動とマウスポインタ移動のオーバーヘッドが大きい。
3. **直感的なキャンバス回転操作の欠如**: 吹き出しの回転がスライダーおよび数値入力のみに限定されており、プレビュー画像上で視覚的に角度を合わせるドラッグ操作ができない。
4. **数値パラメータの微調整性の不足**: フォントサイズや回転角度など、スライダー操作のみでは1単位刻みの微細な増減調整が難しい。

本設計では、これら4つの課題を解決し、漫画セリフ・効果音配置作業の大幅な作業性・直感性向上を実現する。

## 3. 詳細設計

### 3-1. プリセットへのテキスト包含オプションと非破壊ロード (Data & Logic)

#### (1) データ構造の拡張
- `SpeechBubblePreset` に `text: Optional[str] = None`（DBでは NULL 許容）を追加。
- プリセット新規保存時：
  - 「テキストを含める」チェックボックス（デフォルト OFF または直前の入力有無に応じて選択可能）を設置。
  - チェック ON の場合：現在の `bubble.text` を `text` として送信。
  - チェック OFF の場合：`text: null` として送信。
- プリセット上書き保存時：
  - 上書き確認ダイアログまたはインライン選択にて、現在のテキストを含めるか選択可能にする（または現在のテキストで更新）。

#### (2) 非破壊的ロードロジック
- プリセット適用時（`handleApplyPreset`）：
  ```typescript
  const handleApplyPreset = (preset: SpeechBubblePreset) => {
    const updatePayload: Partial<SpeechBubble> = {
      shape: preset.shape,
      orientation: preset.orientation,
      fontFamily: preset.font_family,
      fontSize: preset.font_size,
      textColor: preset.text_color,
      backgroundColor: preset.background_color,
      borderColor: preset.border_color,
      borderWidth: preset.border_width,
      effects: preset.effects,
    }
    // preset.text が存在する場合のみテキストを上書き適用（SE系プリセット）
    // preset.text が null / undefined / 空文字の場合は既存の bubble.text を保持
    if (preset.text !== undefined && preset.text !== null && preset.text !== '') {
      updatePayload.text = preset.text
    }
    onUpdate(updatePayload)
  }
  ```
- プリセットチップ表示：
  - `preset.text` が保存されているプリセットには `💬` バッジを表示し、スタイルのみのプリセットと一目で判別可能にする。

### 3-2. 頻出調整コントロールのテキスト入力周辺への集約 (UI Reorganization)

#### レイアウト構成の再編成
作業頻度と操作の関連性に基づき、3つの明快なゾーンに整理する：

1. **【都度調整ゾーン (Top)】: テキスト入力 & 画像ごとの動的調整**
   - **セリフテキスト入力エリア (Textarea)** & ドラフト生成ボタン
   - **直下クイックアクションバー**:
     - 文字方向切り替え（縦書き / 横書き）
     - 📐 枠サイズ自動フィットボタン（テキスト長さに合わせてワンクリック調整）
     - 吹き出し回転（スライダー + `[-]` `[+]` ボタン + 数値入力 + `0°リセット`）
     - W / H 手動サイズ入力（px）
   - **口調変換 (LLM)** アコーディオン（任意展開）

2. **【プリセットゾーン (Middle)】: スタイル・定型文の適用と保存**
   - プリセット一覧（テキスト入りバッジ付き）
   - ＋ プリセット登録（「テキストを含める」チェック付き）

3. **【詳細スタイル・装飾ゾーン (Bottom)】: 一度決めたら固定化する設定**
   - 形状選択（楕円・角丸・叫び・思考・枠なし）
   - フォント & フォントサイズ（自動フィットチェック + スライダー + `[-]` `[+]` ボタン）
   - 色・装飾設定（文字色、背景色、枠線色、枠線幅 + `[-]` `[+]` ボタン、最近使用した色）
   - 💥 漫画テキスト演出 (FX) アコーディオン

### 3-3. プレビューキャンバスでのドラッグ＆ドロップ回転 (Canvas Direct Manipulation)

#### (1) 回転ハンドルの描画 (`speechBubbleRenderer.ts`)
- 選択中吹き出し（`isSelected === true`）の上部中央に、ステム線（長さ 20px）と円形の回転ハンドル（半径 6px）を描画。
- 吹き出しの回転角度 `rotation` に追従してキャンバス座標系を回転。
- ハンドルのローカル座標：
  - ステム始点: `(bx + bw / 2, by)`
  - ハンドル中心: `(bx + bw / 2, by - 20)`

#### (2) マウス・タッチ操作と角度計算 (`SpeechBubbleEditorModal.tsx`)
- **ヒットテスト (`handleMouseDown`)**:
  - `getLocalBubblePoint(x, y, activeBubble, scaleX, scaleY)` により、マウス座標を吹き出しローカル座標に変換。
  - ハンドル中心との距離が 10px 以内であれば `draggingState = { type: 'rotate', bubbleId, startX, startY, initialBubble }` を開始。
- **ドラッグ中の角度計算 (`handleMouseMove`)**:
  - 吹き出し中心座標: `cx = (initB.x + initB.w / 2) * scaleX`, `cy = (initB.y + initB.h / 2) * scaleY`
  - マウス位置との角度: `angleRad = Math.atan2(y - cy, x - cx)`
  - 角度を度数法に変換（上方向基準: `angleDeg = (angleRad * 180 / Math.PI) + 90`）
  - `-180°` 〜 `+180°` の範囲に正規化。
  - `onUpdate({ rotation: Math.round(angleDeg) })` でリアルタイムに反映。
- **ホバー時カーソル**:
  - 回転ハンドルホバー時は `cursor: grab` または `crosshair` を表示。

---

### 3-4. 数値パラメータのステップ増減（+/-）微調整コントロール

- 主要な数値調整項目に対して、スライダー前後にコンパクトな `[-]` / `[+]` ボタンを配置：
  - **吹き出し回転**: ステップ `1°`（範囲: -180 ~ 180）
  - **フォントサイズ**: ステップ `1px`（範囲: 8 ~ 64）
  - **枠線幅**: ステップ `1px`（範囲: 0 ~ 10）
  - **文字間 (Letter Spacing)**: ステップ `1px`（範囲: -10 ~ 50）
  - **行間倍率 (Line Height)**: ステップ `0.05`（範囲: 0.8 ~ 2.5）
  - **シアー傾斜 (Shear)**: ステップ `1°`（範囲: -45 ~ 45）
- クリック時に規定のステップ分増減し、min / max でクランプ。

## 4. トレードオフ・リスク開示 (Trade-offs & Constraints)

1. **既存プリセットデータとの後方互換性**:
   - 既存のDB内プリセットデータは `text` カラムが `NULL` となるため、ロード時にテキストを上書きせずスタイルのみ適用される安全なフォールバック動作となる。
2. **キャンバス回転操作時の境界クリッピング**:
   - 大きな吹き出しを回転させた際、画像の外側に一部がはみ出ることがあるが、現行のレンダラーと同様にキャンバス全体に対するクリッピングなしで自然に描画される。
3. **UI密集度のバランス**:
   - テキスト入力直下に回転や枠サイズ調整を集約することで縦スクロール量がわずかに増加するが、アコーディオンとコンパクトなボタングリッドを採用することで操作性を最大化する。
