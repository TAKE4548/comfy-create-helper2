# REQ-090: useWorkflowParams.tsにおけるlora_stackパーステストの追加・関数分割設計書

## 目的
`useWorkflowParams.ts` の `getInitialParams` 関数は、LoRAスタック（EasyLoraStack/StandardLoraStack）の判別や各種LoRAパラメータのパース、一般パラメータの抽出処理が含まれ、肥大化しています。
本設計では、この関数を「LoRAスタックパラメータ抽出」と「一般パラメータ抽出」のヘルパー関数に分割し、それぞれに詳細なユニットテストを追加して、保守性と堅牢性を向上させます。

## 設計方針

### 1. 関数分割 (リファクタリング)
`getInitialParams` から以下のヘルパー関数を抽出します。これらはユニットテストから直接呼び出せるように `export` します。

- `extractLoraStackParams(node: any, role: string): Record<string, string>`
  - 指定された `node` (lora_stack型) から、`num_loras` または `lora_count` に基づいて `loraCount` を判定します。
  - `loraCount` が明示的に定義されていない場合、`lora_${i}_name` または `lora_name_${i}` が定義されている最大値 (1〜10) を `loraCount` とします。
  - 各LoRAスロットに対して、名前、強度(wt)、モデル強度、CLIP強度を抽出し、`role` プレフィックス付きのパラメータマップを返します。
- `extractGeneralParam(node: any, paramName: string): string`
  - 一般ノードのパラメータを抽出します。
  - `node.inputs[paramName]` が存在すればそれを文字列化して返し、なければ `node.inputs['value']` の値、それもなければ空文字 `""` を返します。

### 2. getInitialParams の再実装
分割したヘルパー関数を用いて、以下のように簡潔に再実装します。

```typescript
export function getInitialParams(workflow: Workflow): Record<string, string> {
  const init: Record<string, string> = {}
  const wfJson = (workflow.json_body || {}) as Record<string, any>
  workflow.mappings.forEach((m) => {
    if (!m.role) return
    const node = m.node_id ? wfJson[m.node_id] : null

    if (m.input_type === 'lora_stack') {
      const loraParams = extractLoraStackParams(node, m.role)
      Object.assign(init, loraParams)
    } else {
      let val = ''
      if (m.node_id && m.param_name) {
        val = extractGeneralParam(node, m.param_name)
      }
      init[m.role] = val
    }
  })
  return init
}
```

### 3. テスト設計
`useWorkflowParams.test.ts` に以下のテストケースを追加します。

#### extractLoraStackParams
- **EasyLoraStack のパース検証**: `num_loras` が定義されている場合、`lora_${i}_name` や `lora_${i}_strength` 等が正しくパースされること。
- **StandardLoraStack のパース検証**: `lora_count` が定義されている場合、`lora_name_${i}` や `lora_wt_${i}` 等が正しくパースされること。
- **カウント自動判定**: `num_loras` / `lora_count` が未定義のとき、存在するインデックスキーの最大値を自動検出すること。
- **未定義/空ノードのハンドリング**: `node` が `null` または `inputs` が存在しない場合、`lora_count: '0'` を返すこと。

#### extractGeneralParam
- **指定パラメータの取得**: 指定した `paramName` の入力値が取得できること。
- **代替値 'value' の取得**: 指定した `paramName` の入力値がなく、`value` が存在する場合にそれが取得できること。
- **存在しない場合**: パラメータが何もない場合に空文字が返ること。

#### getInitialParams (統合検証)
- LoRAスタックと一般パラメータの双方が混在するワークフローを正しく一括パースできること。
