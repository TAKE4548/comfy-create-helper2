# 設計書: REQ-244 Web Managerプロセス再起動の適正化とバッチ起動引数統一

## 1. 設計概要 (Architecture Overview)

本設計は、REQ-242で実装された「Service Manager ターミナルバックグラウンド起動とタブ別コンソール出力表示」が正常にユーザー環境で動作しなかった根本原因を解消する。
具体的には、
1. `restart_web_manager.bat` における既存 Web Manager プロセスの強制停止失敗の検知・昇格ハンドリング、ポート解放の厳密検証、および新プロセス稼働確認ロジックの適正化
2. `start_servers.bat`、`toggle_servers.bat`、`start_background_all.bat` における `-Background` 引数の統一およびレガシー `conhost.exe` の完全排除
を実施し、デスクトップ上に 3 つのターミナルウィンドウが残存する現象を根絶し、Web UI 上でのタブ別コンソール閲覧を確実に実現する。

---

## 2. 課題と解決アプローチ (Problem & Solution Approach)

### 2.1 `restart_web_manager.bat` の停止失敗隠蔽と誤判定
- **現状の課題**:
  - タスクスケジューラ等（管理者権限/別コンテキスト）で常駐している既存プロセス（PID 29248 等）に対し、一般ユーザー権限からの `taskkill /F` は「アクセス拒否」で失敗する。
  - スクリプトが `2>$null` や `-ErrorAction SilentlyContinue` でエラーを握りつぶしているため、停止失敗を認識せず起動ステップへ進む。
  - 新プロセスはポート 8899 のバインドに失敗して即座にクラッシュ（`PermissionError: [WinError 10013]`）する。
  - スクリプトの完了判定（ステップ4）が「ポート 8899 が LISTEN しているか」しか見ていないため、**死ななかった旧プロセスを「新プロセスの起動成功」と誤認してブラウザを開く**。
- **解決策**:
  1. **停止の確実化**:
     - まず通常の `taskkill.exe /PID $p /T /F` を試みる。
     - ポートが 3 秒以内に解放されない場合、プロセスが特権等で保護されているとみなし、PowerShell の `Start-Process powershell.exe -Verb RunAs -ArgumentList "...taskkill /PID $p /T /F..." -Wait` を呼び出して UAC 昇格による強制終了を試行する。
  2. **ポート解放の厳格な検証**:
     - 旧プロセスが消滅し、ポート 8899 が完全に解放（`$null -eq (Get-NetTCPConnection -LocalPort 8899 -ErrorAction SilentlyContinue | Where-Object State -eq 'Listen')`）されたことを確認するまで、新プロセスの起動に進まない。
     - タイムアウト（10秒）経過後も解放されない場合は、**処理を即時中断（ABORT）し、エラー原因（ポート占有プロセスと管理者権限の必要性）を明示して終了する**。絶対にクラッシュすることが明らかな新プロセスの起動へ進まない。
  3. **新旧プロセスの識別検証**:
     - 停止前の旧 PID 一覧（`$oldPids`）を記録。
     - 新プロセスの起動後、ポート 8899 で LISTEN している PID が **旧 PID に含まれない新しい PID** であることを検証する。
     - これにより、万一旧プロセスが生き残っていた場合に「再起動成功」と誤認するバグを 100% 防止する。

### 2.2 バッチ起動エントリポイントのバックグラウンド統一
- **現状の課題**:
  - `start_servers.bat` および `toggle_servers.bat` が `server-manager.ps1` を呼び出す際、`-Background` 引数を付与していない。
  - `server-manager.ps1` の `$Background` が `$false` となり、`Start-Process "cmd.exe" -ArgumentList "/k title ..."` が走って 3 つのウィンドウが前面に開きっぱなしになる。
  - `start_background_all.bat` に `conhost.exe ... -WindowStyle Hidden` が残存しており、ウィンドウ生成が抑制されない。
- **解決策**:
  1. `start_servers.bat`: `-Action start -Background` を明示指定。
  2. `toggle_servers.bat`: `-Action toggle -Background` を明示指定。
  3. `start_background_all.bat`: `conhost.exe` の呼び出しを排除し、`server-manager.ps1 -Action start -Background` および `run_web_manager.bat` を直接 `WindowStyle Hidden` / `CreateNoWindow` で起動。

## 3. モジュール別詳細設計 (Detailed Module Design)

### 3.1 `tools/server-manager/restart_web_manager.bat`

```powershell
$port = 8899
$windowed = '%*' -match '-Windowed|--windowed'
Write-Host "========================================================" -ForegroundColor Cyan
Write-Host "  Prompt Surgeon - Restart Web Manager (Port 8899)" -ForegroundColor Cyan
Write-Host "========================================================" -ForegroundColor Cyan

# [1/4] 既存プロセスの検出と停止
Write-Host "[1/4] Checking for existing Web Manager process on port $port..." -ForegroundColor Yellow
$conns = Get-NetTCPConnection -LocalPort $port -ErrorAction SilentlyContinue | Where-Object State -eq 'Listen'
$oldPids = @()
if ($conns) {
    $oldPids = @($conns | Select-Object -ExpandProperty OwningProcess -Unique)
    foreach ($p in $oldPids) {
        Write-Host "      Stopping PID $p..." -ForegroundColor Yellow
        & taskkill.exe /PID $p /T /F 2>$null
        Stop-Process -Id $p -Force -ErrorAction SilentlyContinue
    }
}

# [2/4] ポート解放待機と昇格停止フォールバック
Write-Host "[2/4] Waiting for port $port to be released..."
$sw = [System.Diagnostics.Stopwatch]::StartNew()
$freed = $false
while ($sw.ElapsedMilliseconds -lt 4000) {
    $check = Get-NetTCPConnection -LocalPort $port -ErrorAction SilentlyContinue | Where-Object State -eq 'Listen'
    if (-not $check) { $freed = $true; break }
    Start-Sleep -Milliseconds 500
}

# 一般権限で停止できなかった場合、UAC昇格で強制終了を試みる
if (-not $freed -and $oldPids.Count -gt 0) {
    Write-Host "      Standard kill failed (Process may be elevated). Requesting admin elevation..." -ForegroundColor Yellow
    $pidArgs = ($oldPids | ForEach-Object { "/PID $_" }) -join " "
    $elevateCmd = "taskkill.exe $pidArgs /T /F"
    Start-Process -FilePath "powershell.exe" -ArgumentList "-Command `"$elevateCmd`"" -Verb RunAs -Wait -WindowStyle Hidden
    Start-Sleep -Seconds 1
    
    $check = Get-NetTCPConnection -LocalPort $port -ErrorAction SilentlyContinue | Where-Object State -eq 'Listen'
    if (-not $check) { $freed = $true }
}
$sw.Stop()

if (-not $freed) {
    Write-Host "      [ERROR] Port $port could not be released. Existing process PID(s): $($oldPids -join ', ')" -ForegroundColor Red
    Write-Host "      Please close the process manually or run this batch as Administrator." -ForegroundColor Yellow
    pause
    exit 1
}
Write-Host "      Port is free." -ForegroundColor Green

# [3/4] 新規 Web Manager の起動
Write-Host "[3/4] Starting new Web Manager process..."
$logsDir = Join-Path (Get-Location).Path 'logs'
if (-not (Test-Path $logsDir)) { New-Item -ItemType Directory -Path $logsDir | Out-Null }
$webLog = Join-Path $logsDir 'web_manager.log'
if ($windowed) {
    Start-Process -FilePath "cmd.exe" -ArgumentList '/k title Prompt Surgeon - Web Manager && run_web_manager.bat' -WorkingDirectory (Get-Location).Path
} else {
    Start-Process -FilePath "cmd.exe" -ArgumentList ('/c run_web_manager.bat > ' + [char]34 + $webLog + [char]34 + ' 2>&1') -WorkingDirectory (Get-Location).Path -WindowStyle Hidden
}

# [4/4] 新規プロセスの起動・リスン確認（新旧PID識別）
Write-Host "[4/4] Verifying Web Manager startup on port $port..."
$sw = [System.Diagnostics.Stopwatch]::StartNew()
$newPid = $null
while ($sw.ElapsedMilliseconds -lt 15000) {
    $conn = Get-NetTCPConnection -LocalPort $port -ErrorAction SilentlyContinue | Where-Object State -eq 'Listen'
    if ($conn) {
        $candidatePids = @($conn | Select-Object -ExpandProperty OwningProcess -Unique)
        foreach ($cp in $candidatePids) {
            if ($oldPids -notcontains $cp) {
                $newPid = $cp
                break
            }
        }
        if ($newPid) { break }
    }
    Start-Sleep -Milliseconds 500
}
$sw.Stop()

if ($newPid) {
    Write-Host "      Web Manager is successfully running (PID: $newPid)!" -ForegroundColor Green
    Write-Host "      Opening http://localhost:$port in default browser..." -ForegroundColor Cyan
    Start-Process "http://localhost:$port"
    Write-Host "Restart completed successfully." -ForegroundColor Green
    Start-Sleep -Seconds 2
} else {
    Write-Host "      [ERROR] Web Manager failed to bind to port $port." -ForegroundColor Red
    Write-Host "      Check error log: $webLog" -ForegroundColor Yellow
    pause
    exit 1
}
```

### 3.2 `tools/server-manager/start_servers.bat`
```bat
@echo off
title Prompt Surgeon - Start Servers
cd /d "%~dp0"
powershell.exe -ExecutionPolicy Bypass -File "%~dp0server-manager.ps1" -Action start -Background
echo.
pause
```

### 3.3 `tools/server-manager/toggle_servers.bat`
```bat
@echo off
title Prompt Surgeon - Toggle Servers
cd /d "%~dp0"
powershell.exe -ExecutionPolicy Bypass -File "%~dp0server-manager.ps1" -Action toggle -Background
echo.
pause
```

### 3.4 `tools/server-manager/start_background_all.bat`
```bat
@echo off
cd /d "%~dp0"
if not exist "logs" mkdir logs

:: 1. Web Manager (Port 8899)
powershell.exe -ExecutionPolicy Bypass -Command "if (-not (Get-NetTCPConnection -LocalPort 8899 -ErrorAction SilentlyContinue | Where-Object State -eq 'Listen')) { Start-Process -FilePath 'cmd.exe' -ArgumentList '/c run_web_manager.bat > ""%~dp0logs\web_manager.log"" 2>&1' -WorkingDirectory '%~dp0' -WindowStyle Hidden }"

:: 2. Services (WSL ComfyUI, Backend, Frontend)
powershell.exe -ExecutionPolicy Bypass -WindowStyle Hidden -File "%~dp0server-manager.ps1" -Action start -Background
```

## 4. トレードオフ・リスクの開示 (Trade-off Disclosure)

- **管理者権限プロンプト (UAC) の発生可能性**:
  - タスクスケジューラ経由で起動された特権プロセスを一般ユーザーが再起動する場合、UAC ダイアログが表示される。これは Windows セキュリティモデル上不可避であり、権限のないプロセスが他セッションの特権プロセスを強制終了できないための安全な正攻法である。
  - 停止できなかった場合はサイレントに失敗せず、明示的にエラーを表示して中断するため、誤認を完全に防止できる。
- **ウィンドウ表示モードが必要な場合の操作**:
  - デバッグ等の目的で各サービスのコンソールウィンドウを直接見たい場合は、引き続き `server_menu.bat` の `[1] Start All Services (Windowed)` から起動可能。
