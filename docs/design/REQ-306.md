# REQ-306: Animaモードにおけるタブ切替時のタグチップ結合状態先祖返り不具合の修正 詳細設計書

## 1. 概要 (Overview)
本設計は、Animaモード（自然言語・ピリオド区切り対応モデル）において発生している以下の先祖返り不具合を解消するための設計仕様を定義する。
1. タブ切替（プリセット切替）や画面復帰（History画面からの復帰等）時に、ピリオド区切りのタグチップがカンマ区切り専用のデフォルトパーサーにより再パースされ、単一の結合チップに上書きされる。
2. ワークフロー管理側（`useWorkflowManagement`）で検知した `isAnimaMode` がグローバルストア（`useGenerationStore`）へ同期されておらず、ストア内部の `isAnimaMode` が常に `false` のままになっている。
3. プリセット一括更新ロジック（`usePresetState`）における `parseToChips` 呼び出しでも `isAnimaMode` が欠落している。
4. `DesktopLayout` および `MobileLayout` で `TagChipEditor` の `defaultTextMode` が常に `isAnimaMode` に直接バインドされており、コンポーネント再マウント時（プリセットタブ切替や画面遷移）にユーザーがチップモードへ切り替えた状態が破棄されテキストモードへ先祖返りする。

## 2. アーキテクチャおよびデータフロー設計 (Architectural Data Flow)

### 2.1 グローバル状態の単一情報源 (SSoT) 整合性
- **`useGenerationStore` (multiSetSlice)**:
  - `isAnimaMode: boolean` (既存)
  - `setIsAnimaMode: (isAnima: boolean) => void` (既存)
  - `roleTextModes: Record<string, boolean>` (新規追加): 各プロンプトロール（`Main_Positive_Prompt`等）ごとのテキストモード/チップモード選択状態をグローバルに保持。
  - `setRoleTextMode: (role: string, isTextMode: boolean) => void` (新規追加): ユーザーの明示的なエディタ表示モード切替を記録。

### 2.2 ワークフロー検知とストア同期
- **`useWorkflowManagement.ts`**:
  - `baseModels` と `workflow.target_base_model_id` から検出した `isAnima` 判定（`selectedModel?.name === 'Anima'`）を検知した際、`useGenerationStore.getState().setIsAnimaMode?.(isAnima)` を確実に実行する。
  - フック戻り値の `isAnimaMode` は `useGenerationStore((state) => state.isAnimaMode ?? false)` を直接参照するか、ストア状態と常時同期させる。

### 2.3 プリセット読込時のタグチップ非破壊的保護
- **`multiSetSlice.ts` (`loadPresetData`)**:
  - `const isAnimaMode = get().isAnimaMode ?? false;`
  - プリセット値 `val` をチップ化する際、既存の `existingSet?.promptChips?.[role]` を検査。
  - 既存チップが存在し、その文字列表現 `chipsToString(existingChips, isAnimaMode) === val` の場合は、既存チップ配列をそのまま維持（enabled/disabled等のメタデータやピリオド区切り構造を保持）。
  - チップが存在しない場合または更新されている場合は `parseToChips(val, isAnimaMode)` を明示的な `isAnimaMode` フラグ付きで呼び出す。
- **`usePresetState.ts`**:
  - 一括更新ハンドラ（L498, L523付近）における `parseToChips(val)` 呼び出しにも、`storeRef.current.isAnimaMode ?? false` を渡す。

### 2.4 エディタ表示モード（Text/Chip）のチップモード基本化と状態維持
- **`DesktopLayout.tsx` / `MobileLayout.tsx`**:
  - Animaモードを含む全ワークフローにおいて、初期表示の基本をタグチップモード（`false`）に統一。
  - 各ロールの初期テキストモード解決ロジック:
    ```typescript
    const resolvedDefaultTextMode = roleTextModes?.[m.role!] ?? false;
    ```
  - `TagChipEditor` の `onTextModeToggle`:
    ```typescript
    onTextModeToggle={(isText) => {
      setRoleCollapsed(m.role!, false);
      setRoleTextMode(m.role!, isText);
    }}
    ```
  - これにより、Animaモードであっても初期表示は常に利便性の高いタグチップモードとなり、ユーザーが手動でテキストモード（textarea）へ切り替えた場合のみその選択状態がタブ切替や画面遷移を跨いで確実に維持される。

### 2.5 Animaモードにおけるタグ強度フォーマットの正常化
- **`useChipParser.ts` (`formatTagWeight`)**:
  - 引数に `isAnimaMode: boolean = false` を追加。
  - `trimmedBase` の末尾にピリオドが存在する場合、または `isAnimaMode: true` の場合:
    1. 括弧の内側にピリオドが入らないよう `cleanBase = trimmedBase.replace(/\.+$/, '')` で末尾ピリオドを事前に除去。
    2. 強度指定が有効（`weight !== null && weight !== 1`）な場合、括弧の外側にピリオドを付与した `(${cleanBase}:${rounded}).` 形式で出力。
    3. 強度指定が 1.0 または null の場合は、元の末尾ピリオドを維持した `${cleanBase}.` を返却。
- **`useChipParser.ts` (`parseTagWeight`)**:
  - 入力文字列が `(tag:x).`（括弧外ピリオド）および `(tag.:x)`（旧来の括弧内ピリオド）の双方を検知できるように正規表現を拡張:
    `const match = trimmed.match(/^\((.+):([0-9.]+)\)\.?$/);`
  - ピリオドの有無を保持しつつ、ベーステキストから内側末尾ピリオドをサニタイズ。
- **`TagChip.tsx`**:
  - `formatTagWeight` 呼び出し箇所（L145, L159, L186）において、コンポーネントが受け取っている `isAnimaMode` を第3引数として伝播。
- **`useChipParser.ts` (`chipsToString`)**:
  - チップ文字列が `(tag:x).` で終わるため、`prevText.endsWith('.')` が正しく `true` となり、後続チップとの区切りが `, ` ではなく半角空白 `' '` として連結される。

## 4. セキュリティおよび非機能要件
- **メモリ効率**: `roleTextModes` はロール名をキーとする軽量な boolean マップであり、不要なレンダリングやメモリ浪費を生じさせない。
- **安全なフォールバック**: `isAnimaMode` や `roleTextModes` が未設定（undefined）の場合でも、常に安全なデフォルト値（`false`）へフォールバックする。
