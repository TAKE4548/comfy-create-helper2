#### 4.1.2 系統A: 高中低分散抽出アルゴリズム

```python
FILLER_PATTERNS = re.compile(
    r"^(うん|はい|ええ|あ|ああ|そう|なるほど|うーん|んー|へー|ふーん){1,3}[。！？…]?$"
)

def extract_character_tone_samples_high_mid_low(
    db: Session,
    target_tag_set_id: Optional[int],
    current_prompt: str,
    exclude_snapshot_id: Optional[int] = None,
) -> List[ToneSampleItem]:
    """
    1. 同キャラ(target_tag_set_id) かつ 8<=len(text)<=50 かつ非SE のセリフを
       直近50スナップショットから走査
    2. FILLER_PATTERNS に一致するセリフを除外
    3. current_prompt との Stemmer 類似度スコアを計算
    4. スコア降順ソート → High=Top-1, Mid=中央値, Low=Tail
       3件とも異なる snapshot_id であること
    5. フォールバック: 3件未満はある分だけ、0件は SpeechTonePreset.prompt を fallback tier で返却
    """
```

#### 4.1.4 VLM画像 1024px JPEG圧縮

```python
def load_image_as_base64(image_path: Path, max_size: int = 1024) -> str:
    """Load image, resize to max_size (longest edge), convert to JPEG, return base64."""
    from PIL import Image as PILImage
    import io
    with PILImage.open(image_path) as img:
        img = img.convert("RGB")
        w, h = img.size
        if max(w, h) > max_size:
            ratio = max_size / max(w, h)
            img = img.resize((int(w * ratio), int(h * ratio)), PILImage.LANCZOS)
        buf = io.BytesIO()
        img.save(buf, format="JPEG", quality=85)
        return base64.b64encode(buf.getvalue()).decode("utf-8")
```
