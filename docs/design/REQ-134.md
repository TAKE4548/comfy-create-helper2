# REQ-134: fix(backend): requirements.txt に Pillow 依存を追加

## 概要 (Overview)
REQ-132のWebP変換実装において、`from PIL import Image` がバックエンドコード（`snapshots.py`, `snapshot_service.py`）に追加されたが、`backend/requirements.txt` に `Pillow` パッケージの記述が漏れていた。
本設計では、`backend/requirements.txt` に `Pillow>=10.0.0` を明記し、仮想環境へのインストールおよび正常動作を保証する。

## 変更内容 (Proposed Changes)
- `backend/requirements.txt`
  - `Pillow>=10.0.0` を追加。

## 影響範囲 (Impact Area)
- `backend/requirements.txt`
- バックエンド仮想環境 (Python パッケージ依存関係)

## 受入条件検証 (Acceptance Criteria Mapping)
- AC-1: `backend/requirements.txt` に `Pillow>=10.0.0` が記載されていること。
- AC-134-2: `pip install -r requirements.txt` 実行後の仮想環境にて `python -c "import app.main"` および pytest がエラーなく動作すること。
