# Design Document: REQ-080 Default Parameter Value Initialization for New Profiles

## 1. Overview
When a user creates a new profile (preset) and selects "ワークフローのデフォルト設定" (Workflow Default Settings) as the source, the profile is currently saved with empty parameters (`paramValues: {}`, `appliedAssets: {}`). This design document describes how to properly load and inject default workflow parameters when creating a profile from the workflow defaults.

## 2. Requirements & User Interaction
- When a user opens the "Add Set" (新規プロファイル作成) modal and selects "ワークフローのデフォルト設定" as the copy source:
  - The created profile should contain the default parameters parsed from the workflow's `json_body` (representing the initial values of nodes mapped to each role).
  - The created profile should contain the default applied assets parsed from the workflow's `default_applied_assets`.
- When the profile is loaded, the inputs should populate with these default values instead of being cleared.

## 3. Architecture & Dependencies
- **`getInitialParams` Function**:
  - Currently, `getInitialParams(workflow: Workflow): Record<string, string>` is defined inside `useWorkflowParams.ts`.
  - It parses `workflow.json_body` and matches it against `workflow.mappings` to output the initial parameter values.
  - To reuse it, we will export this function from `useWorkflowParams.ts` and import it in `useGeneratePageState.ts`.
- **Applied Assets Initialization**:
  - `workflow.default_applied_assets` contains a JSON string representing the default applied assets.
  - If present, we will parse this string into a `Record<string, any>` and pass it to `createPresetMutation.mutate`. Otherwise, we pass `{}`.

## 4. UI/UX Changes
No UI changes are needed because the user interface (the modal selection) is already implemented. The logic change occurs purely in the preset creation handler.

## 5. File Modifications
- `useWorkflowParams.ts` (`../../frontend/src/pages/GeneratePage/hooks/useWorkflowParams.ts`):
  - Export `getInitialParams`.
- `useGeneratePageState.ts` (`../../frontend/src/pages/GeneratePage/hooks/useGeneratePageState.ts`):
  - Import `getInitialParams`.
  - In `handleCreatePreset`'s `copySourceId === 'default'` branch, compute `initialParams` and `defaultAssets` and mutate with them.
