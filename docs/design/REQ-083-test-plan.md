# REQ-083 実行可能テスト計画 (監査済み版)

## 1. 自動テスト (CLI Verification)
本機能は主にインタラクティブな UI レイアウト変更であるため、単体テストよりも手動/ブラウザ検証が中心となる。
ただし、コンポーネントのビルド成功を厳密に検証する。

- **コマンド**: `npm run build`
- **判定基準 (Pass/Fail)**:
  - **PASS**: コマンド終了ステータスが `0` であり、コンソール出力に TypeScript エラーやコンパイルエラーが含まれていないこと。
  - **FAIL**: エラーコードが `0` でない場合、またはコンソールに "Error" / "Failed to compile" などの文字列が含まれる場合。

## 2. ツール主導監査 (Tool-Driven Audit)
- **コマンド**: `python ${GLOBAL_SCRIPTS}\local_model_adapter.py arch-audit .`
- **判定基準 (Pass/Fail)**:
  - **PASS**: スクリプトが正常終了（Exit Code 0）し、警告レベル以上のエラーや "No issues found" のような成功メッセージを出力すること。
  - **FAIL**: エラーコードが `0` でない場合、または "Warning", "Error", "Issue detected" などの文字列が含まれる場合。

## 3. ブラウザ検証 (Browser Agent Verification)
**環境設定**: 
- URL: `http://localhost:5173/`
- リロード方法: ハードリロード (`Ctrl+Shift+R` / `Cmd+Shift+R`) を使用して、必ず初期状態から開始する。

### 3-1. リサイザブルレイアウトの検証
**対象**: 生成ページ (`http://localhost:5173/`) のメインコンテナ。

| 検証 ID | 操作手順 (Action) | 期待される結果 (Expected Result / Assertion) |
| :--- | :--- | :--- |
| **AC-1** | 左右の境界線領域にマウスカーソルを移動させる。 | カーソル形状が `col-resize` (左右矢印) に変化すること。 |
| **AC-2** | 左ペインの境界線をドラッグして幅を変更する。 | ペインの幅が変更され、かつ最小値 `380px` および最大値 `700px` の間で制限されること（それ以外に縮小/拡大できない）。 |
| **AC-2b** | 上下境界線（メインプレビューと履歴サムネイルの間）をドラッグする。 | プレビュー領域およびサムネイル領域の高さが変更され、最小高さ `250px` の制限が利くこと。 |
| **AC-3** | 1. 上記のサイズ変更を行う。<br>2. ハードリロード (`Ctrl+Shift+R`) を実行する。<br>3. ページ読み込み完了後、左ペインおよび上下の高さを測定する。 | 変更前のサイズ（幅と高さ）が完全に維持されていること。 |

### 3-2. 設定画面アコーディオンの検証
**対象**: 設定ページ (`http://localhost:5173/settings`) の各セクションヘッダー。

| 検証 ID | 操作手順 (Action) | 期待される結果 (Expected Result / Assertion) |
| :--- | :--- | :--- |
| **AC-4-1** | 任意のセクション（例：LLM System Prompts）のヘッダーをクリックする。 | コンテンツ領域が折り畳まれ、右端のアイコンが `fa-chevron-down` から `fa-chevron-up` に変化すること（クラス名等のDOM状態が変化すること）。 |
| **AC-4-2** | 再度同じヘッダーをクリックする。 | コンテンツ領域が展開され、アイコンが `fa-chevron-up` から `fa-chevron-down` に変化すること。 |
| **AC-4-3** | ページをハードリロード (`Ctrl+Shift+R`) する。 | 全てのセクションが初期状態で「展開済み」になっていること。 |
