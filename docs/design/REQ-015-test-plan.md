# PBI-REQ-015 実行可能テスト計画

## 1. 自動テスト (CLI Verification)
本改修はフロントエンドの UI/UX 改善（純粋な React コンポーネント実装）であり、プロジェクト内にフロントエンド用の自動ユニットテスト環境（Jest/Vitest 等）は構築されていません。
したがって、検証は以下の手動ブラウザ検証を主とします。

## 2. ツール主導監査 (Tool-Driven Audit)
- **コード監査**: `local_model_adapter.py arch-audit .`
  - バックエンド/フロントエンドのコードベース全体の設計整合性を検証するために実行します。

## 3. ブラウザ検証 (Browser Agent Verification)
ブラウザを起動し、以下の手順に沿って挙動を検証します。

### 3.1 通常のチップ表示とトグル (AC-1, AC-2, AC-3)
- **対象URL**: `http://localhost:5173/` (開発環境の Generate ページ)
- **検証手順**:
  1. `Generate` ページを開き、ワークフローを選択する。
  2. `Main prompt` (textarea だった部分) がタグチップエディタとして表示されていることを確認する。
  3. 各チップのテキストをクリックし、取り消し線＋薄色表示（無効状態）になることを確認する。
  4. 再度クリックして有効に戻ることを確認する。
  5. 右側の `×` ボタンをクリックしてチップが削除されることを確認する。
  6. キーボードの `Tab` キーでチップにフォーカスを合わせ、`Space` を押してトグル、`Delete` / `Backspace` で削除されることを確認する。
- **判定基準**: クリックおよびキーボード操作でトグル・削除が完璧に動作すること。

### 3.2 並び替えとインライン編集 (AC-4, AC-5)
- **検証手順**:
  1. チップのドラッグハンドルをドラッグ＆ドロップし、並び替えができることを確認する。
  2. ドラッグハンドルにホバーした際、「ドラッグで並び替え / キーボード: Space → ←→」のツールチップが表示されることを確認する。
  3. チップをダブルクリックして入力フィールドに変化することを確認する。
  4. テキストを編集して `Enter` またはフォーカスアウトで確定することを確認する。
  5. 空文字列で確定した場合はチップが削除されることを確認する。
  6. 編集中に `Escape` を押して元のテキストに復元されることを確認する。
- **判定基準**: スムーズな並び替えおよびインライン編集ができること。

### 3.3 新規タグ入力とエスケープハッチ (AC-6, AC-7)
- **検証手順**:
  1. チップ列末尾の入力欄に文字を入力し、カンマ（`,`）または `Enter` / `Tab` で確定してチップ化することを確認する。
  2. `"tagA, tagB, tagC"` をペーストして、3つの別々のチップとして一括生成されることを確認する。
  3. 入力欄が空の状態で `Backspace` を押し、直前のチップが削除されることを確認する。
  4. 右上の「テキスト入力モードに切替」をクリックし、カンマ区切りの生テキストの `textarea` に切り替わることを確認する。
  5. 有効なチップのみが `textarea` に引き継がれることを確認する（無効なチップは破棄される）。
  6. テキストを編集し、「チップモードに切替」をクリックして、再度チップ配列にパースされることを確認する。
- **判定基準**: テキストとチップの変換が意図通りに行われること。

### 3.4 Undo/Redo の検証 (AC-9)
- **検証手順**:
  1. チップを追加・削除・トグル・並び替えした直後に `Ctrl+Z` を押し、操作が巻き戻ることを確認する。
  2. `Ctrl+Shift+Z` または `Ctrl+Y` を押し、操作がやり直されることを確認する。
  3. 最大50件まで履歴が保持されることを確認する。
- **判定基準**: ショートカットキーで安全に Undo/Redo が動作すること。

### 3.5 モバイル表示の検証 (AC-1-2)
- **検証手順**:
  1. ブラウザのデベロッパーツールで画面幅を 1024px 未満（例: 768px または 375px）にする、もしくは `/mobile` (将来用) のパスに遷移する。
  2. 入力欄がタグチップではなく、従来通りの `textarea` になっていることを確認する。
- **判定基準**: モバイルサイズではチップエディタが読み込まれないこと。
