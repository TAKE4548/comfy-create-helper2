# PBI-REQ-042 実行可能テスト計画 (監査済み版)

## 1. 自動テスト (CLI Verification)
本変更は UI/UX に閉じたものであるため、静的検証で不整合を排除します。
- **ビルド・検証コマンド**:
  ```bash
  cd frontend
  npm run build      # ビルドエラーチェック
  npm run lint       # コード品質チェック
  ```

## 2. ツール主導監査 (Tool-Driven Audit)
- **コード監査**: `local_model_adapter.py arch-audit .` を実行し、設計整合性の客観的証明を得ること。

## 3. ブラウザ検証 (Browser Agent Verification)
**環境設定**: Chrome DevTools > モバイルエミュレーター (Pixel 7 または iPhone 12 Pro) に切り替える。
**対象 URL**: `http://localhost:5173/history`

### 事前条件 (Prerequisites)
- 画面に少なくとも 3 つ以上の画像が表示されていること。
- ソート順が「カスタム」になっていること（またはテスト前に設定すること）。

### 検証手順と判定基準 (AC)

#### A. タッチ操作シナリオ (モバイルエミュレーター下)
1. **スクロール確認**:
   - 画像を短くタップ、またはタップ直後に指を上下に動かす。
   - **AC-1**: 並び替えが開始されず、ページ全体が縦にスクロールされること（ドラッグイベントが発生しない）。

2. **ロングタップ (500ms) 確認**:
   - 画像の中央を指で固定し、500ms 以上保持する。
   - **AC-4**: 
     - 500ms 経過時点で画像が拡大表示され、影が追加されて浮き上がる視覚効果が発生すること。
     - 具体的には、ドラッグ中の `SortableItem` のインラインスタイルに `scale(1.05)` と `box-shadow` が適用されることを目視確認する。

3. **ドラッグ開始 (AC-2)**:
   - 上記の状態から指を動かす。
   - **AC-2**: ドラッグ＆ドロップによる並び替えが開始され、他の画像と位置が入れ替えられること。

#### B. マウス操作シナリオ (PC モード)
1. **モード切り替え**: DevTools でモバイルエミュレーションを解除し、マウスカーソルを表示する。
2. **ドラッグ開始 (AC-3)**:
   - 画像の中央をクリックしてドラッグする（500ms 待機なし）。
   - **AC-3**: 長押し待機（500ms ディレイ）を必要とせず、ドラッグ開始直後（マウス移動 8px 以上）に即時に並び替えが開始されること。

#### C. タグチップエディター画面
- `http://localhost:5173/` にアクセスし、同様の手順 (A, B) をタグ入力エリアに対して実行する。
- **AC**: モバイルでは 500ms ディレイあり、PC では即時ドラッグ可能であることを確認する。

### 4. 異常検知 (Negative Testing)
- **AC-5**: 操作中にブラウザコンソールにエラーログが出力されないこと。
- **AC-6**: ページの再読み込みやクラッシュ（白画面化）が発生しないこと。
