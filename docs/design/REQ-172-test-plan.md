## 3. ブラウザ手動検証 (Browser Verification)
- **対象URL**: `http://localhost:5173` (または開発サーバー)
- **操作手順**:
  1. スナップショット一覧から画像を選択し、「セリフ編集」モーダルを開く。
  2. セリフテキストに「ドォォン」と入力し、「枠サイズ自動フィット」をクリック → テキスト入力直下で即座に枠サイズがフィットすることを確認。
  3. テキスト直下の回転スライダー横の `+` / `-` ボタンをクリック → 1度ずつ回転角度が増減することを確認。
  4. プレビュー画像上の吹き出し上部にある青い回転ハンドルをドラッグ → マウスの動きに合わせてリアルタイムに回転し、操作パネル側の角度数値も同期することを確認。
  5. プリセット登録を開き、「テキストを含める」にチェックを入れて「SE_ドォォン」として保存 → プリセット一覧に `💬` バッジ付きで表示されることを確認。
  6. テキストエリアを「こんにちは」に変更し、スタイルのみの別プリセット（キャラ用等）をクリック → テキスト「こんにちは」が維持されたまま装飾のみ切り替わることを確認。
  7. 保存した「SE_ドォォン」プリセットをクリック → テキストが「ドォォン」に切り替わることを確認。
- **判定基準 (Assertion)**:
  - プリセットのテキスト包含・非破壊切り替えが完全に動作すること。
  - テキスト入力エリア周辺からの視線・マウス移動が最小限で作業が完結すること。
  - キャンバスドラッグ回転および `+`/`-` ボタンによる微調整がスムーズに機能すること。
