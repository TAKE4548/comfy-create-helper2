# Design Document: REQ-300 デスクトップ生成画面におけるプリセットタブバーの画面全幅化と操作ボタンの左ペイン集約

## 1. Summary & Background
デスクトップ生成画面（`DesktopLayout.tsx`）において、プリセットタブ（`SetTabItem` 一覧）が左ペイン（入力設定カラム）の幅制約内に配置されていたため、プリセット名が付与されると2つ程度しか同時にタブを視認できず、一覧性や切り替え作業性が著しく低下していた。また、右ペイン（プレビューエリア）の上部は空間を持て余していた。
一方で、プリセット追加（Add Set）やプリセット管理（管理）ボタンは、左ペインで行われるプロンプト・パラメータ編集やUndo/Redoといった試行錯誤の主導線に属しており、タブバーと一緒に画面右端へ移動してしまうとFittsの法則（Fitts's Law）に反してマウス移動距離が著しく増大する。

本設計では以下の2点を構造的に分離・最適化する：
1. **Information Design（全幅タブバー）**: プリセットタブ一覧を左右2ペインの親コンテナ直上（画面幅100%）に昇格配置し、プレビューエリア上部を含めた全幅を活用して多数のタブを一覧・横スクロール可能にする。
2. **Interaction Design（左ペインツールバーへの操作集約）**: 「Add Set」「管理」ボタンを全幅タブバーから分離し、左ペイン上部のUndo/Redoツールバー領域へ近接集約配置することで、マウス移動を最小化し入力ワークフローを一元化する。

## 2. Architecture & Layout Hierarchy

### 2-1. コンポーネント階層の再構成
従来のデスクトップレイアウト階層：
```text
[Desktop Container: flex h-full]
  └── [ResizableSplitLayout]
        ├── [Left Pane: 420px~]
        │     ├── [Header: Generate / Workflow Select / Anima / Settings]
        │     ├── [Multi-Set Tab Bar: Tabs + Add Set + 管理]  <-- 狭小・混在
        │     ├── [Set Settings Bar: activeSet.name + Undo / Redo]
        │     └── [Inputs: Audit / Prompts / Params...]
        └── [Right Pane]
              └── [Preview / Strip / Controls]
```

新規デスクトップレイアウト階層：
```text
[Desktop Container: flex flex-col h-full w-full overflow-hidden relative]
  ├── [Global Header: ワークフロー選択 / Anima / Settings] (画面全幅: flex-shrink-0)
  ├── [Full-Width Preset Tabs Bar: 新規全幅配置] (画面全幅 100%: flex-shrink-0)
  │     └── [Horizontal Scrollable Tabs Container]
  │           └── [SetTabItem * N] (flex-shrink-0, max-w-[140px], overflow-x: auto)
  └── [Dual-Pane Content Area: flex-1 min-h-0 relative w-full overflow-hidden]
        └── [ResizableSplitLayout]
              ├── [Left Pane: w-full h-full flex flex-col overflow-hidden bg-surface-2/10]
              │     ├── [Left Pane Toolbar: Add Set / 管理 / Undo / Redo] (flex-shrink-0)
              │     │     ├── Left: activeSet.name + Undo/Redo ボタン
              │     │     └── Right: Add Set + 📑 管理 ボタン
              │     └── [Scrollable Inputs Panel: flex-1 overflow-y-auto custom-scrollbar]
              │           └── [AuditPanel / MappingErrorPanel / Prompts / ParamPanel]
              └── [Right Pane: w-full h-full flex flex-col overflow-hidden]
                    └── [Preview / Strip / Controls / Status]
```

### 2-2. 視覚的・インタラクション詳細仕様
1. **Global Header (最上部)**:
   - 全幅コンテナの最上部に配置（`px-5 py-3 border-b border-[rgba(255,255,255,0.06)] bg-surface/50`）。
   - タイトル「Generate」、接続ステータス、ワークフロー選択プルダウン（`#workflow-select`）、Anima特化トグル（`#anima-mode-toggle`）、設定ボタン（`#settings-toggle-btn`）を配置。

2. **Full-Width Preset Tabs Bar (全幅タブバー)**:
   - ワークフロー選択時（`selectedWorkflowId` が存在するとき）に描画。
   - `id="desktop-preset-tabs-bar"`、`border-b border-[rgba(255,255,255,0.06)] bg-surface-2/40 px-5 py-2 w-full overflow-hidden flex-shrink-0`。
   - 子要素として `overflow-x-auto w-full py-1 scrollbar-thin` を内包し、多数のタブが存在してもブラウザ全体の縦横スクロールに影響を与えず独立して横スクロール可能。
   - 各タブ（`SetTabItem`）は `flex-shrink-0` を付与し、名称の `max-w` を従来の `80px` から `140px` に拡張。プリセット名の視認性を向上。

3. **Left Pane Toolbar (左ペイン上部ツールバー)**:
   - `selectedWorkflowId` が存在するときに左ペイン最上部に配置。
   - `id="left-pane-toolbar"`、`border-b border-[rgba(255,255,255,0.06)] bg-surface-2/30 px-4 py-2.5 flex items-center justify-between gap-2.5 flex-shrink-0`。
   - 左側：`activeSet` が存在する場合、アクティブプリセット名バッジ（`max-w-[120px] truncate`）および Undo/Redo ボタングループ（`#undo-btn`, `#redo-btn`）。
   - 右側：新規セット追加ボタン（`#add-set-btn`）およびプリセット管理モーダル起動ボタン（`#manage-presets-btn`）。

4. **MobileLayout への非干渉保証**:
   - モバイル画面（`MobileLayout.tsx`）は独立したコンポーネントであり、デスクトップ専用の全幅化変更による影響を一切受けない。
   - `isMobile` フラグによるブレークポイント切り替え（1024px境界等）において、双方のレイアウトが破綻なく動作することを保証。

## 3. SSoT Specification Impact
- **Impacted Spec**: `docs/specs/SPEC_GENERATE.md`
  - Section 2「デスクトップレイアウト (`DesktopLayout`)」のアスキー図および構成記述を、最上部ヘッダー → 全幅プリセットタブバー → 左右2ペイン（左ペイン上部ツールバーにAdd Set/管理を集約）の構造へと同期更新予定。
## 4. BA Audit Observations & Mitigations
- **Audit Model**: `qwen3.5-9b-claude-4.6-highiq-thinking-heretic-uncensored` (Domain: reasoning)
- **Result**: `CONDITIONALLY APPROVED WITH RESERVATIONS`
- **Mitigation Actions Incorporated**:
  1. **コンテナ垂直スペース保護**: `DesktopLayout` のルートに `flex flex-col h-full overflow-hidden w-full relative`、ヘッダーおよび全幅タブバーに `flex-shrink-0`、スプリットペイン親ラッパーに `flex-1 min-h-0 relative w-full overflow-hidden` を明示指定し、ヘッダー追加によるコンテンツ領域の縮退・二重スクロールバーの発生を完全に防止。
  2. **プリセット 0 件 / activeSet 未選択時の安全ガード**: `activeSet` が null/undefined の場合でもクラッシュせず、`#add-set-btn` および `#manage-presets-btn` が正常に表示・操作可能である安全ガードを実装。
  3. **Undo/Redo スコープの明確化**: `undo?.(activeSet.id)` によるプリセット単位の履歴管理を維持し、タブ切り替え時にも他プリセットの Undo 履歴と干渉しないことを担保。
  4. **モバイルレイアウト完全分離**: `GeneratePage.tsx` の `isMobile` 分岐により `MobileLayout` はデスクトップの全幅化影響を受けず、ブレークポイント境界（1024px）で互いに干渉しないことを担保。
