# REQ-151 詳細設計書: タグチップのサブメニュー展開による強度調整および有効・無効切替機能

## 1. 概要 (Overview)
タグチップをクリック/タップした際にサブメニュー（ポップオーバー）を展開し、タグの有効・無効切り替えトグルおよび強度（Weight）の数値直接入力・ステップ増減操作を行えるようにする。

### 課題と背景
- 現行のタグチップはクリック/タップが直接の有効/無効トグルに専有されている。
- 一方でプロンプト調整においては、有効・無効のトグルよりも強度の微調整（Weight調整）の方が頻度が高い。
- タグチップをクリックしてサブメニューを開く方式に統一することで、トグル操作と強度調整の両方を直感的に行えるようにする。

### 基本方針
1. **タグ強度解析・整形ロジック (`useChipParser.ts`)**:
   - `parseTagWeight(text: string)`:
     - `(tag:1.2)` や `(masterpiece:0.8)` などの SD 標準の重み付き記法 `^\((.+):([0-9.]+)\)$` を解析し、`{ baseText: string, weight: number | null }` を抽出。
     - 記法がない場合（例: `1girl`）は `{ baseText: "1girl", weight: null }` を返す。
   - `formatTagWeight(baseText: string, weight: number | null)`:
     - `weight` が `null` または `1` / `1.0` の場合は `baseText` をそのまま返す。
     - `weight` が 1 以外の場合は `(${baseText}:${parseFloat(weight.toFixed(2))})` を返す。
   - `adjustWeight(currentWeight: number | null, delta: number)`:
     - `currentWeight ?? 1.0` をベースに `delta`（`+0.1`, `-0.1`, `+1.0`, `-1.0`）を加算し、小数点誤差を丸めて `Math.max(0, ...)` の正数を返す。
2. **サブメニュー（ポップオーバー）UI & インタラクション (`TagChip.tsx`)**:
   - チップ本体（テキスト部）のクリック/タップでサブメニュー（ポップオーバー）を開く。
   - サブメニュー内の構成:
     - **有効/無効トグル**: 現在の `enabled` 状態の表示と、クリックによる `onToggle(id)` 実行。
     - **強度直接入力**: `<input type="number" step="0.1" ... />` により数値を直接編集可能。未設定時は `1.0` をプレフィル。
     - **ステップ増減ボタン**: `-1.0`, `-0.1`, `+0.1`, `+1.0` ボタンを提供。押下で即座に `onEdit(id, formattedText)` を実行。
     - **クローズ処理**: サブメニュー外部のクリック（Click Away）または `Escape` キー押下でメニューを閉じる。
3. **キーボード操作・アクセシビリティの互換性**:
   - `Space` キー: フォーカスされたチップで引き続き直接の有効/無効トグルをサポート。
   - ダブルクリック: インラインテキスト編集モードを維持。
   - `Delete` / `Backspace` / `Ctrl+D`: 既存の削除・複製ショートカットを維持。

## 3. 詳細ロジック設計 (Detailed Logic)

### 3.1 タグ強度ユーティリティ (`useChipParser.ts`)

```typescript
export interface ParsedTagWeight {
  baseText: string;
  weight: number | null;
}

/**
 * タグ文字列からベーステキストと強度を抽出します。
 * 例: "(1girl:1.2)" -> { baseText: "1girl", weight: 1.2 }
 * 例: "1girl" -> { baseText: "1girl", weight: null }
 */
export function parseTagWeight(text: string): ParsedTagWeight {
  const trimmed = text.trim();
  const match = trimmed.match(/^\((.+):([0-9.]+)\)$/);
  if (match) {
    const baseText = match[1].trim();
    const weightNum = parseFloat(match[2]);
    if (!isNaN(weightNum)) {
      return { baseText, weight: weightNum };
    }
  }
  return { baseText: trimmed, weight: null };
}

/**
 * ベーステキストと強度からSD形式のタグ文字列を整形します。
 * weightがnullまたは1.0の場合はベーステキストのみを返します。
 */
export function formatTagWeight(baseText: string, weight: number | null): string {
  const trimmedBase = baseText.trim();
  if (weight === null || isNaN(weight) || weight === 1) {
    return trimmedBase;
  }
  // 小数点第2位までに丸め
  const rounded = parseFloat(weight.toFixed(2));
  if (rounded === 1) {
    return trimmedBase;
  }
  return `(${trimmedBase}:${rounded})`;
}

/**
 * 現在の強度に対してdeltaを加算・調整します（0未満にはならないよう保護）。
 */
export function adjustWeight(currentWeight: number | null, delta: number): number {
  const base = currentWeight ?? 1.0;
  const next = Math.max(0, base + delta);
  return parseFloat(next.toFixed(2));
}
```

### 3.2 サブメニュー UI 仕様 (`TagChip.tsx`)

- **展開トリガー**: チップのテキスト部分をクリックした際に `isMenuOpen = true`。
- **UIレイアウト**:
  - `div.relative` 内の `div.absolute.top-full.left-0.mt-1.z-50` として配置。
  - 背景色 `#18181C`、ボーダー `rgba(255,255,255,0.15)`、影 `shadow-xl`、パディング `p-2.5`、角丸 `rounded-lg`。
  - **上部**:
    - タグ名（切り詰め表示 `max-w-[140px] truncate font-medium`）
    - トグルスイッチ / ボタン: `[ 有効 / 無効 ]` (`bg-emerald-600` / `bg-zinc-700`)
  - **中間**:
    - ラベル: `強度 (Weight)`
    - `<input type="number" step="0.1" value={displayWeight} />` (未設定時は `1.0`)
  - **下部 (ステップボタン群)**:
    - 4つのクイックボタン: `[-1.0]` `[-0.1]` `[+0.1]` `[+1.0]`
    - クリック時に即座に `adjustWeight` を計算し、`onEdit(id, newFormattedText)` をコール。

## 4. トレードオフとリスクの開示 (Trade-offs & Risks)
- **操作ステップの変化**: タグチップのクリックが直接トグルからメニュー展開へと変更されるため、純粋なトグル操作については1ステップ増加します。ただし、ユーザー要望の通りプロンプト調整における強度の変更頻度がトグルより高いため、UIの一貫性と利便性の向上というメリットが上回ります。キーボードの `Space` キーによるワンキー直接トグルは引き続きサポートすることで、キーボード派ユーザーの効率を維持します。
- **ネストされた括弧の扱い**: `((tag))` や複合括弧記法については、標準の `(tag:weight)` 形式を基本として解析します。特殊記法が含まれる場合はベース文字列として安全に保持されます。
