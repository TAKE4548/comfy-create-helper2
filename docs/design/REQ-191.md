# REQ-191: anima特化モードに応じたタグチップ重み増減量の動的切り替え 詳細設計書

## 1. 概要 (Overview)

生成画面のタグチップ（プロンプトタグ）サブメニューに配置されている重み増減ボタンについて、現在有効なモード（Anima特化モード / 通常モード）に応じて増減量（ステップ幅）とボタン表示を動的に切り替える。

- **Anima特化モード (isAnimaMode: true)**: 重みを大きく振るユースケースに合わせ、刻み幅を **±0.5 / ±1.0** とする（ボタン: `-1.0`, `-0.5`, `+0.5`, `+1.0`）。
- **通常モード (isAnimaMode: false / default)**: 微細な調整を行う標準的なユースケースに合わせ、刻み幅を **±0.1 / ±0.3** とする（ボタン: `-0.3`, `-0.1`, `+0.1`, `+0.3`）。

---

## 2. アーキテクチャとUI仕様 (Architecture & UI Specifications)

### 2.1 現状の課題と仕様差異

1. **現状 (Before)**:
   - `TagChip.tsx` のサブメニュー内増減ボタンは固定で `[-1.0, -0.1, +0.1, +1.0]` の4つが配置されている。
   - 標準モデル（SDXL / SD1.5 / Illustrious等）では `±0.3` の中間刻みができず、Anima特化モデルでは `±0.5` の刻みができず複数回クリックが必要となっていた。

2. **改修後 (After)**:
   - `isAnimaMode` の boolean 値を受け取り、サブメニュー内の刻み幅定義を動的に切り替える。

| モード | ボタン1 (大減) | ボタン2 (小減) | ボタン3 (小増) | ボタン4 (大増) | input[type=number] step |
|---|---|---|---|---|---|
| **通常モード** (`isAnimaMode: false`) | `-0.3` | `-0.1` | `+0.1` | `+0.3` | `0.1` |
| **Anima特化モード** (`isAnimaMode: true`) | `-1.0` | `-0.5` | `+0.5` | `+1.0` | `0.5` |

## 3. コンポーネント改修仕様 (Component Implementation Details)

### 3.1 `frontend/src/components/TagChipEditor/TagChip.tsx`
- **Props 拡張**:
  ```typescript
  export interface TagChipProps {
    id: string;
    text: string;
    enabled: boolean;
    isAnimaMode?: boolean; // 追加
    onToggle: (id: string) => void;
    onDelete: (id: string) => void;
    onEdit: (id: string, text: string) => void;
    onDuplicate: (id: string) => void;
  }
  ```
- **ステップボタンの動的生成**:
  ```typescript
  const stepOptions = isAnimaMode
    ? [
        { delta: -1.0, label: '-1.0' },
        { delta: -0.5, label: '-0.5' },
        { delta: 0.5, label: '+0.5' },
        { delta: 1.0, label: '+1.0' },
      ]
    : [
        { delta: -0.3, label: '-0.3' },
        { delta: -0.1, label: '-0.1' },
        { delta: 0.1, label: '+0.1' },
        { delta: 0.3, label: '+0.3' },
      ];
  ```
- **サブメニューUI**:
  - `stepOptions.map(...)` でボタングリッド（`grid grid-cols-4 gap-1`）をレンダリング。
  - 直接入力フィールドの `step` 属性を `isAnimaMode ? '0.5' : '0.1'` に設定。

### 3.2 `frontend/src/components/TagChipEditor/index.tsx`
- **Props 拡張**:
  ```typescript
  interface TagChipEditorProps {
    id?: string;
    value: string;
    onChange: (val: string) => void;
    placeholder?: string;
    variant?: string;
    defaultTextMode?: boolean;
    isAnimaMode?: boolean; // 追加
  }
  ```
- **子コンポーネントへの伝達**:
  - `<TagChip ... isAnimaMode={isAnimaMode} />` に props をバケツリレー。

### 3.3 `frontend/src/pages/GeneratePage/components/DesktopLayout.tsx` & `MobileLayout.tsx`
- 既存の `isAnimaMode` state（`useGeneratePageState` 由来）を `<TagChipEditor isAnimaMode={isAnimaMode} ... />` に引き渡す。

## 5. 受け入れ基準 (Acceptance Criteria)

- **AC-1**: anima特化モードが有効な場合、タグチップのサブメニューにおける重み増減ボタンが「±0.5」「±1.0」の刻み幅で表示・動作すること。
- **AC-2**: anima特化モードが無効（通常・その他モード）な場合、タグチップのサブメニューにおける重み増減ボタンが「±0.1」「±0.3」の刻み幅で表示・動作すること。
- **AC-3**: 増減ボタン押下時に、対象タグの現在の重みに対して正確なステップ値で加算・減算が行われ、プロンプトテキストおよびタグチップ表示に正しく反映されること。
- **AC-4**: 設定やトグル等でanima特化モードのON/OFFが切り替わった際、ページリロードなしで即座に増減ボタンの表示と挙動が追従すること。
- **AC-5**: 既存の直接数値入力やその他のタグ操作（削除・移動・ネガティブ移動等）にデグレーションが発生しないこと。
