# REQ-113: プリセット管理モーダルからタブを開く機能の設計書

**作成日**: 2026-07-09  
**PBI**: REQ-113  
**ステータス**: Design

---

## 1. 背景・問題定義

プリセット管理モーダル（`GeneratePage.tsx` 内の `isPresetManagerOpen=true` 時に表示される `PresetManagerPanel`）において、プリセット一覧の各行をクリックしてもタブバーにタブが開かれない。

### 原因

ストアアクション `openPreset(id)` (`useGenerationStore.ts:1286-1292`) は実装済みだが、以下の配線が欠落している。

| 欠落 | 説明 |
|---|---|
| `PresetManagerPanelProps` に `onOpenAsTab` が未定義 | コールバックの型定義がない |
| `SortablePresetRow` に「タブを開く」UI 要素がない | ボタン/ハンドラが未実装 |
| `GeneratePage.tsx` で `openPreset` が渡されていない | モーダルへの Props 配線がない |

---

## 2. 設計方針

### 2-1. UX 設計

`SortablePresetRow` の右端のアクションボタン群（鉛筆・削除の左隣）に `ExternalLink` アイコンボタンを追加する。

```
[ ⠿ ] [ ☑ ] [ preset name ] [ ↗ ] [ ✏ ] [ 🗑 ]
         チェック  名前       タブ  編集  削除
```

**理由**: 
- 行全体クリックを採用すると、鉛筆・削除ボタンのバブリングが発生しリグレッションリスクがある
- ダブルクリック（名前編集）との干渉を避けるため、専用ボタンが最も安全

### 2-2. 動作仕様

1. ユーザーが `↗` ボタンをクリック
2. `openPreset(preset.id)` → `openPresetIds` に追加（既にある場合は何もしない）
3. `setActiveSetId(preset.id)` → そのタブをアクティブ化
4. `setIsPresetManagerOpen(false)` → モーダルを閉じる
