# REQ-341: 全画面共通ヘッダーデザイン統一・左クラスタリング操作性最適化およびモバイル展開 詳細設計書

## 1. 概要 (Overview)
本設計書は、Prompt Surgeon (comfy-create-helper2) における全6画面（Generate, Studio, LoRAs, Tags, History, Settings）のヘッダーデザイン統一、PCワイド画面における操作性最適化（左クラスタリング）、およびモバイル環境（ブレークポイント < 768px）における2段展開式ヘッダーの構造と実装仕様を定義する。
本仕様は SSoT である 	mp/prompt_surgeon_header_spec.html (UI-SPEC-2026-10-11-v3) に完全準拠する。

## 3. 詳細仕様 (Detailed Specifications)

### 3.1 全画面共通50pxヘッダー基盤 (AC-1)
- **高さ**: デスクトップ環境で h-[50px] 固定。
- **背景 & ボーダー**: g-surface (#18181C), order-b border-[rgba(255,255,255,0.06)]。
- **タイポグラフィ**: 	ext-sm font-semibold text-zinc-200 truncate。
- **アイコン規格**: サイズ 16px、カラー 	ext-zinc-400 flex-shrink-0。
- **画面遷移保証**: 6画面すべてで同一のルート要素構造・クラス名・パディングを採用し、垂直方向のレイアウトシフト（CLS）を 0 に抑止。

### 3.2 左クラスタリング操作性最適化 (AC-2)
- **Fitts's Law 対策**: タイトルおよび状態バッジの直後（左側）に画面固有の主要アクションを配置。
- **各画面の配置割当**:
  - Generate: ワークフロー選択 ＋「⋯」設定メニュー ＋ Anima特化トグル ＋ Undo / Redo ボタン
  - Studio: プロジェクト選択 ＋「1.マトリクス / 2.キュレーター / 3.学習設定 / 4.評価」切り替えボタングループ
  - LoRAs: 検索ボックス ＋ + Register Model ボタン ＋ 再スキャン/カテゴリ管理ボタン ＋ 件数バッジ
  - Tags: 検索ボックス ＋ + New Tag Set ボタン ＋ エクスポート/インポートボタン ＋ 件数バッジ
  - History: スナップショット/アルバム切り替えボタングループ ＋ ✨ セリフ一括変換 ＋ + Add to Album ＋ 件数バッジ
  - Settings: 設定カテゴリ切り替えチップ群（サービス接続, VRAMガード, マッピング, モデル, LLM, 翻訳）

### 3.3 スリム状態バッジ & ツールチップ (AC-3)
- **PCデスクトップ**: スリムな緑枠ピル [● READY]。冗長な FE · BE · Comfy テキストは非表示化。
  - マウスホバー時: ツールチップに FE 200 · BE 200 · Comfy (FastAPI中継 OK) を表示。
- **モバイル (< 768px)**: 7px緑発光ドットインジケーターのみを配置（テキスト一切なし）。

### 3.4 受動的リソースモニター & ホバーカード詳細表示 (AC-4)
- **チップ配置順序**: ヘッダー右端に CPU → RAM → GPU → VRAM を厳密配置（VRAMはパープルアクセント）。
- **Hover Card (幅 250px)**:
  - マウスホバー時にポップアップ展開。
  - 実メモリ消費量: VRAM: m / n GB (xx%), RAM: m / n GB (xx%) をプロポーショナルバー付きで表示。
  - GPU利用率、CPU負荷をバー付き表示。
  - 未取得時・接続エラー時は --% プレースホルダーで安全にフォールバック（レイアウト崩れなし）。

### 3.5 縦3点メニュー & ストレージ推定値 & ComfyUI直通URL撤廃 (AC-5)
- **配置**: ヘッダー最右端（28x28px ボタン）。
- **ドロップダウン (幅 270px)**:
  - LocalStorage / SessionStorage 推定使用量（UTF-16 2 bytes/char 概算、「Estimate Only」明記）。
  - プライベートブラウジング等での SecurityError 発生時は「推定容量: 取得不可」を安全に表示。
  - キャッシュ整合性再同期アクションボタン。
  - 設定画面（/settings）へのリンク導線。
  - **ComfyUI直通URLの完全撤廃**: FastAPIプロキシ移行完了に伴い、入力欄・表示を完全撤廃。

### 3.6 Generate画面 ワークフロー個別設定集約 (AC-6)
- ワークフローセレクタの直横に [⋯] ボタンを配置。
- ドロップダウン内:
  - ベースモデル紐付け（Auto / Anima / SDXL）
  - デフォルトパラメータ保存 / リセット
  - ワークフロー名前変更モーダル呼び出し
  - ワークフロー複製（コピー）
  - ノード再スキャン

### 3.7 モバイル2段レイアウト & VRAMスライド展開オーバーレイ (AC-7, AC-8)
- **1段目 (トップバー, 高さ 28px)**:
  - タイトル（単行ellipsis省略）＋ 7px発光ドット ＋ [VRAM xx% ◀] ピル ＋ 縦3点メニュー
- **2段目 (アクションバー)**:
  - 画面固有のアクション群を横スクロール可能なタッチ最適化バー（overflow-x: auto; scrollbar-none）で提供。
- **VRAMピル左スライド展開オーバーレイ**:
  - 通常時: 幅96px [VRAM xx% ◀]。
  - タップ時: 右端の縦3点ボタンの上に覆いかぶさりつつ（z-index: 80 vs 10）、左方向へスムーズに伸長（幅96px → 330px）。
  - 内部に CPU xx% | RAM xxG | GPU xx% | VRAM xxG | ✕ をインライン表示。
  - ✕タップ、ピル再タップ、領域外タップで自動格納され、縦3点ボタンが即時再露出。
