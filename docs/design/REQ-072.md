# Design Document: REQ-072 Image Download and Zip Functionality

## 1. Overview
This feature introduces single-image download capability on the album detail view cards, and bulk-download functionality (as a ZIP archive) for selected snapshots and album items.

## 2. Requirements & User Interaction
- **Single Download**:
  - Main history page card hover menu: Already implemented.
  - Album detail page card hover menu: Add a download icon button using `lucide-react`'s `Download` icon, aligned next to the existing delete button.
- **Bulk Download**:
  - Multi-select toolbar: Add an "一括ダウンロード" button when items are selected.
  - ZIP Naming:
    - From Album Detail: `[AlbumName].zip`
    - From Snapshot List (overall history): `YYYYMMDD_HHmmss.zip`
  - ZIP File Content:
    - Download images client-side by fetching them as blobs.
    - Prevent filename collisions by adding sequential counters (e.g. `file_1.png`).
    - Exclude other metadata (only image files).

## 3. Architecture & Dependencies
- **Client-side Compression**: We will use `jszip` (JavaScript ZIP library) installed via npm in the `frontend` project.
- **Fetching Assets**: Standard `fetch` requests with CORS support to download the images as `Blob` data before adding them to the zip archive.

## 4. UI/UX Changes
### 4-1. Album Card Hover Menu
Add download button inside `HistoryPage.tsx` for album detail cards:
```tsx
{item.image_path && (
  <a
    href={item.image_path}
    download
    id={`album-item-download-${item.snapshot_id}`}
    onClick={(e) => e.stopPropagation()}
    className="absolute top-2 right-9 p-1.5 rounded-md bg-black/60 text-zinc-400 hover:text-white opacity-0 group-hover:opacity-100 transition-opacity z-20"
  >
    <Download size={12} />
  </a>
)}
```

### 4-2. MultiSelectToolbar Actions
Update `MultiSelectToolbar` in both Snapshots and Album Detail sections to render the bulk download button:
```tsx
<button
  id="bulk-download-btn"
  onClick={handleBulkDownload}
  disabled={selectedIds.size === 0}
  className="text-xs px-3 py-1.5 rounded-lg bg-zinc-700 hover:bg-zinc-650 text-white font-medium disabled:opacity-50 transition-all flex items-center gap-1"
>
  <Download size={12} />
  一括ダウンロード
</button>
```

## 5. File Modifications
- `frontend/package.json`: Add `jszip` to `dependencies` and `@types/jszip` to `devDependencies` (if needed, or just install `jszip` which contains built-in types or separate types).
- `frontend/src/pages/HistoryPage.tsx`: Implement download functions, state for zip generation (optional loading indicator), and UI buttons.
