## 2. 結合・E2E検証 (Integration & E2E Verification)

### シナリオ 1: モーダル起動と初期スナップショット・自動検出
- **手順**:
  1. `HistoryPage` 等からスナップショットを指定して `SpeechBubbleEditorModal` を開く。
  2. スナップショットの既存パラメータ（`speech_bubbles`）が存在する場合はそれを復元。
  3. 未保存スナップショットの場合は `snapshotsApi.detectBubble` を自動実行し、検出バウンディングボックスから初期吹き出しを配置。
- **期待値**:
  - Canvas 上に背景画像と初期吹き出しが正常にレンダリングされる。

### シナリオ 2: Canvas マウス/タッチ対話操作（移動・回転・リサイズ・しっぽ）
- **手順**:
  1. 吹き出し中央をドラッグして移動。
  2. 上部回転ハンドルをドラッグして任意の角度へ回転（-180度〜180度）。
  3. 4隅（nw, ne, se, sw）のハンドルをドラッグして矩形サイズを変更。
  4. しっぽ先端ハンドルをドラッグして吹き出し外部の任意位置へ移動。
  5. 「🎯 しっぽ微調整モード」をONにし、境界上の2接点ハンドルをドラッグして配置調整。「🔄 接点初期化」でリセット。
  6. モバイル表示時またはタッチイベント発生時、同様の操作がタッチエミュレーションで動作すること。
- **期待値**:
  - 全てのアクションで座標計算が滑らかに追従し、最小サイズ（30px）制限やしっぽ外部クランプが正確に働くこと。

### シナリオ 3: ROI 範囲指定検出とセリフドラフト生成
- **手順**:
  1. 画像の余白部分をドラッグして赤色破線の矩形（ROI）を描画。
  2. マウスリリース時に `snapshotsApi.detectBubbleROI` が呼び出され、指定範囲内に新しい吹き出しが追加される。
  3. 選択中の吹き出しに対し、プロパティパネルの「セリフ下書き生成」をクリック。
- **期待値**:
  - `llmPromptsApi.speechDraft` が呼び出され、返却されたテキストが吹き出しの `text` に即時反映される。

### シナリオ 4: 保存・アルバム登録フロー
- **手順**:
  1. 保存モードとして「新規保存」または「上書き保存」を選択。
  2. 保存先アルバムとして「+ 新規アルバムを作成」を選択し、アルバム名を入力。または既存アルバムを選択。
  3. 「新規保存して履歴へ追加」をクリック。
- **期待値**:
  - オフスクリーン Canvas で実寸大（1:1）の合成画像が生成され、`snapshotsApi.upload` でアップロード。
  - スナップショット作成/更新とアルバムへの追加が行われ、React Query キャッシュが破棄されてモーダルが閉じること。

### シナリオ 5: 候補デバッグテーブル
- **手順**:
  1. 「デバッグ: 全ての検出候補を表示」にチェックを入れる。
  2. 候補一覧テーブルが表示され、OK/NGフィルタおよび面積・輝度ソートを切り替える。
  3. テーブル行にマウスホバーすると、該当矩形が Canvas 上でオレンジ色に強調表示される。
  4. 「適用」ボタンをクリックすると、その候補領域に新規吹き出しが作成される。
- **期待値**:
  - 候補のハイライト描画と吹き出し生成が正しく連動すること。

## 3. Red Teaming (境界値・異常系検証)

### Red-1: 微小 ROI（10px 未満）の無視・リセット
- **操作**:余白を 10px 未満（幅 5px, 高さ 5px など）ドラッグしてリリースする。
- **期待値**:
  - ROI 検出 API は発火せず、ROI 矩形表示が何事もなかったかのようにクリアされること。

### Red-2: 新規アルバム名の空欄バリデーション
- **操作**:
  - `targetAlbumId === 'new'` の状態で `newAlbumName` を空文字（または空白のみ）にして保存ボタンをクリック。
- **期待値**:
  - 「新規アルバム名を入力してください」というアラートが表示され、画像アップロードおよび保存処理が完全に中断されること。

### Red-3: 画像未ロード時および吹き出しゼロ件時の保存ボタン不活性化
- **操作**:
  - 吹き出しを全削除（`bubbles.length === 0`）にする。
- **期待値**:
  - 保存ボタンが `disabled` 属性となり、クリック操作を受け付けないこと。

### Red-4: API 通信エラー時の安全なフォールバック
- **操作**:
  - `snapshotsApi.upload` または `llmPromptsApi.speechDraft` が 500 エラーを返す状態をシミュレート。
- **期待値**:
  - 各種ローディング状態（`isSaving`, `isDrafting`）が必ず false に復帰し、エラーアラートが表示され、編集中の吹き出し状態が失われないこと。

### Red-5: リサイズ時の最小寸法クランプ（minSize: 30px）
- **操作**:
  - 矩形ハンドルを内側に極端にドラッグし、幅または高さを 0 や負の数にしようとする。
- **期待値**:
  - 幅・高さが 30px 未満に縮小されず、反転や破綻が発生しないこと。
