# Design Document: REQ-066 アプリ全体の長押し感度設定機能の追加

## 概要
スマートフォン等のタッチ操作やマウス操作において、長押し（ロングプレス）のアクション開始時間を、設定画面から個別に調整可能にします。
対象とする操作は以下の2種類です。
1. **履歴の複数選択モードへの遷移**: デフォルト値は 0.8秒 (800ms)
2. **カードの移動（ドラッグ＆ドロップ開始）**: デフォルト値は 0.5秒 (500ms)

これらの設定値は `localStorage` に保存され、アプリ全体で再起動後も永続化されます。

## 影響範囲・変更内容

### 1. localStorage キーの定義 (`frontend/src/utils/localStorageKeys.ts`)
以下のキーを追加します。
- `LONG_PRESS_DELAY_MULTI_SELECT`: `'prompt-surgeon-longpress-delay-multiselect'`
- `LONG_PRESS_DELAY_CARD_MOVE`: `'prompt-surgeon-longpress-delay-cardmove'`

### 2. 長押しフックの修正 (`frontend/src/hooks/useMultiSelect.ts`)
- `useMultiSelect` 内の `getLongPressHandlers` が `localStorage` から `LONG_PRESS_DELAY_MULTI_SELECT` を取得して判定時間（ミリ秒）として利用するように修正します。
- 設定値が存在しない場合は、デフォルトの `800` ms を使用します。

### 3. カード移動ディレイの修正
並び替え（Dnd-kitの `TouchSensor`）を使用している以下のファイルにおいて、`delay` の設定値を `localStorage` の `LONG_PRESS_DELAY_CARD_MOVE` から取得するように修正します。
- `frontend/src/pages/HistoryPage.tsx`
- `frontend/src/pages/LoRAsPage.tsx`
- `frontend/src/pages/TagsPage.tsx`
- 設定値が存在しない場合は、デフォルトの `500` ms を使用します。

### 4. 設定画面へのUI追加 (`frontend/src/pages/SettingsPage.tsx`)
- 設定ページに「長押し感度設定（アプリ全体）」セクションを追加します。
- 以下の2つのスライダー（0.1s 〜 5.0s、0.1s刻み）を設置します。
  - **履歴の複数選択長押し判定時間**: 初期表示は保存値、なければ `0.8`秒
  - **カード移動の長押し判定時間**: 初期表示は保存値、なければ `0.5`秒
- スライダーを変更した際、即座に `localStorage` に書き込み、画面上にフィードバック（「保存しました」の表示等）を行います。

## テスト計画
- `useMultiSelect.test.ts` において、`localStorage` の設定値に従って長押し判定時間が変化することを確認するテストケースを追加します。
- 設定画面でのスライダー変更が `localStorage` に正しく反映されること、および変更後の感度で機能が動作することを目視・手動で確認します。
