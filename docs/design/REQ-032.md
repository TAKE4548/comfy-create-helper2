# 設計書 - REQ-032: 生成画面での新規ワークフローアップロード・登録機能の追加

## 1. 目的と概要
システム仕様（`spec_and_migration.md`）で謳われている、ローカルにあるComfyUIのJSONワークフローを生成画面（Generateページ）から直接アップロードし、命名規則ベースでの自動マッピング判定および手動マッピング調整を経て、システムに新規登録する機能を提供します。

既存の「Select workflow…」という選択肢を「+ 新しいワークフローを追加 (Upload New...)」という選択肢（値: `new`）に置き換え、これを選択した際（または未選択状態のデフォルト時）に、左ペイン（通常はプロンプト入力欄などが表示される領域）にドラッグ＆ドロップおよびクリックでファイルを選択できる「アップロード用UI」を表示します。
これにより、ヘッダーに余計なボタンを増やすことなく、スマートで洗練されたUXを実現します。

## 2. アーキテクチャ設計

### 2.1 フロントエンド（React + TypeScript）

#### 1. 左ペインの表示切り替え（GeneratePage.tsx）
- `selectedWorkflowId` が `null` または未選択状態（または `new` 状態）のとき、通常プロンプト等が表示されるスクロール領域に、ファイルアップロード用のドロップゾーン（`UploadZone`）を大きく表示する。
- ドロップゾーンは以下のインタラクションに対応する：
  - ドラッグオーバー時のハイライト表示
  - ドラッグ＆ドロップによる `.json` ファイルの受け入れ
  - クリックによるファイルブラウザの起動（`<input type="file" accept=".json" ... />` と連動）

#### 2. 新規登録モーダル: `UploadWorkflowModal.tsx`
- **役割**: ファイルロード後に立ち上がり、自動スキャン（`POST /api/workflows/scan`）の結果をプレビュー・手動調整して新規登録を行うモーダル。
- **ワークフロー名設定**:
  - デフォルト値はファイル名（拡張子なし）。同名のワークフローが既に存在する場合は、APIの409エラーをハンドルして「すでに同名のワークフローが存在します」という重複警告を表示する。
- **保存処理**:
  - `workflowsApi.create` を使用して `POST /api/workflows` を呼び出し。

#### 3. 登録完了後の自動選択
- 登録完了後、`['workflows']` クエリをリフレッシュし、`selectedWorkflowId` を新しく追加されたワークフローのID（レスポンスから取得）に自動的に切り替える。これにより、左ペインは自動的にアップロード用UIからそのワークフローの入力フォームへ切り替わる。

---

## 3. UI/UX デザイン設計

### 3.1 ワークフロー選択ドロップダウンの項目変更
```html
<select id="workflow-select">
  <option value="">+ 新しいワークフローを追加 (Upload New...)</option>
  <!-- 既存のワークフローリスト -->
</select>
```
※従来の「Select workflow…」の代わりに、未選択時のデフォルト状態（value=""）または明示的な新規追加選択肢として機能させます。

### 3.3 左ペインのアップロードUI（ドロップゾーン）デザイン
```
+---------------------------------------------------+
|               Generate [Connected]                |
+---------------------------------------------------+
|  [ + 新しいワークフローを追加 (Upload New...) v ]    |
+---------------------------------------------------+
|                                                   |
|   +-------------------------------------------+   |
|   |                                           |   |
|   |                 [ JSON ]                  |   |
|   |                                           |   |
|   |      ComfyUIワークフローJSONをドロップ         |   |
|   |             またはここをクリック             |   |
|   |                                           |   |
|   +-------------------------------------------+   |
|                                                   |
+---------------------------------------------------+
```
デザインはTailwind CSSを用い、ガラスモーフィズム、点線の境界線、ホバー時の滑らかな発光エフェクト（glow）等を施し、プレミアムな質感を持たせます。
