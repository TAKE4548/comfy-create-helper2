# REQ-146 詳細設計書: セリフ編集画像の上書き保存オプションおよび保存時アルバム選択・登録機能

## 1. 概要 (Overview)
セリフ編集画面（`SpeechBubbleEditorModal`）で画像を編集して保存する際、現在は常に新規スナップショットとして作成・保存されます。
これにより以下の問題が発生しています：
1. **上書き更新ができない**: 既存のスナップショット画像に対してセリフ調整・再編集を行った際にも新規画像として複製保存されてしまい、不要なスナップショット履歴が増加する。
2. **アルバム登録フローの分断**: セリフ編集した画像をアルバムにまとめたい場合、保存後に一度モーダルを閉じ、履歴画面またはアルバム画面へ移動して手動でアルバム追加を行う必要があり、編集から整理までの一連の体験（Interaction Friction）が損なわれている。
3. **前回保存先アルバムの記憶と優先順位**: 生成画面同様、セリフ編集画面でも前回選択した保存先アルバム（`LS_KEYS.LAST_SAVE_ALBUM_ID`）を最優先で初期選択とする。情報がない場合のフォールバックとして、アルバム詳細画面からの起動時は開いているアルバム、履歴画面からの起動時は新規アルバム生成を初期選択とする。

本設計では、セリフ編集画面の保存ワークフローを強化し、以下の機能を提供します：
- **保存モード選択（新規保存 / 上書き保存）**: 元スナップショットを直接更新する「上書き保存」と、別画像として追加する「新規保存」を切り替え可能にする。
- **保存先アルバム選択とシームレス登録・新規アルバム作成**: 保存時に登録先アルバム（既存アルバム一覧から選択、新規アルバム作成、登録なし）を指定でき、画像保存完了と同時にアルバムへのアイテム追加（または新規作成＋登録）を自動実行する。

## 3. 詳細設計 (Detailed Design)

### 3.1 Backend: `SnapshotUpdate` と `SnapshotService.update_snapshot`

#### `backend/app/schemas/snapshot.py`
```python
class SnapshotUpdate(BaseModel):
    lora_ids: Optional[list[int]] = None
    tag_set_ids: Optional[list[int]] = None
    image_path: Optional[str] = None
    thumbnail_path: Optional[str] = None
    params: Optional[dict[str, Any]] = None
```

#### `backend/app/services/snapshot_service.py`
```python
    @staticmethod
    def update_snapshot(db: Session, snapshot_id: int, payload: schemas.SnapshotUpdate) -> models.Snapshot:
        s = db.query(models.Snapshot).filter(models.Snapshot.id == snapshot_id).first()
        if not s:
            raise HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail="Snapshot not found")

        if payload.lora_ids is not None:
            for lora_id in payload.lora_ids:
                exists = db.query(models.Lora).filter(models.Lora.id == lora_id).first()
                if not exists:
                    raise HTTPException(status_code=status.HTTP_400_BAD_REQUEST, detail=f"Lora with ID {lora_id} does not exist")
            db.query(models.SnapshotLora).filter(models.SnapshotLora.snapshot_id == snapshot_id).delete()
            for lora_id in set(payload.lora_ids):
                db.add(models.SnapshotLora(
                    snapshot_id=snapshot_id,
                    lora_id=lora_id,
                    strength=1.0,
                    role="positive"
                ))

        if payload.tag_set_ids is not None:
            for tag_set_id in payload.tag_set_ids:
                exists = db.query(models.TagSet).filter(models.TagSet.id == tag_set_id).first()
                if not exists:
                    raise HTTPException(status_code=status.HTTP_400_BAD_REQUEST, detail=f"TagSet with ID {tag_set_id} does not exist")
            db.query(models.SnapshotTagSet).filter(models.SnapshotTagSet.snapshot_id == snapshot_id).delete()
            for tag_set_id in set(payload.tag_set_ids):
                db.add(models.SnapshotTagSet(
                    snapshot_id=snapshot_id,
                    tag_set_id=tag_set_id,
                    role="positive"
                ))

        if payload.image_path is not None:
            s.image_path = payload.image_path
        if payload.thumbnail_path is not None:
            s.thumbnail_path = payload.thumbnail_path
        if payload.params is not None:
            s.params = json.dumps(payload.params)

        try:
            db.commit()
            db.refresh(s)
            return s
        except Exception as db_err:
            db.rollback()
            raise db_err
```

### 3.2 Frontend: `SpeechBubbleEditorModal`

#### Props & State
```tsx
import { LS_KEYS } from '../utils/localStorageKeys'

export interface SpeechBubbleEditorModalProps {
  snapshot: SnapshotSummary
  initialAlbumId?: number
  onClose: () => void
  onSaved: () => void
}

// State inside modal
const [saveMode, setSaveMode] = useState<'new' | 'overwrite'>('new')
const [targetAlbumId, setTargetAlbumId] = useState<number | 'new' | ''>(() => {
  try {
    const saved = localStorage.getItem(LS_KEYS.LAST_SAVE_ALBUM_ID)
    if (saved && !isNaN(Number(saved)) && Number(saved) > 0) {
      return Number(saved)
    }
  } catch {}
  if (initialAlbumId !== undefined) return initialAlbumId
  return 'new'
})
const [newAlbumName, setNewAlbumName] = useState('')
const [albums, setAlbums] = useState<AlbumRead[]>([])
```

#### アルバム一覧の初期ロードとフォールバック
```tsx
useEffect(() => {
  albumsApi.list().then((list) => {
    setAlbums(list || [])
    if (typeof targetAlbumId === 'number' && list) {
      const exists = list.some((a) => a.id === targetAlbumId)
      if (!exists) {
        // 保存されていたIDが存在しない場合のフォールバック
        if (initialAlbumId !== undefined && list.some((a) => a.id === initialAlbumId)) {
          setTargetAlbumId(initialAlbumId)
        } else {
          setTargetAlbumId('new')
        }
      }
    }
  }).catch((err) => {
    console.error('Failed to load albums for save dropdown:', err)
  })
}, [])
```

#### 保存処理フロー (`handleSave`)
```tsx
const handleSave = async () => {
  if (!imageObj || bubbles.length === 0) return
  if (targetAlbumId === 'new' && !newAlbumName.trim()) {
    alert('新規アルバム名を入力してください')
    return
  }

  setIsSaving(true)
  try {
    const offCanvas = document.createElement('canvas')
    offCanvas.width = imageObj.naturalWidth
    offCanvas.height = imageObj.naturalHeight
    const offCtx = offCanvas.getContext('2d')
    if (!offCtx) throw new Error('Offscreen canvas context generation failed')

    offCtx.drawImage(imageObj, 0, 0, offCanvas.width, offCanvas.height)
    bubbles.forEach((bubble) => {
      drawSpeechBubble(offCtx, bubble, false, 1, 1, activeFontFamily)
    })

    const blob = await new Promise<Blob | null>((resolve) => offCanvas.toBlob(resolve, 'image/png'))
    if (!blob) throw new Error('Canvas blob generation failed')

    const uploadRes = await snapshotsApi.upload(blob)
    const parentSnapshot = await snapshotsApi.get(currentSourceSnapshotId)

    const updatedParams = {
      ...(parentSnapshot.params || {}),
      speech_bubbles: bubbles,
      base_snapshot_id: currentSourceSnapshotId,
      base_image_path: currentImageUrl,
    }

    let savedSnapshotId: number

    if (saveMode === 'overwrite') {
      await snapshotsApi.patch(snapshot.id, {
        image_path: uploadRes.image_path,
        thumbnail_path: uploadRes.thumbnail_path,
        params: updatedParams,
      })
      savedSnapshotId = snapshot.id
    } else {
      const created = await snapshotsApi.create({
        workflow_id: parentSnapshot.workflow_id,
        image_path: uploadRes.image_path,
        params: updatedParams,
        source_snapshot_id: parentSnapshot.id,
      })
      savedSnapshotId = created.id
    }

    // アルバム登録
    if (targetAlbumId === 'new') {
      const createdAlbum = await albumsApi.create({
        name: newAlbumName.trim(),
        snapshot_ids: [savedSnapshotId],
      })
      try {
        localStorage.setItem(LS_KEYS.LAST_SAVE_ALBUM_ID, String(createdAlbum.id))
      } catch {}
    } else if (typeof targetAlbumId === 'number') {
      await albumsApi.addItems(targetAlbumId, [savedSnapshotId])
      try {
        localStorage.setItem(LS_KEYS.LAST_SAVE_ALBUM_ID, String(targetAlbumId))
      } catch {}
    } else {
      try {
        localStorage.setItem(LS_KEYS.LAST_SAVE_ALBUM_ID, '')
      } catch {}
    }

    onSaved()
    onClose()
  } catch (err: any) {
    console.error(err)
    alert('画像の保存に失敗しました: ' + err.message)
  } finally {
    setIsSaving(false)
  }
}
```

#### UI デザイン（Footer エリア）
- 保存オプションセクション:
  - **保存モード選択**: `[ 新規保存 ]` / `[ 上書き保存 ]` セグメント切り替え
  - **保存先アルバム選択**:
    - ドロップダウン `保存先アルバム: [ + 新規アルバムを作成 | なし (アルバムに追加しない) | 既存アルバム... ]`
    - `targetAlbumId === 'new'` の場合、インラインで `新規アルバム名入力` (`<input type="text" placeholder="アルバム名" />`) を表示。
- アクションボタン:
  - `キャンセル`
  - `保存ボタン`:
    - `saveMode === 'overwrite'` の場合: `上書き保存 ({bubbles.length})`
    - `saveMode === 'new'` の場合: `新規保存して履歴へ追加 ({bubbles.length})`
