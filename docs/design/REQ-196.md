# REQ-196: LoRA管理・タグセット管理の編集モーダルおよびサムネ操作の不具合改修 詳細設計書

## 1. 概要 (Overview)

LoRA管理画面（LoRAsPage.tsx）およびタグセット管理画面（TagsPage.tsx）において報告された以下のUI/UXおよび機能不整合の不具合を解消する。

1. **モバイルモードでの編集モーダル操作不能**: z-50 重複および下部セーフエリア・ナビゲーション考慮不足の解消。
2. **編集モーダルの項目不整合・欠落**: TagsPage.tsx 内の重複モーダル定義を廃止し、TagSetModals.tsx へ一元化。「Target Base Models」および「Subsets（バリエーション）」を漏れなく編集可能にする。
3. **モバイルでのサムネ上アイコン視認不可**: group-hover 依存の透明化を見直し、モバイル/タッチ環境でもアイコンを常時視認可能にし、ドラッグハンドルとの座標衝突を解消する。
4. **カバーサムネ設定時の候補画像サムネイル非表示 & メインプレビュー固定**:
   - 候補画像一覧（Related Snapshots）のサムネイル一覧を共通提供し、クリックで即座に切り替え可能にする。
   - **メインプレビューの固定化（ユーザー要望）**: 候補サムネイル一覧やフォームをスクロールしてもメインプレビュー画像が画面外に流れてしまわないよう、プレビュー領域を上部に固定（デスクトップでは左ペイン上部に固定、モバイルでは上部固定または sticky 表示）し、候補サムネイル領域およびフォーム領域のみが独立してスクロールする設計とする。

## 3. 詳細実装仕様 (Implementation Details)

### 3.1 タグセット管理 (rontend/src/components/TagSetModals.tsx & rontend/src/pages/TagsPage.tsx)

#### 1) フォームフィールドの一元化 (TagSetFormFields)
- TagSetFormFields に以下を完全実装：
  - Name (テキスト)
  - Description (テキスト)
  - Category (InlineCategorySelect)
  - Target Base Models (チェックボックス一覧: 	arget_base_model_ids)
  - Tags (テキストエリア)
  - Cover Thumbnail Image (現在のカバー表示 + 画像アップロードボタン)
  - Subsets / バリエーション (サブセット名 + カンマ区切りタグ + 追加/削除)
- TagSetCreateModal, TagSetEditModal, TagSetDetailModal (編集モード) のすべてで共通 TagSetFormFields を利用。

#### 2) TagsPage.tsx のローカルモーダル廃止
- TagsPage.tsx 内の LocalTagSetFormFields, LocalTagSetCreateModal, LocalTagSetEditModal を削除。
- TagSetModals.tsx の一元化モーダルを利用。

#### 3) メインプレビュー固定 + 候補画像サムネイルグリッド（Related Snapshots）独立スクロール
- 左ペイン（またはモバイル上部）において、メインプレビュー（spect-square）は lex-shrink-0 として常に表示領域に固定。
- 候補サムネイル一覧（Related Snapshots）はプレビュー直下で独立してスクロール可能（overflow-y-auto max-h-[140px] や lex-1 overflow-y-auto）とする。
- 候補画像をタップ/クリックすると、スクロール位置を崩さずにメインプレビューが即時切り替わり、カバー画像設定・確認がストレスなく行える。

---

### 3.2 LoRA管理 (rontend/src/components/LoraModals.tsx & rontend/src/pages/LoRAsPage.tsx)

#### 1) メインプレビュー固定 + 候補サムネイル独立スクロール
- LoraDetailModal においても同様に、メインプレビュー領域を上部に固定し、直下の Related Snapshots 候補サムネイル領域および右ペインのフォーム領域をそれぞれ独立してスクロール可能とする。

---

### 3.3 モバイルモードでの操作性・z-index・アイコン配置改善 (共通)

#### 1) モーダル z-index と下部余白の統一
- すべてのモーダルで .modal-backdrop クラス（z-index: 100 かつ padding-bottom: calc(var(--mobile-nav-height) + 1rem + env(safe-area-inset-bottom))）を適用。
- モバイルボトムナビゲーション（z-50）に遮られない構造にする。

#### 2) サムネイル上の操作アイコンのモバイル視認性と配置
- PC（マウス環境）: lg:opacity-0 lg:group-hover:opacity-100（ホバー時に表示）。
- モバイル（タッチ環境）: opacity-100（常時表示）。
- ドラッグハンドル（GripVertical）と編集・削除ボタンの座標重複を解消（ドラッグハンドルを 	op-2 left-2、編集・削除を右上に配置など）。
