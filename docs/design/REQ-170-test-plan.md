# PBI-REQ-170: 吹き出し自体の回転および吹き出し複製・コピー機能 - テスト計画書

## 1. 自動テスト計画 (Automated Tests)

### 1.1 単体テスト実行コマンド
```bash
npm --prefix frontend test -- speechBubbleRenderer.test.ts SpeechBubbleControls.test.tsx SpeechBubbleEditorModal.test.tsx
```

### 1.2 テスト対象および検証項目
1. **`speechBubbleRenderer.test.ts`**:
   - `drawSpeechBubble` において `rotation` が指定された場合、`ctx.rotate` および `ctx.translate` が吹き出し中心座標に対して正しく呼び出されること。
   - `rotation: 0` または未指定の場合に不要な回転変換が行われないこと。
   - REQ-171 で追加される縦書きパステストとの共存・非破壊を確認。
2. **`SpeechBubbleControls.test.tsx`**:
   - 吹き出し回転スライダー / 数値入力フィールドがレンダリングされ、変更時に `onUpdate({ rotation: value })` が発火すること。
   - 「複製」ボタンが表示され、クリック時に `onDuplicate` が発火すること。
3. **`SpeechBubbleEditorModal.test.tsx`**:
   - 吹き出し選択時に `Ctrl+C` および `Ctrl+V` を入力すると、新規吹き出しが複製追加され、選択状態になること。
   - テキストエリア等の入力フォームフォーカス時には `Ctrl+C`/`Ctrl+V` で吹き出し複製が行われないこと。
   - 回転された吹き出しに対するクリック・ドラッグ判定（逆回転座標変換）が正しく機能すること。

---

## 2. 手動検証シナリオ (Manual Verification Scenarios)

### シナリオ 1: 吹き出し回転
1. スナップショット詳細から「セリフ編集」モーダルを開く。
2. 任意の吹き出しを選択し、回転スライダーを動かして角度を 45° に設定する。
3. プレビュー上で吹き出し、テキスト、装飾が 45° 傾いて描画されることを確認する。
4. 回転した状態の吹き出しをドラッグ移動、リサイズできることを確認する。
5. 「保存」を実行し、保存された派生画像でも同様に 45° 傾いてレンダリングされていることを確認する。

### シナリオ 2: 吹き出し複製 (UIボタン & キーボードショートカット)
1. 吹き出しを選択した状態で、コントロールパネルの「複製」ボタンを押下する。
2. 元の吹き出しから少しずれた位置に同一内容・同一スタイルの吹き出しが生成され、選択状態になることを確認する。
3. PC上で吹き出しを選択し、`Ctrl+C` を押した後に `Ctrl+V` を複数回押下する。
4. 押した回数分だけ吹き出しが連続複製配置されることを確認する。
5. テキスト入力欄にフォーカスを当てて文字を選択し、`Ctrl+C` / `Ctrl+V` を行った際、吹き出しではなく通常のテキストコピー＆ペーストが動作することを確認する。
