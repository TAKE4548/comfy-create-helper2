# REQ-149 詳細設計書: アルバム一覧画面におけるアルバムの任意並び替え機能およびアルバム名編集（リネーム）機能の追加

## 1. 概要 (Overview)
アルバム一覧画面およびアルバム管理機能に関して、以下の課題を解決します：
1. **アルバム表示順序の固定化**:
   現在はアルバム一覧の並び順が名前順（`models.Album.name`）で固定されており、ユーザーが作業頻度や整理方針に合わせてアルバムの表示順序を自由に並び替える（ドラッグ＆ドロップ等で順序変更・永続化する）ことができない。
2. **アルバム作成後の名前編集不可（不変性）**:
   アルバム作成時に設定した名前を後から変更する手段（リネームAPIおよびUI）が存在せず、誤字修正やアルバムの用途変更に対応できない。

本設計では、以下を実装します：
- **アルバムの任意並び替え（D&Dおよび永続化）**:
  - `albums` テーブルに `sort_order` カラムを追加し、アルバム作成時に自動採番、一覧取得時は `sort_order` 昇順で返却。
  - バックエンドに `PUT /api/albums/reorder` エンドポイントを新設。
  - フロントエンドのアルバム一覧画面（`HistoryPage.tsx`）に `@dnd-kit` を用いたドラッグ＆ドロップによる並び替え機能を実装。
- **アルバム名の編集（リネーム）**:
  - バックエンドに `PUT /api/albums/{album_id}` エンドポイントを新設（名前の空文字チェックおよび重複チェックバリデーションを含む）。
  - フロントエンドのアルバムカードおよびアルバム詳細画面ヘッダーにリネームUI（編集ボタン・インライン入力等）を追加。

## 3. 詳細設計 (Detailed Design)

### 3.1 Backend 設計

#### 3.1.1 DB モデル (`models.py`)
```python
class Album(Base):
    __tablename__ = "albums"

    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    name: Mapped[str] = mapped_column(String, nullable=False, unique=True)
    sort_order: Mapped[int] = mapped_column(Integer, nullable=False, default=0)
    created_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.utcnow)

    items: Mapped[list["AlbumItem"]] = relationship(
        back_populates="album", cascade="all, delete-orphan",
        order_by="AlbumItem.sequence_order"
    )
```

#### 3.1.2 スキーマ (`schemas/album.py`)
```python
class AlbumUpdate(BaseModel):
    name: Optional[str] = None
    sort_order: Optional[int] = None

class AlbumReorder(BaseModel):
    ordered_ids: list[int]

class AlbumRead(BaseModel):
    model_config = ConfigDict(from_attributes=True)
    id: int
    name: str
    sort_order: int = 0
    created_at: datetime
    items: list[AlbumItemRead] = []

class AlbumSummary(BaseModel):
    model_config = ConfigDict(from_attributes=True)
    id: int
    name: str
    sort_order: int = 0
    created_at: datetime
```

#### 3.1.3 ルーター (`routers/albums.py`)
```python
@router.get("", response_model=list[schemas.AlbumRead])
def list_albums(db: Session = Depends(get_db)):
    albums = db.query(models.Album).order_by(models.Album.sort_order.asc(), models.Album.id.asc()).all()
    return [
        schemas.AlbumRead(
            id=album.id,
            name=album.name,
            sort_order=album.sort_order,
            created_at=album.created_at,
            items=[
                schemas.AlbumItemRead(
                    snapshot_id=item.snapshot_id,
                    sequence_order=item.sequence_order,
                    image_path=item.snapshot.image_path if item.snapshot else None,
                    created_at=item.snapshot.created_at if item.snapshot else None,
                )
                for item in sorted(album.items, key=lambda x: x.sequence_order)
            ],
        )
        for album in albums
    ]

@router.put("/reorder", status_code=status.HTTP_204_NO_CONTENT)
def reorder_albums(payload: schemas.AlbumReorder, db: Session = Depends(get_db)):
    for i, aid in enumerate(payload.ordered_ids):
        db.query(models.Album).filter(models.Album.id == aid).update({"sort_order": i})
    db.commit()

@router.put("/{album_id}", response_model=schemas.AlbumRead)
def update_album(album_id: int, payload: schemas.AlbumUpdate, db: Session = Depends(get_db)):
    album = db.query(models.Album).filter(models.Album.id == album_id).first()
    if not album:
        raise HTTPException(status_code=404, detail="Album not found")
    
    if payload.name is not None:
        trimmed_name = payload.name.strip()
        if not trimmed_name:
            raise HTTPException(status_code=400, detail="Album name cannot be empty")
        
        # 重複チェック（自身以外の同名アルバム）
        existing = db.query(models.Album).filter(
            models.Album.name == trimmed_name,
            models.Album.id != album_id
        ).first()
        if existing:
            raise HTTPException(status_code=400, detail="Album with this name already exists")
        
        album.name = trimmed_name

    if payload.sort_order is not None:
        album.sort_order = payload.sort_order

    db.commit()
    db.refresh(album)
    return get_album(album_id, db)
```

### 3.2 Frontend 設計

#### 3.2.1 API Client (`client.ts`)
```typescript
export const albumsApi = {
  list: () => request<Album[]>('/albums'),
  get: (id: number) => request<Album>(`/albums/${id}`),
  create: (data: unknown) => request<Album>('/albums', { method: 'POST', body: JSON.stringify(data) }),
  update: (id: number, data: { name?: string; sort_order?: number }) =>
    request<Album>(`/albums/${id}`, { method: 'PUT', body: JSON.stringify(data) }),
  reorder: (ordered_ids: number[]) =>
    request<void>('/albums/reorder', { method: 'PUT', body: JSON.stringify({ ordered_ids }) }),
  delete: (id: number) => request('/albums/' + id, { method: 'DELETE' }),
  // ...
}
```

#### 3.2.2 `HistoryPage.tsx` の UI 拡張
- **アルバム並び替え**:
  - アルバムカードリストを `<DndContext>` と `<SortableContext items={albums.map(a => a.id)}>` で囲む。
  - 各アルバムカードに `SortableAlbumCard` を作成し、ドラッグハンドルまたはカード全体をドラッグ可能とする。
  - ドラッグ終了（`onDragEnd`）時に `albumsApi.reorder` を呼び出し、UIを即時楽観更新＆クエリ無効化。
- **アルバムリネーム**:
  - アルバムカード内に `Pencil` アイコンの編集ボタンを配置。
  - クリックするとインラインでテキスト入力欄が表示され、Enterキーまたはチェックボタンで `albumsApi.update` を実行。
  - アルバム詳細画面のヘッダーのタイトル横にも同様にリネームアイコンを配置し、詳細画面からも名前を変更可能にする。
