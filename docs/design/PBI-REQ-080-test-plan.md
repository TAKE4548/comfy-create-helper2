# PBI-REQ-080 実行可能テスト計画: 新規プロファイル作成時のデフォルト値保持機能の検証

## 1. 自動テスト (CLI Verification)
- **コマンド**: `npm run test -- src/pages/GeneratePage/hooks/__tests__/useWorkflowParams.test.ts`
- **期待値**: テストスイートの全項目が PASS すること。
- **判定ロジック**: Exit code が 0 でない場合、テスト失敗とみなす。

## 2. ツール主導監査 (Tool-Driven Audit)
- **コード監査**: `npm run lint` を実行し、構文エラーや警告が出ないことを確認する。

## 3. ブラウザ検証 (Browser Agent Verification)
- **前提条件**: ローカル開発サーバー (`npm run dev`) が起動済みであること。
- **対象 URL**: `http://localhost:5173/`
- **操作手順**:
  1. **ワークフロー選択**: 生成ページにて、任意のワークフロー（例: `comfy-default-workflow` など）を選択する。
  2. **モーダル開閉**: プロファイル選択横の「プロファイルを追加」ボタンをクリックし、「新規プロファイル作成 (Add Set)」モーダルを開く。
  3. **設定入力**: 
     - コピー元（ベース設定）で**「ワークフローのデフォルト設定」**を選択する。
     - プロファイル名に `TestDefaultSet` を入力する。
     - 「作成」ボタンをクリックする。
  4. **状態確認**: モーダルが閉じ、`TestDefaultSet` がアクティブプロファイルになっていることを確認する。

- **判定基準 (Assertion)**:
  以下の条件を**すべて**満たす場合のみ「テスト合格」とみなす：
  1. ラベル確認: 画面内に新規プロファイル名として `"TestDefaultSet"` が存在すること。
  2. パラメータ非空確認: 画面上のパラメータ入力欄（例: 各種プロンプト入力欄）が空欄にならず、ワークフローに設定された初期デフォルトテキストが入っていること。
