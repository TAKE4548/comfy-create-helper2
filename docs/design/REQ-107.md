# REQ-107 詳細設計書

## 1. 概要
タブレットやモバイル（画面幅1024px未満）において、画像プレビューモーダル（`HistoryModalPreview`）をフルスクリーン表示した際、下部ナビゲーションメニューの余白が考慮されたままとなり、画像表示領域が最大化されない。
本設計では、フルスクリーン表示（HTML5 Fullscreen API 適用時）に下部余白を解除し、画面全体に最大化して表示されるようにする。

## 2. 設計詳細

### 2-1. CSSルールの追加
`frontend/src/index.css` の `.modal-backdrop` クラスに対して、フルスクリーン表示時（`:fullscreen` 擬似クラス適用時）にパディングをリセットする定義を追加する。

```css
/* フルスクリーン表示時は、下部メニュー等の余白を排除して画面全体に最大化する */
.modal-backdrop:fullscreen {
  padding: 0 !important;
}

/* Safari/iOS互換用のプレフィックス対応 */
.modal-backdrop:-webkit-full-screen {
  padding: 0 !important;
}
```

また、もし必要であれば、HistoryModalPreview 内で `isFullscreen` の状態変更時に `is-fullscreen` クラスを要素に付加し、CSS側で `.modal-backdrop.is-fullscreen { padding: 0 !important; }` といった代替的な制御も可能とする。しかし、Fullscreen APIの `:fullscreen` または `-webkit-full-screen` 疑似クラスを適用する方が、ブラウザのフルスクリーン表示と密結合できて確実である。

### 2-2. 影響範囲
- モーダル全般の背景 `.modal-backdrop`
  - 通常表示時は `padding: 1rem` および `padding-bottom` (モバイル余白) がそのまま適用されるため影響はない。
  - `HistoryModalPreview` 以外のモーダルがフルスクリーン化されることは現時点ではないため、デグレーションの心配は極めて低い。

## 3. 動作検証方針
- PCブラウザのデベロッパーツールで画面幅を 1024px 未満（モバイル・タブレット表示）にシミュレート。
- 画像プレビューモーダルを開き、フルスクリーンボタンをクリック。
- フルスクリーン時に、画像表示領域が画面の上下左右いっぱいに最大化され、下部に約4rem+の隙間（GAP）が生じていないことを確認。
