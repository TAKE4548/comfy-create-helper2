# REQ-026 テスト計画書

## 1. テスト概要
スマホモード（画面幅768px未満）における、画像生成中の細いライン状プログレスバーの表示・非表示動作、および生成履歴/スナップショット画像タップ時の全画面モーダルプレビューにおける動作（スワイプ、閉じる操作、スクロールメタ情報表示）が正常に動作することを確認します。

## 2. テストケース・検証項目

### 2.1 モバイル生成進捗表示の検証 (AC-1, AC-2)
* **手順**:
  1. Chromeデベロッパーツールでモバイル表示（例: 幅375px）にする。
  2. ワークフローを選択し、プロンプトを入力して「Generate Batch」を実行する。
* **期待される結果**:
  * 生成中、ヘッダーとプレビューエリア（メインコンテンツ）の間に細いライン状のプログレスバーが表示されること。
  * プログレスバーの付近に進行状況のパーセンテージ（例: `50%`）が表示されること。
  * 生成完了時、または「Cancel」押下による生成中断時に、プログレスバーおよびパーセンテージが速やかに非表示になること。
  * 画面幅が極端に狭い（例: 320px）場合、パーセンテージテキストが非表示またはレイアウトが崩れずに適応されること。

### 2.2 全画面モーダルの表示・非表示の検証 (AC-3, AC-5)
* **手順**:
  1. モバイル表示で「Generate」ページの履歴サムネイルストリップ、または「History」ページの履歴サムネイルをタップする。
  2. 表示されたプレビューモーダルの右上にある「閉じる(X)」ボタンをクリックする。
  3. 再度サムネイルをタップしてモーダルを開き、画像外の背景黒エリアをタップする。
* **期待される結果**:
  * サムネイルタップ時に画面全体を覆うプレビューモーダルがオーバーレイとして表示されること。
  * 閉じるボタンタップ、および画像外の背景エリアタップでモーダルが正しく閉じ、元の画面に戻ること。

### 2.3 スワイプ操作による画像切り替えの検証 (AC-4)
* **手順**:
  1. 履歴画像が複数存在する状態でサムネイルをタップし、モーダルを開く。
  2. 画像エリア上で左方向にスワイプ（指を右から左へ動かす）する。
  3. 次に右方向にスワイプ（指を左から右へ動かす）する。
* **期待される結果**:
  * 左スワイプで次の履歴画像へ切り替わること。
  * 右スワイプで前の履歴画像へ切り替わること。
  * 最初または最後の画像でそれ以上スワイプできない場合の境界値動作が正常であること。

### 2.4 メタ情報のスクロール表示検証 (AC-6)
* **手順**:
  1. プレビューモーダルを開いた状態で、モーダル内を上下にスクロールする。
* **期待される結果**:
  * プレビュー画像自体の表示領域（`60vh`等）が阻害されないよう考慮されたレイアウトであること。
  * 下部にスクロールすると、その画像を生成した際のプロンプト、シード値、ステップ数、CFG等のメタ情報が崩れずに表示されること。
  * 情報量が多い場合でもメタ情報エリアが正しくスクロールし、最下部までスクロールして全てのメタ情報を読めること。

## 3. 手動テストの検証方法
* Chromeデベロッパーツールのモバイルエミュレータ（Touch emulation有効）を用いてタッチスワイプ動作を確認します。
