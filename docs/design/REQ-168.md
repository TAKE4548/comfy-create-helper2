# REQ-168 詳細設計書: セリフ編集における漫画演出修飾パラメータ拡張およびプリセット対応

## 1. 概要 (Overview)
漫画制作におけるセリフやSE（描き文字・擬音・擬態語）の表現力を向上させるため、セリフ編集機能（`SpeechBubbleEditor` / `SpeechBubbleControls`）において多様な修飾パラメータ（フォント変形、文字単位の90度回転/縦中横、サイズ揺らぎ・スケールカーブ、パス・ステップ配置、グラデーション・トーン・中抜き、多重フチ・輪郭スタイル）を追加する。
また、これらの拡張パラメータを一括で管理・再利用できるようにプリセット機能（`SpeechBubblePreset`）およびローカルストレージ（`LAST_USED_STYLE_STORAGE_KEY`）を拡張し、既存プリセットとの後方互換性（デフォルト値による自動マイグレーション）を担保する。

## 3. レンダリングエンジン設計 (`frontend/src/utils/speechBubbleRenderer.ts`)

### 3.1 描画パイプライン
1. **テキスト解析・レイアウト分割**:
   - `bubble.orientation`（縦書き / 横書き）に応じて文字を行・列に分割。
   - 各文字のインデックス（全体の通し番号）を保持。
2. **文字ごとの座標・変形計算**:
   - **縦中横（90度回転）**: `rotate90Indices` に含まれるインデックスの文字、または縦書き時の `!?` / 英数字（ユーザー指定）をその場で90度回転描画。
   - **ダイナミックスケール**: 文字通し位置比率 `t = index / (totalChars - 1)` に基づき、`scaleCurve`（linear, ease-in, ease-out）に応じた文字フォント倍率を適用。
   - **サイズ揺らぎ (Jitter)**: `sizeJitter > 0` の場合、疑似乱数（文字位置依存シード）により `±sizeJitter%` の拡大縮小を合成。
   - **パス配置**: `pathPreset` に応じて基準ベースライン座標 `(cx, cy)` を算出（波型: `sin(x)`, 階段状: ステップオフセット, 円弧: `arc(r, angle)`）。
   - **シアー変形 (Skew)**: `shearAngle` によるテキスト傾斜マトリクス適用。
3. **多重フチ（MultiStroke）描画**:
   - `multiStrokes` の太いレイヤーから順に `ctx.strokeText` を実行。
   - 各レイヤーの `lineJoin`, `lineStyle` (破線), `offsetX`, `offsetY`, `roughness` を反映。
4. **塗りつぶし（Fill）描画**:
   - `fillMode === 'solid'`: `ctx.fillStyle = textColor`
   - `fillMode === 'gradient'`: テキスト領域全体に対して `createLinearGradient` / `createRadialGradient` を生成して `fillText`
   - `fillMode === 'tone'`: 網点パターンの CanvasPattern を生成して `fillText`
   - `fillMode === 'hollow'`: `fillText` をスキップしフチのみ表示

### 3.2 演出パラメータ連動の吹き出しサイズ・フォント自動計算
演出パラメータによって文字の専有領域が変化するため、`calculateFitBubbleDimensions` および `calculateFitFontSize` に `effects?: MangaTextEffectConfig` 引数を追加し、以下の補正を適用する：

1. **実効文字スケール (Max Scale Multiplier)**:
   - `maxScale = Math.max(scaleStart || 1.0, scaleEnd || 1.0) * (1 + (sizeJitter || 0) / 100)`
   - 各文字の基準サイズに `maxScale` を乗算して最大専有幅・高さを算出。
2. **字間 (Letter Spacing) & 行間 (Line Height)**:
   - 縦書き: `lineHeight = fontSize * (lineHeightRatio || 1.15) + (letterSpacing || 0)`, `colStep = fontSize * 1.3`
   - 横書き: `colStep = fontSize * (lineHeightRatio || 1.25)`, 各文字間に `(letterSpacing || 0)` を加算。
3. **シアー傾斜 (Shear / Skew)**:
   - 傾斜角度 $\theta$（度数法）による水平/垂直のはみ出し: `extraSkewW = totalTextHeight * Math.tan(abs(shearAngle) * Math.PI / 180)`
4. **多重フチ (MultiStroke) & オフセット**:
   - 各ストロークレイヤーの最大拡張幅: `extraStroke = max(layer.width + abs(layer.offsetX), layer.width + abs(layer.offsetY))` をバウンディングサイズに加算。
5. **パス軌道 (Path Preset) & ベースラインガタつき**:
   - 波型（sine-wave）の振幅、円弧（arc）のたわみ量、階段状（stepped）のステップ段差、`baselineJitter` をバウンディング矩形に余白として加算。

## 4. UI/UX コントロール設計 (`frontend/src/components/SpeechBubbleControls.tsx`)

### 4.1 アコーディオン／タブ構成
- **基本スタイル**: 形状、組み方向（縦/横）、フォント、基本色、吹き出し枠線
- **🔤 タイポグラフィ & 縦中横**:
  - 字間スライダー（-10 ~ 50px）
  - 行間スライダー（0.8 ~ 2.5倍）
  - 傾斜（シアー）スライダー（-45° ~ 45°）

  - スケール変化カーブ（なし / だんだん大きく / だんだん小さく / イージング）
  - 開始倍率・終了倍率スライダー
  - サイズ揺らぎ（Jitter）スライダー（0 ~ 50%）
- **〰️ パス・軌道レイアウト**:
  - プリセット軌道（なし / 斜め上がり / 階段状ステップ / 波型 / 円弧）
  - パス追従文字回転トグル
  - ガタつきオフセットスライダー
- **🎨 塗り・グラデーション・トーン**:
  - 塗りモード（単色 / グラデーション / トーン / 中抜き）
  - グラデーション方向・カラーストップエディタ
- **🔲 多重フチ（多層アウトライン）**:
  - フチ取りレイヤー追加・削除・並び替え
  - レイヤーごとの太さ、色、影オフセット、角処理（Round/Miter/Bevel）、破線、かすれ処理
- **💾 プリセット管理**:
  - 現在の演出設定を名前をつけて保存
  - 登録済みプリセット一覧からワンクリック適用
  - 削除・並び替え

## 5. 後方互換性およびマイグレーション
- 既存の DB レコード（`effects_json` なし/空）は、`DEFAULT_MANGA_EFFECTS` として解釈。
- `localStorage` に保存された旧フォーマットの `LAST_USED_STYLE_STORAGE_KEY` は、`DEFAULT_MANGA_EFFECTS` とマージして安全にロード。
- APIレスポンスにおいて `effects` がない場合はデフォルトオブジェクトを返却。
