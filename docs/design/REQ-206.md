# REQ-206 設計仕様書: セリフ編集のしっぽ詳細調整の改善

## 1. 概要
本仕様書は、セリフ編集モーダルにおけるしっぽ（Tail）の微調整機能について、吹き出し移動時の設定消失バグの修正、吹き出し内部への頂点・接点侵入防止ガード、および2箇所の接点を独立してドラッグ操作可能にする仕様拡張を定義する。

## 2. 変更対象コンポーネント & データ構造

### 2.1 データ型定義 (rontend/src/types/speechBubble.ts)
`	ypescript
export interface BubbleTail {
  x: number // 元画像座標系での尻尾先端X
  y: number // 元画像座標系での尻尾先端Y
  baseAngle1?: number // 1点目の接点角度 (rad, -PI ~ PI)
  baseAngle2?: number // 2点目の接点角度 (rad, -PI ~ PI)
  baseAngleOffset?: number // (後方互換用) 旧・本体接点中心角度オフセット
  baseSpreadRatio?: number // (後方互換用) 旧・接点幅倍率
  isFineTuning?: boolean // 微調整モード有効フラグ (default: false)
}
`

### 2.2 幾何計算 & レンダリング仕様 (rontend/src/utils/speechBubbleRenderer.ts)

#### 1. 頂点（先端）の侵入防止クランプ (clampTailApexOutsideBubble)
- 吹き出し中心 (cx, cy)、半幅・半高 (rx, ry) に対し、先端座標 (tx, ty) が吹き出し外周内部に入り込まないようクランプする。
- 楕円 (oval): (dx/rx)^2 + (dy/ry)^2 >= 1.05 を維持。内側に入った場合は同角度の外周 + 5% マージン位置に押し出す。
- 角丸 (rounded-rect): max(|dx|/hw, |dy|/hh) >= 1.05 を維持。

#### 2. 外周接点座標の計算 (getTailContactPositions)
- aseAngle1, aseAngle2 が指定されている場合はその角度を使用。
- 未指定の場合（または旧形式 aseAngleOffset, aseSpreadRatio）は、先端方向 	ailAngle = atan2(ty - cy, tx - cx) を基準にデフォルトスプレッド（楕円は 0.25 rad, 角丸は 0.12 * min(w,h)）を展開して (angle1, angle2) を算出。
- 楕円: P1 = (cx + rx * cos(angle1), cy + ry * sin(angle1)), P2 = (cx + rx * cos(angle2), cy + ry * sin(angle2))
- 角丸: 中心から ngle1, ngle2 への放射線と角丸矩形外周との交点 P1, P2 を算出。

#### 3. 形状パス生成 (drawBubbleShape)
- 楕円: ctx.ellipse で ngle2 から ngle1 までの大円弧を描画し、ctx.lineTo(tx, ty) で先端を結び ctx.closePath() で閉じる。
- 角丸: 外周上の P2 から角を巡って P1 まで線・円弧を描画し、ctx.lineTo(tx, ty) で先端を結び closePath() で閉じる。

#### 4. ハンドル描画 (drawSpeechBubble)
- 微調整モード時（isFineTuning === true）:
  - 先端ハンドル（青丸, 半径6px）
  - 接点1ハンドル（橙丸, 半径6px, P1）
  - 接点2ハンドル（橙丸, 半径6px, P2）
  - ガイド点線: P1 -> (tx, ty) および P2 -> (tx, ty) の破線

### 2.3 キャンバス操作 & 状態保持 (rontend/src/components/SpeechBubbleEditorModal.tsx)

#### 1. 移動・複製時のプロパティ保持
- draggingState.type === 'bubble' および handleDuplicateBubble において、	ail: initB.tail ? { ...initB.tail, x: initB.tail.x + dx, y: initB.tail.y + dy } : undefined とし、全プロパティを完全保持。

#### 2. 接点ドラッグ処理
- draggingState.type: 'tail-base-1' / 'tail-base-2'
- マウス移動時にローカル中心 (cx, cy) に対する角度 Math.atan2(localPt.y - cy, localPt.x - cx) を計算し、aseAngle1 / aseAngle2 を更新。
- 先端ドラッグ時（draggingState.type === 'tail'）は clampTailApexOutsideBubble を適用。

#### 3. ツールバーUI
- 「🎯 しっぽ微調整モード」チェックボックス
- 「接点1・2をドラッグして微調整」ガイドテキスト
- 「🔄 接点初期化」ボタン（aseAngle1: undefined, baseAngle2: undefined, baseAngleOffset: 0, baseSpreadRatio: 1.0）

## 3. 後方互換性
- 既存データに aseAngleOffset や aseSpreadRatio のみが存在する場合、または何も角度指定がない場合でも、getTailContactPositions が自動的に適切な2接点を導出して描画するため、既存プリセットやスナップショットデータとの完全な互換性を維持する。
