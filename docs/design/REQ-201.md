# REQ-201: 生成プリセット一括編集機能の強化 詳細設計書

## 1. 概要 (Overview)

本設計は、生成プリセットの一括編集・一括管理における操作性と柔軟性を大幅に強化することを目的とする。
具体的には以下の4つの主要機能を実装する。

1. **プリセット一覧における範囲選択（Shift+クリック）**:
   - プリセット一覧で、Shiftキーを押しながら選択することで、直前の選択項目から対象項目までの範囲を一括で選択・解除可能にする（`useMultiSelect` の統合）。
2. **パラメータ一括編集UIの型対応（数値スピン/スライダー、セレクタ等）**:
   - `ProfileBulkEditModal` のパラメータ編集タブにおいて、サンプラー、スケジューラー、ブール値、数値（int/float）、カスタム型パラメータ等について、それぞれの型に応じた専用UIコントロールを提供し、「変更しない」と特定値の指定を明確に区別して一括適用できるようにする。
3. **選択プリセット間の共通タグ抽出および選択削除機能**:
   - 選択された複数プリセットのプロンプト（各テキストフィールド）を解析し、全対象プリセットに共通して含まれるタグを自動抽出・列挙。
   - ユーザーが不要な共通タグをチェック/チップ選択し、選択中の全プリセットから一括除外（削除）できる `remove_tags` オペレーションを提供する。
4. **一括編集モーダル上のプロンプト編集欄のタグチップUI対応**:
   - 一括編集モーダルのプロンプト入力欄（追加・置換・削除対象のタグ入力）において、タグチップ形式のUI（`TagChipInput` 等）を採用し、タグ単位での追加・個別削除・ハイライト等の視覚的な操作体験を提供する。

## 3. 詳細仕様 (Detailed Specifications)

### 3.1 範囲選択機能の実装 (`PresetManagerPanel.tsx`)
- 既存の `useMultiSelect` Hook を `PresetManagerPanel` に導入。
- `bulkSelectedIds` および `bulkMode` を `useMultiSelect` の戻り値（`selectedIds`, `isMultiSelectMode`, `handleItemClick`, `selectAll`, `clearSelection`, `toggleItem` 等）と統合。
- `SortablePresetRow` のクリックイベントおよびチェックボックス操作時、`event.shiftKey` を `handleItemClick` に渡すことで、Shift+クリックによる範囲選択がシームレスに動作する。

### 3.2 パラメータ一括編集UIの型対応・個別活性化チェックボックス設計 (`ProfileBulkEditModal.tsx`)
- `ProfileBulkEditModalProps` に `paramTypeMasters?: ParamTypeMaster[]` を追加（`GeneratePage.tsx` から受け渡す）。
- **個別「変更する」チェックボックスによる活性化制御 (Explicit Opt-in UI)**:
  - パラメータタブ内の各項目（ロール）およびバッチ数（Batch Size）に、**「変更する」チェックボックス**を配置。
  - **初期状態（未チェック時）**:
    - 入力コントロールは非活性（`disabled`、薄いグレーアウト表示）となり、一括変更の対象外であることを視覚的・機能的に明示。
  - **チェック時（活性化時）**:
    - コントロールが活性化し、ユーザーが通常の直感的な入力（ドロップダウン選択、数値入力、ブールトグル等）を行えるようになる。
- **型別UIコントロールの仕様**:
  - `select_sampler`: ComfyUIオブジェクト情報またはデフォルトリストに基づくドロップダウン。
  - `select_scheduler`: スケジューラーリストに基づくドロップダウン。
  - `boolean`: 標準のトグルスイッチ（チェック時のみ切り替え可能）。
  - `int` / `float`: 数値入力コントロール（ステップ幅、最小値、最大値のサポート）。
  - `customType` (`paramTypeMasters` に登録された型):
    - `widget_type === 'select'`: `combo_options` をオプションとして持つ `<select>`。
    - `widget_type === 'boolean'`: トグルスイッチ。
    - 数値型: ステップ・範囲指定付き数値入力。
  - `textarea` / `string`: テキスト入力。
  - `Batch Size`: バッチ数入力コントロール。
- **ペイロード生成ルール**:
  - チェックボックスがON（`enabledParams.has(role)`）になっている項目のみを抽出し、その入力値を `paramPatch`（または `batchSize`）に設定してペイロードを構築。
  - チェックされていない項目は100%確実にペイロードから除外され、既存プリセットの値が完全に維持される。

### 3.3 共通タグの抽出・選択削除機能 (`ProfileBulkEditModal.tsx`, `useGeneratePageState.ts`)
- **共通タグ抽出ロジック (`computeCommonTags`)**:
  - モーダル上で選択されている対象プロンプトフィールド（`promptTargetAll` が有効な場合は全 textarea ロール、個別にチェックされている場合はその選択されたロール群）を抽出スコープとする。
  - 対象ロールが動的に切り替わるたびに、選択中の全プリセットから該当ロールのプロンプトをパースしてタグ配列を取得。
  - 選択中の全プリセット（$N$ 件）において、指定された対象ロール群内に共通して含まれるタグ（出現回数 $= N$）をリアルタイムに算出・抽出。
  - 抽出された共通タグ一覧をインタラクティブなチップ形式で表示。
- **削除タグ選択とペイロード**:
  - 共通タグチップをクリックすることで「削除対象（赤系バッジ / 取り消し線）」としてトグル選択。
  - ペイロードに `promptOps: [{ op: 'remove_tags', fields: targetFields, tags: selectedCommonTags }]` を追加。
- **適用ロジック (`handleBulkEditApply`)**:
  - `op.op === 'remove_tags'` の場合、各プリセットの対象フィールド文字列をカンマ区切りでパースし、指定された削除対象タグ（大文字小文字を区別せず比較）を除去。
  - 残ったタグを `, ` で再結合して `newParamValues[field]` に保存。

### 3.4 一括編集モーダル上のタグチップUI (`ProfileBulkEditModal.tsx`)
- 一括編集モーダル内のプロンプト入力エリア（「検索・置換」の置換テキスト、「先頭に追加」「末尾に追加」「全置換」のテキスト入力欄）に `TagChipInput` を組み込み。
- カンマ区切り入力や Enter によるタグ化、チップの「✕」ボタンによる個別削除、テキスト貼り付けによる一括タグ化をサポート。
- 「共通タグから選んで削除」セクションでは、抽出された共通タグをインタラクティブなチップとして一覧表示し、クリックで直感的に削除指定可能にする。
