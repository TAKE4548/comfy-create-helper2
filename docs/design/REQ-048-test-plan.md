# REQ-048: LoRA・タグセット管理のカバー画像設定機能 テスト計画

## 1. 単体・統合テスト (Backend)

### 1.1 マイグレーションテスト
- バックエンドサーバー起動時に `run_migrations` が正常に実行され、エラーが発生しないこと。
- SQLite DB (`db/prompt_surgeon.db`) の `tag_sets` テーブルに `thumbnail_path` カラムが追加されていること。

### 1.2 API テスト
- Python 統合テスト（pytest 等）または手動 HTTP リクエスト検証を行う。
- **TagSet API の検証内容**:
  - `POST /api/tag-sets` で `thumbnail_path` を指定して作成し、返却値に正しく反映されること。
  - `PUT /api/tag-sets/{id}` で `thumbnail_path` を更新し、反映されること。
  - `GET /api/tag-sets` および `GET /api/tag-sets/{id}` のレスポンスに `thumbnail_path` が含まれていること。
  - 関連するスナップショットを6件以上作成した状態で `GET /api/tag-sets` 等を呼び出し、`snapshot_paths` に5件を超えるすべての画像パスが含まれていること。
- **Lora API の検証内容**:
  - 関連するスナップショットを6件以上作成した状態で `GET /api/loras` 等を呼び出し、`snapshot_paths` に5件を超えるすべての画像パスが含まれていること。

## 2. フロントエンド UI・機能テスト

### 2.1 モーダル表示とレイアウト検証
- LoRA / タグセットの「詳細モーダル」および「編集モーダル」を開いたとき、レイアウトが崩れず拡大表示されること。
- 関連スナップショットが存在する場合、最初の画像またはカバー設定済み画像がプレビューに表示されること。
- 関連スナップショットが複数ある場合、プレビュー画像の左右矢印をクリックすることで、画像が順番に切り替わること。
- 関連スナップショットの一覧がグリッド形式で漏れなく（5件制限なく）表示され、スクロール等で閲覧できること。グリッドの画像をクリックした際にメインプレビューがその画像に切り替わること。

### 2.2 カバー画像設定機能検証
- 編集モーダル内で、任意のサンプル画像を選択して「カバーに設定」ボタンを押下した際、プレビュー部分でマーク等によりカバー指定状態であることが視認できること。
- その状態でモーダルの「保存（Save Changes）」ボタンを押下した際、更新 API が正常に走り、モーダルが閉じること。
- 保存後、再度詳細・編集モーダルを開いたとき、設定したカバー画像がプレビューの初期画像として表示されること。
- LoRA管理およびタグセット管理の一覧（リスト）ビューに、設定されたカバー画像がサムネイルとして表示されること。
