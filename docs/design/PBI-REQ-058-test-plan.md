# PBI-REQ-058 実行可能テスト計画

## 1. 自動テスト (CLI Verification)
- **フロントエンド型チェック**: `npm run build` または `npx tsc` (フロントエンドディレクトリ内)
- **バックエンドテスト**: `pytest`

## 2. ツール主導監査 (Tool-Driven Audit)
- **コード監査**: `local_model_adapter.py arch-audit .` を実行し、設計整合性の客観的証明を得ること。

## 3. ブラウザ検証 (Browser Agent Verification)
- **対象URL**: `http://localhost:5173/` (または現在のフロントエンドのアドレス)
- **検証シナリオ 1: 新しいマッピングマスタ入力タイプの登録と編集**
  1. 設定画面 (`/settings`) にアクセスする。
  2. マッピングマスタ登録フォームを開く。
  3. `input_type` の選択肢に `select_sampler` と `select_scheduler` が存在することを確認する。
  4. 新しいマスタを登録してみる（例: `Test_Sampler`, `select_sampler`, `sampler_name`）。
- **検証シナリオ 2: サンプラ・スケジューラ選択肢の表示**
  1. 生成画面 (`/`) にアクセスし、サンプラ/スケジューラマッピングが存在するワークフローをロードする。
  2. 生成画面のパラメータ入力欄において、サンプラ選択ドロップダウンの選択肢に `euler`, `dpmpp_2m` などの適切なサンプラ名リストが表示されることを確認する。
  3. スケジューラ選択ドロップダウンの選択肢に `normal`, `karras` などの適切なスケジューラ名リストが表示されることを確認する。
- **検証シナリオ 3: 初期アップロード時のパラメータ値反映**
  1. ワークフローを初期ロード（アップロード）した際、JSONに含まれるサンプラ名/スケジューラ名の値が、生成画面のパラメータ欄のドロップダウンに初期値として正しく設定され、表示されることを確認する。
- **検証シナリオ 4: ComfyUIオフライン時のフォールバック**
  1. ComfyUIがオフラインの状態でも、標準サンプラ/スケジューラリストがフォールバックとしてドロップダウンに正しく表示され、エラー画面にならないことを確認する。
