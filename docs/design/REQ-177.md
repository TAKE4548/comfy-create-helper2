# REQ-177 詳細設計書: タッチ操作端末における D&D 並び替え TouchSensor activationConstraint 競合解消

## 1. 概要 (Overview)
タッチ操作環境（スマートフォン・タブレット等）における並び替えドラッグ操作において、@dnd-kit/core の TouchSensor に設定された ctivationConstraint: { distance: 5, tolerance: 5 } により、指を動かした瞬間に AbstractPointerSensor の許容誤差判定（	olerance）によって即時キャンセルされドラッグが開始できない不具合を解消する。

### 基本方針
1. **TouchSensor の制約修正**:
   - 	olerance を削除し、純粋な distance: 5 制約とする。
   - これにより、ドラッグハンドルを押下して5px以上スワイプした時点で確実にドラッグ（並び替え）セッションが開始される。
2. **影響対象の全コンポーネント一括適用**:
   - TagChipEditor (TagChipEditor/index.tsx)
   - PresetManagerPanel (PresetManagerPanel.tsx)
   - TagsPage (TagsPage.tsx)
   - LoRAsPage (LoRAsPage.tsx)
   - HistoryPage (HistoryPage.tsx)
   - SettingsPage (SettingsPage.tsx)
3. **PC操作・既存挙動の非干渉**:
   - PCマウス用の MouseSensor（distance: 8）およびキーボード用 KeyboardSensor は変更せず維持する。

## 3. 詳細設計 (Detailed Design)

### 3.1 センサー定義の統一パターン
`	sx
const sensors = useSensors(
  useSensor(MouseSensor, {
    activationConstraint: {
      distance: 8,
    },
  }),
  useSensor(TouchSensor, {
    activationConstraint: {
      distance: 5,
    },
  }),
  // KeyboardSensor (存在する場合)
);
`

## 4. トレードオフ・リスク開示 (Trade-off & Risk Disclosure)
- **スクロールとの微細な競合リスク**:
  - distance: 5 は非常に小さい移動量でドラッグが発動するため、ドラッグハンドル（<GripVertical>）に指が触れた状態での画面スクロール操作時にドラッグが優先される。
  - **緩和策**: 各画面（カード一覧・タグチップ）において、タッチ用ドラッグハンドル領域（	ouch-none）とコンテンツ領域（スクロール・タップ可能領域）がすでに明確に分離されているため、ハンドル外の通常のカード/チップタッチでは画面スクロール・タップが阻害されない。
