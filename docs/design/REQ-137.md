# REQ-137 詳細設計書: SpeechBubbleEditorModal モバイルモード対応UIおよびタッチ操作の実装

## 1. 概要 (Overview)
`SpeechBubbleEditorModal`（REQ-136にて導入されたセリフ編集・吹き出し追加機能）において、画面幅が狭いモバイル端末（ビューポート 768px 未満）利用時にキャンバス（プレビューエリア）とコントロールパネル（設定エリア）が固定横並び（`flex-row`）で配置されているため表示崩れや入力欄のはみ出しが発生していました。
本設計では、画面幅に応じたレスポンシブな配置切替（モバイルでの縦積み・モバイル専用タブ切り替えUI `[プレビュー ⇄ 設定]`）、キャンバス領域の動的フィッティング、およびモバイル実機でのタッチ操作（`Touch` イベント）対応を実現します。

## 3. 詳細設計 (Detailed Architecture)

### 3.1 レスポンシブモーダルレイアウト & モバイルタブUI
- **コンテナ設計**:
  - モーダル外枠: `relative w-full max-w-5xl max-h-[92vh] flex flex-col bg-[#18181C] ...`
  - メインコンテンツ: `flex flex-col md:flex-row flex-1 overflow-y-auto p-3 md:p-6 gap-4 md:gap-6`
- **モバイル専用タブ切替 (`mobileTab: 'preview' | 'controls'`)**:
  - `md:hidden`（画面幅768px未満）のヘッダー直下に `[ 🖼️ プレビュー ]` `[ ⚙️ 編集設定 ]` のタブ切替バーを配置。
  - モバイルモード時、`mobileTab === 'preview'` の場合はキャンバス領域を表示し、`mobileTab === 'controls'` の場合はコントロールパネルを表示（または縦積みスクロール表示と併用）。
  - デスクトップ表示（`md:`）ではタブバーを非表示とし、従来の `flex-[3]` (キャンバス) と `flex-[2]` (コントロール) の横並び二列表示を維持。

### 3.2 キャンバス描画領域の動的フィッティング
- モバイル端末の画面幅（例: 375px〜414px）に合わせ、`maxW` の計算をウィンドウ幅・コンテナ幅に応じて動的に縮小。
```typescript
const containerMaxW = Math.min(500, typeof window !== 'undefined' ? window.innerWidth - 48 : 500)
```
- キャンバスの `style={{ maxWidth: '100%', height: 'auto' }}` によるCSSアスペクト比維持表示。

### 3.3 モバイルタッチ操作対応 (`Touch Events`)
キャンバス上のドラッグ操作（吹き出し移動・サイズ変更・尻尾位置変更・ROI描画）において、タッチイベントを処理するラッパー関数を定義:
```typescript
const getTouchPos = (e: React.TouchEvent<HTMLCanvasElement>) => {
  const canvas = canvasRef.current
  if (!canvas || e.touches.length === 0) return null
  const rect = canvas.getBoundingClientRect()
  const touch = e.touches[0]
  return {
    x: touch.clientX - rect.left,
    y: touch.clientY - rect.top
  }
}

const handleTouchStart = (e: React.TouchEvent<HTMLCanvasElement>) => {
  const pos = getTouchPos(e)
  if (!pos) return
  // mouseDown と同等のロジックを実行
}

const handleTouchMove = (e: React.TouchEvent<HTMLCanvasElement>) => {
  const pos = getTouchPos(e)
  if (!pos) return
  // mouseMove と同等のロジックを実行
}

const handleTouchEnd = () => {
  // mouseUp と同等のロジックを実行
}
```

## 4. 受容条件 (Acceptance Criteria Verification)
- **AC-1**: モバイル表示（画面幅 768px 未満）でモーダルが開かれた際、表示崩れを起こさず、タブ切替またはスクロールでプレビューと設定パネルの両方が操作可能であること。
- **AC-2**: モバイル画面幅に応じてキャンバス領域が画面幅内に収まるよう自動フィッティングされること。
- **AC-3**: タッチ操作で吹き出しのドラッグ移動・尻尾位置調整・ROI範囲選択が動作すること。
- **AC-4**: 768px 以上のデスクトップ表示で従来の横並び表示・マウス操作に影響がないこと。
