# REQ-041: アルバム内表示・編集機能 テスト計画書

本テスト計画は、REQ-041 (アルバム内表示・編集機能) の各受け入れ基準 (AC) が正しく満たされているかを検証するためのものです。

---

## 1. 自動テスト計画 (バックエンド)

### 1-1. 一括削除 API の検証
`backend/tests` ディレクトリ内の既存テスト環境を利用し、以下のケースを検証するテストコードを実装します。

*   **テスト対象**: `POST /api/albums/{album_id}/items/delete`
*   **ケース1**: 存在するアルバムから、指定した複数の画像を削除できること。削除後に残ったアイテムの `sequence_order` が `0` から昇順に詰め直されていること。
*   **ケース2**: アルバムからすべての画像を削除できること。
*   **ケース3**: 存在しない `snapshot_id` を指定して削除リクエストを送った場合、無視されるかエラーを適切にハンドリングすること（残りの存在するものは削除される）。

### 1-2. 実行コマンド
*   バックエンドのユニットテスト実行コマンド:
    ```bash
    pytest backend/tests/test_albums.py
    ```

---

## 2. 手動検証計画 (フロントエンド)

ブラウザ上で以下のシナリオを実行し、挙動を確認します。

### シナリオ1: 詳細確認画面への遷移とクロップなし表示 (AC-1, AC-2)
1. 「History」画面を開き、「Albums」タブに切り替える。
2. 作成済みのアルバムカードをクリックする。
3. アルバム詳細画面へ遷移し、アルバム内の画像がすべてアスペクト比を維持したまま表示されることを確認する。
4. **【判定基準】**:
    *   ブラウザの開発者ツール (F12) で画像要素 (`<img>`) を確認し、CSS で `object-contain` などの比率維持プロパティが適用されていること。
    *   表示されている画像の `clientWidth` と `clientHeight` から算出される表示アスペクト比が、画像自体の元の解像度アスペクト比（または `naturalWidth` / `naturalHeight`）と一致しており、切り抜き（クロップ）が発生していないことを確認する。

### シナリオ2: 削除・一括削除機能 (AC-3, AC-4)
1. 任意の画像にマウスホバー（またはタップ）し、オーバーレイ表示される「削除アイコン」をクリックする。
2. 「選択削除モード」のトグルをONにする。
3. 複数の画像を選択し、「一括削除」ボタンをクリックする。
4. **【判定基準】**:
    *   UI 上から対象の画像カードが即座に消滅すること。
    *   ブラウザの Network タブで `/api/albums/{album_id}/items/delete` に対する POST リクエストを確認し、ステータスコード `200` の正常レスポンスが返っていることを確認する。
    *   レスポンスに含まれるアルバム情報内の `items` 配列の要素数が、削除された画像数だけ正しく減少していることを確認する。

### シナリオ3: ドラッグ＆ドロップによる順序変更と永続化 (AC-5, AC-6)
1. ソート順が「カスタム順」であることを確認する。
2. 任意の画像をドラッグし、別の位置へドロップして順番を入れ替える。
3. **【判定基準】**:
    *   ドロップ完了時に `/api/albums/{album_id}/order` に対する PUT リクエストが送信され、ステータス `200` の正常レスポンスが返っていることを確認する。
    *   ページをリロードした際、並べ替えた画像順序が維持されていること。
    *   画像要素に付与されたインデックス（またはデータ属性 `data-index` や `key` 等）を検証し、DOM 上の順序が永続化した順序と一致することを確認する。
    *   ソート条件を「登録順（古い順）」や「登録順（降順）」に切り替えた際、表示される順序が切り替わること。また、カスタム順以外のときはドラッグ＆ドロップ操作が無効（ドラッグできない状態）になっていることを確認する。

### シナリオ4: 拡大ビューワーと画像送り (AC-7, AC-8)
1. 画像一覧の画像をクリックして、全画面 Lightbox ビューワーを表示する。
2. ビューワー内の左右矢印ボタンをクリック、あるいはキーボードの左右矢印キー（`←`, `→`）を押下する。
3. タッチデバイスまたはシミュレータにおいて、左右スワイプ操作を行う。
4. **【判定基準】**:
    *   現在のインデックス `i` から、操作に応じて `(i + 1)` または `(i - 1)` の画像へ正確に切り替わること。
    *   最初または最後の画像に到達した際、ナビゲーションボタンが非表示または無効化され、それ以上の送り操作がブロックされること。
    *   ビューワーに渡されている画像リストの順序が、詳細画面で現在適用されているソート条件（カスタム順、登録順など）の並び順と完全に同期していることを確認する。
