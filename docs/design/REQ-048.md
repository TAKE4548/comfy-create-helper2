# REQ-048: LoRA・タグセット管理のカバー画像設定機能 設計書

## 1. 目的・背景
現在、LoRA管理およびタグセット管理では、関連スナップショット画像のうち最新5件のみがサムネイル候補として取得される制限がある。また、任意の画像を代表の「カバー画像」として選択・固定する機能がなく、さらに編集・詳細モーダルでの画像プレビュー機能やレイアウトが不十分である。
本設計では、全スナップショット画像の閲覧、任意の画像のカバー画像設定、および編集・詳細モーダルのレイアウト見直し（拡大とカルーセル・グリッドUIの導入）を実現する。

## 2. 影響範囲・変更内容

### 2.1 データベース (SQLite) マイグレーション
- `tag_sets` テーブルにカバー画像の保存用カラム `thumbnail_path` (TEXT / Nullable) を追加する。
- アプリ起動時の自動マイグレーション処理 (`backend/app/main.py` の `run_migrations()` 関数) に `tag_sets` テーブルの `thumbnail_path` カラム追加処理を追加する。

### 2.2 バックエンド (FastAPI)

#### `backend/app/main.py`
- `run_migrations()` に `tag_sets` テーブルへ `thumbnail_path` カラムがなければ追加する処理を記述。

#### `backend/app/models.py`
- `TagSet` モデルクラスに `thumbnail_path: Mapped[Optional[str]] = mapped_column(String)` を追加。

#### `backend/app/schemas/tagset.py`
- `TagSetCreate` に `thumbnail_path: Optional[str] = None` を追加。
- `TagSetRead` に `thumbnail_path: Optional[str] = None` を追加。

#### `backend/app/routers/tag_sets.py`
- `_tagset_to_schema` 内の関連スナップショット取得クエリから `.limit(5)` を削除し、関連するすべてのスナップショット画像パスを取得可能にする。
- `_tagset_to_schema` の戻り値 `schemas.TagSetRead` の引数に `thumbnail_path=ts.thumbnail_path` を追加。
- `create_tag_set` エンドポイントで `thumbnail_path=payload.thumbnail_path` を設定して作成。
- `update_tag_set` エンドポイントで `ts.thumbnail_path = payload.thumbnail_path` を設定して更新。

#### `backend/app/routers/loras.py`
- `_lora_to_schema` 内の関連スナップショット取得クエリから `.limit(5)` を削除。

### 2.3 フロントエンド (React / TypeScript)

#### `frontend/src/api/types.ts`
- `TagSet` インタフェースに `thumbnail_path: string | null` を追加。
- `TagSetCreate` インタフェースに `thumbnail_path?: string` を追加。

#### `frontend/src/components/LoraModals.tsx` & `frontend/src/components/TagSetModals.tsx`
- **詳細モーダル (`LoraDetailModal`, `TagSetDetailModal`)**:
  - モーダル自体の最大幅を `max-w-lg` から `max-w-4xl` 等に拡大し、左右2カラムレイアウト（左側：画像プレビュー＆スナップショットグリッド、右側：メタデータ情報）へ見直す。
  - 左カラムに現在のカバー画像（または選択中のサンプル画像）を大きく表示し、左右の矢印ボタンで関連スナップショットをスライド切り替え（カルーセル閲覧）できるUIを実装する。
  - その下に、関連するすべてのスナップショットをグリッド形式（縮小サムネイル）で並べ、クリックすることでメインプレビューを切り替えられるようにする。
- **編集モーダル (`LoraEditModal`, `TagSetEditModal`) / フォームフィールド**:
  - 詳細モーダルと同様にレイアウトを拡大し、画像プレビューおよびスナップショットグリッドを配置する。
  - スナップショットのグリッド内各画像ホバー時、あるいはメインプレビュー箇所に「カバー画像に設定」ボタンを配置する。
  - ボタン押下時にフォーム状態（`form.thumbnail_path`）を更新し、最終的な保存時にバックエンドへ送信する。

## 3. UI/UX デザイン案
- モーダルの全体幅を拡張。
- 左側に `384px` 以上の正方形プレビューエリアを確保。
- プレビュー下部に関連画像（スナップショット）のグリッド一覧（例: `w-16 h-16` の正方形）を表示。
- スナップショットが0件の場合は「サンプル画像がありません」とプレースホルダーを表示。
