# REQ-114: 既存タグセットの編集が保存（Save）できない不具合の修正

## 1. 背景と目的

タグセット管理画面（TagsPage）およびタグセット詳細モーダル（TagSetDetailModal）において、既存のタグセットの「Save Changes」を実行しても、モーダルが閉じず、一覧データも更新されない（実際にバックエンドのAPIで422バリデーションエラーが発生している）不具合を解消する。

## 2. 影響範囲

| ファイル | 変更種別 | 内容 |
|---|---|---|
| `frontend/src/pages/TagsPage.tsx` | MODIFY | `openEdit` での初期値設定の漏れ修正、`updateTagSet` の `onSuccess` でのモーダルクローズ、`onError` によるエラーハンドリングの実装 |
| `frontend/src/components/TagSetModals.tsx` | MODIFY | `TagSetDetailModal` の `handleStartEdit` における `subsets` の初期値バインド漏れ修正 |

バックエンド変更: **なし**（FastAPI の Pydantic スキーマ変更なし。フロントエンドの送信データ不整合を修正して対応する）

## 3. 実装詳細

### 3-1. `TagsPage.tsx` の修正

#### (1) `openEdit` 内での `target_base_model_ids` 初期値設定
編集モーダルを開く際、既存の `target_base_model_ids` が `editForm` のステートにコピーされていないため、送信時に `undefined` となりバックエンドの `TagSetCreate` スキーマで422バリデーションエラーが発生していた。

**修正案:**
```typescript
  const openEdit = (ts: any) => {
    setEditTagSet(ts)
    setEditForm({
      name: ts.name,
      description: ts.description ?? '',
      category_id: ts.category_id ?? undefined,
      tags: ts.tags.join(', '),
      thumbnail_path: ts.thumbnail_path ?? undefined,
      subsets: ts.subsets ? ts.subsets.map((s: any) => ({
        name: s.name,
        tags: s.tags.join(', ')
      })) : [],
      target_base_model_ids: ts.target_base_model_ids ?? [] // 👈 追加
    })
  }
```

#### (2) `updateTagSet` でのクローズ処理とエラーハンドリング
保存が成功した際に `editTagSet` と `selectedTagSetForDetail` を `null` に戻してモーダルを閉じるようにし、エラー発生時はエラーアラートを出すようにする。

**修正案:**
```typescript
  const updateTagSet = useMutation({
    mutationFn: ({ id, tagForm }: { id: number; tagForm: TagSetModalFormState }) =>
      tagSetsApi.update(id, {
        name: tagForm.name,
        description: tagForm.description || undefined,
        category_id: tagForm.category_id,
        tags: tagForm.tags.split(',').map((t) => t.trim()).filter(Boolean),
        thumbnail_path: tagForm.thumbnail_path || undefined,
        subsets: tagForm.subsets ? tagForm.subsets.map((s) => ({
          name: s.name,
          tags: s.tags.split(',').map((t) => t.trim()).filter(Boolean)
        })) : [],
        target_base_model_ids: tagForm.target_base_model_ids
      }),
    onSuccess: () => { 
      qc.invalidateQueries({ queryKey: ['tag-sets'] });
      setEditTagSet(null);                   // 👈 追加: 編集モーダルを閉じる
      setSelectedTagSetForDetail(null);      // 👈 追加: 詳細モーダルを閉じる
    },
    onError: (err: any) => {
      console.error(err);
      alert('タグセットの保存に失敗しました。'); // 👈 追加: エラーハンドリング
    }
  })
```

### 3-2. `TagSetModals.tsx` の修正

#### (1) `TagSetDetailModal` 内の `handleStartEdit` における `subsets` 初期値設定
詳細モーダルの編集開始時に `subsets` が `form` ステートにコピーされていないため、編集後に保存すると `subsets` が空配列として送信され、既存のサブセットデータが消えてしまうのを防ぐ。

**修正案:**
```typescript
  const handleStartEdit = () => {
    setForm({
      name: tagSet.name,
      description: tagSet.description ?? '',
      category_id: tagSet.category_id ?? undefined,
      tags: tagSet.tags.join(', '),
      thumbnail_path: tagSet.thumbnail_path ?? undefined,
      target_base_model_ids: tagSet.target_base_model_ids ?? [],
      subsets: tagSet.subsets ? tagSet.subsets.map((s) => ({ // 👈 追加
        name: s.name,
        tags: s.tags.join(', ')
      })) : []
    })
    setIsEditing(true)
  }
```
