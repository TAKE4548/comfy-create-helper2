# REQ-192: LLMプロバイダー選択時の翻訳疎通テスト・プロンプト翻訳エラー修正 詳細設計

## 1. 概要 (Overview)
翻訳設定において `provider="llm"` を選択した状態で疎通テスト（`POST /api/translate/test`）やプロンプト翻訳（`POST /api/translate/prompt`）を実行すると、`translation_service.py` 内の `translate_llm` が `call_llm` を不正な引数形式（単一引数および `db=db` キーワード引数）で呼び出しているため、`TypeError: call_llm() got an unexpected keyword argument 'db'` が発生する。
本設計では、`translate_llm` の実装を `call_llm` のインターフェースに合わせて改修し、LLM経由のプロンプト翻訳および接続テストが正常に動作するようにする。

---

## 2. アーキテクチャと影響範囲 (Architecture & Impact Analysis)

### 2.1 影響ファイル
1. `backend/app/services/translation_service.py`:
   - `translate_llm` 関数の呼び出しシグネチャを修正。
   - `system_prompt`（翻訳指示）と `user_prompt`（翻訳対象テキスト）を分離して渡す。
   - `db` が渡されている場合は `translation_model` および `llm_params_translation` の設定を取得して `model` / `llm_params` として `call_llm` に渡す。
2. `backend/tests/test_translation_proxy.py`:
   - `provider="llm"` 用の単体テスト（疎通テスト・翻訳テスト）を追加。

## 3. 実装詳細仕様 (Detailed Specifications)

### 3.1 `translate_llm` の改修
```python
async def translate_llm(
    text: str,
    source_lang: str = "en",
    target_lang: str = "ja",
    db: Optional[Session] = None,
) -> str:
    """Local LLM translation using existing call_llm service."""
    from app.services.llm_request import call_llm

    system_prompt = (
        f"You are a professional prompt translator for AI image generation. "
        f"Translate the following stable diffusion prompt from {source_lang} to {target_lang}. "
        f"Preserve all tokens like __TOKEN_0__, commas, and structure. Output ONLY the translated prompt without explanations."
    )
    model = None
    llm_params = None
    if db:
        try:
            from app import models
            model_record = db.query(models.LlmPrompt).filter(models.LlmPrompt.key == "translation_model").first()
            if model_record and model_record.content and model_record.content.strip():
                model = model_record.content
            params_record = db.query(models.LlmPrompt).filter(models.LlmPrompt.key == "llm_params_translation").first()
            if params_record and params_record.content:
                import json
                try:
                    llm_params = json.loads(params_record.content)
                except Exception:
                    pass
        except Exception as e:
            logger.warning(f"Failed to fetch translation LLM settings from DB: {e}")

    result = await call_llm(
        system_prompt=system_prompt,
        user_prompt=text,
        model=model,
        llm_params=llm_params,
        timeout=60.0,
    )
    return result.strip() if result else text
```
