# REQ-022 実行可能テスト計画

## 1. 前提条件 (Setup & Environment)
- バックエンド (`uvicorn app.main:app`) およびフロントエンド (`npm run dev`) が起動していること。
- テストデータとして、データベースに以下のレコードが存在すること：
  - 選択可能なワークフロー（ID: `1`）
  - 上記ワークフローに紐づく過去のスナップショットデータ（少なくとも1件以上。`params` に `Positive_Prompt`, `Sampler_Seed` などが設定されていること）
  - スナップショットが存在しない別のワークフロー（ID: `2`）

## 2. 自動テスト & ツール主導検証 (CLI & Tool-Driven Audit)
- 変更後のアーティファクト整合性と仕様検査を実行します。
```bash
python ${GLOBAL_SCRIPTS}\artifact_linter.py docs/design
```
- 期待値: 出力レポートの `<status>` タグが `PASS` であること。

## 3. API検証 (API Integration Verification)
- 期待するAPIエンドポイントが意図したJSONレスポンスを返却することを確認します。

### 3.1 `GET /api/snapshots` エンドポイント検証
1. 以下のHTTPリクエストを実行する（curlまたは同等のクライアント）:
   ```bash
   curl -s http://localhost:8000/api/snapshots?workflow_id=1
   ```
2. **Assertion 1**:
   - レスポンスのJSON配列内のオブジェクトが `params` キーを含んでおり、`params` が非空のオブジェクト（`dict`）であることを確認する。
   - `created_at` が ISO 8601 形式の文字列であること。

## 4. ブラウザ検証 (Browser Verification)
- **対象URL**: `http://localhost:5173`

### 4.1 履歴フィルタリングとドロップダウンUI表示のテスト (AC-1, AC-2, AC-5)
1. 生成ページ (`/`) にアクセスし、スナップショット履歴が「存在する」ワークフロー（ID: `1`）を選択する。
2. **Assertion 2 (AC-1, AC-2)**:
   - ワークフロー選択エリアの横にスナップショット選択ドロップダウン（`#snapshot-history-select`）が表示され、活性化（enabled）状態になっていることを確認する。
   - ドロップダウンを展開した際、時系列の新しい順に項目が並んでおり、各項目に「生成日時」と「ポジティブプロンプトの冒頭（最大25文字）」が表示されていることを確認する。
3. スナップショット履歴が「存在しない」ワークフロー（ID: `2`）を選択する。
4. **Assertion 3 (AC-5)**:
   - スナップショット選択ドロップダウンが非活性化（`disabled`）状態になっていること、またはオプションが「履歴なし」と表示されていることを確認する。

### 4.2 設定ロード機能および接続保持テスト (AC-3, AC-4)
1. ワークフロー（ID: `1`）を再度選択する。
2. 画面上のプロンプト入力欄に、手動でダミー文字列を入力する（例: `temporary prompt`）。
3. シード値入力モードを「ランダム（random）」に設定する。
4. スナップショット選択ドロップダウンから特定の過去スナップショット（例: `Positive_Prompt="a beautiful landscape", Sampler_Seed="12345"`）を選択する。
5. **Assertion 4 (AC-3)**:
   - プロンプト入力欄（`#prompt-Positive_Prompt`）の値が、自動的に `"a beautiful landscape"` に上書き（ロード）されていることを確認する。
   - シード値入力モードが自動的に「固定（fixed）」に切り替わり、シード入力値（`#seed-input`等）が `"12345"` に設定されていることを確認する。
6. **Assertion 5 (AC-4)**:
   - ロード処理の前後でワークフローのノード構造（接続やマッピング定義）は変化せず保持されていることを確認する（マッピングエラーなどが生じていないこと）。
7. スナップショット選択ドロップダウンの表示が初期状態（「過去スナップショットを選択...」などのプレースホルダー）にリセットされていることを確認する。
