# 補足仕様書: REQ-121 生成画面のプロファイルタブおよびアコーディオン展開状態の永続化・保持機能

- **作成日**: 2026-07-21
- **著者**: Architect
- **対象PBI**: [REQ-121](../backlog/pbi/active/REQ-121.md)

---

## 1. 概要 (Overview)

生成画面（`GeneratePage`）におけるプロファイルタブ（Multi-Set / プリセットタブ）の選択状態（`activeSetId`）、モバイルプロンプトタブ（`activePromptTab`）、および各プロンプトカードのアコーディオン展開状態（`collapsedRoles`）がページリロード時に保持されずデフォルト状態にリセットされる不具合を解消し、`localStorage` を用いた確実な永続化・復元処理を実装する。

   - `collapsedRoles` (アコーディオン開閉状態) の `localStorage` との同期処理。

## 3. 詳細仕様 (Detailed Design)

### 3.1 プロファイルタブ (`activeSetId`) の復元ロジック
- `useEffect`（`presets` / `selectedWorkflowId` 読み込み時）において：
  1. `localStorage.getItem(LS_KEYS.ACTIVE_SET_PREFIX + selectedWorkflowId)` より直前に選択されていた `activeSetId` を取得。
  2. 取得した `activeSetId` が有効な `preset` に存在するか判定 (`presets.some(p => String(p.id) === String(storedActiveId))`)。
  3. 存在する場合は、強制リセットを行わず `storedActiveId` をアクティブタグとして保持・復元する。

### 3.2 モバイルプロンプトタブ (`activePromptTab`) の永続化
- タブ切り替え関数 `handleSelectPromptTab(role)` または `setActivePromptTab(role)` 呼び出し時に `localStorage.setItem(LS_KEYS.ACTIVE_PROMPT_TAB_PREFIX + selectedWorkflowId, role)` を保存。
- ワークフローロード時：`localStorage` から保存された `activePromptTab` を取得し、テキストマッピングに存在するロールであれば復元。存在しない場合のみ `texts[0].role` をフォールバック選択する。

### 3.3 アコーディオン展開状態 (`collapsedRoles`)
- 各ロールごとの折りたたみ状態を `localStorage.getItem('prompt-surgeon-collapsed-' + role)` および `collapsedRoles` ステートで管理し、リロード後もアコーディオンの開閉状態を正確に復元する。

---

## 4. 影響範囲とリスク (Trade-off & Risk Disclosure)

- **リスク**: キャッシュされた `activeSetId` や `activePromptTab` が削除されたワークフローやロールを指している場合、UIエラーが発生するリスク。
- **対策**: 復元時に現在の `presets` または `workflow.mappings` に存在するか必ず検証し、存在しない場合のみ安全なデフォルト値（先頭要素）へフォールバックするガード処理を設ける。
