# REQ-219: 生成プロンプト各入力欄および個別タグのコピー＆ペースト・履歴・タグセット連携 詳細設計書

## 1. 概要 (Overview)
生成画面（`GeneratePage`）の各プロンプト入力セクションおよび個別タグ（`TagChip`）において、プロンプトの丸ごとコピー＆ペースト、複数件のコピー履歴保持、ペースト時の上書き／追加選択、およびセクション内容から直接タグセット（新規作成／既存上書き）へ保存する機能を実装する。

これにより、背景や衣装などのプロンプト設定を別のプリセットやタグセットへ素早く再利用・転用できるようにし、プロンプト編集の作業効率と柔軟性を大幅に向上させる。

## 3. 詳細設計 (Detailed Design)

### 3.1 クリップボード履歴ストア (`usePromptClipboardStore.ts`)
- **状態 (State)**:
  - `history: string[]`: 直近コピーされたプロンプト文字列の配列（最大10件）。
  - `pasteMode: 'append' | 'overwrite'`: ペースト時の動作設定（デフォルト: `'append'` または選択式）。
- **アクション (Actions)**:
  - `copyText(text: string): Promise<boolean>`:
    - `navigator.clipboard.writeText(text)` で OS クリップボードへ書き込み。
    - 空文字でない場合、`history` の先頭に追加（重複する同一文字列は先頭に移動し、最大件数10件に切り詰め）。
    - LocalStorage に永続化。
  - `setPasteMode(mode: 'append' | 'overwrite'): void`
  - `clearHistory(): void`

### 3.2 個別タグのコピー (`TagChip.tsx`)
- サブメニュー（ポップオーバー）上部のヘッダー領域（タグ名入力と有効/無効トグルの間、または下部）に `Copy` アイコンボタンを配置。
- ボタン押下時:
  - `copyText(text)` を実行。
  - アイコンが一時的に `Check` に変化し、"コピー完了" をフィードバック。

### 3.3 プロンプトセクション向けクリップボードメニュー (`PromptSectionClipboardMenu.tsx`)
- セクションヘッダーに2つのコントロールを配置:
  1. **コピーボタン**:
     - 現在のセクションのプロンプト（`paramValues[role]`）をコピー。
     - コピー成功時にチェックアイコンとトースト/ツールチップを表示。
  2. **ペースト / 履歴ボタンドロップダウン**:
     - クリックでポップオーバーメニューを開く。
     - **上書き / 追加モード切替**: スイッチまたはセグメントコントロール（「上書き」「末尾に追加」）。
     - **OSクリップボードからペースト**: クリップボードの最新テキストを現在のモードで反映。
     - **履歴リスト（最大10件）**:
       - 各履歴項目のプロンプトプレビュー（長文は省略表示）。
       - クリックで即座に対象セクションへペースト（選択中の上書き/追加モードに従う）。
     - **タグセットとして保存ボタン**:
       - クリックすると `SaveAsTagSetModal` を開く。

### 3.4 タグセット登録・上書きモーダル (`SaveAsTagSetModal.tsx`)
- 対象セクションの現在のプロンプト文字列をタグ配列に分割・正規化（カンマ区切り、トリム）。
- タブ切替:
  1. **「新規タグセットとして登録」タブ**:
     - タグセット名（必須）、カテゴリ（`tagsetCategories` から選択、任意）、説明（任意）。
     - サブセット名（任意、空の場合はベースタグとして登録）。
     - 登録実行で `tagSetsApi.create` を呼び出し、React Query のキャッシュ（`['tagSets']`）を無効化。
  2. **「既存タグセットを上書き」タブ**:
     - 既存タグセットの検索・一覧（`AddAssetModal` と同様のリストUI）。
     - タグセット選択時、サブセット（`subsets`）が存在する場合は「メインタグを上書き」または「特定サブセットを上書き」を選択可能。
     - 上書き確認ダイアログまたは明示的な上書き実行ボタンで `tagSetsApi.update` を呼び出し。

## 4. トレードオフおよびリスク開示 (Trade-off Disclosure)

- **OS クリップボード API の権限制限**:
  - ブラウザのセキュリティ仕様により、`navigator.clipboard.readText()` はフォーカス時かつユーザー操作時（クリック等）にのみ動作し、一部環境ではパーミッション要求が発生する場合がある。
  - **対策**: アプリ内 Zustand ストア（LocalStorage 永続化）による `history` を主軸とし、ブラウザの権限が拒否された場合でもアプリ内履歴からのペーストは常に確実に動作するハイブリッド設計とする。
- **タグセット上書き時の破壊的変更**:
  - 既存タグセットを上書きする場合、元のタグ情報が失われるリスクがある。
  - **対策**: モーダル上で上書き対象の既存タグと、上書き後に反映される新規タグの差分/プレビューを提示し、誤操作による上書きを防ぐ。
