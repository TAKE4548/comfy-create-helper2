# PBI-REQ-005 実行可能テスト計画

## 1. 静的検証・ビルドテスト (Lint & Build Verification)
- **コマンド (Frontend)**:
  ```bash
  cd frontend
  npm run lint
  npm run build
  ```
- **期待値**: エラーなくLintおよびビルドが完了すること。

## 2. ブラウザ検証 (Browser Manual Verification)
- **対象URL**: `http://localhost:5173/loras` (フロントエンドのLoRAsページ)
- **操作手順**:
  1. 開発サーバーを起動する (`cd frontend && npm run dev` および backend の起動)。
  2. `http://localhost:5173/loras` にアクセスする。
  3. LoRAカードのメインタイトルが `description`（未設定の場合はモデル名）に変わっていることを確認する。
  4. LoRAカードのメインエリアをクリックし、詳細確認モーダルが正しく開くことを確認する。
  5. モーダル内に、モデルのメタ情報（フルパス、説明など）と登録されているすべてのトリガセットが表示されることを確認する。
  6. トリガセットの横にあるコピーボタンをクリックし、クリップボードにコピーされること、およびアイコンがチェックマークに2秒間変化することを確認する。
  7. コピーした内容がエディタ等に正しくペーストできることを確認する。
  8. モーダルの「X」ボタンまたはモーダル外クリックでモーダルが正常に閉じることを確認する。
  9. LoRAカードの右上にある「編集（鉛筆）」ボタンおよび「削除（ゴミ箱）」ボタンをクリックした際、詳細モーダルが開かずにそれぞれの編集・削除ダイアログが正しく動作することを確認する（イベントバブリングの阻止）。
- **必須エビデンス**:
  - モーダルが開いた状態のスクリーンショット。
  - トリガセットコピー時のチェックマーク状態のスクリーンショット。
