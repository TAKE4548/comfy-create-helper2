# REQ-303 詳細設計書: Animaモードにおけるピリオド区切りタグチップ分割とプロンプト結合制御

## 1. 概要と背景
Prompt Surgeonのタグチップエディタ（`TagChipEditor`）において、自然言語指向の文・センテンスを入力する「Animaモード（`isAnimaMode: true`）」が導入されている。
しかし、現行のパーサー（`useChipParser.ts`）および新規入力欄（`TagInput.tsx`）はカンマ（`,`）のみを区切り境界としており、ピリオド（`.`）で終わる英文センテンスを入力・ペーストした際に文単位で分割されない問題があった。
さらに、タグチップ配列からComfyUI投入用プロンプト文字列へ復元するシリアライザー（`chipsToString`）が一律に `join(', ')` でカンマ結合するため、ピリオド付きの文の後にカンマが付与され（例: `1girl. , red dress.`）、自然言語プロンプトの文法構造が破壊される課題が存在していた。

本設計では、以下の改修を行う:
1. `isAnimaMode: true` 時に、カンマ（`,`）に加えてピリオド（`.`）をトークン境界として認識・分割する。
2. ピリオド区切りの場合、カンマのように記号を除去せず、直前のトークン末尾に `.` を保持した状態でチップ化する。
3. 括弧ネスト記法 `(tag:1.2)` や小数表記（`1.5`）内のピリオドは区切り文字として扱わず保護する。
4. `chipsToString` において、`isAnimaMode: true` 時は直前の有効チップ末尾が `.` の場合にカンマを付与せず半角スペース `" "` のみで後続チップと結合する。Anima モード自体はチップ末尾へピリオドを追加しない。
5. 通常モード（`isAnimaMode: false`）時は既存の動作（カンマ区切り・一律 `, ` 結合）を100%維持する。

## 3. アーキテクチャおよびコンポーネント詳細設計

### 3-1. トークナイザー・パーサー設計 (`useChipParser.ts`)

#### A. `splitTags(text: string, isAnimaMode: boolean = false): string[]`
文字列を走査し、タグ配列に分割する純粋関数。
- **括弧深度管理**:
  - `(`, `[`, `{` で `depth++`、`)`, `]`, `}` で `depth--`。
  - `depth > 0` の間は、`,` および `.` を区切りとして認識しない。
- **区切り文字判定 (depth === 0)**:
  - `,`: 常に区切り文字。現在のバッファをトリムし、内容が存在すれば登録。バッファからカンマは除外。
  - `.`:
    - `isAnimaMode === false` の場合: 単なる文字列としてバッファに追加。
    - `isAnimaMode === true` の場合:
      - 小数判定: 前の文字が数字かつ次の文字が数字（`/\d$/.test(current) && /\d/.test(text[i + 1])`）の場合は区切りとみなさずバッファに追加。
      - 文末判定: ピリオドをバッファ末尾に追加（`current += '.'`）した上でトリムし、有効な内容（`current.replace(/[.,\s]/g, '').length > 0`）があればトークンとして登録。
- **空トークン除外**:
  - 連続区切り（`..`, `, .`, `,,`）による空文字やピリオド/カンマ/空白のみのトークンは自動的に除外。

#### B. `parseToChips(text: string, isAnimaMode: boolean = false): TagChip[]`
- `splitTags(text, isAnimaMode)` で得た各文字列に対し、`generateChipId()` による一意なIDと `enabled: true` を付与して `TagChip` 配列を生成。

#### C. `chipsToString(chips: TagChip[], isAnimaMode: boolean = false): string`
- `chips.filter(c => c.enabled)` で有効チップを抽出。
- `!isAnimaMode` の場合:
  - 従来通り `enabled.map(c => c.text.trim()).filter(Boolean).join(', ')` を返却。
- `isAnimaMode` の場合:
  - 有効チップを順次結合:
    - 先頭チップ（`i === 0`）: そのまま追加。
    - 2つ目以降（`i > 0`）:
      - 直前の有効チップ末尾が `.` で終わる場合（`prev.endsWith('.')`）: 半角スペース `" "` + 現在チップ。
      - 直前の有効チップ末尾が `.` 以外の場合: カンマ空白 `", "` + 現在チップ。

### 3-2. UI入力インタラクション設計 (`TagInput.tsx`, `index.tsx`)

#### A. `TagInput.tsx`
- Props に `isAnimaMode?: boolean` を追加。
- `handleInputChange`:
  - `val.endsWith(',')`: カンマ直前のテキストをトリムして `onAddTags([textBeforeComma])` 呼び出し。
  - `isAnimaMode && val.endsWith('.')`:
    - 括弧ネスト外（`openCount <= closeCount`）かつトリム後のテキストに実質文字が存在する場合、ピリオド付きのまま `onAddTags([val.trim()])` を呼び出して入力を確定・クリア。
- `handlePaste`:
  - ペーストされた平文を `splitTags(text, isAnimaMode)` で分割し、一括で `onAddTags(tags)` を実行。

#### B. `TagChipEditor/index.tsx`
- `<TagInput ... isAnimaMode={isAnimaMode} />` にモードを伝播。
- テキストモード切替（`handleSwitchToTextMode`）およびチップモード復帰（`handleSwitchToChipMode`）において、`chipsToString(state, isAnimaMode)` および `parseToChips(textValue, isAnimaMode)` を使用。
- 外部プロパティ同期（`value` 更新検知）および内部変更通知（`onChipsChange`）の `chipsToString` 呼び出しに `isAnimaMode` を適用。

### 3-3. グローバルストア・シリアライズ連携設計 (`multiSetSlice.ts`)

- `useChipParser.ts` から `chipsToString` をインポートして再利用（重複コードの排除）。
- `MultiSetState` に `isAnimaMode: boolean`（初期値 `false`）と `setIsAnimaMode: (val: boolean) => void` を追加。
- `getEffectiveParamValues(paramValues, promptChips, isAnimaMode?: boolean)`:
  - `promptChips` から有効プロンプトを抽出する際、`chipsToString(chips, isAnimaMode)` を呼び出し、Animaモード時の空白結合をComfyUI投入用パラメータに正確に反映。

## 4. 非機能要件・安全性設計
- **線形時間トークナイズ (ReDoS防止)**:
  - 複雑な正規表現によるバックトラッキングを避け、文字列の1パス走査（O(N)）で括弧深度と区切り文字を判定。
- **後方互換性の担保**:
  - `isAnimaMode` のデフォルト値は `false` とし、既存の通常モード（SD1.5 / SDXL / Illustrious等）の動作・テスト・プロンプト結合結果に一切の副作用を与えない。
