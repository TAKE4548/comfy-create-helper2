# 設計書 - REQ-021: アセット追加時のプロンプト直接挿入およびLoRAトリガー選択モーダル機能

## 1. 目的と概要
現在のアセット追加機能は、プロンプト入力欄とは別に「適用中アセット」として管理し、生成時に裏でプロンプトテキストと結合する仕様になっています。このため、追加されたアセット（LoRAトリガーやタグ）が直接エディタ上で編集・確認できないという不便さがあります。
本設計では、アセット（タグセット・LoRA）を追加した際に、そのトリガーワードやLoRA埋め込み文字列（`<lora:filename:strength>`）をプロンプト入力欄（`TagChipInput` / `textarea`）へ直接カンマ区切りのチップ（テキスト）として挿入するよう変更します。
また、LoRA追加時に複数のトリガーセットから選択して適用できるモーダルを常に表示し、適用後も「読み込み中」であることを示すバッジを引き続き表示します。

## 2. アーキテクチャ設計

### 2.1 Zustandストアの更新 (`frontend/src/store/useGenerationStore.ts`)
アセットの追加、有効・無効切り替え、削除操作をプロンプト文字列 (`paramValues[role]`) と完全に同期させるため、Zustandストアのアクションを拡張します。

- **`addAppliedAsset`**
  - アセットを `appliedAssets` に登録すると同時に、アセットのタグ群（および LoRA 埋め込み文字列）を現在の `paramValues[role]` にカンマ区切りで追加します。
- **`removeAppliedAsset`**
  - アセットを `appliedAssets` から削除する際、そのアセットが有効（`enabled === true`）であれば、該当するタグおよび LoRA 埋め込み文字列を `paramValues[role]` から削除します。
- **`toggleAppliedAsset`**
  - アセットの有効/無効を切り替える際、`enabled` になる場合はプロンプトに追加し、`disabled` になる場合はプロンプトから削除します。

#### プロンプト文字列同期の補助関数
- **`addAssetToPrompt(prompt: string, tags: string[], loraPromptString?: string): string`**
  - プロンプトの末尾に、カンマ区切りでアセットのタグおよび LoRA 文字列を安全に追加します。
- **`removeAssetFromPrompt(prompt: string, tags: string[], loraPromptString?: string): string`**
  - プロンプトから、アセットのタグおよび LoRA 文字列（強度の変化にも対応できるよう部分一致含む）を削除し、余分なカンマやスペースを整形します。

### 2.2 フロントエンド画面の更新 (`frontend/src/pages/GeneratePage.tsx`)
- **生成実行時 (`handleGenerate`) の結合処理の廃止**
  - プロンプト入力欄 (`paramValues`) 自体がアセットを含んだ最終状態となるため、`handleGenerate` での裏での結合処理を廃止し、`paramValues[role]` をそのまま送信するようにします。
- **LoRAトリガーセット選択モーダルの追加**
  - 「+ Add Asset」から LoRA を選択した際、即座に適用するのではなく、トリガーセットと強度を選択するためのモーダルを表示します。
  - **モーダル仕様**:
    - 対象 LoRA の情報（モデル名、説明、推奨強度範囲）を表示。
    - 登録されている `trigger_word_sets` を選択肢として提示。各セットのトリガーワードをプレビュー表示する。
    - トリガーセットが登録されていない、もしくは空の場合でも、「トリガーワードなし（デフォルト）」を選択可能（AC-6）。
    - スライダー/数値入力フィールドで LoRA 強度 (`strength`) を調整可能（初期値は推奨強度の中間値またはデフォルト `1.0`）。
    - 「適用」ボタンクリックで、選択したトリガーワードと `<lora:filename:strength>` をプロンプト欄に挿入し、バッジを登録する。

## 3. UI/UX 仕様

### 3.1 LoRAトリガーセット選択モーダルデザイン
- `shadcn/ui` に倣った `bg-surface-2` (背景) と `border-[rgba(255,255,255,0.08)]` (境界) を基調とするプレミアムなダークモードダイアログ。
- 各トリガーセットをカード状のラジオボタンまたはクリック可能なリスト項目としてレイアウト。選択中の項目を `border-accent-green` で強調。
- 強度スライダー (`0.0` から `2.0`、ステップ `0.1`) を配置し、視覚的なフィードバックを伴って適用強度を変更可能にする。
