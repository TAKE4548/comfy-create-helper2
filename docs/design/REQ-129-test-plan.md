# REQ-129 テスト計画書 (Test Plan)

## 1. 概要
`MobileLayout.tsx` における `ParamSyncModal` 統合の動作を検証する。

## 2. 自動テスト
フロントエンドのビルドおよび型チェックを実施する。
```bash
npm --prefix frontend run build
```

## 3. 手動検証・動作確認手順
1. **モバイル表示でのモーダル起動確認**:
   - ブラウザの開発者ツールでモバイル画面幅（例: iPhone / 768px以下）に設定する。
   - `GeneratePage` を開く。
   - `ParamPanel` のパラメータ同期設定管理ボタンを押下する。
   - `ParamSyncModal` が画面中央に表示されることを確認する (AC-1)。

2. **モーダル操作確認**:
   - モーダル内で同期グループの追加、編集、削除、トグル切替を試みる。
   - グループの作成・更新が画面に即時反映されることを確認する (AC-2)。

3. **モーダル閉鎖確認**:
   - モーダル右上の閉じるボタン (✕) またはキャンセルボタンを押下する。
   - モーダルが正常に閉じられることを確認する (AC-3)。
