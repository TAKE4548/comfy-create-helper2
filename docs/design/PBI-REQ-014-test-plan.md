# PBI-REQ-014 実行可能テスト計画

## 1. 自動テスト (CLI Verification)
- **コマンド**: `python -m pytest backend/tests/`
- **期待値**: 全テストケースが正常にパスすること。
- **追加テスト**: `backend/tests/test_loras.py` において、`snapshot_paths` を含むレスポンスのアサーションを行うテストを追加。

## 2. ツール主導監査 (Tool-Driven Audit)
- **API検証**: エンドポイント `GET /api/loras` および `GET /api/tag-sets` のレスポンススキーマに `snapshot_paths` が追加されていることを確認する。
- **コード監査**: `python ${GLOBAL_SCRIPTS}\artifact_linter.py .` を実行し、アーティファクトの文法チェックをパスすること。

## 3. 手動・ブラウザ検証 (Manual & Browser Verification)
**注意**: 以下の手順は実際にブラウザ上で操作して実行してください。単なる論理的推測や画面の想像での判定は不可です。

- **対象環境**: `http://localhost:5173/` (フロントエンド)

### 検証手順 A: プレビュー表示ロジックの確認
1. **操作**: `thumbnail_path` が未設定でスナップショットも存在しないアセットカードをブラウザ上で**マウスホバー**する。
2. **判定基準**: 
   - カード内に「No Preview」または同等のプレースホルダー画像が表示されていることを確認する。

### 検証手順 B: 複数サムネカルーセルの動作確認
1. **操作**: アセットに 2 枚以上のスナップショットが there are 2 or more snapshots for the asset, verify hover control:
   - カードの右端にある**矢印アイコンをクリック**する。
   - カードの左端にある**矢印アイコンをクリック**する。
   - カード本体（画像領域）を**クリック**する。
2. **判定基準**: 
   - 矢印クリック時：画像が切り替わり、下部のドットインジケーターのアクティブな点が移動することを確認する。
   - カード本体クリック時：詳細モーダルが開くか、または別の遷移が発生し、カードクリックイベントが伝搬して意図しない動作（例：無限ループやエラー）を起こしていないことを確認する。
