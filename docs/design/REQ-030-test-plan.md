# テスト計画書 - REQ-030: スナップショット一覧のアルバム表示不具合の修正

## 1. テスト概要
本テスト計画では、`GET /api/albums` API が正しいスキーマ（`items` フィールド含む）で応答すること、およびフロントエンドの「Albums」タブで正常に保存されたアルバム一覧が表示されることを検証します。

## 2. 検証項目

### 2.1 バックエンド単体・統合テスト

#### 2.1.1 API レスポンススキーマ検証
FastAPI サーバーを起動し、cURL もしくはテスト用クライアントを用いて `GET /api/albums` にリクエストした際、レスポンス JSON 内の各オブジェクトに `items` 配列が含まれており、かつ `image_path` が正しく取得できていることを確認します。

- **実行コマンド例**:
  ```bash
  curl -s http://localhost:8000/api/albums
  ```

- **期待されるレスポンス形式**:
  ```json
  [
    {
      "id": 1,
      "name": "My Favorite Album",
      "created_at": "2026-06-12T12:00:00",
      "items": [
        {
          "snapshot_id": 12,
          "sequence_order": 0,
          "image_path": "db/snapshots/abc123_00001.png"
        }
      ]
    }
  ]
  ```

#### 2.1.2 pytest による検証
バックエンドの pytest が通ることを検証します。
- **実行コマンド**:
  ```bash
  cd backend
  pytest
  ```

### 2.2 フロントエンド・手動検証

1. **Albums 画面の表示確認**:
   * ブラウザで `http://localhost:5173/history` を開き、「Albums」タブを選択する。
   * 保存されているアルバムがある場合、カード状にレイアウトされて表示されること。
   * カード内に最大3枚の画像サムネイルが表示され、かつ画像枚数表示が正しいこと。
   * ブラウザの開発者コンソールに JavaScript のエラー（`TypeError` 等）が出力されていないこと。

2. **新規アルバム作成時の正常動作**:
   * 「Snapshots」タブで画像を選択して「New Album」からアルバムを作成し、保存する。
   * 再び「Albums」タブを選択し、新規作成したアルバムが正しく表示されること。
