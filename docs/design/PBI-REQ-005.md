# 設計書 - REQ-005: LoRAカード詳細モーダルの追加とメイン表示のDescription化

## 1. 目的と概要
現在、LoRAカードには限られた情報（登録された一部のトリガワードなど）しか表示されておらず、長文や多数のトリガセットを持つLoRAの全体情報を確認する手段がありません。
また、カードのメイン表示がモデルのパス名（物理ファイル名）になっており、ユーザーフレンドリーな名称である `description` が直接確認しづらい課題があります。

本設計では以下の機能を追加・改善します。
1. **カードのメイン表示改善**: カードの第一タイトルに `description` を表示し、未設定時のみ物理パス名をフォールバック表示します。サブテキストにはモデル名を表示します。
2. **詳細確認・コピーモーダル**: カード（編集・削除ボタンを除く）をクリックした際に、モデル名、カテゴリ、推奨強度、説明、登録ファイルパス、および全トリガセットを網羅した詳細モーダルを表示します。
3. **トリガセットのコピー機能**: モーダル内で、トリガセットごとにワンクリックでクリップボードへコピーできるボタンを提供します。コピー成功時にはチェックマークなどの視覚的フィードバックを提供します。

## 2. アーキテクチャ設計

### 2.1 バックエンド（FastAPI）
- 本要件は既存の `lorasApi.list()` から取得できるモデルデータ（`Lora` オブジェクト）のメタ情報およびリレーションを使用するため、**バックエンドAPIの変更はありません**。

### 2.2 フロントエンド（React + TypeScript）
- **UI コンポーネント (`frontend/src/pages/LoRAsPage.tsx`)**
  - **カード表示の更新**:
    - `lora.model_name` の代わりに `lora.description` をカードのプライマリタイトルとして表示します。
    - `lora.description` が存在しない場合は、`lora.model_name.split('/').pop()` をタイトルとして表示します。
    - サブタイトル部分には、`lora.model_name.split('/').pop()` またはモデル名/ファイル名を表示します。
  - **詳細モーダルの実装**:
    - 新しいState `selectedLoraForDetail: Lora | null` を追加します。
    - カードクリック時に `selectedLoraForDetail` に該当の `Lora` オブジェクトをセットします。
    - 編集ボタン `lora-edit-{id}` および削除ボタン `lora-delete-{id}` のクリックイベント（`onClick`）では、`e.stopPropagation()` を呼び出し、詳細モーダルが開くのを防ぎます。
  - **コピーフィードバック機能**:
    - コピー完了状態を追跡するState `copiedTriggerSetId: number | null` を追加します。
    - コピーボタンがクリックされた際、`navigator.clipboard.writeText(...)` を実行後、`copiedTriggerSetId` を対象の `tws.id` に設定し、2秒後に `null` に戻します。
    - コピーボタンのアイコンは、通常時は `Copy`、コピー完了時の2秒間は `Check` に動的に切り替えます。
