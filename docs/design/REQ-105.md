# Design Specification: REQ-105 Scene Generatorの追加調整

本ドキュメントは、Scene Generator機能の追加調整に関する設計仕様を定義する。

## 1. 目的・背景
前回のタスク（REQ-103）で追加した「Scene Generator」機能において、LLMの出力品質の調整やベースとなるプロファイルの柔軟な選択を可能にすることで、ユーザーのプロファイル作成効率と生成画像の品質を向上させる。

## 2. 要件仕様
1. **LLMモデルの動的取得と切り替え**
   - 設定画面でLM Studioの `/v1/models` エンドポイントを叩き、ロード中のモデル一覧を取得して表示する。
   - ユーザーは任意のモデルを選択し、その設定を永続化（次回ロード時にも保持）できる。
2. **ベースとなるプロファイルの選択機能**
   - モーダル起動時、現在のパラメータ値だけでなく、既存の保存済みプロファイル（プリセット）の一覧からベースプロファイルを選択できる。
3. **LLMシステムプロンプトの調整機能**
   - 設定画面で `scene_generate` キーに紐づくシステムプロンプトを直接編集できるようにする。
   - デフォルトプロンプトの記述をより詳細化し、ポーズや構図などのマッピングが適切に行われ、より多くの関連タグが追加されるよう改善する。

## 3. システムアーキテクチャ・API設計

### 3-1. バックエンド API の拡張

1. **利用可能モデルの取得**
   - **Endpoint**: `GET /api/llm-prompts/models`
   - **処理内容**: LM Studio API（`http://localhost:1234/v1/models`）にアクセスし、ロード済みモデルの `id` のリストを取得して返す。
   - **レスポンス**: `list[str]`

2. **現在選択されているモデルの取得**
   - **Endpoint**: `GET /api/llm-prompts/current-model`
   - **処理内容**: データベース内の `llm_prompts` テーブルから `key = "llm_model"` のレコードを検索する。存在しない場合は `settings.llm_model` をデフォルト値として格納・返却する。
   - **レスポンス**: `LlmPromptRead`

3. **選択モデルの更新**
   - **Endpoint**: `PUT /api/llm-prompts/current-model`
   - **処理内容**: データベース内の `llm_prompts` テーブルの `key = "llm_model"` の `content` フィールドを選択されたモデル名に更新する。
   - **リクエスト**: `LlmPromptUpdate`
   - **レスポンス**: `LlmPromptRead`

### 3-2. LLM呼び出しロジックの修正
- `app/services/llm_request.py` の `call_llm` 関数を、モデル名を引数として受け取れるように変更する。
- 各LLM呼び出し（`run_audit`, `run_scene_generate` 等）の際、DBから `llm_model` が取得できればそれをモデル名として適用する。

### 3-3. フロントエンドの拡張

1. **設定画面 (SettingsPage)**
   - 「LLM System Prompts」の編集対象表示ラベル（`PROMPT_LABELS`）に `scene_generate` キーを追加。
   - 設定画面のLLM関連セクションの直上に「LLM Model Settings」を追加。
     - 現在設定されているモデルの表示と、取得したリストからのモデル変更ドロップダウンを配置する。
     - ロード失敗時のエラーハンドリング（LM Studioが未起動の場合のフォールバック）を実装する。

2. **Scene Generatorモーダル (SceneGeneratorModal)**
   - モーダル内に「ベースプロファイル」の選択ドロップダウンを追加。
     - 選択肢: `現在の値` (デフォルト) / 登録済みプリセット一覧 (`presets`)。
     - 選択されたベースプロファイルに応じて、ローカルで保持する `baseParamValues` 状態を更新する。

## 5. デフォルトシステムプロンプトの調整案
`scene_generate` のシステムプロンプトの指示をより厳密に調整し、タグの不足やマッピングミスを防ぐ。

```
You are a scene description expert for AI image generation.
Given a scene summary in Japanese and a list of candidate fields with their current values,
analyze the scene and generate English prompt tags for the relevant fields.

Rules:
1. Output MUST be a valid JSON array — no markdown, no explanation outside JSON.
2. Only include fields you want to change; omit unchanged fields.
3. Each field value must be comma-separated English prompt tags. DO NOT output sentences.
4. Ensure tags are mapped to the correct field:
   - Pose/Action related tags (e.g., standing, sitting, running, dynamic pose) MUST go to the pose-related fields.
   - Composition/Angle tags (e.g., full body, upper body, close-up, high angle) MUST go to composition-related fields.
5. Generate rich and expressive tags to fully depict the input summary (generate at least 5-8 tags per active field where appropriate).
```
