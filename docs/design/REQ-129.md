# REQ-129 システム詳細設計書: モバイル環境におけるパラメータ同期設定モーダルの表示・連動不具合の修正

## 1. 概要
モバイル画面（`MobileLayout.tsx`）において、REQ-126で導入された `ParamSyncModal` のインポート、状態管理、`ParamPanel` への Props 伝達、およびモーダルの描画処理が欠落しているため、モーダルを開けない不具合を修正する。

## 2. 変更対象コンポーネントと設計詳細

### 2.1 変更ファイル: `frontend/src/pages/GeneratePage/components/MobileLayout.tsx`

1. **インポート追加**
   - `import { ParamSyncModal } from '../../../components/ParamSyncModal'` を追加する。

2. **Zustand Store・ローカル状態追加**
   - `useGenerationStore` から `paramSyncGroups` および `toggleParamSyncGroup` を取得する。
   - `useState` で `isParamSyncSettingsOpen` (boolean) を定義する。

3. **`ParamPanel` への Props 伝達**
   - `<ParamPanel />` に以下のプロパティを追加伝達する:
     - `paramSyncGroups={paramSyncGroups}`
     - `onToggleParamSync={(groupId, isEnabled) => toggleParamSyncGroup(groupId, isEnabled)}`
     - `onOpenParamSyncSettings={() => setIsParamSyncSettingsOpen(true)}`

4. **モーダル描画**
   - `MobileLayout` JSX の末尾付近（`BypassSettingsModal` 描画直後等）に以下を追加:
     ```tsx
     {isParamSyncSettingsOpen && (
       <ParamSyncModal
         onClose={() => setIsParamSyncSettingsOpen(false)}
       />
     )}
     ```

## 3. 影響範囲とリスク
- **影響範囲**: `frontend/src/pages/GeneratePage/components/MobileLayout.tsx` のみ。
- **リスク**: 極めて低リスク（既存のデスクトップ実装 `DesktopLayout.tsx` と同様のバインディングを適用するのみ）。
