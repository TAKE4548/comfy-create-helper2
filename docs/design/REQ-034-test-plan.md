# テスト計画書: REQ-034 スマホアクセス時の生成メインページ表示エラーの修正

## 1. 目的
REQ-034 の実装後、スマートフォンおよびPC上のモバイル表示エミュレーション環境で、生成メインページがクラッシュせず正常に表示され、画像生成等の主要機能が動作することを確認する。

---

## 2. 動作検証手順 (Manual Verification Plan)

### 2-1. PCブラウザによるモバイル表示エミュレーションテスト
1. ホストPCにてフロントエンド・バックエンドを起動する。
2. ブラウザで `http://localhost:5173/` にアクセスする。
3. 開発者ツール（F12）を開き、モバイル表示（デバイスエミュレーションモードで iPhone または Pixel 等の画面サイズ）に切り替える。
4. 画面をリロード（F5）する。
5. **期待される結果**:
   - 画面が真っ白にならず、モバイル用レイアウトの「Generate」ヘッダーやワークフロー選択、プレビューエリア、下部ナビゲーションが正常に表示されること。
   - コンソールに未キャッチの JavaScript 例外（Red Trace）が出力されていないこと。

### 2-2. 実機スマートフォンからの実接続テスト
1. ホストPCのIPアドレス（例: `http://192.168.X.X:5173`）にスマートフォンからアクセスする。
2. **期待される結果**:
   - 画面が正常に描画され、操作ができること。
   - 他のタブ（LoRA管理、Tags）と切り替えても、クラッシュせずに正常に画面が描画されること。

---

## 3. 自動テスト (Automated Test Plan)
- 今回は主に React レンダリングとブラウザ環境（特に WebSocket 例外などの外部要因）に依存するバグであるため、自動テストは既存の単体テスト（`npm run test`）が通ることをデグレーション防止の条件とします。
- 以下のコマンドでフロントエンドのテスト群が正常にパスすることを確認します。

```bash
cd frontend
npm run test
```
