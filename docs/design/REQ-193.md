# REQ-193: 翻訳設定（プロバイダー・APIキー・URL）の保存不具合修正 詳細設計

## 1. 概要 (Overview)
設定画面の「プロンプト翻訳設定（TranslationSettingsSection）」において、プロバイダーやAPIキー、API URLの変更を「設定を保存」ボタンで保存しようとしても、フロントエンドの API 呼び出し形式不整合（オブジェクト形式 `{ content: ... }` ではなく文字列を渡している）により 422 Unprocessable Entity が発生し、またバックエンドのキー未存在時 404 エラーおよび初期シードデータ未登録により保存が反映されない。
本設計では、フロントエンドとバックエンドの双方を修正し、翻訳設定の保存・読み込みが確実に機能するようにする。

---

## 2. 影響範囲 (Impact Analysis)

### 2.1 影響ファイル
1. `frontend/src/pages/SettingsPage/components/TranslationSettingsSection.tsx`:

2. `backend/app/routers/llm_prompts.py`:

5. `backend/tests/test_llm_models.py`:
   - `PUT /api/llm-prompts/{key}` のアップサート動作を検証する単体テストを追加。

## 3. 実装詳細仕様 (Detailed Specifications)

### 3.1 フロントエンド改修 (`TranslationSettingsSection.tsx`)
```typescript
  const saveSettingsMutation = useMutation({
    mutationFn: async () => {
      await Promise.all([
        llmPromptsApi.update('translation_provider', { content: provider }),
        llmPromptsApi.update('translation_api_key', { content: apiKey }),
        llmPromptsApi.update('translation_api_url', { content: apiUrl }),
      ])
    },
    onSuccess: () => {
      qc.invalidateQueries({ queryKey: ['llm-prompts'] })
      setSaved(true)
      setTimeout(() => setSaved(false), 2000)
    },
  })
```

### 3.2 バックエンド改修 (`llm_prompts.py`)
```python
@router.put("/{key}", response_model=schemas.LlmPromptRead)
def update_llm_prompt(key: str, payload: schemas.LlmPromptUpdate, db: Session = Depends(get_db)):
    prompt = db.query(models.LlmPrompt).filter(models.LlmPrompt.key == key).first()
    if not prompt:
        prompt = models.LlmPrompt(
            key=key,
            content=payload.content,
            description=payload.description or f"Setting for {key}",
            updated_at=datetime.utcnow()
        )
        db.add(prompt)
    else:
        prompt.content = payload.content
        if payload.description is not None:
            prompt.description = payload.description
        prompt.updated_at = datetime.utcnow()
    db.commit()
    db.refresh(prompt)
    return prompt
```
