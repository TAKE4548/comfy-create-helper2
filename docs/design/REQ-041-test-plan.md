# REQ-041: アルバム内表示・編集機能 テスト計画書

本テスト計画は、REQ-041 (アルバム内表示・編集機能) の各受け入れ基準 (AC) が正しく満たされているかを検証するためのものです。

---

## 1. 自動テスト計画 (バックエンド)

### 1-1. 一括削除 API の検証
`backend/tests` ディレクトリ内の既存テスト環境を利用し、以下のケースを検証するテストコードを実装します。

*   **テスト対象**: `POST /api/albums/{album_id}/items/delete`
*   **ケース1**: 存在するアルバムから、指定した複数の画像を削除できること。削除後に残ったアイテムの `sequence_order` が `0` から昇順に詰め直されていること。
*   **ケース2**: アルバムからすべての画像を削除できること。
*   **ケース3**: 存在しない `snapshot_id` を指定して削除リクエストを送った場合、無視されるかエラーを適切にハンドリングすること（残りの存在するものは削除される）。

### 1-2. 実行コマンド
*   バックエンドのユニットテスト実行コマンド:
    ```bash
    pytest backend/tests/test_albums.py
    ```

---

## 2. 手動検証計画 (フロントエンド)

ブラウザ上で以下のシナリオを実行し、挙動を確認します。

### シナリオ1: 詳細確認画面への遷移とクロップなし表示 (AC-1, AC-2)
1. 「History」画面を開き、「Albums」タブに切り替える。
2. 作成済みのアルバムカードをクリックする。
3. アルバム詳細画面へ遷移し、アルバム内の画像がすべてアスペクト比を維持したまま (クロップなし) で一覧表示されることを確認する。

### シナリオ2: 削除・一括削除機能 (AC-3, AC-4)
1. 任意の画像にマウスホバー（またはタップ）し、オーバーレイ表示される「削除アイコン」をクリックする。
2. その画像がアルバムから除外されることを確認する。
3. 「選択削除モード」のトグルをONにする。
4. 複数の画像を選択し、「一括削除」ボタンをクリックする。
5. 選択した画像がすべてアルバムから除外されることを確認する。

### シナリオ3: ドラッグ＆ドロップによる順序変更と永続化 (AC-5, AC-6)
1. ソート順が「カスタム順」であることを確認する。
2. 任意の画像をドラッグし、別の位置へドロップして順番を入れ替える。
3. ページをリロードし、変更した順番が維持されていること（永続化されていること）を確認する。
4. ソート順を「登録順（昇順）」や「登録順（降順）」に切り替えた際、それぞれの順序で正しく並べ替わることを確認する。また、カスタム順以外のときはドラッグ＆ドロップ操作が無効になっていることを確認する。

### シナリオ4: 拡大ビューワーと画像送り (AC-7, AC-8)
1. 画像一覧の画像をクリックして、全画面 Lightbox ビューワーを表示する。
2. ビューワー内の左右矢印ボタンをクリック、あるいはキーボードの左右矢印キー（`←`, `→`）を押下した際、現在選択されているソート順に従って前後の画像へ切り替わることを確認する。
3. モバイル表示またはタッチデバイスにおいて、左右スワイプで前後の画像へ切り替わることを確認する。
