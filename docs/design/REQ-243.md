# 設計書: REQ-243 Web Manager 自体の再起動バッチ (restart_web_manager.bat) の追加

## 1. 設計概要 (Architecture Overview)

本設計は、Prompt Surgeon のサービスマネージャーにおいて、Web Manager（`tools/server-manager/server_api.py` / ポート 8899）専用の再起動スクリプト `tools/server-manager/restart_web_manager.bat` を新設し、Web Manager 自体のコード更新時や不調時にワンクリックで安全・確実に再起動を行える運用環境を提供する。

### 解決する課題
1. **手動ポート解放・タスク強制終了の手間**: Web Manager 自体のアップデート時や動作不調時に、ポート 8899 の PID を手動で調べて `taskkill` する必要があった。
2. **Web UI 自身からの再起動の構造的限界**: Web Manager 自身が HTTP リクエストを受信している最中に自分自身を強制終了・再起動することはソケット切断やプロセス消滅を招くため、外部バッチスクリプトによるアウトオブバンド再起動が不可欠である。
3. **他サービスへの波及防止**: `taskkill /IM python.exe` 等の粗いプロセス終了を行うと、同一マシン上で稼働する Backend (FastAPI, 8000) や WSL ComfyUI (8188) まで誤って巻き添え終了させてしまうリスクがあった。本スクリプトはポート 8899 にバインドされた PID のみを厳密に特定して終了する。

## 2. アーキテクチャ構成と処理シーケンス (Architecture & Sequence)

```
[User Execution: restart_web_manager.bat]
   │
   ├─ [1. プロセス検知・停止フェーズ]
   │     ├─ Get-NetTCPConnection -LocalPort 8899
   │     ├─ ポート 8899 占有 PID を抽出
   │     └─ 稼働中の場合: taskkill.exe /PID <PID> /T /F で安全に強制終了
   │        (未稼働の場合はスキップして正常継続)
   │
   ├─ [2. ポート解放待機フェーズ]
   │     └─ ポート 8899 が非 LISTEN になるまでポーリング待機 (最大10秒, 500ms間隔)
   │
   ├─ [3. 新規プロセス起動フェーズ]
   │     ├─ run_web_manager.bat を経由して python server_api.py を起動
   │     │   (デフォルト: バックグラウンド常駐 / 引数 -Windowed 指定時は別窓表示)
   │     └─ logs/web_manager.log に標準出力・エラー出力をリダイレクト
   │
   ├─ [4. ヘルスチェック・起動完了待機フェーズ]
   │     └─ ポート 8899 が LISTEN 状態になるまで待機 (最大15秒, 500ms間隔)
   │
   └─ [5. ブラウザ自動起動・完了フェーズ]
         ├─ 正常起動確認後、ブラウザで http://localhost:8899 をオープン
         └─ 完了ステータスを表示 (エラー時は logs/web_manager.log の参照を案内)
```

## 3. モジュール別詳細設計 (Detailed Module Design)

### 3.1 `tools/server-manager/restart_web_manager.bat` (新規)

#### 構成仕様
- **ファイルパス**: `tools/server-manager/restart_web_manager.bat`
- **実行方式**: バッチファイルから PowerShell (`powershell.exe -ExecutionPolicy Bypass`) を呼び出し、安全かつ堅牢にプロセス制御・ポート監視を実行。
- **引数サポート**: 
  - 引数なし (デフォルト): バックグラウンド起動 (`-WindowStyle Hidden`)。
  - `-Windowed` / `--windowed`: デバッグ用に独立したコンソールウィンドウで起動。

#### 内部ロジック詳細
```bat
@echo off
title Prompt Surgeon - Restart Web Manager
cd /d "%~dp0"

powershell.exe -ExecutionPolicy Bypass -NoProfile -Command ^
  "$port = 8899;" ^
  "$windowed = $args -contains '-Windowed' -or $args -contains '--windowed';" ^
  "Write-Host '========================================================' -ForegroundColor Cyan;" ^
  "Write-Host '  Prompt Surgeon - Restart Web Manager (Port 8899)' -ForegroundColor Cyan;" ^
  "Write-Host '========================================================' -ForegroundColor Cyan;" ^
  "" ^
  "# 1. 既存プロセスの検知と停止" ^
  "Write-Host '[1/4] Checking for existing Web Manager process on port ' -NoNewline; Write-Host $port -ForegroundColor Yellow;" ^
  "$conns = Get-NetTCPConnection -LocalPort $port -ErrorAction SilentlyContinue | Where-Object State -eq 'Listen';" ^
  "if ($conns) {" ^
  "    $pids = @($conns | Select-Object -ExpandProperty OwningProcess -Unique);" ^
  "    foreach ($p in $pids) {" ^
  "        Write-Host \"      Stopping PID $p...\" -ForegroundColor Yellow;" ^
  "        & taskkill.exe /PID $p /T /F 2>$null;" ^
  "        Stop-Process -Id $p -Force -ErrorAction SilentlyContinue;" ^
  "    }" ^
  "} else {" ^
  "    Write-Host '      Web Manager is not currently running.' -ForegroundColor Gray;" ^
  "}" ^
  "" ^
  "# 2. ポート解放待機" ^
  "Write-Host '[2/4] Waiting for port ' -NoNewline; Write-Host $port -NoNewline -ForegroundColor Yellow; Write-Host ' to be released...';" ^
  "$sw = [System.Diagnostics.Stopwatch]::StartNew();" ^
  "$freed = $false;" ^
  "while ($sw.ElapsedMilliseconds -lt 10000) {" ^
  "    $check = Get-NetTCPConnection -LocalPort $port -ErrorAction SilentlyContinue | Where-Object State -eq 'Listen';" ^
  "    if (-not $check) { $freed = $true; break; }" ^
  "    Start-Sleep -Milliseconds 500;" ^
  "}; $sw.Stop();" ^
  "if (-not $freed) {" ^
  "    Write-Host '      [WARNING] Port did not close within 10s. Attempting start anyway...' -ForegroundColor Yellow;" ^
  "} else {" ^
  "    Write-Host '      Port is free.' -ForegroundColor Green;" ^
  "}" ^
  "" ^
  "# 3. 新規 Web Manager の起動" ^
  "Write-Host '[3/4] Starting new Web Manager process...';" ^
  "$logsDir = Join-Path $PSScriptRoot 'logs';" ^
  "if (-not (Test-Path $logsDir)) { New-Item -ItemType Directory -Path $logsDir | Out-Null };" ^
  "$webLog = Join-Path $logsDir 'web_manager.log';" ^
  "if ($windowed) {" ^
  "    Start-Process -FilePath 'cmd.exe' -ArgumentList '/k title Prompt Surgeon - Web Manager ^&^& run_web_manager.bat' -WorkingDirectory $PSScriptRoot;" ^
  "} else {" ^
  "    Start-Process -FilePath 'cmd.exe' -ArgumentList \"/c run_web_manager.bat > `\"$webLog`\" 2>&1\" -WorkingDirectory $PSScriptRoot -WindowStyle Hidden;" ^
  "}" ^
  "" ^
  "# 4. 起動確認とブラウザオープン" ^
  "Write-Host '[4/4] Verifying Web Manager startup on port ' -NoNewline; Write-Host $port -NoNewline -ForegroundColor Yellow; Write-Host '...';" ^
  "$sw = [System.Diagnostics.Stopwatch]::StartNew();" ^
  "$ready = $false;" ^
  "while ($sw.ElapsedMilliseconds -lt 15000) {" ^
  "    $conn = Get-NetTCPConnection -LocalPort $port -ErrorAction SilentlyContinue | Where-Object State -eq 'Listen';" ^
  "    if ($conn) { $ready = $true; break; }" ^
  "    Start-Sleep -Milliseconds 500;" ^
  "}; $sw.Stop();" ^
  "if ($ready) {" ^
  "    Write-Host '      Web Manager is successfully running!' -ForegroundColor Green;" ^
  "    Write-Host '      Opening http://localhost:8899 in default browser...' -ForegroundColor Cyan;" ^
  "    Start-Process 'http://localhost:8899';" ^
  "    Write-Host 'Restart completed successfully.' -ForegroundColor Green;" ^
  "    Start-Sleep -Seconds 2;" ^
  "} else {" ^
  "    Write-Host '      [ERROR] Web Manager failed to bind to port ' -NoNewline -ForegroundColor Red; Write-Host $port -ForegroundColor Yellow;" ^
  "    Write-Host \"      Check error log: $webLog\" -ForegroundColor Yellow;" ^
  "    pause;" ^
  "}" -- %*
```

## 4. 受入基準 (AC) とのトレーサビリティ

| AC | 要件内容 | 設計上の対応箇所 |
|---|---|---|
| **AC-1** | ポート 8899 占有プロセスの自動検知と安全な停止 | `Get-NetTCPConnection -LocalPort 8899` で PID を取得し、`taskkill /PID <PID> /T /F` でツリーごと安全に終了 |
| **AC-2** | 停止後のポート 8899 解放確認待機 | 最大10秒間のポーリングループ (`Where-Object State -eq 'Listen'`) で解放を確実に検知 |
| **AC-3** | 未稼働状態からの実行時も正常起動 | `$conns` が空の場合は停止処理をスキップして起動処理へ直行し、エラー終了しない |
| **AC-4** | 再起動完了後のブラウザ自動オープン | ポート 8899 の LISTEN 状態復旧を確認後に `Start-Process http://localhost:8899` を実行 |
| **AC-5** | 他サービス（Backend, ComfyUI, Frontend）への非干渉 | ポート 8899 の PID のみを選択終了。`taskkill /IM python.exe` などの総称終了は一切行わない |

## 5. リスク評価とトレードオフ (Trade-off & Risk Assessment)

1. **二重起動や連打時の挙動**:
   - リスク: ユーザーが `restart_web_manager.bat` を素早く連打した場合に競合が発生する可能性。
   - 対策: スクリプト起動直後にポート 8899 をチェックし、解放待機タイムアウトを設けているため、後発プロセスが安全に既存プロセスを回収して再起動する。
2. **バックグラウンド vs ウィンドウ表示**:
   - トレードオフ: バックグラウンド実行時はコンソール画面がすっきりする反面、リアルタイムの標準出力が見えなくなる。
   - 対策: 出力を `logs/web_manager.log` に自動記録するとともに、引数 `-Windowed` を指定すれば独立コンソールウィンドウで起動可能なハイブリッド設計とする。
