## 1. アーキテクチャ・変更概要

1. **マイグレーション `step_035_variant_id_references` の未解決キー救済（AC-1）**
   - `mapping_variants` テーブルまたは `role` 列が存在しない場合は引き続き `MissingMappingVariantsError`（`ValueError` サブクラス）を送出して中断・ロールバックする。
   - `workflow_presets` および `param_sync_groups` に未解決 `role` キー（ゴーストキー）が存在する場合、`audit_role_references()` による `ValueError` 全件中断を行わず、以下の救済ルールで移行を完了させる:
     - `workflow_presets`: `normalize_params(index, data)` で解決可能なエントリを `workflow_preset_values` へ移行し、`norm.unresolved` に含まれる未解決キーは `logger.warning` に `preset id` と未解決キー一覧を記録した上で除外し、`workflow_presets.param_values` には `norm.reserved`（`__` 予約キー）のみを残す（`POST`/`PUT` プリセット API と同一契約。再実行時の冪等性を保証）。不正 JSON 文字列も `logger.warning` を出力してスキップする。
     - `param_sync_groups`: `master_variant_id` 列を追加した上で、`master_role` が解決可能なら `master_variant_id` を設定し、未解決なら `logger.warning`（`sync_group id` と `master_role`）を記録して `master_variant_id = NULL` のまま保持する。`slave_roles` の各要素も解決可能なもののみ `param_sync_group_members` へ登録し、未解決要素は `logger.warning` を記録してスキップする。
2. **ワークフロー複製 (`copy_workflow`) の安全動作（AC-2）**
   - `backend/app/routers/workflows.py` の `copy_workflow` は `ParamSyncGroup` の `master_variant_id` が `None` の場合もそのまま複製可能であることを結合テストで保証する（`ParamSyncGroup.master_variant_id` は `nullable=True`）。
3. **起動時マイグレーション失敗時のフェイルファスト（AC-3）**
   - `backend/app/main.py` の `lifespan` で `run_migrations()` が例外を送出した場合、`logger.error` で記録した上で例外を再送出（`raise`）し、DB スキーマ不整合のまま API サーバを起動継続しない。

## 2. Seam Map [W-DD-SEAM]

1. **Integrated (実コード)**: FastAPI ルータ (`workflows.py`) → SQLAlchemy ORM (`models.py`) → SQLite (in-memory)。マイグレーションは `step_035_variant_id_references` / `run_migrations` を実 `steps.py` で実行。
2. **Severed (外部 I/O のみ)**: 外部 HTTP (ComfyUI/LM Studio) は `conftest.py` の `respx` で遮断。`lifespan` テストでは `run_migrations` 呼び出し後の外部サービス起動前段を検証（または `run_migrations` 注入/モックは異常系テストのみ限定使用）。
3. **Mock Level**: `VariantIndex`, `normalize_params`, `step_035_variant_id_references`, `copy_workflow` の内部ビジネスロジックに対するモンキーパッチ禁止。
4. **PBT 判定**: 不要（パーサ・DSL・数値計算の新規追加はなく、既存の `VariantIndex` / `normalize_params` を利用するため）。
5. **Fault Injection**:
   - ① `mapping_variants` 欠如時の `step_035` 中断・ロールバック維持 (AC-1)
   - ② ゴーストキー混入時の警告ログ出力＋解決可能分移行・冪等性 (AC-1)
   - ③ `master_variant_id=None` を含む同期グループを持つワークフローの複製成功 (AC-2)
   - ④ `run_migrations()` 例外発生時の `lifespan` 起動停止 (AC-3)
