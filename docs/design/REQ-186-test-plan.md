# REQ-186 実行可能テスト計画

## 1. 自動テスト (CLI Verification)
- **コマンド**: `npm test -- src/pages/__tests__/GeneratePage.test.tsx` (frontend ディレクトリ内)
- **期待値**: 全テストケース PASS。

### テストシナリオ
1. **プリセット選択時のモーダル継続表示**:
   - プリセット管理モーダルを開いた状態で、プリセット行をクリックして `onOpenAsTab` を発火。
   - プリセットがロード/適用された後もモーダル（`プリセット管理` 見出し等）が DOM 上に存在し続けていることを検証。
2. **モーダル内からのタブ閉じる操作**:
   - タブ表示中のプリセット行にある「タブを閉じる」ボタン（`#preset-close-tab-btn-xxx`）をクリック。
   - `removeSet` が該当 ID で呼び出され、モーダルが開いたまま維持されることを検証。
3. **モーダルクローズボタンによる終了**:
   - モーダル右上のクローズボタンをクリックすると、モーダルが閉じられることを検証。

## 2. ツール主導監査 (Tool-Driven Audit)
- **コード監査**: `local_model_adapter.py` によるアーキテクチャ・品質監査。

## 3. ブラウザ検証 (Browser / Manual Verification)
- **対象URL**: `http://localhost:5173/`（生成画面）
- **操作手順**:
  1. 生成画面で「管理」ボタンをクリックしてプリセット管理モーダルを開く。
  2. 任意のプリセットをクリックする → プリセットが適用され、タブが開くが、モーダルは開いたまま維持されること。
  3. タブ表示中のプリセット行の「タブを閉じる」ボタンをクリックする → タブバーから該当プリセットタブが閉じること。
  4. 複数のプリセットを続けてクリック/閉じる操作を行い、連続してタブの開閉ができること。
  5. モーダルの「✕」ボタンを押下してモーダルが正常に閉じること。
- **判定基準**: モーダルが不要なタイミングで勝手に閉じず、複数タブの整理・選択が連続して行えること。
