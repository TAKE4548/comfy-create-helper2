# REQ-202: 生成プリセット一括編集における共通タグの編集・強度調整機能 詳細設計書

## 1. 概要 (Overview)

本設計は、生成プリセットの一括編集モーダル（`ProfileBulkEditModal`）において、抽出された共通タグを削除（除外）するだけでなく、通常の `TagChip` と同様にサブメニューを展開し、**タグ名の変更**、**強度の直接入力およびステップ増減（±0.1, ±0.3 / AnimaMode時 ±0.5, ±1.0）**、**有効/無効の切り替え**、**削除** を行い、選択中の全プリセットに対して一括適用できるようにすることを目的とする。

## 3. 詳細仕様 (Detailed Specifications)

### 3.1 共通タグの抽出と状態管理 (`ProfileBulkEditModal.tsx`)

1. **共通タグ抽出 (`computeCommonTags`)**:
   - 選択された複数プリセットの対象プロンプトフィールドからタグを抽出し、ベース名（`parseTagWeight` による重み除去後の文字列）基準で全プリセットに共通して含まれるタグを抽出。
2. **共通タグ状態 (`commonTagItems`)**:
   - 各共通タグを `{ id, originalBase, text, enabled }` として保持。
   - `text`: 現在の表示用文字列（例: `1girl` または `(1girl:1.2)`）。
   - `originalBase`: 元のベース名（プリセット内の該当タグを特定するためのキー）。
   - `enabled`: 有効状態（`false` の場合はプリセットから除外）。
3. **UI レンダリング**:
   - 単なるボタンスタイルではなく、既存の `TagChip` コンポーネントを再利用。
   - `TagChip` のサブメニューから、タグ名変更、強度数値入力、ステップ増減ボタン（`±0.1`, `±0.3` 等）、有効/無効トグル、削除ボタンがシームレスに利用可能。
   - `isAnimaMode` に対応し、AnimaMode時は `±0.5`, `±1.0` のステップボタンを表示。

### 3.2 ペイロードと適用ロジック (`ProfileBulkEditModal.tsx`, `useGeneratePageState.ts`)

1. **ペイロード定義**:
   ```typescript
   export interface CommonTagOp {
     originalBase: string; // 元のタグベース名 (小文字正規化比較用)
     newFormattedTag: string; // 変更後のタグ文字列 (例: "(1girl:1.2)", "1boy")
     action: 'update' | 'remove'; // 'update' (変更反映) または 'remove' (除外/削除)
   }
   ```
   `BulkPromptOp` または `BulkEditPayload` に `commonTagOps?: CommonTagOp[]` を含める。

2. **プリセット更新ロジック (`handleBulkEditApply`)**:
   - 各プリセットの対象フィールドに対して、タグ配列（カンマ区切り）を走査。
   - 各タグのベース名（`parseTagWeight(tag).baseText.toLowerCase()`）が `commonTagOps` の `originalBase.toLowerCase()` と一致する場合：
     - `action === 'remove'`: タグをリストから除外。
     - `action === 'update'`: `newFormattedTag` に置換。
   - 一致しないプリセット固有タグは元の順序と内容をそのまま保持。
   - 更新されたタグ配列をカンマ連結して `newParamValues` を更新。

## 4. テスト・検証設計 (Verification Plan)

### 4.1 自動テスト (Automated Tests)
1. **`ProfileBulkEditModal.test.tsx`**:
   - 共通タグが `TagChip` として描画されること。
   - サブメニューを開いて強度を変更した際、`onApply` に正しい `commonTagOps` が渡されること。
   - サブメニューでタグ名を変更した際、`onApply` に更新された `newFormattedTag` が渡されること。
   - 有効/無効トグルや削除ボタンで `action: 'remove'` が正しく生成されること。
2. **`useGeneratePageState.test.tsx`**:
   - `handleBulkEditApply` において、`commonTagOps` が選択中の全プリセットに正しく一括適用されること（強度変更、名称変更、削除）。
   - プリセットごとの固有タグが保持されること。

### 4.2 手動検証 (Manual Verification)
- 複数プリセットを選択して一括編集モーダルを開き、共通タグの強度調整・タグ名変更・削除を実行し、各プリセットのプロンプトに意図通り反映されることを確認。
