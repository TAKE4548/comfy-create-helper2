---

### 検証項目詳細

#### AC-1 & AC-2: トリガーワードセットの追加表示と動的追加
**操作手順**:
1. 「Register Model」ボタンをクリック。
2. モーダルが開いたら、画面中央に「Trigger Word Sets」という見出しが存在するか確認する。
3. その直下に「+ Add Set」ボタンが存在するか確認する。
4. 「+ Add Set」ボタンを 1 回クリックする。

**判定基準（Pass/Fail）**:
- [ ] **AC-1**: モーダル開示時、必ず「Trigger Word Sets」という見出しが表示されているか。
- [ ] **AC-2**: 「+ Add Set」ボタンを 1 回クリックすると、フォーム内に以下の要素が追加されるか：
    - `Set Name` 入力フィールド（初期値なし）
    - `Trigger Words` 入力フィールド（TagChipEditor 適用）
    - 右端に「削除（ゴミ箱）」アイコンまたはボタン
- [ ] **AC-2 (続)**: ボタンを 3 回クリックした場合、フォーム内に上記のセットが正確に 3 つ追加されているか。

#### AC-3: TagChipEditor の適用確認
**操作手順**:
1. 追加された「Trigger Words」フィールドに `masterpiece` と入力し、Enter キーを押す。
2. 次に `bad_hands` と入力し、カンマ `,` を押す。

**判定基準（Pass/Fail）**:
- [ ] **AC-3 (チップ化)**: 入力されたテキストが、背景色付きの「タグ（Chip）」としてリスト表示されるか。
- [ ] **AC-3 (並べ替え)**: 生成されたタグをマウスでドラッグして順序を入れ替えた際、再配置された順に反映されるか。
- [ ] **AC-3 (モード切り替え)**: タグをクリックして「テキストモード」に切り替えると、入力欄が単なるテキストエリアに戻り、タグが表示されなくなるか。

#### AC-4: トリガーワードセットの動的削除
**操作手順**:
1. 上記で追加したセットを 3 つ作成する（合計 3 セット）。
2. 最初のセットの「削除」ボタンをクリックする。

**判定基準（Pass/Fail）**:
- [ ] **AC-4 (即時削除)**: ボタンクリック直後、フォーム上からそのセットが物理的に消失しているか。
- [ ] **AC-4 (整合性)**: 削除操作後、他のセットのデータ（名前やタグ内容）に変更がないか。

#### AC-5: 保存とデータベース同期の確認（重要：DB 検証含む）
**操作手順**:
1. 「Register Model」ボタンをクリックし、以下の設定で新規登録する：
   - **Model Name**: `test_lora_crud_001`
   - **File Path**: `models/test/test_lora_crud_001.safetensors`
   - **Trigger Word Sets**:
     1. Set Name: `Default`, Trigger Words: `solo, looking at viewer`
     2. Set Name: `Outfit B`, Trigger Words: `dress, hat`
2. 「Save」または「Register LoRA」ボタンをクリックし、モーダルが閉じ、リストページに戻る。

**判定基準（Pass/Fail）**:
- [ ] **AC-5 (保存)**: リストページに `test_lora_crud_001` という名前の LoRA が追加表示されているか。

3. 登録した LoRA をクリックし、詳細モーダルを開く。

**判定基準（Pass/Fail）**:
- [ ] **AC-5 (読み込み)**: モーダル内の「Trigger Word Sets」セクションに、登録時の 2 つのセットが正確な内容で表示されているか。

4. 詳細モーダルを閉じ、`test_lora_crud_001` の「Edit」ボタンをクリックし、以下の変更を行う：
   - Set `Default` の Trigger Words に `smile` を追加する。
   - Set `Outfit B` を削除する。
   - 新規セットを追加: Name=`Outfit C`, Words=`swimsuit`。
5. 「Save Changes」ボタンをクリックし、モーダルを閉じる。

**判定基準（Pass/Fail）**:
- [ ] **AC-5 (更新・同期)**: 再度詳細モーダルを開き、以下の状態になっているか：
    - Set `Default`: 元の内容に `smile` が追加されているか（`solo, looking at viewer, smile`）。
    - Set `Outfit B`: 存在しないか。
    - Set `Outfit C`: 新規追加された内容が表示されているか（`swimsuit`）。
- [ ] **AC-5 (DB 整合性)**: ブラウザをリロード（キャッシュクリア）後、同じ LoRA の詳細を確認し、変更内容が正しく保持されているか。
