# REQ-078: 全画面プレビュー機能の実装 設計書

## 目的
モバイルおよびタブレット端末において、画像のプレビューサイズを最大限に大きく表示させ、詳細確認を容易にするため、標準の Fullscreen API を統合した完全全画面表示プレビュー機能を実装する。

## 画面遷移およびインタラクション
1. **通常モーダル表示 (通常プレビュー)**
   - サムネイルタップ時に [HistoryModalPreview](file:///frontend/src/components/HistoryModalPreview.tsx) が開き、背景が `bg-black/95` のオーバーレイで画像が表示される。
2. **完全全画面への遷移**
   - モーダル内の画像領域をタップまたはクリックすると、モーダルのルート要素に対して `requestFullscreen()` (または Safari用の `webkitRequestFullscreen()`) が実行され、完全全画面表示に移行する。
3. **全画面表示中の操作**
   - スワイプによる画像切り替え (左右フリック)、キーボードの `ArrowLeft` / `ArrowRight` による画像切り替え、および左右の矢印ボタンによる画像切り替えは、全画面表示中もそのまま動作する。
4. **全画面の解除とモーダルのクローズ (Bパターン)**
   - 全画面表示中に以下のいずれかの操作が行われた場合、全画面を終了し、さらにプレビューモーダルも同時に閉じて呼び出し元の画面 (一覧画面/生成画面) に戻る。
     - モーダル右上の「✕」ボタン (閉じるボタン) をクリック
     - `Esc` キーを押す
     - モバイル等のシステム標準ジェスチャーや全画面解除操作を行う
     - 画像を再度タップ/クリックする (トグル動作)

## コンポーネント設計 (HistoryModalPreview.tsx)

### 状態 (State)
- `isFullscreen` (boolean): 現在ブラウザが全画面モードであるか。`fullscreenchange` イベント経由で同期する。

### 参照 (Ref)
- `containerRef` (React.RefObject<HTMLDivElement>): モーダルのルートコンテナ要素を全画面化するための `ref`。

### 副作用 (Effect)
- **全画面イベント監視**: `document` に対する `fullscreenchange` および `webkitfullscreenchange` イベントを監視し、全画面状態が解除された (`document.fullscreenElement` または `document.webkitFullscreenElement` が `null` になった) ことを検知した場合、かつモーダルが開いている状態であれば、`onClose()` を呼び出してモーダルを閉じる。

### イベントハンドラー
- `handleToggleFullscreen`:
  - `document.fullscreenElement` または `document.webkitFullscreenElement` が存在しない場合、`containerRef.current.requestFullscreen()` (または `webkitRequestFullscreen()`) を呼び出す。
  - すでに全画面の場合は `document.exitFullscreen()` を呼び出して全画面を解除する。これにより、上記のイベント監視副作用がトリガーされ、自動的にモーダルも閉じられる。

### UI / スタイル変更
- 全画面表示時には、ヘッダーや操作用の矢印ボタンなどをアスペクト比に合わせて適切に配置し、画像が `object-fit: contain` で画面いっぱいに表示されるようにCSSを調整する。
- Tailwind の `:fullscreen` 疑似クラス、もしくは `isFullscreen` の状態フラグを用いたクラスの切り替えを行う。

## 影響を受ける SSoT ファイル
- 本変更はUIの表現方法およびブラウザ API の利用に留まり、API スキーマや永続化データモデル (SSoT) への影響はない。
