# 詳細設計書: REQ-034 スマホアクセス時の生成メインページ表示エラーの修正

## 1. 背景・目的
スマートフォン等の外部デバイスから IP アドレス経由で本アプリケーションのフロントエンド（例: `http://192.168.X.X:5173`）にアクセスした際、メインの「生成（Generate）ページ」を開くと画面全体が完全に真っ白（空）になり、ヘッダーやナビゲーションバーすら表示されない。
ただし、「LoRA管理」や「Tags」などの他のサブページ（他ルート）はスマートフォンからでも問題なく正常に表示・操作できる。
この画面クラッシュバグを解消し、スマホからでも正常にメインページで画像生成操作が行えるようにする。

## 2. 影響範囲・調査箇所
- `frontend/src/pages/GeneratePage.tsx` (モバイル表示時 `isMobile === true` のレイアウト処理)
- `frontend/src/store/useGenerationStore.ts` (WebSocket接続処理時の未キャッチ例外対策)
- `frontend/src/hooks/useComfyWebSocket.ts` (WebSocket接続処理時の未キャッチ例外対策)

---

## 3. 詳細設計 (Detailed Design)

### 3-1. インラインコンポーネントのトップレベル切り出しによる再レンダリング崩壊対策
`GeneratePage.tsx` では、`ParamPanel`、`AppliedAssetChips`、`AuditPanel`、`MappingErrorPanel` などのサブコンポーネントが、親コンポーネント `GeneratePage()` の内部で**インライン関数**として定義され、JSX内でタグ（例: `<ParamPanel />`）としてレンダリングされています。

親の再レンダリングごとにコンポーネントタイプが動的に再作成されるため、特にモバイルレイアウト切り替え時や状態更新時に React の仮想DOMツリーの不整合（マウント崩壊）が発生し、アプリがクラッシュする原因となります。

- **対策**: `GeneratePage` コンポーネント의 内部で定義されている以下のサブコンポーネントを、`GeneratePage` の外（ファイルのトップレベル）に定義し直すか、必要なProps（`workflows`, `snapshots`, `isConnected`, `isGenerating`, `paramValues` 等）を明示的に受け取るように書き換えて安全にします。
  - `ParamPanel`
  - `AppliedAssetChips`
  - `AuditPanel`
  - `MappingErrorPanel`

### 3-2. WebSocket初期化時の `SecurityError` 未キャッチ例外対策 (堅牢化)
スマホ（iOS Safari等）のローカルネットワークアクセス制限により、非セキュアな `ws://` 接続の試行自体が `new WebSocket` 呼び出しの瞬間に同期例外（`SecurityError`）をスローすることがあります。
- **対策**: [useGenerationStore.ts](../../frontend/src/store/useGenerationStore.ts#L269-L270) と [useComfyWebSocket.ts](../../frontend/src/hooks/useComfyWebSocket.ts#L73) の `new WebSocket` 呼び出し部分を `try-catch` で囲み、例外を安全に処理するように変更します。

```typescript
// 変更イメージ
try {
  ws = new WebSocket(`${wsUrl}/ws?clientId=${get().clientId}`)
} catch (e) {
  console.error("Failed to establish WebSocket connection:", e)
  set({ isConnected: false })
}
```

## 4. 懸念事項・トレードオフ (Trade-off Disclosure)
- **インラインコンポーネントの切り出し**:
  - 切り出しに伴い、親コンポーネントのローカル状態（State）やAPIクエリ結果を Props 経由で明示的に引き渡す必要があります。Props の記述量が増加しますが、React の公式ガイドに準拠し、再レンダリング時の状態損失やクラッシュを防群堅牢性を優先します。
