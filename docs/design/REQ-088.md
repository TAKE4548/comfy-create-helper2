# REQ-088: 生成中の詳細プログレスバー表示機能 設計書

## 1. 概要
生成中のプログレスバーを「全体バッチ進捗」と「実行中ノード進捗」の2つのバーに分割し、詳細な進捗状況（現在実行中のノード名、進捗率）、生成開始からの経過時間、および予測残り時間（ETA）をリアルタイムに表示する。

## 2. 状態管理の変更 (`useGenerationStore.ts`)
- **新しい状態変数**:
  - `currentWorkflow`: `Record<string, any> | null` (現在実行中のワークフローJSON。ノードIDからクラス名/カスタムタイトルを引くために使用)
  - `currentNode`: `{ id: string; name: string } | null` (現在実行中のノード)
  - `nodeProgress`: `{ value: number; max: number; percentage: number; nodeId?: string; nodeName?: string } | null` (ノードごとの詳細進捗)
  - `generationStartTime`: `number | null` (生成開始のタイムスタンプ)

- **WebSocket メッセージハンドラ (`ws.onmessage`)**:
  - `execution_start`:
    - `generationStartTime` を `Date.now()` に設定。
    - `currentNode`, `nodeProgress` を初期化。
  - `executing`:
    - `data.node` (ノードID) を取得。
    - `currentWorkflow` から該当ノードのクラス名（`class_type`）またはタイトル（`_meta.title`）を取得し、`currentNode` に設定。
    - 新しいノードの実行開始時に、`nodeProgress` のパーセンテージを `0` にリセット。
  - `progress`:
    - `data.value`, `data.max`, `data.node` を取得。
    - ノードIDからノード名を取得し、`nodeProgress` を更新。
  - `executed` / `execution_complete` / `execution_error`:
    - 生成終了時（バッチジョブが全て完了した場合）、`generationStartTime`, `currentNode`, `nodeProgress`, `currentWorkflow` を `null` にリセット。

- **プロンプト送信時 (`queuePrompt`)**:
  - 送信する `workflow` (JSON) を `currentWorkflow` に保持する。

## 3. UI表示の変更 (`DesktopLayout.tsx` & `MobileLayout.tsx`)
- **プログレスバーの2本表示**:
  1. **全体バッチ進捗バー**:
     - 進捗率: `(完了数 / 総数) * 100` (または詳細進捗の端数を含めて滑らかに表示)
     - テキスト: `全体進捗: m/n 枚目 (xx%)`
  2. **詳細ノード進捗バー**:
     - 進捗率: `nodeProgress.percentage`
     - テキスト: `実行中: [ノード名] (xx%)` (例: `実行中: KSampler (45%)`)
- **時間表示**:
  - 経過時間: 秒単位でカウントアップ (`経過時間: X秒`)
  - 残り予測時間 (ETA): 全体進捗率と経過時間から算出 (`残り約: Y秒`)
    - 計算式: `ETA = 経過時間 * (100 - 全体進捗率) / 全体進捗率` (経過時間 > 2秒 かつ 全体進捗率 > 5% の場合に表示)

## 4. 懸念点・トレードオフ (Trade-off Disclosure)
- **手動実行や外部クライアントからのトリガー**:
  - 自セッション以外からトリガーされた生成（他クライアントからのWSイベント等）では `currentWorkflow` が取得できないため、ノード名が `Node #9` のようなID表記にフォールバックされます。
- **ETAの精度**:
  - KSampler以外のノード（ロードや保存など）は一瞬で終わるか進捗が出ないため、進捗率の進み方に偏りがあり、ETAの秒数は多少前後します。これは仕様として許容します。
