## Planned contracts and task obligations
Generation record v1 is a JSON string under `__prompt_surgeon_metadata_v1` within existing `params` transport; mutable associations use separate `__metadata_associations_v1`. No DB migration is planned. The record freezes workflow identity/name, timestamp semantics, mapped prompt and non-prompt graph values/types/order/status, actual injected seed, and generation-time asset/trigger provenance where it was explicitly selected. Bypass status/reference-valued graph inputs must not be represented as resolved values. Snapshot params is the saved-image source of truth even when empty; never fill from current UI/cache/master when the snapshot record is absent. Keep existing retention behavior.
