# REQ-311 詳細設計書: FuguMT翻訳実行時のsentencepiece依存欠落によるエンジン初期化失敗の修正

## 1. 概要と背景 (Overview & Background)

### 1-1. 課題認識
REQ-304 および REQ-310 にて、CPU常駐・超低遅延（20〜30ms）・VRAM消費ゼロ（0MB）の `FuguMTService` が導入された。
しかし、翻訳実行時（`POST /api/translate/prompt` 等）に以下のエラーが発生し、和訳機能が全停止する事象が報告された：
```
API error 500: {"detail":"Translation failed: FuguMT engine is not available"}
```

トリアージ調査（`docs/incident_report.md`）により、以下の事実とメカニズムが特定された：
1. **モデル配置は成功済み**: `backend/models/fugumt-en-ja` にモデルファイル群（`model.bin`, `source.spm`, `target.spm` 等）は正常にダウンロード・配置されていた。
2. **sentencepiece 依存の欠落**: MarianMT ベースの FuguMT モデルを `transformers.AutoTokenizer.from_pretrained` でロードする際、SentencePiece トークナイザー変換ライブラリ `sentencepiece` が必須となる。しかし `backend/requirements.txt` に記載がなく、仮想環境（`.venv`）にも未インストールであったため、`AutoTokenizer` のインスタンス化時に例外が発生していた。
3. **例外原因の隠蔽**: `FuguMTService.initialize()` 内で例外を捕捉した際、詳細な原因メッセージが破棄され、`translate_batch()` では一律で `RuntimeError("FuguMT engine is not available")` を送出していたため、ユーザーやフロントエンドには「エンジンが存在しない」と誤認させるメッセージとなっていた。
4. **テスト検証のすり抜け**: 既存テスト（`test_fugumt_service.py`）で `AutoTokenizer.from_pretrained` を `MagicMock` で過剰にモックしていたため、実ランタイムの依存欠落が CI/テストで検出されなかった。

### 1-2. 改修ゴール
1. `backend/requirements.txt` に `sentencepiece>=0.2.0` を追加し、環境に導入する。
2. `FuguMTService` において、スレッドセーフな初期化ロック（`threading.Lock`）を導入し、初期化失敗時の例外詳細（`_init_error`）を保持して、`RuntimeError` 送出時およびエラーログへ明瞭かつ重複なく伝達する。
3. 実行時のカレントディレクトリ（CWD）に依存せず `__file__` を起点とした絶対パス候補検索による堅牢なモデルパス解決を実装する。
4. モックに頼らず実ランタイムでの依存ロード・トークナイズ健全性を検証する回帰テストを追加し、依存欠落の再発を恒久的に防ぐ。

## 3. 詳細実装設計

### 3-1. `FuguMTService` の例外伝播・パス解決・スレッドセーフ化
```python
import threading
from pathlib import Path

class FuguMTService:
    ...
    def __init__(
        self,
        model_dir: Optional[str] = None,
        intra_threads: int = 6,
        auto_download: bool = True,
    ) -> None:
        raw_dir = model_dir or os.environ.get("FUGUMT_MODEL_DIR", "models/fugumt-en-ja")
        
        # CWD 依存を排除した確実なパス解決
        p_raw = Path(raw_dir)
        if p_raw.exists():
            self.model_dir = str(p_raw)
        else:
            # backend/app/services -> backend/models/fugumt-en-ja
            backend_model_dir = Path(__file__).resolve().parent.parent.parent / "models" / "fugumt-en-ja"
            if backend_model_dir.exists():
                self.model_dir = str(backend_model_dir)
            else:
                self.model_dir = raw_dir

        self.intra_threads = intra_threads
        self.auto_download = ...
        self._init_lock = threading.Lock()
        self._init_error: Optional[str] = None

    def initialize(self) -> bool:
        if self._is_initialized and self.translator is not None and self.tokenizer is not None:
            return True

        with self._init_lock:
            if self._is_initialized and self.translator is not None and self.tokenizer is not None:
                return True
            ...
            try:
                import ctranslate2
                from transformers import AutoTokenizer

                self.translator = ctranslate2.Translator(...)
                self.tokenizer = AutoTokenizer.from_pretrained(self.model_dir)
                self._is_initialized = True
                self._init_error = None
                return True
            except Exception as e:
                self._init_error = str(e)
                logger.error("Failed to initialize FuguMT engine: %s", e)
                self._is_initialized = False
                return False

    def translate_batch(self, texts: List[str]) -> List[str]:
        if not texts:
            return []
        if not self._is_initialized or self.translator is None or self.tokenizer is None:
            if not self.initialize():
                err_detail = f": {self._init_error}" if self._init_error else ""
                raise RuntimeError(f"FuguMT engine is not available{err_detail}")
        ...
```

## 5. BA 監査所見と対応方針 (BA Audit Trace & Response)

<!-- [LLM Audit Trace: Action=ba-audit | Model=qwen3.5-9b-claude-4.6-highiq-thinking-heretic-uncensored | Domain=reasoning | Params=9.0B | Quant=Q6_K] -->

### 5-1. 監査所見と設計反映
1. **パス解決の CWD 依存の排除 (Critical)**:
   - **所見**: `os.path.join("backend", raw_dir)` によるフォールバックは、CWD が `backend/` の際に `backend/backend/...` となり失敗する懸念がある。
   - **対応**: `Path(__file__).resolve().parent.parent.parent / "models" / "fugumt-en-ja"` をフォールバックアンカーとし、プロセスの CWD に一切左右されない決定的なパス解決へと設計を変更。
2. **エラーメッセージの二重ラッピング防止 (High)**:
   - **所見**: `_init_error = f"{type(e).__name__}: {str(e)}"` とすると送出時にクラス名が重複する。
   - **対応**: `_init_error = str(e)` で保持し、`RuntimeError(f"FuguMT engine is not available: {self._init_error}")` で明瞭かつ簡潔に整形。
3. **トークナイザーの実動作テスト拡充 (Medium)**:
   - **所見**: `import sentencepiece` の確認だけではモデルファイルからの実際のトークナイズ動作が保証されない。
   - **対応**: モデルファイルが存在する場合に `tokenizer.encode("Hello, world!")` を実際に実行してトークン配列が得られることを検証するテストを追加。
4. **スレッドセーフ初期化 (Low-Medium)**:
   - **所見**: 並行リクエスト時の初期化競合リスク。
   - **対応**: `threading.Lock()` によるダブルチェックロッキングを導入。
