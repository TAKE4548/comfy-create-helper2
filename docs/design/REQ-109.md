# REQ-109: タブレットやスマホから Scene Generator を開くと画面が真っ黒になる問題の修正 設計書

## 1. 概要
非セキュアコンテキスト（実機のスマートフォンやタブレットから HTTP 経由でアクセスした際など）において、`crypto.randomUUID()` が `undefined` となり画面が真っ黒にクラッシュする問題を修正する。

## 2. 影響コンポーネントと修正内容

### 2-1. `frontend/src/utils/uuid.ts` [NEW]
セキュアコンテキスト以外でも安全に一意の ID（UUID）を生成するための共通関数 `generateUUID()` を作成する。

**実装コードイメージ**:
```typescript
export function generateUUID(): string {
  if (typeof window !== 'undefined' && window.crypto) {
    if (window.crypto.randomUUID) {
      return window.crypto.randomUUID();
    }
    if (window.crypto.getRandomValues) {
      return '10000000-1000-4000-8000-100000000000'.replace(/[018]/g, (c: any) =>
        (c ^ (window.crypto.getRandomValues(new Uint8Array(1))[0] & (15 >> (c / 4)))).toString(16)
      );
    }
  }
  // 完全なフォールバック (Math.random)
  return 'xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx'.replace(/[xy]/g, (c) => {
    const r = (Math.random() * 16) | 0;
    const v = c === 'x' ? r : (r & 0x3) | 0x8;
    return v.toString(16);
  });
}
```

### 2-2. `frontend/src/components/SceneGeneratorModal.tsx` [MODIFY]
- `crypto.randomUUID()` を呼び出している箇所を、新規作成する `generateUUID()` に変更する。
- 該当行: L47, L72, L77

## 3. 懸念点とトレードオフ (Trade-off Disclosure)
- **IDの衝突リスク**: `Math.random` フォールバック時の UUID の衝突確率は `crypto.randomUUID` に比べて高くなりますが、Scene Generator 内のシーン一覧の `key` および一連のセッション内での一時識別子としてのみ使用されるため、衝突による実害は極めて低く、クラッシュの防止を優先するトレードオフとして妥当です。
