# 設計書 - REQ-003: サイドバーの折り畳み機能

## 1. 目的と概要
画面サイズが狭い場合や、ユーザーがメインの生成ワークスペースに集中したい場合に、サイドバーの表示領域を最小限（アイコンのみの表示状態であるミニバー）にする折り畳み機能を提供します。これにより、メインコンテンツ領域が横方向に自動で広がり、画面の有効活用と操作性の向上を図ります。
また、折り畳み状態を `localStorage` に保持することで、ページのリロードや再アクセス時にも前回の状態が引き継がれるようにします。

## 2. アーキテクチャ設計

### 2.1 フロントエンド（React + TypeScript）

#### 1. 状態管理（Zustand または React Hook）
本機能はレイアウト全体に関わるため、`frontend/src/components/layout/AppShell.tsx` 内で状態を管理します。
- `isCollapsed` (boolean): サイドバーが折り畳まれているかどうか（`true` のとき折り畳み状態）。
- 初期値は `localStorage.getItem('prompt-surgeon-sidebar-collapsed') === 'true'` とします。
- 状態切り替え時に `localStorage` への保存を行います。

#### 2. スタイルとアニメーション (Tailwind CSS)
- **Aside (サイドバーコンポーネント)**:
  - クラス名に `transition-all duration-300 ease-in-out` を追加し、スムーズな幅変化を実現します。
  - 幅の切り替え: `isCollapsed` が `true` の場合は `w-16`、`false` の場合は `w-56`。
- **テキスト・ロゴ名の表示制御**:
  - サイドバーが折り畳まれた際、テキストラベルやロゴテキストは非表示にする必要があります。
  - アニメーション中にテキストが不自然に改行されるのを防ぐため、`overflow-hidden whitespace-nowrap transition-all duration-300` と連動させ、`isCollapsed` 時には `w-0 opacity-0`、通常時には `w-auto opacity-100` となるように制御します。
- **トグルボタン**:
  - サイドバーの最上部（ヘッダー部分）にトグルボタンを配置します。
  - アイコンには `lucide-react` の `ChevronLeft`（通常時）および `ChevronRight`（折り畳み時）を使用します。

## 3. UI/UX デザイン設計

### 3.1 展開状態 (Expanded Sidebar - Width: 56)
```
+------------------------------------+
| [Logo] Prompt Surgeon       [ < ]  |  <- ヘッダー (トグルボタン含む)
+------------------------------------+
| (Icon) Generate                    |  <- 各メニュー項目 (アイコン+テキスト)
| (Icon) LoRAs                       |
| (Icon) Tags                        |
| (Icon) History                     |
| (Icon) Settings                    |
+------------------------------------+
| v2.0.0                             |  <- バージョン表示
+------------------------------------+
```

### 3.2 折り畳み状態 (Collapsed Sidebar - Width: 16)
```
+--------+
|  [ > ] |  <- ヘッダー (トグルボタンのみ中央配置)
+--------+
|  (Icon)|  <- メニュー項目 (アイコンのみ中央配置)
|  (Icon)|
|  (Icon)|
|  (Icon)|
|  (Icon)|
+--------+
|        |  <- バージョン表示非表示
+--------+
```

### 3.3 インタラクションと配置詳細
- トグルボタンには一意の ID `#sidebar-toggle` を付与し、テストおよびブラウザ操作スクリプトから確実に検出できるようにします。
- 折り畳み・展開の切り替えは `duration-300` (300ms) のイージングを伴ってスムーズにアニメーションします。
- メインコンテンツ領域（`<main>`）は `flex-1` を指定しているため、サイドバーの幅変化に応じて自動的に横幅が伸長・収縮します。
