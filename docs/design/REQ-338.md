# REQ-338: Prompt Surgeon モバイル最適化および全ビュー共通基盤改修 詳細設計書

## 1. アーキテクチャ概要 (Architecture Overview)

本設計は、スマートフォン・タブレット端末（360px〜768px未満）における操作性課題を解決するとともに、デスクトップ（PC）の生産性をも同時に飛躍させる**「全ビュー共通基盤（Part 1）」**と**「モバイル特化仕様（Part 2）」**の二大アーキテクチャ分離設計である。

### 1.1 二大分類と設計方針
1. **Part 1: 全ビュー共通基盤 (Desktop / Tablet / Mobile 共通)**
   - **C-01. Hybrid Stepper Slider**: 粗調整スライダーに [-] [+] ステッパーボタンと直接数値入力を統合。
   - **C-02. 全画面 Lightbox & A/B カーテン比較**: 画像クリックで全画面展開、1:1 等倍ズーム・パン、中央仕切りドラッグによる A/B スプリットカーテン比較。
   - **C-03. スリープ復帰 0 秒再同期**: `document.visibilitychange` / `window.focus` を契機に、切断ソケット破棄＆WebSocket再開（`systemWsService.resume()`）と REST API（`generationApi.getState()`）フェッチを並行実行。
   - **C-04. モーダル共通基盤**: `body { overflow: hidden }`（Body Scroll Lock）、`overscroll-behavior: contain`、および常時可視化 Sticky Footer。
   - **C-05. 共通 CSS 防壁**: `min-w-0 truncate` / `break-all` による横あふれ防止と、数値表示の `tabular-nums font-mono` 統一。

2. **Part 2: モバイル特化仕様 (Mobile-Only: < 768px)**
   - **M-01. 余白と情報密度**: 画面外枠 `px-3 py-2.5`（12px / 10px）、カード内 `p-2.5`（10px）、グリッド `gap-2`（8px）。
   - **M-02. タッチターゲット Hit-Slop 拡張**: 外形 24px（`h-6`）のタグチップに対し、透明疑似要素 `before:-inset-2` でタップ判定を 40px〜44px に拡張。
   - **M-03. ビューポート動的追従 & セーフエリア**: ルートコンテナ `100dvh`、固定ボトムバー `pb-[calc(env(safe-area-inset-bottom)+12px)]` による Safari ツールバー・Home Indicator 干渉排除。
   - **M-04. ボトムシート (Drawer)**: モバイル表示時のモーダルを下部引き出し形式（Drawer）に置換し、下スワイプクローズと親指ゾーン決定ボタンを提供。
   - **M-05. 仮想キーボード (IME) 防御**: 入力フォーカス時に下部固定 Action Bar を自動退避（`hidden`）、キーボード直上にタグサジェストバーを吸着配置。
   - **M-06. 親指エルゴノミクス (Thumb Zone)**: 画面下部 40%（Natural Zone）に最重要アクション（Generate、選別、キュー管理）を集約し、上部スクロールに `overscroll-behavior-y: contain` を付与して Pull-to-refresh 暴発を遮断。

## 2. コンポーネント設計 (Component Specifications)

### 2.1 Hybrid Stepper Slider (`frontend/src/components/common/StepperSlider.tsx`)
- **Props**:
  - `value: number`
  - `onChange: (value: number) => void`
  - `min: number` (default: 0)
  - `max: number` (default: 1)
  - `step?: number` (default: 0.05)
  - `label?: string`
  - `presets?: number[]` (e.g. `[0.5, 0.7, 1.0, 1.2]`)
  - `className?: string`
  - `disabled?: boolean`
- **内部動作**:
  - [-] ボタン押下で `Math.max(min, Number((value - step).toFixed(4)))`
  - [+] ボタン押下で `Math.min(max, Number((value + step).toFixed(4)))`
  - 数値 input に直接入力可能（フォーカス解除または Enter でバリデーション・クランプ）
  - スライダー (`<input type="range">`) のドラッグによる粗調整
  - 表示数値には `tabular-nums font-mono` を適用

### 2.2 全画面 Lightbox ＆ A/B カーテン比較 (`LightboxModal.tsx` & `CurtainCompareView.tsx`)
- **LightboxModal**:
  - `isOpen: boolean`, `onClose: () => void`, `children: ReactNode`
  - 全画面固定 (`fixed inset-0 z-50 bg-black/95`)
  - キーボード操作: `Escape` で閉じる、`Space` で比較トグル
- **CurtainCompareView**:
  - `imageA: string`, `imageB?: string`, `splitPercent?: number`, `onSplitChange?: (p: number) => void`
  - ホイールスクロールで拡大縮小（100%〜400%等倍ズーム）
  - ドラッグによるパン操作（Pointer events / Pan offset）
  - 画像中央の垂直スプリットバーをドラッグして左右の比較比率を 0%〜100% で無段階調整

### 2.3 スリープ復帰 0 秒再同期 (`useAppLifecycleSync.ts`)
- **トリガー**: `document.addEventListener('visibilitychange')` および `window.addEventListener('focus')`
- **実行ロジック**:
  - `document.visibilityState === 'visible'` 検知時:
    1. `systemWsService.resume()` を即座に実行（古い Half-Open ソケットを破棄・再接続）。
    2. `generationApi.getState()` を非同期実行し、最新の `GenerationSnapshot` を取得。
    3. `useGenerationStore.getState().fetchQueue()` または `applyGenerationSnapshot(snapshot, upstream)` を呼び出して最新世代（Epoch / Revision）を反映。
    4. 復帰通知トースト／ログを出力。

### 2.4 モーダル共通基盤 (`Modal.tsx`)
- **Body Scroll Lock**:
  - `useLayoutEffect` で `isOpen === true` のとき `document.body.style.overflow = 'hidden'` を適用。アンマウント時または `isOpen === false` 時に元のスタイルを復元。
- **Sticky Footer & Overscroll Contain**:
  - ダイアログ内部コンテナに `max-h-[85vh] flex flex-col`
  - 本文コンテンツ領域に `flex-1 overflow-y-auto overscroll-contain`
  - フッターに `sticky bottom-0 bg-surface-3 border-t p-4` を適用

### 2.5 ボトムシート Drawer (`BottomSheet.tsx`)
- **モバイル専用 Drawer**:
  - 画面下部からスライドイン (`fixed inset-x-0 bottom-0 z-50 rounded-t-2xl bg-surface-3`)
  - 上部にドラッグハンドル (`h-1.5 w-12 rounded-full bg-zinc-600 mx-auto my-2`)
  - タッチイベント（`touchstart`, `touchmove`, `touchend`）による下スワイプ検知（下方向移動量 > 80px で `onClose` 実行）
  - 親指ゾーンに Sticky Footer ボタン（決定／キャンセル）を固定

### 2.6 タッチ判定吸着・Hit-Slop 適正化 (`TagChip.tsx`, `TagChipViewer.tsx`)
- **高密度保持と自然な判定吸着 (Proximity Snap)**:
  - タグチップ外形（`h-6 text-xs px-2`）およびチップ間の余白（`gap-1.5`）を完全に維持し、スカスカ感を防止。
  - 上下左右の密集領域での判定重複を防ぐため、単純な広域 `before:-inset-2` を排除し、重複のないコンパクトな Hit-Slop を採用。
  - タッチポイントに最も近いチップを判定・吸着（Proximity Snap）するイベントハンドリングを適用。
  - `touch-action: manipulation` でダブルタップズームによる 300ms 遅延を排除。
  - `active:scale-[0.97]` により即座にタッチフィードバックを提供。

### 2.7 モバイルレイアウト統合 (`MobileLayout.tsx`)
- **外枠余白**: ルートラッパーに `px-3 py-2.5`、カードに `p-2.5`、グリッドに `gap-2`
- **100dvh & セーフエリア**: `min-h-[100dvh]`、ボトムドックに `pb-[calc(env(safe-area-inset-bottom)+12px)]`
- **IME キーボード防御**:
  - 入力フォーカス時、下部固定 Action Bar (`#generate-btn-mobile` 等) を `hidden` に退避
  - キーボード直上にタグサジェストバーを表示
- **Natural Thumb Zone**:
  - 画面最下部 40% に Generate / 選別 / キュー管理を集約
  - 上部スクロールコンテナに `overscroll-behavior-y: contain` を適用して Pull-to-refresh を遮断
- **端末回転防御**:
  - Portrait / Landscape 切替時にもセーフエリアと Natural Zone を破綻なく保持

## 4. トレードオフ開示 (Trade-off Disclosure)

1. **共通基盤化 vs モバイル個別実装の分離コスト**:
   - スライダーや Lightbox、モーダル基盤を共通化することで、PC 版にも恩恵が及ぶ一方、PC 側の既存レイアウト（ParamPanel, GeneratePage）との統合テストが必要になる。
   - **対策**: 既存の `Modal.tsx` の互換性を 100% 維持しつつ、Body Scroll Lock と Sticky Footer を自然に有効化。スライダーも既存の range input を段階的かつ安全に StepperSlider へ置換可能とする。
2. **タッチ判定 Hit-Slop と要素近接衝突**:
   - `before:-inset-2` による 40px タップ領域拡張を単純適用すると、上下左右にチップが密集するタグクラウドにおいて隣接チップ同士の判定が重複し、意図しないタグがタップされるリスクがある。一方、単に gap を広げると情報密度が低下してスカスカになってしまう。
   - **対策**: チップ間の見た目の余白（`gap-1.5`）と高密度な一覧表示は完全に維持する。疑似要素による重複を避けるため、静的な矩形拡張の代わりにタッチポイントに最も近いチップを自然に選択・吸着する近接判定（または重複のないコンパクトな Hit-Slop + `touch-manipulation` + `active:scale-[0.97]`）を適用し、密集度とタップ精度の両立を実現する。
3. **IME キーボード検知のブラウザ差異**:
   - iOS Safari と Android Chrome で仮想キーボード起動時の `window.visualViewport` 挙動や `resize` イベントのタイミングが異なる。
   - **対策**: 単純な Viewport リサイズ判定に依存せず、input / textarea の `focus` / `blur` イベント駆動と `visualViewport.height` のハイブリッド検知を適用し、環境依存の誤作動を防止する。
