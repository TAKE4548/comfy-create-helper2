# REQ-128: 吹き出しセリフ保存時の解像度低下・ガイドオーバーレイ混入バグ修正 設計書

## 1. 概要

吹き出しセリフ編集モーダル (`SpeechBubbleEditorModal.tsx`) で「保存」を行った際、表示用プレビューキャンバス（最大500x500px）をそのまま `toBlob()` して保存していたため、以下の2つの不具合が発生していた。
1. **解像度の低下**: 元画像の解像度に関わらず500x500px以下に縮小されて保存される。
2. **ガイドオーバーレイの混入**: プレビュー画面描画用の緑枠（吹き出し検出ボーダー）、デバッグ候補領域枠、ROI選択枠がそのまま保存画像に合成される。

本設計では、`handleSave()` 時に表示用キャンバスとは独立した**元画像解像度のオフスクリーンキャンバス (Offscreen Canvas)** を動的に作成・描画し、そこから画像 Blob を生成・アップロードする構造へ変更する。

## 2. 変更仕様

### 2.1 オフスクリーンキャンバスによる保存処理
`handleSave()` 実行時に以下の処理を行う:
1. `imageObj.naturalWidth` × `imageObj.naturalHeight` のサイズで DOM 非非表示キャンバス (`document.createElement('canvas')`) を生成。
2. 背景として `imageObj` (元画像) を全画面描画。
3. `boundingBox` および `speechText` が存在する場合、元画像スケールに応じたテキスト描画を実施:
   - スケールファクター `scaleFactor = imageObj.naturalWidth / canvasDimensions.width` を算出。
   - 吹き出し背景の白色塗りつぶし (元画像座標 `boundingBox.x, y, w, h`)。
   - セリフテキストのフォントサイズ算出・配置 (`layoutVerticalText` を適用)。フォントサイズ検索範囲は `(36 * scaleFactor)` ～ `(8 * scaleFactor)`。
   - `activeFontFamily` を用いてテキストを黒色で描画。
4. ガイドライン描画ロジック（緑枠、デバッグ枠、ROI枠）は一切適用しない。
5. 作成したオフスクリーンキャンバスから `toBlob(resolve, 'image/png')` を呼び出し、サーバーへアップロード。

## 4. 影響範囲とリスク (Trade-offs)
- **メモリ使用量**: 一時的に元画像サイズのキャンバスをメモリ上に展開するが、Blob生成完了後に破棄されるため影響は軽微。
- **フォント適用**: 表示用プレビューで読み込み済みの `FontFace` (`activeFontFamily`) をオフスクリーンキャンバスでもそのまま使用可能。
