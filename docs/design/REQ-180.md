# REQ-180: セリフ・吹き出し編集機能の強化およびモーダルUIの最適化

## 1. 背景と目的
セリフ（吹き出し）編集モーダルにおいて、以下の4点の課題および改善要望に対応する：
1. **セリフ修飾の屈折方向反転**: パス配置やスケール変化において、変形方向（左右・上下・凸凹・文字サイズ増減）を逆転させる反転機能が不足している。
2. **プレビューエリアの余白削減・表示拡大**: プレビュー周囲の固定的な余白設定（500x500上限や過度なpadding）により、画像表示領域が狭く視認性・編集操作性が制限されている。
3. **プリセット一覧の表示順序変更**: 現在「テキストあり」が先に表示されているが、スタイル選択用途の利便性向上のため「テキストなし（スタイル専用）」を先頭に表示する。
4. **しっぽ本体接点の調整と微調整モード**: 吹き出しのしっぽは先端頂点のみ操作可能で本体との接点幅・位置が固定されているため、太さや接地位置を細かく制御できる「微調整モード」を提供する。

## 3. 詳細設計

### 3-1. プレビューエリア余白削減と拡大表示 (`SpeechBubbleEditorModal.tsx`)
- **余白削減**:
  - モーダルコンテンツのパディングを `p-3 md:p-6` から `p-2 md:p-3` へスリム化。
  - キャンバスラッパーのパディング・マージンを最小限に整理。
- **キャンバス動的サイズ拡大**:
  - 従来 `maxW = 500, maxH = 500` 固定だった上限を、ウィンドウサイズおよびモーダル利用可能領域（例: `Math.min(900, window.innerWidth * 0.58)` / `Math.min(720, window.innerHeight * 0.72)`）に応じて拡大。
  - レスポンシブに元画像アスペクト比を保ちつつ、プレビュー領域を最大限利用する。

### 3-2. プリセット表示順序変更 (`SpeechBubbleControls.tsx`)
- **順序逆転**:
  - `withoutTextPresets`（テキストなし・スタイル専用）セクションを先にレンダリング。
  - `withTextPresets`（テキスト付き）セクションを後にレンダリング。
  - 既存のソート（名前順・作成順）や検索フィルタ、折り畳み状態は各セクション内でそのまま維持。

### 3-3. セリフ修飾の屈折・スケール反転 (`speechBubbleRenderer.ts` / `SpeechBubbleControls.tsx`)
- **データ構造**:
  - `MangaTextEffectConfig` に `scaleInvert?: boolean` またはスケール反転操作、`pathInvert?: boolean` またはパス制御点反転ロジックを追加。
- **反転ロジック**:
  - スケール反転: `scaleStart` と `scaleEnd` の増減方向を反転（または開始・終了値の反転適用）。
  - パス反転: 
    - 縦書き時: X座標を反転（`x = 1 - x`、左曲がり⇔右曲がり）。
    - 横書き時: Y座標を反転（`y = 1 - y`、上凸⇔下凸）。
- **UI**:
  - セリフ修飾パネルのパス設定エリアおよびスケール設定エリアに「方向反転 ⇄」ボタンまたはトグルを設置。

### 3-4. 吹き出ししっぽ本体接点（基部幅/位置）調整と微調整モード
- **データ構造**:
  - `BubbleTail`:
    ```typescript
    export interface BubbleTail {
      x: number // 尻尾先端X
      y: number // 尻尾先端Y
      baseOffset?: number // 本体外周上の接点中心オフセット（radまたは相対値）
      baseSpread?: number // 接点幅・広がり（radまたはpx）
      isCustomBase?: boolean // 微調整モード有効フラグ
    }
    ```
- **微調整モードUI**:
  - 吹き出し設定内（またはしっぽ操作時）に「しっぽ微調整モード」トグルを配置（デフォルト: OFF）。
  - OFF時: 従来通りの先端頂点ハンドルのみ表示（接点は先端座標から自動計算）。
  - ON時: 先端ハンドルに加え、本体外周の接点位置（または両端接点）を操作できる青/紫色のドラッグハンドルを表示。
- **レンダリング**:
  - `speechBubbleRenderer.ts` において、`isCustomBase` が有効な場合は `baseOffset` / `baseSpread` を適用して楕円・角丸矩形のしっぽ基部を描画。
