# PBI-REQ-059 実行可能テスト計画

## 1. 静的検証及びビルドチェック (CLI Verification)
フロントエンドプロジェクトが正常にビルド・チェックを通ることを確認します。
- **コマンド**:
  ```bash
  cd frontend
  npm run lint
  npm run build
  ```
- **期待値**: エラーなく Lint および TypeScript コンパイル、Vite ビルドが完了すること。

## 2. ブラウザ検証 (Manual / Browser Agent Verification)
開発用サーバーを立ち上げ、UI操作による画像の切り替え動作を検証します。
- **検証手順**:
  1. バックエンドおよびフロントエンドを起動します。
  2. 生成ページ (`http://localhost:5173/` など) にアクセスします。
  3. 画像の生成を1回実行し、生成が完了してプレビューに画像が表示されるのを確認します。
  4. 画面下部にある過去の履歴サムネイル（生成画像とは異なるもの）をクリックします。
  5. **判定基準 (Assertion)**:
     - メインプレビュー部分の画像が、クリックした履歴画像のサムネイルに即座に切り替わること。
     - ページのリロードを行わずに切り替わること。
     - その後、別の履歴画像をさらにクリックした際も、プレビュー画像が追従して切り替わること。
