# 設計書 - REQ-029: 生成画面のデザイン修正および旧REQ-019の統合

## 1. 目的と概要
生成画面（Generate View）の操作性を高め、不要なスペースを排除し、情報構造を効率化します。具体的には、ワークフロー設定セクションのポップオーバー化、プログレスバーの非ブロッキング化、スナップショット選択の画像付きサムネイルタブ統合、および旧REQ-019で定義されていたプレビューの装飾と操作性改善を統合して実装します。

## 2. 詳細設計

### 2.1 ワークフロー設定のポップオーバー化 (AC-1)
- **対象**: `frontend/src/pages/GeneratePage.tsx`
- **設計**: 
  - ワークフロー選択ドロップダウンのすぐ右隣にギアアイコン（`Settings`）を配置。
  - クリックで absolute 配置のポップオーバーを表示する。
  - ポップオーバー内に、ComfyUI 接続 URL の入力欄、ワークフロー設定の「デフォルト保存」ボタンおよび「デフォルトにリセット」ボタンを移植する。
  - ComfyUI URL が変更された際は、`useGenerationStore` の `setComfyUrl` を呼び出し、WebSocket コネクションのクローズと再初期化をトリガーする。

### 2.2 非ブロッキングプログレスバーの採用 (AC-2)
- **対象**: `frontend/src/pages/GeneratePage.tsx`
- **設計**:
  - 生成中のプレビュー画像全体を覆うローディング表示（`isGeneratingHere` 時のオーバーレイ）を完全に廃止する。
  - 生成中もメインプレビュー領域には、ComfyUI から送られてくるリアルタイムプレビュー画像（`previewImage`）または最後に選択された画像（`selectedImg`）を表示し続ける。
  - プレビューコンテナの底面（または上面）に、高さ 4px のプログレスバー（`progress.percentage` に基づく幅）を絶対配置でオーバーレイ表示する。

### 2.3 スナップショットのビジュアル選択 (AC-3)
- **対象**: `frontend/src/pages/GeneratePage.tsx`
- **設計**:
  - メインプレビュー下部の履歴表示エリアの上部に「履歴」「スナップショット」の2つのタブを設置する。
  - **「履歴」タブ**: 従来の生成履歴（サムネイルストリップ）を表示。
  - **「スナップショット」タブ**: 現在選択されているワークフローのスナップショット一覧（`snapshots`）を表示する。各スナップショットは、日付情報とサムネイル画像を含むカード形式で配置し、クリックで対象スナップショットのパラメータをロードする。

### 2.4 保存アイコンのカメラ化 (AC-4)
- **対象**: `frontend/src/pages/GeneratePage.tsx`
- **設計**:
  - 「Save Snapshot」ボタンの Lucide アイコンを `Save` (フロッピーディスク) から `Camera` (カメラ) に変更する。

### 2.5 メインプレビューのサイズ調整と装飾 (AC-5, 旧REQ-019)
- **対象**: `frontend/src/pages/GeneratePage.tsx`
- **設計**:
  - メインプレビューコンテナ内で画像自体が占める最大サイズを `max-h-[70%] max-w-[70%]` 程度に調整し、コンテナ中央に余白を持って配置する。
  - 画像に対して境界線（`border border-zinc-800`）とボックスシャドウ（`shadow-[0_4px_30px_rgba(0,0,0,0.8)]`）を付与し、立体感のあるカードデザインとする。

### 2.6 ホバー左右切り替えボタンおよびキーボードショートカット (AC-6, AC-7, 旧REQ-019)
- **対象**: `frontend/src/pages/GeneratePage.tsx`
- **設計**:
  - メインプレビューにマウスホバーした際、左右中央付近にナビゲーションボタン（`<` / `>`）をフェードイン（またはホバー時のみ絶対配置で表示）する。クリックで履歴配列（`displayImages`）の前後へインデックスをシフトさせる。
  - プレビュー領域に `tabIndex={0}` を設定し、キーボードの `ArrowLeft` / `ArrowRight` キーで履歴画像を切り替えるイベントハンドラを追加する。入力フィールドやテキストエリアへのフォーカス時は発火しないようにガードを入れる。
