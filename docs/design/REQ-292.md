# REQ-292 設計書: SpeechBubbleEditorModal ヘッダー「シーン一括生成」ボタン統合

## 1. 概要 (Summary)

仕様書 REQ-291-UI 採用案3「モーダルヘッダー統合」に基づき、既存の `SpeechBubbleEditorModal` ヘッダー右側ボタングループに「シーン一括生成」ボタンを追加する。  
フックは `useSceneSpeechGeneration` を使用し、`primaryTagSetId` prop を経由してモーダルに渡す。

## 2. SSoT インパクト分析

| 変更対象 | 変更種別 | 影響範囲 |
|---|---|---|
| `SpeechBubbleEditorModal/index.tsx` | UI追加 + prop追加 | ヘッダーDOM、テスト |
| `useSceneSpeechGeneration.ts` | ロジック変更 (nullガード解除) | フックテスト |
| `SpeechBubbleEditorModal/types.ts` | interface拡張 | 型チェック全体 |
| `__tests__/SpeechBubbleEditorModal.test.tsx` | テスト追加 | CI |

doc_mapper.py では直接対応するスペックドキュメントは未登録（スタブPBI）。上流仕様は REQ-291-UI。

## 3. アーキテクチャ設計

### 3.1 Props 拡張 (`SpeechBubbleEditorModalProps`)

```typescript
// frontend/src/components/SpeechBubbleEditorModal/types.ts (L6-L11)
export interface SpeechBubbleEditorModalProps {
  snapshot: SnapshotSummary
  initialAlbumId?: number
  onClose: () => void
  onSaved: () => void
  // --- 追加 ---
  primaryTagSetId?: number | null        // シーン一括生成用 tagSetId
  generateDraftApi?: (payload: {...}) => Promise<{bubbles: GeneratedSpeechBubbleRead[]}>
  applyPresetToBubbles?: (bubbles: GeneratedSpeechBubbleRead[], presetId: number | null) => any[]
}
```

> **NOTE**: `generateDraftApi` と `applyPresetToBubbles` をオプション prop にすることで、既存のレンダリング側を無変更にできる。フックはデフォルト実装を持つ。

### 3.2 `useSceneSpeechGeneration` nullガード解除 (AC-3)

**現状 (L28)**:
```typescript
const handleBatchGenerateClick = async () => {
  if (!primaryTagSetId) return;  // ← これを削除
```

**変更後**:
```typescript
const handleBatchGenerateClick = async () => {
  // primaryTagSetId が null でも API 呼出継続
  if (primaryTagSetId !== undefined && primaryTagSetId !== null) {
    const existingPreset = await speechBubblePresetsApi.getByTagSetId(primaryTagSetId);
    // ... 既存ルート
  } else {
    // null ルート: target_tag_set_id: null で直接 API 呼出
    setIsGenerating(true);
    try {
      const res = await generateDraftApi({ snapshot_id: snapshotId, target_tag_set_id: null });
      setBubbles((prev) => [...prev, ...applyPresetToBubbles(res.bubbles, null)]);
    } finally {
      setIsGenerating(false);
    }
  }
};
```

### 3.4 モバイル自動タブ遷移 (AC-4)

`handleBatchGenerateClick` の `.finally()` にて `activeMobileTab === 'controls'` の場合 `setActiveMobileTab('preview')` を呼出す。  
この副作用はフック外部 (モーダル側) で管理し、`onGenerationComplete` コールバックとして注入する。

## 4. 依存関係と境界条件

- `generateDraftApi` のデフォルト実装は `llmPromptsApi.generateSceneDraft` または既存の `persistence.handleGenerateDraft` を利用。ただし型シグネチャを合わせる必要あり。
- `applyPresetToBubbles` のデフォルト実装はバブル配列をそのまま SpeechBubble 型に変換するアダプター関数。

## 5. トレードオフ開示

| 選択 | 採用理由 | 却下理由 |
|---|---|---|
| Props 経由でフック依存注入 | テスト容易性・疎結合 | 呼び出し側の記述量増加 |
| null ガード完全削除 | AC-3 準拠・シンプル | null 時の `getByTagSetId` 呼び出し不要APIコスト |
| null ルート分岐追加 | APIコスト最小化・意図明確 | 若干複雑化 |
| モーダル側でタブ遷移管理 | フック単責原則維持 | コールバック引数増加 |

採用: **null ルート分岐追加 + モーダル側タブ遷移管理**
