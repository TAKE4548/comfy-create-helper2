# PBI-REQ-063 実行可能テスト計画

## 1. 静的検証・ビルドテスト (CLI Verification)
- **コマンド**:
  ```bash
  cd frontend
  npm run build
  ```
- **期待値**: ビルドがエラーなしで成功すること。

## 2. ブラウザ検証 (Manual & Browser Agent Verification)
- **対象URL**: `http://localhost:5173/loras` および `http://localhost:5173/tags` (ローカル開発サーバー)
- **操作手順**:
  ### A. LoRA管理画面 (`/loras`)
  1. `All` カテゴリの状態でカードのドラッグ＆ドロップを行い、順序が入れ替わることを確認。
  2. カード領域をクリックし、LoRA詳細モーダルが起動することを確認。
  3. カード右上の「編集（鉛筆）」ボタンをクリックし、LoRA編集モーダルが起動することを確認。
  4. カード右上の「削除（ゴミ箱）」ボタンをクリックし、削除確認ダイアログが表示されることを確認。

  ### B. タグセット管理画面 (`/tags`)
  1. `All` カテゴリの状態でカードのドラッグ＆ドロップを行い、順序が入れ替わることを確認。
  2. カード領域をクリックし、タグセット詳細モーダルが起動することを確認。
  3. カード右上の「編集（鉛筆）」ボタンをクリックし、タグセット編集モーダルが起動することを確認。
  4. カード右上の「削除（ゴミ箱）」ボタンをクリックし、削除確認ダイアログが表示されることを確認。

- **判定基準 (Assertion)**:
  - ドラッグ時の順序変更が動作すること。
  - 各クリックアクション（詳細、編集、削除）がドラッグ開始イベントに吸われず、期待通り動作すること。
