# REA-063: LoRA管理・タグセット管理のD&Dとクリックイベント競合解消 設計書

## 1. 背景と目的
LoRA管理画面（`LoRAsPage.tsx`）およびタグセット管理画面（`TagsPage.tsx`）において、ドラッグ＆ドロップ（D&D）による並び替え機能を導入した結果、カード全体のクリックイベント（詳細表示モーダルの起動）やカード内ボタンのクリックイベント（編集・削除モーダルの起動）が、ドラッグ開始イベントと競合して吸い取られてしまい、動作しなくなっていた。
本設計では、`@dnd-kit` のセンサー設定を利用して、クリック動作とドラッグ動作を判別可能にすることで、この不具合を解消する。

## 2. 影響範囲
- `frontend/src/pages/LoRAsPage.tsx`
- `frontend/src/pages/TagsPage.tsx`

## 3. 詳細設計

### 3.1 センサー設定の追加
`@dnd-kit/core` から `useSensors`, `useSensor`, `MouseSensor`, `TouchSensor` をインポートし、ドラッグ開始判定に以下のしきい値を設定する。

```typescript
const sensors = useSensors(
  useSensor(MouseSensor, {
    activationConstraint: {
      distance: 8, // マウス押下後に8px移動するまではドラッグを開始しない（クリックとみなす）
    },
  }),
  useSensor(TouchSensor, {
    activationConstraint: {
      delay: 250, // モバイル環境でのタップと長押しドラッグを区別するため、250ms以上のホールドでドラッグ開始
      tolerance: 5,
    },
  })
)
```

### 3.2 DndContext へのバインド
両ページの `<DndContext>` 要素に対し、`sensors={sensors}` 属性を追加して上記センサー定義を適用する。

```xml
<DndContext collisionDetection={closestCenter} onDragEnd={handleDragEnd} sensors={sensors}>
```

## 4. 懸念点とトレードオフ
- ドラッグ操作を開始するために、マウスの場合は 8px 以上ドラッグさせる必要があり、タッチ操作の場合は 250ms 以上長押しする必要がある。これにより、ユーザーに対して「少ししっかりドラッグする」操作感が生まれるが、クリックやタップの正常な動作を保証するために必要なトレードオフである。
