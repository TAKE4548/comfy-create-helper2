# REQ-043: LoRA・タグセット紐付け編集およびフィルタ機能 - テスト計画書

## 1. 自動テスト (Unit Tests)
API レベルの挙動を確認するためのバックエンドテストおよび、フロントエンドコンポーネントのテストを行います。

### 1-1. バックエンド単体・統合テスト
- `backend/tests/test_snapshots_patch.py` を新規作成。
  - スナップショット作成後、`PATCH /api/snapshots/{snapshot_id}` を実行して LoRA / タグセットの紐付けが期待通り追加・削除されることを確認するテスト。
  - `GET /api/snapshots` で `lora_id` や `tag_set_id` クエリパラメータを指定したときに、対象のスナップショットのみが絞り込まれて取得されることを確認するテスト。

### 1-2. バックエンドテスト実行コマンド
```bash
cd backend
.venv\Scripts\pytest tests/test_snapshots_patch.py
```

## 2. 手動テスト (Manual Verification)

### 2-1. スナップショット紐付け編集の検証
1. ローカル開発サーバーを起動します。
2. 履歴（History）画面を開き、任意のスナップショットのサムネイルをクリックして詳細モーダルを開きます。
3. Applied Assets エリアに新設された「編集」ボタンをクリックします。
4. 紐付ける LoRA またはタグセットを選択し、「保存」をクリックします。
5. モーダルを閉じ、再度開いたときに変更したアセットが正しく表示されることを確認します。
6. バックエンドデータベース（またはAPI）で、対応するリレーションレコードが正しく増減していることを確認します。

### 2-2. 履歴画面でのアセットフィルタリングの検証
1. 履歴画面の上部に配置された「LoRAフィルタ」「タグセットフィルタ」のセレクトボックスを確認します。
2. 特定の LoRA（例: "LoRA A"）を選択し、その LoRA が紐付いているスナップショットのみが一覧に表示されることを確認します。
3. 同様に、特定のタグセット（例: "TagSet B"）を選択し、絞り込みが行われることを確認します。
4. フィルタを解除（"All" を選択）し、すべてのスナップショットが再表示されることを確認します。
