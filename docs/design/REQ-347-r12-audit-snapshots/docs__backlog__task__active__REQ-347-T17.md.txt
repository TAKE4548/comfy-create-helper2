## Contract

- 任意slotをtoolbar先頭、mode buttonを後ろへ置く。wrapperに `data-prompt-toolbar=""`、flex/wrap/align-center/gap6px/min-width0。overflow:hiddenを置かずpopupをclipしない。
- showModeStatus=falseは独立のChips Mode/Text Mode captionだけを省略。切替button各1つ、名前「テキスト入力モード切替」/「チップモード切替」を維持。現在modeは編集UI/次の切替actionで示す。canUndo/canRedo hintの条件/内容は別spanで保持する。
- default=true、slot未指定は既存caption/機能を維持。Mobile/Studio側propsを変更しない。
- button type/callback/parse/disabled chips/history/外部chips-value同期/key-mount寿命を変更しない。textarea/DnD bodyを別component/branchへ移さない。
