# 設計書 - REQ-015: タグチップエディタの導入（LLM連携除く）

## 1. 目的と概要
現在、`comfy-create-helper2` のプロンプト入力欄は単一の `textarea` またはシンプルなカンマ区切り入力になっています。本改修では、プロンプト試行錯誤時の利便性を劇的に向上させるため、高機能な **タグチップエディタ（TagChipEditor）** を導入します。
本機能により、タグの一時的な有効/無効化、並び替え、インライン編集、新規追加、ペーストによる一括パース、および Undo/Redo ショートカット機能を提供します。なお、LLM連携機能（自動補完、サジェストなど）は別の PBI（REQ-016）にて扱います。

## 2. アーキテクチャ設計

### 2.1 フロントエンド（React + TypeScript）

#### 1. データ構造
チップの内部データ構造は以下の通り定義します：
```typescript
export type TagChip = {
  id: string;        // ドラッグ・再描画用のユニークなキー（UUIDまたはランダム文字列）
  text: string;      // タグ文字列（トリミング済み）
  enabled: boolean;  // 有効か無効（グレーアウト）か
};
```

#### 2. コンポーネント構成
`frontend/src/components/TagChipEditor/` 配下にコンポーネントを分割して実装します：
- `index.tsx`: メインラッパー（propsの受け取り、テキスト入力モードとのトグル、DnDコンテキストの設定など）。
- `TagChip.tsx`: 個別チップのUIとダブルクリック時インライン編集。
- `TagInput.tsx`: 新規タグ入力フィールド（カンマ・Enter/Tabキー、ペースト対応、空状態でのBackspace）。
- `useChipHistory.ts`: 独自に最大50件の Undo/Redo 履歴を保持するフック。
- `useChipParser.ts`: カンマ区切りのテキスト ↔ `TagChip[]` のパースと再構築を行うフック。
- `tagChipEditor.css`: ドラッグ中のスタイルや Tailwind CSS でカバーしにくいアニメーション等のスタイル。

#### 3. ドラッグ＆ドロップ (`@dnd-kit/sortable` & `@dnd-kit/core`)
- `@dnd-kit/core` および `@dnd-kit/sortable` を使用してチップの並び替えを実現します。
- `flex-wrap: wrap` によるグリッドに近いレイアウトになりますが、DOMの1次元のインデックス順序（左上から右下）に基づいて並び替えを行います。
- キーボード操作（Spaceでドラッグ開始、左右アローキーで移動、Spaceで決定）もアクセシビリティ対応としてサポートします。

#### 4. Undo / Redo の履歴管理
- `useChipHistory.ts` を用いて、追加・削除・トグル・並び替え・編集のアクションが発生するたびにスナップショットを最大50件保存します。
- ショートカットキー (`Ctrl+Z`, `Ctrl+Shift+Z` / `Ctrl+Y`) を検出し、履歴の巻き戻し・やり直しを行います。

#### 5. スマホ（モバイル）表示での制御
- `window.location.pathname.startsWith('/mobile')` または画面幅が `1024px` 未満（デスクトップサイズ未満）の場合は、アクセビリティと入力のしやすさを優先し、従来通り `textarea` 表示のまま維持します。

## 3. UI/UX デザイン設計

### 3-1. チップの外観

- **有効チップ (Enabled)**:
  - 背景色: `#1f1f25` (surface-2)
  - ボーダー: `border-[rgba(255,255,255,0.08)]`
  - 文字色: `#e0e0e8` (text-primary)
  - ホバー時、ドラッグ可能な `grab` カーソルを表示。

- **無効チップ (Disabled/Grayed Out)**:
  - 背景色: `#18181c` (surface)
  - ボーダー: `border-[rgba(255,255,255,0.05)]`
  - 文字色: `rgba(255,255,255,0.3)` (text-mutedに近い、透過)
  - 文字に取り消し線 (`line-through`) を適用。

### 3-2. 操作とインタラクション

- **クリック**: チップのテキスト部分をクリックすると、有効 ↔ 無効がトグルします。
- **削除ボタン (×)**: クリックすると即座にチップが削除されます。ホバー時に強調されます。
- **ダブルクリック**: インラインで入力欄化し、Enter/Tab/フォーカスアウトで編集確定、Escapeでキャンセル。空文字確定時は削除。
- **新規タグ入力**: カンマまたは Enter / Tab で確定し、新しいチップが生成されます。カンマ区切りテキストをペーストした場合は、自動的に複数チップに分割されます。
- **エスケープハッチ (テキスト入力モード)**:
  - 右上に「テキスト入力モードに切替」ボタンを表示し、従来のテキストエリア表示に戻せるようにします。
  - テキストエリアに戻す際は、現在有効なチップのみを `, ` で連結した文字列が初期値になります。無効なチップは破棄されます。
  - 再び「チップモードに切替」を押すと、テキストエリアの内容をパースしてチップ化します。

## 4. サジェスション機能との連携
- **干渉タグ診断結果との連携**:
  - `suggestedDisables` props を受け取り、干渉したタグの無効化指示があった場合、該当タグを削除するのではなく `enabled: false` に更新します。
- **語彙サジェスト結果との連携**:
  - `suggestedAdds` props を受け取り、追加指示があった場合に重複がない限り末尾に追加します（冪等性担保）。

---

## 5. アクセシビリティ設計
- `role="listbox"`, `role="option"`, `aria-selected` など適切なARIA属性を付与。
- チップに対して `tabIndex={0}` を設定し、キーボードフォーカスを可能にします。
- フォーカス中に `Delete` / `Backspace` で削除、`Space` でトグルを実行します。
- ドラッグハンドル部分には `aria-roledescription="ドラッグで並び替え可能"` およびツールチップを表示します。
