# PBI-REQ-188 テスト計画書: セリフ編集のパス軌道およびスケール変化カーブの不具合修正

## 1. 自動テスト計画 (Automated Tests)

### 1.1 フロントエンド単体テスト (Frontend Unit Tests)
- **対象ファイル**:
  - `frontend/src/utils/__tests__/speechBubbleRenderer.test.ts`
  - `frontend/src/components/__tests__/SpeechBubbleControls.test.tsx`
- **テストケース**:
  1. **パス制御点同期と縦書き/横書き対応**:
     - `getDefaultPathPoints` が各プリセット（line, arc, wave, stepped）に対して縦書き・横書きで適切な点数・座標を返すことの検証。
     - `calculateCharacterTransform` において、縦書き吹き出しで `line` や `stepped` を指定した際、縦方向の座標および接線角度が返ることの検証。
  2. **パス反転計算（`flipPathPoints` & `handleFlipPath`）**:
     - 縦書き時のX軸ミラーリング（$x' = 1.0 - x$）および横書き時のY軸ミラーリング（$y' = 1.0 - y$）の検証。
     - `SpeechBubbleControls` で「パス反転 ⇄」を押下した際、`pathPoints` が正しく更新されることの検証。
  3. **可変文字送り（Proportional Character Advancement）**:
     - `scaleCurve`（`linear` 等）適用時、拡大文字（scale > 1.0）の後続文字が重ならずにシフトし、縮小文字（scale < 1.0）が過剰に空隙を開けずに配置されることの検証。
  4. **パス軌道における弧長ベース配置と縦書きグリフ置換**:
     - ベジェ曲線上で文字サイズおよび `letterSpacing` に応じた文字配置が行われることの検証。
     - 縦書きパス配置時に `verticalCharMap`（`ー` → `｜` 等）が適用されることの検証。
- **実行コマンド**:
  ```bash
  npm --prefix frontend test -- speechBubbleRenderer.test.ts SpeechBubbleControls.test.tsx
  ```

## 2. 手動検証計画 (Manual Verification Plan)

### 2.1 シナリオ 1: 縦書き吹き出しにおける全軌道タイプの配置検証 (AC-1, AC-5)
1. 吹き出し編集モーダルを開き、文字方向を「縦書き」に設定する。
2. テキストに「あーい！う」と入力する。
3. 漫画演出セクションを開き、軌道タイプを順に切り替える：
   - 「直線（2制御点）」: 上から下へ垂直に配置されること。
   - 「階段（2制御点）」: 上から下へ階段状に配置され、文字同士が重ならないこと。
   - 「円弧・アーチ（3制御点）」: 縦方向の弧に沿って配置されること。
   - 「S字波（4制御点）」: 縦方向の波に沿って配置されること。
4. 長音符「ー」が縦書き用の縦棒「｜」として表示されることを確認する。

### 2.2 シナリオ 2: パス反転の動作検証 (AC-2)
1. 軌道タイプ「円弧」を選択する。
2. 「パス反転 ⇄」ボタンを押下する。
3. **期待結果**:
   - プレビュー上で円弧の膨らみ方向が反転すること（縦書きなら左右反転、横書きなら上下反転）。
4. 「S字波」および「階段」でも同様に「パス反転 ⇄」を押下し、波・階段の傾き方向が反転することを確認する。

### 2.3 シナリオ 3: スケール変化カーブと字間ギャップの調整検証 (AC-3, AC-4)
1. スケール変化カーブで `linear`（線形）を選択する。
2. 開始倍率 `scaleStart` を 2.0、終了倍率 `scaleEnd` を 0.5 に設定する。
3. **期待結果**:
   - 先頭の大きな文字と後続の文字が重ならず、自然な文字間隔で配置されること。
   - 末尾の小さな文字との間隔が不自然に空きすぎないこと。
4. 文字間隔（`letterSpacing`）スライダーを動かし、パス軌道・スケール変化時にも均等に文字間が広がる・狭まることを確認する。
