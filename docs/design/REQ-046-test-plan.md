# REQ-046 テスト計画書

## 1. 自動テスト
本要件はフロントエンドのコンポーネント改修が主であるため、ビルドとリンターの正常終了をもって自動テストとします。

```bash
cd frontend
npm run build
npm run lint
```

## 2. 手動検証計画（マニュアルテスト）

### 2.1 生成画面メインプレビューからのフルサイズ表示検証
1. 生成画面で画像生成済み、または履歴画像が表示されている状態にする。
2. メインプレビュー画像エリアをクリックする。
3. 暗い半透明の背景を持つオーバーレイが画面全体に表示され、画像がアスペクト比を維持したままウィンドウの長辺いっぱいに拡大表示されることを確認する。
4. 右上の「閉じる」ボタンをクリックし、モーダルが閉じて元の画面に戻ることを確認する。
5. 再度モーダルを開き、左右の画像送りボタンをクリックして生成履歴の前後の画像に切り替えられることを確認する。

### 2.2 スナップショット一覧・アルバムからのフルサイズ表示検証
1. 履歴画面（スナップショット一覧またはアルバム詳細）を開く。
2. 任意の画像をクリックしてプレビューモーダルを開く。
3. デフォルトでメタ情報が表示されず、画像がウィンドウいっぱいのフルサイズで表示されることを確認する。
4. プレビュー右下に表示されている情報アイコン（Info）をクリックする。
5. 画像表示エリアが縮小され、下部にプロンプト・パラメータ等のメタ情報が表示されることを確認する（現行の「メタ情報表示＋縮小画像」モードへ切り替わること）。
6. メタ情報表示中に右下に表示される最大化アイコン（Maximize2）をクリックし、再びフルサイズ表示に戻ることを確認する。

### 2.3 タッチ操作（スワイプ）による画像送り検証
1. Chrome DevTools 等のデバイスエミュレーターでモバイル表示に切り替える。
2. プレビューモーダルを開く。
3. 画面を左右にスワイプし、前後の画像に切り替えられることを確認する。
