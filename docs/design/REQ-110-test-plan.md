## 3. ブラウザ検証 (Browser Agent Verification)
- **対象URL**: `http://localhost:5173/` (フロントエンド開発サーバー)
- **検証項目と操作手順**:
  1. **リロード時のプロファイル選択保持の確認**:
     - 生成画面を開き、複数のプロファイルタブ（例: "Set 1", "Set 2"）が表示されていることを確認する。
     - 二番目のプロファイル（"Set 2"）を選択してアクティブにする。
     - ブラウザをリロード（F5）する。
     - 期待値: リロード完了後、最初にロードされていた "Set 1" ではなく、リロード前にアクティブだった "Set 2" がアクティブな状態（タブがハイライトされ、そのパラメータ値が表示されている状態）で表示されること。
  2. **新規プロファイル作成時の自動オープン・アクティブ化確認**:
     - "Add Set" ボタンをクリックし、新しいプロファイル名（例: "New Profile Test"）を入力して作成する。
     - 期待値: 作成完了直後、新しく作成した "New Profile Test" タブが自動的に追加されてアクティブ（選択された）状態になり、入力パラメータの表示がその新規プロファイルのものに切り替わること。また、リロードしても "New Profile Test" のアクティブ状態が維持されること。
- **必須エビデンス**: `.gemini/evidence_req_110_verification.png` などの検証時スクリーンショット（開発完了時に取得）。
