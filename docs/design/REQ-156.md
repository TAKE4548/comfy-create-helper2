# REQ-156 詳細設計書: 生成画面の履歴複数選択時の画像追加に伴う選択ズレ不具合の修正

## 1. 概要 (Overview)
生成画面（GeneratePage）の履歴サムネイル一覧から複数選択（マルチセレクト）を行っている最中、または保存モーダル操作中に画像生成が完了して新たな画像が追加された際、選択していた画像の位置がずれて意図しない画像が選択・保存されてしまう不具合（REQ-156）の改修設計を定義します。

---

## 2. 影響分析・対象範囲 (Scope & SSoT Impact)

### 影響を受けるフロントエンドファイル
1. **`frontend/src/hooks/useMultiSelect.ts`** (MODIFY):
   - ジェネリクス `ID extends number | string = number` をサポートし、数値だけでなく画像URLなどの文字列IDでも複数選択を管理できるように拡張。
2. **`frontend/src/pages/GeneratePage/hooks/useGeneratePageState.ts`** (MODIFY):
   - `historyItems` の `id` を配列添字 `idx` から画像URL（`url`）に変更。
   - `useMultiSelect<string>` として画像URLの `Set<string>` で選択状態を管理。
   - 選択時プレビュー同期の `useEffect` で `sortedDisplayImages[lastId]` ではなく `lastUrl` を参照。
3. **`frontend/src/pages/GeneratePage/components/DesktopLayout.tsx` & `MobileLayout.tsx`** (MODIFY):
   - `getLongPressHandlers(img)`、`isSelected(img)`、`handleItemClick(img, e)` に配列インデックスではなく画像URL（`img`）を渡すよう修正。
4. **`frontend/src/pages/GeneratePage.tsx`** (MODIFY):
   - `onConfirm` 保存確定時のURL配列取得処理を、`[...selectedIds].map(idx => sortedDisplayImages[idx])` から `[...selectedIds]`（すでに画像URLの集合）に変更。
5. **テストファイル**:
   - `frontend/src/hooks/__tests__/useMultiSelect.test.ts` (文字列IDのテストケース追加)
   - `frontend/src/pages/GeneratePage/hooks/__tests__/useGeneratePageState.test.tsx` (URLによる複数選択テストの更新・検証)

### 3.2 `useGeneratePageState.ts` の履歴選択ロジック改修
#### 課題
`sortedDisplayImages.map((url, idx) => ({ id: idx, url }))` で動的な配列インデックスを渡しているため、新画像追加時にインデックスがシフトして選択がずれる。

#### 改修方針
```typescript
  const historyItems = useMemo(() => {
    return sortedDisplayImages.map((url) => ({ id: url, url }))
  }, [sortedDisplayImages])

  const {
    isMultiSelectMode,
    selectedIds,
    handleItemClick,
    getLongPressHandlers,
    isSelected,
    exitMultiSelectMode,
    selectAll,
    clearSelection,
  } = useMultiSelect<string>({ items: historyItems })
```

プレビュー同期の副作用：
```typescript
  useEffect(() => {
    if (isMultiSelectMode && selectedIds.size > 0) {
      const idsArray = Array.from(selectedIds);
      const lastUrl = idsArray[idsArray.length - 1];
      if (lastUrl && sortedDisplayImages.includes(lastUrl)) {
        if (lastUrl !== selectedImg) {
          setSelectedImg(lastUrl);
        }
      }
    }
  }, [selectedIds, isMultiSelectMode, sortedDisplayImages, selectedImg, setSelectedImg]);
```

## 4. トレードオフ・リスク評価 (Trade-off & Risk Disclosure)
- **URLの一意性**:
  - `sortedDisplayImages` に含まれる画像URLはクエリパラメータ（キャッシュバスターやタイムスタンプ `?t=...` 等）を含み、生成画像ごとに一意性が保証されている。
  - 同一URLの重複が存在しないため、画像URLをキーとして管理することによる副作用はない。
- **後方互換性**:
  - `useMultiSelect` のデフォルト型引数を `<ID extends number | string = number>` とすることで、他の数値IDベースのコンポーネント（プリセット一覧など）に対する破壊的変更を完全に防止。
