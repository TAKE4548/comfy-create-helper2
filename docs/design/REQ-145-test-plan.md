# REQ-145 テスト計画書: セリフ編集の修飾設定プリセット登録・再利用およびDB永続化機能

## 1. 概要 (Overview)
REQ-145 に対する自動テストおよび手動検証の計画書です。
バックエンドの DB 永続化・API エンドポイントのテスト、およびフロントエンドのプリセット操作（適用・新規保存・更新・削除）を網羅します。

---

## 2. 自動テスト計画 (Automated Test Plan)

### 2.1 バックエンドテスト (`backend/tests/test_speech_bubble_presets.py`)
実行コマンド:
```bash
pytest backend/tests/test_speech_bubble_presets.py -v
```

検証項目:
- **T-BE-1**: プリセットの新規作成（POST `/api/speech-bubble-presets`）が正常に 201 Created を返し、DB に登録されること。
- **T-BE-2**: 同一の名前を持つプリセットの作成が 400 Bad Request で拒絶されること。
- **T-BE-3**: プリセット一覧の取得（GET `/api/speech-bubble-presets`）で、`sort_order` 順に正しく全件取得できること。
- **T-BE-4**: 既存プリセットの更新（PUT `/api/speech-bubble-presets/{id}`）で、各スタイル項目および名前が正常に更新されること。
- **T-BE-5**: プリセットの削除（DELETE `/api/speech-bubble-presets/{id}`）で 204 No Content が返り、DB から削除されること。
- **T-BE-6**: 存在しない ID に対する PUT / DELETE が 404 Not Found を返すこと。

### 2.2 フロントエンドテスト (`frontend/src/components/__tests__/SpeechBubbleControls.test.tsx`)
実行コマンド:
```bash
cd frontend && npm test -- SpeechBubbleControls
```

検証項目:
- **T-FE-1**: 登録済みプリセット一覧が正しくボタン/バッジとしてレンダリングされること。
- **T-FE-2**: プリセットをクリックした際に、現在選択されている吹き出しの修飾プロパティ（文字色、背景色、枠線色、太さ、フォント、形状等）が一括更新されること。
- **T-FE-3**: 「＋ プリセット保存」から名前を入力して保存した際、API が呼び出され一覧が更新されること。
- **T-FE-4**: プリセット削除ボタンをクリックした際、API 削除リクエストが送信され一覧から除外されること。

### 2.3 フロントエンド型チェック・ビルド検証
実行コマンド:
```bash
cd frontend && npm run build
```

## 3. 手動検証シナリオ (Manual Verification Scenarios)

1. **プリセット保存とキャラ別使い分け**:
   - セリフ編集画面を開き、吹き出し A を選択して「ピンク背景、赤文字、角丸」に設定。
   - 「＋ プリセット保存」から「キャラA」という名前で保存。
   - 別の吹き出し B を作成し、「青背景、白文字、叫び」に設定して「キャラB」という名前で保存。
   - 吹き出し A を選択した状態で「キャラB」プリセットをクリックすると、吹き出し A の装飾が一瞬でキャラB設定に切り替わることを確認。
2. **ページリロード & デバイス間永続化**:
   - ブラウザをリロードして再度セリフ編集画面を開く。
   - 保存した「キャラA」「キャラB」のプリセットがそのまま一覧に表示され、即座に適用できることを確認。
3. **プリセットの更新・削除**:
   - 「キャラA」プリセットの装飾を少し変更して上書き更新できることを確認。
   - 不要になったプリセットの削除アイコンをクリックして削除できることを確認。
