# Test Plan: REQ-196 LoRA管理・タグセット管理の編集モーダルおよびサムネ操作の不具合改修

## 1. 概要 (Test Overview)
本テスト計画は、REQ-196におけるタグセット/LoRA編集モーダルのモバイル下部メニュー被り解消、編集項目の網羅性（Target Base Models, Subsets）、サムネイル操作アイコンのモバイル視認性、および候補画像サムネイル一覧（Related Snapshots）の表示・選択動作を検証するものである。

## 3. 手動テスト・検証シナリオ (Manual Verification)

### シナリオ 1: モバイル画面での編集モーダル操作（下部メニュー被り解消）
1. ブラウザの開発者ツールでモバイルビュー（例: iPhone 14 / 幅 390px）にする。
2. 「Tags」画面を開き、タグセットの編集モーダルを開く。
3. **合否判定基準**:
   - モーダルが下部ナビゲーションバーの前面に表示されること。
   - モーダル内をスクロールして「Save Changes」「Cancel」ボタンがはっきりと見え、タップ操作できること。
4. 「LoRAs」画面でも同様に編集・詳細モーダルを開き、保存・キャンセルボタンが操作できること。

### シナリオ 2: タグセット詳細モーダルからの編集項目の網羅性
1. 「Tags」画面で登録済みタグセットカードをクリックして詳細モーダルを開く。
2. 「Edit」ボタンを押下して編集モードにする。
3. **合否判定基準**:
   - 「Target Base Models」（チェックボックス一覧）が表示され、チェックの付け外しができること。
   - 「Subsets (バリエーション)」セクションが表示され、「+ Add Subset」による追加、サブセット名・タグの編集、削除ができること。
   - 「Save Changes」を押下して保存した際、詳細表示および一覧に更新内容が正しく反映されること。

### シナリオ 3: モバイル（タッチ）環境におけるサムネイル上アイコンの視認性
1. モバイルビュー（幅 < 1024px）で「LoRAs」および「Tags」画面を開く。
2. **合否判定基準**:
   - 各カードのサムネイル上にある編集・削除アイコンが非ホバー時でも視認できること。
   - ドラッグ並び替えハンドルと編集・削除アイコンが重ならず、それぞれのタップ領域が独立して機能すること。

### シナリオ 4: カバーサムネ設定時の候補画像サムネイル表示と選択
1. 複数のスナップショットが紐づくLoRAまたはタグセットの詳細/編集モーダルを開く。
2. **合否判定基準**:
   - 「Related Snapshots」の候補画像サムネイル一覧が表示されること。
   - 候補サムネイルをクリック/タップするとメインプレビューが切り替わり、「Set as Cover」でカバー画像として設定・保存できること。
   - モバイルビュー時でもプレビューと候補サムネイル一覧が縦スクロール等でアクセス可能であること。
