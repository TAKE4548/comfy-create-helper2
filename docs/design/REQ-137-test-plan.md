cd frontend && npm test -- src/components/__tests__/SpeechBubbleEditorModal.test.tsx --watchAll=false

### コンポーネント単体テスト設計
- `SpeechBubbleEditorModal.test.tsx`:
  1. レンダリングテスト: デフォルトでプレビュー・コントロールエリアが正しく描画されること。
  2. レスポンシブ/モバイルタブテスト: モバイル表示時のタブ切り替えボタン (`🖼️ プレビュー`, `⚙️ 編集設定`) のクリック動作によって対象エリアが正しく非表示/表示切り替えされること。

## 2. 手動テストシナリオ (Manual Verification Plan)

### シナリオ 1: モバイルビューポートでのレイアウト検証
1. ブラウザデベロッパーツールで画面幅を `375px`（iPhone SE等）に設定する。
2. 履歴ページのスナップショットから「セリフ編集・吹き出し追加」モーダルを開く。
3. **確認**: モーダルが画面外へはみ出さず、モバイル専用のタブ切替バー（`[🖼️ プレビュー]` / `[⚙️ 編集設定]`）が表示されること。
4. **確認**: 「編集設定」タブをクリックするとコントロールパネルが表示され、テキスト入力やカラーピッカーが正常に操作できること。

### シナリオ 2: タッチ操作による吹き出しドラッグ検証
1. モバイルビューポートまたは実機スマホにてキャンバス上の吹き出しをタッチドラッグ移動する。
2. **確認**: タッチ移動に伴い吹き出しが滑らかに追従・移動すること。

### シナリオ 3: デスクトップ表示の互換性検証
1. 画面幅を `1024px` 以上に戻す。
2. **確認**: タブ切替バーが非表示になり、従来通りの二列横並び（キャンバス＋コントロールパネル）で表示されること。
