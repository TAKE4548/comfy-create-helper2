# PBI-REQ-024 実行可能テスト計画

## 1. 静的・ビルド検証 (CLI Verification)
フロントエンド側の実装にシンタックスエラーやコンパイルエラーがないことを、リンターおよびビルドコマンドで検証します。

- **静的解析 (Linter)**:
  - コマンド: `cd frontend && npm run lint`
  - 期待値: 警告やエラーが出力されないこと。
- **型チェック・ビルド検証**:
  - コマンド: `cd frontend && npm run build`
  - 期待値: TypeScriptのコンパイルおよびViteビルドが正常に完了すること。

## 2. 起動・ネットワーク検証 (Startup Verification)
Vite開発サーバーが外部インターフェースから接続可能な状態で起動することを確認します。

- **確認手順**:
  1. `cd frontend && npm run dev` を実行。
  2. 出力されるコンソールログに、`Network:` アドレス（例: `http://192.168.x.x:5173/`）が表示されていることを確認する。

## 3. ブラウザ手動検証 (Manual Browser Verification)
スマホなどの外部デバイスまたはローカルブラウザから実際に接続し、疎通と機能を確認します。

- **対象URL**:
  - ローカルアクセス: `http://localhost:5173/`
  - 外部アクセス（ホストPCのIPアドレス）: `http://192.168.x.x:5173/` （実際のホストIP）
- **確認手順**:
  1. **バックエンド起動**: FastAPIバックエンドをポート `8000` で、ComfyUIをポート `8188` でそれぞれ起動する。
  2. **ローカル疎通検証**:
     - `http://localhost:5173/` にアクセス。
     - 開発ツールでワークフロー一覧などのAPI疎通が正常に行われていることを確認。
     - Settings 画面にて、FastAPI Backend (`http://localhost:5173/health` 経由) と ComfyUI (`http://localhost:5173/comfy` 経由) の Connection Status の Ping をクリックし、双方が **ok (Green)** になることを確認する。
  3. **外部疎通検証（スマホ等）**:
     - ホストPCと同じローカルネットワークに接続された外部デバイス（スマートフォン等）から `http://192.168.x.x:5173/` にアクセスする。
     - フロントエンドが正常にロードされ、ワークフロー一覧やLoRA一覧が正しく表示されることを確認する（AC-2）。
     - Settings 画面にて両接続が **ok (Green)** になることを確認。
  4. **WebSocket/生成機能検証**:
     - 外部デバイスの画面から生成処理（Queue Prompt）をトリガーする。
     - WebSocket接続経由で進捗（1%〜100%）がリアルタイムに更新されることを確認する。
     - 生成完了後、プレビュー画像が外部デバイス上でも正しく表示されることを確認する（AC-3）。

## 4. 必須エビデンス
1. `npm run build` が正常終了したことを示すコンソール出力のログ。
2. Vite起動時の `Network: http://192.168.x.x:5173/` の出力ログ。
3. 外部デバイス（またはそのシミュレーション）で、Settings 画面の Connection Status が **両方 ok** になっている画面のスクリーンショット。
4. 外部デバイスで **画像が正常に生成・表示された状態** のスクリーンショット。
