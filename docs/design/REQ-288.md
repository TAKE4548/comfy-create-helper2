## 3. バックエンド詳細設計

### 3-1. `backend/app/services/resource_monitor.py` (NEW)

```python
class ResourceMonitorService:
    _interval: float = 2.5
    _task: asyncio.Task | None

    async def start(self, broadcast_fn: Callable) -> None: ...
    async def stop(self) -> None: ...
    async def _collect(self) -> SystemStatsData: ...
    async def _get_gpu_stats(self) -> tuple[float|None, float|None, float|None, float|None]: ...
```

- `psutil.cpu_percent(interval=None)` + `psutil.virtual_memory()`
- `rocm-smi --showmeminfo vram --json` subprocess (AMD SMI)
- AMD SMI 取得不可 → GPU フィールドを `null` で返す

### 3-2. `backend/app/routers/ws.py` (NEW)

```python
router = APIRouter(prefix="/api", tags=["websocket"])

class ConnectionManager:
    active_connections: list[WebSocket]
    async def connect(ws) / disconnect(ws) / broadcast(msg) -> None

manager = ConnectionManager()

@router.websocket("/ws")
async def ws_endpoint(websocket: WebSocket):
    await manager.connect(websocket)
    try:
        while True:
            await asyncio.wait_for(websocket.receive_text(), timeout=30.0)
    except (WebSocketDisconnect, asyncio.TimeoutError):
        manager.disconnect(websocket)
```

### 3-3. `backend/app/main.py` 変更点

- import `ws` router + `ResourceMonitorService`
- lifespan: `await resource_monitor.start(manager.broadcast)`
- lifespan cleanup: `await resource_monitor.stop()`
- `app.include_router(ws.router)` 追加

## 5. 疎結合設計の保証

| 接続先 | サービス | 独立性 |
|-------|---------|--------|
| `ws://[comfyURL]/ws` | `comfyWsService` | ComfyUI生成制御 |
| `ws://[backendURL]/api/ws` | `systemWsService` | リソースHUD専用 |

2つの WebSocket 接続は別サービスクラス・別Zustandスライスで完全分離。

## 6. AMD GPU フォールバック戦略

```
rocm-smi subprocess
    ↓ 成功 → JSON parse → GPU/VRAM データ抽出
    ↓ 失敗 (FileNotFoundError / timeout / parse error)
    → gpu_pct=null, vram_*=null
    → UI 表示: "--"
```
