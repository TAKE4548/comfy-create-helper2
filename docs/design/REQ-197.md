# REQ-197: サムネイルのアスペクト比設定およびパン・ズームクロップ調整機能 詳細設計書

## 1. 概要 (Overview)

生成AIによる出力画像は縦長（3:4, 2:3, 9:16など）が多く利用されるが、現状のアプリケーション全体（LoRA一覧、タグセット一覧、履歴/スナップショット一覧、モーダル等）のサムネイル表示は正方形（1:1, `aspect-square`）に固定されている。
本設計では以下の2点を実現し、ユーザーの意図した構図でのサムネイル閲覧・編集を可能にする。

1. **サムネイル標準アスペクト比のグローバル設定機能**:
   - 設定画面（SettingsPage）にサムネイルのアスペクト比設定セクションを追加。
   - ComfyUI等で一般的に利用される代表的なアスペクト比プリセット（`1:1`, `3:4`, `4:3`, `2:3`, `3:2`, `9:16`, `16:9`）の選択、および任意のカスタム比率入力（`W:H` 形式、例: `5:7`, `7:9` 等）を可能にする。
   - アプリケーション全体のサムネイル表示（LoRA、タグセット、履歴/スナップショット、詳細モーダル、画像選択モーダル等）を設定されたアスペクト比に連動して動的に切り替える。
2. **インタラクティブなパン＆ズーム クロップ調整機能**:
   - カバー画像設定時（画像アップロード時、または既存カバー画像/候補スナップショットの「クロップ調整」時）に `ImageCropper` モーダルを起動。
   - 設定されたアスペクト比に基づき、ドラッグ＆ドロップ（パン移動）およびホイール/スライダー（ズーム）でトリミング範囲を直感的に調整して保存・反映できるようにする。

## 3. 詳細実装仕様 (Implementation Details)

### 3.1 アスペクト比ユーティリティ・Hook設計 (`frontend/src/utils/aspectRatio.ts`, `frontend/src/hooks/useThumbnailAspectRatio.ts`)

#### 1) プリセット定義 (`ASPECT_RATIO_PRESETS`)
```ts
export interface AspectRatioPreset {
  id: string
  label: string
  ratioStr: string // e.g. "3 / 4"
  numericRatio: number // width / height (e.g. 0.75)
}

export const ASPECT_RATIO_PRESETS: AspectRatioPreset[] = [
  { id: '1:1', label: '1:1 (正方形)', ratioStr: '1 / 1', numericRatio: 1 },
  { id: '3:4', label: '3:4 (縦長・標準)', ratioStr: '3 / 4', numericRatio: 3 / 4 },
  { id: '4:3', label: '4:3 (横長・標準)', ratioStr: '4 / 3', numericRatio: 4 / 3 },
  { id: '2:3', label: '2:3 (縦長・写真)', ratioStr: '2 / 3', numericRatio: 2 / 3 },
  { id: '3:2', label: '3:2 (横長・写真)', ratioStr: '3 / 2', numericRatio: 3 / 2 },
  { id: '9:16', label: '9:16 (縦長・スマホ)', ratioStr: '9 / 16', numericRatio: 9 / 16 },
  { id: '16:9', label: '16:9 (横長・ワイド)', ratioStr: '16 / 9', numericRatio: 16 / 9 },
  { id: 'custom', label: 'カスタム入力', ratioStr: '', numericRatio: 1 },
]
```

#### 2) カスタム比率パース (`parseAspectRatio`)
- 入力文字列（例: `"5:7"`, `"5/7"`, `"0.714"` 等）を安全にパースし、有効な `numericRatio` (width / height) と CSS `aspectRatio` 文字列（例: `"5 / 7"`）を生成。
- 不正値・0以下の場合はデフォルトの `3 / 4` (0.75) にフォールバック。

#### 3) `useThumbnailAspectRatio` Hook
- `localStorage` の `LS_KEYS.THUMBNAIL_ASPECT_RATIO`（デフォルト: `'3:4'`）と `LS_KEYS.THUMBNAIL_ASPECT_RATIO_CUSTOM` を購読。
- 設定変更時にカスタムイベント（`window.dispatchEvent(new Event('thumbnail-aspect-ratio-changed'))`）等を発火し、ページ遷移なしで即座にアプリ全体の表示を同期更新。
- 戻り値:
  - `presetId`: string
  - `customRatio`: string
  - `aspectRatioStyle`: CSSProperties (例: `{ aspectRatio: '3 / 4' }`)
  - `aspectRatioStr`: string (例: `'3 / 4'`)
  - `numericRatio`: number (例: `0.75`)
  - `setPreset(id: string)`: 設定保存
  - `setCustomRatio(ratio: string)`: カスタム設定保存

---

### 3.2 設定画面 UI 実装 (`frontend/src/pages/SettingsPage/components/ThumbnailSettingsSection.tsx`)
- `SettingsPage.tsx` に「サムネイル表示設定（Thumbnail Appearance）」セクションを追加。
- プリセット選択ボタン一覧（1:1, 3:4, 4:3, 2:3, 3:2, 9:16, 16:9, カスタム）。
- カスタム選択時のテキスト入力フィールド（`W:H` 形式、プレースホルダー: `例: 5:7`）。
- リアルタイム・ライブプレビューカードを表示し、選択したアスペクト比でダミー枠がどのように表示されるかを視覚的に確認可能にする。

---

### 3.3 クロップエディタ改善 (`frontend/src/components/ImageCropper.tsx`)
- Props に `aspectRatio?: number` を受け取り、`react-easy-crop` の `aspect` に適用（デフォルトは `3/4` または渡された比率）。
- マウスドラッグによる位置（パン）移動、マウスホイールおよびズームスライダーによる拡大縮小（1x〜3x）。
- レスポンシブ対応（モバイル・デスクトップでの操作性確保、モーダル z-index 100 統一）。
- クロップ確定時に高解像度 Canvas でトリミング画像を生成し、JPEG Blob としてコールバック。

---

### 3.4 全体サムネイル表示への適用
以下のコンポーネントで固定の `aspect-square` を `style={aspectRatioStyle}` または動的アスペクト比クラスに置き換え:
1. `frontend/src/pages/LoRAsPage.tsx`: LoRAカードのサムネイル枠
2. `frontend/src/pages/TagsPage.tsx`: タグセットカードのサムネイル枠
3. `frontend/src/pages/HistoryPage.tsx`: スナップショットギャラリーカードのサムネイル枠
4. `frontend/src/components/LoraModals.tsx`: 詳細・編集モーダルのメインプレビュー枠、候補サムネイル枠
5. `frontend/src/components/TagSetModals.tsx`: 詳細・編集モーダルのメインプレビュー枠、候補サムネイル枠
6. `frontend/src/components/BaseImageSelectModal.tsx`: スナップショット選択モーダルのサムネイル枠

さらに、`LoraModals.tsx` および `TagSetModals.tsx` のカバー画像領域に「クロップ調整」ボタンを追加し、既に設定済みの画像や選択したスナップショットに対しても即座に再パン・ズーム調整を起動できるようにする。
