## 2. ブラウザ検証 (Browser Agent Verification)

### AC-1: 複数候補（duplicated）のドロップダウン動作
- **操作手順**:
  1. 生成ページ (`GeneratePage`) を開く。
  2. 新規ワークフローまたは既存ワークフローで、同じパターンのノードが複数存在する状態にしてスキャン／再スキャンを行う。
  3. マッピングモーダル（`UploadWorkflowModal` または `RescanModal`）が開いたことを確認する。
  4. 複数候補（ステータス：複数候補）となっている項目の入力欄をクリックする。
- **判定基準**:
  - 対象ノードIDの候補がすべてドロップダウン（datalist）に選択肢として表示されること。
  - 任意の候補を選択した際、入力欄にその値が反映されること。

### AC-2: 正常マッチ（ok）のドロップダウン動作
- **操作手順**:
  1. マッピングモーダルで、ステータスが `ok`（マッチ成功）になっている項目の入力欄をクリックする。
- **判定基準**:
  - マッチしたノードIDがドロップダウン候補に表示されること。
  - ドロップダウンからの選択、および別ノードIDの直接入力ができること。

### AC-3: 保存と適用
- **操作手順**:
  1. ドロップダウンから別のノードIDを選択、または新しいノードIDを直接入力し、「適用・保存」ボタンをクリックする。
  2. 再スキャンモーダルを閉じ、その設定が正しく反映されて保存されることを確認する。
- **判定基準**:
  - エラーなく保存が完了すること。
