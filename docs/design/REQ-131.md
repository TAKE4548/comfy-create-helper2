# Design Document: REQ-131 アルバムページでの複数選択画像の一括D&D順番入れ替え機能

## 1. Overview
アルバム詳細画面において、複数選択モード時に選択した画像をドラッグ＆ドロップ（D&D）操作で一括して並び替えられる機能を提供します。

## 2. Affected Components & Files
- `frontend/src/pages/HistoryPage.tsx`
  - D&D有効化条件の変更 (`isDndEnabled`)
  - `DragOverlay`における複数選択時の重ね合わせプレビュー表示の実装
  - `handleDragEnd`における一括並び替え挿入ロジックの修正
  - 並び替え後における選択状態の保持

## 3. Detailed Technical Design

### 3.1 D&D Enablement Condition
```typescript
const isDndEnabled = sortBy === 'custom' && !updateAlbumOrder.isPending
```
複数選択モード (`albumItemMultiSelect.isMultiSelectMode`) であるか否かにかかわらず、`sortBy === 'custom'` かつ `updateAlbumOrder.isPending` でない場合に D&D を有効化します。

### 3.2 Drag Overlay (Stacked Preview)
ドラッグ中 (`activeId` 存在時)、`albumItemMultiSelect.isMultiSelectMode` で選択数が2件以上かつ `activeId` が選択アイテムに含まれる場合、背景に重ね合わせたカード（2重〜3重のシャドウ・傾き・オフセット効果）および右下に選択件数バッジを表示します。

### 3.3 Bulk Reordering Logic in `handleDragEnd`
1. `active.id` と `over.id` が等しい、または `over` が存在しない場合は処理終了。
2. 複数選択モードかつ `active.id` が選択集合に含まれる場合：
   - 選択されたアイテム群 (`selectedItems`) と非選択アイテム群 (`nonSelectedItems`) に分類。
   - `over.id` が非選択群に含まれる場合：非選択群での `over.id` のインデックスの位置へ `selectedItems` を一括挿入。
   - `over.id` が選択群に含まれる場合：選択群自体が移動対象のため順序変更なし（必要に応じて非選択群との境界へ挿入）。
   - 単一選択状態または非選択アイテムをドラッグした場合：従来の単一アイテム移動ロジックを実行。
3. `updateAlbumOrder.mutate()` を実行（楽観的更新およびサーバー同期）。
4. ドロップ完了後、`albumItemMultiSelect.selectedIds` の選択状態は維持。

## 4. Acceptance Criteria Verification Strategy
- **AC-1**: D&D開始時に重ね合わせ風プレビューと件数バッジが表示されることを確認。
- **AC-2**: 選択されたアイテムが元の相対順序を保ってドラッグ先に移動することを確認。
- **AC-3**: ドロップ完了後も選択チェックボックスがONのままであることを確認。
- **AC-4**: ドロップ後、`updateAlbumOrder` 変異が走り並び順が保存・反映されることを確認。
