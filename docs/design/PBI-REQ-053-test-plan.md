## 3. ブラウザ検証 (Browser Agent Verification)
- **対象URL**: `http://localhost:5173`
- **確認項目1: 全画面表示でのクラッシュ解消 (AC-1)**
  - **手順**:
    1. 生成（Generate）または履歴（History）画面で画像をクリックし、`HistoryModalPreview` モーダルを開く。
  - **判定基準**:
    - 黒画面にならず、画像とスナップショットのメタデータが正常に表示されること。
    - 右上の「閉じる (X)」ボタンや、画像の背景エリアをクリックすることで、正常にモーダルを閉じることができること。
- **確認項目2: モバイル表示時のオーバーレイ解消 (AC-2)**
  - **手順**:
    1. Chrome DevTools などのデバイスエミュレータを使用し、画面幅を 1024px 未満（モバイル表示）にする。
    2. 生成および履歴画面でページ最下部までスクロールする。
  - **判定基準**:
    - ページの最下部コンテンツが、下部メニューバーに覆われることなく表示され、すべてのボタンやインプットがクリック・操作可能であること。
- **必須エビデンス**:
  - デスクトップ表示での画像プレビュー表示時のスクリーンショット。
  - モバイル表示での最下部スクロール時のスクリーンショット。
