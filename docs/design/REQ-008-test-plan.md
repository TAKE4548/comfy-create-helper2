# PBI-REQ-008 実行可能テスト計画

## 1. 自動テスト (CLI Verification)
FastAPI のテストコードを追加し、`/api/config` エンドポイントが環境変数で指定された `COMFY_URL` を正しく返却することを確認する。

- **事前準備**: `backend/.env` に `COMFY_URL=http://localhost:8188` が記述されていることを確認する。
- **コマンド**: `python -m unittest backend/tests/test_config.py -v`
- **期待値**: 
  - テスト出力に `test_... ... OK` と表示されること。
  - 全テストケースの失敗数 (Failures) が 0 であること。

## 2. ツール主導監査 (Tool‑Driven Audit)
### 2‑1. API 検証
- **コマンド**: `curl -s http://localhost:8000/api/config`
- **期待値**: HTTP ステータス 200、レスポンス JSON に `comfy_url` が `http://127.0.0.1:8188`（IP 置換後）または設定値として含まれること。

### 2‑2. コード構造監査
- **コマンド**: `pylint backend/app/main.py --errors-only`
- **期待値**: 出力に `E0602` (未定義変数) や `W0603` (グローバルステート汚染) が含まれず、`Your code has been rated at 10.00/10` のように 10/10 以上のスコアが得られること。
- **エビデンス**: コマンド実行画面のスクリーンショットを保存する。

## 3. ブラウザ検証 (Manual & Browser Verification)
- **対象 URL**: `http://localhost:5173/` (フロントエンド) および `http://localhost:5173/settings` (設定ページ)
- **確認手順**:
  1. **環境同期**: `backend/.env` の `COMFY_URL` が `http://localhost:8188` であることを再確認し、必要に応じて修正する。
  2. **接続設定確認**: 設定画面の `Connections` セクションで ComfyUI の URL が `http://127.0.0.1:8188` に置換されて表示されていることを確認する。
  3. **Ping テスト**: 「Ping」ボタンをクリックし、ステータスが **ok (Green)** になるまで待機する。コンソールに `WebSocket connection established` のログが出力されていることを確認する。
  4. **生成テスト**: 生成ページで画像生成をトリガーし、次の項目を検証する。
     - コンソールに `ws://localhost:8188` へのエラーメッセージが **出ていない**（代わりに `ws://127.0.0.1:8188` への接続成功ログがある）。
     - プログレスバーが **1% から 100%** まで正常に更新される。
     - 生成完了後、プレビュー画像および生成された画像が画面に正しく表示される。

## 4. 必須エビデンス
1. `pylint` 実行結果（エラーなし）のスクリーンショット。
2. ブラウザコンソールに **WebSocket 接続成功** ログが表示されている状態のスクリーンショット。
3. 設定画面で **Ping が Green** になることを示すスクリーンショット。
4. 生成完了後に **画像が表示されている** ことを示すスクリーンショット（2 枚）。

**改善ポイント**
- ツール主導監査で具体的な静的解析コマンド (`pylint`) を明示し、AI が結果を捏造できないようにした。
- 環境設定の `.env` 確認手順を追加し、設定漏れを防止。
- WebSocket エラー否定テストを **成功ログ** と **エラーログが無いこと** の両方で判定するようにした。

この修正版テスト計画を用いて、再度 `qa‑audit` を実行すれば全項目が ✅ になるはずです。
