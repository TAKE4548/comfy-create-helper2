# REQ-133 詳細設計書: REQ-132のWebP化に伴うLoRA/TagSetカバー画像パスの不整合修正

## 1. 概要 (Overview)
REQ-132にて導入された画像WebP変換マイグレーション処理 (`backend/scripts/migrate_images_to_webp.py`) は、`Snapshot` モデルの `image_path` および `thumbnail_path` のみを更新していました。
しかし、`Lora` モデルおよび `TagSet` モデルの `thumbnail_path` カラムにも明示的なカバー画像パス（例: `/api/snapshots/images/snapshot_xxx.png`）が保持されているケースがあり、元ファイルがWebP化・削除されたことでフロントエンド表示において404エラー（リンク切れ）が発生していました。

本設計では、`migrate_images_to_webp.py` スクリプトを拡張し、`Lora` および `TagSet` テーブルに保存されている旧拡張子 (`.png`, `.jpg`, `.jpeg`) の `thumbnail_path` を自動的に `.webp` 形式のパスへと一括変換・更新する仕組みを構築します。

---

## 2. 影響分析・対象範囲 (Scope & SSoT Impact)

### 影響を受けるコンポーネント・ファイル

- **テストコード**: `backend/tests/test_migrate_images_to_webp.py`

- `models.TagSet`: `thumbnail_path` (Optional[str])

## 3. 詳細ロジック設計 (Detailed Logic Design)

### 3.1 `backend/scripts/migrate_images_to_webp.py` の改修方針

マイグレーション関数 `migrate_images()` 内で以下の追加処理を実行する。

1. **パス変換ヘルパー関数の定義**:
   ```python
   def _update_path_to_webp(path_str: str | None) -> str | None:
       if not path_str:
           return path_str
       lower_path = path_str.lower()
       for old_ext in [".png", ".jpg", ".jpeg"]:
           if lower_path.endswith(old_ext):
               return path_str[:-len(old_ext)] + ".webp"
       return path_str
   ```

2. **Snapshot の処理**:
   既存の Snapshot 変換ロジック（画像WebP化・サムネイル作成・DBパス更新）を維持。

3. **Lora.thumbnail_path の一括更新**:
   ```python
   loras = db.query(models.Lora).all()
   for lora in loras:
       if lora.thumbnail_path:
           new_path = _update_path_to_webp(lora.thumbnail_path)
           if new_path != lora.thumbnail_path:
               lora.thumbnail_path = new_path
               migrated_count += 1
   ```

4. **TagSet.thumbnail_path の一括更新**:
   ```python
   tag_sets = db.query(models.TagSet).all()
   for ts in tag_sets:
       if ts.thumbnail_path:
           new_path = _update_path_to_webp(ts.thumbnail_path)
           if new_path != ts.thumbnail_path:
               ts.thumbnail_path = new_path
               migrated_count += 1
   ```

## 4. 課題・リスクおよびトレードオフ (Trade-offs & Risks)

- **リスク**: 既に存在しない・またはWebP化対象外の外部URL等の `thumbnail_path` が誤って `.webp` に変換されるリスク。
- **対策**: パス文字列が `.png`, `.jpg`, `.jpeg` で終わっている場合のみ `.webp` に書き換える。また、マイグレーション処理は冪等（何度実行しても結果が変わらない）に設計する。
