# REQ-171 詳細設計書: 縦書きセリフにおけるパス軌道レイアウトの縦方向追従および接線回転補正

## 1. 概要 (Overview)
REQ-168で導入された漫画テキスト演出パラメータ（`MangaTextEffectConfig`）の「パス・軌道レイアウト（`pathPreset`）」機能において、縦書きセリフ（`bubble.orientation === 'vertical'`）が指定された場合に、文字が上から下への進行軌道として配置されず横書き軌道（左から右）で配置される不具合を解消する。
本設計では、セリフの組み方向（`orientation`）に応じて適切なパスデフォルト制御点（`getDefaultPathPoints`）を算出し、縦書き時の上から下への進行ベクトルに合わせた文字座標・接線回転角（`tangentAngle`）の補正を行う。

---

## 2. アーキテクチャと詳細ロジック設計 (Architecture & Logic Design)

### 2.1 組み方向に応じたデフォルト制御点の定義 (`getDefaultPathPoints`)
`frontend/src/utils/speechBubbleRenderer.ts` において、`bubble.orientation`（`vertical` / `horizontal`）および `pathPreset` に応じたデフォルト制御点を返す関数を定義する。

```typescript
export function getDefaultPathPoints(
  preset: PathPresetType,
  orientation: TextOrientation = 'horizontal'
): PathPoint[] {
  const isVertical = orientation === 'vertical'
  switch (preset) {
    case 'line':
      return isVertical
        ? [
            { x: 0.5, y: 0.1 },
            { x: 0.5, y: 0.9 },
          ]
        : [
            { x: 0.1, y: 0.5 },
            { x: 0.9, y: 0.5 },
          ]
    case 'arc':
      return isVertical
        ? [
            { x: 0.7, y: 0.1 },
            { x: 0.3, y: 0.5 },
            { x: 0.7, y: 0.9 },
          ]
        : [
            { x: 0.1, y: 0.7 },
            { x: 0.5, y: 0.3 },
            { x: 0.9, y: 0.7 },
          ]
    case 'wave':
      return isVertical
        ? [
            { x: 0.5, y: 0.1 },
            { x: 0.2, y: 0.35 },
            { x: 0.8, y: 0.65 },
            { x: 0.5, y: 0.9 },
          ]
        : [
            { x: 0.1, y: 0.5 },
            { x: 0.35, y: 0.2 },
            { x: 0.65, y: 0.8 },
            { x: 0.9, y: 0.5 },
          ]
    case 'stepped':
      return isVertical
        ? [
            { x: 0.7, y: 0.1 },
            { x: 0.3, y: 0.9 },
          ]
        : [
            { x: 0.1, y: 0.2 },
            { x: 0.9, y: 0.8 },
          ]
    default:
      return []
  }
}
```

### 2.2 制御点の解決ロジック (`calculateCharacterTransform`)
- ユーザー指定の `fx.pathPoints` が存在し、各プリセットで必要な点数（line: 2, arc: 3, wave: 4, stepped: 2）を満たしている場合は指定された `fx.pathPoints` を使用する。
- 未指定または点数不足の場合は、`getDefaultPathPoints(fx.pathPreset, bubble.orientation)` から取得した制御点を使用する。

### 2.3 パス接線回転角（`tangentAngle`）の縦書き補正
- **横書き（horizontal）**: 水平右方向（$\theta = 0$）がテキスト進行方向の基準。
  `tangentAngle = Math.atan2(dy, dx)` をそのまま文字回転角に加算。
- **縦書き（vertical）**: 垂直下方向（$\theta = +\pi/2$、90度）がテキスト進行方向の基準。
  縦書き時は、文字自体が元々上から下に向かって配置されるため、パスの進行ベクトルに対する文字の傾きは下向き基準（$\theta - \pi/2$）となる。
  ```typescript
  let rot = trans.rotateRad
  if (fx?.pathFollowRotation && trans.pathPos) {
    if (bubble.orientation === 'vertical') {
      rot += (trans.pathPos.tangentAngle - Math.PI / 2)
    } else {
      rot += trans.pathPos.tangentAngle
    }
  }
  ```

## 4. トレードオフおよびリスク開示 (Trade-offs & Risks)

- **ユーザー指定のカスタム制御点との関係**:
  ユーザーが明示的に `pathPoints`（絶対座標・相対値）をカスタム入力している場合、その座標が優先される。`bubble.orientation` を縦/横で切り替えた際に `pathPoints` が未変更のままであれば、UIコントロール側でプリセット再選択時に適切なデフォルト点に更新されるか、レンダラーがデフォルト点と一致する場合に自動追従する設計とする。
