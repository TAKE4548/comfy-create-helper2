# 設計書: REQ-035 シード値ランダム設定バグの修正

## 1. 概要
生成ページ（GeneratePage）で画像生成を実行する際、シード設定が「Shuffle」（ランダムモード）に設定されていても、送信されるシード値がランダムにならずに固定値のままになる問題を修正します。

## 2. 影響範囲と依存関係
- **影響ファイル**: `frontend/src/pages/GeneratePage/hooks/useGenerateAction.ts`
- **対象ロール**: `Sampler_Seed`（画像生成ワークフローのシードノード）

## 3. 詳細設計
[useGenerateAction.ts](../../frontend/src/pages/GeneratePage/hooks/useGenerateAction.ts) 内のシード注入ロジックを修正します。

### 修正前
```typescript
      const seedNode = workflow.mappings.find((m) => m.role === 'Sampler_Seed')
      if (seedNode) {
        const node = wfJson[seedNode.node_id] as Record<string, unknown> | undefined
        if (node) {
          const inputs = node.inputs as Record<string, unknown>
          inputs['seed'] = seedMode === 'random' ? Math.floor(Math.random() * 2 ** 32) : seed + i
        }
      }
```

### 修正後
シードノードがプリミティブノードなどの場合に、パラメータ名が `'seed'` ではなく `'value'` になっているケースに対応するため、一般的なパラメータマッピング処理と同様に動的キー解決ロジックを導入します。

```typescript
      const seedNode = workflow.mappings.find((m) => m.role === 'Sampler_Seed')
      if (seedNode) {
        const node = wfJson[seedNode.node_id] as Record<string, unknown> | undefined
        if (node) {
          const inputs = node.inputs as Record<string, unknown>
          // パラメータ名が直接存在すればそれを使用し、なければ 'value' キーへのフォールバック等を行う
          const targetKey =
            inputs[seedNode.param_name] !== undefined
              ? seedNode.param_name
              : inputs['value'] !== undefined
              ? 'value'
              : seedNode.param_name
          
          inputs[targetKey] = seedMode === 'random' ? Math.floor(Math.random() * 2 ** 32) : seed + i
        }
      }
```

これにより、マッピング先のノード構造に関わらず、正しいパラメータキーにランダム化（または固定＋インクリメント）されたシード値が代入されるようになります。
