# Test Plan: REQ-066 アプリ全体の長押し感度設定機能の追加

## 1. 自動テスト
`frontend/src/hooks/__tests__/useMultiSelect.test.ts` に、`localStorage` の設定値（長押し時間）を読み込んで正しく動作するかのテストを追加します。

### 実行コマンド
```bash
npm --prefix frontend run test src/hooks/__tests__/useMultiSelect.test.ts
```

## 2. 手動テスト
設定画面で長押し感度の値を変更し、各機能に適用されるか確認します。

### 2-1. 履歴の複数選択モードへの遷移
- 設定画面（`SettingsPage`）で「履歴 of 複数選択長押し判定時間」を `2.0`秒 に設定する。
- 履歴画面（`HistoryPage`）に遷移し、アイテム（スナップショットなど）を1秒間長押ししても複数選択モードに遷移**しない**ことを確認する。
- 同アイテムを2秒以上長押しした際に、複数選択モードに遷移することを確認する。
- 再度設定画面で「履歴の複数選択長押し判定時間」を `0.2`秒 に設定し、履歴画面で軽く長押ししただけで即座に複数選択モードに遷移することを確認する。

### 2-2. カード移動
- 設定画面で「カード移動の長押し判定時間」を `2.0`秒 に設定する。
- 履歴画面（アルバム詳細など並び替え可能な場所）、またはLoRA管理画面（`LoRAsPage`）、タグ管理画面（`TagsPage`）で、タッチドラッグ操作（スマホエミュレータを使用）を行い、長押しを2秒間維持しないとドラッグ移動が開始**しない**ことを確認する。
- 設定画面で「カード移動の長押し判定時間」を `0.2`秒 に設定し、軽くタッチしてスライドさせるだけでドラッグ移動が開始することを確認する。
