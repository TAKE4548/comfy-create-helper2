# テスト計画書: REQ-047

## 1. ビルド・静的解析の確認
修正後にフロントエンドプロジェクトが正常にビルド・型チェックをパスすることを確認します。

### 実行コマンド
```bash
npm run build
```

## 2. 手動結合テスト（進捗更新時のモーダル動作検証）
### 試験手順
1. ComfyUI を起動（またはモックサーバーを起動）し、フロントエンドの開発サーバー (`npm run dev`) を立ち上げ、ブラウザでアクセスします。
2. テキストプロンプトとワークフローを選択し、`Generate Batch` ボタンを押して画像生成を開始します。
3. 生成処理（数秒〜十数秒かかる処理）の実行中に、画面下部の `Save Snapshot` ボタン、または `Job Management`（キュー管理）ボタン、あるいはLoRA一覧のLoRAカードをクリックして設定モーダルを表示させます。
4. 進捗率（0% -> 20% -> 50%...）が更新される過程において、以下の項目を検証します。

### 期待される結果 (Acceptance Criteria)
- モーダルが点滅したり、再度開くアニメーションが走ったりしないこと。
- スナップショット保存モーダルなどのテキスト入力フィールドに入力した文字が、進捗更新によってリセットされず維持されること。
- 入力フィールドにフォーカスを当てている場合、進捗が更新されてもフォーカスが外れないこと。
