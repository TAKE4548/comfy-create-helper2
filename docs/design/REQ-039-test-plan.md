# 検証計画書: REQ-039 生成ジョブのキャンセル機能

## 1. 自動テスト（フロントエンド単体）
**目的**: ビルドプロセスおよび型チェックが正常に通ることを確認する。
**実行コマンド**:
```bash
cd frontend && npm run build
```
**判定基準**:
- [ ] エラーなくビルドが成功すること。

---

## 2. 手動検証（ブラウザによる確認手順）

### 事前準備
1. バックエンドおよびフロントエンド開発サーバーを起動する。
2. ブラウザで `http://localhost:5173/` にアクセスする。
3. 接続設定で正常に動作している ComfyUI の URL を設定する。

### 検証項目詳細

#### AC-1 & AC-2: ジョブ管理モーダルの表示と一覧表示
**操作手順**:
1. 画面上の進捗表示エリアにある「Queue: X」というラベルをクリックする。
2. ジョブ管理モーダルが表示されることを確認する。
3. 現在生成中のジョブがある場合、モーダル内に「生成中 (Running)」のジョブが表示されることを確認する。
4. キューに待機しているジョブがある場合、モーダル内に「待機中 (Pending)」のジョブが一覧表示されることを確認する。

**判定基準**:
- [ ] 「Queue: X」をクリックしたときにモーダルが開くか。
- [ ] 実行中のジョブが1件、および待機中のジョブが順序通りリスト表示されるか。

#### AC-3: 個別キャンセルアクションの動作
**操作手順**:
1. 適当なジョブを複数生成し、キューを溜める。
2. 待機中（Pending）の特定のジョブの右側にある「キャンセル (ゴミ箱/X)」ボタンをクリックする。
3. ComfyUIのキューおよび画面上の「Queue待機数」が1つ減ることを確認する。
4. 実行中（Running）のジョブの「キャンセル」ボタンをクリックする。
5. 即座に生成処理が中断され、画像生成の進捗表示がストップすることを確認する。

**判定基準**:
- [ ] 待機中ジョブの個別キャンセルによって、該当ジョブのみがキューから削除されるか。
- [ ] 実行中ジョブのキャンセルによって、ComfyUI の実行が即座に中断 (Interrupt) されるか。

#### AC-4: 一括キャンセルアクションの動作
**操作手順**:
1. 複数のジョブを生成してキューを蓄積する。
2. モーダル内の「一括キャンセル (Cancel All)」ボタンをクリックする。
3. 実行中のジョブおよび待機中の全てのジョブが同時にキャンセル・クリアされることを確認する。

**判定基準**:
- [ ] 一括キャンセル後に実行中ジョブが停止し、待機中ジョブがすべてクリアされるか。

#### AC-5 & AC-6: 履歴非保持と状態の即時更新
**操作手順**:
1. 個別キャンセルおよび一括キャンセルを行った後、生成履歴一覧（History タブなど）を確認する。
2. キャンセルしたジョブが履歴に登録されていないこと（画像やログが残っていないこと）を確認する。
3. モーダル内のジョブリストおよびメイン画面の「Queue待機数」が即座に `0` (または最新件数) にリセットされることを確認する。

**判定基準**:
- [ ] キャンセルされたジョブが履歴一覧に一切出現しないか。
- [ ] キャンセル実行後、画面上の待機数表示やステータスがタイムラグなく最新状態へ同期されるか。
