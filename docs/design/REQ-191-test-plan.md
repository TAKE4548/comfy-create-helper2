# REQ-191: anima特化モードに応じたタグチップ重み増減量の動的切り替え テスト計画書

## 1. 自動テスト計画 (Automated Unit & Integration Tests)

### 1.1 単体テスト (`frontend/src/components/TagChipEditor/__tests__/TagChip.test.tsx`)
1. **通常モード（デフォルト / `isAnimaMode: false`）**:
   - サブメニューを開いた際、ステップ増減ボタンとして `-0.3`, `-0.1`, `+0.1`, `+0.3` が表示されること。
   - `+0.1` 押下で重みが 1.0 ➔ 1.1 になること。
   - `+0.3` 押下で重みが 1.0 ➔ 1.3 になること。
   - `-0.1` 押下で重みが 1.0 ➔ 0.9 になること。
   - `-0.3` 押下で重みが 1.0 ➔ 0.7 になること。
2. **Anima特化モード（`isAnimaMode: true`）**:
   - サブメニューを開いた際、ステップ増減ボタンとして `-1.0`, `-0.5`, `+0.5`, `+1.0` が表示されること。
   - `+0.5` 押下で重みが 1.0 ➔ 1.5 になること。
   - `+1.0` 押下で重みが 1.0 ➔ 2.0 になること。
   - `-0.5` 押下で重みが 1.0 ➔ 0.5 になること。
   - `-1.0` 押下で重みが 1.0 ➔ 0 になること。

### 1.2 統合テスト (`frontend/src/components/TagChipEditor/__tests__/TagChipEditor.test.tsx`)
1. `TagChipEditor` に `isAnimaMode={true}` を与えた際、子コンポーネントの `TagChip` で Anima モード用の増減ステップが反映されること。
2. `isAnimaMode={false}` を与えた際、通常モード用の増減ステップが反映されること。

cd frontend

## 2. 手動検証シナリオ (Manual Verification Plan)

### シナリオ 1: 通常モードでのタグ重み増減
1. 生成画面を開く（Anima特化トグルがOFFの状態）。
2. プロンプト入力欄にタグを追加し、タグチップをクリックしてサブメニューを開く。
3. 増減ボタンが `-0.3`, `-0.1`, `+0.1`, `+0.3` となっていることを確認。
4. `+0.3` を押下し、タグが `(tag:1.3)` に更新されることを確認。

### シナリオ 2: Anima特化モードでのタグ重み増減
1. 生成画面の「Anima特化」トグルをONにする。
2. タグチップをクリックしてサブメニューを開く。
3. 増減ボタンが `-1.0`, `-0.5`, `+0.5`, `+1.0` に即座に切り替わっていることを確認。
4. `+0.5` を押下し、タグが `(tag:1.5)` に更新されることを確認。
5. トグルをOFFに戻し、再びサブメニューのボタンが `-0.3`, `-0.1`, `+0.1`, `+0.3` に戻ることを確認。
