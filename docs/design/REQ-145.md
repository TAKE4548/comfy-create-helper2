# REQ-145 詳細設計書: セリフ編集の修飾設定プリセット登録・再利用およびDB永続化機能

## 1. 概要 (Overview)

現在、セリフ編集画面（`SpeechBubbleEditorModal` / `SpeechBubbleControls`）では、吹き出しの修飾設定（形状、文字方向、フォント、フォントサイズ、文字色、背景色、枠線色、枠線幅）を個別に手動調整できます。また、直前に使用した設定は `localStorage` に保存（`loadLastUsedBubbleStyle` / `saveLastUsedBubbleStyle`）されます。

しかし、以下の課題があります：
1. **名前付きプリセットの保持不可**: 複数キャラクターのセリフ（例: キャラAはピンク背景・丸枠・特定フォント、キャラBは青背景・角丸・太枠）を頻繁に切り替えて入力する際、名前を付けた複数パターンのプリセットを保持・ワンクリックで呼び出すことができない。
2. **デバイス間・環境間での非同期**: 設定がローカルブラウザの `localStorage` に閉じており、別デバイスや別ブラウザから利用する際にプリセットが引き継がれない。

本設計では、セリフ修飾設定を名前付きでサーバー（SQLite DB）に永続化し、セリフ編集画面上で素早く登録・適用・更新・削除できるプリセット管理機能を実装します。

## 3. 詳細設計 (Detailed Design)

### 3.1 データベース設計 (`SpeechBubblePreset`)

テーブル名: `speech_bubble_presets`

| カラム名 | 型 | 制約 | 説明 |
|---|---|---|---|
| `id` | Integer | PK, AutoIncrement | プリセットID |
| `name` | String | NOT NULL, UNIQUE | プリセット表示名（例: "キャラA (標準)", "ナレーション"） |
| `shape` | String | NOT NULL, Default: 'oval' | 吹き出し形状 (`oval`, `rounded-rect`, `burst`, `cloud`, `none`) |
| `orientation` | String | NOT NULL, Default: 'vertical' | 文字方向 (`vertical`, `horizontal`) |
| `font_family` | String | NOT NULL, Default: 'sans-serif' | フォント名またはフォントファイル名 |
| `font_size` | Integer | NOT NULL, Default: 0 | フォントサイズ（0 = 自動フィット） |
| `text_color` | String | NOT NULL, Default: 'rgba(0, 0, 0, 1)' | 文字色 (RGBA文字列) |
| `background_color` | String | NOT NULL, Default: 'rgba(255, 255, 255, 0.95)' | 背景色 (RGBA文字列) |
| `border_color` | String | NOT NULL, Default: 'rgba(0, 0, 0, 1)' | 枠線色 (RGBA文字列) |
| `border_width` | Integer | NOT NULL, Default: 2 | 枠線幅 (px) |
| `sort_order` | Integer | NOT NULL, Default: 0 | 表示順序 |
| `created_at` | DateTime | NOT NULL, Default: UTC now | 作成日時 |

```python
class SpeechBubblePreset(Base):
    __tablename__ = "speech_bubble_presets"

    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    name: Mapped[str] = mapped_column(String, nullable=False, unique=True)
    shape: Mapped[str] = mapped_column(String, nullable=False, default="oval")
    orientation: Mapped[str] = mapped_column(String, nullable=False, default="vertical")
    font_family: Mapped[str] = mapped_column(String, nullable=False, default="sans-serif")
    font_size: Mapped[int] = mapped_column(Integer, nullable=False, default=0)
    text_color: Mapped[str] = mapped_column(String, nullable=False, default="rgba(0, 0, 0, 1)")
    background_color: Mapped[str] = mapped_column(String, nullable=False, default="rgba(255, 255, 255, 0.95)")
    border_color: Mapped[str] = mapped_column(String, nullable=False, default="rgba(0, 0, 0, 1)")
    border_width: Mapped[int] = mapped_column(Integer, nullable=False, default=2)
    sort_order: Mapped[int] = mapped_column(Integer, nullable=False, default=0)
    created_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.utcnow)
```

### 3.2 バックエンド API エンドポイント

プレフィックス: `/api/speech-bubble-presets`

- **GET `/api/speech-bubble-presets`**
  - レスポンス: `list[SpeechBubblePresetRead]` (`sort_order.asc(), id.asc()`)
- **POST `/api/speech-bubble-presets`**
  - リクエスト: `SpeechBubblePresetCreate`
  - 同名のプリセットが存在する場合は 400 Bad Request ("Preset name already exists")
  - レスポンス: `SpeechBubblePresetRead` (HTTP 201)
- **PUT `/api/speech-bubble-presets/{id}`**
  - リクエスト: `SpeechBubblePresetUpdate`
  - 存在しない場合は 404 Not Found
  - レスポンス: `SpeechBubblePresetRead` (HTTP 200)
- **DELETE `/api/speech-bubble-presets/{id}`**
  - 存在しない場合は 404 Not Found
  - レスポンス: 204 No Content

### 3.4 UI / UX 設計 (`SpeechBubbleControls.tsx`)

`SpeechBubbleControls` の最上部（またはフォント・装飾設定の上部）に「**修飾プリセット**」セクションを追加：

1. **プリセット一覧とワンクリック適用**:
   - 登録済みプリセットのピル/バッジ一覧を横並びまたはラップ表示。
   - バッジには背景色・文字色のカラープレビュー丸ドットとプリセット名を表示。
   - クリックすると、現在選択中の吹き出しに以下のプロパティが一括適用される：
     `shape`, `orientation`, `fontFamily`, `fontSize`, `textColor`, `backgroundColor`, `borderColor`, `borderWidth`
   - 適用後、さらに手動で個別のスライダーやカラーピッカーによる微調整が可能。

2. **現在の設定を新規プリセットとして保存**:
   - 「＋ プリセット保存」ボタンを配置。
   - クリックするとインライン入力（またはポップオーバー）が開き、プリセット名を入力して保存。
   - API を呼び出して DB に登録後、一覧を即座に再取得・更新。

3. **既存プリセットの更新・削除**:
   - 各プリセットバッジに「上書き保存」および「削除」のクイックアクション（ホバー時または管理モード/右クリックメニュー/編集アイコン）を提供。
   - 誤操作防止のため削除時は簡単な確認ダイアログまたはインライン確認を挟む。

## 4. トレードオフ・リスク分析 (Trade-offs & Risks)

- **トレードオフ: スタイル設定とサイズ (w, h) の分離**:
  - 吹き出しの幅・高さ (`w`, `h`) や座標 (`x`, `y`)、尻尾位置 (`tail`) はセリフの文字量やキャラ位置によって個別に異なるため、プリセットには含めず、純粋な「修飾スタイル（形状・フォント・カラー・ボーダー）」のみを対象とします。これにより、どんなセリフ・どんなサイズに対してもスタイルだけを安全に再利用できます。
- **リスク: オフライン / ネットワーク遅延時のフォールバック**:
  - API エラー時でも、直前のローカル設定（`localStorage` の `lastUsedStyle`）は従来通り機能し、セリフ編集自体の作業がブロックされないようにします。
