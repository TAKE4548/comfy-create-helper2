# PBI-167: アプリ離脱・リロード時の生成履歴画像取得およびマージ順序の不具合修正 設計書

## 1. 概要 (Overview)
モバイル端末やバックグラウンド移行によってWebSocketが一時切断された後、アプリへ復帰またはリロードした際に、ComfyUIで完了した生成結果が生成履歴ストリップに正しく読み込まれず表示されない問題を解消する。

## 2. アーキテクチャと設計方針 (Architecture & Design)

### 2.1 バックエンド (`backend/app/routers/comfy.py`)
1. `GET /api/comfy/history`:
   - クエリパラメータ `max_items: Optional[int] = Query(default=100, ge=1, le=1000)` を追加。
   - `httpx.AsyncClient(timeout=15.0)` で ComfyUI の `/history` へ `params={"max_items": max_items}` を中継。
   - `GET /api/comfy/history/{prompt_id}` エンドポイントを追加し、単一プロンプトの履歴取得プロキシを提供。
2. タイムアウト緩和:
   - 大規模ワークフローのレスポンスでも切断されないようタイムアウトを5.0秒から15.0秒へ緩和。

### 2.2 フロントエンド API クライアント (`frontend/src/api/client.ts`)
1. `comfyApi.getHistory`:
   - `getHistory: (maxItems?: number) => request<Record<string, any>>('/comfy/history' + (maxItems ? `?max_items=${maxItems}` : ''))`
2. `comfyApi.getPromptHistory`:
   - `getPromptHistory: (promptId: string) => request<Record<string, any>>(`/comfy/history/${encodeURIComponent(promptId)}`)`

### 2.3 フロントエンド ストア (`frontend/src/store/useGenerationStore.ts`)
1. `fetchHistory()` のマージ順序是正:
   - 新着履歴画像（`targetImages`）を配列の先頭に配置:
     ```ts
     const targetImages = state.filterOwnSession ? ownImages : allImages
     const mergedBatchImages = Array.from(new Set([...targetImages, ...state.batchImages])).slice(0, 50)
     const nextHistoryImages = Array.from(new Set([...allImages, ...state.comfyHistoryImages])).slice(0, 50)
     ```
   - 選択中画像（`selectedImg`）の更新:
     `!state.selectedImg` または以前の選択が空の場合、`mergedBatchImages[0]` を `selectedImg` に設定。
2. バッチキュー投入時の状態永続化 (`useGenerateAction.ts` & `useGenerationStore.ts`):
   - `queuePrompt` で `isBatchIntermediate: true` の場合でも、最新の `promptId` を `CURRENT_PROMPT_ID` に保存し、タブ復帰時の `reconcileState` が正常に機能するようにする。
   - `reconcileState` 内で `fetchHistory()` を呼び出す際にも最新の履歴が先頭にマージされることを保証。

## 4. トレードオフ・リスク開示 (Trade-off Disclosure)
- **Trade-off**: `GET /api/comfy/history` に `max_items=100`（デフォルト）を設定することで、ComfyUI全体の過去全件（数千件）は取得しなくなる。しかし、UI上の表示制限は最大50枚であるため、最新100件の取得で充分要件を満たし、レスポンス速度とメモリ消費を大幅に改善できる。
