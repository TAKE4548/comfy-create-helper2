# REQ-142 詳細設計書: セリフ編集における新規吹き出し作成時の装飾設定（フォント等）の直前設定引き継ぎおよびlocalStorage永続化

## 1. 概要 (Overview)
現在、`SpeechBubbleEditorModal` において吹き出しを新規作成（ダブルクリック、ROIドラッグ検出、デバッグ候補クリック等）する際、常にハードコードされた既定デフォルト値（楕円、縦書き、黒文字、白背景等）で生成されていました。
そのため、ユーザーが特定のフォントや装飾カラーを適用した状態で複数の吹き出しを連続作成する場合、作成するたびに設定を再調整する手間が発生していました。

本設計では、直前に編集または選択されていた吹き出しの装飾設定（フォント種類、フォントサイズ、文字色、背景色、枠線色/太さ、形状、文字方向）を `localStorage`（キー: `speech_bubble_last_used_style`）へ永続化し、モーダルを閉じた後の別画像編集時やブラウザ再起動後も含めて、新規吹き出し作成時に初期値として引き継ぎます。
既存の吹き出しを選択・切り替えた際はその吹き出し自体のプロパティを優先して読み込み、各吹き出しの局所的・独立した編集性を維持します。

## 3. 詳細設計 (Detailed Design)

### 3.1 スタイル設定インターフェースとヘルパー (`types/speechBubble.ts`)
```typescript
export interface BubbleStyleConfig {
  shape: BubbleShapeType
  orientation: TextOrientation
  fontFamily: string
  fontSize?: number // 0 または未指定時は自動フィット
  textColor: string // rgba(r,g,b,a)
  backgroundColor: string // rgba(r,g,b,a)
  borderColor: string // rgba(r,g,b,a)
  borderWidth: number // px
}

export const DEFAULT_BUBBLE_STYLE: BubbleStyleConfig = {
  shape: 'oval',
  orientation: 'vertical',
  fontFamily: 'sans-serif',
  fontSize: 0,
  textColor: 'rgba(0, 0, 0, 1)',
  backgroundColor: 'rgba(255, 255, 255, 0.95)',
  borderColor: 'rgba(0, 0, 0, 1)',
  borderWidth: 2,
}

export const LAST_USED_STYLE_STORAGE_KEY = 'speech_bubble_last_used_style'

export function extractBubbleStyle(bubble: Partial<SpeechBubble>): Partial<BubbleStyleConfig> {
  const style: Partial<BubbleStyleConfig> = {}
  if (bubble.shape !== undefined) style.shape = bubble.shape
  if (bubble.orientation !== undefined) style.orientation = bubble.orientation
  if (bubble.fontFamily !== undefined) style.fontFamily = bubble.fontFamily
  if (bubble.fontSize !== undefined) style.fontSize = bubble.fontSize
  if (bubble.textColor !== undefined) style.textColor = bubble.textColor
  if (bubble.backgroundColor !== undefined) style.backgroundColor = bubble.backgroundColor
  if (bubble.borderColor !== undefined) style.borderColor = bubble.borderColor
  if (bubble.borderWidth !== undefined) style.borderWidth = bubble.borderWidth
  return style
}

export function loadLastUsedBubbleStyle(): BubbleStyleConfig {
  if (typeof window === 'undefined' || !window.localStorage) {
    return DEFAULT_BUBBLE_STYLE
  }
  try {
    const saved = localStorage.getItem(LAST_USED_STYLE_STORAGE_KEY)
    if (!saved) return DEFAULT_BUBBLE_STYLE
    const parsed = JSON.parse(saved)
    return {
      ...DEFAULT_BUBBLE_STYLE,
      ...extractBubbleStyle(parsed),
    }
  } catch {
    return DEFAULT_BUBBLE_STYLE
  }
}

export function saveLastUsedBubbleStyle(style: Partial<BubbleStyleConfig>): void {
  if (typeof window === 'undefined' || !window.localStorage) return
  try {
    const current = loadLastUsedBubbleStyle()
    const merged = { ...current, ...extractBubbleStyle(style) }
    localStorage.setItem(LAST_USED_STYLE_STORAGE_KEY, JSON.stringify(merged))
  } catch {
    // ignore storage errors
  }
}
```

### 3.2 直前装飾設定の管理と新規作成時の適用 (`SpeechBubbleEditorModal.tsx`)

#### (1) ステート管理と初期復元
```typescript
const [lastUsedStyle, setLastUsedStyle] = useState<BubbleStyleConfig>(() => loadLastUsedBubbleStyle())
```
- 初期フォントリスト取得完了時に、もし保存されていた `lastUsedStyle.fontFamily` がリスト内にも存在するならそれを優先、未設定/デフォルトなら `msgothic.ttc` または先頭フォントをフォールバックとして `selectedFont` に設定。

#### (2) 既存吹き出し選択時の同期と永続化
```typescript
const selectBubble = (bubble: SpeechBubble) => {
  setSelectedBubbleId(bubble.id)
  const style = extractBubbleStyle(bubble)
  setLastUsedStyle((prev) => ({ ...prev, ...style }))
  saveLastUsedBubbleStyle(style)
}
```

#### (3) 吹き出し編集時のスタイル更新と永続化
```typescript
onUpdate={(updated) => {
  if (!selectedBubbleId) return
  setBubbles((prev) =>
    prev.map((b) => (b.id === selectedBubbleId ? { ...b, ...updated } : b))
  )
  const updatedStyle = extractBubbleStyle(updated)
  if (Object.keys(updatedStyle).length > 0) {
    setLastUsedStyle((prev) => {
      const next = { ...prev, ...updatedStyle }
      saveLastUsedBubbleStyle(next)
      return next
    })
  }
}}
```

#### (4) 吹き出し新規作成ヘルパー
```typescript
const createBubbleFromStyle = (params: {
  id?: string
  x: number
  y: number
  w: number
  h: number
  text?: string
  tail?: BubbleTail
}): SpeechBubble => {
  return {
    id: params.id || `bubble-${Date.now()}-${Math.random().toString(36).substring(2, 6)}`,
    x: params.x,
    y: params.y,
    w: params.w,
    h: params.h,
    text: params.text ?? '',
    shape: lastUsedStyle.shape,
    orientation: lastUsedStyle.orientation,
    fontFamily: lastUsedStyle.fontFamily || selectedFont || 'sans-serif',
    fontSize: lastUsedStyle.fontSize ?? 0,
    textColor: lastUsedStyle.textColor,
    backgroundColor: lastUsedStyle.backgroundColor,
    borderColor: lastUsedStyle.borderColor,
    borderWidth: lastUsedStyle.borderWidth,
    tail: params.tail,
  }
}
```

## 4. 非機能要件 & エッジケース対応
- **localStorage破損・未対応環境**: `try...catch` でラップし、不正なJSONやアクセス拒否時は常に安全に `DEFAULT_BUBBLE_STYLE` へフォールバック。
- **フォントロード**: `localStorage` から復元されたフォントファイル名（サーバーフォント）が指定された場合でも、エディタ初期化時に動的フォントロード（`FontFace`）が自動で呼び出され、描画崩れを防ぐ。
