# PBI-REQ-037 実行可能テスト計画

## 1. 自動テスト (CLI Verification)
フロントエンドの単体テストが正常にビルド・通過することを確認します。

- **コマンド**: `npm run test` (Cwd: `frontend`)
- **期待値**: 全テストケースの PASS。

## 2. ツール主導監査 (Tool-Driven Audit)
- **コード監査**: `python ${GLOBAL_SCRIPTS}\local_model_adapter.py engineer-audit .` を実行し、設計整合性の客観的証明を得ること。

## 3. ブラウザ検証 (Browser Agent Verification)
### 事前準備
1. バックエンドおよびフロントエンドを起動します。
2. ComfyUI を起動するか、ダミー接続を行います。

### 検証項目

#### AC-1 & AC-4: 画像生成完了時のプレビュー・履歴自動更新の確認
1. 生成ページを開き、履歴エリアに現在の履歴画像が表示されていることを確認します。
2. 「自セッションフィルタ」(`filterOwnSession`) を **有効**（チェックあり）にした状態で画像を生成します。
   - 生成完了時、プレビューエリアに生成画像が即時表示されること。
   - 履歴エリア（バッチ画像一覧）の先頭に生成画像が即時追加されること。
3. 「自セッションフィルタ」(`filterOwnSession`) を **無効**（チェックなし）にした状態で画像を生成します。
   - 生成完了時、プレビューエリアおよび履歴エリア（全体履歴 `comfyHistoryImages`）の先頭に生成画像が即時追加されること。
   - どちらの設定でも、画面の手動リロードなしでリアルタイムに画像が追加されることを確認します。

#### AC-2: 履歴のソート順（UUIDキー・最新順）の検証
1. 履歴ページまたは生成ページの全体履歴一覧において、画像が「生成された日付（最新順）」でソートされていることを確認します。
2. 新たに生成された画像が常に一番最初（左上または先頭）に配置されること。
3. UUIDキーで返却されるComfyUI環境においても、最新履歴が正しく先頭に来ることを確認します。

#### AC-3: WebSocket自動再接続の検証
1. 開発コンソールのネットワークタブ等を利用して一時的にWebSocketを切断させるか、ComfyUIサーバーを一時停止します。
2. UI上の接続ステータスが切断（オフライン）になることを確認します。
3. 再びサーバーを復旧させた際（または3秒経過後）、画面リロードなしでWebSocketが自動接続され、ステータスが接続中（オンライン）に復帰することを確認します。
