## 4. 手動検証シナリオ (Manual Verification Scenario)

### シナリオ1: 専用エントリーポイントからの起動とセリフ画像のフィルタリング
1. **事前準備**: セリフ（吹き出し）が付与された画像と、セリフのない通常の生成画像が混在する状態を用意。
2. **専用ボタン押下**: 履歴ページ上部の「セリフ一括変換」ボタンをクリック。
3. **候補一覧確認**:
   - セリフのない画像は除外され、セリフが付与された画像のみが一覧に表示されることを確認。
   - ワークフロー絞り込み、アルバム絞り込み、日付ソート、セリフ検索を行い、目的の画像が正しく絞り込まれることを確認。
4. **対象選択**: 対象としたい画像カードを選択し、必要に応じて個別の吹き出しチェックをON/OFFする。

### シナリオ2: 一括変換の実行・個別/全体キャンセル
1. 複数吹き出しを選択し、「一括変換開始」をクリック。
2. 待機中（pending）の1つの吹き出しについて「キャンセル」をクリックし、キューから除外されることを確認。
3. 変換中（processing）の状態で「全体キャンセル」をクリックし、直ちに進行中のリクエストが中断されて全キューが停止することを確認。
4. 既に完了した吹き出しのテキストは保持されていることを確認。

### シナリオ3: 全件完了後の個別再生成（キュー再投入）
1. 全件の変換が完了した状態（全体進捗 100%）を確認。
2. 任意の吹き出しカードの「再生成」ボタンをクリック。
3. 該当吹き出しのみが再度「変換中」スピナーに切り替わり、サーバー側キューワーカーが自動で再開されて新しいLLM変換結果が取得・表示されることを確認。
4. 再生成されたセリフに対してインライン編集で微調整できることを確認。

### シナリオ4: バックグラウンド継続・ページ遷移復帰と一括保存
1. 変換中にモーダルの「✕」ボタンを押して閉じる、または別ページ（`/generate`）へ移動する。
2. 履歴ページヘッダーの「セリフ一括変換」ボタンに進行中バッジ（例: `変換中 1/3`）が表示され、サーバー側で処理が継続していることを確認。
3. 再度「セリフ一括変換」ボタンをクリックしてモーダルを開き、完了した項目が保持されていることを確認。
4. 保存モード（「上書き保存」または「新規画像として保存」）を選択し、「変更を一括保存」をクリック。
5. 保存進行状況が表示され、完了後にモーダルが自動で閉じ、スナップショット一覧で画像が更新されていることを確認。
