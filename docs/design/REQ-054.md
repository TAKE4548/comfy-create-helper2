## 1. 問題の要約

`HistoryModalPreview.tsx` にて、`loraStacks = useMemo(...)` が条件付き早期リターン (`if (!isOpen || images.length === 0) return null`) の**後**に配置されている。

React の Rules of Hooks により、フック呼び出しはレンダリングごとに同じ順序で呼ばれなければならない。現在の配置では `isOpen` の値によってフック数が変動し、React がクラッシュして黒画面になる。

---

## 2. 技術設計

### 2-1. 修正対象

| ファイル | 行 | 内容 |
|---|---|---|
| `frontend/src/components/HistoryModalPreview.tsx` | L71 | 早期リターン（基準点） |
| `frontend/src/components/HistoryModalPreview.tsx` | L117–L150 | `loraStacks = useMemo(...)` ← 移動対象 |

### 2-2. 修正方針

`loraStacks` の `useMemo` ブロック（L117–L150）を、早期リターン（L71）より**前**に移動する。

**Before（現在の構造）:**
```tsx
// L58-L69: useEffect (keyboard)
// L71: if (!isOpen || images.length === 0) return null  ← 早期リターン
// ...
// L99-L109: getParamValue 関数定義
// L111-L115: getParamValue 呼び出し
// L117-L150: const loraStacks = useMemo(...)  ← ⚠️ 違反位置
```

**After（修正後の構造）:**
```tsx
// L58-L69: useEffect (keyboard)
// [ここに移動] const loraStacks = useMemo(...)  ← ✅ 早期リターンより前
// if (!isOpen || images.length === 0) return null  ← 早期リターン
// ...
// getParamValue 関数定義
// getParamValue 呼び出し（loraStacks はここでは使わないため問題なし）
```

### 2-3. 副作用分析

| 懸念事項 | 評価 |
|---|---|
| `useMemo` の依存値（`snapshot?.params`, `loras`）が `isOpen=false` 時に評価される | ✅ **安全**: `snapshot` と `loras` は `useQuery` のキャッシュ値。`isOpen=false` でも null/undefined になるだけで、`useMemo` 内の `if (!snapshot?.params) return []` がガードする |
| `loraStacks` が JSX で参照される箇所 | ✅ **変更なし**: JSX 内の参照位置は変わらない |
| `getParamValue` と `loraStacks` の順序 | ✅ **問題なし**: `loraStacks` は `getParamValue` を使用していない |
