# REQ-027 テスト計画書

## 1. テスト概要
フロントエンドに導入した `Vitest` テストランナーおよび `React Testing Library` が正常に機能し、タグチップエディタ（`TagChipEditor`）のユニットテストとコンポーネントテストがすべて成功することを確認します。また、カバレッジ計測およびウォッチモードが想定通り機能することを検証します。

## 2. 検証項目と実行方法

### 2.1 自動テスト (CLI Verification)
- **検証内容**: 新規追加したすべてのユニットテストおよびコンポーネントテストを実行し、すべて正常に通過すること。
- **実行コマンド**:
  ```bash
  cd frontend
  npm run test
  ```
- **期待される結果**:
  - `useChipParser.test.ts`, `useChipHistory.test.ts`, `TagChip.test.tsx`, `TagInput.test.tsx`, `TagChipEditor.test.tsx` のすべてのテストケースが PASS すること。

### 2.2 ウォッチモードの動作検証
- **検証内容**: テストファイルの変更を検知して自動でテストが再実行されること。
- **実行コマンド**:
  ```bash
  cd frontend
  npm run test:watch
  ```
- **手順**:
  1. 上記コマンドでウォッチモードを起動する。
  2. `useChipParser.test.ts` 内の任意のアサーション値を意図的に失敗する値に変更し、保存する。
  3. テストが自動実行され、該当箇所が FAIL することを確認する。
  4. 値を元に戻して保存し、再度自動実行で PASS になることを確認する。
  5. `q` キーで監視モードを終了する。

### 2.3 カバレッジ測定の検証
- **検証内容**: 各ファイルのテストカバー率が測定され、レポートが出力されること。
- **実行コマンド**:
  ```bash
  cd frontend
  npm run test:coverage
  ```
- **期待される結果**:
  - カバレッジ測定ツール（`@vitest/coverage-v8` 等）がインストール・設定され、ターミナルにカバレッジ表が出力されること。
  - `frontend/coverage/` ディレクトリ配下に HTML レポートが出力されること。

## 3. 手動テスト・ビルド検証
- **検証内容**: テスト環境の導入や設定ファイルの変更によって、通常のアプリビルドやアプリ起動に影響がないことを確認します。
- **実行コマンド**:
  ```bash
  cd frontend
  npm run build
  ```
- **期待される結果**:
  - `tsc` による型チェックおよび `vite build` によるビルドが正常に完了すること。
