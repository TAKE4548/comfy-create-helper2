# REQ-045 テスト計画書

## 1. 自動テスト
バックエンドの DB スキーマ追加、およびルーター API の振る舞いを検証するテストコードを実行します。

### 1.1 バックエンドテストの実行
FastAPI の pytest 実行コマンド:
```bash
pytest backend/tests/
```
※ 必要に応じて、REQ-045 専用のテストケース `backend/tests/test_req_045.py` を実装し実行します。

## 2. 手動検証計画（マニュアルテスト）

### 2.1 ワークフロー切り替え時のUIリセット検証
1. ワークフロー A を選択し、適当な LoRA / タグセットを positive プロンプトに適用して、バッジが表示されることを確認。
2. 別のワークフロー B に切り替える。
3. ワークフロー B に切り替えた直後、LoRA / タグセットのバッジ表示が自動でリセットされる（またはワークフロー B に保存されていたバッジ状態に更新される）ことを確認する。

### 2.2 ワークフローデフォルト設定の保存と復元検証
1. ワークフロー A において、任意のパラメータを変更し、LoRA / タグセットをいくつか適用。
2. 「デフォルト設定として保存」（Save Defaults）を実行する。
3. パラメータと適用バッジの構成を変更する。
4. 「デフォルト設定にリセット」（Reset Defaults）を実行する。
5. 1.で保存したパラメータおよび LoRA / タグセットの適用バッジ（およびプロンプト内のタグ）が正しく復元されることを確認する。

### 2.3 スナップショット保存とロード時のLoRA・タグセット復元検証
1. ワークフロー A において、LoRA およびタグセットを適用し、スナップショットを新規作成して保存する。
2. 画面上の LoRA / タグセットの適用を全て解除する。
3. 1.で作成したスナップショットを選択し、ロードする。
4. スナップショット作成時と全く同じパラメータ、プロンプト、LoRA・タグセットのバッジ状態が復元されることを確認する。
