## 3. ブラウザ検証 (Browser Agent Verification)
- **対象URL**: `http://localhost:5173/`
- **操作手順**:
  1. 生成ページのプロンプト入力欄にある「Add Asset」ボタンをクリックする。
  2. 専用の「アセット追加モーダル」が表示されることを確認する。
  3. 検索窓に任意のキーワード（登録されているLoRA名やタグセット名の一部）を入力し、フィルタリングが動作することを確認する。
  4. タブを「LoRA」から「タグセット」に切り替え、それぞれの表示項目と検索フィルタが連動することを確認する。
  5. 複数のLoRAアセットを選択し、それぞれに異なる推奨強度やトリガーワードセットを割り当てる。
  6. 一部のアセットで「LoRAロードタグを挿入する」チェックボックスをOFFにし、別のアセットではONのままにする。
  7. タグセットタブに切り替え、別のタグセットにもチェックを入れる。
  8. 「適用」ボタンをクリックする。
- **判定基準 (Assertion)**:
  - 選択されたすべてのLoRAとタグセットが、プロンプトテキストエリアに一括で挿入されること。
  - 「LoRAロードタグを挿入する」がONのLoRAは、`<lora:ファイル名:強度>` とトリガーワードの両方が挿入されること。
  - 「LoRAロードタグを挿入する」がOFFのLoRAは、ロードタグ `<lora:ファイル名:強度>` が挿入されず、トリガーワードのみが挿入されること。
  - 適用後、アセット追加モーダルが閉じ、選択状態がクリアされること。
- **必須エビデンス**:
  - モーダル表示中のスクリーンショット: `db/snapshots/req-085-modal.png`
  - 適用後のプロンプトテキスト状態のスクリーンショット: `db/snapshots/req-085-applied.png`
