# REQ-314 実装レビューの補修記録

承認済みD1（診断・生成6種）/D2（既存契約内）を維持した実装レビュー。以下はコード確認で見つかった具体的な不一致と、コーディネーターから得た補修・局所検証の報告。全体の受入判定は最終検証とユーザー手動確認を別途参照する。

| 検出した問題 | 補修 | 局所検証の報告 |
|---|---|---|
| 選択中タブの視覚差がない | 選択状態とフォーカスを設定ページ限定CSSで表示 | T2/T11 |
| 翻訳A→B→Aで新しいAが旧pending判定に阻まれる | リクエスト順序で新しいAを実行し古い応答を無視 | T6: 5件PASS |
| 翻訳の明示実行後にもデバウンスが発火する | 明示実行時に待機タイマーを解除 | T6: 5件PASS |
| 接続設定取得後もURL入力が既定値のまま | 未編集のURL欄だけ実効URLへ同期、編集内容は保持 | T14: 5件PASS |
| LM障害を空一覧HTTP200で接続成功と誤判定 | 空一覧はモデル未取得・接続確認不可と表示 | T14: 5件PASS |
| 新カードがアプリの配色と一致しない | 既存surface/zinc/accentトークンを使用 | 配信用ビルドPASS |
| 保存中の新しい翻訳設定を保存済み扱いにする | 送信した値のスナップショットを保持 | T4: 12件PASS |
| 隠れたAPI認証情報の編集が非APIプレビューを妨げる | 認証のdirty判定をAPIプロバイダーに限定 | T4: 12件PASS |
| 古いキャッシュが保存直後の設定を戻す | 保存結果と再取得の同期境界を保護 | T4: 12件PASS |
| モバイルタブが縮み、横スクロールを失う | 狭い画面で非縮小・内容幅、768px以上で等幅 | T11: 7件PASS、実寸は手動待ち |
| モーダルに画面内スクロール規則が適用されない | 実際の内側カードにdialog属性と名前を付与 | T8/T9/T10、実寸は手動待ち |
| 保存領域拒否で常時マウントした子が例外になる | 長押し・サムネイル設定の読書きを保護 | T5/T17 |
| 旧13区分の保存値を書き換える | 旧キーへの書込みを削除し、その値を維持 | T18: 11件PASS |
| 768〜1023pxでボトムナビ余白がなくなる | ページ余白の切り替えを1024pxへ合わせる | 配信用ビルドPASS、実寸は手動待ち |
| システム設定の分類が4兄弟カードになる | 接続、VRAM、表示・操作感の3論理カードへ構成 | T7/T19 |

ブラウザ操作・CSS寸法・実サービス接続・実翻訳の観測はユーザー手動確認待ち。ビルドやDOMテストをその代替証拠にはしない。監査モデルの原判定もこの記録で書き換えない。
