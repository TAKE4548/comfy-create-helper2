# REQ-058: マスタマッピングのサンプラ・スケジューラ選択肢の分離と初期アップロード時の設定値反映

## 1. システム構成・全体設計

本機能では、これまで `select` 入力タイプにてLoRA一覧がハードコードされていた仕様を改善し、サンプラ名およびスケジューラ名に応じた適切な選択肢を提供する。

### データの取得方式
1. **ComfyUI APIからの動的取得**:
   - フロントエンドから、接続中の `comfyUrl` を用いて `comfyUrl + "/object_info"` または `/object_info/KSampler` をフェッチする。
   - レスポンスから以下のパスを通じて有効な選択肢を取得する。
     - サンプラ名: `KSampler.input.required.sampler_name[0]` (または `KSamplerAdvanced.input.required.sampler_name[0]`)
     - スケジューラ名: `KSampler.input.required.scheduler[0]` (または `KSamplerAdvanced.input.required.scheduler[0]`)
2. **静的フォールバック**:
   - ComfyUI未起動時やAPI接続エラーに備え、標準的なサンプラ名・スケジューラ名の固定配列をフロントエンドに静的に定義してフォールバックとして使用する。

---

## 2. 変更・追加点

### フロントエンド

#### A. API定義・型定義 (`frontend/src/api/types.ts`)
- `MappingMaster` の `input_type` のユニオン型定義に `'select_sampler' | 'select_scheduler'` を追加する。

#### B. 定数定義・ユーティリティ (`frontend/src/utils/comfyParams.ts`) [NEW]
- 静的なフォールバック用のサンプラ一覧（`DEFAULT_SAMPLERS`）とスケジューラ一覧（`DEFAULT_SCHEDULERS`）を定義する。

#### C. パラメータ入力フォーム生成部 (`frontend/src/pages/GeneratePage.tsx` および `SettingsPage.tsx`)
- `GeneratePage.tsx`:
  - `select_sampler` のときは、ComfyUI からフェッチした（またはフォールバック用の）サンプラリストを `<option>` としてレンダリングする。
  - `select_scheduler` のときは、同様にスケジューラリストを `<option>` としてレンダリングする。
  - `select` のときは、既存通りLoRAリストを表示する。
  - いずれの場合も初期パースされた値と選択肢が一致するため、初期アップロード時の設定値が正しく画面に反映されるようになる。
- `SettingsPage.tsx`:
  - マッピングマスタ管理UIの入力タイプドロップダウンの選択肢に「select_sampler」および「select_scheduler」を追加する。

#### D. ComfyUI Object Info取得フック
- `useGenerationStore.ts` または React Query フックを用いて、`comfyUrl + '/object_info'` から取得したデータを保持・管理する。
