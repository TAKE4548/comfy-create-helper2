# REQ-293 設計ドキュメント: 「シーン一括生成」ボタン無反応バグ修正

## 1. 問題の要約

HistoryPage から SpeechBubbleEditorModal を開いた場合、「シーン一括生成」ボタンを押下しても POST /api/speech/scene-draft が発火しない。

### 根本原因 (Type-A: 実装欠陥)

| # | 欠陥箇所 | 内容 |
|---|---|---|
| 1 | HistoryPage/index.tsx L444-457 | SpeechBubbleEditorModal 呼び出し時に generateDraftApi prop を渡していない |
| 2 | SpeechBubbleEditorModal/index.tsx L170 | generateDraftApi 未注入時の fallback が空スタブ () => Promise.resolve({ bubbles: [] }) |

**伝播チェーン**:
`
HistoryPage (generateDraftApi未渡し)
  -> SpeechBubbleEditorModal (fallback: 空スタブ)
    -> useSceneSpeechGeneration (空スタブを実行)
      -> setBubbles([]) -> スピナー即終了 -> 画面無変化
`

## 2. HistoryPage 現状コード確認

HistoryPage/index.tsx の L444-457 (現在の呼び出しコード):
`	sx
{selectedForSpeech && (
  <SpeechBubbleEditorModal

    initialAlbumId={selectedAlbumId ?? undefined}

`
**問題**: generateDraftApi / primaryTagSetId / pplyPresetToBubbles が渡されていない。

## 3. 既存 API クライアント調査

rontend/src/api/client.ts に /api/speech/scene-draft 相当の専用関数は**存在しない**。

既存の近傍関数:
- llmPromptsApi.speechDraft(snapshot_id) -> /api/llm-prompts/speech-draft (別エンドポイント)
- **/api/speech/scene-draft** への呼び出し関数: 未実装

## 4. 修正方針

### Fix-1: SpeechBubbleEditorModal/index.tsx fallback を実 fetch に変更

**変更箇所**: L170
`	sx
// Before (空スタブ)
generateDraftApi: generateDraftApi ?? (() => Promise.resolve({ bubbles: [] })),

// After (実 fetch fallback)
generateDraftApi: generateDraftApi ?? (async (payload) => {
  const res = await fetch('/api/speech/scene-draft', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(payload),
  });
  if (!res.ok) throw new Error(await res.text());
  return res.json();
}),
`

**設計判断: fetch を直接使う理由**
- pi/client.ts に専用関数を追加する場合、SceneDraftRequest/SceneDraftResponse 型を rontend/src/api/types.ts に反映する作業が発生し、スコープが広がる
- SpeechBubbleEditorModal の fallback は Props 未注入時の最終手段であり、軽量な inline fetch が適切
- useSceneSpeechGeneration の generateDraftApi 型シグネチャと完全一致

### Fix-2: HistoryPage/index.tsx に generateDraftApi を追加

HistoryPage は primaryTagSetId を持たないため、最もシンプルなパス: generateDraftApi のみ渡す。
fallback を Fix-1 で修正済みのため、Props に渡す関数は Fix-1 の inline fetch と同一実装を参照するか、独立した関数を定義する。

`	sx
// HistoryPage/index.tsx への追加
const generateSceneDraft = async (payload: {
  snapshot_id: number;
  target_tag_set_id?: number | null;
  explicit_preset_id?: number | null;
}) => {
  const res = await fetch('/api/speech/scene-draft', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(payload),
  });
  if (!res.ok) throw new Error(await res.text());
  return res.json();
};

// JSX 使用箇所
<SpeechBubbleEditorModal
  snapshot={selectedForSpeech}
  initialAlbumId={selectedAlbumId ?? undefined}
  generateDraftApi={generateSceneDraft}  // <- 追加
  onClose={() => setSelectedForSpeech(null)}
  onSaved={() => { ... }}
/>
`
