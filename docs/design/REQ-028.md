# 設計書 - REQ-028: バッチ数に基づく複数画像生成および生成中のキューイング対応

## 1. 目的と概要
現在、生成画面において `Batch Size` を設定しても 1 回しか ComfyUI に生成リクエストが送信されません。また、自分が生成を開始すると生成ボタンが非活性になり、ComfyUI のキュー機能を利用して後続の生成リクエストを連続して投入することができません。
本設計では、`Batch Size` 設定時にその回数分ループして生成リクエストを ComfyUI に送信し、かつ自身が生成中であってもボタンを非活性化せずにキューへ順次追加できるように改善します。

## 2. 詳細設計

### 2.1 生成リクエストのループ処理とシード制御
`frontend/src/pages/GeneratePage.tsx` の `handleGenerate` 関数を以下のように修正します。

1. **バッチサイズのループ化**:
   `batchSize` 回数分ループを回し、各ループ内で ComfyUI の `/prompt` へのリクエスト（`queuePrompt`）を送信します。
2. **シード値の動的制御**:
   各ループ内で送信するワークフローのパラメータのうち、`seed` を以下のように動的変更します。
   * **`seedMode === 'random'` の場合**: 
     ループごとに新しく `Math.floor(Math.random() * 2 ** 32)` を生成してセットします。
   * **`seedMode === 'fixed'` などの場合**:
     基準シード値 `seed` に対し、ループのインデックス `i` を加算した `seed + i` をセットします。

### 2.2 生成ボタンの活性制御
自セッションが生成中であってもキューへの追加を許可するため、以下の修正を行います。

1. **無効化条件の変更**:
   モバイルおよびデスクトップの生成ボタンの `disabled` 条件から `isGenerating && activeClientId === clientId` の判定を除外します。
   * 修正前: `disabled={(isGenerating && activeClientId === clientId) || !selectedWorkflowId}`
   * 修正後: `disabled={!selectedWorkflowId || !isConnected}`
2. **ボタン文言・スタイルの統一**:
   自身が生成中であってもボタンが押せるようになるため、`isGenerating` が `true` の期間はボタンのスピナー表示を行わず、一貫して `Generate Batch (キュー追加)` と表示します。
   * `isGenerating` が `true` の場合: `Generate Batch (キュー追加)`
   * `isGenerating` が `false` の場合: `Generate Batch`

## 3. 影響範囲
* `frontend/src/pages/GeneratePage.tsx`: 生成ボタンの無効化ロジック、文言、および `handleGenerate` 送信処理。
