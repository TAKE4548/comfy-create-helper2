## 3. ブラウザ検証 (Browser Agent Verification)
- **対象URL**: `http://localhost:5173/` (フロントエンドの開発用URL)
- **検証手順1: 設定画面での翻訳LLM設定**:
  1. 設定画面 (`/settings`) にアクセスし、「LLM Model Settings」セクションを開く。
  2. 「翻訳用LLMモデル」セレクトボックスおよび「翻訳デバウンス間隔 (ms)」数値入力欄が存在することを確認する。
  3. 「翻訳用LLMモデル」で有効なモデルを選択し、「翻訳デバウンス間隔」を `800` ms に変更し、保存ボタンをクリックする。
  4. ページをリロード（F5）した後、選択したモデル名および入力した `800` ms の数値がそのまま保持されていることをアサートする。
  5. 「LLM System Prompts」セクションを開き、`translation_ja_to_en` と `translation_en_to_ja` のエディタ（アコーディオン）が表示され、編集・保存が可能であることを確認する。
- **検証手順2: 生成画面でのトグル動作**:
  1. 生成画面 (`/generate`) にアクセスする。
  2. ワークフロー選択エリアの横に「Anima特化モード」トグルスイッチがあることを確認する。
  3. ベースモデルが `Anima` に設定されたワークフロー（例: `Anima-v1` 等）を選択した際、トグルが自動的に `checked (ON)` 状態になり、プロンプト入力エリアのテキストエリアが即座に表示（テキスト入力モードデフォルト化）されることをアサートする。
  4. ベースモデルが `Anima` 以外のワークフローを選択した際、トグルが `unchecked (OFF)` 状態に切り替わり、元のデフォルト入力方式（タグチップモード等）に戻ることを確認する。
  5. トグルを手動で OFF に切り替えた場合、タグチップエディタが代わりに表示されること、および ON に切り替えるとテキストエリアに戻ることを確認する。
- **検証手順3: 双方向デバウンス翻訳の検証**:
  1. 「Anima特化モード」を ON にし、プロンプトエリアの「翻訳」アイコンをクリックしてフローティング翻訳ウィンドウを表示する。
  2. 翻訳ウィンドウがドラッグ可能であることを確認する。
  3. メインプロンプト入力欄に「赤いドレスを着た女の子」と入力する。
  4. キー入力の停止から設定されたデバウンス時間（例: `800` ms）の経過後、バックエンドに `POST /api/llm-prompts/translate` リクエストが送信（ブラウザの開発者ツール Network タブでステータス `200` を確認）され、フローティングウィンドウの英語エリアに翻訳テキスト（例: "a girl wearing a red dress" など）が出力されることをアサートする。
  5. フローティングウィンドウの英語エリアのテキストを "a girl wearing a blue dress" に変更する。
  6. キー入力停止からデバウンス時間経過後、逆翻訳リクエストが送信され、メインプロンプト入力欄（日本語）が「青いドレスを着た女の子」に自動的に書き換わることをアサートする。
