# REQ-085: Asset (LoRA/タグセット) 追加UIの探索・複数適用機能の強化 設計書

## 1. 概要
アセット（LoRAおよびタグセット）の数が増加した際にも目的のアセットを迅速に探索できるようにし、さらに複数のアセットを一度の操作でプロンプトへ一括適用可能にするため、従来のドロップダウンUIを「専用のアセット追加モーダルUI」へと刷新します。

## 2. 要件と Acceptance Criteria (AC) のマッピング
- **AC-1: 探索・フィルタ機能**
  - モーダル内に「LoRA」と「タグセット」のタブを設け、タブごとにアセットを分類表示。
  - テキスト検索入力欄を提供し、アセット名、説明文、またはタグ（LoRAの場合はトリガーワード）でリアルタイムに絞り込み可能とする。
- **AC-2: 複数選択機能**
  - 各アセットの左側にチェックボックスを配置し、複数のLoRAおよびタグセットを選択可能にする。
- **AC-3: 一括追加機能**
  - 「追加」ボタン押下時に、選択されたすべてのアセットを一括で適用（プロンプトへの挿入および appliedAssets 状態への追加）する。
- **AC-4: LoRAロードタグの個別選択適用**
  - LoRAアセットごとに「LoRAロードタグを挿入する」チェックボックスを提供。
  - チェックONの場合は、`<lora:filename:strength>` を含めて適用する。
  - チェックOFFの場合は、ロードタグを挿入せず、選択されたトリガーワードのみをプロンプトに挿入する。

## 3. UI/UX 設計

### 3.1 モーダルレイアウト
モーダルは画面中央にオーバーレイ表示されます。

```
+-------------------------------------------------------------+
| アセットを追加 (ロール: positive)                       [X] |
+-------------------------------------------------------------+
| [ 検索: 名前、説明、タグで検索...                         ] |
|                                                             |
|  +--------+ +------------+                                  |
|  | LoRA   | | タグセット |                                  |
|  +--------+ +------------+                                  |
| +---------------------------------------------------------+ |
| | [x] LoRA名 A                                            | |
| |     [x] LoRAロードタグを挿入する                         | |
| |     トリガーワード: (o) セット1 [a, b]  ( ) セット2 [c]   | |
| |     強度: [=================o====] 1.0                  | |
| | ------------------------------------------------------- | |
| | [ ] LoRA名 B                                            | |
| |     ...                                                 | |
| +---------------------------------------------------------+ |
+-------------------------------------------------------------+
| [2 件選択中]                       [キャンセル] [一括追加]  |
+-------------------------------------------------------------+
```

### 3.2 検索・フィルタ仕様
- 入力値による大文字・小文字を区別しない部分一致検索。
- **LoRAの検索対象**: モデル名、説明文（description）、トリガーワードセット内の単語。
- **タグセットの検索対象**: タグセット名、説明文（description）、含まれるタグ。

## 4. コンポーネントおよび状態設計

### 4.1 新規コンポーネント: `AddAssetModal`
- **ファイルパス**: `frontend/src/pages/GeneratePage/components/AddAssetModal.tsx`
- **Props**:
  ```typescript
  interface AddAssetModalProps {
    role: string
    displayName: string
    loras: Lora[]
    tagSets: TagSet[]
    onClose: () => void
    onApply: (assets: SelectedAssetPayload[]) => void
  }
  ```
- **状態管理 (内部ステート)**:
  - `activeTab`: `'lora' | 'tagset'`
  - `searchQuery`: `string`
  - `selectedAssets`: 選択されたアセットの情報マップ
    - LoRAの場合: `loraId`, `strength`, `triggerSetId` (number | 'default'), `insertLoraTag` (boolean)
    - タグセットの場合: `tagSetId`

### 4.2 アセット適用処理
- `GeneratePage.tsx` または `useGeneratePageState.ts` から、モーダルで確定された複数アセットの配列を受け取り、ループまたはバルク更新で `addAppliedAsset` 相当 of 処理を実行する。
- 既存の `addAppliedAsset` は以下の通り:
  ```typescript
  addAppliedAsset: (role, asset) => { ... }
  ```
  これを利用して、モーダルから返された各アセットを順番に適用する。
