# REQ-132 詳細設計書 (System & Architecture Design)

## 1. 概要と目標
アプリ内の画像ストレージ効率最適化および表示レスポンス向上のため、以下の機能を提供する。
1. **保存画像の WebP 自動変換**: 新規保存・アップロード画像を品質を保持（原寸: quality=90）した WebP 形式に自動圧縮変換。
2. **サムネイル用低解像度画像の生成・分離**: サムネイル用（幅最大300px, quality=80）の軽量 WebP 画像を別途保存し、一覧表示はサムネイル用、モーダル/プレビュー表示時のみ原寸高解像度画像を使用。
3. **エクスポート/ダウンロード時のフォーマット変換 API**: `/api/snapshots/{id}/download?format=png|jpeg|webp` を提供し、ダウンロード時に任意形式にオンザフライ変換。
4. **既存画像のマイグレーション**: 過去保存されている PNG/JPEG 画像を WebP 化（原寸: quality=90, サムネイル: quality=80）し、サムネイル画像を生成する一括移行 CLI スクリプト/エンドポイントを提供。

---

## 2. データベース & データモデル仕様

### 2.1 `snapshots` テーブル構造拡張
既存の `snapshots` テーブルに `thumbnail_path` カラムを追加。

```sql
ALTER TABLE snapshots ADD COLUMN thumbnail_path TEXT;
```

`models.Snapshot`:
- `image_path`: 原寸 WebP 画像パス (例: `/api/snapshots/images/snapshot_xxx.webp`)
- `thumbnail_path`: サムネイル WebP 画像パス (例: `/api/snapshots/images/thumb_snapshot_xxx.webp`)

---

## 3. API インターフェース仕様

### 3.1 既存レスポンスの拡張
`SnapshotSummary` および `SnapshotRead`:
- `thumbnail_path`: `Optional[str]` フィールドを追加。

### 3.2 画像ダウンロード/変換エンドポイント
- **POST/GET**: `/api/snapshots/{snapshot_id}/download`
- **Query Parameter**: `format` (enum: `png`, `jpeg`, `webp`, default: `png`)
- **Response**: `FileResponse` (指定フォーマットに動的変換またはダウンロード用ヘッダー付きレスポンス)

### 3.3 マイグレーション API / CLI
- **CLI Command**: `python backend/scripts/migrate_images_to_webp.py`
- **内容**: `snapshots` テーブル内の全レコードおよび `settings.snapshot_path` ディレクトリ内の既存画像をスキャンし、WebP 変換およびサムネイル生成を実施して DB パスを更新。

---

## 4. フロントエンドコンポーネント設計

1. **`HistoryPage.tsx` / `DesktopLayout.tsx` / `MobileLayout.tsx`**:
   - グリッド一覧表示部: `item.thumbnail_path || item.image_path` を参照。
   - 拡大プレビュー / モーダル表示部: `item.image_path` を参照。
2. **ダウンロードボタン**:
   - ダウンロードモーダルまたはドロップダウンメニューを追加し、フォーマット（PNG / JPEG / WebP）を選択してダウンロード API を呼び出す。

---

## 5. テスト・検証計画

1. **ユニットテスト (Backend)**: `tests/test_snapshots_webp.py`
   - WebP 変換処理およびサムネイル作成処理の検証。
   - フォーマット変換ダウンロード API の検証。
2. **フロントエンドテスト**: `npm run test`
   - 型エラーおよび `thumbnail_path` 参照コンポーネントの正常動作確認。
3. **マイグレーションテスト**: スクリプト実行による画像ファイル群および DB レコードの正確な更新検証。
