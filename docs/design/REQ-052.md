# REQ-052 設計書: Dynamic LoRA Stack (easyLoraStack) 対応

## 1. 概要

本変更は、ComfyUI の `easyLoraStack` のように複数の LoRA を動的に増減・管理するノード構造に対し、フロントエンドがフラットな Zustand 状態管理（`Record<string, string>`）を維持したまま動的なノードスタック仕様に対応するためのものである。
新入力タイプ `lora_stack` を定義し、スロットを動的に増減できる専用UI `LoraStackEditor` を実装する。スロットの最大登録数は10件とする。また、LoRAモデル選択時に、LoRA管理（DB登録データ）を参照して `description` がある場合はその値を表示し、未登録の場合はファイルパスを表示する。

---

## 2. システム設計

### 2-1. データ構造とZustand Storeのキー設計
Zustandストア（`useGenerationStore.ts`）のフラットな `paramValues` 構造を維持するため、キー名は以下の命名ルールで生成する。
- スロット件数（整数）：`${role}_lora_count`
- インデックス `i` (1から始まる) の LoRA名選択：`${role}_lora_name_${i}`
- インデックス `i` のウェイト：`${role}_lora_wt_${i}`
- インデックス `i` のモデル強度：`${role}_model_str_${i}`
- インデックス `i` のCLIP強度：`${role}_clip_str_${i}`

## 3. 詳細ロジック設計

### 3-1. 繰り上げ（インデックス再計算）処理
スロット `i` を削除した場合、`i + 1` 以降の値を1つずつ前方にシフトする。
```typescript
const handleRemoveSlot = (indexToRemove: number) => {
  const currentCount = parseInt(paramValues[`${role}_lora_count`] || '0');
  const nextParams = { ...paramValues };

  for (let i = indexToRemove; i < currentCount; i++) {
    nextParams[`${role}_lora_name_${i}`] = paramValues[`${role}_lora_name_${i + 1}`] || '';
    nextParams[`${role}_lora_wt_${i}`] = paramValues[`${role}_lora_wt_${i + 1}`] || '1.0';
    nextParams[`${role}_model_str_${i}`] = paramValues[`${role}_model_str_${i + 1}`] || '1.0';
    nextParams[`${role}_clip_str_${i}`] = paramValues[`${role}_clip_str_${i + 1}`] || '1.0';
  }

  // 最後のスロットの値をクリア
  delete nextParams[`${role}_lora_name_${currentCount}`];
  delete nextParams[`${role}_lora_wt_${currentCount}`];
  delete nextParams[`${role}_model_str_${currentCount}`];
  delete nextParams[`${role}_clip_str_${currentCount}`];

  // 件数をデクリメント
  nextParams[`${role}_lora_count`] = String(currentCount - 1);
  setParamValues(nextParams);
};
```

### 3-2. サニタイズ（ペイロード生成時）
生成時に `lora_count` を基準とし、それを超えるインデックスに該当する不要なキーをノードの `inputs` から明示的に削除する。
```typescript
if (m.input_type === 'lora_stack') {
  const node = wfJson[m.node_id];
  if (node && node.inputs) {
    const loraCountVal = parseInt(paramValues[`${m.role}_lora_count`] || '0');
    node.inputs['lora_count'] = loraCountVal;

    // 1 から loraCountVal までを注入
    for (let i = 1; i <= loraCountVal; i++) {
      node.inputs[`lora_name_${i}`] = paramValues[`${m.role}_lora_name_${i}`] || '';
      node.inputs[`lora_wt_${i}`] = parseFloat(paramValues[`${m.role}_lora_wt_${i}`] || '1.0');
      node.inputs[`model_str_${i}`] = parseFloat(paramValues[`${m.role}_model_str_${i}`] || '1.0');
      node.inputs[`clip_str_${i}`] = parseFloat(paramValues[`${m.role}_clip_str_${i}`] || '1.0');
    }

    // 登録されている inputs キーのうち、loraCountVal を超えるインデックスのキーを削除
    Object.keys(node.inputs).forEach((key) => {
      const match = key.match(/^(lora_name|lora_wt|model_str|clip_str)_(\d+)$/);
      if (match) {
        const idx = parseInt(match[2]);
        if (idx > loraCountVal) {
          delete node.inputs[key];
        }
      }
    });
  }
}
```

### 3-3. 履歴プレビューでのグループ化表示
`HistoryModalPreview.tsx` でパラメータをループ処理する際、`_lora_name_` / `_lora_wt_` などのプレフィックス/サフィックスを検知してLoRAスタックとして認識する。
```typescript
// パラメータ解析
const loraStacks: Record<string, Array<{ name: string; weight: number }>> = {};
if (snapshot?.params) {
  Object.entries(snapshot.params).forEach(([key, val]) => {
    // 例: "15_lora_name_1" もしくは "lora_name_1"
    const nameMatch = key.match(/^(.*?)_?lora_name_(\d+)$/);
    if (nameMatch) {
      const prefix = nameMatch[1] || 'default';
      const index = nameMatch[2];
      const wtKey = Object.keys(snapshot.params).find(k => k === `${prefix}_lora_wt_${index}` || k === `lora_wt_${index}`);
      const weight = wtKey ? parseFloat(snapshot.params[wtKey]) : 1.0;
      
      if (!loraStacks[prefix]) {
        loraStacks[prefix] = [];
      }
      loraStacks[prefix].push({ name: String(val), weight });
    }
  });
}
```
これらを「LoRA Stack (easyLoraStack)」という名前で専用のテーブルにグループ化して表示する。
また、LoRA表示名のマッピングロジック（`lorasApi.list` から取得した `lora.description` があればそれを使用し、なければ `file_path` を使用）を適用する。
