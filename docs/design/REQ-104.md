# Design Document: REQ-104 モバイルレイアウトでの Scheduler/Sampler 選択肢の欠落問題の修正

## 1. Summary
本ドキュメントは、モバイル端末や外部 IP を経由した接続において、パラメータパネル（`ParamPanel`）の `Scheduler` や `Sampler` のドロップダウン選択肢に欠落が生じ、ComfyUI の全選択肢（例: `beta`）が表示されなくなる問題を修正するための設計を定義します。

## 2. Design Principles & Changes

### 2-1. `useGeneratePageState.ts` における `comfyUrl` の解決処理の追加
フロントエンドの `useGeneratePageState.ts` 内で `comfyObjectInfo` をフェッチする際、Vite のリバースプロキシ用 URL `/comfy` などを適切に考慮してローカルループバックアドレス（`localhost` / `127.0.0.1`）を解決する `resolveComfyUrl` ヘルパー関数を適用します。これにより、モバイルデバイス等の外部端末からアクセスした場合でも、Vite のプロキシサーバーを経由して ComfyUI のオブジェクト情報を正しく取得できるようになります。

#### 変更対象ファイル：`frontend/src/pages/GeneratePage/hooks/useGeneratePageState.ts`
- `resolveComfyUrl` を `../../../hooks/useComfyWebSocket` からインポートします。
- `comfyObjectInfo` の取得処理（React Query の `queryFn`）において、`comfyUrl` の代わりに `resolveComfyUrl(comfyUrl)` を使用するように書き換えます。

```typescript
// 変更前
const res = await fetch(comfyUrl + '/object_info', { signal: AbortSignal.timeout(3000) })

// 変更後
const resolvedUrl = resolveComfyUrl(comfyUrl)
const res = await fetch(resolvedUrl + '/object_info', { signal: AbortSignal.timeout(3000) })
```

### 2-2. `ParamPanel.tsx` におけるフォールバック値（デフォルトリスト）の拡充
万が一、ComfyUI の接続がオフラインの場合でも最低限の標準的なサンプラーおよびスケジューラーが選択できるように、`ParamPanel.tsx` の `DEFAULT_SCHEDULERS` および `DEFAULT_SAMPLERS` 配列を最新の ComfyUI に合わせて拡充します。

#### 変更対象ファイル：`frontend/src/pages/GeneratePage/components/ParamPanel.tsx`
- `DEFAULT_SCHEDULERS` 配列に `beta` などの一般的なスケジューラーを追加します。

```typescript
// 変更後（例）
const DEFAULT_SCHEDULERS = [
  'normal', 'karras', 'exponential', 'sgm_uniform', 'simple', 'ddim_uniform', 'beta'
]
```

## 3. Impact Range & Risks
- **通信経路**: 接続解決のためのフロントエンド側のみの修正であり、バックエンドや DB スキーマへの影響はありません。
- **セキュリティ**: すでに websocket 接続等で `resolveComfyUrl` を通した Vite Proxy（`/comfy`）を利用しているため、新たなセキュリティ上の懸念はありません。

## 4. Verification Plan
- ブラウザ環境下にて、ネットワークのタイムアウトやエラーが発生した際のフォールバック動作を検証するため、テストコードまたは手動検証により確認します。
- デバイスエミュレーション等でモバイルレイアウト時の動作確認を行います。
