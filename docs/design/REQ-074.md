# REQ-074: GeneratePage.tsx の分割リファクタリング設計

## 1. 目的と背景
`GeneratePage.tsx` は約 2,000 行に肥大化しており、状態管理、APIのミューテーション、複数のサブパネル、およびレスポンシブ（デスクトップ・モバイル）レイアウトがすべて単一ファイルに混在しています。これにより、コードの可読性および保守性が低下しています。
本設計では、UIコンポーネント、状態制御ロジック、およびレイアウト表示を疎結合化し、モジュール性を高めます。

## 2. アーキテクチャ構成

### 2.1 新規カスタムフック
- **`useGeneratePageState`** (`src/pages/GeneratePage/hooks/useGeneratePageState.ts`)
  - `GeneratePage.tsx` の内部状態（モーダル開閉、タブ選択、ソート状態等）を集中管理。
  - ワークフローおよびプリセット関連の mutations を集約・提供。
  - 各ハンドラー関数（`handleLoadSnapshot`, `handleAddLoraAsset` 等）をカプセル化。

### 2.2 新規コンポーネントの抽出 (`src/pages/GeneratePage/components/`)
1. **`SettingsPopover.tsx`**: ComfyUIのURL設定およびワークフロー設定パネル。
2. **`AssetDropdown.tsx`**: LoRAおよびTagSetのアセット選択ドロップダウン。
3. **`AppliedAssetChips.tsx`**: 適用済みアセットのトグル・削除チップリスト。
4. **`AuditPanel.tsx`**: LLM Audit 実行および結果表示パネル。
5. **`MappingErrorPanel.tsx`**: ワークフローの役割マッピングエラー表示・修正パネル。
6. **`ParamPanel.tsx`**: パラメータ、バッチサイズ、シード値等のパラメータ入力パネル。
7. **`DesktopLayout.tsx`**: PC/デスクトップ環境用レイアウト。
8. **`MobileLayout.tsx`**: モバイル環境用レイアウト。

### 2.3 `GeneratePage.tsx` の役割
- デバイス判定（`isMobile`）を行い、`DesktopLayout` と `MobileLayout` を切り替えるエントリーポイントとしての役割のみを持つ。
- `useGeneratePageState` を呼び出して状態を取得し、各レイアウトコンポーネントに props として分配する。

## 4. 影響範囲
- `GeneratePage.tsx` 内部のリファクタリングであるため、他のページ（`HistoryPage`, `SettingsPage` 等）やグローバルストアへの破壊的変更はありません。
- 既存のテストスイート `useGenerateAction.test.ts` などが正しく動作し続けることを保証します。
