# 設計書: REQ-037 WebSocket生成完了時のプレビュー・履歴自動更新バグ修正

## 1. 概要
画像生成完了時（WebSocketの `executed` / `execution_complete` イベント受信時）に、画面をリロードすることなく、プレビューおよび履歴エリア（サムネイル一覧）に生成画像がリアルタイムで即座に反映されるようにします。
また、履歴ソート処理におけるUUID非互換バグを修正し、WebSocket切断時の自動再接続・クリーンアップ機構を整備します。

## 2. 影響範囲と依存関係
- **frontend**:
  - `frontend/src/store/useGenerationStore.ts`: 
    - WebSocketイベントハンドラ (`executed` / `execution_complete`) の更新。
    - 履歴一覧 (`comfyHistoryImages`) の即時ローカル更新処理の追加。
    - 履歴取得メソッド (`fetchHistory`) のソートロジック修正（UUIDキー対応）。
    - WebSocket切断時の自動再接続（レジリエンス向上）およびクリーンアップ処理の実装。

## 3. 詳細設計

### 3.1. 履歴画像リストの即時ローカル更新とレースコンディションの解消
- **現象**: WebSocket受信後すぐに `/history` APIを叩いても、ComfyUIの内部DB/ファイル保存処理が完了していない場合があり、新規画像が履歴一覧に表示されない（レースコンディション）。
- **対策**:
  1. `executed` イベント受信時、イベントに含まれる `images` 配列からすべての画像URLを構築する（バッチサイズ > 1 にも対応）。
  2. 構築した画像URL群を、セッション限定履歴の `batchImages` だけでなく、全体履歴の `comfyHistoryImages` にも即時で先頭に差し込み（prepend）更新する。
  3. `/history` 取得の呼び出し自体は `setTimeout` を使用して `500ms` 遅延させて実行し、ComfyUI側の書き込み完了を待って同期する。

### 3.2. 履歴ソートロジックの修正（UUID対応）
- **現象**: `fetchHistory` 内で、ComfyUI履歴データのキー名（プロンプトID）を `Number(key)` キャストして降順ソートしている。しかしComfyUIが返すキー名がUUID（例: `"a1b2c3d4-..."`）の場合、`Number` キャストは `NaN` となり、ソート結果が不整合を起こして最新履歴が先頭に表示されなくなる。
- **対策**:
  - 履歴アイテム内の構造 `ComfyHistoryItem.prompt[0]` に格納されている sequential な実行インデックス（`number`）を基準に降順ソートするように修正する。
  ```typescript
  const sortedEntries = Object.entries(data).sort(([, itemA], [, itemB]) => {
    const indexA = (itemA as ComfyHistoryItem).prompt?.[0] || 0
    const indexB = (itemB as ComfyHistoryItem).prompt?.[0] || 0
    return indexB - indexA
  })
  ```

### 3.3. WebSocket自動再接続およびクリーンアップ
- **現象**: 接続エラーや一時的なサーバーダウンでWebSocketが切断された場合、状態 `isConnected` が `false` になるだけで再接続されない。また、シングルトン変数 `ws` が残るため、以降の `initialize()` 呼び出しが早期リターンでブロックされてしまう。
- **対策**:
  - モジュールスコープ変数 `reconnectTimer` を導入。
  - `ws.onclose` および `ws.onerror` 時に `ws` シングルトン変数を `null` にクリアする。
  - `ws.onclose` 時に `reconnectTimer` が未設定であれば `setTimeout`（例: 3秒）で `initialize()` を再実行し、自動的に接続修復を試みる。
  - `setComfyUrl()` や `initialize()` の冒頭で既存の `reconnectTimer` を確実にクリア（クリーンアップ）する。
