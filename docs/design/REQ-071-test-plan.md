# REQ-071 実行可能テスト計画: 並び替え操作時と長押し複数選択操作の競合不具合の修正

## 1. 自動テスト (Unit Tests)

### 1-1. テスト項目

`frontend/src/hooks/__tests__/useMultiSelect.test.ts` において、以下のテストケースを追加・検証する。

1. **しきい値を超えるマウス移動によるキャンセル**:
   - `onMouseDown` 後、10pxを超える `onMouseMove` イベントが発生した場合、タイマーがクリアされ、800ms経過しても複数選択モードに移行しないこと。
2. **しきい値を超えるタッチ移動によるキャンセル**:
   - `onTouchStart` 後、10pxを超える `onTouchMove` イベントが発生した場合、タイマーがクリアされ、800ms経過しても複数選択モードに移行しないこと。
3. **しきい値未満の移動（手ブレ）での長押し成立**:
   - `onMouseDown` または `onTouchStart` 後、しきい値（10px）未満の極小の移動が発生した場合はタイマーがクリアされず、800ms経過時点で複数選択モードに移行すること。

### 1-2. テストの実行コマンド

```bash
npm run test -- frontend/src/hooks/__tests__/useMultiSelect.test.ts
```

## 2. 手動検証 (Manual Verification)

### 2-1. 現象の解消確認手順

1. **ドラッグによる並び替え**:
   - アルバム画面、LoRA画面、またはTagセット画面を開く。
   - 任意のアイテム（カード）をドラッグ（マウス長押し＋移動、またはタッチ長押し＋移動）し、そのままボタンを離さずに1秒以上待機する。
   - **確認事項**: 複数選択モード（チェックボックス）が誤発火せず、そのままドラッグ＆ドロップによる並び替えが成功すること。
2. **静止状態の長押し（複数選択モード起動）**:
   - アイテムをドラッグせずにその場で長押し（デフォルト0.8秒以上）する。
   - **確認事項**: 複数選択モードが正常に起動し、チェックボックスが表示されること。
3. **手ブレ耐性の検証**:
   - アイテム上でクリック/タッチし、意図的にわずかに（2〜3px程度）マウスや指を滑らせながら長押しする。
   - **確認事項**: 軽微なブレであれば移動とみなされず、0.8秒経過時に正しく複数選択モードが起動すること。
