# REQ-186: 生成画面のプリセット管理モーダルにおけるモーダル継続表示と複数タブ開閉操作性の改善 詳細設計書

## 1. 概要と背景
生成画面の「プリセット管理」モーダルにおいて、以下の課題が存在していました：
1. **プリセット選択時の自動クローズによる作業分断**: プリセット一覧からプリセットを選択（ロード）すると、モーダルが自動的に閉じてしまうため、複数のプリセットを続けて切り替えたり確認したりする際に都度モーダルを再展開する必要がある。
2. **モーダル内からのタブ開閉操作の欠落**: 現在どのプリセットがタブバーに展開されているかがモーダル上で把握しづらく、またモーダルを開いたままタブを閉じたり開いたりを連続して整理する導線がない。

本設計では、プリセット選択後もモーダルを開いたまま維持し、モーダル内から各プリセットの「タブ表示状態の把握」および「タブを開く / 閉じる」操作を直接実行可能とすることで、連続的で軽快なタブ整理・プリセット適用体験を提供します。

---

## 2. アーキテクチャ・UI設計詳細

### 2.1 プリセット管理モーダルの継続表示
- **対象**: `frontend/src/pages/GeneratePage.tsx`
- **変更内容**:
  - `PresetManagerPanel` の `onOpenAsTab` コールバック内で `setIsPresetManagerOpen(false)` を呼び出していた処理を削除。
  - プリセット選択（ロード/適用）時もモーダルは閉じず、背後の生成画面側のタブ状態・パラメータが更新される。
  - ユーザーはモーダル右上の「✕」ボタンや背景オーバーレイのクリックで明示的にモーダルを閉じられる。

### 2.2 モーダル内でのタブ状態表示とタブ閉じる操作
- **対象**: `frontend/src/components/PresetManagerPanel.tsx`
- **Props 追加**:
  - `openPresetIds?: (string | number)[]`: 現在タブバー上に展開されているプリセットID一覧。
  - `onCloseTab?: (id: string | number) => void`: タブを閉じる（`openPresetIds` から除外し、必要に応じてアクティブタブを切り替える）ハンドラ。
- **UI 表示・操作**:
  - `SortablePresetRow` において、`openPresetIds` に含まれるプリセットは `isOpenAsTab = true` と判定。
  - `isOpenAsTab` のプリセットには「タブ表示中」バッジを表示。
  - 通常モード時（`bulkMode === false`）、`isOpenAsTab` であればアクションボタン部に「タブを閉じる」ボタン（`id="preset-close-tab-btn-${preset.id}"`、`title="タブを閉じる"`）を表示。
  - 「タブを閉じる」ボタン押下時は、イベントのバブリング（`e.stopPropagation()`）を抑止した上で `onCloseTab(preset.id)` を実行。
  - プリセット行自体のクリックは従来どおり `onOpenAsTab(preset.id)` を呼び出し、タブを開いてアクティブに切り替える。

### 2.3 `GeneratePage` との連携
- **対象**: `frontend/src/pages/GeneratePage.tsx`
- **連携内容**:
  - `useGenerationStore` から提供される `openPresetIds` および `removeSet` を `PresetManagerPanel` に渡す：
    - `openPresetIds={openPresetIds}`
    - `onCloseTab={(id) => removeSet(id)}`
