# REQ-142 テスト計画書: セリフ編集における新規吹き出し作成時の装飾設定の直前設定引き継ぎおよびlocalStorage永続化

## 1. 自動テスト (Automated Unit Tests)

### テスト対象ファイル
- `frontend/src/components/__tests__/SpeechBubbleEditorModal.test.tsx`

### テストケース
1. **新規吹き出し作成時の直前設定引き継ぎ**:
   - 既存の吹き出しの装飾設定（例: `fontFamily: 'msgothic.ttc'`, `textColor: 'rgba(255, 0, 0, 1)'`, `shape: 'burst'`, `orientation: 'horizontal'` 等）を変更後、ダブルクリックで新しい吹き出しを作成した際、新しい吹き出しに直前の装飾設定が反映されていること。
2. **localStorageへの保存と初期化時の復元**:
   - 吹き出しの装飾設定を変更した際に `localStorage` の `speech_bubble_last_used_style` に設定が保存されること。
   - `localStorage` にあらかじめスタイル設定が保存されている状態でモーダルを起動した場合、新規追加する吹き出しに保存されていたスタイルが初期適用されること。
3. **既存吹き出し選択時の個別設定保持**:
   - 異なる装飾設定を持つ2つの吹き出し（吹き出しA: 青背景、吹き出しB: 黄背景）が存在する場合、吹き出しAから吹き出しBへ選択を切り替えた際、吹き出しB自身のプロパティ（黄背景）がUIに保持・表示され、意図しない上書きが発生しないこと。
4. **局所的編集の独立性**:
   - 直前設定を引き継いで作成された新しい吹き出しのスタイルを変更した際、既存の吹き出しの設定値に影響を与えないこと。

### 実行コマンド
```bash
cd frontend && npm test -- src/components/__tests__/SpeechBubbleEditorModal.test.tsx --run
```

---

## 2. 手動確認手順 (Manual Verification Plan)
1. スナップショットカードから「セリフ編集・吹き出し追加」モーダルを開く。
2. 最初の吹き出しを選択し、フォントを「MS Gothic」、文字色を「赤」、吹き出し形状を「角丸」、文字方向を「横書き」に変更する。
3. モーダルを一度キャンセルまたは閉じる。
4. 再度別のスナップショットでセリフ編集モーダルを開き、空き領域をダブルクリックして新規吹き出しを追加する。
5. 新しく追加された吹き出しがセッションを跨いで「MS Gothic」「赤文字」「角丸」「横書き」で初期化されていることを確認する。
6. 個別の吹き出しの装飾を変更し、他の吹き出しに影響がないことを確認する。
