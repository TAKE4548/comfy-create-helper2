# PBI-REQ-070 実行可能テスト計画

## 1. 自動テスト (CLI Verification)
- **ビルド・静的解析**:
  - `npm run build` を `frontend/` で実行し、ビルドエラーがないことを確認する。
  - `npm run lint` または `eslint` を実行して構文上の警告やエラーがないことを確認する。

## 2. ツール主導監査 (Tool-Driven Audit)
- 該当なし（API仕様およびDBスキーマの変更は発生しないため）。

## 3. ブラウザ検証 (Browser Agent Verification)
- **対象URL**: `http://localhost:5173/` (フロントエンドローカル開発サーバー)
- **操作手順**:
  1. ブラウザのデベロッパーツールを開き、端末シミュレーターでモバイルサイズ（例：iPhone 12 Pro, 390x844）にする。
  2. 生成履歴等から画像をクリックし、全画面プレビューモーダルを開く。
  3. 縦長の画像を選択し、表示を確認する。
  4. プレビューのまま、画面最下部を確認する。
- **判定基準 (Assertion)**:
  - アプリ下部のボトムナビゲーションバーがプレビュー画像やモーダルの一部を隠しておらず、プレビューが前面を完全に覆っていること。
  - 縦長画像が画面外にはみ出して上下が切り取られることなく、アスペクト比を保ったまま画面高さに合わせて縮小表示されていること（長辺基準のスケールが正しく効いていること）。
- **必須エビデンス**:
  - モバイルサイズでの全画面プレビュー時のスクリーンショットを撮影する。
