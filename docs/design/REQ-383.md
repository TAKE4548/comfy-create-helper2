### 2. 閲覧モデル3階層整理・最新-first固定・右上共有ツールバー設計 (AC-1, AC-5, AC-6, AC-10, AC-11)

1. **閲覧モデル3階層と最新-first固定 (AC-1)**: 第1階層（メインプレビュー: `GenerateParallelPreview`）、第2階層（履歴: `GenerationGallerySection`）、第3階層（詳細モーダル: `HistoryModalPreview`）で構成。`useGenerateDisplayState.ts` の `sortedDisplayImages` を最新画像先頭（`index 0`、右方向へ過去画像）に固定し、`GenerationGallerySection.tsx` デスクトップのソート順反転操作を非表示化する（AC-1）。
2. **`GenerateParallelPreviewProps` 契約**:
   ```tsx
   export interface GenerateParallelPreviewCenterRequest { image: string; seq: number }
   export interface GenerateParallelPreviewProps {
     images: string[]; selectedImage: string | null; aspectRatios?: Record<string, number>
     onSelect: (image: string) => void; onOpen: () => void; onImageUnavailable?: (image: string) => void
     previewAutoFollow?: boolean; onToggleAutoFollow?: () => void
     filterOwnSession?: boolean; onToggleFilterOwnSession?: (checked: boolean) => void
     isHistoryExpanded?: boolean; onToggleHistoryExpanded?: () => void
     isMultiSelectMode?: boolean; centerRequest?: GenerateParallelPreviewCenterRequest | null
   }
   ```
3. **右上共有ツールバーと端点ジャンプ (`data-testid="generate-reel-toolbar"`, AC-5, AC-6, AC-10, AC-11)**:
   1. `← 最新へ` (`data-generate-reel-latest="true"`, `hidden={scrollLeft < 72}`): 過去側へスクロール移動中に表示。押下時に進行中のスクロール慣性を即座に停止（`stopInertia()`）し、最新画像（先頭 `index 0`）をプレビュー水平中央へ移動・表示する（AC-5）。
   2. `最古へ →` (`data-generate-reel-oldest="true"`, `disabled={images.length <= 1}`): 複数画像時に常時利用可能。押下時に進行中のスクロール慣性を即座に停止（`stopInertia()`）し、最古画像（末尾）をプレビュー水平中央へ移動・表示する（AC-6）。
   3. `最新追従` (`data-generate-reel-auto-follow="true"`, `aria-pressed={Boolean(previewAutoFollow)}`): プレビュー上部と履歴ペイン内（`#preview-autofollow-toggle-desktop`）で単一状態（`previewAutoFollow`）を共有し、一方を切り替えた際にもう一方の表示状態も即座に同じON/OFF状態へ同期する（AC-10）。
   4. `自セッション` (`data-generate-reel-session-filter="true"`, `aria-pressed={Boolean(filterOwnSession)}`): プレビュー上部と履歴ペイン内（`#session-filter-toggle`）で単一状態（`filterOwnSession`）を共有し、一方を切り替えた際にもう一方の表示状態も即座に同じON/OFF状態へ同期して表示対象画像群に反映する（AC-11）。
   5. `履歴` (`data-generate-reel-history-toggle="true"`, `aria-expanded={Boolean(isHistoryExpanded)}`): 履歴ペインを開閉する。

### 3. 連続リールレイアウト・混在アスペクト比・慣性中央吸着・詳細モーダル設計 (AC-2, AC-3, AC-4, AC-12, AC-14)

1. **混在アスペクト比維持と領域内収まり (AC-4)**:
   - リール（`role="listbox"`, `data-testid="generate-reel-viewport"`, `overflow-x-auto overflow-y-hidden`, `overscrollBehaviorX: 'contain'`）の有効高 `availableHeight = Math.max(80, reelClientHeight - 24)`、有効幅 `viewportWidth = Math.max(240, reelClientWidth)`、最大幅 `maxWidth = Math.max(120, viewportWidth * 0.86)` を算出。
   - アスペクト比 `ar = clamp(aspectRatios?.[img] ?? loadedAspectRatios[img] ?? (2 / 3), 0.3, 3.0)` に対し、`widthFromHeight = availableHeight * ar`、`tileWidth = Math.round(Math.max(80, Math.min(widthFromHeight, maxWidth)))`、`tileHeight = Math.round(Math.max(80, widthFromHeight > maxWidth ? tileWidth / ar : availableHeight))` を設定。縦長・正方形・横長（2:1等）が混在する状態で元アスペクト比を維持しつつプレビュー領域を上下・左右にはみ出さず、細長い空枠や極端な縮小なしに表示する（AC-4）。
2. **端部スクロール余白と初期中央配置 (AC-2)**:
   - 先頭・末尾画像の表示幅を圧縮せず、先頭に `marginLeft = Math.max(0, Math.round(viewportWidth / 2 - firstTileWidth / 2 - paddingLeft))`、末尾に `marginRight = Math.max(0, Math.round(viewportWidth / 2 - lastTileWidth / 2 - paddingRight))` を付与。初期表示（`scrollLeft = 0`）では最新画像（先頭）中心が水平中央に配置され、最新・最古いずれの端点画像も水平中央へ吸着・配置できる（AC-2）。
3. **ホイールインパルス慣性・減衰・中央吸着 (AC-3)**:
   - `wheel`（`{ passive: false }`, `event.preventDefault()`）でマウスホイール（係数 `0.38`）やトラックパッド横スクロール（係数 `0.28`）連続入力を `velocityRef.current` に加算し `requestAnimationFrame` で駆動。毎フレーム減衰率 `0.89` を乗算し、不要な振動や急停止を起こさず滑らかに横スクロール・減衰させ、閾値 `0.35` 未満で停止した後に最も中心に近い画像をプレビュー水平中央へ吸着させる（AC-3）。新着追加時は `previewAutoFollow` ON なら最新中央、OFF なら閲覧中画像の相対位置をアンカー補正する。
4. **詳細モーダル起動と横スクロール抑止 (AC-12, AC-14)**:
   - タイル（`role="option"`, `data-generate-reel-tile="true"`）クリック時に `stopInertia()` → `onSelect(image)` → `onOpen()` を呼び、既存の `HistoryModalPreview`（拡大表示・`Escape` キーまたは閉じるボタンでClose）を起動する（AC-12）。キーボード `Home`/`End`/`ArrowLeft`/`ArrowRight` を実装し、ルートと各ペインに `min-w-0 overflow-hidden` を適用して操作中の `document.body` 横スクロールバー（`overflow-x`）発生を防止する（AC-14）。

### 4. 履歴ペイン双方向同期・複数選択保護・ローカルClose設計 (AC-7, AC-8, AC-9, AC-13)

1. **通常クリック時の双方向同期と複数選択・修飾キー時のスクロール抑止 (AC-7, AC-8)**:
   - `useGenerateDisplayState.ts` で `isMultiSelectMode` 中に `selectedIds` 変化で `selectedImg` を上書きする副作用を停止。
   - `useGalleryInteraction.ts` の `handleThumbnailClick(img, index, event)` で、**通常状態（`!multiSelect.isMultiSelectMode`）かつ修飾キーなし（`!event.ctrlKey && !event.metaKey && !event.shiftKey`）のクリック時のみ**対象画像を選択状態（`setSelectedImg(img)`）にし、`onCenterPreviewImage?.(img)` → `centerRequest` でメインプレビューを該当画像の水平中央へスクロール移動・表示する（AC-7）。
   - 複数選択モード有効または修飾キー（`Ctrl`/`Meta`/`Shift`）押下時は `multiSelect.handleItemClick` のみを実行して複数選択状態のみを更新し、メインプレビューの表示位置を移動・ジャンプさせない（AC-8）。
2. **境界バー `⌄ 履歴を閉じる` と既存履歴操作維持 (AC-9, AC-13)**:
   - `DesktopLayout.tsx` で `isHistoryExpanded`（初期値 `false`）を管理し、展開時は境界バーに `<button data-generate-reel-history-close="true" aria-label="履歴ペインを閉じる">⌄ 履歴を閉じる</button>` を配置。押下により履歴ペインが閉じ、メインプレビュー表示領域が展開前の通常表示高へ復帰する（AC-9）。複数選択チェックボックス操作・一括保存・選択解除・スナップショットタブ切り替えおよび REQ-362 キャッシュ契約をエラーなく動作させる（AC-13）。
