# Test Plan: REQ-105 Scene Generatorの追加調整

本ドキュメントは、REQ-105における変更内容に対するテスト方針および実行コマンドを定義する。

## 1. ユニットテスト / 統合テスト

### 1-1. バックエンドテスト
バックエンドに新しく追加したエンドポイントおよびLLM切り替えのテストを追加する。
`backend/tests/test_llm_prompts.py` または新規ファイル `backend/tests/test_llm_models.py` を作成し、以下を検証する。

1. `GET /api/llm-prompts/models` が LM Studio API のレスポンスをモック化して正しくモデル一覧を返却すること。
2. `GET /api/llm-prompts/current-model` がDBに値がない場合デフォルト値を返却し、値がある場合その値を返却すること。
3. `PUT /api/llm-prompts/current-model` が指定されたモデル名をDBに永続化し、以降の `call_llm` でそのモデル名が使用されること。

#### テスト実行コマンド
```bash
pytest backend/tests/test_llm_models.py -v
```

## 2. フロントエンドの手動検証項目

### 2-1. 設定画面（Settings）の検証
1. 設定画面を開き、新しく追加された「LLM Model Settings」セクションが表示されていることを確認する。
2. LM Studioが起動している場合、ロードされているモデルの一覧がドロップダウンに表示されること。
3. モデルを変更し「Save」等のアクション（あるいは変更時即時保存）を実行後、ページをリロードしても変更後のモデルが選択されたままになっていることを確認する。
4. 「LLM System Prompts」セクションに「Scene Generator プロンプト」が追加されており、テキストエリアでプロンプトを編集・保存できることを確認する。

### 2-2. Scene Generator モーダルの検証
1. 生成画面（Generate）から「Scene Generator」モーダルを起動する。
2. 「Base Profile」のドロップダウンが表示されており、初期状態で「現在の値」が選択されていることを確認する。
3. ドロップダウンを展開し、保存済みの別のプリセットを選択した際、シーンドラフト生成のベースとなる値がそのプリセットの値に切り替わることを確認する。
4. シーンの概要テキスト（例：「学校の屋上、たたずむ少女」）を入力し、生成を実行した際、設定画面で選択したモデルとプロンプトが適用され、適切なフィールド（例：構図、背景等）に適切な英語タグが複数生成されることを確認する。
