# Design Document: REQ-342 - Fix Node Candidate Label Missing Title and Class Type

## 1. Overview & Architectural Context
In ComfyUI workflows, candidate nodes displayed in dropdowns (during workflow registration and node remapping) must consistently display their ID, title, and node class type in the standardized format:
`${id} - [${title}] (${classType})`

Prior to this fix:
- `RescanModal.tsx` relied on an incomplete map (`nodeTitleMap`) derived solely from `scanResult.matched`. Candidate nodes beyond the 1st match in a role had `nodeTitleMap.get(id) === undefined`, rendering as raw IDs (e.g., `11`), and even matched nodes displayed the master role instead of the node class (`(Role)`).
- `UploadWorkflowModal.tsx` only inspected `node._meta?.title`, lacking fallbacks to `node.title` and `class_type`, which produced empty bracket labels `${id} - [] (${classType})`.
- `NodeRemapModal.tsx` omitted titles when `title` was not explicitly present on the node, rendering `#{id} - (${classType})`.

## 2. Unified Utility Architecture (`frontend/src/utils/workflowNodeUtils.ts`)
To establish a Single Source of Truth for node label formatting, introduce `getNodeLabel` and `resolveNodeMetadata`:

```typescript
export interface ResolvedNodeMetadata {
  id: string
  title: string
  classType: string
}

export function resolveNodeMetadata(
  id: string,
  workflowJson?: Record<string, any> | null
): ResolvedNodeMetadata {
  if (!workflowJson || typeof workflowJson !== 'object') {
    return { id, title: '', classType: '' }
  }

  let rawNode: Record<string, any> | undefined = undefined

  if (workflowJson[id] && typeof workflowJson[id] === 'object') {
    rawNode = workflowJson[id]
  } else if (Array.isArray(workflowJson.nodes)) {
    rawNode = workflowJson.nodes.find(
      (n: any) => n && String(n.id) === String(id)
    )
  }

  if (!rawNode) {
    return { id, title: '', classType: '' }
  }

  const classType = String(rawNode.class_type || rawNode.type || '').trim()
  const customTitle = String(
    rawNode._meta?.title || rawNode.title || ''
  ).trim()

  const title = customTitle || classType || ''

  return { id, title, classType }
}

export function getNodeLabel(
  id: string,
  workflowJson?: Record<string, any> | null
): string {
  const meta = resolveNodeMetadata(id, workflowJson)
  if (!meta.title && !meta.classType) {
    return id
  }
  if (meta.title && meta.classType) {
    return `${id} - [${meta.title}] (${meta.classType})`
  }
  if (meta.title) {
    return `${id} - [${meta.title}]`
  }
  return `${id} - (${meta.classType})`
}
```

## 3. Component Integration Design
1. **RescanModal.tsx**:
   - Remove obsolete `nodeTitleMap` state / useMemo.
   - Replace `{id}{nodeTitleMap.get(id) ? ... : ''}` with `getNodeLabel(id, workflowJson as Record<string, any>)`.
2. **UploadWorkflowModal.tsx**:
   - Replace local `getNodeLabel` with the imported `getNodeLabel(id, workflowJson as Record<string, any>)`.
3. **NodeRemapModal.tsx**:
   - Replace local `getNodeLabel` with the imported `getNodeLabel`.
   - Update parameter mapping options to use `getNodeLabel(id, workflow.json_body as Record<string, any>)`.

## 4. Security & Performance
- Zero additional network calls or API dependencies.
- O(1) dictionary lookup for API prompt workflows, O(N) fallback only if UI graph array format is uploaded.
- Safe handling of null/undefined inputs without runtime crashes.
