## 3. ブラウザ検証 (Browser Agent Verification)
- **対象URL**: `http://localhost:5173/` (フロントエンドのローカル開発サーバーURL)
- **操作手順**:
  1. スナップショット一覧から、画像を含む最初（IDが最も小さいもの）のスナップショットカードを選択し、「セリフ編集」モーダルを開く。
  2. モーダル内の「フォント」セレクトボックス（`<select>`）をクリックし、一覧から `"ＭＳ ゴシック (MS Gothic)"` を選択する。
  3. セリフテキスト（`<textarea>`）に「こんにちはー」と入力する。
  4. 一度テキストを消去し、セリフテキストに「とても長い文章を入力して、フォントサイズが自動で縮小されるか検証します。この長文は吹き出しの枠外にはみ出さないように自動でフォントサイズが小さくなる必要があります。」と入力する。
  5. 編集後、「保存して履歴へ追加」ボタンをクリックして保存する。
- **判定基準 (Assertion)**:
  - 選択したスナップショットカードの画像が正常にロードされること。
  - 「フォント」セレクトボックスのデフォルト値が選択可能であること。
  - テキストが吹き出しプレビュー Canvas 領域内で右端から左端に向けて縦書きで表示されていること。
  - 長音符「ー」が縦書き用の直線「｜」として Canvas にレンダリングされていること。
  - 長文を入力した際、文字が吹き出しのバウンディングボックスの枠線（緑色）の外側にはみ出していないこと。
  - 手動のフォントサイズスライダー（`input[type="range"]`）がモーダルUI上に存在しないこと。
- **必須エビデンス**:
