# REQ-136 詳細設計書: 任意位置へのセリフ手動追加および吹き出し・テキスト装飾機能

## 1. 概要 (Overview)
現状の `SpeechBubbleEditorModal` は、単一の矩形検出（自動検出またはROI矩形ドラッグ）を対象に、黒文字・白背景の縦書きテキストを描画する仕様となっています。
本設計では、複数の吹き出し・セリフをキャンバス上の任意位置へダブルクリック/ダブルタップで追加・配置・ドラッグ移動でき、各吹き出しごとに形状（楕円、角丸四角、叫び/トゲトゲ、思考/モコモコ、枠なし）、テキスト方向（縦書き/横書き）、フォント・サイズ・文字色（RGBA）・背景色（RGBA）・枠線色（RGBA）・枠線幅、および尻尾（突起）位置をインタラクティブにカスタマイズ・描画・保存できるアーキテクチャを構築します。
さらに、カラーピッカーには直近で使用した色（RGBA）を最大10件記録し、「最近使用した色」パレットからワンクリックで再利用できる機能を備えます。

## 3. 詳細データ構造 & レンダリング設計 (Detailed Architecture)

### 3.1 吹き出しデータ構造 (`frontend/src/types/speechBubble.ts`)
```typescript
export type BubbleShapeType = 'oval' | 'rounded-rect' | 'burst' | 'cloud' | 'none'
export type TextOrientation = 'vertical' | 'horizontal'

export interface BubbleTail {
  x: number // 元画像座標系での尻尾先端X
  y: number // 元画像座標系での尻尾先端Y
}

export interface SpeechBubble {
  id: string
  x: number // 元画像座標系でのバウンディングボックスX
  y: number // 元画像座標系でのバウンディングボックスY
  w: number // 元画像座標系での幅
  h: number // 元画像座標系での高さ
  text: string
  shape: BubbleShapeType
  orientation: TextOrientation
  fontFamily: string
  fontSize?: number // 未指定(0)の場合はバウンディングボックス自動フィット
  textColor: string // rgba(r, g, b, a) または 8桁HEX
  backgroundColor: string // rgba(r, g, b, a)
  borderColor: string // rgba(r, g, b, a)
  borderWidth: number // ピクセル
  tail?: BubbleTail
}
```

### 3.2 吹き出し形状描画アルゴリズム (`speechBubbleRenderer.ts`)

1. **楕円 (Oval)**:
   - 中心 `(cx, cy)`、半径 `(rx, ry)` で `ctx.ellipse` を描画。
   - 尻尾がある場合、楕円外周上の2点と `tail(x, y)` を繋ぐ三角形ポリゴンを結合して塗りつぶし・枠線描画。
2. **角丸四角 (Rounded Rectangle)**:
   - `ctx.roundRect` または `arcTo` による角丸矩形。
   - 尻尾がある場合、矩形辺上の2点と `tail(x, y)` を繋ぐ三角形を結合。
3. **叫び・トゲトゲ (Burst / Shout)**:
   - バウンディングボックス外周に沿って多数の鋭角スパイク（星型多角形）パスを動的生成。
   - 尻尾位置に向かう頂点を延長して一体化描画。
4. **思考・モコモコ (Cloud / Thought)**:
   - バウンディングボックス外周に沿って複数の円弧（モコモコ）を繋いだパスを描画。
   - 尻尾は小さな円が2〜3個連なって `tail(x, y)` へ向かうスタイル。
5. **枠なし (None / Plain Text)**:
   - 背景・枠線を描画せず、テキストのみを描画。

### 3.3 テキストレイアウト & フィッティング
- **縦書き (Vertical)**:
  - 既存の `verticalCharMap` を使用し、長音や句読点、括弧を縦書き用約物にマッピング。
  - 列ごとの文字列を生成し、右列から左列へと文字を描画。
  - バウンディングボックス内に収まる最大フォントサイズをステップダウン計算。
- **横書き (Horizontal)**:
  - 改行文字 (`\n`) および最大幅での自動ワードラップ。
  - 上行から下行へと描画。
  - バウンディングボックス内に収まるフォントサイズをステップダウン計算。

### 3.4 カラーピッカー & 最近使用した色パレット (`RgbaColorPicker`)
- **RGB入力**: `<input type="color">` またはHEX入力
- **Alpha入力**: 不透明度スライダー (0%〜100%)
- **最近使用した色 (Recent Colors)**:
  - ユーザーが色を確定/選択した際、`localStorage` の `speech_bubble_recent_colors`（最大10件のキュー）に追加。
  - 文字色・背景色・枠線色ピッカーの直下に10個のカラーチップを表示し、クリックで現在編集中のカラープロパティに即時適用。

### 3.5 インタラクション仕様
- **新規追加**: キャンバス上ダブルクリックでクリック位置を中心にデフォルトバブル（`w: 160, h: 140`、縦書き、楕円、白背景、黒枠）を追加しフォーカス。
- **移動**: バブル内をマウスドラッグすることで `(x, y)` を更新。
- **尻尾調整**: 選択中バブルの尻尾先端に円形ハンドルを表示。ハンドルをドラッグすることで `tail(x, y)` を更新。
- **削除**: 選択中に `Delete` / `Backspace` キー、またはコントロールパネルの削除ボタン押下で削除。

## 4. 課題・リスクおよびトレードオフ (Trade-offs & Risks)

- **座標変換精度の維持**: キャンバス表示スケール（`scaleX`, `scaleY`）と元画像高解像度座標（`naturalWidth`, `naturalHeight`）の変換ズレを防ぐため、データモデルはすべて「元画像絶対座標」で保持し、レンダリング時のみスケールを掛ける。
- **パフォーマンス**: バブル移動やドラッグ時にスムーズに再描画できるよう、レンダラーは純粋な Canvas 2D Path 命令で完結させ、毎フレームの無駄な再生成を抑制する。
- **RGBAカラーピッカーの操作性**: ブラウザ標準の `<input type="color">` はアルファ値をサポートしないため、HEX/RGBカラー入力に加えて不透明度スライダー（0%〜100%）と最近使用した色チップ（10件）を組み合わせたRGBAコントロールを提供する。
