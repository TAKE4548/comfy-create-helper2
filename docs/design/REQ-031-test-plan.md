# テスト計画書 - REQ-031: ComfyUIキュー内のジョブ数表示機能の追加

## 1. テスト概要
本テスト計画では、ComfyUIのキュー内の待機数・進捗率が常時画面上に表示されること、および「自セッションのみ」フィルターが有効な場合と無効な場合で表示ジョブ数が正しく切り替わることを検証します。

## 2. 検証項目

### 2.1 ストア状態および同期検証 (フロントエンド)

1. **初期接続時のキュー同期**:
   - アプリ起動時、ComfyUI `/queue` から情報が取得され、`queueRunning` および `queuePending` に格納されること。
2. **WebSocketイベント連動**:
   - ジョブ生成をリクエストした際、WebSocketから `status` または `execution_start` が流れると同時に、キュー件数がインクリメントされること。
   - ジョブが完了 (`execution_complete`) または中断 (`cancelGeneration`) した際、キュー件数が正しくデクリメントされること。

### 2.2 画面表示およびフィルター連動検証 (UI表示)

1. **常時表示の確認**:
   - 生成中・未生成時を問わず、モバイル・デスクトップ両方のプレビュー領域付近に `Queue: {件数}` と `{進捗}%` が表示され続けていること。
   - ジョブがゼロの場合、`Queue: 0` / `0%` が表示されること。
2. **「自セッションのみ」フィルターとの連動**:
   - 他セッションでジョブが実行中または待機中の状態で、「自セッションのみ」にチェックを入れた場合、それらのジョブがカウントから除外されること。
   - チェックを外した場合、自他すべてのジョブの合計件数が表示されること。
3. **複数ジョブ投入時の連続変化**:
   - バッチ数を指定して生成を実行した際、キュー数に全件数が登録され、1件完了するごとにカウントが減っていくこと。
