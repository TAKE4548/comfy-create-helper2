# REQ-120 テスト計画書: 吹き出しセリフの縦書き化・フォントサイズ自動調整・サーバーフォント選択機能

## テスト環境前提条件
- フロントエンド: `npm run dev` が起動済みであること。
- バックエンド: `uvicorn app.main:app --reload` が起動済みであること。
- ブラウザ上でスナップショット一覧から「セリフ編集」モーダルを起動可能であること。

---

## テストケース一覧

### TC-1: サーバーフォント取得と動的ロードの検証 (AC-3-1, AC-3-2)
1. 吹き出し編集モーダルを開く。
2. **検証項目**:
   - モーダル内に「フォント」セレクトボックスが存在し、サーバー上のフォントリスト（ＭＳ ゴシック、メイリオ等）が表示されていること。
3. セレクトボックスで「メイリオ」または「遊ゴシック」を選択する。
4. **検証項目**:
   - 選択した書体が非同期でダウンロード・適用され、Canvas上のセリフテキストの書体が変化すること。

### TC-2: セリフテキストの縦書き描画の検証 (AC-1, AC-4, AC-5)
1. 吹き出し編集モーダルを開く。
2. セリフテキスト入力エリアに「こんにちはー\n縦書きのテストです」と入力する。
3. **検証項目**:
   - プレビューの吹き出し内で、テキストが縦書き（上から下）かつ右から左に改行されていることを確認する。
   - 長音符「ー」が「｜」に適切に変換されて描画されていることを確認する。
   - 保存ボタンを押下し、保存されたスナップショット画像でもプレビューと同一の縦書きレイアウト・書体が維持されていることを確認する。

### TC-3: フォントサイズ自動調整の検証 (AC-2)
1. 吹き出し編集モーダルを開く。
2. テキスト入力エリアに短いセリフ「こんにちは」を入力する。
3. **検証項目**:
   - 吹き出し内に収まる大きめのフォントサイズ（例: 24px以上）で描画されていることを確認する。
4. テキスト入力エリアに長文（例: 「この文章は吹き出しのフォントサイズ自動調整機能を検証するための非常に長いテキストであり、文字数が多くても吹き出しからはみ出さないようにフォントサイズが小さく調整されるべきです。」）を入力する。
5. **検証項目**:
   - フォントサイズが自動的に小さくなり（例: 10px〜12pxなど）、吹き出しの矩形領域内にすべての文字が収まっていることを確認する。

### TC-4: 手動設定UIの廃止の検証 (AC-3)
1. 吹き出し編集モーダルを開く。
2. **検証項目**:
   - 以前存在していた「フォントサイズ」のスライダーおよびサイズ数値（px）表示のUI要素が画面から完全に削除されており、非表示になっていることを確認する。
