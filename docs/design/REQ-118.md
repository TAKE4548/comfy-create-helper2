# REQ-118: ワークフローコピー時のバイパス設定引継ぎ機能 詳細設計書

## 1. 概要
ワークフローの複製機能 (`POST /api/workflows/{workflow_id}/copy`) 実行時に、ソースワークフローに紐づくバイパスプロファイル (`BypassProfile`) がコピー先の新ワークフローへ複製されない不具合を修正する。

## 2. 変更仕様

### 2.1 バックエンド複製処理 (`backend/app/routers/workflows.py`)
`copy_workflow` 関数内で、ソースワークフロー (`src`) の `bypass_profiles` リレーションから各プロファイルを抽出し、新ワークフロー (`new_wf.id`) に紐づけた `models.BypassProfile` インスタンスを作成して `db.add()` する。

```python
for bp in src.bypass_profiles:
    db.add(models.BypassProfile(
        workflow_id=new_wf.id,
        name=bp.name,
        bypassed_node_ids=bp.bypassed_node_ids,
        is_enabled=bp.is_enabled,
    ))
```

## 3. 影響範囲
- `backend/app/routers/workflows.py` (`copy_workflow` 関数)
- `backend/tests/test_workflows.py` (自動テスト追加)

## 4. データ構造 & 関係性
`Workflow` (1) <---> (*) `BypassProfile`
- `BypassProfile` フィールド:
  - `workflow_id`: 新ワークフローID
  - `name`: プロファイル名 (文字列)
  - `bypassed_node_ids`: バイパスノードIDのリスト (JSON文字列)
  - `is_enabled`: 有効/無効フラグ (ブール値)
