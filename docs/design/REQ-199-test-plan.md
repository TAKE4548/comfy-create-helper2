# テスト計画書: REQ-199 ImageCropper操作時におけるイベント伝播制御とモーダル誤クローズ防止

## 1. 自動テスト計画 (Automated Tests)

### 1.1 単体テスト (`frontend/src/components/__tests__/ImageCropper.test.tsx`)
- [ ] **TC-1**: `ImageCropper` 内をクリックした際に、イベントが親要素の `onClick` ハンドラにバブリングしない（`e.stopPropagation()` が機能する）ことの検証。
- [ ] **TC-2**: `ImageCropper` のオーバーレイ（背景部分）をクリックした際に、親へのバブリングなしで `onCancel` が発火することの検証。
- [ ] **TC-3**: `ImageCropper` のキャンセルボタン（「✕」および「キャンセル」）を押下した際に `onCancel` が正しく呼び出されることの検証。
- [ ] **TC-4**: `aspectRatio` の引き渡しとレンダリングが維持されていることの検証。

#### 実行コマンド:
```bash
npm test src/components/__tests__/ImageCropper.test.tsx -- --run
```

## 2. 手動検証計画 (Manual Verification)

### 2.1 ブラウザでの実機・UI検証
- [ ] **MV-1**: LoRA 一覧から LoRA 詳細/編集モーダルを開き、サムネイルプレビュー下の「クロップ調整」をクリックして `ImageCropper` を開く。

- [ ] **MV-3**: ズームスライダーをドラッグ操作して倍率を変更し、マウスを離してもモーダルが閉じないことを確認する。

- [ ] **MV-5**: タグセット詳細/編集モーダルおよび新規作成モーダルでも同様にクロップドラッグ＆ドロップを行い、誤クローズが発生しないことを確認する。
