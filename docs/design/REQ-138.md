# REQ-138 詳細設計書: アルバム詳細画面からのセリフ編集モーダル起動および即時反映

## 1. 概要 (Overview)
現在、`HistoryPage` では通常のスナップショット一覧表示時（`view === 'snapshots'`）のみ各カードに「セリフ編集・吹き出し追加」ボタン（`snap-speech-edit-${snap.id}`）が存在し、`SpeechBubbleEditorModal` を開いてセリフ編集を行うことができます。
一方、アルバム詳細画面（`view === 'albums'` かつ `selectedAlbumId !== null`）における画像カード一覧（Album Items）にはセリフ編集ボタンが存在せず、アルバム内の画像を編集するためには通常スナップショット一覧に戻る必要がありました。

本設計では、アルバム詳細画面内の各画像カード（非一括選択モード時）にセリフ編集ボタンを設置し、クリック時に直接 `SpeechBubbleEditorModal` を起動できるようにします。また、セリフ編集・保存完了時にはアルバム詳細およびスナップショット一覧のキャッシュを無効化（`invalidateQueries`）し、変更結果が即時に反映されるようにします。

## 2. 影響分析・対象範囲 (Scope & SSoT Impact)

### 影響を受けるフロントエンドファイル
1. `frontend/src/pages/HistoryPage.tsx` (MODIFY):
   - アルバムアイテムカード内にセリフ編集ボタン（`MessageSquarePlus` アイコン、`id={`item-speech-edit-${item.snapshot_id}`}`) を配置。
   - ボタンクリック時に親要素へのイベント伝播を停止（`e.stopPropagation()`）し、対象アイテムの情報を元に `setSelectedForSpeech` を呼び出す。
   - `SpeechBubbleEditorModal` の `onSaved` コールバックで `['snapshots']` に加えて `['album', selectedAlbumId]` および `['albums']` のクエリキャッシュを無効化。
2. `frontend/src/pages/__tests__/HistoryPage.test.tsx` (NEW):
   - アルバム詳細画面でのセリフ編集ボタン表示、クリックによるモーダル起動、保存後のキャッシュ無効化の動作を検証するコンポーネントテストを追加。

## 3. 詳細設計 (Detailed Design)

### 3.1 アルバムアイテムカードへのボタン追加 (`HistoryPage.tsx`)
アルバム詳細表示時（`visibleAlbumItems.map((item) => ...)` 内）の `cardContent` において、`!albumItemMultiSelect.isMultiSelectMode` のブロック内にセリフ編集ボタンを追加します。

```tsx
{item.image_path && (
  <button
    id={`item-speech-edit-${item.snapshot_id}`}
    onClick={(e) => {
      e.stopPropagation()
      setSelectedForSpeech({
        id: item.snapshot_id,
        workflow_id: 0,
        image_path: item.image_path,
        thumbnail_path: item.thumbnail_path,
        created_at: item.created_at || '',
      })
    }}
    title="セリフ編集・吹き出し追加"
    className="absolute top-2 right-16 p-1.5 rounded-md bg-black/60 text-zinc-400 hover:text-accent-green opacity-0 group-hover:opacity-100 transition-opacity z-20"
  >
    <MessageSquarePlus size={12} />
  </button>
)}
```

### 3.2 モーダル保存時のキャッシュ更新
```tsx
{selectedForSpeech && (
  <SpeechBubbleEditorModal
    snapshot={selectedForSpeech}
    onClose={() => setSelectedForSpeech(null)}
    onSaved={() => {
      qc.invalidateQueries({ queryKey: ['snapshots'] })
      if (selectedAlbumId !== null) {
        qc.invalidateQueries({ queryKey: ['album', selectedAlbumId] })
      }
      qc.invalidateQueries({ queryKey: ['albums'] })
    }}
  />
)}
```

## 4. 非機能要件・アクセシビリティ
- ツールチップ（`title="セリフ編集・吹き出し追加"`）および適切なホバー状態・フォーカススタイルを維持。
- ドラッグ＆ドロップ（DnDソート）有効時でもボタンクリックが正しく反応し、誤ってドラッグが開始されないよう `stopPropagation` を徹底。
