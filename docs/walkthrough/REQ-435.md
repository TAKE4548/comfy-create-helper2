## 1. エグゼクティブサマリ

REQ-435 により、Generate 画面（Desktop 幅 768px 以上 / Mobile 幅 767px 以下）および History 画面（Mobile 幅 767px 以下・Desktop 互換維持）の表示面積を圧迫していた UI 要素を以下の 6 軸で整理した。

1. **モバイル余白・密度整理と Hit-Slop 保証（AC-1, AC-2, AC-19）**: `index.css` のグローバル 44px 規則は維持しつつ、対象ボタン・タブへ `data-tap-target-exempt` + `h-7`/`h-8`（28px/32px）と `::before` 透明 Hit-Slop（≥44×44px）を適用。隣接タップ領域の非重複と `:focus-visible` 可視性を確保。
2. **Desktop 表示からのモバイル寸法除去（AC-3）**: 幅 800px / 1280px においてプリセットタブ外枠・内部ボタン・タブバー・ActionBar（`#queue-open-btn`, `#generate-btn`, `#save-snapshot-btn`）・History 検索入力/チップを 44px 未満のデスクトップ寸法へ整理。
3. **プリセットタブのメニュー統合（AC-4, AC-5, AC-6）**: 各タブの独立 `×` ボタンを廃止し単一の統合メニューボタン（`data-preset-menu-trigger`）へ集約。ボタンタップ／クリック・右クリック・500ms 長押しの 3 入口から同一メニュー（Mobile 下部シート / Desktop メニュー）を開き、先頭に「このタブを閉じる」を配置しつつ REQ-402 の一括クローズ・失敗保持を維持。
4. **モバイル単一進捗バー＋`n/m` 文字表示（AC-7, AC-8, AC-9）**: 幅 767px 以下の生成中は上部ステータスヘッダーに実行中 job の進捗バー 1 本のみと全体進捗 `n/m`（`selectMobileOverallProgress`）を表示し、重複していた 2 本の進捗バーを削除。Desktop の進捗表示は不変。
5. **History モバイルフィルター初期折り畳み（AC-10, AC-11, AC-12）**: 幅 767px 以下ではフィルターを 1 行バーに折り畳んで初期表示（360×640 で最初の画像カードがスクロールなしで視認可能）。絞り込み中は件数を文字表示し、開閉によらず常時ソート可能・AND 結合・0 件時 Empty State フィルター解除を維持。
6. **ステージ表示・折り畳みと `localStorage` 永続化（AC-13〜AC-18）**: Mobile `ParamPanel` へ `stageGrouping={true}` を導入し、Desktop Prompt および Desktop/Mobile Parameters のステージ見出しをクリック／タップ／Enter／Space で折り畳み可能にした。状態は `LS_KEYS.STAGE_COLLAPSED_STATE`（`prompt-surgeon-stage-collapsed-v1`）で `workflowId:pane` ごとに永続化し、`hidden` 属性により生成・ParamSync・プリセット切替値および Desktop sticky 見出し挙動を保持。

- **仕様・文書同期**: `docs/specs/SPEC_GENERATE.md`、`docs/specs/SPEC_HISTORY.md`、`docs/backlog/pbi/active/REQ-373.md`、`docs/backlog/pbi/active/REQ-374.md` を更新済み（`backlog_linter.py` PASS）。

## 3. Red Teaming（境界値・異常系シナリオ RT-1 〜 RT-5）

1. **RT-1（隣接 Hit-Slop 重複・誤爆検証）**: `generateMobileGallery.spec.ts` および `historyResponsive.spec.ts` にて `::before` 疑似要素の実効矩形の交差面積 0 および中心タップ独立実行を実ブラウザで検証。
2. **RT-2（`n/m` のキャンセル・失敗・`unconfirmed` 混在）**: `generationQueueSync.test.ts` にて `selectMobileOverallProgress` の 3 件中 1 件キャンセル（`m=2`）、失敗混在（`finished` 加算）、全件完了（`m/m`）、全件キャンセル（`null`）、`unconfirmed` 除外を検証。
3. **RT-3（`localStorage` 破損 JSON・Stale ステージ・`QuotaExceededError`）**: `useStageCollapseState.test.ts` にて不正 JSON・バージョン不一致・存在しないステージキー・`setItem` 例外時の安全フォールバック（全展開・例外非送出）を検証。
4. **RT-4（360px + Safe-Area + ソフトキーボード開閉 + 固定バー退避）**: `generateMobileGallery.spec.ts` `[REQ-435/AC-19]` にて横はみ出し 0・固定生成バーおよびボトムナビ非被覆を検証。
5. **RT-5（折り畳みステージに対する ParamSync・プリセット切替・生成）**: `ParamPanel.test.tsx`・`DesktopLayout.test.tsx`・`MobileLayout.test.tsx` `[REQ-435/AC-17]` にて折り畳み中ステージの値保持・反映を検証。
