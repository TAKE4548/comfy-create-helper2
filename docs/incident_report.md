# 障害調査報告書 (Incident Report)

## 障害概要
生成画面（Generate ページ）において、新規のワークフロー（ComfyUIのAPI版JSONファイル）を新規登録・アップロードするためのユーザーインターフェース（ボタンやドラッグ＆ドロップエリア等）が存在しない。

## 再現手順
1. アプリケーションの生成（Generate）画面を開く。
2. ワークフロー選択用ドロップダウン（`Select workflow…`）周辺や、画面のヘッダー・サイドバー・設定ポップアップなど、UI全体を確認する。
3. ローカルのComfyUIワークフローJSONファイルをシステムに新規アップロード・登録するためのボタンやエリアが存在しないことを確認する。

## 根本原因 (Root Cause Analysis)
1. **フロントエンドUIの実装不足**:
   * フロントエンドの [GeneratePage.tsx](../frontend/src/pages/GeneratePage.tsx) では、既存の登録済みワークフローを一覧表示して選択するセレクトボックス（モバイル用: L576-L586, デスクトップ用: L1277-L1287）および設定・履歴などのボタンのみが配置されている。
   * 新しいワークフローJSONファイルをアップロードするためのファイル入力要素（`<input type="file" ...>`）やドラッグ＆ドロップ領域、およびアップロードをハンドリングするUI処理が実装されていない。
2. **フロントエンドAPI呼び出しの未実装**:
   * フロントエンドのAPIクライアント（[client.ts](../frontend/src/api/client.ts#L24-L31)）には `workflowsApi.create` や `workflowsApi.scan` が定義されているが、これらを呼び出すコンポーネントが生成画面に存在しない。
3. **仕様定義と設計の乖離（仕様漏れ）**:
   * システム全体の概要（`docs/spec_and_migration.md`）では、「ComfyUIのAPI版JSONワークフローをアップロードし、編集対象ノードを命名規則ベースで自動マッピング・特定する」という仕様が謳われている。
   * しかし、ワークフロー新規アップロード時の具体的なUI/UXデザインやマッピング確認モーダルの設計・仕様、タスクカード（PBI）が設計段階で定義されておらず、実装から漏れていた。

## 障害分類
* **分類**: **Type B (Specification Flaw / 仕様の不備・機能未設計)**
  * 単なるコードの実装ミス（バグ）ではなく、機能要件である「ワークフローのアップロード・新規登録」を実現するためのUI設計・遷移仕様自体が定義されておらず、結果として機能が欠落している状態であるため。

## 対策方針（※調査フェーズのため実装は行いません）
* ワークフローをアップロードするためのUI/UX（ファイルダイアログ、またはドラッグ＆ドロップ領域）の配置設計。
* アップロードされたJSONを `workflowsApi.scan` でスキャンし、検出されたノードと役割（MappingMaster）の自動マッピング結果を確認・編集するための登録確認用モーダルUIの設計。
* ユーザーがワークフロー名を入力し、マッピングを確定させたのちに `workflowsApi.create` を実行してDBに新規保存する一連のシーケンスの設計。
* 本機能の設計を具体化するため、まずは `/sys-design` ワークフローに移行して詳細設計書を策定することを推奨します。
