#### 外部翻訳プロバイダー仕様・通信契約 (External Provider API Contracts)

1. **Google Free Web API (デフォルト・APIキー不要)**:
   - Endpoint: `https://translate.googleapis.com/translate_a/single?client=gtx&sl={source_lang}&tl={target_lang}&dt=t&q={encoded_text}`
   - HTTP Method: `GET`
   - Response Format (JSON array): `[[["訳文", "原文", null, null, 1]], null, "en", ...]`
   - Extraction: `data[0][0][0]` (または `"".join([segment[0] for segment in data[0] if segment and segment[0]])`)

2. **Google Cloud Translation API v2**:
   - Endpoint: `https://translation.googleapis.com/language/translate/v2?key={api_key}`
   - HTTP Method: `POST` (JSON: `{"q": chunks, "source": source_lang, "target": target_lang, "format": "text"}`)
   - Response Format: `{"data": {"translations": [{"translatedText": "訳文1"}, {"translatedText": "訳文2"}]}}`
   - Extraction: `[t["translatedText"] for t in data["data"]["translations"]]`

3. **DeepL API**:
   - Endpoint: `https://api-free.deepl.com/v2/translate` (または APIキーが `:fx` で終わらない場合 `https://api.deepl.com/v2/translate`、もしくは設定の `api_url`)
   - HTTP Method: `POST`
   - Headers: `{"Authorization": f"DeepL-Auth-Key {api_key}", "Content-Type": "application/json"}`
   - Body: `{"text": chunks, "source_lang": source_lang.upper(), "target_lang": target_lang.upper()}`
   - Response Format: `{"translations": [{"text": "訳文1"}, {"text": "訳文2"}]}`
   - Extraction: `[t["text"] for t in data["translations"]]`

4. **Local LLM (既存 call_llm 連動)**:
   - `from app.services.llm_request import call_llm` を呼び出し。

1. **`translation_service.py` の実装**:
   - **キャッシュストレージ**:
     ```python
     TRANSLATION_CACHE: Dict[str, str] = {}
     ```
   - **特殊構文退避 & 復元**:
     ```python
     def sanitize_and_tokenize(text: str) -> Tuple[str, Dict[str, str]]:
         # LoRA tags: <lora:name:0.8>
         # Weights: (tag:1.2), (tag), {tag}
         # Embeddings: embedding:name
         tokens = {}
         counter = 0
         def repl(match):
             nonlocal counter
             placeholder = f"__TOKEN_{counter}__"
             tokens[placeholder] = match.group(0)
             counter += 1
             return placeholder

         pattern = re.compile(r"<lora:[^>]+>|\((?:[^:()]+:[0-9.]+)\)|\((?:[^()]+)\)|\{[^{}]+\}|embedding:[^\s,]+")
         sanitized = pattern.sub(repl, text)
         return sanitized, tokens

     def restore_tokens(text: str, tokens: Dict[str, str]) -> str:
         for placeholder, original in tokens.items():
             text = text.replace(placeholder, original)
         return text
     ```
   - **チャンク分割 & 正規化**:
     - `re.split(r"[,、\n]+", sanitized)` で分割し、前後の空白を除去して空文字を除外。
     - 各チャンクのキャッシュキー: `hashlib.sha256(f"{chunk.lower()}:{target_lang}:{provider}".encode("utf-8")).hexdigest()`
   - **プロバイダー別リクエスト送信**:
     - `httpx.AsyncClient(timeout=10.0)` を使用。
     - 502/500 エラーハンドリングとロギング。
   - **`translate_prompt` メソッド**:
     - DB からプロバイダー設定を取得（未設定時は `google_free`）。
     - 特殊構文退避 $\rightarrow$ チャンク分割 $\rightarrow$ キャッシュ照合 $\rightarrow$ 未キャッシュ分送信 $\rightarrow$ キャッシュ保存 $\rightarrow$ 順序通り結合 $\rightarrow$ 特殊構文復元 $\rightarrow$ `PromptTranslateResponse` 返却。
   - **`test_connection` メソッド**:
     - テスト文字列（`"1girl, masterpiece"` など）を渡して指定プロバイダーで疎通テストを実行し `TranslateTestResponse` を返す。
