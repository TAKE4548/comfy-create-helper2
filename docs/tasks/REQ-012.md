```typescript
  const handleGenerate = async () => {
    if (!workflow) return
    const wfJson = { ...workflow.json_body } as Record<string, unknown>
    // Inject params into workflow JSON
    workflow.mappings.forEach((m) => {
      if (!m.role || !m.param_name) return
      const node = wfJson[m.node_id] as Record<string, unknown> | undefined
      if (!node) return
      const inputs = node.inputs as Record<string, unknown>
      if (!inputs) return
      const val = m.input_type === 'int'
        ? parseInt(paramValues[m.role] || '0')
        : m.input_type === 'float'
          ? parseFloat(paramValues[m.role] || '0.0')
          : paramValues[m.role] || ''
      
      if (inputs[m.param_name] !== undefined) {
        inputs[m.param_name] = val
      } else if (inputs['value'] !== undefined) {
        inputs['value'] = val
      } else {
        inputs[m.param_name] = val
      }
    })
```

## 3. 実装要件 (Implementation Logic)
- [x] **TagChipInput コンポーネントの作成 (`frontend/src/components/TagChipInput.tsx`)**:
  - `value`（カンマ区切り文字列）をパースし、各タグをチップUIとしてレンダリングする。
  - 各チップに個別の削除（`×`）ボタンを配置し、削除時に `onChange` をトリガーする。
  - チップの末尾にテキスト入力用のインライン `<input>` を配置。
  - インプット入力中の `,`（カンマ）入力、または `Enter` キー押下で新しいチップを確定・追加する。
  - インプットが空の状態で `Backspace` キーが押されたとき、末尾のチップを削除する。
  - `onPaste` イベントをインターセプトし、カンマ区切りテキストを自動で分割展開して追加する。
  - 配色テーマ（ポジティブ用は緑枠背景・ネガティブ用は赤/ローズ枠背景、その他はグレー枠背景）のプロパティをサポート。
- [x] **Zustand ストアの更新 (`frontend/src/store/useGenerationStore.ts`)**:
  - `GenerationState` に `appliedAssets: Record<string, AppliedAsset[]>` を追加。
  - 初期化時に `localStorage`（キー：`prompt-surgeon-applied-assets`）から `appliedAssets` をパースして読み込むロジックを追加。
  - ストアにアクション `addAppliedAsset(role: string, asset: Omit<AppliedAsset, 'id' | 'enabled'>)`、`removeAppliedAsset(role: string, id: string)`、`toggleAppliedAsset(role: string, id: string)` を追加し、それぞれ `localStorage` にシリアライズ保存する。
- [x] **GeneratePage の更新 (`frontend/src/pages/GeneratePage.tsx`)**:
  - プロンプト入力欄の `textarea` を `TagChipInput` に差し替える。
  - プロンプトヘッダー右側に `+ Add Asset` ボタン（ポップオーバーメニュー）を追加し、登録済みの LoRA およびタグセットをロードして選択できるようにする。
  - **LoRAの強度自動計算**:
    - `recommended_strength_min` と `recommended_strength_max` が両方存在する場合、その中間値 `(min + max) / 2` を算出し、小数第一位に丸める（四捨五入）。
    - どちらか片方のみ存在する場合、その値。
    - 設定されていない場合、`1.0`。
  - **LoRAの埋め込み文字列生成**:
    - `file_path` または `model_name` のいずれかから、ディレクトリパス and 拡張子を除外したファイル名（例: `rin_iilustrious`）を抽出し、`<lora:filename:strength>` 形式の埋め込み用文字列を構築する。
  - プロンプト入力欄의 直下に、適用されたアセットチップを表示する。
    - アセットごとにトグル（チェックボックスまたはボタン）を配置し、無効化時はグレーアウト。
  - **画像生成処理 (`handleGenerate`) の更新**:
    - `textarea` タイプ（プロンプト）の値を差し込む際、適用中でかつ「有効」になっているアセットの `tags` と、LoRAアセットの場合は `loraPromptString` も配列に結合した上で、最終的なプロンプトとしてComfyUIに送信する。
    - LoRAローダーのパラメータ（`Character_Lora_Model` 等）は自動で上書きせず、そのまま送信する。
