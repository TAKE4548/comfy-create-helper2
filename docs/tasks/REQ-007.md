## 3. 実装要件 (Implementation Logic)
- [x] **状態管理の追加**:
  - 詳細モーダル用の選択中タグセット状態 `selectedTagSetForDetail` (型: `TagSet | null`) を追加。
  - 編集用の選択中タグセット状態 `editTagSet` (型: `TagSet | null`) と、編集用フォーム状態 `editForm` (新規作成フォーム `form` と同様 of 構造) を追加。
  - タグセット更新用のミューテーション `updateTagSet` を `tagSetsApi.update` を用いて定義し、成功時は `tag-sets` クエリキャッシュを無効化する。
- [x] **カードレイアウトへの変更**:
  - `grouped.entries()` を展開する部分の、アコーディオン形式のリスト (`sets.map(...)`) をグリッドレイアウトに変更。
  - グリッドのCSS: `grid grid-cols-1 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4 gap-4` を指定。
  - 各カードの構成:
    - ヘッダー部分にセット名（太字タイトル）と、右上部分にホバーまたは常時表示される編集ボタン（Pencilアイコン）と削除ボタン（Trash2アイコン）を配置。
    - サブ情報としてカテゴリ名（もしあれば）とタグ数（例: "12 tags"）を表示。
    - タグプレビューエリアを配置し、含まれるタグの最初の数個（例: 最大10個程度）を小さなチップ形式で表示。残りのタグがある場合は "+X more" などの表示を行う。
    - カード自体（編集・削除ボタン除く）をクリックした際に `selectedTagSetForDetail` をセットして詳細モーダルを開く。
- [x] **詳細モーダルの実装**:
  - 選択されたタグセットの名称、説明、所属カテゴリ、全タグの一覧を美しく表示するモーダルを追加。
  - 全タグのコピーボタンを配置。
- [x] **編集モーダルの実装**:
  - 新規作成モーダルと同様の入力フィールドを持つ編集用モーダルを追加（`editTagSet` が `null` でないときに表示）。
  - 各フィールド of 初期値として `editTagSet` のデータをセットし、変更があった箇所を含めて `updateTagSet.mutate` で更新できるようにする。
  - 「Tags」入力エリアはカンマ区切りの文字列を配列に変換して送信する。
