### REQ-166-T1: ジョブ管理におけるキュー削除と全ジョブ中断の機能・UIボタン分離、中断状態同期の堅牢化、および完了時のモーダル自動クローズ

#### 目的
ジョブ管理モーダルにおいて、「待機キューのみクリア（現在生成中の1枚は最後まで継続）」と「すべて中断（実行中も含めて即座に完全停止）」の2つの操作を明確に分離し、ComfyUIの中断処理（`/interrupt`）およびWebSocketイベントとの状態同期の堅牢化を行う。また、操作完了時にモーダルを自動的に閉じるようにする。

#### 対象ファイル
1. `frontend/src/store/useGenerationStore.ts` (MODIFY)
2. `frontend/src/components/JobManagementModal.tsx` (MODIFY)

##### 1. `frontend/src/store/useGenerationStore.ts` の改修

```typescript
// 1. GenerationState インターフェースに clearPendingQueue を追加
export interface GenerationState {
  // ...
  clearPendingQueue: () => Promise<void>;
  cancelJob: (promptId: string) => Promise<void>;
  cancelAllJobs: () => Promise<void>;
  // ...
}

// 2. WebSocket メッセージハンドラ (switch (type)) に execution_interrupted を追加
case 'execution_interrupted': {
  const promptId = data.prompt_id as string
  set({
    isGenerating: false,
    progress: null,
    currentPromptId: null,
    activeClientId: null,
    generationStartTime: null,
    currentNode: null,
    nodeProgress: null,
    currentWorkflow: null,
    activeBatch: null,
  })
  localStorage.removeItem(LS_KEYS.CURRENT_PROMPT_ID)
  get().fetchQueue()
  window.dispatchEvent(new CustomEvent('comfy-job-event', { detail: { type: 'execution_interrupted', promptId } }))
  break
}

// 3. clearPendingQueue アクションの実装
clearPendingQueue: async (): Promise<void> => {
  get().abortSubmission()
  try {
    const pendingIds = get().queuePending.map((j) => j[1])
    // 待機キューのみ削除（interruptは呼ばない）
    await comfyApi.deleteQueue({ clear: true })
    if (pendingIds.length > 0) {
      await comfyApi.deleteHistory({ delete: pendingIds })
    }

    // activeBatch がある場合、待機中のジョブのみ除外
    const activeBatch = get().activeBatch
    if (activeBatch) {
      const updatedBatch = activeBatch.filter(
        (job) => job.status === 'generating' || job.status === 'completed'
      )
      set({ activeBatch: updatedBatch.length > 0 ? updatedBatch : null })
    }
    await get().fetchQueue()
  } catch (e) {
    console.error('Failed to clear pending queue:', e)
  }
},

// 4. cancelAllJobs アクションの改修
cancelAllJobs: async (): Promise<void> => {
  get().abortSubmission()
  try {
    const runningIds = get().queueRunning.map((j) => j[1])
    const pendingIds = get().queuePending.map((j) => j[1])
    const allIds = [...runningIds, ...pendingIds]

    // 1. 待機キューの全クリア
    await comfyApi.deleteQueue({ clear: true })

    // 2. 実行中ジョブへの割り込み
    await comfyApi.interrupt()

    // 3. 履歴からの削除
    if (allIds.length > 0) {
      await comfyApi.deleteHistory({ delete: allIds })
    }

    // 4. ステートリセット
    set({
      activeBatch: null,
      isGenerating: false,
      currentPromptId: null,
      activeClientId: null,
      generationStartTime: null,
      currentNode: null,
      nodeProgress: null,
      currentWorkflow: null,
    })
    localStorage.removeItem(LS_KEYS.CURRENT_PROMPT_ID)

    await get().fetchQueue()
  } catch (e) {
    console.error('Failed to cancel all jobs:', e)
  }
},
```

##### 2. `frontend/src/components/JobManagementModal.tsx` の改修

```tsx
// useGenerationStore から clearPendingQueue を取得
const {
  queueRunning,
  queuePending,
  clientId,
  filterOwnSession,
  cancelJob,
  clearPendingQueue,
  cancelAllJobs,
} = useGenerationStore()

// ハンドラー
const handleClearQueueOnly = async () => {
  if (confirm(`待機中のキュー（${visiblePending.length}件）をクリアしますか？\n※現在生成中の1枚は中断せず最後まで生成されます。`)) {
    await clearPendingQueue()
    onClose()
  }
}

const handleCancelAll = async () => {
  if (confirm('実行中の生成を中断し、待機中のすべてのジョブを削除しますか？')) {
    await cancelAllJobs()
    onClose()
  }
}

// 個別ジョブの title 属性
// 実行中: title="中断（生成を停止）"
// 待機中: title="キューから削除"

// フッターボタン構成
<div className="flex gap-3">
  {visiblePending.length > 0 && (
    <button
      type="button"
      onClick={handleClearQueueOnly}
      className="px-3.5 py-1.5 rounded-lg bg-amber-500/10 hover:bg-amber-500/25 border border-amber-500/30 text-amber-400 hover:text-amber-300 text-xs font-semibold flex items-center gap-1.5 transition-all"
    >
      <Trash2 size={14} />
      キューのみクリア
    </button>
  )}
  {totalJobsCount > 0 && (
    <button
      type="button"
      onClick={handleCancelAll}
      className="px-3.5 py-1.5 rounded-lg bg-red-500/10 hover:bg-red-500/25 border border-red-500/30 text-red-400 hover:text-red-300 text-xs font-semibold flex items-center gap-1.5 transition-all"
    >
      <Trash2 size={14} />
      すべて中断
    </button>
  )}
  <button
    type="button"
    onClick={onClose}
    className="px-4 py-1.5 rounded-lg bg-zinc-800 hover:bg-zinc-700 border border-[rgba(255,255,255,0.08)] text-zinc-300 text-xs font-semibold transition-all"
  >
    閉じる
  </button>
</div>
```
