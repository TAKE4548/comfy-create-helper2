## 3. 実装要件 (Implementation Logic)
1. **静的ファイル配信設定の追加**:
   - `backend/app/main.py` において、`app.mount("/api/snapshots/images", StaticFiles(directory=settings.snapshot_path), name="snapshots_images")` を追加する。
2. **画像ダウンロードおよびパス変換処理の実装**:
   - `backend/app/routers/snapshots.py` 内で、受け取った `payload.image_path` が `http://` または `https://` で始まる場合:
     - 以下の仕様に基づきダウンロードを実行し、ファイルを保存する：
       ```python
       import urllib.request
       import urllib.parse
       import uuid
       from pathlib import Path

       # 1. クエリパラメータ "filename" の抽出
       parsed_url = urllib.parse.urlparse(payload.image_path)
       queries = urllib.parse.parse_qs(parsed_url.query)
       filename = queries.get("filename", [None])[0]
       
       if not filename:
           filename = Path(parsed_url.path).name
       if not filename or filename.strip() == "":
           filename = f"snapshot_{uuid.uuid4().hex}.png"
       else:
           # 2. ファイル名の安全な生成（衝突回避のため UUID の一部を付与）
           ext = Path(filename).suffix or ".png"
           stem = Path(filename).stem
           filename = f"{stem}_{uuid.uuid4().hex[:8]}{ext}"
       
       # 3. ディレクトリの存在保証とファイルの保存
       target_dir = settings.snapshot_path
       target_path = target_dir / filename
       
       # 4. HTTP ダウンロード
       req = urllib.request.Request(
           payload.image_path, 
           headers={'User-Agent': 'Mozilla/5.0'}
       )
       with urllib.request.urlopen(req, timeout=5) as response:
           with open(target_path, 'wb') as f:
               f.write(response.read())
       ```
     - ダウンロードおよび保存が成功した場合、`models.Snapshot` の `image_path` に保存する値を相対パス `/api/snapshots/images/<生成した一意のファイル名>` に書き換える。
     - 例外発生時などは適切にエラーハンドリング（警告ログ出力など）を行い、フォールバックとして元の `payload.image_path` をそのまま保存する。
