### REQ-165-T4: 設定画面（SettingsPage）への翻訳プロバイダー・API設定セクションの実装

#### 目的
設定画面（SettingsPage）に「Translation Settings (翻訳設定)」セクションを新設し、ユーザーが翻訳プロバイダー（Google無料Web / Google Cloud API / DeepL / ローカルLLM）の選択、APIキーの設定、および疎通テストを行えるようにする。また、バックエンドに `translate` ルーターをマウントする。

#### 対象ファイル
1. `frontend/src/pages/SettingsPage/components/TranslationSettingsSection.tsx` (NEW)
2. `frontend/src/pages/SettingsPage.tsx` (MODIFY)
3. `backend/app/main.py` (MODIFY)

#### 完全な型定義・スキーマ (Complete Context Types & Schemas)

```typescript
export interface TranslationConfig {
  provider: 'google_free' | 'google_cloud' | 'deepl' | 'llm';
  apiKey?: string;
  apiUrl?: string;
}

export interface TranslateTestResponse {
  success: boolean;
  sample_translation: string;
  error?: string;
}
```

#### 実装指示 (Implementation Steps)

1. **`TranslationSettingsSection.tsx` の実装**:
   - `prompts` (`models.LlmPrompt`) から以下のキーを読み書き:
     - `translation_provider` (`'google_free'` | `'google_cloud'` | `'deepl'` | `'llm'`)
     - `translation_api_key` (Google Cloud / DeepL APIキー)
     - `translation_api_url` (カスタムURL)
   - UIパーツ:
     - プロバイダー選択（ラジオまたはドロップダウン）:
       - **Google 翻訳 (無料 / APIキー不要)** [推奨・デフォルト]
       - **Google Cloud Translation API** (要APIキー)
       - **DeepL API** (要APIキー)
       - **ローカルLLM (LMStudio / Ollama)** (従来方式)
     - API Key 入力フィールド（`google_cloud` または `deepl` 選択時のみ表示、パスワード伏せ字/表示トグル付き）
     - 疎通テストボタン（`translateApi.testConnection` を呼び出し、成功時は「✓ 疎通成功: {訳文}」、失敗時はエラーメッセージを表示）
     - キャッシュクリアボタン（`translateApi.clearCache`）

2. **`SettingsPage.tsx` の更新**:
   - `expandedSections.translation` アコーディオン状態を追加。
   - `TranslationSettingsSection` を「LLM Model Settings」と「Prompt Templates」の間にマウント。

3. **`backend/app/main.py` の更新**:
   - `from app.routers import translate` を追加。
   - `app.include_router(translate.router)` をマウント。
