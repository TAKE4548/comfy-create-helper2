## 3. 実装要件 (Implementation Logic)
1. **状態管理の追加**:
   - `react` から `useState` をインポートし、`isCollapsed` 状態を定義します。
   - 初期値は `localStorage.getItem('prompt-surgeon-sidebar-collapsed') === 'true'` から読み込みます。
   - トグルボタン押下時に状態を反転し、`localStorage.setItem('prompt-surgeon-sidebar-collapsed', String(newVal))` で保存します。

2. **アイコンのインポート**:
   - `lucide-react` から `ChevronLeft`, `ChevronRight` をインポートします。

3. **サイドバー幅の動的変更とアニメーション**:
   - `<aside>` に `transition-all duration-300 ease-in-out` を追加します。
   - `w-16 xl:w-56` の代わりに、`isCollapsed` が `true` の場合は `w-16`、`false` の場合は `w-56` になるように動的クラスを追加します。
   - モバイル向けの `hidden lg:flex` は維持します。

4. **トグルボタンの追加**:
   - サイドバー上部（ヘッダー）のロゴエリアの配置を調整します。
   - `isCollapsed` が `true` の場合、ヘッダーにトグルボタンのみを中央寄せで表示します（ロゴと「Prompt Surgeon」テキストは非表示）。
   - `isCollapsed` が `false` の場合、ロゴと「Prompt Surgeon」テキストを表示し、その右側にトグルボタンを表示します。
   - ボタンには `id="sidebar-toggle"` を付与し、`title` に適切なツールチップを付与します。
   - クリックイベントでトグル関数を実行します。

5. **テキストとアクティブインジケータのフェードアウト/非表示化**:
   - 各 NavLink 内のテキスト（`<span>`）、およびアクティブ時の丸いインジケータ（`<div>`）の表示制御を修正します。
   - 既存の `hidden xl:block` の代わりに、`isCollapsed` が `true` の場合は非表示、`false` の場合は表示されるようにします。
   - アニメーション時にテキストが折り返されてしまうのを防ぐため、`overflow-hidden whitespace-nowrap transition-all duration-300` と連動させ、`isCollapsed ? 'w-0 opacity-0' : 'w-auto opacity-100'` とクラスを適用するとスムーズです。
   - 最下部のバージョン表示エリアも同様に、`isCollapsed` が `true` の場合は非表示、`false` の場合は表示するようにします。
