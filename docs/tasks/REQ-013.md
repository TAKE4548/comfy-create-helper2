## 2. 密閉コンテキスト (Hermetic Context)

### 2.1 既存の create_snapshot と get_snapshot
```python
@router.get("/{snapshot_id}", response_model=schemas.SnapshotRead)
def get_snapshot(snapshot_id: int, db: Session = Depends(get_db)):
    s = db.query(models.Snapshot).filter(models.Snapshot.id == snapshot_id).first()
    if not s:
        raise HTTPException(status_code=404, detail="Snapshot not found")
    return schemas.SnapshotRead(
        id=s.id,
        workflow_id=s.workflow_id,
        params=json.loads(s.params),
        image_path=s.image_path,
        created_at=s.created_at,
    )


@router.post("", response_model=schemas.SnapshotSummary, status_code=status.HTTP_201_CREATED)
def create_snapshot(payload: schemas.SnapshotCreate, db: Session = Depends(get_db)):
    s = models.Snapshot(
        workflow_id=payload.workflow_id,
        params=json.dumps(payload.params),
        image_path=payload.image_path,
    )
    db.add(s)
    db.commit()
    db.refresh(s)
    return s
```
</hermetic_context>

## 3. 実装要件 (Implementation Logic)
- [ ] **保存APIの拡張 (`create_snapshot`)**:
  - `payload.new_album_name` が指定された場合、`models.Album` を検索、存在しなければ新規作成してコミットする。
  - `payload.album_id` が指定された場合、存在するかチェックし、なければ `404` もしくは `400` エラー。
  - スナップショットを DB に追加後、`db.flush()` して ID を確定。
  - アルバムが決定している場合、`models.AlbumItem` を作成して追加。その際、対象アルバム内の最大 `sequence_order` を `func.max` で取得し、それに `+1` した値を設定する（存在しない場合は `0`）。
  - `payload.loras` があれば `models.SnapshotLora` を作成して追加。
  - `payload.tag_sets` があれば `models.SnapshotTagSet` を作成して追加。
  - `db.commit()` と `db.refresh(s)` を行い、作成されたスナップショットを返却。
- [ ] **取得APIの拡張 (`get_snapshot`)**:
  - 戻り値の `schemas.SnapshotRead` オブジェクトを組み立てる際、`loras` と `tag_sets` の関連リストを含めて返却するように変更。
- [ ] **単体テストの追加 (`backend/tests/test_snapshots.py`)**:
  - 「LoRA紐付け保存」「既存アルバムへの紐付けと sequence_order インクリメント」「新規アルバム作成と紐付け」をテストする pytest テストコードを追加。
