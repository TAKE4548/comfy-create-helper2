## 3. 実装要件 (Implementation Logic)
- [ ] **DesktopLayout.tsx**:
  - `activeSet` を取得する際、比較する両方の ID を `String` にキャストする: `String(s.id) === String(activeSetId)`.
  - タブの表示判定やクラス適用条件での比較も同様にする: `String(s.id) === String(activeSetId)`.
- [ ] **useGeneratePageState.ts (同期useEffect)**:
  - `isInvalidActive` の判定において、`activeSetId` を `String` 化した上で、`safeOpenPresetIds` を `String` の配列にマップして `includes` 判定する: `activeSetId === null || !safeOpenPresetIds.map(String).includes(String(activeSetId))`.
  - `activePreset` の検索において、ID 比較に `String` キャストを適用する: `presets?.find(p => String(p.id) === String(activeSetId))`.
- [ ] **useGeneratePageState.ts (新規作成時)**:
  - `createPresetMutation` の `onSuccess` ハンドラにおいて、`setActiveSetId(newPreset.id)` と併せて `openPreset?.(newPreset.id)` を呼び出し、新規作成されたプロファイルが自動的に開かれるようにする。
