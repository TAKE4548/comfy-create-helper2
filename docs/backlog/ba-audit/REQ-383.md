## 2. Requirement Clarification & Evolution
- **端部スクロール余白と論理順序の整合化（F-001/F-002対処）**:
  - 指摘: 「最新画像が先頭（index 0 / 左側起点）」と「最新画像が領域水平中央に配置される」ことの物理的関係および、最古画像到達時の挙動の混同。
  - 整理・反映: 画像自体の表示幅を圧縮しない端部スクロール余白（パディング・スペーサー）を設けることで、論理順序の先頭（最新画像）および末尾（最古画像）のいずれであっても画像中心をプレビュー領域中央へ吸着配置可能であることをAC-2に明記。また、初期表示時の配置アサーションとスクロール操作時のアサーションを分離した。
- **慣性スクロール停止契機の明示（F-002/F-003対処）**:
  - 指摘: 「← 最新へ」「最古へ →」ボタン押下時の慣性停止タイミング、および「入力相殺による急停止」の表現曖昧性。
  - 整理・反映: AC-5およびAC-6において「押下契機で即座に進行中のスクロール慣性を停止し、対象画像がプレビュー水平中央に移動・表示される」と契機を明定。AC-3においても「連続入力時でも不要な振動や入力相殺による意図しない急停止が発生せず、減衰停止後に最寄り画像が水平中央へ吸着する」と滑らかな減衰特性を明確化。
- **トグル操作の前提条件および詳細モーダル動作の明確化（F-001/F-002対処）**:
  - 指摘: 「最新追従」「自セッション」の共有トグルが有効となるコンテキスト（デスクトップ表示かつ履歴展開時）の前提記述、および詳細プレビューモーダル（HistoryModalPreview）の維持対象機能の具体性。
  - 整理・反映: AC-10・AC-11のGiven条件にデスクトップ表示（幅768px以上）で履歴展開中であることを明記し、AC-12では既存モーダル（HistoryModalPreview）における拡大表示および閉じる操作（Escapeキー/閉じるボタン）の維持を明確化した。
