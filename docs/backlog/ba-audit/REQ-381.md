## 2. Findings & Requirement Evolution
- **F-001 (AC-10: 口調プリセットモーダル／シートの仕様参照)**:
  - 指摘: SpeechTonePresetModal のレイアウトや「キャンセル左／保存右」の維持判定基準が明示されていない。
  - 整理・反映: AC-10 において、セリフ支援タブの口調プリセット編集・作成モーダル（SpeechTonePresetModal）が SPEC_COMMON §1-4 / SPEC_SETTINGS §2 に準拠した共通ボトムシートとして動作することを明記した。
- **F-002 (AC-3: Node Mapping Masters ヘッダーの視認性基準)**:
  - 指摘: タイトルの識別可能性およびボタンの競合防止の判定基準が定性的である。
  - 整理・反映: 主操作「Add Master」を直接表示し、「ステージ管理」「カスタム型マスタ」を「管理 ⋯」サブメニュー内に隔離してコンテナ幅超過と重なりを防止することを明記した。詳細タイポグラフィ基準は設計フェーズで確認する。
- **F-003 (AC-4: サブメニュー内モーダル遷移の定義)**:
  - 指摘: 「従来どおり」のモーダル挙動の参照元が不明確である。
  - 整理・反映: 先行する REQ-367 / SPEC_SETTINGS のモーダル契約に準拠することを Inferred points に記録した。
- **F-004 (AC-5: ⓘ アイコン対象パラメータの具体化)**:
  - 指摘: どのパラメータに ⓘ アイコンを配置するかの境界が曖昧。
  - 整理・反映: AC-5 において、画像処理フィルタ、フキダシ検出パラメータ、翻訳待ち時間デバウンス等の「詳細説明を要するパラメータ」を明示し、明白な重複説明（見出しの単純な言い換え）との境界を明確化。
- **F-005 (AC-6: ポップオーバーの背景不透明度とコントラスト)**:
  - 指摘: 「不透明なダーク背景」と「十分なコントラスト」の基準が曖昧。
  - 整理・反映: ダークテーマに準拠した不透明背景（背面の透け込みによる可読性阻害を防止）およびカード枠外クリップ防止を AC-6 に定めた。
