## 依存interface / API

`getState(key): {phase:'idle'|'dirty'|'invalid'|'saving'|'saved'|'error';revision:number;error:string|null}`。`stage(key,string|null)`, `commit(key)`, `retry(key)`, `acceptServer(key,string)`。PUT /api/settings/vramはGB必須/flag任意、responseはGB/flag必須。PUT /api/llm-prompts/{key}はcontent:string、responseはLlmPrompt。API/schema/backendは変更しない。

## T0 Draft registry integration

T0の `useSettingsDraftRegistration(resourceId,{cancelQueued,discardLocal})` は `{update(risk),clear()}` を返す。riskは `{dirty,invalid,failed,queued,inFlight}:boolean`。unique instance ID/resourceで登録し、raw値をregistryへ渡さない。edit/commit/ack/errorで同期updateし、cleanup/成功baseline一致/明示cancelで適切にclearする。mobile/desktopとも登録する。

Cancel navigationはdraft/queueを変えない。確認中inflight保存は通常完了するが、Leaveは全persist inFlight==falseまでdisabled。explicit Leave時だけ未送信queueを同期停止しlocal draftを破棄するcallbackを提供し、remote successのrollbackやautomatic retryをしない。同Settings hash/query切替とresizeだけでは破棄しない。previewなど非persist要求は保存inFlightに数えない。

Bubble/VRAM/debounceはcommit hookのqueue/pendingに加えraw invalidを登録。Translation provider+credential form、workflow config/import適用前draft、BaseModel/model/checkpoint formも現親state/baselineからdirtyを登録する。credentialsはflagsのみ渡す。既存requestが進行中はinFlight、失敗はfailed。取消でdraftが残り、Leave callbackで未送信queueのみ停止。
