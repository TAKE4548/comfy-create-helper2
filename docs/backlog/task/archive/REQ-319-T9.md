# REQ-319-T9: Step 3 ローカル学習設定パネル・パラメータ解説Tooltip・リアルタイムLoss/VRAM監視チャート

## 1. 概要と目的
LoRA学習パラメータ設定（Epochs, Repeats, Batch Size, Save Interval）から総ステップ数とチェックポイント数を動的に算出し、全パラメータに対する数学的・物理的意味およびハードウェア推奨値（RX 9070 XT / ROCm）の解説Tooltipを提供する。また、WSL2上の学習プロセス非同期起動、停止ボタンによる安全中断、リアルタイム Loss 収束 SVG グラフ、VRAM・温度テレメトリ監視、および学習中の画像生成抑止ガードを実装する。

## 2. 密閉コンテキスト (Hermetic Context)

### 2.1 スケジュール動的計算ロジック
```typescript
export function computeTrainingSchedule(itemCount: number, repeats: number, batchSize: number, epochs: number, saveInterval: number) {
  const stepsPerEpoch = Math.ceil((itemCount * repeats) / batchSize)
  const totalSteps = stepsPerEpoch * epochs
  const checkpointsCount = Math.floor(epochs / saveInterval)
  return { stepsPerEpoch, totalSteps, checkpointsCount }
}
```
