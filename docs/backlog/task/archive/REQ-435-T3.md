# REQ-435-T3: History画面のモバイル余白整理・フィルター初期折り畳み・件数表示・常時ソート

> 本 Task Card は本タスクの唯一の意味仕様書（sole semantic specification）である。実装時の追加調査が必要な場合は dev-task の有界調査規則に従い、未解決事項は推測せずエスカレーションすること。

## 1. 概要と目的
History 画面（幅 767px 以下）において、ヘッダー操作ボタンの視覚外形をスリム化しつつ Hit-Slop ≥ 44×44px を保ち、スナップショット一覧のフィルター領域を初期折り畳み（1 行表示）にする。絞り込み条件指定中は折り畳み行に件数を文字表示し、ソートは開閉状態によらず常時操作可能とし、0 件時 Empty State からのフィルター解除を維持する。

## 2. ターゲット識別（Impacted Files）
- `frontend/src/pages/HistoryPage/index.tsx`（L293–345）
- `frontend/src/pages/HistoryPage/views/SnapshotGalleryView.tsx`（L65–228, L366–375）
- `frontend/src/pages/HistoryPage/views/__tests__/SnapshotGalleryView.test.tsx`

## 3. UI アーキタイプと外科的制約
<constraints>
- **Archetype**: `Archetype 2: Tabs / Chips / Grids` + `Archetype 3: Forms & Controls`
- **Hit-Slop (Mobile <768px)**: 対象ボタン（`#view-snapshots`, `#view-albums`, `#open-batch-speech-modal-btn`, `#start-create-album`, `#history-mobile-filter-toggle`, モバイルソート 2 ボタン）に `data-tap-target-exempt` + `relative h-8 md:h-auto touch-manipulation before:absolute before:content-[''] before:inset-x-0 before:-inset-y-[7px] md:before:hidden`（枠なしボタンは `before:-inset-y-1.5`）を適用し、外形 32px・有効高さ 44px・横拡張 0px（隣接非重複）を保証。
- **クリッピング防止**: View Toggle ラッパー（`index.tsx` L300）およびソートボタングループラッパーの `overflow-hidden` を除去し、先頭/末尾ボタンに `first:rounded-l-lg last:rounded-r-lg` を付与。
- **Desktop 保護**: フィルターパネルは `${isMobileFilterOpen ? 'flex' : 'hidden'} md:flex` により 768px 以上で常時展開を維持。検索 input・絞り込みチップの `min-h-11` は `md:min-h-0 md:h-8` で PC 過大寸法を解消。
- **REQ-374 境界保護**: 画像カードオーバーレイ（`SnapshotGalleryView.tsx` L305–353）およびヘッダー要素の配置先移動は変更しない。
</constraints>

## 5. 実装要件
- [ ] `HistoryPage/index.tsx`:
  - `#view-snapshots`, `#view-albums`, `#open-batch-speech-modal-btn`, `#start-create-album` に `data-tap-target-exempt` + `h-8 md:h-auto` + 縦方向 Hit-Slop を適用し、View Toggle 外枠の `overflow-hidden` を外す（AC-1, AC-2）。
- [ ] `SnapshotGalleryView.tsx`:
  - モバイル専用常時表示 1 行バー（`data-testid="history-mobile-filter-bar"`, `className="flex md:hidden items-center justify-between gap-2 px-3 py-1.5 border-b border-[rgba(255,255,255,0.06)] bg-surface/30"`）を追加（AC-10）。
    - 左: `#history-mobile-filter-toggle` ボタン（`aria-expanded={isMobileFilterOpen}`, `aria-controls="history-filter-controls"`, `data-tap-target-exempt`, `h-8` + Hit-Slop）。テキスト「フィルター」と、`activeFilterCount > 0` のとき `<span data-testid="history-active-filter-count">({activeFilterCount}件)</span>` および開閉 Chevron を表示（AC-11）。
    - 右: モバイル用ソート切替（「新しい順」「古い順」、`data-tap-target-exempt`, `h-8` + Hit-Slop、`overflow-hidden` なし）＋件数 `{sortedSnapshots.length}件`（AC-12）。
  - 既存フィルターコンテナに `id="history-filter-controls"` を付与し、`${isMobileFilterOpen ? 'flex' : 'hidden'} md:flex flex-wrap items-center gap-2 sm:gap-3 px-3 md:px-5 py-2 border-b border-[rgba(255,255,255,0.06)] bg-surface/30` とする。内部の Desktop ソート＆件数表示には `hidden md:flex` / `hidden md:inline` を付与してモバイルでの重複表示を防ぐ。
  - グリッドラッパーのパディングを `p-3 md:p-5` とし、360×640px で最初の画像カードがスクロールなしで確実に収まるようにする（AC-10）。
  - `sortedSnapshots.length === 0` 時、`activeFilterCount > 0` なら「条件に一致するスナップショットがありません。」と「フィルターを解除」ボタンを表示して `clearAllFilters` を実行できるようにする（AC-12）。
