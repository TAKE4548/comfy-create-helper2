### 4.2 無限スクロール (Infinite Scroll Implementation)
`IntersectionObserver` を用いて、リスト下部のセンチネル要素（`snapshotSentinelRef` / `albumItemSentinelRef`）がビューポートに交差した際、表示件数リミットを `+24` します。
```typescript
useEffect(() => {
  const sentinel = snapshotSentinelRef.current
  if (!sentinel) return

  const observer = new IntersectionObserver((entries) => {
    if (entries[0].isIntersecting) {
      setSnapshotLimit((prev) => prev + 24)
    }
  }, { rootMargin: '200px' })

  observer.observe(sentinel)
  return () => observer.unobserve(sentinel)
}, [snapshots, snapshotLimit])
```

### 4.3 UI 構造 (UI Layout & Element IDs)
1. **Modal Container**:
   - `fixed inset-0 z-50 flex items-center justify-center bg-black/75 backdrop-blur-sm p-4`
   - モーダルカード: `bg-[#18181C] border border-[rgba(255,255,255,0.08)] rounded-xl w-full max-w-4xl max-h-[85vh] flex flex-col overflow-hidden shadow-2xl`
2. **Header**:
   - 左側: アイコン (`ImageIcon`) + タイトル「ベース画像を差し替え」
   - 中央: タブ切り替えボタン (`button id="tab-snapshots"`, `button id="tab-albums"`)
   - 右側: 閉じるボタン (`X`)
3. **Snapshots View** (`activeTab === 'snapshots'`):
   - フィルタバー:
     - ワークフロー選択: `select id="base-image-workflow-filter"` (Option: "All Workflows", 各ワークフロー名)
     - LoRA 選択: `select id="base-image-lora-filter"` (Option: "All LoRAs", 各LoRA名)
     - TagSet 選択: `select id="base-image-tagset-filter"` (Option: "All Tag Sets", 各TagSet名)
     - ソート順切り替え: `button id="sort-desc"` (新しい順), `button id="sort-asc"` (古い順)
     - 件数ラベル: `{sortedSnapshots.length} 枚`
   - グリッド (`grid grid-cols-3 sm:grid-cols-4 md:grid-cols-6 gap-3`):
     - 各アイテム: `button` (クリックで `onSelect(s)` 実行)
     - サムネイル画像: `s.thumbnail_path || s.image_path || ''`
     - 現在の画像表示: `s.id === currentSnapshotId` の場合「現在」バッジ
     - ID 表示: `#{s.id}`
     - センチネル: `div ref={snapshotSentinelRef}` (可視件数 < 総件数の場合)
4. **Albums View** (`activeTab === 'albums'`):
   - **アルバム未選択時 (`selectedAlbumId === null`)**:
     - グリッド (`grid grid-cols-2 sm:grid-cols-3 md:grid-cols-4 gap-4`):
       - アルバムカード: クリックで `setSelectedAlbumId(album.id)`
       - カバーサムネイル: `album.items[0]?.thumbnail_path || album.items[0]?.image_path` (無ければ `BookOpen` アイコン)
       - アルバム名、アイテム件数表示
   - **アルバム詳細表示 (`selectedAlbumId !== null`)**:
     - サブヘッダー:
       - 戻るボタン (`ArrowLeft`, `button id="album-back-btn"`): クリックで `setSelectedAlbumId(null)`
       - アルバム名、枚数
       - ソートセレクター: `button id="album-sort-custom"`, `button id="album-sort-date-desc"`, `button id="album-sort-date-asc"`
     - グリッド:
       - アルバムアイテムカード: クリックで `onSelect({ id: item.snapshot_id, image_path: item.image_path, thumbnail_path: item.thumbnail_path })`
       - 現在の画像表示: `item.snapshot_id === currentSnapshotId` の場合「現在」バッジ
       - センチネル: `div ref={albumItemSentinelRef}`
