## 3. 実装要件 (Implementation Logic)
1. **`App.tsx`**:
   - `excluded` 配列に `'workflow-presets'` を追加し、起動時に過去のキャッシュが復元されて初期化判定を壊す挙動を防止。
2. **`usePresetState.test.ts`**:
   - `isDirty: false` 時にサーバーの `updated_at` が進んだ場合、`loadPresetData` が呼ばれてストアが同期されることのテスト。
   - `isDirty: true` 時にサーバーの `updated_at` が進んだ場合、勝手に上書きされず `conflictData` が生成されることのテスト。
   - 409 Conflict 時に `conflictData` が正しくセットされることのテスト。
3. **`PresetConflictModal.test.tsx`**:
   - デスクトップ表示（左右2カラム）およびモバイル表示（タブ切り替え）のレンダリングテスト。
   - 3つのボタン（サーバー採用、ローカル上書き、別名保存）のコールバック発火テスト。
