## Dispatch clarification: numeric bounds

WorkflowMapping fields are role:string|null, param_name:string|null, input_type:string|null. ParamTypeMaster has name/widget_type/min_value/max_value/step (nullable values); existing custom-type lookup is name === mapping.input_type. Its finite min_value/max_value are authoritative for custom fields. For built-in sampler roles Sampler_Steps/Sampler_CFG/Sampler_Denoise, read comfyObjectInfo.KSampler or KSamplerAdvanced fallback, input.required[param_name] or optional[param_name], tuple index 1 metadata {min?,max?,step?}. Those exact sampler roles can fall back to known parameter names steps/cfg/denoise if param_name is absent. Missing metadata retains the existing unconstrained range; do not invent bounds. Required increments are 1/0.1/0.01 respectively. Clamp available finite bounds and round decimal precision; synced slaves stay disabled. LoRA 0.05 is integrated by LoRA/AddAsset cards rather than modifying unowned LoraStackEditor here. Test ± behavior with metadata bounds, no metadata, decimal precision, and disabled fields.
