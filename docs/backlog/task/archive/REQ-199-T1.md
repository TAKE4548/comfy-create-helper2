### 2.2 JSX 構造とイベント伝播制御 (`frontend/src/components/ImageCropper.tsx`)
- 最外層の固定オーバーレイ要素 (`div.fixed.inset-0.z-50...`) に `onClick` ハンドラを追加し、イベントの親要素へのバブリングを確実に遮断（`e.stopPropagation()`）する。
- 同時に、オーバーレイ背景自体をクリックした場合にのみ `onCancel()` を呼び出す（`if (e.target === e.currentTarget) onCancel()`）。
- 内部のモーダルダイアログ本体 (`div.relative.flex.flex-col...`) にも `onClick={(e) => e.stopPropagation()}` を設定し、ダイアログ内（Cropper、スライダー、ボタン等）のクリック・ドラッグ操作終了イベントがオーバーレイ側へバブリングしないようにする。

```tsx

  imageSrc,
  onCropComplete,
  onCancel,
  aspectRatio = 3 / 4,

    <div
      className="fixed inset-0 z-50 flex flex-col items-center justify-center p-4 bg-black/80 backdrop-blur-sm"

        if (e.target === e.currentTarget) {
          onCancel();
        }

          </h3>

            onClick={onCancel}
            className="text-slate-400 hover:text-slate-200 transition-colors"
```
