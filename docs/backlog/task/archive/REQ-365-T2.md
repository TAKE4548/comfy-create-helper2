## 変更内容
1. `ModalProps` に `sheetMaxHeightClass?: string` を追加。既定は現行文字列 `'max-h-[calc(100dvh-env(safe-area-inset-top))]'`。dialogのclassNameでその部分を `${sheetMaxHeightClass}` に置換（`md:max-h-[90dvh] lg:max-h-full` は維持）。呼出側は `'max-h-[85dvh]'` を渡せる。
   `sheetMaxHeightClass` が未指定または空文字列（`''`）の場合は既定クラスへフォールバックする（空文字でmax-h無しにならない）。
2. ドラッグハンドル `div` に `data-testid="modal-sheet-handle"` を追加（クラス・md:hidden維持）。
3. それ以外（focus trap、body scroll lock、Escape、backdropクリック、`role="dialog"`、`aria-label`）は**変更しない**。

## テスト追加（`Modal.test.tsx`）
- `it('[REQ-365/AC-9] renders the sheet handle with testid and applies sheetMaxHeightClass', ...)`: `sheetMaxHeightClass="max-h-[85dvh]"` で `role=dialog` の className に `max-h-[85dvh]` を含み、既定の `calc(100dvh-env(safe-area-inset-top))` を含まない。未指定時は現行クラスを含む（後方互換）。`getByTestId('modal-sheet-handle')` が `md:hidden` と `aria-hidden` を持つ。
- `it('[REQ-365/AC-9] falls back to the default max-height class when sheetMaxHeightClass is empty', ...)`。
- `it('[REQ-365/AC-9] keeps rounded-t-2xl and items-end bottom-sheet classes on mobile', ...)`: backdropに `items-end`/`md:items-center`、dialogに `rounded-t-2xl`。

<constraints>

- 生 `vh` 禁止、`dvh` を使う。フォント変更なし。
</constraints>
