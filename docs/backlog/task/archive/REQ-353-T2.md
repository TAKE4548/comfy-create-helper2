## Implementation and Acceptance

1. primary→fallback登録順を唯一の解決規則にする。非空文字列・完全一致・重複除外・own property・値!==undefinedで最初の既存keyを返す。無ければnull。

2. implicit value/noise_seed推定やkey新設を行わない。valueを使うならprimaryまたはfallbackへの明示登録が必要。fallback未指定/nullは空候補扱い。

3. unitはprimaryとfallback共存、二つのfallbackの順序、重複候補、0/null、未登録key、undefined、missing inputs、prototype属性、登録済valueと未登録valueを確認する。

4. primaryの値が配列でもkey解決自体はprimaryを返す。graph-reference拒否はconsumer責務で、別名へ逃げない。
