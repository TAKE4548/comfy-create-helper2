# REQ-427-T5: 画像入力 UI（Desktop / Mobile）

## 1. 目的
`input_type === 'image'` の有効マッピングに対し、Generate のパラメータ入力パネル（Desktop / Mobile 共通の `ParamPanel`）へ画像入力欄と選択中画像のサムネイルを表示する（AC-3）。主導線は生成履歴・スナップショットからの選択（AC-4）、加えてファイル選択アップロード・D&D・フォーカス時ペースト（AC-5）。失敗時はエラーを通知し既存の値・サムネイルを保持する。無効化マッピングは表示されず（AC-7）、プリセット切替等で値が変わればサムネイルが追従する（AC-8）。クリアボタンは作らない。

## 6. UI 仕様
### 6.1 ImageParamField（Archetype 3: Forms & Controls ＋ ドロップ領域は Generic）
- ラベル `label`。ルート要素に `data-testid={`image-param-${fieldKey}`}`。ピッカーの開閉時に `onPickerOpenChange?.(open)` を呼ぶ。本体: サムネイル（Desktop 64px / Mobile 56px 角、`shrink-0 object-cover rounded`）＋ボタン群。
- 値が `isRefImageToken` → `<img src={refImageThumbnailUrl(value)} alt="選択中の参照画像">`、`onError` で「プレビューを表示できません」（値は保持）。サーバー側の自動クリーンアップ（GC）で画像が削除済みの場合もこの表示になる。値を勝手に消したり未指定へ戻したりしない（生成時はサーバーが 422 `ref_image_not_found` を返し、利用者が選び直す）。それ以外 → 「未指定」プレースホルダー。
- ボタン: 「履歴/スナップショットから選択」（`RefImagePickerModal` を開く）、「アップロード」（非表示 `input[type=file][accept="image/png,image/jpeg,image/webp"]` を click）。
- D&D: ルート要素で `onDragOver`（`preventDefault`、強調表示）/`onDragLeave`/`onDrop`（`dataTransfer.files[0]`）。
- ペースト: ルート要素 `tabIndex={0}` + `onPaste`。`clipboardData.files[0]`、無ければ `items` の `kind === 'file'` かつ `type` が image のもの。**フィールド外の paste は扱わない**（document リスナー禁止）。
- 事前検証: `type` が `ACCEPTED_REF_IMAGE_MIME` 外 → 「画像ファイル（PNG / JPEG / WebP）を指定してください」、`size > MAX_REF_IMAGE_BYTES` → 「画像サイズが上限（20MB）を超えています」。API を呼ばない。
- 実行: `refImagesApi.upload(file, file.name)` → 成功で `onChange(res.token)`。モーダル選択は `onSelected(image)` → `onChange(image.token)`。
- 失敗（事前検証・例外）: フィールド内 `<p role="alert" className="text-xs text-red-400 break-words">`（truncate 禁止）＋ `setErrorToast({ message, type: 'error' })`。**`onChange` を呼ばない**＝既存値・サムネイル保持。成功時はエラー表示を消す。
- 並行: 要求ごとに連番 `requestSeq`（`useRef`）を採番し、応答時に最新番号でなければ破棄（成功・失敗とも反映しない）。処理中はボタン `disabled` と「処理中…」表示。
- `disabled`（ParamSync slave）時は全操作不可・ドロップ/ペースト無視。

### 6.2 RefImagePickerModal（Archetype 1: Modals、内部グリッドは Archetype 2）
- `Modal` を `size="lg"`, `ariaLabel="参照画像を選択"`, `sheetMaxHeightClass="max-h-[85dvh]"` で使用。
- タブ「生成履歴」「スナップショット」。履歴は `comfyHistoryImages` を `toThumbnailUrl(url)` で表示、`parseHistoryImageUrl(url) === null` の項目は `disabled`。スナップショットは `useQuery({ queryKey: ['snapshots', { workflow_id: workflowId ?? null }], queryFn: () => snapshotsApi.list({ workflow_id: workflowId }), enabled: isOpen })`、`thumbnail_path ?? image_path` を表示、`image_path` 無しは除外。
- 0 件時は空状態文言（「生成履歴がありません」「スナップショットがありません」）。
- 選択: 履歴 → `refImagesApi.importFromHistory(parsed)`、スナップショット → `importFromSnapshot(id)`。成功 → `onSelected(res)` → `onClose()`。失敗 → モーダル内 `role="alert"` 表示、開いたまま。処理中は全タイル `disabled`。
