# REQ-415-T1: PatternTagInput モバイル仮想キーボード対応・追加ボタン新設・IMEガード・Blurフォールバック実装 & テスト

## 1. 概要と目的
`PatternTagInput` において、モバイル仮想キーボードでEnterを押下した際にフォーム内の次項目（Role上書き）へフォーカスが移動して入力が消失する不具合を解消し、タップ用「追加」ボタン（`<Plus size={12} />` 付き、44px Hit-Slop対応）、`enterKeyHint="done"`、日本語IME変換確定ガード、およびフォーカス離脱（`onBlur`）時の自動確定フォールバックを実装する。また、受入基準 AC-1 〜 AC-5 を検証する単体テストを `PatternTagInput.test.tsx` に追記する。

※本タスクは **AC-1, AC-2, AC-3, AC-4, AC-5** の実装とテストを担当する。

## 4. 実装要件 (Implementation Logic)
- [ ] 1. **「追加」ボタンの新設 (AC-1, AC-5)**:
  - `lucide-react` から `Plus` をインポート。
  - 入力欄の右側（またはフレックスコンテナ内）に `<button type="button">` を設置。
  - スタイル: `flex items-center gap-1 px-2.5 py-1 text-xs bg-zinc-800 hover:bg-zinc-700 text-zinc-200 rounded border border-zinc-700 disabled:opacity-40 transition-colors shrink-0`
  - Hit-Slop: `relative before:absolute before:-inset-2 touch-manipulation`
  - `disabled`: `disabled={disabled || !inputValue.trim() || patterns.includes(inputValue.trim())}`
  - クリック時に `addTag(inputValue)` を実行。
- [ ] 2. **仮想キーボード制御とEnterフォーム遷移抑止 (AC-2)**:
  - `<input>` に `enterKeyHint="done"` を設定。
  - `handleKeyDown` の Enter 押下時に必ず `e.preventDefault()` を実行してフォーム送信・遷移をブロック。
- [ ] 3. **フォーカス離脱 (onBlur) 自動コミット (AC-3)**:
  - `<input>` に `onBlur={() => addTag(inputValue)}` を設定。
  - 入力欄に未追加テキストがある状態でフォーカスが外れた場合、自動的に `addTag` を試みる。
- [ ] 4. **日本語IME確定ガード (AC-4)**:
  - `handleKeyDown` の先頭で `if (e.nativeEvent.isComposing || e.keyCode === 229) return` を追加。
  - 変換確定時のEnterではタグ追加を発火させず、変換完了後のEnterでのみ追加を許可する。
- [ ] 5. **重複・空文字ガード (AC-5)**:
  - `addTag` において、`text.trim()` が空文字、または `patterns.includes(trimmed)` の場合は追加せず `setInputValue('')` とする。
- [ ] 6. **ユニットテスト追記 (PatternTagInput.test.tsx)**:
  - `[REQ-415/AC-1]`: 「追加」ボタンタップでタグ追加＆入力欄クリア
  - `[REQ-415/AC-2]`: `enterKeyHint="done"` 設定およびEnter押下でのタグ追加
  - `[REQ-415/AC-3]`: 入力中のBlurでタグ自動追加
  - `[REQ-415/AC-4]`: 日本語IME入力中（isComposing）のEnterでは追加抑止、確定後Enterで追加
  - `[REQ-415/AC-5]`: 空文字または重複時の「追加」ボタン非活性（disabled）および重複追加抑止
