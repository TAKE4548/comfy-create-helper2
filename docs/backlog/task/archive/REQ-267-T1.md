## 1. 目的とスコープ
`SnapshotService.create_snapshot` において、外部クライアント端末から送信された ComfyUI `/view` URL のホスト部をバックエンド内部の `settings.comfy_url`（`http://localhost:8188`）へ正規化して実画像を取得するように改修する。また、ダウンロード失敗時に不正な URL がサイレントフォールバックとして DB 登録されるのを防止する。

## 4. 実装要件・手順
1. **URL 正規化ヘルパー関数の追加**:
   - `resolve_internal_comfy_url(url: str, base_url: str) -> str`:
     - URL に `/view?` または `/view/` が含まれる場合、クエリパラメータ（`filename`, `subfolder`, `type` 等）を維持したまま、オリジン（スキーム + ネットロケーション）を `base_url`（`settings.comfy_url`）に置き換える。
     - `/view` 形式でない外部一般画像 URL の場合は元の URL をそのまま返却。
2. **ダウンロード対象 URL の切り替え**:
   - `payload.image_path` が HTTP/HTTPS の場合、上記ヘルパーを用いて内部 URL `target_download_url = resolve_internal_comfy_url(payload.image_path, settings.comfy_url)` を生成。
   - `urllib.request.urlopen(target_download_url, timeout=10)` で画像を取得。
3. **エラーハンドリングの厳格化**:
   - ダウンロード例外（`URLError`, `HTTPError` 等）が発生した際、エラーログを出力した上で `HTTPException(status_code=502, detail=f"Failed to download snapshot image from ComfyUI: {e}")` を送出し、不完全なレコードが DB に登録されないようにする。
   - すでにローカルにある画像パス（`/api/snapshots/images/...`）の場合は既存のサムネイル生成・流用処理を維持。
