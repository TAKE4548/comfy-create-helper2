    def do_POST(self):
        if self.path == "/api/action":
            length = int(self.headers.get("Content-Length", 0))
            payload = json.loads(self.rfile.read(length).decode("utf-8") or "{}")
            action = payload.get("action", "status")
            service = payload.get("service", "")
            cmd = ["powershell.exe", "-ExecutionPolicy", "Bypass", "-File", str(PS_SCRIPT), "-Action", action]
            if action in ["start", "restart", "reboot-service"]:
                cmd.append("-Background")
            if service:
                cmd += ["-Service", service]
            res = subprocess.run(cmd, capture_output=True, text=True, creationflags=CREATE_NO_WINDOW)
            self._send_json({
                "status": "ok",
                "action": action,
                "output": (res.stdout or "") + (res.stderr or "")
            })
```

def check_port_listening(port: int, timeout: float = 0.5) -> bool:
    try:
        with socket.create_connection(("127.0.0.1", port), timeout=timeout):
            return True
    except (socket.timeout, ConnectionRefusedError, OSError):
        return False
```

## 3. 実装要件 (Implementation Logic)
- [x] `check_port_listening(port, timeout=0.5)` を実装し、ポートの LISTEN 状態を高速判定できるようにする。
- [x] `/api/status`:
  - `subprocess.run` に `timeout=6` を設定。
  - `threading.Lock` を導入して同時実行（多重 `powershell.exe` 生成）を防止。直近 2 秒以内のキャッシュがあればそれを返すか、ロック獲得で逐次実行する。
  - `subprocess.TimeoutExpired` 発生時: プロセスを `taskkill /PID ... /T /F` で確実に強制終了し、`check_port_listening` を用いたソケットフォールバック状態（FE/BE は実際の疎通結果、Comfy は `status = "TIMEOUT"`、`error = "PowerShell / WSL 応答タイムアウト"`）を HTTP 200 で返却する。
- [x] `/api/action`:
  - `subprocess.run` に `timeout=15` を設定。
  - `subprocess.TimeoutExpired` 発生時は HTTP 504 とエラー JSON を返却する。
- [x] フロントエンド JavaScript (HTML_TEMPLATE 内):
  - `setInterval(fetchStatus, 5000)` を廃止し、`isFetchingStatus` フラグおよび先行リクエスト終了後に再スケジュールする再帰的 `setTimeout` パターンに変更する。
  - `fetch('/api/status')` に `AbortController` (タイムアウト 7秒) を付与し、ブラウザ側でのリクエストハングを防止する。
  - `renderServices`: `status === 'TIMEOUT'` の場合に `.badge-timeout`（アンバー色）を適用し、エラーメッセージを表示しつつ、他サービス（FE/BE）のカードや操作ボタンが妨害されないようにする。
- [x] `tests/unit/test_server_manager_timeout.py` を作成し、ソケット判定、`/api/status` タイムアウトフォールバック、`/api/action` タイムアウト、並行アクセスロックをテストする。
