## 目的と受入

AC1:5分類と全設定値/操作を保持。AC2:mobile本文padding12px・主gap12px、横overflow/見切れなし。AC9:本文左右gestureと縦scroll/入力/overlayが共存。AC12:desktop/URL/hash/history/localStorage既存契約を維持。

新API: `useSettingsMobile(): boolean`（matchMedia max-width767px、listener cleanup）、`useSettingsSwipe({enabled, activeTab, onSelect}: {enabled:boolean; activeTab:SettingsTabId; onSelect:(id:SettingsTabId)=>void})`（本文へspread可能なpointer handlersを返す）。pure判定を同module内でexportしPBT可能にする。

- 1本primary touch/penのみ。dx>=48pxかつabs(dx)>1.5*abs(dy)で隣tabへ1回、端では不発。縦12px先行、多点、pointercancelは中止。preventDefault/pointer capture不要、本文touch-action pan-y。
- input/textarea/select/button/a/contenteditable/range/tablist、横scroll領域、`data-settings-swipe-ignore`、dialog/menu/popover中とoverlayが開いている間は不発。
- `SettingsTabId='workflows'|'prompt'|'dialogue'|'translation'|'system'`。並びはこの順、既存 `useSettingsTab():{activeTab:SettingsTabId;selectTab:(id:SettingsTabId)=>void}` を使う。URL/localStorage logicを複製しない。5panel hidden保持と直接tab/Arrow/Home/Endを残す。選択tabをscrollIntoViewで可視へ。
- shell/rootとBaseModel wrapperに明示的responsive classを付け、p3/md:p5、gap3/md:gap6を適用。CSSの任意の子padding一括overrideは禁止。固有cardの内部密度は後続card所有。
- 正常・vertical-first・interactive・overlay・端・dx/dy境界を実hook/pure判定で検証。fast-checkで任意dx/dyと保護targetの不発を検証。実layout/scrollは後続browserで実測。

## Constraints / UI archetypes

- mobileは<768px、desktopは>=768px。desktopの既存操作/Save/配置を保持。生vh、global font floor、一括padding overrideを追加しない。文字は11px以上、重要なerror/未保存はtruncateしない。

- Overlaysはoverscroll-contain、画面内/keyboard可視域に収める。横chip/tabはshrink-0/whitespace-nowrap、flexテキストはmin-w-0。共通Modalのfocus/Escape/85dvh契約を維持。
