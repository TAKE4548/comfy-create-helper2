# REQ-302-T3: MobileImageSheetおよびHistoryModalPreviewの前面化と画像閲覧例外維持

## 1. 概要と目的
画像閲覧を目的とする `MobileImageSheet.tsx`（下部画像プレビューシートおよび全画面ビューア）および `HistoryModalPreview.tsx` は、画像確認の既存例外としてその独自DOM・WakeLock・全画面切り替え・アスペクト比維持の仕様を保護する（通常Modalへの機械的置換を行わない）。
その上で、`z-50` を `z-[var(--z-modal)]`（100）へ統一し、ボトムナビ（`--z-mobile-nav: 50`）より前面化して背面操作を遮断するとともに、768〜1023px タブレット幅での不要余白が解消されていることを検証・固定する。

## 3. 変更仕様
1. **`MobileImageSheet.tsx` の前面化**:
   - 全画面ビューア: `className="... z-50 ..."` を `className="... z-[var(--z-modal)] ..."` へ変更。
   - 下部シート: `className="... z-50 ..."` を `className="... z-[var(--z-modal)] ..."` へ変更。
   - 既存の WakeLock 制御、タッチ操作、`100dvh`、Escapeキーによる段階的クローズ（fullscreen解除 -> sheetClose）はそのまま維持。
2. **`MobileImageSheet.test.tsx` のアサーション更新**:
   - `[REQ-372/AC-3]` の `expect(sheetContainer.className).toContain('fixed inset-0 z-50')` を `z-[var(--z-modal)]`（または `z-modal`）へのアサーションへ更新。
   - `[REQ-302/AC-1]` および `[REQ-302/AC-6]` の画像閲覧例外維持・前面化テストを追加。
3. **`HistoryModalPreview.test.tsx` のテスト追加**:
   - `[REQ-302/AC-2]` flex-col preview backdrop does not retain obsolete nav avoidance margin in tablet width

<constraints>
- Archetype 1: Modals & Overlays (画像閲覧例外)
- Universal Safety: raw `100vh` 禁止（`100dvh` 使用）、`touch-action: manipulation`
- 通常Modalへの機械的置換は厳禁（AC-6画像閲覧例外を維持）。
</constraints>
