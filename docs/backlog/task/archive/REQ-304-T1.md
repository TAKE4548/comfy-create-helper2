## 3. 実装要件 (Implementation Logic)
- [ ] `backend/requirements.txt`
  - `ctranslate2>=4.0.0` および `transformers>=4.30.0` を追記。
- [ ] `backend/app/services/fugumt_service.py`
  - `FuguMTService` クラスを実装する。
  - シングルトンパターン（`get_instance()`）を提供。
  - `initialize()`:
    - 遅延初期化を採用し、FastAPI起動時のクラッシュを防止。
    - `model_dir`（環境変数 `FUGUMT_MODEL_DIR` またはデフォルト `models/fugumt-en-ja`）からモデルとトークナイザーをロード。
    - `ctranslate2.Translator(model_dir, device="cpu", intra_threads=6, inter_threads=1, compute_type="int8")` を初期化。
    - `AutoTokenizer.from_pretrained(model_dir)` を初期化。
  - `normalize_input(text: str) -> str`:
    - `text.strip()` で前後空白を削除し、`re.sub(r"\s+", " ", ...)` で連続スペースを単一空白に縮退。
    - 空文字の場合は空文字 `""` を返却。
  - `translate_batch(texts: List[str]) -> List[str]`:
    - 空リストの場合は `[]` を即時返却。
    - 各要素を `normalize_input` 処理。
    - 未初期化の場合は `initialize()` を実行。失敗時は `RuntimeError("FuguMT engine is not available")` をスロー。
    - メモリ枯渇・バッファ超過防止のため、`MAX_BATCH_SIZE = 100` ごとにチャンク分割して推論ループを実行。
    - `source_tokens = [tokenizer.convert_ids_to_tokens(tokenizer.encode(t)) for t in chunk]` を生成し、`translator.translate_batch(source_tokens)` で推論。
    - 結果トークン列を `tokenizer.decode` で日本語文字列に復元して連結リストで返却。
  - `set_translator(translator, tokenizer)`:
    - テスト時にモック translator / tokenizer を注入可能にする DI メソッドを提供。
- [ ] `backend/tests/test_fugumt_service.py`
  - `normalize_input` の単体テスト（前後空白、タブ・改行、連続空白、空文字）。
  - `translate_batch` のモック推論テスト（バッチ一括変換、特殊トークン保持、空リスト）。
  - `initialize` の未検出ディレクトリ時の例外ハンドリングテスト。
  - `set_translator` を用いたモックDI検証。
