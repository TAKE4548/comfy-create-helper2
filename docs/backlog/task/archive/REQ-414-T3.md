# REQ-414-T3: バッチ生成・乱数生成およびワークフロー注入の大整数整合

## 1. 概要と目的
`seedBatch.ts` において、`MAX_SAFE_SEED` および `COMFY_RANDOM_SEED_MAX` をインポートし、バッチ生成前の範囲検証（`MAX_SAFE_SEED` 超過チェック）と乱数生成（0 〜 1125899906842624）を大整数安全に更新する。また `workflowParamInjector.ts` においてComfyUIワークフローJSONへの注入処理が正常に完了することを担保し、統合テストを整備する。
