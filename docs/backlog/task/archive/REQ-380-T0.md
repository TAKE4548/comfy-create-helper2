# REQ-380-T0

## Responsibility and ownership

engineer/dev-taskが.agents/verification.jsonだけを所有する。目的はManager source変更をGate identityへ含めること。profileのfixed_commands/endpoints/full_suite_argv/require_scenarioや既存入力範囲は変更しない。設計の具体承認とcoordinatorによるstatus開始後だけ着手する。

## Execution context

Windows PowerShell、cwdは検証済みproject Git root。PYTHONDONTWRITEBYTECODE=1を設定する。現在のsandboxでは.agentsがread-onlyなので、実際の公開された許可機構でこの1ファイルへの書込権限を確認する。拒否時はpendingを返し、別profile・コピー・別shellで回避しない。installed execution.mdを同じGLOBAL_SKILLS rootから読み、共通helperを使う場合はsection 9のpath/cwd/output副作用を先に確認する。配布済み定義や他の設定は編集しない。

## Contract

- identity.input_dirsへtools/server-managerを重複なしで追加する。
- identity.excluded_prefixesへtools/server-manager/logs/を重複なしで追加する。
- root-relative POSIX path、UTF-8 BOMなし、LF、重複JSON keyなしを保つ。
- 入力に含まれるconfig.jsonの既存ユーザー変更を戻さない。logsは除外するがManager source自体は除外しない。
- code/local検査の完了を返す。final Gate記録、scope manifest、PBI/Card状態、commit/archiveはcoordinator所有。

## Verification and return

~~~powershell
backend\.venv\Scripts\python.exe -c "import json,pathlib; p=pathlib.Path('.agents/verification.json'); b=p.read_bytes(); assert not b.startswith(bytes([239,187,191])) and bytes([13]) not in b; v=json.loads(b); assert 'tools/server-manager' in v['identity']['input_dirs']; assert 'tools/server-manager/logs/' in v['identity']['excluded_prefixes']"
~~~

変更前後diffで2つの追加だけを確認する。最終受入担当はverification_recordの通常profile読込でschemaを検証し、Managerソース変更で入力identityが変化すること、logs生成では変化しないことをtest-owned一時fixtureで確認する（実sourceに試験用変更を残さない）。このCardは動作テスト追加を要しない限定設定変更。返却は変更path、before/after hash、実行commandと結果、権限制限。独立受入PASSは付けない。

## Runtime boundary

対象は現行Windows PowerShellの検証設定だけであり、cross-OS互換を追加しない。指定commandはargvで実行し、shellを使うのは環境変数の設定と起動だけ。テスト用configはproduction configと別のtemp pathに限定し、本番設定の書換えで検証identityを試さない。
