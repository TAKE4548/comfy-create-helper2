# REQ-338-T7: モバイルレイアウト統合（Spacing Tokens、100dvh、IME自動退避・サジェストバー吸着、Natural Thumb Zone、端末回転防御）

## 1. 概要と目的
`MobileLayout.tsx` に対し、Spacing Tokens 圧縮（`px-3 py-2.5`、`p-2.5`、`gap-2`）、`100dvh` 動的追従、iOS Home Indicator セーフエリアクリアランス、IME 仮想キーボード起動時の Action Bar 自動退避とタグサジェストバー吸着、下部 40% Natural Zone 集約、および Pull-to-refresh 暴発防止を統合する。

## 4. 実装要件 (Implementation Logic)
- [ ] ルートコンテナのビューポートを `h-[100dvh] flex flex-col` に変更。
- [ ] 画面外枠パディングを `px-3 py-2.5`、カード内パディングを `p-2.5`、グリッド間隔を `gap-2` に圧縮。
- [ ] 入力欄（input, textarea）へのフォーカス時に `isInputFocused` を `true` にし、固定 Action Bar を `hidden` に自動退避。
- [ ] キーボード直上にタグサジェストアクセサリバーを吸着配置。
- [ ] 最下部 40%（Natural Zone）に Generate、選別、キュー管理を集約。
- [ ] 最外層スクロール領域に `overscroll-behavior-y: contain` を付与し、Pull-to-refresh 誤爆を完全に防止。
- [ ] 端末回転（縦 ↔ 横）時にもセーフエリアと Natural Zone を正しく維持。
- [ ] `useAppLifecycleSync()` フックを組み込み、タブ復帰時の 0 秒再同期を有効化。
- [ ] [BA監査反映・端末回転＆IME連携] 端末回転（`orientationchange` / `resize`）時のキーボード退避状態リセットと、`window.visualViewport` リサイズイベントへの動的追従ハンドラの実装。
- [ ] 単体・統合テスト `MobileLayout.test.tsx` で Spacing、Action Bar 退避、Natural Zone の動作を検証。
