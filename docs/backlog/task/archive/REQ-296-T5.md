## 密閉コンテキスト

対象: `backend/app/routers/speech_scene.py:52,63`。JSON APIは現在 `ValueError` を404、他例外を本文付き500にする。streamは `_stream_error(exc: Exception) -> dict[str,str]` で400/接続/時間切れ/ValueError以外をunknownにする。

```python
except ValueError as e:
    logger.warning(f"Bad request in generate_scene_draft: {e}")
    raise HTTPException(status_code=404, detail=str(e))
except Exception as e:
    logger.error(f"Error in generate_scene_draft: {e}", exc_info=True)
    raise HTTPException(status_code=500, detail=f"Scene draft generation failed: {e}")

def _stream_error(exc: Exception) -> dict[str, str]:
    if isinstance(exc, httpx.HTTPStatusError) and exc.response.status_code == 400:
        kind, message = "lm_studio_400", "The language model rejected the request."
    elif isinstance(exc, httpx.ConnectError):
        kind, message = "connection_refused", "The language model service is unavailable."
    elif isinstance(exc, httpx.TimeoutException):
        kind, message = "timeout", "Scene generation timed out."
    elif isinstance(exc, ValueError):
        kind, message = "invalid_request", "Scene draft inputs are invalid."
    else:
        kind, message = "unknown", "Scene draft generation failed."
    return {"type": "error", "error_kind": kind, "message": message}
```

## 実装契約

- `SceneDraftError.code` をJSON APIとstreamの双方で明示的に分類する。VLM形式・途中終了・モデル構造化非対応・LM Studio通信エラーは制御された502/503/504相当と短い固定文言で返す。入力404の条件は限定する。
- ログはエラーコード、HTTP状態、処理段階、解放成功/失敗を残し、モデル返答・画像・prompt・サーバー返答本文やファイルパスを含めない。
- 元の推論エラーと解放エラーが重なっても元のAPIエラー分類を保持し、解放失敗を別の安全な診断として観測可能にする。正常結果で解放失敗したJSON APIは `vram_unloaded=false` を正しく返すか、streamと整合する制御失敗を返す。選択した挙動をAPIテストで固定する。
