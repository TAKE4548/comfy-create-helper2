## 3. 実装要件 (Implementation Logic)
- [ ] `frontend/src/store/types.ts` および `frontend/src/store/slices/multiSetSlice.ts` において:
  - `roleTextModes: Record<string, boolean>` 状態を初期値 `{}` で定義。
  - `setRoleTextMode: (role: string, isTextMode: boolean) => void` アクションを定義し、`set((state) => ({ roleTextModes: { ...state.roleTextModes, [role]: isTextMode } }))` を実装。
- [ ] `DesktopLayout.tsx` および `MobileLayout.tsx` において:
  - ストアから `roleTextModes` と `setRoleTextMode` を取得。
  - 各ロールの `defaultTextMode` 算出を以下のように改善（Animaモード含む全モデルでデフォルトをチップモードへ統一）:
    ```typescript
    const resolvedTextMode = roleTextModes?.[m.role!] ?? false;
    ```
  - `onTextModeToggle` コールバックで `(isText) => { setRoleCollapsed(role, false); setRoleTextMode?.(role, isText); }` を呼び出す。
  - これにより、Animaモードを含む全モデルで初期表示がタグチップモードとなり、ユーザーが手動でテキストモードへ切り替えた場合のみタブ切替（`activeSetId` 変化によるアンマウント/再マウント）や画面遷移後もテキストモード状態が保持される。
