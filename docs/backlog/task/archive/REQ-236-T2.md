# Task: REQ-236-T2 バックエンド障害注入テスト (respx) の新設

## 1. 概要
respx を活用し、ComfyUI プロキシおよび LLM サービスとの外部 HTTP 通信において、接続タイムアウト（`httpx.ConnectTimeout`）、読み取りタイムアウト（`httpx.ReadTimeout`）、および不正・破損 JSON 受信時の適切なエラーハンドリングと HTTPException(503/502等) の送出を検証するバックエンドテストを新設する（AC-4）。

## 2. 対象ファイル (最大3ファイル)
- `backend/tests/test_comfy_proxy_fault.py` [NEW]
- `backend/tests/test_llm_service_fault.py` [NEW]

### 3.3 respx を用いたテスト実装パターン
```python
import pytest
import respx
import httpx
from fastapi.testclient import TestClient
from app.main import app
from app.config import settings

@pytest.fixture
def client():
    return TestClient(app)

@respx.mock
def test_comfy_object_info_connect_timeout(client):
    respx.get(f"{settings.comfy_url}/object_info").mock(
        side_effect=httpx.ConnectTimeout("Connection timed out")
    )
    response = client.get("/api/comfy/object_info")
    assert response.status_code == 503
    assert "unavailable" in response.json()["detail"].lower()
```

## 4. 実装手順 (Step-by-Step Implementation)

### 4.1 `backend/tests/test_comfy_proxy_fault.py` の作成
1. `@respx.mock` を用いて、`settings.comfy_url` へのリクエストをインターセプトする。
2. `/api/comfy/object_info` に対して `httpx.ConnectTimeout` を注入し、ステータスコード `503` が返却されることをアサート。
3. `/api/comfy/object_info` に対して `httpx.ReadTimeout` を注入し、ステータスコード `503` が返却されることをアサート。
4. `/api/comfy/object_info` に対して不正な JSON（壊れた HTML エラーページ等）を返却し、`503` が返却されることをアサート。
5. `/api/comfy/prompt` に対して `httpx.ConnectTimeout` を注入し、ステータスコード `502` が返却されることをアサート。
6. `/api/comfy/prompt` に対して `httpx.ReadTimeout` を注入し、ステータスコード `502` が返却されることをアサート。

### 4.2 `backend/tests/test_llm_service_fault.py` の作成
1. `@respx.mock` を用いて、`settings.llm_base_url` へのリクエストをインターセプトする。
2. `call_llm` を直接呼び出し、`httpx.ConnectTimeout` および `httpx.ReadTimeout` 発生時に適切に例外が再送出されることを検証。
3. 不正 JSON（`choices` フィールドが存在しないレスポンス等）を受信した際、KeyError や JSONDecodeError が適切にハンドリングされることを検証。
4. TestClient を通じて `/api/llm-prompts/scene-generate` および `/api/llm-prompts/translate` を呼び出し、LLM サーバーダウン時（ConnectionRefused / Timeout）に適切な HTTP 500/503 エラーレスポンスが返却され、サーバープロセスがクラッシュしないことを検証。
