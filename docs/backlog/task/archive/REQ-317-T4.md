## Implementation
- 新hookでT3 measureBrowserStorageUsageを呼び、local React stateで返す。active mount初回計測、2500msごとの計測、hiddenでtimer停止、visible復帰で即計測してtimer再開。cleanupでlistener/timer全撤去。
- useSystemStats/WS/socket/remote arrivalへ依存させない。getter失敗もUIをクラッシュさせず領域別結果を反映。初期値はunavailable、初回正常計測後に更新する。
- visibility連打・StrictModeの再マウントでtimer重複を残さない。同タブsetItemのstorage eventは発火しないのでeventだけの更新にしない。
