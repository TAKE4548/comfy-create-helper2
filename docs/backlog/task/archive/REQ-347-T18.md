## Clipboard Popup Placement (source evidence)

~~~ts
interface PromptSectionClipboardMenuProps {
  role: string; currentValue: string;
  onChangeValue: (newValue: string) => void;
  onOpenSaveAsTagSet?: () => void;
  menuAlign?: 'end' | 'start'; // default='end'
}
~~~
