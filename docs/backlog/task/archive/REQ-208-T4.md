# Task: REQ-208-T4 DesktopLayout & MobileLayout の明示的コールバック統合および結合テスト・リグレッション検証

## 1. 概要
`DesktopLayout.tsx` および `MobileLayout.tsx` 内の `TagChipEditor` 呼び出し箇所に `onTextModeToggle={() => setRoleCollapsed(role, false)}` をバインドし、カスタムイベントへの依存を排除する。全ユニットテスト・結合テストスイートを実行し、リグレッションが発生していないことを確認する。

## 2. 対象ファイル (最大3ファイル)
- `frontend/src/pages/GeneratePage/components/DesktopLayout.tsx` [MODIFY]
- `frontend/src/pages/GeneratePage/components/MobileLayout.tsx` [MODIFY]
- `frontend/src/pages/GeneratePage/hooks/__tests__/useGeneratePageState.test.tsx` [MODIFY]

## 3. 密閉コンテキスト (Hermetic Context)
<hermetic_context>

### 3.1 `DesktopLayout.tsx` における `TagChipEditor` 修正箇所
`DesktopLayout.tsx` 内で `TagChipEditor` をレンダリングしている箇所：
```tsx
<TagChipEditor
  id={`prompt-${mapping.role}`}
  value={paramValues[mapping.role] || ''}
  onChange={(val) => {
    setParamValues({ ...paramValues, [mapping.role!]: val })
  }}
  placeholder={mapping.display_name || mapping.role}
  variant={mapping.role}
  defaultTextMode={false}
  isAnimaMode={isAnimaMode}
  onTextModeToggle={() => setRoleCollapsed(mapping.role!, false)}
/>
```

### 3.2 `MobileLayout.tsx` における `TagChipEditor` 修正箇所
同様に `MobileLayout.tsx` 内の `TagChipEditor` 呼び出し箇所に `onTextModeToggle={() => setRoleCollapsed(mapping.role!, false)}` を渡す。

### 3.3 `useGeneratePageState.test.tsx` の更新
- `useGeneratePageState` をモック・単体テストするテストスイートで、サブフック分割後も既存のすべてのテストケース（ワークフロー切替、プリセットCRUD、オートセーブ、Undo/Redo、スナップショット復元など）が完全にパスすることを確認・同期する。
</hermetic_context>
