## 3. 実装要件 (Implementation Logic)

### 3.1 マッピングマスタの一括編集マージ対応
- `SettingsPage.tsx` の `bulkUpdateMasters` において：
  - `selectedIds` 内の各 `id` について、`sortedMasters` から既存の `mm` オブジェクトを特定する。
  - 送信する `updatedMm` オブジェクトを構築する：
    - `role`, `display_name`, `param_name`, `input_type` などの必須フィールドは既存のものを使用。一括編集値（`values`）に含まれる値があれば上書き。
    - `expected_class_types` や `title_patterns` の配列値も既存データから確実にマッピング（無ければ空配列 `[]`）。
  - `mappingMastersApi.update(id, updatedMm)` を呼び出す。

### 3.2 複数選択時のグリップ表示とドラッグの有効化
- `SettingsComponents.tsx` の `SortableMasterRow` において：
  - `useSortable` のオプションから `disabled: isMultiSelectMode` を廃止、または `disabled: false` に変更し、複数選択中もドラッグ可能にする。
  - レンダリング（`td`）部分を修正：
    - `isMultiSelectMode` が `true` の場合、チェックボックスの隣にドラッグ用ボタン（`GripVertical` を持つボタン）も並べて表示する。
    - ドラッググリップボタンに対してのみ `{...attributes} {...listeners}` をバインドする。
    - 複数選択モードではない（`!isMultiSelectMode`）場合は、従来どおりグリップアイコンのみを表示する。

## 4. 検証手順 (AC)
- 設定ページでマッピングマスタを複数選択した際、各行にチェックボックスと並び替えグリップの両方が表示されることを確認。
- 複数選択中にグリップアイコンをドラッグし、複数行がグループとして正しく順序入れ替えできること。
- 一括編集を行い、Param Name や Input Type などの変更内容が正しく各項目に保存されることを確認。
