### REQ-362-T3: 画像生成完了通知（WebSocket / executed）契機でのフルサイズWebP先行非同期キャッシュ生成

#### 1. 目的とスコープ
- ComfyUI のジョブ完了イベント（WebSocket / `executed`）を受信したハンドラにおいて、サムネイルWebP生成と連動してフルサイズWebP（Quality 90, sRGB）も先行して非同期キャッシュ生成し、`db/full_cache/` に保存する（AC-3）。
- ユーザーが生成直後の画像を選択した時点で既にフルサイズWebPキャッシュが存在する状態を作り出し、プレビュー表示待機時間を完全ゼロ化（0ms）する。
- T1で実装された `_get_full_webp_disk_path`、`_convert_to_full_webp`、および `_prune_full_cache_if_needed` を利用し、一時ファイル書き込みからのアトミック置換（`os.replace`）で並行読み出し時の整合性を担保する。

#### 2. 対象ファイルと変更箇所（Surgical Snippets）
- **対象ファイル**: `backend/app/routers/comfy.py`

```python
async def handle_executed_image(filename: str, subfolder: str, image_type: str) -> None:
    # 既存のサムネイル先行生成
    await _generate_thumbnail_cache(filename, subfolder, image_type)

    # フルサイズ WebP の先行非同期キャッシュ生成 (Eager Cache, Atomic Write)
    try:
        cache_key = f"{image_type}:{subfolder}:{filename}"
        disk_path = _get_full_webp_disk_path(cache_key)
        if not (disk_path.is_file() and disk_path.stat().st_size > 0):
            client = get_comfy_client()
            resp = await client.get(
                f"{settings.comfy_url}/view",
                params={"filename": filename, "subfolder": subfolder, "type": image_type},
                timeout=15.0,
            )
            if resp.status_code == 200:
                webp_bytes = await asyncio.to_thread(_convert_to_full_webp, resp.content, 90)
                tmp_path = disk_path.with_suffix(f".tmp_{os.getpid()}_{hashlib.sha256(webp_bytes[:64]).hexdigest()[:8]}")
                await asyncio.to_thread(tmp_path.write_bytes, webp_bytes)
                await asyncio.to_thread(os.replace, tmp_path, disk_path)
                asyncio.create_task(_prune_full_cache_if_needed(disk_path.parent))
    except Exception as e:
        logger.warning(f"Failed to eagerly cache full webp for {filename}: {e}")
```
