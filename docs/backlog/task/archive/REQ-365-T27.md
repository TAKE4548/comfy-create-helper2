## 変更内容
1. Escape 用 `useEffect`（上記後者）を**削除**（`useEffect`/`useRef` import は focus 用に残る）。focus/select の `useEffect` は維持（子の passive effect は Modal の layout-effect 初期フォーカスの後に走るため最終フォーカスは input）。
2. 外枠を置換:
```tsx
<Modal isOpen onClose={onClose} size="sm" ariaLabel={title} sheetMaxHeightClass="max-h-[85dvh]">
  <div className="shrink-0 flex items-center justify-between gap-3 px-4 md:px-6 pt-2 md:pt-6 pb-3">
    <h3 className="text-base font-semibold text-zinc-100">{title}</h3>
    <button type="button" onClick={onClose} disabled={isPending} aria-label="閉じる" className="inline-flex items-center justify-center min-h-[44px] min-w-[44px] touch-manipulation …"><X size={18} /></button>
  </div>
  <form onSubmit={handleSubmit} className="flex-1 min-h-0 overflow-y-auto overscroll-contain space-y-4 px-4 md:px-6 pb-4 md:pb-6">…既存…</form>
</Modal>
```
   - 閉じ方は旧挙動維持: backdrop クリック=閉じる（既定 true）、Esc=閉じる（Modal既定、pending 中も旧実装どおり）。
   - 追加の `pb` 禁止（Modalがsafe-areaを提供）。`lg:max-h-[85vh]`/`max-h-full`/生 `vh` は撤去。
3. **44px**: 閉じる(X) は上記。input: `min-h-[44px] md:min-h-0`。キャンセル/保存(コピーを作成): `min-h-[44px] md:min-h-0 touch-manipulation`。**ボタン可視名は変更しない**。`text-[10px]` 以下は無し（確認済み）。
4. `import { Modal } from './common/Modal'` を追加。
