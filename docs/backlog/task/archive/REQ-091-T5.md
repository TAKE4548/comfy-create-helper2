## 3. 実装要件 (Implementation Logic)
- **`BypassSettingsModal.tsx`**:
  - 左右2カラム構成のモーダルダイアログ。
  - 左カラム: 
    - ワークフローに紐づく `bypassProfiles` の一覧。
    - 「新規作成」ボタンがあり、名前を入力して新プロファイルを追加可能。
    - 各プロファイル行に、編集（ダブルクリックまたは鉛筆アイコンで名前変更）と削除（✕ボタン）を配置。
    - クリックで選択（アクティブ化）される。
  - 右カラム:
    - 現在アクティブなプロファイルがある場合のみ表示。
    - `currentWorkflow` 内の全ノードの一覧をチェックボックス付きでスクロール表示。
    - チェックボックスをON/OFFすると、アクティブなプロファイルの `bypassed_node_ids` が更新され、DBに保存（PUT）される。
  - 「閉じる」ボタンでモーダルを閉じる。
