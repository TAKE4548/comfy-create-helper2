## 1. 目的・スコープ・AC-1〜AC-14 全体契約とタスク分担 (Goal, Scope & AC Alignment)

`frontend/src/pages/GeneratePage/components/GenerateParallelPreview.tsx` を旧ページ送り式から最新-first固定（`index 0`=最新、右=過去）の**連続横スクロールリール**へ置換する。
- **本タスク (`REQ-383-T2`) 実装対象 (AC-1〜AC-8, AC-10〜AC-12, AC-14)**:
  - **AC-1**: 最新画像が先頭（`index 0`）で右方向へ過去画像が並び、ソート順反転UIを表示しない。
  - **AC-2**: 初期表示で最新画像中心を水平中央に配置し、端点画像も幅を圧縮せず水平中央吸着できる端部余白（`marginLeft`/`marginRight`）を設ける。
  - **AC-3**: ホイール／トラックパッド連続入力時に滑らかに慣性減衰し、停止後に最寄り画像が水平中央へ吸着する。
  - **AC-4**: 縦長・正方形・横長（2:1等）混在時に元アスペクト比を維持し、領域外へのはみ出しや細長い空枠を生じさせない。
  - **AC-5 / AC-6**: 過去側閲覧時に「← 最新へ」を表示し即座に慣性停止・最新画像中央表示する（AC-5）。「最古へ →」押下で即座に慣性停止・最古画像中央表示する（AC-6）。
  - **AC-7 / AC-8 (リール受信側)**: `centerRequest` 受信時に進行中慣性を停止し該当画像を水平中央へ移動する（AC-7）。複数選択時や修飾キー操作中は `centerRequest` が更新されずプレビュー位置は移動・ジャンプしない（AC-8）。
  - **AC-10 / AC-11**: プレビュー上部の「最新追従（`previewAutoFollow`）」および「自セッション（`filterOwnSession`）」トグルを履歴ペイン側と即時双方向同期する。
  - **AC-12**: リール内画像クリック時に既存の詳細プレビューモーダル（`HistoryModalPreview`）を開き、拡大表示および `Escape` キー／閉じるボタンでのCloseを機能させる。
  - **AC-14**: ルートとリールコンテナに `min-w-0 overflow-hidden` を適用し、操作中に `document.body` に横スクロールバー（`overflow-x`）を発生させない。
- **他タスク委譲AC（本タスク対象外）**:
  - **AC-1 (履歴側ソートUI撤去) / AC-7 (通常クリック発火) / AC-8 (複数選択時発火抑止) / AC-13 (履歴複数選択・一括保存・スナップショット機能維持)**: `REQ-383-T3` が担当する。
  - **AC-9 (境界バー「⌄ 履歴を閉じる」押下による履歴ペイン閉鎖とプレビュー通常高復帰) および 全体結線・E2E**: `REQ-383-T4` が担当する。
  - **正本仕様書改定**: `REQ-383-T1` が担当する。

### 2.2 混在アスペクト比・端部スクロール余白・慣性スクロール実装契約
```tsx
// 1. 混在アスペクト比サイズ計算 (AC-4)
const availableHeight = Math.max(80, (containerSize.height || 340) - 24)
const viewportWidth = Math.max(240, containerSize.width || 640)
const maxWidth = Math.max(120, viewportWidth * 0.86)
const ar = clamp(aspectRatios?.[img] ?? loadedAspectRatios[img] ?? (2 / 3), 0.3, 3.0)
const widthFromHeight = availableHeight * ar
const widthConstrained = widthFromHeight > maxWidth
const tileWidth = Math.round(Math.max(80, Math.min(widthFromHeight, maxWidth)))
const tileHeight = Math.round(Math.max(80, widthConstrained ? tileWidth / ar : availableHeight))

// 2. 端部スクロール余白 (AC-2): タイル自体の width は圧縮せず marginLeft / marginRight を付与
const firstMarginLeft = Math.max(0, Math.round(viewportWidth / 2 - firstTileWidth / 2 - 14))
const lastMarginRight = Math.max(0, Math.round(viewportWidth / 2 - lastTileWidth / 2 - 14))

// 3. ホイールインパルス + 慣性減衰 + 停止時中央吸着 (AC-3)
const unit = event.deltaMode === 1 ? 18 : event.deltaMode === 2 ? reel.clientWidth : 1
const horizontalInput = Math.abs(event.deltaX) > Math.abs(event.deltaY)
const dominantDelta = horizontalInput ? event.deltaX : event.deltaY
const impulse = dominantDelta * unit * (horizontalInput ? 0.28 : 0.38)
const maxVelocity = Math.max(28, (reel.clientWidth || 640) * 0.08)
velocityRef.current = clamp(velocityRef.current + impulse, -maxVelocity, maxVelocity)
```

### 2.3 DOM 構造・データ属性・必須機能要件
1. **ルートコンテナ**: `data-testid="generate-parallel-preview"`、`data-generate-reel-proposal="true"`、クラス `relative flex flex-col w-full h-full min-h-0 min-w-0 overflow-hidden select-none`（AC-14）。
2. **上部ヘッダーと右上共有ツールバー (`data-testid="generate-reel-toolbar"`)**:
   - 左側表示 (`data-testid="parallel-preview-page-indicator"`): `連続プレビュー · 左端が最新 / 右へ過去 · {activeIndex + 1} / {images.length} 枚`
   - 右上ツールバー（左から右へ時系列順配置）:
     1. `← 最新へ` (`data-generate-reel-latest="true"`, `aria-label="最新の生成画像へ戻る"`, `hidden={scrollLeft < 72}`): クリックで `stopInertia()` し、先頭タイル（`index 0`, `scrollLeft = 0`）を中央移動し `onSelect(images[0])`（AC-5）。
     2. `最古へ →` (`data-generate-reel-oldest="true"`, `aria-label="最古の生成画像へ移動"`, `disabled={images.length <= 1}`): クリックで `stopInertia()` し、末尾タイル（`index = images.length - 1`）を水平中央へ移動し `onSelect(images[images.length - 1])`（AC-6）。
     3. `最新追従` (`data-generate-reel-auto-follow="true"`, `aria-pressed={Boolean(previewAutoFollow)}`): ラベル `previewAutoFollow ? '● 最新追従' : '○ 最新追従'`、クリックで `onToggleAutoFollow?.()`（AC-10）。
     4. `自セッション` (`data-generate-reel-session-filter="true"`, `aria-pressed={Boolean(filterOwnSession)}`): ラベル `filterOwnSession ? '✓ 自セッション' : '自セッション'`、クリックで `onToggleFilterOwnSession?.(!filterOwnSession)`（AC-11）。
     5. `履歴` (`data-generate-reel-history-toggle="true"`, `aria-expanded={Boolean(isHistoryExpanded)}`): ラベル `isHistoryExpanded ? '履歴を閉じる' : '履歴を展開'`、クリックで `onToggleHistoryExpanded?.()`。
3. **リールビューポート (`reelRef`) とタイル**:
   - リール: `role="listbox"`, `tabIndex={0}`, `aria-label="生成画像の連続プレビュー。左端が最新です"`, `data-testid="generate-reel-viewport"`, `overflow-x-auto overflow-y-hidden`, `overscrollBehaviorX: 'contain'`。
   - タイル: `role="option"`, `aria-selected={isSelected}`, `data-generate-reel-tile="true"`, `data-index={index}`, `data-testid={`parallel-preview-item-${index}`}`, `shrink-0`。内部に既存の `ProgressivePreviewImage`（REQ-362）とダウンロードリンクを維持。
   - タイルクリック時は `stopInertia()` → `onSelect(image)` → `onOpen()` を呼ぶ（AC-12）。
   - キーボード: `Home`（先頭中央）、`End`（最古中央）、`ArrowLeft` / `ArrowRight`（`event.stopPropagation()` + `stopInertia()` + 隣接タイル中央移動）。
   - `centerRequest?.seq` 更新時（かつ `!isMultiSelectMode`）に `stopInertia()` し対象画像を中央移動する。新規画像先頭追加時は `previewAutoFollow` が ON なら先頭中央、OFF なら閲覧中画像のスクロール位置をアンカー補正する。
