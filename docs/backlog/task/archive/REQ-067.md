## 3. 実装要件 (Implementation Logic)

### 3.1 ORM モデルの修正 (`backend/app/models.py`)
- `SnapshotLora` の `__table_args__` を以下のように修正する：
  `__table_args__ = (UniqueConstraint("snapshot_id", "lora_id", "role"),)`
- `SnapshotTagSet` の `__table_args__` を以下のように修正する：
  `__table_args__ = (UniqueConstraint("snapshot_id", "tag_set_id", "role"),)`

### 3.2 マイグレーション処理の実装 (`backend/app/main.py`)
- `run_migrations` 内に、`snapshot_loras` および `snapshot_tag_sets` のユニーク制約を更新する処理を追加する。
- 既存のユニーク制約を `inspector.get_unique_constraints(table_name)` で取得し、`role` カラムが含まれていない古い制約 `(snapshot_id, lora_id)` / `(snapshot_id, tag_set_id)` が存在するかをチェックする。
- 古い制約が存在する場合、SQLiteのテーブル再作成とデータ移行を行う。具体的には以下のSQL文を接続 (`conn`) から実行する：
  ```sql
  -- 1. snapshot_loras の移行
  -- 一時テーブル作成
  CREATE TABLE snapshot_loras_new (
      id INTEGER NOT NULL PRIMARY KEY AUTOINCREMENT,
      snapshot_id INTEGER NOT NULL,
      lora_id INTEGER NOT NULL,
      strength FLOAT NOT NULL,
      role VARCHAR NOT NULL DEFAULT 'positive',
      UNIQUE (snapshot_id, lora_id, role),
      FOREIGN KEY(snapshot_id) REFERENCES snapshots (id) ON DELETE CASCADE,
      FOREIGN KEY(lora_id) REFERENCES loras (id) ON DELETE CASCADE
  );
  -- データ移行
  INSERT INTO snapshot_loras_new (id, snapshot_id, lora_id, strength, role)
  SELECT id, snapshot_id, lora_id, strength, role FROM snapshot_loras;
  -- 古いテーブル削除とリネーム
  DROP TABLE snapshot_loras;
  ALTER TABLE snapshot_loras_new RENAME TO snapshot_loras;

  -- 2. snapshot_tag_sets の移行
  CREATE TABLE snapshot_tag_sets_new (
      id INTEGER NOT NULL PRIMARY KEY AUTOINCREMENT,
      snapshot_id INTEGER NOT NULL,
      tag_set_id INTEGER NOT NULL,
      role VARCHAR NOT NULL DEFAULT 'positive',
      UNIQUE (snapshot_id, tag_set_id, role),
      FOREIGN KEY(snapshot_id) REFERENCES snapshots (id) ON DELETE CASCADE,
      FOREIGN KEY(tag_set_id) REFERENCES tag_sets (id) ON DELETE CASCADE
  );
  INSERT INTO snapshot_tag_sets_new (id, snapshot_id, tag_set_id, role)
  SELECT id, snapshot_id, tag_set_id, role FROM snapshot_tag_sets;
  DROP TABLE snapshot_tag_sets;
  ALTER TABLE snapshot_tag_sets_new RENAME TO snapshot_tag_sets;
  ```
