## 確定シグネチャ（そのまま実装する）
```ts
// frontend/src/components/common/header/headerMenuPlacement.ts
export const HEADER_MENU_GAP_PX = 6
export const HEADER_MENU_EDGE_MARGIN_PX = 8
export const HEADER_MENU_MIN_HEIGHT_PX = 96

export interface RectLike { top: number; bottom: number; left: number; right: number }
export type HeaderMenuAlign = 'start' | 'end'
export interface HeaderMenuPlacementInput {
  anchor: RectLike
  panelWidth: number                               // 計測済み offsetWidth(px)。未計測は0
  viewport: { width: number; height: number }      // visualViewport ?? window.inner*
  align: HeaderMenuAlign
}
export interface HeaderMenuPlacement { top: number; left: number; maxHeight: number; shouldClose: boolean }

export function computeHeaderMenuPlacement(input: HeaderMenuPlacementInput): HeaderMenuPlacement
```

## アルゴリズム（確定。境界は厳密不等号）
```
top         = anchor.bottom + GAP
maxHeight   = max(0, viewport.height - top - EDGE)
offscreen   = anchor.bottom < 0 || anchor.top > viewport.height
              || anchor.right < 0 || anchor.left > viewport.width
shouldClose = offscreen || maxHeight < MIN_HEIGHT
width       = max(0, min(panelWidth, viewport.width - 2*EDGE))
rawLeft     = align === 'end' ? anchor.right - width : anchor.left
left        = clamp(rawLeft, EDGE, max(EDGE, viewport.width - width - EDGE))
```
注意: jsdom の `getBoundingClientRect()` は全て0。ゼロ矩形を「画面外」と判定してはならない（`<`/`>` の厳密不等号を守る）。

## テスト（`headerMenuPlacement.test.ts`）
- ケース名は `[REQ-346/AC-1]`〜 を含める。fast-check の `fc.assert(fc.property(...))` で以下を検証（入力域: viewport.width/height 200–2400、panelWidth 0–600、anchor は viewport 内の矩形＋一部は画面外）:
  - `[REQ-346/AC-1] top is always at least anchor.bottom + 6` 。
  - `[REQ-346/AC-3] top + maxHeight never exceeds viewport.height - 8 (maxHeight >= 0)`。
  - `[REQ-346/AC-5] left stays within [8, viewport.width - width - 8] for any anchor and align when the panel fits`（`panelWidth <= viewport.width - 16`）。panelWidth が大きい場合は `left === 8`。
  - `[REQ-346/AC-6] maxHeight is non-increasing when viewport.height shrinks (same anchor)`。
  - `[REQ-346/AC-6] shouldClose is true iff offscreen or maxHeight < 96`（独立にオラクルを実装して比較）。
- 例示ケース（境界値）: 375×667 でアンカー(top 11,bottom 39,left 300,right 330)・panelWidth 240・align start/end の期待値、高さ 360、ゼロ矩形 `{0,0,0,0}` が `shouldClose === false` かつ `top === 6`。
- Red Team: `align='end'` でアンカーが左端付近（right 20）のときの左クランプ、`viewport.width` がパネル幅より小さい場合に `left === 8`。
