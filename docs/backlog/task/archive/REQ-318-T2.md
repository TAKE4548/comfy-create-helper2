### 2.1 型定義・シグネチャ
`python
def repack_tag(translated_core: str, prefix: str, weight: Optional[float], suffix: str) -> str:
    if not prefix and not suffix:
        return translated_core
    if weight is not None:
        return f'{prefix}{translated_core}:{weight}{suffix}'
    return f'{prefix}{translated_core}{suffix}'
`

### 2.2 既存の再パック呼び出し (L500-L510)

## 3. 実装要件 (Implementation Logic)
1. 文ブロック全体が (( ... :1.2)) などの強度構文で囲まれている場合、外側の強度構文をアンパックして内部の自然文のみを翻訳対象とする。
2. FuguMT からの翻訳結果に対して前後の余分なホワイトスペースをサニタイズ（トリム）し、下流トークナイザーへの影響を抑止する。
3. repack_tag を適用して、日本語訳を元の括弧および強度倍率構文へ正確に再格納する。
4. 再結合された自然文に対して、文全体の単位で get_cache_key を生成して TRANSLATION_CACHE へ登録・参照する。
