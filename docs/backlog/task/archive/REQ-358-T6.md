## Implementation Logic

### Stage Rank Contract

normalize(s)はASCII A-Zだけをa-zへ変換し、ASCII whitespace（U+0009〜U+000DとU+0020）、`_`、ASCII `-`を除去する。
候補の実タイトル全体と現在stageName、allStageNamesの各登録stage名に同じnormalizeを適用する。
正規化後空のstage名は除外する。NBSP/全角空白/Unicode dash/括弧を除去せず、非ASCII文字を小文字化しない。
match(stage,title)はnormalize(title).includes(normalize(stage))の連続部分文字列一致のみ。
文字単位の散在一致、単語単位照合、role/search_keywords/suffix/aliasは使わない。

- 0: 現在stageの正規化名が非空でmatch。別stageにもmatchしていても現在stageを優先する。
- 1: 現在stageにもallStageNames内の非空stageにもmatchしない（不明）。
- 2: 現在stageにはmatchせず、allStageNames内の非空の別stageの1件以上だけにmatchする。

現在stageはallStageNamesに含まれていなくても独立に判定する。空の現在stageは絶対にrank0にしない。
tier0/1にだけこのrankを適用する。tier2/3/4のstageRankは1とし、stage名による区分内sortも行わない。
比較tupleは[tier, tier<=1 ? stageRank : 1, nodeId]。stageが異なるtierの順位を逆転させない。
