# REQ-316-T16: 保存画像のHTTP MIMEを実ファイルから確定

## 範囲と根拠
ユーザー承認済みAC-22〜24の形式表示を、実生成QAで見つかった不具合に合わせて修正する。
Windows環境でWebPを配信するStaticFilesのContent-Typeがapplication/octet-streamとなり、
HEADに基づく形式表示が未取得になる。承認済みの表示範囲を変えない局所修正。

## 所有・依存
rootがbackend/app/main.pyとbackend/tests/test_snapshot_image_mime_req316.pyを所有する。
他担当の編集を戻さない。T14の形式表示を前提とするQA修正。変更100行以下、2ファイル。

## 契約
汎用Content-Typeの場合のみPillowで実画像ヘッダーを読み、既知の画像MIMEを返す。
無効ファイル・取得不能時は汎用MIMEを維持し、推測した形式を表示しない。
GETとHEAD、画像本体、404、Cache-Control、条件付き応答を維持する。
