# REQ-356-T12: [Parallel & Execution Gates] 並列実行安全性検証、Gate 1/2/3 実行時間短縮(旧113秒未満)の計測・検証

## 1. 概要と目的
再構成されたテストスイートに対し、並列実行設定（`pytest -n auto`, Vitest pool forks）での安全性を検証する（AC-14）。
`tmp_path` や `:memory:` DB の完全分離により、共有リソース衝突による失敗が0件であり、並列と逐次で成否が完全一致することを確認する。
さらに、Gate 1/2/3 を順次実行し、Gate 2（統合テスト）の合計所要時間が再構成前の約113秒から大幅短縮されていることを実測・記録する（AC-12）。

## 2. ターゲット識別
- **対象ファイル**: `backend/pytest.ini`, `frontend/vite.config.ts`
- **対象シンボル**: テスト並列実行設定・ゲートコマンド

## 3. 密閉コンテキスト (Hermetic Context)
<hermetic_context>
### 3.1 実行ゲートコマンド
```bash
# Gate 1: 静的検証 + 単体
cd frontend && npm run typecheck && npx vitest run src/utils src/components/**/__tests__ && cd .. && mypy backend && backend\.venv\Scripts\python -m pytest backend/tests/unit

# Gate 2: 統合テストスイート (旧113秒からの短縮ターゲット)
cd frontend && npm test && cd .. && backend\.venv\Scripts\python -m pytest backend/tests/integration

# 並列実行検証
backend\.venv\Scripts\python -m pytest backend/tests -n auto
```
</hermetic_context>

## 4. 実装要件 (Implementation Logic)
- [ ] Backend および Frontend の全テストを並列実行し、リソース衝突エラーが0件であることを確認する（AC-14）。
- [ ] 逐次実行と並列実行の全テスト結果（Passed数）が完全に一致することを検証する（AC-14）。
- [ ] Gate 2 の合計実行時間を計測し、旧113秒より大幅に短縮されていることを記録する（AC-12）。

## 5. 検証手順 & ユニットテスト (Verification Command)
- **検証コマンド**: `backend\.venv\Scripts\python -m pytest backend/tests/integration && cd frontend && npm test`
- **期待値**: 全テスト PASS、エラー 0 件、実行時間 < 113秒。
