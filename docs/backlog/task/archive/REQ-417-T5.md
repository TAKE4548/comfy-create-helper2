# REQ-417-T5: 設定画面UI刷新（Master/RuleSet/NodeSelector 3分割と参照元表示）

## 1. 概要と目的
マスタ編集画面（`MappingMasterEditModal.tsx`）を、3層アーキテクチャ（値のメタデータ定義、入力判定 RuleSet、ノード特定 NodeSelector）に合わせて再構築する。各共有定義の編集時には参照元 role 一覧を表示し、他ステージへの意図しない波及を防ぐための「複製して編集（フォーク）」機能を提供する。また、`UploadWorkflowModal.tsx` および `workflowMappingState.ts` において、旧 `m:<id>` スロットキー処理を廃止し、永続化された `v:<id>` および `input_name` を直接扱うように整理する。

## 4. 実装要件 (Implementation Logic)
- [ ] `MappingMasterEditModal.tsx` の内部を、Master属性（キー・名称・型・グループ）、BindingRuleSet（入力名一覧・優先度）、NodeSelector（パターン一覧・完全/部分一致・優先度）の3セクション／タブに分割する。
- [ ] 共有されている RuleSet / NodeSelector を編集する際、参照元 role 一覧（`referenced_roles`）を表示する。
- [ ] 「複製して編集」ボタンを提供し、押下時に新規 RuleSet または NodeSelector として複製（ディープコピー）して当該 Variant に割り当て、他のステージに影響を与えずに編集できるようにする。
- [ ] 削除時にバックエンドから参照中エラー（400）が返された場合、トーストまたはモーダル内に参照中 role 一覧を表示して安全にガイダンスする。
- [ ] `UploadWorkflowModal.tsx` および `workflowMappingState.ts` から旧 `m:<id>` スロットキー処理を削除し、`v:<id>` 基準で統一する。
- [ ] `frontend/src/components/__tests__/MappingMasterEditModal.test.tsx` に `[REQ-417/AC-5]` テストケースを追加し、参照中表示・複製ボタン・3分割表示を検証する。
