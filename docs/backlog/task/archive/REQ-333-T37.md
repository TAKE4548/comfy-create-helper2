# REQ-333-T37

## Approved regression correction

生成中プレビューが消えるというユーザー報告への修正。状態revisionの更新を画像更新の根拠にしない。既存APIを維持し、JobViewにoptional `preview_url: str | None = None`を追加する。画像未受信ではnull、実際のpreview callback受信時だけ一時的なjob別URL revisionを更新する。進捗・health更新では同じURL。終端jobはnull。DBへpreview bytesやrevisionを書かない。再接続snapshotでも受信済みpreview URLを返す。未知jobと終端jobのcallbackは無視する。URLは既存`/api/generation/preview/{job_id}?revision={preview_revision}`とする。

## Impacted Files

- backend/app/schemas/generation.py
- backend/app/services/generation_service.py
- backend/tests/test_generation_service.py

## Verification Command

```powershell
backend/.venv/Scripts/python.exe -m pytest backend/tests/test_generation_service.py -q
backend/.venv/Scripts/python.exe -m mypy backend
```

TDDで未受信null、受信後URL、node進捗後同URL、次画像でURL変更、終端null、DB更新なしを検証する。他担当変更を巻き戻さず、カード外変更はCoordinatorへ報告する。
