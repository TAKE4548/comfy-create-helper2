## 変更内容
1. import 追加: `import { HeaderDropdown } from './HeaderDropdown'`、`import { HEADER_MENU_GAP_PX } from './headerMenuPlacement'`。`const monitorRef = useRef<HTMLDivElement>(null)` を追加し、ルート `div`（`data-testid="resource-hover-monitor"`）へ `ref={monitorRef}` を付与。
2. **A3**: L42–53 の effect を次へ置換（外側クリックは `HeaderDropdown` が担う。**640px 以上へ拡大するとトリガー（`sm:hidden`）が非表示になるため、孤立防止で閉じる**）:
```tsx
useEffect(() => {
  if (!isMobileExpanded) return
  const closeAtSm = () => { if (window.innerWidth >= 640) setIsMobileExpanded(false) }
  window.addEventListener('resize', closeAtSm)
  return () => window.removeEventListener('resize', closeAtSm)
}, [isMobileExpanded])
```
   `{isMobileExpanded && (<div data-testid="mobile-resource-overlay" className="absolute ...">…</div>)}` を次に置換（子要素は**内容不変**。`absolute right-0 top-full mt-2 z-40` を削除）:
```tsx
<HeaderDropdown
  open={isMobileExpanded}
  onClose={() => setIsMobileExpanded(false)}
  anchorRef={mobileRef}
  align="end"
  data-testid="mobile-resource-overlay"
  className="w-[240px] rounded-xl border border-white/10 bg-surface-2 p-3 shadow-2xl flex flex-col gap-2.5 backdrop-blur-md animate-in fade-in duration-150"
>
  {/* 既存の子要素（閉じるボタン含む） */}
</HeaderDropdown>
```
3. **A4**: `{isHovered && (<div data-testid="resource-hover-card" ...>…</div>)}` を次に置換（子要素 L90–133 は**内容不変**。`absolute right-0 top-full mt-1.5` と `z-50` を削除。他のクラスは維持）。**ホバー継続ブリッジ**（HEO-9(c)）はトリガーラッパー内（ポータルの外）に置く:
```tsx
{isHovered && (
  <div
    data-testid="resource-hover-bridge"
    aria-hidden="true"
    className="hidden sm:block absolute left-0 right-0 top-full"
    style={{ height: HEADER_MENU_GAP_PX + 1 }}
  />
)}
<HeaderDropdown
  open={isHovered}
  onClose={() => setIsHovered(false)}
  anchorRef={monitorRef}
  align="end"
  role="tooltip"
  data-testid="resource-hover-card"
  className="hidden sm:block w-[250px] p-3 rounded-lg border border-zinc-800 bg-surface-1/95 backdrop-blur-md shadow-2xl text-xs text-zinc-300 pointer-events-auto"
>
  {/* 既存の子要素（見出し、VRAM/RAM ゲージ、CPU/GPU） */}
</HeaderDropdown>
```
   - `onMouseEnter`/`onMouseLeave`（ルート）は**そのまま**。カードはポータル（`body` 直下）だが React ツリー上はルートの子孫のため、ブリッジ（DOM 子）→カード（ポータル）への移動ではルートの `onMouseLeave` は発火しない（React 18 の enter/leave は React ツリー基準）。ポインターがブリッジ・カード・トリガーのいずれにも無くなれば即時に閉じる（**遅延は入れない**。既存テスト3箇所の「`mouseLeave` 直後にカードが消える」を無改修で通すため）。
   - ブリッジ高さは `HEADER_MENU_GAP_PX + 1`（サブピクセル誤差で隙間が残らないよう 1px 重ねる）。

### A4（hover 型。既存3ケース「`mouseEnter` で表示、`mouseLeave` で即時に消える」は**無改修で PASS**すること）
- `[REQ-346/AC-1] hover card is a body-level fixed layer below the monitor and does not live inside it`: `mouseEnter(monitor)` → `monitor.contains(card) === false`、`card.parentElement === document.body`、`style.position === 'fixed'`、`top === '45px'`、`data-header-menu-panel` と `role="tooltip"`、`z-[var(--z-header-menu)]` クラス、`w-[250px]`・`hidden`・`sm:block` クラス維持（640px 未満は非表示＝A3 が担う）。ブリッジ `resource-hover-bridge` が `monitor` 内にあり `style.height === '7px'`、`aria-hidden="true"`。非ホバー時はブリッジ・カードとも存在しない。
- `[REQ-346/AC-2] moving the pointer from the monitor or bridge into the card keeps it open (hover continuity)`: `fireEvent.mouseOut(monitor, { relatedTarget: card })` と `fireEvent.mouseOut(bridge, { relatedTarget: card })` の後もカードが残り、`card.textContent` に `CPU:`・`GPU:` が含まれる。（React ツリー基準の enter/leave の確認。この挙動が jsdom で再現できない場合は実装を変えず設計へ escalate する。実ポインターの最終判定は T10。）
- `[REQ-346/AC-4] leaving the monitor/card or pressing outside closes the hover card; there is no click toggle`: `fireEvent.mouseOut(card, { relatedTarget: document.body })` で閉じる。再度 `mouseEnter` → `fireEvent.pointerDown(document.body)` でも閉じる（RT-8 互換: `fireEvent.mouseDown(document.body)` でも閉じる）。開いたまま `fireEvent.click(monitor)` してもカードは閉じない（トグル無し）。
- `[REQ-346/AC-3] hover card height is capped by the viewport (maxHeight) and scrolls inside`: `vh=360` → `maxHeight === '307px'`、`overflow-y-auto`・`overscroll-contain` クラス。
- `[REQ-346/AC-5] hover card stays inside the viewport for 640, 768 and 1280 wide viewports (align end)`: アンカー `{left: vw-200, right: vw, bottom: 39, top: 11}` で `left === vw − 258`（右端クランプ）、`8 <= left`。
- `[REQ-346/AC-6] hover card recomputes maxHeight on resize while hovered and closes when the monitor scrolls offscreen`: `vh` 667→360 の `resize` で `maxHeight` が `614px`→`307px` に更新される（667−45−8、360−45−8）。矩形スタブを `bottom: -10` にして `scroll` を送ると `queryByTestId('resource-hover-card')` が null。
- Red Team `[REQ-346/AC-1] telemetry null still renders the hover card inside the fixed layer`（`systemStats: null`、`-- / -- GB` 表示は既存ケースで担保済みのため位置属性のみ確認）。
