## 2. 密閉コンテキスト (Hermetic Context)
<hermetic_context>
### 2.1 課題と移行仕様
1. **`SpeechBubbleEditorModal.tsx`**:
   - 生 `useEffect` で `albumsApi.list()` と `fontsApi.list()` を呼んでいる。
   - `useAlbums(true)` または `useQuery({ queryKey: ['albums'], queryFn: albumsApi.list, staleTime: STALE_TIMES.ALBUMS })` を使用する。
   - `fonts` を `useQuery({ queryKey: ['fonts'], queryFn: fontsApi.list, staleTime: STALE_TIMES.FONTS })` に置換する。
   - 新規アルバム作成（保存処理内）完了時に `queryClient.invalidateQueries({ queryKey: ['albums'] })` を実行する。
2. **`SpeechBubbleControls.tsx`**:
   - `speechBubblePresetsApi.list()` を生 `useEffect` で呼んでいる。
   - `useQuery({ queryKey: ['speech-bubble-presets'], queryFn: speechBubblePresetsApi.list, staleTime: STALE_TIMES.SPEECH_BUBBLE_PRESETS })` に移行する。
   - プリセットの保存・削除時に `queryClient.invalidateQueries({ queryKey: ['speech-bubble-presets'] })` を実行する。
</hermetic_context>

## 3. 実装手順 (Step-by-Step Instructions)
1. `SpeechBubbleEditorModal.tsx` で `@tanstack/react-query` の `useQuery`, `useQueryClient` をインポートし、`albumsApi.list()` と `fontsApi.list()` の生 `useEffect` を `useQuery` に置き換える。
2. `SpeechBubbleControls.tsx` で `speechBubblePresetsApi.list()` を `useQuery` に置き換え、プリセット変更時の `invalidateQueries` を接続する。
3. `SpeechBubbleControls.test.tsx` および `SpeechBubbleEditorModal.test.tsx` が正常に通るようにテストを更新・検証する。
