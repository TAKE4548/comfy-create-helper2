# REQ-414-T1: SSoT改定およびコアSeedモデルの大整数対応

## 1. 概要と目的
`SPEC_GENERATE.md` のSeed範囲規定を改定し、`seedModel.ts` において大整数（`Number.MAX_SAFE_INTEGER` = 9007199254740991）およびComfyUI WebUI標準乱数上限（`1125899906842624`）を安全にパース可能にする。64bit整数値の入力に対してはmoduloによる安全整数フォールドを実装し、単体テストを整備する。

## 2. ターゲット識別
- **対象ファイル**:
  - `docs/specs/SPEC_GENERATE.md`
  - `frontend/src/utils/seedModel.ts`
  - `frontend/src/utils/__tests__/seedModel.test.ts`
- **対象シンボル**: `MAX_SAFE_SEED`, `COMFY_RANDOM_SEED_MAX`, `parseSeedValue`, `readSeedSettings`
- **行番号目安**: `seedModel.ts:6-36`, `seedModel.test.ts:60-75`

## 3. 密閉コンテキスト (Hermetic Context)
<hermetic_context>
### 3.1 既存の型定義と定数 (`frontend/src/utils/seedModel.ts`)

```ts
export type SeedMode = 'random' | 'fixed'
export interface SeedSettings { mode: SeedMode; seed: number }
export const SEED_MODES_KEY = '__seed_modes_v1'
export const UINT32_MAX = 4294967295
```

### 3.2 既存のパース実装 (`frontend/src/utils/seedModel.ts`)
```ts
export function parseSeedValue(raw: string, label: string): number {
  if (!/^[0-9]+$/.test(raw)) throw new Error(`${label} must be an unsigned integer`)
  const value = Number(raw)
  if (!Number.isSafeInteger(value) || value < 0 || value > UINT32_MAX) {
    throw new Error(`${label} must be between 0 and ${UINT32_MAX}`)
  }
  return value
}
```
</hermetic_context>

## 4. 実装要件 (Implementation Logic)
- [ ] `docs/specs/SPEC_GENERATE.md` §2-5, §8 を改定し、専用Seed欄の許容範囲を `Number.MAX_SAFE_INTEGER`（9,007,199,254,740,991）、ComfyUI WebUI標準乱数上限を `1,125,899,906,842,624` とする仕様へ更新する。
- [ ] `frontend/src/utils/seedModel.ts` に `MAX_SAFE_SEED = Number.MAX_SAFE_INTEGER` (9007199254740991) および `COMFY_RANDOM_SEED_MAX = 1125899906842624` をエクスポート追加する（`UINT32_MAX` は後方互換aliasとして維持）。
- [ ] `parseSeedValue` を改修し、`MAX_SAFE_SEED` 以下の正当な数値をそのまま保持し、`MAX_SAFE_SEED` を超える巨大数値文字列に対しては `BigInt(raw) % BigInt(MAX_SAFE_SEED)` を用いて安全整数へ正規化する。負数、空文字、小数、非数値文字列に対しては厳格にエラーをスローする。
- [ ] `frontend/src/utils/__tests__/seedModel.test.ts` に `[REQ-414/AC-1]`（4294967295超大整数、`MAX_SAFE_SEED`、64bit整数パース）および `[REQ-414/AC-5]`（負数・小数・空文字拒否）のテストケースを追加する。
