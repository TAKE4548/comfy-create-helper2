### REQ-162-T2: フロントエンド comfyApi クライアント新設と Bypass 配線安全性強化

#### 目的
FastAPIバックエンドに新設された `/api/comfy/*` を利用する `comfyApi` を整備し、`/object_info` 取得の短縮タイムアウトを廃止する。さらに、`applyBypass` において `comfyObjectInfo` が空の場合でも後続ノードの必須入力を誤って削除しない安全ガードを実装し、LocalStorage 未初期化時のプリセット初期チェックを修正する。

#### 対象ファイル
1. `frontend/src/api/client.ts`
2. `frontend/src/utils/bypassUtils.ts`
3. `frontend/src/pages/GeneratePage/hooks/useGeneratePageState.ts`

#### 実装詳細 (Frontend Specifications)

1. **`frontend/src/api/client.ts`**:
```typescript
export const comfyApi = {
  getObjectInfo: () => request<Record<string, any>>('/comfy/object_info'),
  queuePrompt: (data: { prompt: Record<string, any>; client_id?: string }) =>

}
```

2. **`frontend/src/utils/bypassUtils.ts`**:
```typescript
export function applyBypass(
  workflow: Record<string, any>,
  bypassedNodeIds: string[],
  comfyObjectInfo: any
): Record<string, any> {
  const wf = JSON.parse(JSON.stringify(workflow));

  for (const B of bypassedNodeIds) {
    const node = wf[B];
    if (!node) continue;

    const classType = node.class_type;
    const nodeInfo = comfyObjectInfo?.[classType];
    
    // nodeInfo がない場合は、必須入力リンクを delete せずスキップする安全ガード
    if (!nodeInfo) {
      console.warn(`[applyBypass] Schema info for node class '${classType}' not found. Skipping input deletion to preserve required connections.`);
      delete wf[B];
      continue;
    }

    const mapping: Record<number, string> = {};
    const outputs: string[] = nodeInfo.output || [];
    const inputs: Record<string, string> = {};

    const inputConfig = nodeInfo.input || {};
    const inputSources = [inputConfig.required, inputConfig.optional];
    for (const source of inputSources) {
      if (source) {
        for (const [key, value] of Object.entries(source)) {
          if (Array.isArray(value) && typeof value[0] === 'string') {
            inputs[key] = value[0];
          }
        }
      }
    }

    const matchedInputs = new Set<string>();
    for (let outIdx = 0; outIdx < outputs.length; outIdx++) {
      const outType = outputs[outIdx];
      let foundSlot: string | null = null;
      for (const [inName, inType] of Object.entries(inputs)) {
        if (inType === outType && !matchedInputs.has(inName)) {
          foundSlot = inName;
          break;
        }
      }
      if (foundSlot !== null) {
        mapping[outIdx] = foundSlot;
        matchedInputs.add(foundSlot);
      }
    }

    for (const key of Object.keys(wf)) {
      if (key === B) continue;
      const otherNode = wf[key];
      if (otherNode && otherNode.inputs) {
        for (const inputSlot of Object.keys(otherNode.inputs)) {
          const val = otherNode.inputs[inputSlot];
          if (Array.isArray(val) && val.length === 2 && val[0] === B) {
            const outputIndex = val[1];
            const mappedInputSlotName = mapping[outputIndex];
            
            if (mappedInputSlotName !== undefined && node.inputs) {
              const sourceConnection = node.inputs[mappedInputSlotName];
              if (Array.isArray(sourceConnection) && sourceConnection.length === 2) {
                otherNode.inputs[inputSlot] = sourceConnection;
              } else {
                delete otherNode.inputs[inputSlot];
              }
            } else {
              delete otherNode.inputs[inputSlot];
            }
          }
        }
      }
    }

    delete wf[B];
  }

  return wf;
}
```

3. **`frontend/src/pages/GeneratePage/hooks/useGeneratePageState.ts`**:
- `comfyObjectInfo` クエリを `comfyApi.getObjectInfo()` に切り替え。
- `checkedPresetsRaw === null` の場合に全プリセット（または先頭プリセット）をデフォルトで `checked: true` に設定。
