## 変更内容
1. `if (!isOpen) return null` は維持し、外枠を置換（`isOpen` は早期returnで保証済みのため常時 true で渡す）:
```tsx
<Modal isOpen onClose={onClose} size="lg" ariaLabel="ワークフローからノードを選択して逆引き登録"
  closeOnBackdropClick={false} sheetMaxHeightClass="max-h-[85dvh]">
  {/* Header: shrink-0 … h3 id="workflow-node-picker-title" 維持。X: aria-label="閉じる" を 44px に */}
  {/* Search: shrink-0 */}
  <div className="flex-1 min-h-0 overflow-y-auto overscroll-contain md:overflow-hidden grid grid-cols-1 md:grid-cols-2 … text-zinc-100">…</div>
  {/* Footer: shrink-0 */}
</Modal>
```
   - `closeOnBackdropClick={false}`: 旧実装はバックドロップ無反応のため維持。Esc は新規に有効（外側Modalは picker 表示中 Esc を無視する設計済み）。`aria-label` は見出しと同一文言。
   - 旧 `bg-zinc-900 border … max-h-[85vh] overflow-hidden` の独自パネル、`fixed inset-0 z-50`、`role="dialog"` 付き外側divを撤去。生 `vh` を残さない。追加の `pb` 禁止。
2. **モバイルのスクロール設計**: 旧 `overflow-hidden` + 各リスト `max-h-[350px]` は縦積み(grid-cols-1)で合計700pxとなりシート(85dvh)内でクリップされる。グリッド容器を `flex-1 min-h-0 overflow-y-auto overscroll-contain md:overflow-hidden`、各リストを `max-h-[40dvh] md:max-h-[350px] overflow-y-auto overscroll-contain` にする（Container/Control 分離）。
3. **44px**: 閉じる(X) `inline-flex items-center justify-center min-h-[44px] min-w-[44px] touch-manipulation`。ノード行 `min-h-[44px]`（`flex items-center` 可）、引数行 `min-h-[44px]`、検索 input 行 `min-h-[44px] md:min-h-0`、フッターボタン `min-h-[44px] md:min-h-0 touch-manipulation`。**可視テキスト・ボタン名は変更しない**（既存テストが `#1 KSampler Main`・`steps`・`設定フォームへ反映` を `getByText` で引く）。
4. 11pxフロア: `text-[10px]`（約183・200・202行の3箇所）→ `text-[11px]`。
5. `import { Modal } from './common/Modal'` を追加。
