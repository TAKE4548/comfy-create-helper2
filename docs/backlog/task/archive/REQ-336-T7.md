# REQ-336-T7: 外部PNG履歴チェーンフォールバックと結合E2E/RedTeam検証

## 1. 概要と目的
DB外に存在する外部PNG画像メタデータ（過去のRoleキー）が読み込まれた際、StageMaster の `previous_suffixes` 履歴チェーン（最大10件）から最新Roleキーへ自動解決し、履歴外の未知キーも `base_key` によりグレイスフル解決するロジックを実装する。さらに、AC-1〜AC-9 の全受入基準および Red Teaming 失敗シナリオ（マイグレーション強制ロールバック、並行競合、履歴溢れガード、不正JSON耐性）を検証する結合テストを作成・完遂する。

### 3.1 外部Roleキーのフォールバック解決シグネチャ
```typescript
// frontend/src/utils/workflowParamInjector.ts
export function resolveRoleWithHistoryFallback(
  roleKey: string | null | undefined,
  stages: StageMaster[],
  knownRoles: string[]
): string {
  // 0. 空値・不正入力ガード
  if (!roleKey) return ''
  // 1. 直接合致
  if (knownRoles.includes(roleKey)) return roleKey
  // 2. previous_suffixes 履歴チェーン解決 (直近最大10件に制限)
  for (const st of stages) {
    if (!st.previous_suffixes || !Array.isArray(st.previous_suffixes)) continue
    const historyChain = st.previous_suffixes.slice(0, 10)
    for (const prev of historyChain) {
      if (prev && roleKey.endsWith(prev)) {
        const base = roleKey.slice(0, -prev.length)
        const updated = `${base}${st.suffix}`
        if (knownRoles.includes(updated)) return updated
      }
    }
  }
  // 3. base_key グレイスフル解決 (アンダースコア分割による親プレフィックス合致)
  const baseKey = roleKey.split('_')[0]
  const matched = knownRoles.find((r) => r.startsWith(baseKey))
  return matched || roleKey
}
```
