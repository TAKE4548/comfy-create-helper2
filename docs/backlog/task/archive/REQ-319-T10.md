# REQ-319-T10: Step 4 4軸ストレステスト実行・4×3判定マトリクス・推奨強度ハイライト表示

## 1. 概要と目的
学習完了成果物（.safetensors）を確認後、トリガー名に基づき「衣装分離」「衣装再現」「ポーズ追従」「アングル追従」の4項目×3強度（0.6, 0.8, 1.0）の計12件の検証用プロンプトを ComfyUI へ一括投入し、結果を4列×3行の比較グリッドで表示する。各セルの拡大モーダル表示、および推奨運用強度（スイートスポット: 0.75〜0.85）の自動ハイライトカードを提供する。

## 2. 密閉コンテキスト (Hermetic Context)

### 2.1 4×3 ベンチマークグリッド構造
```typescript
export interface BenchmarkCell {
  axisId: 'decoupling' | 'bake_in' | 'pose' | 'angle'
  weight: 0.6 | 0.8 | 1.0
  imageUrl?: string
  status: 'PENDING' | 'PASS' | 'WARN' | 'FAIL'
  prompt: string
}
```

### 2.2 スイートスポット推奨仕様 (`SweetSpotCard.tsx`)
```typescript
interface SweetSpotCardProps {
  recommendedWeightDisplay: string // e.g. "0.75 〜 0.85"
  reason: string
}
```

### 2.3 拡大モーダル仕様 (`BenchmarkCellModal.tsx`)
```typescript
interface BenchmarkCellModalProps {
  cell: BenchmarkCell | null
  onClose: () => void
}
```

## 3. 実装要件 (Implementation Logic)
1. **`frontend/src/pages/DatasetStudioPage/components/BenchmarkGrid.tsx`**:
   - 「4軸ストレステスト一括実行」ボタン。
   - `benchmarkApi.generatePrompts` で12件取得後、ComfyUI（Port 8188）へ直接キュー投入。
   - 4列（衣装分離、衣装再現、ポーズ追従、アングル追従）× 3行（強度 0.6, 0.8, 1.0）のグリッドテーブル描画。
   - 各セルクリック時に `BenchmarkCellModal` を開いて拡大表示。
2. **`frontend/src/pages/DatasetStudioPage/components/SweetSpotCard.tsx`**:
   - 12件完了時、`benchmarkApi.evaluate` の結果を受信して推奨強度（0.75〜0.85）をグリーンアクセントで目立たせて表示。
3. **`frontend/src/pages/DatasetStudioPage/components/BenchmarkCellModal.tsx`**:
   - 高解像度での画像確認、生成時プロンプト、重み、シードの確認モーダル。

## 4. 完了条件と検証
- [ ] 12件のテスト画像が4×3グリッドに整然と配置されること。
- [ ] 各セルをクリックして拡大モーダルで確認できること。
- [ ] 推奨運用強度（スイートスポット）がハイライト表示されること。
