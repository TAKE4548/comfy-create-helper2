# Task Card: REQ-277-T2

## 1. 目的
`useGenerateAction.ts` の `handleGenerateSets` および `handleGenerate` において、ボタン押下瞬間の最新 Zustand ストア状態（`useGenerationStore.getState()`）を直接取得し、各セットの `paramValues` マージおよび `injectWorkflowParams` への注入を 100% 確実に遂行する。
また、単一セット時やチェック済みセットが1つだけの場合（`checkedSets.length === 1`）、および `activeSetId` の型不一致（string vs number）時のフォールバック保護を強化し、画面で入力されたパラメータがワークフロー JSON に正確に反映されるようにする。

## 2. 対象ファイル
- `frontend/src/pages/GeneratePage/hooks/useGenerateAction.ts`
- `frontend/src/store/slices/multiSetSlice.ts`

## 3. 実装仕様

### 3.1 実行時最新ストアの取得
`handleGenerateSets` の先頭で Zustand 最新状態を取得：
```typescript
const state = getLatestState()
const currentParamValues = state.paramValues
const currentPromptChips = state.promptChips
const currentSets = state.sets
const currentActiveSetId = state.activeSetId
const currentParamSyncGroups = state.paramSyncGroups || []
const currentBypassProfiles = state.bypassProfiles || []
```

### 3.2 アクティブ判定・単一チェック保護とワークフロー注入
```typescript
for (const setItem of checkedSets) {
  const isExplicitActive =
    currentActiveSetId !== null &&
    currentActiveSetId !== undefined &&
    String(setItem.id) === String(currentActiveSetId)

  // 単一チェック時、またはアクティブIDがセット一覧に見当たらない場合の安全フォールバック
  const isActive =
    isExplicitActive ||
    (checkedSets.length === 1 &&
      (!currentActiveSetId ||
        !currentSets.some((s) => String(s.id) === String(currentActiveSetId)) ||
        !checkedSets.some((s) => String(s.id) === String(currentActiveSetId))))

  const itemParams = isActive
    ? { ...setItem.paramValues, ...currentParamValues }
    : setItem.paramValues

  const itemChips = isActive
    ? ((currentPromptChips && Object.keys(currentPromptChips).length > 0)
        ? currentPromptChips
        : (setItem.promptChips || {}))
    : (setItem.promptChips || {})

  const effectiveParamValues = getEffectiveParamValues(itemParams, itemChips)
  const syncedParamValues = applyParamSync(effectiveParamValues, currentParamSyncGroups)

  for (let i = 0; i < setItem.batchSize; i++) {
    let wfJson = injectWorkflowParams({
      workflow,
      paramValues: syncedParamValues,
      seedOptions: {
        seedMode: setItem.seedMode,
        seed: setItem.seed,
        index: i,
      },
      cloneJson: true,
    })
    ...
```

## 4. 完了条件
1. `handleGenerateSets` がボタン押下瞬間の最新 `paramValues` を取得し、`wfJson` に注入すること。
2. 単一チェック時（`checkedSets.length === 1`）や型不一致（文字列/数値）時でも、画面の最新パラメータが除外されずに `wfJson` に渡されること。
3. 非アクティブセットのパラメータがアクティブセットの値で意図せず上書きされないこと。
