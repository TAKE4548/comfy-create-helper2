# REQ-338-T6: タグチップ自然近接吸着・Hit-Slop適正化とタッチ操作フィードバックの実装

## 1. 概要と目的
極小タグチップ（外形 24px）の高密度な並び（`gap-1.5`）を完全に維持したまま、上下左右の判定重複を招く広域矩形拡張を排除し、タッチポイントに最も近いチップを自然に吸着・選択するイベント処理（Proximity Hit Snap）および重複のないコンパクトな Hit-Slop を導入する。あわせて `touch-action: manipulation` による 300ms 遅延排除と `active:scale-[0.97]` のタッチフィードバックを適用し、密集度とタップ精度の両立を実現する。

## 2. ターゲット識別
- **対象ファイル**:
  - `frontend/src/components/TagChipViewer.tsx`
  - `frontend/src/components/TagChipEditor/TagChip.tsx`
- **テストファイル**: `frontend/src/components/TagChipEditor/__tests__/TagChip.test.tsx`
- **対象シンボル**: `TagChipViewer`, `TagChip`
