### 2.2 レンダリングロジック仕様
1. **文字単位の変形・配置計算 (`drawBubbleText`)**:
   - 各文字のインデックス `i`（0 から `totalChars - 1`）を取得。
   - **スケールカーブ**:
     - `scaleStart` (default 1.0) と `scaleEnd` (default 1.0) の間を `t = totalChars > 1 ? i / (totalChars - 1) : 0` で補間。
     - `'linear'`: `start + (end - start) * t`
     - `'ease-in'`: `start + (end - start) * (t * t)`
     - `'ease-out'`: `start + (end - start) * (1 - (1 - t) * (1 - t))`
     - `'bezier'`: `start + (end - start) * (t * t * (3 - 2 * t))`
   - **サイズ揺らぎ (Jitter)**:
     - 文字ごとの決定論的ハッシュ (例: `Math.sin(i * 997 + text.length)`) で `-sizeJitter% ~ +sizeJitter%` の倍率補正。
   - **縦中横（90度回転）**:
     - `bubble.orientation === 'vertical'` かつ `rotate90Indices` に文字インデックスが含まれる場合（または `!?` などの指定記号）:
     - 文字の中心を原点として `ctx.rotate(Math.PI / 2)` を適用して描画。
   - **傾斜（シアー）**:
     - `shearAngle` (度数法) が指定されている場合、`ctx.transform(1, 0, Math.tan(shearAngle * Math.PI / 180), 1, 0, 0)` を適用。
   - **パス配置（固定ハンドル補間方式）**:
     - `pathPreset === 'line'`: 2点 $P_0, P_1$ 間の線形補間 $(1-t)P_0 + t P_1$。
     - `pathPreset === 'arc'`: 3点 $P_0, P_1, P_2$ による二次ベジェ曲線 $(1-t)^2 P_0 + 2(1-t)t P_1 + t^2 P_2$。
     - `pathPreset === 'wave'`: 4点 $P_0, P_1, P_2, P_3$ による三次ベジェ曲線 $(1-t)^3 P_0 + 3(1-t)^2 t P_1 + 3(1-t)t^2 P_2 + t^3 P_3$。
     - `pathPreset === 'stepped'`: 2点間を指定段数 `pathSteppedCount`（default: 3）でステップ分割。
     - `pathFollowRotation === true` の場合、パス接線ベクトル $(\frac{dx}{dt}, \frac{dy}{dt})$ から回転角度 $\theta = \operatorname{atan2}(dy, dx)$ を算出し文字を回転。
2. **多層フチ（MultiStroke）描画**:
   - `multiStrokes` 配列が存在する場合、外側の太いストロークレイヤーから内側の順に描画。
   - 各レイヤーの `width`, `color`, `opacity`, `offsetX`, `offsetY`, `lineJoin`, `lineStyle` (dashedの場合は `ctx.setLineDash([4, 4])`) を設定して `ctx.strokeText`。
3. **文字塗りつぶし（Fill）描画**:
   - `fillMode === 'solid'`: `ctx.fillStyle = bubble.textColor`
   - `fillMode === 'gradient'`:
     - 線形グラデーション: `ctx.createLinearGradient(x0, y0, x1, y1)`
     - 放射グラデーション: `ctx.createRadialGradient(cx, cy, 0, cx, cy, r)`
     - 各カラーストップ `gradientStops` を追加して `ctx.fillStyle` に指定。
   - `fillMode === 'tone'`:
     - 4x4 または 8x8 のオフスクリーン Canvas で網点（ドット）パターンを作成し、`ctx.createPattern(patternCanvas, 'repeat')` を `ctx.fillStyle` に適用。
4. **演出連動の自動サイズ・フォント計算 (`calculateFitBubbleDimensions`, `calculateFitFontSize`)**:
   - `calculateFitBubbleDimensions(text: string, fontSize: number, orientation: TextOrientation, effects?: MangaTextEffectConfig, ctx?: CanvasRenderingContext2D): { w: number; h: number }`
     - 最大スケール倍率 `maxScale`（`scaleStart`, `scaleEnd`, `sizeJitter` から算出）をフォントサイズに乗算。
     - `letterSpacing` を文字間に追加、`lineHeightRatio` を行・列間隔に反映。
     - `shearAngle` による傾斜はみ出し幅（`textH * tan(abs(shearAngle))`）を加算。
     - `multiStrokes` の最大ストローク幅＋オフセットをバウンディングサイズに加算。
     - パス（波型振幅・円弧高さ・ステップ段差）および `baselineJitter` を余白に加算。
   - `calculateFitFontSize(text: string, width: number, height: number, orientation: TextOrientation, effects?: MangaTextEffectConfig, ctx?: CanvasRenderingContext2D): number`
     - 二分探索内で `effects` を加味した文字専有領域が吹き出し有効領域（幅・高さ）に収まる最大フォントサイズを探索。
