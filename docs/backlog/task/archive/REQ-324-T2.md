# REQ-324-T2: API Core Domains Modularization (workflows.ts, snapshots.ts, loraStudio.ts)

## 1. 概要と目的
`frontend/src/api/client.ts` 内の主要リソース管理 API をドメイン単位で分割する。
- ワークフローおよびノードパラメータ系: `domains/workflows.ts`
- スナップショット・アルバム・メタデータ・タグ系: `domains/snapshots.ts`
- LoRA・モデル・Dataset Studio・学習・ベンチマーク系: `domains/loraStudio.ts`
各モジュールは `../core/base` の `request` をインポートして自己完結し、循環依存を生じさせない。

## 2. ターゲット識別
- **対象ファイル**:
  - `frontend/src/api/domains/workflows.ts` (新規作成)
  - `frontend/src/api/domains/snapshots.ts` (新規作成)
  - `frontend/src/api/domains/loraStudio.ts` (新規作成)
- **対象シンボル**:
  - `workflowsApi`, `workflowPresetsApi`, `bypassProfilesApi`, `paramSyncGroupsApi`, `mappingMastersApi`, `paramTypeMastersApi`
  - `snapshotsApi`, `albumsApi`, `promptMetadataApi`, `tagSetsApi`, `tagsetCategoriesApi`
  - `lorasApi`, `loraCategoriesApi`, `baseModelsApi`, `checkpointMappingsApi`, `datasetApi`, `trainingApi`, `benchmarkApi`

// workflows.ts 対象:
export const workflowsApi = {
  list: () => request<WorkflowSummary[]>('/workflows'),
  get: (id: number) => request<Workflow>(`/workflows/${id}`),
  create: (name: string, jsonBody: Record<string, unknown>) =>
    request<Workflow>('/workflows', { method: 'POST', body: JSON.stringify({ name, json_body: jsonBody }) }),
  update: (id: number, data: { name?: string; json_body?: Record<string, unknown> }) =>
    request<Workflow>(`/workflows/${id}`, { method: 'PUT', body: JSON.stringify(data) }),
  delete: (id: number) => request<void>(`/workflows/${id}`, { method: 'DELETE' }),
  syncMappings: (id: number) => request<Workflow>(`/workflows/${id}/sync-mappings`, { method: 'POST' }),
}

// snapshots.ts 対象:
export const snapshotsApi = {
  list: (params?: { workflow_id?: number; search?: string; sort?: string; page?: number; per_page?: number }) => {
    const searchParams = new URLSearchParams()
    if (params?.workflow_id) searchParams.set('workflow_id', String(params.workflow_id))
    if (params?.search) searchParams.set('search', params.search)
    if (params?.sort) searchParams.set('sort', params.sort)
    if (params?.page) searchParams.set('page', String(params.page))
    if (params?.per_page) searchParams.set('per_page', String(params.per_page))
    const query = searchParams.toString()
    return request<SnapshotSummary[]>(`/snapshots${query ? `?${query}` : ''}`)
  },
  get: (id: number) => request<Snapshot>(`/snapshots/${id}`),
  patch: (id: number, data: {
    tag_sets?: SnapshotTagSetCreate[]
    lora_trigger_sets?: SnapshotTriggerAssociation[]
  }) => request<Snapshot>(`/snapshots/${id}`, { method: 'PATCH', body: JSON.stringify(data) }),
  // ... delete, detectBubble, createSpeechBubble 等
}
