## 3. 実装要件 (Implementation Logic)
- [ ] `frontend/src/pages/GeneratePage/hooks/useGenerateAction.ts`:
  - `waitForVramRecovery(signal: AbortSignal): Promise<boolean>` を定義。
  - 初回判定で `systemStats.vram_safe === false` の場合:
    - `setVramWaitStatus({ isWaiting: true, freeGb: systemStats.vram_free_gb ?? null, requiredGb: systemStats.vram_min_free_gb ?? 6.0, waitDurationSec: 0 })` を設定。
    - 経過時間タイマー（1秒インターバル）を起動し `waitDurationSec` をインクリメント。
    - `waitDurationSec === 10` 到達時に `setErrorToast({ message: 'VRAM解放待ちが継続しています。他プロセスの終了待機中（キャンセル可能）', type: 'warning' })` を発行 (AC-3)。
    - `useGenerationStore.subscribe` により `systemStats` の更新を監視。WebSocketから `vram_safe === true` がプッシュされた瞬間にPromiseをresolve(true) (AC-5)。
    - **キャンセル冪等性保証**: `signal.aborted` が発火した場合は即座にPromiseをresolve(false)し、タイマーと購読をクリーンアップ。直後に回復イベントが来ても自動再開を確実に遮断 (AC-4)。
  - `handleGenerate` および `handleGenerateSets` の `queuePrompt` 直前で上記を呼出し、`false` の場合は安全に中断。
- [ ] `frontend/src/pages/GeneratePage/components/DesktopLayout.tsx`:
  - `renderStatusBar()` の先頭に `if (isVramWaiting && vramWaitStatus)` 分岐を追加。
  - ステータスバー表示:
    - 黄色パルスインジケーター + `「VRAM解放待ち（他プロセスの終了待機中）」`
    - 詳細情報: `空き: ${vramWaitStatus.freeGb ?? '--'} GB / 必要: ${vramWaitStatus.requiredGb} GB (待機: ${vramWaitStatus.waitDurationSec}秒)` (WebSocketによりリアルタイム追従)
    - `[待機キャンセル]` ボタン（押下時に `cancelAllJobs()` / `cancelVramWait()` を呼出）。
- [ ] `frontend/src/pages/GeneratePage/components/MobileLayout.tsx`:
  - プレビュー領域またはアクションバー直上に `isVramWaiting` 時の専用ステータスバナー（黄色背景/警告アイコン/キャンセルボタン）を表示。
