# TASK-REQ-043-01: バックエンド スキーマ定義および PATCH API の追加

## 1. ターゲット識別
- **対象ファイル**: 
  - `backend/app/schemas/snapshot.py`
  - `backend/app/schemas/__init__.py`
  - `backend/app/routers/snapshots.py`

## 2. 密閉コンテキスト (Hermetic Context)
<hermetic_context>
`SnapshotLora` および `SnapshotTagSet` のモデル定義は `backend/app/models.py` で以下のように定義されています。
```python
class SnapshotLora(Base):
    __tablename__ = "snapshot_loras"
    __table_args__ = (UniqueConstraint("snapshot_id", "lora_id", "role"),)
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    snapshot_id: Mapped[int] = mapped_column(ForeignKey("snapshots.id", ondelete="CASCADE"), nullable=False)
    lora_id: Mapped[int] = mapped_column(ForeignKey("loras.id", ondelete="CASCADE"), nullable=False)
    strength: Mapped[float] = mapped_column(Float, nullable=False)
    role: Mapped[str] = mapped_column(String, nullable=False, default="positive")
```
</hermetic_context>

## 3. 実装要件
1. **Pydantic スキーマ追加**:
   - `schemas/snapshot.py` に `SnapshotUpdate` を追加：
     ```python
     class SnapshotUpdate(BaseModel):
         lora_ids: list[int] = []
         tag_set_ids: list[int] = []
     ```
   - `schemas/__init__.py` で `SnapshotUpdate` を re-export。
2. **PATCH API の追加**:
   - `routers/snapshots.py` に `PATCH /api/snapshots/{snapshot_id}` を追加。
   - `snapshot_id` に紐付く既存の `SnapshotLora` レコードと `SnapshotTagSet` レコードを削除し、指定された `lora_ids` (強度 1.0, role='positive') および `tag_set_ids` (role='positive') に基づいてリレーションレコードを作成・保存する。
3. **GET API のフィルタ拡張**:
   - `GET /api/snapshots` のパラメータに `lora_id: Optional[int] = None` と `tag_set_id: Optional[int] = None` を追加。
   - `lora_id` や `tag_set_id` が指定されている場合、SQLAlchemy クエリで `join` して絞り込み。
