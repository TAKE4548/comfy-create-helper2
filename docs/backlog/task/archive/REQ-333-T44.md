# REQ-333-T44

GenerationMetadataPanelの生成完了時刻は常に未記録になっている。header optional completedAtを受け、実日時ありなら表示、欠落なら未記録。SnapshotMetadataTabはgetMetadataViewのcompletedAtをheaderへ渡す。active Snapshotも記録自身の日時を表示し、created_atを代用しない。既存queuedAt、metadataSavedAt、imageSavedAt、画像/seed/asset表示を保持。

## Impacted Files
- frontend/src/components/GenerationMetadataPanel.tsx
- frontend/src/components/history/SnapshotMetadataTab.tsx
- frontend/src/components/__tests__/GenerationMetadataPanel.test.tsx

```powershell
Set-Location frontend
npx vitest run src/components/__tests__/GenerationMetadataPanel.test.tsx
```

TDDで実completedAt表示、旧recordの未記録、他日時を完了日時として出さない。所有外編集禁止、他担当変更を巻き戻さない。
