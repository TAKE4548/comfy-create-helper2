## 変更内容
1. 外側の `fixed inset-0 ...` div と内側パネル div（`max-w-3xl bg-zinc-900 ... max-h-[90vh] overflow-hidden`）を撤去し、次に置換（children は Header / form の2要素のみ。パネル用の背景・border・角丸・`max-h-[90vh]` は持ち込まない）:
```tsx
const dialogTitle = master ? `マッピングマスター編集: ${master.name || master.display_name}` : '新規マッピングマスター作成'
return (
  <Modal
    isOpen={isOpen}
    onClose={onClose}
    size="lg"
    ariaLabel={dialogTitle}
    sheetMaxHeightClass="max-h-[85dvh]"
    closeOnEsc={!isNodePickerOpen}
  >
    {/* Header: 既存。h2 id="mapping-master-edit-title" は維持。className に shrink-0 を追加 */}
    <form onSubmit={handleSubmit} className="flex-1 min-h-0 overflow-y-auto overscroll-contain p-4 md:p-6 space-y-6 text-zinc-100">
      ...既存のまま（WorkflowNodePicker も form 内に維持）
    </form>
  </Modal>
)
```
   - `ariaLabel` は現行の見出し文言と**同一**（既存テスト `findByRole('dialog', { name: /新規マッピングマスター作成/ })` を維持）。
   - `closeOnEsc={!isNodePickerOpen}`: 旧実装にEscape閉じは無かったため、ノードピッカー（Escape非対応のネストdialog）表示中に誤ってフォーム全体を閉じない保険。
   - 二重 `pb` 禁止（Modalが safe-area を提供）。Header は `text-zinc-100` を継承しないため、必要なら Header にも `text-zinc-100`。
2. **44pxタッチターゲット**（モバイル。デスクトップの見た目は変えない）:
   - 閉じるボタン(`aria-label="閉じる"`): `inline-flex items-center justify-center min-h-[44px] min-w-[44px] touch-manipulation`（`p-1` は置換）。
   - フッタ「キャンセル」「マスターを保存」: `min-h-[44px] touch-manipulation`（`md:min-h-0` 可）。
   - クラス型チップの削除ボタン(`aria-label="{type} を削除"`)と候補パレットボタン(`+ {candidate}`): 見た目を変えず Hit-Slop `relative before:absolute before:-inset-2 touch-manipulation`。他のバリアント有効トグル等のボタン/チェックも同様に確認。
   - `input`/`select`: `min-h-[44px] md:min-h-0`。
   - 範囲外: `PatternTagInput` / `FallbackParamsInput` / `WorkflowMappingPreview` / `WorkflowNodePicker` の内部ボタン（別ファイル、本カードは変更しない。検証者へ「未対応の外部コンポーネント」として報告）。
3. 11pxフロア: 本ファイル内の `text-[10px]`（例: `(全バリアントへ継承)`）は `text-[11px]` へ是正。生 `vh` 禁止（`max-h-[90vh]` は撤去される）。
