## 背景
現行は右クラスタ内の `absolute right-0 top-full mt-1.5` でヘッダー高さには切り詰められない（参照方向）。ただし (1) 最大高さ・メニュー内スクロールがない、(2) ラッパー `style={{ zIndex: 10 }}` が作る stacking context により、後続DOMの Desktop プリセットタブバー（`relative z-10`）／Mobile の `sticky z-40` 進捗ラインより前面になれない疑いがある（実ブラウザ未確認。E2E T7 で実測）。`HeaderDropdown` に統一して契約を単一化する。

## 現行コード（`HeaderKebabMenu.tsx`）
```tsx
import { useState, useRef, useEffect } from 'react'                   // L1
  const [isOpen, setIsOpen] = useState(false)                        // L11
  const menuRef = useRef<HTMLDivElement>(null)                       // L12
  const storage = useBrowserStorageUsage()                           // L13

  useEffect(() => {                                                  // L15-26 ← 削除（HeaderDropdownが担う）
    if (!isOpen) return
    const handleOutside = (e: MouseEvent | TouchEvent) => { if (menuRef.current && !menuRef.current.contains(e.target as Node)) { setIsOpen(false) } }
    document.addEventListener('pointerdown', handleOutside)
    return () => { document.removeEventListener('pointerdown', handleOutside) }
  }, [isOpen])

  return (
    <div className="relative inline-flex items-center" ref={menuRef} style={{ zIndex: 10 }}>   // L38  ← style を削除
      <button ... id="header-kebab-btn" data-testid="header-kebab-menu-button" onClick={() => setIsOpen((prev) => !prev)} ...>  // L39-54 維持
      </button>

      {isOpen && (                                                                              // L56
        <div
          data-testid="header-kebab-dropdown"
          className="absolute right-0 top-full mt-1.5 w-[270px] p-3 rounded-lg border border-zinc-800 bg-surface-1/95 backdrop-blur-md shadow-2xl z-20 text-xs text-zinc-300"
        >
          ... （L61-101: ストレージ使用量セクション＋アクション(キャッシュ再同期ボタン／設定リンク)）
        </div>
      )}                                                                                        // L102-103
    </div>
  )
```

## 変更内容
1. `import { useState, useRef } from 'react'`（`useEffect` 削除）。`HeaderDropdown` を `./HeaderDropdown` から import。
2. L15–26 の `useEffect` を削除。ラッパーの `style={{ zIndex: 10 }}` を削除（`className`・`ref` は維持）。
3. `{isOpen && (<div data-testid="header-kebab-dropdown" className="absolute ...">…</div>)}` を次に置換（子要素は内容不変）:
```tsx
<HeaderDropdown
  open={isOpen}
  onClose={() => setIsOpen(false)}
  anchorRef={menuRef}
  align="end"
  data-testid="header-kebab-dropdown"
  className="w-[270px] p-3 rounded-lg border border-zinc-800 bg-surface-1/95 backdrop-blur-md shadow-2xl text-xs text-zinc-300"
>
  {/* 既存の子要素 */}
</HeaderDropdown>
```
   （`absolute right-0 top-full mt-1.5 z-20` は削除）
4. `handleResync` の `setIsOpen(false)`、設定リンクの `onClick={() => setIsOpen(false)}`、トリガーのトグルは維持（AC-4）。

<constraints>

- トリガーの 44px タップ領域（`w-11 h-11 -m-2 md:w-[28px] md:h-[28px]`）と `touch-manipulation` は変更しない（REQ-365/AC-2 回帰）。
</constraints>
