# REQ-307-T2 キュー投入の失敗通知契約

`QueuePromptOptions` に `onSubmissionFailure?: (failure: QueueSubmissionFailure) => void` を追加。`BypassState.errorToast` と `BypassActions.setErrorToast` の通知型に `persistent?: boolean` を追加する。`queuePrompt` は失敗時に一度コールバックを呼び、指定時は単独トーストを抑える。指定なしの既存呼び出しは従来の通知を維持。中断は通知しない。`prompt_id` 欠落は理由不明。`Promise<string | null>` は維持。
