## 3. 実装要件 (Implementation Logic)
- [x] `ProfileBulkEditModal.tsx`:
  - `computeCommonTags` をベース名抽出（`parseTagWeight`）に対応させ、各共通タグの初期文字列表現を取得できるようにする。
  - `commonTagItems: CommonTagItem[]` 状態を管理し、共通タグ一覧を `TagChip` コンポーネント群で描画する。
  - `TagChip` の `onEdit`（タグ名変更・強度変更）、`onToggle`（有効/無効切替）、`onDelete`（削除）イベントを受け取って `commonTagItems` を更新する。
  - 一括編集適用時、`promptOps` に `commonTagOps`（各共通タグの `action: 'update' | 'remove'`、`originalBase`、`newFormattedTag`）を含めてペイロードを送信する（従来の `tags` 配列との後方互換性も維持）。
- [x] `useGeneratePageState.ts`:
  - `handleBulkEditApply` において、`op.commonTagOps` が存在する場合、対象フィールドのタグをパースして各タグのベース名と照合し、`action === 'remove'` は削除、`action === 'update'` は `newFormattedTag` に置換して更新する。
