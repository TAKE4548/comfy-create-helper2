# REQ-413-T2: groupMappingsByStageおよびbuildParamSyncCandidatesにおける無効バリアント除外

## 1. 概要と目的
マスタ側で無効化（`is_enabled = false`）されたステージバリアントが、ステージグループ表示および ParamSync モーダル（`ParamSyncModal`）の代表・同期先候補に表示されることを防ぐため、`groupMappingsByStage` で解決されたバリアントが `is_enabled === false` のマッピングをステージグループから除外する。`buildParamSyncCandidates` および `useMappingStageGroups`（`groupMappingsByStage` の React ラッパー）は内部で本関数を呼び出すため、自動的に除外される。

※本タスクは **AC-5** を担当する。AC-1〜AC-4（useWorkflowManagement / generationWorkflow におけるパラメータ枠除外および生成注入除外）は `REQ-413-T1` が担当する。

```typescript
      const master = masters.find(candidate => candidate.id === mapping.master_id && isV2(candidate))
      if (master && isV2(master)) {
        const variant = master.variants.find(item => item.id === mapping.variant_id && item.master_id === master.id)
        if (variant) match = { variant, master }
      }
    } else if (mapping.role != null) {
      const candidates: ResolvedVariant[] = []
      for (const master of masters) {
        if (!isV2(master) || master.id !== mapping.master_id) continue
        for (const variant of master.variants) {
          if (variant.master_id === master.id && variant.computed_role === mapping.role) candidates.push({ variant, master })
        }
      }
      if (candidates.length === 1) match = candidates[0]
    }
    addMapping(index, mapping, match)
  })
```

## 4. 実装要件 (Implementation Logic)
