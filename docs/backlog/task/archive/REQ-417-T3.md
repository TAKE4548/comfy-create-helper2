# REQ-417-T3: 共有定義CRUD API実装とOpenAPI型同期

## 1. 概要と目的
`binding_rule_sets` および `node_selectors` の CRUD 操作を提供する新規 API ルーターを実装する。共有定義の取得時には参照元 role 一覧（`referenced_roles`）を返却し、他 Variant から参照されている定義の削除リクエストに対しては参照中 role リストとともに HTTP 400 を返却して保護する。また、`WorkflowMappingRead` スキーマに `input_name: str` を追加し、旧スキャン分岐を整理した上で、`openapi.json`, `docs/openapi.yaml` を再生成し、`frontend/src/api/types.ts` と同期させる。

## 3. 密閉コンテキスト (Hermetic Context)
<hermetic_context>
### 3.1 削除ガードおよび参照元role返却スニペット (`backend/app/routers/binding_rules.py`)
```python
@router.delete("/binding-rules/{rule_set_id}", status_code=204)
def delete_binding_rule_set(rule_set_id: int, db: Session = Depends(get_db)):
    rule_set = db.query(BindingRuleSet).filter(BindingRuleSet.id == rule_set_id).first()
    if not rule_set:
        raise HTTPException(status_code=404, detail="BindingRuleSet not found")
    # 参照元 Variant の role 一覧を検出
    referencing_variants = db.query(MappingVariant).filter(MappingVariant.binding_rule_set_id == rule_set_id).all()
    if referencing_variants:
        roles = [v.role for v in referencing_variants]
        raise HTTPException(
            status_code=400,
            detail={"error": "Cannot delete rule set currently in use", "referenced_roles": roles}
        )
    db.delete(rule_set)
    db.commit()
    return None
```
</hermetic_context>
