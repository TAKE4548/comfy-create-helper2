## Approved Acceptance Context (coordinator dispatch)

The user approved the complete design on 2026-10-10. These exact PBI criteria provide behavior context; ownership above still limits this task. Cross-component criteria are integration outcomes, not permission to edit unowned files.

- AC-21: Given 幅800のGenerate, When 開く, Then 左330pxは入力・設定に限定され、生成とSnapshot保存は右下Action Barにある。
- AC-22: Given Generateの各幅, When スクロールする, Then Queue管理/Generate Batch/Snapshot保存をAction Barから使用でき、Mobileでは下部ナビ直上に表示される。
- AC-23: Given バッチ/ノード進捗通知, When 状態を表示する, Then 全体件数・%とノード名・ステップ%を独立した2本の進捗で確認できる。
- AC-24: Given 経過時間/ETAが既知または未知, When 表示する, Then 既知値は秒数、未知値は「未取得」となる。
- AC-25: Given Queueピル, When クリック/PCホバーする, Then 管理画面が開く/「ジョブキュー一覧・管理を開く」が表示される。
- AC-33: Given 実行中ジョブ, When 管理画面で進捗受信する, Then ノード名・現在/総ステップ・Set名・プロンプト抜粋が更新される。
- AC-34: Given 実行中1件・待機2件, When 待機のみクリアを確認実行する, Then 待機2件だけが取り消され実行中は継続する。
- AC-35: Given 実行中1件・待機2件と全生成対象, When 全中断・クリアを確認実行する, Then 実行中停止と待機取消の確認結果が表示される。
- AC-36: Given 通常生成だけを取消対象に指定しStudio/未分類ジョブがある, When 確認実行する, Then 保護対象は継続し、処理見送りの対象と理由を表示する。
- AC-37: Given 取消結果が部分成功/未確認, When 結果が返る, Then 成功・未確認の対象を表示してモーダルを維持する。
- AC-38: Given 単一待機ジョブ取消を選択, When 3000ms未満でUndoを押す, Then 取消は適用されない（「取消予約」と表示し中断済み画像の復元を意味しない）。
- AC-39: Given 待機取消予約, When Undoせず3000ms経過する, Then まだ待機中の対象だけを取消し、実行開始済みなら「取消できません」と表示する。
- AC-40: Given 接続設定操作, When ラベル・説明を見る, Then 「ワークフロー / 接続設定」に統一される。
- AC-41: Given 翻訳モーダル入力済み, When Ctrl+Enterを押す, Then 翻訳を1回実行し生成要求は追加しない。
