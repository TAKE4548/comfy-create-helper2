# REQ-427-T6: プロファイル一括編集での image 型

## 1. 目的
「プロファイル一括編集」（`ProfileBulkEditModal` のパラメータタブ）で `input_type === 'image'` のロールを正式に扱う。通常の Generate 入力と同じ部品 `ImageParamField`（サムネイル、履歴/スナップショット選択、アップロード、D&D、ペースト）で画像を選び、選択中の複数プリセットへ **同一トークン** を一括適用できるようにする。画像未選択（またはチェック OFF）のロールは各プリセットで変更しない。部品は二重実装しない。

## 2. 所有ファイル（これ以外は編集しない）

## 3. 実行環境・コマンド前提

## 4. 前提契約（T5 提供、変更禁止）
```ts
// frontend/src/components/ImageParamField.tsx
export interface ImageParamFieldProps {
  label: string; fieldKey: string; value: string | undefined; onChange: (token: string) => void
  mobile?: boolean; disabled?: boolean; workflowId?: number; onPickerOpenChange?: (open: boolean) => void
}
export function ImageParamField(props: ImageParamFieldProps): JSX.Element
```
- 内部で upload/import を行い、成功時のみ `onChange(token)`（`refimg:<sha256>.<ext>`）を呼ぶ。失敗時は自身でエラー表示し `onChange` を呼ばない。ピッカー（共通 `Modal`）の開閉を `onPickerOpenChange` で通知する。サムネイル取得失敗時は「プレビューを表示できません」を表示し、値は保持する。
- ルート要素の `data-testid` は `image-param-${fieldKey}`。

## 5. 現行実装（調査済み・変更しない部分）
- `useProfileBulkEditState.paramRoles` は textarea 以外の全 MappingMaster（`image` を含む）。値はロール単位で `enabledParams: Set<string>`（チェック）と `paramPatch: Record<string, string>`（値）。
- `buildBulkEditPayload`（`buildPayload.ts` L73-80）は「チェック ON かつ値が空でない」ロールだけを `payload.paramPatch` に入れる。
- `usePresetState.handleBulkEditApply` の動作:
  - 対象は `payload.targetPresetIds`、無ければ一括編集を開いたときの選択プリセット `bulkTargetIds`。
  - 各プリセットに `computePresetPatch` で `param_values` へ `paramPatch` をマージし、`workflowPresetsApi.update` を `Promise.all` で並列 PUT する。
  - 全件成功で sets・アクティブ状態・クエリキャッシュを同期し、成功トーストを出す。
  - 失敗時はエラートーストを出して例外を再送出する。成功済み PUT はロールバックしない。
  - 適用後 `resetParamSelection` でチェックは全解除される（値は残る）。
- 上記（`buildPayload.ts`, `presetBulkPatcher.ts`, `usePresetState.ts`, `useProfileBulkEditState.ts`, `ParamFieldControl.tsx`, `LoraStackSection.tsx`）は **変更しない**。image のトークンは通常の文字列値として既存経路で一括適用される。
