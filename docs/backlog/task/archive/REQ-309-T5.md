# REQ-309-T5

## Scope and AC
T2〜T4 実装後の candidate を**本番ビルド**し、T0 が凍結した基準と同一条件で前後比較し、全 route・離脱保護・chunk 失敗・モーダル巡回を本番バンドルで検証するスイートを実装・実行する。対象 AC: AC-1〜AC-6 と Requirement 2。**このカードの PASS は最終受入ではない**（独立 tester が最終 candidate から再ビルド・再計測する）。FAIL（AC-1/AC-2 未達、初期グラフに遅延境界が混入、chunk 500 kB 超）の場合は原因の chunk/静的 import を記録して設計へ戻す。`manualChunks`・`chunkSizeWarningLimit` などで警告だけを消す変更は禁止。
**AC 分担**: AC-2 は `buildGuard` の 3 ケース（ビルドログ全文・config 無変更・全 chunk ≤ 500,000 bytes）で判定し、警告の消失だけでは AC-1 を PASS としない（`compare-before-after-*` と `initial-graph-excludes-lazy-boundaries` が別途必要）。AC-3〜AC-6 と Requirement 2 は下表のスペックが担当し、統合 Vitest 側は T2〜T4 が担当する。

## 手順（PowerShell。`cd frontend` 起点、ログは `..\docs\logs\REQ-309\`）
1. 正式ビルド（AC-2 の証拠）: `npm.cmd --prefix frontend run build -- --outDir ../docs/logs/REQ-309/candidate/dist --emptyOutDir 2>&1 | Tee-Object docs/logs/REQ-309/candidate/build.log`（`build.log` は警告も含め全文）。
2. 解析ビルド: `cd frontend; npx vite build --manifest --outDir ../docs/logs/REQ-309/candidate/dist-manifest --emptyOutDir`。`dist` と `dist-manifest` の `assets/*.js` ファイル名集合が一致することを `chunkReport.mjs` が検証する（ハッシュ一致＝同一内容）。
3. `node e2e/prod/support/srcManifest.mjs --out ../docs/logs/REQ-309/candidate/src-manifest.json`、`--diff` で baseline との差分を `candidate/src-diff.json` に保存。差分が **T1〜T5 の所有ファイル以外**を含む場合は完了報告に明記（最終検証が統制基準へ切替える）。
4. `node e2e/prod/support/chunkReport.mjs --manifest ../docs/logs/REQ-309/candidate/dist-manifest/.vite/manifest.json --dist ../docs/logs/REQ-309/candidate/dist --out ../docs/logs/REQ-309/candidate/chunk-report.json`。

## chunkReport.mjs の契約
入力は Vite の `manifest.json`。出力 JSON: `{ chunks:[{file,bytes}], overLimit:[file…](bytes>500000), map:{<source key>: <emitted file>}, initialGraph:[file…], violations:[…] }`。`initialGraph` = `isEntry` の chunk と、その `imports`（静的）の閉包 ∪ `src/pages/GeneratePage.tsx` の動的 entry とその `imports` の閉包。**禁止集合**（これらの `map` 先ファイルが `initialGraph` に含まれたら violation）: 5 route `src/pages/LoRAsPage.tsx`・`src/pages/TagsPage.tsx`・`src/pages/HistoryPage.tsx`・`src/pages/SettingsPage.tsx`・`src/pages/DatasetStudioPage/index.tsx`、および 14 モーダル `src/components/{ProfileBulkEditModal,RescanModal,UploadWorkflowModal,WorkflowManageModal,PresetManagerPanel,HistoryModalPreview,JobManagementModal,AddSnapshotToAlbumModal,SceneGeneratorModal,PresetConflictModal,BypassSettingsModal,ParamSyncModal}.tsx`、`src/pages/GeneratePage/components/{PromptTranslationModal,SaveAsTagSetModal}.tsx`。キーが manifest に存在しない場合（動的 import 化されていない）も violation。`TagsPage → LoRAsPage` 結合などの共有 chunk は `chunks` 一覧で報告する。
