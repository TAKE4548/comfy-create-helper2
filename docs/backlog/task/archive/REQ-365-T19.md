# REQ-365-T19: Kebab 44px タッチターゲット (AC-2 E2E不具合是正)

E2E AC-2 (375px) が `button[ヘッダーメニュー] 28x44`（幅28 < 44）を違反として検出。人間承認済み方針A: 視覚は28pxのまま、モバイル(<768px)でボタン自体の寸法を44x44にする。

## 設計判断（E2E測定方式に基づく）
E2Eは `el.getBoundingClientRect()` で `width/height < 44-0.5` を違反とする（アイコンのみbuttonは幅も判定）。**`before:-inset-2` 等の疑似要素はボタンの矩形を変えないため、hit-slop疑似要素だけではE2Eを通過しない。** したがってボタン要素自体を実寸44pxにし、視覚28px箱は内側spanへ移す。レイアウト占有は負マージンで28pxに保つ。
- ボタン（ヒット領域、背景/枠なし）: `group relative inline-flex items-center justify-center w-11 h-11 -m-2 md:w-[28px] md:h-[28px] md:m-0 touch-manipulation`
- 内側span（視覚）: 従来の見た目を移し、hoverは `group-hover:` に変更。
