## 変更内容
1. 外側 `fixed inset-0 …` と内側パネルを撤去し、**testid 付きの無スタイルラッパー div の内側に Modal を置く**（既存テストが `within(screen.getByTestId('speech-tone-preset-modal')).getByRole('dialog', { name: '口調プリセット編集' })` と配下の `保存`/`キャンセル` を引くため、testid は Modal の祖先でなければならない）:
```tsx
const title = mode === 'create' ? '新規口調プリセット作成' : '口調プリセット編集'
return (
  <div data-testid="speech-tone-preset-modal">
    <Modal isOpen onClose={onClose} size="lg" ariaLabel={title}
      closeOnBackdropClick={false} sheetMaxHeightClass="max-h-[85dvh]">
      {/* Header: shrink-0 px-4 md:px-5 py-3 border-b …。h3 id={headingId} は維持（見出しは dialog 内で1つのみ） */}
      <form onSubmit={handleSubmit} className="flex flex-col min-h-0 flex-1">
        <div className="flex-1 min-h-0 overflow-y-auto overscroll-contain space-y-3.5 px-4 md:px-5 py-4">{/* 既存フィールド群 */}</div>
        <div className="shrink-0 flex justify-end gap-2 px-4 md:px-5 py-3 border-t …">{/* 既存フッターのボタン */}</div>
      </form>
    </Modal>
  </div>
)
```
   - `aria-label` は見出しと同一文言。`closeOnBackdropClick={false}`: 旧実装はバックドロップ無反応（入力途中の誤消失防止）なので維持。Esc は新規に有効（Modal既定）。
   - 追加の `pb` 禁止（Modalがsafe-areaを提供）。`animate-fade-in` 等の独自overlay用classは撤去。
2. 44px: 閉じる(X)・入力・テキストエリア・フッター2ボタンは既に `min-h-11`。維持（縮小禁止）。
3. 11pxフロア: 約130行 `text-[10px]`（「生成プレビュー」）→ `text-[11px]`。生 `vh` を新規追加しない。
4. `import { Modal } from '../../../components/common/Modal'` を追加。
5. **対象外（変更しない）**: 同ファイル約364行の `role="alertdialog"` `aria-label="口調プリセット削除の確認"` は行内インライン確認（オーバーレイではない）。
