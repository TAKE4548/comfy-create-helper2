# REQ-294-T14（設計レビュー待ち）

`SceneSpeechProgressEvent` / `SceneSpeechStreamEvent` / `SceneSpeechStreamOptions` を `api/types.ts` に型定義し、`api/client.ts` へ `sceneSpeechApi.generateStream(payload: SceneDraftRequest, options?: SceneSpeechStreamOptions): Promise<SceneDraftResponse>` を追加する。clientの `BASE_URL = '/api'` を使って `POST /api/speech/scene-draft/stream` の `ReadableStream` をTextDecoderで増分解析し、JSON行の複数チャンク分割/複数行同着/最終改行なしを扱う。`result` でresolve、HTTP 4xx/5xx・`error` イベント・結果なしEOF・不正行でreject、AbortSignalを通す。既存 `request()` と他APIは変更しない。上記3ファイルのみ、300行以下目安。

検証: frontendで `npm run typecheck`、`npx vitest run src/api/__tests__/sceneSpeechStream.test.ts`。テストに分割チャンク/正常終端/全異常/abortを含める。

## 密封コンテキスト: exact types と client入口

`api/types.ts` には既存 `SceneDraftRequest` / `SceneDraftResponse` が存在する。追加する型は以下。`error_kind` は既存Hook `classifyError` と一致する文字列を使う。

```typescript
export type SceneSpeechProgressStep = 'reference' | 'vlm' | 'style' | 'vram'
export type SceneSpeechProgressStatus = 'active' | 'done' | 'error'
export interface SceneSpeechProgressEvent {
  type: 'progress'
  step: SceneSpeechProgressStep
  status: SceneSpeechProgressStatus
}
export type SceneSpeechStreamErrorKind = 'lm_studio_400' | 'connection_refused' | 'timeout' | 'invalid_request' | 'vram_unload_failed' | 'unknown'
export type SceneSpeechStreamEvent = SceneSpeechProgressEvent
  | { type: 'result'; data: SceneDraftResponse }
  | { type: 'error'; error_kind: SceneSpeechStreamErrorKind; message: string }
export interface SceneSpeechStreamOptions {
  onProgress?: (event: SceneSpeechProgressEvent) => void
  signal?: AbortSignal
}
```

`api/client.ts` 冒頭には `const BASE_URL = '/api'` と汎用 `request<T>(path, options)` がある。streamに `request()` は使わず、既存fetchと同じ `${BASE_URL}` を使う。型import一覧へ上記4型と `SceneDraftRequest/Response` を追加し、次のnamed exportを置く。

error行のkind/messageはT15へ渡すため `api/client.ts` で `export class SceneSpeechStreamError extends Error { constructor(public kind: SceneSpeechStreamErrorKind, message: string) { super(message); this.name = 'SceneSpeechStreamError' } }` を定義し、この例外でrejectする。HTTP失敗/不正行などkindが判定できない場合は `unknown`。T15は `instanceof SceneSpeechStreamError` で正確なkindを取得する。

不正行/未知イベント/result重複を明確な例外とし、`onProgress` は各progress行につき一回だけ呼ぶ。abortでreaderをキャンセルする。
