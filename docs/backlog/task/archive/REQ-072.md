### 2.3 画像取得および重複回避ロジック仕様
1. **画像取得**:
   - 各スナップショットの `image_path`（例：`/api/snapshots/123/image` や `/outputs/filename.png`）は、フロントエンド開発サーバー（あるいは本番プロキシ経由）でそのままHTTP GETリクエストが可能です。
   - `const response = await fetch(imagePath); const blob = await response.blob();` で画像データを取得します。

2. **重複ファイル名の回避アルゴリズム**:
   - `usedNames` という `Set<string>` を使用して、すでに追加されたファイル名を記憶します。
   - 抽出したファイル名（無効な場合は `snapshot_[id].png`）が既に存在する場合、以下の手順で連番を付与します。
     ```typescript
     const getUniqueFilename = (originalName: string, usedNames: Set<string>) => {
       if (!usedNames.has(originalName)) {
         usedNames.add(originalName);
         return originalName;
       }
       const extIndex = originalName.lastIndexOf('.');
       const base = extIndex !== -1 ? originalName.slice(0, extIndex) : originalName;
       const ext = extIndex !== -1 ? originalName.slice(extIndex) : '';
       let counter = 1;
       let newName = `${base}_${counter}${ext}`;
       while (usedNames.has(newName)) {
         counter++;
         newName = `${base}_${counter}${ext}`;
       }
       usedNames.add(newName);
       return newName;
     };
     ```
