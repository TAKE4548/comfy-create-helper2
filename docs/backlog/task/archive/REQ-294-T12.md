## 密封コンテキスト: 既存箇所と厳密な契約

必要な追加importは `typing` の `Awaitable, Callable, Literal`。既存の `Any, Optional` を残す。callback型はこのファイルからT13がimportする。

```python
ProgressStepKey = Literal["reference", "vlm", "style", "vram"]
ProgressStatus = Literal["active", "done", "error"]
ProgressCallback = Callable[[ProgressStepKey, ProgressStatus], Awaitable[None]]

async def generate_scene_script(
    db: Session,
    snapshot_id: int,
    target_tag_set_id: Optional[int] = None,
    explicit_preset_id: Optional[int] = None,
    scene_hint: Optional[str] = None,
    override_similar_scene_snapshot_id: Optional[int] = None,
    progress_callback: ProgressCallback | None = None,
) -> tuple[str, list[GeneratedSpeechBubbleRead], bool,
           list[ToneSampleItem], Optional[int], list[SimilarSceneCandidate]]:
    ...
```

現行 `snapshot = db.query(Snapshot)...` の前でreference active、`vlm_model = get_llm_prompt_content(...)` の後でreference done / vlm activeを発行する。現行末尾は次の順序で、T1の空items例外を保全する。

```python
    vram_unloaded = False
    try:
        raw_response = await call_vlm(image_base64, prompt, vlm_model)
        try:
            parsed = parse_vlm_json_with_fallback(raw_response)
        except (ValueError, TypeError) as exc:
            raise RuntimeError("Invalid VLM response: malformed JSON") from exc
        if not isinstance(parsed, dict) or not isinstance(parsed.get("items"), list) or not parsed["items"]:
            raise RuntimeError("Invalid VLM response: items must be a non-empty list")
        interpretation = parsed.get("scene_interpretation", "")
        items = parsed["items"]
        bubbles = convert_items_to_bubbles(db, items,
            target_tag_set_id=target_tag_set_id, explicit_preset_id=explicit_preset_id)
    finally:
        vram_unloaded = await unload_vlm_model_with_retry()
```

VLM parse/非空確認後にvlm done / style active、convert後にstyle done、finally内でvram active/doneを発行する。例外時はその時点の工程をerrorにし、unload実行後に元の例外を再送出。callbackが失敗してもunloadを飛ばさない設計とする。
