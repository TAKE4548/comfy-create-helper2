# REQ-435-T2: ステージ折り畳み永続化フック・StageInputGroup・ParamPanel・進捗セレクタ実装

## 1. 概要と目的
ステージ折り畳み状態をワークフロー×欄（`prompt` / `parameters`）単位で `localStorage` に永続化する `useStageCollapseState`、`StageInputGroup` の折り畳み UI と sticky 見出し維持、`ParamPanel` のステージ折り畳み接続、およびモバイル全体進捗 `n/m` を算出する純粋関数 `selectMobileOverallProgress` を実装する。

### 4.3 `ParamPanel.tsx`（現行 L72–87, L104–126）
```tsx
// ParamPanelProps に追加:
workflowId?: number | null

function StageGroupedParameters({
  mappings,
  workflowId,
  renderMapping,
}: {
  mappings: readonly WorkflowMapping[]
  workflowId?: number | null
  renderMapping: (mapping: WorkflowMapping) => ReactNode
}): React.JSX.Element {
  const stageGroups = useMappingStageGroups(mappings, undefined, true)
  const { isStageCollapsed, toggleStageCollapsed } = useStageCollapseState(workflowId, 'parameters')
  const validKeys = stageGroups.map((g) => g.key)
  return <>
    {stageGroups.map((group) => (
      <StageInputGroup
        key={group.key}
        groupKey={group.key}
        stageName={group.stageName}
        stageKey={group.stageKey}
        collapsible
        collapsed={isStageCollapsed(group.key)}
        onToggleCollapse={() => toggleStageCollapsed(group.key, validKeys)}
      >
        <div className="space-y-3">{group.mappings.map(renderMapping)}</div>
      </StageInputGroup>
    ))}
  </>
}
```

### 4.4 `generationSelectors.ts` 追加関数

```ts
export interface MobileOverallProgress {
  current: number // n: 完了件数+1（全件完了時は m）
  total: number   // m: 有効job総数（cancelled / released / unconfirmed を除外、failed は完了に含める）
  label: string   // `${current}/${total}`
}
export function selectMobileOverallProgress(
  normalProgress: { finished: number; total: number } | null,
  activeBatch: ReadonlyArray<{ status?: string }> | null | undefined,
  isGeneratingHere: boolean,
): MobileOverallProgress | null
```
