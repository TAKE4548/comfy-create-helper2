# REQ-309-T4

## Scope and AC
`GenerateModalsOverlay.tsx`（Desktop/Mobile 両レイアウトが描画）が静的 import する 4 モーダル（`BypassSettingsModal`・`ParamSyncModal`・`PromptTranslationModal`・`SaveAsTagSetModal`）を `LazyModalHost`（T1）に置換する。対象 AC: AC-1、AC-3。コピー作成ダイアログとエラートースト（`role="alert"`）は静的のまま（初期画面で即時表示可能）。T3 と所有ファイルが異なるため並列実行できる。
**AC 分担**: AC-2 は T2/T3 とともに実チャンク縮小へ寄与し判定は T5 `buildGuard`。AC-4（checkpoint → 生成）は T3/T5、AC-5/AC-6 の遷移は T2/T5、SSoT は T6。

## 所有ファイル
- `frontend/src/pages/GeneratePage/sections/GenerateModalsOverlay.tsx`
- `frontend/src/pages/GeneratePage/sections/__tests__/GenerateModalsOverlay.test.tsx`（既存を拡張。既存の通知ケースは無変更で PASS）
`DesktopLayout.tsx`/`MobileLayout.tsx` は編集禁止（呼び出し側の props は変更しない）。

## 現行コード（`GenerateModalsOverlay.tsx`）
```tsx
import { BypassSettingsModal } from '../../../components/BypassSettingsModal'
import { ParamSyncModal } from '../../../components/ParamSyncModal'
import { PromptTranslationModal } from '../components/PromptTranslationModal'
import { SaveAsTagSetModal } from '../components/SaveAsTagSetModal'
// ... export const GenerateModalsOverlay = memo(function GenerateModalsOverlay({ state, showCopyModal, ... }: GenerateModalsOverlayProps) {
{isBypassSettingsOpen && (
  <BypassSettingsModal onClose={() => setIsBypassSettingsOpen(false)} workflowJson={workflow?.json_body} />
)}
{isParamSyncSettingsOpen && (
  <ParamSyncModal onClose={() => setIsParamSyncSettingsOpen(false)} />
)}
{promptTranslation && (
  <PromptTranslationModal isOpen={promptTranslation.isOpen} onClose={promptTranslation.closeTranslation}
    roleDisplayName={textMappings.find((m) => m.role === promptTranslation.activeRole)?.display_name || promptTranslation.activeRole || 'プロンプト'}
    mode={promptTranslation.mode} onModeChange={promptTranslation.setMode}
    sourceText={promptTranslation.sourceText} onSourceTextChange={promptTranslation.setSourceText}
    translatedText={promptTranslation.translatedText} meta={promptTranslation.meta}
    isTranslating={promptTranslation.isTranslating} error={promptTranslation.error}
    onTranslate={promptTranslation.executeTranslate} onApply={promptTranslation.applyToPrompt} />
)}
{saveAsTagSetRole && (
  <SaveAsTagSetModal role={saveAsTagSetRole} promptText={paramValues[saveAsTagSetRole] ?? ''} onClose={() => setSaveAsTagSetRole(null)} />
)}
```
named export: `BypassSettingsModal`（`components/BypassSettingsModal.tsx`）、`ParamSyncModal`（`components/ParamSyncModal.tsx`）、`PromptTranslationModal`（`pages/GeneratePage/components/PromptTranslationModal.tsx`、`React.FC`）、`SaveAsTagSetModal`（`pages/GeneratePage/components/SaveAsTagSetModal.tsx`）。`SaveAsTagSetModal.tsx` は `extractTagsFromPrompt` も export するが、この overlay では使わない。

## 変更規則
| モーダル | mode | isOpen | 備考 |
|---|---|---|---|
| BypassSettingsModal | while-open | `isBypassSettingsOpen` | `onClose` は `() => setIsBypassSettingsOpen(false)`、`modalProps: { onClose, workflowJson }` |
| ParamSyncModal | while-open | `isParamSyncSettingsOpen` | |
| SaveAsTagSetModal | while-open | `!!saveAsTagSetRole` | `role` は `saveAsTagSetRole`（非 null を保つ） |
| PromptTranslationModal | latch | `promptTranslation.isOpen` | **外側の `promptTranslation &&` ガードは維持**（テスト fixture が `{}` や未定義でも従来どおり安全）。modalProps に現行の全 props（`isOpen` 含む）を渡す。ホストは 1 つの `promptTranslation` の存続期間中、初回オープン後は mount 維持 |
loader はモジュールレベル定数。`label`: 'バイパス設定'、'パラメータ同期設定'、'タグセット保存'、'プロンプト翻訳'。`onClose`（局所エラーの「閉じる」）は各モーダルの現行 close ハンドラ（`promptTranslation.closeTranslation` 等）。4 モジュールへの静的 import を残さない。`memo` と props 型 `GenerateModalsOverlayProps` は変更しない。
