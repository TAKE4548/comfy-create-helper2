### REQ-362-T4: GenerateParallelPreview におけるサムネイル先行描画プログレッシブプレビュー表示

#### 1. 目的とスコープ
- 履歴プレビュー表示コンポーネント（`GenerateParallelPreview.tsx`）において、フルサイズWebP画像の読み込みが完了するまでの間、キャッシュ済みのサムネイルWebP（低解像度）をプレースホルダーとして先行描画する（AC-7）。
- フルサイズ画像のロード完了時にシームレスに切り替え、画像の読み込み待機による画面の空白やガタつき（レイアウトシフト）を防止する。
- フルサイズ画像ロードエラー時（`onError`）はサムネイル表示のまま維持し、画面がハングしたり無限ローディングになることを防ぐ。

#### 2. 対象ファイルと変更箇所（Surgical Snippets）
- **対象ファイル**: `frontend/src/pages/GeneratePage/components/GenerateParallelPreview.tsx`

```tsx
const thumbnailUrl = `/api/comfy/thumbnail?filename=${encodeURIComponent(image.filename)}&subfolder=${encodeURIComponent(image.subfolder || '')}&type=${encodeURIComponent(image.type || 'output')}`;
const fullViewUrl = `/api/comfy/view?filename=${encodeURIComponent(image.filename)}&subfolder=${encodeURIComponent(image.subfolder || '')}&type=${encodeURIComponent(image.type || 'output')}`;

const [isFullLoaded, setIsFullLoaded] = useState(false);
const [thumbError, setThumbError] = useState(false);
const [fullError, setFullError] = useState(false);

return (
  <div className="relative w-full h-full flex items-center justify-center bg-zinc-900/50">
    {/* 先行プレースホルダー: サムネイル */}
    {(!isFullLoaded || fullError) && !thumbError && (
      <img
        src={thumbnailUrl}
        alt="Preview Thumbnail"
        onError={() => setThumbError(true)}
        className="absolute inset-0 w-full h-full object-contain filter blur-sm transition-opacity duration-200"
      />
    )}
    {!isFullLoaded && thumbError && !fullError && (
      <div className="absolute inset-0 flex items-center justify-center text-zinc-500 text-xs">
        Loading preview...
      </div>
    )}
    {/* メインプレビュー: フルサイズWebP */}
    {!fullError && (
      <img
        src={fullViewUrl}
        alt="Full Preview"
        onLoad={() => setIsFullLoaded(true)}
        onError={() => setFullError(true)}
        className={`w-full h-full object-contain transition-opacity duration-200 ${isFullLoaded ? 'opacity-100' : 'opacity-0'}`}
      />
    )}
  </div>
);
```
