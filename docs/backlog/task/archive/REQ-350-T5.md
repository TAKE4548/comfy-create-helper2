## Implementation Requirements

- 共通 SeedField を作り input_type==='seed' 行だけで使う。Shuffle/Lock、モード名、日本語accessible name、step=1,min=0,max=UINT32_MAX を表示。random時入力disabled、fixed時編集可能。各DOM idにmapping.idとmobileを含める。
- paramValues[m.role] を値SSoT、SEED_MODES_KEY のslotをmodeSSoTにする。modeトグルは基準値を変更しない。setParamValues の既存経路で値・modeを一緒に更新する。
- 同期slave は値とmodeトグル両方disabled、親欄名と同期表示を保持。表示値/mode は親設定を反映。混在型・循環は生成前validationで説明する。
- T1 resolveSeedSyncRootsで同期チェーンの最終親を求め、readSeedSettingsで同じrootのmode/値を表示する。resolverがエラーなら欄に説明を出し、生成時も拒否する。
- legacy専用global Seed 行は nonseed Sampler_Seed mapping が存在する時のみ表示。専用seedしかない場合の二重操作を解消する。既存global操作は legacy欄へ作用する。
- T11でlegacy Sampler_SeedもparamMappingsへ入るため、map描画はinput_type!=='seed'かつrole==='Sampler_Seed'の普通数値行をskipし、既存global行へ集約する。専用seed Sampler_Seed行はskipしない。
- 通常float/int、カスタムfloatに専用トグルを追加しない。desktop/mobile は同じ共通コンポーネントを利用し、未設定modeはfixedで現在値を維持。UIでmetadataパースエラーを欄のエラーとして示す。
