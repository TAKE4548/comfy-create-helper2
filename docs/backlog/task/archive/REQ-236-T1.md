## 4. 実装手順 (Step-by-Step Implementation)

### 4.1 `useGenerateAction.fault.test.ts` の作成
1. MSW `server.use` で `http.post('/api/comfy/prompt', ...)` に対して HTTP 503 エラーレスポンスを定義。
2. `handleGenerate()` を呼び出し、`setErrorToast` が発火し、`isGenerating` が安全に `false` に維持されること、`isBatchSubmitting` が `false` に解除されることをアサート。
3. `http.post('/api/comfy/prompt', () => HttpResponse.error())` でネットワーク切断を注入し、例外クラッシュせず同様に安全に回復することを検証。
4. `handleGenerateSets()` において、セット投入中に 503 が発生した際、該当ジョブが `status: 'failed'` となりエラートーストが表示されることを検証。

### 4.2 `usePromptTranslation.fault.test.ts` の作成
1. MSW `server.use` で `http.post('/api/translate/prompt', ...)` に対して 504 Gateway Timeout または ネットワークエラーを注入。
2. `openTranslation('positive_prompt', '1girl, original text')` でモーダルを開き、`executeTranslate()` を実行。
3. タイムアウト発生時に `isTranslating` が `false` に復帰し、`error` にエラーメッセージがセットされること。
4. 原文 `sourceText` ('1girl, original text') および `paramValues.positive_prompt` が一切破壊・消去されず維持されることをアサート。

### 4.3 `useLlmAction.fault.test.ts` の作成
1. MSW で `/api/audit` および `/api/llm-prompts/scene-generate` に対して 504 Timeout レスポンスを注入。
2. `useAuditAction` の `runAudit.mutateAsync()` を実行し、タイムアウト時に `auditStatus` が `'error'` に遷移して操作ブロックが解除されることを検証。
3. `useSceneGenerator` の `generateDrafts()` を実行し、30秒タイムアウト発生時に例外が安全にキャッチ可能であり、上位コンポーネントで `isDrafting` を false に解除できることを検証。
