# REQ-407-T1: Gate 3 の E2E 実行手順を正式ラッパー（scripts/run_e2e.py）へ是正し前提条件を併記する

## 1. 概要と目的
`.agents/context.md`、`docs/specs/SPEC_TEST_ARCHITECTURE.md` §6、`README.md` において、Gate 3（実ブラウザ E2E）の実行手順として記載されているコマンドを正式なラッパースクリプト `scripts/run_e2e.py`（または `backend\.venv\Scripts\python scripts/run_e2e.py`）へ是正する。
同時に、`npx playwright test` による直接実行を行う場合の必須前提条件（dev server ポート 5173 の事前起動が必要であること、未起動時は接続拒否 `net::ERR_CONNECTION_REFUSED` で失敗すること）を同一箇所に併記し、手順書通りに実行すれば追加知識なしで E2E が成立する状態を実現する（AC-1〜AC-5）。

- **置換後 (Replacement)**:

Playwright による実ブラウザでの描画・物理スクロール・sticky追従の検証を行います。

**正式な実行方法**:
リポジトリルートからラッパースクリプトを実行します。Vite dev server（ポート 5173）を自律起動し、テスト完了後に自動終了します（dev server 事前起動不要）。
```bash
# Windows
backend\.venv\Scripts\python scripts/run_e2e.py

# または仮想環境有効化時
python scripts/run_e2e.py
```
局所実行（特定 spec のみ）:
```bash

```

**直接実行する場合（非推奨・前提条件）**:
`npx playwright test` を直接実行する場合は、**事前に Vite dev server（ポート 5173: `cd frontend && npm run dev`）が起動していること**が必須前提となります。dev server が未起動の状態で直接実行すると、接続拒否（`net::ERR_CONNECTION_REFUSED`）によりテストが失敗します。
```bash
# 前提: 別ターミナル等で dev server (http://localhost:5173) が起動済みであること
cd frontend
npx playwright test
```
```
