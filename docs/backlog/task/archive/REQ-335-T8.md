# REQ-335-T8: pytest 収集から docs/logs を除外する

## 1. 目的
最終QAの Gate 2（`backend\.venv\Scripts\python.exe scripts/run_full_suite.py`）が FAIL した原因を除く。
`scripts/run_full_suite.py` はリポジトリ直下を cwd に `python -m pytest -n auto`（引数なし）を実行する。直下には pytest 設定ファイルが無く（`backend/pytest.ini` は直下実行では使われない）、`docs/logs/REQ-380/commit-candidate-20261024/` 配下の git 無視コピー（`backend/tests/**`、`tests/unit/**` と同じ basename）まで再帰収集され、`import file mismatch` で 80 件の収集エラーになる（実測: `--collect-only` で 743 collected / 80 errors）。
ユーザー決定: `docs/logs` を pytest 収集から**除外**する。**Gate 2 の argv は変更しない**（`scripts/run_full_suite.py` 自体も編集しない）。
実テストの 100% 保持が条件。`--ignore=docs/logs` 付きの実測は 743 件（`backend/tests` 694 + `tests/unit` 49）で、除外後も同数であること。

## 2. 設計判断（調査結果）
- 収集ルートは cwd=リポジトリ直下の再帰収集のみ（設定ファイル無し）。`.claude/worktrees`・`backend/.venv`・`frontend/node_modules` は pytest 既定の `norecursedirs`（`.*`、`node_modules`、`venv`…）で既に除外されている。
- `docs/logs` 配下に git 追跡ファイルは 0 件（`git ls-files docs/logs` が空。`.gitignore:151 logs/` で無視）。`docs/logs` 内の `.py` 199ファイル（`test_*.py`/`conftest.py` を含む）はすべて過去PBIの証跡コピーで、実テストは存在しない。ガード規則の再現は一時ディレクトリで実測済み（ini あり=1 collected/exit 0、ini なし=import file mismatch の収集エラー）。
- **採用**: 直下に新規 `pytest.ini` を置き `norecursedirs` に `docs/logs` を追加する。**重要な罠**: `norecursedirs` は pytest 既定値を**置換**する。`docs/logs` だけを指定すると `backend/.venv`・`node_modules` を収集して 240 件の収集エラーになる（実測）。**既定値を併記**した形（下記）は実測で 743 collected / 0 errors。
- 不採用: (a) `run_full_suite.py` に `--ignore=docs/logs` 追加（Gate 2 だけ直り、`.agents/context.md` 記載の素の `pytest -n auto` と開発者の直接実行は壊れたまま）。(b) `testpaths`（将来の別ディレクトリのテストを黙って落とす）。(c) 直下 `conftest.py` の `collect_ignore`（設定が散在）。(d) `docs/logs` コピーの削除（利用者の証跡を破壊）。
- 影響範囲: `pytest.ini` は `backend/` 配下を引数に取る実行（Gate 1 `pytest backend/tests/unit` 等）では最寄りの `backend/pytest.ini` が優先され**変わらない**。引数なし直下実行と `pytest tests/unit` が新 ini を使う（`norecursedirs` のみで他設定は入れない。`testpaths`/`addopts`/`python_files` は追加しない＝挙動不変）。
- 注意: `.agents/verification.json` の identity は `backend/ scripts/ tests/ docs/ …` と root_files（README/.gitignore/.gitattributes）のみ。**直下 `pytest.ini` は identity 入力外**。このためガードテスト（`backend/tests` 配下＝identity 入力）で内容を固定する。

### 4.2 `backend/tests/governance/test_pytest_collection.py`（新規）
```python
"""Collection guard: the root pytest run must skip docs/logs (git-ignored evidence copies)."""
from __future__ import annotations

import configparser
import os
import shutil
import subprocess
import sys
from pathlib import Path

import pytest

REPO_ROOT = Path(__file__).resolve().parents[3]
ROOT_INI = REPO_ROOT / "pytest.ini"
PYTEST_DEFAULTS = {".*", "build", "dist", "node_modules", "venv", "*.egg", "_darcs", "CVS", "{arch}"}
PROBE = "def test_probe() -> None:\n    assert True\n"


def _norecursedirs() -> list[str]:
    parser = configparser.ConfigParser(interpolation=None)
    assert parser.read(ROOT_INI, encoding="utf-8"), f"missing {ROOT_INI}"
    return parser.get("pytest", "norecursedirs").split()


def _write(path: Path) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(PROBE, encoding="utf-8", newline="\n")


def _collect(cwd: Path) -> subprocess.CompletedProcess[str]:
    env = {k: v for k, v in os.environ.items() if not k.startswith("PYTEST_")}
    return subprocess.run(
        [sys.executable, "-m", "pytest", "--collect-only", "-q", "-p", "no:cacheprovider"],
        cwd=cwd, env=env, capture_output=True, text=True, timeout=120,
    )


def test_root_pytest_ini_excludes_docs_logs_and_keeps_pytest_defaults() -> None:
    """norecursedirs replaces pytest defaults; dropping them would collect .venv/node_modules."""
    patterns = set(_norecursedirs())
    assert "docs/logs" in patterns
    assert PYTEST_DEFAULTS <= patterns


@pytest.mark.parametrize("with_ini", [True, False])
def test_collection_skips_docs_logs_copies_with_duplicate_basenames(tmp_path: Path, with_ini: bool) -> None:
    """Behavioural: same-basename copies under docs/logs, .venv, node_modules must not be collected.
    The no-ini control proves the probe really reproduces the 'import file mismatch' failure."""
    if with_ini:
        shutil.copy(ROOT_INI, tmp_path / "pytest.ini")
    _write(tmp_path / "tests" / "test_dup.py")
    for ignored in ("docs/logs/x/tests", ".venv/lib", "node_modules/pkg"):
        _write(tmp_path / ignored / "test_dup.py")
    proc = _collect(tmp_path)
    out = (proc.stdout + proc.stderr).replace("\\", "/")
    if with_ini:
        assert proc.returncode == 0, out
        assert "tests/test_dup.py::test_probe" in out
        assert "docs/logs" not in out
        assert "1 test collected" in out
    else:
        assert proc.returncode != 0, out  # control: duplicates collide without the ini


def test_docs_logs_has_no_tracked_files() -> None:
    """Anything tracked under docs/logs would be silently excluded from collection."""
    git = shutil.which("git")
    if git is None:
        pytest.skip("git is not available")
    proc = subprocess.run(
        [git, "-C", str(REPO_ROOT), "ls-files", "--", "docs/logs"],
        capture_output=True, text=True, timeout=60,
    )
    assert proc.returncode == 0, proc.stderr
    assert proc.stdout.strip() == ""
```
`.venv` を含むのは `.*` 既定パターンの保持も実測で縛るため。`mypy backend` が通る型注釈を維持する（`subprocess.CompletedProcess[str]`）。
