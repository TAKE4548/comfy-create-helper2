# REQ-365-T20: ボトムシートのドラッグハンドル二重表示の是正 (AC-9「ドラッグハンドル付き」)

ユーザー承認済みの是正。<768px で共通Modalのダイアログに、(a) 実DOMのハンドル `div[data-testid="modal-sheet-handle"]`（`md:hidden`、`h-1 w-10`）と (b) index.css の旧擬似要素 `::before`（36x4px）の2本が表示されると推定される。共通Modalのみ (b) を無効化し、(a) の1本に統一する。

## 原子性
変更2ファイル必須（index.css 1行変更、settingsResponsive.spec.ts 追加数行）+ Modal.test.tsx は不要見込み（下記）。合計約20行。PASS。

## 根本原因（実ファイル確認済み）
`frontend/src/index.css` の `@media (max-width: 767px)` ブロック内（約347-355行、レイヤー外）:
```css
  .modal-backdrop:not(.flex-col):not(:fullscreen):has(> [role='dialog']) > [role='dialog']::before {
    content: '';
    display: block;
    width: 36px;
    height: 4px;
    margin: 0 auto 0.75rem;
    border-radius: 9999px;
    background-color: rgb(255 255 255 / 0.2);
  }
```
共通Modal（`frontend/src/components/common/Modal.tsx` 約143行）のdialogは `data-radius-exempt` を持ち、直後の子に実ハンドルを持つ:
```tsx
        data-radius-exempt
        ...
        <div aria-hidden="true" data-testid="modal-sheet-handle" className="mx-auto mt-2 mb-1 h-1 w-10 flex-shrink-0 rounded-full bg-white/30 md:hidden" />
```
`data-radius-exempt` を `src` で付与しているのは Modal.tsx のみ（grep確認済み）。旧カスタムダイアログ MappingMasterEditModal（約294行 `role="dialog"`）/ StageManagerModal（約178行）は同属性を持たないため、セレクタを絞れば擬似ハンドルを維持できる。

## 変更内容（index.css、既存1規則のセレクタのみ変更。宣言本体は変更しない）
上記規則の1行目を次に置換する:
```css
  .modal-backdrop:not(.flex-col):not(:fullscreen):has(> [role='dialog']) > [role='dialog']:not([data-radius-exempt])::before {
```
- 新規規則追加は不要。`:not([data-radius-exempt])` は属性セレクタ分 specificity が増えるのみで、同ブロック内の順序・他規則（T18追加の共通Modal用規則、`data-sheet-max-height` 規則）との競合はない（`::before` を対象とするのは本規則のみ）。
- `!important` 禁止（ui-invariant）。他規則、`@layer` 内規則、Modal.tsx は変更しない。
- 結果: 共通Modalの `::before` は `content: normal`/`none`（生成されない）、旧ダイアログは従来どおり擬似ハンドル。
- 実ハンドルは `md:hidden` で >=768px 非表示のため、デスクトップへの影響なし（擬似ハンドルは元々 <768px のみ）。
