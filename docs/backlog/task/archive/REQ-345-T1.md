原画の既存判定抜粋（backend comfy.py:276-298、23行、参照専用）:
~~~python
async def probe_image_availability(filename: str, subfolder: str = "", type: str = "output") -> ImageAvailability:
    """Check the original, independently of thumbnail caches and generation IDs."""
    client = get_comfy_client()
    params = {"filename": filename, "subfolder": subfolder, "type": type}
    try:
        response = await client.head(f"{settings.comfy_url}/view", params=params, timeout=3.0)
        if response.status_code == 200:
            return ImageAvailability(availability="present")
        if response.status_code == 404:
            return ImageAvailability(availability="missing")
    except httpx.HTTPError:
        pass
    try:
        response = await client.get(f"{settings.comfy_url}/view", params=params, timeout=10.0)
        if response.status_code == 200:
            return ImageAvailability(availability="present")
        if response.status_code == 404:
            return ImageAvailability(availability="missing")
    except httpx.HTTPError:
        pass
    return ImageAvailability(availability="unknown")
~~~

## Implementation Logic

- [ ] URLを現在originで解析。pathname=/view、filename非空。key=JSON.stringify([filename,subfolder||'',type||'output'])。host/tを送らず、不正値はunknown/probe0。
- [ ] observeでownerにidentity登録してcheck。retainOwnerImagesで現在一覧外を除去、releaseOwnerでowner解除。owner間でpending共有。
- [ ] active<=2。identityごとpending Promiseと完了値共有。checking/settleを購読通知。例外/不正本文はunknown。API HTTP404だけでmissingにしない。
- [ ] refreshVisibleは登録presentだけ再確認、pending合流。unknownは明示retryのみ。missingはretry=trueでも再照会しない。
- [ ] retry時もpendingを消さない。dispose後queue停止/購読通知停止、queued Promiseはunknownでsettle。React owner寿命はT3。
- [ ] timer、永続記録、TTLを新設しない。unitで最大2/identity差分/owner解放/pending共有/unknown retry/missing固定/dispose raceを確認。
