# タスクカード: REQ-185-T1

## 目的
1. スナップショット一覧およびアルバム詳細画面のサムネイル右上に「セリフ編集 → ダウンロード → 削除」の順序でバッジを統一配置し、ホバー不要で常時視認・操作可能（常時表示化）にする。
2. アルバム詳細画面のソート機能を「基準（カスタム順 / 登録順）」と「方向（昇順 / 降順）」の2つの独立した操作軸に分離する。
3. 狭小・モバイル画面幅において、フィルタバーや複数選択ツールバーが画面外にはみ出さず適切に折り返して収まるようレスポンシブレイアウトを適用する。
4. 履歴画面の複数選択モードに「一括削除」機能を追加し、誤削除防止の2段階確認モーダルを実装する。
5. アルバム画面からのアイテム削除（単一・一括）時に、「アルバムから削除（登録解除のみ）」と「元画像ごと削除（実体完全削除）」を選択できるモーダルを実装する。

## Acceptance Criteria
- [ ] AC-1: 履歴一覧とアルバム画面において、サムネイル上に表示されるバッジ（セリフ編集・ダウンロード・削除）の配置位置およびスタイルが統一されていること
- [ ] AC-2: サムネイル上の各バッジがホバー時のみではなく常時視認可能な状態で表示され、タッチデバイス等でも迷わず操作できること
- [ ] AC-3: アルバム画面において、ソート基準（カスタム順/登録順等）とソート方向（昇順/降順）をそれぞれ独立して選択・適用できること
- [ ] AC-4: モバイルや幅狭画面表示時、フィルタ・ソートメニューや複数選択時の操作メニューが画面端からはみ出さず、適切に収まる/操作可能であること
- [ ] AC-5: 履歴画面で複数選択した際の操作に「一括削除」が追加され、誤削除を防ぐための2段階操作（確認モーダル）を経て削除が実行できること
- [ ] AC-6: アルバム画面でアイテムを削除する際、「アルバムから削除」と「元画像ごと削除」のいずれかをユーザーが選択して実行できること
- [ ] AC-7: 既存の他機能・デスクトップ表示等に意図しない表示崩れや動作デグレーションが発生しないこと

  ? [...currentAlbum.items].sort((a, b) => {
      if (albumSortCriterion === 'date') {
        const dateA = a.created_at ? new Date(a.created_at).getTime() : 0
        const dateB = b.created_at ? new Date(b.created_at).getTime() : 0
        return albumSortDirection === 'asc' ? dateA - dateB : dateB - dateA
      } else {
        return albumSortDirection === 'asc'

          : b.sequence_order - a.sequence_order
