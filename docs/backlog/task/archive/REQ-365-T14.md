<div key={wf.id} className="flex flex-col">

## 変更内容
1. 行内の6ボタン群 `div.flex.items-center.gap-2` を **単一の「︙」トリガー**（`MoreVertical` アイコン、`lucide-react`）に置換:
```tsx
<div className="relative shrink-0">
  <button type="button" aria-haspopup="menu" aria-expanded={menuWorkflowId === wf.id}
    aria-controls={`workflow-menu-${wf.id}`} aria-label={`${wf.name} の操作メニュー`}
    onClick={() => setMenuWorkflowId(menuWorkflowId === wf.id ? null : wf.id)}
    className="relative inline-flex min-h-11 min-w-11 items-center justify-center rounded-lg touch-manipulation before:absolute before:-inset-2 before:content-['']"><MoreVertical size={16} /></button>
  {menuWorkflowId === wf.id && (
    <div id={`workflow-menu-${wf.id}`} role="menu" className="absolute right-0 z-20 mt-1 w-56 max-h-[60dvh] overflow-y-auto overscroll-contain rounded-lg border ... bg-surface-3 shadow-xl">
      {/* role="menuitem" × 名前変更 / コピー / スマート置換 / (hasRollbackMap)ロールバック / プロファイル管理 / 削除 — 各 min-h-11、クリックで既存ハンドラ実行後に setMenuWorkflowId(null) */}
    </div>
  )}
</div>
```
   メニュー項目の表示文言とアイコンは現行ボタンと同一（`名前変更`, `コピー`, `スマート置換`, `ロールバック`, `プロファイル管理`, `削除`）。`削除`は危険色。ロールバックは `hasRollbackMap[wf.id]` のときのみ。
2. 新state `const [menuWorkflowId, setMenuWorkflowId] = useState<number | null>(null)`。同時に開くメニューは1つ。**Escapeで閉じてトリガーへフォーカス復帰**、外側クリック（`pointerdown`）で閉じる、`ArrowDown/ArrowUp` で項目移動（任意だがフォーカス可能にする）。メニュー開閉は他モーダル（削除ダイアログ、WorkflowManage、DiffReplace）と排他（項目選択で先に閉じる）。
3. ワークフロー名は `min-w-0 flex-1 truncate`＋`title`、トリガーは右端固定（`shrink-0`）。モバイルで行が折返さない。
