# REQ-394-T1: ルート pytest.ini の testpaths（AC-3）

## 実行境界

- 役割は engineer / dev-task。workspace・cwd はリポジトリルート。`PYTHONDONTWRITEBYTECODE=1`。Python は `backend\.venv\Scripts\python`。
- 所有ファイルは上記 2 つだけ。`backend/pytest.ini`、`backend/app/**`、`scripts/**`、`.agents/**` は変更しない。
- 前提: コーディネーターが設計承認を確認し、本 Card を exact-ID で in-progress へ遷移済みであること。状態更新・QA・commit は担当外。
- `scripts/verify_test_naming.py` は実行しない（追跡ファイルを書き換えるため）。
- 新しいテスト名には `[REQ-394/AC-3]` を含める（parametrize id）。ticket ID を含む新テストファイルは作らない。

## 背景（計測済み）

ルートには testpaths が無く、`pytest`・`pytest -n auto` が db/（約13,600ファイル）・docs・frontend を走査し、収集が 8.2〜9.2s（パス指定は 1.9s）。`testpaths = backend/tests tests` を足すと `-n auto` が 43〜45s から 32〜34s になる（設計 §2.2）。`backend/tests tests` と `tests backend/tests` のどちらの順でも 774 件を収集できることは確認済み。

## 1. pytest.ini（現状 → 変更）

現状（全文）:

```ini
[pytest]
# Gate 2 runs `python -m pytest -n auto` from the repository root with no config file.
# docs/logs holds git-ignored evidence copies (e.g. REQ-380 commit-candidate trees) whose test
# modules share basenames with the real suites and break collection ("import file mismatch").
# NOTE: norecursedirs REPLACES pytest's defaults, so the defaults are repeated after docs/logs.
norecursedirs = docs/logs .* build dist node_modules venv *.egg _darcs CVS {arch}
```

先頭のコメントブロックの直後、`norecursedirs` の前に次の 3 行を追加する（既存行は 1 文字も変えない）:

```ini
# REQ-394: collect only the real suites. Without testpaths a repository-root run walks db/ (about
# 13,600 cached images), docs/ and frontend/, adding about 8 s per xdist worker.
testpaths = backend/tests tests
```

## 2. test_pytest_collection.py（現状の該当部分）

```python
def _collect(cwd: Path) -> subprocess.CompletedProcess[str]:
    env = {k: v for k, v in os.environ.items() if not k.startswith("PYTEST_")}
    return subprocess.run(
        [sys.executable, "-m", "pytest", "--collect-only", "-q", "-p", "no:cacheprovider"],
        cwd=cwd, env=env, capture_output=True, text=True, timeout=120,
    )
```

既存の挙動テスト `test_collection_skips_docs_logs_copies_with_duplicate_basenames` は、コピーした ini に testpaths が入ると `tests/` しか走査されず常に通る（形骸化）。`norecursedirs` を引き続き検証するため、`.` を明示して testpaths を迂回する。

変更 1: `_collect` に任意の位置引数を足す。

```python
def _collect(cwd: Path, *paths: str) -> subprocess.CompletedProcess[str]:
    env = {k: v for k, v in os.environ.items() if not k.startswith("PYTEST_")}
    return subprocess.run(
        [sys.executable, "-m", "pytest", "--collect-only", "-q", "-p", "no:cacheprovider", *paths],
        cwd=cwd, env=env, capture_output=True, text=True, timeout=120,
    )
```

変更 2: 既存テストの収集呼出しを `proc = _collect(tmp_path, ".")` にする（それ以外は触らない）。docstring に 1 行足す: `testpaths is bypassed with an explicit "." so norecursedirs stays under test (REQ-394).`

変更 3: ファイル末尾（`test_docs_logs_has_no_tracked_files` の後）に次の 2 テストを追加する（`pytest.ini` を読む既存の `ROOT_INI`・`_write`・`_collect` を使う）:

```python
@pytest.mark.parametrize("_case", [pytest.param(None, id="[REQ-394/AC-3]-testpaths-declared")])
def test_root_pytest_ini_declares_testpaths_for_backend_and_tests(_case: None) -> None:
    """[REQ-394/AC-3] The root ini limits a no-argument run to backend/tests and tests."""
    parser = configparser.ConfigParser(interpolation=None)
    assert parser.read(ROOT_INI, encoding="utf-8"), f"missing {ROOT_INI}"
    assert parser.get("pytest", "testpaths").split() == ["backend/tests", "tests"]


@pytest.mark.parametrize(
    "with_testpaths",
    [
        pytest.param(True, id="[REQ-394/AC-3]-with-testpaths"),
        pytest.param(False, id="[REQ-394/AC-3]-control-without-testpaths"),
    ],
)
def test_collection_without_args_skips_db_docs_frontend_dirs(tmp_path: Path, with_testpaths: bool) -> None:
    """[REQ-394/AC-3] Same-basename tests under db/, docs/, frontend/ are not walked; the control collides."""
    ini = ROOT_INI.read_text(encoding="utf-8")
    if not with_testpaths:
        ini = "\n".join(l for l in ini.splitlines() if not l.lstrip().startswith("testpaths")) + "\n"
    (tmp_path / "pytest.ini").write_text(ini, encoding="utf-8", newline="\n")
    _write(tmp_path / "tests" / "test_dup.py")
    for scanned in ("db/cache", "docs/notes", "frontend/e2e"):
        _write(tmp_path / scanned / "test_dup.py")
    proc = _collect(tmp_path)
    out = (proc.stdout + proc.stderr).replace("\\", "/")
    if with_testpaths:
        assert proc.returncode == 0, out
        assert "tests/test_dup.py::test_probe" in out
        assert "db/" not in out and "docs/" not in out and "frontend/" not in out
        assert "1 test collected" in out
    else:
        assert proc.returncode != 0, out  # control: duplicate basenames collide without testpaths
```

BE の収集件数は 774 → 777（本 Card の新規 3 件: 上記 1 + 2）。
