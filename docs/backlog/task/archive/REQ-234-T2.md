# Task: REQ-234-T2 フロントエンド パッケージ導入 & Vitest 隔離環境強化

## 1. 概要
フロントエンドの `package.json` に `msw` (Mock Service Worker v2) および `fast-check` を `devDependencies` として追加しインストールする。また `frontend/vite.config.ts` の Vitest 設定に環境隔離（`isolate: true`）、スパイ自動リストア（`restoreMocks: true`）、コール履歴クリア（`clearMocks: true`）、モック実装リセット（`mockReset: true`）を設定してテスト間の状態汚染を排除する。

## 2. 対象ファイル (最大3ファイル)
- `frontend/package.json` [MODIFY]
- `frontend/vite.config.ts` [MODIFY]

## 3. 密閉コンテキスト (Hermetic Context)
<hermetic_context>

### 3.1 `frontend/package.json` 追加内容
`devDependencies` 内に以下を追加する:
```json
"devDependencies": {
  "fast-check": "^3.18.0",
  "msw": "^2.3.0"
}
```

### 3.2 `frontend/vite.config.ts` 設定変更仕様
現行の `test` ブロック:
```typescript
  test: {
    globals: true,
    environment: 'jsdom',
    setupFiles: './src/test/setup.ts',
  },
```
変更後の `test` ブロック:
```typescript
  test: {
    globals: true,
    environment: 'jsdom',
    setupFiles: './src/test/setup.ts',
    isolate: true,        // テストファイルごとの完全プロセス/環境分離
    restoreMocks: true,   // vi.spyOn をテストごとに自動リストア
    clearMocks: true,     // モックの呼び出し履歴を自動クリア
    mockReset: true,      // モックの実装を自動リセット
  },
```
</hermetic_context>

## 4. 実装要件 (Implementation Logic)
- [x] `frontend/package.json` の `devDependencies` に `"msw": "^2.3.0"` および `"fast-check": "^3.18.0"` を追加する。
- [x] `npm --prefix frontend install` を実行し、パッケージをインストールする。
- [x] `frontend/vite.config.ts` の `test` 設定に `isolate: true`, `restoreMocks: true`, `clearMocks: true`, `mockReset: true` を追加する。
