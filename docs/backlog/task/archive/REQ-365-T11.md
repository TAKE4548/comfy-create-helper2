## 変更内容
1. 単一state（`logService/logContent/logFilename/logMessage/loadingLogs/logsOpen`）を **サービス別state** に置換:
```ts
type LogPanel = { open: boolean; loading: boolean; filename: string; content: string; message: string }
const [logPanels, setLogPanels] = useState<Record<ManagerServiceName, LogPanel>>(initialPanels)
const toggleLog = (service: ManagerServiceName) => { /* 開く時のみ loadLogs(service)。閉じる時は取得しない */ }
```
   Managerが利用不可（`!managerAvailable`）のとき、ログボタンは `disabled`、パネルには `ログ表示は利用できません。` を表示。
2. 「サービス状態」を **行リスト**（`ul`）に再構成。行順: Supervisor(`manager`) / Windows Backend(`backend`) / ComfyUI(`comfy`) / Frontend(`frontend`)。既存の `aria-label`（`Supervisor`, `Windows Backend`, `ComfyUI`）と表示文言（`接続中`/`不明`、`Backend: 稼働中` 等）は維持。各行:
```tsx
<li aria-label="ComfyUI" className="rounded-lg border ...">
  <div className="flex items-center gap-2">
    <span role="img" aria-label={`死活: ${state}`} className="h-2.5 w-2.5 shrink-0 rounded-full bg-emerald-400|bg-zinc-500|bg-rose-400" />
    <span className="min-w-0 flex-1 truncate text-sm" title="ComfyUI">ComfyUI</span>
    <span className="shrink-0 whitespace-nowrap text-xs">{processStatus(...)}</span>
    <button type="button" aria-expanded={panel.open} aria-controls={`service-log-${service}`} disabled={!managerAvailable}
      onClick={() => toggleLog(service)} className="relative min-h-11 min-w-11 touch-manipulation before:absolute before:-inset-2 before:content-['']">ログ {panel.open ? '▲' : '▼'}</button>
  </div>
  {panel.open && <div id={`service-log-${service}`} role="region" aria-label={`${label} のログ`} className="mt-2"> {filename} {message(role=status)} <pre aria-label="サービスログ内容" className="max-h-64 overflow-auto overscroll-contain whitespace-pre-wrap break-words ..."/> </div>}
</li>
```
   ログパネルは **対象行の直下**（同一`li`内）にインライン展開。複数同時展開可。`pre` に `aria-label="サービスログ内容"` は残すが複数開く場合は `aria-label={`${label} のログ内容`}` とし、既存テストは `getByLabelText` を行内スコープ（`within`）に更新。
3. 旧 `<details>サービスログ` ブロック、`select#manager-log-service`、`最新ログを表示` ボタンは撤去し、各パネル内に `再取得`（`aria-label="${label} のログを再取得"`）ボタンを置く（取得失敗後のリトライ用）。
4. ログ取得失敗時は `ログを取得できませんでした: ...` を `role="status"` で表示（重要情報のため`truncate`しない）。
