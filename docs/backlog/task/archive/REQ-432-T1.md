# REQ-432-T1: VRAMガード判定ロジックと ComfyUI stats 取得

## 1. 概要と目的
生成後に ComfyUI が保持する VRAM（自セッション残留）だけを理由に生成が無期限で待機する不具合を解消するため、判定用空き容量を ComfyUI `/system_stats` から算出する。PDH の VRAM 使用量を primary LUID のアダプタに限定し、呼び出しのたびに新規にサンプリングする API を追加する。

確定事実（実機計測 2026-11-16）: 生成後の残留約 7GB は ComfyUI 自身（WSL2 の `vmwp.exe`）である。`/free` 後、ComfyUI の free は即時に回復するが、PDH は約 12 秒遅れる。2 枚目のアダプタは 0MB。

## 4. 共有契約（実装必須シグネチャ）

### C1: 判定ロジック（`resource_monitor.py` モジュールレベル、純粋関数）
```python
from dataclasses import dataclass
from typing import Any, Iterable, Literal

HoldReason = Literal["external", "unattributed"]
MeasureSource = Literal["comfyui", "host"]

@dataclass(frozen=True)
class ComfyVramSnapshot:
    vram_total_bytes: int        # devices[0].vram_total (T)
    vram_free_bytes: int         # devices[0].vram_free (F)
    torch_reserved_bytes: int    # devices[0].torch_vram_total (R)
    torch_free_bytes: int        # devices[0].torch_vram_free (Rf)

@dataclass(frozen=True)
class VramGuardDecision:
    safe: bool
    guard_free_gb: float | None
    own_residual_gb: float | None
    hold_reason: HoldReason | None   # None iff safe
    source: MeasureSource | None     # None iff comfy and host both unavailable

def parse_comfy_system_stats(payload: Any) -> ComfyVramSnapshot | None: ...
def evaluate_vram_guard(*, guard_enabled: bool, min_free_gb: float,
                        host_free_gb: float | None,
                        comfy: ComfyVramSnapshot | None) -> VramGuardDecision: ...
```
- `parse`: `payload["devices"][0]` の 4 フィールドを使う。次の場合は `None` を返す: payload が dict でない、devices が空または list でない、値が bool・非数値・非有限（NaN/Infinity）・負値、`T <= 0`、`F > T`、`Rf > R`。例外を送出しない。
- `evaluate`（GiB = bytes / 1024**3、小数第 2 位で丸め）:
  - comfy あり: `guard_free = clamp((F - Rf) + R, 0, T)`、`own_residual = R`、`source="comfyui"`。不足時の理由は `"external"`。
  - comfy なし・host あり: `guard_free = host_free_gb`、`own_residual=None`、`source="host"`。不足時の理由は `"unattributed"`。
  - 両方なし: `safe=True`、各値 `None`、`source=None`（従来の「判定不能では保留しない」）。
  - `safe = (not guard_enabled) or guard_free >= min_free_gb`。境界の等号は safe。`hold_reason` は `not safe` のときだけ設定する。
- 計測 B 点の期待値: T=16GiB, F=6.76GiB, R=7.216GiB, Rf=0.2GiB, min=6.0 → safe=True, guard_free≈13.78。

### C2: primary LUID 合算（モジュールレベル、純粋関数）
```python
def sum_adapter_dedicated_usage(samples: Iterable[tuple[str, float]],
                                primary_luid_hex: str | None) -> float: ...
```
- `primary_luid_hex` の形式は既存 L116 の `"0x{High:08x}_0x{Low:08x}"`（小文字）。インスタンス名例: `luid_0x00000000_0x0000d1b5_phys_0`。
- 小文字化した名前に `f"luid_{primary_luid_hex}_"` を含むものだけを合算する（同一 LUID の複数 `phys_N` は合算）。
- `primary_luid_hex is None`、または一致 0 件 → 全サンプルを合算する（安全側）。一致 0 件で 0 を返してはならない。
- `WindowsGpuMonitor` は DLL 読み出しを I/O 専用メソッド `_read_counter_items(self, h_counter, fmt) -> list[tuple[str, float]]` に分離する（`CStatus == 0` の項目だけ返す。失敗時は `[]`）。`collect()` の VRAM は `sum_adapter_dedicated_usage(self._read_counter_items(self._h_vram, self.PDH_FMT_LARGE), self.primary_luid_hex)` で算出する。`_get_engine_max` の挙動は変えない（必要なら同じ I/O メソッドを使ってよい）。

### C3: `ComfyGenerationBridge.system_stats`
```python
async def system_stats(self) -> dict[str, Any] | None:
```

### C4: `SYSTEM_STATS`（`_collect()` の返却 dict）への追加キー
既存キーはすべて維持する。`vram_free_gb` = ホスト空き（primary 限定）で意味は不変。`vram_used_gb` と `vram_pct` も primary 限定値になる。

| `vram_hold_reason` | `decision.hold_reason`（`"external"`/`"unattributed"`/`None`） |

### C5: `ResourceMonitorService`
```python
def configure_comfy_stats(self, provider: Callable[[], Awaitable[dict[str, Any] | None]] | None) -> None: ...
async def sample_guard_status(self) -> dict[str, Any]: ...
```
- `sample_guard_status` は呼び出しのたびに `await self._get_gpu_stats()`（ホスト I/O の新規収集）と provider（`asyncio.wait_for(..., timeout=1.0)`、例外・timeout は `None`）を実行し、`parse` → `evaluate` を行う。キャッシュ `_last_*` を判定に使わない（更新だけ行う）。
- 返却キー: `vram_guard_enabled`, `vram_min_free_gb`, `vram_free_gb`, `vram_total_gb`, `vram_guard_free_gb`, `vram_own_residual_gb`, `vram_hold_reason`, `vram_measure_source`, `vram_safe`。

- `_run()` の `VRAM_RECOVERED` 判定は `data["vram_safe"]` のまま（意味だけが C1 に変わる）。

```python
        def collect(self) -> tuple:
            if not self._initialized or self._pdh is None:
                return (None, None, self.vram_total_gb, None)
            try:
                self._pdh.PdhCollectQueryData(self._h_query)
```
