# Task REQ-376-T1: LoRA一覧カードのモバイル表示改善と縦スクロール一本化

## 1. 目的とスコープ
`frontend/src/pages/LoRAsPage.tsx` において、モバイル（幅767px以下）表示時の一覧カードを改修し、下部情報を「①タイトル」「②Description」「③対象Base Model」の3項目に整理、カード内部の独立スクロールを撤去してページ縦スクロールに統合する。また、編集・削除ボタンのタップ領域重複解消、サムネイル画像の中央配置、Stickyカテゴリ見出しの空隙解消を行う。デスクトップ表示（幅768px以上）は従来仕様を完全維持する。

## 2. 担当ファイル
- `frontend/src/pages/LoRAsPage.tsx` (実装対象)
- `frontend/src/pages/__tests__/LoRAsPage.test.tsx` (単体・統合テスト)
- `frontend/src/pages/__tests__/AssetCardInteractions.test.tsx` (操作・タップ領域テスト)

## 3. UIアーキタイプ分類と外科的制約
- **Archetype 2: Tabs / Chips / Grids (カードグリッド・サムネイル)**
  - 制約: カード高 `h-[320px] min-h-[320px] max-h-[320px]` 固定。
  - 制約: モバイル下部情報領域は `overflow-hidden`（内部スクロールの完全撤去）。
  - 制約: タイトル `line-clamp-2 break-words`、説明 `line-clamp-2 break-words`、Base Model `truncate whitespace-nowrap mt-auto`。
  - 制約: 11pxフロア準拠（最小フォントサイズ11px：`text-[11px]`）。
- **Archetype 3: Forms & Controls (操作ボタン)**
  - 制約: 編集・削除ボタンは `min-h-[44px] min-w-[44px] flex items-center justify-center`。
  - 制約: モバイル時、削除は `top-1 right-1`、編集は `top-1 right-[50px]` に配置し重なりを防止。PC時は `md:top-2 md:right-2` と `md:top-2 md:right-8`（`md:min-h-0 md:min-w-0 md:p-1`）に復帰。
- **Archetype 4: Shell & Page Layout (スクロールコンテナ・Sticky見出し)**
  - 制約: スクロールコンテナは `pt-0 md:pt-5`（Sticky見出し上端密着）。
