## Implementation Logic

- [ ] A/Bサムネload成功、initial present、history更新でA missing/B present。A非表示/B保持。
- [ ] missing後別選択/rerender/filter/sort/layout再mount/history更新。AのAPI/主原画要求増分0。
- [ ] cache seed、真のpage remountで初期確認。settle後Aなし、反復なし。
- [ ] thumbnail404のみ/503/通信例外/timeout=unknownで保持、自動増分0、明示retry1。
- [ ] localStorage.removeItem、metadata delete、Snapshot query mutationをspyして0。BE bytes保持は既存pytestを実行。
- [ ] Snapshot同URLで画像/params/query深い等価、branch probe0。
- [ ] 200行、Observer需要2行で初期2identity、active<=2。race/最後の1件は局所test証拠も参照。
