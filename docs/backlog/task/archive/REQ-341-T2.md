# REQ-341-T2: 共通PageHeader基盤・レスポンシブ2段レイアウト実装

## 1. 概要と目的
全画面の共通骨格となる `PageHeader.tsx` を改修し、PCデスクトップでの50px固定高さ・共通タイポグラフィ・アイコン規格、左クラスタリング用コンテナ、右クラスタ（ResourceHoverMonitor ＋ HeaderKebabMenu）の統合、およびモバイル（幅 < 768px）での2段レイアウト（1段目: タイトル省略 + 7px発光ドット + スライド展開ピル + 縦3点 / 2段目: 横スクロール可能アクションバー）を完結させる。
AC-1（全6画面共通50pxヘッダー・デザイン統一）、AC-7（モバイル2段レイアウト・7px発光ドット）を担保する。

## 4. 実装要件 (Implementation Logic)
- [ ] `PageHeader.tsx`:
  - デスクトップ表示（md以上 / width >= 768px）:
    - 高さ `h-[50px]` 固定、背景 `bg-surface` (`#18181C`)、下線 `border-b border-[rgba(255,255,255,0.06)]`、パディング `px-4 sm:px-5`。
    - 左クラスタ: アイコン（16px, `text-zinc-400 flex-shrink-0`）、タイトル（`text-sm font-semibold text-zinc-200 whitespace-nowrap`）、スリム状態バッジ（`variant="slim"`）、件数バッジ（`badge`）、垂直区切り線（`w-px h-4 bg-white/10 shrink-0`）、左クラスタリング主要アクション（`actions`）。
    - 右クラスタ: `ResourceHoverMonitor` ＋ 垂直区切り線（`w-px h-4 bg-white/10 shrink-0`） ＋ `HeaderKebabMenu` を配置（`ml-auto flex items-center gap-2.5 shrink-0`）。
  - モバイル表示（md未満 / width < 768px）:
    - 2段構成レイアウトを提供:
      - 1段目: アイコン ＋ タイトル（`truncate min-w-0`） ＋ 7px発光ドット（`variant="dot"`） ＋ 件数バッジ、右端に `ResourceHoverMonitor`（スライド展開ピル）と `HeaderKebabMenu`。
      - 2段目: `actions` を横スクロール可能なバー（`overflow-x-auto scrollbar-none flex items-center gap-2 py-1.5 px-4`）として展開。
  - 画面遷移時の垂直方向のガタつき・レイアウトシフト（CLS）を 0 に抑止する固定高さ設計。
- [ ] `PageHeader.test.tsx`:
  - 50px 固定高さクラスの存在、左クラスタへの actions 描画、右クラスタ（ResourceHoverMonitor, HeaderKebabMenu）の描画、およびモバイルビューでの2段構成要素の存在を検証。
