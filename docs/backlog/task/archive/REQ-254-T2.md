# REQ-254-T2: ワークフロー退避用履歴テーブルとDBマイグレーション

## 1. 目的とスコープ
ワークフロー置換直前の状態（`json_body` および `mappings`）を安全に退避し、操作ミス時の即時復元（ロールバック）を可能にする `WorkflowHistory` モデルと SQLite マイグレーションステップ（`step_011`）を定義・実装する。

## 2. 変更対象ファイル
- `backend/app/models.py` [MODIFY]: `WorkflowHistory` モデル定義、`Workflow` へのリレーション追加
- `backend/app/migrations/steps.py` [MODIFY]: `step_011_create_workflow_history` ステップ追加
- `backend/tests/test_workflow_history_migration.py` [NEW]: マイグレーション適用とモデル CRUD、カスケード削除の検証

## 3. 技術仕様とコードスニペット

### `backend/app/models.py`
```python
class WorkflowHistory(Base):
    __tablename__ = "workflow_history"

    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    workflow_id: Mapped[int] = mapped_column(ForeignKey("workflows.id", ondelete="CASCADE"), nullable=False)
    json_body: Mapped[str] = mapped_column(Text, nullable=False)
    mappings: Mapped[str] = mapped_column(Text, nullable=False)  # JSON array: [{"master_id": 1, "node_id": "6"}]
    created_at: Mapped[datetime] = mapped_column(DateTime, default=utc_now)

    workflow: Mapped["Workflow"] = relationship(back_populates="history_entries")

# Workflow モデル側に追加
history_entries: Mapped[list["WorkflowHistory"]] = relationship(
    back_populates="workflow", cascade="all, delete-orphan", order_by="desc(WorkflowHistory.created_at)"
)
```

### `backend/app/migrations/steps.py`
```python
def step_011_create_workflow_history(conn: Connection, inspector: any) -> None:
    if "workflow_history" not in inspector.get_table_names():
        conn.execute(sa.text("""
            CREATE TABLE workflow_history (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                workflow_id INTEGER NOT NULL REFERENCES workflows(id) ON DELETE CASCADE,
                json_body TEXT NOT NULL,
                mappings TEXT NOT NULL,
                created_at DATETIME DEFAULT CURRENT_TIMESTAMP
            )
        """))
        logger.info("Migrated: Created 'workflow_history' table.")

# ALL_MIGRATION_STEPS に追加
MigrationStep("011", "create_workflow_history", step_011_create_workflow_history),
```
