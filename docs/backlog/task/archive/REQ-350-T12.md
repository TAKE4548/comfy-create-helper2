# REQ-350-T12: ParamPanelのlegacy Seed表示テストとfloat欄の境界を検証する

## Scope

T5はlegacy global Seed行をnonseed `Sampler_Seed` mappingがある場合だけ表示する。既存の「全セクション展開」テストはそのmappingを持たないfixtureでSeed行を期待しており、旧仕様の前提が残っている。該当fixtureにlegacy `Sampler_Seed` mappingと値を追加し、global Seed行の既存表示・回帰を正しい入力条件で検証する。さらに同じParamPanelのテストファイルで専用`seed`欄が操作を表示し、float CFG欄にSeedトグルを追加しないことをテストする。専用seedのみの場合にglobal行が出ないことはT9の統合E2Eでカバーする。
