### 2.2 プロンプト操作補助関数 (Zustandストア内またはモジュールスコープ)
```typescript
export function removeAssetFromPrompt(prompt: string, tags: string[], loraPromptString?: string): string {
  let chips = prompt.split(',').map(c => c.trim()).filter(Boolean);
  const tagsToRemove = new Set(tags.map(t => t.toLowerCase()));
  if (loraPromptString) {
    tagsToRemove.add(loraPromptString.toLowerCase());
    const match = loraPromptString.match(/<lora:([^:]+):/i);
    if (match) {
      const baseLoraPrefix = `<lora:${match[1]}:`.toLowerCase();
      chips = chips.filter(chip => {
        const lowerChip = chip.toLowerCase();
        return !(lowerChip.startsWith(baseLoraPrefix) && lowerChip.endsWith('>'));
      });
    }
  }
  chips = chips.filter(chip => !tagsToRemove.has(chip.toLowerCase()));
  return chips.join(', ');
}

export function addAssetToPrompt(prompt: string, tags: string[], loraPromptString?: string): string {
  const currentVal = prompt || '';
  const tagsToAdd = [...tags];
  if (loraPromptString) {
    tagsToAdd.push(loraPromptString);
  }
  const toAddStr = tagsToAdd.join(', ');
  if (!currentVal) return toAddStr;
  return `${currentVal}, ${toAddStr}`;
}
```

## 3. 実装要件 (Implementation Logic)

### 3.1 `useGenerationStore.ts` のアクション書き換え
1. **`addAppliedAsset`**
   - 新しいアセットを `appliedAssets[role]` に登録する際、そのアセットの `tags`（および `loraPromptString` が存在する場合はそれも）を `paramValues[role]` にカンマ区切りで追加します。
2. **`removeAppliedAsset`**
   - アセットを削除する際、そのアセットが `enabled` であった場合は、`removeAssetFromPrompt` を使用して `paramValues[role]` から対応するタグおよび LoRA 埋め込み文字列を除去します。
3. **`toggleAppliedAsset`**
   - 有効から無効に切り替える際：`removeAssetFromPrompt` を呼び出して `paramValues[role]` から除去。
   - 無効から有効に切り替える際：`addAssetToPrompt` を呼び出して `paramValues[role]` に再追加。

### 3.2 `GeneratePage.tsx` の更新
1. **`handleGenerate` 内の文字列結合処理の廃止**
   - `textarea` 型のインプット処理において、アセットとの自動結合を廃止し、`paramValues[m.role]` の値をそのまま `val` として扱うように修正。
2. **LoRAトリガーセット選択モーダルの実装**
   - 状態変数 `selectedLoraForModal` (型 `{ role: string, lora: Lora } | null`)、`selectedTriggerSetId` (型 `number | 'default'`)、`loraStrength` (型 `number`) を追加。
   - `Add Asset` 内で LoRA をクリックした際、`handleAddLoraAsset` を即座に呼ぶのではなく、`selectedLoraForModal` にセットしてモーダルを表示する。
   - モーダルでは、選択された LoRA に関連する `trigger_word_sets` が存在すればリスト表示し、なければ「トリガーワードなし（デフォルト）」のみを提示。
   - 強度設定はスライダーおよび数値入力フィールドで `0.0` 〜 `2.0`（0.1刻み）で調節可能にする（初期値は LoRA の推奨強度範囲の中間値、またはデフォルト `1.0`）。
   - モーダルで「適用」をクリックした際、選択されたトリガーセットの言葉と強度を反映した `loraPromptString` (`<lora:filename:strength>`) を算出し、`handleAddLoraAsset` を呼び出してモーダルを閉じる。
