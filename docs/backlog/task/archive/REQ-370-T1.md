# REQ-370-T1: connectionSlice スナップショット全成功ジョブの包括マージと loadSnapshot 公開

## 1. 概要と目的
初回ロード時や HTTP 再同期（`loadSnapshot` / epoch 変更時）において、状態遷移イベントを経由していない既完了ジョブが `mergeManagedHistory` に渡されず履歴から脱落する不具合を解消するため、`connectionSlice.ts` の `applyGenerationSnapshot` でスナップショット内の全 `status === 'succeeded'` ジョブを対象にマージを実行する。また、外部 Hook からスナップショット再同期を明示要求できるよう `loadSnapshot` を `ConnectionActions` へ公開する。

## 3. 実装制約と設計上の注意事項
- `notifyTransitions` は変更しないこと（リアルタイム完了トーストや autoFollow の発火条件を維持する）。
- `mergeManagedHistory` 内の `imageIdentity` 重複排除およびシグネチャ一致スキップ（L131-133）により不要な再レンダリングや重複は発生しない。
- `loadSnapshot` は `createConnectionSlice` の戻り値オブジェクトに含めて外部公開すること。
