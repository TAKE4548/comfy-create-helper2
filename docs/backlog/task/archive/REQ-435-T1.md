# REQ-435-T1: プリセットタブのメニュー統合・モバイルHit-Slop・Desktopコンパクト化

> 本 Task Card は本タスクの唯一の意味仕様書（sole semantic specification）である。実装時の追加調査が必要な場合は dev-task の有界調査規則に従い、未解決事項は推測せずエスカレーションすること。

## 1. 概要と目的
`PresetTabItem` の操作ボタン（ellipsis と 閉じる `×`）を単一の統合ボタンへ集約し、Mobile では `data-tap-target-exempt` + Hit-Slop で視覚外形をスリム化しつつ ≥44×44px 非重複タップ領域を保証、Desktop（768px 以上）ではモバイル最小寸法（`min-h-11 min-w-11`）を除去する。`PresetTabCloseMenu` の先頭に「このタブを閉じる」を追加し、既存の一括クローズ（REQ-402）と単件クローズを同一メニューへ統合する。

## 2. ターゲット識別（Impacted Files）
- `frontend/src/pages/GeneratePage/components/PresetTabItem.tsx`（L1–97）
- `frontend/src/pages/GeneratePage/components/PresetTabCloseMenu.tsx`（L1–109）
- `frontend/src/pages/GeneratePage/hooks/__tests__/usePresetTabClose.integration.test.tsx`

## 3. UI アーキタイプと外科的制約
<constraints>
- **Archetype**: `Archetype 2: Tabs / Chips / Grids`（`PresetTabItem`）+ `Archetype 1: Modals & Overlays`（`PresetTabCloseMenu`）
- **Hit-Slop (Mobile <768px)**: `data-tap-target-exempt` + `relative touch-manipulation before:absolute before:content-[''] before:-inset-2 md:before:hidden`（`h-7 w-7` 28px + 16px = 44×44px）
- **隣接非重複 (AC-2)**: タブ内部コンテナを `gap-4 md:gap-1` とし、Mobile で隣接 `before:-inset-2`（8+8=16px）の重なりを 0px にする
- **Desktop コンパクト化 (AC-3)**: 外枠 `h-8 py-0.5 md:h-7 md:py-0`（28px）、内部ボタン/チェック `h-7 md:h-6 md:w-6`（24px）、`min-h-11 min-w-11` を撤去
- **Truncation**: タブ名 `max-w-[140px] truncate text-left`、外枠 `min-w-0 shrink-0`
- **Gesture**: `style={{ touchAction: 'pan-x pan-y' }}` 維持、500ms 長押し＋8px 移動キャンセル＋解放クリック抑止維持
- **Focus**: `index.css` の `:focus-visible` アウトラインを阻害しない（`focus:outline-none` 禁止）
</constraints>

## 5. 実装要件
- [ ] `PresetTabItem.tsx`:
  - 独立した閉じる（`×`）ボタン（L94）と未使用の `X` import を削除し、操作ボタンを `data-preset-menu-trigger` の 1 ボタンのみにする（AC-4）。
  - `onRemove` prop は T4/T5 との並行型整合のため `onRemove?: () => void` とする。
  - 外枠を `h-8 md:h-7 gap-4 md:gap-1 px-1.5 md:px-2 py-0.5 md:py-0` とし、選択ボタン・チェック `<label>`・統合メニューボタンに `data-tap-target-exempt` を付与。
  - 選択ボタン: `relative h-7 min-w-[32px] md:h-6 md:min-w-0 max-w-[140px] truncate text-left touch-manipulation before:absolute before:content-[''] before:-inset-x-1.5 before:-inset-y-2 md:before:hidden`。
  - チェック `<label>`・統合メニューボタン: `relative inline-flex h-7 w-7 md:h-6 md:w-6 shrink-0 items-center justify-center touch-manipulation before:absolute before:content-[''] before:-inset-2 md:before:hidden`。
  - 統合ボタンタップ、右クリック、500ms 長押しすべてで `onOpenMenu` を呼び、開くだけでは `onSelect` を呼ばない（AC-5）。
- [ ] `PresetTabCloseMenu.tsx`:
  - `onCloseSingle?: () => void` を追加し、メニュー項目先頭に「このタブを閉じる」ボタンを配置（`disabled={pending}`）。クリック時は `onCloseSingle?.()` を呼ぶ（AC-6）。
  - 続けて既存の一括クローズ 3 項目（「左のタブをすべて閉じる」「右のタブをすべて閉じる」「他のタブを閉じる」）を配置し、`createPresetTabClosePlan` と REQ-402 の対象集合・失敗挙動を完全維持する（AC-6）。
  - `items` ref 配列および Desktop キーボードナビ（`ArrowDown`/`ArrowUp`/`Home`/`End`）・初回フォーカス対象に「このタブを閉じる」（インデックス 0）を含める。
- [ ] `usePresetTabClose.integration.test.tsx`:
  - `[REQ-435/AC-4]`, `[REQ-435/AC-5]`, `[REQ-435/AC-6]` のテストケースを追加（単一ボタン確認、3 入口同一メニュー＆選択不変、「このタブを閉じる」実行＋一括クローズ・503/409 失敗保持回帰）。
