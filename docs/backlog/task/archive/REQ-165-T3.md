### REQ-165-T3: フロントエンド翻訳モーダルコンポーネント実装および既存自動上書きロジックのクリーンアップ

#### 目的
新しい翻訳モーダルコンポーネント `PromptTranslationModal.tsx` を実装し、英→日確認プレビューおよび日→英自由入力・手動反映（追記/上書き）UIを提供する。また、`DesktopLayout.tsx` および `useGeneratePageState.ts` から従来のデバウンス自動翻訳・自動上書きロジックを完全に除去し、安全な設計へ刷新する。

#### 対象ファイル
1. `frontend/src/pages/GeneratePage/components/PromptTranslationModal.tsx` (NEW)
2. `frontend/src/pages/GeneratePage/components/DesktopLayout.tsx` (MODIFY)
3. `frontend/src/pages/GeneratePage/hooks/useGeneratePageState.ts` (MODIFY)

#### 完全な型定義・スキーマ (Complete Context Types & Schemas)

```typescript
export interface PromptTranslationModalProps {
  isOpen: boolean;
  onClose: () => void;
  roleDisplayName: string;
  mode: 'en_to_ja' | 'ja_to_en';
  onModeChange: (mode: 'en_to_ja' | 'ja_to_en') => void;
  sourceText: string;
  onSourceTextChange: (text: string) => void;
  translatedText: string;
  meta: {
    total_chunks: number;
    cached_chunks: number;
    api_requested_chunks: number;
    billed_characters: number;
  } | null;
  isTranslating: boolean;
  error: string | null;
  onTranslate: () => void;
  onApply: (mode: 'append' | 'replace') => void;
}
```

#### 実装指示 (Implementation Steps)

1. **`PromptTranslationModal.tsx` の実装**:
   - ダイアログ/モーダル（またはフローティングポップアップ）として描画。
   - タブ切り替え:
     - 「英→日 確認」(`en_to_ja`):
       - 原文エリア: 対象ロールのプロンプトテキスト。
       - 「翻訳して確認」ボタン（ローディングインジケーター付き）。
       - 日本語プレビューボックス（`bg-surface-2 border border-zinc-700/50 p-3 rounded text-sm text-zinc-200`）。
       - コピーボタン。
     - 「日→英 作成・追記」(`ja_to_en`):
       - 日本語自由入力エリア: `textarea`。
       - 「英語へ翻訳」ボタン。
       - 英語プレビューボックス。
       - アクションボタン群:
         - 「末尾に追記」(`onApply('append')`) - `bg-accent-green text-black hover:bg-accent-green/80`
         - 「上書き反映」(`onApply('replace')`) - `bg-zinc-700 text-white hover:bg-zinc-600`
         - 「コピー」
   - フッター:
     - キャッシュメタデータ表示（例: `チャンク: 4 / キャッシュ済: 3 (API消費: 18文字)`）。

2. **`useGeneratePageState.ts` のクリーンアップとフック統合**:
   - 既存の `triggerTranslationJaToEn`, `triggerTranslationEnToJa`, `debounceTimerRef`, `translationJa`, `translationEn` の自動上書き・デバウンスコードを完全削除。
   - `usePromptTranslation` フックを呼び出し、必要なステートとハンドラーを `DesktopLayout` へ渡す。

3. **`DesktopLayout.tsx` の更新**:
   - 各プロンプト入力欄上部の「翻訳」ボタンクリックハンドラーを `promptTranslation.openTranslation(m.role!, paramValues[m.role!] || '')` に接続。
   - 既存のインラインドラッグウィンドウを削除し、`PromptTranslationModal` をマウント。
