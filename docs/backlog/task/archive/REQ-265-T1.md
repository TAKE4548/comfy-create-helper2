# REQ-265-T1: スナップショットプレビュー導線と復元状態分離のフック層実装

本カードは実装タスクの唯一の意味仕様であり、自己完結した技術契約・境界・検証手順を定義する。

## Delegation & Boundaries

- **責務・スコープ・完了条件 (D1)**:
  - `useGeneratePageModals.ts`: スナップショット復元モーダル開閉状態（`isSnapshotRestoreOpen`, `snapshotRestoreInitialId`, `openSnapshotRestoreModal`, `closeSnapshotRestoreModal`）を追加する。
  - `useGeneratePageState.ts`: `useGenerateKeyboardShortcuts` の `modalOpen` 条件に `modals.isSnapshotRestoreOpen` を含める。
  - `useGalleryInteraction.ts`: `onLoadSnapshot` を `onPreviewSnapshot?: (snapshotId: number) => void` に置き換え、`handleSnapshotClick(snapshotId)` が即時復元ではなくプレビューモーダル起動コールバックのみを呼ぶように分離する。
  - `useAssetSelectionState.ts`: `handleLoadSnapshot(id: number): Promise<boolean>` が成功時 `true`・失敗時 `false` を返すようにし、呼び出し元（モーダルの明示的復元アクション）が成功判定できるようにする。
  - 完了条件: `npm run typecheck` および対象 Vitest 単体テストが全件 PASS すること。
- **依存関係と理由 (D2)**: `depends_on: []`（他カードへの依存なし、T2 と並列実行可能）。
- **隣接カードの所有ファイル (D3)**:
  - `REQ-265-T2`: `SnapshotRestoreModal.tsx`, `SnapshotRestoreModal.test.tsx`
  - `REQ-265-T3`: `GenerationGallerySection.tsx`, `DesktopLayout.tsx`, `MobileLayout.tsx`, `GeneratePage.tsx`, `GenerationGallerySection.cache.test.tsx`, `generateSnapshotRestore.spec.ts`
- **共有契約 (D4)**:
  - `useGeneratePageModals` 返却値に `isSnapshotRestoreOpen: boolean`, `snapshotRestoreInitialId: number | null`, `openSnapshotRestoreModal: (initialSnapshotId?: number) => void`, `closeSnapshotRestoreModal: () => void` を追加。
  - `UseGalleryInteractionOptions.onPreviewSnapshot?: (snapshotId: number) => void`
  - `useAssetSelectionState.handleLoadSnapshot: (id: number) => Promise<boolean>`
- **AC と検証の対応 (D5)**:
  - `[REQ-265/AC-1]`: `useGalleryInteraction.test.ts` で `handleSnapshotClick` が `onPreviewSnapshot` のみを呼び、アクティブプリセット状態を変更しないことを検証。
  - `[REQ-265/AC-4]`: `useAssetSelectionState.test.ts` で `handleLoadSnapshot` が成功時 `true`、API 失敗時 `false` を返すことを検証。
- **Engineer 委譲範囲 (D6)**: `closeSnapshotRestoreModal` 時に `snapshotRestoreInitialId` を `null` リセットするか保持するかの内部状態整理。
- **変更禁止スコープ (D7)**:
  - `handleLoadSnapshot` 内部の `loadSnapshotParams` / LoRA / TagSet 再構築ロジック自体は変更しない。
  - `backend/`、レイアウト/ページ JSX ファイル、隣接カードの所有ファイルは編集しない。
  - テストファイル名にチケット番号（`req\d+`）を含めない。
