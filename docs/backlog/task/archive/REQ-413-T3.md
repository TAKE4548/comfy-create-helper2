# REQ-413-T3: マスタ無効化ステージバリアントの生成・表示除外に関するSSoT仕様書の同期

## 1. 概要と目的
マスタ側で無効化（`is_enabled = false`）されたステージバリアントの生成画面（ParamPanel/PromptPanel）および生成要求ペイロード（ComfyUI ワークフロー JSON）からの除外契約、ならびにステージグループ（`groupMappingsByStage`）および ParamSync 候補からの除外契約を、正本仕様書（`SPEC_GENERATE.md`, `SPEC_SETTINGS.md`）へ同期・明記する。

## 2. ターゲット識別
- **所有ファイル**:
  1. `docs/specs/SPEC_GENERATE.md`
  2. `docs/specs/SPEC_SETTINGS.md`
- **対象セクション**:
  - `docs/specs/SPEC_GENERATE.md` §2-5「### 2-5. パラメータ入力パネル (`ParamPanel.tsx`)」配下の「#### REQ-358 workflow mappingの無効化」、および §2-8「### 2-8. パラメータ同期グループ (`ParamSyncModal.tsx`)」
  - `docs/specs/SPEC_SETTINGS.md` §4-1-1「### 4-1-1. REQ-358 ノード候補とworkflow slot状態」

## 3. 実装要件 (Implementation Logic)
- [ ] 1. `docs/specs/SPEC_GENERATE.md`:
  - §2-5「#### REQ-358 workflow mappingの無効化」:
    - `generationWorkflow` による生成用マッピング選別において、ワークフロー個別の `mapping_slot_states`（明示 `false` の除外）に加え、マスタ側のステージバリアント有効フラグ（`variant.is_enabled !== false`、`SlotDefinition.variantEnabled` 経由）を評価する。マスタで無効化されたバリアント（`variantEnabled === false`）および全バリアントが無効なマスタのレガシーマッピング（`variant_id == null`）を生成用 `workflow.mappings` 配列から除外することを追記する。
    - これにより、パラメータ入力枠（ParamPanel）・プロンプト枠への表示および ComfyUI ワークフロー JSON へのパラメータ/プロンプト注入を遮断することを明記する。
    - 有効なバリアント（`variantEnabled !== false`）かつワークフロー個別で無効化されていないマッピングは正常に保持される契約を明記する。
    - DB 上の `workflow_mappings` レコード自体は削除せず保持し、マスタで再有効化された場合に即時復旧する契約を明記する。
  - §2-8「### 2-8. パラメータ同期グループ (`ParamSyncModal.tsx`)」:
    - `buildParamSyncCandidates` が `groupMappingsByStage` に基づき、マスタ側で `is_enabled === false` となっているステージバリアントのマッピングを同期先・代表候補から除外することを明記する。
- [ ] 2. `docs/specs/SPEC_SETTINGS.md`:
  - §4-1-1「### 4-1-1. REQ-358 ノード候補とworkflow slot状態」:
    - マスタ側で無効化されたステージバリアント（`MappingVariant.is_enabled === false`）は、リマッピング画面（`RescanModal`）での非表示に加え、ステージグループ分類（`groupMappingsByStage`）および ParamSync 候補生成（`buildParamSyncCandidates`）からも除外される契約を明記する。
    - REQ-419 で同期された 3層モデル（Variant/RuleSet/NodeSelector）の判定契約および既存の未割当スロット保持・孤立マッピング浄化規定と矛盾なく追記する。
    - DB 上の `workflow_mappings` レコード自体は削除せず保持し、マスタ側でバリアントが再有効化された場合には即座に復元・表示される契約を明記する。
