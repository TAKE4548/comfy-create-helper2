## 3. 実装要件 (Implementation Logic)
- [ ] **usePresetState.ts**:
  - `handleBulkEditApply` において、`payload.targetPresetIds` が指定されている場合はそれを対象ID集合として使用し、未指定の場合は `bulkTargetIds` を使用する（AC-4連携）。
  - 適用成功処理で `setIsBulkEditOpen(false)` と `setBulkTargetIds([])` を削除し、モーダルを開いたまま維持する（AC-3）。
  - 適用完了時に成功トースト `setErrorToast({ message: `${selectedPresets.length} 件のプリセットに適用しました`, type: 'success' })` を表示する。
  - 適用失敗時（APIエラー・例外発生時）はモーダルを閉じずに開いたまま維持し、エラー通知トーストを表示して再試行を可能にする。
- [ ] **ProfileBulkEditModal/index.tsx**:
  - `handleConfirm` を `async` 化し、`await onApply(pendingPayload)` を実行。成功後に `state.resetParamSelection()` を呼び出し、パラメータタブの選択状態（`enabledParams`, `batchSizeEnabled`）を未選択に自動初期化する（AC-2）。適用失敗時はパラメータリセットを行わず、ユーザーの入力・選択を保全する。
  - `useEffect` で `keydown` イベントリスナーを登録し、`e.key === 'Escape'` 押下時に `onClose()` を呼び出してモーダルを閉じる（AC-3）。ただし `showConfirm` やアセット追加モーダルが表示されている場合はそれらのクローズを優先し、モーダル本体の同時クローズを防ぐ。
