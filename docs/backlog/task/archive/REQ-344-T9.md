# REQ-344-T9: 未実施のtarget/受入

> **2026-10-13 superseded:** 原因確定と最小差分再設計により、このカードを再dispatchしない。
> 実施済み状態・当時の結果は履歴として保持。現在の実装/受入はREQ-344-T10〜T12を参照。
> このカードの未実施ゲートや原因外の修正を新計画へ継承しない。

## Scope and Gate

出力docs/design/REQ-344-environment-validation.md 1file/180行以下、生log/JSON別。
source/ACL/cache/config変更禁止。ほかの担当者の変更やT1-T6原本を戻さない。
T8 alternate focused正常完了/2case PASS/query証拠/warning0/env解除、
同metadata/context/cache安全性＋今回reviewの条件付き検証承認が全て必要。
T6のtarget/suite NOT-RUNはそのまま保持。受入条件は既定npm test連続5回target PASS。
実行contextを元contextの安定性証明と主張しない。

## Hermetic Context

T8 reportのNode/npm/npx source/version/cwd/source hash/context/cache gateを引継ぐ。
各開始前にT7のread-only metadata/cache確認を行い、一致がなければ停止。
depsがあればvite.configにchmod枝、deps_temp/metadata欠落でrm枝がある。
通常cache書込みの許可を推測しない。安全性不明ならtests NOT-RUNで親へ。
T5の診断flagは解除し、既定timeout/forks/pool/worker/retryを維持する。

## Single Target Command

同alternate permission context（review後のrequire_escalated予定）、wall120秒、1回のみ:
```powershell
Remove-Item Env:VITE_REQ344_QUERY_DIAGNOSTICS -ErrorAction SilentlyContinue
npx vitest run src/pages/__tests__/GeneratePage.test.tsx --reporter=verbose *> ../docs/design/REQ-344-environment-target.log
$req344EnvironmentTargetExit = $LASTEXITCODE
Get-Content -LiteralPath '../docs/design/REQ-344-environment-target.log' -Tail 35
exit $req344EnvironmentTargetExit

```

正常完了exit0/全件PASS/skipなし/警告・例外・collection障害なしがsuite gate。
EPERM/FAIL/期限/証拠不足ならバッチを追加せず親レビューへ。

## Acceptance Batch

同metadata/context/source、既定npm test最大5回/各wall600秒の1バッチ。
test planにloop記載。各開始前cache safetyを確認し不明なら停止する。
logはREQ-344-environment-suite-N.log、JSONはenvironment-suite-results.json。
EPERM/collection失敗/target FAIL/警告/未処理例外/期限/結果不明で停止。
失敗回を捨てず未実行はNOT-RUN。途中context変更や追加retryは禁止。
別fileのassertion FAILは全体Gate FAILとして対象ACと分け、親へ報告する。

## Output and Verification

reportにsource hashes/context/runtime/cwd/approval、target結果、
5行表/NOT-RUN、raw logs/exit/wall停止/collection/警告、
cache safety各run、未確定事項、親へ返す理由を記す。
5回target PASS＋環境gate＋追加修正不要の親判断だけがT4条件。
workspace root:
```powershell
Get-Content -LiteralPath 'docs/design/REQ-344-environment-suite-results.json' -Raw
rg -n 'context|cache|NOT-RUN|EPERM|INCONCLUSIVE|PASS|Next Decision' docs/design/REQ-344-environment-validation.md

```

JSONがないNOT-RUN phaseを捏造して補完しない。親がraw evidenceをレビューする。
