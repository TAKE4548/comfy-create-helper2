## 1. 目的とスコープ
ユーザーがブラウザタブへ復帰した際（`document.visibilityState === 'visible'` または `window.onfocus`）、非アクティブ中に切断された WebSocket を即座に能動再接続するリカバリー処理を追加する。

## 3. 対象コードスニペット (Target Code Snippet)
[`frontend/src/pages/GeneratePage/hooks/useGenerateDisplayState.ts` L234-L248](frontend/src/pages/GeneratePage/hooks/useGenerateDisplayState.ts#L234-L248):
```ts
  // Visibility / focus refresh
  useEffect(() => {
    const handleVisibility = () => {
      if (document.visibilityState === 'visible') {
        store.fetchQueue()
        store.fetchHistory()
      }
    }
    document.addEventListener('visibilitychange', handleVisibility)
    window.addEventListener('focus', handleVisibility)
    return () => {
      document.removeEventListener('visibilitychange', handleVisibility)
      window.removeEventListener('focus', handleVisibility)
    }
  }, [store])
```

---

## 4. 実装要件・手順
1. **`handleVisibility` ハンドラの拡張**:
   - `document.visibilityState === 'visible'` 時に、`!store.isConnected` であるかを判定。
   - `!store.isConnected` の場合、即座に `store.initialize({ force: true })` を呼び出し、WebSocket 接続の能動的再確立を開始する。
   - 既存の `store.fetchQueue()` および `store.fetchHistory()` はそのまま維持し、REST API で最新状態を取得する。
2. **多重呼び出し防御**:
   - `store.initialize({ force: true })` は `connectionSlice` 側のガードにより適切に管理されるため、イベント発火時に安全に実行可能。
