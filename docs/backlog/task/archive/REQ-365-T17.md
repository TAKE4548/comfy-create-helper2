2. **§1-4 共通Modal（追記）**: 共通Modalは既定でモバイルの最大高さを `calc(100dvh - safe-area-inset-top)` とし、利用側は `sheetMaxHeightClass` で上限（例: `max-h-[85dvh]`）を指定できる。上端ハンドル要素は `data-testid="modal-sheet-handle"` を持つ（テスト契約）。モーダルは相互に排他で、ネスト表示しない（list→form は閉じてから開く）。Settingsの管理系モーダル（カスタム型マスタ、BaseModelマスタ等）は共通Modal（ボトムシート）に統一する。上端角丸は16px（`rounded-t-2xl`）で、§1-3 の「上端12px」の記述と**矛盾しないよう数値を整合**させる（現行実装は `rounded-t-2xl` = 16px。差異があれば §1-3 の数値を実装に合わせて修正し、修正理由を1行で明記）。
