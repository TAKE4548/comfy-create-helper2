## 3. 実装要件 (Implementation Logic)
- [ ] **ParamBulkEditTab/index.tsx**:
  - ローカルステート `searchQuery` (`string`, 初期値 `''`) を定義。
  - パラメータ一覧の最上部に検索ボックス（`Search` アイコン、クリアボタン、プレースホルダー: `パラメータを検索... (名称・キー)`）を追加。
  - `searchQuery` によるフィルタリングロジックを実装：
    - `const query = searchQuery.trim().toLowerCase();`
    - `paramRoles` を `m.display_name.toLowerCase().includes(query) || m.role.toLowerCase().includes(query) || (m.param_name && m.param_name.toLowerCase().includes(query))` で絞り込み。
    - バッチサイズセクションの表示判定: `!query || 'バッチサイズ'.includes(query) || 'batch_size'.includes(query) || 'batch'.includes(query)`。
  - 絞り込み結果が0件かつバッチサイズも非該当の場合、「該当するパラメータが見つかりません」の空メッセージを表示。
  - 検索ボックス右端に、入力時のみ表示される「クリア」アイコン/ボタンを設置し、クリックで `setSearchQuery('')` を実行。
  - 検索フィルタによる表示/非表示は `enabledParams` の選択状態や適用ペイロード生成に一切影響を与えないことを保証（AC-6）。
