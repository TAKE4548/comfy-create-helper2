### 2.3 問題の本質
- React QueryのキャッシュはJSメモリ（heap）にのみ存在する
- モバイルOSはバックグラウンドタブをキルするため、毎回クリーンな状態からスタートする
- `gcTime` のデフォルト（5分）が過ぎると `workflow` キャッシュがメモリから削除される
- `PersistQueryClientProvider` + `createSyncStoragePersister` によりlocalStorageへ永続化することでリロード後も即復元できる

### 2.4 永続化するクエリ
| queryKey | 用途 |
|---|---|
| `['workflow', id]` | ワークフローJSON（最重要） |
| `['workflows']` | ワークフロー一覧 |
| `['workflow-presets', id]` | プリセット一覧 |
| `['loras']` | LoRA一覧 |
| `['base-models']` | ベースモデル一覧 |
| `['mapping-masters']` | マッピングマスタ |
| `['param-type-masters']` | パラメータ型マスタ |

### 2.5 永続化しないクエリ（除外）
| queryKey | 理由 |
|---|---|
| `comfy-object-info` | ComfyUI URL依存・URLが変わると無効になる |
| `snapshots` | 生成ごとに変化する動的データ |

### 2.6 テスト上の注意
- 既存のテストファイルで `QueryClientProvider` を直接使っている箇所はそのまま維持する
- `PersistQueryClientProvider` はテストで使用しない（App.tsx のみの変更）

  ```typescript
  import { QueryClient } from '@tanstack/react-query'
  import { PersistQueryClientProvider } from '@tanstack/react-query-persist-client'
  import { createSyncStoragePersister } from '@tanstack/query-sync-storage-persister'

  const queryClient = new QueryClient({
    defaultOptions: {
      queries: {
        retry: 1,
        staleTime: 30_000,
        gcTime: 1000 * 60 * 10, // 10分
      },
    },
  })

  const persister = createSyncStoragePersister({
    storage: window.localStorage,
    key: 'prompt-surgeon-rq-cache',
  })

  // JSX内:
  <PersistQueryClientProvider
    client={queryClient}
    persistOptions={{
      persister,
      maxAge: 1000 * 60 * 10, // 10分でキャッシュ無効化
      dehydrateOptions: {
        shouldDehydrateQuery: (query) => {
          const key = query.queryKey[0] as string
          const excluded = ['comfy-object-info', 'snapshots']
          return !excluded.includes(key)
        },
      },
    }}
  >
    ...
  </PersistQueryClientProvider>
  ```
