### 2.2 UIコンポーネント構成仕様 (`frontend/src/components/SpeechBubbleControls.tsx`)
1. **漫画演出設定アコーディオン / セクション (`MangaEffectsSection`)**:
   - `bubble.effects`（未定義時は `DEFAULT_MANGA_EFFECTS`）をベースに状態をバインド。
   - **タイポグラフィ & 縦中横**:
     - 字間スライダー (`letterSpacing`: -10 ~ 50px)
     - 行間スライダー (`lineHeightRatio`: 0.8 ~ 2.5)
     - シアー角度スライダー (`shearAngle`: -45° ~ 45°)
     - 縦書き時「`!?` 自動90度回転」ワンクリックボタン（テキスト内の `!?`, `!!`, `?!`, `!`, `?` の位置を検出し `rotate90Indices` に一括トグル登録）
     - 文字個別回転ピッカー（テキスト各文字のトグルボタン）
   - **ダイナミックスケール & 感情揺らぎ**:
     - スケールカーブ選択（なし / 線形変化 / イーズイン / イーズアウト / ベジェ）
     - 開始倍率 (`scaleStart`: 0.5 ~ 3.0)・終了倍率 (`scaleEnd`: 0.5 ~ 3.0)
     - サイズ揺らぎ (`sizeJitter`: 0 ~ 50%)
   - **パス・軌道レイアウト（固定ハンドル方式）**:
     - 軌道タイプ選択（`なし` / `直線 (2点)` / `円弧・アーチ (3点)` / `S字波 (4点)` / `階段 (2点)`）
     - 選択時に対応する初期制御点 `pathPoints`（2〜4点）を自動設定し、キャンバス上のハンドルドラッグで直感編集
     - 接線追従回転トグル (`pathFollowRotation`)
     - ガタつきオフセット (`baselineJitter`: 0 ~ 20px)
   - **カラー・塗り・グラデーション・トーン**:
     - 塗りモード (`solid`, `gradient`, `tone`, `hollow`)
     - グラデーション角度・開始色・終了色ピッカー
     - 網点パターン (`dots`, `noise`)
   - **多重フチ（多層アウトライン）**:
     - ストロークレイヤー一覧（追加・削除・並び替え）
     - レイヤーごとの線の太さ (`width`)、色 (`color`)、影オフセット (`offsetX`, `offsetY`)、角処理 (`lineJoin`)、破線 (`lineStyle`)、かすれ (`roughness`)
3. **自動サイズ調整との連携**:
   - `fontSize === 0` (自動フィット有効時) またはサイズ自動調整ボタン押下時、`calculateFitBubbleDimensions(text, fontSize, orientation, effects)` を呼び出して最新の演出パラメータ（字間・スケール・多重フチ・シアー）を反映した吹き出しサイズ `(w, h)` を計算し `onUpdate`。
