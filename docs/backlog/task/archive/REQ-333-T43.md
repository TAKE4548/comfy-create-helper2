# REQ-333-T43

version1 GenerationRecordのoptional `completed_at?: string | null`を追加する。BEは成功jobの実finished_atを記録。getMetadataViewが`completedAt`として返す。省略した旧recordも互換で有効。欠落/null/不正日時はnull扱い、他の記録済み項目を失わない。queued_at/metadata保存日時/画像保存日時から完了日時を推測しない。Snapshotのparam_values内recordも同じ解釈。

有効なlocal凍結recordでも完了日時が欠落/不正なら対応promptのremote metadataを照会し、prompt ID一致と有効なremote v1 recordの実completed_atだけをlocal recordのcopyへ補う。localの他params/seed/assets/workflow/queued_atは置き換えない。remote失敗/不正/ID不一致はlocalを保持。localに有効な完了日時があれば従来のlocal優先を維持して照会不要。
