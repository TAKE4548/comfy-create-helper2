### 2.1 既存の対象コード (`tools/server-manager/server_status.py` L24-L32)
```python
def check_port_listening(port: int, timeout: float = 0.5) -> bool:
    """ローカルポート（127.0.0.1）に TCP 接続可能かを判定する。"""
    try:
        with socket.create_connection(("127.0.0.1", port), timeout=timeout):
            return True
    except (socket.timeout, ConnectionRefusedError, OSError):
        return False
```

### 2.2 改修要件
1. `check_port_listening`:
   - `socket.create_connection(("127.0.0.1", port), timeout=timeout)` で接続成功後、`s.close()` の前に `s.shutdown(socket.SHUT_RDWR)` を呼び出す。
   - `shutdown` 時の `OSError`（相手が既に切断している等）は `except OSError: pass` で安全に握り潰す。
   - `finally` 句で確実に `s.close()` を実行する。
2. `tests/unit/test_server_status.py`:
   - `check_port_listening` が接続成功時に `shutdown` を実行していることを確認するテストを追加。
   - 既存の5件のテストが全件 PASS することを確認。
