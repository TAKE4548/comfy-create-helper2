## 確定インターフェース
```tsx
import type { AriaRole, ReactNode, RefObject } from 'react'
import type { HeaderMenuAlign } from './headerMenuPlacement'

export interface HeaderDropdownProps {
  open: boolean
  onClose: () => void
  anchorRef: RefObject<HTMLElement | null>   // トリガーを含むラッパー。内側判定とrect基準
  align?: HeaderMenuAlign                    // default 'start'
  role?: AriaRole
  className?: string                         // 見た目(幅/背景/枠/padding/animation)のみ。位置・高さ・z-indexは持たせない
  'data-testid'?: string
  children: ReactNode
}
export function HeaderDropdown(props: HeaderDropdownProps): React.JSX.Element | null
```

## 実装要件（骨子。細部はこのカード内の契約で実装する）
```tsx
export function HeaderDropdown({ open, onClose, anchorRef, align = 'start', role, className = '',
  'data-testid': testId, children }: HeaderDropdownProps) {
  const panelRef = useRef<HTMLDivElement>(null)
  const onCloseRef = useRef(onClose)
  onCloseRef.current = onClose
  const [pos, setPos] = useState<{ top: number; left: number; maxHeight: number } | null>(null)

  useLayoutEffect(() => {
    if (!open) { setPos(null); return }
    const measure = () => {
      const anchor = anchorRef.current, panel = panelRef.current
      if (!anchor || !panel) return
      const vv = window.visualViewport
      const p = computeHeaderMenuPlacement({
        anchor: anchor.getBoundingClientRect(), panelWidth: panel.offsetWidth, align,
        viewport: { width: vv?.width ?? window.innerWidth, height: vv?.height ?? window.innerHeight },
      })
      if (p.shouldClose) { onCloseRef.current(); return }
      setPos((prev) => prev && prev.top === p.top && prev.left === p.left && prev.maxHeight === p.maxHeight
        ? prev : { top: p.top, left: p.left, maxHeight: p.maxHeight })
    }
    measure()
    window.addEventListener('resize', measure)
    window.addEventListener('scroll', measure, true)      // capture: 祖先スクロール容器も拾う
    window.visualViewport?.addEventListener('resize', measure)
    window.visualViewport?.addEventListener('scroll', measure)
    return () => { /* 上記を対称に removeEventListener */ }
  }, [open, align, anchorRef])

  useEffect(() => {
    if (!open) return
    const onOutside = (e: Event) => {
      const t = e.target as Node | null
      if (!t || panelRef.current?.contains(t) || anchorRef.current?.contains(t)) return
      onCloseRef.current()
    }
    document.addEventListener('pointerdown', onOutside)
    document.addEventListener('mousedown', onOutside)     // 既存テスト(fireEvent.mouseDown)互換。クローズは冪等
    return () => { /* 対称に解除 */ }
  }, [open, anchorRef])

  if (!open) return null
  return createPortal(
    <div ref={panelRef} role={role} data-testid={testId}
      data-header-menu-panel="" data-placement="below-anchor"
      className={`overflow-y-auto overscroll-contain custom-scrollbar z-[var(--z-header-menu)] ${className}`}
      style={{ position: 'fixed', top: pos?.top ?? 0, left: pos?.left ?? 0,
        maxHeight: pos?.maxHeight, maxWidth: 'calc(100vw - 16px)', touchAction: 'pan-y',
        visibility: pos ? 'visible' : 'hidden' }}>
      {children}
    </div>,
    document.body,
  )
}
```
- 要点: `createPortal(document.body)` ＋ `position: fixed`（HEO-1）。`top`はトリガー下端＋6（HEO-2）。`maxHeight`＋`overflow-y-auto`（HEO-3）。**制御型・トリガー非依存**: 開閉状態(`open`/`onClose`)は呼出側が持つ。click 型（A1–A3・将来アクション）も hover 型（A4 の `ResourceHoverMonitor`、`role="tooltip"`）も同じプリミティブを使う。**プリミティブ自身は hover 判定・トグル・ホバー継続ブリッジ・閉鎖遅延を持たない**（hover 型の規律 HEO-9 は呼出側 T5 が担う。T-9 参照）。外側 `pointerdown`/`mousedown` によるクローズは両型で有効（トリガーラッパー内＝ブリッジを含む＝は「内側」）。Escape・フォーカストラップ・フォーカス復帰は**実装しない**（PBI非目標）。
- hooks は早期 return より前に宣言する（`if (!open) return null` は全hooks後）。`useLayoutEffect` の `setPos` は測定完了までパネルを `visibility: hidden` に保ち、描画前に確定させる。
- `animate-fade-in` など呼び出し側の `className` はそのまま適用される（位置系クラスは呼び出し側に書かせない）。

<constraints>
- Archetype 1（Overlay）: `overscroll-contain`、`touch-action: pan-y`（インライン style）、`z-[var(--z-header-menu)]`。
- 生 `vh` 禁止。高さ計算は `visualViewport.height ?? window.innerHeight`（px）のみ。幅上限は `calc(100vw - 16px)`。
- 二重 padding を作らない（パネル内 padding は呼び出し側 `className`）。
- `react-refresh/only-export-components`: `HeaderDropdown.tsx` からはコンポーネントと型のみ export。
</constraints>

## テスト（`HeaderDropdown.test.tsx`）
テスト用ハーネス: `anchorRef` 付きの div（`data-testid="anchor"`）＋ `<HeaderDropdown open onClose align data-testid="panel">`。`vi.spyOn(HTMLElement.prototype, 'getBoundingClientRect').mockImplementation(function (this: HTMLElement) {...})` で `anchor` にだけ `{top:11,bottom:39,left:300,right:330,...}` を返し、`Object.defineProperty(HTMLElement.prototype, 'offsetWidth', { configurable: true, get: () => 240 })`、`window.innerWidth/innerHeight` を各ケースで設定。`afterEach` で復元。
- `[REQ-346/AC-1] renders the panel through a portal under document.body with position fixed below the anchor`: `container` に含まれない、`style.position === 'fixed'`、`top === '45px'`（39+6）、`data-header-menu-panel` と `data-placement="below-anchor"`、`z-[var(--z-header-menu)]` クラス。
- `[REQ-346/AC-2] keeps interactive children clickable inside the panel`: 子ボタンの `onClick` 実行、`onClose` は呼ばれない。あわせて `role="tooltip"` を渡すとパネルの `role` 属性に反映される（hover 型 A4 の利用形。1 アサーションのみ追加）。
- `[REQ-346/AC-3] sets maxHeight from the viewport and enables in-panel scrolling`: innerHeight 667 → `maxHeight === '614px'`（667−45−8）、innerHeight 360 → `307px`。`overflow-y-auto` と `overscroll-contain` クラス。
- `[REQ-346/AC-4] closes on outside pointerdown/mousedown but not on anchor or panel interactions`。`open=false` のとき何もレンダリングしない。
- `[REQ-346/AC-5] clamps left inside the viewport for 375, 768 and 1280 wide viewports`: `align=start/end` 双方で `8 <= left <= vw - 240 - 8`。
- `[REQ-346/AC-6] recomputes maxHeight on window resize while open`: innerHeight を 667→360 に変え `window.dispatchEvent(new Event('resize'))` → `maxHeight` 更新。トリガーが画面外（`bottom: -10`）になった scroll イベントで `onClose` 呼出。`visualViewport` 未定義でも動作。
- `[REQ-346/AC-6] removes all listeners on unmount and under StrictMode double mount`: `removeEventListener` 呼出の対称性、二重マウントでリスナー漏れ・二重クローズなし。
- `[REQ-346/AC-8] accepts tall content (40 items) with the last item present in the panel`: 40 項目の子をレンダリングし、最終項目が panel 内に存在、`maxHeight` が設定済み（実到達性の幾何検証は Tier3）。
