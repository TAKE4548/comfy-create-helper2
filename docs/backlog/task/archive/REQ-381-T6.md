## 現在のAPI・guard・表示契約（変更対象ではない）

```ts
import { systemManagerApi, ManagerActionOutcomeUnknownError,
  type ManagerActionResult } from '../../../api/domains/systemManager'
// systemManagerApi.freeMemory(): Promise<ManagerActionResult>
// ManagerActionResult={status:'ok'|'error'|'timeout'; action:string;
//   output?:unknown; error?:unknown; outcome?:'accepted'|'unconfirmed'}
```

実base URLは `http://${window.location.hostname}:8899`。freeMemoryはPOST `/api/action`にJSON `{action:'free-memory',service:'comfy'}`、action予算120秒。成功は明示的 `{status:'ok',action:'free-memory',outcome:'accepted'}` だけで、返却量や全VRAM解放を保証しない。

HTTP409/503でも `{status:'error',action:'free-memory',request_sent:false,code:string,error:string}` が検証された場合は未送信のactionable failure。その他HTTP503/504、timeout/network失敗、応答未確認は結果不明で再送しない。`ManagerActionOutcomeUnknownError`ならUIは「解放要求の結果を確認できません。状態を再取得します。操作は再送しません。」、一般Errorは「解放要求に失敗しました: …」。**観測した既存差**: HTTP200の明示outcome='unconfirmed'は現freeMemoryのaccepted検証で一般ErrorになるためUnknownError文言には入らない。非success/再送なしは保持し、分類や文言の外部契約不一致をT6で直さずREQ-380担当へ返す。

有効条件はManager availableかつstatusあり、actionPendingなし・Manager action_in_progressなし・busyRef=false、Comfy status='LISTEN'、execution_state='idle'、queue_running===0、queue_pending===0の全成立。running boolean単独では有効にしない。executing/queued/unknown/停止/null/欠落queueはdisabledと理由表示を保持する。

開始時busyRefを同期true、actionPending='comfy:free-memory'、表示「解放要求を送信中」。success表示は「解放要求を受け付けました。空き容量は監視値で確認してください」、queryKey ['settings-vram']をinvalidate。finallyでManager状態をrefetch後、busyRef/actionPendingを解除する。連打/未知結果の自動再送は行わない。

実button labelは **ComfyUIのメモリ解放**、disabled={!freeMemoryEnabled}、`min-h-[44px] touch-manipulation`。T6では375pxの死活/ログ/長label/当buttonの非重複・折返し・44×44px領域とdesktop維持だけを調整し、上記request/guard/結果/再取得logicを変更しない。既存testのfake API値だけでAC11のbrowser layout PASSを作らない。

  const managerAvailable = available && status !== null

  const freeMemoryReason = !managerAvailable ? 'Manager状態を確認できません。' : busy ? '別のサービス操作中です。' :

    comfy.execution_state === 'executing' ? 'ComfyUIで生成中です。' :
    comfy.execution_state === 'queued' || comfy.queue_running !== 0 || comfy.queue_pending !== 0 ? 'ComfyUIのキューが空ではありません。' :
    !freeMemoryEnabled ? 'ComfyUIの実行状態が不明です。' : ''

  const runFreeMemory = async (): Promise<void> => {
    if (!freeMemoryEnabled || busyRef.current) return
    busyRef.current = true
    setActionPending('comfy:free-memory')
    setActionMessage('解放要求を送信中')
    try {
      await systemManagerApi.freeMemory()
      setActionMessage('解放要求を受け付けました。空き容量は監視値で確認してください')
      await queryClient.invalidateQueries({ queryKey: ['settings-vram'] })
    } catch (error) {
      setActionMessage(error instanceof ManagerActionOutcomeUnknownError
        ? '解放要求の結果を確認できません。状態を再取得します。操作は再送しません。'
        : `解放要求に失敗しました: ${error instanceof Error ? error.message : String(error)}`)
