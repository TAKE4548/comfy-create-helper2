# REQ-302-T4: DatasetStudioモーダル群およびHistoryPage一括削除確認の共通Modal統一

## 1. 概要と目的
DatasetStudio（`CreateProjectModal`, `NodeRemapModal`, `BenchmarkCellModal`）および `HistoryPage` のスナップショット一括削除確認モーダルにおいて、`z-50` 直書きの独自モーダル構造を共通 `Modal.tsx`（または共通契約）に統一する。
既存の `data-testid`（`create-project-modal-backdrop`, `create-project-modal`, `node-remap-modal`, `benchmark-cell-modal`）とフォーム送信機能を完全維持しつつ、Focus Trap、Escapeキー、Backdropクリック、Safe-Area対応、90dvh対応を保証する。

## 3. 変更仕様
1. **`CreateProjectModal.tsx` の共通Modal移行**:
   - `<Modal isOpen={isOpen} onClose={onClose} size="lg" ariaLabel="新規プロジェクト作成">` を使用。
   - バックドロップとダイアログの `data-testid="create-project-modal-backdrop"` および `data-testid="create-project-modal"` を維持。
   - `CreateProjectModal.test.tsx` に `[REQ-302/AC-3]` Escape・フォーカストラップテストを追加。
2. **`NodeRemapModal.tsx` の共通Modal移行**:
   - `<Modal isOpen={isOpen} onClose={onClose} size="xl" sheetMaxHeightClass="max-h-[90dvh]" ariaLabel="ノードマッピング再割当">` を使用。
   - `data-testid="node-remap-modal"` を維持。
   - `NodeRemapModal.test.tsx` に `[REQ-302/AC-5]` 縮小viewport時の到達性テストを追加。
3. **`BenchmarkCellModal.tsx` の共通Modal移行**:
   - `<Modal isOpen={!!cell} onClose={onClose} size="lg" sheetMaxHeightClass="max-h-[90dvh]" ariaLabel="評価セル詳細">` を使用。
   - `data-testid="benchmark-cell-modal"` を維持。
   - `BenchmarkGrid.test.tsx` に `[REQ-302/AC-1]` 前面化確認テストを追加。
4. **`HistoryPage/index.tsx` 一括削除確認の共通Modal移行**:
   - `<Modal isOpen={isDeleteSnapshotsModalOpen} onClose={() => setIsDeleteSnapshotsModalOpen(false)} size="sm" ariaLabel="スナップショットの一括削除">` を使用。
   - `HistoryPage.test.tsx` に `[REQ-302/AC-4]` 排他確認ダイアログ開閉テストを追加。

<constraints>
- Archetype 1: Modals & Overlays (`overscroll-contain`)
- Universal Safety: raw `100vh` 禁止（`90dvh` 使用）、11px Floor
- 既存の `data-testid` 属性および API 結合コールバック（`onCreated`, `onClose`）は厳密に維持。
</constraints>
