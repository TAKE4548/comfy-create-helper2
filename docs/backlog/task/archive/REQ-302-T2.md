# REQ-302-T2: Generate画面モーダル群およびPresetConflictModalの共通Modal統一

## 1. 概要と目的
`GeneratePage.tsx`（LoRA設定モーダル `selectedLoraForModal`、プリセット管理 `isPresetManagerOpen`、一括削除確認 `isBulkDeleteConfirmOpen`）、`GenerateModalsOverlay.tsx`（新規プロファイル作成 `showCopyModal`）、および `PresetConflictModal.tsx` において、`z-50` 直書きの独自モーダル実装を共通 `Modal.tsx`（または共通契約）に統一する。
これにより、ボトムナビ（`--z-mobile-nav: 50`）より前面（`--z-modal: 100`）へ配置し、Focus Trap、Escapeキー、Backdropクリック、スクロール遮断、Safe-Area対応、90dvh対応を一貫して担保する。

## 3. 変更仕様
1. **`selectedLoraForModal` の統一**:
   - `<Modal isOpen={!!selectedLoraForModal} onClose={() => setSelectedLoraForModal(null)} size="sm" ariaLabel="LoRA設定">` に置き換える。内部のトリガーセット選択・強度スライダー・適用/キャンセルボタンはそのまま維持。
2. **`isPresetManagerOpen` の統一**:
   - `<Modal isOpen={isPresetManagerOpen && !!selectedWorkflowId} onClose={() => setIsPresetManagerOpen(false)} size="sm" sheetMaxHeightClass="max-h-[75dvh]" ariaLabel="プリセット管理">` に置き換える。既存の `data-testid="preset-manager-overlay"` および `preset-manager-modal` を維持。
3. **`isBulkDeleteConfirmOpen` の統一**:
   - `<Modal isOpen={isBulkDeleteConfirmOpen} onClose={() => setIsBulkDeleteConfirmOpen(false)} size="sm" ariaLabel="一括削除の確認">` に置き換える。
4. **`showCopyModal` の統一**:
   - `<Modal isOpen={showCopyModal} onClose={() => setShowCopyModal(false)} size="sm" ariaLabel="新規プロファイル作成">` に置き換える。
5. **`PresetConflictModal.tsx` の統一**:
   - 外側 div を `<Modal isOpen={isOpen} onClose={onClose} size="4xl" sheetMaxHeightClass="max-h-[90dvh]" ariaLabel="プリセットの競合を検知しました">` へ移行。
   - `max-h-[90vh]` を `max-h-[90dvh]` に変更。
6. **テスト追加 (`PresetConflictModal.test.tsx`)**:
   - `[REQ-302/AC-3] traps Tab focus, closes on Escape or backdrop click, and restores focus`

<constraints>
- Archetype 1: Modals & Overlays (`overscroll-contain`, `touch-action: manipulation`)
- Universal Safety: raw `100vh` 禁止（`90dvh` 使用）、11px Floor
- AC-4要件対応: モーダルは原則排他切替（LoRA設定、プリセット管理、一括削除確認、新規プロファイル作成、競合モーダルは同時表示せず排他制御）。SPEC_COMMON §1-4の明示的ネスト例外（MappingMasterEditModal内のWorkflowNodePicker）との整合性を維持し、本カード対象のモーダルで不正なネストを導入しない。
</constraints>
