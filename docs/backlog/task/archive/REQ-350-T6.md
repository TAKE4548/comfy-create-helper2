## Implementation Requirements

- 専用seed初期値は getInitialParams が取得するgraph数値、mode metadata未設定はfixed。floatからseedへ変更した場合も既存のrole値を優先する。
- 新規seed roleの補完は全セットに default値を補完する既存経路を利用し、既存の値/modeは保持する。別workflowへmetadataを流用しない。
- loadSnapshotParams は SEED_MODES_KEY を通常パラメータとして復元しない。スナップショットの実使用Seedを専用seed各roleのfixed基準値へ復元して新しいmode metadataを作る。legacy Sampler_Seed に限り既存global setSeed/setSeedMode を維持。
- Save Default はモードをgraphへ保存せず基準値のみ注入。Reset Default は現在workflow内専用seedをgraphの値/fixedに戻し他の予約metadataを壊さない。
- 旧プリセットでmetadata不在・数値0・Main/Rough別値・snapshotからfixed再現・型変更で値保持を確認する。未知schema/mode破損は勝手に修復しない。
