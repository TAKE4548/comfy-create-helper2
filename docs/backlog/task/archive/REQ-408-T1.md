# REQ-408-T1: Modal モバイル下部シートのスワイプダウン閉じるジェスチャー実装と既存動作非破壊検証

## 1. 概要と目的
共通モーダルコンポーネント（`Modal.tsx`）において、モバイル画面幅（768px未満）のボトムシート表示時に、シート上部ハンドルまたはコンテンツ領域からの下方向スワイプ／ドラッグ操作による閉じるジェスチャー（Swipe-down to Close）を実装する。
内部スクロール（`scrollTop > 0`）との調停、閾値（80px / フリック速度0.5px/ms）判定、閾値未満でのスナップ復帰、オプトアウト機能（`disableSwipeToClose`）、およびデスクトップ表示（>= 768px）や既存の閉じる経路（ボタン、バックドロップ、Esc）の完全維持を保証する。

## 2. ターゲット識別と所有ファイル
- **所有ファイル (Exclusive Ownership)**:
  - `frontend/src/components/common/Modal.tsx`
  - `frontend/src/components/common/__tests__/Modal.test.tsx`
- **対象シンボル**:
  - `ModalProps` インターフェース (`disableSwipeToClose?: boolean` 追加)
  - `Modal` コンポーネント (タッチイベントハンドラ・スタイル拡張)

## 3. Delegation & Boundaries ([W-DD-BOUNDARY] D1〜D7)

### D1: 責務・スコープ・完了条件
- **責務**: `Modal.tsx` へのタッチスワイプ閉じるジェスチャー実装、内部縦スクロール調停、デスクトップ非破壊検証、および既存テストファイル `Modal.test.tsx` への受入テスト追記。
- **完了条件**:
  1. モバイル幅（< 768px）で下方向80px以上のドラッグまたは下向きフリックで `onClose` が呼ばれること ([REQ-408/AC-1])。
  2. 移動量80px未満で離した際、`onClose` は呼ばれず元の位置にスナップ復帰すること ([REQ-408/AC-2])。
  3. `scrollTop > 0` では内部スクロールが優先され、スワイプ閉じる操作が発火しないこと ([REQ-408/AC-3])。
  4. 閉じるボタン、キャンセルボタン、バックドロップタップ、Escキーによる既存の閉じる動作が完全維持されること (MUI-10準拠) ([REQ-408/AC-4])。
  5. デスクトップ表示（>= 768px）ではスワイプダウンによる閉じる動作が無効化されること ([REQ-408/AC-5])。
  6. `npm test src/components/common/__tests__/Modal.test.tsx` および `npm run typecheck` が全件PASSすること。

- **Hit-Slop & Gesture**:

  - `font-size < 11px` の禁止。
