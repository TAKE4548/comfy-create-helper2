# タスクカード: REQ-190-T1

## 目的
1. `useGenerationStore.ts` の `cancelJob` において、楽観的UI更新（`queuePending` からの即時除外）を導入し、待機中ジョブに対する不要な `deleteHistory` の呼び出しおよび末尾の直列 `await get().fetchQueue()` を撤廃する。
2. `clearPendingQueue` において、楽観的UI更新（`queuePending: []`）を導入し、待機ジョブへの不要な `deleteHistory` および末尾の直列 `await get().fetchQueue()` を撤廃する。
3. `cancelAllJobs` において、冗長な末尾の `await get().fetchQueue()` を撤廃し、UI応答を高速化する。
4. ジョブ完了時における `fetchHistory` の重複多重発火を抑制（In-flight Promise の再利用）し、ComfyUI / プロキシサーバの負荷を低減する。
5. 初期化、WebSocketイベント、画面復帰時などの「必須 fetchQueue」は確実に維持し、キュー同期の整合性を担保する。
6. 単体テスト（`useGenerationStore.test.ts`）を更新・追加し、最適化された各アクションの挙動を検証する。

### 2. `cancelJob` の最適化実装
```typescript
    cancelJob: async (promptId: string): Promise<void> => {
      get().abortSubmission();
      if (activeSubmissionPromise) {
        try {
          await activeSubmissionPromise;
        } catch {}
      }
      try {
        const isCurrentRunning = get().currentPromptId === promptId
        const isInQueueRunning = get().queueRunning.some((job) => job[1] === promptId)
        const isRunning = isCurrentRunning || isInQueueRunning

        // 1. 楽観的ローカル更新: 待機キューから即時除外
        set((state) => ({
          queuePending: state.queuePending.filter((job) => job[1] !== promptId)
        }))

        // 2. 実行中の場合は割り込みを投げる
        if (isRunning) {
          await comfyApi.interrupt()
          // 実行中ジョブのみ履歴クリーンアップ（非同期）
          comfyApi.deleteHistory({ delete: [promptId] }).catch((e) => {
            console.error('Failed to delete history in cancelJob:', e)
          })
        } else {
          // 待機中の場合はキューから削除する（待機ジョブは history に存在しないため deleteHistory は呼ばない）
          await comfyApi.deleteQueue({ delete: [promptId] })
        }

        // 3. 自セッションのバッチジョブ/実行中ジョブのステート更新
        const activeBatch = get().activeBatch
        if (activeBatch && activeBatch.some((job) => job.promptId === promptId)) {
          const updatedBatch = activeBatch.map((job) =>
            job.promptId === promptId ? { ...job, status: 'failed' as const } : job
          )
          const remainingUnfinished = updatedBatch.filter(
            (job) => job.status === 'pending' || job.status === 'generating'
          )
          if (remainingUnfinished.length > 0) {
            set({
              activeBatch: updatedBatch,
              ...(promptId === get().currentPromptId
                ? {
                    currentPromptId: null,
                    currentNode: null,
                    nodeProgress: null,
                  }
                : {}),
            })
            if (promptId === get().currentPromptId) {
              localStorage.removeItem(LS_KEYS.CURRENT_PROMPT_ID)
            }
          } else {
            set({
              activeBatch: null,
              isGenerating: false,
              currentPromptId: null,
              activeClientId: null,
              generationStartTime: null,
              currentNode: null,
              nodeProgress: null,
              currentWorkflow: null,
            })
            localStorage.removeItem(LS_KEYS.CURRENT_PROMPT_ID)
          }
        } else if (promptId === get().currentPromptId) {
          set({
            activeBatch: null,
            isGenerating: false,
            currentPromptId: null,
            activeClientId: null,
            generationStartTime: null,
            currentNode: null,
            nodeProgress: null,
            currentWorkflow: null,
          })
          localStorage.removeItem(LS_KEYS.CURRENT_PROMPT_ID)
        }

        // 注意: 末尾の await get().fetchQueue() は削除（ComfyUIの WebSocket 'status' イベントで自動同期）
      } catch (e) {
        console.error('Failed to cancel job:', e)
      }
    },
```

### 3. `clearPendingQueue` の最適化実装
```typescript
    clearPendingQueue: async (): Promise<void> => {
      get().abortSubmission()
      if (activeSubmissionPromise) {
        try {
          await activeSubmissionPromise;
        } catch {}
      }
      try {
        // 1. 楽観的ローカル更新: 待機キューを即時クリア
        set({ queuePending: [] })

        // 2. 待機キュークリアリクエスト
        await comfyApi.deleteQueue({ clear: true })

        // 3. activeBatch がある場合、待機中のジョブのみ除外
        const activeBatch = get().activeBatch
        if (activeBatch) {
          const updatedBatch = activeBatch.filter
            ((job) => job.status === 'generating' || job.status === 'completed')
          set({ activeBatch: updatedBatch.length > 0 ? updatedBatch : null })
        }
        // 注意: deleteHistory(pendingIds) および await get().fetchQueue() は削除
      } catch (e) {
        console.error('Failed to clear pending queue:', e)
      }
    },
```

### 4. `cancelAllJobs` の最適化実装
```typescript
    cancelAllJobs: async (): Promise<void> => {
      get().abortSubmission();
      if (activeSubmissionPromise) {
        try {
          await activeSubmissionPromise;
        } catch {}
      }
      try {
        const runningIds = get().queueRunning.map((j) => j[1])

        // 1. 楽観的ステートリセット
        set({
          queuePending: [],
          activeBatch: null,
          isGenerating: false,
          currentPromptId: null,
          activeClientId: null,
          generationStartTime: null,
          currentNode: null,
          nodeProgress: null,
          currentWorkflow: null,
        })
        localStorage.removeItem(LS_KEYS.CURRENT_PROMPT_ID)

        // 2. 待機キューの全クリア
        try {
          await comfyApi.deleteQueue({ clear: true })
        } catch (e) {
          console.error('Failed to clear queue in cancelAllJobs:', e)
        }

        // 3. 中断 (割り込み)
        try {
          await comfyApi.interrupt()
        } catch (e) {
          console.error('Failed to interrupt in cancelAllJobs:', e)
        }

        // 4. 実行中だったジョブの履歴削除（非同期）
        if (runningIds.length > 0) {
          comfyApi.deleteHistory({ delete: runningIds }).catch((e) => {
            console.error('Failed to delete history in cancelAllJobs:', e)
          })
        }

        // 注意: 末尾の await get().fetchQueue() は削除
      } catch (e) {
        console.error('Failed to cancel all jobs:', e)
      }
    },
```
