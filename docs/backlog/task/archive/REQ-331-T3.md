# REQ-331-T3: NodeRemapModal のホワイトリスト方式ロールフィルタおよびマッピング拡張

## 1. 概要と目的
Studio の `NodeRemapModal` を改修し、Positive/Negative プロンプト注入先ノードに加えて、Steps, CFG, Sampler などの各種パラメータロールも再割当・確認できるように拡張する。その際、Studio 独自のマトリクス因子と競合する汎用 textarea プロンプトロールを除外（ホワイトリスト方式）して表示する。

## 2. ターゲット識別
- **対象ファイル**: `frontend/src/pages/DatasetStudioPage/components/NodeRemapModal.tsx`
- **対象シンボル**: `NodeRemapModal`, `isStudioAllowedRole`, `handleSave`

## 3. 密閉コンテキスト (Hermetic Context)
<hermetic_context>
### 3.1 ホワイトリスト判定条件
```typescript
export const isStudioAllowedRole = (mapping: WorkflowMapping): boolean => {
  if (mapping.input_type !== 'textarea') return true
  const role = mapping.role || ''
  return (
    role === 'Main_Positive_Prompt' ||
    role === 'Negative_Prompt' ||
    role.toLowerCase().includes('positive') ||
    role.toLowerCase().includes('negative')
  )
}
```
</hermetic_context>

## 4. 実装要件 (Implementation Logic)
- [ ] `NodeRemapModal.tsx`: `workflow.mappings` のうち `isStudioAllowedRole` を満たす全ロールを行として一覧表示。
- [ ] 各ロールの候補ノードドロップダウン選択肢を表示（`getNodeLabel` 準拠）。
- [ ] 保存時、変更されたロールの `node_id` を反映した更新マッピングリストを作成し、`workflowsApi.update` を発行して保存・親コンポーネントへ反映。
