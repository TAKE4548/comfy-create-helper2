# REQ-386-T2: connectionSliceのautoFollowImage契機previewImage即時解除およびuseGenerateDisplayStateの自動追従URL保持

## 1. 概要と目的
本タスク（REQ-386-T2）は主として **AC-2**（画像完了時の即時プレビュー表示）を担当する。連続生成（バッチ等）において、直前の画像生成完了（`autoFollowImage` 発生）契機で旧中間プレビューフレーム（`previewImage`）を即時解除し、モーダル自動追従URLの消費タイミングを同期することで、完了画像のプレビュー遅延を解消する。
なお、**AC-1**（個別プログレスバー同期）は T1（バックエンド）および T3（UIレイアウト）、**AC-3**（全完了時の100%整合）は T3 が担う。

## 4. 実装要件 (Implementation Logic)
- [ ] **AC対応と責務境界**:
  - 本タスクは **AC-2**（各画像完了時の即時プレビュー表示）を実装・検証する。
  - AC-1（個別進捗同期）は T1 / T3、AC-3（完了時100%）は T3 が担当する。
- [ ] **connectionSliceのpreviewImage即時解除 (AC-2)**:
  - `connectionSlice.ts` の `applyGenerationSnapshot` において、`autoFollowImage !== null` かつ後続プレビュー未受信（`runningJob?.preview_url == null`）の場合、旧プレビューを解除（`previewImage = null`）する。
  - 後続ジョブの実プレビューフレーム（`runningJob?.preview_url`）が存在する場合はそれを維持・優先し、`SPEC_GENERATE.md:180` の原則を遵守する。
- [ ] **useGenerateDisplayStateのURL消費制御 (AC-2)**:
  - `useGenerateDisplayState.ts` において、`pendingAutoFollowUrlRef.current` は、`sortedDisplayImages.indexOf(targetUrl) !== -1`（実際にリスト内に存在することを確認したとき）に初めて消費（`null` 設定）する。
- [ ] **Constraints & Invariants**:
  - `SPEC_GENERATE.md:180` の不変条件（後続実frame受信時は維持、画像未受信でも旧frameで覆わない）を両立する。
