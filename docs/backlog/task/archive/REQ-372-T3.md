# REQ-372-T3: モバイル履歴：3列縦スクロールグリッド化・空状態・複数選択保護

## 1. 概要と目的
モバイル幅における履歴ギャラリー（`GenerationGallerySection`）のサムネイル一覧を、従来の1行横スクロールレール（`flex gap-2 overflow-x-auto`）から、ページの縦スクロールに従う3列正方形グリッド（`grid grid-cols-3 gap-2 py-2`）へ改修する。履歴0枚時の空状態表示を保護し、長押しによる複数選択モード時に通常タップが画像ボトムシートを誤爆発火しないようガードする。

## 2. ターゲット識別
- **対象ファイル**:
  - `frontend/src/pages/GeneratePage/sections/GenerationGallerySection.tsx` (L305-L350)
  - `frontend/src/pages/GeneratePage/hooks/useGalleryInteraction.ts` (L45-L65)
  - `frontend/src/pages/GeneratePage/sections/__tests__/GenerationGallerySection.cache.test.tsx`
- **UI Archetype**: `Archetype 2: Tabs / Chips / Grids`
- **担当受入基準 (AC)**: AC-2, AC-7, AC-8, AC-10, AC-11, AC-14
- **他タスク分担（本タスク対象外）**:
  - AC-1, AC-9: 常駐プレビュー撤去およびステータスヘッダー完了導線は REQ-372-T2 にて実装。
  - AC-3, AC-4, AC-5, AC-6, AC-12, AC-13: 画像ボトムシート・全画面ビューア・Wake Lock制御は REQ-372-T4 にて実装。
  - AC-8 プレビュー機能移行分担: 機能2（自動追従/固定）・機能6（複数選択）は本タスク、機能1はT2、機能3/4/5はT4で実装。無断削除なし。
  - 結合E2E検証: Playwright実ブラウザテストは REQ-372-T5 にて実施。

## 3. UI制約 (Surgical Constraints)
- **Grid Structure**: `isMobile ? 'grid grid-cols-3 gap-2 py-2 overflow-x-visible' : ...`
- **Thumbnail Aspect**: `w-full aspect-square object-cover`
- **Touch Gesture**: `touch-action: pan-y`（横スワイプレールを排除し縦スクロールを主ジェスチャーとする）
- **Hit-Slop**: 各サムネイルボタンは画面幅3等分で十分なタップ面積（80px〜120px正方形）を確保

## 5. 実装要件 (Implementation Logic)
- [ ] `GenerationGallerySection.tsx` において、`isMobile === true` 時のコンテナを `grid grid-cols-3 gap-2 py-2 overflow-x-visible` に変更し、横スクロールレールを撤去する（AC-2）。
- [ ] モバイル時のサムネイルボタンクラスを `w-full aspect-square rounded-lg overflow-hidden border-2 relative select-none` とし、中の `LazyThumbnail` を `w-full h-full object-cover` で正方形トリミング描画する（AC-2）。
- [ ] 履歴が0枚の場合（`sortedDisplayImages.length === 0`）、既存の空状態「履歴はありません」コンポーネントが描画され、存在しない画像が表示されないことを維持する（AC-7）。
- [ ] 履歴ヘッダーに `previewAutoFollow` トグルボタン（`#preview-autofollow-toggle-mobile`）を配置し、ON時に新規ジョブ完了で履歴先頭を自動選択、OFF時にユーザー選択を保持する（AC-8）。
- [ ] 長押しで複数選択モードに遷移した際（`isMultiSelectMode === true`）、サムネイルタップで画像シートを開かず、選択トグル（個別選択/解除）として動作することを確認（AC-10）。
- [ ] 既存テスト `GenerationGallerySection.cache.test.tsx` に `[REQ-372/AC-2]`, `[REQ-372/AC-7]`, `[REQ-372/AC-10]` を追加。
