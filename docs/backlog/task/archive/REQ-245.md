## 2. 検証手順 (AC)
- [x] AC-1: Generate画面の生成履歴ストリップにおいて、画像一覧の初期表示時に通信詰まりを起こさず、表示領域内の画像が迅速に表示され、未表示のスクロール先画像によって先頭の表示が遅延しないこと。
- [x] AC-2: Generate画面で履歴画像を閲覧・選択する際、ストリップ一覧用の軽量表示と拡大プレビュー用の高精細表示が適切に切り替わり、プレビュー要求時のみ高精細画像が通信ロードされること。
- [x] AC-3: LoRAs一覧画面およびTags一覧画面において、カード登録数が多い状態でも初期読み込み時に通信が飽和せず、画面スクロールに合わせて必要なサムネイルが順次スムーズに描画されること。
- [x] AC-4: 一括変換モーダル（BatchSpeechTransformModal）など複数画像を選択・表示するダイアログ展開時において、多数の画像が含まれる場合でもモーダル描画が引っかからず軽快に開くこと。
- [x] AC-5: LoRAおよびTagSetのカードサムネイル登録（クロップ保存等）を行った際、一覧表示用の軽量サムネイルが確実に紐付けられ、次回以降の一覧表示時に重い元画像が読み込まれないこと。
- [x] AC-6: ネットワーク帯域が制限された環境（低速Wi-Fiやモバイル回線相当）においても、初期マウント時の接続詰まりが抑制され、画面全体の体感表示速度およびスクロール操作の滑らかさが保たれること。
