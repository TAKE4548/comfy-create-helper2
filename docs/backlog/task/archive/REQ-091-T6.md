# TASK-REQ-091-T6: Integrate Bypass Toggles and Error Toast into Layouts

## 1. ターゲット識別
- **対象ファイル**:
  - `frontend/src/pages/GeneratePage/components/ParamPanel.tsx`
  - `frontend/src/pages/GeneratePage/components/DesktopLayout.tsx`
  - `frontend/src/pages/GeneratePage/components/MobileLayout.tsx`
- **対象シンボル**:
  - `ParamPanel` (既存コンポーネント)
  - `DesktopLayout` (既存コンポーネント)
  - `MobileLayout` (既存コンポーネント)

## 2. 密閉コンテキスト (Hermetic Context)
<hermetic_context>
`ParamPanel` はパラメータ関連の設定を表示する。
`DesktopLayout` と `MobileLayout` は全体レイアウトを描画し、状態を受け取っている。
</hermetic_context>

## 3. 実装要件 (Implementation Logic)
- **`ParamPanel.tsx`**:
  - 新しく `bypassProfiles` (配列)、`onToggleBypass` (コールバック関数)、`onOpenBypassSettings` (コールバック関数) を Props に追加する。
  - パラメータ設定部分の末尾に「Bypass」セクションを追加。
  - 登録されている各プロファイルの名前と、ON/OFF切り替え用トグルスイッチ（またはチェックボックス）を動的に表示。
  - 「Bypass Settings」（歯車アイコンまたはボタン）を配置し、クリック時に `onOpenBypassSettings` を呼び出す。
- **`DesktopLayout.tsx` & `MobileLayout.tsx`**:
  - `useGenerationStore` から `bypassProfiles`, `updateBypassProfile`, `errorToast`, `setErrorToast` を取得。
  - `ParamPanel` へのパラメータ渡し部分に `bypassProfiles`, `onToggleBypass` などをバインドして渡す。
  - `BypassSettingsModal` コンポーネントをレイアウト内にインクルードし、モーダル開閉ステートに応じて表示する。
  - ページロード時（`useEffect` 等）に現在のワークフローに対するバイパスプロファイル一覧をDBからフェッチ（`fetchBypassProfiles`）する。
  - **エラートースト通知の描画**:
    - `errorToast` が `null` でない場合、画面上部中央にフェードインする赤いエラートーストを描画。
    - 5秒後に自動的に `setErrorToast(null)` が呼ばれるように `useEffect` でタイマーを仕掛ける。手動で消去できる✕ボタンも配置。

## 4. 検証手順 (AC)
- ワークフロー読み込み時、パラメータパネルの末尾にバイパス設定へのボタンが表示されること。
- バイパス設定モーダルからプロファイルを追加し、ノードを選択して保存すると、パラメータパネルにトグルが動的追加されること。
- トグルをON/OFFして生成（Generate）ボタンを押下した際、該当ノードが正しくバイパスされて送信されること。
- コネクションエラーやバリデーションエラー時に画面上部中央にトーストが表示され、5秒後に消えること。
