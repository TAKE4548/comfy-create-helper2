## 3. 実装要件 (Implementation Logic)

1. **`usePresetState.ts` の未同期 autosave ロック (保存遮断)**:
   - Autosave Effect の先頭に `if (!isInitialSyncRef.current) return` を追加。
   - サーバからのデータ読み込みおよび初回セット同期が完了するまで、autosave タイマーおよび updateMutation の発火を完全にロックする。
   - `rawMappedSets` 構築時に既存 `promptChips` を欠落させないよう保持する。

2. **ID型正規化によるデバイス跨ぎ同期漏れ防止**:
   - `localStorage` から復元される `activeSetId`（string 型）と DB から返る `preset.id`（number 型）の不一致による同期脱落を解消する：
     - `typeof currentActiveSetId === 'number'` や `typeof activeSetId !== 'number'` などの厳密型チェックを撤廃し、`activeSetId !== null && activeSetId !== undefined`、`String(s.id) === String(activeSetId)` に正規化。
     - これにより、スマホ端末・PC 起動直後などデバイス環境に依存せず、常に同一のプリセットとして認識・同期・autosave されることを保証する。

3. **`multiSetSlice.ts` (`loadPresetData`) の role 別有効チップ判定**:
   - `s.promptChips && Object.keys(s.promptChips).length > 0 ? s.promptChips : initialPromptChips` を廃止。
   - 各 role ごとに有効なチップ（`chips && chips.length > 0`）が存在するかを個別にマージ判定：
     ```typescript
     const mergedPromptChips: Record<string, TagChip[]> = { ...initialPromptChips }
     if (s.promptChips) {
       for (const [role, chips] of Object.entries(s.promptChips)) {
         if (chips && chips.length > 0) {
           mergedPromptChips[role] = chips
         }
       }
     }
     ```
   - これにより、未同期時に空配列 `{ [role]: [] }` が存在しても BE プロンプトから生成された正規チップ（`initialPromptChips`）が優先復元される。

4. **単体・結合・デバイス跨ぎ回帰テスト拡充**:
   - **`useGenerationStore.test.ts`**:
     - セットに `{ positive: [] }` が存在していても `loadPresetData` で `param_values.positive` から正規チップが復元されることの検証。
   - **`MobileLayout.test.tsx`**:
     - モバイルレイアウトでのプロンプトタブ切り替え時に他ロールやアクティブロールのプロンプトが空文字・空チップ配列で上書きされず、正常に維持されることの検証。
   - **`GeneratePage.test.tsx`**:
     - 初期同期完了前は autosave が発火しないこと、およびサーバ再起動シミュレーションでプロンプトが空文字破壊されないことの回帰テスト。
