```powershell
function Start-BackendProcess ([bool]$asBackground) {
    if (Test-PortOpen $cfg.backend.port) { Write-Host "Backend is already running on port $($cfg.backend.port)." -ForegroundColor Yellow; return }
    $beDir = (Resolve-Path (Join-Path $SCRIPT_DIR $cfg.backend.relative_dir)).Path
    $beArgs = "--host 0.0.0.0 --port $($cfg.backend.port)"
    if ($asBackground) {
        Start-ProcessNoWindow "cmd.exe" "/c run_server.bat $beArgs > `"$(Join-Path $LOGS_DIR 'backend.log')`" 2>&1" $beDir
    } else {
        Start-Process -FilePath "cmd.exe" -ArgumentList "/k title PromptSurgeon Backend && run_server.bat $beArgs" -WorkingDirectory $beDir
    }
}
```

## 3. 実装要件 (Implementation Logic)
- [x] `backend/run_server.bat`:
  - `set PYTHONUNBUFFERED=1` を追加する。
  - `python -m uvicorn app.main:app %ARGS%` を `python -u -m uvicorn app.main:app %ARGS%` に変更する。
- [x] `tools/server-manager/server-manager.ps1`:
  - `Rotate-LogFile ([string]$logPath, [int]$maxCount = 5)` 関数を実装:
    - 既存の `$logPath` が存在する場合、古い順に `${logPath}.($i-1)` を `${logPath}.$i` にリネーム。
    - `$maxCount` を超える古いログは削除。
    - `${logPath}` を `${logPath}.1` にリネーム。
  - `Start-BackendProcess`:
    - 起動前に `Rotate-LogFile` を実行し、直前セッションのログを保全。
    - セッション開始ヘッダー（`[YYYY-MM-DD HH:mm:ss] Starting Prompt Surgeon Backend...`）をログファイルへ刻印。
    - クリーンな新規 `backend.log` へリダイレクト起動する。
  - `Start-FrontendProcess` および `Start-ComfyUIProcess`:
    - 同様に起動前に `Rotate-LogFile` を実行する。
  - `reboot-service` / `restart` 内の `backend`:
    - `Wait-For-Port-Closed` が false（未クローズ）を返した場合に再度 `Stop-BackendProcess` を試行し、確実にポート解放させる。
    - 起動待機 `Wait-For-Port` のタイムアウトを 20秒（`$cfg.backend.wait_timeout_sec` または 20）に設定する。
- [x] `tests/unit/test_server_manager_logs.py`:
  - `test_read_log_file_tail_seek`: 数MBのダミーログから末尾シークで正確に最終行群が高速取得できることをテスト。
  - `test_web_manager_rotating_logger`: `RotatingFileHandler` で `web_manager.log` が正しく記録・ローリングされることをテスト。
