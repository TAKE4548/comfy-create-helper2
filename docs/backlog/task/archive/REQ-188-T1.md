## 3. 実装要件 (Implementation Logic)
- [x] **1. `DEFAULT_MANGA_EFFECTS` の初期値修正**:
  - `types/speechBubble.ts` 内の `pathPoints` を空配列 `[]` に変更。
- [x] **2. `SpeechBubbleControls.tsx` における制御点同期と反転の修正**:
  - 軌道タイプ（`pathPreset`）変更時、選択されたプリセットと現在の文字方向に応じたデフォルト制御点を `pathPoints` にセット。
  - 文字方向（`orientation`）変更時、パス軌道が有効であれば新しい文字方向のデフォルト制御点に同期更新。
  - `handleFlipPath` において、現在のプリセットの必要点数（arc: 3, wave: 4, line: 2, stepped: 2）を満たしていない場合は `getDefaultPathPoints` から取得した上で反転処理を実行。
- [x] **3. `speechBubbleRenderer.ts` における描画・文字送りアルゴリズムの改善**:
  - `flipPathPoints`: 縦書きはX座標ミラー（$1.0 - x$）、横書きはY座標ミラー（$1.0 - y$）。中心線上の直線等は配列順序（始点・終点）をスワップ。
  - `calculateCharacterTransform`: 制御点の点数チェックを厳密化し、不足時は `bubble.orientation` に応じたデフォルト点にフォールバック。
  - `drawBubbleText` (通常配置): 各文字の `scale` を考慮した可変文字送り（Proportional Character Advancement）を計算し、拡大文字による重なりと縮小文字による過剰空隙を解消。
  - `drawBubbleText` (パス配置):
    - 弧長サンプリングに基づき、各文字のサイズと `letterSpacing` を考慮してパス上の位置を決定。
    - `stepped` において同一ステップ内の文字が同一座標に重複しないよう分散配置。
    - 縦書きパス描画時に `verticalCharMap` による文字変換（`ー` → `｜` 等）を適用。
