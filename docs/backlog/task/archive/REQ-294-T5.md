# REQ-294-T5: LM Studio エラーと JPEG 送信契約

対象は上記2ファイルのみ（変更見込み100行以下）。T1が画像をJPEG圧縮するため、VLMリクエストのdata URLもJPEG MIMEに合わせる。

## Hermetic Context

```python
async def call_vlm(image_base64: str, system_prompt: str, model: str) -> str:
    url = f"{settings.llm_base_url}/chat/completions"
    payload = {
        "model": model,
        "messages": [
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": [
                {"type": "image_url",
                 "image_url": {"url": f"data:image/png;base64,{image_base64}"}},
                {"type": "text", "text": "この画像の内容を日本語で簡潔に説明してください。"},
            ]},
        ],
        "stream": False, "max_tokens": 512,
    }
    async with httpx.AsyncClient(timeout=60.0) as client:
        response = await client.post(url, json=payload)
        response.raise_for_status()
        return response.json()["choices"][0]["message"]["content"]
```

## 実装・検証

- 400以上でHTTPステータスとresponse.textを含む例外を伝播。接続拒否とタイムアウトも分類可能にする。
- JPEG圧縮済み画像のdata URLをdata:image/jpeg;base64,へ変更する。
- test_speech_draft.pyに400本文、接続拒否、タイムアウト、JPEG MIMEのモックテストを追加。
- コマンド: mypy backend。次に backend ディレクトリで .venv/Scripts/python -m pytest tests/test_speech_draft.py -v --tb=short。
