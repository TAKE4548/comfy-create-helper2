#### Context & Purpose
REQ-305 で再構成されたデスクトップレイアウトの全幅グローバルヘッダー、全幅プリセットタブバー、左ペインツールバーの左寄せ順序配置（プリセット名 → Undo/Redo → Add Set → 管理）、および Red Team 境界値（空プリセット、未選択、長大プリセット名省略、折り返し防止）を検証するテストを更新・追加する。
また、SSoT仕様書 `docs/specs/SPEC_GENERATE.md` のデスクトップレイアウト図および記述を最新構成に同期更新する。

#### Surgical Code References
1. `DesktopLayout.tabs.test.tsx` Test Suite Updates:
```tsx
it('AC-1 & AC-2: renders Global Header at top level before #desktop-preset-tabs-bar and ResizableSplitLayout', () => {
  const { container } = renderDesktopLayout()
  const root = container.firstElementChild as HTMLElement
  const children = Array.from(root.children)

  // 1番目が Global Header (workflow-select を含む)
  expect(children[0].querySelector('#workflow-select')).toBeInTheDocument()
  expect(children[0]).toHaveClass('w-full')

  // 2番目が #desktop-preset-tabs-bar
  expect(children[1]).toHaveAttribute('id', 'desktop-preset-tabs-bar')

  // 3番目が ResizableSplitLayout コンテナ
  expect(children[2]).toBeInTheDocument()
})

it('AC-3: renders #left-pane-toolbar with justify-start in exact order: name badge, undo/redo, add-set, manage', () => {
  const { container } = renderDesktopLayout()
  const toolbar = container.querySelector('#left-pane-toolbar') as HTMLElement
  expect(toolbar).toBeInTheDocument()
  expect(toolbar).toHaveClass('justify-start')
  expect(toolbar).not.toHaveClass('justify-between')

  // 子要素順序の検証
  const elements = Array.from(toolbar.children)
  expect(elements[0].textContent).toContain('Set 1')
  expect(elements[1].querySelector('#undo-btn')).toBeInTheDocument()
  expect(elements[2]).toHaveAttribute('id', 'add-set-btn')
  expect(elements[3]).toHaveAttribute('id', 'manage-presets-btn')
})
```
