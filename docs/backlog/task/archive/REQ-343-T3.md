# REQ-343-T3: マッピングフック（useMasterMappingRows）の多段階スロット展開および未設定オプトアウト対応

## 1. 概要と目的
`useMasterMappingRows` を拡張し、単一の `master_id` に対する1つのノード割り当てだけでなく、ワークフローから検出された有効ステージやスキャン結果の `variant_id` に応じてRole×Stageの複数スロットを展開できるようにする。
また、各スロットを未設定（空文字）にできるクリア操作（`clearSlot`）を提供し、`getMappings()` では未設定のスロットを除外して `{ master_id, node_id, variant_id }` の形式で返却する。

## 2. ターゲット識別
- **対象ファイル**:
  - `frontend/src/hooks/useMasterMappingRows.ts`
  - `frontend/src/hooks/__tests__/useMasterMappingRows.test.ts`
- **対象シンボル**:
  - `MasterMappingRow`, `StageSlotItem`, `useMasterMappingRows`
  - `buildRows`, `updateSlotNodeId`, `clearSlot`, `initFromScan`, `getMappings`

  const getMappings = (mainRows: MasterMappingRow[], notFoundRows: MasterMappingRow[]) => {
    const results: { master_id: number; node_id: string; variant_id?: number }[] = []
    for (const r of [...mainRows, ...notFoundRows]) {
      if (r.stageSlots && r.stageSlots.length > 0) {
        for (const slot of r.stageSlots) {
          if (slot.node_id && slot.node_id.trim() !== '') {
            results.push({ master_id: slot.masterId, node_id: slot.node_id.trim(), variant_id: slot.variantId })
          }
        }
      } else if (r.node_id && r.node_id.trim() !== '') {
        results.push({ master_id: r.master.id, node_id: r.node_id.trim() })
      }
    }
    return results

## 4. 実装要件 (Implementation Logic)
- [ ] `frontend/src/hooks/useMasterMappingRows.ts`:
