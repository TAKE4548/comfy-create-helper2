# Task Card: REQ-248-T4

## Context & Responsibility
`frontend/src/api/types.ts` および `frontend/src/api/domains/generation.ts` の手書き API 型定義を調査し、`frontend/src/api/schema.ts` の `components['schemas']` への型参照・エイリアスへ移行する。UI専用型（API契約外のローカル状態や表示用フラグ等）は明示的に区別して維持し、手書き API 型の二重管理を解消する。既存の全クライアント通信、応答不明照合（`reconcile` / `unconfirmed`）、再送防止、キャンセル、エラーハンドリングとの型互換性を 100% 維持する (AC-3)。

本 Task Card は実装作業における唯一のセマンティック仕様書（Sole Semantic Specification）であり、外部の親 PBI や設計文書の閲覧に依存せず完結して作業を実施すること。

## Owned Files
- `frontend/src/api/types.ts` (更新)
- `frontend/src/api/domains/generation.ts` (更新)

## Delegation & Boundaries
- **Responsibility & Scope**: `types.ts` および `domains/generation.ts` における手書き API 型の `components['schemas']` 参照への置換、UI専用型の分類コメント付与、および型互換性の維持。
- **Prerequisites & Dependencies**: REQ-248-T3 (`frontend/src/api/schema.ts` が生成されていること)。
- **Neighboring Task Owned Files**:
  - REQ-248-T1: `scripts/export_openapi.py`, `backend/openapi.json`
  - REQ-248-T3: `frontend/package.json`, `frontend/src/api/schema.ts`
  - REQ-248-T5: `scripts/verify_openapi_sync.py`
- **Shared Contracts**: `frontend/src/api/schema.ts` の `components['schemas']` を正本として参照。既存の外部エクスポート型名およびシグネチャを破壊しない。
- **AC Verification Mapping**: AC-3 (FE 型整合性および既存クライアント・通信フロー互換性の維持)。
- **Delegated Judgment**: 手書き型が生成スキーマと同一名の場合は直接型エイリアス化、一部の UI 固有フィールドを持つ場合は `extends` インターフェース化する判断は Engineer に委任される。
- **Prohibited-Change Scope**: API クライアントの通信処理本体（`api/client.ts`）、UI コンポーネント本体の JSX/ロジック変更は禁止。
