# REQ-315-T2: メニューと確定本文の連携

**人間の設計レビューと T1 の実装後に着手する。対象は `frontend/src/components/TagChipEditor/TagChip.tsx` と `frontend/src/components/TagChipEditor/__tests__/TagChip.test.tsx` の2ファイル、推定変更160行以下。**

## 密閉コンテキスト

公開 Props とメニュー状態（`TagChip.tsx`）:

```tsx

  const [isMenuOpen, setIsMenuOpen] = useState(false);
```

現行確定処理（同ファイル、`handleWordSubmit`）:

```tsx
  const handleWordSubmit = () => {
    const trimmed = wordInput.trim();
    if (!trimmed) {
      setWordInput(baseText);
      return;
    }
    if (trimmed !== baseText) {
      const { weight: currentWeight } = parseTagWeight(text);
      const newFormatted = formatTagWeight(trimmed, currentWeight, isAnimaMode);
      onEdit(id, newFormatted);
    }
  };

  const handleWordKeyDown = (e: React.KeyboardEvent<HTMLInputElement>) => {
    e.stopPropagation();
    if (e.key === 'Enter') {
      e.preventDefault();
      handleWordSubmit();
    } else if (e.key === 'Escape') {
      e.preventDefault();
      setWordInput(baseText);
      setIsMenuOpen(false);
    }
  };
```

現行カード接続（同ファイル、サブメニュー末尾）:

```tsx
          {isTranslationOpen && (
            <TagChipTranslationCard

```

T1 後の追加 Props 契約: `menuRef?: React.RefObject<HTMLDivElement>`。翻訳カードの `text` 変更時だけ取得し、カード自身が古い応答を排除する。

## 実装契約

1. チップのクリックで閉状態からメニューを開くと同時にカード表示状態を開く。再クリックでメニューを閉じる。既存の翻訳ボタンは手動の閉じる・再表示用に維持し、表示名や aria-label は実際の状態に合わせる。
2. カードの `text` を編集中の `wordInput` から確定済みの `baseText` に変更し、`menuRef` を渡す。Enter と blur は既存 `handleWordSubmit` で親へ確定値を送り、親の `text` 更新がカード取得を起動する。入力途中では API を呼ばない。重みのみの更新でも本文が同じなら翻訳を繰り返さない。
3. 空欄・Escape は既存の巻き戻しとメニュー閉鎖を保つ。Escape で取り消した文字列をカードへ渡さない。カードへのフォーカス移動は入力確定を起こすが、カードは閉じない。メニュー外のクリックでは両方を閉じる。

## 局所検証と完了条件

`cd frontend; npm run typecheck` と `cd frontend; npx vitest run src/components/TagChipEditor/__tests__/TagChip.test.tsx`。親の `text` を実際に更新する小さなテスト用ラッパーを使い、初回自動表示、入力中の無呼び出し、Enter/blur 後の新訳、カード内操作後の維持、キャンセル、Enter と blur の重複回避を検証する。既存の重み編集・コピー・ドラッグ導線を壊さない。
