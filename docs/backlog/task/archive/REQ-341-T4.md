## 4. 実装要件 (Implementation Logic)
- [ ] `DatasetStudioPage/index.tsx`:
  - 独自 `<header>` を `PageHeader`（title="LoRA Studio", icon={Sparkles}）へ置換。
  - 左クラスタリング `actions`:
    - `[プロジェクト選択 ▼]`（`data-testid="project-selector"`）
    - 4段階ステップ切替ボタングループ（`[1.マトリクス] [2.キュレーター] [3.学習設定] [4.評価]`）
    - 自動保存ステータスバッジ（`<span data-testid="autosave-status">`）
  - 右端は `PageHeader` 内蔵の `ResourceHoverMonitor` と `HeaderKebabMenu` で一元表示。
- [ ] `LoRAsPage.tsx`:
  - 独自ヘッダー `div` を `PageHeader`（title="LoRAs", icon={Layers}, badge={`(${filteredLoras.length})`}）へ置換。
  - 左クラスタリング `actions`:
    - 検索ボックス（`id="lora-search"`）
    - `[+ Register Model]`（`id="register-lora-btn"`）
    - カテゴリ管理ボタン（`title="カテゴリ管理"`）
  - 50px 固定高さに統合され、画面遷移時のガタつきを排除。
