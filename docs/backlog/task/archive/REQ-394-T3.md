## A. test_comfy_proxy.py: test_prune_disk_cache_if_needed

製品側（参照のみ。`backend/app/routers/comfy.py`）: 定数は呼出時に読まれる。

```python
_DISK_CACHE_MAX_FILES = 4000
_DISK_CACHE_TARGET_FILES = 3600
def _prune_disk_cache_if_needed(disk_dir: Path) -> None:
    files = list(disk_dir.glob("*.webp"))
    if len(files) <= _DISK_CACHE_MAX_FILES:
        return
    files.sort(key=lambda f: f.stat().st_mtime)
    delete_count = len(files) - _DISK_CACHE_TARGET_FILES
    ...
```

現状のテスト（4,001 ファイル作成で 3.4s）:

```python
    def test_prune_disk_cache_if_needed(self):
        """4,000件超過時に古い順にファイルが削除されて 3,600件まで間引かれること。"""
        import tempfile
        from pathlib import Path

        with tempfile.TemporaryDirectory() as tmpdir:
            disk_dir = Path(tmpdir)
            # 4,001件の .webp ファイルを作成
            total = 4001
            for i in range(total):
                f = disk_dir / f"thumb_{i:05d}.webp"
                f.write_bytes(b"dummy")

            comfy_router._prune_disk_cache_if_needed(disk_dir)

            remaining = list(disk_dir.glob("*.webp"))
            self.assertLessEqual(len(remaining), comfy_router._DISK_CACHE_TARGET_FILES)
```

変更後（ファイル先頭で `patch` は import 済み）。本番定数を別アサーションで固定し、縮小値で同じ論理（上限超過 → 目標数まで削除）を検証する:

```python
    def test_prune_disk_cache_if_needed(self):
        """4,000件超過時に古い順にファイルが削除されて 3,600件まで間引かれること（定数を縮小して同じ論理を検証、REQ-394）。"""
        import tempfile
        from pathlib import Path

        self.assertEqual(comfy_router._DISK_CACHE_MAX_FILES, 4000)
        self.assertEqual(comfy_router._DISK_CACHE_TARGET_FILES, 3600)
        with patch.object(comfy_router, "_DISK_CACHE_MAX_FILES", 40), \
                patch.object(comfy_router, "_DISK_CACHE_TARGET_FILES", 36), \
                tempfile.TemporaryDirectory() as tmpdir:
            disk_dir = Path(tmpdir)
            total = 41  # one over the (scaled) limit
            for i in range(total):
                (disk_dir / f"thumb_{i:05d}.webp").write_bytes(b"dummy")

            comfy_router._prune_disk_cache_if_needed(disk_dir)

            remaining = list(disk_dir.glob("*.webp"))
            self.assertEqual(len(remaining), 36)
```

## B. serve_forever の poll_interval（shutdown 待ち最大 0.5s の解消）

`ThreadingHTTPServer.serve_forever()` の既定 `poll_interval=0.5` のため、`shutdown()` が最大 0.5s ブロックされる。起動側で `kwargs={"poll_interval": 0.01}` を渡す。

`tests/unit/test_server_status.py`（3 箇所: 行 174、202、256 付近。同一文）:

```python
# 現状
    thread = threading.Thread(target=listener.serve_forever, daemon=True)
# 変更後
    thread = threading.Thread(target=listener.serve_forever, kwargs={"poll_interval": 0.01}, daemon=True)
```

`tests/unit/test_server_manager_timeout.py`（4 箇所: 行 61、70、144、152 付近）:

```python
# 現状
    comfy_thread = threading.Thread(target=comfy.serve_forever, daemon=True)
    manager_thread = threading.Thread(target=manager.serve_forever, daemon=True)
# 変更後
    comfy_thread = threading.Thread(target=comfy.serve_forever, kwargs={"poll_interval": 0.01}, daemon=True)
    manager_thread = threading.Thread(target=manager.serve_forever, kwargs={"poll_interval": 0.01}, daemon=True)
```

Hypothesis テストの `@settings(max_examples=8, deadline=None)` は既に明示済みなので変更しない。
