## Implementation Logic

生成画面に返すworkflowはfalse slot除外clone。useGeneratePageStateがparams/seed/preset/injectorへ渡す同一workflowを使うためprompt/parameter/mobile/seed等が揃って除外される。保存修正はrawを使い隠れたmappingを巻き込んで削除しない。master defaultflagは既存workflowのfilter条件にしない。再有効化後はrawを再派生して復元。 handleUpdateMappingの全行変換でvariant_idを保持し、legacy nullだけm:<masterId>へ正規化する。無効な非対象slotをvariantなしへ降格させない。
