# REQ-337-T3: MappingMasterEditModal Dynamic ClassType Autocomplete Dropdown

## 1. 概要と目的
`MappingMasterEditModal.tsx` の Class Types 入力欄に、`useComfyNodeTypes` と連動した動的オートコンプリート・ドロップダウンを統合する。
キーボード操作（上下矢印キー、Enter、Tab、Escape）およびマウスクリック選択を可能にし、重複追加を防止する。
ComfyUI 未接続時やAPIエラー時でも通常の手入力および静的候補パレット（`COMMON_CLASS_CANDIDATES`）が阻害されないノンブロッキング・グレイスフル設計とする。

### 3.2 既存のハンドラロジック (`MappingMasterEditModal.tsx` L148-L167)
```tsx
const addClassType = (typeToAdd: string) => {
  const trimmed = typeToAdd.trim()
  if (!trimmed) return
  if (!classTypes.includes(trimmed)) {
    setClassTypes([...classTypes, trimmed])
  }
  setInputClass('')
}

const removeClassType = (typeToRemove: string) => {
  setClassTypes(classTypes.filter((t) => t !== typeToRemove))
}

const handleClassKeyDown = (e: React.KeyboardEvent<HTMLInputElement>) => {
  if (e.key === 'Enter' || e.key === ',') {
    e.preventDefault()
    addClassType(inputClass)
  }
}
```

## 4. 実装要件 (Implementation Logic)
- [ ] `useComfyNodeTypes` をインポートし、`filterClassTypes`, `isLoading`, `isError` を取得する。
- [ ] `inputClass.trim()` が 1 文字以上かつ `!isLoading && !isError` の場合に `filterClassTypes(inputClass, classTypes)` を呼び出し、候補リスト `filteredCandidates` を導出する。
- [ ] ドロップダウン表示状態（`showDropdown`）およびフォーカスインデックス（`highlightIndex`）の state を管理する。
  - 入力文字列が変化した際は `highlightIndex` を 0（または -1）にリセット。
  - 入力欄フォーカス喪失時（`onBlur`）は 150ms 遅延または `relatedTarget` チェックで安全に閉じる。
- [ ] キーボード操作ハンドラを拡張:
  - `ArrowDown`: ドロップダウンを開き、`highlightIndex` を次に進める（末尾で循環または停止）。
  - `ArrowUp`: `highlightIndex` を前に戻す。
  - `Enter` / `Tab`: `highlightIndex >= 0 && filteredCandidates[highlightIndex]` の場合はその候補を追加。候補選択中でない場合は通常通り `inputClass` の手入力を追加。
  - `Escape`: ドロップダウンを閉じる。
- [ ] ドロップダウン UI を入力欄の下部に配置（`relative` 親要素に対し `absolute z-20`）:
  - スクロール可能な最大高（`max-h-60 overflow-y-auto`）、Tailwind `bg-zinc-900 border border-zinc-700 rounded-lg shadow-xl`。
  - マウスホバーおよび `highlightIndex` 一致で背景色ハイライト（`bg-[#7C6FDD]/20 text-[#7C6FDD]`）。
  - `onMouseDown`（Blur防止）で `addClassType(candidate)` を呼び出し、チップ追加と入力欄クリアを行う。
- [ ] 重複追加防止: 既に `classTypes` に含まれる文字列は `addClassType` で無視され重複しないこと。
- [ ] テスト `frontend/src/components/__tests__/MappingMasterEditModalAutocomplete.test.tsx` を作成し、AC-1（候補表示・矢印キー/クリック選択）、AC-2（エラー時通常手入力・静的パレット）、AC-3（重複防止）を網羅する。
