## destructive-confirm の扱い（重要）
- 2つとも**現行は `role="dialog"`（alertdialog ではない）**で、既存テストも `getByRole('dialog', …)`。Modal は `role="dialog"` 固定で alertdialog 非対応のため、**role は dialog のまま維持**（Modal を拡張しない。安全な最小方針）。
- 初期フォーカス: Modal は最初のフォーカス可能要素へ移す。`MappingMasterDeleteModal` は DOM 順で「Cancel」が先、`WorkflowDeleteConfirmDialog` は閉じる(X)が先 → いずれも破壊的ボタン（Delete/削除する）に初期フォーカスが当たらない。この順序を**維持**（Delete ボタンを DOM 上で前に出さない）。
- 閉じ方の維持/強化:
  - `MappingMasterDeleteModal`: 旧=バックドロップ無反応・Esc無し → `closeOnBackdropClick={false}`、`closeOnEsc={!isPending}`。
  - `WorkflowDeleteConfirmDialog`: 旧=バックドロップで onClose（pending 中も）、X は `disabled={isPending}` → `closeOnBackdropClick={!isPending}`、`closeOnEsc={!isPending}`（pending 中の誤閉じを X の disabled と整合させる意図的な軽微な強化。報告に記す）。
  - 「理解しました」チェックによる削除ボタン無効化（`disabled={isPending || isLoadingDetails || !understood}`）は不変。

## 変更内容
1. 各 dialog の外側 `fixed inset-0 …` と内側パネルを撤去し `Modal` に置換:
```tsx
<Modal isOpen onClose={onClose} size="md" sheetMaxHeightClass="max-h-[85dvh]"
  ariaLabel="Delete Mapping Master?" closeOnBackdropClick={false} closeOnEsc={!isPending}>
  <div className="flex-1 min-h-0 overflow-y-auto overscroll-contain space-y-4 p-4 md:p-6">{/* 既存の見出し〜使用状況 */}</div>
  <div className="shrink-0 flex items-center justify-end gap-3 px-4 md:px-6 pb-4 md:pb-6 pt-2">{/* Cancel / Delete */}</div>
</Modal>
```
   - ワークフロー版は `ariaLabel={\`ワークフロー「${workflowName}」を削除しますか？\`}`、`closeOnBackdropClick={!isPending}`、`closeOnEsc={!isPending}`。**見出し `h3` とその `id`（`mapping-master-delete-title` / `workflow-delete-title`）は維持**（既存テストが各 dialog 内の `getByRole('heading').id` の相異を検証。dialog 内の見出しは1つのみ）。
   - ワークフロー版の絶対配置 X ボタンは見出し行（flex行）内に移し `aria-label="閉じる"` を付与、`disabled={isPending}` 維持。`relative`/`animate-scale-up`/`onClick={onClose}`/`stopPropagation` は撤去。
   - 追加の `pb` 禁止（Modalがsafe-areaを提供）。`animate-*` の独自overlay用classは撤去。
2. **44pxタッチターゲット**: X ボタン `inline-flex items-center justify-center min-h-[44px] min-w-[44px] touch-manipulation`。Cancel/Delete/キャンセル/削除する: `min-h-[44px] md:min-h-0 touch-manipulation`。チェックボックス行の `label` に `min-h-[44px]`（行全体がタップ領域）。**ボタン可視名は変更しない**（`Cancel`/`Delete`/`キャンセル`/`削除する`）。
3. 11pxフロア: 約194行 `text-[10px]`（警告見出し）→ `text-[11px]`。生 `vh` を追加しない。
4. `import { Modal } from './common/Modal'` を追加。
