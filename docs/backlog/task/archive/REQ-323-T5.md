# REQ-323-T5: E2E ライフサイクル検証と画面離脱・リロード復元テスト (e2e_req323)

## 1. 概要と目的
Dataset Studio における「プロジェクト即時作成」「デバウンス付きオートセーブ」「リアルタイム sessionStorage 下書き退避」「画面再訪・リロード時の自動復元」「保存ステータスフィードバック」の一連の振る舞いを網羅する包括的 E2E テストスイート（`frontend/src/test/e2e_req323_autosave_draft.test.tsx`）を構築・検証する。

## 2. 密閉コンテキスト (Hermetic Context)

### 2.1 テスト対象モック API 定義 (`src/api/client.ts`)
```typescript
vi.mock('../api/client', () => ({
  datasetApi: {
    createProject: vi.fn(),
    updateProject: vi.fn(),
    getProjects: vi.fn(),
    getProject: vi.fn(),
    calculateMatrix: vi.fn(),
  },
  workflowsApi: {
    list: vi.fn(),
    get: vi.fn(),
  },
}))
```

### 2.2 検証対象 Acceptance Criteria
- AC-1: 新規プロジェクト作成の即時永続化と失敗時入力保持
- AC-2: フォーム変更後 750ms のデバウンス・オートセーブ
- AC-3: 入力ごとのリアルタイム `sessionStorage` 下書き退避
- AC-4: 画面遷移・リロード時の未保存下書き自動復元
- AC-5: サーバー保存完了時のキャッシュ同期
- AC-6: 保存ステータス表示（未保存、保存中、保存完了、保存失敗）
- AC-7: 型検査およびテスト完全パス

## 3. 実装要件 (Implementation Logic)
1. **`frontend/src/test/e2e_req323_autosave_draft.test.tsx` の新規作成**:
   - `beforeEach`: `sessionStorage.clear()`, `useStudioStore.getState().resetStudio()`, モック初期化。
   - **Test 1 (AC-1)**:
     - `CreateProjectModal` を通じた新規プロジェクト作成。
     - `datasetApi.createProject` が呼ばれ、戻り値のプロジェクトIDがアクティブになりヘッダーに反映されること。
     - 作成失敗時にモーダル内の入力が保持されエラーが表示されること (Red Team 3)。
   - **Test 2 (AC-2, AC-3, AC-6)**:
     - プロジェクト表示中にキャラトリガーやタグを変更。
     - 直ちに `sessionStorage` の `dataset_studio_draft_${id}` にデータとタイムスタンプが書き込まれること。
     - ステータスが「未保存（下書き保持）」となること。
     - 750ms 経過後、`datasetApi.updateProject` が自動発行され、ステータスが「保存完了」に遷移すること。
   - **Test 3 (AC-4, AC-5)**:
     - 変更途中でアンマウントし、`sessionStorage` を維持したまま再度 `DatasetStudioPage` をマウント。
     - 直前の入力が自動復元され、入力消失が発生しないこと。
   - **Test 4 (Red Team 1, 2)**:
     - `sessionStorage.setItem` が `QuotaExceededError` をスローする状態でもアプリがクラッシュしないこと。
     - `updateProject` が 500 エラーを返した場合、「保存失敗」が表示され下書きが保持されること。
   - **Test 5 (Red Team 5: 競合検知 & 手動解消)**:
     - 下書きの `base_server_updated_at` がサーバー側の `updated_at` と異なる状態でマウントした場合、`draft-conflict-alert` が表示され自動保存が停止すること。
     - 「下書きで上書き」クリック時に下書きでサーバー保存が実行され競合が解消すること。
     - 「サーバーの最新を読込」クリック時に下書きがクリアされサーバー最新値でリロードされること。
