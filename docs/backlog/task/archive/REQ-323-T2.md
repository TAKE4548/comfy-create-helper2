# REQ-323-T2: 新規プロジェクト作成モーダル (CreateProjectModal) とストア拡張の実装

## 1. 概要と目的
Dataset Studio 開始時に即時サーバー永続化（`datasetApi.createProject`）を行い、一意なプロジェクトIDを確定させる新規プロジェクト作成モーダル（`CreateProjectModal`）を新設する。また、保存状態およびプロジェクトリストを管理できるよう Zustand ストア（`useStudioStore`）を拡張する。

## 2. 密閉コンテキスト (Hermetic Context)

### 2.1 型定義: `src/api/types.ts`
```typescript
export interface DatasetProject {
  id: number
  name: string
  character_trigger: string
  outfit_trigger: string
  workflow_id: number
  prompt_meta: string
  prompt_physical: string
  prompt_exclusive_outfit: string
  selected_alt_outfits: string
  prompt_negative?: string
  created_at: string
  updated_at: string
}

export interface DatasetProjectCreate {
  name: string
  character_trigger: string
  outfit_trigger: string
  workflow_id: number
  prompt_meta: string
  prompt_physical: string
  prompt_exclusive_outfit: string
  selected_alt_outfits?: string
  prompt_negative?: string
}

export type StudioSaveStatus = 'idle' | 'unsaved' | 'saving' | 'saved' | 'error'
```

### 2.2 現行コードスニペット: `frontend/src/pages/DatasetStudioPage/useStudioStore.ts` (L15-L25)
```typescript
export interface StudioState {
  currentStep: 1 | 2 | 3 | 4
  setCurrentStep: (step: 1 | 2 | 3 | 4) => void

  activeProject: DatasetProject | null
  setActiveProject: (project: DatasetProject | null) => void

  items: DatasetItem[]
  setItems: (items: DatasetItem[]) => void
```

## 3. 実装要件 (Implementation Logic)
1. **`useStudioStore.ts` の拡張**:
   - `saveStatus: StudioSaveStatus`（初期値 `'idle'`）および `setSaveStatus` を追加。
   - `projectsList: DatasetProject[]`（初期値 `[]`）および `setProjectsList` を追加。
   - `resetStudio` 時に `saveStatus: 'idle'` となるようリセット処理を更新。
2. **`frontend/src/pages/DatasetStudioPage/components/CreateProjectModal.tsx` の新規作成**:
   - Props:
     ```typescript
     export interface CreateProjectModalProps {
       isOpen: boolean
       onClose: () => void
       onCreated: (project: DatasetProject) => void
       workflows: Workflow[]
     }
     ```
   - フォーム入力項目:
     - プロジェクト名 (`data-testid="create-project-name-input"`, default: `'My New Chara LoRA'`)
     - キャラトリガー名 (`data-testid="create-character-trigger-input"`, default: `'mychara'`)
     - 本命衣装トリガー名 (`data-testid="create-outfit-trigger-input"`, default: `'mychara_outfit'`)
     - ComfyUI ワークフロー (`data-testid="create-workflow-select"`)
   - 「作成して開始」ボタン (`data-testid="submit-create-project-btn"`):
     - `datasetApi.createProject` を非同期呼び出し。
     - 成功時: `onCreated(res)` を発火してモーダルを閉じる。
     - 失敗時: `data-testid="create-project-error"` にエラーを表示。モーダルは閉じず、ユーザーが入力した値を保持したまま再試行可能とする (AC-1, Red Team 3)。
3. **単体テスト `frontend/src/pages/DatasetStudioPage/components/__tests__/CreateProjectModal.test.tsx` の新規作成**:
   - 正常系: 入力後に作成ボタン押下で `datasetApi.createProject` が呼ばれ、`onCreated` が発火すること。
   - 異常系: API エラー時にモーダルが閉じずエラーメッセージが表示され、入力値が保持されること (Red Team 3)。

## 4. 完了条件と検証
- [ ] モーダルからプロジェクト作成が行われ、即時サーバーに保存されること (AC-1)。
- [ ] 作成失敗時にエラーが表示され、モーダル内の入力状態が維持されて再試行できること (AC-1, Red Team 3)。
- [ ] `useStudioStore` に `saveStatus` と `projectsList` が追加され型検査を通過すること。
