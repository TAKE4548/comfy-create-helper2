# REQ-423-T5: 生成パイプラインにおけるComfyUI Seed伝播E2E/統合検証

## 1. 概要と目的
生成実行フロー（`useGenerateAction`）において、サンプラーノード（KSamplerAdvanced: `noise_seed`）を持つワークフローで Seed 値を変更して生成を実行した際、ComfyUI への送信バッチペイロード内の対象ノード入力（`inputs.noise_seed`）に指定した Seed 値が確実に注入され、実在しない `inputs.seed` への誤注入が発生しないことを統合検証する。
さらに、`buildGenerationRecord` によってメタ情報に記録された Seed 値および入力キー名が、ComfyUI に送信されたグラフと完全に一致することをエンドツーエンドで担保する。
