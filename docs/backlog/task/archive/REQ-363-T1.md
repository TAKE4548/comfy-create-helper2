# REQ-363-T1: プロンプト切り替えタブの文字重なり ＆ チップのボタン下潜り込み & チェックボックスタップによる「Generate Batch」バー突然消失バグ

## 1. 概要と目的
### プロンプト切り替えタブの文字重なり ＆ チップのボタン下潜り込み
- タブの独立 pill 化: タブボタンに shrink-0 whitespace-nowrap を厳格適用し、横スクロールで文字衝突ゼロを保証。
- スクロール終端パディング (pb): スクロールコンテナに pb-[calc(54px+env(safe-area-inset-bottom)+56px+16px)] を確保し、最下部チップがボタンの 16px 上で綺麗にスクロールアウト完了。
- コンパクトチップ表示: モバイル時は text-xs px-2.5 py-1 の流動型タグチップへ切り替え、作業領域を 2 倍確保。
### チェックボックスタップによる「Generate Batch」バー突然消失バグ
- 入力タイプ判定の厳密化: isTextInput で target.type !== 'checkbox' && target.type !== 'radio' を必須条件に追加。
- 安定したバー表示: チェックボックスやトグルスイッチ操作時もアクションバーは常時固定表示を維持。

### 3.1 isTextInput (L137-141)
```typescript
  const isTextInput = (target: unknown): target is HTMLElement => {
    if (!target || !(target instanceof HTMLElement)) return false
    const tag = target.tagName.toLowerCase()
    if (target instanceof HTMLInputElement) {
      return target.type !== 'checkbox' && target.type !== 'radio' && target.type !== 'range' && target.type !== 'button'
    }
    return tag === 'input' || tag === 'textarea' || target.isContentEditable
  }
```
