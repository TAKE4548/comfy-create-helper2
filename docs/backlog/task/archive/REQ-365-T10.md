## 変更内容
1. `SpeechToneSection` 内に新state: `selectedPresetId: number | null`、`testText: string`、`testResult: string | null`、`testError: string | null`、`isTesting: boolean`、`revision`/`pending` ref（上記モーダルと同じ「最新リクエストのみ採用」ガード）。
2. 展開領域を `grid grid-cols-1 gap-4 xl:grid-cols-2` に再構成: 左=既存の表（DOM・文言不変）、右=テストパネル `data-testid="speech-tone-test-panel"`。
3. 表の操作列（編集・削除の隣）に「テストに使う」ボタンを追加: `aria-pressed={selectedPresetId === tp.id}`、`aria-label={`${tp.name} をテスト対象にする`}`、アイコンのみ可、44×44 + Hit-Slop。選択でテスト結果をクリア。**プリセット名・説明の本文テキストを新たに重複出力しない**（既存テストの `getAllByText` 件数を変えない。選択名の表示はパネル内 `aria-live` 領域外の `title`/`aria-label` のみ）。
4. テストパネル: `<label htmlFor="speech-tone-test-input">テスト入力</label><textarea id="speech-tone-test-input" rows={3} />`、ボタン `テスト実行`（無効条件: 未選択 / 入力が空白のみ / 実行中）、結果領域 `<div aria-live="polite" aria-label="テスト出力">`、エラー `role="alert"`。実行は:
```tsx
const preset = tonePresets.find((tp) => tp.id === selectedPresetId)
const result = await speechTonePresetsApi.rewrite({ text: testText, tone_prompt: preset.prompt, preset_id: preset.id })
```
5. 入力変更・選択変更時は `revision.current += 1` で進行中の応答を無効化し結果/エラーをクリア（古い応答を採用しない）。選択中プリセットが削除されたら選択を解除。
6. 未選択時は案内文 `口調プリセットを選択してテスト入力を行ってください。`。
