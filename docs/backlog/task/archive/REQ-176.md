# タスクカード: REQ-176

## 1. 目的
`SpeechBubbleControls.tsx` において、セリフ修飾プリセット一覧の探索性と利便性を向上させるため、以下の機能を実装する：
1. **テキスト付き / スタイル専用の区分と折り畳み**: プリセットを「テキスト付き」と「テキストなし（スタイル専用）」に分離し、それぞれ個別に折り畳み/展開可能にする。
2. **ソート機能**: 名前昇順（デフォルト）・名前降順・登録日時昇順・登録日時降順の並び替えを提供する。
3. **検索・フィルタ機能**: 自由テキストによる名前検索、および「すべて / 縦書き / 横書き」の種別フィルタを提供する。
4. **localStorage永続化**: 検索条件、縦横フィルタ、ソート順、セクション開閉状態を `localStorage` に保存・復元する。
5. **テスト拡充**: 単体テストを新規追加・更新し、全機能の動作を担保する。

### 3-3. フィルタ・ソートロジック
```typescript
// フィルタ
const filteredPresets = presets.filter((p) => {
  if (presetDirectionFilter === 'vertical' && p.orientation !== 'vertical') return false
  if (presetDirectionFilter === 'horizontal' && p.orientation !== 'horizontal') return false

  if (presetSearchQuery.trim()) {
    const q = presetSearchQuery.trim().toLowerCase()
    const nameMatch = p.name.toLowerCase().includes(q)
    const textMatch = p.text ? p.text.toLowerCase().includes(q) : false
    if (!nameMatch && !textMatch) return false
  }

  return true
})

// ソート
const sortedPresets = [...filteredPresets].sort((a, b) => {
  switch (presetSortBy) {
    case 'name-asc':
      return a.name.localeCompare(b.name, 'ja')
    case 'name-desc':
      return b.name.localeCompare(a.name, 'ja')
    case 'created-asc': {
      const timeA = a.created_at ? new Date(a.created_at).getTime() : a.id
      const timeB = b.created_at ? new Date(b.created_at).getTime() : b.id
      return timeA - timeB
    }
    case 'created-desc': {
      const timeA = a.created_at ? new Date(a.created_at).getTime() : a.id
      const timeB = b.created_at ? new Date(b.created_at).getTime() : b.id
      return timeB - timeA
    }
    default:
      return 0
  }
})

// 区分
const withTextPresets = sortedPresets.filter((p) => p.text !== undefined && p.text !== null && p.text.trim() !== '')
const withoutTextPresets = sortedPresets.filter((p) => !p.text || p.text.trim() === '')
```
