### 4. Implementation logic

- [ ] **Validation & resolution on write (`POST` and `PUT`)**:
  - `name` must be non-empty after `.strip()` (else raise `HTTPException(status_code=422, detail="Group name must not be empty")`).
  - Build `index = VariantIndex.from_session(db)`.
  - **Master resolution** (on `POST`, or on `PUT` when `master_variant_id is not None` or `master_role is not None`):
    - Prefer `master_variant_id` if `is not None`: verify `index.role_of(master_variant_id)` is not None (else 422).
    - Else if `master_role` is non-empty: `ck = index.classify(master_role)`; require `ck.kind == KeyKind.ROLE` and `ck.variant_id is not None` (else 422).
    - Else on `POST`: raise 422.
  - **Slave resolution** (on `POST`, or on `PUT` when `slave_variant_ids is not None` or `slave_roles is not None`):
    - Prefer `slave_variant_ids` if `is not None`: verify each `vid` exists in `index` (else 422); deduplicate preserving order and exclude `master_variant_id`.
    - Else if `slave_roles is not None`: classify each role (`KeyKind.ROLE`, else 422); deduplicate `variant_id` preserving order and exclude `master_variant_id`.
    - Else on `POST`: `[]`.
  - **Persistence**: set `group.master_variant_id = resolved_master_id`, `group.master_role = index.role_of(resolved_master_id)` (non-null copy), `group.slave_roles = "[]"`. Replace `group.members` with `[models.ParamSyncGroupMember(variant_id=vid) for vid in resolved_slave_ids]` (flush before re-adding on `PUT`).
- [ ] **Read path (`_group_to_schema` / `list_param_sync_groups`)**:
  - `master_variant_id = group.master_variant_id`; `slave_variant_ids = [m.variant_id for m in group.members if index.role_of(m.variant_id) is not None]`.
  - `master_role = index.role_of(master_variant_id) or group.master_role`; `slave_roles = [index.role_of(vid) for vid in slave_variant_ids]`.
  - Populate `variants: list[VariantRef]` for `{master_variant_id, *slave_variant_ids}` from `MappingVariant` + `master.display_name` (batch-load once per request).
- [ ] Do not touch `routers/workflows.py` (owned by T3).
