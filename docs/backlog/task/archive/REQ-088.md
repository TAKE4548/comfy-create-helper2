## 3. 実装要件 (Implementation Logic)
### 3.1 `useGenerationStore.ts` の変更:
- 送信する `workflow` (JSON) を `currentWorkflow` 状態変数に保存する。
- 以下の状態変数を追加・管理する:
  - `currentNode`: `{ id: string; name: string } | null`
  - `nodeProgress`: `{ value: number; max: number; percentage: number; nodeId?: string; nodeName?: string } | null`
  - `generationStartTime`: `number | null`
- WebSocketメッセージ処理の修正・追加:
  - `execution_start` イベント時: `generationStartTime: Date.now()`, `currentNode: null`, `nodeProgress: null` を設定。
  - `executing` イベント (新設) 時: `data.node` からノードIDを取得。`currentWorkflow` から該当ノードの `_meta.title` または `class_type` を引き、`currentNode` に設定。`nodeProgress` をリセット（%を0に初期化）。
  - `progress` イベント時: `data.node` から該当ノードの `_meta.title` または `class_type` を引き、`nodeProgress` を更新。
  - `executed`, `execution_complete`, `execution_error` イベント時: 生成が完全に終了したと判定されるタイミングで、`generationStartTime`, `currentNode`, `nodeProgress`, `currentWorkflow` を `null` にリセット。

### 3.2 `DesktopLayout.tsx` & `MobileLayout.tsx` の変更:
- `useGenerationStore` から新設した状態変数 (`nodeProgress`, `currentNode`, `generationStartTime`, `isGenerating`) をインポート。
- UI上に全体バッチ進捗と、詳細ノード進捗の2本のバーを表示する。
  - **全体バッチ進捗**: ジョブの完了数/総数に基づく。テキストとして `全体進捗: m/n 枚目 (xx%)` を表示。
  - **詳細ノード進捗**: `currentNode` や `nodeProgress` に基づく。実行中のノード名とノードのパーセンテージ（例: `実行中: KSampler (45%)`）を表示。
- 経過時間と残り時間（ETA）をリアルタイムに計算して表示する。
  - `generationStartTime` がセットされている間、1秒間隔の `setInterval` 等を用いて経過時間（秒単位）を表示する。
  - `ETA = 経過時間 * (100 - 全体進捗%) / 全体進捗%` から概算の残り予測時間を算出し、`残り約: Y秒` として表示する。
