## First Alternate Call: Read-only Probe Only

同cwd/runtime、metadataをT7の値と先に照合し、alternate contextを1つだけ比較する。
read-only probe1回/wall30秒。コマンド:
```powershell
node -e 'const fs=require("fs"),p=require("path");const ts=[".","src","src/test","src/test/setup.ts"];const rows=ts.flatMap(t=>[t,p.resolve(t)].map(x=>{const r={path:x};try{const s=fs.statSync(x);r.stat={ok:true,file:s.isFile(),directory:s.isDirectory()};}catch(e){r.stat={ok:false,code:e.code,message:e.message};}try{r.native={ok:true,value:fs.realpathSync.native(x)};}catch(e){r.native={ok:false,code:e.code,syscall:e.syscall,message:e.message};}return r;}));let read;try{read={ok:true,bytes:fs.readFileSync("src/test/setup.ts").length};}catch(e){read={ok:false,code:e.code,message:e.message};}const allPass=rows.every(r=>r.stat.ok&&r.native.ok)&&read.ok;const eperm=rows.every(r=>r.stat.ok&&!r.native.ok&&r.native.code==="EPERM")&&read.ok;console.log(JSON.stringify({version:process.version,execPath:process.execPath,cwd:process.cwd(),diagnosticEnvPresent:Object.hasOwn(process.env,"VITE_REQ344_QUERY_DIAGNOSTICS"),rows,read,result:allPass?"BASELINE_NATIVE_PASS":eperm?"BASELINE_NATIVE_EPERM":"OTHER_OR_MIXED"},null,2));process.exitCode=allPass?0:eperm?2:3;' *> ../docs/design/REQ-344-environment-alternate-native.json
$req344AlternateExit = $LASTEXITCODE
Get-Content -LiteralPath '../docs/design/REQ-344-environment-alternate-native.json' -Raw
exit $req344AlternateExit

```

native全成功＋metadata一致でもcontext差を支持するだけで、sandbox/ACL根因の証明ではない。
EPERM/別error/期限/証拠不足ならstop、testsなしで親へ。
cache状態をT7のread-only commandsで一度照合する。安全性不明ならprobe結果だけ返す。

## Focused Retry: Conditional, At Most Once

以下全て必要: alternate native成功、同metadata、cache安全性充足、
focused retryまで人の明示承認。1回/wall120秒、同alternate context。
toolは同じrequire_escalated、case timeout/pool設定を変えない。
```powershell
$env:VITE_REQ344_QUERY_DIAGNOSTICS = '1'
try {
  npx vitest run src/pages/__tests__/GeneratePage.test.tsx --testNamePattern 'REQ-161: Generate button follows workflow load state' --reporter=verbose *> ../docs/design/REQ-344-environment-focused.log
  $req344EnvironmentDiagnosticExit = $LASTEXITCODE
} finally {
  Remove-Item Env:VITE_REQ344_QUERY_DIAGNOSTICS -ErrorAction SilentlyContinue
  Write-Output ("diagnostic env present: " + (Test-Path Env:VITE_REQ344_QUERY_DIAGNOSTICS))
}
Get-Content -LiteralPath '../docs/design/REQ-344-environment-focused.log' -Tail 35
exit $req344EnvironmentDiagnosticExit

```

正常完了2case PASS・warning0・key/queryFn/mock一致/observer総数の証拠・env解除が必要。
EPERM/collection0/期限/metadata変化/警告/不足ならFAILまたはINCONCLUSIVE、T9 NOT-RUN。
warning未出力とcollection不能をwarning0の成功証拠にしない。
codeが取れない停止はINCONCLUSIVE。envを確実に解除できなければT9へ進めない。
