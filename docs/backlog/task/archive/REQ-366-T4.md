## 4. 実装要件 (Implementation Logic)
- [ ] `scripts/verify_ui_invariants.py` を実装する:
  - 対象拡張子: `.css` (主対象), `.tsx`, `.ts`, `.jsx`, `.js` (走査対象: `frontend/src`)
  - ファイル読み込み時は `encoding="utf-8-sig"` または BOM 除去を行い、BOM 付き/なしの両方に耐性を持たせる。
  - 以下のルールを判定:
    - `rule-no-global-font-floor`: CSSファイル内のグローバルセレクタでの一括 `font-size: 11px` や `[class~='text-[8px]'] { font-size: 11px; }`
    - `rule-no-raw-100vh`: CSSでの `height: 100vh`、および TSX/JSX でのトークン文字列 `h-[100vh]`, `min-h-[100vh]`
    - `rule-no-indiscriminate-important`: CSS内の `!important` 記述
  - 例外コメント検出:
    - 同一行または直前行に `/* ui-invariant-ignore: <rule-id> reason: <理由> */` または `// ui-invariant-ignore: <rule-id>` が存在する場合は violation から除外。
  - スクリプト内 allowlist: 移行期レガシー用除外設定。
  - CLI: 違反があれば Exit Code 1、違反ゼロなら Exit Code 0。
- [ ] `backend/tests/governance/test_ui_invariants.py` を実装する:

  - CLI Exit Code 1 / 0 の結合テスト。
