## 3. UI アーキタイプと外科的制約
<constraints>
- **SPEC-TESTING v2.1 厳守**: ファイル名・ディレクトリ名に `req435` / `REQ-435` を絶対に含めないこと。全 `test()` / `test.step()` に `[REQ-435/AC-n]` タグと `{ tag: '@critical' }` を付与すること。
- **配置計画厳守**: `docs/design/REQ-435-test-plan.md` §2.2 の親 `test()` 名と 1 テスト最大 6 ステップ上限を厳守すること（`workflow_validator.py test-hygiene REQ-435` の警告 0 を目標）。
- **外部 I/O 切断**: 全 spec で `page.routeWebSocket((url) => url.pathname === '/api/ws', ...)` および `page.route((url) => url.pathname.startsWith('/api/'), ...)` を `page.goto` より前に登録し、Zero-GPU / スタンドアロンで決定論的に実行すること。
- **実測手法**: Hit-Slop 実効矩形は `getBoundingClientRect()` と `getComputedStyle(el, '::before')`（`top/right/bottom/left`・`padding-box` 基準）から算出し、幅 ≥ 44px・高さ ≥ 44px かつ隣接矩形の交差幅・交差高が 0 であることを検証する。
</constraints>
