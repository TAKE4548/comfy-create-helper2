## 3. 実装要件 (Implementation Logic)
- [ ] `tagChipCollisionDetection.ts` の作成:
  1. `collisionRect` または `droppableContainers` が空、あるいは `droppableContainers.length === 0` の場合は `[]` を返却する。
  2. `droppableContainers` を走査し、`active` 自身（`c.id === active?.id`）や `c.disabled` をスキップする。
  3. 各 droppable に対し `droppableRects.get(c.id)` から矩形を取得。矩形が存在しない場合はスキップ。
  4. AABB 重複矩形（幅 `w`、高さ `h`）を計算:
     - `w = Math.max(0, Math.min(collisionRect.right, targetRect.right) - Math.max(collisionRect.left, targetRect.left))`
     - `h = Math.max(0, Math.min(collisionRect.bottom, targetRect.bottom) - Math.max(collisionRect.top, targetRect.top))`
     - `intersectionArea = w * h`
     - `targetArea = targetRect.width * targetRect.height`
     - `activeArea = collisionRect.width * collisionRect.height`
     - `targetOverlap = targetArea > 0 ? intersectionArea / targetArea : 0`
     - `activeOverlap = activeArea > 0 ? intersectionArea / activeArea : 0`
     - `maxOverlap = Math.max(targetOverlap, activeOverlap)`
  5. ポインタ内包判定:
     - `pointerCoordinates` が存在し、`x >= targetRect.left && x <= targetRect.right && y >= targetRect.top && y <= targetRect.bottom` のとき `isPointerInside = true`。
  6. 閾値判定:
     - `isPointerInside || maxOverlap >= (options.overlapThreshold ?? 0.20)` を満たす候補のみを抽出。
     - 微小接触（角の 1〜2% 接触等、20% 未満かつポインタ外）は除外。
  7. スコアリングとヒステリシス（チャタリング防止）:
     - ポインタ内包候補には優先ボーナスを付与（例: スコア +1.0）。
     - 複数候補が存在する場合:
       - 直前の `lastActiveCollisionId` と一致する候補がある場合、競合相手のスコアが `last` のスコアを `EPSILON = 0.05` 上回らない限り `last` を優先維持する。
  8. ソートして降順で最上位候補を先頭にした `Collision[]` を返却（該当なしなら `[]`）。
  9. `lastActiveCollisionId` を最上位候補の ID で更新（候補なしなら `null`）。
- [ ] `tagChipCollisionDetection.test.ts` の作成:
  - 20% 重複で中心点到達前でも衝突検知されることの検証。
  - ポインタが相手領域に入った瞬間に衝突検知されることの検証。
  - 5% 未満の角微小接触で衝突が弾かれることの検証。
  - 境界線上でのヒステリシスによるチャタリング抑止の検証。
  - 完全に領域外へ出た場合に空配列 `[]` が返却されることの検証。
