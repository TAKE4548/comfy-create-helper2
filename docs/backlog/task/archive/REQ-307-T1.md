# REQ-307-T1 キュー投入失敗理由の正規化

公開型 `QueueSubmissionFailure = { reason: string; outcome: 'failed' | 'unconfirmed' }` と純粋関数 `parseQueueSubmissionFailure(error: unknown): QueueSubmissionFailure` を新設。HTTP Error の `API error 400: <body>` から JSON の `error.message`、`error.details`、`detail`、`node_errors` の説明可能な文字列を読む。平文も受け取る。空・空白・HTTP 番号だけ・未知オブジェクトは `理由を特定できませんでした`。長さや繰り返しだけで説明を捨てない。HTML 風の文字列は後段で React テキストとして表示する。タイムアウトと応答不明の通信障害は `unconfirmed`、明示的な拒否は `failed`。
