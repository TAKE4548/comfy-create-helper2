# REQ-363-T5: パラメータ行: 無条件2行化を撤廃し、余白を無駄にしないスマート適応型1行レイアウト

## 1. 概要と目的
### パラメータ行: 無条件2行化を撤廃し、余白を無駄にしないスマート適応型1行レイアウト
- 数値ステッパー・トグルは「厳格に1行維持」: Sampler Steps Rough や CFG、Denoise、Boolean はステッパー幅が約 105px とコンパクト。flex-1 pr-2 のラベル領域（約 200px）で確実に1行のまま快適に収まるため2行化しない。
- セレクトボックスの適正幅化 (w-36固定撤廃): ドロップダウン選択（Sampler, Scheduler）は gap-2 に詰め、セレクト幅を w-[125px]（または流動）に最適化。長いラベルも 1 行（極端に長い場合のみ leading-tight で高さを抑えた軽微な2行化）にとどめ、余白の目立ちを根絶。
- モーダルパディングの引き締め: AddAssetModal 等の余白を p-3.5（14px）に最適化。
