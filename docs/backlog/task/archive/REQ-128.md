### 2.2 既存の handleSave 実装 (修正前)
```typescript
  const handleSave = async () => {
    const canvas = canvasRef.current
    if (!canvas) return

    setIsSaving(true)
    try {
      // 1. Get blob from canvas (問題: 表示用500x500キャンバスがそのまま使われる)
      const blob = await new Promise<Blob | null>((resolve) => canvas.toBlob(resolve, 'image/png'))
      if (!blob) throw new Error('Canvas blob generation failed')

      // 2. Upload image
      const uploadRes = await snapshotsApi.upload(blob)

      // 3. Retrieve parent snapshot details
      const parentSnapshot = await snapshotsApi.get(snapshot.id)

      // 4. Create new snapshot
      await snapshotsApi.create({
        workflow_id: parentSnapshot.workflow_id,
        image_path: uploadRes.image_path,
        params: parentSnapshot.params,
        source_snapshot_id: parentSnapshot.id,
      })

      onSaved()
      onClose()
    } catch (err: any) {
      console.error(err)
      alert('画像の保存に失敗しました: ' + err.message)
    } finally {
      setIsSaving(false)
    }
  }
```

## 3. 実装要件 (Implementation Logic)
- [x] `handleSave` 内で `imageObj` が存在しない場合は処理を中断する。
- [x] `document.createElement('canvas')` を使用し、`naturalWidth` x `naturalHeight` の解像度を持つオフスクリーンキャンバスを生成する。
- [x] 背景として `imageObj` をオフスクリーンキャンバスの全面 (0, 0, naturalWidth, naturalHeight) に描画する。
- [x] `boundingBox` および `speechText` が存在する場合:
  - プレビューキャンバスとの倍率 `scaleFactor = imageObj.naturalWidth / canvasDimensions.width` を算出。
  - 吹き出し枠内 (`boundingBox.x, y, w, h` 直接指定、1pxインセット) を `rgba(255, 255, 255, 0.92)` で塗りつぶす。
  - `layoutVerticalText` を使用して、元画像スケールに応じたテキスト配置とフォントサイズ算出を実施 (`startFontSize = 36 * scaleFactor`, `minFontSize = 8 * scaleFactor`)。
  - セリフ文字を `activeFontFamily` で黒色塗りつぶし描画する。
- [x] 緑の検出枠、デバッグ枠、ROI矩形などの UI オーバーレイはオフスクリーンキャンバスへは一切描画しない。
- [x] オフスクリーンキャンバスの `toBlob(resolve, 'image/png')` から取得した Blob をアップロードする。
