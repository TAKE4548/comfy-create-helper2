## 3. 実装要件 (Implementation Logic)
- [ ] `frontend/src/components/TagChipEditor/TagChipTranslationCard.tsx`
  - **コンポーネント構造**:
    - `fixed z-[100] w-[320px] bg-[#18181C] border border-[rgba(255,255,255,0.15)] rounded-lg shadow-2xl overflow-hidden flex flex-col text-xs`
  - **位置初期化とクランプ**:
    - `anchorRect` から初期位置 `(left, top)` を算出（画面下側にはみ出る場合は上側に退避）。
    - ドラッグ中および画面リサイズ時の座標を `[0, window.innerWidth - 320]` および `[0, window.innerHeight - 200]` にクランプ。
    - `window.addEventListener('resize', ...)` を登録し、画面リサイズ時にも現在位置をビューポート内に再クランプ（アンマウント時にクリーンアップ）。
  - **Pointer Events によるドラッグ操作 (AC-5, AC-6)**:
    - ヘッダーバーに `onPointerDown`, `onPointerMove`, `onPointerUp`, `onPointerCancel` を付与し、`setPointerCapture` / `releasePointerCapture` を確実に実行（アンマウント時のキャプチャリーク防止）。
    - ヘッダーに `touch-action: none`（`touch-none`）と `cursor-move select-none` を適用し、モバイルでのブラウザスクロールを抑止。
    - 訳文本文コンテナ（`max-h-[160px] overflow-y-auto select-text`）には `onPointerDown={(e) => e.stopPropagation()}` を付与し、本文ドラッグによるカード移動を完全防止。
  - **和訳フェッチと状態管理 (AC-3, AC-4)**:
    - マウント時および `text` 変更時に `translateApi.translatePrompt({ prompt: text, source_lang: 'en', target_lang: 'ja' })` を呼び出し。
    - `isLoading`（ローディングスピナー / "和訳を取得中..."）。
    - `translatedText`（成功時の訳文表示）。
    - `error`（エラー表示と [再試行] ボタン。アプリは絶対にクラッシュさせない）。
  - **クリップボードコピー (AC-7)**:
    - コピーボタン押下で `navigator.clipboard.writeText(translatedText)` を実行。
    - アイコンを `<Check size={12} className="text-emerald-400" />` に切り替え、1.5秒後に元に戻す。
  - **クローズ処理 (AC-8)**:
    - [✕] ボタンクリック、`Escape` キー押下、カード外クリック（`mousedown` / `touchstart`）で `onClose()` を呼び出し。
