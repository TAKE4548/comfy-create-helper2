## 3. 実装要件 (Implementation Logic)
1. **`backend/app/services/training_manager.py`**:
   - スケジュール計算: `total_steps = (items * repeats // batch_size) * epochs`。
   - `config.toml` 生成: `mixed_precision = "bf16"`, `gradient_checkpointing = true`, `text_encoder_lr = 0.0` を強制適用。
   - サブプロセス起動・PID 記録・安全中断（プロセスグループ考慮）。
   - 標準出力パースループとアクティブ WebSocket 接続への配信。
   - 完了時の `.safetensors` ファイル存在・サイズ完全性チェック。
2. **`backend/app/routers/training_router.py`**:
   - `POST /api/training/jobs` (作成)
   - `POST /api/training/jobs/{job_id}/start` (起動)
   - `POST /api/training/jobs/{job_id}/stop` (安全中断)
   - `GET /api/training/jobs/{job_id}` (状態取得)
   - `GET /api/training/status` (GPUガード確認用)
   - `WebSocket /api/training/ws/{job_id}` (テレメトリストリーミング)
3. **`backend/app/main.py`**:
   - `training_router` をインポートし、`app.include_router(training_router.router)` を登録。

## 4. 完了条件と検証
- [ ] スケジュール数式が正しく計算されること（20枚, 10 repeats, 1 batch, 10 epochs -> 2,000 steps）。
