# REQ-423-T1: バックエンド API 契約と workflow_mappings.input_name 永続化往復検証

## 1. 概要と目的
本タスクは **AC-2 のバックエンド永続化部分** を担当する（AC-1 は T3/T4、AC-2 のフロントエンド保存は T4、AC-3/AC-4 は T2/T5 が担当）。
ワークフローの作成（`POST /api/workflows`）、更新（`PUT /api/workflows/{id}`）、および複製（`POST /api/workflows/{id}/duplicate`）において、マッピングの `input_name` 属性（例: `"noise_seed"`, `"steps"`）が DB テーブル `workflow_mappings.input_name` に確実に永続化され、`GET /api/workflows/{id}` で欠損なく往復取得できることを保証する統合回帰テストを `backend/tests/integration/api/test_workflows.py` に追加する。

- **対象ファイル**: `backend/tests/integration/api/test_workflows.py`

- **行番号目安**: 末尾付近 (L1100以降)
