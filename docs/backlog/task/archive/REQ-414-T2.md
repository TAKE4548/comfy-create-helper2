# REQ-414-T2: SeedFieldコンポーネントの大整数入力対応

## 1. 概要と目的
`SeedField.tsx` において、`seedModel.ts` からエクスポートされた `MAX_SAFE_SEED` をインポートし、`<input type="number">` の `max` 属性を `MAX_SAFE_SEED` に更新する。大整数Seed（ComfyUI乱数 `1125899906842624` や `MAX_SAFE_SEED`）が投入された際にエラーなく正常表示・編集できることを確認する単体テストを追加する。

- **行番号目安**: `SeedField.tsx:4-50`, `SeedField.test.tsx:20-32`
