## 2. 密閉コンテキスト (Hermetic Context)

### 2.1 修正前コード (MobileLayout.tsx L687)
```tsx
<button id="generate-btn-mobile" onClick={handleGenerateSets} disabled={!selectedWorkflowId || !isConnected}
  className="flex-1 flex items-center justify-center gap-2 py-3 rounded-xl bg-accent-green text-background font-bold text-sm hover:brightness-110 disabled:opacity-50 transition-all active:scale-95">
  <Zap size={16} />{isGenerating ? 'Generate Batch (キュー追加)' : 'Generate Batch'}
</button>
```

### 2.2 データフロー
- `useGeneratePageState` フックが `workflow`（React Query結果）を返す
- `MobileLayout` / `DesktopLayout` は `useGeneratePageState` の返却値を props として受け取る
- `workflow` が `undefined` の間は `injectParams`（useGenerateAction.ts L38）が即座に `return` し、空JSONがComfyUIに送信される
- ComfyUIは有効なプロンプトを受け取れず `prompt_id: null` を返す → エラートースト表示

### 2.3 根本原因
- `isConnected`（WebSocket接続）は `workflow` のHTTPフェッチより先に確立される
- モバイルLAN環境ではキャッシュがなく `workflow` の取得に数秒かかる
- その間にボタンを押すと `promptId: null` → エラートースト `[Set X] のキュー投入に失敗しました`

### 2.4 修正方針
- `disabled` 条件に `!workflow` を追加するだけで安全弁として機能する
- `workflow` prop がコンポーネントに渡されているか確認し、渡されていない場合は追加する

</hermetic_context>
