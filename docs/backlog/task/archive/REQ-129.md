# TASK-REQ-129-T1: MobileLayout への ParamSyncModal コンポーネント組み込みおよび状態連動

- **Parent PBI**: [REQ-129](../../pbi/active/REQ-129.md)
- **Design Doc**: [REQ-129.md](../../../design/REQ-129.md)
- **Target Files**: `frontend/src/pages/GeneratePage/components/MobileLayout.tsx`

---

## 1. 目的とタスク概要
`MobileLayout.tsx` において、`ParamSyncModal` のインポート、Zustand store (`useGenerationStore`) からの同期グループ状態取得、`useState` によるモーダル表示制御、`<ParamPanel />` への各種プロパティ・ハンドラ伝達、および `<ParamSyncModal />` の JSX 描画を追加し、モバイル画面でもパラメータ同期設定モーダルを起動・操作できるようにする。

---

## 2. 必要なコンテキスト & スニペット情報 (Encapsulated Context)

### 2.1 対象ファイル
- `frontend/src/pages/GeneratePage/components/MobileLayout.tsx`

### 2.2 追加するインポート
```tsx
import { ParamSyncModal } from '../../../components/ParamSyncModal'
```

### 2.3 Store取得およびローカルState
```tsx
// useGenerationStore から取得
const paramSyncGroups = useGenerationStore((state) => state.paramSyncGroups)
const toggleParamSyncGroup = useGenerationStore((state) => state.toggleParamSyncGroup)

// ローカル State
const [isParamSyncSettingsOpen, setIsParamSyncSettingsOpen] = useState(false)
```

### 2.4 `<ParamPanel />` への Props 伝達
```tsx
<ParamPanel
  mobile
  paramMappings={paramMappings}
  paramValues={paramValues}
  setParamValues={setParamValues}
  loras={loras}
  paramTypeMasters={paramTypeMasters}
  batchSize={batchSize}
  setBatchSize={setBatchSize}
  seedMode={seedMode}
  setSeedMode={setSeedMode}
  seed={seed}
  setSeed={setSeed}
  comfyObjectInfo={comfyObjectInfo}
  bypassProfiles={bypassProfiles}
  onToggleBypass={(profileId, isEnabled) => updateBypassProfile(profileId, { is_enabled: isEnabled })}
  onOpenBypassSettings={() => setIsBypassSettingsOpen(true)}
  paramSyncGroups={paramSyncGroups}
  onToggleParamSync={(groupId, isEnabled) => toggleParamSyncGroup(groupId, isEnabled)}
  onOpenParamSyncSettings={() => setIsParamSyncSettingsOpen(true)}
/>
```

### 2.5 JSX 描画（モーダルレンダリング）
```tsx
{isParamSyncSettingsOpen && (
  <ParamSyncModal
    onClose={() => setIsParamSyncSettingsOpen(false)}
  />
)}
```
