# REQ-356-T3: [Backend Unit] backend/tests/unit/ への純粋ロジック・スキーマ・ヘルパーテスト移行・PBIタグ付与

## 1. 概要と目的
DB非接続・外部I/O不要の純粋ロジックテスト（Pydantic スキーマ検証、設定パース、純粋ヘルパー関数）を `backend/tests/unit/` 階層へ新設・移動する（AC-2, AC-11）。
各テストケースに `[REQ-xxx/AC-n]` のタグプレフィックスを付与し（AC-9, AC-15）、ファイル名からチケット番号を除去する（AC-1）。
これらが DB や外部モックを一切読み込まず、超高速（数秒以内）に単独実行できることを保証する。
