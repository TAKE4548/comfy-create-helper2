# REQ-336-T4: Frontend 型定義拡張とMapping/Stage/Group APIクライアント

## 1. 概要と目的
フロントエンドの API 型定義に `MappingGroupMaster`, `StageMaster`, `MappingMasterV2`, `MappingVariant`, `CascadePreviewResult`, `CascadeRenamePayload` 等を追加し、マッピングマスター・ステージ・グループの各ドメイン API クライアント関数（CRUD、カスケードプレビュー・置換等）を整備する。

## 2. ターゲット識別
- **対象ファイル**:
  - `frontend/src/api/types.ts` (L10〜L35 付近)
  - `frontend/src/api/domains/mappingMasters.ts` (および新規 `stageMasters.ts`, `mappingGroups.ts`)
- **対象シンボル**: `MappingGroupMaster`, `StageMaster`, `MappingMasterV2`, `MappingVariant`, `CascadePreviewResult`, `stageMastersApi`, `mappingGroupsApi`, `mappingMastersApi`

### 3.2 API クライアントシグネチャ
```typescript
// frontend/src/api/domains/stageMasters.ts
export const stageMastersApi = {
  list: (): Promise<StageMaster[]> => apiClient.get('/api/stage-masters'),
  create: (data: Partial<StageMaster>): Promise<StageMaster> => apiClient.post('/api/stage-masters', data),
  update: (id: number, data: Partial<StageMaster>): Promise<StageMaster> => apiClient.put(`/api/stage-masters/${id}`, data),
  delete: (id: number): Promise<void> => apiClient.delete(`/api/stage-masters/${id}`),
  cascadePreview: (id: number, newSuffix: string): Promise<CascadePreviewResult> =>
    apiClient.get(`/api/stage-masters/${id}/cascade-preview`, { params: { new_suffix: newSuffix } }),
  cascadeRename: (id: number, payload: CascadeRenamePayload): Promise<{ success: boolean; replaced_count: number }> =>
    apiClient.post(`/api/stage-masters/${id}/cascade-rename`, payload),
}
```
