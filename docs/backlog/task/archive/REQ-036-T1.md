## 3. 実装要件 (Implementation Logic)
- [x] `backend/app/schemas/lora.py` に `ComfyLoraModel` スキーマを追加する。
- [x] `backend/app/schemas/__init__.py` にて `ComfyLoraModel` をインポートし、`__all__` に追加する。
- [x] `backend/app/routers/loras.py` に `GET /comfy-models` エエンドポイントを実装する。
  - `httpx.AsyncClient` を利用して `settings.comfy_url` + `/api/models/loras` へリクエストを送信する。
  - エラー（`httpx.RequestError` やタイムアウト）またはステータスコード404の場合、フォールバックとして `/api/experiment/models/loras` を呼び出す。
  - 両方のComfyUI接続でエラーが発生した場合は空のリスト `[]` を返し、エラーを `logger.warning` または `logger.exception` で出力する。
  - レスポンス内のモデルパス一覧を取得し、バックスラッシュ `\` をスラッシュ `/` に置換して正規化する。
  - DBから現在登録されている全LoRAの `file_path` を取得し、マッピング（`file_path -> lora_id`）を作成する。
  - ComfyUIのモデル名ごとに、DB登録済みかをチェックして `ComfyLoraModel` リストを構築する。
    - `model_name` には正規化したパスのベース名（ファイル名部分、例: `model.safetensors`）を格納する。
    - `file_path` には正規化した相対パス（例: `folder/model.safetensors`）を格納する。
  - **ソート順**: 未登録 (`is_registered == False`) を上位にし、それぞれアルファベット順にソートする。
