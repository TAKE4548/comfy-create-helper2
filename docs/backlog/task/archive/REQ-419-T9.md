## 5. 変更仕様

### 5-1. `CandidateDefinition` 拡張とランク（`workflowNodeUtils.ts` 現 L7-11, L72-102）
現状（抜粋）:
```ts
export interface CandidateDefinition {
  expectedClassTypes: readonly string[]
  titlePatterns: readonly string[]
  paramNames: readonly string[]
}
  ...
  const expectedClasses = new Set(definition.expectedClassTypes)
  const normalizedPatterns = definition.titlePatterns.map(normalizeCandidateText).filter(Boolean)
  ...
    const classMatch = expectedClasses.has(classType)
    const exactTitle = !!rawTitle && definition.titlePatterns.includes(rawTitle)
    const normalizedTitle = !!rawTitle && normalizedPatterns.includes(normalizedRawTitle)
    ...
    const paramMatch = definition.paramNames.some((name) => inputNames.includes(name))
    const tier: RankedNodeCandidate['tier'] = classMatch
      ? exactTitle ? 0 : normalizedTitle ? 1 : 2
      : paramMatch ? 3 : 4
```
変更（既存フィールドは不変、任意フィールドを追加）:
```ts
export interface CandidateDefinition {
  expectedClassTypes: readonly string[]
  titlePatterns: readonly string[]          // exact パターン
  paramNames: readonly string[]
  /** 指定時: class 一致は「classType 一致かつ paramName がノード入力に存在」するペアがあること */
  entryPairs?: ReadonlyArray<{ classType: string; paramName: string }>
  /** 指定時: class 一致かつ正規化タイトルが正規化 contains パターンを含めば tier 1 */
  containsPatterns?: readonly string[]
}
```
- `entryPairs` が `undefined` のときは現行ロジックを完全に維持する（既存の REQ-358 テストと旧呼び出しを壊さない）。
- `entryPairs` 指定時: `classMatch = entryPairs.some(p => p.classType === classType && inputNames.includes(p.paramName))`、`paramMatch = entryPairs.some(p => inputNames.includes(p.paramName)) || paramNames.some(...)`。
- `normalizedTitle` 判定に「`containsPatterns` のいずれか（正規化後、空は除外）を `normalizedRawTitle` が含む」を OR で加える（`containsPatterns` 指定時のみ）。
- `stageRank`・`stageAffinity`・score 帯・並び順・`reasons` の文字列は不変。

### 5-2. `variantCandidateDefinition.ts`（新規）
```ts

  variant: Pick<MappingVariant, 'rule_entries' | 'selector_patterns'> | null | undefined

```
- `rule_entries` を priority 昇順（同値は入力順）に並べ、`entryPairs = [{classType: class_type, paramName: param_name}]`、`expectedClassTypes` = class_type の重複除去、`paramNames` = param_name の重複除去（priority 順）。
- `selector_patterns` を priority 昇順に並べ、`match_type === 'exact'` を `titlePatterns`、`'contains'`（未指定・その他は contains 扱い。スキャナと同じ）を `containsPatterns`。
- `variant` が null/undefined、または `rule_entries` が無い／空のときは `{ expectedClassTypes: [], titlePatterns: [], paramNames: [], entryPairs: [], containsPatterns: [] }`（旧列へのフォールバックはしない）。
- Master オブジェクトを引数に取らない（旧列を読めない形にする）。
