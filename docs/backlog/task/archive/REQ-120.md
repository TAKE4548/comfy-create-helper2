## 3. 実装要件 (Implementation Logic)

### 3-1. バックエンドフォントルーターの作成
- [x] 1. **`backend/app/routers/fonts.py` の新規作成**:
  - `platform` を使用して実行環境のOSを判別し、フォント格納ディレクトリを選択する。
    - Windowsの場合: `C:\Windows\Fonts`
    - macOSの場合: `/Library/Fonts` または `/System/Library/Fonts`
    - Linuxの場合: `/usr/share/fonts` または `/usr/local/share/fonts`
  - パス走査には `pathlib.Path` を使用し、Windows/Linux のパス区切り文字の違いを抽象化する。
  - 日本語システムフォントファイルと表示名のマッピングテーブルを作成し、ディレクトリ内に該当ファイルがあれば表示名付きで一覧化する。
    - `"msgothic.ttc"` -> `"ＭＳ ゴシック (MS Gothic)"`
    - `"msmincho.ttc"` -> `"ＭＳ 明朝 (MS Mincho)"`
    - `"meiryo.ttc"` -> `"メイリオ (Meiryo)"`
    - `"meiryob.ttc"` -> `"メイリオ ボールド (Meiryo Bold)"`
    - `"yugothm.ttc"` -> `"遊ゴシック Medium (Yu Gothic Medium)"`
    - `"yugothb.ttc"` -> `"遊ゴシック Bold (Yu Gothic Bold)"`
    - `"yumin.ttf"` -> `"遊明朝 (Yu Mincho)"`
    - `"bizudgothic.ttc"` -> `"BIZ UDゴシック (BIZ UD Gothic)"`
    - `"bizudminchomedium.ttc"` -> `"BIZ UD明朝 (BIZ UD Mincho)"`
  - `GET /api/fonts` エンドポイントを実装し、存在するフォントの `name` と `file_name` の一覧を返す。
  - `GET /api/fonts/{font_filename}` エンドポイントを実装し、フォントファイルを `FileResponse` でバイナリ返却する。ファイルが存在しない場合は 404 エラーをスローする。
- [x] 2. **`backend/app/main.py` へのルーター登録**:
  - `app.include_router(fonts.router)` を追記する。

### 3-3. フロントエンド吹き出し編集モーダルの更新
- [x] 1. **フォント一覧の取得と動的ロード**:
  - モーダルマウント時に `fontsApi.list()` を呼び出して `fontList` に格納。デフォルトフォントとして最初の要素（または `msgothic.ttc` 等）を選択・適用。
  - フォント変更時、ブラウザの `FontFace` API を用いて非同期ダウンロードし、`document.fonts.add` で登録して `activeFontFamily` を更新。
    - フォントファミリー名: `server-font-${fontFileName.replace(/\./g, '-')}`
    - ロード中は `isFontLoading` を `true` にし、Canvas再描画時に「ロード中」の状態表示を可能にする。
- [x] 2. **縦書きレイアウト関数の実装**:
  - `layoutVerticalText(text: string, fontSize: number, maxHeight: number): string[]`
  - テキストを改行コードで分割し、縦方向に文字を追加。`maxHeight` を超えるか `\n` で左隣の列へ折り返す。
  - カッコや長音記号等の縦書き文字マッピング（`ー` → `｜`, `「` → `﹁` 等）を適用する。
- [x] 3. **フォントサイズ自動計算（ステップダウン探索）**:
  - `maxFontSize = 36`, `minFontSize = 8` の範囲で、`layoutVerticalText` で得られた列数 $N$ から `totalWidth = N * fontSize * 1.3` （1.3倍は列間のスペーシング係数）を算出し、`totalWidth <= maxWidth` となる最大のフォントサイズを決定する。
- [x] 4. **Canvasへの縦書き描画**:
  - 複数列を右端から左端に向けて配置。
  - X座標: `colX = startX - colIndex * (fontSize * 1.3)` （`startX` はテキスト全体幅の半分オフセット）
  - Y座標: 各列 of 文字数に基づいて上下センタリング。文字ごとに `fontSize` ずつ下にずらして `ctx.fillText(char, x, y)` を実行。
  - Canvas設定:
    - `ctx.font = "bold " + computedFontSize + "px " + activeFontFamily`
    - `ctx.textBaseline = "middle"`
    - `ctx.textAlign = "center"`
- [x] 5. **UI of 修正**:
  - フォント選択用のドロップダウンメニュー (`<select>`) を追加。
  - フォント読み込み中はローディングインジケーター等を表示。
  - 従来の「フォントサイズ」スライダーUIは削除。
