# Task Card: REQ-383-T4 — DesktopLayout におけるリール・履歴ペイン双方向同期・ローカルClose導線統合および実ブラウザE2E検証

- **Role**: `engineer` / **Assigned Skill**: `dev-task` / **Change Kind**: `code` / **Subsystem**: `frontend`
- **Depends On**: `["REQ-383-T2", "REQ-383-T3"]`
- **Reference Design**: `docs/design/REQ-383.md` (§2〜§5), `docs/design/REQ-383-test-plan.md`

## 1. 目的・スコープ・AC-1〜AC-14 全体統合契約 (Goal, Scope & AC Alignment)

`REQ-383-T2`（`GenerateParallelPreview`）と `REQ-383-T3`（`GenerationGallerySection` / `useGalleryInteraction` / `useGenerateDisplayState`）の成果物を `DesktopLayout.tsx` で統合し、AC-1〜AC-14 の全挙動を完成・E2E検証する（正本仕様書改定は `REQ-383-T1` が担当）:
1. **連続横スクロールリール・端点ジャンプ・詳細モーダル・横あふれ抑止の統合 (AC-1〜AC-6, AC-12, AC-14)**:
   - 最新画像が先頭（`index 0`）で右方向へ過去画像が並びソート順反転UIを表示しない（AC-1）。初期表示で最新画像中心を水平中央に配置し、最新・最古いずれの端点画像も表示幅を圧縮せずに水平中央へ吸着できる端部余白を持つ（AC-2）。
   - ホイール／トラックパッド横スクロール連続入力に対し振動や急停止を起こさず滑らかに減衰し、停止後に最寄り画像が水平中央へ吸着する（AC-3）。縦長・正方形・横長（2:1等）混在時に元アスペクト比を維持しつつプレビュー領域をはみ出さず、細長い空枠や極端な縮小なしに表示する（AC-4）。
   - 過去閲覧時に「← 最新へ」を表示し押下で進行中慣性を即座に停止して最新画像を水平中央へ移動・表示し（AC-5）、「最古へ →」押下で進行中慣性を即座に停止して最古画像（末尾）を水平中央へ移動・表示する（AC-6）。
   - リール内画像クリックで `HistoryModalPreview` が開き拡大表示・`Escape` キー／閉じるボタンCloseが機能し（AC-12）、操作中に `document.body` に横スクロールバー（`overflow-x`）を発生させない（AC-14）。
2. **プレビュー上部ツールバーと履歴ペイン間の双方向同期・複数選択保護 (AC-7, AC-8, AC-10, AC-11, AC-13)**:
   - `previewAutoFollow`（最新追従: AC-10）および `filterOwnSession`（自セッション: AC-11）をプレビュー上部と履歴ペインの双方へ渡し、単一状態で即時双方向同期し表示対象画像群に反映する。
   - 履歴展開かつ通常状態（単一選択）で任意の履歴サムネイルをクリックした際、対象画像を選択状態にし `onCenterPreviewImage(img)` → `centerRequest` でメインプレビューを該当画像の水平中央へ移動・表示する（AC-7）。複数選択モードまたは修飾キー（`Ctrl`/`Meta`/`Shift`）押下時は複数選択状態のみを更新し、メインプレビュー位置を移動・ジャンプさせない（AC-8）。
   - 履歴の複数選択チェックボックス・一括保存・選択解除・スナップショットタブ切り替えの既存機能を維持する（AC-13）。
3. **履歴ペイン開閉制御と境界バー `⌄ 履歴を閉じる` ローカルClose導線 (AC-9)**:
   - `DesktopLayout.tsx` で `isHistoryExpanded`（初期値 `false`）を管理する。展開時はプレビューと履歴の境界バーにローカルCloseボタン `⌄ 履歴を閉じる`（`data-generate-reel-history-close="true"`, `aria-label="履歴ペインを閉じる"`）を表示し、押下により履歴ペインが閉じてメインプレビュー表示領域が展開前の通常表示高（右ペイン全高）へ復帰する（AC-9）。

## 2. 外科的スニペットと変更契約 (`DesktopLayout.tsx` L587-L725 付近)

```tsx
  const [isHistoryExpanded, setIsHistoryExpanded] = useState(false)
  const [centerRequest, setCenterRequest] = useState<GenerateParallelPreviewCenterRequest | null>(null)

  const handleCenterPreviewImage = useCallback((img: string) => {
    setSelectedImg(img)
    setCenterRequest((prev) => ({ image: img, seq: (prev?.seq ?? 0) + 1 }))
  }, [setSelectedImg])
```
- `GenerateParallelPreview` に以下の Props を渡す:
  - `previewAutoFollow={previewAutoFollow}`, `onToggleAutoFollow={() => setPreviewAutoFollow(!previewAutoFollow)}`
  - `filterOwnSession={filterOwnSession}`, `onToggleFilterOwnSession={setFilterOwnSession}`
  - `isHistoryExpanded={isHistoryExpanded}`, `onToggleHistoryExpanded={() => setIsHistoryExpanded((prev) => !prev)}`
  - `centerRequest={centerRequest}`
- `GenerationGallerySection` に `onCenterPreviewImage={handleCenterPreviewImage}` を渡す。
- `showStrip && isHistoryExpanded` のとき:
  - プレビューと履歴の境界バーに `<button type="button" data-generate-reel-history-close="true" aria-label="履歴ペインを閉じる" onClick={() => setIsHistoryExpanded(false)}>⌄ 履歴を閉じる</button>` を配置し、下部に `GenerationGallerySection` を表示する。
- `!showStrip || !isHistoryExpanded` のとき:
  - 履歴ペインを閉じて `mainPreviewContent` を右ペイン全高（`flex-1 min-h-0 min-w-0 h-full`）で表示する（AC-9）。
