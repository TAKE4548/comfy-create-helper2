## Implementation Requirements

- InjectWorkflowParamsOptions に resolvedSeeds?:Record<string,number> を追加。seed mapping では seedSlotKey から値を取得して対象キーへ number を注入。生成用の resolvedSeeds にスロット欠落があればエラー。
- resolvedSeeds がない Save Default 呼出しは current paramValues の seed を検証して注入する。モードが random でも保存時に抽選せず、入力基準値を保存。
- legacy Sampler_Seed の特殊注入は input_type!=='seed' のときだけ維持。専用 Sampler_Seed には global seedOptions を適用せず個別値が優先。
- role履歴補正のループは SEED_MODES_KEY を除外する。専用seedの値では現在の完全role一致またはstages.previous_suffixesから一意に対応できる場合のみ復元し、base_keyだけで別ステージ値を流用しない。曖昧時はエラー。
- nested inputsを含むgraphの深い不変性をテストする。生成経路は常にcloneJson:trueを指定し、cloneJson:falseの既存呼出し契約は維持する。
- cloneJson 既定true を維持。元graph不変、複数stage・value fallback・グローバル非干渉・予約キー非漏出・通常float保持をテストする。
