# REQ-302-T1: 基底モーダルバックドロップの不要ナビ回避余白撤廃とレスポンシブ余白改修

## 1. 概要と目的
`frontend/src/index.css` の `.modal-backdrop` に残存する `--mobile-nav-height`（4rem / 64px）の不要なナビ回避下部余白を撤廃し、`calc(1rem + env(safe-area-inset-bottom, 0px))` に統一する。
また、768〜1023px（タブレット幅、ボトムナビ `md:hidden` 状態）で共通Modal（`role="dialog"`）やプレビュー（`.flex-col`）から旧余白が残る除外セレクタ（`:not(:has(> [role='dialog']))` や `:not(.flex-col)`）を整理し、768px以上で一律 `padding-bottom: 1rem;` が適用されるようにする。

## 2. 密閉コンテキスト (Hermetic Context)

### 対象ファイル 1: `frontend/src/index.css` (L290-L318)
```css
.modal-backdrop {
  position: fixed;
  inset: 0;
  background-color: rgba(0, 0, 0, 0.7);
  backdrop-filter: blur(8px);
  -webkit-backdrop-filter: blur(8px);
  display: flex;
  align-items: center;
  justify-content: center;
  z-index: var(--z-modal);
  padding: 1rem;
  padding-bottom: calc(var(--mobile-nav-height) + 1rem + env(safe-area-inset-bottom));
}

.modal-backdrop:fullscreen {
  padding: 0 !important;
}

.modal-backdrop:-webkit-full-screen {
  padding: 0 !important;
}

@media (min-width: 1024px) {
  .modal-backdrop {
    padding-bottom: 1rem;
  }
}
```

### 対象ファイル 2: `frontend/src/index.css` (L420-L425)
```css
@media (min-width: 768px) and (max-width: 1023px) {
  .modal-backdrop:not(.flex-col):not(:fullscreen):not(:has(> [role='dialog'])) {
    padding-bottom: 1rem;
  }
}
```

## 3. 変更仕様
1. **`.modal-backdrop` 基底のパディング修正**:
   - `padding-bottom: calc(var(--mobile-nav-height) + 1rem + env(safe-area-inset-bottom));` を
     `padding-bottom: calc(1rem + env(safe-area-inset-bottom, 0px));` へ変更。
2. **768px以上のレスポンシブパディング統一**:
   - `@media (min-width: 768px)` において `.modal-backdrop` の `padding-bottom: 1rem;` を無条件適用（`:not(:has(> [role='dialog']))` や `:not(.flex-col)` による除外を撤廃）。
3. **テスト追加 (`Modal.test.tsx`)**:
   - `[REQ-302/AC-2] eliminates mobile-nav-height offset from backdrop padding-bottom at all breakpoints`
   - `[REQ-302/AC-2] applies uniform 1rem padding-bottom in 768-1023px tablet range without nav margin`
   - `[REQ-302/AC-5] incorporates env(safe-area-inset-bottom) with 0px fallback and avoids double padding`

<constraints>
- Archetype 1: Modals & Overlays (`overscroll-contain`)
- Universal Safety: raw `100vh` 禁止（`100dvh` または `dvh` 使用）、二重パディング加算禁止
- `--z-mobile-nav: 50` および `--z-modal: 100` のトークン定義は不変。40や110へ変更しない。
</constraints>
