## Implementation
- 成功prompt ID確定/取消確認後、CURRENT_PROMPT_ID保存より前にprunePromptMetadataCache(promptId)を同期で呼ぶ。prefixはT1のLS_KEYS.METADATA_PREFIXを利用。既存setTimeoutの200件整理を全撤去する。
- 整理/受付ID保存/meta保存/server createを個別try/catchとし、各失敗をreportPersistenceFailureで通知。整理失敗後も保存を試み、local失敗がserver createを阻害しない。成功受付のreturn prompt ID、現在のfreeze/queued_at/record contents、非同期server保存を維持。
- バッチ中間ジョブも同じ経路。取り消し/IDなし/queueエラーでは整理しない。取得失敗をqueue submission errorへ変換しない。
