# Task Card: REQ-276-T1

## 1. 目的
1. バックエンドのプリセット API において、`updated_at` / `created_at` のシリアライズ時に明示的に UTC タイムゾーン情報を付与し、常に UTC ISO8601 文字列（末尾 `Z`）として返却されるようにする。
2. マッピングマスター更新 API（`PUT /api/mapping-masters/{id}`）において、`role` 名が変更・タイポ修正された際に、既存プリセットの JSON キーを自動追従させる「カスケード置換」を実装する。
3. データベース内に残存する 636 件の旧ロール名キー `'Resolution Selecto'` を正規キー `'Resolution Selector'` に一括正規化するマイグレーションスクリプトを作成・実行する。

## 2. 対象ファイル
1. `backend/app/routers/presets.py`
2. `backend/app/routers/mapping_masters.py`
3. `backend/scripts/migrate_resolution_selector_keys.py` (新規)

## 3. 実装仕様

### 3.1 `backend/app/routers/presets.py`
`_preset_to_schema` ヘルパーにおいて、`preset.created_at` および `preset.updated_at` が naive datetime（`tzinfo is None`）の場合に `replace(tzinfo=timezone.utc)` を適用する。

```python
# ターゲット箇所のスニペット (backend/app/routers/presets.py: L16-L30)
def _ensure_utc(dt: Optional[datetime]) -> Optional[datetime]:
    if dt is None:
        return None
    if dt.tzinfo is None:
        return dt.replace(tzinfo=timezone.utc)
    return dt

def _preset_to_schema(preset: models.WorkflowPreset) -> schemas.WorkflowPresetRead:
    raw_updated = preset.updated_at or preset.created_at
    return schemas.WorkflowPresetRead(
        id=preset.id,
        workflow_id=preset.workflow_id,
        name=preset.name,
        param_values=json.loads(preset.param_values) if preset.param_values else {},
        applied_assets=json.loads(preset.applied_assets) if preset.applied_assets else {},
        batch_size=preset.batch_size,
        seed_mode=preset.seed_mode,
        seed=preset.seed,
        created_at=_ensure_utc(preset.created_at),
        updated_at=_ensure_utc(raw_updated),
        sort_order=preset.sort_order,
    )
```

### 3.2 `backend/app/routers/mapping_masters.py`
`update_master` において、`old_role != new_role` の場合にプリセットテーブルの JSON キーを一括置換する。

```python
# ターゲット箇所のスニペット (backend/app/routers/mapping_masters.py: L47-L60)
@router.put("/{master_id}", response_model=schemas.MappingMasterRead)
def update_master(master_id: int, payload: schemas.MappingMasterCreate, db: Session = Depends(get_db)):
    mm = db.query(models.MappingMaster).filter(models.MappingMaster.id == master_id).first()
    if not mm:
        raise HTTPException(status_code=404, detail="MappingMaster not found")
    
    old_role = mm.role
    new_role = payload.role
    if old_role and new_role and old_role != new_role:
        old_pattern = f'"{old_role}":'
        new_pattern = f'"{new_role}":'
        db.query(models.WorkflowPreset).filter(
            models.WorkflowPreset.param_values.contains(old_pattern)
        ).update(
            {
                models.WorkflowPreset.param_values: func.replace(
                    models.WorkflowPreset.param_values, old_pattern, new_pattern
                )
            },
            synchronize_session=False
        )
```

### 3.3 `backend/scripts/migrate_resolution_selector_keys.py`
`db/prompt_surgeon.db` に対して単一 SQL による一括置換を実行。

```python
import sqlite3

def migrate():
    conn = sqlite3.connect("db/prompt_surgeon.db")
    cur = conn.cursor()
    cur.execute("""
        UPDATE workflow_presets 
        SET param_values = replace(param_values, '"Resolution Selecto":', '"Resolution Selector":')
        WHERE param_values LIKE '%"Resolution Selecto":%'
    """)
    affected = cur.rowcount
    conn.commit()
    conn.close()
    print(f"Migrated {affected} presets successfully.")

if __name__ == "__main__":
    migrate()
```
