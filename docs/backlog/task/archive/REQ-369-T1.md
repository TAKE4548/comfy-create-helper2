# REQ-369-T1: バックエンド孤立マッピング除外フィルタとマイグレーションStep 031の実装

## 1. 概要と目的
- ワークフロー作成・更新・コピー・ロールバック時に、実在しない `mapping_masters.id` または不整合な `mapping_variants.id` を参照する孤立マッピングを除外して保存する（`AC-4`）。
- マイグレーション `Step 031` (`cleanup_orphaned_workflow_mappings`) を追加し、DB 内の `workflow_mappings` から孤立レコードを冪等に削除する（`AC-5`）。

## 4. 実装要件 (Implementation Logic)
- [ ] `backend/app/migrations/steps.py` に `step_031_cleanup_orphaned_workflow_mappings(conn: Connection, inspector: Inspector) -> None` を実装する：
  - `table_names = set(inspector.get_table_names())` で `"workflow_mappings"` と `"mapping_masters"` が存在することを確認する。
  - `DELETE FROM workflow_mappings WHERE master_id NOT IN (SELECT id FROM mapping_masters)` を実行する。
  - `"mapping_variants"` が存在する場合は、`DELETE FROM workflow_mappings WHERE variant_id IS NOT NULL AND NOT EXISTS (SELECT 1 FROM mapping_variants mv WHERE mv.id = workflow_mappings.variant_id AND mv.master_id = workflow_mappings.master_id)` を実行する。
  - `ALL_MIGRATION_STEPS` に `MigrationStep("031", "cleanup_orphaned_workflow_mappings", step_031_cleanup_orphaned_workflow_mappings)` を追加する。
- [ ] `backend/app/routers/workflows.py` に `_load_valid_mapping_refs(db: Session) -> tuple[set[int], set[tuple[int, int]]]` と `_is_valid_mapping_ref(master_id: int, variant_id: int | None, valid_masters: set[int], valid_variants: set[tuple[int, int]]) -> bool` を追加する：
  - `valid_masters = {row[0] for row in db.query(models.MappingMaster.id).all()}`
  - `valid_variants = {(row[0], row[1]) for row in db.query(models.MappingVariant.master_id, models.MappingVariant.id).all()}`
  - `master_id not in valid_masters` の場合は `False`。`variant_id is not None and (master_id, variant_id) not in valid_variants` の場合も `False`。それ以外は `True`。
  - `create_workflow`, `update_workflow`, `copy_workflow`, `rollback_workflow` の全マッピング追加ループで `_is_valid_mapping_ref` が `True` のエントリのみを `db.add(models.WorkflowMapping(...))` する。
- [ ] `backend/tests/integration/api/test_workflows.py` に以下の統合テストを追加する（チケット名ファイルは新設しない）：
  - `test_workflow_save_filters_orphaned_master_and_variant_mappings` (`[REQ-369/AC-4]`): 存在する `master_id` と存在しない `master_id: 9999` および不整合 `variant_id: 8888` を含む `POST /api/workflows` / `PUT /api/workflows/{id}` を呼び出し、有効なマッピングのみが保存され `GET /api/workflows/{id}` に `role: None` が含まれないことを検証する。
  - `test_step_031_cleanup_orphaned_workflow_mappings` (`[REQ-369/AC-5]`): 孤立した `master_id` および不整合 `variant_id` を持つ `workflow_mappings` 行を挿入した状態で `step_031_cleanup_orphaned_workflow_mappings` を 2 回実行し、孤立行のみが削除され有効な行が保持されること（冪等性）を検証する。
