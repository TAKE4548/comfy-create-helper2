### 2.2 パラメータタブの個別活性化チェックボックスと型対応UI (`ProfileBulkEditModal.tsx`)
- **個別活性化チェックボックス (Explicit Opt-in UI)**:
  - `enabledParams`（`Set<string>`）state を保持し、各パラメータ行および Batch Size 行に「変更する」チェックボックスを配置。
  - 未チェック時: 入力要素は `disabled={!enabledParams.has(m.role)}` となり、変更対象外であることを明示。
  - チェック時: 入力要素が活性化し、通常通り値を変更可能。
- **型別UIレンダリング**:
  1. `m.input_type === 'select_sampler'`:
     - サンプラー一覧のドロップダウン。
  2. `m.input_type === 'select_scheduler'`:
     - スケジューラー一覧のドロップダウン。
  3. `m.input_type === 'boolean'`:
     - 標準のトグルスイッチ（活性化時のみトグル可能）。
  4. カスタム型 (`paramTypeMasters?.find(ptm => ptm.name === m.input_type)`):
     - `widget_type === 'select'`: `combo_options` をオプションとして持つ `<select>`。
     - `widget_type === 'boolean'`: トグルスイッチ。
     - 数値型: `type="number"`, `min`, `max`, `step` 属性を設定。
  5. `int` / `float`:
     - `type="number"`, `step={m.input_type === 'float' ? '0.1' : '1'}`。
  6. `textarea` / `string` (デフォルト):
     - `type="text"`。
  7. `Batch Size`:
     - `batchSizeEnabled` チェックボックスと連動した数値入力フィールド。
- **ペイロード構築 (`buildPayload`)**:
  - `enabledParams.has(role)` が `true` のパラメータのみを抽出し、`paramPatch[role]` に格納。
  - 未チェックの項目は一切ペイロードに含めない。

### 2.3 プロンプトタブにおける `TagChipInput` の統合
- `promptOp === 'search_replace'` の「置換後の文字列」欄、および `overwrite`, `prefix`, `suffix` の入力欄に `TagChipInput` を配置。
- カンマ区切りによるタグ生成、チップの「✕」による個別削除、複数タグ貼り付けの自動分割をサポート。
