# REQ-254-T1: トポロジー解析エンジンとフィンガープリント照合ロジックの実装

## 1. 目的とスコープ
ComfyUI ワークフロー JSON のネットワークトポロジー（入出力接続 DAG、ノードクラス型、タイトル、ID）を抽出し、新旧ノードの同一性・役割引き継ぎを高精度に推測する独立サービスクラス `workflow_diff_engine.py` を実装し、単体テストで検証する。

## 2. 変更対象ファイル
- `backend/app/services/workflow_diff_engine.py` [NEW]: トポロジー抽出、Jaccard スコアリング、状態判定
- `backend/tests/test_workflow_diff_engine.py` [NEW]: 単体テスト群（Renamed, Re-indexed, False Reuse, Symmetric LoRA）

## 3. 技術仕様とデータ構造

### 主要データ構造（Pydantic または Dataclass / TypedDict）
```python
from typing import TypedDict, Optional, Any

class NodeTopology(TypedDict):
    node_id: str
    title: str
    class_type: str
    inputs: list[dict[str, Any]]   # [{'slot': 'clip', 'source_node_id': '4', 'source_class': '...', 'source_title': '...'}]
    outputs: list[dict[str, Any]]  # [{'slot': 'positive', 'target_node_id': '3', 'target_class': '...', 'target_title': '...'}]

class NodeCandidate(TypedDict):
    node_id: str
    title: str
    class_type: str
    score: float

class RoleMigration(TypedDict):
    master_id: int
    role: str
    display_name: str
    old_node_id: str
    new_node_id: Optional[str]
    confidence: float
    reason: str
    status: str  # ok | renamed | reindexed | substituted | false_reuse | not_found
    candidates: list[NodeCandidate]
    old_topology: Optional[NodeTopology]
    new_topology: Optional[NodeTopology]
```

### スコア計算ロジック（100点満点）
```python
def compute_similarity(old_node: dict, new_node: dict, old_wf: dict, new_wf: dict) -> tuple[float, str]:
    # 1. Class Type Match: 35 pts
    class_match = 35.0 if old_node.get("class_type") == new_node.get("class_type") else 0.0
    
    # 2. In-Degree Topology Jaccard: 30 pts
    # Inputs: set of (slot_name, upstream_class)
    in_score = 30.0 * jaccard_similarity(old_in_sig, new_in_sig)
    
    # 3. Out-Degree Topology Jaccard: 20 pts
    # Outputs: set of (target_slot_name, downstream_class)
    out_score = 20.0 * jaccard_similarity(old_out_sig, new_out_sig)
    
    # 4. Title similarity: 10 pts
    title_score = 10.0 if old_title == new_title else (10.0 * levenshtein_ratio(old_title, new_title))
    
    # 5. ID Bonus: 5 pts
    id_bonus = 5.0 if old_id == new_id else 0.0
    
    total = class_match + in_score + out_score + title_score + id_bonus
    # False reuse detection: ID match but score < 40
    return total, reason
```
