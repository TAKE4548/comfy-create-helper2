# REQ-372-T2: モバイルGenerate：常駐プレビュー撤去・入力領域解放・ステータスヘッダー完了導線

## 1. 概要と目的
画面幅767px以下のモバイルGenerateにおいて、プロンプト入力上方に常駐していた画像プレビュー領域（`data-testid="mobile-main-preview"`）を撤去し、プロンプト入力面積を解放する。上部のsticky status headerは維持し、生成完了時に新画像へ到達可能な導線（「生成完了: 最新画像を表示」タップで履歴タブ切り替え＋最新画像フォーカス）を追加する。
