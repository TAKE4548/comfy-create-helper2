## 3. 実装要件 (Implementation Logic)
- [ ] `frontend/src/components/TagChipEditor/TagChip.tsx`
  - サブメニュー外枠クラスを `min-w-[220px]` から `w-[360px] max-w-[calc(100vw-24px)]` に変更（AC-2）。
  - state に `isTranslationOpen: boolean`（初期値 `false`）を追加。
  - サブメニューヘッダーのコピーボタンと有効/無効トグルボタンの間に、`[翻訳]` ボタン（ラベル: 「翻訳」）を追加（AC-2）。
  - `[翻訳]` ボタンクリックで `isTranslationOpen` をトグル反転。
  - `isTranslationOpen && isMenuOpen` のとき、`<TagChipTranslationCard text={wordInput || baseText} onClose={() => setIsTranslationOpen(false)} anchorRect={menuRef.current?.getBoundingClientRect()} />` をレンダリング（AC-3）。
  - 親サブメニューが閉じた際（`useEffect(() => { if (!isMenuOpen) setIsTranslationOpen(false); }, [isMenuOpen])`）、`isTranslationOpen` も確実に `false` にリセットし競合状態を防止（AC-8）。
