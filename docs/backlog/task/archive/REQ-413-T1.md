# REQ-413-T1: SlotDefinitionへのvariantEnabled追加とgenerationWorkflow・useWorkflowManagementでの無効バリアント除外

## 1. 概要と目的
マスタ側で無効化（`is_enabled = false`）されたステージバリアントが、生成画面のパラメータ入力枠（ParamPanel）やプロンプト枠に表示され ComfyUI 生成時に注入される不具合を解消するため、`SlotDefinition` に `variantEnabled` を導入し、`useWorkflowManagement` でマスタからフラグを伝播させ、`generationWorkflow` で無効バリアントのマッピング（および全バリアントが無効なマスタのレガシーマッピング）を生成用 `workflow.mappings` から除外する。

※本タスクは **AC-1, AC-2, AC-3, AC-4** を担当する。AC-5（ステージグループおよび ParamSync 候補からの除外）は `REQ-413-T2` が担当する。

```typescript
// frontend/src/utils/workflowMappingState.ts (L80-88)
export function generationWorkflow<T extends MappingWorkflow>(raw: T, slots: readonly SlotDefinition[] = []): Omit<T, 'mappings'> & {
  mappings: T['mappings'][number][]
} {
  const mappings = raw.mappings.filter((mapping) => (
    (raw.mapping_slot_states?.[mappingSlotKey(mapping, slots)]
      ?? raw.mapping_slot_states?.[slotKey(mapping.master_id, mapping.variant_id)]) !== false
  )) as T['mappings'][number][]
  return { ...raw, mappings }
}
```

## 4. 実装要件 (Implementation Logic)
※本タスクは AC-1〜AC-4 を実装・検証する（AC-5 は REQ-413-T2 の担当）：
- [ ] 1. `frontend/src/utils/workflowMappingState.ts`:
  - `SlotDefinition` に `variantEnabled?: boolean` を追加。
  - `generationWorkflow` で `slots` が渡されている場合、各 mapping について対応する slot の `variantEnabled` を評価する：
    - `mapping.variant_id != null`: `slots.find(s => s.masterId === mapping.master_id && s.variantId === mapping.variant_id)` の `variantEnabled === false` なら除外。
    - `mapping.variant_id == null`: 当該マスタの全スロット `masterSlots = slots.filter(s => s.masterId === mapping.master_id)` について、`masterSlots.length > 0 && masterSlots.every(s => s.variantEnabled === false)` なら除外。また `mappingSlotKey` で解決されたスロットが `variantEnabled === false` なら除外。
    - 既存の `mapping_slot_states` チェック（明示 `false` の除外）も維持する。
- [ ] 2. `frontend/src/pages/GeneratePage/hooks/useWorkflowManagement.ts`:
  - `slotDefinitions` の `variants.map` 内で `variantEnabled: variant.is_enabled !== false` を渡す。
  - バリアントなしのマスタでは `variantEnabled: master.default_enabled !== false` を渡す。
- [ ] 3. `frontend/src/utils/__tests__/wiringStageGroups.test.ts`:
  - `[REQ-413/AC-1]` マスタで無効化されたバリアント（`variantEnabled: false`）を持つマッピングが `generationWorkflow` から除外され、`workflow.mappings` および `paramMappings` に含まれないこと。
  - `[REQ-413/AC-2]` 除外されたバリアントのマッピングが生成用配列に含まれず、パラメータ注入対象にならないこと。
  - `[REQ-413/AC-3]` マスタで有効（`variantEnabled: true` または未指定）で個別無効化されていないマッピングが正常に保持されること。
  - `[REQ-413/AC-4]` レガシー形式（`variant_id == null`）のマッピングで、対応バリアントが `variantEnabled: false` の場合に安全に除外されること。
