# REQ-265-T2: SnapshotRestoreModal コンポーネントと単体テストの実装

本カードは実装タスクの唯一の意味仕様であり、自己完結した技術契約・境界・検証手順を定義する。

## Delegation & Boundaries

- **責務・スコープ・完了条件 (D1)**:
  - `SnapshotRestoreModal.tsx` を新規作成し、過去スナップショットの大きめサムネイル一覧表示・選択・簡易プレビュー・明示的復元アクション・キャンセル/閉じる保護を提供する。
  - `SnapshotRestoreModal.test.tsx` を新規作成し、正常系・異常系（API失敗、復元失敗、連打抑止）を `[REQ-265/AC-n]` タグ付きでテストする。
  - 完了条件: `npm run typecheck`、`verify_ui_invariants.py`、`verify_test_naming.py --strict`、`SnapshotRestoreModal.test.tsx` が全件 PASS すること。
- **依存関係と理由 (D2)**: `depends_on: []`（共通 `Modal` と `snapshotsApi` にのみ依存するため T1 と並列実行可能）。
- **隣接カードの所有ファイル (D3)**:
  - `REQ-265-T1`: `useGeneratePageModals.ts`, `useGalleryInteraction.ts`, `useAssetSelectionState.ts`, `useGeneratePageState.ts`, `useGalleryInteraction.test.ts`, `useAssetSelectionState.test.ts`
  - `REQ-265-T3`: `GenerationGallerySection.tsx`, `DesktopLayout.tsx`, `MobileLayout.tsx`, `GeneratePage.tsx`, `GenerationGallerySection.cache.test.tsx`, `generateSnapshotRestore.spec.ts`
- **共有契約 (D4)**:
  ```ts
  export interface SnapshotRestoreModalProps {
    isOpen: boolean
    onClose: () => void
    snapshots: SnapshotSummaryWithParams[]
    initialSnapshotId?: number | null
    onRestore: (snapshotId: number) => Promise<boolean>
  }
  ```
- **AC と検証の対応 (D5)**:
  - `[REQ-265/AC-1]`: モーダル内でサムネイル選択や詳細取得を行っても `onRestore` やストア変更が一切発生しないこと。詳細取得失敗時は `role="alert"` を表示すること。
  - `[REQ-265/AC-3]`: 大きめサムネイルグリッドが表示され、選択に応じた簡易プレビュー（画像、日時、プロンプト、パラメータ抜粋、LoRA/TagSet件数または名称）が確認できること。
  - `[REQ-265/AC-4]`: 「アクティブプリセットに復元」ボタン押下時のみ `onRestore(selectedId)` が呼ばれ、成功（`true`）時のみ `onClose()` すること。復元中はボタンを `disabled` にすること。
  - `[REQ-265/AC-5]`: 「キャンセル」、閉じるボタン、Escape、バックドロップ押下時に `onRestore` を呼ばず `onClose()` すること。復元失敗（`false`）時は閉じずにエラー表示すること。
- **Engineer 委譲範囲 (D6)**: プレビューペインのパラメータ表示順序・日時フォーマット補助関数・Tailwind 装飾。
- **変更禁止スコープ (D7)**:
  - モーダル内から `useGenerationStore` の `setParamValues` / `setAppliedAssets` / `setSeed` 等を直接呼ばない（復元は必ず `onRestore` prop 経由のみ）。
  - `src/components/common/Modal.tsx` 本体は変更しない。
  - テストファイル名にチケット番号（`req\d+`）を含めない。

## UI Archetype & Constraints (`<constraints>`)

- **分類**: Composite (`Archetype 1: Modals & Overlays` + `Archetype 2: Tabs / Chips / Grids` + `Archetype 3: Forms & Controls`)
- **Container (`Modal`)**:
  - `src/components/common/Modal.tsx` を使用（`size="full"`, `dialogClassName="md:max-w-4xl lg:max-w-5xl md:max-h-[85dvh] overflow-hidden"`, `sheetMaxHeightClass="max-h-[88dvh]"`）。
  - スクロール領域に `overflow-y-auto overscroll-contain` を適用。生の `100vh` 使用禁止。
- **Grid & Text**:
  - サムネイル一覧: `grid grid-cols-2 sm:grid-cols-3 gap-3`、選択カードは `aria-pressed={isSelected}` と緑枠・バッジで明示。
  - テキスト省略は `min-w-0 flex-1 truncate`、プロンプト本文は `whitespace-pre-wrap break-words`。
  - 最小文字サイズ 11px (`text-[11px]` / `text-xs`)、グローバル CSS 底上げ禁止。
- **Controls**:
  - 閉じる・キャンセル・復元ボタンは最小 44×44px (`min-h-11` または `relative before:absolute before:-inset-2 before:content-['']`) と `touch-manipulation` を適用。
