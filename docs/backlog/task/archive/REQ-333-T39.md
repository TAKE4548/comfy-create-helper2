# REQ-333-T39

ユーザー指示: 進捗率は整数位で十分。枚数・node進捗の表示文字列はMath.roundで整数にする。計算正本とbar幅の精度は変えない。PCとモバイルの両方、通常生成と待機表示を確認する。

- frontend/src/pages/GeneratePage/components/DesktopLayout.tsx
- frontend/src/pages/GeneratePage/components/MobileLayout.tsx
- frontend/src/pages/GeneratePage/components/__tests__/GenerationProgress.req333.test.tsx
