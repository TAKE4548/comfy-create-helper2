## 実装要件
1. `Modal`（`size="lg"`, `ariaLabel="カスタム型マスタ管理"`, `sheetMaxHeightClass="max-h-[85dvh]"`）で描画。ヘッダに見出し `カスタム型マスタ管理 (N)` と閉じるボタン（`aria-label="閉じる"`）、「新規型を作成」ボタン。
2. 本文は `overscroll-contain overflow-y-auto` のリスト。各行: 名前（`min-w-0 flex-1 truncate` かつ `title`）、`widget_type` バッジ（`shrink-0 whitespace-nowrap`）、編集/削除ボタン（アイコンのみ、`aria-label="{name} を編集"` / `"{name} を削除"`）。
3. 0件時は文言 `カスタム型マスターはまだ登録されていません。`。
4. 削除はこのコンポーネント内で `confirm()` を使わず、行内インライン確認（`role="alertdialog"` ではなく同一dialog内の確認行）後に `onDelete(item)`。確認キャンセルで何も呼ばない。
5. `onCreate`/`onEdit` 呼出しは親が本モーダルを閉じて既存`ParamTypeMasterModal`を開く（排他）ため、本コンポーネントは自分で閉じない。

## スニペット（行のレイアウト参考）


<constraints>
- Archetype 1: モバイルでボトムシート（Modal任せ）、`overscroll-contain`、ハンドルはModal提供のものを使い自前で重複しない。
- Archetype 3（内包ボタン）: Hit-Slop `before:absolute before:-inset-2`、`touch-action: manipulation`（`touch-manipulation`）、最小44×44。
- Composite Scoping: コンテナ=Modal（overscroll/layout）、要素=ボタン（hit-slop/touch）。
- 最小フォント11px、生`vh`禁止、`pb`二重禁止（Modalが`pb-[env(safe-area-inset-bottom)]`を提供）。重要情報（名前）は `title` と `aria-label` で全文保持。
</constraints>
