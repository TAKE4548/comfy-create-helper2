対象箇所の現状または新規ファイルの依存文脈（周辺約20行）:
```ts
// 新規ファイル。既存WS/SystemStats型から独立した契約。
// Storageの標準DOM interface（実装依存のObject.keysは使用しない）:
interface Storage {
  readonly length: number
  clear(): void
  getItem(key: string): string | null
  key(index: number): string | null
  removeItem(key: string): void
  setItem(key: string, value: string): void
  [name: string]: any
}
// measureBrowserStorageUsageは領域ごとのgetterを渡す:
// measureStorageUsage(() => window.localStorage)
// measureStorageUsage(() => window.sessionStorage)
// 数式: sum((key.length + value.length) * 2)
// JS.lengthはUTF-16コード単位。JSON parseをしない。
// 1 KiB = 1024 bytes
// 1 MiB = 1048576 bytes
// bytes < 1048576 -> KiB, else MiB
// Number.toFixed(1)で小数点1桁。

```

## Implementation
- 計測utility/型/formatを1moduleに実装。getter・length・key・getItemを全てtry内で行い、領域ごとに独立した成功/取得不可を返す。全キー全値を加算しprefixで絞らない。
- 読取/列挙例外、key/value null、途中削除や検出可能なlength変化、不正な合計では部分値を捨てる。空領域0 bytesは成功。window storage getterそのもののSecurityErrorを捕捉する。書込・内容ログ・ネットワーク要求を行わない。
- formatは真のbytesで単位を判定し、その後四捨五入1桁。失敗は取得不可。%/10MB/残量/警告閾値を追加しない。

## Verification
