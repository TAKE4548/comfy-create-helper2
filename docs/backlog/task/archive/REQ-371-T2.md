# REQ-371-T2: TagChipドラッグz-index適正化と下部チップサブメニューのFlip表示

## 1. 概要と目的
ドラッグ中のタグチップが画面下部の固定生成バー（z-40）の前面に被って描画される現象を防ぐため、ドラッグ時 z-index を 30 に調整する。また、画面下部付近のチップで詳細編集サブメニューを開いた際、固定バーに重なって操作項目が隠れることを防止するため、下部余白が不足する場合にサブメニューを上向きに展開する反転（Flip）表示を実装する。Tag Set 作成・編集や PC 画面等での非回帰を担保する。

## 2. ターゲット識別
- **対象ファイル**:
  - `frontend/src/components/TagChipEditor/TagChip.tsx`
  - `frontend/src/components/TagChipEditor/__tests__/TagChip.test.tsx`
- **対象シンボル**:
  - `TagChip.tsx`: `TagChip` コンポーネント、`style` オブジェクト、サブメニュー描画部
- **行番号目安**:
  - `TagChip.tsx`: L90〜L105（ドラッグスタイル）、L300〜L320（サブメニュークラス）

## 3. UI 4大アーキタイプ分類と制約
- **UI分類**: `Archetype 2: Tabs / Chips / Grids` / `Archetype 1: Modals & Overlays`
- **制約 (`<constraints>`)**:
  - Chips: `shrink-0 whitespace-nowrap`, `select-none`
  - Hit-Slop: 操作アイコン・ボタンに `before:absolute before:-inset-2` を担保
  - Popover: 下部領域不足時に `bottom-full mb-1.5` で上向き展開 (Flip)
  - Universal Safety: 11px Floor、ドラッグ z-index を 30 に固定（固定バー 40 より下）

## 5. 実装要件 (Implementation Logic)
- [x] `TagChip.tsx`: `style` 定義内の `zIndex: isDragging ? 50 : undefined` を `zIndex: isDragging ? 30 : undefined` に変更する。通常チップ（`z-10`）より前面、固定アクションバー（`z-40`）より背面に位置づける。
- [x] `TagChip.tsx`: サブメニュー表示時にチップ要素のビューポート下部マージンを判定する（またはメニュー開閉時にチップの位置を検査する）。下部余白が不足する場合（例: チップ下端からビューポート下端まで 220px 未満、または `rect.bottom + 200 > window.innerHeight - 126`）は、クラスを `top-full mt-1.5` から `bottom-full mb-1.5` へ切り替えて上向きに展開する。
- [x] `frontend/src/components/TagChipEditor/__tests__/TagChip.test.tsx` に以下のテストケースを追加する：
  - `[REQ-371/AC-3]` ドラッグ中のインラインスタイルで `zIndex` が 30 となり、アクションバー（z-40）の背面を通過しつつ並べ替えが完了すること。
  - `[REQ-371/AC-4]` 下部付近のチップでサブメニューを開いた際、`bottom-full mb-1.5` が適用されて全コントロール（タグ名入力、強度変更、削除、コピー等）が隠れず操作可能であること。
  - `[REQ-371/AC-6]` 共通コンポーネントとしての TagChip の基本機能（表示・削除・編集・複製・強度変更）が Tag Set / LoRA 画面含め非回帰であること。
  - `[REQ-371/AC-7]` デスクトップ表示（幅768px以上）および十分な下部余白がある通常状態で `top-full mt-1.5` が維持されること。
  - `[REQ-371/AC-4] [RedTeam] RT-2` ビューポート最下端境界におけるサブメニュー展開がエラーなく上向きに安全にフォールバックすること。
