# REQ-386-T1: GenerationService.on_eventのprogressイベントprompt_id/nodeバインド強化およびactive jobフォールバック

## 1. 概要と目的
本タスク（REQ-386-T1）は主として **AC-1**（個別進捗同期のバックエンド配信）を担当する。画像生成中にComfyUIから送信される `progress` イベントにおいて、`prompt_id` が省略されている場合や `node` が数値型（int）で渡された場合、および `job.node` が未初期化の場合でも、実行中ジョブのノードステップ進捗を確実に更新・配信し、個別プログレスバーの停止を解消する。
なお、**AC-2**（プレビュー即時表示）は T2 / T3、**AC-3**（全完了時100%整合）は T3 が担う。

```python
# backend/app/services/generation_service.py:268-308
    async def on_event(self, event: dict[str, Any]) -> None:
        event_type = event.get("type")
        data = event.get("data")
        if not isinstance(event_type, str) or not isinstance(data, dict):
            return
        prompt_id = event.get("prompt_id")
        if not isinstance(prompt_id, str):
            prompt_id = data.get("prompt_id")
        if not isinstance(prompt_id, str):
            prompt_id = await self._verified_event_prompt()
        if not isinstance(prompt_id, str):
            await self._publish_if_composite_changed()
            return
        async with self._lock:
            state = self._snapshot()
            job = next((candidate for candidate in state.jobs if candidate.prompt_id == prompt_id), None)
            if job is None or job.status in _TERMINAL:
                await self._publish_if_composite_changed()
                return
            now = self._now()
            if event_type in {"execution_start", "executing", "progress"}:
                node_id = data.get("node")
                if event_type == "executing" and node_id is None:
                    # ComfyUI sends executing with node: null to signal execution completion
                    await self._handle_prompt_completion(job, prompt_id, now)
                else:
                    fields: dict[str, Any] = {}
                    if job.status != "running":
                        fields.update(status="running", started_at=job.started_at or now)
                    progress = event_type == "progress"
                    if not isinstance(node_id, str) and progress and job.node is not None:
                        node_id = job.node.id
                    if isinstance(node_id, str):
                        node = self._node_progress(job.job_id, node_id, data, job.node)
                        if node is not None:
                            fields["node"] = node
                    if not fields:
                        return
                    status: JobStatus = "running" if "status" in fields else job.status
                    fields.pop("status", None)
                    self.repository.transition(job.job_id, status, **fields)
```

## 4. 実装要件 (Implementation Logic)
- [ ] **AC対応と責務境界**:
  - 本タスクは **AC-1**（ステップ進捗のリアルタイム同期）のバックエンド配信を実装・検証する。
  - AC-2（プレビュー即時表示）は T2 / T3、AC-3（完了時100%）は T3 が担う。
- [ ] **prompt_id のフォールバック解決 (AC-1)**:
  - `prompt_id` が `event` / `data` に含まれない場合、直ちに `/queue` をHTTPポーリングする前に、`self._snapshot().jobs` 内で `status == "running"` かつ `prompt_id` を保持するジョブが単一であれば、その `prompt_id` を採用する。
- [ ] **node_id の型正規化**:
  - `raw_node = data.get("node")` に対し、`node_id = str(raw_node) if raw_node is not None else None` として数値型（int）のノードIDを安全に文字列化する。
- [ ] **未初期化サンプラーノードのフォールバック**:
  - `progress` イベント受信時に `node_id is None` かつ `job.node is None` の場合、`self._frozen_graphs.get(job.job_id, {})` 内から `class_type` に `"Sampler"` を含むノードID（見つからなければ `"sampler"`）を補完する。
- [ ] **状態更新と配信**:
  - `_node_progress` で生成された `NodeView` を `repository.transition(job.job_id, status, node=node)` で保存し、`await self._publish_snapshot()` を発行する。
- [ ] **Backend Zero-Contamination Guardrail**:
  - 本タスクには UI CSS、Tailwind クラス、タッチ制約を一切混入させないこと。
