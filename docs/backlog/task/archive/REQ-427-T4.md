# REQ-427-T4: FE 基盤（型・トークン・API・注入・Settings 選択肢）

## 1. 目的
- Settings の MappingMaster 作成・編集で標準型 `image` を選択・保存できるようにする（AC-1）。
- 参照トークンの判定・URL 生成ユーティリティと `/api/ref-images` クライアントを提供する（T5 の UI が使用）。
- 生成用 graph への注入で、`image` マッピングにトークンがあれば対象ノード入力へ注入し、未指定（空・非トークン）なら元 JSON の値を変更しない（AC-6）。無効化マッピングは既存 `generationWorkflow` で除外され注入されないことを固定する（AC-7）。
- Snapshot 復元・生成記録・Multi-Set 生成でトークンが保持されることを固定する（AC-8）。

## 4. 前提契約（T1 提供、変更禁止）
- トークン C1: `^refimg:([0-9a-f]{64})\.(png|jpg|webp)$`。`ref_id` = `<sha256>.<ext>`。
- API: `POST /api/ref-images/upload`（multipart `file`）→ 201 `RefImageRead`、`POST /api/ref-images/import`（JSON `{source:'history', filename, subfolder, type}` または `{source:'snapshot', snapshot_id}`）→ 201、`GET /api/ref-images/{ref_id}`、`GET /api/ref-images/{ref_id}/thumbnail`。
- `RefImageRead = { token, ref_id, media_type, width, height, byte_size, view_url, thumbnail_url }`。
