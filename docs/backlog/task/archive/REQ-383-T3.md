# Task Card: REQ-383-T3 — 履歴の最新-first固定（ソート切替UI撤去）および通常/複数選択クリック時のプレビュー同期制御

- **Role**: `engineer` / **Assigned Skill**: `dev-task` / **Change Kind**: `code` / **Subsystem**: `frontend`
- **Depends On**: `[]`（`REQ-383-T1`, `REQ-383-T2` とファイル競合なしで並列実行可能）
- **Reference Design**: `docs/design/REQ-383.md` (§2, §4, §5), `docs/design/REQ-383-test-plan.md`

## 1. 目的・スコープ・AC-1〜AC-14 全体契約とタスク分担 (Goal, Scope & AC Alignment)

1. **最新-first固定とソート切替UIの撤去 (AC-1)**:
   - `useGenerateDisplayState.ts` において、`sortedDisplayImages` が常に最新-first（`index 0` = 最新画像、右方向へ過去画像）となるよう固定し、`GenerationGallerySection.tsx` のデスクトップツールバーから「新しい順 / 古い順」ソート順反転UIを撤去する（AC-1）。
2. **通常クリック時のプレビュー中央同期と複数選択・修飾キー時のスクロール抑止 (AC-7, AC-8)**:
   - `useGenerateDisplayState.ts` の複数選択トラッキング `useEffect`（L601-L611）が `isMultiSelectMode` 中に `selectedImg` を上書きしてメインプレビューの移動を引き起こす挙動を抑止する（AC-8）。
   - `useGalleryInteraction.ts` と `GenerationGallerySection.tsx` に `onCenterPreviewImage?: (img: string) => void` を追加し、**通常モード（`!isMultiSelectMode`）かつ修飾キー（`ctrlKey`, `metaKey`, `shiftKey`）が押されていないクリック時のみ** `setSelectedImg(img)` と `onCenterPreviewImage?.(img)` を呼び出してメインプレビューを該当画像の水平中央へ移動させる（AC-7）。
   - 複数選択モード中、または `ctrlKey` / `metaKey` / `shiftKey` 押下クリック時は、`multiSelect.handleItemClick(img, event)` のみを実行し、複数選択状態のみを更新してメインプレビューの表示位置を移動・ジャンプさせない（AC-8）。
3. **共有トグル同期・既存履歴操作の維持 (AC-10, AC-11, AC-13)**:
   - 履歴ヘッダー内の `#preview-autofollow-toggle-desktop`（最新追従: AC-10）および `#session-filter-toggle`（自セッション: AC-11）をプレビュー上部トグルと単一状態で即時双方向同期する。
   - 履歴ペインの複数選択チェックボックス操作・一括保存・選択解除・スナップショットタブ切り替えおよび REQ-362 キャッシュ契約をエラーなく動作させる（AC-13）。
4. **隣接タスク分担**:
   本タスクの担当ACは `AC-1`, `AC-7`, `AC-8`, `AC-10`, `AC-11`, `AC-13` である。プレビューリール本体は `REQ-383-T2`、レイアウト統合・E2Eは `REQ-383-T4`、仕様同期は `REQ-383-T1` が担当する。

## 2. 外科的スニペットと変更契約 (Surgical Snippets & Contracts)

### 2.1 `useGenerateDisplayState.ts`（L552-L612 付近）
現行コード:
```tsx
  const sortedDisplayImages = useMemo(() => {
    const valid = displayImages.filter((url) => !unavailableImages.has(imageIdentity(url)))
    return sortOrder === 'asc' ? [...valid].reverse() : valid
  }, [displayImages, sortOrder, unavailableImages])
```
改定方針:
- `sortedDisplayImages` は常に最新-firstの `valid`（`displayImages.filter(...)`）を返すよう固定し、`setSortOrder` が呼ばれても順序が逆転しないようにする（返却オブジェクトの `sortOrder: 'desc'` と `setSortOrder` プロパティ自体は型互換のため残す）。
- L601-L611 の `MultiSelect selection tracking` による `setSelectedImg(lastUrl)` 自動更新を撤去（または無効化）し、複数選択操作でメインプレビューの選択画像・スクロール位置が動かないようにする（AC-8）。

### 2.2 `useGalleryInteraction.ts`（L11-L62 付近）
```tsx
export interface UseGalleryInteractionProps {
  sortedDisplayImages: string[]
  selectedImg: string | null
  setSelectedImg: (img: string | null) => void
  onSelectImage?: (img: string) => void
  onCenterPreviewImage?: (img: string) => void
  isModalOpen?: boolean
}
```
`handleThumbnailClick` 内:
- `!multiSelect.isMultiSelectMode && !event.ctrlKey && !event.metaKey && !event.shiftKey` のときのみ `setSelectedImg(img)` と `onCenterPreviewImage?.(img)` を呼び出す（AC-7）。
- `multiSelect.isMultiSelectMode || event.ctrlKey || event.metaKey || event.shiftKey` のときは `multiSelect.handleItemClick(img, event)` のみを実行し、`setSelectedImg` も `onCenterPreviewImage` も呼ばない（AC-8）。

### 2.3 `GenerationGallerySection.tsx`（L20-L56, L139-L157 付近）
- `GenerationGallerySectionProps` に `onCenterPreviewImage?: (img: string) => void` を追加し、`useGalleryInteraction` へ渡す。
- L139-L156 のデスクトップソート切替ボタン（`title="ソート順を切り替え"`、`新しい順` / `古い順`）を撤去する（AC-1）。
- 既存の `#session-filter-toggle`、`#preview-autofollow-toggle-desktop`、複数選択ボタン、一括保存、選択解除、削除、クリア、スナップショットタブ切替はそのまま保持する（AC-10, AC-11, AC-13）。
