# REQ-319-T7: 別衣装マスタ選択モーダルおよび25%均等割当UI統合

## 1. 概要と目的
本命衣装とシルエットや形状が対照的な別衣装を選択・管理できる `OutfitMasterModal.tsx` を実装し、選択されたプリセット衣装（カジュアル、部屋着、水着、スーツ等）をタグバッジ形式で表示して、直交マトリクスの25%別衣装枠（全20件中5件）に均等配分するUI連携を完成させる。


### 2.3 25% 配分ロジック仕様
```typescript
export function distributeAltOutfits(selectedOutfits: OutfitMasterPreset[], altSlotCount: number = 5): OutfitMasterPreset[] {
  if (selectedOutfits.length === 0) return []
  const result: OutfitMasterPreset[] = []
  for (let i = 0; i < altSlotCount; i++) {
    result.push(selectedOutfits[i % selectedOutfits.length])
  }
  return result
}
```

## 3. 実装要件 (Implementation Logic)
1. **`frontend/src/pages/DatasetStudioPage/components/OutfitMasterModal.tsx`**:
   - バックエンドの `datasetApi.getOutfitMasters` から内蔵/カスタムプリセット一覧を取得・一覧表示。
   - 複数チェックボックス選択（カジュアル、部屋着、水着、スーツなど）。
   - 新規カスタム別衣装の追加入力欄（名称、カテゴリ、プロンプトタグ）。
   - 「保存・適用」ボタンで選択されたプリセット一覧を親へ通知。
2. **`frontend/src/pages/DatasetStudioPage/components/OutfitPresetBadge.tsx`**:
   - 選択された別衣装のタグバッジ（削除用×ボタン付き）。
3. **`frontend/src/pages/DatasetStudioPage/components/MatrixGenerationStep.tsx`**:
   - 「別衣装ライブラリから選択」ボタンを配置。
   - 選択された衣装バッジ一覧と、配分サマリー（「5枠中: カジュアル3件, 部屋着2件」）を動的表示。
   - マトリクス算出リクエスト時に `selected_alt_outfits` ID 配列を渡す。
