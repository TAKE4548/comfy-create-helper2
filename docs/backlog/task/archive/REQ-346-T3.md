## 背景（原因）
この要素は `PageHeader` の `actions` スロット（`overflow-x-auto` 外枠、高さ約50px）内で `absolute left-0 top-full` により描画され、外枠の `overflow-y` が `auto` に計算されるため高さで切り詰められる。`HeaderDropdown` はポータル＋`position: fixed` でこの外枠の外へ描画する。

## 使用する API（T2 で確定済み）
```tsx
import { HeaderDropdown } from '../../../components/common/header/HeaderDropdown'
// props: { open: boolean; onClose: () => void; anchorRef: RefObject<HTMLElement | null>;
//          align?: 'start' | 'end'; role?: AriaRole; className?: string; 'data-testid'?: string; children }
```
外側クリック（`pointerdown`/`mousedown`）での閉鎖は `HeaderDropdown` が行う。

## 現行コード（`WorkflowActionsMenu.tsx`）
```tsx
import { useState, useRef, useEffect } from 'react'          // L1
// ...
  const [isOpen, setIsOpen] = useState(false)                // L30
  const menuRef = useRef<HTMLDivElement>(null)               // L31

  useEffect(() => {                                          // L33-42  ← 削除（HeaderDropdownが担う）
    if (!isOpen) return
    const handleClickOutside = (e: MouseEvent) => {
      if (menuRef.current && !menuRef.current.contains(e.target as Node)) { setIsOpen(false) }
    }
    document.addEventListener('mousedown', handleClickOutside)
    return () => document.removeEventListener('mousedown', handleClickOutside)
  }, [isOpen])

  if (!workflowId || !workflow) { return null }              // L44-46（hooks の後。維持）

  return (
    <div className="relative inline-flex items-center" ref={menuRef}>   // L49  ← 維持（anchorRef）
      <button type="button" id="workflow-actions-btn" onClick={() => setIsOpen((prev) => !prev)} ...>  // L50-64 維持
      </button>

      {isOpen && (                                                       // L66
        <div
          role="menu"
          className="absolute left-0 top-full mt-1.5 w-[240px] bg-surface-2 border border-[rgba(255,255,255,0.1)] rounded-xl shadow-2xl p-3 z-50 space-y-3 animate-fade-in"
        >
          ... （L71-163 の子要素: 見出し／ベースモデルselect／デフォルト保存・リセット／名前を変更・複製・ノード再スキャン）
        </div>
      )}                                                                 // L164-165
    </div>
  )
```

## 変更内容
1. `import { useState, useRef } from 'react'`（`useEffect` を削除。`noUnusedLocals` に注意）。`HeaderDropdown` を import。
2. L33–42 の `useEffect` を削除。
3. `{isOpen && (<div role="menu" className="absolute ...">…</div>)}` を次に置換（子要素 L71–163 はインデントのみ調整し**内容不変**）:
```tsx
<HeaderDropdown
  open={isOpen}
  onClose={() => setIsOpen(false)}
  anchorRef={menuRef}
  align="start"
  role="menu"
  className="w-[240px] bg-surface-2 border border-[rgba(255,255,255,0.1)] rounded-xl shadow-2xl p-3 space-y-3 animate-fade-in"
>
  {/* 既存の子要素 */}
</HeaderDropdown>
```
   `absolute`／`left-0`／`top-full`／`mt-1.5`／`z-50` は削除（位置・z-index はプリミティブが担う）。
4. 各項目の `onClick` 内 `setIsOpen(false)`（保存・リセット・名前変更・複製・再スキャン）は**そのまま**維持。トリガーの `onClick`（トグル）も維持し、再押下で閉じる（AC-4）。

<constraints>
- Archetype 1（Overlay）: 位置・高さ・z-index は `HeaderDropdown` に集約。本ファイルに `absolute`/`fixed`/`z-*`/`max-h-*` を書かない。
- メニュー内の既存文字サイズ（`text-[10px]` 等）は本PBIの変更対象外（変更しない）。
- ボタン `#workflow-actions-btn` の見た目・サイズ（`w-[26px] h-[28px]`）は変更しない。
</constraints>
