# REQ-336-T3: MappingMaster/Variant CRUD API改修とWorkflowScanner連携

## 1. 概要と目的
MappingMaster API を2軸構造（親マスターおよび紐づく MappingVariant 群の一括取得・更新）へ拡張し、大カテゴリ管理用の `mapping_groups` ルーターを新設する。また、`workflow_scanner.py` を改修し、各 StageMaster の `search_keywords` およびバリアント定義に基づく高精度な自動マッチングを可能にする。

## 2. ターゲット識別
- **対象ファイル**:
  - `backend/app/routers/mapping_masters.py` (L14〜L87 付近)
  - `backend/app/routers/mapping_groups.py` (新規)
  - `backend/app/services/workflow_scanner.py` (L73〜L150 付近の scan_workflow)
- **対象シンボル**: `list_masters`, `update_master`, `router`, `scan_workflow`, `scan_workflow_variants`
