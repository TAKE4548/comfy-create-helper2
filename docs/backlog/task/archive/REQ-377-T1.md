# REQ-377-T1: TagSetFormFields Subsets 独立スクロール撤廃と親コンテナ統合

## 1. 概要と目的
`TagSetFormFields` 内の Subsets (バリエーション) 一覧に設定されている `max-h-[160px] overflow-y-auto` による内部独立縦スクロールを撤廃し、親シートおよび作成モーダルのスクロールコンテナに統合する（MUI-02, AC-9, AC-10）。

## 2. ターゲット識別
- **対象ファイル**: `frontend/src/components/TagSetModals/TagSetFormFields.tsx`
- **テストファイル**: `frontend/src/components/TagSetModals/__tests__/TagSetFormFields.test.tsx`
- **対象シンボル**: `TagSetFormFields` 内 Subsets レンダリングブロック
- **行番号目安**: `TagSetFormFields.tsx` L261〜L285

## 3. コンポーネント分類と制約 (<constraints>)
- **UI Archetype**: `Archetype 3: Forms & Controls` / `Archetype 2: Tabs / Chips / Grids`
- **Surgical Constraints**:
  - `Scroll`: 親コンテナ (`overscroll-contain`) にスクロールを一元化。子要素内での `max-h-[160px]` および `overflow-y-auto` による独立スクロールを完全禁止（入れ子スクロール防止）。
  - `Hit-Slop`: サブセット追加・削除ボタンおよび画像アップロードボタンは最小 44×44px タッチ領域 (`relative before:absolute before:-inset-2 before:content-['']`) を確保。
  - `Truncation`: サブセット名入力欄およびプレビュー要素に `min-w-0 flex-1 truncate` を遵守。
  - `Universal Safety`: フォントサイズ 11px 以上（`text-[11px]` 以上）、二重パディングの排除。

## 5. 実装要件 (Implementation Logic)
1. `TagSetFormFields.tsx` L278 のコンテナクラスから `max-h-[160px] overflow-y-auto custom-scrollbar pr-1` を除去し、`<div className="space-y-2">` に変更する。
2. Subsets が複数件登録されても内部スクロールバーが出現せず、リスト全体が親の縦領域に自然展開されることを確認する。
3. `TagSetFormFields.test.tsx` に `[REQ-377/AC-9][REQ-377/AC-10]` を付与したテストケースを追加し、Subsets コンテナが `max-h-[160px]` や `overflow-y-auto` を持たず、利用箇所で意図しない独立スクロールが発生しないことを検証する。
