## 変更内容
1. import: `import { Modal } from './common/Modal'`。
2. 外側の2つの`div`（fixed overlay とカードコンテナ）を
```tsx
<Modal isOpen onClose={onClose} size="md" ariaLabel={mode === 'create' ? 'カスタム型マスター作成' : 'カスタム型マスター編集'} sheetMaxHeightClass="max-h-[85dvh]">
  {/* Header・form はそのまま */}
</Modal>
```
   に置換。Modalが提供する Escape / backdrop / focus trap / body scroll lock / ボトムシート（768px未満）を利用する。
3. ヘッダの閉じるボタンに `aria-label="閉じる"`、最小44×44（`min-h-11 min-w-11` + 中央寄せ）を付与。`type="button"` を明示。フッターの「キャンセル」「保存」ボタンも `min-h-11`（モバイル44px）。`pb`はModalが安全域を提供するためフォーム側に追加しない（二重padding禁止）。
4. 必要なら`form`に `overscroll-contain overflow-y-auto` を付けスクロール領域を1箇所にする。
