## 3. 実装要件
1. **`/api/config` の動的ホスト置換**:
   - `get_config(request: Request)` にシグネチャを更新。
   - `request.url.hostname` を取得。
   - ホスト名が存在し、かつローカルループバック（`localhost`, `127.0.0.1`, `::1`）以外の場合：
     - `settings.comfy_url` に含まれる `localhost` または `127.0.0.1` を `request.url.hostname` に動的置換して返却。
   - ローカルアクセスの場合は既存の `settings.comfy_url` をそのまま返却。
2. **CORS 設定の外部 LAN 適合**:
   - LAN 内端末（`http://192.168.*`, `http://10.*` 等）からの API リクエストが CORS で遮断されないよう、`allow_origin_regex=r"^https?://.*"` または `allow_origins=["*"]`（`allow_credentials=False` の場合）等の柔軟な適合を行う。
3. **単体テストの作成 (`backend/tests/test_api_config_network.py`)**:
   - `TestClient` を用いて、`Host: localhost:8000` の場合、`Host: 192.168.1.50:8000` の場合、Host が不正な場合の動作を検証。
