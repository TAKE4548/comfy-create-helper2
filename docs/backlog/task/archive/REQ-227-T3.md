### 2.1 変更仕様詳細

#### 1) `frontend/src/pages/GeneratePage/hooks/usePresetState.ts`
`presets` クエリの再取得（オートセーブ成功時の `invalidateQueries` 等）時、`existingSet.paramValues` を保持し、編集中の未保存・保存途中パラメータが初期値へ巻き戻る競合を遮断する。

```typescript
// L684-L700 周辺:
const rawMappedSets = presets.map((p) => {
  const existingSet = existingSetsMap.get(String(p.id))
  return {
    id: p.id,
    name: p.name,
    // defaultParams < サーバー取得値 < 既存セット内のローカル編集値 の順で優先マージ
    paramValues: {
      ...defaultParams,
      ...(p.param_values || {}),
      ...(existingSet?.paramValues || {}),
    },
    appliedAssets: existingSet?.appliedAssets || p.applied_assets || {},
    promptChips: existingSet?.promptChips,
    batchSize: existingSet?.batchSize || p.batch_size || 1,
    seedMode: existingSet?.seedMode || (p.seed_mode as 'random' | 'fixed') || 'random',
    seed: existingSet?.seed !== undefined ? existingSet.seed : (p.seed !== undefined ? p.seed : 42),
    checked: checkedPresets === null ? true : checkedPresets.includes(p.id),
  }
})
```

#### 2) `frontend/src/pages/GeneratePage/hooks/useGenerateAction.ts`
`handleGenerateSets` において、`checkedSets` をループ処理する際、アクティブなセットであれば現在の生ストア値（`currentParamValues`）を優先マージし、Reactのステート反映ラグによる古い設定値の送信を防ぐ。

```typescript
// L142 周辺:

    : setItem.paramValues
  const itemChips = isActive
    ? (promptChips || setItem.promptChips || {})
    : (setItem.promptChips || {})

  const effectiveParamValues = getEffectiveParamValues(itemParams, itemChips)
  const syncedParamValues = applyParamSync(effectiveParamValues)
  // ... injectWorkflowParams に syncedParamValues を伝搬
}
```
