# REQ-333-T46

HistoryModalPreviewは同期localRecordedMetadataをresolved query結果より優先するため、T43がserver実completed_atだけをlocalのcopyへ補っても画面へ出ない。未保存画像では現在prompt IDのresolved metadataが到着したらそのcopyを使い、pending時は現在promptの同期localを即表示する。resolvedは他のlocal凍結生成factsを保持する契約。Snapshotは保存済みsnapshot.paramsの正本を維持。queryKeyはprompt IDごとで、別画像の記録をpending時に表示しない。
