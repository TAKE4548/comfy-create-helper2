## 現行コード（`headerMenuPlacement.ts` 全体の該当部分）
```ts
export const HEADER_MENU_MIN_HEIGHT_PX = 96                      // L3
export interface HeaderMenuPlacementInput {                      // L14-21
  anchor: RectLike
  /** Measured offsetWidth (px). Unmeasured = 0. */
  panelWidth: number
  /** visualViewport ?? window.inner* */
  viewport: { width: number; height: number }
  align: HeaderMenuAlign
}
// computeHeaderMenuPlacement 内（L38-49）
  const top = anchor.bottom + HEADER_MENU_GAP_PX
  const maxHeight = Math.max(0, viewport.height - top - EDGE)
  const offscreen =
    anchor.bottom < 0 || anchor.top > viewport.height ||
    anchor.right < 0 || anchor.left > viewport.width
  const shouldClose = offscreen || maxHeight < HEADER_MENU_MIN_HEIGHT_PX
```

## 変更内容（確定）
1. 定数を追加（`HEADER_MENU_MIN_HEIGHT_PX` の直後）:
```ts
/** PageHeader ルート要素の目印。HeaderDropdown が anchor.closest() でヘッダー下端を取得する（T13 が属性を付与）。 */
export const PAGE_HEADER_ROOT_SELECTOR = '[data-page-header-root]'
```
2. `HeaderMenuPlacementInput` に任意項目を追加（`anchor` の直後）:
```ts
  /** PageHeader ルートの bottom（ビューポート座標）。未指定・非有限（NaN/Infinity）は無視してトリガー基準へ縮退。 */
  headerBottom?: number
```
   `anchor` の意味: 水平基準・画面外判定に使うラッパー rect。`anchor.bottom` は呼出側（T12）がトリガー実体（子要素のヒットスロップ込み）の下端として計測済みの値を渡す。純関数は `anchor.bottom` をそのまま `triggerBottom` として扱う。
3. `top` の計算のみを置換（`maxHeight`・`offscreen`・`shouldClose`・`left` の式は**不変**）:
```ts
  const refBottom =
    headerBottom !== undefined && Number.isFinite(headerBottom)
      ? Math.max(anchor.bottom, headerBottom)
      : anchor.bottom
  const top = refBottom + HEADER_MENU_GAP_PX
```
   `const { anchor, headerBottom, panelWidth, viewport, align } = input` に分割代入を更新。
