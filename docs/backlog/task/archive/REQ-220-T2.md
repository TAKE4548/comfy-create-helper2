  - `initialChips` の初期化:

  - 状態変更時の通知:
    - ユーザー操作（トグル、追加、削除、並び替え等）により `state` が変更された際、`onChipsChange?.(state)` を直接呼び出して完全なチップ配列を親に通知する。
