# REQ-308-T3: 生成境界で prompt role のみ chip を反映

## Impacted Files
- `frontend/src/pages/GeneratePage/hooks/useGenerateAction.ts`
- `frontend/src/pages/GeneratePage/hooks/__tests__/useGenerateAction.test.ts`

## Hermetic Context
`useGenerateAction(workflow: Workflow | undefined, ...)` owns workflow mappings and has two production calls:
```ts
const effectiveParamValues = getEffectiveParamValues(currentParamValues, currentPromptChips || {})
const effectiveParamValues = getEffectiveParamValues(itemParams, itemChips)
```
`Workflow.mappings` contains nullable `role`/`input_type`. Anima flag is currently not forwarded at these call sites.

## Implementation
- Use the helper signature completed by T1 to provide explicit prompt roles and Anima mode.
- At both single and multi-set generation call sites pass textarea roles from `workflow?.mappings` and current `isAnimaMode`.
- Missing workflow/mappings means an empty allowlist, preserving original parameters; never infer prompt roles from chip existence.
- Test that single and multi-set payloads retain dotted checkpoint/LoRA values while prompt chips use period-aware serialization.
