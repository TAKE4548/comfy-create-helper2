## 4. 実装要件・手順
1. **URL 正規化ユニットテスト**:
   - `test_resolve_internal_comfy_url_rewrites_external_host`:
     - `http://192.168.3.13:8188/view?filename=test.png&type=temp` が渡された場合、`http://localhost:8188/view?filename=test.png&type=temp` に正しく書き換えられること。
   - `test_resolve_internal_comfy_url_preserves_non_comfy_urls`:
     - `https://example.com/photo.png` のような通常 URL は書き換えられないこと。
2. **スナップショット保存 API 結合テスト**:
   - `test_create_snapshot_with_external_comfy_url_saves_webp_and_thumbnail`:
     - 外部 IP の ComfyUI URL（`http://192.168.1.100:8188/view?filename=test.png`）を送信した際、内部 ComfyUI から画像を取得して `db/snapshots/` に WebP 画像とサムネイルを永続化し、返却および DB の `image_path` / `thumbnail_path` が `/api/snapshots/images/...` になることを検証（AC-1, AC-2）。
   - `test_create_snapshot_download_failure_raises_502_and_rolls_back`:
     - ダウンロードが失敗した場合（404 またはタイムアウト等）、HTTP 502 / 404 エラーを送出し、DB に壊れたレコード（`thumbnail_path: None`）が残らないことを検証。
