# REQ-343-T4: ワークフロー取り込み（UploadWorkflowModal）および再スキャン（RescanModal）の多段階スロットUIと未設定操作の実装

## 1. 概要と目的
`UploadWorkflowModal` および `RescanModal` において、Role単位でワークフローから検出された有効ステージ（Main, Rough, Detail等）のスロットを展開するUIを実装する。
各ステージスロットには、推奨ノード（★バッジ付き）の選択ドロップダウンと「未設定」選択肢、およびワンクリックで未設定化できるクリアボタン（✕）を配置する。
不要な組み合わせを未設定にしたまま、バリデーションエラーなく安全に保存・登録を完了できるようにする。

## 2. ターゲット識別
- **対象ファイル**:
  - `frontend/src/components/UploadWorkflowModal.tsx`
  - `frontend/src/components/RescanModal.tsx`

- **対象シンボル**:
  - `UploadWorkflowModal`, `RescanModal`
  - スロット描画ロジック、`handleConfirm`, `saveMutation`

## 4. 実装要件 (Implementation Logic)
- [ ] `frontend/src/components/UploadWorkflowModal.tsx`:
  - `useMasterMappingRows` から `updateSlotNodeId`, `clearSlot` を取得。
  - 各Role行において、`row.stageSlots` が存在する場合はステージごとのサブスロット（ステージバッジ、セレクトボックス、クリアボタン✕）をレンダリング。
  - ドロップダウンの先頭に `<option value="">未設定</option>` を配置し、推奨ノードには `★ [ID] タイトル [推奨]` を表示。
  - スロット右側にワンクリックで未設定化する `clearSlot(slot.slotKey)` ボタン（✕アイコン）を設置。
  - `getMappings(mainRows, notFoundRows)` で取得したマッピング（未設定スロットは自動除外される）を用いて `workflowsApi.create` を実行。
- [ ] `frontend/src/components/RescanModal.tsx`:
  - `UploadWorkflowModal` と同様に、各Role行内で `row.stageSlots` を展開し、クリアボタンおよび「未設定」選択肢を提供。
  - 保存時に未設定スロットが除外されたマッピングで `workflowsApi.update` を実行。
- [ ] `frontend/src/components/__tests__/WorkflowModalMultiStage.test.tsx`:
  - 多段階ステージ（Main, Rough）が存在するワークフローに対し、Roleごとにステージスロットが表示されるテスト。
  - クリアボタンをクリックすると未設定状態になり、保存時にそのスロットが除外されてAPIに送信されるテスト。
