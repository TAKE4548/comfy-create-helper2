# REQ-385-T2: ComfyGenerationBridgeの不要な二重queue()削減と完了時プレビュークリア

## 1. 概要と目的
`ComfyGenerationBridge.interrupt()` で実行されていた連続する冗長な二重 `await self.queue()` を1回に削減し、また `_handle_json_message` で `executing` (node: null) 受信時にも `_latest_preview` キャッシュをクリアするよう改修する。

## 2. ターゲット識別
- **対象ファイル**: `backend/app/services/comfy_generation_bridge.py`
- **対象シンボル**: `ComfyGenerationBridge.interrupt`, `ComfyGenerationBridge._handle_json_message`
- **行番号目安**: L150-L161, L244-L250 付近

## 3. 密閉コンテキスト (Hermetic Context)

# backend/app/services/comfy_generation_bridge.py:150-161
    async def interrupt(self, prompt_id: str) -> None:
        before = await self.queue()
        if len(before["running"]) != 1 or before["running"][0]["prompt_id"] != prompt_id:
            raise RuntimeError("target is no longer the uniquely observed running prompt")
        # ComfyUI's /interrupt has no target parameter. Recheck immediately before
        # sending it and refuse to interrupt if the running prompt changed.
        latest = await self.queue()
        if len(latest["running"]) != 1 or latest["running"][0]["prompt_id"] != prompt_id:
            raise RuntimeError("target is no longer the uniquely observed running prompt")
        response = await self._request("POST", "/interrupt", timeout=5.0)
        self._response_json(response)

# backend/app/services/comfy_generation_bridge.py:244-250
        if isinstance(prompt_id, str) and (
            event["type"] in {
                "execution_success",
                "execution_error",
                "execution_interrupted",
            }
            or (event["type"] == "executing" and data.get("node") is None)
        ):
            self._latest_preview.pop(prompt_id, None)

## 4. 実装要件 (Implementation Logic)
- [ ] `ComfyGenerationBridge.interrupt` において、`before = await self.queue()` を呼び出した直後に再度 `latest = await self.queue()` を呼んでいる冗長性を解消し、1回の queue チェック後に直ちに `POST /interrupt` を送信する。
- [ ] `ComfyGenerationBridge._handle_json_message` において、`executing` (node: null) を受信した場合も `_latest_preview.pop(prompt_id, None)` を実行して中間プレビューを速やかに解放する。
- [ ] 既存テスト `test_comfy_generation_bridge.py` の `test_interrupt_*` で `queue_reads == 2` をアサートしている箇所を `queue_reads == 1`（または新挙動）へ整合させる。
