# Task Card: REQ-278-T2

## 1. 目的
REQ-277 で混入した `useGenerateAction.ts` 内の肥大化した対症療法パッチ（`checkedSets.length === 1` や多重の非存在チェックによる複雑な `isActive` 判定）を整理する。
上流の `usePresetState.ts`（T1）でインメモリ状態の完全性が保証されるため、下流のフォールバック判定をシンプルかつ堅牢に一本化し、過剰改修による認知負荷と潜在バグを根絶する。

## 2. 対象ファイル
- `frontend/src/pages/GeneratePage/hooks/useGenerateAction.ts`

## 3. 実装仕様

### 3.1 `handleGenerateSets` 内の `isActive` 判定シンプル化
```typescript
const isExplicitActive =
  currentActiveSetId !== null &&
  currentActiveSetId !== undefined &&
  String(setItem.id) === String(currentActiveSetId)

// 単一チェック時またはアクティブID一致時の安全かつシンプルなアクティブ判定
const isActive =
  isExplicitActive ||
  (checkedSets.length === 1 &&
    (!currentActiveSetId || String(checkedSets[0].id) === String(setItem.id)))

const itemParams = isActive
  ? { ...setItem.paramValues, ...currentParamValues }
  : setItem.paramValues
```
