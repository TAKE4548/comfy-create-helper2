# REQ-338-T4: Modal基盤 Body Scroll Lock & Sticky Footer、overscroll-contain強化

## 1. 概要と目的
PC・モバイル問わずモーダルダイアログ展開中に背面ページが連動スクロールしてしまう不快挙動（Scroll Chaining）を防止するため、Body Scroll Lock（`body { overflow: hidden }`）を確実に適用し、ダイアログ下部決定ボタンの Sticky Footer 化および `overscroll-behavior: contain` を強化する。

## 2. ターゲット識別
- **対象ファイル**: `frontend/src/components/common/Modal.tsx`
- **テストファイル**: `frontend/src/components/common/__tests__/Modal.test.tsx`
- **対象シンボル**: `Modal`, `ModalProps`

## 3. 密閉コンテキスト (Hermetic Context)
<hermetic_context>
### 3.1 既存の Modal.tsx (抜粋)
```typescript
// frontend/src/components/common/Modal.tsx:43-54
  useLayoutEffect(() => {
    if (!isOpen) return

    const previouslyFocused = document.activeElement as HTMLElement | null
    const focusableElements = getFocusableElements(dialogRef.current)
    ;(focusableElements[0] ?? dialogRef.current)?.focus()

    return () => {
      if (previouslyFocused?.isConnected) previouslyFocused.focus()
    }
  }, [isOpen])
```

### 3.2 Body Scroll Lock 実装パターン
```typescript
  useLayoutEffect(() => {
    if (!isOpen) return
    const originalOverflow = document.body.style.overflow
    document.body.style.overflow = 'hidden'
    return () => {
      document.body.style.overflow = originalOverflow
    }
  }, [isOpen])
```
</hermetic_context>

## 4. 実装要件 (Implementation Logic)
- [ ] `Modal.tsx` に `body` スクロール固定フックを導入。`isOpen` が `true` の間 `document.body.style.overflow = 'hidden'` を設定し、クローズ時およびアンマウント時に元のスタイルへ復元する。
- [ ] 複数モーダル展開時のカウンタ管理（参照カウント式、またはアクティブモーダル判定）により、ネストしたモーダルが閉じられた際にも親モーダルが開いていれば lock を維持する。
- [ ] ダイアログコンテナに `overscroll-contain` を徹底し、外枠へのスクロール連動を遮断。
- [ ] フッター領域（子要素に Sticky クラスが適用可能な flex-col 構造）のスタイル整合性を担保。
- [ ] `Modal.test.tsx` でモーダル開閉時の `document.body.style.overflow` の設定・復元を検証。
