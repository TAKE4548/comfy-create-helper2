## Implementation Logic

全登録master/variantのタイトル集合を共通定義に変換してrank関数をslot毎に呼ぶ。候補採点は選択stateを更新しない。共通ビューに切替えstage一括/個別toggleを接続。basicfalseの初回行は非表示。空欄/disabledノードIDは独立、保存はraw mappings+全取込state。masters解決とscan完了の両方を待ってinitし保存中は編集ロック。
承認済みT8接続: buildRows().rowsのmaster順→stageSlots順でEditableSlotへ展開し、node_id→nodeId、reference_missing→missingReference、enabled→enabledを投影。editor/input keyはhookのv_<id>/m_<id>をそのまま使い、onToggleSlotはsetSlotEnabled(key,enabled)、onToggleStageはhook setStageEnabled(stageId,enabled)。保存getMappings(rows,[])とmappingSlotStatesは空欄/disabledで欠落させない。同sessionのscan/refetchで再initせず、再open/別workflowではhook remountでsessionを分ける。Mの同input/key/value/focus証拠をHの補足caseと組み合わせる。

追加file/300変更行超過/矛盾時は証拠と分割案をcoordinatorへ返して再設計。
実logicを実行し、fetch/MSW HTTP、SQLite/disk境界だけを切る。新caseでAPIclient/helperをpatchしない。
入力DOMをstatus/candidate数で差し替えない。stable keyと明示空文字を保つ。masters+scan/GET完了後に1session1回init。
