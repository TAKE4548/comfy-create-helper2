# REQ-333-T42

既存T4の完了を前提に開始する回帰修正root。既存受付契約を再設計せず、本修正内の依存はT42→T43→T44の3層。

ユーザー指示: 画像メタ情報に生成完了日時がない。version1の予約メタrecord `__prompt_surgeon_metadata_v1`へoptional `completed_at`を追加する。succeeded遷移時のGenerationJob.finished_atをUTC日時で同transactionに保存し、queued_atと凍結params/seed/assetsを維持する。リプレイで日時を更新しない。failed/cancelledには成功画像の完了日時を捏造しない。marker欠落/不正/未知versionを壊さず維持。元の凍結受付metadataは書き換えない。

既存生成もGET prompt-metadata時に、valid version1 recordと対応succeeded GenerationJob.finished_atが存在する場合だけ、返却copyにcompleted_atを補う。既存recordの記録済みcompleted_atを優先し、DB更新なし。created_atや画像保存時刻を代用しない。generation rowが整理済みなら未記録のまま。Snapshot品質・ライフサイクル・DB schemaは変更しない。新しいSnapshotは既存のparam_valuesコピーにより日時recordを引き継げる。
