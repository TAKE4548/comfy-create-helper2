# REQ-333-T40

ユーザー指示: モバイルで表示セッションのキャプションとStudio含む範囲selectの位置が悪く、下部が崩れる。狭幅ではキャプション、範囲select、取消actionを段組みし、横溢れと潰れを避ける。Desktopも自然に表示。captionの表示フィルタは取消範囲と独立、default scope allと既存3取消操作を維持する。長い結果messageも折り返し。高さ不足時に内容をscrollできること。視覚変更であり動作は変更しない。

## Impacted Files
- frontend/src/components/JobManagementModal.tsx
- frontend/src/components/__tests__/JobManagementModal.req333.test.tsx

Set-Location frontend
npx vitest run src/components/__tests__/JobManagementModal.req333.test.tsx
