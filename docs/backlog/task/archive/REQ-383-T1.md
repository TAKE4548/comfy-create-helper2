## 3. 規範的改定要件 (Normative Implementation Requirements — AC-1〜AC-14)

1. **冒頭メタデータ・§1・§2 デスクトップ構成（AC-1, AC-12, AC-14）**:
   - バージョンおよび最終更新日を更新し、関連仕様書リンクに `[REQ-383設計](../design/REQ-383.md)` と `[REQ-383検証計画](../design/REQ-383-test-plan.md)` を追加する（既存の他リンクは削除・変更しない）。
   - §2 において、デスクトップ右カラム（幅768px以上）の閲覧モデルを **(1) メインプレビュー（直近結果の連続横スクロールリール閲覧・比較）**、**(2) 履歴（大量結果の俯瞰・ジャンプ・複数選択）**、**(3) 詳細表示（`HistoryModalPreview` による単一画像の拡大確認）** の3階層として明記し、メインプレビューと履歴は最新画像を先頭（`index 0`）とする同一の時系列画像列に対する縮尺・密度の異なる2つの操作ビューであることを定義する。
   - デスクトップ表示でのメインプレビュー横スクロールおよび履歴の開閉・選択操作中に、`document.body` に横スクロールバー（`overflow-x`）を発生させない不変条件（AC-14）を明記する。
2. **§2-9 メインプレビューの連続横スクロールリール化・端点ジャンプ・共有コントロール（AC-1, AC-2, AC-3, AC-4, AC-5, AC-6, AC-10, AC-11, AC-14）**:
   - **連続横スクロールリール化（AC-1）**: 旧来のページ送り式（利用可能横幅に収まる枚数ごとのページ分割・ページ矢印切替）記述を廃止し、最新画像を論理上の先頭（`index 0`、左端）として右方向へ進むほど過去画像となる最新-first固定の連続横スクロールリール（REQ-383）へ更新する。ソート順を反転する操作は表示しない。
   - **初期中央配置と端部余白（AC-2）**: 初期表示時は端部スクロール余白により最新画像（先頭、`index 0`）の中心をプレビュー領域の水平中央に配置する。先頭（最新）および末尾（最古）のいずれの端点画像も、画像自体の表示幅を圧縮せずにプレビュー水平中央へ吸着・配置できる端部スクロール余白を確保する。
   - **慣性スクロールと停止時中央吸着（AC-3）**: マウスホイール（縦ホイール入力から横移動インパルスへの変換）およびトラックパッドの横入力による連続横スクロールをサポートし、連続入力時でも不要な振動や入力相殺による急停止を起こさず滑らかに減衰し、減衰停止後に最も中心に近い画像がプレビュー水平中央へ吸着することを明記する（モック検証時の初期基準値：縦ホイール係数 `0.38`、横係数 `0.28`、減衰 `0.89`、停止閾値 `0.35` は参考値として併記可）。
   - **混在アスペクト比維持と領域内表示（AC-4）**: 縦長・正方形・横長（2:1等）の画像が混在する場合でも各画像の元アスペクト比を維持して均一な基準高に揃え、横長画像には最大幅上限（viewport幅の約 `0.86` 倍基準等）を設けて高さを比例調整することで、画像やタイルがプレビュー領域を上下・左右にはみ出さず、細長い空枠や枠内での極端な縮小を防止することを明記する。
   - **プレビュー右上共有ツールバーと端点ジャンプ（AC-5, AC-6, AC-10, AC-11）**:
     - プレビュー右上に時系列方向と一致させた順序で `← 最新へ`、`最古へ →`、`最新追従`、`自セッション`、`履歴` を整列配置する。
     - `← 最新へ`（AC-5）: ユーザーが過去画像側へスクロール移動している状態（目安閾値 `scrollLeft >= 72px` 等）で動的に表示し、押下契機で即座に進行中のスクロール慣性を停止して最新画像（`index 0`）をプレビュー水平中央へ移動・中央表示する。
     - `最古へ →`（AC-6）: 履歴に複数画像がある状態で常時利用可能とし、押下契機で即座に進行中のスクロール慣性を停止して最古画像（末尾）をプレビュー水平中央へ移動・表示する。
     - `最新追従`（AC-10）および `自セッション`（AC-11）: 履歴を開かずに通常プレビュー上部から直接操作可能とし、履歴ペイン側のトグルと単一の共有状態（`previewAutoFollow` / `filterOwnSession`）として双方向に即時連動・同期する。新規生成完了時は自動追従ONなら最新画像を中央表示し、OFFまたは過去閲覧中は閲覧中画像のスクロールアンカーを補正して視覚的ジャンプを防止する。
   - **キーボード操作**: リールフォーカス時の `Home`（慣性停止＋最新画像を中央表示）、`End`（慣性停止＋最古画像を中央表示）、`ArrowLeft` / `ArrowRight`（慣性停止＋隣接/横方向スクロール移動）を明記する。§2-9 の REQ-362（プログレッシブWebP・三位一体キャッシュ）、右側ActionBar、REQ-387（配信窓・ジョブ管理）の既存記述はそのまま保持する。
3. **§2-11 サムネイルストリップ（履歴ペイン）の最新-first固定・双方向同期・ローカルClose（AC-1, AC-7, AC-8, AC-9, AC-10, AC-11, AC-13）**:
   - **ソート切替廃止（AC-1）**: 現行の「表示順: 『新しい順（降順）』『古い順（昇順）』切替」を廃止し、メインプレビューと同一の最新-first固定（先頭 `index 0` が最新画像）に改める。
   - **通常クリック時の双方向同期（AC-7）**: 履歴展開時、通常モード（単一選択）で任意の履歴サムネイルをクリックした際、対象画像を選択状態にするとともにメインプレビューの進行中慣性を停止し、該当画像へスクロール移動してプレビュー水平中央に表示する。
   - **複数選択時のスクロール抑止（AC-8）**: 複数選択モード中（または `Ctrl` / `Meta` / `Shift` 等の複数選択修飾キー押下時）に履歴サムネイルをクリックして選択／解除する場合は、メインプレビューのスクロール位置を移動・ジャンプさせない。
   - **履歴ローカルClose導線（AC-9）**: 履歴展開時、プレビューと履歴の境界バーに `⌄ 履歴を閉じる` ボタンを配置し、押下により履歴ペインが閉じてメインプレビューの表示領域が履歴展開前の通常表示高へ復帰することを明記する（プレビュー右上の `履歴` 開閉ボタンとも状態同期）。
   - **既存履歴操作の維持（AC-13）**: 複数選択チェックボックス、一括保存、選択解除、スナップショットタブ（`history` / `snapshots`）操作、および §2-11 後半の画像URL正規化・ゼロプローブ・reload差分同期の既存記述を完全に維持する。
4. **§6-2 履歴プレビューモーダル & §7 コンポーネント構成（AC-12）**:
   - §6-2 において、メインプレビューのリール内画像をクリックした際、既存の詳細プレビューモーダル（`HistoryModalPreview.tsx`）が開き、拡大表示・メタデータ確認・追従トグルおよび閉じる操作（`Escape` キーまたは閉じるボタン）が正常に機能すること（AC-12）を明記する。
   - §7 のツリー図に `components/GenerateParallelPreview.tsx` および `hooks/useGalleryInteraction.ts` を補完する。
