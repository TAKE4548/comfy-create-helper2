# REQ-268-T4: tmp/ 配下の滞留ファイル・一時スクリプト・ログのクリーンアップ

## 1. 概要
`tmp/` 配下に滞留している一時ログ（`uvicorn.log`）、一時検証スクリプト（`verify_api.py` 等）、過去の調査 PDF、役目を終えた要件ドラフトなど 23 件の不要ファイルを一括パージ・クリーンアップする。

## 2. 変更対象領域
- `tmp/` 配下の全滞留ファイル（23件）:
  - 一時ログ: `uvicorn.log`
  - 一時スクリプト・データ: `verify_api.py`, `verify_migration.py`, `API_base_v5.json`
  - 過去レポート・PDF: `*.pdf` (7件)
  - 過去ドラフト仕様・スタブ: `*.md` (8件), `*.gdoc` (4件)

## 3. 手順詳細
1. `tmp/` 配下の滞留ファイルを全量削除する。
2. 削除後、`tmp/` ディレクトリがクリーンな状態になっていることを確認する。

## 4. コンテキスト
- `tmp/*` は既に `.gitignore` に含まれており Git 管理対象外であるため、削除によって Git リポジトリ履歴に悪影響を与えることはない。
- 将来の検証スクリプト実行時にも支障のない一時領域として初期化される。

## 5. 検証手順
- `ls tmp` で滞留ファイルがパージされていることを確認。
