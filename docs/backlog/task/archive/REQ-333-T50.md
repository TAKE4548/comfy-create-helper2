# REQ-333-T50

実ログAPIは全4サービスHTTP200、linesは総行数number、contentは本文string。FEはlines:string[]しか認めず取得失敗になる。sourceと稼働APIのnumeric lines契約を維持し、FE decoderはnumber＋contentを受け、既存array payload互換も維持する。UIへ渡すlinesはcontentからの配列に正規化して良い。filename/exists/contentを保持、不正payloadは拒否する。

FEの一律7000msはManager操作より短い。status/logsは従来7秒維持、actionだけ上限120秒へ延長し、90秒までのManager予算に余裕を持つ。TimeoutError/HTTP504は結果未確認として識別できるtyped errorを返し、明確なnonzero/HTTP502/不正レスポンスの失敗と区別する。HTTP503/接続断はmutation結果不明として自動再送しない。responseの成功のみでrunningを捏造しない。既存action payloadは維持。
