## Implementation Requirements
- [ ] 両test fileは独立状態を作る。beforeEachは `localStorage.clear()` / `sessionStorage.clear()`、new `IDBFactory()`、QueryClient・Zustand store・deferred API mockをcaseごとに再作成する。Persisterは `createIndexedDBPersister({ indexedDB: idbFactory, storage: window.localStorage, now: () => controlledNow })` を使う。before/after local/session key-value snapshotを保持し、API cacheの削除・更新以外の差分を許可しない。
- [ ] 大容量fixture: API cache JSONのpayloadを2,097,152 UTF-16 code unitsにする。非APIデータは固定。`prompt-surgeon-meta-*` の30record合計を786,432 UTF-16 code unitsにし、promptId/timestampをすべて別値にする。期待localStorage量はΣ(key.length+value.length)*2、旧APIキーの長さも除く。UTF-16推定量を実browser quotaと同じと扱わない。
