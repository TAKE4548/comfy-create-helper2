### REQ-340-T3: Frontend: FallbackParamsInput (表記ゆれパラメータ名 チップ管理・優先順並び替え) 実装

#### 1. 目的とスコープ
プライマリの `param_name` に対応する表記ゆれ（フォールバック）パラメータ名を複数登録・管理・優先順位並び替えできる `FallbackParamsInput` コンポーネントを実装する。

#### 2. 型定義・コンポーネントシグネチャ
```typescript
// frontend/src/components/FallbackParamsInput.tsx
export interface FallbackParamsInputProps {
  primaryParamName: string
  fallbackParams: string[]
  onChange: (params: string[]) => void
  disabled?: boolean
}
```

#### 3. 変更箇所のサージカルスニペット
```typescript
// チップの追加と優先順移動
const movePriority = (index: number, direction: 'up' | 'down') => {
  const targetIndex = direction === 'up' ? index - 1 : index + 1
  if (targetIndex < 0 || targetIndex >= fallbackParams.length) return
  const next = [...fallbackParams]
  const [removed] = next.splice(index, 1)
  next.splice(targetIndex, 0, removed)
  onChange(next)
}
```
