### 2.3 変更後の修正方針
1. `handleWeightKeyDown` の先頭に `e.stopPropagation()` を追加し、数値入力欄内でのキーイベント（`Backspace`、`Delete`、`Space`、`Ctrl+D` 等）が親の `div` に伝播するのを防ぐ。
2. サブメニューのルート `div` に `onKeyDown` ハンドラを追加し、`e.stopPropagation()` を呼ぶとともに `Escape` キー押下時に `setIsMenuOpen(false)` を実行して、サブメニュー全体のキー伝播境界を確立する。

```tsx
  const handleWeightKeyDown = (e: React.KeyboardEvent<HTMLInputElement>) => {
    e.stopPropagation();
    if (e.key === 'Enter') {
      e.preventDefault();
      handleWeightSubmit();
    } else if (e.key === 'Escape') {
      e.preventDefault();
      setIsMenuOpen(false);
    }
  };
```
