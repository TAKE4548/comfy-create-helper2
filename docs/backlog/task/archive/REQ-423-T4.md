# REQ-423-T4: フロントエンドUI各種保存経路におけるinput_name欠落防止と再スキャン復元

## 1. 概要と目的
フロントエンドの各保存処理（設定画面 `WorkflowConnectionSection`、再スキャンモーダル `RescanModal`、生成画面 `useWorkflowManagement`、データセットスタジオ `NodeRemapModal`）において、API更新ペイロードの構築時に `input_name` を除外せず、確実にバックエンドへ送信・永続化するよう改修する。
また既存ワークフローに対して再スキャン（`RescanModal`）を実行して保存した際、スキャナーが合致した `input_name`（`"noise_seed"` 等）が DB へ確実に反映・復元されることを検証する。
