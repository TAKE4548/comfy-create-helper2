### 2.3 防護モジュール設計要件 (`backend/app/utils/windows_loop_defense.py`)
1. `sys.platform == "win32"` の場合のみ実行（非Windowsでは安全に no-op で True を返却）。
2. `asyncio.set_event_loop_policy(asyncio.WindowsSelectorEventLoopPolicy())` を適用。
3. `asyncio.proactor_events.BaseProactorEventLoop._start_serving` を安全にラップ:
   - 内部の `loop(f)` 内で `OSError` が発生した際、`getattr(exc, "winerror", None) in (64, 1236, 10053, 10054)` の場合:
     - 警告ログを出力（"Ignored transient Windows accept error [WinError {winerr}]. Preserving listener socket."）。
     - リスナーソケット `sock` を `close()` せず、`self._proactor.accept(sock)` を再発行してループを継続。
   - それ以外の致命的 `OSError` や `CancelledError` は既存のハンドラ通り処理。
</hermetic_context>
