# REQ-377-T3: LoraDetailModal モバイルボトムシート再構成・固定フッター・小型Cover導線

## 1. 概要と目的
`LoraDetailModal` のモバイル表示（幅 767px 以下）を再構成し、本文上部に小型 Cover＋Snapshot 件数バナーを配置して画像ギャラリーサブビュー導線を提供する。フッターを本文スクロールから分離して最下部に固定し、閲覧時（Close左／Edit右）・編集時（Cancel左／Save右）のアクション配置を統一する（MUI-03, MUI-04, MUI-05, AC-1〜AC-7, AC-11, AC-13, AC-14）。

## 3. コンポーネント分類と制約 (<constraints>)
- **UI Archetype**: `Archetype 1: Modals & Overlays` / `Composite: Modal + Form + Media`
- **Surgical Constraints**:
  - `Modals & Overlays`: 下端起点ボトムシート (`modal-backdrop items-end md:items-center p-0 md:p-4`, `rounded-t-2xl`, `max-h-[90dvh] flex flex-col`).
  - `Scroll`: 本文単一スクロール (`overscroll-contain`, `flex-1 overflow-y-auto`). 親スクロール競合を遮断.
  - `Fixed Footer`: 本文外固定 (`flex-shrink-0 border-t border-[rgba(255,255,255,0.06)] px-5 py-3 bg-surface flex gap-3 pb-[calc(0.75rem+env(safe-area-inset-bottom,0px))]`).
  - `Action Placement`: 閲覧中 = 左 `Close` / 右 `Edit`、編集中 = 左 `Cancel` / 右 `Save` (MUI-04).
  - `Hit-Slop`: フッターボタンおよび小型 Cover は最小 44×44px タッチ領域 (`relative before:absolute before:-inset-2 before:content-['']`).
  - `Truncation`: モデル名・ファイルパス表示に `break-all` / `min-w-0 flex-1 truncate` を指定.

## 5. 実装要件 (Implementation Logic)
1. `LoraDetailModalProps` に `initialEditing?: boolean` を追加し、`const [isEditing, setIsEditing] = useState(Boolean(initialEditing))` で初期化する。
2. モバイルレイアウト（幅 767px 以下）の再構成：
   - 本文上部: 小型 Cover サムネイル（48×48px）＋「Related Snapshots (N 件)」行を配置。タップで `isGalleryOpen = true` に切り替える。
   - ギャラリーサブビュー: モバイルで `isGalleryOpen = true` 時、ヘッダーを「← 詳細に戻る」にし、スナップショット全件プレビューと Cover 選択・アップロード導線を展開する。
   - 固定フッター（モバイル）:
     - 閲覧中: 左 `Close` / 右 `Edit`
     - 編集中: 左 `Cancel` / 右 `Save`（バリデーションエラーまたは `isPending` 時に disabled）
     - セーフエリアパディング `pb-[calc(0.75rem+env(safe-area-inset-bottom,0px))]` を適用。
   - デスクトップ表示（`md:` 以上）: 既存の左右 2 列分割 (`md:grid-cols-2`) と右ペイン内ボタン配置を維持する。
3. `LoRAsPage.tsx`:
   - カード右上の編集ボタン (`#lora-edit-${id}`) クリック時、`setDetailInitialEditing(true); setSelectedLoraForDetail(lora)` を呼び出す。
   - カードクリック時は `setDetailInitialEditing(false); setSelectedLoraForDetail(lora)` を呼び出す。
4. `LoraDetailModal.test.tsx` および `LoraModals.test.tsx` に `[REQ-377/AC-1]` 〜 `[REQ-377/AC-7]`, `[REQ-377/AC-11]`, `[REQ-377/AC-13]`, `[REQ-377/AC-14]` テストケースを追加する。
