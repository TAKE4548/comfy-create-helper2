# REQ-386-T3: DesktopLayoutおよびMobileLayoutの個別進捗バーフォールバック表示とプレビュー即時表示統合

## 1. 概要と目的
本タスク（REQ-386-T3）は、**AC-1**（UI個別プログレスバーのフォールバック）、**AC-2**（DesktopLayoutプレビュー合成）、および **AC-3**（全完了時100%整合）を担当する。
個別プログレスバーをストアの `nodeProgress` に安全にフォールバックさせ、メインプレビューで生成完了画像（`selectedImg`）を即座（1秒以内）にレンダリングする。

  - `MobileLayout.tsx`: L265-L290 付近

## 4. 実装要件 (Implementation Logic)
- [ ] **AC対応と責務境界**:
  - 本タスクは **AC-1**（UI個別進捗バー表示）、**AC-2**（DesktopLayout即時プレビュー合成）、**AC-3**（全ジョブ完了時100%整合）を実装・検証する。
- [ ] **個別進捗率のフォールバック計算 (AC-1)**:
  - `DesktopLayout.tsx` および `MobileLayout.tsx` で `displayNodePercentage` を改修する。
  - `normalRunningJob?.node` の有効値があれば優先し、未取得時は `nodeProgress?.percentage ?? 0` へ安全にフォールバックする。
  - `displayNodeName` についても `normalRunningJob?.node?.name || nodeProgress?.nodeName || '準備中...'` とする。
- [ ] **完了画像の即時プレビュー表示 (AC-2)**:
  - `DesktopLayout.tsx` で `selectedImg` が履歴リスト先頭に未反映の場合、一時的に合成した `[selectedImg, ...currentDisplayImages]` を渡す。
  - これにより `GenerateParallelPreview` で完了画像が即時（1秒以内）にインデックス0としてプレビュー表示される。
- [ ] **全完了時の100%維持 (AC-3)**:
  - 全ジョブ完了直後、バッチ進捗率および全体進捗率が 100% となり、最新画像がプレビューに選択された状態を維持する。

### 4.1 UI Archetype 分類 & 制約 (Surgical Constraints)
- **UI Archetype**: `Archetype 4: Shell & Page Layout`
- **Universal Safety**:
  - 最小フォントサイズ 11px を維持（`text-[11px]`、`text-[10px]` は補助情報のみ）
  - raw `vh` の使用禁止（`dvh` または `h-full` レイアウトを使用）
  - 二重パディングの排除
- **Truncation**:
  - ノード名表示: `min-w-0 flex-1 truncate`
