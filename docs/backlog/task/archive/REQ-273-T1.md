## 2. 密閉コンテキスト (Hermetic Context)

### 2.1 コンポーネントインターフェース
```typescript
import React, { useState } from 'react';
import { LayoutGrid, FileText } from 'lucide-react';

export interface TagChipViewerProps {
  tags: string[];
  accentColor?: 'purple' | 'green';
  defaultMode?: 'chips' | 'text';
  className?: string;
  emptyPlaceholder?: string;
}
```

### 2.2 実装仕様要件
1. **初期状態**: `defaultMode`（未指定時は `'chips'`）で初期化。
2. **切替ボタン**:
   - 右上に小さなボタンスイッチを配置（`LayoutGrid` / `FileText` アイコン）。
   - クリックで `mode` を `'chips'` ⇄ `'text'` でトグル。
3. **チップモード (`chips`)**:
   - 各タグをバッジ表示（`flex flex-wrap gap-1.5`）。
   - `accentColor === 'green'` の場合: `bg-[rgba(74,222,128,0.1)] border border-[rgba(74,222,128,0.2)] text-accent-green`
   - `accentColor === 'purple'` の場合: `bg-[rgba(124,111,221,0.1)] border border-[rgba(124,111,221,0.2)] text-[#a99ef7]`
   - 閲覧専用: ドラッグ＆ドロップ、削除ボタン、編集フィールドは一切含めない。
4. **テキストモード (`text`)**:
   - カンマ区切り文字列（`tags.join(', ')`）を表示。
   - `p` または `div`（`font-mono text-xs text-zinc-300 break-words select-all leading-relaxed`）。
5. **空タグ時のフォールバック**:
   - `tags.length === 0` の場合、`emptyPlaceholder || 'No tags'` を薄い文字色（`text-zinc-500 italic`）で表示。
</hermetic_context>

## 3. 実装手順 (Step-by-Step Instructions)
1. `frontend/src/components/TagChipViewer.tsx` を新規作成し、上記仕様に基づいてコンポーネントを実装する。
2. `frontend/src/components/__tests__/TagChipViewer.test.tsx` を作成し、Vitest / React Testing Library で以下を検証する：
   - デフォルトでチップモードとしてレンダリングされること。
   - トグルボタン押下でテキストモードに切り替わり、再度押すとチップに戻ること。
   - チップ表示時に編集用要素（削除×ボタン、input）が存在しないこと。
   - `accentColor="green"` および `"purple"` のスタイルクラスが正しく適用されること。
   - 空タグ配列でもエラーなくプレースホルダーが表示されること。
3. `npm test TagChipViewer.test.tsx` を実行し、全テストパスを確認する。
