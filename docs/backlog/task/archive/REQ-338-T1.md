# REQ-338-T1: Hybrid Stepper Slider コンポーネントおよび数値防壁の実装

## 1. 概要と目的
粗調整スライダーに [-] [+] ステッパーボタンと直接数値入力を統合した `StepperSlider` 共通コンポーネントを新規実装する。マウス手振れによる行き過ぎストレスを解消し、数値表示に `tabular-nums font-mono` を適用して桁揺れを防止する。

## 2. ターゲット識別
- **対象ファイル**: `frontend/src/components/common/StepperSlider.tsx` (新規)
- **テストファイル**: `frontend/src/components/common/__tests__/StepperSlider.test.tsx` (新規)
- **対象シンボル**: `StepperSlider`, `StepperSliderProps`

## 3. 密閉コンテキスト (Hermetic Context)
<hermetic_context>
### 3.1 必須の型定義
```typescript
export interface StepperSliderProps {
  value: number
  onChange: (value: number) => void
  min?: number
  max?: number
  step?: number
  label?: string
  presets?: number[]
  className?: string
  disabled?: boolean
  id?: string
  ariaLabel?: string
}
```

### 3.2 実装構造イメージ
```tsx
<div className={`space-y-1.5 ${className}`}>
  {label && <div className="text-xs font-medium text-zinc-400">{label}</div>}
  <div className="flex items-center gap-2">
    <button type="button" aria-label="decrease" onClick={handleDecrease} className="w-8 h-8 rounded bg-surface border text-zinc-300">-</button>
    <input type="number" step={step} value={displayValue} onChange={handleInputChange} onBlur={handleBlur} className="w-16 h-8 text-center font-mono tabular-nums bg-surface-2 border rounded" />
    <button type="button" aria-label="increase" onClick={handleIncrease} className="w-8 h-8 rounded bg-surface border text-zinc-300">+</button>
    <input type="range" min={min} max={max} step={step} value={value} onChange={handleSliderChange} className="flex-1 accent-[#7C6FDD]" />
  </div>
  {presets && presets.length > 0 && (
    <div className="flex items-center gap-1.5 pt-1">
      {presets.map((p) => (
        <button key={p} type="button" onClick={() => onChange(p)} className="px-2 py-0.5 text-[10px] rounded bg-surface-2 border text-zinc-400">{p.toFixed(2)}</button>
      ))}
    </div>
  )}
</div>
```
</hermetic_context>

## 4. 実装要件 (Implementation Logic)
- [ ] `StepperSlider.tsx` の作成。
- [ ] [-] [+] ボタンクリックで `±step`（デフォルト 0.05）の増減。最小値・最大値でのクランプと浮動小数点数誤差（`toFixed` 等）の解消。
- [ ] 数値入力欄（直接入力）のサポート。フォーカスアウト時および Enter キー押下時に不正値（NaN、min未満、max超過）のバリデーションとクランプ。
- [ ] スライダートラック (`<input type="range">`) でのドラッグ粗調整。
- [ ] `presets` 配列が渡された場合、ワンタッププリセットピルを表示。
- [ ] 単体テスト `StepperSlider.test.tsx` でボタン増減、直接入力、クランプ、キーボード操作を検証。
