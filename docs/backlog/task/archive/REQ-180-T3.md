# タスクカード: REQ-180-T3

## 目的

## 密閉コンテキスト (Hermetic Context)

### 1. 型定義拡張 (`speechBubble.ts`)
```typescript
export interface BubbleTail {
  x: number // 元画像座標系での尻尾先端X
  y: number // 元画像座標系での尻尾先端Y
  baseAngleOffset?: number // 本体接点中心角度オフセット (rad, default: 0)
  baseSpreadRatio?: number // 接点幅倍率 (0.2 ~ 3.0, default: 1.0)
  isFineTuning?: boolean // 微調整モード有効フラグ (default: false)
}
```

### 2. レンダラーでの微調整反映 (`speechBubbleRenderer.ts`)
```typescript
if (bubble.shape === 'oval' && bubble.tail) {
  const tx = bubble.tail.x * scaleX
  const ty = bubble.tail.y * scaleY
  const baseAngle = Math.atan2(ty - cy, tx - cx) + (bubble.tail.isFineTuning ? (bubble.tail.baseAngleOffset ?? 0) : 0)
  const defaultSpread = 0.25
  const spread = bubble.tail.isFineTuning ? defaultSpread * (bubble.tail.baseSpreadRatio ?? 1.0) : defaultSpread
  const startAngle = baseAngle + spread
  const endAngle = baseAngle - spread

  ctx.ellipse(cx, cy, rx, ry, 0, startAngle, endAngle + (endAngle < startAngle ? Math.PI * 2 : 0))
  ctx.lineTo(tx, ty)
  ctx.closePath()
}
```

### 3. モーダルでのハンドル操作 (`SpeechBubbleEditorModal.tsx`)
- 選択中吹き出しにしっぽがある場合、しっぽ微調整トグルボタンをプレビューツールバーまたは設定に表示。
- 微調整モードON時、本体接点ハンドル（基部中心）を描画し、`draggingState.type === 'tail-base'` でドラッグ時に `baseAngleOffset` や `baseSpreadRatio` を更新。
