# REQ-341-T1: ヘッダー共通テレメトリ・メニューサブコンポーネント実装

## 1. 概要と目的
共通ヘッダー右端および状態表示で使用する3つの核となるサブコンポーネント（スリム状態バッジ、受動的リソースモニター＋Hover Card＋モバイル左スライド展開ピル、縦3点ケバブメニュー）を実装・改修する。
AC-3（スリム状態バッジ・ホバー詳細）、AC-4（リソースモニター・Hover Card）、AC-5（縦3点メニュー・ストレージ推定値・ComfyUI直通URL撤廃）、AC-7（7px発光ドット）、AC-8（モバイルVRAMピル左スライド展開オーバーレイ）の要素ロジックを担保する。

## 2. ターゲット識別
- **対象ファイル**:
  - `frontend/src/components/common/SystemStatusBadge.tsx`
  - `frontend/src/components/common/header/ResourceHoverMonitor.tsx` (新規)

  - `SystemStatusBadge`: スリムピル (`[● READY]`) ＋ ホバーツールチップ、モバイル用 7px 発光ドット (`variant?: 'full' | 'slim' | 'dot'`)
  - `ResourceHoverMonitor`: 常時 CPU->RAM->GPU->VRAM チップ表示、Hover Card (幅 250px, m/n GB)、モバイル用展開ピル (`[VRAM xx% ◀]` -> 330px オーバーレイ)
  - `HeaderKebabMenu`: 縦3点ボタン (28x28px)、ドロップダウン (幅 270px)、LocalStorage/SessionStorage 推定使用量、キャッシュ再同期、設定リンク

## 4. 実装要件 (Implementation Logic)
- [ ] `SystemStatusBadge.tsx`: `variant` プロパティを追加。
  - デフォルト/`slim`: 緑枠ピル `[● READY]` のみ表示し、冗長な `FE · BE · Comfy` テキストは常時非表示。ホバー時のツールチップ（`title` またはカスタムtooltip）で `FE 200 · BE 200 · Comfy (FastAPI中継 OK)` を表示。
  - `dot`: モバイル用の 7px 緑発光ドット（`w-[7px] h-[7px] rounded-full`、テキストなし）のみをレンダリング。
- [ ] `ResourceHoverMonitor.tsx`:
  - `useGenerationStore(s => s.systemStats)` からテレメトリを取得。
  - デスクトップ表示: チップを厳密な順序 `CPU` -> `RAM` -> `GPU` -> `VRAM` で配置（VRAMはパープルアクセント）。
  - ホバー時に幅 250px の `HoverCard` を展開。VRAM / RAM の実容量（`m / n GB`）とプロポーショナルバーを表示。テレメトリ未取得時や null 時は `--%` で安全フォールバック。
  - モバイル表示: 常時 `[VRAM xx% ◀]`（幅96px）を表示。タップで右隣の縦3点ボタンの上に覆いかぶさりつつ左方向へ 330px 伸長（z-index: 80 vs 10）。全リソース（`CPU xx% | RAM xxG | GPU xx% | VRAM xxG | ✕`）をインライン表示。✕または外側タップで格納。
- [ ] `HeaderKebabMenu.tsx`:
  - 28x28px の縦3点（⋮）ボタンと幅 270px のドロップダウン。
  - UTF-16 概算（キー＋値長 × 2 bytes）による LocalStorage および SessionStorage 推定容量表示（「推定値 / Estimate Only」明記）。SecurityError 時は「推定容量: 取得不可」を安全表示。
  - キャッシュ再同期アクションボタン、および `/settings` 画面遷移リンクを提供。
  - 旧ヘッダーの「ComfyUI 本体 URL」入力・表示は完全排除。
