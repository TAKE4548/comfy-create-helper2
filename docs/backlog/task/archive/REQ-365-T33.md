# REQ-365-T33: 入れ子ピッカーのバックドロップ margin 予防修正 (AC-9)

T31 と同一原因の静的解析所見（実ブラウザ実測は未実施。レポート D-R3-1 は入れ子ピッカーを欠陥なしとしたが、構造上は同型）。T31 とファイルが独立のため並行可。

## 原子性
2ファイル、変更は約5行（`<WorkflowNodePicker>` ブロックの移動のみ）。

## 原因
`MappingMasterEditModal.tsx:322` は `<form onSubmit={handleSubmit} className="flex-1 min-h-0 overflow-y-auto overscroll-contain p-4 md:p-6 space-y-6 text-zinc-100">`。その子として `:593` の `<WorkflowNodePicker>`（内部で共通 `Modal` → `.modal-backdrop` `position: fixed; inset: 0`、`WorkflowNodePicker.tsx:119`）が `WorkflowMappingPreview`（:584）の次、すなわち 2番目以降の子として置かれている。`space-y-6` により picker 展開時、その backdrop に `margin-top: 24px` が付く。

## 修正
`<WorkflowNodePicker .../>` の JSX ブロック（現状 593-599 行、下記）を `</form>`（:618）の**直後**、`</Modal>`（:619）の前へ移す。外側 Modal の children は dialog 直下（`flex flex-col`、`space-y` なし）で、fixed の backdrop は flow 外のため margin は付かない。picker は外側 dialog の DOM 内に残るので、外側 Modal のフォーカストラップや `closeOnEsc={!isNodePickerOpen}` の挙動は不変。副次効果としてピッカーのボタンがフォームの外になる。
```tsx
        <WorkflowNodePicker
          isOpen={isNodePickerOpen}
          onClose={() => setIsNodePickerOpen(false)}
          workflowJson={pickerWorkflowJson}
          hasExistingValues={Boolean(classTypes.length > 0 || paramName || titlePatterns.length > 0)}
          onSelectNode={handleApplyPickedNode}
        />
```
移動後:
```tsx
      </form>

      {/* Outside the space-y-6 form: the nested picker's .modal-backdrop must not receive a sibling margin. */}
      <WorkflowNodePicker ...same props... />
    </Modal>
```
`</form>` と `</Modal>` の間に他要素が無いことを実ファイルで確認する。

## テスト（既存 `MappingMasterEditModal.test.tsx` に追記。ケース名 `[REQ-365/AC-9]`）
既存 `does not close on Escape while the workflow node picker is open`（:102）と同じ準備でピッカーを開く（`workflowsApi.list/get` モック、`登録済みワークフロー選択` で選択、`ワークフローからノード選択 (逆引き)` クリック、dialog が2つ）:
```tsx
  it('[REQ-365/AC-9] nested node picker backdrop is not inside the space-y form (no sibling margin)', async () => {
    // ...same arrange as the Esc test above (list/get mocks, select workflow, click picker trigger)
    await waitFor(() => expect(screen.getAllByRole('dialog')).toHaveLength(2))
    const picker = screen.getByRole('dialog', { name: /ワークフローからノードを選択/ })
    const backdrop = picker.parentElement as HTMLElement
    expect(backdrop).toHaveClass('modal-backdrop')
    expect(backdrop.closest('form')).toBeNull()
    for (let el: HTMLElement | null = backdrop.parentElement; el; el = el.parentElement) {
      expect(el.className).not.toMatch(/(^|\s)(space-[xy]-|divide-[xy])/)
      if (el.getAttribute('role') === 'dialog') break
    }
  })
```
RED 確認: 修正前は `closest('form')` が非 null で失敗。既存の Esc 非クローズ・外側 Modal テストは緑のままであること。
