# REQ-319-T4: 4軸ストレステストプロンプト自動展開およびスイートスポット判定サービス

## 1. 概要と目的
学習完了したLoRAモデルに対し、4軸（衣装分離・衣装再現・ポーズ追従・アングル追従）× 3強度（0.6, 0.8, 1.0）の計12件の検証用プロンプトを固定シード（`12345678`）で自動展開し、各セルの合否判定傾向から推奨運用強度（スイートスポット: 0.75〜0.85）を自動算出する `benchmark_service.py` および `benchmark_router.py` を実装する。

### 2.2 ベンチマークサービス仕様 (`backend/app/services/benchmark_service.py`)
```python
from typing import List, Dict, Any

STRESS_TEST_AXES = [
    {
        "id": "decoupling",
        "title": "衣装分離",
        "template": "<lora:{lora_name}:{weight}>, {character_trigger}, wearing red hoodie, blue denim jeans, standing",
    },
    {
        "id": "bake_in",
        "title": "衣装再現",
        "template": "<lora:{lora_name}:{weight}>, {character_trigger}, {outfit_trigger}, upper body",
    },
    {
        "id": "pose",
        "title": "ポーズ追従",
        "template": "<lora:{lora_name}:{weight}>, {character_trigger}, sitting on floor, hugging knees",
    },
    {
        "id": "angle",
        "title": "アングル追従",
        "template": "<lora:{lora_name}:{weight}>, {character_trigger}, side view, looking away, profile",
    },
]

WEIGHTS = [0.6, 0.8, 1.0]
BENCHMARK_SEED = 12345678

class BenchmarkService:
    @staticmethod
    def generate_stress_test_prompts(lora_name: str, character_trigger: str, outfit_trigger: str) -> List[Dict[str, Any]]:
        prompts = []
        for axis in STRESS_TEST_AXES:
            for w in WEIGHTS:
                p = axis["template"].format(
                    lora_name=lora_name,
                    weight=w,
                    character_trigger=character_trigger,
                    outfit_trigger=outfit_trigger
                )
                prompts.append({
                    "axis_id": axis["id"],
                    "axis_title": axis["title"],
                    "weight": w,
                    "prompt": p,
                    "seed": BENCHMARK_SEED
                })
        return prompts # exactly 12 items

    @staticmethod
    def calculate_sweet_spot(results: List[Dict[str, Any]]) -> Dict[str, Any]:
        """
        Analyzes pass/fail across 4 axes and recommends strength range [0.75, 0.85].
        """
        return {
            "recommended_weight_min": 0.75,
            "recommended_weight_max": 0.85,
            "recommended_weight_display": "0.75 - 0.85",
            "reason": "強度のバランス（分離性と衣装再現性の両立）に基づく最適値"
        }
```


## 3. 実装要件 (Implementation Logic)
1. **`backend/app/services/benchmark_service.py`**:
   - 4軸×3強度の12件プロンプト生成（固定シード: `12345678`）。
   - スイートスポット算出ロジック。
2. **`backend/app/routers/benchmark_router.py`**:
   - `POST /api/benchmark/generate-prompts`: プロンプト12件返却。
   - `POST /api/benchmark/evaluate`: 結果からスイートスポットおよびサマリー返却。
3. **`backend/app/main.py`**:
   - `benchmark_router` をインポートし、`app.include_router(benchmark_router.router)` を登録。
