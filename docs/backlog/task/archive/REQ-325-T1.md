## 1. 概要と目的
平文プロンプト文字列を安全・正確に解析・シリアライズし、タグ除外/トリガー注入（デカップリング）を行う `PromptTokenEngine` 基盤を `frontend/src/utils/prompt/` に新設する。

### 3.2 既存の参考パース実装 (`frontend/src/components/TagChipEditor/useChipParser.ts`)
```typescript
export const splitTags = (text: string, isAnimaMode: boolean = false): string[] => {
  if (!text) return [];
  const tokens: string[] = [];
  let current = '';
  let parenDepth = 0;
  let bracketDepth = 0;
  let braceDepth = 0;
  for (let i = 0; i < text.length; i++) {
    const char = text[i];
    if (char === '(') parenDepth++;
    else if (char === ')' && parenDepth > 0) parenDepth--;
    else if (char === '[') bracketDepth++;
    else if (char === ']' && bracketDepth > 0) bracketDepth--;
    else if (char === '{') braceDepth++;
    else if (char === '}' && braceDepth > 0) braceDepth--;
    const inNest = parenDepth > 0 || bracketDepth > 0 || braceDepth > 0;
    if (!inNest && char === ',') {
      const trimmed = current.trim();
      if (trimmed.replace(/[.,\s]/g, '').length > 0) tokens.push(trimmed);
      current = '';
      continue;
    }
    current += char;
  }
  const trimmed = current.trim();
  if (trimmed.replace(/[.,\s]/g, '').length > 0) tokens.push(trimmed);
  return tokens;
};
```

## 4. 実装要件 (Implementation Logic)
- [ ] **AC-1 充足**: `tokenize(promptText: string): PromptToken[]`
  - 入力が空文字列・空白・null/undefined 相当の場合、空配列 `[]` を安全に返却。
  - カンマ/改行で分割（括弧ネスト外のみ）。連続カンマ `,,,` や空白のみの要素は完全に除外。
  - 各トークンから括弧ネスト深度（`bracketDepth`）および重み付け構文 `((tag:1.2))`、`(tag:0.8)`、`(((tag)))` をパース。
  - `raw`: 元のトークン文字列、`text`: クリーンなタグ本体、`weight`: 数値倍率（指定なしは 1.0）、`enabled`: true。
- [ ] **AC-2 充足**: `serializeToComfyPrompt(tokens: PromptToken[]): string`
  - `enabled === true` のトークンのみを ComfyUI 構文で出力。
  - `weight !== 1.0` の場合: `(text:weight)` 形式。
  - `weight === 1.0` かつ `bracketDepth > 0` の場合: 深度分の括弧でラップ。
  - 余分なカンマや空白のないカンマ区切り文字列（`, `）を出力。空配列の場合は `""`。
- [ ] **AC-3 充足**: `decoupleTags(tokens, removeTags, injectTrigger, options)`
  - `removeTags`（大文字小文字・前後空白無視）に合致するトークンを除去。
  - `injectTrigger`（文字列または配列）が渡された場合、空要素を除外して指定位置（デフォルト先頭）に注入。
- [ ] `adjustWeight(token, delta)`: 重み倍率を増減（下限 0 保護、小数第2位に丸め）。
- [ ] **Red Team 境界値 (RT-1〜RT-3)**:
  - RT-1: 連続カンマ `,,, \n  ,,` の安全なスキップ。
  - RT-2: 閉じ括弧不足 `((tag:1.2` 等の不整合構文に対する例外なし安全フォールバック。
  - RT-3: 大小文字混在タグの確実な除去。
