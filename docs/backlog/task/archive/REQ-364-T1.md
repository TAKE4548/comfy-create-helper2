# Task: HeaderDropdown ESCキー閉止サポート（closeOnEsc）の実装と単体検証

## 1. 目的とスコープ
`HeaderDropdown` コンポーネントに `closeOnEsc` オプション（既定値: `true`）を追加し、ドロップダウン展開中に `Escape` キーが押下された際に安全に `onClose` コールバックを呼び出すキーボードアクセシビリティを実装する。
これにより、REQ-364 AC-3（「また外側クリックまたはESCキー押下で閉じること」）の基盤要件を満たす。

## 2. 変更対象ファイル
- `frontend/src/components/common/header/HeaderDropdown.tsx`
- `frontend/src/components/common/header/__tests__/HeaderDropdown.test.tsx`

## 3. サージカルコンテキストと型定義

### 3-1. インターフェース拡張 (`HeaderDropdown.tsx`)
```typescript
export interface HeaderDropdownProps {
  open: boolean
  onClose: () => void
  anchorRef: RefObject<HTMLElement | null>
  align?: HeaderMenuAlign
  role?: AriaRole
  className?: string
  hoverBridge?: boolean
  closeOnEsc?: boolean // 追加 (既定値: true)
  'data-testid'?: string
  children: ReactNode
}
```

### 3-2. 実装スニペット (`HeaderDropdown.tsx`)
```typescript
  useEffect(() => {
    if (!open) return
    const onOutside = (e: Event) => {
      const t = e.target as Node | null
      if (
        !t ||
        panelRef.current?.contains(t) ||
        bridgeRef.current?.contains(t) ||
        anchorRef.current?.contains(t)
      )
        return
      onCloseRef.current()
    }
    const onKeyDown = (e: KeyboardEvent) => {
      if (closeOnEsc && e.key === 'Escape') {
        onCloseRef.current()
      }
    }
    document.addEventListener('pointerdown', onOutside)
    document.addEventListener('mousedown', onOutside)
    if (closeOnEsc) {
      document.addEventListener('keydown', onKeyDown)
    }
    return () => {
      document.removeEventListener('pointerdown', onOutside)
      document.removeEventListener('mousedown', onOutside)
      if (closeOnEsc) {
        document.removeEventListener('keydown', onKeyDown)
      }
    }
  }, [open, anchorRef, closeOnEsc])
```

## 4. 単体テストケース設計 (`HeaderDropdown.test.tsx`)
- `[REQ-364/AC-3] closes the dropdown when Escape key is pressed`
  - `open={true}` でレンダリングし、`fireEvent.keyDown(document, { key: 'Escape' })` を発行。
  - `onClose` が1回呼び出されることをアサート。
- `[REQ-364/AC-3] does not close on Escape if closeOnEsc is false`
  - `closeOnEsc={false}` 指定時は `Escape` を押しても `onClose` が呼ばれないことを確認。
