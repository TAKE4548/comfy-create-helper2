# タスクカード: REQ-180-T2

## 目的
セリフ修飾機能（パス沿い配置、文字スケール変化、円弧・波形等の変形）において、変形方向（左右・上下・凸凹・文字サイズ増減方向）を反転できる機能を追加し、UI上の反転ボタンおよびレンダラーでの反転描画を実装する。

## 密閉コンテキスト (Hermetic Context)

### 1. パス制御点の反転ロジック (`speechBubbleRenderer.ts` / `SpeechBubbleControls.tsx`)
```typescript
/**
 * 軌道制御点を反転（縦書き: X座標ミラー, 横書き: Y座標ミラー）
 */
export function flipPathPoints(points: PathPoint[], orientation: TextOrientation): PathPoint[] {
  return points.map((pt) => ({
    x: orientation === 'vertical' ? 1.0 - pt.x : pt.x,
    y: orientation === 'horizontal' ? 1.0 - pt.y : pt.y,
  }))
}
```

### 2. UIハンドラー (`SpeechBubbleControls.tsx`)
```tsx
// スケール反転
const handleFlipScale = () => {
  const currentStart = fx.scaleStart ?? 1.0
  const currentEnd = fx.scaleEnd ?? 1.0
  updateEffects({
    scaleStart: currentEnd,
    scaleEnd: currentStart,
  })
}

// パス反転
const handleFlipPath = () => {
  const currentPreset = fx.pathPreset || 'none'
  const defaultPts = getDefaultPathPoints(currentPreset, bubble.orientation)
  const currentPts = fx.pathPoints && fx.pathPoints.length > 0 ? fx.pathPoints : defaultPts
  const flipped = flipPathPoints(currentPts, bubble.orientation)
  updateEffects({ pathPoints: flipped })
}
```
