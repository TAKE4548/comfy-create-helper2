# REQ-338-T2: 全画面 Lightbox および A/B カーテン比較コンポーネントの実装

## 1. 概要と目的
画像クリックで全画面展開し、マウスホイールでの 1:1 等倍ズーム（100%〜400%）およびドラッグパン操作、2枚画像選択時の垂直スプリット A/B カーテン比較を提供する共通コンポーネントを実装する。

## 2. ターゲット識別
- **対象ファイル**:
  - `frontend/src/components/common/LightboxModal.tsx` (新規)
  - `frontend/src/components/common/CurtainCompareView.tsx` (新規)
- **テストファイル**: `frontend/src/components/common/__tests__/CurtainCompareView.test.tsx` (新規)
- **対象シンボル**: `LightboxModal`, `CurtainCompareView`

## 3. 密閉コンテキスト (Hermetic Context)
<hermetic_context>
### 3.1 必須の型定義
```typescript
export interface LightboxModalProps {
  isOpen: boolean
  onClose: () => void
  children: React.ReactNode
  ariaLabel?: string
}

export interface CurtainCompareViewProps {
  imageA: string
  imageB?: string
  initialSplit?: number // 0 - 100, default: 50
  onClose?: () => void
  onKeep?: (image: string) => void
  onDiscard?: (image: string) => void
}
```

### 3.2 カーテン比較の構造イメージ
```tsx
<div className="relative w-full h-full overflow-hidden flex items-center justify-center select-none" onWheel={handleWheel} onPointerDown={handlePointerDown}>
  <img src={imageA} alt="A" style={{ transform: `scale(${zoom}) translate(${pan.x}px, ${pan.y}px)` }} className="max-w-full max-h-full object-contain" />
  {imageB && (
    <div className="absolute inset-0 overflow-hidden" style={{ clipPath: `inset(0 ${100 - splitPercent}% 0 0)` }}>
      <img src={imageB} alt="B" style={{ transform: `scale(${zoom}) translate(${pan.x}px, ${pan.y}px)` }} className="max-w-full max-h-full object-contain" />
    </div>
  )}
  {imageB && (
    <div onPointerDown={startSplitDrag} style={{ left: `${splitPercent}%` }} className="absolute top-0 bottom-0 w-1 bg-accent-green cursor-ew-resize">
      <div className="w-8 h-8 rounded-full bg-accent-green text-black flex items-center justify-center text-xs font-bold">◀▶</div>
    </div>
  )}
</div>
```
</hermetic_context>
