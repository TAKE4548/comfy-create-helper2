### REQ-342-T1: Implement unified getNodeLabel and resolveNodeMetadata utility with unit tests

- **Subsystem**: frontend
- **Target Files**:
  - frontend/src/utils/workflowNodeUtils.ts (NEW)
  - frontend/src/utils/__tests__/workflowNodeUtils.test.ts (NEW)
- **Dependencies**: None
- **Verification Command**: `cd frontend; npx vitest run src/utils/__tests__/workflowNodeUtils.test.ts`

#### Technical Context & Types
```typescript
export interface ResolvedNodeMetadata {
  id: string
  title: string
  classType: string
}

export function resolveNodeMetadata(
  id: string,
  workflowJson?: Record<string, any> | null
): ResolvedNodeMetadata

export function getNodeLabel(
  id: string,
  workflowJson?: Record<string, any> | null
): string
```

#### Detailed Specification
1. Create `frontend/src/utils/workflowNodeUtils.ts`.
2. Implement `resolveNodeMetadata(id, workflowJson)`:
   - Handle null/undefined/non-object `workflowJson` safely by returning `{ id, title: '', classType: '' }`.
   - Check API Prompt dictionary format `workflowJson[id]`.
   - Check UI Graph array format `workflowJson.nodes.find(...)`.
   - Extract `classType` from `node.class_type || node.type || ''`.
   - Extract `customTitle` from `node._meta?.title || node.title || ''`.
   - Fallback `title` to `customTitle || classType || ''`.
3. Implement `getNodeLabel(id, workflowJson)`:
   - If both `title` and `classType` are available, return `${id} - [${title}] (${classType})`.
   - If only `title` is available, return `${id} - [${title}]`.
   - If only `classType` is available, return `${id} - (${classType})`.
   - If neither is available, return `${id}`.
4. Create `frontend/src/utils/__tests__/workflowNodeUtils.test.ts` verifying TC-UTIL-01 to TC-UTIL-06 and TC-RED-01 to TC-RED-02 (including null/undefined safety and numeric vs string id matching).
