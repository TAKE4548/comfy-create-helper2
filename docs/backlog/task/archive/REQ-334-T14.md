- AC-09: Given LoRA/TagSet/Snapshots/アルバム内画像, When 複数選択ボタン、Ctrlクリック、またはMobileで500ms長押しする, Then 選択モードに入り対象カードのチェック状態と選択件数が表示される。
- AC-10: Given Aを選択済みの一覧, When 現在表示順のDをShiftクリックする, Then A〜Dが選択される。
- AC-11: Given 複数選択モード, When 全選択/解除/終了をそれぞれ実行する, Then 絞り込み後の全件選択/選択0件/モード終了になる（未ロードの絞り込み対象も全選択に含む）。
- AC-12: Given 選択済みカード, When 一覧を表示する, Then 緑チェックと緑枠で識別できる。
- AC-13: Given LoRA/TagSet/アルバム内画像の複数選択モード, When ドラッグする, Then 並び順は変わらない。
- AC-14: Given 一括削除/キュー破棄/実行中中断/強制再起動/設定上書き, When 実行を選ぶ, Then 対象と件数（サービスは名称）を記した画面内確認が現れ、確認実行まで処理されない。
- AC-15: Given 画面内確認, When キャンセルする, Then その操作による対象状態の変更はない。
- AC-76: Given Snapshot複数選択, When ZIP保存/アルバム追加/確認後削除を実行する, Then 選択画像だけが対象となる。
- AC-80: Given アルバム内複数選択, When ダウンロード/確認後除外する, Then 選択画像だけが対象となり除外でもSnapshot本体は残る。
