## 3. 実装要件 (Implementation Logic)

### 3.1 バックエンド静的ファイルの永続キャッシュ化 (`backend/app/main.py`)
1. `backend/app/main.py` の `app` 初期化付近で、`StaticFiles` を継承した `CachedStaticFiles` クラスを定義する。
   ```python
   class CachedStaticFiles(StaticFiles):
       def file_response(
           self,
           path: str,
           stat_result: os.stat_result,
           scope: dict,
           status_code: int = 200,
       ) -> Response:
           response = super().file_response(path, stat_result, scope, status_code)
           response.headers["Cache-Control"] = "public, max-age=31536000, immutable"
           return response
   ```
2. `app.mount("/api/snapshots/images", ...)` の箇所を、`StaticFiles` から `CachedStaticFiles` に差し替える。

### 3.3 フロントエンドでの画像 Lazy Loading と自動遅延読み込み (Auto Lazy Loading / Infinite Scroll) (`frontend/src/pages/HistoryPage.tsx`)
1. `HistoryPage.tsx` のすべての画像 `<img />` タグ（スナップショット一覧、アルバム一覧、アルバム詳細一覧など）に `loading="lazy"` 属性を追加する。
2. 表示制限件数の `state` を追加する。
   - `const [snapshotLimit, setSnapshotLimit] = useState(24)`
   - `const [albumItemLimit, setAlbumItemLimit] = useState(24)`
3. フィルターや切り替えイベント発生時、表示上限件数を `24` にリセットする `useEffect` を追加する。
   - `selectedWorkflowId`, `selectedLoraId`, `selectedTagSetId`, `sortOrder` の変更監視 -> `setSnapshotLimit(24)`
   - `selectedAlbumId` の変更監視 -> `setAlbumItemLimit(24)`
4. 表示対象となるデータを切り出すための `useMemo` 等を定義する。
   - `const visibleSnapshots = useMemo(() => sortedSnapshots.slice(0, snapshotLimit), [sortedSnapshots, snapshotLimit])`
   - `const visibleAlbumItems = useMemo(() => sortedAlbumItems.slice(0, albumItemLimit), [sortedAlbumItems, albumItemLimit])`
5. レンダリング箇所で `sortedSnapshots.map(...)` と `sortedAlbumItems.map(...)` をそれぞれ `visibleSnapshots.map(...)` と `visibleAlbumItems.map(...)` に置き換える。
6. `IntersectionObserver` を用いて、リスト下部のセンチネル要素が画面内に入った際、自動で上限を増やすフック/副作用を実装する。
   - Reactの `useRef` を用いてセンチネル用の `div` を参照し、`useEffect` 内で `IntersectionObserver` インスタンスを作成して監視する。
   - スナップショット一覧用とアルバム詳細用にそれぞれセンチネル用の `div` をリスト最下部に配置する。
     - スナップショット一覧の末尾（`visibleSnapshots.length < sortedSnapshots.length` の場合）にセンチネル `div` を表示。交差検知時に `setSnapshotLimit(prev => prev + 24)` を実行。
     - アルバム詳細一覧の末尾（`visibleAlbumItems.length < sortedAlbumItems.length` の場合）にセンチネル `div` を表示。交差検知時に `setAlbumItemLimit(prev => prev + 24)` を実行。
