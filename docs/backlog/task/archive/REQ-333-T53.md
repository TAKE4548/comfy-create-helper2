# REQ-333-T53

T50のexport ManagerActionOutcomeUnknownErrorはname同名、readonly outcome='unconfirmed'、通常Error.message。timeout/504/503/通信切断後のmutation結果不明はこの型。ServiceConnectionCardはこれを「要求結果未確認」と表示してstatusを再取得し、明確な失敗と区別する。running表示だけでrestart完了を断定せず、再送も行わない。確定失敗は従来failure表示。actionPendingをfinally解除し、Manager側busyがある間のcontrols disabledは保持。成功時も実status再取得を維持。

## Impacted Files
- frontend/src/pages/SettingsPage/components/ServiceConnectionCard.tsx
- frontend/src/pages/SettingsPage/components/__tests__/ServiceConnectionCard.test.tsx

TDDでtimeout後実status runningでも「再起動成功」「失敗」と断定しない、再確認・再送0、確定失敗・成功の既存挙動を保持。所有外編集禁止、他担当変更を巻き戻さない。
