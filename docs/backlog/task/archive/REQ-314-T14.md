## Implementation Logic
- [ ] D2は既存契約内に確定済み。Comfy URLのdraft入力＋保存で既存store.setComfyUrlへ渡す。空/不正http(s)入力は保存抑止。自動typing保存で接続再初期化を連打しない。
- [ ] Comfy実効URLはstore値優先→config値→既存default。Backendはwindow.location.origin/healthで疎通、API BASE_URL=/api固定。LM Studioはモデル一覧の既存backend経由APIで疎通を判定する。
- [ ] URL draftは初期化後もeffective URLに追従する。ただし利用者が未保存編集を始めたらdirty扱いにして外部store/config更新で上書きせず、保存成功時だけdraftを保存済みeffective URLへ同期しdirtyを解除する。
- [ ] LM Studio `getModels()` が空配列の場合は「接続済み」と表示しない。Backend APIがHTTP 200で空配列を返すことがあるため、空は「モデルを取得できない／接続確認不可」とし、非空時だけモデル一覧API成功を示す。Backend healthとLM Studio確認結果を分ける。
- [ ] LM Studio実際URLをfrontendが取得する契約は無いため、default1234を現在設定として偽装しない。'.envのLLM_BASE_URLで変更'と取得不可を説明。Backend表示をeditできるふりのinputにしない。
- [ ] 疎通はBackend/Comfyの既存URLにfetch({signal:AbortSignal.timeout(3000)})しresponse.okを確認。HTTP4xx/5xxもerror。現行ConnectionStatusの『fetch解決=成功』動作を再利用しない。localStorageは既存COMFY_URLと既存store保存を使用し新API/schema/config書込を作らない。結果と失敗messageをaria-live。本カードではBackend/LM Studio URL編集・設定API拡張を行わない。
- [ ] Import paths above are fixed; do not introduce new state/store/API contracts. Backend status URL is `${window.location.origin}/health`; LM Studio reachability is the existing `llmPromptsApi.getModels()` through Backend and its configured base URL is not displayed.
- [ ] User-facing headings, actions, errors, and status are Japanese. Use existing settings surface/border/rounded/input/button visual classes; preserve accessible labels/live status.
- [ ] Use the repository's unconditional dark settings tokens (`bg-surface-2/20`, `bg-surface`, `border-[rgba(255,255,255,0.06)]`, `text-zinc-*`, existing green accent). Do not use `bg-white`/`dark:bg-gray-*` variants: dark mode uses `darkMode:'class'` and the document does not add that class, so the light surface makes inherited light text unreadable.
