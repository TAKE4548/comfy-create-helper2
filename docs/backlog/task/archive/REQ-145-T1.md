## 3. ルーター実装仕様 (`backend/app/routers/speech_bubble_presets.py`)

プレフィックス: `/api/speech-bubble-presets`, tags: `["speech-bubble-presets"]`

1. **GET `/api/speech-bubble-presets`**
   - 戻り値: `list[schemas.SpeechBubblePresetRead]`
   - クエリ: `db.query(models.SpeechBubblePreset).order_by(models.SpeechBubblePreset.sort_order.asc(), models.SpeechBubblePreset.id.asc()).all()`
2. **POST `/api/speech-bubble-presets`**
   - リクエスト: `schemas.SpeechBubblePresetCreate`
   - 重複チェック: `db.query(models.SpeechBubblePreset).filter(models.SpeechBubblePreset.name == payload.name).first()` が存在すれば `HTTPException(400, "Preset with this name already exists")`
   - 作成・コミット・リフレッシュして `201 Created` で `SpeechBubblePresetRead` を返却。
3. **PUT `/api/speech-bubble-presets/{id}`**
   - 存在チェック: 無ければ `HTTPException(404, "Preset not found")`
   - 名前の変更がある場合、他レコードとの重複チェック
   - 更新フィールドの適用、コミット、リフレッシュして `SpeechBubblePresetRead` を返却。
4. **DELETE `/api/speech-bubble-presets/{id}`**
   - 存在チェック: 無ければ `HTTPException(404, "Preset not found")`
   - 削除、コミット、`204 No Content` を返却。
