# REQ-336-T2: 動的Role導出・Cascade一括置換サービスおよびStageMaster API

## 1. 概要と目的
ステージ接尾辞（suffix）変更時の影響範囲事前検証プレビュー（Preview）および排他ロック下の単一トランザクション一括置換（Cascade Rename）サービスを実装する。また、StageMaster の CRUD、3重削除ガード（is_builtin, usage_count, is_active推奨）、旧接尾辞履歴（previous_suffixes, 最大10件）管理APIを提供する。

## 2. ターゲット識別
- **対象ファイル**:
  - `backend/app/services/mapping_service.py` (新規)
  - `backend/app/schemas/mapping.py` (新規)
  - `backend/app/routers/stage_masters.py` (新規)
- **対象シンボル**: `MappingService`, `preview_cascade_rename`, `execute_cascade_rename`, `validate_stage_deletion`, `router`
