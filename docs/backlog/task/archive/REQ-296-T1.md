## 所有と原子性

## 密閉コンテキスト

対象: `backend/app/services/speech_draft_service.py:14`。既存シグネチャは `async def call_vlm(image_base64: str, system_prompt: str, model: str) -> str`。呼び出し先は `settings.llm_base_url + "/chat/completions"`。

```python
async def call_vlm(image_base64: str, system_prompt: str, model: str) -> str:
    url = f"{settings.llm_base_url}/chat/completions"
payload = {
    "model": model,
    "messages": [
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": [
            {"type": "image_url", "image_url": {"url": f"data:image/jpeg;base64,{image_base64}"}},
            {"type": "text", "text": "この画像の内容を日本語で簡潔に説明してください。"},
        ]},
    ],
    "stream": False,
    "max_tokens": 512,
}
async with httpx.AsyncClient(timeout=60.0) as client:
    response = await client.post(url, json=payload)
    response.raise_for_status()
    return response.json()["choices"][0]["message"]["content"]
```

## 実装契約

- `@dataclass(frozen=True) class SceneVlmCompletion: content: str | None; finish_reason: str | None` と `async def call_scene_vlm(image_base64: str, system_prompt: str, instance_id: str) -> SceneVlmCompletion` を追加する。payloadの `model` は必ず渡された `instance_id` とする。`choices` 欠落/空のときは固定コード付き `VlmResponseShapeError` を出す。
- system と user の双方で「画像を読んでシーンに合うセリフ・SEを指定JSONで生成」とする。`response_format` はLM Studio `json_schema`。`scene_interpretation: str` と非空 `items[]`、itemの `role/speaker/text/position` に型・必須・列挙制約を定義する。
- `choices[0].message.content` と `finish_reason` を安全に取り出す。`finish_reason=length`/`content_filter`/欠落は値を返し、T2の検証へ渡す。`choices=[]`/欠落やmessage欠落は `VlmResponseShapeError` にする。HTTP 400本文を例外文字列へ含めない。構造化出力非対応時は自動で無制約推論へ戻さない。
- LM StudioがHTTP 400かつJSON本文が厳密に `{"error":"Model is unloaded."}` の場合に限り、readiness retryを開始する。同じpayload/同じinstance IDで最大90秒・1秒間隔。後続POST timeoutは最大60秒（残りdeadlineでcap）。このreadiness window開始後に起こるReadTimeoutも残りdeadline内で再試行する。load endpointは再送しない。その他のHTTP 400またはreadiness window開始前のtransport errorは再試行せず、安全な固定分類へ変換する。再試行枯渇時は `LM_STUDIO_INSTANCE_NOT_READY` とする。エラーresponse本文はログ/APIへ露出しない。
- 旧 `call_vlm` のJPEG・画像説明契約が変わらない回帰テストも残す。
- 局所プローブでは別名ID `req296-instance-probe` をChat Completionsの `model` に指定した短いテキスト推論がHTTP 200、`finish_reason=stop`、`OK` だった。画像とJSON Schemaの併用はT1のモック検証とGate 3の実機検証に残す。
