## 3. 実装要件 (Implementation Logic)
1. SENTENCE_SPLIT_PATTERN（ピリオド・改行・感嘆符・疑問符）と TAG_SPLIT_PATTERN（カンマ・読点）を分離定義する。
2. ピリオドで区切られた文ブロックごとに TAG_SPLIT_PATTERN で要素を分割する process_sentence_block を実装する。
3. 文ブロック内の各要素について、Danbooru 辞書ヒット要素（is_tag=True）と辞書非該当要素（is_tag=False）を判定する。
4. 辞書非該当の連続要素をカンマと空白で再結合し、1つの完全な英文ブロック（自然文）として復元する。
5. 連続カンマや末尾カンマ等による空要素はスキップし、空文字列の翻訳呼び出しを排除する。
