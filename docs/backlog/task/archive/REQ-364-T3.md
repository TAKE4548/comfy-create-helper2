# Task: PageHeader統合および共通ヘッダー結合テストの拡充

## 1. 目的とスコープ
`PageHeader.tsx` における `SystemStatusBadge` のレスポンシブ配置（デスクトップ: `variant="slim"`, モバイル: `variant="dot"`）と結合し、`unifiedHeaderIntegration.test.tsx` にエンドツーエンド統合テストを追加する。
動的ポート追従、画面幅によるバッジの表示切り替え、Popoverの表示整合性、および他ヘッダー要素（ResourceHoverMonitor, HeaderKebabMenu）との共存を保証する。

## 2. 変更対象ファイル
- `frontend/src/components/common/__tests__/unifiedHeaderIntegration.test.tsx`

## 3. サージカルコンテキストと結合シナリオ
- **シナリオ 1: デスクトップヘッダー描画**:
  - `PageHeader` をデスクトップ表示（md以上）でレンダリングした際、`SystemStatusBadge`（slim）とともに DEV 環境下で動的 `DEV :${port}` タグバッジが描画されることを確認。
- **シナリオ 2: モバイルヘッダー描画**:
  - `PageHeader` をモバイル表示（md未満）でレンダリングした際、`SystemStatusBadge`（dot）が描画され、`DEV :ポート` タグバッジが抑制されることを確認。
- **シナリオ 3: Popover インタラクションと他要素の非干渉**:
  - ステータスバッジクリックによるモニタ展開時、隣接するアクションボタンやケバブメニューが誤動作しないことを確認。

## 4. UI制約 & Archetype
- **Archetype 4: Shell & Page Layout**
- **Constraints**:
  - デスクトップとモバイルでクラス競合（`hidden md:inline-flex` vs `inline-block md:hidden`）が崩れていないこと。

```bash
npm test -- unifiedHeaderIntegration.test.tsx -t "REQ-364"
```
