# REQ-345-T12 残存差分APIのOpenAPI正本を同期する

## Ownership and Atomicity

書込は次の1ファイル、変更合計200行以内。ほかの担当者も同じcodebaseを使用するため他者の編集をrevertせず整合させる。監査指摘のレビューと人間設計承認前に着手しない。予算超過見込みは着手前に再分割する。

- docs/openapi.yaml

## Purpose

T7実装結果の新route/schema/ErrorEnvelopeをAPI正本へ反映する。T6は3仕様文書までで本API文書を含めない。

## Hermetic Context

~~~ts
interface ImageIdentity { filename: string; subfolder: string; type: string }
interface ResidualHistoryRequest { known: ImageIdentity[]; examined: ImageIdentity[] }
interface ResidualHistoryItem {
  identity: ImageIdentity; view_url: string; session_id: string | null; availability: 'present'
}
interface ResidualHistoryResponse {
  items: ResidualHistoryItem[]
  rejected: Array<{ identity: ImageIdentity; availability: 'missing' | 'unknown' }>
  has_more: boolean
}
~~~
~~~yaml
/api/generation/history/residual:
  post:
    tags: [generation]
    summary: Get Residual History
    requestBody:
      required: true
      content:
        application/json:
          schema: {$ref: '#/components/schemas/ResidualHistoryRequest'}
    responses:
      '200':
        description: Only new images with confirmed present originals
        content:
          application/json:
            schema: {$ref: '#/components/schemas/ResidualHistoryResponse'}
      '422':
        description: Invalid identity or request bound
        content:
          application/json:
            schema: {$ref: '#/components/schemas/ErrorEnvelope'}
      '503':
        description: Residual history could not be read
        content:
          application/json:
            schema: {$ref: '#/components/schemas/ErrorEnvelope'}
~~~
上は新規routeの24行挿入契約。既存GET /api/comfy/historyとGET /api/comfy/image-availabilityの契約は保持する。

## Implementation Logic

- [ ] T7の実FastAPI schemaに合わせdocs/openapi.yamlへ新POSTと型を反映。既存生成API ErrorEnvelope refsを再利用する。
- [ ] known/examined各上限1000、response page10、present literal、rejected missing/unknownをschemaへ示す。probe/mergeの仕様はREQ-345 designへ参照。
- [ ] 実装前にAPIが存在すると記録しない。差分200行枠を超える全再生成diffなら限定schema編集かカード再分割を依頼する。

### Exact Backend Schema Contract

T7実装で確認済みのResponse shapes。OpenAPIへは次の意味を同じにして定義する（新routeが他のErrorEnvelope参照元を変更する必要はない）。

~~~yaml
ImageIdentity:
  type: object
  additionalProperties: false
  required: [filename, subfolder, type]
  properties:
    filename: {type: string, minLength: 1}
    subfolder: {type: string}
    type: {type: string}
ResidualHistoryRequest:
  type: object
  additionalProperties: false
  required: [known, examined]
  properties:
    known: {type: array, maxItems: 1000, items: {$ref: '#/components/schemas/ImageIdentity'}}
    examined: {type: array, maxItems: 1000, items: {$ref: '#/components/schemas/ImageIdentity'}}
ResidualHistoryItem:
  type: object
  required: [identity, view_url, session_id, availability]
  properties:
    identity: {$ref: '#/components/schemas/ImageIdentity'}
    view_url: {type: string}
    session_id: {type: [string, 'null']}
    availability: {type: string, const: present}
ResidualHistoryRejected:
  type: object
  required: [identity, availability]
  properties:
    identity: {$ref: '#/components/schemas/ImageIdentity'}
    availability: {type: string, enum: [missing, unknown]}
ResidualHistoryResponse:
  type: object
  required: [items, rejected, has_more]
  properties:
    items: {type: array, maxItems: 10, items: {$ref: '#/components/schemas/ResidualHistoryItem'}}
    rejected: {type: array, maxItems: 10, items: {$ref: '#/components/schemas/ResidualHistoryRejected'}}
    has_more: {type: boolean}
ErrorDetail:
  type: object
  required: [code, message, outcome, request_id, job_id]
  properties:
    code: {type: string}
    message: {type: string}
    outcome:
      anyOf:
        - {type: string, enum: [failed, unconfirmed]}
        - {type: 'null'}
    request_id: {type: [string, 'null']}
    job_id: {type: [string, 'null']}
ErrorEnvelope:
  type: object
  required: [detail]
  properties:
    detail: {$ref: '#/components/schemas/ErrorDetail'}
~~~

Route errors 422/503 return this `ErrorEnvelope` through `GenerationAPIRoute`; generic framework `HTTPValidationError` is not the contract for this route. Only add these component schema definitions if absent; do not rename or rewrite existing schemas.
