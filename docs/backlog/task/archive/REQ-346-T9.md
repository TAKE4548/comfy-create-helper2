```md
### 4-4-1. 共通ヘッダー展開アクション契約（REQ-346）

共通ヘッダー（`PageHeader` の `actions` スロットと右クラスタ）に置く展開アクションは、ヘッダー内の高さ制限で切り詰められず、ページ内容に重ねてヘッダー下へ展開する。実装の共通プリミティブは `components/common/header/HeaderDropdown.tsx`（配置計算は `headerMenuPlacement.ts`）。

| 項目 | 契約 |
|---|---|
| 重なり展開 | パネルは `document.body` へのポータルで `position: fixed` 描画し、ヘッダー高さ・ページ高さ・スクロール高さを押し広げない。`actions` スロットの `overflow-x-auto` に切り詰められない |
| 配置 | 上端はトリガー下端＋6px。左右は 8px の余白を保ってビューポート内へクランプ（`align` は start／end）。最大幅は `calc(100vw - 16px)` |
| 高さの切り詰め禁止と末尾到達性 | ヘッダー高さで切り詰めない。最大高さは `visualViewport.height`（なければ `innerHeight`）−上端−8px で、超過分はパネル内スクロール（`overflow-y: auto`、`overscroll-behavior: contain`）により最後の項目へ画面内で到達・押下できる |
| 重なり順 | `--z-header-menu: 60`（ボトムナビ 50 より前面、共通Modal 100 より背面）。背景内容・固定ボトムナビに隠れない |
| 開閉（click 型） | トリガー再押下で閉じる。外側 `pointerdown`/`mousedown` で閉じる。開閉状態は呼出側が持つ（`HeaderDropdown` は制御型でトリガー種別に依存しない）。ウィンドウ resize／向き変更／スクロール中は再計測し、トリガーが画面外または残り高さが 96px 未満なら閉じる |
| 開閉（hover 型） | ポインター進入で開き、ポインターがトリガー・ブリッジ・カードのいずれの上にも無くなると閉じる（遅延なし）。外側 `pointerdown`/`mousedown` でも閉じる。トリガーとカードの間の隙間（6px）は、トリガーラッパー内の透明ブリッジ（`aria-hidden`、高さ 7px）で埋め、ポインターをカード内へ移動してもカードが閉じない（カード内スクロールのため）。クリックによるトグルは持たず、「再押下で閉じる」は「ポインター離脱／外側押下で閉じる」に読み替える。配置・高さ上限・スクロール・重なり順・追従は click 型と同一。640px 未満では表示しない |
| 将来の展開アクション | 共通ヘッダーへ追加する展開アクション（click 型・hover 型いずれも）は `HeaderDropdown` を使うか同等にこの契約を満たし、検証一覧（E2E ハーネス `frontend/e2e/headerMenuOverlay.spec.ts`。hover 型は同ディレクトリの hover カード用 E2E と同方式）へ追加する。ヘッダーより高い内容でも下端まで表示され末尾項目へ到達できること。hover 型は呼出側でブリッジを実装する |
| 非目標 | Escape キー、フォーカストラップ／復帰、ブラウザズーム対応、hover 型の開閉遅延やクリック開閉の追加、内容項目・保存動作の変更は本契約に含めない |

対象アクション（2026-10-16 時点。`HeaderDropdown` 適用）:

| 区分 | アクション | 実装 |
|---|---|---|
| 適用 | ワークフロー設定（`#workflow-actions-btn`、Generate Desktop／Mobile） | `pages/GeneratePage/components/WorkflowActionsMenu.tsx` |
| 適用 | ヘッダーメニュー（キャッシュ／ストレージ、`#header-kebab-btn`、全ページ） | `components/common/header/HeaderKebabMenu.tsx` |
| 適用 | モバイル VRAM ピル展開（640px 未満。640px 以上へ拡大すると閉じる） | `components/common/header/ResourceHoverMonitor.tsx` |
| 適用（hover 型） | デスクトップ資源ホバーカード（640px 以上、`role=tooltip`、`data-testid="resource-hover-card"`） | 同上（A3 と同一ファイル。ブリッジ `resource-hover-bridge` を含む） |

検証幅（既存サポート範囲）: mobile 375／639／767、tablet 768／1023、desktop 1024／1280。短い高さ 360 でメニュー内スクロールを確認する。hover 型（640px 以上のみ表示）は 640／768／1024／1280 で確認する。
```
