## 変更内容（group === 'prompt' のみ）
1. state: `const [selectedPromptKey, setSelectedPromptKey] = useState<string>(PROMPT_EDITOR_KEYS[0])`。種別切替で `edits`（本文draft）と `llmParamsEdits` は**保持**（draft非破壊。リセットしない）。
2. Prompts section の `visiblePrompts.map` アコーディオンを、`group === 'prompt'` のとき次の統合エディタへ置換（他groupは従来のmap）:
```tsx
<div data-testid="prompt-unified-editor" className="grid grid-cols-1 gap-4 lg:grid-cols-2">
  <div className="min-w-0 space-y-3">  {/* 左ペイン: 本文 */}
    <label htmlFor="prompt-type-select" className="block text-xs text-zinc-400">プロンプト種別</label>
    <select id="prompt-type-select" value={selectedPromptKey} onChange={(e) => setSelectedPromptKey(e.target.value)}
      className="min-h-11 w-full rounded-lg bg-surface-2 px-3 text-xs touch-manipulation">
      {PROMPT_EDITOR_KEYS.map((k, i) => <option key={k} value={k}>{`${'①②③④⑤⑥'[i]} ${PROMPT_LABELS[k] ?? k}`}</option>)}
    </select>
    <textarea id={`prompt-content-${selected.key}`} value={getContent(selected)} onChange={/* 既存と同一のdraft更新 */} rows={16} className="... min-h-[16rem]" />
    {/* reset: id=`prompt-reset-${selected.key}` / save: id=`prompt-save-${selected.key}` は既存と同一ハンドラ */}
  </div>
  <div className="min-w-0" data-testid="prompt-unified-params"> {/* 右ペイン */} </div>
</div>
```
3. 右ペイン（`promptParamGroupFor(selectedPromptKey)` で得た群 `pg` のみ表示）:
   - 読み取り表示 `使用モデル: {currentModelData?.content ?? '未設定'}（全プロンプト共通。変更は上の「現在のモデル」）`。**モデル保存契約は追加しない**。
   - 既存と同じ構造のカード `div.rounded-xl` に `<h3>{PARAM_LABELS[pg]}</h3>`、保存ボタン（先頭の`button`、`handleSaveParams(pg)`）、`Temperature` と `Max Tokens` の number+range（`PARAM_FIELDS` の `temperature`, `max_tokens` を先に、`handleParamChange(pg, field, val)`）。残り（`top_p`, `presence_penalty`, `frequency_penalty`）は `<details><summary className="min-h-11">その他のパラメータ</summary>` 内に同じ入力。→ 既存の `paramInputs` ヘルパ互換のため、先頭の number input は Temperature。
4. Params section（`LLM詳細パラメータ設定` ブロック）は `group === 'prompt'` のとき **描画しない**（右ペインへ統合済み）。他groupは従来どおり。
5. Prompt Playground セクション（`group === 'prompt'`）はそのまま維持（`playgroundPresetKey` 等は独立）。
6. `selectedPromptKey` に対応する `prompts` レコードがまだ取得されていない／存在しない場合は textarea を `disabled` にし `このプロンプトはまだ取得されていません。` を表示（NaN/undefined参照を避ける。`PROMPT_EDITOR_KEYS` は固定6キーなので未知キーは選択不能）。
7. 入力の`font-size`は`text-xs`以上。number入力は`min-h-11`。モバイルは`grid-cols-1`（左→右の縦積み）。

- `dialogue` / `translation` / legacy の既存テスト（`prompt-expand-` が3/2/11個等）は**無変更でグリーン**であること。
