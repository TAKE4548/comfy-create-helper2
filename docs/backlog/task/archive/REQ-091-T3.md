## 3. 実装要件 (Implementation Logic)
- **`bypassUtils.ts`**:
  - `applyBypass(workflow: Record<string, any>, bypassedNodeIds: string[], comfyObjectInfo: any): Record<string, any>` を実装する。
  - ワークフローをディープコピーし、`bypassedNodeIds` 内の各ノードID `B` に対して:
    - ノード `B` の `class_type` が `comfyObjectInfo` にあるかチェック。
    - 入力側のデータタイプと、出力側のデータタイプを取得し、型名が完全に一致するペアを見つけてマッピングを作る（`inputSlotName` -> `outputIndex`）。
    - ワークフロー全体の他のすべてのノードの `inputs` を走査し、`[ "B", outputIndex ]` となっているものを `wf[B].inputs[inputSlotName]` (接続元 `S`) へ書き換える。
    - 最後にノード `B` 自体を削除する。
- **`bypassUtils.test.ts`**:
  - `vitest` を用いて、単一ノード、複数ノード、サブグラフをバイパスした際に直結されることを検証するテストケースを実装。
  - 型不一致時にバイパス接続が無視される（接続が切れる）ことを確認。
