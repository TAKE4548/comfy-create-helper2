# REQ-430-T2: MappingMaster 2行カード統一 & listScrollMaxHeight 対応

## 1. 概要と目的
1. **AC-1**: `SettingsResponsive.css` の `.settings-mobile-card` を全画面幅で 2行 CSS Grid（1行目: `title` + `actions`、2行目: `badges`）に統一し、デスクトップ（`xl:grid-cols-2` 半幅）でもステージ状態バッジがタイトルを押し潰さないようにする。
2. **AC-2 準備**: `MappingMasterSection` に `listScrollMaxHeight?: number` prop と `data-testid="mapping-master-list-scroll"` を追加し、右ペインが左ペインより長い場合に内部スクロールできるようにする。

## 4. UI 制約 (`<constraints>`)
- **Archetype**: `Archetype 4: Shell & Page Layout` + `Archetype 2: Tabs / Chips / Grids`
- `min-w-0` を維持し、flex/grid 内のタイトル省略が横はみ出しを起こさないこと。
- `overflow-y-auto overscroll-contain` をスクロールコンテナに付与すること。
- **禁止**: `SettingsResponsive.css` に `!important` を追加しないこと（`SettingsPage.test.tsx` が 1 箇所のみを強制）、生 `100vh` を使用しないこと。

## 5. 実装要件
- [ ] `SettingsResponsive.css`: `.req314-settings .settings-mobile-card` のベースルールを `display: grid; grid-template-columns: minmax(0, 1fr) auto; grid-template-areas: "title actions" "badges badges"; gap: 0.375rem 0.5rem; min-width: 0;` に変更し、`__title { grid-area: title; min-width: 0; }`、`__actions { grid-area: actions; justify-self: end; display: flex; flex-shrink: 0; align-items: center; gap: 0.25rem; }`、`__badges { grid-area: badges; display: flex; flex-wrap: wrap; gap: 0.375rem; min-width: 0; }` とする。`@media (max-width: 767px)` 内の `.settings-mobile-card__target-node` 非表示やテーブル用 `grid-template-areas` 等はそのまま維持する。
- [ ] `MappingMasterSection.tsx`: `MappingMasterSectionProps` に `listScrollMaxHeight?: number` を追加し、L661 の `<div className="divide-y divide-zinc-800">` に `data-testid="mapping-master-list-scroll"`、`overflow-y-auto overscroll-contain`、および `style={listScrollMaxHeight != null ? { maxHeight: `${listScrollMaxHeight}px` } : undefined}` を付与する。
