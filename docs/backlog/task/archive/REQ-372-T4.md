# REQ-372-T4: モバイル画像確認：ボトムシート・全画面ビューア・WakeLock・Fullscreen縮退フォールバック

## 1. 概要と目的
モバイル幅においてサムネイルタップ時に開く画像ボトムシート（`MobileImageSheet.tsx`）および画像タップ時に切り替わる全画面ビューアを新規実装する。元の縦横比での画像表示、全画面時のシートクローム非表示・黒背景没入、ブラウザ Fullscreen API 制御、Screen Wake Lock API による画面消灯抑止、非対応環境での CSS 100dvh 縮退フォールバックを完備する。

// Fullscreen API 呼び出しと例外ハンドリング
const requestFullscreenSafe = async (el: HTMLElement) => {
  try {
    if (el.requestFullscreen) await el.requestFullscreen()
    else if ((el as any).webkitRequestFullscreen) await (el as any).webkitRequestFullscreen()
  } catch (_e) {
    // Non-blocking fallback to CSS 100dvh
  }
}
