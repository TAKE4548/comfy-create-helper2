# REQ-309-T2

## Scope and AC
`App.tsx` の 6 画面（Generate / Studio / LoRAs / Tags / History / Settings）を `React.lazy` + `Suspense` に変更し、初期 `/` で他 5 画面のコードを取得しない。対象 AC: AC-1、AC-2（寄与）、AC-3（fallback）、AC-5、AC-6、および Requirement 2（全 route・離脱保護・cache 復元・例外境界の維持）。API・永続化・`AppShell`・store 起動・`vite.config.ts` は変更しない。
**AC 分担**: AC-2 は本カードの route 分割による実チャンク縮小が寄与し、判定は T5 `buildGuard`。AC-3 のモーダル系・AC-4（checkpoint → 生成）は T3/T5、SSoT は T6、前後の転送量比較は T0/T5 が担当する。
