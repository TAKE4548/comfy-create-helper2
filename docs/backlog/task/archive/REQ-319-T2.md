# REQ-319-T2: 直交計画 (DOE) ソルバーサービス実装および素材マトリクスAPIエンドポイント新設

## 1. 概要と目的
因子プール（Shot, Angle, Expression, Pose, Outfit）から制約付き貪欲法（Greedy Orthogonal Selection）により交絡を最小化する20件の直交計画プロンプトを算出する `matrix_service.py` を実装し、プロジェクト管理・マトリクス算出・エクスポートを行う `dataset_router.py` を新設して `main.py` に登録する。

## 3. 実装要件 (Implementation Logic)
1. **`backend/app/services/matrix_service.py`**:
   - 因子プールの全直積からハード制約（Close-up と特定ポーズの排他など）を除外。
   - 周辺比率（Shot: Close-up 5枚, Bust 9枚, Full body 6枚 / Outfit: 本命15枚, 別衣装5枚）を充足。
   - 選択された別衣装マスタ群を5枠にラウンドロビン配分。別衣装枠では専用服装タグは一切含めず別衣装タグを展開。
   - 共起誤差最小化による貪欲選択ロジックを実装。
2. **`backend/app/routers/dataset_router.py`**:
   - CRUD API を実装。
   - `/export` エンドポイントで指定ディレクトリへ画像ファイルと同名の `.txt` キャプションペアを出力。
3. **`backend/app/main.py`**:
   - `dataset_router` をインポートし、`app.include_router(dataset_router.router)` を登録。
