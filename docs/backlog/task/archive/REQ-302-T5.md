# REQ-302-T5: ネスト例外保護とAppShell背面ナビ遮蔽の統合検証

## 1. 概要と目的
SPEC_COMMON §1-4 で唯一明示されたネスト例外（`MappingMasterEditModal` 内の `WorkflowNodePicker`）を保護し、外側と内側での独立したEscapeキー制御（内側のみ閉じる）および最前面操作性を検証する。
また、`AppShell.tsx` のモバイルボトムナビゲーションに対し、前面オーバーレイ展開時に背面ナビへのタップ・クリックイベント伝播およびキーボードフォーカスが完全に遮断され、意図しないルーティング画面遷移が一切発生しないことをテストで固定する。

## 2. 密閉コンテキスト (Hermetic Context)

### 対象ファイル 1: `frontend/src/components/__tests__/WorkflowNodePicker.test.tsx` (L101-L118)
```tsx
  it('[REQ-365/AC-9] nested in another Modal: Escape closes only the picker and backdrop click does not close it', () => {
    const outerClose = vi.fn()
    const onClose = vi.fn()
    render(
      <Modal isOpen onClose={outerClose} closeOnEsc={false} ariaLabel="outer">
        <WorkflowNodePicker isOpen={true} onClose={onClose} workflowJson={dummyWorkflow} hasExistingValues={false} onSelectNode={vi.fn()} />
      </Modal>
    )
    expect(screen.getAllByRole('dialog')).toHaveLength(2)
    const pickerBackdrop = screen.getByLabelText(TITLE).closest('.modal-backdrop') as HTMLElement
    fireEvent.click(pickerBackdrop)
    expect(onClose).not.toHaveBeenCalled()
    fireEvent.keyDown(window, { key: 'Escape' })
    expect(onClose).toHaveBeenCalledTimes(1)
    expect(outerClose).not.toHaveBeenCalled()
  })
```

### 対象ファイル 2: `frontend/src/components/layout/__tests__/AppShell.test.tsx` (L35-L50)
```tsx
describe('AppShell REQ-334 navigation', () => {
  it.each(routes)('$label remains reachable and marks the active route', ({ path, id, label }) => {
    renderApp()

    const desktopLink = document.getElementById(id)!
    expect(desktopLink).toHaveAccessibleName(label)
    fireEvent.click(desktopLink)
    expect(screen.getByTestId('current-route')).toHaveTextContent(path)
    expect(desktopLink).toHaveAttribute('aria-current', 'page')

    const mobileLink = document.getElementById(`${id}-mobile`)!
    expect(mobileLink).toHaveAccessibleName(label)
    fireEvent.click(mobileLink)
    expect(screen.getByTestId('current-route')).toHaveTextContent(path)
    expect(mobileLink).toHaveAttribute('aria-current', 'page')
  })
```

## 3. 変更仕様
1. **`WorkflowNodePicker.test.tsx` のテスト拡充**:
   - `[REQ-302/AC-4] preserves nested exception: Escape closes picker only and does not bubble to outer modal`
   - 内側の `WorkflowNodePicker` 展開中、外側モーダルのコントロールやボトムナビにアクセスできないことを検証。
2. **`AppShell.test.tsx` のテスト拡充**:
   - `[REQ-302/AC-1] mobile navigation is not clickable or accessible when modal overlay is present`
   - モーダル（`.modal-backdrop`）表示中に画面下部のボトムナビゲーション領域をクリック/タップしてもルーティング遷移が発生しないことを検証。
   - Red Teaming RT-1（高速連続タップ）でゴーストクリックによる画面遷移がゼロであることを検証。

<constraints>
- Archetype 1: Modals & Overlays

- モーダルネストの一般化は禁止（`WorkflowNodePicker` 以外のネスト例外を追加しない）。
</constraints>
