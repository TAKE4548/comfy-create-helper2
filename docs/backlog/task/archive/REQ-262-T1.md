## 3. 実装要件 (Implementation Logic)
- [x] `backend/app/config.py`:
  - `Settings` クラスに `frontend_dist_dir: str = "../frontend/dist"` を追加。
  - プロパティ `frontend_dist_path` を追加。カレントディレクトリ配下の `frontend/dist` または `../frontend/dist` から存在するパスを解決し、存在しない場合もデフォルトの解決済み `Path` を返すこと。
- [x] `backend/app/main.py`:
  - `SPAStaticFiles(StaticFiles)` クラスを定義:
    - `async def get_response(self, path: str, scope: Scope) -> Response`:
      - パス区切り文字を正規化（`path.replace('\\', '/')`）。
      - `super().get_response(path, scope)` を呼び出し、`HTTPException(404)` が送出された場合:
        - `norm_path.startswith("api/")` または `norm_path == "api"` の場合は `JSONResponse(status_code=404, content={"detail": "Not Found"})` を返却（APIの保護）。
        - 拡張子を持たないパス（`not Path(norm_path).suffix`）の場合は、SPA ルーティングフォールバックとして `await super().get_response("index.html", scope)` を返却。
        - 拡張子を持つアセット欠損パスは `raise exc`（404）。
  - 末尾で `frontend_dist = settings.frontend_dist_path` を取得:
    - `(frontend_dist / "index.html").exists()` の場合、`app.mount("/", SPAStaticFiles(directory=str(frontend_dist), html=True), name="frontend")` を登録。
    - 存在しない場合、`GET /` にフォールバックエンドポイントを登録し、ビルド手順と `/docs` の案内を返す。
