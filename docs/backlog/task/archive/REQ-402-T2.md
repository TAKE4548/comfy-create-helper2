## Exact Menu Count Contract
```ts
type PresetTabCloseCounts = Record<PresetTabCloseMode, number>
// Menu props (complete count/action boundary):
counts: PresetTabCloseCounts
pending: boolean
onAction: (mode: PresetTabCloseMode) => void | Promise<void>
// Layout derives these every render from its latest real state, not cached menu-open state:
const input = { selectedWorkflowId, sets, openPresetIds, activeSetId }
const modes: PresetTabCloseMode[] = ['others', 'left', 'right']
const counts = Object.fromEntries(modes.map(mode => [mode,
  createPresetTabClosePlan(input, triggerId, mode)?.targetIds.length ?? 0
])) as PresetTabCloseCounts
```
- countsは内部の無効判定用、項目labelに数値は付けず承認済3labelをそのまま表示する。`disabled=pending || counts[mode]===0`。無効項目はonActionを呼ばない。
- label→modeは 他のタブを閉じる→others、左のタブをすべて閉じる→left、右のタブをすべて閉じる→right。onActionは起点triggerIdを閉じ込めたlayout callbackから `handleClosePresetTabs(triggerId,mode)` を一度だけ呼ぶ。menuが独自にstore commitしない。
- triggerIdはmenuを開いたtabの元ID、入力4項目は最新layout state。plannerのnullは無効trigger/空targetのどちらもcount0。クリック確定時に上流handlerが最新planを生成・固定し保存後に再検証するため、表示countをclose許可証として使わない。

## Required Behavior and Constraints
1. desktop局所SetTabItemとmobile inlineを共有itemへ置換。非interactive外枠に選択/check/単件close/ellipsisを兄弟配置、button入れ子禁止。checkbox/closeのpropagationを止め、従来の各操作維持。
2. 常設ellipsisの通常tapで同menu、aria-label=`${name}のタブ操作`。inactiveでもmenu起動だけでselectしない。right contextmenuは選択領域だけpreventDefaultして同menuへ。native input controlsを奪わない。
3. touch/pen500ms長押し。checkbox/close/ellipsis起点を除外。8px超move/scroll/up/cancel/2本目pointer/unmountでtimer解除。pointerdownでpreventDefault/captureせず横scroll維持。
4. 成立後のnative contextmenuはpreventDefault/dedupe、synthetic click一度消費。shorttap選択や次回通常操作へ抑止を持ち越さない。
5. 3labels: 他のタブを閉じる / 左のタブをすべて閉じる / 右のタブをすべて閉じる。plannerからlatest counts、target0はdisabled。対象tab名を見出しに。
6. >=768pxはbody portal fixed menuをviewport内へ補正。<768pxは既存BottomSheet、中央modal禁止。resize中のclip/focus破綻も避ける。
7. desktop menu/menuitem、Arrow/Home/End/Enter/Space/Escape。sheet dialog内の通常button群とfocus循環。初期focus=有効項目、全無効ならClose。
8. 外側/backdropは背景へclick-throughせずmenuだけ閉じる。Escape同様、tab/open/input不変。focus起点へ戻し、消失時activeへfallback。
9. 操作開始時にmenuは閉じてよいが、tab chip/open一覧を楽観的に除去しない。pending中二重一括操作拒否、editorのglobal lockなし。上流がdriftでabortした場合は全tabを表示したまま保持する。menu閉鎖を保存取消と混同しない。
10. E2E locatorにdata-preset-id/accessible namesを用いる。ticket ID入りDOM IDなし。
11. Archetypes=Tabs/Chips+Overlays+Controls。min-w-0/truncate、shrink-0/nowrap、overflow-x-auto、44px非重複hit領域、最低11px、dvh、sheet overscroll-contain/safe-area。pan-x pan-y/manipulationで横scroll維持。一律pan-yやglobal font floor/doublepadding禁止。
