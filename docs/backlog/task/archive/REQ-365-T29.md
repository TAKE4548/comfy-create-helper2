特異性 (0,2,0) のため、これらは Modal の Tailwind ユーティリティ（`md:max-h-[90dvh]` `md:pb-0` 等）より優先されうる。

## 変更内容
1. `@media (max-width: 767px)` 内の `.req314-settings [role='dialog'] { max-height: min(85dvh, …) }` ブロック（約189〜191行）を**削除**（同 `@media` 内の他規則は残す）。
2. ベース規則（約42〜48行）から `max-height` と `padding-bottom` の2宣言を**削除**（`box-sizing`/`max-width`/`overflow` は維持）。理由: Modal は自前の `max-h`（`sheetMaxHeightClass`・`md:max-h-[90dvh]`）と `pb-[env(safe-area-inset-bottom)] md:pb-0` を持ち、重複は二重paddingのアンチパターンとなる。**前提確認で独自overlay残存が無い場合のみ**実施。判断に迷う場合は 1. のみ実施し、2. を見送った理由を報告。
3. `form`/`form > div`/`.settings-action-row` の `flex-wrap` 規則は維持（Modal 内容への影響は flex-wrap のみで無害。変更しない）。
4. `!important` を追加しない（既存の1件 `ui-invariant-ignore` 付きのみ）。`100vh` 生vhを追加しない。
