# REQ-432-T5: primary LUID フォールバック時の初回のみ debug ログ

## 1. 概要と目的
設計で定めた次の挙動が、完了済みの REQ-432-T1 で未実装のまま残っている（承認済みの手戻り範囲）。

> `primary_luid_hex` が未解決（DXGI 失敗）の場合、または一致するインスタンスが 0 件の場合は、全インスタンスを合算する（従来と同じ。安全側）。その旨を初回のみ debug ログに出す。一致 0 件のときに 0 を返すことは禁止する。

全合算は実装済みである。本カードでは「初回のみ debug ログ」を追加する。ログはサンプル（2.5 秒周期と判定直前の取得）ごとには出さず、プロセス内で最初にフォールバックしたときに 1 回だけ出す。戻り値は一切変えない。

## 4. 契約 C2a（実装必須）
```python
import logging

logger = logging.getLogger(__name__)          # "app.services.resource_monitor"

_adapter_fallback_logged: bool = False        # module-level once-flag

def sum_adapter_dedicated_usage(samples: Iterable[tuple[str, float]],
                                primary_luid_hex: str | None) -> float: ...  # signature unchanged
```
- フォールバック経路（`primary_luid_hex` が falsy、または一致 0 件で全合算を返す経路）に入ったとき、`_adapter_fallback_logged` が `False` なら `logger.debug(...)` を 1 回呼び、フラグを `True` にする。`True` なら何も出さない。未解決と一致 0 件で共通の 1 フラグとする（プロセス内で合計 1 回）。
- 一致があり primary 合算を返す経路では、ログを出さずフラグも変えない。
- ログには少なくとも次を含める: フォールバック理由（`unresolved` か `no_match`）、`primary_luid_hex` の値（未解決なら `None`）、インスタンス数。`%s` 形式の遅延フォーマットを使う（f-string で事前整形しない）。
- 副作用はモジュールフラグの更新と debug ログだけとする。ログ呼び出しで例外を出さない。戻り値は変更前と完全に同じ値にする。
- `samples` は既存どおり 1 回だけ列挙する（iterator を渡されても壊れないこと）。
- 複数スレッドから同時に初回到達した場合に 2 回出ることは許容する（debug ログのみのため、ロックは追加しない）。
- テストからのリセット: テストは `monkeypatch.setattr(resource_monitor_module, "_adapter_fallback_logged", False)` で初期化する。`resource_monitor_module` は `import app.services.resource_monitor as resource_monitor_module` で取得する（既存の `from ... import resource_monitor` はシングルトン変数であり、モジュールではない点に注意）。

def sum_adapter_dedicated_usage(samples: Iterable[tuple[str, float]], primary_luid_hex: str | None) -> float:
    """Sum PDH dedicated usage of the primary adapter; fall back to all samples when unresolved or unmatched."""
    items = [(name.lower(), value) for name, value in samples]
    if primary_luid_hex:
        tag = f"luid_{primary_luid_hex.lower()}_"
        matched = [value for name, value in items if tag in name]
        if matched:
            return float(sum(matched))
    return float(sum(value for _, value in items))
