## 3. 実装要件 (Implementation Logic)
1. **`PresetConflictModal.tsx`**:
   - **ヘッダー**: 警告アイコン、タイトル「プリセットの競合を検知しました」、説明テキスト。
     - 複数プリセットが競合した際に切り替え可能なタブUI構造を考慮した構成とする。
   - **PC表示 (`md:grid-cols-2`)**:
     - 左カラム: **サーバー最新版（他端末での編集）**（更新日時、プロンプト一覧、主要パラメータ）。
     - 右カラム: **この端末の編集（未保存ローカル）**（プロンプト一覧、主要パラメータ）。
     - 差異がある項目（プロンプト、数値など）にハイライト枠または差分バッジを付与。
   - **モバイル表示 (`md:hidden`)**:
     - タブボタン（`[サーバー最新版]` / `[この端末の編集]`）で表示内容をスイッチ。
   - **フッター（3つの解決アクションボタン）**:
     - `サーバー最新版を採用` (danger/neutral)
     - `この端末の編集で上書き` (warning)
     - `別名で両方保存 (推奨)` (accent/primary)
2. **`GeneratePage.tsx`**:
   - `useGeneratePageState`（または `usePresetState`）から `conflictData` と解決ハンドラを受け取り、`PresetConflictModal` をマウント。
