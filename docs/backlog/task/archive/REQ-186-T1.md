# タスクカード: REQ-186-T1

## 目的
1. 生成画面の「プリセット管理」モーダルにおいて、プリセット選択（ロード・適用）時にモーダルが自動クローズせず、開いたまま表示が維持されるようにする。
2. プリセット管理モーダル内から、各プリセットが現在タブバーに表示されているか（`isOpenAsTab`）を視認できるようにし、モーダル内から直接「タブを閉じる」操作を実行可能にする。
3. プリセット管理モーダルを開いたまま、複数のタブの「開く（選択）」および「閉じる」操作を連続して実行できるようにする。

## Acceptance Criteria
- [x] AC-1: プリセット管理モーダル内でプリセットを選択（ロード・適用）しても、モーダルが自動で閉じずに開いた状態が維持されること
- [x] AC-2: プリセット管理モーダル内から各プリセット/タブを閉じる操作（非表示化・整理）が直接実行可能であること
- [x] AC-3: プリセット管理モーダルを開いたまま、複数タブの「開く（選択）」および「閉じる」操作を連続して実行できること
- [x] AC-4: プリセット管理モーダル自体を閉じる明確な操作（閉じるボタンの押下等）により、作業完了時にユーザーが意図してモーダルを閉じられること
- [x] AC-5: 既存のプリセット保存・更新・適用等の基本機能にデグレーションが発生しないこと

### 2. `GeneratePage.tsx` の連携実装
```tsx
<PresetManagerPanel
  presets={presets || []}
  onRename={async (id, name) => {
    await renamePresetMutation.mutateAsync({ id, name })
  }}
  onReorder={async (ordered_ids) => {
    await reorderPresetsMutation.mutateAsync(ordered_ids)
  }}
  isPending={renamePresetMutation.isPending || reorderPresetsMutation.isPending}
  sets={sets}
  activeSetId={activeSetId}
  openPresetIds={openPresetIds}
  onToggleCheck={(id) => toggleSetChecked(id)}
  onDelete={(id) => handleDeletePreset(id)}
  onOpenAsTab={(id) => {
    const targetPreset = presets?.find((p) => String(p.id) === String(id));
    if (targetPreset) {
      handleLoadPreset(targetPreset);
    } else {
      openPreset(id);
      setActiveSetId(id);
    }
    // 自動で閉じない（setIsPresetManagerOpen(false) を削除）
  }}
  onCloseTab={(id) => removeSet(id)}
  onSaveOverwrite={(id, name) => handleUpdatePreset(id, name)}
  onSaveAsNew={(name) => handleCreatePreset(name)}
  onOpenSceneGenerator={() => {
    setIsPresetManagerOpen(false)
    setIsSceneGeneratorOpen(true)
  }}
  onBulkDelete={(selectedIds) => {
    handleBulkDeleteRequest(selectedIds)
  }}
  onBulkEdit={(selectedIds) => {
    handleBulkEditRequest(selectedIds)
  }}
/>
```
