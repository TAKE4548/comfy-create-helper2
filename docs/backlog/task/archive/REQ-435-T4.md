# REQ-435-T4: Generate DesktopLayout のモバイル寸法除去・メニュー統合配線・ステージ折り畳み統合

> 本 Task Card は本タスクの唯一の意味仕様書（sole semantic specification）である。実装時の追加調査が必要な場合は dev-task の有界調査規則に従い、未解決事項は推測せずエスカレーションすること。

## 1. 概要と目的
`DesktopLayout`（幅 768px 以上）において、プリセットタブバー・アクションバーに残存するモバイル最小寸法（`min-h-11`・過剰 `py`）を除去し、統合メニューの「このタブを閉じる」を `removeSet` に配線する。また、Desktop プロンプト欄に `useStageCollapseState(selectedWorkflowId, 'prompt')` を接続し、Desktop パラメータ欄 `<ParamPanel>` に `workflowId={selectedWorkflowId}` を渡してステージ折り畳み＆永続化を有効にする。Desktop の進捗表示は一切変更しない。

## 2. ターゲット識別（Impacted Files）
- `frontend/src/pages/GeneratePage/components/DesktopLayout.tsx`（L129–147, L530–621, L653–674, L766–783, L868–879）
- `frontend/src/pages/GeneratePage/components/__tests__/DesktopLayout.tabs.test.tsx`
- `frontend/src/pages/GeneratePage/components/__tests__/DesktopLayout.test.tsx`

## 3. UI アーキタイプと外科的制約
<constraints>
- **Archetype**: `Archetype 4: Shell & Page Layout` + `Archetype 2: Tabs / Chips / Grids`
- **Desktop コンパクト寸法 (AC-3)**: `#desktop-preset-tabs-bar` を `py-1.5`・内側スクローラを `py-0.5` とし、バー高さを 44px 未満にする。ActionBar（`#queue-open-btn`, `#generate-btn`, `#save-snapshot-btn`）から `min-h-11` / `py-3` を除去し `h-9 py-1.5`（36px < 44px）に統一。
- **Sticky 見出し契約 (AC-18)**: `#desktop-prompt-scroll` および `#desktop-controls-scroll` の `data-stage-scroll-root=""` と `stage-input-scroll-root` を維持し、上端物理 padding を追加しない。
- **Desktop 進捗保護 (AC-9)**: `renderStatusBar()`（L331–445）は一切変更しない。
</constraints>

  useStageCollapseState(selectedWorkflowId, 'prompt')
