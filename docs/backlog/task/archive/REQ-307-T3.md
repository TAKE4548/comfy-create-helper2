# REQ-307-T3 生成操作と失敗理由の対応づけ

単一の `handleGenerate` と複数セットの `handleGenerateSets` が `onSubmissionFailure` を渡す。対象・番号・理由・outcome を各ジョブの失敗レコードへ固定し、`null` や例外時にフォールバックを使う。処理終了時に一つのトーストへ全件を行単位で集約し `persistent: true` を付ける。単一で batchSize=1 は番号なし、複数回投入時のみ `i/N` を付ける。複数セットは `[セット名] (i/N)`。REQ-141 の failed 状態・継続とキャンセル非通知を維持。仕様を `SPEC_GENERATE.md` に同期。既存 fault テストが旧 API status wrapper を期待する場合、具体的な説明を含む新しい通知契約を検証するよう更新する。
