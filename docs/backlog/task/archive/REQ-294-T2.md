## 3. 実装要件 (Implementation Logic)

### 3.1 `SceneSpeechModal.tsx` 新規作成

- [ ] T8の `SceneSpeechModalState` 型と `ProgressStep` 型をimport
- [ ] `export function SceneSpeechModal(props: SceneSpeechModalProps)` をnamed exportする（T6がimport）
- [ ] **State `progress`**: ステップリスト（参照抽出/VLM推論/スタイル割当/VRAM解放）と経過秒数を表示
  - `useEffect` で 1秒ごとに `elapsedSeconds` をインクリメント（クリーンアップ必須）
  - 各ステップの `status` に応じてアイコン変化（pending=○、active=⏳spin、done=✓、error=✗）
- [ ] **State `onboarding`**: T8の `SceneSpeechOnboarding` を描画する。state.tagSetId、fontList、onPresetCreated、onPresetSkippedを渡す
  - 「適用して続行」ボタン → `onPresetCreated(presetId)` コールバック
  - 「スキップ」ボタン → `onPresetSkipped()` コールバック（生成結果は保持してReviewへ進む）
- [ ] **State `error`**: エラー種別ラベル（"LM Studio 400" / "接続拒否" / "タイムアウト" / "不明"）+ エラーメッセージ + 「再試行」ボタン
- [ ] **State `review`**: レビュー画面
  - `result.bubbles` をチェックボックス付きリストで表示（全デフォルト選択）
  - `result.tone_samples` が存在する場合: 系統Aセクション（高/中/低 サムネイル3コマ）
  - `result.candidate_similar_scenes` が存在する場合: 系統Bセクション（Top-3候補サムネイル + 「このシーンで再生成」ボタン）
    - ボタンクリック → `onReferenceSwitch(snapshotId)` コールバック
  - 「キャンバスに反映」ボタン → 選択済みバブルのみ `onApply(selectedBubbles)` へ渡す
- [ ] **PC/モバイル共存レイアウト**:
  - PC（md以上）: `fixed inset-0 z-50 items-center justify-center hidden md:flex`、最大幅540px
  - モバイル（md未満）: `fixed inset-x-0 bottom-0 z-50 md:hidden`、`max-h-[80vh] overflow-y-auto`
  - 両レイアウトで全4ステートが描画されること
