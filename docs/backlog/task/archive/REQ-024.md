# TASK-REQ-024-02: ComfyUI URL解決ロジックのプロキシ対応と接続チェックURLの修正

## 2. 密閉コンテキスト (Hermetic Context)
<hermetic_context>

### 2.1 既存の ComfyUI 解決ロジック (useComfyWebSocket.ts)
```typescript
export function resolveComfyUrl(url: string | null): string {
  if (!url) return 'http://127.0.0.1:8188'
  return url.replace('localhost', '127.0.0.1')
}
```

### 2.2 既存の接続チェックリスト (SettingsPage.tsx)
```tsx
            {[
              { label: 'FastAPI Backend', url: 'http://localhost:8000/health' },
              { label: 'ComfyUI', url: resolveComfyUrl(comfyUrl) },
            ].map(({ label, url }) => (
              <ConnectionStatus key={label} label={label} url={url} />
            ))}
```
</hermetic_context>

## 3. 実装要件 (Implementation Logic)
1. **`frontend/src/hooks/useComfyWebSocket.ts` の修正**:
   - `resolveComfyUrl` を更新する。
   - `url` が null の場合、ブラウザ環境であれば `${window.location.origin}/comfy` を返却する。
   - `url` に `localhost` または `127.0.0.1` が含まれる場合、ブラウザ環境であれば `${window.location.origin}/comfy` に解決するようにする。それ以外（非ブラウザ環境等）は従来の置換を行う。
2. **`frontend/src/pages/SettingsPage.tsx` の修正**:
   - `ConnectionStatus` に渡す FastAPI Backend の `url` について、`http://localhost:8000/health` からブラウザ環境であれば `${window.location.origin}/health` に動的解決するように更新する。
