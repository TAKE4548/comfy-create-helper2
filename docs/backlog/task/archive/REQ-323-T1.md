# REQ-323-T1: sessionStorage 下書きキャッシュユーティリティと例外安全保護の実装

## 1. 概要と目的
Dataset Studio の入力消失を防ぐため、`sessionStorage` へのプロジェクト単位（`dataset_studio_draft_${projectId}`）での即時下書き退避・復元・クリアおよびクォータ超過（`QuotaExceededError`）安全保護関数群を提供する。

## 2. 密閉コンテキスト (Hermetic Context)

### 2.1 型定義: `DatasetStudioDraft`
```typescript
export interface DatasetStudioDraft {
  projectId: number
  name: string
  character_trigger: string
  outfit_trigger: string
  workflow_id: number
  prompt_meta: string
  prompt_physical: string
  prompt_exclusive_outfit: string
  prompt_negative: string
  selected_alt_outfits: string // JSON 文字列
  updated_at: string // ISO-8601 文字列 (下書き更新日時)
  base_server_updated_at?: string // 編集開始時のサーバー更新日時 (楽観的ロック・競合判定用)
  is_synced: boolean
}
```

### 2.2 提供関数シグネチャ (`frontend/src/pages/DatasetStudioPage/utils/studioDraftStorage.ts`)
```typescript
export const DRAFT_STORAGE_PREFIX = 'dataset_studio_draft_'
export const ACTIVE_PROJECT_ID_KEY = 'dataset_studio_active_project_id'

export function getDraftStorageKey(projectId: number): string
export function saveStudioDraft(draft: DatasetStudioDraft): void
export function loadStudioDraft(projectId: number): DatasetStudioDraft | null
export function clearStudioDraft(projectId: number): void
export function markStudioDraftSynced(projectId: number, serverUpdatedAt?: string): void
export function saveActiveProjectId(projectId: number | null): void
export function loadActiveProjectId(): number | null
```

## 3. 実装要件 (Implementation Logic)
1. **`frontend/src/pages/DatasetStudioPage/utils/studioDraftStorage.ts` の新規作成**:
   - `getDraftStorageKey`: `\`${DRAFT_STORAGE_PREFIX}${projectId}\`` を返却。
   - `saveStudioDraft`:
     - `JSON.stringify(draft)` を `sessionStorage.setItem` で保存。
     - `QuotaExceededError` やストレージアクセス禁止例外を `try/catch` で補足し、例外発生時も上位処理へスローせずコンソール警告に留める（AC-3 厳守）。
   - `loadStudioDraft`:
     - `sessionStorage.getItem` で取得し、`JSON.parse` して返却。パース失敗やデータ不在時は `null` を返却。
   - `clearStudioDraft`:
     - `sessionStorage.removeItem(getDraftStorageKey(projectId))` を実行。
   - `markStudioDraftSynced`:
     - 保存中のドラフトをロードし、`draft.is_synced = true` に更新して再退避。
   - `saveActiveProjectId` / `loadActiveProjectId`:
     - `ACTIVE_PROJECT_ID_KEY` にプロジェクトID数値を退避・復元。
2. **ユニットテスト `frontend/src/pages/DatasetStudioPage/utils/__tests__/studioDraftStorage.test.ts` の新規作成**:
   - 正常系の保存・取得・クリア・同期フラグ更新を検証。
   - `sessionStorage.setItem` が `QuotaExceededError` を送出する異常系をモックし、エラーが上位に漏れず安全に処理されることを検証 (Red Team 1)。

## 4. 完了条件と検証
- [ ] `saveStudioDraft`, `loadStudioDraft`, `clearStudioDraft`, `markStudioDraftSynced` が正しく動作すること。
- [ ] `QuotaExceededError` が発生してもアプリがクラッシュしないこと (Red Team 1)。
- [ ] `saveActiveProjectId`, `loadActiveProjectId` で直近のプロジェクトIDが安全に維持されること。
