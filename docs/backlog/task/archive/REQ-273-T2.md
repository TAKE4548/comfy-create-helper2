#### 2) サブセットタグ入力部 (TagSetFormFields)
```tsx
// BEFORE:
<input
  type="text"
  placeholder="Tags (comma-separated)"
  value={sub.tags}
  onChange={(e) => {
    const next = [...(form.subsets || [])]
    next[idx] = { ...next[idx], tags: e.target.value }
    setForm((f) => ({ ...f, subsets: next }))
  }}
  className="w-full bg-surface-2 border border-[rgba(255,255,255,0.08)] rounded-md px-2 py-1 text-xs text-zinc-200 font-mono focus:outline-none focus:border-[#7C6FDD]/40"
/>

// AFTER:
<TagChipEditor
  value={sub.tags}
  onChange={(val) => {
    const next = [...(form.subsets || [])]
    next[idx] = { ...next[idx], tags: val }
    setForm((f) => ({ ...f, subsets: next }))
  }}
  placeholder="Tags (comma-separated)..."
  defaultTextMode={false}
/>
```

## 3. 実装手順 (Step-by-Step Instructions)
1. `TagSetModals.tsx` に `TagChipEditor` および `TagChipViewer` をインポートする。
2. `TagSetFormFields` のメインタグ textarea およびサブセット input を `TagChipEditor` に置き換える。
3. `TagSetDetailModal` のメインタグ一覧およびサブセットタグ一覧を `TagChipViewer` に置き換える。
4. `TagSetModals.test.tsx` を更新し、以下を検証する：
   - 登録・編集画面で `TagChipEditor` がチップモードで表示され、追加・削除が正しくフォームに同期すること。
   - 詳細モーダルで `TagChipViewer` が描画され、初期表示がチップモードであること。
   - 詳細モーダルの切替ボタンを押下するとテキストモードになること。
5. `npm test TagSetModals.test.tsx` を実行し、全テストパスを確認する。
