# TASK-REQ-216-T1: 共通 `<Modal>` コンポーネントの実装および単体テスト

## 1. 概要
プロジェクト共通のモーダルラッパーコンポーネント `frontend/src/components/common/Modal.tsx` を新規作成し、単一のコンポーネントで `.modal-backdrop` クラス（`z-index: var(--z-modal)` [100]、モバイル下部ナビセーフエリアパディング）、Escキーハンドリング、背景クリックハンドリング、内部伝播防止を一元管理する。

## 2. 実装詳細
- `frontend/src/components/common/Modal.tsx`:
  - Props: `isOpen`, `onClose`, `children`, `className`, `size` ('sm' | 'md' | 'lg' | 'xl' | '5xl' | 'full'), `closeOnBackdropClick`, `closeOnEsc`
  - 最外殻: `<div className="modal-backdrop animate-fade-in" onClick={handleBackdropClick}>`
  - 内側コンテナ: `<div className={`bg-[#121316] border border-[rgba(255,255,255,0.1)] rounded-2xl w-full ${sizeClass} max-h-full flex flex-col shadow-2xl overflow-hidden ${className}`} onClick={(e) => e.stopPropagation()}>`
- `frontend/src/components/common/__tests__/Modal.test.tsx`:
  - `isOpen=false` の場合に描画されないこと
  - `isOpen=true` の場合に `.modal-backdrop` が適用されコンテンツが表示されること
  - Escキー押下で `onClose` が発火すること
  - 背景クリックで `onClose` が発火し、ダイアログ内クリックでは発火しないこと
