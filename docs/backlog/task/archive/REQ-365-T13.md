## 現行コード（`ThumbnailSettingsSection.tsx` 42–62行）
```tsx
<label className="text-xs font-medium text-zinc-300 block">アスペクト比の選択</label>
<div className="grid grid-cols-2 sm:grid-cols-4 gap-2">
```

## 変更内容
1. ボタン群を1つの `<select id="thumbnail-aspect-preset">`（`<label htmlFor>` 付き `アスペクト比の選択`）に置換:
```tsx
<select id="thumbnail-aspect-preset" data-testid="thumbnail-aspect-select" value={presetId}
  onChange={(e) => handlePresetChange(e.target.value)}
  className="min-h-11 w-full touch-manipulation rounded-lg border ... px-3 text-xs sm:max-w-xs">
  {presets.map((p) => <option key={p.id} value={p.id}>{p.label}</option>)}
</select>
```
2. `custom` 選択時のカスタム入力（`data-testid="custom-aspect-ratio-input"`）、`現在適用中`、保存メッセージ（`role=status/alert`）、Live Previewボックス（`data-testid="aspect-ratio-preview-box"`）は**不変**。
3. `preset-btn-*` の testid は廃止（テスト更新）。ラベル行を縦に短縮し、レイアウトは `select` 1行＋プレビューの2列（`md:grid-cols-3` を維持して可）。

## テスト（`[REQ-365/AC-2]`）
- 既存 `preset-btn-*` を使うケースを `fireEvent.change(getByTestId('thumbnail-aspect-select'), {target:{value}})` に更新し、保存メッセージ・localStorage永続化の期待値は不変。
- 追加: `renders a single select with all presets and reflects the persisted selection`、`select has min-h-11 and touch-manipulation`、`custom input appears only for custom`、`shows persistence error without crashing when localStorage throws`.

<constraints>
- Archetype 3: `select`/`input` 44px以上、`touch-action: manipulation`、`label`は`htmlFor`で対象限定。iOSズーム回避のため`select`のフォントは`text-xs`(12px)未満にしない（11px floor遵守）。
- 長いラベルは`truncate`せず`select`の幅 `w-full`。`min-w-0`でflex親のはみ出しを防止。
- 生`vh`禁止、`pb`二重禁止、グローバルfont変更禁止。
</constraints>
