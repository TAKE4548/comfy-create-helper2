# REQ-430-T3: ワークフロー管理内部スクロール & xl 左右ペイン高さ整合

## 1. 概要と目的

## 5. 実装要件
- [ ] `WorkflowConnectionSection.tsx`: `WorkflowConnectionSectionProps` に `workflowListMaxHeight?: number` を追加し、L703 の `<div className="divide-y divide-[rgba(255,255,255,0.04)]">` に `data-testid="workflow-list-scroll"`、`overflow-y-auto overscroll-contain`、および `style={workflowListMaxHeight != null ? { maxHeight: `${workflowListMaxHeight}px` } : undefined}` を設定する。
- [ ] `SettingsPage.tsx`:
  - `MIN_SCROLL_LIST_HEIGHT = 240` を定義し、`activeTab === 'workflows'` かつ `window.matchMedia('(min-width: 1280px)').matches` のとき、`ResizeObserver`（存在しない環境では安全にスキップ）および `useLayoutEffect` で左右ペインの自然高さを計測する。
  - 自然高さの算出（循環計測防止）:
    - `wfList` = `[data-testid="workflow-list-scroll"]`, `mpList` = `[data-testid="mapping-master-list-scroll"]`
    - `wfChrome = wfCard.offsetHeight - wfList.clientHeight`（`wfList` 不在時は `wfCard.offsetHeight`）
    - `leftNatural = wfChrome + (wfList?.scrollHeight ?? 0) + 24 + bmCard.offsetHeight`
    - `mpChrome = mpCard.offsetHeight - mpList.clientHeight`（`mpList` 不在時は `mpCard.offsetHeight`）
    - `rightNatural = mpChrome + (mpList?.scrollHeight ?? 0)`
    - `target = Math.min(leftNatural, rightNatural)`
    - `leftNatural > target && wfList` なら `workflowListMaxHeight = Math.max(240, Math.floor(target - wfChrome - 24 - bmCard.offsetHeight))`、それ以外は `undefined`。
    - `rightNatural > target && mpList` なら `mappingListMaxHeight = Math.max(240, Math.floor(target - mpChrome))`、それ以外は `undefined`。
  - `<1280px` または `activeTab !== 'workflows'` では両方 `undefined` にリセットする。
  - 算出した値を `WorkflowConnectionSection` (`workflowListMaxHeight`) および `MappingMasterSection` (`listScrollMaxHeight`) へ渡す。
