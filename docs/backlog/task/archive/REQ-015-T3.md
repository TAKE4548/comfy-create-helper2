## 3. 実装要件 (Implementation Logic)
### 3-1. index.tsx
1. `useChipParser` と `useChipHistory` フックをインポートして呼び出す。
2. 外部から渡される `value` プロップと、`useChipHistory` 内の `present` チップを同期する。
   - `value` が更新され、かつ有効なチップ列のカンマ区切り文字が現在の状態と異なる場合にのみ、履歴を上書きせずに `setChips(parseToChips(value), false)` で同期する。
3. `DndContext` の `onDragEnd` ハンドラ：
   - ドラッグ元とドラッグ先の `id` を基に、`arrayMove` を使って順序を入れ替えた新しい配列を作成し、`setChips(newChips, true)` を呼び出して履歴に登録しつつ更新する。
4. キーボードセンサーとポインターセンサーを適切に初期化する（入力エリアでの競合を防ぐため、センサーのアクティベーション条件を調整する）。
5. `isTextMode` トグル処理：
   - テキストモード切替時、有効チップのみをカンマ連結して `textarea` の初期値とする。
   - チップモードに戻す時、テキストエリアの入力文字列をパースしてチップ配列に復元する。
6. カスタムイベントハンドリング：
   - `useEffect` 内で `window.addEventListener('tag-chip-editor:disable-tag', ...)` および `window.addEventListener('tag-chip-editor:add-tag', ...)` を登録する。
   - `disable-tag` イベント受信時：該当するタグ文字列を持つチップの `enabled` を `false` に変更し、履歴に積む。
   - `add-tag` イベント受信時：重複しない場合、末尾に有効チップとして追加し、履歴に積む。

### 3-2. tagChipEditor.css
1. ドラッグ中のプレースホルダー（`.drag-placeholder`）や、ドラッグ中のアクティブ要素スタイルを定義する。
2. インライン編集用 `input` の外枠を打ち消すリセットCSSなどを追加する。
