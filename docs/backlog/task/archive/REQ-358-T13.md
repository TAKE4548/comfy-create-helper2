## Implementation Logic

getからstatesと完全raw mappingsを読込み、prop既存mappingが提供された場合はその値を初期入力に使うがdisabledの保存行をfilterしない。null variantをlegacy keyへ正規化。get/masters/scan解決前は保存不可。workflowIdでsessionを識別し旧応答を破棄。既存IDと状態がscanより優先、newdefaultfalseは非表示。共通editor/rankに接続し一commit payloadで保存。
承認済みT8接続: buildRows().rowsのmaster順→stageSlots順でEditableSlotへ展開、node_id→nodeId/reference_missing→missingReference/enabled→enabled。editor/input keyはv_<id>/m_<id>、toggleはhook setSlotEnabled(key,enabled)/setStageEnabled(stageId,enabled)。保存はgetMappings(rows,[])でdisabled/参照先なし/非推奨の保存IDと未知mappingを保持。AC-33はgraph内の非推奨保存ID、AC-35はgraph欠落の保存IDをscan defaultへ置換せず「参照先なし」と表示する。scan/refetch/init再応答はdirty値を維持、workflow/reopen切替はhook remountで別sessionとし旧応答を破棄。M/modalはT11完了後に排他lock。

追加file/300変更行超過/矛盾時は証拠と分割案をcoordinatorへ返して再設計。
実logicを実行し、fetch/MSW HTTP、SQLite/disk境界だけを切る。新caseでAPIclient/helperをpatchしない。
入力DOMをstatus/candidate数で差し替えない。stable keyと明示空文字を保つ。masters+scan/GET完了後に1session1回init。
