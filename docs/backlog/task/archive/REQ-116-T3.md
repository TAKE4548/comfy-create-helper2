## 3. 実装要件 (Implementation Logic)
- **3-1. API クライアントへの翻訳API追加**:
  - `frontend/src/api/client.ts` に `llmPromptsApi.translate` メソッドを追加する。
    - `POST /api/llm-prompts/translate` を呼び出し、引数として `text: string` と `direction: 'ja_to_en' | 'en_to_ja'` を取る。レスポンスとして翻訳された文字列を返却する。
- **3-2. `TagChipEditor` の defaultTextMode サポート**:
  - `frontend/src/components/TagChipEditor/index.tsx` の `TagChipEditorProps` に `defaultTextMode?: boolean` プロパティを追加する。
  - 内部ステート `isTextMode` の初期値を `defaultTextMode ?? false` とする。
  - `useEffect` を追加し、プロップス `defaultTextMode` が変更された際に `setIsTextMode(defaultTextMode)` するように同期させる。
- **3-3. `useGeneratePageState.ts` への状態と自動連動ロジックの追加**:
  - 状態 `isAnimaMode`（boolean, デフォルト `false`）を定義し、返却オブジェクトに含める。
  - `baseModels` と `workflow` の取得データを監視する `useEffect` を追加する。
    - 現在選択中のワークフローの `target_base_model_id` を用いて、`baseModels` リストから対応するモデルを検索し、その `name` が `'Anima'` である場合は `isAnimaMode` を `true` に、そうでない場合は `false` に自動設定する。
- **3-4. トグルスイッチの UI 実装**:
  - `DesktopLayout.tsx` および `MobileLayout.tsx` のヘッダー部（ワークフロー選択プルダウンの横など）に、「Anima特化モード」を ON/OFF 切り替えるトグルスイッチ（UI）を配置し、`isAnimaMode` と `setIsAnimaMode` にバインドする。
- **3-5. プロンプト入力エリアとの連携**:
  - `DesktopLayout.tsx`（および `MobileLayout.tsx`）でプロンプト入力エリアとして呼び出している `TagChipEditor` コンポーネントに対し、`defaultTextMode={isAnimaMode}` を渡すように変更する。
- **3-6. ドラッグ可能なフローティング翻訳ウィンドウのUI実装**:
  - プロンプト入力エリアの近くに「翻訳」開閉ボタン（アイコン）を配置する。
  - 開いた際に、画面上でマウス・タッチドラッグ移動可能なフローティング形式のサブウィンドウを表示する（`react-draggable` 等を利用するか、簡易的な `onMouseDown` / `onMouseMove` / `onMouseUp` イベント追跡によるドラッグ処理を自作する）。
  - ウィンドウ内には「日本語入力欄（TextArea）」「英語入力欄（TextArea）」「処理中インジケータ（スピナー等）」を配置する。
- **3-7. 双方向デバウンス翻訳の実装**:
  - DBから設定キー `translation_debounce` の値（ミリ秒）を取得し、無ければデフォルト `500` ms とする。
  - メインプロンプト入力欄または翻訳ウィンドウの日本語欄が変更されたら、デバウンス時間の経過後にバックエンドの翻訳APIを `direction: 'ja_to_en'` で呼び出し、結果を翻訳ウィンドウの英語欄に反映する。
  - 翻訳ウィンドウの英語欄が変更されたら、デバウンス時間の経過後に `direction: 'en_to_ja'` で逆翻訳を呼び出し、結果をメインプロンプト入力欄および日本語欄に反映する。
  - リクエスト送信中に別の入力が発生した場合は、`AbortController` を用いて以前の通信リクエストをキャンセルする。
