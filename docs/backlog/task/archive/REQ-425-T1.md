# REQ-425-T1: Backend プロンプト構造テンプレートDB・Anima標準シード・ワークフロー出力グループAPI実装

## Goal
プロンプト構造テンプレートの永続化テーブル `prompt_structure_templates` と `workflows.prompt_template_config` / `workflow_history.prompt_template_config` カラムをマイグレーション（`step_036`）で追加し、起動時に「Anima 標準テンプレート」（キャラクター19ブロック Repeat可 ＋ 全体17ブロック 非Repeat）をシードする。さらに `/api/prompt-templates` CRUD API およびワークフローの作成・更新・取得・複製・ロールバックにおける `prompt_template_config` 永続化を実装し、OpenAPI スキーマ（`backend/openapi.json`, `frontend/src/api/schema.ts`）を同期する。

- `Workflow` および `WorkflowHistory` に `prompt_template_config` カラムを追加し、`PromptStructureTemplate` モデルを新設する：
```python
class PromptStructureTemplate(Base):
    __tablename__ = "prompt_structure_templates"

    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    name: Mapped[str] = mapped_column(String, nullable=False, unique=True)
    description: Mapped[str] = mapped_column(Text, nullable=False, default="", server_default=text("''"))
    structure_json: Mapped[str] = mapped_column(Text, nullable=False, default='{"sections":[]}', server_default=text("'{\"sections\":[]}'"))
    is_builtin: Mapped[bool] = mapped_column(Boolean, nullable=False, default=False, server_default=text("0"))
    sort_order: Mapped[int] = mapped_column(Integer, nullable=False, default=0, server_default=text("0"))
    created_at: Mapped[datetime] = mapped_column(DateTime, nullable=False, default=lambda: datetime.now(timezone.utc))
    updated_at: Mapped[datetime] = mapped_column(
        DateTime,
        nullable=False,
        default=lambda: datetime.now(timezone.utc),
        onupdate=lambda: datetime.now(timezone.utc),
    )
```

### 4. Pydantic スキーマ (`backend/app/schemas/prompt_template.py` & `workflow.py`)
```python
class PromptTemplateBlockSchema(BaseModel):
    id: str = Field(..., min_length=1)
    label: str = Field(..., min_length=1)
    description: str = ""
    default_value: str = ""

class PromptTemplateSectionSchema(BaseModel):
    id: str = Field(..., min_length=1)
    name: str = Field(..., min_length=1)
    is_repeatable: bool = False
    blocks: List[PromptTemplateBlockSchema] = Field(default_factory=list)

class PromptTemplateStructureSchema(BaseModel):
    sections: List[PromptTemplateSectionSchema] = Field(default_factory=list)

class PromptRepeatFilterSchema(BaseModel):
    mode: Literal["all", "index"] = "all"
    index: Optional[int] = Field(default=None, ge=1)

class PromptOutputGroupSchema(BaseModel):
    id: str = Field(..., min_length=1)
    name: str = Field(..., min_length=1)
    target_role: str = Field(..., min_length=1)
    block_ids: List[str] = Field(default_factory=list)
    repeat_filter: PromptRepeatFilterSchema = Field(default_factory=PromptRepeatFilterSchema)

class WorkflowPromptTemplateConfigSchema(BaseModel):
    template_id: Optional[int] = None
    template_snapshot: Optional[PromptTemplateStructureSchema] = None
    output_groups: List[PromptOutputGroupSchema] = Field(default_factory=list)

class PromptTemplateCreate(BaseModel):
    name: str = Field(..., min_length=1)
    description: str = ""
    structure: PromptTemplateStructureSchema = Field(default_factory=PromptTemplateStructureSchema)
    sort_order: int = 0

class PromptTemplateUpdate(BaseModel):
    name: Optional[str] = Field(default=None, min_length=1)
    description: Optional[str] = None
    structure: Optional[PromptTemplateStructureSchema] = None
    sort_order: Optional[int] = None

class PromptTemplateRead(BaseModel):
    model_config = ConfigDict(from_attributes=True)
    id: int
    name: str
    description: str = ""
    structure: PromptTemplateStructureSchema = Field(default_factory=PromptTemplateStructureSchema)
    is_builtin: bool = False
    sort_order: int = 0
    created_at: datetime
    updated_at: datetime
```
- `WorkflowCreate`, `WorkflowRead` に `prompt_template_config: WorkflowPromptTemplateConfigSchema = Field(default_factory=WorkflowPromptTemplateConfigSchema)` を追加し、`WorkflowRead` で文字列 JSON を `WorkflowPromptTemplateConfigSchema` へパースする `@field_validator("prompt_template_config", mode="before")` を実装する。
- `WorkflowUpdate` に `prompt_template_config: Optional[WorkflowPromptTemplateConfigSchema] = None` を追加し、`mapping_slot_states` と同様に明示的 `null` 指定時は `ValueError("prompt_template_config cannot be null")` を送出する。

### 5. ルーター (`backend/app/routers/prompt_templates.py` & `workflows.py`)
- `prompt_templates.py` で `GET /api/prompt-templates`, `POST /api/prompt-templates` (201, 重複名409), `PUT /api/prompt-templates/{template_id}`, `DELETE /api/prompt-templates/{template_id}` (204) を実装し、`main.py` に `include_router` する。
- `workflows.py` の `create_workflow`, `update_workflow`（`"prompt_template_config" in payload.model_fields_set` の場合に JSON 保存）、`copy_workflow`、`rollback_workflow`（`workflow_history` へのバックアップと復元）で `prompt_template_config` を扱う。
- 実装後、`python scripts/export_openapi.py --output backend/openapi.json` および `npm --prefix frontend run openapi:generate` を実行して契約スナップショットを更新する。
