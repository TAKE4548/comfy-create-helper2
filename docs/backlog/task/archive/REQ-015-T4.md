## 3. 実装要件 (Implementation Logic)
1. `GeneratePage.tsx` の冒頭で `TagChipInput` の代わりに `TagChipEditor` をインポートする。
2. モバイル判定ロジックを実装する。
   - `const isMobile = window.location.pathname.startsWith('/mobile') || window.innerWidth < 1024;`
3. プロンプト入力エリアのレンダリング部を更新する。
   - `isMobile` が `true` の場合は、従来通りの `textarea`（スタイルは既存の textarea スタイルと同様）を表示する。
   - `isMobile` が `false` の場合は、`<TagChipEditor>` を表示する。
4. LLM Audit パネルの干渉タグ診断結果（Interference）の表示を拡張する：
   - 各干渉タグの横に「無効化」ボタン（またはアイコン）を追加する。
   - ボタンクリック時、`window.dispatchEvent(new CustomEvent('tag-chip-editor:disable-tag', { detail: { tag: item.tag } }))` を実行する。
5. LLM Audit パネルの語彙サジェスト結果（Suggestions）の表示を拡張する：
   - `+{item.suggestion}` 部分をクリック可能にする、または `[+]` ボタンを追加する。
   - クリック時、`window.dispatchEvent(new CustomEvent('tag-chip-editor:add-tag', { detail: { tag: item.suggestion } }))` を実行する。
