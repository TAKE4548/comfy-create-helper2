## Hermetic Context and Acceptance Criteria

AC-1: mouse8px超/touch5px超handle dragで意図したchipの順序と親状態が一致。
AC-2: ×中央の実座標click/tapで対象IDのみ削除、menu誤起動なし。
AC-3: step、number Enter/Blur、有効toggleが既存format/handlerどおり状態反映。
AC-4: 閉じたchip本体feedbackと2pxcompact hit-slopを維持し、内側/隣接操作を遮らない。
AC-5: menu押下中の祖先scaleによる座標基準変化なし、cardの閉じる/drag/外側境界も機能。
以上は人の設計レビューを経る提案で、PBIは全証拠揃うまでDoneにしない。

### Relevant Signatures and Layout

~~~typescript
interface TagChipProps {
  id: string; text: string; enabled: boolean; isAnimaMode?: boolean;
  onToggle: (id: string) => void; onDelete: (id: string) => void;
  onEdit: (id: string, text: string) => void; onDuplicate: (id: string) => void;
}
interface TagChipTranslationCardProps {
  text: string; onClose: () => void; anchorRect?: DOMRect | null;
  menuRef?: React.RefObject<HTMLDivElement>;
}
~~~

rootはdata-ux-tag-chip=true、drag handle aria-label=並び替えハンドル、
delete aria-label=タグ {text} を削除。menuはabsolute top-full z-50、
weight numberはspinbutton、stepは通常±0.1/±0.3、Anima±0.5/±1.0。
タグ名input aria-label=タグ名編集、card data-testid=translation-card、fixed z-[100]。
document mousedown/touchstartでmenuRef.contains(target)がfalseなら閉じる。
menu keydown stopPropagation、Escapeでclose。Root shortcutsはDelete/Space/Ctrl+D。
数値は0下限、2桁round、1.0で通常本文へ戻す。数値規則の仕様整理は本件外。
