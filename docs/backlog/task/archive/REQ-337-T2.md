# REQ-337-T2: useComfyNodeTypes Hook for Cached Object Info and Filtering

## 1. 概要と目的
ComfyUI の全ノード定義を取得し、セッションキャッシュしながらインクリメンタル検索可能なカスタムフック `useComfyNodeTypes` を作成する。
ComfyUI 未接続・503・タイムアウト時でも例外をスローせず、`classNames: []` および `isError: true` を返却するグレースフル設計とする。

- **対象シンボル**: `useComfyNodeTypes`, `UseComfyNodeTypesResult`
- **行番号目安**: 新規作成

## 4. 実装要件 (Implementation Logic)
- [ ] `frontend/src/hooks/useComfyNodeTypes.ts` を作成し、`useQuery` を用いて全ノード情報を取得・キャッシュする。
- [ ] 取得されたオブジェクトのキー一覧を明示的 `string[]` として抽出し、アルファベット順にソートした `classNames` をメモ化する（未取得・エラー時は空配列）。
- [ ] インクリメンタルフィルタリング関数 `filterClassTypes(query: string, exclude?: string[])` を実装する。
  - 前方一致（prefix match）を最優先、部分一致（partial match）を次点とする。
  - 大文字小文字を区別しない。
  - `exclude` に指定されたクラス名は候補から除外する。
  - 大量ノード（100件超）でも描画負荷を抑制するため最大15件に制限（`slice(0, 15)`）する。
- [ ] ComfyUI 未接続・エラー発生時にも `isError: true`, `classNames: []` を安全に返し、クラッシュさせない。
- [ ] ユニットテスト `frontend/src/hooks/__tests__/useComfyNodeTypes.test.ts` を作成し、正常系・フィルタリング順序・exclude・15件超のデータセット・エラー時のフォールバックを網羅する。
