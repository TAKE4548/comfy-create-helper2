# REQ-331-T4: MatrixGenerationStep への共用コンポーネント統合と ComfyUI バッチ投入ペイロード反映

## 1. 概要と目的
Step 1（`MatrixGenerationStep`）に入力セクション（`CollapsibleSection`: マトリクス因子プロンプト枠、ネガティブ枠、`ParamPanel` パラメータ枠、バイパス・マッピング枠）を組み込み、画面の整理と操作性を向上させる。さらに「ComfyUIに20件直接投入」押下時に、編集された `paramValues` および `bypassedNodeIds` を各プロンプトペイロードに注入して ComfyUI へ一括投入する。

## 2. ターゲット識別
- **対象ファイル**: `frontend/src/pages/DatasetStudioPage/components/MatrixGenerationStep.tsx`
- **対象シンボル**: `MatrixGenerationStep`, `handleSubmitBatch`, `injectPromptAndSeed`

## 3. 密閉コンテキスト (Hermetic Context)
<hermetic_context>
### 3.1 バッチ投入ペイロード注入スニペット
```typescript
// In MatrixGenerationStep.tsx handleSubmitBatch loop:
// For each of the 20 items:
// 1. Clone workflow.json_body
// 2. Inject positive prompt into positive node, negative into negative node
// 3. Inject paramValues (steps, cfg, sampler, scheduler, etc.) into mapped nodes
// 4. Set mode = 2 (Bypass/Mute) for any node in bypassedNodeIds
// 5. Call comfyApi.queuePrompt({ prompt: payload, client_id: clientId })
```
</hermetic_context>

## 4. 実装要件 (Implementation Logic)
- [ ] Step 1 の UI を `CollapsibleSection` で構造化（プロンプト枠、パラメータ枠、バイパス・マッピング枠）。
- [ ] 共通コンポーネント `ParamPanel` および `BypassSettingsModal` を Step 1 に配置し、`useStudioStore` と直接連携。
- [ ] `handleSubmitBatch`（バッチ直接投入）において、各アイテムのプロンプト・シードに加えて `paramValues` および `bypassedNodeIds` をグラフ JSON に注入して `comfyApi.queuePrompt` へ投入。
