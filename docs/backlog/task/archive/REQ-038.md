## 3. 実装要件 (Implementation Logic)
1. **コンポーネントとアイコンのインポート**:
   - `frontend/src/components/LoraModals.tsx` の冒頭に `Trash2` を `lucide-react` からインポートする。
   - `TagChipEditor` を `./TagChipEditor` からインポートする。
2. **状態更新ハンドラの実装**:
   - `LoraFormFields` 内に、以下のトリガーワードセット更新用ヘルパー関数群を実装する。
     - `handleAddTriggerSet`: フォームの `trigger_word_sets` 配列に `{ name: '', words: '' }` を追加する。
     - `handleRemoveTriggerSet(index)`: 指定されたインデックスの要素を配列から除外する。
     - `handleUpdateTriggerSetName(index, name)`: 指定されたインデックスのセットの `name` を更新する。
     - `handleUpdateTriggerWords(index, words)`: 指定されたインデックスのセットの `words` (カンマ区切り文字列) を更新する。
3. **管理用セクションのUI追加**:
   - `LoraFormFields` の戻り値である `JSX` の末尾（Categoryセレクトボックスの下）に、トリガーワードセット管理セクションを追加する。
   - セクションタイトル「Trigger Word Sets」と「+ Add Set」ボタンを表示する。
   - `form.trigger_word_sets` 配列をマッピングし、各セットごとに以下のフィールドを含む入力ブロック（カード型レイアウトなど）を描画する。
     - **削除ボタン (ゴミ箱アイコン)**: 右上に配置し、`handleRemoveTriggerSet` を呼び出す。
     - **Set Name**: セット名入力用テキストボックス。`handleUpdateTriggerSetName` を使用。
     - **Trigger Words**: `TagChipEditor` を適用し、`value={tws.words}`、`onChange={(val) => handleUpdateTriggerWords(index, val)}` を渡す。
4. **スクロール対応**:
   - モーダル側のコンテナ (`LoraRegisterModal` と `LoraEditModal` 内の `p-5` の親要素) に `max-h-[80vh] overflow-y-auto custom-scrollbar` を適用し、縦スクロール可能にする。
