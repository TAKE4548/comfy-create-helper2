# REQ-308-T4: Anima chip 編集で明示された末尾ドットだけ保持

## Impacted Files

## Hermetic Context
```ts
export function formatTagWeight(baseText: string, weight: number | null, isAnimaMode = false): string {
  const trimmedBase = baseText.trim()
  const hasPeriod = trimmedBase.endsWith('.') || isAnimaMode
  const cleanBase = trimmedBase.replace(/\.+$/, '')
  if (weight === null || isNaN(weight) || weight === 1) return hasPeriod ? `${cleanBase}.` : cleanBase
  const rounded = parseFloat(weight.toFixed(2))
  if (rounded === 1) return hasPeriod ? `${cleanBase}.` : cleanBase
  return hasPeriod ? `(${cleanBase}:${rounded}).` : `(${cleanBase}:${rounded})`
}
```

## Implementation
- Set `hasPeriod` solely from the edited `baseText`'s explicit trailing period; Anima mode alone must not create one.
- Preserve explicit period for unweighted, unit-weight and non-unit-weight forms, normalizing multiple trailing periods to one.
- Tests cover Anima with/without dot, weight null/1/1.3, and non-Anima compatibility.
