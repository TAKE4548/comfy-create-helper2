# タスクカード: REQ-173-T2

## 1. 目的
`SpeechBubbleControls.tsx` において、プリセット一覧チップの表示名およびツールチップに、各プリセットの文字方向に応じた識別サフィックス `(縦)` / `(横)` を自動付与してレンダリングする。また、関連するフロントエンドユニットテストを更新・拡充する。

## 2. 変更対象ファイル
| ファイル | 変更内容 |
|---|---|
| `frontend/src/components/SpeechBubbleControls.tsx` | プリセット一覧チップのラベル表示および `title` 属性に `(縦)` / `(横)` を付与 |
| `frontend/src/components/__tests__/SpeechBubbleControls.test.tsx` | プリセットのサフィックス付き表示に関する検証テストを追加・更新 |

## 3. 密閉コンテキスト (Hermetic Context)
