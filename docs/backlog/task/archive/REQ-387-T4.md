## 実装契約

1. `database.py` に公開関数 `def configure_sqlite_pragmas(target_engine: Engine) -> None` を追加する。
   - `target_engine.url.get_backend_name() == "sqlite"` の場合だけ `event.listens_for(target_engine, "connect")` を登録する。
   - リスナーは DBAPI connection の cursor で `PRAGMA journal_mode=WAL`、`PRAGMA busy_timeout=5000`、`PRAGMA synchronous=NORMAL` を実行する。
   - `:memory:` で journal_mode が `memory` を返しても例外にしない。
   - モジュールの `engine` 生成直後に `configure_sqlite_pragmas(engine)` を呼ぶ。
   - import は `from sqlalchemy import create_engine, event` と `from sqlalchemy.engine import Engine`。
2. `logging_config.py`: 既存の uvicorn.access 行の後に `logging.getLogger("httpx").setLevel(logging.WARNING)` と `logging.getLogger("httpcore").setLevel(logging.WARNING)` を追加する。

## テスト（`backend/tests/unit/test_config.py` を拡張）

- `test_req387_ac7_sqlite_file_engine_uses_wal_and_busy_timeout(tmp_path)`: `create_engine(f"sqlite:///{tmp_path/'t.db'}")` に `configure_sqlite_pragmas` を適用して接続する。`PRAGMA journal_mode` が `wal`、`PRAGMA busy_timeout` が `5000` であることを確認する。`sqlite:///:memory:` でも接続が例外にならないこと（RT8）も確認する。最後に `engine.dispose()` する。
- `test_req387_ac7_httpx_logger_is_warning_after_setup_logging(tmp_path)`: `setup_logging(tmp_path, "INFO", 1)` の後に `logging.getLogger("httpx").level == logging.WARNING` と httpcore も同じであることを確認する。テスト後は root logger の handlers を元に戻す（handler を close して `root.handlers` を保存値へ復元）。
