# REQ-333-T41

ユーザー報告: 複数プリセットの一括バッチでcurrent以外がworkflow defaultになったが現在は再現しない。handleGenerateSetsで各setのparams/chips/assets/seedを凍結し、そのgraphとmetadataへ同じ値を渡すことを確認する。active setは現在編集中のstate、非active setは保存済みset値。初回・初期化・空値false/0・current切替・送信後編集で他setの値をdefaultへ置き換えない。再現しないなら推測で本番変更せず、複数の異なる非active presetを含む有意な回帰試験と調査結果を残す。

## Impacted Files
- frontend/src/pages/GeneratePage/hooks/useGenerateAction.ts
- frontend/src/pages/GeneratePage/hooks/__tests__/useGenerateAction.test.ts
- frontend/src/pages/GeneratePage/hooks/__tests__/useGenerateAction.fault.test.ts
