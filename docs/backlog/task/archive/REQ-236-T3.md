## 4. 実装手順 (Step-by-Step Implementation)

### 4.1 `useChipParser.property.test.ts` の作成
1. `fast-check` をインポートし、`fc.assert` と `fc.property` を構成。
2. Property 1 (No-crash): 任意のランダム Unicode 文字列に対して `parseToChips` および `chipsToString` が例外を出さないこと。
3. Property 2 (Round-trip): カンマを含まない非空白文字列リストについて、`parseToChips` -> `chipsToString` で各要素が順序通り抽出されること。
4. Property 3 (Weight Parsing): ランダムな baseText と浮動小数点数（0.0〜10.0）に対して `formatTagWeight` と `parseTagWeight` が安全に変換できること。

### 4.2 `workflow_scanner.py` の防御的修正
1. `_find_candidate_nodes` において、`_meta` が辞書型でない場合や `class_type` が文字列でない場合に備えて安全な型判定ガードを追加。
2. `title_patterns` や `expected_class_types` 内の要素が文字列以外の型であった場合でも `.strip().lower()` で AttributeError が発生しないようガード。

### 4.3 `test_workflow_scanner_property.py` の作成
1. `hypothesis` の `@given` デコレータを用いて、壊れた階層構造を持つ辞書 JSON（`st.dictionaries`）を生成。
2. `scan_workflow` に投入し、いかなる破損 JSON に対してもプロセスが停止（クラッシュ）せず、安全に `warnings` または `matched` が返却されることをアサート。
