## 3. 実装要件 (Implementation Logic)
### 3-1. TagChip.tsx
1. `@dnd-kit/sortable` の `useSortable({ id })` を呼び出す。
2. ドラッグ時の `transform`, `transition` に合わせてスタイルをインライン適用する。
3. `isDragging` の際はプレースホルダーとしての透明度やスタイルを設定する。
4. インライン入力状態 (`isEditing`) のステートを管理する。
   - `input` タグを表示し、マウント時に自動フォーカスする。
   - `Enter` / `Tab` または `blur` で `onEdit` を実行し確定。空文字の場合は `onDelete` を実行する。
   - `Escape` で元のテキストに戻してキャンセルする。
5. `×` ボタンには `aria-label` およびホバーエフェクトを設定する。
6. `aria-roledescription="ドラッグで並び替え可能"` および左右キー操作のツールチップを追加する。

### 3-2. TagInput.tsx
1. `<input>` フォームをレンダリングする。
2. `onChange` にて入力値が `,` で終わる場合、末尾のカンマを除いてトリミングし、`onAddTags([newTag])` を呼び出す。
3. `onKeyDown` ハンドラ：
   - `Enter` / `Tab` の場合：入力がある場合、`onAddTags([inputValue.trim()])` を呼び出して確定し、入力をクリアする。`e.preventDefault()` すること。
   - `Backspace` の場合：`inputValue === ""` であれば `onRemoveLast()` を呼び出す。
4. `onPaste` ハンドラ：
   - クリップボードテキストを取得し、カンマ区切りでパースし、空文字を除外した上で `onAddTags(pastedTags)` を呼び出す。
