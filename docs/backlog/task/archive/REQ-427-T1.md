# REQ-427-T1: 参照画像ストア（保存・touch・GC）と /api/ref-images API

## 1. 目的
参照画像（ref 画像）の実体を内容アドレス方式で保存するバックエンドストアと、アップロード・履歴/スナップショット取り込み・原本/サムネイル配信の REST API を新設する。値は参照トークン `refimg:<sha256>.<ext>` として返し、以降のカード（供給経路・UI）の共通基盤とする。あわせて、どこからも参照されず猶予期間を過ぎた画像を起動時と定期実行で削除する GC を実装する（§4.4）。最優先の原則は「参照収集が一部でも不確実なら一切削除しない」。

## 4. 共有契約（このカードが提供する）
### 4.1 トークン（C1）
- 完全一致正規表現 `^refimg:([0-9a-f]{64})\.(png|jpg|webp)$`。`ref_id` = `<sha256>.<ext>`、トークン = `refimg:` + `ref_id`。sha256 は保存原本バイト列のハッシュ。拡張子は Pillow 検出 `format`（PNG→png, JPEG→jpg, WEBP→webp）。ファイル名・Content-Type は判定に使わない。

### 4.2 `backend/app/services/ref_image_store.py`（公開シグネチャ。T3 が import する）
```python
REF_TOKEN_RE: re.Pattern[str]
REF_ID_RE: re.Pattern[str]                 # ^([0-9a-f]{64})\.(png|jpg|webp)$
MAX_REF_IMAGE_BYTES = 20 * 1024 * 1024
MAX_REF_IMAGE_PIXELS = 50_000_000

class RefImageError(Exception):
    def __init__(self, status: int, code: str, message: str) -> None: ...
    status: int; code: str; message: str

class StoredRefImage(NamedTuple):
    ref_id: str; media_type: str; width: int; height: int; byte_size: int

def parse_ref_token(value: object) -> str | None   # 完全一致なら ref_id、それ以外 None
def token_for(ref_id: str) -> str

class RefImageStore:
    def __init__(self, root: Callable[[], Path] | None = None) -> None
        # 既定 root は「呼び出しのたびに」Path(settings.snapshot_path).parent / "ref_images"
    @classmethod
    def default(cls) -> "RefImageStore"
    def save_bytes(self, data: bytes) -> StoredRefImage
    def exists(self, ref_id: str) -> bool            # REF_ID_RE 不一致は False
    def read(self, ref_id: str) -> tuple[bytes, str] # (原本, media_type)。無ければ RefImageError(404, "not_found", ...)
    def describe(self, ref_id: str) -> StoredRefImage
    def thumbnail_path(self, ref_id: str) -> Path    # 無ければ再生成。原本無しは RefImageError(404)
    def root(self) -> Path                           # 現在のストアルート（GC が使用）
    def touch(self, ref_id: str, *, min_interval_s: float = 0.0) -> bool
        # STORE_LOCK 下で原本 mtime を現在時刻へ（os.utime）。現 mtime が min_interval_s 以内なら更新しない。原本無しは False
    def claim(self, ref_ids: Iterable[str]) -> list[str]
        # STORE_LOCK 下で各 ref_id の存在確認＋touch を原子的に実施し、欠落した ref_id を返す（T3 の受付で使用）

STORE_LOCK: threading.RLock   # プロセス内共有。save_bytes / touch / claim / GC の削除フェーズが保持
```
- 保存先: `<root>/<sha256>.<ext>`、サムネイル `<root>/thumbs/<sha256>.webp`（`ImageOps.exif_transpose` 後に長辺 256px、WebP quality 80）。
- `save_bytes` 手順: 空→`RefImageError(422,"empty_file")`、`len > MAX`→`(413,"too_large")`、`Image.open`→`verify()`→再 open して `format`/`size` 取得、PNG/JPEG/WEBP 以外・`UnidentifiedImageError`/`OSError`/`SyntaxError`→`(415,"unsupported_media_type")`、`w*h > MAX_REF_IMAGE_PIXELS` または `Image.DecompressionBombError`/`DecompressionBombWarning`（`warnings.catch_warnings` で例外化）→`(413,"too_large")`。既存同名ファイルは再書込せず `touch` のみ行う（冪等、猶予延長）。新規は `<root>/.tmp_<uuid4hex>` へ書いて `Path.replace`。サムネイルも同様。書き込み・replace・touch は `STORE_LOCK` 下で行う（Pillow 検証はロック外）。
- 削除 API は作らない。削除は GC（§4.4）のみが行う。

### 4.3 REST API（`backend/app/routers/ref_images.py`、`APIRouter(prefix="/api/ref-images", tags=["ref-images"])`）
```python
class RefImageRead(BaseModel):
    token: str; ref_id: str; media_type: str; width: int; height: int; byte_size: int
    view_url: str        # f"/api/ref-images/{ref_id}"
    thumbnail_url: str   # f"/api/ref-images/{ref_id}/thumbnail"

class RefImageImportRequest(BaseModel):
    model_config = ConfigDict(extra="forbid")
    source: Literal["history", "snapshot"]
    filename: str | None = None
    subfolder: str = ""
    type: Literal["output", "temp"] = "output"
    snapshot_id: int | None = None
```
| メソッド/パス | 成功 | 失敗 |
|---|---|---|
| `POST /upload`（multipart `file: UploadFile`） | 201 `RefImageRead` | 415 / 413 / 422（`RefImageError` を `HTTPException(status, detail={"code","message"})` へ変換） |
| `POST /import`（JSON） | 201 `RefImageRead` | 422（検証）/ 404 `source_not_found` / 502 `upstream_unavailable` / 415 / 413 |
| `GET /{ref_id}` | 200 原本（`media_type`、`Cache-Control: public, max-age=86400`。`immutable` は付けない） | 404 `not_found`（形式不一致も 404） |
| `GET /{ref_id}/thumbnail` | 200 `image/webp`（同 Cache-Control） | 404 `not_found` |
- 両 GET は応答前に `store.touch(ref_id, min_interval_s=3600)` を行う（表示された画像の GC 猶予を延長。max-age 24h ＋抑制 1h は猶予 72h より十分短いため、キャッシュ失効後に再表示された画像は猶予内に再 touch される）。
- upload は `await file.read(MAX_REF_IMAGE_BYTES + 1)` で上限 +1 バイトまでのみ読む。Pillow 処理は `asyncio.to_thread`。
- import 検証（model_validator または handler 冒頭）: `source="history"` は `filename` 必須、`source="snapshot"` は `snapshot_id` 必須。`filename` に `/`・`\\`・`..` を含む、`subfolder` に `..`・`\\` を含む／先頭 `/`、は 422。
- history: `get_comfy_client().get(f"{settings.comfy_url}/view", params={"filename","subfolder","type"}, timeout=10.0)` が 200 なら原本を `save_bytes`。404 または `httpx.HTTPError` のときは `_get_full_webp_disk_path(f"{type}:{subfolder}:{filename}")` が存在すればそのバイト列を `save_bytes`。どちらも無い場合、上流 404 なら 404 `source_not_found`、上流接続失敗なら 502 `upstream_unavailable`。
- snapshot: `SnapshotService.get_snapshot(db, snapshot_id)`。無い・`image_path` 無しは 404。`Path(settings.snapshot_path) / Path(image_path).name` を `resolve()` し、`settings.snapshot_path.resolve()` 配下でなければ 404。存在しなければ 404。

### 4.4 GC（`backend/app/services/ref_image_gc.py`）
```python
GC_GRACE_SECONDS = 72 * 3600; GC_INITIAL_DELAY_SECONDS = 60; GC_INTERVAL_SECONDS = 6 * 3600
GC_MAX_DELETIONS_PER_RUN = 500; TMP_STALE_SECONDS = 3600
REF_SCAN_RE = re.compile(r"refimg:([0-9a-f]{64})\.(png|jpg|webp)")   # 部分一致（JSON 内・入れ子文字列内も拾う）
class GcReport(NamedTuple):
    aborted: bool; reason: str | None; tables_scanned: tuple[str, ...]; referenced: int
    stored: int; deleted: tuple[str, ...]; kept_recent: int; kept_referenced: int
def collect_db_references(conn: Connection) -> tuple[set[str], tuple[str, ...]]
def run_gc(store: RefImageStore, connect: Callable[[], ContextManager[Connection]], *, now: Callable[[], float] = time.time) -> GcReport
async def gc_loop(store: RefImageStore, connect: Callable[[], ContextManager[Connection]], *,
                  initial_delay: float = GC_INITIAL_DELAY_SECONDS, interval: float = GC_INTERVAL_SECONDS) -> None
```
- **参照収集**（`collect_db_references`）: `SELECT name FROM sqlite_master WHERE type='table' AND name NOT LIKE 'sqlite_%'` で実行時にテーブル一覧を得る。各テーブルを `SELECT * FROM "<name>"`（名前内の `"` は `""` へエスケープ）で全列・全行走査（`fetchmany(500)`）。`str` はそのまま、`bytes` は `decode("utf-8", "ignore")` して `REF_SCAN_RE.finditer` で `f"{sha}.{ext}"` を収集。全体を 1 つの読み取りトランザクション（`with conn.begin():`）で行う。テーブル名を固定列挙しない（将来の保存場所を自動で含めるため）。例外は呼び出し元へ伝播させる。
- **run_gc 手順**（例外はすべて捕捉し `aborted=True` で返す。どの中止でも削除 0 件）:
  1. `store.root()` が無い・列挙失敗 → 中止。ルート直下の `REF_ID_RE` 一致の通常ファイル（`is_symlink()` は除外）を原本一覧とする。
  2. 収集 1 回目（`with connect() as conn`）。失敗 → 中止。
  3. 候補 = 未参照 かつ `now() - mtime > GC_GRACE_SECONDS`。候補が空なら 5 へ。
  4. 収集 2 回目。失敗 → 中止。2 回目で参照された候補は除外。残りを ref_id 昇順で最大 `GC_MAX_DELETIONS_PER_RUN` 件、各々 `STORE_LOCK` 下で mtime を再取得し、なお猶予超過なら原本と `thumbs/<sha>.webp` を `unlink(missing_ok=True)`。
  5. 付随整理（同じくロック下）: 原本の無い `thumbs/^[0-9a-f]{64}\.webp$` のうち mtime 猶予超過のもの、ルート直下 `.tmp_*` のうち mtime 1 時間超のものを削除。
  - 上記以外の名前・サブディレクトリ・シンボリックリンク・ルート外へ解決されるパスには触れない。DB へは書き込まない。
- **gc_loop**: `initial_delay` 待機 → `await asyncio.to_thread(run_gc, ...)` → `logger.info`（集計値）/ 中止時 `logger.warning`（1 回）→ `interval` 待機、を繰り返す。`CancelledError` 以外の例外は捕捉してログのみで継続する。

## Delegation & Boundaries
