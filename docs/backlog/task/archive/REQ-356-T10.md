# REQ-356-T10: [Frontend E2E Playwright] frontend/e2e/ Playwright基盤構築、sticky・実スクロール検証移行

## 1. 概要と目的
SPEC-TESTING v2.1 境界A/B規約に従い、`position: sticky` および実スクロールの検証を Playwright（`frontend/e2e/`）へ移行し、jsdom 内での擬似スクロールテストを全廃する（AC-8）。
Playwright の sticky 検証をデスクトップ（1280x800）とモバイル（375x667）の2種類の viewport で実行し、レイアウト破綻がないことを実ブラウザ上で保証する（AC-8）。

## 2. ターゲット識別
- **対象ファイル**: `frontend/e2e/stickyHeader.spec.ts`, `frontend/playwright.config.ts`
- **対象シンボル**: `test.describe('Sticky Header E2E')`

## 3. 密閉コンテキスト (Hermetic Context)
<hermetic_context>
### 3.1 必須の型定義
```typescript
import { test, expect } from '@playwright/test';
```

### 3.2 実装対象コード例 (stickyHeader.spec.ts)
```typescript
const viewports = [
  { name: 'Desktop', width: 1280, height: 800 },
  { name: 'Mobile', width: 375, height: 667 },
];

for (const vp of viewports) {
  test(`[REQ-356/AC-8] sticky header remains in view on scroll (${vp.name})`, async ({ page }) => {
    await page.setViewportSize({ width: vp.width, height: vp.height });
    await page.goto('/');
    const header = page.locator('[data-testid="sticky-header"]');
    await page.evaluate(() => window.scrollTo(0, 500));
    const box = await header.boundingBox();
    expect(box?.y).toBeLessThanOrEqual(10);
  });
}
```
</hermetic_context>
