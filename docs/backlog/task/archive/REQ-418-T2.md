### 4. Implementation logic

- [ ] **Models (`backend/app/models.py`)**:
  - `WorkflowPresetValue` (`workflow_preset_values`): `id` PK autoincrement; `preset_id` FK `workflow_presets.id` ON DELETE CASCADE NOT NULL; `variant_id` FK `mapping_variants.id` ON DELETE CASCADE NOT NULL; `sub_key` String NOT NULL default `""`; `value` Text NOT NULL; `UniqueConstraint("preset_id", "variant_id", "sub_key")`.
  - `ParamSyncGroupMember` (`param_sync_group_members`): `id` PK; `group_id` FK `param_sync_groups.id` ON DELETE CASCADE NOT NULL; `variant_id` FK `mapping_variants.id` ON DELETE CASCADE NOT NULL; `UniqueConstraint("group_id", "variant_id")`.
  - `ParamSyncGroup.master_variant_id`: `Optional[int]` FK `mapping_variants.id` ON DELETE CASCADE, `nullable=True`. Keep `master_role` and `slave_roles` columns unchanged.
  - Relationships: `WorkflowPreset.values` (`cascade="all, delete-orphan"`, order by id); `ParamSyncGroup.members` (`cascade="all, delete-orphan"`, order by id) and `ParamSyncGroup.master_variant`; on `MappingVariant`: `preset_values`, `sync_memberships`, `master_of_sync_groups` (`cascade="all, delete-orphan"`, `passive_deletes=True`).
- [ ] **Migration `step_035_variant_id_references(conn, inspector)` (`backend/app/migrations/steps.py`)**:
  1. **Prerequisite check (AC-1)**: if neither `workflow_presets` nor `param_sync_groups` exists in `sqlite_master`, return. Otherwise, if `mapping_variants` does not exist or lacks a `role` column, raise `ValueError("mapping_variants prerequisite table is missing")` before any DB change.
  2. Build `index = VariantIndex({row[0]: row[1] for row in conn.execute(sa.text("SELECT id, role FROM mapping_variants")).fetchall()})`.
  3. **Validation phase (no writes; single-transaction rollback guarantee for AC-1)**: expose `audit_role_references(conn) -> list[tuple[str, int, str]]`. For every preset, parse `param_values` JSON (invalid JSON or non-dict -> unresolved `<invalid json>`) and classify each key with `index.classify`; record any `KeyKind.UNRESOLVED` as `("preset", preset_id, key)`. For every sync group where `master_variant_id` is NULL (or column not yet added), check `master_role` and each item of `slave_roles` with `index.classify`; record any non-`KeyKind.ROLE` as `("sync_group", group_id, role)`. If the unresolved list is non-empty, raise `ValueError` listing all unresolved items without modifying the DB.
  4. **Mutation phase (only after 0 unresolved rows, AC-1)**:
     - Create `workflow_preset_values` and `param_sync_group_members` (`CREATE TABLE IF NOT EXISTS` matching model DDL with `REFERENCES mapping_variants(id) ON DELETE CASCADE` and `UNIQUE`), and add `master_variant_id INTEGER REFERENCES mapping_variants(id) ON DELETE CASCADE` to `param_sync_groups` if absent.
     - If tables are empty, schema creation and FK attachment complete and commit with no data rows written (AC-1).
     - For each preset: insert `(preset_id, variant_id, sub_key, value)` for `VARIANT`/`ROLE`/`DERIVED_ROLE` keys (skipping existing `(preset_id, variant_id, sub_key)`; non-`str` values serialized via `json.dumps(v, ensure_ascii=False)`), and update `workflow_presets.param_values` to `json.dumps(reserved_dict, ensure_ascii=False)`.
     - For each unmigrated sync group: set `master_variant_id` and insert deduplicated `param_sync_group_members` rows in order.
