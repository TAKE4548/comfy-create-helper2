# REQ-268-T1: .gitignore 設定更新およびゴミファイル・未追跡ファイルの整理

## 1. 概要
`db/thumbnails/` や `scratch/` などが Git の未追跡ファイルとして露出している問題を解消するため、`.gitignore` を更新し、混入していたゴミファイル（誤複製品およびバックアップ）を削除する。

## 2. 変更対象ファイル（Atomicity: 3 files）
- `.gitignore` (更新)
- `frontend/src/pages/GeneratePage/components/SettingsPopover (1).tsx` (削除)
- `tools/server-manager/config.json.bak` (削除)

## 3. 手順詳細
1. `.gitignore` の行 140 付近（`# App databases and snapshots`）に `db/thumbnails/`, `scratch/`, `*.bak` を追加する。
2. 誤操作で作成された未追跡ファイル `frontend/src/pages/GeneratePage/components/SettingsPopover (1).tsx` を削除する。
3. 未追跡バックアップファイル `tools/server-manager/config.json.bak` を削除する。

## 4. コンテキスト・コードスニペット
```gitignore
// Target in .gitignore (L140-L147)
# App databases and snapshots
db/snapshots/
db/thumbnails/
*.bak
*.db.bak
*.db-journal
db/prompt_surgeon.db
brain/
scratch/
.vite/
logs/
```

## 5. 検証手順
- `git check-ignore db/thumbnails/test.png` がマッチすること。
- `git check-ignore scratch/test.txt` がマッチすること。
- `git status -s` を実行し、`db/thumbnails/` や `scratch/` が `??` に表示されないことを確認。
