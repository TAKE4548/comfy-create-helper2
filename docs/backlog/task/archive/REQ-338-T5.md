# REQ-338-T5: モバイル特化ボトムシート Drawer コンポーネントおよび下スワイプクローズの実装

## 1. 概要と目的
画面幅 768px 未満のモバイル環境において、中央浮遊モーダルに代わる画面下部引き出し型「ボトムシート（Drawer）」共通コンポーネントを実装する。上部ドラッグハンドルによる下スワイプ即クローズと親指ゾーン決定ボタンを提供する。

## 2. ターゲット識別
- **対象ファイル**: `frontend/src/components/common/BottomSheet.tsx` (新規)
- **テストファイル**: `frontend/src/components/common/__tests__/BottomSheet.test.tsx` (新規)
- **対象シンボル**: `BottomSheet`, `BottomSheetProps`

## 3. 密閉コンテキスト (Hermetic Context)
<hermetic_context>
### 3.1 必須の型定義
```typescript
export interface BottomSheetProps {
  isOpen: boolean
  onClose: () => void
  title?: string
  children: React.ReactNode
  footer?: React.ReactNode
  maxHeight?: string // default: '85dvh'
  className?: string
  closeOnBackdropClick?: boolean
}
```

### 3.2 構造とタッチスワイプイメージ
```tsx
<div className="fixed inset-0 z-50 bg-black/60 backdrop-blur-sm flex items-end">
  <div
    ref={sheetRef}
    onTouchStart={handleTouchStart}
    onTouchMove={handleTouchMove}
    onTouchEnd={handleTouchEnd}
    style={{ transform: `translateY(${translateY}px)` }}
    className="w-full bg-surface-3 rounded-t-2xl border-t border-white/10 flex flex-col max-h-[85dvh] overscroll-contain pb-[env(safe-area-inset-bottom)]"
  >
    {/* Drag Handle */}
    <div className="mx-auto my-2.5 h-1.5 w-12 rounded-full bg-zinc-600 flex-shrink-0" />
    {title && <div className="px-4 py-2 text-sm font-bold text-white border-b border-white/5">{title}</div>}
    <div className="flex-1 overflow-y-auto px-4 py-3">{children}</div>
    {footer && <div className="sticky bottom-0 bg-surface-3 border-t border-white/10 p-3">{footer}</div>}
  </div>
</div>
```
</hermetic_context>

## 4. 実装要件 (Implementation Logic)
- [ ] `BottomSheet.tsx` の実装。
- [ ] ドラッグハンドル（上部中央バー）とタッチジェスチャーハンドラの実装。
  - `touchstart` で開始 Y 座標を記録。
  - `touchmove` で下方向へのドラッグ量をリアルタイムに `translateY` へ反映（上方向へは過剰移動を抑制）。
  - `touchend` で移動量が閾値（例: 80px）を超えている場合は `onClose()` を呼び出し、満たない場合は 0px にバウンス復帰。
- [ ] `footer` が指定された場合、最下部親指ゾーンに Sticky 固定。
- [ ] `BottomSheet.test.tsx` で開閉、下スワイプジェスチャーでのクローズ呼び出しを検証。
