## Implementation Logic

共通Editorの有効かつ空欄のrowに「未使用」を文字表示し、そのrowだけopacity-50で減光する。
既存row.slotKeyをReact keyに使い続け、ノードID/候補数/statusをkeyへ追加しない。
入力後は未使用文字と減光を解除。空文字のinputを別要素へ交換しない。
明示無効行は既存readonly/再有効化を保持し、未使用表示で明示無効に変更しない。
rowへ `data-testid={'mapping-slot-' + row.slotKey}` を付け、各slotを一意に観測可能にする。
input/候補popupは既存MappingNodeSelectorの同じDOMを利用し、このmoduleの変更は不要。

HTTP境界testの旧 `slot-input-v_101` / `mapping-row-1` selectorを現共通EditorのDOM契約へ置換する。
inputは `getAllByRole('textbox', {name:'ノードID'})` の2件を観測し、
rowは `mapping-slot-v_101` と `mapping-slot-v_201`。
旧master単位wrapperや旧modal独立inputを復活させてtestを通さない。
