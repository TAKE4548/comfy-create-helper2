## 3. 実装要件
1. `NodeRemapModal.tsx`:
   - 既存のワークフローリマッピング機構をベースに流用。
   - Positive (`Main_Positive_Prompt`) と Negative (`Negative_Prompt`) の 2 つのプロンプトロールのみにフィルタして表示。不要な非プロンプトロールは削除。
   - ワークフロー JSON から抽出したテキスト入力候補ノードをドロップダウン選択肢として提供。
   - 保存時: 既存 `workflow.mappings` の他ロールを維持しつつ、Positive/Negative の `master_id` に対応するマッピングを更新し、`workflowsApi.update(workflow.id, { mappings })` を呼び出して永続化。
2. `MatrixGenerationStep.tsx`:
   - ワークフロー選択エリアに Positive / Negative 対象ノード情報バッジ（Node ID, クラス名, タイトル）と「ノード再割当」ボタンを配置。
   - 3分割タグ入力欄の下部に全幅カードとして「④ ネガティブプロンプト (Negative Prompt)」入力枠（`TagChipEditor`）を追加。
   - ワークフロー選択時の初期値自動取得（Presets -> ノードテキスト -> 定型フォールバック。ただしユーザー入力済みの場合は維持）。
   - プロジェクト保存/更新時に `prompt_negative` を永続化。
   - ComfyUI バッチ投入時に解決された `positiveNodeId`, `negativeNodeId`, `negativePrompt` を渡して投入。
3. `MatrixGenerationStep.test.tsx`:
   - AC-1 〜 AC-5 を検証するテストケースを追加。
