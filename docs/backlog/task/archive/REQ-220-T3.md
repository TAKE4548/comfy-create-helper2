## 3. 実装要件 (Implementation Logic)
- [x] `frontend/src/pages/GeneratePage/components/DesktopLayout.tsx`:

    ```tsx
    key={activePromptTabMapping.role!}

    ```
- [x] `frontend/src/pages/GeneratePage/hooks/useGenerateAction.ts`:
