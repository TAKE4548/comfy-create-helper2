# REQ-315-T1: 和訳カードの取得状態と外側操作

**人間の設計レビュー後に実装する。対象は `frontend/src/components/TagChipEditor/TagChipTranslationCard.tsx` と `frontend/src/components/TagChipEditor/__tests__/TagChipTranslationCard.test.tsx` の2ファイル、推定変更200行以下。**

## 密閉コンテキスト

公開 Props と翻訳 API の型:

```tsx
export interface TagChipTranslationCardProps {
  text: string;
  onClose: () => void;
  anchorRect?: DOMRect | null;
}

export interface PromptTranslateRequest {
  prompt: string
  source_lang?: string
  target_lang?: string
  provider?: string
  repack?: boolean
}

export interface PromptTranslateResponse {
  translated_prompt: string
  meta: TranslateMeta
}
```

現行取得箇所（`TagChipTranslationCard.tsx`、`fetchTranslation` と effect）:

```tsx
  // Translation fetching
  const fetchTranslation = useCallback(async (promptText: string) => {
    if (!promptText || !promptText.trim()) {
      setTranslatedText('');
      setIsLoading(false);
      return;
    }
    setIsLoading(true);
    setError(null);
    try {
      const res = await translateApi.translatePrompt({
        prompt: promptText,
        source_lang: 'en',
        target_lang: 'ja',
        repack: false,
      });
      setTranslatedText(res.translated_prompt);
    } catch (err: any) {
      setError(err?.message || '和訳の取得に失敗しました');
    } finally {
      setIsLoading(false);
    }
  }, []);

  useEffect(() => {
    fetchTranslation(text);
  }, [text, fetchTranslation]);
```

現行外側判定（同ファイル、閉じる effect）:

```tsx
  // Close triggers: Escape key & Outside click
  useEffect(() => {
    const handleKeyDown = (e: KeyboardEvent) => {
      if (e.key === 'Escape') {
        onClose();
      }
    };
    const handleOutsideClick = (e: MouseEvent | TouchEvent) => {
      if (cardRef.current && !cardRef.current.contains(e.target as Node)) {
        onClose();
      }
    };

    window.addEventListener('keydown', handleKeyDown);
    document.addEventListener('mousedown', handleOutsideClick);
    document.addEventListener('touchstart', handleOutsideClick);
```

## 実装契約

1. Props に `menuRef?: React.RefObject<HTMLDivElement>` を追加する。外側判定は `cardRef` または `menuRef` に含まれるターゲットを内部操作とみなし、それ以外で `onClose` を呼ぶ。カード自身の閉じる・Escape・ドラッグ・コピーを維持する。
2. テキスト変更と再試行ごとに要求番号を更新する。新要求開始時に旧訳と旧エラーを消して取得中を表示し、応答・失敗・完了処理はいずれも現行番号だけ反映する。アンマウント時は番号を無効化する。
3. `translated_prompt` が空または空白のみの場合は失敗状態にし、10秒無応答はタイムアウトとして表示する。タイムアウト後に届いた結果は無視する。再試行はその時点の `text` を使う。期限タイマーは解決時とアンマウント時に必ず解除する。
4. `translateApi.translatePrompt({ prompt: text, source_lang: 'en', target_lang: 'ja', repack: false })` の契約を維持する。API 層の変更は行わない。

## 局所検証と完了条件

`cd frontend; npm run typecheck` と `cd frontend; npx vitest run src/components/TagChipEditor/__tests__/TagChipTranslationCard.test.tsx`。制御可能な Promise で新旧応答の逆転、旧失敗の後着、再試行競合、アンマウント、空応答、10秒タイムアウトを検証する。メニュー内の `mousedown` / `touchstart` は閉じず、真の外側操作では閉じる。既存のドラッグ・コピー・Esc・再試行テストを維持する。
