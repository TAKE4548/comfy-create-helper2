### 2.1 新設するプロセス実行ヘルパー仕様
```powershell
function Invoke-ProcessWithTimeout (
    [string]$filePath,
    [string]$arguments,
    [int]$timeoutSec = 3
) {
    $psi = New-Object System.Diagnostics.ProcessStartInfo
    $psi.FileName = $filePath
    $psi.Arguments = $arguments
    $psi.RedirectStandardOutput = $true
    $psi.RedirectStandardError = $true
    $psi.UseShellExecute = $false
    $psi.CreateNoWindow = $true

    $proc = New-Object System.Diagnostics.Process
    $proc.StartInfo = $psi
    try {
        if (-not $proc.Start()) {
            return [PSCustomObject]@{ ExitCode = -1; StdOut = ""; StdErr = "Failed to start process"; TimedOut = $false }
        }
        $stdoutTask = $proc.StandardOutput.ReadToEndAsync()
        $stderrTask = $proc.StandardError.ReadToEndAsync()

        if ($proc.WaitForExit($timeoutSec * 1000)) {
            $stdoutTask.Wait()
            $stderrTask.Wait()
            return [PSCustomObject]@{
                ExitCode = $proc.ExitCode
                StdOut = $stdoutTask.Result
                StdErr = $stderrTask.Result
                TimedOut = $false
            }
        } else {
            try {
                & taskkill.exe /PID $proc.Id /T /F 2>$null
                $proc.Kill()
            } catch {}
            return [PSCustomObject]@{
                ExitCode = -1
                StdOut = ""
                StdErr = "Command timed out after ${timeoutSec}s"
                TimedOut = $true
            }
        }
    } catch {
        return [PSCustomObject]@{
            ExitCode = -1
            StdOut = ""
            StdErr = $_.Exception.Message
            TimedOut = $false
        }
    } finally {
        $proc.Dispose()
    }
}

function Invoke-WslWithTimeout ([string]$bashCommand, [int]$timeoutSec = 3) {
    $wslPrefix = Get-WslDistroPrefix
    $args = "$($wslPrefix)bash -c `"$bashCommand`""
    return Invoke-ProcessWithTimeout "wsl.exe" $args $timeoutSec
}
```

## 3. 実装要件 (Implementation Logic)
- [x] `Invoke-ProcessWithTimeout` および `Invoke-WslWithTimeout` を `server-manager.ps1` 内に実装する。規定タイムアウトは 3 秒とし、超過時はプロセスを `taskkill /T /F` および `Kill()` で強制解放する。
- [x] `Get-WslComfyPids`: `Invoke-WslWithTimeout "pgrep -f 'python.*main.py'" 3` に置き換える。タイムアウト時は戻り値として空配列を返し、呼び出し元がタイムアウトを検知できるようにする（例: `$script:lastWslTimedOut = $true` または戻り値オブジェクト）。
- [x] `Test-WslAvailability`: `Invoke-WslWithTimeout "echo OK" 3` に置き換える。タイムアウト時は `$false` を安全に返却する。
- [x] `Stop-ComfyUIProcess`: `pkill` および `pkill -9` 呼び出しを `Invoke-WslWithTimeout`（3秒）でラップし、WSL ハング時も永久ブロックしないようにする。
- [x] `Show-Logs`: `tail` 呼び出しを `Invoke-WslWithTimeout`（3秒）でラップする。
- [x] `Get-StatusObject`: ComfyUI の状態判定において、WSL がタイムアウトした場合は `status = "TIMEOUT"`、`error = "WSL応答タイムアウト (3s)"` を設定し、FE や BE の判定を阻害せずに返却する。
- [x] `tests/unit/test_server_manager_wsl_timeout.ps1` を作成し、通常コマンドの成功・意図的なスリープコマンドの 2 秒タイムアウト・プロセスの強制終了を検証する。
