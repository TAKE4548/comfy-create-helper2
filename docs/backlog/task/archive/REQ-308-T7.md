# REQ-308-T7: Workflow textarea mappings in preset integration test fixtures

## Impacted Files
- `frontend/src/pages/GeneratePage/hooks/__tests__/useGeneratePageState.test.tsx`

## Hermetic Context
REQ-308-T1 intentionally defaults the prompt role allowlist to `[]`; the production source of prompt roles is `workflow.mappings` entries where `role` is set and `input_type === 'textarea'`. The full test suite showed two failures in this file where fixtures expected `positive_prompt` chips but the mocked workflow omitted mappings:
- REQ-163 preset switching: `loadPresetData` expected two args while it now receives defaults and an empty role list.
- REQ-198 bulk edit: expected parsed prompt chips although the fixture had no textarea mapping.

## Implementation
- Add `positive_prompt` textarea mapping to only the workflow fixtures for these two tests.
- Update call expectations to include the explicit `['positive_prompt']` allowlist.
- Do not alter production behavior or other test files.
