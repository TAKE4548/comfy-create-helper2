## 3. 実装要件 (Implementation Logic)
1. **`SearchableLoraSelect` コンポーネントの作成**:
   - `frontend/src/components/SearchableLoraSelect.tsx` を新規作成する。
   - トリガーとなるボタンをクリックした際に、絶対配置（`absolute`）のカスタムドロップダウンが開閉するようにする。外側をクリックした時に閉じるように制御（`useEffect` 等）。
   - ドロップダウン内部の最上部に、`sticky top-0 bg-surface z-10` で固定されたヘッダを設ける。
   - 固定ヘッダに以下のコントロールを配置する：
     - **フリーワード検索窓**（入力時に `model_name`、`file_path`、`description` に部分一致でフィルタリング。大文字小文字無視）。
     - **ベースモデルフィルタ**（React Query を用いて `baseModelsApi.list()` を呼び出し、取得したベースモデルを選択できるようにする。選択されたベースモデルに紐づくLoRAに絞り込む。LoRAの `target_base_model_ids` に対象のIDが含まれているもの、または未設定のもの）。
     - **カテゴリフィルタ**（React Query を用いて `loraCategoriesApi.list()` を呼び出し、取得したカテゴリを選択できるようにする。選択されたカテゴリに属するLoRAに絞り込む。LoRAの `category_id` を参照）。
   - リスト部分には、フィルタリングされたLoRAおよび未登録モデルの一覧を表示し、スクロール可能とする。

2. **`LoraStackEditor` のリプレイス**:
   - 既存の `<select>` 要素を `SearchableLoraSelect` に置き換え、propsを正しく渡す。
   - `activeBaseModelId` (現在選択されているワークフローのベースモデルID) を props から受け取り、初期フィルタとして機能するように連動させる。

3. **`ParamPanel` のリプレイス**:
   - LoRA選択用 select を `SearchableLoraSelect` に置き換える。
