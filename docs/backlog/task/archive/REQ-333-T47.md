# REQ-333-T47

実再現: localhost5173はGENERATION_SNAPSHOT受信、192.168.3.13:5173はHTTP403、同LAN8000は受信。Vite /api proxyのchangeOrigin:trueがupstream Hostを127.0.0.1:8000へ書き換え、browser Origin LAN5173とBEのexact same-origin照合が不一致。PC localhostは設定allowlistにより通る。

## Impacted Files
- frontend/vite.config.ts

## Correction

/api proxyはtarget127.0.0.1:8000とws:trueを維持し、元のHostとOriginを保持する。changeOrigin:falseを採用し、理由をコメントに残す。Origin自体の書換・BE全Origin許可・8188直接接続は行わない。/health設定は変更不要。GET API routingと配布8000経路は維持。

## Verification Command
```powershell
Set-Location frontend
npm run typecheck
```

Coordinatorが実稼働Vite自動再読込後、localhost5173/LAN5173/LAN8000でgeneration snapshotとSYSTEM_STATSを確認し、LAN5173への外部Originは403のままと確認する。低影響config変更でコピーをassertするunit testは追加不要。所有外編集禁止、他担当変更を巻き戻さない。サービスを手動停止しない。
