# REQ-377-T2: TagSetDetailModal モバイルボトムシート再構成・固定フッター・小型Cover・編集入口統一

## 1. 概要と目的
`TagSetDetailModal` をモバイル（幅 767px 以下）で下端起点のボトムシート（ヘッダー・単一縦スクロール本文・固定フッター）に再構成し、本文上部に小型 Cover＋Snapshot 件数を配置して画像ギャラリーサブビュー導線を提供する。さらにカードの編集アイコンと詳細内の Edit ボタンの双方が同一の `TagSetDetailModal` 編集モードを開くよう統一する（MUI-03, MUI-04, MUI-05, MUI-09, AC-1〜AC-8, AC-12〜AC-14）。

## 3. コンポーネント分類と制約 (<constraints>)
- **UI Archetype**: `Archetype 1: Modals & Overlays` / `Composite: Modal + Form + Media`
- **Surgical Constraints**:
  - `Modals & Overlays`: 下端起点ボトムシート (`modal-backdrop items-end md:items-center p-0 md:p-4`, `rounded-t-2xl`, `max-h-[90dvh] flex flex-col`).
  - `Scroll`: 本文単一スクロール (`overscroll-contain`, `flex-1 overflow-y-auto`). 親スクロール競合を遮断.
  - `Fixed Footer`: 本文外固定 (`flex-shrink-0 border-t border-[rgba(255,255,255,0.06)] px-5 py-3 bg-surface flex gap-3 pb-[calc(0.75rem+env(safe-area-inset-bottom,0px))]`).
  - `Action Placement`: 閲覧中 = 左 `Close` / 右 `Edit`、編集中 = 左 `Cancel` / 右 `Save` (MUI-04).
  - `Hit-Slop`: フッターボタンおよび小型 Cover は最小 44×44px タッチ領域 (`relative before:absolute before:-inset-2 before:content-['']`).
  - `Truncation`: タイトル・タグ表示に `min-w-0 flex-1 truncate` / `break-all` を指定.

## 5. 実装要件 (Implementation Logic)
1. `TagSetDetailModalProps` に `initialEditing?: boolean` を追加し、`const [isEditing, setIsEditing] = useState(Boolean(initialEditing))` で初期化する。
2. モバイルレイアウト（幅 767px 以下）のボトムシート化：
   - 外枠: `modal-backdrop items-end md:items-center p-0 md:p-4`
   - シート: `relative mt-auto md:my-auto w-full max-w-full bg-surface rounded-t-2xl md:rounded-2xl border border-[rgba(255,255,255,0.08)] shadow-2xl overflow-hidden max-h-[90dvh] md:max-h-[85vh] flex flex-col`
   - 上端ハンドルバー: `<div aria-hidden="true" className="mx-auto mt-2 h-1 w-10 rounded-full bg-zinc-600 md:hidden" />`
   - モバイル本文先頭: 小型 Cover サムネイル＋「Related Snapshots (N 件)」行を配置。タップで `isGalleryOpen = true` に切り替え、画像全件一覧を展開する。
   - 固定フッター（モバイル）: 閲覧中 = 左 `Close` / 右 `Edit`、編集中 = 左 `Cancel` / 右 `Save`（`md:hidden`）。
   - デスクトップ表示（`md:` 以上）: 既存の左右 2 列レイアウト（`md:grid-cols-2`）と右ペイン内ボタンを維持する。
3. `TagsPage.tsx` の編集入口統一：
   - カード右上の編集アイコン (`#tagset-edit-${id}`) クリック時、`setDetailInitialEditing(true); setSelectedTagSetForDetail(ts)` を呼ぶ。
   - カードクリック時は `setDetailInitialEditing(false); setSelectedTagSetForDetail(ts)` を呼ぶ。
   - `TagSetDetailModal` に `initialEditing={detailInitialEditing}` を渡し、双方が同一の編集画面を開くように統一する。
