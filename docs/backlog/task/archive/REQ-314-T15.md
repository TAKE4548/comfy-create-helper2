## Implementation Logic
- [ ] group prompt/dialogueはモデル常時可視。モデルheaderのtoggle/chevronはgroupなし互換だけにし、groupありでは閉じられるbuttonを残さない。
- [ ] 既存promptとparamsの二つの長いsectionを局所wrapper内へ収める。groupありのinner sectionは境界/背景を外し、prompt/dialogueに単一の外枠カードと単一buttonを設ける。既存JSXを全行移動/再インデントして変更行を増やさない。
- [ ] prompt/dialogueのbuttonはtype=button、aria-expanded、aria-controls付き。instance内IDはgroupまたはuseIdで一意、見出しは「プロンプト診断・生成の詳細設定」「セリフ生成の詳細設定」。
- [ ] groupedの内側prompt/params headerは出さず、共通bodyをhiddenでisExpandedPromptsへ同期。editor DOMを保持し非表示時focus不可。groupなしは既存三つの開閉props/handler動作を保つ。
- [ ] group translationでは余分な内側accordionを設けず、T4の外側詳細枠で3種editorをまとめて見せる。モデルとprompt/paramsは外側可視条件下で表示。未表示providerでmountを保持する責務はT4。
- [ ] PROMPT_LABELSのspeech3ラベルを「画像シチュエーション読み取りプロンプト (VLM)」「セリフ自動生成プロンプト (LLM)」「キャラクター口調変換プロンプト (LLM)」へ変更。画像理解/セリフ文章化/口調変換の短い補足を該当editorに添える。保存key/contentは変えない。
- [ ] 初期falseとv2永続化の責務はT7。T15でstorage/query/APIを新設しない。modelFooterはT3のmodel card内配置を維持。
