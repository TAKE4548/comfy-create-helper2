# REQ-412-T2: ヘッダーリソース詳細パネルへのComfyUIメモリ解放ボタン配置とE2E

## 1. 概要と目的

共通ヘッダーの `ResourceHoverMonitor` が表示する 2 つのパネル（640px 以上のホバーカード `resource-hover-card`、640px 未満のオーバーレイ `mobile-resource-overlay`）の末尾に「ComfyUI メモリ解放」ボタン群を追加する。送信・ガード・文言は T1 の共有フック `useComfyFreeMemory` を使う。ホバーカードは対話要素を含むため `role="tooltip"` を外し、内容を `role="group"` + `aria-label="リソース詳細"` の要素で包む（§4.2）。

## 4. 実装コンテキスト

### 4.1 T1 提供の契約（`frontend/src/hooks/useComfyFreeMemory.ts`）

```ts
export const FREE_MEMORY_OPERATION_KEY = 'comfy:free-memory'
export const FREE_MEMORY_MESSAGES: { pending: '解放要求を送信中'; accepted: '解放要求を受け付けました。空き容量は監視値で確認してください';
  unconfirmed: '要求結果未確認: 解放要求の結果を確認できません。状態を再取得します。操作は再送しません。'; failedPrefix: '解放要求に失敗しました: ' }
export interface FreeMemoryFeedback { kind: 'none' | 'pending' | 'accepted' | 'unconfirmed' | 'failed'; message: string }
export function tryBeginManagerOperation(key: string): boolean
export function endManagerOperation(key: string): void
export function resetManagerOperationStoreForTests(): void
export function useComfyFreeMemory(options?: { onAccepted?: () => Promise<unknown> | void }): {
  enabled: boolean; reason: string; pending: boolean; feedback: FreeMemoryFeedback; run: () => Promise<FreeMemoryFeedback | null>
}
```

理由文言: `Manager状態を確認できません。` / `別のサービス操作中です。` / `ComfyUIが停止中または状態不明です。` / `ComfyUIで生成中です。` / `ComfyUIのキューが空ではありません。` / `ComfyUIの実行状態が不明です。`。`run()` は内部で `useManagerStatus().refetch()` を 2 回呼び、その完了までロック（`pending`）を保持する。ヘッダーでは `onAccepted` を渡さない（QueryClientProvider に依存しないため）。

### 4.2 DOM 契約

```tsx
// HeaderFreeMemoryAction.tsx
export interface HeaderFreeMemoryActionProps { variant: 'desktop' | 'mobile' }
export function HeaderFreeMemoryAction({ variant }: HeaderFreeMemoryActionProps): React.JSX.Element
```

- ラッパー `data-testid="resource-free-memory"`（各パネルの**最終子要素**。上に `border-t` 区切り）
- ボタン `type="button"`、表示名・アクセシブル名「ComfyUI メモリ解放」、`data-testid="resource-free-memory-button"`、`disabled={!enabled || pending}`、`aria-busy={pending}`、pending 中は lucide `Loader2`（`animate-spin`、`aria-hidden`）、通常は `RefreshCw`（`aria-hidden`）
- 理由 `data-testid="resource-free-memory-reason"`（`!enabled && !pending` のとき `reason`）
- 結果 `data-testid="resource-free-memory-status"`、`role="status"`、`aria-live="polite"`、`feedback.message`
- ホバーカード: `HeaderDropdown` には `role` を渡さない（`role="tooltip"` を削除）。カードの children 全体を `<div role="group" aria-label="リソース詳細">` で包む（`HeaderDropdown` は `aria-label` を受け取れず、変更禁止のため）。デスクトップの `resource-free-memory` はこの group の最終子要素、モバイルは `mobile-resource-overlay` の最終子要素
