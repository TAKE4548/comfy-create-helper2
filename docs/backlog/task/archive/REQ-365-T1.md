```tsx
const TABS: ReadonlyArray<{ id: SettingsTabId; label: string; shortLabel: string; icon: LucideIcon }> = [
  { id: 'workflows', label: 'ワークフロー・モデル', shortLabel: 'モデル', icon: Workflow },

```
`className="inline-flex min-h-11 h-11 min-w-max snap-start items-center justify-center gap-1.5 px-3 md:min-w-0"`、tablist は `flex snap-x snap-mandatory overflow-x-auto md:grid md:grid-cols-5`。

## 変更内容
1. `shortLabel` を `'① モデル'`, `'② 呪文'`, `'③ セリフ'`, `'④ 翻訳'`, `'⑤ システム'` に変更（可視テキストのみ）。長い表示名 `label` は**変更しない**。`aria-label`（=`label`）に丸数字を**含めない**（既存テスト `not.toMatch(/[①②③④⑤]/)` を維持）。
2. 横スクロールタブ（モバイル）で選択タブが見える現行 `scrollIntoView` を維持。
3. タブボタンに `touch-action: manipulation` 相当の Tailwind `touch-manipulation` を追加（Gesture制約）。`snap-x snap-mandatory`/`min-h-11` は維持。

## テスト追加
- `SettingsTabBar.test.tsx`: `it('[REQ-365/AC-2] shows numbered compact labels below md while keeping unnumbered aria-labels', ...)` — 5タブの短縮ラベル `span.md\:hidden` テキストが上記と一致、`aria-label` は丸数字を含まない。`tablist` に `overflow-x-auto`/`snap-x`/`snap-mandatory`、各`tab`に `min-h-11` と `touch-manipulation`。
- `useSettingsTab.test.tsx`: `it('[REQ-365/AC-10] persists the active tab to prompt-surgeon-settings-active-tab on every selection', ...)` — Harnessでタブを順に選択し `window.localStorage.getItem('prompt-surgeon-settings-active-tab')` が最新ID。`localStorage.setItem` を例外化（`vi.spyOn(Storage.prototype,'setItem').mockImplementation(()=>{throw new Error('quota')})`）してもレンダリングが継続し `activeTab` が切り替わる。キー文字列は `LS_KEYS.SETTINGS_ACTIVE_TAB === 'prompt-surgeon-settings-active-tab'` を直接assert。

<constraints>
- Archetype 2: `shrink-0 whitespace-nowrap`（CSSで保証済み）, `overflow-x-auto`。タブラベルに `truncate` を使わない。
- Hit-Slop: 44px確保は既存 `min-h-11`（44px）。`min-w` はラベル幅で44px以上。
- フォントは `text-[11px]` 未満禁止。生 `vh` 禁止。新規グローバルセレクタ禁止。
</constraints>
