# REQ-333-T49

Managerがaction_in_progress.service='fe'を返すとServiceConnectionCardのserviceLabelがfrontendしか知らずundefinedになる。非活性理由をユーザーへ正しく表示するため、frontend/fe、backend/be、comfy/wsl、managerと全体allを表示名へ正規化する。未知名は値を表示しundefinedにしない。busyなら管理操作disabledは維持し、同時操作やAPI409を無視しない。生成通信には依存を追加しない。

## Impacted Files
- frontend/src/pages/SettingsPage/components/ServiceConnectionCard.tsx
- frontend/src/pages/SettingsPage/components/__tests__/ServiceConnectionCard.test.tsx

## Verification Command
```powershell
Set-Location frontend
npx vitest run src/pages/SettingsPage/components/__tests__/ServiceConnectionCard.test.tsx
npm run typecheck
```

TDDで全サービス稼働中でもfe/startが「Frontend起動処理中」の理由として表示され操作はdisabled、busy解除後は操作可能を確認。既存action payloadは維持。所有外編集禁止、他担当変更を巻き戻さない。
