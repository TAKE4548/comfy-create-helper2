## 3. 実装要件 (Implementation Logic)

### 3.1 `useGenerationStore.ts` の修正
1. **初期値取得**:
   - `storedWorkflowId` が `null` でない場合、`localStorage.getItem("prompt-surgeon-params-wf-" + storedWorkflowId)` から値の取得を試みる。
   - 取得成功時はそれをパースして `storedParams` に割り当てる。存在しない、またはエラー時は空のオブジェクト `{}` で初期化する。
2. **`setSelectedWorkflowId` アクション**:
   - 引数 `id` が `null` でない場合、`localStorage` から `prompt-surgeon-params-wf-{id}` を取得する。
   - 値が存在すれば、それをデシリアライズして `paramValues` 状態に適用する。存在しない場合は空のオブジェクト `{}` で `paramValues` を初期化する。
3. **`setParamValues` アクション**:
   - 更新された `values` を `paramValues` 状態に反映する。
   - 同時に、現在選択されている `selectedWorkflowId` があれば、そのID固有のキー `prompt-surgeon-params-wf-{selectedWorkflowId}` を使って `localStorage` に保存する。

### 3.2 `GeneratePage.tsx` の修正
1. **`useEffect` (ワークフロー切替時) の修正**:
   - `workflow` オブジェクトが利用可能になった際、まず `localStorage.getItem("prompt-surgeon-params-wf-" + workflow.id)` をチェックする。
   - キーが存在する場合は `setParamValues` でそのセッション値を復元し、以降のデフォルト値抽出処理はスキップする。
   - キーが存在しない場合のみ、`workflow.json_body` のマッピング情報からデフォルト値を抽出して `paramValues` に設定し、`localStorage.setItem("prompt-surgeon-params-wf-" + workflow.id, ...)` に保存する。
2. **デフォルト値保存ミューテーション (`saveDefaultParamsMutation`) の追加**:
   - React Query の `useMutation` を追加する。
   - 実行関数は `workflowsApi.update(workflowId, { json_body })` を呼び出す。
   - 成功時には、クエリキャッシュ `['workflow', selectedWorkflowId]` および `['workflows']` を無効化 (`invalidateQueries`) する。
3. **「デフォルト保存」ハンドラ (`handleSaveDefaultParams`)**:
   - 現在の `workflow.json_body` を複製し、`workflow.mappings` 定義に基づいて `paramValues` の現在値を各ノードの入力ウィジェットに上書きする。
   - `saveDefaultParamsMutation.mutateAsync` を呼び出してDBのワークフロー情報を更新する。
   - 成功後、localStorage の `prompt-surgeon-params-wf-{workflowId}` にも最新の `paramValues` を書き込む。
4. **「デフォルトにリセット」ハンドラ (`handleResetDefaultParams`)**:
   - `workflow.json_body` から各マッピングのデフォルト値を直接抽出し、`paramValues` および localStorage をそのデフォルト値で上書きする。
5. **UIコントロールエリアの追加**:
   - 左カラムの入力エリア上部（「LLM Audit」パネルのすぐ下）に、ワークフローが選択されている時に表示される設定管理カードを設置する。
   - カード内に「デフォルト保存」「デフォルトにリセット」ボタンを配置し、保存中はボタンを無効化（Disabled）してローディング表示にする。
   - UI は既存のプレミアムダークモードに合致したスタイル（`bg-surface-2/60`, `border-[rgba(255,255,255,0.06)]` 等）を使用すること。
