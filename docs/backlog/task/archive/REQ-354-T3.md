## Hermetic Context

`Workflow`は `{id:number,name:string,created_at:string,json_body:Record<string,unknown>,mappings:WorkflowMapping[]}`。
`WorkflowMapping`はid/master_id:number、node_id:string、variant_id?:number|null、role/param_name/input_type/display_name:string|null、fallback_param_names?:string[]|null。
`setSeedModeForMapping(mapping, paramValues:Record<string,string>, mode:'fixed'|'random')`がモードmetadataを返す。
`useGenerateAction(workflow)`はasync `handleGenerate()`/`handleGenerateSets()`を返す。

既存test位置（24行）:

```typescript
  it('rejects missing primary and fallback seed inputs before normal submission state changes', async () => {
    const fallbackMapping = { ...seedMapping, fallback_param_names: ['noise_seed'] }
    const missingWorkflow: Workflow = {
      ...workflow,
      json_body: { '3': { inputs: {} } },
      mappings: [fallbackMapping],
    }

    await useGenerateAction(missingWorkflow).handleGenerate()

    expect(store.submitGenerationBatch).not.toHaveBeenCalled()
    expect(store.setIsBatchSubmitting).not.toHaveBeenCalled()
    expect(store.setErrorToast).toHaveBeenCalledWith(expect.objectContaining({
      type: 'error', message: expect.stringContaining('Sampler Seed'),
    }))
  })

  it('rejects checked sets when the seed target is missing before any submission state changes', async () => {
    const fallbackMapping = { ...seedMapping, fallback_param_names: ['noise_seed'] }
    const missingWorkflow: Workflow = {
      ...workflow,
      json_body: { '3': { inputs: {} } },
      mappings: [fallbackMapping],
    }
```

beforeEachでstore.paramValues/batchSize/setsとsubmit mockをreset、afterEachでvi.restoreAllMocks。seedMappingは `{id:1,master_id:1,variant_id:2,node_id:'3',role:'Sampler_Seed',param_name:'seed',input_type:'seed',display_name:'Sampler Seed'}`。
batch errorは `${label}: seed入力を解決できません (node ${mapping.node_id}, 候補: ${candidates})`。primary→登録aliasの順でown keyを選び、graph referenceは拒否。
aliasのnull/undefined/[]は `fallback_param_names ?? []` で候補なし。primaryがなければ例外で全件拒否し、crashや未登録noise_seed推測をしない。既存resolverのnull testを再利用する。
