承認対象の内部接続（queryを条件分岐せず同順で呼ぶ）:

~~~tsx
const stageQuery = useQuery({
  queryKey: ['stage-masters'],
  queryFn: () => stageMastersApi.list(true),
  enabled,
})
const masterQuery = useQuery({
  queryKey: ['mapping-masters'],
  queryFn: () => mappingMastersApi.list() as Promise<(MappingMaster | MappingMasterV2)[]>,
  enabled: enabled && masters === undefined,
})
const resolvedMasters = masters ?? masterQuery.data ?? []
const resolvedStages = stageQuery.data ?? []
return enabled
  ? groupMappingsByStage(mappings, resolvedMasters, resolvedStages)
  : []
~~~

明示masters=[]をcacheで補わない。pending/errorでも最後のdataを使い、data無しだけ[]。返却値にquery statusを追加せず、入力・値・chipsを保持してfallbackへ渡す。disabledではcache有でも[]を返す。このobserverからfetchを開始せず、他observerの共有fetchをcancelしない。retry/staleTime等は既存QueryClient設定を継承し新規設定しない。Desktopは `(textMappings, mappingMasters, true)`、ParamPanelは `(visibleParamMappings, undefined, stageGrouping)`、Mobile/default=falseは元renderer。
