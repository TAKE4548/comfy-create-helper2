# タスクカード: REQ-180-T1

## 目的
1. セリフ編集モーダルのプレビュー領域の余白を削減し、ウィンドウサイズに応じてキャンバスをより大きく拡大表示する。
2. プリセット一覧において、「テキストなし（スタイル専用）」セクションを「テキストあり」セクションよりも上位/先頭に表示する。

## Acceptance Criteria
- [x] AC-1: `SpeechBubbleControls.tsx` において、`withoutTextPresets`（スタイル専用）が `withTextPresets`（テキスト付き）より前にレンダリングされること。
- [x] AC-2: `SpeechBubbleEditorModal.tsx` のプレビューエリアにおいて、固定上限 `500x500` をウィンドウサイズに応じた拡大（例: 幅最大 900px、高さ最大 720px）に拡張し、コンテナ余白（padding）をスリム化すること。
- [x] AC-3: `SpeechBubbleControls.test.tsx` にプリセットの描画順序（テキストなし先行）を検証するテストが追加され、パスすること。

