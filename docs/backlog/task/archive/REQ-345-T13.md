## Implementation Logic

- [ ] fixture:D=[A missing,B present]、BEのみC present/D missing/E unknown。初回復元→snapshot→差分→lazy確認settleで[B,C]一度ずつ、A/D/Eなし。
- [ ] B旧host/t、F同filename別subfolder/type、Cが応答待ち中live event到着。最新再比較でB/C重複0、F別行、既存B/CURL・相対順・選択維持。
- [ ] restore/snapshot到着順を両順で試験。非空canonical persist baselineがない場合はPOST0/fullGET0。自sessionfilter/Snapshottab有効でも全logical history knownを送る。unknown/nullsessionはownに追加0。
- [ ] 二page受信でBE順保持、max20pages/200検査とcapacitypartial、has_more循環不正response停止。new unknown自動probe0、existing unknown保持。
- [ ] 初回GET /comfy/history0、history-fetched全件置換0、全snapshot成功出力暗黙追加0。StrictMode/rerender/filter/sort/focusでresidual cycle再開始0。
- [ ] 503/timeout/network/malformed/leave遅延→既存deep equal、selection/modal保持、fallback/retry0。manual retryだけ1cycle再開。
- [ ] Snapshot/metadata/既存cleanup非干渉。実機Gate3はNetworkからPOSTknown/examined増分、full GETなし、表示差分、原画request数を証拠化。
