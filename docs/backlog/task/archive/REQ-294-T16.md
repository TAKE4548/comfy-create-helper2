## 密封コンテキスト: Editor差し替え位置

`index.tsx` の `useSceneSpeechGeneration` 呼び出しだけを標準transport変更箇所とする。既存 `setActiveMobileTab` / `applyPresetToBubbles` は保持する。

```tsx
  } = useSceneSpeechGeneration({
    snapshotId: currentSourceSnapshotId,
    primaryTagSetId,
    setBubbles,
    generateDraftApi: generateDraftApi ?? (async (payload) => {
      const res = await fetch('/api/speech/scene-draft', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(payload),
      });
      if (!res.ok) throw new Error(await res.text());
      return res.json();
    }),
    applyPresetToBubbles: applyPresetToBubbles ?? ((b) => b),
    setActiveMobileTab,
  })
```

`types.ts` 現状は `generateDraftApi?: (payload: SceneDraftRequest) => Promise<SceneDraftResponse>`。T14の `SceneSpeechStreamOptions` を `../../api/types` からimportし、optional第2引数を加える。`index.tsx` は `sceneSpeechApi` を `../../api/client` からimportし、既定値に `sceneSpeechApi.generateStream` を渡す。テスト内の一引数モックは型互換で維持できる。`SceneSpeechModal` のprops/描画やT2修復内容には触れない。
