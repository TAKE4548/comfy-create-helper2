## Implementation
- 両componentでT4 hookを起動しT3 formatを使用。labelを正確にlocalStorage/sessionStorageとし各推定量を別項目にする。失敗は取得不可、空は0.0 KiB。
- desktopはCPU/GPUを使用率だけ横並び1行、RAM/VRAM各1行、保存領域各1行。既存hardware4指標のラベル/値/--/警告色を維持。追加行は許容済み。元CPU/GPUのdetailとpct重複は残さない。
- mobileはhardware chip列+storage折返し列を同component内に置く。wrapperを縮小可能にし既存overflow-x-autoを有効に保つ。既存header親を改修する必要が生じたら所有範囲を勝手に拡張せず設計担当へ戻す。
- 両UIでdetails/summary『推定使用量の説明』をkeyboard/tapで開け、現在オリジン/現在タブとキー+値UTF-16×2 bytesの意味を本文で確認できるようにする。titleだけにしない。保存内容のキー名・値内容は表示しない。
