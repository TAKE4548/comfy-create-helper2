## 3. 実装要件 (Implementation Logic)
- [ ] `sanitize_and_tokenize` の正規表現パターンを純粋メタ構文のみに限定：
  `pattern = re.compile(r"<lora:[^>]+>|<hypernet:[^>]+>|embedding:[^\s,]+")`
  （※括弧構文は `unpack_tag` / `repack_tag` 側で処理するため保護対象から除外）
- [ ] `translate_prompt` の処理フローを刷新：
  1. `sanitized, tokens = sanitize_and_tokenize(prompt)`
  2. `load_danbooru_dict()` を呼び出しインメモリ辞書を確保。
  3. `SPLIT_PATTERN.split(sanitized)` で区切り記号を保持したままトークン列を取得。
  4. 偶数インデックス（チャンク）から空文字以外のものを抽出し、`unpack_tag` を適用。
  5. コア文字列に対して：
     - `__TOKEN_\d+__` の場合はそのままスキップ。
     - `DANBOORU_DICT` に存在する場合は即時定訳を採用（FuguMT 推論スキップ、`cached_chunks += 1`）。
     - 存在せず、かつ `TRANSLATION_CACHE` にある場合はキャッシュ採用（`cached_chunks += 1`）。
     - どちらにもない場合は `unique_missing` に追加し、推論プロバイダ（FuguMT 等）へバッチ要求。
  6. 取得した和訳コア文字列に対し、`repack` が True の場合は `repack_tag` で強度構文を再構築し、False の場合はコア文字列のまま採用。
  7. トークン列を `"".join(tokens)` で再結合し、元のピリオド・カンマ構造を維持。
  8. `restore_tokens(joined_prompt, tokens)` でメタ構文を復元。
- [ ] `backend/app/routers/translate.py` の `PromptTranslateRequest` に `repack: Optional[bool] = True` を追加し、`translate_prompt` に渡す。
