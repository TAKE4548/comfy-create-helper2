# REQ-308-T6: Store sync preset load に textarea allowlist を伝播

## Impacted Files
- `frontend/src/pages/GeneratePage/hooks/usePresetStoreSync.ts`
- `frontend/src/pages/GeneratePage/hooks/__tests__/usePresetStoreSync.test.ts`

## Hermetic Context
`UsePresetStoreSyncProps` includes `workflow: Workflow | undefined`. During initial sync it builds `defaultParams`, then calls:
```ts
if (currentStore.loadPresetData) {
  currentStore.loadPresetData(activePreset, defaultParams)
}
```
The store action's new signature is defined by REQ-308-T1 to accept an optional third prompt-role allowlist. `Workflow.mappings` has nullable `role` and `input_type`; only `role && input_type === 'textarea'` qualifies.

## Implementation
- Derive allowed textarea roles from `workflow?.mappings` and pass them in the store load call.
- If workflow/mappings are missing, pass an empty role list so non-prompt parameters remain raw.
- Add a store-sync regression with a dotted checkpoint and textarea prompt to ensure only the prompt receives chips.
