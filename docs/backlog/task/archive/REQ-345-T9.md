## Implementation Logic

- [ ] Dはall/own和集合からmissingを除く。不正URL既存は保持するが要求identityへ含めない。Snapshotレコードを受け取らない。
- [ ] 応答時の最新all/own/missingへ再比較。presentのみ、global Dにないものだけ追加。host/t違いは同一、subfolder/type違いは別。旧URLは保持。
- [ ] 追加ブロックはBE受信順で、複数pageはpriorAddedIdentitiesに基づき既存追加の直後へ後続pageを挿入する。既存行同士の相対順は変えない。live実行完了の新行を巻き戻さない。
- [ ] 全体へ全追加、自sessionへsession_id===clientIdのみ。不明/foreignをownに追加しない。既存200行優先、残slotだけ追加。existing>=200でも削除しない。
- [ ] 戻り値に選択/modal/Snapshot/metadataは含めない。差分absenceをmissingと推測しない。
- [ ] unit: empty集合の純粋merge（callerはbaselineなしskip）、同URL/旧host+t、同filename異subfolder/type、応答中C到着、二page順、asc reverse、capacity、unknown/missing除外、own/null/foreign。
