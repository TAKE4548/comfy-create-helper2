### REQ-162-T3: 一括Abortの完全停止化・複数セッション履歴自動同期の実装

#### 目的
「一括キャンセル」実行時にセッションフィルタやローカルキューの古い状態にかかわらず、バックエンドプロキシ経由で ComfyUI の全待機キューをクリアし割り込み中断を即座に発行する。また、WebSocket の `status` イベント（キュー残数変化）時に履歴を自動再取得し、PC で生成した画像がモバイル側のギャラリーにも自動同期されるようにする。

#### 対象ファイル
1. `frontend/src/store/useGenerationStore.ts`
2. `frontend/src/pages/GeneratePage/hooks/useGenerateAction.ts`

#### 実装詳細 (Specifications)

1. **`frontend/src/store/useGenerationStore.ts`**:
- `queuePrompt`:
  - `comfyApi.queuePrompt({ prompt: workflow, client_id: get().clientId })` を使用。
  - ComfyUI 側エラー時はエラーメッセージをトースト表示。
- `fetchQueue`:
  - `comfyApi.getQueue()` を呼び出し、ストア内の `queueRunning`, `queuePending` を更新。
- `cancelAllJobs`:
  - `get().abortSubmission()` を即座に実行。
  - `comfyApi.deleteQueue({ clear: true })` を呼び出して ComfyUI の待機キューを一括パージ（セッション ID で除外しない）。
  - `comfyApi.interrupt()` を呼び出して実行中ジョブを即時中断。
  - 状態リセット (`activeBatch: null`, `isGenerating: false`, `currentPromptId: null`, etc.)。
  - `await get().fetchQueue()`。
- `fetchHistory`:
  - `comfyApi.getHistory()` を呼び出し。
  - 取得した画像 URL リストを `comfyHistoryImages` に更新。
  - `filterOwnSession` が OFF の場合は全画像を、ON の場合は自 `clientId` 画像を `batchImages` にマージ。
- WebSocket `status` ハンドラ:
  - `case 'status':` 受信時に `get().fetchQueue()` を実行し、直前のキュー数から減少している場合（ジョブ完了時）は `get().fetchHistory()` を連動トリガー。

2. **`frontend/src/pages/GeneratePage/hooks/useGenerateAction.ts`**:
- `handleGenerateSets`:
  - `abortController.signal.aborted` 検知時のクリーンアップ。
  - `checkedSets.length === 0` の場合にユーザーに「生成対象のセットが選択されていません」とトースト通知を表示。
