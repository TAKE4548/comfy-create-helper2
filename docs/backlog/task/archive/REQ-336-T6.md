# REQ-336-T6: ワークフロー配線画面: 完全データ駆動型アダプティブ配線UI

## 1. 概要と目的
ハードコードされた1段/2段サンプラ分岐を撤廃し、ワークフローノード情報と全 `stage_masters` の `search_keywords` を動的走査・照合して、合致ノードが存在するステージ（およびシステム必須ステージ）のみを展開する完全データ駆動型アダプティブ配線UIを実装する。合致ノードが0件のステージは自動非表示化し、空行や不要な未割当警告を完全に排除する。

### 3.1 アダプティブ判定アルゴリズムシグネチャ
```typescript
// frontend/src/utils/workflowAdaptiveStageDetector.ts
export interface ActiveStageInfo {
  stage: StageMaster
  matchingNodesCount: number
  matchedNodeIds: string[]
  isAlwaysVisible: boolean // stage.is_builtin または key === 'main' 等のシステム必須
}

export function detectActiveStages(
  workflowJson: Record<string, any> | null | undefined,
  stages: StageMaster[]
): ActiveStageInfo[] {
  if (!workflowJson || typeof workflowJson !== 'object') return []
  // 1. 各 stage の search_keywords と node._meta?.title / class_type を安全に照合 (dirty node try-catch/null guard)
  // 2. isAlwaysVisible (stage.is_builtin || stage.key === 'main') は matchingNodesCount === 0 でも常時バイパス展開
  // 3. それ以外のステージは matchingNodesCount > 0 のみ展開 (count === 0 は完全非表示)
}
```

## 4. 実装要件 (Implementation Logic)
- [ ] `workflowAdaptiveStageDetector.ts` を作成：
  - ワークフローノードのメタデータと各 StageMaster の検索キーワードを安全に走査（`_meta` 不在や不正型ノードのガード付き）。
  - `isAlwaysVisible` (システム必須) ステージはノード数 0 件でも常に展開し、それ以外のカスタムステージは合致ノード 0 件時に自動非表示。
- [ ] `AdaptiveWorkflowWiring.tsx` を作成：
  - `useMemo` による走査結果のメモ化を徹底し、不要な再計算ボトルネックを排除。
  - 各ステージタブ内に、該当ステージのバリアントスロットのみを表示（空スロットや無関係な警告を排除）。
  - ノード選択ドロップダウンにおいて、ステージキーワードに合致する候補ノードを優先ハイライト。
  - 物理配線は数値の `variant_id` でバインド・保存。
- [ ] `WorkflowConnectionSection.tsx` のインライン配線設定部分を `AdaptiveWorkflowWiring` に統合し、1段・2段・3段以上・リージョン分割ワークフローのすべてで破綻なく適応描画されるように改修。
