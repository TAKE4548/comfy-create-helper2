# Task Card: REQ-248-T3

## Context & Responsibility
`frontend/package.json` の `devDependencies` に `openapi-typescript` (`^7.13.0`) を追加し、保存済み `backend/openapi.json` から TypeScript 型定義 `frontend/src/api/schema.ts` を生成する npm スクリプト (`openapi:generate`) および非更新同期検査スクリプト (`openapi:check`) を導入する。初回実行により `frontend/src/api/schema.ts` を出力し、`--check` による未同期検出を検証する (AC-2, AC-4)。

本 Task Card は実装作業における唯一のセマンティック仕様書（Sole Semantic Specification）であり、外部の親 PBI や設計文書の閲覧に依存せず完結して作業を実施すること。
