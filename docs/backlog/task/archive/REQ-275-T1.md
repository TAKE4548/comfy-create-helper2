```python
def read_log_file(filename: str, tail_lines: int = 200) -> tuple[bool, str, int]:
    target = LOGS_DIR / filename
    if not target.exists():
        return False, "ログファイルはまだ生成されていません (サービス未起動)", 0
    try:
        try:
            with open(target, "r", encoding="utf-8") as f:
                lines = f.readlines()
        except UnicodeDecodeError:
            with open(target, "r", encoding="cp932", errors="replace") as f:
                lines = f.readlines()
        tail = lines[-tail_lines:] if len(lines) > tail_lines else lines
        return True, "".join(tail), len(lines)
    except Exception as e:
        return False, f"ログ読み込みエラー: {e}", 0
```

- [x] `server_api.py` に `get_action_timeout(action: str, service: str = "", config: Optional[dict] = None) -> int` を新設する:
  - `restart`, `reboot-service`:
    - `service.lower() in ["backend", "be"]`: 35
    - `service.lower() in ["comfy", "wsl"]`: 50
    - `service.lower() in ["frontend", "fe"]`: 35
    - `not service` または `service.lower() == "all"`: 90
  - `start`:
    - `service.lower() in ["backend", "be", "frontend", "fe"]`: 25
    - `service.lower() in ["comfy", "wsl"]`: 35
    - `not service` または `service.lower() == "all"`: 60
  - `stop`:
    - `not service` または `service.lower() == "all"`: 25
