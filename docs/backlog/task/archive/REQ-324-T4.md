# REQ-324-T4: API Backward-Compatibility Re-export Hub (client.ts)

## 1. 概要と目的
`frontend/src/api/client.ts` を、新設した `core/` および `domains/` からの透過的な集約 re-export ハブへとリファクタリングする。既存のフロントエンド全コンポーネント・フック・テストが `import { ... } from '@/api/client'` または `../api/client` を 1 行も修正することなく動作する 100% 後方互換性を保証する。

## 2. ターゲット識別
- **対象ファイル**:
  - `frontend/src/api/client.ts` (リファクタリング)
  - `frontend/src/api/__tests__/clientReExport.test.ts` (新規作成)
- **対象シンボル**:
  - `BASE_URL`, `SceneSpeechStreamError`
  - `workflowsApi`, `mappingMastersApi`, `snapshotsApi`, `albumsApi`, `lorasApi`, `tagSetsApi`, `loraCategoriesApi`, `tagsetCategoriesApi`, `auditApi`, `llmPromptsApi`, `configApi`, `fontsApi`, `workflowPresetsApi`, `bypassProfilesApi`, `paramSyncGroupsApi`, `baseModelsApi`, `checkpointMappingsApi`, `paramTypeMastersApi`, `speechBubblePresetsApi`, `speechTonePresetsApi`, `comfyApi`, `translateApi`, `speechBatchApi`, `promptMetadataApi`, `settingsApi`, `datasetApi`, `trainingApi`, `benchmarkApi`
  - 型定義: `PromptMetadataRead`, `VramSettings`, および `./types` 由来の全型
