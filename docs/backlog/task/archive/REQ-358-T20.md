### Required Contract

```text
MappingMaster legacy/V2 Create/Read: default_enabled boolean, omission default true
MappingMaster V2 Update: default_enabled optional boolean, omission preserves current value
Explicit request null/nonboolean: 422 (strict validation)
GET /api/mapping-masters: array<MappingMasterV2Read>, includes disabled masters
GET /api/mapping-masters/{id}: MappingMasterV2Read
POST /api/mapping-masters: actual V2 Create -> V2 Read
```
