## 3. 実装要件 (Implementation Logic)
### 3.1 `HistoryModalPreview.tsx` の新規作成
- React関数コンポーネント `HistoryModalPreview` を定義する。
- Propsの定義:
  ```typescript
  interface HistoryModalPreviewProps {
    isOpen: boolean;
    onClose: () => void;
    images: string[]; // 画像URLの配列
    currentIndex: number;
    onChangeIndex: (index: number) => void;
    snapshotIds?: (number | null)[]; // 対応するデータベーススナップショットIDがあれば渡す
  }
  ```
- モーダルの全体スタイル: `fixed inset-0 z-50 bg-black/95 flex flex-col`
- 右上の閉じるボタン:
  - `absolute top-4 right-4 z-50 p-2 rounded-full bg-white/10 hover:bg-white/20 text-white/80 transition-colors`
  - ボタンを押したとき、または画像外の背景エリア（画像コンテナの余白等）をタップした際に `onClose()` を呼び出す。
- スワイプジェスチャの検知:
  - `onTouchStart`, `onTouchMove`, `onTouchEnd` を画像表示領域 (`height: '60vh'`) にアタッチする。
  - 左フリック (スワイプ距離 > 50px) で `currentIndex + 1` (配列の範囲内) へ、右フリック (スワイプ距離 < -50px) で `currentIndex - 1` へ切り替える。
- メタ情報パネル:
  - 画像領域の下部に `flex-1 overflow-y-auto p-5 bg-surface border-t border-[rgba(255,255,255,0.06)]` のメタ情報スクロールパネルを設ける。
  - `snapshotIds[currentIndex]` が有効な場合、`useQuery` を用いて `snapshotsApi.get(id)` からデータを取得し、以下の項目を表示する。
    - **Prompt**: ポジティブプロンプト
    - **Negative Prompt**: ネガティブプロンプト
    - **CFG Scale**
    - **Steps**
    - **Seed**
    - **Loras & Tag Sets**: 適用されている LoRA やタグセットの一覧
  - スナップショットIDが無い一時生成画像の場合は、その旨または現在の設定値を控えめに表示する。

### 3.2 `GeneratePage.tsx` への適用
- ヘッダー (`bg-surface-2` の `div`) の直下に、`isGeneratingHere && progress` が有効な場合のみ表示されるプログレスラインを挿入する。
  ```tsx
  {isGeneratingHere && progress && (
    <div className="w-full bg-surface-2 border-b border-[rgba(255,255,255,0.06)] px-4 py-1.5 flex items-center justify-between gap-2 text-[10px] text-zinc-400">
      <div className="flex items-center gap-1.5 min-w-0">
        <Loader2 size={10} className="animate-spin text-accent-green flex-shrink-0" />
        <span className="truncate">Generating...</span>
      </div>
      <div className="flex items-center gap-2 flex-1 max-w-[150px]">
        <div className="h-1 bg-surface-2 rounded-full border border-white/5 overflow-hidden flex-1">
          <div
            className="h-full bg-accent-green progress-shimmer transition-all duration-200"
            style={{ width: `${progress.percentage}%` }}
          />
        </div>
        <span className="font-mono text-accent-green whitespace-nowrap">{progress.percentage}%</span>
      </div>
    </div>
  )}
  ```
- 履歴サムネイルストリップのサムネイルボタン (`onClick`) にて、モバイル表示時は直接 `selectedImg` を更新するだけでなく、全画面モーダルを開く状態にする。
- モーダル用のステートを `GeneratePage` に追加する:
  - `isModalPreviewOpen: boolean`
  - `modalPreviewIndex: number`
- `HistoryModalPreview` コンポーネントを配置し、`displayImages` を画像配列として渡す。

### 3.3 `HistoryPage.tsx` への適用
- 各スナップショットカード (`snap-card-{id}`) の `onClick` ハンドラを修正し、モバイル幅（または通常のクリック動作時）に全画面プレビューモーダルを開くようにする。
- 状態管理として `isModalPreviewOpen` と `modalPreviewIndex` を追加。
- `HistoryModalPreview` に、`snapshots` の画像パスの配列とスナップショットIDの配列を渡して表示する。
