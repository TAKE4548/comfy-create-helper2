~~~~md
## 2. デスクトップレイアウト (`DesktopLayout`)

画面最上部グローバルヘッダー + 全幅プリセットタブバー + 入力左ペイン/プレビュー右ペイン構成。幅800pxでは入力ペイン330pxを確保し、右側の永続ActionBarとプレビューを維持する。
~~~~

上記は正本の冒頭24行を抽出した文脈抜粋であり全文置換用ではない。
正本末尾に「GeneratePage回帰テスト (REQ-344)」を追記する。

契約:
- 両layoutのworkflow未ロード中はdisabled、ロード成功後enabled。
- preset初期同期前はautosaveしない。同期後positiveを保持し、変更時は1000ms debounceで保存。
- テストは毎case fresh API実装/store/query/timer/storageで隔離する。
- AC-1は既定 npm test 連続5回で対象全ケースPASS。
- Test case数は既存13＋追加ケース。実測最終件数を記す。

coordinator提供ファイル:

JSON項目は run, started_at, finished_at, exit_code, log。
ログからtarget PASS/FAIL、test件数、timeout/unhandled errorsを取得する。

