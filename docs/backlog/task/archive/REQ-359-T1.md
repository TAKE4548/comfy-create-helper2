# REQ-359-T1: Generate hookのworkflow参照とAnima更新を安定化

## 1. 概要と目的
GeneratePage初期化時のReact更新ループを止める。表示用workflowの参照を安定化し、Anima判定のstore更新を値が変わるときの1回に限定する。無効mappingのfilter契約とraw workflow保持は維持する。

## 2. ターゲット識別
- **対象ファイル**: `frontend/src/pages/GeneratePage/hooks/useWorkflowManagement.ts`
- **テストファイル**: `frontend/src/pages/GeneratePage/hooks/__tests__/useWorkflowManagement.seed.test.ts`, `frontend/src/utils/__tests__/wiringStageGroups.test.ts`
- **対象シンボル**: `useWorkflowManagement`
- **行番号目安**: raw workflow query後の `generationWorkflow` 導出と Anima Detection effect

export function generationWorkflow<T extends MappingWorkflow>(raw: T): Omit<T, 'mappings'> & {
  mappings: T['mappings'][number][]

## 4. 実装要件 (Implementation Logic)
- [ ] `generationWorkflow(rawWorkflow)` をraw workflow参照に対して `useMemo` し、同じraw入力時の派生workflow参照を再利用する。
- [ ] `isAnimaMode` をZustandから購読し、ローカルmode stateを重複して持たない。`setIsAnimaMode` は `useCallback` で安定させ、現在のstore値からfunctional updateを解決し、差がある場合だけstore actionを1回呼ぶ。
- [ ] `generationWorkflow(rawWorkflow)` を `useMemo` し、Anima effectの依存はselectedWorkflowId、memoized workflow、baseModels、stable setterとする。loading中は更新せず、manual mode変更はeffectを起動しない。
- [ ] 無効mappingは生成用cloneのみから除外し、raw workflow / `mapping_slot_states` を変更しない。
