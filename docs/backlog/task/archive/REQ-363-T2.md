# REQ-363-T2: メインプレビュー領域: 現行の固定42vhスクロール必須の解消 ＆ タップ手動トグルによる「生成キュー継続」最優先設計

## 1. 概要と目的
### メインプレビュー領域: 現行の固定42vhスクロール必須の解消 ＆ タップ手動トグルによる「生成キュー継続」最優先設計
- 初期状態をコンパクト（約 105px）に固定: 画面を開いた瞬間にプロンプト入力欄がファーストビューに収まり、スクロールなしで即座にタグ編集に着手可能。
- タップによる手動トグル切替: プレビュー領域をタップすることで、[コンパクト: 105px] ⇔ [標準プレビュー: 220px/42vh] を手動トグル（role="button", tabIndex=0, Enter/Space, aria-expanded）。
- 生成開始時もコンパクト維持（編集継続最優先）: 生成が始まってもプレビューは自動展開せずコンパクト状態を維持。sticky プログレス行（22px）のみで進行を知らせ、連続して次のプロンプトを編集・キュー投入可能。
- 全画面モーダル拡大は2段階タップ: 標準プレビュー状態で再度タップ（または拡大ボタン）で全画面モーダルへ展開。
