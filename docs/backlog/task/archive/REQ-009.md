## 3. 実装要件 (Implementation Logic)
1. **Zustand ストア (`frontend/src/store/useGenerationStore.ts`) の新規作成**:
   - `zustand` から `create` をインポートし、`localStorage` と自動同期するグローバルストアを実装。
   - ストア初期化時に `clientId` が `localStorage` になければランダム生成して保存。
   - `initialize()` メソッド内で ComfyUI の `/config` をフェッチして WebSocket を初期化。
   - `/history` および `/queue` をフェッチして、切断時の完了画像の回収および進行中ジョブの進捗復元（再アタッチ）を処理。
   - トグル `filterOwnSession` によるフィルタリング結果（自身が生成した画像のみ / 他セッションを含む全画像）を適用して UI に提供。

2. **アプリ全体でのストア初期化 (`frontend/src/App.tsx`)**:
   - `App.tsx` にて `useGenerationStore` の `initialize()` を `useEffect` で呼び出す。

3. **生成画面の置換 (`frontend/src/pages/GeneratePage.tsx`)**:
   - `paramValues` 等のローカルステートと `useComfyWebSocket()` 呼び出しを `useGenerationStore` からの値とアクションに置換。
   - 履歴ストリップ付近に「自セッションのみ表示」のトグルスイッチ（トグルのラベル: `自セッションのみ表示`）を配置。
   - 他セッションが生成中の場合、画面上に「他セッションで生成中...」という進捗状況の補助表示を出す。
