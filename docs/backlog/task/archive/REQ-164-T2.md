### REQ-164-T2: 他セッション生成中の進捗バー・キュー数可視化とUIステート改善

#### 目的
他端末・セッションでジョブが実行中である場合にも、モバイル/デスクトップ画面上で「他セッションで生成中...」というステータス、実行中ノード名、全体キュー数がプログレスバー領域に明確に表示され、フィルムストリップ（生成履歴）でも全履歴へのアクセスが容易に行えるようにする。

#### 対象ファイル
1. `frontend/src/pages/GeneratePage/hooks/useGeneratePageState.ts`
2. `frontend/src/pages/GeneratePage/components/DesktopLayout.tsx`
3. `frontend/src/pages/GeneratePage/components/MobileLayout.tsx`
4. `frontend/src/pages/GeneratePage/hooks/__tests__/useGeneratePageState.test.tsx`

#### 実装指示 (Implementation Steps)

1. **状態判定・キュー集計の改善 (`useGeneratePageState.ts`)**:
   ```typescript
   const isGeneratingHere = store.isGenerating && (
     store.activeClientId === clientId ||
     (store.activeBatch !== null && store.activeBatch.some(j => j.status === 'generating' || j.status === 'pending'))
   )

   const isOtherSessionGenerating = store.isGenerating && !isGeneratingHere

   const allQueueCount = useMemo(() => {
     return store.queueRunning.length + store.queuePending.length
   }, [store.queueRunning, store.queuePending])

   const totalQueueCount = useMemo(() => {
     if (!store.filterOwnSession) return allQueueCount
     const filterJob = (job: any) => job[3]?.client_id === clientId
     return store.queueRunning.filter(filterJob).length + store.queuePending.filter(filterJob).length
   }, [store.queueRunning, store.queuePending, store.filterOwnSession, clientId, allQueueCount])
   ```

2. **プログレスバー領域のUI改善 (`DesktopLayout.tsx` & `MobileLayout.tsx`)**:
   - `isGeneratingHere ? (...) : isOtherSessionGenerating ? (...) : (...)` の3分岐構造に改修。
   - `isOtherSessionGenerating` 時の表示内容:
     - ステータスバッジ: 「他セッションで生成中...」（パルスアニメーション付き）
     - 実行中ノード: `実行中: ${currentNode?.name || '処理中...'}`
     - プログレスバー: シマー付きアニメーションバー（インジケーター）
     - キュー情報: `Queue: ${allQueueCount} (他セッション)`（クリックでジョブ管理モーダルを開く）
     - 経過時間: `経過: ${elapsedTime}秒`

3. **フィルムストリップ（履歴一覧）の案内改善**:
   - `filterOwnSession: true` かつ `displayImages.length === 0` かつ `comfyHistoryImages.length > 0` の場合:
     - 「他セッションの履歴（${comfyHistoryImages.length}件）があります」メッセージと「自セッションのみ表示を解除」ボタンを表示。

4. **単体テスト作成 (`useGeneratePageState.test.tsx`)**:
   - **Test 1**: `store.isGenerating = true` かつ `activeClientId !== clientId` の際、`isOtherSessionGenerating` が `true`、`isGeneratingHere` が `false` になること。
   - **Test 2**: `allQueueCount` が全セッションのジョブ数を集計し、`totalQueueCount` が `filterOwnSession` に応じて切り替わること。
   - **Test 3**: `filterOwnSession = false` の際に `displayImages` が `comfyHistoryImages` を返すこと。
