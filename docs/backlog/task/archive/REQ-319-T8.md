# REQ-319-T8: Step 2 キュレーションサムネイルグリッド・自動デカップリングキャプション・単発リロール・ペア出力

## 1. 概要と目的
Step 1 で生成された20枚の素材画像を一覧表示するサムネイルグリッドを構築し、APPROVED / REJECTED の合否判定を行う。また、身体的特徴タグと専用服装タグを自動消去（ストリップ）してキャラ・衣装トリガーへ置換する `captionDecoupler.ts` を実装し、サムネイルごとの単発リロール（↺）および画像＋.txtペアファイルの一括エクスポートを可能にする。

## 2. 密閉コンテキスト (Hermetic Context)

### 2.1 デカップリング変換ユーティリティ仕様 (`captionDecoupler.ts`)
```typescript
export interface DecoupleParams {
  rawPrompt: string
  characterTrigger: string
  outfitTrigger: string
  physicalTags: string[]
  exclusiveOutfitTags: string[]
  isDefaultOutfit: boolean
}

export function decoupleCaption(params: DecoupleParams): string {
  const { rawPrompt, characterTrigger, outfitTrigger, physicalTags, exclusiveOutfitTags, isDefaultOutfit } = params
  let tags = rawPrompt.split(',').map(t => t.trim()).filter(Boolean)
  
  // 1. Strip physical tags
  const physicalLower = new Set(physicalTags.map(t => t.toLowerCase()))
  tags = tags.filter(t => !physicalLower.has(t.toLowerCase()))

  // 2. Strip outfit tags if default outfit slot
  if (isDefaultOutfit) {
    const exclusiveLower = new Set(exclusiveOutfitTags.map(t => t.toLowerCase()))
    tags = tags.filter(t => !exclusiveLower.has(t.toLowerCase()))
    return [characterTrigger, outfitTrigger, ...tags].join(', ')
  } else {
    // Alt outfit slot: keep alt tags, never inject outfitTrigger
    return [characterTrigger, ...tags].join(', ')
  }
}
```

### 2.2 単発リロールロジック (`CuratorGrid.tsx`)
```typescript
const handleSingleReroll = async (item: DatasetItem) => {
  const newSeed = Math.floor(Math.random() * 1000000000)
  updateItemStatus(item.id, 'REROLLING')
  // Direct ComfyUI prompt call with identical raw_prompt and new seed
  const res = await executeComfyPrompt(item.raw_prompt, newSeed)
  updateItemImage(item.slot_index, res.image_path)
  updateItemStatus(item.id, 'APPROVED')
}
```

## 3. 実装要件 (Implementation Logic)
1. **`frontend/src/pages/DatasetStudioPage/utils/captionDecoupler.ts`**:
   - `decoupleCaption` 関数を実装。身体的特徴タグを完全消去してキャラトリガーへ置換。本命衣装行では専用服装タグを消去して衣装トリガーへ置換。別衣装行では別衣装タグを維持し衣装トリガーは一切含めない。
2. **`frontend/src/pages/DatasetStudioPage/components/CaptionEditorCard.tsx`**:
   - デカップリングされたキャプションを表示し、ユーザーによる手動オーバーライド編集（textarea）を可能にする。
3. **`frontend/src/pages/DatasetStudioPage/components/CuratorGrid.tsx`**:
   - 20枚のスロット一覧（サムネイル、スロット番号、採用/除外バッジ、リロールボタン ↺、キャプション編集カード）。
   - 「学習用フォルダ一括出力」ボタンを配置し、`datasetApi.exportDataset` を呼び出して画像＋.txtペアファイルを書き出し。
