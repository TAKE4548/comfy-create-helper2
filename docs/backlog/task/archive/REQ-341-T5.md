# REQ-341-T5: Tags・History・Settings画面ヘッダー共通化および左クラスタリング適用

## 1. 概要と目的
Tags、History、Settings の3画面においてヘッダーを `PageHeader` に統一・最新化し、高さ50px固定・統一タイポグラフィ・アイコン規格を適用するとともに、主要操作の左クラスタリングを完了させる。これにより全6画面のヘッダー統一が100%達成される。
AC-1（全6画面共通50pxヘッダー・デザイン統一）、AC-2（Tags, History, Settings画面の左クラスタリング）を担保する。

## 2. ターゲット識別
- **対象ファイル**:
  - `frontend/src/pages/TagsPage.tsx`
  - `frontend/src/pages/HistoryPage/index.tsx`
  - `frontend/src/pages/SettingsPage.tsx`
- **対象シンボル**:
  - `TagsPage`: 独自ヘッダー `div` を `PageHeader` に移行
  - `HistoryPage`: 既存 `PageHeader` を新仕様（左クラスタリング actions）に合わせて再構成
  - `SettingsPage`: 独自ヘッダー `div` を `PageHeader` に移行し、タブチップバーを左クラスタまたはヘッダー内に統合
