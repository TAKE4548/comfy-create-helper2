## 変更内容
1. 外側の `fixed inset-0 ...` と内側パネル（`max-w-2xl bg-zinc-900 border ... max-h-[90vh] overflow-hidden`）を撤去し置換:
```tsx
return (
  <Modal
    isOpen={isOpen}
    onClose={onClose}
    size="lg"
    ariaLabel="ステージ管理 (Stage Manager)"
    sheetMaxHeightClass="max-h-[85dvh]"
  >
    {/* Header: 既存。h2 id="stage-manager-title" は維持、className に shrink-0 と text-zinc-100 */}
    <div className="p-4 md:p-6 overflow-y-auto overscroll-contain space-y-4 flex-1 min-h-0 text-zinc-100">…既存Content…</div>
    {/* Footer: 既存。className に shrink-0 */}
  </Modal>
)
```
   - `ariaLabel` は見出し文言と同一（既存 `findByRole('dialog', { name: /ステージ管理/ })` を維持）。
   - **画面上に `/ステージ管理/` を含む可視テキストを増やさない**（`workflowMappingIntegration.test.tsx` が `findByText(/ステージ管理/)` を単一要素として期待する。`aria-label` は属性でありテキストに含まれないため、ヘッダh2のみが一致する状態を維持）。
   - 追加の `pb` 禁止（Modalが safe-area を提供）。Escapeを新たに有効化（旧実装には無し）。
2. **44pxタッチターゲット**（モバイル。デスクトップ見た目は不変）:
   - 閉じる(`aria-label="閉じる"`、X): `inline-flex items-center justify-center min-h-[44px] min-w-[44px] touch-manipulation`。
   - 編集/削除アイコンボタン(`aria-label="{name} を編集"` / `"{name} を削除"`、現行 `p-1.5`): `inline-flex items-center justify-center min-h-[44px] min-w-[44px] touch-manipulation`（`md:min-h-0 md:min-w-0 md:p-1.5` でデスクトップ維持可）。**aria-label は変更しない**（既存テストが `通常 を削除` / `Rough を編集` で参照）。
   - 「新規ステージ追加」、追加/編集フォームの「保存」「キャンセル」「一括置換を実行」等、ガード内「このステージを無効化する」、フッタ「閉じる」: `min-h-[44px] touch-manipulation`（`md:min-h-0` 可）。**ボタンの可視名は変更しない**（テストが `name: '保存'` 完全一致）。
   - `input`: `min-h-[44px] md:min-h-0`。追加フォームの `grid grid-cols-3` は、狭幅で入力が潰れる場合 `grid-cols-1 sm:grid-cols-3`。
3. 11pxフロア: 本ファイル内の `text-[10px]` 以下は `text-[11px]` へ。生 `vh` 禁止（`max-h-[90vh]` は撤去）。
