# REQ-308-T2: プリセット経路へ textarea role allowlist を伝播

## Impacted Files
- `frontend/src/pages/GeneratePage/hooks/usePresetState.ts`
- `frontend/src/pages/GeneratePage/hooks/__tests__/usePresetState.test.ts`

## Hermetic Context
`UsePresetStateProps` includes `workflow: Workflow | undefined`. Its preset handler builds `defaultParams` from `workflow` and calls `loadPresetData(preset, defaultParams)`. Bulk update has two chip generation loops:
```ts
for (const [role, val] of Object.entries(mergedParams)) {
  if (val) chips[role] = parseToChips(val, storeRef.current.isAnimaMode ?? false)
}
```
## Implementation
- Derive roles from `workflow?.mappings.filter(m => m.role && m.input_type === 'textarea')`.
- Pass that allowlist to the explicit preset load call `loadPresetData(preset, defaultParams, promptRoles)`.
- In both bulk-update loops, parse only allowed roles; preserve merged raw params unchanged for all roles.
- Add regressions for dotted non-textarea values during preset list refresh and bulk update.
