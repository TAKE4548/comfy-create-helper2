# REQ-356-T5: [Backend Integration Services/Models] backend/tests/integration/services/ および models/ へのサービス層・DBテスト移行

## 1. 概要と目的
サービス層とDBの結合テストおよびORMモデル・マイグレーションテストを `backend/tests/integration/services/` および `integration/models/` へ再編する（AC-1, AC-2）。
チケット名ファイル（`test_snapshot_service_req267.py`, `test_req336_cascade_service.py`, `test_base_models_migration.py` 等）を `test_snapshot_service.py`, `test_mapping_service.py`, `test_model_relations.py`, `test_migrations.py` 等に統合する。
SAVEPOINT ロールバックによるクリーンな状態遷移と `tmp_path` サンドボックスによる本番ファイル書き込みゼロを徹底する（AC-4, AC-5）。

## 2. ターゲット識別
- **対象ファイル**: `backend/tests/integration/services/test_snapshot_service.py`, `backend/tests/integration/services/test_mapping_service.py`, `backend/tests/integration/models/test_model_relations.py`
