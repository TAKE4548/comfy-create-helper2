## 1. 目的とスコープ
WebSocket 通信シングルトンサービス（`ComfyWebSocketService`）に以下の機能を追加する：
1. **定期ハートビート（Ping）送信機構**: 接続維持およびアイドル切断の能動防止。
2. **指数バックオフ管理機構**: リトライ回数に応じた再接続遅延（1s〜15s）の計算およびリセット制御。
3. **安全なライフサイクル保護**: ソケット破棄・切断時におけるタイマーの完全破棄。

## 4. 実装要件・手順
1. **メンバ変数の追加**:
   - `private heartbeatTimer: ReturnType<typeof setInterval> | null = null;`
   - `private retryCount: number = 0;`
   - 定数 `HEARTBEAT_INTERVAL_MS = 25000;`（25秒）
   - 定数 `BASE_RECONNECT_DELAY_MS = 1000;`（1秒）
   - 定数 `MAX_RECONNECT_DELAY_MS = 15000;`（15秒）
2. **ハートビートメソッドの実装**:
   - `public startHeartbeat(): void`: 既存タイマーをクリア後、25秒ごとの `setInterval` で `sendPing()` を実行。
   - `public stopHeartbeat(): void`: `heartbeatTimer` を安全に `clearInterval` し `null` に設定。
   - `public sendPing(): void`: `this.ws && this.ws.readyState === WebSocket.OPEN` の場合に `this.ws.send(JSON.stringify({ type: 'ping' }))` を安全に実行（例外時は `stopHeartbeat()`）。
3. **指数バックオフ計算メソッドの実装**:
   - `public getReconnectDelay(): number`: `Math.min(BASE_RECONNECT_DELAY_MS * Math.pow(2, this.retryCount), MAX_RECONNECT_DELAY_MS) + Math.floor(Math.random() * 500)` を返却。
   - `public incrementRetryCount(): void`: `this.retryCount++`
   - `public resetRetryCount(): void`: `this.retryCount = 0`
4. **イベントフックへの統合**:
   - `this.ws.onopen`: コールバック呼び出し前に `this.resetRetryCount()` および `this.startHeartbeat()` を実行。
   - `this.ws.onclose` / `this.ws.onerror` / `disconnect()`: `this.stopHeartbeat()` を実行。
   - `resetForTesting()`: `this.stopHeartbeat()` および `this.resetRetryCount()` を実行。
