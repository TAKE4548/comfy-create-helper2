# Task Card: REQ-276-T3

## 1. 目的
1. 生成ボタン押下時（`handleGenerateSets`）、オートセーブのデバウンス待機中（1秒以内）であっても、即時保存（`flushAutoSave`）を実行し、かつ ComfyUI へのキュー投入ペイロードに UI 上の最新編集値が確実に使用されることを担保する。
2. フロントエンドのパラメータロード時（`useWorkflowParams.ts`）において、万一過去のデータやキャッシュに旧キー `'Resolution Selecto'` が含まれていた場合でも、正規キー `'Resolution Selector'` へ自動昇格する「自己修復（Self-Healing）」マッピングを実装する。

## 2. 対象ファイル
1. `frontend/src/pages/GeneratePage/hooks/useWorkflowParams.ts`
2. `frontend/src/pages/GeneratePage/hooks/useGenerateAction.ts`
3. `frontend/src/pages/GeneratePage/hooks/usePresetState.ts`

## 3. 実装仕様

### 3.1 `usePresetState.ts` の `flushAutoSave`
デバウンスタイマーをクリアし、現在のダーティ状態を即時 `updatePresetMutation.mutate` する関数を公開する。

```typescript
// usePresetState.ts 内
const flushAutoSave = useCallback(() => {
  if (autoSaveTimerRef.current) {
    clearTimeout(autoSaveTimerRef.current)
    autoSaveTimerRef.current = null
  }
  // 未保存の差分があれば即時 mutate
}, [...])
```

### 3.2 `useGenerateAction.ts`
`handleGenerateSets` 開始時に `flushAutoSave` を呼び出し、UI の最新 `currentParamValues` が確実に採用されることを確認。

```typescript
// ターゲット箇所のスニペット (useGenerateAction.ts: L162-L168)
const isActive = activeSetId !== null && String(setItem.id) === String(activeSetId)
const itemParams = isActive
  ? { ...setItem.paramValues, ...currentParamValues }
  : setItem.paramValues
```

### 3.3 `useWorkflowParams.ts` の自己修復
ロード時に旧キーがあれば正規キーに変換。

```typescript
function healLegacyParamKeys(params: Record<string, string>): Record<string, string> {
  const result = { ...params }
  if ('Resolution Selecto' in result && !('Resolution Selector' in result)) {
    result['Resolution Selector'] = result['Resolution Selecto']
    delete result['Resolution Selecto']
  }
  return result
}
```
