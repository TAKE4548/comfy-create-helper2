# REQ-338-T3: スリープ・タブ復帰0秒同期フック useAppLifecycleSync の実装

## 1. 概要と目的
ノートPCのスリープ開閉やブラウザタブ休止（Chromeメモリセーバー等）からの復帰時に、古いHalf-Openソケットを即時破棄して `systemWsService.resume()` を叩き、並行して `generationApi.getState()` を即座にフェッチして待ち時間0秒で最新の生成状態（Epoch / Revision）をStoreへ再同期するカスタムフックを実装する。

## 2. ターゲット識別
- **対象ファイル**: `frontend/src/hooks/useAppLifecycleSync.ts` (新規)
- **テストファイル**: `frontend/src/hooks/__tests__/useAppLifecycleSync.test.ts` (新規)
- **対象シンボル**: `useAppLifecycleSync`

```typescript
// frontend/src/store/services/systemWsService.ts
export class SystemWsService {
  public suspend(): void { ... }
  public resume(): void {
    if (!this.suspended) return
    this.suspended = false
    this._openSocket()
  }
}
```
