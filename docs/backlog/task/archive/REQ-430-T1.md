# REQ-430-T1: SPEC_SETTINGS.md §3-1-1 仕様同期（MUI-02 例外・ペイン高さ整合・2行カード）

## 1. 概要と目的
`docs/specs/SPEC_SETTINGS.md` §3-1-1 を更新し、AC-1（MappingMaster 行の1行目=名称+右端固定アクション・2行目=バッジのモバイル/デスクトップ双方適用）および AC-2/AC-3（`xl` 2カラム時の左右ペイン高さ整合およびワークフロー管理一覧・MappingMaster 一覧の内部スクロール仕様を `SPEC_COMMON.md` MUI-02 の明記例外として定義）を SSoT に反映する。

## 2. ターゲット識別
- **対象ファイル**: `docs/specs/SPEC_SETTINGS.md`
- **対象セクション**: `### 3-1-1. 画面レイアウト（REQ-365）` (L151-158)

## 3. 対象スニペット（抜粋）
```markdown
### 3-1-1. 画面レイアウト（REQ-365）

workflowsタブは `xl`（>=1280px）で2カラムとし、左=ワークフロー（上）・BaseModel（下）、右=MappingMasterを配置する。左カラムはRow-Span余白を作らない。<1280pxはワークフロー→MappingMaster→BaseModelの順に縦積みする。この並べ替えはCSS `order` のみで行い、データ順序およびAPIに影響しない。

モバイル（<768px）ではタブバーを横スワイプ（snap）にし、操作対象は44×44px以上とする。ページ下部余白は `pb-[calc(6rem+env(safe-area-inset-bottom))]` とし、768px以上では解除する。

MappingMaster行とチェックポイント表は超スリムカードで表示する。1行目は名称と右端固定のアクション、2行目はバッジとする。
```

## 4. 実装要件
- [ ] `docs/specs/SPEC_SETTINGS.md` L153 の段落に以下を追記する:
  - `xl`（>=1280px）2カラム表示時は、左ペイン（ワークフロー管理＋BaseModel）と右ペイン（MappingMaster）のうち短いほうの自然高さに合わせて長いほうの一覧（ワークフロー管理一覧またはMappingMaster一覧、最小床 240px）を内部スクロールさせ、片側ペインのみが縦長肥大化しないようにする。これは [SPEC_COMMON.md](./SPEC_COMMON.md) §1-5-4 MUI-02（独立スクロールの仕様書明記例外）に基づく設計である。`<1280px` の単一カラム時は内部スクロール上限を解除し、ページ全体の縦スクロールとする。
- [ ] `docs/specs/SPEC_SETTINGS.md` L157 の「1行目は名称と右端固定のアクション、2行目はバッジとする。」がモバイル（<768px）およびデスクトップ（>=768px）双方の MappingMaster 行に適用されることを明記する。
- [ ] API・DB スキーマ・他セクション（§3-1-2 等）の既存契約は変更しない。
