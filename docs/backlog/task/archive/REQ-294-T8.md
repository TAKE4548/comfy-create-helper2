## 実装

- SceneSpeechModalState.ts に ProgressStep（reference/vlm/style/vram、pending/active/done/error）と排他的 SceneSpeechModalState（progress/onboarding/error/review）をexportする。review.resultはSceneDraftResponse、onboardingはtagSetId:numberを保持する。T2/T3はこの共有型だけをimportする。

```typescript
export interface ProgressStep {
  key: 'reference' | 'vlm' | 'style' | 'vram'
  label: string
  status: 'pending' | 'active' | 'done' | 'error'
}
export type SceneSpeechModalState =
  | { type: 'progress'; steps: ProgressStep[]; elapsedSeconds: number }
  | { type: 'onboarding'; tagSetId: number }
  | { type: 'error'; errorKind: 'lm_studio_400' | 'connection_refused' | 'timeout' | 'unknown'; message: string }
  | { type: 'review'; result: SceneDraftResponse }
```
- SceneSpeechOnboarding.tsx のpropsは tagSetId:number、fontList:ServerFont[]、onPresetCreated:(id:number)=>void、onSkip:()=>void。コンポーネント内で既存プリセット一覧とタグセット名を取得する。キャラ名から「○○ 専用スタイル」を初期入力し、取得失敗時は編集可能な「キャラ#ID 専用スタイル」を使う。
- `export function SceneSpeechOnboarding(props: SceneSpeechOnboardingProps)` としてnamed exportする。T2は `./SceneSpeechOnboarding` からimportする。
- ベースプリセット選択で既存プリセットのstyle値をクライアント側フォーム初期値へコピーする。SpeechBubblePresetCreateにbase_preset_idは存在しないため送信しない。
- PC/モバイルで名前、ベース継承、形状、横/縦、フォント、文字サイズ12〜36、文字/背景/枠の3色、枠幅0〜8（0.5刻み）を全て編集可能にする。初期値はoval、horizontal、Noto Sans JP、16、#1A202C/#FFFFFF/#CBD5E0、2。形状は実型のrounded-rectを「角丸」と表示する。
- 保存でspeechBubblePresetsApi.createへtag_set_idを含む全値を渡し、返却idをonPresetCreatedへ渡す。二重送信防止と失敗表示を実装する。スキップはonSkipだけを呼ぶ。
