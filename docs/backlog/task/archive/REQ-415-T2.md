# REQ-415-T2: タイトル検索パターンのモバイル仮想キーボード対応およびタップ追加導線に関するSSoT仕様書の同期

## 1. 概要と目的
REQ-415 にて実装された `PatternTagInput` のモバイル仮想キーボード対応（`enterKeyHint="done"`）、タップ用「追加」ボタンの新設（MUI-10準拠・44px Hit-Slop）、日本語IME変換確定ガード、およびフォーカス離脱（`onBlur`）時の自動確定フォールバック契約を、正本仕様書（`docs/specs/SPEC_COMMON.md` および `docs/design/REQ-340.md`）へ同期・明記する。

## 2. ターゲット識別
- **所有ファイル**:
  1. `docs/specs/SPEC_COMMON.md`
  2. `docs/design/REQ-340.md`
- **対象セクション**:
  - `docs/specs/SPEC_COMMON.md` §1-6「モバイルUI共通規約 (MUI-10 タッチ操作代替経路)」および §1-5「Preset 3: Forms & Controls」
  - `docs/design/REQ-340.md` §3.2「パターンチップ操作フロー (PatternTagInput)」

## 3. 実装要件 (Implementation Logic)
- [ ] 1. `docs/specs/SPEC_COMMON.md`:
  - §1-6 MUI-10 に、チップ/タグ入力コンポーネントにおけるモバイル仮想キーボードでのEnter押下によるフォーカス誤ジャンプ防止策（`enterKeyHint="done"` と `preventDefault()`）、タップ確定用「追加」ボタンの設置（44×44px Hit-Slop）、日本語IME変換ガード、および `onBlur` フォールバックの設計規約を追記する。
  - §1-5 Preset 3: Forms & Controls の規約表に、Tag/Chip入力コントロールのモバイル対応要件を追加する。
- [ ] 2. `docs/design/REQ-340.md` §3.2:
