## 3. 実装要件 (Implementation Logic)
- [ ] `useWorkflowManagement.ts` において、`selectedModel.name === 'Anima'` の判定結果得た際、`useGenerationStore.getState().setIsAnimaMode?.(isAnima)` を呼び出してグローバルストアを同期する。またフック内部の `setIsAnimaMode` setter 呼び出し時にもストアへ同期する。
- [ ] `multiSetSlice.ts` の `loadPresetData` において:
  - `const isAnimaMode = get().isAnimaMode ?? false` を取得。
  - 各ロールのチップ構築時、既存セット（`get().sets.find((s) => String(s.id) === String(preset.id))`）に既に有効な `promptChips?.[role]` が存在し、その `chipsToString(existing, isAnimaMode) === val` である場合は既存チップを再利用（非破壊維持）する。
  - 新規作成・再パース時は `parseToChips(val, isAnimaMode)` と第2引数に `isAnimaMode` を渡す。
- [ ] `usePresetState.ts` の一括同期処理（L498, L523付近）において、`parseToChips(val, storeRef.current.isAnimaMode ?? false)` を渡し、Animaモード時のピリオド区切りを維持する。
