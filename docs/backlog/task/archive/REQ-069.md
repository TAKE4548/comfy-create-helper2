## 3. 実装要件 (Implementation Logic)
- [x] **`easy loraStack` 判定ロジックの定義**:
  - `node.inputs` において `'num_loras'` または `'lora_1_name'` が定義されている場合、あるいは `node.class_type` が `'easy loraStack'` の場合に `isEasyLoraStack` とする。
- [x] **`getInitialParams` の修正**:
  - `isEasyLoraStack` の場合は `node.inputs['num_loras']` をカウント用入力として優先的に使用する。フォールバックとして `lora_${i}_name` または `lora_name_${i}` が定義されている最大インデックス `i` (1〜10) をスキャンしてカウントとする。
  - 各スロット `i` (1〜loraCount) の値について、`lora_${i}_name` 等の `easy loraStack` 形式のキーを優先し、なければ標準形式のキーから読み出す。
- [x] **`handleSaveDefaultParams` / `injectParams` の修正**:
  - `isEasyLoraStack` の場合は以下を書き込む：
    - `node.inputs['num_loras'] = loraCountVal`
    - 各スロット `i` (1〜loraCountVal)：
      - `node.inputs[`lora_${i}_name`] = name`
      - `node.inputs[`lora_${i}_strength`] = weight`
      - `node.inputs[`lora_${i}_model_strength`] = modelStrength`
      - `node.inputs[`lora_${i}_clip_strength`] = clipStrength`
    - 残りのスロット `i` (loraCountVal + 1〜10)について、もし `lora_${i}_name` などのキーが存在していれば、デフォルト（名前は `'None'`、強度は `1.0`）にリセットする。
    - 標準形式の余分なキー (`lora_count` および `lora_name_X` 等) が存在していれば削除してサニタイズする。
  - `isEasyLoraStack` でない（標準形式）の場合は、従来通りの `lora_count` および `lora_name_X` 等への書き込みを行い、`easy loraStack` 形式 of キーが混在していれば削除する。
