### 2.2 既存の対象コード (`tools/server-manager/server-manager.ps1` L96-L106)
```powershell
function Test-PortOpen ([int]$port) {
    $conn = Get-NetTCPConnection -LocalPort $port -ErrorAction SilentlyContinue | Where-Object State -eq "Listen"
    if ($null -ne $conn) { return $true }
    $tcp = New-Object System.Net.Sockets.TcpClient
    try {
        $ar = $tcp.BeginConnect("127.0.0.1", $port, $null, $null)
        $ok = $ar.AsyncWaitHandle.WaitOne(500, $false)
        if ($ok) { $tcp.EndConnect($ar) }
        return $ok
    } catch { return $false } finally { $tcp.Close(); $tcp.Dispose() }
}
```

### 2.3 改修要件
1. `backend/run_server.bat`:
   - `%ARGS%` に `--loop` が指定されていない場合、自動的に `--loop asyncio:SelectorEventLoop` を追加して uvicorn を起動する。
2. `tools/server-manager/server-manager.ps1`:
   - `Test-PortOpen` の接続成功後、`$tcp.Close()` の前に `$tcp.Client.Shutdown([System.Net.Sockets.SocketShutdown]::Both)` を安全に呼び出す（try-catch でエラー抑止）。
