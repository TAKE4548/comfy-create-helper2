## 3. 実装要件 (Implementation Logic)

### 3.1 DesktopLayout.tsx & MobileLayout.tsx の修正
- スナップショット選択ドロップダウンの削除：
  - `DesktopLayout.tsx` から `<select id="snapshot-history-select"` 要素とその中身を削除する。
  - `MobileLayout.tsx` から `<select id="snapshot-history-select-mobile"` 要素とその中身を削除する。
- 履歴クリック挙動の改善：
  - `DesktopLayout.tsx` の履歴サムネイル `onClick` ハンドラを修正し、`handleItemClick(i, e)` を常に呼び出した上で、非マルチ選択モードかつ修飾キー（Ctrl/Cmd/Shift）も押されていない場合のみ `setSelectedImg(img)` が呼ばれるように整理する。
  - `MobileLayout.tsx` の履歴サムネイル `onClick` ハンドラを同様に修正し、非マルチ選択モードかつ修飾キーも押されていない場合のみ `setSelectedImg(img)`、`setModalPreviewIndex(i)`、`setIsModalPreviewOpen(true)` を呼ぶようにする。
- 「Save Snapshot」ボタンの無効化条件の更新：
  - `DesktopLayout.tsx` の `#save-snapshot-btn` の `disabled` 属性を以下のように更新する：
    `disabled={isMultiSelectMode ? selectedIds.size === 0 : !selectedImg}`
  - `MobileLayout.tsx` の `#save-snapshot-btn-mobile` の `disabled` 属性も同様に更新する。
