# REQ-345-T17 原画URL identityで`/api/comfy/view`を認識する

## Ownership and Atomicity

Write only the two listed files, with at most 150 changed lines total. Shared codebase: preserve other edits and assertions.

## Evidence and Contract

The application displays original image URLs as `/api/comfy/view?...`; the controller currently accepts only `/view`, so gallery observation cannot identify those images. The corresponding `REQ-345-T14` fixture must retain the real application URL.

- Accept same-origin pathname `/view` and `/api/comfy/view`.
- Both path forms with identical `filename`, `subfolder` (default `''`), and `type` (default `'output'`) produce the same key and request identity.
- Keep origin validation, reject other paths and missing/blank filenames, and ignore host and `t` query parameters as identity inputs.
- Add focused tests for equivalent identity across the two paths and rejected paths.
- Do not alter controller queue, adoption, retry, or owner semantics.
