# REQ-336-T1: Backend 2軸正規化データモデル定義と冪等マイグレーション (Step 029)

## 1. 概要と目的
`mapping_group_masters`, `stage_masters`, `mapping_masters`, `mapping_variants` の4層リレーショナルモデルを SQLAlchemy に定義し、既存のフラットな `mapping_master` データを欠損なく安全・冪等に移行する `step_029` マイグレーションを実装する。また、`workflow_mappings` に `variant_id` カラムを追加し、既存の配線データを新バリアントへ正確に付け替える。

## 2. ターゲット識別
- **対象ファイル**:
  - `backend/app/models.py` (L33付近の MappingMaster, WorkflowMapping 周辺)
  - `backend/app/migrations/steps.py` (L529付近の ALL_MIGRATION_STEPS)
  - `backend/app/seeder.py` (L32付近の _seed_mapping_masters)
- **対象シンボル**: `MappingGroupMaster`, `StageMaster`, `MappingMaster`, `MappingVariant`, `WorkflowMapping`, `step_029_workflow_mapping_v2_normalization`

### 3.1 必須の型・モデル定義
```python
from sqlalchemy import Integer, String, Text, Boolean, ForeignKey
from sqlalchemy.orm import Mapped, mapped_column, relationship
from app.database import Base

class MappingGroupMaster(Base):
    __tablename__ = "mapping_group_masters"
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    key: Mapped[str] = mapped_column(String, nullable=False, unique=True)
    name: Mapped[str] = mapped_column(String, nullable=False)
    sort_order: Mapped[int] = mapped_column(Integer, default=0)
    is_builtin: Mapped[bool] = mapped_column(Boolean, default=False)
    is_active: Mapped[bool] = mapped_column(Boolean, default=True)

class StageMaster(Base):
    __tablename__ = "stage_masters"
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    key: Mapped[str] = mapped_column(String, nullable=False, unique=True)
    name: Mapped[str] = mapped_column(String, nullable=False)
    suffix: Mapped[str] = mapped_column(String, nullable=False, default="")
    search_keywords: Mapped[Optional[str]] = mapped_column(Text)
    previous_suffixes: Mapped[Optional[str]] = mapped_column(Text)
    is_builtin: Mapped[bool] = mapped_column(Boolean, default=False)
    is_active: Mapped[bool] = mapped_column(Boolean, default=True)
    sort_order: Mapped[int] = mapped_column(Integer, default=0)

class MappingVariant(Base):
    __tablename__ = "mapping_variants"
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    master_id: Mapped[int] = mapped_column(ForeignKey("mapping_masters.id", ondelete="CASCADE"), nullable=False)
    stage_id: Mapped[int] = mapped_column(ForeignKey("stage_masters.id", ondelete="CASCADE"), nullable=False)
    custom_role_override: Mapped[Optional[str]] = mapped_column(String, nullable=True)
    extra_title_patterns: Mapped[Optional[str]] = mapped_column(Text)
    is_enabled: Mapped[bool] = mapped_column(Boolean, default=True)
    sort_order: Mapped[int] = mapped_column(Integer, default=0)

    master: Mapped["MappingMaster"] = relationship(back_populates="variants")
    stage: Mapped["StageMaster"] = relationship()

    @property
    def computed_role(self) -> str:
        if self.custom_role_override:
            return self.custom_role_override
        suf = self.stage.suffix if (self.stage and self.stage.suffix) else ""
        return f"{self.master.base_key}{suf}"
```

## 4. 実装要件 (Implementation Logic)
- [ ] `backend/app/models.py` に `MappingGroupMaster`, `StageMaster`, `MappingVariant` を定義し、`MappingMaster` に `group_id`, `base_key`, `base_title_patterns` 等のカラム・リレーションシップを追加。
- [ ] `WorkflowMapping` に `variant_id` (ForeignKey) を追加し、`master_id` との共存/プロパティ互換を担保。
- [ ] `backend/app/migrations/steps.py` に `step_029_workflow_mapping_v2_normalization` を作成し、`ALL_MIGRATION_STEPS` に登録。
  - DDL: 新テーブル作成およびカラム追加を安全（カラム存在チェック付き）に実行。
  - DML: 既存の `mapping_master` からグループ・親キー・ステージを判別して移行し、`workflow_mappings` の `variant_id` を自動補完。
  - トランザクション保護: 例外発生時は即座に ROLLBACK される安全設計。
- [ ] `backend/app/seeder.py` を更新し、初期起動時に既定グループ（Prompt, Sampler等）、既定ステージ（Main, Rough, Detail）およびバリアントが投入されるように改修。
