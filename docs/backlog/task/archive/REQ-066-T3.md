## 3. 実装要件 (Implementation Logic)

### 3.1 長押し感度設定セクションの追加
`SettingsPage.tsx` 内の `Connections` セクションの上または下に、「長押し感度設定（アプリ全体）」セクションを追加する。

### 3.2 UIレイアウトおよび機能
- セクションヘッダー：
  - アイコン: `Settings` または `Fingerprint` / `Sliders` 等の適切な lucide アイコン
  - タイトル: 「長押し感度設定（アプリ全体）」
  - サブタイトル: 「— ブラウザ（LocalStorage）に保存」
- 設定項目：
  1. **履歴の複数選択長押し時間** (`LONG_PRESS_DELAY_MULTI_SELECT`)
     - スライダーコントロール (`<input type="range" min="0.1" max="5.0" step="0.1" />`)
     - 現在の設定値（秒単位）を表示する（例：「0.8s」）。
  2. **カード移動の長押し時間** (`LONG_PRESS_DELAY_CARD_MOVE`)
     - スライダーコントロール (`<input type="range" min="0.1" max="5.0" step="0.1" />`)
     - 現在の設定値（秒単位）を表示する（例：「0.5s」）。
- 動作仕様：
  - 設定の読み込み:
    - ページマウント時に `localStorage` から値を取得し、状態（`useState`）を初期化する。
    - 値がない場合はデフォルト値 (`0.8` または `0.5`) とする。
  - 設定の書き込み:
    - スライダーを操作（`onChange`）した際、即座に state を更新し、`localStorage` に書き込む。
    - `saved === 'longpress'` のようなフラグで一時的に「保存しました」のツールチップやテキストを表示させるとユーザーにわかりやすくて良い。

## 4. 検証手順 (AC)
- 設定画面に長押し感度設定セクションと2つのスライダー（履歴複数選択、カード移動）が表示されていることを確認。
- 各スライダーを動かした際に、値の表示が連動して切り替わり、`localStorage` に設定値が秒単位の文字列で保存されることを確認。
- スライダー操作後に設定ページをリロードしても、変更した値が維持されていることを確認。
