# REQ-370-T3: useGenerateDisplayState タブ復帰時スナップショット再同期とクエリキャッシュ整合化

## 1. 概要と目的
バックグラウンド非活性中や他端末での生成完了時にイベントを取りこぼした場合でも、閲覧端末のタブが可視化（フォアグラウンド復帰）した際に最新状態を回復できるよう、`useGenerateDisplayState.ts` の `visibilitychange` ハンドラで `store.loadSnapshot()` を実行する（`AC-4`）。また、Zustand ストアにマージされた画像が TanStack Query キャッシュ（`generateDisplayImages`）へ即座に反映されるようキャッシュ同期エフェクトを整合化する。

### 2.2 改修後コードスニペット: `frontend/src/pages/GeneratePage/hooks/useGenerateDisplayState.ts`
```typescript
  // Synchronize query cache if store rawImages changes (マウント初期の空配列によるキャッシュ消去を防止)
  useEffect(() => {
    if (rawImages.length === 0 && foreignManagedIdentities.size === 0 && unavailableImages.size === 0) return

    const currentQueryData = queryClient.getQueryData<string[]>(queryKey)
    if (!currentQueryData || currentQueryData.length === 0) {
      queryClient.setQueryData(queryKey, unavailableRaw)
    } else {
      const merged = uniqueImages([...unavailableRaw, ...currentQueryData], unavailableImages)
      if (merged.length !== currentQueryData.length || !merged.every((v, i) => v === currentQueryData[i])) {
        queryClient.setQueryData(queryKey, merged)
      }

      if (document.visibilityState === 'visible') {
        if (!store.isConnected) {

        void store.loadSnapshot()

          store.fetchHistory()
```

### 2.3 テスト追加対象: `frontend/src/pages/GeneratePage/hooks/__tests__/useGenerateDisplayState.residual.test.tsx`
`useGenerateDisplayState.residual.test.tsx` に以下の AC-4 受入テストを追加：
```typescript
  it('[REQ-370/AC-4] calls store.loadSnapshot on visibilitychange and updates query cache with newly completed images', async () => {
    const client = new QueryClient()
    const baseline = image('shown')
    client.setQueryData(['generateDisplayImages', { filterOwnSession: false }], [baseline])
    client.setQueryData(['generateDisplayImages', { filterOwnSession: true }], [baseline])
    const store = useGenerationStore.getState()
    const loadSnapshotSpy = vi.spyOn(store, 'loadSnapshot').mockImplementation(async () => {
      useGenerationStore.setState({
        comfyHistoryImages: [image('completed-on-other-device'), baseline],
      })
    })
    const fetchQueueSpy = vi.spyOn(store, 'fetchQueue').mockImplementation(vi.fn())

    const { result } = renderHook(() => useGenerateDisplayState({ selectedWorkflowId: null }), {
      wrapper: makeWrapper(client),
    })

    act(() => {
      Object.defineProperty(document, 'visibilityState', { value: 'visible', configurable: true })
      document.dispatchEvent(new Event('visibilitychange'))
    })

    expect(loadSnapshotSpy).toHaveBeenCalled()
    await waitFor(() => {
      const data = client.getQueryData<string[]>(['generateDisplayImages', { filterOwnSession: false }])
      expect(data).toContain(image('completed-on-other-device'))
    })

    loadSnapshotSpy.mockRestore()
    fetchQueueSpy.mockRestore()
  })
```

## 3. 実装制約と設計上の注意事項
- `store.loadSnapshot` は `REQ-370-T1` で `ConnectionActions` に公開されている前提（依存: `REQ-370-T1`）。
- `useGenerateDisplayState.residual.test.tsx` の既存テスト（L57: `keeps skipping focus and visibility history refresh with a persisted baseline`）で `fetchHistory` が抑止されているアサーションを壊さないこと。`loadSnapshot` はスナップショットの軽量照会であり、`fetchHistory`（ComfyUI history）の抑止仕様と両立する。
