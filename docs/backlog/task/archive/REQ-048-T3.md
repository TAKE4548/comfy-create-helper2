## 3. 実装要件 (Implementation Logic)
1. `frontend/src/api/types.ts` の更新:
   - `TagSet` に `thumbnail_path: string | null` を追加。
   - `TagSetCreate` に `thumbnail_path?: string` を追加。
2. `frontend/src/components/LoraModals.tsx` の修正:
   - **モーダル全幅の拡張**: `max-w-md` や `max-w-lg` から `max-w-4xl` に変更。
   - **左右2カラムレイアウト化**:
     - 左側：カバー画像または選択中のスナップショットを大きくプレビュー表示し、その左右に矢印ボタンを表示してスライドショー（カルーセル）できるコンポーネントを配置。プレビューエリア下部に、関連する全スナップショット画像の一覧をグリッド（例: 4列・5列のスクロール領域）で表示。
     - 右側：既存のフォームフィールドや詳細情報を配置。
   - **詳細モーダル (`LoraDetailModal`)**:
     - 左側に画像プレビューとグリッド、右側にメタデータを配置。
   - **編集モーダル (`LoraEditModal`)**:
     - プレビュー部分に「カバーに設定」ボタンを設置。またはグリッドの画像にホバーした際・選択した際に「カバー画像に指定」できるUIを追加する。
     - カバー画像に設定した場合は、`form.thumbnail_path` をその画像のパスに更新。保存時（`Save Changes`）にバックエンドへ送信する。
