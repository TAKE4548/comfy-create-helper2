# REQ-365-T18: ボトムシート上端角丸 16px (AC-9 E2E不具合是正)

実ブラウザE2E（`frontend/e2e/settingsResponsive.spec.ts` AC-9, T15）で、375pxの共通Modal `role=dialog` の `border-top-left-radius` が **12px**（期待16px）と実測された。人間承認済み方針A: 共通Modalシートを半径上書きから除外する。

## 原子性
変更3ファイル（Modal.tsx 1行、index.css 追加数行、Modal.test.tsx 1テスト）。合計約30行。

## 根本原因（実ファイル確認済み）
`[class~='rounded-2xl']` は完全トークン一致であり、Modalの `rounded-t-2xl` / `md:rounded-2xl` には一致しない。真因は `frontend/src/index.css` の次の2規則:

1. 約163行 `.modal-backdrop > :not(.modal-backdrop):not([data-radius-exempt]) { border-radius: var(--ux-radius-modal); }`（`--ux-radius-modal: 12px`、`@layer utilities` 内）。`data-radius-exempt` で除外可能。
2. 約319行 `@media (max-width: 767px)` 内、約331-340行（レイヤー外 = Tailwindユーティリティに常に勝つ）:
```css
  .modal-backdrop:not(.flex-col):not(:fullscreen):has(> [role='dialog']) > [role='dialog'] {
    align-self: flex-end;
    width: 100%;
    max-width: 100%;
    max-height: calc(100dvh - env(safe-area-inset-top));
    overflow-y: auto;
    margin-top: auto;
    padding-bottom: calc(1rem + env(safe-area-inset-bottom));
    border-radius: var(--ux-radius-modal) var(--ux-radius-modal) 0 0;   /* モバイル12pxの発生源 */
  }
```
規則2は `data-radius-exempt` を考慮しない。**`data-radius-exempt` 属性だけでは375pxで16pxにならない。index.css追加が必須**（index.css所有の根拠）。規則2に `:not([data-radius-exempt])` を足すのは禁止（幅・max-height・padding等の他宣言まで無効化されるため）。

## 変更内容
### 1) Modal.tsx（約139-143行、`role="dialog"` 要素）
`data-radius-exempt` を追加。classNameは変更しない（`rounded-t-2xl rounded-b-none md:rounded-2xl` を維持）。
```tsx
      <div
        ref={dialogRef}
        role="dialog"
        aria-modal="true"
        aria-label={ariaLabel}
        data-radius-exempt
        tabIndex={-1}
```
### 2) index.css: 規則2の直後（同じ `@media (max-width: 767px)` ブロック内、規則2より後ろ）に追加のみ
```css
  /* Common Modal sheet keeps the 16px (rounded-t-2xl) top radius per SPEC_COMMON bottom-sheet. */
  .modal-backdrop:not(.flex-col):not(:fullscreen) > [role='dialog'][aria-modal='true'][data-radius-exempt] {
    border-radius: 1rem 1rem 0 0;
  }
```
specificityは規則2以上かつ後置のため勝つ。`data-radius-exempt` 無しのダイアログは従来どおり12px。

## 既知の挙動差（変更せず報告に記載）
`data-radius-exempt` は規則1も除外するため、デスクトップ(>=768px)の共通Modalは 12px から `md:rounded-2xl` = 16px に変わる（クラス意図どおり）。承認済み方針Aの帰結であり追加調整しない。

## テスト（Modal.test.tsx 末尾、既存 `[REQ-365/AC-9] keeps rounded-t-2xl...` の直後に追加）
```tsx
  it('[REQ-365/AC-9] exempts the sheet from the global radius override and keeps responsive radius classes', () => {
    render(
      <Modal isOpen={true} onClose={vi.fn()}>
        <div>Modal Content</div>
      </Modal>,
    )

  })
```
jsdomはCSSカスケードを評価しないため、実computed radiusはE2Eで検証する。既存テストは変更しない。
