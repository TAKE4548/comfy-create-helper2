## 変更内容（SettingsPage.tsx）
1. workflowsパネルを次の構造に置換（既存3セクションを**そのまま**子として移動。内部ロジック不変）:
```tsx
<div data-testid="settings-workflows-grid" className="grid grid-cols-1 items-start gap-6 xl:grid-cols-2 xl:grid-rows-[auto_1fr]">
  <div data-testid="settings-card-workflow" className="order-1 min-w-0 xl:col-start-1 xl:row-start-1">{/* WorkflowConnectionSection group="workflows" */}</div>
  <div data-testid="settings-card-mapping" className="order-2 min-w-0 xl:col-start-2 xl:row-span-2 xl:row-start-1">{/* MappingMasterSection */}</div>
  <div data-testid="settings-card-basemodel" className="order-3 min-w-0 xl:col-start-1 xl:row-start-2">{/* Base Model accordion section */}</div>
</div>
```
   `xl:grid-rows-[auto_1fr]` + `items-start` により左カラムのWF・BaseModelカード間に空隙を作らない（Row-Span対策）。`<xl` はDOM順に関係なく `order` で WF→Mapping→BaseModel。
2. スクロールコンテナ: `lg:pb-5` を `md:pb-5` に変更（AppShell bottom navは768px未満のみ）。`pb-[calc(6rem+env(safe-area-inset-bottom))]` は維持。内側に `mx-auto w-full max-w-7xl` のラッパ`div`（`data-testid="settings-content-container"`）を追加し、`panels.map` をその内側へ（Desktop Container制約）。
3. 他タブのpanel内容・`hidden`/`role=tabpanel`/`id`/`aria-*` は変更しない。

既存の `.settings-mobile-table tr {display:block}` 等と競合する場合は同一ブロック内で上書き順序を整理する（`!important` 禁止。`ui-invariant-ignore` コメントを増やさない）。`[role='dialog']` の既存 `max-height` は PC では維持し、モバイルのみ85dvhに上書き。
