# REQ-319-T5: LoRA Studio フロントエンド API クライアント型定義および Zustand 状態管理ストア新設

## 1. 概要と目的
LoRA Studio のプロジェクト、マトリクスアイテム、別衣装マスタ、学習ジョブ、および4軸ベンチマークの TypeScript 型定義を `frontend/src/api/types.ts` に追加し、API呼び出し関数を `frontend/src/api/client.ts` に実装する。さらにスタジオ全体のウィザード状態（Step 1〜4）や選択アイテム、学習テレメトリを保持する Zustand ストア `useStudioStore.ts` を新設する。

export interface DatasetProject {

## 3. 実装要件 (Implementation Logic)
1. **`frontend/src/api/types.ts`**:
   - `DatasetProject`, `DatasetItem`, `OutfitMasterPreset`, `LoraTrainingJob`, `StressTestPrompt`, `SweetSpotResult` 型を定義。
2. **`frontend/src/api/client.ts`**:
   - `datasetApi.getProjects`, `datasetApi.createProject`, `datasetApi.calculateMatrix`
   - `datasetApi.updateItem`, `datasetApi.getOutfitMasters`, `datasetApi.exportDataset`
   - `trainingApi.startJob`, `trainingApi.stopJob`, `trainingApi.getJobStatus`
   - `benchmarkApi.generatePrompts`, `benchmarkApi.evaluate`
3. **`frontend/src/pages/DatasetStudioPage/useStudioStore.ts`**:
   - Zustand ストアを作成し、上記状態とアクションを管理。
