## 3. 実装要件 (Implementation Logic)
- [x] **Zustand Storeの更新** (`useGenerationStore.ts`):
  - `sets` データを LocalStorage ではなく、APIから同期できるように `setSets` アクションを追加する。
  - `activeSetId` は `string | number` を許容するように型を変更する（プリセットIDは `number` であるため）。
  - `addSet` などのローカルのみの LocalStorage 更新ロジックを修正/廃止し、プリセットAPI経由で作成されたプリセットが store に流し込まれるようにする。
  - プロファイルのチェック状態（`checked`）を管理するため、LocalStorage を利用した `checked` 状態の保存・取得ロジック（`prompt-surgeon-checked-presets-{workflowId}`）を実装する。
- [x] **React Query と Store の同期** (`useGeneratePageState.ts`):
  - `presets` クエリの結果（`WorkflowPreset[]`）が変化したときに、Zustand の `sets` を更新する `useEffect` を実装する。
  - サーバーの `WorkflowPreset` 型を `GenerationSet` 互換（`paramValues`, `appliedAssets`, `batchSize`, etc を持つ）にマッピングし、LocalStorage から `checked` 状態を補完する。
  - `paramValues` や `appliedAssets` などのパラメータ編集時に、現在アクティブなプロファイル（プリセット）を更新する API 呼び出し（`updatePresetMutation`）をデバウンス（1000ms）をかけて自動実行するオートセーブロジックを実装する。
