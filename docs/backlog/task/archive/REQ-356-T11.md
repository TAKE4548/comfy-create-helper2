# REQ-356-T11: [Test Name Format & Audit] AC-15 / AC-9 テスト名フォーマット検証および grep 逆引きの完全性担保

## 1. 概要と目的
再構成完了後のFrontendおよびBackendの全テストファイルに対し、テスト名の命名形式検証スクリプト `scripts/verify_test_naming.py` を実行し、全PBI紐づきテストが `[REQ-xxx/AC-n]` 形式を満たしていること、ファイル名（パス）に `req[0-9]+` を含むものが0件であることを機械的に検証・合格させる（AC-1, AC-9, AC-15）。
また、`grep -rn "REQ-<番号>"` で各PBIのテストが確実に逆引きできることをサンプリングおよび網羅確認する。
