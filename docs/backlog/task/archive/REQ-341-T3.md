# REQ-341-T3: Generate画面ヘッダー左クラスタリング・ワークフロー個別設定⋯集約

## 1. 概要と目的
Generate画面（DesktopLayout / MobileLayout）のヘッダーを `PageHeader` へ置き換え、主要操作（ワークフロー選択 ＋ ワークフロー個別設定「⋯」メニュー ＋ Anima特化チェックボックス ＋ Undo/Redo）をタイトルの直後（左側）に左クラスタリング配置する。
また、旧 `SettingsPopover` からワークフロー個別設定（ベースモデル紐付け、デフォルト値保存・リセット、名前変更、複製、再スキャン）をワークフローセレクタ直横の `WorkflowActionsMenu.tsx`（「⋯」ボタン）へ集約・分離し、ヘッダーから旧来の「ComfyUI本体URL」直通表示・入力を完全撤廃する。
AC-2（Generate画面の左クラスタリング）、AC-5（ComfyUI直通URL撤廃）、AC-6（ワークフロー設定分離集約）を担保する。

## 2. ターゲット識別
- **対象ファイル**:
  - `frontend/src/pages/GeneratePage/components/WorkflowActionsMenu.tsx` (新規)
  - `frontend/src/pages/GeneratePage/components/DesktopLayout.tsx`
  - `frontend/src/pages/GeneratePage/components/MobileLayout.tsx`
- **対象シンボル**:
  - `WorkflowActionsMenu`: ワークフローセレクタ直横の「⋯」ボタン ＋ 設定ドロップダウン
  - `DesktopLayout`: ヘッダー領域を `PageHeader` に移行
  - `MobileLayout`: モバイルヘッダー領域を `PageHeader` に移行
