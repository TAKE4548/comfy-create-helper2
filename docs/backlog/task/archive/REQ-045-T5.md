## 3. 実装要件 (Implementation Logic)
- [x] `frontend/src/pages/GeneratePage/hooks/useWorkflowParams.ts`
  - `saveDefaultParamsMutation` の `mutationFn` および `workflowsApi.update` 呼び出しに `default_applied_assets` パラメータを追加する。
  - `handleSaveDefaultParams` において、現在の `useGenerationStore` から `appliedAssets` を取得し、それを `JSON.stringify(appliedAssets)` にして、`workflowsApi.update` (mutation) に `default_applied_assets` 引数として渡す。
  - `useEffect` (初期化) 処理にて、`workflow.default_applied_assets` が DB から取得できた場合、それをパースし、store 内の `appliedAssets` に適用する（Zustand store に `setAppliedAssets(assets)` が無ければ追加するか、あるいは store 全体のアクションで更新する）。
  - `handleResetDefaultParams` において、DB の `workflow.default_applied_assets` があればそれを適用し、LocalStorage にも書き込むように修正する。
  - ※ store 側に直接 `appliedAssets` をまるごと設定する `setAppliedAssets` アクションを追加する必要がある場合は `useGenerationStore.ts` に `setAppliedAssets` を追加する。
