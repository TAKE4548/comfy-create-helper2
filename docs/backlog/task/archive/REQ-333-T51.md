# REQ-333-T51

ユーザー報告: 自動追従ONでも生成完了ごとに追従しない。connectionSliceは完了原画をselectedImgへ選ぶが、次job画像未受信では直前jobのpreviewImageを保持し、表示優先順位で原画を覆う。自sessionの成功完了でauto-followした原画が、完了jobの古いpreviewに覆われないようにする。次jobの実frameが既に来ている場合は、その新frameを消さない。進捗だけでは表示を消さず、完了前・autoFollow OFF・他sessionでは従来通り。手動選択/clear、epoch変更、Snapshot/Studio境界を維持。

## Impacted Files
- frontend/src/store/slices/connectionSlice.ts
- frontend/src/store/__tests__/slices/connectionSlice.test.ts

## Verification Command
```powershell
Set-Location frontend
npx vitest run src/store/__tests__/slices/connectionSlice.test.ts src/pages/GeneratePage/hooks/__tests__/useGenerateDisplayState.test.tsx
npm run typecheck
```

TDDでA frame→A succeeded＋B running/null frameでA原画表示、B realframe受信で更新、B frame先行後A completionでB frame保持、その後progressだけでも保持。OFF/foreign/手動lockを回帰。別の確定原因が見つかったら所有外編集前にCoordinatorへ報告。
