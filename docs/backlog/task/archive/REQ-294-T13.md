## 密封コンテキスト: 既存ルートと提案イベント

現行のimport/ルートは次の形。`get_db` は旧JSONルートだけが使用し、新streamルートはgenerator内 `SessionLocal()` と `finally: db.close()` を使う。

```python
from fastapi import APIRouter, Depends, HTTPException, status
from sqlalchemy.orm import Session
from app.database import get_db
from app.schemas.speech import SceneDraftRequest, SceneDraftResponse
from app.services import speech_scene_service

router = APIRouter(prefix="/api/speech", tags=["speech-scene"])

@router.post("/scene-draft", response_model=SceneDraftResponse)
async def generate_scene_draft(
    payload: SceneDraftRequest,
    db: Session = Depends(get_db),
):
    ...
```

追加import: `asyncio`, `json`, `httpx`, `StreamingResponse` (`fastapi.responses`), `SessionLocal` (`app.database`), 必要なら `Any` (`typing`)。進捗はT12の `progress_callback(key, status)` を介し、queueへ `{"type":"progress","step":key,"status":status}` を積む。`result` は現行ルート同様の `SceneDraftResponse(...).model_dump(mode="json")` を `data` に入れる。`error` は `{"type":"error","error_kind":string,"message":string}`。`httpx.HTTPStatusError` の400、`httpx.ConnectError`、`httpx.TimeoutException` をそれぞれ `lm_studio_400`、`connection_refused`、`timeout`、service内ValueErrorを `invalid_request`、unload falseを `vram_unload_failed`、その他を `unknown` にする。各行末尾は `\n`。切断時にproducerをcancelしてawaitし、serviceのunloadとDB closeを待つ。例外はHTTPヘッダー送信後には4xx/5xxへ変えずerror行へ載せる。キャンセル時にerror行を無理に書かない。
