## 現状（変更箇所 `backend/app/services/generation_repository.py` L289-322）

```python
    def snapshot(self) -> dict[str, Any]:
        db = self._session_factory()
        try:
            jobs = db.query(GenerationJob).order_by(
                GenerationJob.accepted_at.asc(), GenerationJob.item_index.asc()
            ).all()
            revision = int(_setting_value(db, _REVISION_KEY, "0"))
            normal_group_id = _setting_value(db, _NORMAL_GROUP_KEY, "") or None
            batches_by_id: dict[str, dict[str, Any]] = {}
            job_views = [_job_view(job) for job in jobs]
            for job in jobs:
                batches_by_id.setdefault(job.batch_id, {
                    "batch_id": job.batch_id,
                    "scope": job.scope,
                    "project_id": job.project_id,
                })
            return {
                "version": 1, "epoch": self.epoch, "revision": revision,
                "normal_group_id": normal_group_id, "jobs": job_views,
                "batches": list(batches_by_id.values()),
                "upstream": {"http_ready": False, "ws_connected": False, "failure_since": None},
            }
        except Exception as exc:
            db.rollback()
            raise HTTPException(status_code=503, detail="Generation state is unavailable") from exc
        finally:
            db.close()
```

関連する既存定義: `_REVISION_KEY = "generation_revision"`、`_NORMAL_GROUP_KEY = "generation_normal_group_id"`、`_TERMINAL_STATUSES = ("succeeded","failed","cancelled","released")`、`_job_view(job) -> dict`（L137。`_prompt_excerpt(job.metadata_json)` を呼ぶ）、`_increment_revision(db)` はすべての書込みメソッド（`accept_batch`/`transition`/`release_unconfirmed`/`annotate_late_identity`/`prune_terminal`）で呼ばれる。モデルは `app.models.GenerationJob`（列: job_id PK, prompt_id unique, session_id, batch_id(index), normal_group_id(index), status(index), metadata_json Text, release_json Text, accepted_at, item_index ほか）。SQLite 3.42（window関数・`json_extract` 可）。

## 実装契約

1. 定数を追加する: `_SNAPSHOT_STATUSES_ACTIVE = ("queued","submitting","running","unconfirmed")`、`_SNAPSHOT_RECENT_BATCHES = 20`、`_SNAPSHOT_RELEASED_PER_SESSION = 10`、`_EXCERPT_MEMO_LIMIT = 4096`。
2. `__init__` に `self._snapshot_cache: tuple[tuple[int, str | None], dict[str, Any]] | None = None`、`self._excerpt_memo: dict[tuple[str, str | None], str | None] = {}`、`self._cache_lock = threading.Lock()` を追加する。
3. `snapshot()`:
   - 最初に revision と normal_group_id だけを読み、`key = (revision, normal_group_id)` を作る。キャッシュのキーと一致すれば `copy.deepcopy(cached)` を返し、`generation_jobs` には問い合わせない。
   - 一致しなければ窓クエリを実行する。`or_` で条件を組む: status ∈ 非終端 / `batch_id IN (非終端jobの batch_id)` / `normal_group_id == 現在group`（None なら省略）/ `batch_id IN (SELECT batch_id … GROUP BY batch_id ORDER BY MAX(accepted_at) DESC LIMIT 20)` / `job_id IN (row_number() OVER (PARTITION BY session_id ORDER BY json_extract(release_json,'$.released_at') DESC, job_id DESC) <= 10 かつ status='released')`。
   - 並びは `accepted_at ASC, item_index ASC`。`metadata_json` は `sqlalchemy.orm.defer` で遅延させる。
   - prompt 抜粋は `_excerpt_memo[(job_id, prompt_id)]` を優先する。未登録の job_id だけ `select(GenerationJob.job_id, GenerationJob.metadata_json).where(job_id.in_(...))` で一括取得し、`_prompt_excerpt` で算出して登録する。メモが上限を超えたら最古挿入から削除する（dict の挿入順）。
   - view は既存 `_job_view` と同じキー集合で作る。`_job_view` に `excerpt` 引数（省略時は従来どおり算出）を足す形を推奨する。
   - 結果をキャッシュへ保存し、deepcopy を返す。例外時の 503 は従来どおり。
4. 追加メソッド（同じ 503/クローズ規約）:
   - `def get_job(self, job_id: str) -> dict[str, Any] | None`: `db.get(GenerationJob, job_id)` → `_job_view` または None。
   - `def find_job_by_prompt(self, prompt_id: str) -> dict[str, Any] | None`: `prompt_id` で1件取得 → `_job_view` または None。
