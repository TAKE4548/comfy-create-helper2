# REQ-351-T3: ステージ付き role の保存・再取得（AC-6 のバックエンド側）

## 1. 概要と目的

- 種別: change_kind = code、subsystem = backend、実行ロール = engineer（init-task スキャフォールドのフロントマターにこれらのキーがないため本文に記載する）。
- AC-6: 代表と同期先を保存済みの状態で同じワークフローの ParamSync を再表示すると、選択したロール×ステージが復元される。本 Card はその前提である「ステージ接尾辞付き role 文字列（`computed_role`）が API で保存・再取得・部分更新されても値と順序が保たれる」ことをテストで固定する。バックエンドのソースは変更しない（テストのみ）。
