# REQ-346-T13: `PageHeader` ルートに `data-page-header-root` を付与 (AC-1,2,6 の基盤)

## 変更内容（確定）
ルート `div` に属性を 1 つ追加する（他は不変）:
```tsx
    <div data-page-header-root="" className={`w-full border-b border-[rgba(255,255,255,0.06)] bg-surface ${className}`}>
```
- この要素の下端が「ヘッダー下端」。モバイル（768px 未満）で 2 行目へ折り返した `actions` 行、`subtitle`、`children` もこのルートの内側＝ヘッダー下端に含まれる。
- ルート直下の構造（`min-h-[50px]` 行、`overflow-x-auto` の actions 枠、右クラスタ）は変更しない。

## テスト追加（`PageHeader.test.tsx` の既存 `describe` へ追記。既存ケースは無変更で PASS を維持）
- `[REQ-346/AC-1] the PageHeader root element carries data-page-header-root exactly once so expand panels can anchor to the header bottom`: `container.firstElementChild` が `data-page-header-root` を持ち、`container.querySelectorAll('[data-page-header-root]')` が 1 件。`hideRightCluster` あり／なし、`actions` あり／なしのいずれでも 1 件。
- `[REQ-346/AC-1] the attribute matches the placement module's PAGE_HEADER_ROOT_SELECTOR`: `import { PAGE_HEADER_ROOT_SELECTOR } from '../header/headerMenuPlacement'` を使い `container.querySelector(PAGE_HEADER_ROOT_SELECTOR) === container.firstElementChild`（セレクタ定数と属性リテラルの不一致検知。設計 R-15）。
- `[REQ-346/AC-1] the attribute does not change the header layout classes`: ルートの `className` に `w-full`／`border-b`／`bg-surface` を含み、`className` props がそのまま連結される（`className="extra"` → 含まれる）。actions 枠は引き続き `overflow-x-auto`（既存ケースで担保済みのため、新ケースはルートのクラス保持のみ）。
