## 変更内容
### A. カスタム型マスタのオンデマンド化 (AC-4)
1. ヘッダ（`Node Mapping Masters` 行）の「ステージ管理」の隣に `カスタム型マスタ` ボタンを追加（`aria-haspopup="dialog"`、`onClick`で `setShowParamTypeManager(true)`、`e.stopPropagation()` は既存ラッパ `onClick` で済）。
2. 展開領域の **「Custom Param Types Bar」ブロック全体を削除**（ページ内常時展開をやめる）。
3. 新state `const [showParamTypeManager, setShowParamTypeManager] = useState(false)`。排他遷移:
```tsx
<ParamTypeMasterManagerModal
  isOpen={showParamTypeManager}
  items={paramTypeMasters}
  onClose={() => setShowParamTypeManager(false)}
  onCreate={() => { setShowParamTypeManager(false); setEditingParamType(null); setParamTypeModalMode('create') }}
  onEdit={(item) => { setShowParamTypeManager(false); setEditingParamType(item); setParamTypeModalMode('edit') }}
  onDelete={(item) => deleteParamTypeMutation.mutate(item.id)}
/>
```
   既存 `ParamTypeMasterModal` の `onClose` と create/update 成功時は `setParamTypeModalMode(null); setEditingParamType(null); setShowParamTypeManager(true)`（一覧へ戻る）。**同時に開く`dialog`は常に1つ**（ネスト禁止）。

### B. MasterRow モバイル超スリムカード (AC-3)
```tsx
<div ref={setNodeRef} style={style} className="settings-mobile-card p-3 border-b border-zinc-800 hover:bg-zinc-800/20 transition-colors">
  <div className="settings-mobile-card__title flex min-w-0 items-center gap-3">
    {/* 並び替えハンドル（aria-label 不変） */}
    <span className="min-w-0 flex-1 truncate font-medium text-zinc-100" title={displayName}>{displayName}</span>
    <span className="settings-mobile-card__target-node text-xs font-mono text-zinc-400">({master.param_name})</span>
  </div>
  <div className="settings-mobile-card__actions"> {/* 編集・削除ボタン（モバイルで右端固定） */} </div>
  <div className="settings-mobile-card__badges"> {/* input_type バッジ、+N classes、先頭variantバッジ、+N stages、default_enabled警告 */} </div>
</div>
```
- Target Node情報（`param_name` と `expected_class_types`）はモバイルで `settings-mobile-card__target-node` により非表示。編集ボタンの `aria-label` に集約:
  `aria-label={`${displayName} のマッピング設定を編集（対象ノード: ${master.param_name}${classes.length ? ' / ' + classes.join(', ') : ''}）`}`（`classes = master.expected_class_types ?? []`）。削除ボタンの `aria-label` は `${displayName} を削除` のまま。
- `expected_class_types.length > 1` のとき `+{n-1} classes` バッジ（`shrink-0 whitespace-nowrap`）。variants は DOM に1度だけ出力: 先頭variantは常時表示、2件目以降は `hidden md:inline-flex`、`variants.length > 1` のとき `md:hidden` の `+{n-1} stages` バッジ。名前重複のDOM出力はしない（既存`getByText`互換）。
- 編集/削除/並び替えボタン: 最小44×44（`min-h-11 min-w-11 inline-flex items-center justify-center`）、Hit-Slop `before:absolute before:-inset-2`、`touch-manipulation`。DnD用ハンドルのリスナー（`{...attributes} {...listeners}`）は維持。
