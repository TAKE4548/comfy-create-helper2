## 3. 実装要件 (Implementation Logic)
1. **状態管理の追加**:
   - `GeneratePage.tsx` 内で、各プロンプト枠（role）の折り畳み状態を保持する状態 `collapsedRoles` を定義する。
   - 初期値のロード時に `localStorage` から `prompt-surgeon-collapsed-${role}` の値をパースして初期状態を設定する（デフォルトは展開状態 `false` とする）。
   - 状態更新用のユーティリティ `setRoleCollapsed(role: string, isCollapsed: boolean)` を用意し、状態更新と同時に `localStorage` に保存する。

2. **トグルUIの配置とスタイル (デスクトップ)**:
   - ヘッダー（タイトル）エリアのラベル `label` をクリック可能なスタイルにするか、ラベル横に Chevron アイコン（`ChevronDown` または `ChevronRight`）を追加し、クリックでトグルできるようにする。
   - 折り畳み状態のとき（`isCollapsed === true` のとき）、`TagChipEditor`、`Add Asset` ボタン、および `AppliedAssetChips` を条件付きレンダリング（例：`{ !isCollapsed && <TagChipEditor ... /> }`）で非表示にし、縦方向の占有スペースを最小化する。

3. **トグルUIの配置とスタイル (モバイル)**:
   - モバイル版（`isMobile` が `true` のとき）についても、現在表示中の active tab の入力エリア（`L796-L835` 付近）のヘッダー部分に Chevron アイコンを配置し、クリックで入力エリア（`textarea`）、Add Assetボタン、AppliedAssetChips を折り畳める（非表示にする）ようにする。
   - 折り畳み状態はデスクトップ版と共通の `collapsedRoles` 状態および `localStorage` に連動させる。

4. **アセット追加時の自動展開**:
   - `handleAddLoraAsset` および `handleAddTagSetAsset` は `GeneratePage.tsx` 内のスコープに定義されており、アセットが追加された時点で `setRoleCollapsed(role, false)` を呼び出してセクションを強制的に展開状態にする。

5. **テキストモード切替時の自動展開**:
   - `TagChipEditor/index.tsx` 内の `handleSwitchToTextMode` および `handleSwitchToChipMode` 実行時に、`tag-chip-editor:text-mode-toggle` カスタムイベントを window にディスパッチする。
   - `GeneratePage.tsx` の `useEffect` 内でこのイベントをリッスンし、イベントの発火元となった `id` から `role` 名（`prompt-${role}` から `role` を抽出）を割り出して `setRoleCollapsed(role, false)` を実行する。
