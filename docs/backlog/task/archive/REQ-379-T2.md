### REQ-379-T2: バックエンド原画確認プローブおよびデッドコードの撤廃

#### 1. 目的とスコープ
- `backend/app/routers/comfy.py` の `get_comfy_thumbnail` 内に残存する未使用関数 `_check_comfy_exists` を削除する（AC-3）。
- `backend/app/services/residual_history.py` における `probe_image_availability` 呼び出しを撤廃し、ComfyUI `/history` から取得された候補はComfyUIへの追加プローブを行わずに即座に `items`（present）として返却する（AC-3）。
- `test_comfy_proxy.py` にデッドコード除去の検証テストを追加し、既存の `test_residual_history.py` および `test_comfy_proxy_fault.py` を新仕様に合わせて更新する（AC-3）。

#### 2. 対象ファイルと変更箇所（Surgical Snippets）
- **対象ファイル**: `backend/app/routers/comfy.py`
  - `get_comfy_thumbnail` 内の未使用関数 `_check_comfy_exists` (lines 444-446) を削除。
- **対象ファイル**: `backend/app/services/residual_history.py`
  - `get_residual_history` の `pending` 候補を ComfyUI への外部 HEAD プローブを行わず直接 `items` に追加。

```python
# residual_history.py: 直接 items に追加
items = []
for (filename, subfolder, image_type), (_, session_id) in page:
    image_identity = ImageIdentity(filename=filename, subfolder=subfolder, type=image_type)
    query = urlencode({"filename": filename, "subfolder": subfolder, "type": image_type})
    items.append(ResidualHistoryItem(identity=image_identity, view_url=f"/api/comfy/view?{query}", session_id=session_id))
return ResidualHistoryResponse(items=items, rejected=[], has_more=len(pending) > len(page))
```
