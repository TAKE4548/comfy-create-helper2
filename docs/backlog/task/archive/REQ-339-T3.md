### REQ-339-T3: SSoT 仕様書更新および E2E 統合検証テスト実装

- **Type**: verification
- **Subsystem**: frontend
- **Dependencies**: REQ-339-T1, REQ-339-T2

#### 1. 目的と変更概要
`docs/specs/SPEC_GENERATE.md` の仕様記述（2-9節のプレビュー分割・並列結果閲覧、2-10節のPCリソース監視HUD）をREQ-339の変更に合わせて同期（SSoT整合）し、統合E2Eテスト `e2e_req339_preview_layout.test.tsx` を作成して全受入基準（AC-1〜AC-8）の準拠を検証する。

#### 2. 対象ファイルと変更箇所のコードスニペット
**Target 1**: `docs/specs/SPEC_GENERATE.md`
- 2-9節: 「`GenerateParallelPreview` はプレビュー領域の利用可能高さに合わせて全画像の高さを揃え、各画像本来のアスペクト比を維持したまま、利用可能横幅に収まる最大枚数を動的に配置する。非2:3画像でも歪みや余白を生じさせない」旨を反映。
- 2-10節: 「デスクトップではプレビューエリア内の重畳HUDを廃止し、Global Header内に `ResourceGaugeChips` として配置してプレビュー領域の遮蔽を完全排除する」旨を反映。

**Target 2**: `frontend/src/test/e2e_req339_preview_layout.test.tsx`
- 複数アスペクト比（16:9, 1:1, 2:3）の画像セット描画における高さ統一と動的横並び枚数の検証。
- ペインリサイズに応じた動的追従の検証。
- デスクトップヘッダーにおけるリソースチップ描画とプレビュー重畳HUD不在の検証。

#### 3. 検証コマンド
```bash
cd frontend; npm run typecheck && npx vitest run src/test/e2e_req339_preview_layout.test.tsx
```
