# TASK-REQ-066-T1: 共通ユーティリティとフックの長押し感度対応

## 1. ターゲット識別
- **対象ファイル**:
  - `frontend/src/utils/localStorageKeys.ts`
  - `frontend/src/hooks/useMultiSelect.ts`
  - `frontend/src/hooks/__tests__/useMultiSelect.test.ts`

## 2. 密閉コンテキスト (Hermetic Context)
<hermetic_context>
### 2.1 useMultiSelect.ts における既存の getLongPressHandlers
```typescript
  const getLongPressHandlers = useCallback(
    (id: number) => {
      let timer: ReturnType<typeof setTimeout> | null = null;

      const start = (e: React.MouseEvent | React.TouchEvent) => {
        // Prevent trigger on right click
        if ('button' in e && e.button !== 0) return;
        timer = setTimeout(() => {
          enterMultiSelectMode(id);
        }, 500);
      };

      const clear = () => {
        if (timer) {
          clearTimeout(timer);
          timer = null;
        }
      };

      return {
        onMouseDown: start,
        onMouseUp: clear,
        onMouseLeave: clear,
        onTouchStart: start,
        onTouchEnd: clear,
      };
    },
    [enterMultiSelectMode]
  );
```
</hermetic_context>

## 3. 実装要件 (Implementation Logic)

### 3.1 localStorageKeys.ts へのキー追加
- `LS_KEYS` に以下の新しい定数を追加する：
  - `LONG_PRESS_DELAY_MULTI_SELECT`: `'prompt-surgeon-longpress-delay-multiselect'`
  - `LONG_PRESS_DELAY_CARD_MOVE`: `'prompt-surgeon-longpress-delay-cardmove'`

### 3.2 useMultiSelect.ts の修正
- `useMultiSelect` フック内の `getLongPressHandlers` において：
  - `localStorage` から `LS_KEYS.LONG_PRESS_DELAY_MULTI_SELECT` キーで値を取得する。
  - 値が存在し数値に変換可能な場合はそれを秒単位からミリ秒単位（`秒数 * 1000`）にして使用する。
  - 値が存在しない、または無効な場合はデフォルト値である `800` ms (0.8秒) を使用する。

### 3.3 useMultiSelect.test.ts の修正とテスト追加
- `vitest` のテストケースにおいて、`localStorage` の設定値をモック（または設定）して長押し時間が動的に変更されることをテストする。
- デフォルト状態のテストケースも `800` ms に合わせて調整する。

## 4. 検証手順 (AC)
- 以下のコマンドで、修正後の `useMultiSelect` テストがすべて通ることを確認。

npm --prefix frontend run test src/hooks/__tests__/useMultiSelect.test.ts
