## 3. 実装要件 (Implementation Logic)
- **1. Store の修正 (`useGenerationStore.ts`)**:
  - `GenerationState` に `comfyUrl` と `setComfyUrl` を追加する。
  - `initialize` の際、`localStorage` の `'prompt-surgeon-comfy-url'` が存在すればそれを使用し、なければ backend から取得した `config.comfy_url` を使用して `comfyUrl` 状態を更新する。
  - `setComfyUrl` が呼び出された際、値を `localStorage` に書き込み、既存の WebSocket コネクションをクローズし、新しい URL で再初期化 (`get().initialize()`) を行う。
- **2. ワークフロー設定のポップオーバー化**:
  - ワークフロー選択セレクトボックスの右側にギアボタン（Lucideの `Settings`）を配置。
  - ポップオーバーUIを実装し、ギアボタンをクリックした時に表示・非表示を切り替える。
  - ポップオーバー内に、ComfyUI URL のテキスト入力欄と、「デフォルト保存」ボタン・「リセット」ボタンを配置。ComfyUI URL 入力欄の入力変更時に `setComfyUrl` がトリガーされるようにする。
- **3. 非ブロッキングプログレスバーの採用**:
  - 画面全体を覆うブロッキングオーバーレイを廃止。
  - 生成中であってもメインプレビュー画像（`previewImage` または `selectedImg`）を表示する。
  - プレビュー領域の下端に高さ 4px の薄いプログレスバー (`bg-accent-green`) を表示する。
- **4. 履歴・スナップショットのタブ統合**:
  - サムネイルストリップの領域に、「履歴 (History)」と「スナップショット (Snapshots)」のタブ（`button` によるタブ切り替え）を追加。
  - 「履歴」タブは従来の ComfyUI から取得した生成履歴画像一覧を表示。
  - 「スナップショット」タブは、`snapshots` クエリから取得した現在のワークフローのスナップショット一覧を、画像サムネイル付きの横並びカードで表示。クリック時に `handleLoadSnapshot(snapshot.id)` を呼び出す。
- **5. 保存ボタンのカメラアイコン化**:
  - 「Save Snapshot」ボタンの Lucide アイコンを `Save` から `Camera` に変更する。
- **6. メインプレビューのサイズ調整と装飾 (旧REQ-019)**:
  - プレビューエリア内の画像表示部分をコンテナに対して中央配置し、最大サイズを約 `h-[70%] w-[70%]` 程度に調整。
  - 画像の周囲に `border border-zinc-800 shadow-2xl rounded-lg` のカード風の枠線と影を設定する。
- **7. 左右切り替えボタンとキーボードショートカット (旧REQ-019)**:
  - メインプレビュー領域にマウスホバーした際、左右に絶対配置のアローボタン (`<` / `>`) を表示する。クリックで履歴画像の前後へ遷移する。
  - メインプレビューコンテナに `tabIndex={0}` と `outline-none` を設定し、フォーカス時に左右矢印キー (`ArrowLeft` / `ArrowRight`) で履歴画像を切り替えられるようにする。インプットやテキストエリアにフォーカスがある場合はキーボードショートカットを無効化する。
