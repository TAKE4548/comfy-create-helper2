## 3. 実装要件 (Implementation Logic)
- **Store側変更 (`useGenerationStore.ts`)**:
  1. `GenerationState` に `queueRunning`, `queuePending`, `fetchQueue` を追加する。
  2. `fetchQueue` は `comfyUrl` が設定されている場合に `${resolvedUrl}/queue` からキューを取得し、`queueRunning` と `queuePending` の状態を更新する。
  3. WebSocket接続開始時、および status, execution_start, executed, execution_complete, execution_error を受信した際に `fetchQueue()` を呼び出してキュー情報を最新化する。
  4. `queuePrompt` および `cancelGeneration` の呼び出し完了時にも `fetchQueue()` を呼び出す。
- **UI側変更 (`GeneratePage.tsx`)**:
  1. モバイル・デスクトップそれぞれのプレビュー表示付近に進捗状態（`isGeneratingHere` や `progress`）とキュー件数（`Queue: X`）を常時表示する。
  2. 「自セッションのみ」チェックボックスの状態 (`filterOwnSession`) と連動し、チェック時は `queueRunning` と `queuePending` 内のジョブから `client_id === clientId` であるもののみを集計する。チェックがない場合は全件を集計する。
  3. 未生成時は `Queue: 0 (0%)` などのように0%およびキュー0件の状態で常時表示を維持する。
