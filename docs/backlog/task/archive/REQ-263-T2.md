### 2.1 既存コード
#### `tools/server-manager/allow_firewall_8000.bat`:
```cmd
@echo off
title Prompt Surgeon - Allow Port 8000 in Firewall
net session >nul 2>&1
if %errorLevel% neq 0 (
    echo Administrator privileges required. Requesting elevation...
    powershell -Command "Start-Process '%~f0' -Verb RunAs"
    exit /b
)
powershell -Command "New-NetFirewallRule -DisplayName 'Prompt Surgeon Backend & UI (8000)' -Direction Inbound -LocalPort 8000 -Protocol TCP -Action Allow -Profile Any -ErrorAction SilentlyContinue"
echo Firewall rule added for Port 8000.
pause
```

## 3. 実装要件
1. **`tools/server-manager/allow_firewall_all.bat` の新規作成**:
   - 管理者権限（UAC昇格）の自動チェックと再起動。

     - Port 8899: `Prompt Surgeon Web Manager (8899)`

   - 単体 Port 8000 の登録を維持しつつ、ComfyUI (8188) を含む全体一括設定スクリプト（`allow_firewall_all.bat`）の実行を促すメッセージを追加。
