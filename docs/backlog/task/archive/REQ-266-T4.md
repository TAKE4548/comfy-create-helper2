## 4. 実装要件・手順
1. **`connectionSlice.test.ts` の拡充**:
   - `it('starts heartbeat timer on open and sends ping, clears on close')`: `vi.useFakeTimers()` を用い、`ws.onopen()` 後に 25 秒進めた際に `ws.send` が `{"type":"ping"}` を引数に呼び出されること、`ws.onclose()` でタイマーが解除されることを検証。
   - `it('schedules reconnection with exponential backoff on onError')`: `ws.onerror()` 発生時に再接続タイマーがセットされ、リトライ回数に応じて遅延が増加することを検証。
   - `it('resets retry count and delay upon successful onOpen')`: 再接続成功後に `comfyWsService.getReconnectDelay()` が初期値（1秒系）に戻ることを検証。
   - `it('forces re-initialization when initialize is called with force: true')`: `isConnected: false` 時に `initialize({ force: true })` が新規接続を試みることを検証。
2. **`useGeneratePageState.test.tsx` の拡充**:
   - `it('triggers store.initialize when visibility becomes visible and isConnected is false')`: `useGenerationStore` の `isConnected` を `false` に設定した状態で `visibilitychange` イベントをディスパッチし、`initialize({ force: true })` が呼び出されることを検証。
