function SortableItem({
  id,
  children,
  disabled
}: {
  id: number
  children: React.ReactNode
  disabled?: boolean
}) {
  const {
    attributes,
    listeners,
    setNodeRef,
    transform,
    transition,
    isDragging
  } = useSortable({ id, disabled })

  const style = {
    transform: CSS.Transform.toString(transform),
    transition,
    zIndex: isDragging ? 10 : 1,
    opacity: isDragging ? 0.8 : 1,
    touchAction: 'none'
  }

  return (
    <div ref={setNodeRef} style={style} className="h-full w-full relative">
      <div {...attributes} {...listeners} className="h-full w-full">
        {children}
      </div>
    </div>
  )
}

## 3. 実装要件 (Implementation Logic)
- [x] `frontend/src/pages/HistoryPage.tsx` のインポートとセンサー定義を変更する。
  - `@dnd-kit/core` から `PointerSensor` を除外し、`MouseSensor`, `TouchSensor` をインポートする。
  - `sensors` 定義を以下に置き換える：
    - `MouseSensor` で `distance: 8` のアプライを設定。
    - `TouchSensor` で `delay: 500, tolerance: 5` のアプライを設定。
- [x] `SortableItem` コンポーネント内の `style` を調整し、ドラッグ時の視覚効果を追加する。
  - `transform`: `transform` がある場合は `${CSS.Transform.toString(transform)} scale(1.05)`、ない場合は `isDragging ? 'scale(1.05)' : undefined`。
  - `zIndex`: `isDragging ? 50 : 1`（重なりの最前面に配置）。
  - `opacity`: `isDragging ? 0.9 : 1`（背面がわずかに透ける状態にする）。
  - `boxShadow`: `isDragging ? '0 20px 25px -5px rgba(0, 0, 0, 0.5), 0 10px 10px -5px rgba(0, 0, 0, 0.5)' : undefined`（浮き上がり影を追加）。
