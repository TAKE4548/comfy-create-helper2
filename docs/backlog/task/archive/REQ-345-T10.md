## Implementation Logic

- [ ] bootstrapHistoryOnceとhistoryBootstrappedを除去。初回/epoch切替の同期でgetHistory/fetchHistoryを呼ばない。
- [ ] 初回/epoch切替に過去成功出力をstoreへmergeしない。同epochのsuccess遷移のみ実行完了event/既存merge対象とし、全過去成功jobを毎snapshotで差分へ混ぜない。
- [ ] 進捗/queue/revision/epoch同期、queue照会、session分類、成功遷移のautoFollowは維持。History/Snapshot/Studioに新差分要求を追加しない。
- [ ] 遅延HTTP/WS/同revision/epoch切替/force initializeの既存試験を保持。fixture expectationsで無条件bootstrap依存のみ改訂する。
- [ ] first snapshotがpending→succeeded transitionになる前にreload差分が走っても後続成功eventは保持。多重snapshotで旧job再挿入なし。
