## Implementation Logic

- [ ] load/error双方でobserve(img,stableOwner)。thumbnailErrors/retryVersionsはUI局所、API/store更新はT3へ集約。
- [ ] undefined/checkingは確認placeholder、「原画を確認中…」、click/keyboard/長押し抑止。presentでサムネ表示。unknownでサムネ/選択保持、明示retry。
- [ ] 独自pending/completed/identityをcontrollerに統合。owner登録は実load/errorのみ、list変更でretainOwnerImages、unmount/branch切替でreleaseOwner。render全件probeなし。
- [ ] retryはstopPropagation、unknownをcheck({retry:true})、サムネkey更新。pendingを消さずmissing再開なし。
- [ ] Snapshot branchにはobserve/確認placeholderを適用しない。同URLでも画像/params維持。
- [ ] 新test: cache成功+missing/present、503 unknown、複数owner共有、checking操作抑止、retry伝播抑止、Snapshot非登録。
- [ ] 旧REQ-333 fixtureへcontrollerを注入し新確認契機へ更新。errorのpresent/unknown/保護期待値維持。3ファイル合計290変更行。

## Controller Dependency Contract

T1がexportする型は以下。T3/T4はこの契約を使用し別のpending集合を作らない。
~~~ts
import type { ImageIdentity, ImageAvailability } from '../../../../api/domains/generation'
// 実際のimport relative depthは変更先ディレクトリに合わせる。
type TrialAvailability = 'checking' | 'present' | 'missing' | 'unknown'
interface TrialIdentity { key: string; request: ImageIdentity }
interface TrialAvailabilityController {
  getIdentity(url: string): TrialIdentity | null
  getStatus(url: string): TrialAvailability | undefined
  observe(url: string, owner: object): void
  retainOwnerImages(owner: object, urls: readonly string[]): void
  releaseOwner(owner: object): void
  adopt(url: string, availability: ImageAvailability['availability']): void
  check(url: string, options?: { retry?: boolean }): Promise<TrialAvailability>
  refreshVisible(): void
  subscribe(listener: (url: string, status: TrialAvailability) => void): () => void
  dispose(): void
}
declare function createTrialAvailabilityController(
  probe: (identity: ImageIdentity) => Promise<ImageAvailability>
): TrialAvailabilityController
~~~

## Residual Sync Status UI
