# TASK-REQ-100-02: デスクトップ＆モバイルUIレイアウトの修正 (DesktopLayout.tsx & MobileLayout.tsx)

## 1. ターゲット識別
- **対象ファイル**:
  - `frontend/src/pages/GeneratePage/components/DesktopLayout.tsx`
  - `frontend/src/pages/GeneratePage/components/MobileLayout.tsx`
- **対象シンボル**:
  - `DesktopLayout` (React Component)
  - `MobileLayout` (React Component)

## 2. 密閉コンテキスト (Hermetic Context)
<hermetic_context>
※エンジニアは、UIのタブ表示部分（`sets` をループ処理してレンダリングしている部分）を対象とする。
</hermetic_context>

## 3. 実装要件 (Implementation Logic)
### 3-1. タブ表示部分の修正
1. **タブのフィルタリング:**
   - 画面上にタブをレンダリングする際、Zustandストアから取得した `sets` の中から `openPresetIds` に含まれるもののみを抽出して表示する。
2. **「×」ボタンのハンドリング:**
   - タブ上の「×」ボタンをクリックした際、`removeSet(presetId)` を呼び出す（前タスクで `removeSet` は単に非表示にするよう修正済み）。
3. **プロファイル選択リストでの再表示:**
   - ヘッダー付近またはプロファイル選択ドロップダウンにおいて、DBに存在するすべてのプロファイルを表示する。
   - 閉じられている（`openPresetIds` に含まれていない）プロファイルを選択した際、それを `openPreset(presetId)` して `activeSetId` に設定する。

### 3-2. Undo/Redo用のボタン配置とショートカット
1. **UIボタンの配置:**
   - パラメータパネルまたはタブバーの近傍に、Undo (↩) / Redo (↪) を実行するためのアイコンボタンを配置する。
   - スタックが空の場合は、ボタンを無効化（disabled）にする。
2. **キーボードショートカット:**
   - 生成画面で `Ctrl + Z` が押されたら Undo を、`Ctrl + Y` が押されたら Redo を呼び出すイベントリスナーを登録する。

### 3-3. モバイル対応
1. モバイル画面（`MobileLayout.tsx`）においても同様にタブの「×」で閉じる挙動、プロファイル選択リストからの再表示、Undo/Redoボタンの操作を同一のZustandストア・フックと連携して動作させる。
2. モバイルレイアウトの「Profiles」タブヘッダーエリアに、デスクトップ版と同様のプロファイルポップオーバー（Preset Popover）を開くボタンを追加し、閉じられたプロファイルの再表示、新規プロファイル追加、プリセット管理モーダルの起動をモバイルから可能にする。

  - Undo/Redoボタンが操作に応じて活性・非活性になり、機能すること。
  - `Ctrl + Z` / `Ctrl + Y` が期待通りに動作すること。
