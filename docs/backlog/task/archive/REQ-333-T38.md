# REQ-333-T38

## Approved regression correction

JobView optional `preview_url?: string | null`を受ける。省略可能として旧payload互換を保持し、存在時はnullまたは文字列をruntime検証する。snapshot revisionから架空のpreview URLを作らない。実際のURLが届いた時だけ表示を差し替える。画像のない進捗通知や同jobのnullは直前previewを保持する。次jobがrunningでも未受信なら直前previewまたは選択済み画像を表示し、画像受信で切替。active workが終了した時はpreviewを解除して既存の完了原画へのauto-followを維持。epoch変更時は旧previewを破棄する。ユーザーによる画像選択とclearPreviewは従来通り。別sessionのpreviewへ切替しない。

## Impacted Files

- frontend/src/api/domains/generation.ts
- frontend/src/store/slices/connectionSlice.ts
- frontend/src/store/__tests__/slices/connectionSlice.test.ts

TDDで未受信時にURLを作らない、進捗だけで既存表示を保持、次画像で切替、連続jobの画像未受信・終端・新epochの解除、旧payload互換を検証する。他担当変更を巻き戻さず、カード外変更はCoordinatorへ報告する。
