# REQ-336-T5: Settings画面: 統合マッピング管理UIと親/バリアント編集モーダル

## 1. 概要と目的
Settings ページのマッピングマスタ管理画面を改修し、大カテゴリタブ（プロンプト系、サンプラー系など）による絞り込み表示と、1行に全ステージバリアント（通常、Rough、Detail等）が集約表示される統合テーブルを実装する。また、親マスターの共通設定（チップ入力での Class Types / 検索パターン、および代表的ノード候補パレット）とバリアント設定を1画面で統合編集可能なモーダル、およびステージ管理モーダル（カスケード置換プレビュー・3重削除ガード付き）を実装する。

## 2. ターゲット識別
- **対象ファイル**:
  - `frontend/src/pages/SettingsPage/components/MappingMasterSection.tsx` (L65〜L150 付近)
  - `frontend/src/components/MappingMasterEditModal.tsx` (新規)
  - `frontend/src/components/StageManagerModal.tsx` (新規)
- **対象シンボル**: `MappingMasterSection`, `MappingMasterEditModal`, `StageManagerModal`

### 3.3 パターン継承ルール (SSoT Inheritance Rule)
- **継承原則**: バリアントは親マスターの `expected_class_types` および `base_title_patterns` を自動継承する。
- **ステージ拡張**: バリアント側の `extra_title_patterns` は親パターンに対する追加フィルタ（論理ANDまたは特定ステージ限定パターン）として機能し、未指定時は親定義をそのまま適用する。
</hermetic_context>
