### REQ-339-T2: デスクトップにおけるリソースモニタのヘッダー移設とプレビュー遮蔽排除

- **Type**: implementation
- **Subsystem**: frontend
- **Dependencies**: None (Root Task - T1と並行実行可能)

#### 1. 目的と変更概要
プレビューエリアを余白なくフル活用できるよう、プレビューエリア右上に重畳配置されていた `<ResourceGaugeHUD />` を撤去し、デスクトップの Global Header にリソース監視チップ（`<ResourceGaugeChips />`）を移設配置する。

#### 2. 対象ファイルと変更箇所のコードスニペット
**Target 1**: `frontend/src/pages/GeneratePage/components/DesktopLayout.tsx`
```typescript
// 変更前 1: プレビューエリア右上の重畳HUD（660-663行付近）
<div className="flex-1 relative overflow-hidden bg-grid flex items-center justify-center outline-none" tabIndex={0}>
  {/* ★ ResourceGaugeHUD をプレビューエリア右上に配置 */}
  <ResourceGaugeHUD />
  {previewContent}
```
→ `<ResourceGaugeHUD />` を削除し、プレビューエリアを100%画像専用キャンバスとする。

```typescript
// 変更後 2: デスクトップ Global Header（712-721行付近）
<div className="flex items-center justify-between px-5 py-3 border-b border-[rgba(255,255,255,0.06)] bg-surface/50 w-full flex-shrink-0 relative z-20">
  <div className="flex items-center gap-3">
    <h1 className="text-base font-semibold text-zinc-200">Generate</h1>
    ...
  </div>
  <div className="flex items-center gap-3">
    {/* ヘッダー部へ移設したリソース監視 */}
    <ResourceGaugeChips />
    <div className="relative flex items-center gap-1">
      <select id="workflow-select" ...>
```

**Target 2**: `frontend/src/pages/GeneratePage/components/__tests__/DesktopLayout.test.tsx`
- デスクトップ環境でプレビューエリア内に重畳HUDが存在せず、Global Header内にリソース監視（CPU/RAM/GPU/VRAM）がレンダリングされることの検証。
