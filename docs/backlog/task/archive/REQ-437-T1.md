def bulk_delete_presets(payload: schemas.WorkflowPresetBulkDelete, db: Session = Depends(get_db)):
    """Delete multiple presets by ID. Non-existent IDs are silently skipped."""
    if payload.ids:
        db.query(models.WorkflowPreset).filter(
            models.WorkflowPreset.id.in_(payload.ids)
        ).delete(synchronize_session=False)
        db.commit()

## 4. 実装要件 (Implementation Logic)
1. **`bulk_delete_presets` の修正（`backend/app/routers/presets.py`）**:
   - `if payload.ids:` のブロック内で、`target_ids = list(dict.fromkeys(payload.ids))` により重複除去したうえで、同一トランザクション内で**先に** `models.WorkflowPresetValue`（`WorkflowPresetValue.preset_id.in_(target_ids)`）を `.delete(synchronize_session=False)` で削除し、**続けて** `models.WorkflowPreset`（`WorkflowPreset.id.in_(target_ids)`）を `.delete(synchronize_session=False)` で削除し、`db.commit()` する。
   - 空配列 `ids: []` や存在しない ID が含まれる場合もエラーにせず 204 No Content を返す既存契約を維持する。
2. **統合テストの追加（`backend/tests/integration/api/test_presets.py`）**:
   - `test_preset_delete_and_bulk_delete` の直後に以下を追加する（ファイル名に `req` / `REQ-` を含めない。docstring に `[REQ-437/AC-n]` を記載し、`@getattr(pytest.mark, "REQ-437")` / `@getattr(pytest.mark, "AC-n")` および `@pytest.mark.parametrize(..., ids=["[REQ-437/AC-n]-..."])` でノード ID を固定する）。
   - **[REQ-437/AC-1]**: `_create_variant_helper` でバリアントを作成し、`param_values` 付きプリセット複数件を作成して `WorkflowPresetValue` 行が DB に生成された状態で `DELETE /api/workflow-presets/bulk` を実行し、対象 `WorkflowPreset` および対応する `WorkflowPresetValue` が 0 件になり、対象外プリセットの `WorkflowPresetValue` は保持されること。境界ケース（空配列 `[]`、非存在 ID `[999999]`、実在+非存在+重複 ID 混在）も検証すること。
   - **[REQ-437/AC-2]**: プリセット作成後、最大 ID のプリセットを `DELETE /api/workflow-presets/bulk` で削除した直後に、同じバリアントキーを含む `POST /api/workflow-presets` を実行し、`IntegrityError` なく HTTP 201 で作成・`WorkflowPresetValue` 保存が完了すること（インメモリ SQLite では最大 ID 削除後の `INSERT` で同一 ID が再利用されるため再現・検証可能）。
