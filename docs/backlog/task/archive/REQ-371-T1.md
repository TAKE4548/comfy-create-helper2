# REQ-371-T1: CSSスタッキングトークン新設と固定生成バーの前面化・不透明化

## 1. 概要と目的
モバイル Generate 画面において、プロンプト欄スクロール時に背面コンテンツ（テキストやタグチップ）が画面下部の固定生成ボタン領域（`mobile-action-bar`）に被って描画される不具合を修正する。無効な Tailwind `z-45` を正規の CSS 変数 `--z-mobile-action-bar: 40;` に置き換えて固有のスタッキングコンテキストを確立し、半透明背景を完全不透明化して文字の透け見えとタップ奪取を根絶する。

## 2. ターゲット識別
- **対象ファイル**:
  - `frontend/src/index.css`
  - `frontend/src/pages/GeneratePage/components/MobileLayout.tsx`
  - `frontend/src/pages/GeneratePage/components/__tests__/MobileLayout.test.tsx`
- **対象シンボル**:
  - `frontend/src/index.css`: `:root`
  - `MobileLayout.tsx`: `mobile-action-bar`, `mobile-vram-wait-banner`
- **行番号目安**:
  - `index.css`: L20〜L35
  - `MobileLayout.tsx`: L880〜L935

## 3. UI 4大アーキタイプ分類と制約
- **UI分類**: `Archetype 4: Shell & Page Layout` / `Archetype 3: Forms & Controls`
- **制約 (`<constraints>`)**:
  - Hit-Slop: `min-h-[44px]` および `before:absolute before:-inset-2` によるタップ判定担保
  - Gesture: `touch-action: pan-y / manipulation`
  - Scroll: `overscroll-contain` を維持
  - Universal Safety: 生の `vh` を禁止（`100dvh` または `calc` 使用）、二重パディングの発生防止

## 5. 実装要件 (Implementation Logic)
- [ ] `frontend/src/index.css`: `:root` に `--z-mobile-action-bar: 40;` を追加する。
- [ ] `MobileLayout.tsx`: `mobile-action-bar` および `mobile-vram-wait-banner` の無効クラス `z-45` を `z-[var(--z-mobile-action-bar,40)]` に変更する。
- [ ] `MobileLayout.tsx`: `mobile-action-bar` の背景クラス `bg-surface/90 backdrop-blur` を完全不透明な `bg-surface border-t border-[rgba(255,255,255,0.06)]` に変更し、背後の文字や装飾がボタン直下に一切透けないようにする。
- [ ] `MobileLayout.tsx`: `mobile-action-bar` に `pointer-events-auto` を付与し、ボタン操作時にタッチ／クリックイベントが背面のテキストエリアやチップへ漏洩・貫通しないことを保証する。
- [ ] `frontend/src/pages/GeneratePage/components/__tests__/MobileLayout.test.tsx` に以下のテストケースを追加する：
  - `[REQ-371/AC-1]` テキスト層およびタグチップがスクロール時に不透明な固定アクションバーの背面を通過し、文字が被らないこと。
  - `[REQ-371/AC-2]` 固定バー各ボタンタップ時にボタンハンドラのみが発火し、背面要素のイベントが発火しないこと。
  - `[REQ-371/AC-5]` 幅360px・セーフエリア環境でボトムナビ（54px）とアクションバーが二重余白や隙間なくスタック配置されること。
  - `[REQ-371/AC-8]` スクロール末尾余白への到達性と、キーボード退避（`isInputFocused`）の動作整合。
  - `[REQ-371/AC-2] [RedTeam] RT-1` 固定バー高速連打時の背面要素へのイベント漏洩遮断。
