## 変更内容（確定）
1. import: `computeHeaderMenuPlacement, PAGE_HEADER_ROOT_SELECTOR, type HeaderMenuAlign, type RectLike` を `./headerMenuPlacement` から。
2. props に `hoverBridge?: boolean`（default `false`）を追加。docコメント: 「hover 型用。トリガー下端〜パネル上端を埋める透明ブリッジを描画する」。
3. 型とヘルパー（ファイル内・非 export。`react-refresh/only-export-components` のためコンポーネントと型以外は export しない）:
```tsx
interface BridgeRect { left: number; top: number; width: number; height: number }
interface PanelPosition { top: number; left: number; maxHeight: number; bridge: BridgeRect | null }

function sameBridge(a: BridgeRect | null, b: BridgeRect | null): boolean {
  if (a === b) return true
  return !!a && !!b && a.left === b.left && a.top === b.top && a.width === b.width && a.height === b.height
}
function samePosition(a: PanelPosition | null, b: PanelPosition): boolean {
  return !!a && a.top === b.top && a.left === b.left && a.maxHeight === b.maxHeight && sameBridge(a.bridge, b.bridge)
}
/** 水平・top はラッパー rect。bottom のみ「ラッパー」と「直接子要素（ヒットスロップ -m-2 等）」の最大（ケバブ根本原因 R3）。 */
function measureAnchor(el: HTMLElement): RectLike {
  const r = el.getBoundingClientRect()
  let bottom = r.bottom
  for (const child of Array.from(el.children)) bottom = Math.max(bottom, child.getBoundingClientRect().bottom)
  return { top: r.top, bottom, left: r.left, right: r.right }
}
```
4. `measure` を置換し、`useLayoutEffect` に `ResizeObserver` を追加（deps に `hoverBridge`）:
```tsx
const measure = () => {
  const anchorEl = anchorRef.current
  const panel = panelRef.current
  if (!anchorEl || !panel) return
  const header = anchorEl.closest(PAGE_HEADER_ROOT_SELECTOR)       // 毎回引き直す（sticky／再親子付けに強い）
  const anchor = measureAnchor(anchorEl)
  const panelWidth = panel.offsetWidth
  const vv = window.visualViewport
  const p = computeHeaderMenuPlacement({
    anchor,
    headerBottom: header?.getBoundingClientRect().bottom,
    panelWidth,
    align,
    viewport: { width: vv?.width ?? window.innerWidth, height: vv?.height ?? window.innerHeight },
  })
  if (p.shouldClose) { onCloseRef.current(); return }
  const bridge: BridgeRect | null = hoverBridge && panelWidth > 0
    ? { left: anchor.left, top: anchor.bottom, width: Math.max(0, anchor.right - anchor.left), height: Math.max(0, p.top - anchor.bottom) + 1 }
    : null
  const next: PanelPosition = { top: p.top, left: p.left, maxHeight: p.maxHeight, bridge }
  setPos((prev) => (samePosition(prev, next) ? prev : next))
}
measure()
const headerEl = anchorRef.current?.closest(PAGE_HEADER_ROOT_SELECTOR) ?? null
const ro = headerEl && typeof ResizeObserver !== 'undefined' ? new ResizeObserver(() => measure()) : null
if (ro && headerEl) ro.observe(headerEl)
window.addEventListener('resize', measure)
window.addEventListener('scroll', measure, true)
window.visualViewport?.addEventListener('resize', measure)
window.visualViewport?.addEventListener('scroll', measure)
return () => { ro?.disconnect(); /* 上記4リスナーを対称に removeEventListener */ }
```
   - `panelWidth > 0` の条件: カードが `display:none`（A4 の `hidden sm:block` が 640px 未満）の間はブリッジを出さない（他要素のヒットテストを奪わない）。
   - ブリッジ高さ = `p.top - anchor.bottom + 1`。`+1` はサブピクセル誤差で隙間が残らないための重ね（パネルは DOM 順でブリッジより後＝前面）。
5. 外側押下 effect に `bridgeRef`（下記）を含める: `if (!t || panelRef.current?.contains(t) || bridgeRef.current?.contains(t) || anchorRef.current?.contains(t)) return`。
6. 描画: `const bridgeRef = useRef<HTMLDivElement>(null)` を追加し、戻り値を次へ（ブリッジは**パネルより前**に置く）:
```tsx
return createPortal(
  <>
    {pos?.bridge && (
      <div
        ref={bridgeRef}
        aria-hidden="true"
        data-header-menu-bridge=""
        data-testid={testId ? `${testId}-bridge` : undefined}
        className="z-[var(--z-header-menu)]"
        style={{ position: 'fixed', top: pos.bridge.top, left: pos.bridge.left, width: pos.bridge.width, height: pos.bridge.height }}
      />
    )}
    <div ref={panelRef} role={role} data-testid={testId} data-header-menu-panel="" data-placement="below-anchor" className={...既存...} style={...既存...}>
      {children}
    </div>
  </>,
  document.body,
)
```
   `data-placement="below-anchor"` の値は既存テスト互換のため据え置く（意味は「ヘッダー／トリガーの下」）。ブリッジはポータル子孫＝React ツリー上 `HeaderDropdown` の呼出元の子孫なので、呼出側ラッパーの `onMouseLeave` はブリッジ↔パネル↔トリガー間の移動で発火しない。
7. `open` が `false` に戻ったら `pos` は `null` にリセット（既存）＝ブリッジも消える。

## テスト追加（`HeaderDropdown.test.tsx` の末尾に新規 `describe('HeaderDropdown header-bottom anchoring', …)` を追記）
共通ハーネス（ファイル内ローカル）: 
```tsx
function HeaderHarness({ open, onClose, hoverBridge = false, headerless = false, onWrapperLeave }: {
  open: boolean; onClose: () => void; hoverBridge?: boolean; headerless?: boolean; onWrapperLeave?: () => void }) {
  const anchorRef = useRef<HTMLDivElement>(null)
  const body = (
    <div onMouseLeave={onWrapperLeave}>
      <div ref={anchorRef} data-testid="anchor"><button type="button" data-testid="trigger-btn">t</button></div>
      <HeaderDropdown open={open} onClose={onClose} anchorRef={anchorRef} align="end" data-testid="panel" hoverBridge={hoverBridge} className="w-[240px]">
        <span>content</span>
      </HeaderDropdown>
    </div>
  )
  return headerless ? body : <div data-page-header-root="" data-testid="header">{body}</div>
}
```
矩形スタブは `data-testid` で返し分ける可変オブジェクト `rects = { header, anchor, button }`（既定 header `{top:0,bottom:118,left:0,right:375}`、anchor `{top:11,bottom:39,left:300,right:330}`、button は anchor と同じ）。`getBoundingClientRect` スパイは既存 `beforeEach` のものを `mockRestore` して差し替える（既存の「anchor scrolls off-screen」ケースと同じ手法）。
- `[REQ-346/AC-1] anchors the top to the header bottom + 6 when inside [data-page-header-root] (header 118, trigger 39 -> 124px)`、`maxHeight`（`innerHeight=667`）は `535px`（667−124−8）。
- `[REQ-346/AC-1] falls back to the trigger bottom when there is no header ancestor`（`headerless` → `top === '45px'`）。
- `[REQ-346/AC-1] hit-slop: a trigger child extending below the wrapper moves the top below the child (wrapper bottom 36, button bottom 44, no header -> 50px; header bottom 40 -> 50px; header bottom 118 -> 124px)`。水平位置（`align=end`）はラッパー基準のまま（`left === 330 - 240 = 90`）で、ボタンの横はみ出しに影響されないこと。
- `[REQ-346/AC-3] maxHeight uses the header-based top (innerHeight 360 -> 228px; innerHeight 227+132 closes via onClose)`: `top=124` のとき `innerHeight=227` で `maxHeight=95` となり `onClose` が呼ばれる（閾値 `viewport.height < headerBottom + 110`）。
- `[REQ-346/AC-6] re-reads the header bottom on scroll and keeps following it`: ヘッダー `bottom` を 118→100 に変えて `window` の `scroll` を発火 → `top` が `124px`→`106px`。さらに anchor `bottom` を −10 にして `scroll` → `onClose` 呼出（トリガー画面外）。
- `[REQ-346/AC-6] observes the header with ResizeObserver, re-measures from its callback and disconnects on close/unmount`: `vi.stubGlobal('ResizeObserver', class { constructor(cb){...} observe=vi.fn(); disconnect=vi.fn() })` で、観測対象が `[data-page-header-root]` 要素であること、コールバック実行（ヘッダー `bottom` を 118→150 に変更後）で `top` が `156px`、`open=false`／アンマウントで `disconnect` 呼出を確認。`ResizeObserver` 未定義（`vi.unstubAllGlobals()` 後）でも例外なく開閉できること。`headerless` では `observe` を呼ばない。
- `[REQ-346/AC-2] hoverBridge renders a fixed, aria-hidden, transparent bridge from the trigger bottom to the panel top (+1px)`: `hoverBridge` 指定・ヘッダー 118 で `getByTestId('panel-bridge')` が `document.body` 直下、`position: fixed`、`left 300px`、`top 39px`、`width 30px`、`height 86px`（124−39+1）、`aria-hidden="true"`、`data-header-menu-bridge`、`z-[var(--z-header-menu)]` クラス。パネルは DOM 順でブリッジの**後**（`bridge.compareDocumentPosition(panel) & Node.DOCUMENT_POSITION_FOLLOWING`）。`headerless` では `height 7px`。`hoverBridge` 未指定では描画されない。`offsetWidth` を 0 にスタブした（カード非描画）場合は描画されない。
- `[REQ-346/AC-2] hover continuity through the portal: moving between the anchor, bridge and panel does not fire the ancestor's onMouseLeave; leaving to body does`: `fireEvent.mouseOut(anchor, { relatedTarget: bridge })`、`fireEvent.mouseOut(bridge, { relatedTarget: panel })` → `onWrapperLeave` 0 回、`fireEvent.mouseOut(panel, { relatedTarget: document.body })` → 1 回。（React 18 の enter/leave が React ツリー基準であることの確認。jsdom で再現できなければ実装を変えず設計へ escalate。実ポインター判定は T10／T8。）
- `[REQ-346/AC-4] pointerdown on the bridge does not close; pointerdown outside closes`。
- `[REQ-346/AC-6] removes the ResizeObserver and listeners symmetrically under StrictMode double mount`（`disconnect` 呼出回数 ≥ `observe` 呼出回数）。
