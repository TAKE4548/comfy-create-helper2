# Task Card: REQ-279-T1

## 1. 目的
`multiSetSlice.ts` の `updateActiveSet` および `usePresetState.ts` の `flushAutoSave` において、`targetActiveId` が `null` かつセットが複数存在する場合に早期 `return` されてインメモリ確定が空振りする問題を解消する。
`activeSetId` が未確定であっても `sets.length > 0` であれば先頭セット（`sets[0].id`）を対象として解決し、ジョブ発行直前に確実にインメモリ `sets` を最新状態で同期的確定させる。

## 2. 対象ファイル
- `frontend/src/store/slices/multiSetSlice.ts`
- `frontend/src/pages/GeneratePage/hooks/usePresetState.ts`

## 3. 実装仕様

### 3.1 `multiSetSlice.ts` の `updateActiveSet` ガード是正
```typescript
// frontend/src/store/slices/multiSetSlice.ts
updateActiveSet: (updates) => {
  const activeSetId = get().activeSetId
  const currentSets = get().sets

  let targetId = activeSetId
  if ((targetId === null || targetId === undefined) && currentSets.length > 0) {
    targetId = currentSets[0].id
  }

  if (targetId === null || targetId === undefined) return

  const updatedSets = currentSets.map((s) => {
    if (String(s.id) === String(targetId)) {
      return { ...s, ...updates }
    }
    return s
  })

  set({ sets: updatedSets })
},
```

### 3.2 `usePresetState.ts` の `flushAutoSave` インメモリ即時同期
```typescript
// frontend/src/pages/GeneratePage/hooks/usePresetState.ts
const flushAutoSave = useCallback(() => {
  if (autoSaveTimerRef.current) {
    clearTimeout(autoSaveTimerRef.current)
    autoSaveTimerRef.current = null
  }
  if (!isInitialSyncRef.current) return

  const currentStore = useGenerationStore.getState()
  let targetActiveId = currentStore.activeSetId
  if ((targetActiveId === null || targetActiveId === undefined) && currentStore.sets?.length > 0) {
    targetActiveId = currentStore.sets[0].id
  }
  if (!selectedWorkflowId || targetActiveId === null || targetActiveId === undefined) return
  const activePreset = presets?.find((p) => String(p.id) === String(targetActiveId))
  if (!activePreset) return

  const currentState: HistoryState = {
    paramValues: currentStore.paramValues,
    appliedAssets: currentStore.appliedAssets,
    batchSize: currentStore.batchSize,
    seedMode: currentStore.seedMode,
    seed: currentStore.seed,
  }

  // インメモリ上の activeSet を即時同期（ジョブ発行直前の必須処理）
  currentStore.updateActiveSet?.(currentState)

  const currentLastSaved = lastSavedStateRef.current[targetActiveId]
  if (currentLastSaved && isStateEqual(currentLastSaved, currentState)) return

  const latestBaseUpdatedAt = presetUpdatedAtRef.current[activePreset.id] || activePreset.updated_at
  if (currentLastSaved) {
    const hist = getHistory(targetActiveId)
    hist.past.push(currentLastSaved)
    hist.future = []
    saveHistory(targetActiveId, hist)
  }
  updatePresetMutation.mutate({
    id: activePreset.id,
    name: activePreset.name,
    param_values: currentState.paramValues,
    applied_assets: currentState.appliedAssets,
    batch_size: currentState.batchSize,
    seed_mode: currentState.seedMode,
    seed: currentState.seed,
    base_updated_at: latestBaseUpdatedAt,
  })
}, [selectedWorkflowId, presets, updatePresetMutation, updateActiveSet])
```
