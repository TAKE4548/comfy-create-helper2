# REQ-426-T2: lifespan フェイルファスト化と copy_workflow 統合テスト

## 1. 概要と目的
1. `backend/app/main.py` の `lifespan` で `run_migrations()` が失敗した際に例外を握りつぶさず再送出し、DB スキーマ不整合状態でのサーバ稼働を防止する（AC-3）。
2. `POST /api/workflows/{workflow_id}/copy` が `master_variant_id` 設定済みおよび `None` の `ParamSyncGroup` を含むワークフローを正常に複製できることを結合テストで保証する（AC-2）。

## 2. ターゲット識別
- **対象ファイル**:
  - `backend/app/main.py` (L60-68)
  - `backend/app/routers/workflows.py` (L122-138 確認・必要時のみ防御補完)
  - `backend/tests/integration/api/test_workflows.py`
  - `backend/tests/unit/test_helpers.py`
- **対象シンボル**: `lifespan`, `copy_workflow`
