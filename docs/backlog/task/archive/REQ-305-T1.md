### REQ-305-T1: DesktopLayout コンポーネントの構造再編

- **Status**: done
- **Subsystem**: frontend
- **Depends On**: []
- **Impacted Files**:
  - `frontend/src/pages/GeneratePage/components/DesktopLayout.tsx`

#### Context & Purpose
デスクトップ生成画面（`DesktopLayout.tsx`）において：
1. `leftPane` 内に配置されていたヘッダー要素（タイトル、接続状態、`WorkflowSelect`、`Anima`、`Settings`）を、ルートコンテナ最上位（`w-full flex-shrink-0 relative z-20`）へ昇格配置する。
2. プリセットタブバー（`#desktop-preset-tabs-bar`）をグローバルヘッダー直下（`w-full flex-shrink-0 relative z-10`）に配置する。
3. `leftPane` 最上部の `#left-pane-toolbar` から `justify-between` を除去し、`justify-start gap-2 flex-nowrap` として「プリセット名バッジ」→「Undo/Redoボタングループ」→「Add Setボタン」→「管理ボタン」の順序で左寄せ連続配置する。
