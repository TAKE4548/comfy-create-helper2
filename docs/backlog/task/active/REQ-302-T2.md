# REQ-302-T2: 共通・個別モーダルコンポーネントのスタッキング階層とセーフエリア整合化

## 1. 概要と目的
コンポーネントディレクトリ内の各種モーダル（`BaseImageSelectModal`, `PresetConflictModal`, `ParamTypeMasterModal`, `SceneSpeechModal`）において、ハードコードされた `z-50` を設計トークン `z-[var(--z-modal)]` / `z-[var(--z-modal-nested)]` または `.modal-backdrop` に整合させ、セーフエリアクリアランス（`pb-[calc(1rem+env(safe-area-inset-bottom,0px))]`）を確保する。

## 2. 密閉コンテキスト (Hermetic Context)

### 2.1 現行スニペット: `frontend/src/components/BaseImageSelectModal.tsx` (L176-L182)
```tsx
  return (
    <div className="fixed inset-0 z-50 flex items-center justify-center bg-black/75 backdrop-blur-sm p-4" onClick={onClose}>
      <div
        className="bg-[#18181C] border border-[rgba(255,255,255,0.08)] rounded-xl w-full max-w-4xl max-h-[85vh] flex flex-col overflow-hidden shadow-2xl"
        onClick={(e) => e.stopPropagation()}
      >
```

### 2.2 現行スニペット: `frontend/src/components/PresetConflictModal.tsx` (L72-L78)
```tsx
  return (
    <div className="fixed inset-0 z-50 flex items-center justify-center p-4 bg-black/75 backdrop-blur-sm animate-fadeIn">
      <div 
        className="w-full max-w-md bg-[#18181C] border border-[rgba(255,255,255,0.08)] rounded-xl p-6 shadow-2xl space-y-4"
        onClick={(e) => e.stopPropagation()}
      >
```

### 2.3 現行スニペット: `frontend/src/components/ParamTypeMasterModal.tsx` (L255-L260)
```tsx
  return (
    <div className="fixed inset-0 z-50 flex items-center justify-center bg-black/60 backdrop-blur-sm p-4 overflow-y-auto">
      <div 
        className="bg-[#121316] border border-white/10 rounded-2xl w-full max-w-2xl overflow-hidden shadow-2xl my-8"
        onClick={(e) => e.stopPropagation()}
      >
```

### 2.4 現行スニペット: `frontend/src/components/SpeechBubbleEditorModal/sections/SceneSpeechModal.tsx` (L108-L112)
```tsx
  return <div data-testid="scene-speech-modal">
    <div className="fixed inset-0 z-50 hidden md:flex items-center justify-center bg-black/50">{panel}</div>
    <div className="fixed inset-x-0 bottom-0 z-50 md:hidden">{panel}</div>
  </div>
```

## 3. 実装要件 (Implementation Logic)
1. **`BaseImageSelectModal.tsx`**:
   - バックドロップの className を `fixed inset-0 z-[var(--z-modal)] flex items-center justify-center bg-black/75 backdrop-blur-sm p-4 pb-[calc(1rem+env(safe-area-inset-bottom,0px))]` に変更。
2. **`PresetConflictModal.tsx`**:
   - 二次確認モーダルとして `fixed inset-0 z-[var(--z-modal-nested)] flex items-center justify-center p-4 pb-[calc(1rem+env(safe-area-inset-bottom,0px))] bg-black/75 backdrop-blur-sm animate-fadeIn` に変更。
3. **`ParamTypeMasterModal.tsx`**:
   - バックドロップの className を `fixed inset-0 z-[var(--z-modal)] flex items-center justify-center bg-black/60 backdrop-blur-sm p-4 pb-[calc(1rem+env(safe-area-inset-bottom,0px))] overflow-y-auto` に変更。
4. **`SceneSpeechModal.tsx`**:
   - `md:hidden` のボトムシートに対し、`fixed inset-x-0 bottom-0 z-[var(--z-modal)] pb-[calc(1rem+env(safe-area-inset-bottom,0px))] md:hidden` を適用。

## 4. 完了条件と検証
- [ ] 各コンポーネントで `z-50` が排除され、`z-[var(--z-modal)]` または `z-[var(--z-modal-nested)]` が適用されていること。
- [ ] モバイル端末におけるセーフエリアフォールバック余白が付与されていること。

`cd frontend; npm run typecheck`
