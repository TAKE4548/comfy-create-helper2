# REQ-413-T3: マスタ無効化ステージバリアントの生成・表示除外に関するSSoT仕様書の同期

## 1. 概要と目的
マスタ側で無効化（`is_enabled = false`）されたステージバリアントの生成画面（ParamPanel/PromptPanel）および生成要求ペイロード（ComfyUI ワークフロー JSON）からの除外契約、ならびにステージグループ（`groupMappingsByStage`）および ParamSync 候補からの除外契約を、正本仕様書（`SPEC_GENERATE.md`, `SPEC_SETTINGS.md`）へ同期・明記する。

## 2. ターゲット識別
- **所有ファイル**:
  1. `docs/specs/SPEC_GENERATE.md`
  2. `docs/specs/SPEC_SETTINGS.md`
- **対象セクション**:
  - `docs/specs/SPEC_GENERATE.md` §2-5「REQ-358 workflow mappingの無効化」
  - `docs/specs/SPEC_SETTINGS.md` §4-1-1「登録・リマッピングの基本方針」

## 3. 実装要件 (Implementation Logic)
- [ ] 1. `docs/specs/SPEC_GENERATE.md` §2-5:
  - `generationWorkflow` において、ワークフロー個別の `mapping_slot_states` に加え、マスタ側のステージバリアント有効フラグ（`variant.is_enabled !== false`）を評価し、無効化されたバリアント（および全バリアントが無効なマスタのレガシーマッピング）を生成用 `mappings` 配列およびパラメータ/プロンプト入力枠から除外することを追記する。
  - DB 上の `workflow_mappings` レコード自体は削除せず保持し、マスタで再有効化された場合に即時復旧する契約を明記する。
- [ ] 2. `docs/specs/SPEC_SETTINGS.md` §4-1-1:
  - `groupMappingsByStage` および `buildParamSyncCandidates` において、マスタ側で `is_enabled === false` となっているステージバリアントをステージグループ表示および ParamSync 同期先/代表候補から除外することを明記する。
