# REQ-302-T5: SSoT 仕様書（SPEC_COMMON.md）のモバイルナビ・モーダル階層仕様同期

## 1. 概要と目的
`docs/specs/SPEC_COMMON.md` の「2-3. モバイル: ボトムナビゲーション」およびモーダルスタッキング規定を更新し、モーダルがボトムナビゲーション前面にオーバーレイ展開される仕様、z-index 設計トークン階層（ボトムナビ: 40、モーダル: 100、二次確認モーダル: 110）、およびボトムナビ回避余白の撤廃を SSoT に反映する。

## 2. 密閉コンテキスト (Hermetic Context)

### 2.1 現行スニペット: `docs/specs/SPEC_COMMON.md` (L67-L74)
```markdown
### 2-3. モバイル: ボトムナビゲーション

- 画面下部固定（`fixed bottom-0`）
- アイコン ＋ ラベルテキスト（Generate / LoRAs / Tags / History / Settings）を表示
- 全ページで同一のルーティング（`/`, `/loras`, `/tags`, `/history`, `/settings`）を共有

設定ページ固有のタブ、responsive、localStorage契約は [SPEC_SETTINGS.md](./SPEC_SETTINGS.md) を参照する。ここでは共通AppShellのナビゲーション境界を定義し、設定内のタブ状態や詳細開閉状態は定義しない。
```

## 3. 実装要件 (Implementation Logic)
1. **`docs/specs/SPEC_COMMON.md` への追記**:
   - モバイルボトムナビゲーション（`--z-mobile-nav: 40`）に対し、モーダルダイアログ（`--z-modal: 100`）および二次確認ダイアログ（`--z-modal-nested: 110`）が前面オーバーレイ（`fixed inset-0`）として展開される仕様を明記。
   - モーダル展開中は背面のボトムナビゲーションへのタップ操作が完全に遮断されること。
   - モーダル下部における過去の回避余白（`--mobile-nav-height` 加算）は撤廃され、セーフエリア（`env(safe-area-inset-bottom)`）のみが考慮されることを規定。
