# タスクカード: REQ-172-T2

## 目的
プレビューキャンバス上で選択中の吹き出し上部に回転用ハンドル（ステム線と円形ノブ）を描画し、ユーザーがマウスまたはタッチ操作で直接ドラッグして吹き出しを直感的に回転できるようにする。

## Acceptance Criteria
- [x] AC-1: `speechBubbleRenderer.ts` の `drawSpeechBubble` において、選択中吹き出し（`isSelected === true`）の上部中央にステム線（長さ 20px）と円形の回転ノブ（半径 6px）が描画されること。
- [x] AC-2: `SpeechBubbleEditorModal.tsx` の `handleMouseDown` / `handleTouchStart` において、回転ノブがクリックされた際に `draggingState = { type: 'rotate', ... }` が開始されること。
- [x] AC-3: `handleMouseMove` / `handleTouchMove` において、吹き出しの中心座標とマウス位置の角度（`Math.atan2`）に基づきリアルタイムに `rotation`（-180°〜180°）が計算・更新されること。
- [x] AC-4: 回転ノブホバー時にカーソルが `grab` または適切な回転カーソルに変化すること。
- [x] AC-5: `SpeechBubbleEditorModal.test.tsx` に回転ハンドルのドラッグ動作テストが追加され、パスすること。

### 1. レンダラー実装スニペット (`speechBubbleRenderer.ts`)
```typescript
export const ROTATE_HANDLE_OFFSET = 20
export const ROTATE_HANDLE_RADIUS = 6

// drawSpeechBubble 内の isSelected ブロック内:
if (isSelected) {
  const bx = bubble.x * scaleX
  const by = bubble.y * scaleY
  const bw = bubble.w * scaleX
  const bh = bubble.h * scaleY

  // ... 既存のバウンディングボックス描画 ...

  // 上部中央の回転ハンドル
  const topCenterX = bx + bw / 2
  const topCenterY = by
  const rotateHandleY = by - ROTATE_HANDLE_OFFSET

  ctx.setLineDash([])
  // ステム線
  ctx.strokeStyle = '#3b82f6'
  ctx.lineWidth = 1.5
  ctx.beginPath()
  ctx.moveTo(topCenterX, topCenterY)
  ctx.lineTo(topCenterX, rotateHandleY)
  ctx.stroke()

  // 回転ハンドル（円）
  ctx.fillStyle = '#3b82f6'
  ctx.strokeStyle = '#ffffff'
  ctx.lineWidth = 2
  ctx.beginPath()
  ctx.arc(topCenterX, rotateHandleY, ROTATE_HANDLE_RADIUS, 0, Math.PI * 2)
  ctx.fill()
  ctx.stroke()
}
```

### 2. モーダル操作スニペット (`SpeechBubbleEditorModal.tsx`)
```typescript
// 1. handleMouseDown / TouchStart 内:
const activeBubble = bubbles.find((b) => b.id === selectedBubbleId)
if (activeBubble) {
  const localPt = getLocalBubblePoint(x, y, activeBubble, scaleX, scaleY)
  const bx = activeBubble.x * scaleX
  const by = activeBubble.y * scaleY
  const bw = activeBubble.w * scaleX

  // 回転ハンドルヒット判定
  const rotHx = bx + bw / 2
  const rotHy = by - 20
  if (Math.hypot(localPt.x - rotHx, localPt.y - rotHy) <= 10) {
    setDraggingState({
      type: 'rotate',
      bubbleId: activeBubble.id,
      startX: x,
      startY: y,
      initialBubble: { ...activeBubble }
    })
    return
  }
}

// 2. handleMouseMove 内:
if (draggingState?.type === 'rotate') {
  const initB = draggingState.initialBubble
  const cx = (initB.x + initB.w / 2) * scaleX
  const cy = (initB.y + initB.h / 2) * scaleY

  // 中心からマウス位置への角度 (rad)
  const rad = Math.atan2(y - cy, x - cx)
  // 上方向を0度とする
  let deg = (rad * 180) / Math.PI + 90
  // -180 ~ 180 に正規化
  while (deg > 180) deg -= 360
  while (deg < -180) deg += 360

  const rounded = Math.round(deg)
  setBubbles((prev) =>
    prev.map((b) => (b.id === draggingState.bubbleId ? { ...b, rotation: rounded } : b))
  )
  return
}
```
