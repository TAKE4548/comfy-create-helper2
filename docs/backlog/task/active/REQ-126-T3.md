# TASK-REQ-126-T3: ParamPanel 連携（トグル配置・従項目入力制御）および生成送信時の動的同期連動

## 1. ターゲット識別
- **対象ファイル**:
  1. `frontend/src/pages/GeneratePage/components/ParamPanel.tsx` — トグルUI追加 & 従項目グレーアウト制御
  2. `frontend/src/pages/GeneratePage/hooks/useGenerateAction.ts` — 生成ペイロードの主従値上書き処理
  3. `frontend/src/pages/GeneratePage/components/DesktopLayout.tsx` — モーダル呼び出しバインド
- **依存タスク**: REQ-126-T2

## 2. 密閉コンテキスト

### 2.1 `ParamPanel.tsx` UI & State制御
- Bypassセクションの下に「Param Sync」セクションを追加（またはBypassと同等のスタイルのコントロールセクション）。
- Activeな同期グループ（`is_enabled === true`）に存在するすべての `slave_roles` を抽出。
- パラメータ一覧レンダリング時、該当ロールが従項目かつActiveな場合:
  - 入力要素（select/input/button等）に `disabled` プロパティを付与してグレーアウト化。
  - 見た目上の値は現在の入力値（または直前の値）を表示したまま手動入力のみ不可にする。
  - 小さな同期インジケーター（例: 「Synced: {MasterName}」）をラベル付近に表示。

### 2.2 `useGenerateAction.ts` 送信直前処理
- 生成実行アクション時、`paramSyncGroups` のうち `is_enabled === true` のグループをループ処理。
- `master_role` に設定されている `paramValues[master_role]` の最新値を取得。
- 該当グループの `slave_roles` に含まれるすべてのキーに対して、送信用 `payloadParamValues` の値を `master_role` の値で置換・上書きする。
- 非活性（`is_enabled === false`）のグループの従項目は上書きせず、ユーザー個別の設定値をそのまま送信する。

## 3. 受入条件 (Acceptance Criteria)
- [ ] Active時に従項目入力欄が操作不能（disabled & visual greyout）になること。
- [ ] 生成実行時、Activeな従項目のパラメータ値が主項目の値で送信されること。
- [ ] Deactiveに切り替えた場合、従項目が即座に操作可能に戻り、個別設定値が維持・送信されること。
