# REQ-433-T5: Playwright E2E によるモバイル・デスクトップ実計算スタイルおよび操作性検証

## 1. 概要と目的
jsdom では検証できない `index.css` 適用後の実ブラウザ計算スタイル（`getComputedStyle`・`getBoundingClientRect`・`::before` Hit-Slop 寸法）を検証するため、既存の Playwright E2E テスト（`settingsResponsive.spec.ts`, `generateMobileGallery.spec.ts`）へモバイル（375×667）およびデスクトップ（1280×800）の検証ケースを追加する。本カードが本タスクの唯一の意味仕様である。

## 2. ターゲット識別
- **対象ファイル**:
  - `frontend/e2e/settingsResponsive.spec.ts`
  - `frontend/e2e/generateMobileGallery.spec.ts`
- **UI Archetype**: `Generic / Custom`（E2E 検証スクリプト）

<constraints>
- SPEC-TESTING v2.1 準拠: チケット番号を含む新規 E2E ファイル（`*req433*` 等）を作成してはならない。
- テスト名には `[REQ-433/AC-2]`, `[REQ-433/AC-3]`, `[REQ-433/AC-4]` プレフィックスを付与すること。
- E2E 実行は必ず `backend\.venv\Scripts\python scripts/run_e2e.py <spec_path>` を使用すること（Vite dev server 自律起動・終了）。
</constraints>

## 3. コンテキスト (Surgical Context)
```ts
// 実ブラウザでの正円・ピル型・Hit-Slop 計算スタイル検証ヘルパー例
// 1. ステータスランプ:
//    rect.width === rect.height (差 <= 0.5px) && parseFloat(cs.borderTopLeftRadius) >= rect.width / 2
// 2. トグルスイッチトラック:
//    rect.width > rect.height && rect.height < 44 && parseFloat(cs.borderTopLeftRadius) >= rect.height / 2
// 3. ::before Hit-Slop (またはラッパー label):
//    getComputedStyle(el, '::before') の width / height、または label rect が >= 44px x 44px
```

## 4. 実装要件
- [ ] `frontend/e2e/settingsResponsive.spec.ts` に以下のテストケースを追記する:
  - `[REQ-433/AC-2] mobile status lamps render as true circles without square distortion`: 375×667 で `ServiceConnectionCard` の各ランプ（稼働中/停止中/不明）およびヘッダーの `SystemStatusBadge` ドットが正円（`width === height`, `borderRadius >= width / 2`）で、`SystemStatusBadge` の `::before` タップ領域が `>= 44×44px` であること。
  - `[REQ-433/AC-3] mobile toggle switches render as pill track with circular knob and 44x44 hit target`: 375×667 で `VramGuardSection` トグルスイッチのトラックがピル型、ノブが正円、タップ領域が `>= 44×44px` であり、クリックで `aria-checked` が切り替わること。
  - `[REQ-433/AC-4] desktop viewports preserve toggle switch and status lamp behavior and accessibility`: 1280×800 でデスクトップ表示・キーボード操作・`aria-checked` が維持されること。
- [ ] `frontend/e2e/generateMobileGallery.spec.ts` に以下のテストケースを追記する:
  - `[REQ-433/AC-3] mobile ParamPanel toggle switches keep pill shape and 44x44 hit slop`: 375×667 で `ParamPanel` のトグルスイッチ（`role="switch"`）が正方形化せずピル型＋正円ノブで描画され、`::before` Hit-Slop が `>= 44×44px`、タップで `aria-checked` が反転し、押しボタン型トグルは角丸 8px のまま維持されること。
