### REQ-118-T1: copy_workflow 関数への BypassProfile 複製ロジック追加とテスト実装

- **Parent PBI**: REQ-118
- **Status**: todo

#### 1. 背景と目的
`POST /api/workflows/{workflow_id}/copy` (`copy_workflow`) において、ソースワークフローに登録された `BypassProfile` が複製先のワークフローにコピーされず消えてしまう不具合を修正する。

#### 2. 対象ファイル
- `backend/app/routers/workflows.py`
- `backend/tests/test_workflows.py`

#### 3. 技術コンテキストと実装指示

##### 3.1 `backend/app/routers/workflows.py` の修正
`copy_workflow` 関数内（`for p in src.presets:` の直後）に、以下のループを追加してバイパスプロファイルを複製する。

```python
for bp in src.bypass_profiles:
    db.add(models.BypassProfile(
        workflow_id=new_wf.id,
        name=bp.name,
        bypassed_node_ids=bp.bypassed_node_ids,
        is_enabled=bp.is_enabled,
    ))
```

参考: `models.BypassProfile` のフィールド定義 (`backend/app/models.py`):
```python
class BypassProfile(Base):
    id: int
    workflow_id: int
    name: str
    bypassed_node_ids: str  # JSON string
    is_enabled: bool
    created_at: datetime
```

##### 3.2 `backend/tests/test_workflows.py` への自動テスト追加
`TestWorkflowsAPI` クラスに `test_copy_workflow_with_bypass_profiles` メソッドを追加する。

```python
def test_copy_workflow_with_bypass_profiles(self):
    # 1. BypassProfile を持つワークフローを作成
    wf = models.Workflow(name="Source WF", json_body="{}")
    self.db.add(wf)
    self.db.commit()
    self.db.refresh(wf)
    
    profile = models.BypassProfile(
        workflow_id=wf.id,
        name="Test Bypass Profile",
        bypassed_node_ids='["10", "20"]',
        is_enabled=True,
    )
    self.db.add(profile)
    self.db.commit()

    # 2. ワークフローのコピーAPIを実行
    response = self.client.post(f"/api/workflows/{wf.id}/copy", json={"name": "Copied WF"})
    assert response.status_code == 201
    new_wf_id = response.json()["id"]

    # 3. コピー先ワークフローのバイパスプロファイル一覧を取得して検証
    res_profiles = self.client.get(f"/api/workflows/{new_wf_id}/bypass-profiles")
    assert res_profiles.status_code == 200
    profiles_data = res_profiles.json()
    assert len(profiles_data) == 1
    assert profiles_data[0]["name"] == "Test Bypass Profile"
    assert profiles_data[0]["bypassed_node_ids"] == ["10", "20"]
    assert profiles_data[0]["is_enabled"] is True
```

#### 4. Verification Criteria (AC)
- [ ] `POST /api/workflows/{workflow_id}/copy` 呼び出し時、ソースワークフローの `BypassProfile` が複製される。
- [ ] 自動テスト `pytest backend/tests/test_workflows.py` が PASS すること。
