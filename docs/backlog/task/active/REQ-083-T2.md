# タスクカード: REQ-083-T2

## 目的

`GeneratePage` の `DesktopLayout.tsx` に `ResizableSplitLayout` を組み込み、左右ペイン（パラメータ設定パネル vs メインエリア）および右ペイン内の上下スプリット（メインプレビュー vs 履歴サムネイル）をドラッグしてサイズ変更できるようにする。

## Acceptance Criteria

- [ ] AC-1: `DesktopLayout.tsx` の大枠レイアウトが `ResizableSplitLayout` (Horizontal) を用いて再構築され、左右ペインの幅をドラッグで調整できること。
- [ ] AC-2: 右ペイン内が `ResizableSplitLayout` (Vertical) を用いて再構築され、メインプレビュー領域とサムネイル表示領域の境界をドラッグして高さを調整できること。
- [ ] AC-3: それぞれの分割幅・高さがブラウザ再読み込み時に `localStorage` から復元・維持されること。
- [ ] AC-4: リサイズ中にレイアウトが崩れず、境界線のホバー時に適切なリサイズカーソルが表示されること。

## 密閉コンテキスト (Hermetic Context)

### 1. 必須の型定義・定数

#### 1-1. `ResizableSplitLayout` のPropsインターフェース
```typescript
interface ResizableSplitLayoutProps {
  direction: 'horizontal' | 'vertical';
  first: React.ReactNode;
  second: React.ReactNode;
  initialSize: number;
  minSize: number;
  maxSize?: number;
  storageKey: string;
  className?: string;
}
```

#### 1-2. 使用するLocalStorageキーの定義
```typescript
export const LS_KEYS = {
  LAYOUT_MAIN_SPLIT: 'prompt-surgeon-layout-main-split',
  LAYOUT_PREVIEW_SPLIT: 'prompt-surgeon-layout-preview-split',
} as const;
```

## 実装詳細

### `DesktopLayout.tsx` のレイアウト構成変更

**Before:**
```tsx
  return (
    <div className="flex h-full overflow-hidden w-full">
      {/* Left Column */}
      <div className="w-[420px] xl:w-[480px] flex-shrink-0 border-r ...">
        {/* パラメータ等の設定コンテンツ */}
      </div>

      {/* Right Column */}
      <div className="flex-1 flex flex-col overflow-hidden">
        {/* Main Preview */}
        <div className="flex-1 relative overflow-hidden bg-grid ...">
          {/* プレビュー画面 */}
        </div>

        {/* Thumbnail Strip */}
        {showStrip && (
          <div className="border-t ...">
            {/* 履歴・スナップショットサムネイル一覧 */}
          </div>
        )}
      </div>
    </div>
  )
```

**After:**
```tsx
import { ResizableSplitLayout } from '../../../components/layout/ResizableSplitLayout'
import { LS_KEYS } from '../../../utils/localStorageKeys'

// ...

  const leftPane = (
    <div className="w-full h-full flex flex-col overflow-hidden bg-surface-2/10">
      {/* パラメータ等の設定コンテンツ（元の Left Column の中身。w-[420px] 等の固定幅クラスは削除） */}
    </div>
  )

  const rightPane = (
    <div className="w-full h-full flex flex-col overflow-hidden">
      {showStrip ? (
        <ResizableSplitLayout
          direction="vertical"
          storageKey={LS_KEYS.LAYOUT_PREVIEW_SPLIT}
          initialSize={550}
          minSize={250}
          first={
            <div className="w-full h-full relative overflow-hidden flex flex-col">
              {/* Main Preview のコンテンツ */}
            </div>
          }
          second={
            <div className="w-full h-full overflow-hidden">
              {/* Thumbnail Strip のコンテンツ */}
            </div>
          }
        />
      ) : (
        <div className="w-full h-full relative overflow-hidden flex flex-col">
          {/* Main Preview のコンテンツのみ表示 */}
        </div>
      )}
    </div>
  )

  return (
    <ResizableSplitLayout
      direction="horizontal"
      storageKey={LS_KEYS.LAYOUT_MAIN_SPLIT}
      initialSize={420}
      minSize={380}
      maxSize={700}
      first={leftPane}
      second={rightPane}
      className="w-full h-full"
    />
  )
```

## 検証方法

- ローカル開発サーバーを起動し、境界線をドラッグして幅・高さが変更され、リロード後も記憶されていることを確認する。
