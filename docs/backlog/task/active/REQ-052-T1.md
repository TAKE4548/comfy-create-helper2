### 2.3 useGenerateAction.ts の既存パラメータ注入
```typescript
      // Inject paramValues into workflow JSON nodes
      workflow.mappings.forEach((m) => {
        if (!m.role || !m.param_name) return
        const node = wfJson[m.node_id] as Record<string, unknown> | undefined
        if (!node) return
        const inputs = node.inputs as Record<string, unknown>
        if (!inputs) return

        let val: string | number = ''
        if (m.input_type === 'int') {
          val = parseInt(paramValues[m.role] || '0')
        } else if (m.input_type === 'float') {
          val = parseFloat(paramValues[m.role] || '0.0')
        } else {
          val = paramValues[m.role] || ''
        }

        if (inputs[m.param_name] !== undefined) {
          inputs[m.param_name] = val
        } else if (inputs['value'] !== undefined) {
          inputs['value'] = val
        } else {
          inputs[m.param_name] = val
        }
      })
```

### 2.4 useGenerationStore の型定義抜粋
Zustandストア（`useGenerationStore`）は `paramValues: Record<string, string>` というフラットな辞書で入力を管理します。
`m.input_type === 'lora_stack'` の場合、以下の動的キーを用いてすべての情報をフラットに保存・取得します。
- `paramValues['${role}_lora_count']` -> スロット件数（例: `'2'`)
- `paramValues['${role}_lora_name_${i}']` -> インデックス `i` (1から始まる) のLoRAモデルファイルパス
- `paramValues['${role}_lora_wt_${i}']` -> インデックス `i` のLoRAウェイト
- `paramValues['${role}_model_str_${i}']` -> インデックス `i` のモデル強度
- `paramValues['${role}_clip_str_${i}']` -> インデックス `i` のCLIP強度
※ `role` は `m.role`（例: `'Lora_Stack'`) を使用します。

## 3. 実装要件 (Implementation Logic)
- [ ] `frontend/src/api/types.ts`
  - `MappingMaster` の `input_type` の型定義に `'lora_stack'` を追加する：
    `input_type: 'textarea' | 'int' | 'float' | 'select' | 'lora_stack'`
- [ ] `frontend/src/pages/GeneratePage/hooks/useWorkflowParams.ts`
  - ワークフロー初期読み込み（`useEffect`）に `lora_stack` の処理を追加する：
    `m.input_type === 'lora_stack'` の場合、`node.inputs['lora_count']` をパース（無い場合は `0`）し、`${role}_lora_count` に代入。そして 1 から `lora_count` までの各インデックス `i` について、`lora_name_${i}`, `lora_wt_${i}`, `model_str_${i}`, `clip_str_${i}` を `node.inputs` から読み込んで `init` のフラットキーに代入する。
  - デフォルト保存処理（`handleSaveDefaultParams`）に `lora_stack` の処理を追加する：
    `m.input_type === 'lora_stack'` の場合、`paramValues` から `${role}_lora_count` を読み取り、`node.inputs['lora_count']` に整数値として設定。1 から `lora_count` までの各キーを `node.inputs` に注入し、不要になった `lora_count` を超えるキー（`lora_name_X` など）を `delete` する。
  - デフォルトリセット（`handleResetDefaultParams`）にも初期読み込みと同様の `lora_stack` 初期キー生成・ストア更新処理を実装する。
- [ ] `frontend/src/pages/GeneratePage/hooks/useGenerateAction.ts`
  - `handleGenerate` メソッド内、各マッピングのループ処理において `m.input_type === 'lora_stack'` を判定する。
  - `lora_count` を `parseInt` で取得し、`inputs['lora_count']` に設定する。
  - 1 から `lora_count` までの各スロット値（`lora_name_X` は `string`、数値は `parseFloat`）を `inputs` に代入する。
  - `inputs` から `lora_count` を超えるインデックスを持つ古いキー（正規表現 `/^(lora_name|lora_wt|model_str|clip_str)_(\d+)$/` にマッチし、インデックスが `lora_count` を超過するもの）を `delete` する。
