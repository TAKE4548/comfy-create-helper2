### 2.2 状態遷移 & フェーズ設計
1. **フェーズ 1: 候補画像抽出とフィルタ・ソート・選択 (`phase === 'select'`)**:
   - `useQuery({ queryKey: ['snapshots'], queryFn: ... })` より全スナップショットを取得。
   - `speechSnapshots = snapshots.filter(s => Array.isArray(s.params?.speech_bubbles) && s.params.speech_bubbles.length > 0)` で自動抽出。
   - フィルタ（WorkflowFilter, AlbumFilter, SearchQuery）および日付ソート（SortOrder: desc/asc）を適用。
   - 画像カード + 吹き出し個別チェックボックスで選択管理。
   - 口調プリセット（`useQuery(['speech-tone-presets'])`）のドロップダウンまたはカスタムプロンプト指定。
   - 「一括変換開始」ボタン押下時に `speechBatchApi.createJob` を呼び出し、`job_id` を保存してフェーズ 2 へ移行。

2. **フェーズ 2: 変換キュー実行・順次プレビュー・再生成・微調整 (`phase === 'review'`)**:
   - `useQuery({ queryKey: ['speech-batch-job', activeJobId], queryFn: () => speechBatchApi.getJob(activeJobId!), refetchInterval: (query) => (query.state.data?.status === 'processing' || query.state.data?.status === 'pending' ? 1000 : false) })`
   - 全体進捗バー（`completed_count / total_count`）および「全体キャンセル（`speechBatchApi.cancelJob`）」ボタンを表示。
   - 各アイテムのステータスバッジ（待機中 / 変換中 / 完了 / エラー / キャンセル）。
   - 完了した吹き出しから元テキスト（取り消し線）vs 変換後テキスト（`currentTexts[itemId] || rewritten_text`）を対比表示。
   - 変換後テキストのインライン編集 `<textarea>` で直接微調整（`onEdit(itemId, text)`）。
   - アイテムごとの「再生成（`speechBatchApi.retryItem`）」ボタン押下で、全完了後でも何度でも再変換可能。
   - アイテムごとの「キャンセル（`speechBatchApi.cancelItem`）」および「元に戻す」ボタン。

3. **フェーズ 3: Canvas合成と一括保存処理 (`handleSaveAll`)**:
   - 保存モード: `saveMode === 'overwrite'` または `'new'`（アルバム選択対応）。
   - 変更があった各スナップショットについて：
     - クリーンなベース画像（`base_image_path || image_path`）を `HTMLImageElement` にロード。
     - オフスクリーン `<canvas>` に `drawImage` し、更新後テキストを反映した `bubbles` を `drawSpeechBubble(ctx, bubble, false, 1, 1, activeFontFamily)` で描画。
     - `canvas.toBlob('image/png')` で Blob 生成し `snapshotsApi.upload` でアップロード。
     - `saveMode === 'overwrite'` なら `snapshotsApi.patch`、`'new'` なら `snapshotsApi.create`（+ アルバム登録）。
   - 全件保存完了後、`activeJobId` を localStorage から削除し、React Query キャッシュ（`snapshots`, `albums`）を無効化してモーダルを閉じる。
