## 3. 実装要件 (Implementation Logic)
- **3-1. `PROMPT_LABELS` への追加**:
  - `translation_ja_to_en` を `'翻訳システムプロンプト (日 -> 英)'` として追加。
  - `translation_en_to_ja` を `'翻訳システムプロンプト (英 -> 日)'` として追加。
  - これにより、「LLM System Prompts」セクション内で自動的に編集可能になる。
- **3-2. 翻訳用LLMモデル選択UIの追加**:
  - `SettingsPage.tsx` の `LLM Model Settings` 内（現在のモデル選択の周辺）に「翻訳用LLMモデル」のセレクトボックスを追加する。
  - DBから取得したキー `translation_model` の値（`LlmPrompt` の一つとして取得される）とバインドする。
  - 値が空の場合は「メインLLMモデルを使用」をデフォルトオプションとする。
  - 選択変更時は `updatePrompt` ミューテーションを利用して `translation_model` キーの `LlmPrompt` レコードを更新・保存する。
- **3-3. 翻訳デバウンス間隔設定UIの追加**:
  - `LLM Model Settings` セクション内に「翻訳デバウンス間隔 (ms)」の設定コントロール（スライダー、または数値入力インプット）を追加する。
  - DB上の `translation_debounce` の値（`LlmPrompt` の一つとして取得される）とバインドする。
  - 入力値が 300 から 2000 ms の範囲であることを検証し、変更時は `updatePrompt` ミューテーションを利用して `translation_debounce` キーを更新・保存する。
