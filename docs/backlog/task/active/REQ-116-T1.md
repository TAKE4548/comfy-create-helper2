### 2-2. 既存の対象コード
`backend/app/services/llm_request.py` 内の `call_llm` のフル実装:
```python
import httpx
import logging
from app.config import settings

logger = logging.getLogger(__name__)

async def call_llm(system_prompt: str, user_prompt: str, timeout: float = 180.0, model: str = None) -> str:
    """Call the LLM server (OpenAI-compatible API) asynchronously."""
    prompt_tokens = (len(system_prompt or "") + len(user_prompt or "")) / 3
    num_ctx = int(prompt_tokens) + 8192
    num_ctx = max(2048, min(262144, num_ctx))

    if not model:
        from app.database import SessionLocal
        from app.models import LlmPrompt
        try:
            with SessionLocal() as db:
                record = db.query(LlmPrompt).filter(LlmPrompt.key == "llm_model").first()
                if record and record.content:
                    model = record.content
        except Exception as e:
            logger.error(f"Failed to fetch llm_model from DB: {e}")
        
        if not model:
            model = settings.llm_model

    payload = {
        "model": model,
        "messages": [
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": user_prompt},
        ],
        "stream": False,
        "temperature": 0.2,
    }

    url = f"{settings.llm_base_url}/chat/completions"
    async with httpx.AsyncClient(timeout=timeout) as client:
        response = await client.post(url, json=payload)
        response.raise_for_status()
        data = response.json()
        return data["choices"][0]["message"]["content"]
```

`backend/app/database.py` 内のデータベースセッションと接続定義:

from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker, DeclarativeBase
from app.config import settings

engine = create_engine(
    settings.database_url,
    connect_args={"check_same_thread": False},
    echo=False,
)

SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)

class Base(DeclarativeBase):
    pass

def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

## 3. 実装要件 (Implementation Logic)
- **3-1. `backend/app/seed_data.py`**:
  - `LLM_PROMPT_SEEDS` は `seed_data.py` 内のモジュールレベル of 定数リストである。この配列の末尾に、以下のキーとデフォルト設定値を持つ新しい辞書を追加する。
    - `translation_ja_to_en` (日英翻訳用システムプロンプト)
      - デフォルト: "You are a professional prompt translator for AI image generation. Translate the following Japanese text into natural, descriptive English prompt. Output ONLY the translated English prompt. Do not output any chat dialog or explanations."
    - `translation_en_to_ja` (英日翻訳用システムプロンプト)
      - デフォルト: "あなたはAI画像生成プロンプトの専門翻訳者です。与えられた英語のプロンプトを、自然な日本語に翻訳してください。翻訳結果のみを出力し、挨拶や余計な解説は一切含めないでください。"
    - `translation_model` (翻訳用モデル名、デフォルト `""`)
    - `translation_debounce` (デバウンス間隔、デフォルト `"500"`)
- **3-2. `backend/app/seeder.py`**:
  - データベースに未登録の `LlmPrompt` が存在する場合、新規シードとして登録されること。
- **3-3. `backend/app/routers/llm_prompts.py`**:
  - `TranslateRequest` スキーマ（Pydanticモデル）を定義する。
    - `text`: 文字列
    - `direction`: Literal["ja_to_en", "en_to_ja"]
  - `/translate` エンドポイントを POST で実装する。
    - リクエスト引数として `TranslateRequest` と `Session` (Depends(get_db)) を受け取る。
    - DBの `llm_prompts` テーブルから `key == f"translation_{payload.direction}"` のレコードを検索し、存在し、かつその `content.strip()` が空文字 `""` でない場合はその値を、存在しないか空文字の場合はフォールバックとして固定値（3-1 に記載されたデフォルトプロンプト文字列）を `system_prompt` に設定する。
    - DBの `llm_prompts` テーブルから `key == "translation_model"` のレコードを検索し、存在し、かつその `content.strip()` が空文字 `""` でない場合はその値を `model` として用いる。それ以外（未登録、または空文字）の場合は `model = None` とする（これにより `call_llm` の内部でメインモデル `llm_model` へのフォールバックが行われる）。
    - `app.services.llm_request.call_llm` を呼び出す。その際、引数には `system_prompt=system_prompt`, `user_prompt=payload.text`, `model=model`, `timeout=30.0` を渡す。
    - 結果の文字列（`strip()` 済み）をレスポンスとして返す。
    - LLM呼び出し時に例外（タイムアウトや接続エラー等）が発生した場合は、キャッチして HTTP 500 エラー (`HTTPException(status_code=500, detail=str(e))`) を発生させる。
