# REQ-433-T4: 全ステータスランプの正円保護・shrink-0・SystemStatusBadge Hit-Slop 統一

## 1. 概要と目的
アプリ全体（全 9 ファイル）のステータスランプ（円形インジケータドット）に対し、`data-radius-exempt` と `shrink-0` を付与してモバイル時の角丸 8px 化・潰れを防止する。また操作可能な `SystemStatusBadge`（`variant="dot"`）については `data-tap-target-exempt` と 44×44px 以上の Hit-Slop を適用し、7×7px 正円表示とタップ操作性を両立する。本カードが本タスクの唯一の意味仕様である。

## 2. ターゲット識別
- **対象ファイル**:
  1. `frontend/src/components/common/SystemStatusBadge.tsx`（L289 `dot`, L320 ピル外枠, L322 内部ドット）
  2. `frontend/src/pages/SettingsPage/components/ServiceConnectionCard.tsx`（L125）
  3. `frontend/src/components/SettingsComponents.tsx`（L235 `ConnectionStatus`）
  4. `frontend/src/components/layout/AppShell.tsx`（L92）
  5. `frontend/src/pages/GeneratePage/components/DesktopLayout.tsx`（L401, L438）
  6. `frontend/src/pages/GeneratePage/components/MobileLayout.tsx`（L512, L577, L611）
  7. `frontend/src/pages/DatasetStudioPage/index.tsx`（L164, L175, L185, L195, L202）
  8. `frontend/src/pages/HistoryPage/index.tsx`（L328）
  9. `frontend/src/components/WorkflowDiffReplaceModal.tsx`（L341, L413）
  - テスト: `frontend/src/components/common/__tests__/SystemStatusBadge.test.tsx`, `frontend/src/pages/SettingsPage/components/__tests__/ServiceConnectionCard.test.tsx`
- **UI Archetype**: `Generic / Custom`（インジケータ、および `SystemStatusBadge` dot は `Archetype 3` 相当の Hit-Slop 適用）

<constraints>
- 全ステータスランプ（`w-1.5 h-1.5` / `w-[7px] h-[7px]` / `w-2 h-2` / `w-2.5 h-2.5` + `rounded-full`）に `data-radius-exempt` と `shrink-0`（または `flex-shrink-0`）を付与すること。
- `SystemStatusBadge` の `variant="dot"`（`<span role="button">` L275–290）は `data-radius-exempt` と `data-tap-target-exempt` を付与し、`relative before:absolute before:-inset-[19px] before:content-['']`（7+38=45px >= 44px）で有効タップ領域を確保すること。
- 色のみで状態を伝えない原則（隣接テキストまたは `aria-label`）を維持すること。
</constraints>
