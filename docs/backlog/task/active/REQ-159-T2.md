### REQ-159-T2: 自セッション履歴同期(Reconciliation)と全体進捗・キュー残数の役割分離

#### 目的
バックグラウンド移行中に完了した生成画像が自セッション履歴（サムネイル一覧）から抜け落ちる問題の解消、および全体進捗（FE投入予定総数基準）とキュー残数（ComfyUI実数基準）の役割分離を実装する。

#### 対象ファイル
1. `frontend/src/store/useGenerationStore.ts`
2. `frontend/src/pages/GeneratePage/hooks/useGenerateAction.ts`
3. `frontend/src/pages/GeneratePage/hooks/useGeneratePageState.ts`

#### 関連型定義 (Context Types)
```typescript
export interface ComfyHistoryOutput {
  images?: Array<{
    filename: string
    subfolder: string
    type: string
  }>
}

export interface ComfyHistoryItem {
  outputs: Record<string, ComfyHistoryOutput>
  prompt: [
    number,              // prompt index
    string,              // prompt_id
    Record<string, any>, // workflow JSON
    {
      client_id?: string
      [key: string]: any
    },                   // extra_data
    any[]                // outputs info
  ]
  status: {
    completed: boolean
    [key: string]: any
  }
}

export interface BatchJob {
  promptId: string;
  setName: string;
  status: 'pending' | 'generating' | 'completed' | 'failed';
}
```

#### 実装仕様詳細 (Implementation Details)

##### 1. `frontend/src/store/useGenerationStore.ts`
- **`fetchHistory` (L1086-1115)**:
  `/history` 取得時に、`item.prompt[3]?.client_id === get().clientId` に一致する画像を抽出して `batchImages` へマージ・永続化する。
  ```typescript
  fetchHistory: async () => {
    if (!comfyUrl) return
    const resolvedUrl = resolveComfyUrl(comfyUrl)
    try {
      const res = await fetch(`${resolvedUrl}/history`)
      if (!res.ok) return
      const data = await res.json()
      const allImages: string[] = []
      const ownImages: string[] = []
      const clientId = get().clientId

      const entries = Object.entries(data) as [string, ComfyHistoryItem][]
      const sortedEntries = entries.sort(([, itemA], [, itemB]) => {
        const indexA = itemA.prompt ? itemA.prompt[0] : 0
        const indexB = itemB.prompt ? itemB.prompt[0] : 0
        return indexB - indexA
      })

      sortedEntries.forEach(([key, item]) => {
        const isOwnPrompt = item.prompt && item.prompt[3]?.client_id === clientId
        Object.values(item.outputs).forEach((out) => {
          if (out.images) {
            out.images.forEach((img) => {
              const url = `${resolvedUrl}/view?filename=${encodeURIComponent(img.filename)}&subfolder=${encodeURIComponent(img.subfolder)}&type=${encodeURIComponent(img.type)}&t=${key}`
              allImages.push(url)
              if (isOwnPrompt) {
                ownImages.push(url)
              }
            })
          }
        })
      })

      set((state) => {
        // 自セッション履歴のマージ (既存と結合して重複排除、最大50件)
        const mergedBatchImages = Array.from(new Set([...state.batchImages, ...ownImages])).slice(0, 50)
        localStorage.setItem(LS_KEYS.BATCH_IMAGES, JSON.stringify(mergedBatchImages))
        const nextSelected = state.selectedImg || (mergedBatchImages.length > 0 ? mergedBatchImages[0] : null)
        if (nextSelected && !state.selectedImg) {
          localStorage.setItem(LS_KEYS.SELECTED_IMG, nextSelected)
        }

        return {
          comfyHistoryImages: allImages.slice(0, 50),
          batchImages: mergedBatchImages,
          selectedImg: nextSelected,
        }
      })
    } catch (e) {
      console.error('Failed to fetch comfy history:', e)
    }
  }
  ```

##### 2. `frontend/src/pages/GeneratePage/hooks/useGenerateAction.ts`
- **`handleGenerateSets` (L207-312)**:
  - 投入開始時に今回の全投入予定枠（既存未完了分とマージ）を `activeBatch` にセットし、全体進捗母数 `M` を正しく設定。
  - 各ジョブの `queuePrompt` 実行時、成功時は実際の `prompt_id` に更新し、失敗時は `status: 'failed'` に設定。
  - `fetchQueue()` を定期または完了時に呼び出し、ComfyUIの実際のキュー数を更新。

##### 3. `frontend/src/pages/GeneratePage/hooks/useGeneratePageState.ts`
- **`totalQueueCount` (L819-826)**:
  クライアント側の未送信ダミーを加算せず、純粋にComfyUI側の実キュー（`queueRunning` + `queuePending`）を集計。
  ```typescript
  const totalQueueCount = useMemo(() => {
    const filterJob = (job: any) => !store.filterOwnSession || job[3]?.client_id === clientId
    return store.queueRunning.filter(filterJob).length + store.queuePending.filter(filterJob).length
  }, [store.queueRunning, store.queuePending, store.filterOwnSession, clientId])
  ```
- **フォアグラウンド復帰時の自動同期**:
  `visibilitychange` および `focus` イベントリスナーを登録。
  ```typescript
  useEffect(() => {
    const handleVisibility = () => {
      if (document.visibilityState === 'visible') {
        store.fetchQueue()
        store.fetchHistory()
      }
    }
    document.addEventListener('visibilitychange', handleVisibility)
    window.addEventListener('focus', handleVisibility)
    return () => {
      document.removeEventListener('visibilitychange', handleVisibility)
      window.removeEventListener('focus', handleVisibility)
    }
  }, [store])
  ```

#### エッジケース・エラーハンドリング
- 通信切断時: WebSocket切断時でも復帰時に `visibilitychange` ハンドラが `fetchHistory` を呼び出して完全同期。
- `POST /prompt` 失敗時: `status: 'failed'` となり、全体進捗の母数は崩れずトースト通知される。
