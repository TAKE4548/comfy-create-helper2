### REQ-165-T2: フロントエンド API クライアント拡張および翻訳状態管理フックの実装

#### 目的
バックエンドの翻訳プロキシAPIおよび疎通テストAPIを呼び出すクライアントメソッドを追加し、モーダルの開閉、モード切替（英→日確認 / 日→英作成）、翻訳プレビュー、明示的な反映・追記（手動適用）を安全に制御するカスタムフック `usePromptTranslation` を実装する。

#### 対象ファイル
1. `frontend/src/api/client.ts` (MODIFY)
2. `frontend/src/pages/GeneratePage/hooks/usePromptTranslation.ts` (NEW)
3. `frontend/src/pages/GeneratePage/hooks/__tests__/usePromptTranslation.test.ts` (NEW)

#### 完全な型定義・スキーマ (Complete Context Types & Schemas)

```typescript
export interface PromptTranslateRequest {
  prompt: string;
  source_lang?: string;
  target_lang?: string;
}

export interface TranslateMeta {
  total_chunks: number;
  cached_chunks: number;
  api_requested_chunks: number;
  billed_characters: number;
  provider: string;
}

export interface PromptTranslateResponse {
  translated_prompt: string;
  meta: TranslateMeta;
}

export interface TranslateTestRequest {
  provider: 'google_free' | 'google_cloud' | 'deepl' | 'llm';
  api_key?: string;
  api_url?: string;
}

export interface TranslateTestResponse {
  success: boolean;
  sample_translation: string;
  error?: string;
}

export type TranslationMode = 'en_to_ja' | 'ja_to_en';
```

#### 実装指示 (Implementation Steps)

1. **`client.ts` の拡張**:
   - `translateApi` オブジェクトを定義:
     ```typescript
     export const translateApi = {
       translatePrompt: (data: PromptTranslateRequest) =>
         request<PromptTranslateResponse>('/translate/prompt', {
           method: 'POST',
           body: JSON.stringify(data),
         }),
       testConnection: (data: TranslateTestRequest) =>
         request<TranslateTestResponse>('/translate/test', {
           method: 'POST',
           body: JSON.stringify(data),
         }),
       getStats: () =>
         request<{ cached_entries_count: number }>('/translate/stats'),
       clearCache: () =>
         request<{ status: string }>('/translate/clear-cache', {
           method: 'POST',
         }),
     }
     ```

2. **`usePromptTranslation.ts` の実装**:
   - 状態管理:
     - `activeRole: string | null`
     - `isOpen: boolean`
     - `mode: TranslationMode` (`'en_to_ja'` | `'ja_to_en'`)
     - `sourceText: string`
     - `translatedText: string`
     - `meta: TranslateMeta | null`
     - `isTranslating: boolean`
     - `error: string | null`
   - アクション:
     - `openTranslation(role: string, currentPromptValue: string)`:
       - モーダルを開き、`activeRole` をセット。
       - モードを `'en_to_ja'` にリセット。
       - `sourceText` に `currentPromptValue` をセットし、`translatedText` / `meta` をクリア。
     - `closeTranslation()`: モーダルを閉じ、ステートをリセット。
     - `setMode(newMode: TranslationMode)`: モードを切り替える。
     - `executeTranslate(customText?: string)`:
       - 現在の `sourceText`（または引数テキスト）をAPIに送信。
       - ローディング管理とエラーハンドリング。
       - 翻訳結果を `translatedText` および `meta` にセット。
       - ※重要: `paramValues` は一切変更しない！
     - `applyToPrompt(actionType: 'append' | 'replace')`:
       - `activeRole` が存在し、`translatedText` がある場合のみ実行。
       - `'append'`: 既存の `paramValues[activeRole]` の末尾に `, ${translatedText}` を安全に連結。
       - `'replace'`: `paramValues[activeRole]` を `translatedText` で更新。

3. **単体テストの実装 (`usePromptTranslation.test.ts`)**:
   - モーダルオープン・クローズ時のステート検証。
   - `executeTranslate` 実行時に `setParamValues` が自動呼び出しされないことの検証。
   - `applyToPrompt('append')` および `applyToPrompt('replace')` 実行時にのみ `setParamValues` が正しく更新されることの検証。
