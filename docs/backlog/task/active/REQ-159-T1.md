### REQ-159-T1: プログレスバー表示とアクティブセッション判定の是正

#### 目的
WebSocketの `execution_start` イベント受信時やジョブ移行時に `activeClientId` が消失し、`isGeneratingHere` 判定が `false`（Ready 0%）にリセットされる不具合を修正する。

#### 対象ファイル
1. `frontend/src/store/useGenerationStore.ts`
2. `frontend/src/pages/GeneratePage/hooks/useGeneratePageState.ts`

#### 関連型定義とストア仕様 (Context Types & Store Architecture)
本プロジェクトのフロントエンドは **Zustand (`create<GenerationState>((set, get) => ...)`)** を状態管理として採用しています。

#### バッチジョブ状態遷移マシン (Batch Job State Machine)
| 現在の状態 | トリガーイベント | 遷移後の状態 | 副作用・アクション |
|---|---|---|---|
| `(初期化)` | `handleGenerateSets` 実行 | `pending` | `activeBatch` に登録（`promptId: "pending-xxx"` または確定 `promptId`） |
| `pending` | ComfyUI `execution_start` 受信 | `generating` | `updateBatchJobStatus(promptId, 'generating')`, `isGenerating: true`, `activeClientId` を `clientId` に維持 |
| `generating` | ComfyUI `executed` 受信 | `completed` | `updateBatchJobStatus(promptId, 'completed')`, 生成画像を `batchImages` へ追加 |
| `generating` | ComfyUI `execution_complete` 受信 | `completed` | `updateBatchJobStatus(promptId, 'completed')` |
| `pending` / `generating` | ComfyUI `execution_error` または Abort | `failed` | `updateBatchJobStatus(promptId, 'failed')` |

#### 実装仕様詳細 (Implementation Details)

##### 1. `frontend/src/store/useGenerationStore.ts`
- **`queuePrompt` (L1018-1033)**:
  `options?.isBatchIntermediate === true` の場合でも `activeClientId: get().clientId` を設定する。
  ```typescript
  if (options?.isBatchIntermediate) {
    set({
      isGenerating: true,
      currentPromptId: promptId,
      activeClientId: get().clientId,
    })
  }
  ```
- **WebSocket `execution_start` ハンドラ (L637-652)**:
  現在 `activeClientId: null` にリセットされている処理を修正。
  ```typescript
  case 'execution_start': {
    const promptId = data.prompt_id as string
    const currentBatch = get().activeBatch
    const isOwnBatchJob = currentBatch ? currentBatch.some((job) => job.promptId === promptId) : false
    const hasUnfinishedBatch = currentBatch ? currentBatch.some((job) => job.status === 'pending' || job.status === 'generating') : false

    if (currentBatch) {
      get().updateBatchJobStatus(promptId, 'generating')
    }
    set({
      isGenerating: true,
      progress: null,
      currentPromptId: promptId,
      activeClientId: (isOwnBatchJob || hasUnfinishedBatch) ? get().clientId : (get().activeClientId ?? get().clientId),
      generationStartTime: Date.now(),
      currentNode: null,
      nodeProgress: null,
    })
    get().fetchQueue()
    break
  }
  ```
- **`fetchQueue` (L1117-1150)**:
  キュー取得時、`queue_running` に実行中ジョブが存在する場合に `activeClientId` を同期する。
  ```typescript
  const running = data.queue_running || []
  if (running.length > 0) {
    const activeJobClientId = running[0][3]?.client_id || null
    if (activeJobClientId) {
      set({ activeClientId: activeJobClientId })
    }
  }
  ```

##### 2. `frontend/src/pages/GeneratePage/hooks/useGeneratePageState.ts`
- **`isGeneratingHere` 判定 (L818)**:
  自セッション判定に `activeBatch` 内の未完了ジョブ存在チェックを追加。
  ```typescript
  const isGeneratingHere = store.isGenerating && (
    !store.filterOwnSession ||
    store.activeClientId === clientId ||
    (store.activeBatch !== null && store.activeBatch.some(j => j.status === 'generating' || j.status === 'pending'))
  )
  ```

#### エッジケース・エラーハンドリング (Error Boundaries & Fallbacks)
1. **`clientId` の永続性**:
   - `localStorage.getItem(LS_KEYS.CLIENT_ID)` から読み込み、未存在時は `'prompt-surgeon-' + Math.random().toString(36).slice(2, 9)` を自動生成して即時保存。
2. **WebSocket切断と再接続**:
   - `ws.onclose` / `ws.onerror` 発生時、`isConnected: false` をセットし、`reconnectTimer = setTimeout(() => get().initialize(), 3000)` により自動再接続。
3. **他クライアント生成時のセッション分離**:
   - `filterOwnSession: true` 有効時、外部クライアントからの生成ジョブは `store.activeClientId !== clientId` かつ `activeBatch` に存在しないため、`isGeneratingHere === false` となり自画面のUI進捗には混入しない。

#### 受け入れ基準 (AC)
- [x] AC-1-1: モバイル端末および `filterOwnSession: true` 環境において、1枚目生成開始からバッチ全件完了まで、プログレスバーが途切れず正常に表示されること。
- [x] AC-1-2: 1枚目の生成が完了して2枚目以降のジョブへ移行した際にも、`isGeneratingHere` が維持され、プログレスバーが「Ready (0%)」にリセットされないこと。
- [x] AC-1-3: 生成中にページをリロードした場合でも、実行中ジョブの進捗バーが継続表示されること。
