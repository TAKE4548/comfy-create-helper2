# REQ-425-T3: Frontend 設定画面のプロンプト構造テンプレート管理UIおよびワークフロー出力グループ設定UI実装

## Goal
設定画面（`SettingsPage` の「ワークフロー・マッピング」タブ）に、プロンプト構造テンプレートを作成・編集・削除できる管理セクション（`PromptTemplateManagerSection.tsx`）と、ワークフロー毎の「対応付け・設定」パネル内でプロンプト出力グループ（任意名称、送信先 `target_role` 割り当て、結合対象 `block_ids` 選択・順序変更、Repeat 対象指定 `all` / `index`）を構成・保存・エクスポート/インポートできるエディタ（`WorkflowPromptOutputGroupsEditor.tsx`）を実装する。

## Target Files (Write Scope)
- `frontend/src/pages/SettingsPage/components/PromptTemplateManagerSection.tsx` (新規)
- `frontend/src/pages/SettingsPage/components/WorkflowPromptOutputGroupsEditor.tsx` (新規)
- `frontend/src/pages/SettingsPage/components/WorkflowConnectionSection.tsx`
- `frontend/src/pages/SettingsPage.tsx`
- `frontend/src/pages/SettingsPage/__tests__/SettingsPage.test.tsx`

## Context & Surgical Snippets

### 1. プロンプト構造テンプレート管理 UI (`PromptTemplateManagerSection.tsx` & `SettingsPage.tsx`)
- `PromptTemplateManagerSectionProps`:
```typescript
export interface PromptTemplateManagerSectionProps {
  isExpanded?: boolean
  onToggle?: () => void
}
```
- `useQuery({ queryKey: ['prompt-templates'], queryFn: () => promptTemplatesApi.list() })` でテンプレート一覧（「Anima 標準テンプレート」を含む）を取得・表示する（`AC-1`, `AC-2`）。
- 機能要件：
  - **新規テンプレート作成 / 既存テンプレート編集 / 複製 / 削除**。
  - 各テンプレートの `structure.sections` に対して：
    - セクションの追加・名称変更・削除・上下移動。
    - `is_repeatable`（Repeat セクション / 複数インスタンス追加可否）チェックボックストグル。
    - セクション内の `blocks`（各ブロックの `label`, `id`）の追加・編集・削除・順序入れ替え（上へ/下へボタン）。
- `SettingsPage.tsx` の `activeTab === 'workflows'` 内に `<PromptTemplateManagerSection />` を配置する。

### 2. ワークフロー別プロンプト出力グループ設定 UI (`WorkflowPromptOutputGroupsEditor.tsx`)
```typescript
import type {
  PromptTemplate,
  WorkflowMapping,
  WorkflowPromptTemplateConfig,
} from '../../../api/types'

export interface WorkflowPromptOutputGroupsEditorProps {
  templates: PromptTemplate[]
  textareaMappings: WorkflowMapping[]
  config: WorkflowPromptTemplateConfig
  onChange: (nextConfig: WorkflowPromptTemplateConfig) => void
}
```
- 機能要件（`AC-3`）：
  1. **適用テンプレート選択 (`select`)**:
     - `"未適用 (従来の単一プロンプト入力)"` (`template_id: null, template_snapshot: null, output_groups: []`) または `templates` 一覧から選択。
     - テンプレートを選択または変更した際、`config.template_id` とともに選択テンプレートの `structure` を `config.template_snapshot` にコピーして保持する。
  2. **出力グループ一覧と操作**:
     - `[+ 出力グループを追加]` ボタンで新規グループ（`id: generateUUID()`, `name: "出力グループ N"`, `target_role: textareaMappings[0]?.role ?? ""`, `block_ids: allBlockIds`, `repeat_filter: { mode: "all" }`）を追加。
     - 各出力グループカード内で：
       - **グループ名入力 (`input[type="text"]`)**: 自由入力（例: `"全体プロンプト"`, `"アップスケール用"`, `"FaceDetailer #1"` 等、固定ステージ名のハードコードなし）。
       - **送信先プロンプトノード選択 (`select`)**: `textareaMappings`（`input_type === 'textarea'` を持つワークフローマッピング）の `role` / `display_name` から選択。
       - **Repeat 対象指定 (`select` + インスタンス番号 `input[type="number"]`)**:
         - `mode: "all"`（「全インスタンスを結合」）
         - `mode: "index"`（「特定インスタンスのみ結合 (#1, #2...)」、`index >= 1` の数値入力）。
       - **結合対象ブロック選択・順序制御**:
         - セクション毎の「全選択」「全解除」ボタン、および各ブロックのチェックボックス ON/OFF。
         - 選択済みブロックの結合順序を上下移動できるコントロール（またはセクション内順序に基づく整列ボタン）。
  3. **未割り当てプロンプト欄の表示**:
     - `textareaMappings` のうち、いずれの `output_group.target_role` にも割り当てられていないロール（例: `negative` 等）を「単一入力欄として維持されるプロンプトノード」としてバッジ表示し、ユーザーに明確に伝える（`AC-4`）。

### 3. `WorkflowConnectionSection.tsx` への統合
- `WorkflowConnectionSection.tsx` のワークフロー「対応付け・設定」パネル（`configWorkflowId === wf.id` ブロック、715〜761行付近）に以下を統合する：
  - `configPromptTemplate` state（初期値 `configWorkflow.prompt_template_config ?? { template_id: null, template_snapshot: null, output_groups: [] }`）を追加。
  - `<WorkflowPromptOutputGroupsEditor>` を描画し、変更時に `configDraftRevision.current += 1` と `setConfigPromptTemplate(next)` を呼ぶ。
  - `handleSaveLinks` および `saveWorkflowConfig` で `workflowsApi.update(configWorkflow.id, { ..., prompt_template_config: configPromptTemplate })` を送信する。
  - 「設定JSONをエクスポート」および「設定JSONをインポート」（`handlePreviewConfig`）のペイロードに `prompt_template_config` を含める。
