# REQ-302-T1: デザインシステムトークン定義とモーダルバックドロップの余白・レイヤー改修

## 1. 概要と目的
モバイルビューでモーダルがボトムナビゲーションを前面で覆い、全画面の高さを有効活用できるよう、`frontend/src/index.css` と `frontend/tailwind.config.js` のスタッキング階層（z-index）とバックドロップ余白設定を改修する。

## 2. 密閉コンテキスト (Hermetic Context)

### 2.1 現行コードスニペット: `frontend/src/index.css` (L14-L22)
```css
    --border: rgba(255, 255, 255, 0.08);
    --text-primary: #E4E4E7;
    --text-muted: #A1A1AA;
    --mobile-nav-height: 4rem;
    --z-mobile-nav: 50;
    --z-modal: 100;
  }
```

### 2.2 現行コードスニペット: `frontend/src/index.css` (L138-L164)
```css
.modal-backdrop {
  position: fixed;
  inset: 0;
  background-color: rgba(0, 0, 0, 0.7);
  backdrop-filter: blur(8px);
  -webkit-backdrop-filter: blur(8px);
  display: flex;
  align-items: center;
  justify-content: center;
  z-index: var(--z-modal);
  padding: 1rem;
  padding-bottom: calc(var(--mobile-nav-height) + 1rem + env(safe-area-inset-bottom));
}

.modal-backdrop:fullscreen {
  padding: 0 !important;
}

.modal-backdrop:-webkit-full-screen {
  padding: 0 !important;
}

@media (min-width: 1024px) {
  .modal-backdrop {
    padding-bottom: 1rem;
  }
}
```

### 2.3 現行コードスニペット: `frontend/tailwind.config.js` (L8-L20)
```javascript
  theme: {
    extend: {
      colors: {
        background: '#0F0F11',
        surface: '#18181C',
        'surface-2': '#1F1F25',
        'accent-green': '#3ecf8e',
        'accent-purple': '#7C6FDD',
        border: 'rgba(255,255,255,0.08)',
      },
```

## 3. 実装要件 (Implementation Logic)
1. **`frontend/src/index.css` の z-index トークン更新**:
   - `--z-mobile-nav: 50;` を `--z-mobile-nav: 40;` に変更。
   - `--z-modal: 100;` を維持し、新たに `--z-modal-nested: 110;` および `--z-toast: 200;` を追加。
2. **`frontend/src/index.css` の `.modal-backdrop` 余白改修**:
   - `padding-bottom: calc(var(--mobile-nav-height) + 1rem + env(safe-area-inset-bottom));` から `--mobile-nav-height` の加算を撤廃。
   - `padding-bottom: calc(1rem + env(safe-area-inset-bottom, 0px));` に変更。
   - `@media (min-width: 1024px)` では `padding-bottom: 1rem;` を維持。
3. **`frontend/tailwind.config.js` の zIndex 拡張**:
   - `theme.extend` に以下を追加:
     ```javascript
     zIndex: {
       'mobile-nav': '40',
       'modal': '100',
       'modal-nested': '110',
       'toast': '200',
     },
     ```

## 4. 完了条件と検証
- [ ] `--z-mobile-nav` が 40、`--z-modal` が 100、`--z-modal-nested` が 110 として定義されていること。
- [ ] `.modal-backdrop` の `padding-bottom` から `--mobile-nav-height` が完全に除去されていること。
- [ ] Tailwind で `z-mobile-nav`, `z-modal`, `z-modal-nested` クラスが利用可能であること。

`cd frontend; npm run typecheck`
