### 2.2 UI要件 & 最近使用した色パレット (Recent Colors)
1. **未選択状態**:
   - `bubble === null` の場合、「吹き出しが選択されていません。キャンバス上の吹き出しをクリックするか、ダブルクリックで追加してください。」というガイダンスを表示。
2. **選択中状態**:
   - **セリフテキスト入力**: textarea + 「ドラフト生成 (LLM)」ボタン
   - **形状選択 (Shape Selector)**:
     - 5つのボタン（楕円 / 角丸 / 叫び / 思考 / 枠なし）
   - **文字方向 (Orientation)**:
     - 「縦書き」「横書き」のトグルボタン
   - **描画フォント & サイズ**:
     - `fontList` の select ドロップダウン
     - フォントサイズ指定（自動フィット / 8〜64px の数値・スライダー）
   - **色彩・装飾設定 (RGBA) & 最近使用した色**:
     - 文字色 (Text Color): カラーピッカー + 不透明度スライダー (0%〜100%)
     - 吹き出し背景色 (Background Color): カラーピッカー + 不透明度スライダー (0%〜100%)
     - 枠線色 (Border Color): カラーピッカー + 不透明度スライダー (0%〜100%)
     - 枠線の太さ (Border Width): 0px 〜 10px のスライダー
     - **最近使用した色 (Recent Colors)**:
       - カラー変更時に `localStorage.getItem('speech_bubble_recent_colors')` に最大10件まで色（RGBA文字列またはHEX+Alpha）を重複なしで先頭に追加・保存。
       - 各カラーピッカー下に「最近使用した色」チップ列（最大10個）を表示し、チップクリックで対象色（文字色・背景色・枠線色）にワンクリック適用。
   - **削除ボタン**:
     - 「この吹き出しを削除」ボタン（ゴミ箱アイコン）
