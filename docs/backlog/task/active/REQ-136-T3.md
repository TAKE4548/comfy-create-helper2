### 2.2 インタラクション要件
1. **ダブルクリック / ダブルタップでの新規追加**:
   - キャンバス上でダブルクリック時、クリック座標（元画像座標系に変換後）を中心とする新規 `SpeechBubble` を生成し、`bubbles` に追加して選択状態にする。
   - 初期値:
     - `w: 160, h: 140`
     - `shape: 'oval'`
     - `orientation: 'vertical'`
     - `fontFamily: selectedFont`
     - `textColor: 'rgba(0, 0, 0, 1)'`
     - `backgroundColor: 'rgba(255, 255, 255, 0.95)'`
     - `borderColor: 'rgba(0, 0, 0, 1)'`
     - `borderWidth: 2`
     - `tail: { x: bubble.x + bubble.w / 2 - 30, y: bubble.y + bubble.h + 40 }`
2. **マウス操作（シングルクリック・ドラッグ）**:
   - 尻尾ハンドル上クリック: `draggingState.type = 'tail'`
   - バブル矩形内クリック: 対象バブルを選択し、`draggingState.type = 'bubble'`
   - キャンバスの何もない部分クリック: ドラッグでROI範囲指定、または選択解除
3. **キーボード操作**:
   - `selectedBubbleId` がある状態で `Delete` / `Backspace` キー（テキスト入力欄にフォーカスがない場合）を押下すると、対象バブルを `bubbles` から削除。
4. **自動検出（Auto Detect / Debug Panel）との連携**:
   - 吹き出し自動検出結果（`detectBubble` または candidates からの適用）が返った場合、その位置に新規バブルを追加（または初期バブルとして設定）。
5. **保存処理 (`handleSave`)**:
   - オフスクリーン Canvas にて `drawImage(imageObj, 0, 0)`。
   - 各 `SpeechBubble` に対して `drawSpeechBubble`（選択枠なし・元画像スケール）を順次描画。
   - `offCanvas.toBlob` -> `snapshotsApi.upload` -> `snapshotsApi.create`。
</hermetic_context>
