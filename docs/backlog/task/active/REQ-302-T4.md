## 3. 実装要件 (Implementation Logic)
1. **新規 `frontend/src/test/e2e_req302_mobile_modal_overlay.test.tsx` の実装**:
   - **AC-1 & AC-3**: モバイルビューで `AppShell` とモーダルをレンダリング。
     - モーダルのバックドロップが `fixed inset-0` で全画面を覆うこと。
     - モーダル展開中にボトムナビ領域をクリックしても `<NavLink>` の遷移が発生しないこと。
     - バックドロップタップでモーダルが閉じること。Esc キー押下でモーダルが閉じること。
   - **AC-2**: `.modal-backdrop` に `--mobile-nav-height` 回避用のパディングが付与されていないことを検証。
   - **AC-4**: 二次確認モーダル（`z-[var(--z-modal-nested)]` = 110）が一次モーダル（`z-[var(--z-modal)]` = 100）およびボトムナビ（`z-[var(--z-mobile-nav)]` = 40）よりも上位に描画されること。
   - **AC-5**: セーフエリアフォールバック（`calc(1rem + env(safe-area-inset-bottom, 0px))`）が設定されていること。
   - **AC-6**: デスクトップ幅（1024px 以上）における非回帰（レイアウト・センタリング保持）。
2. **Red Teaming シナリオ**:
   - モーダル表示中のボトムナビへの高速重複タップ遮断。
   - 二次モーダル展開時の Esc キーが最前面のみを閉じること。
