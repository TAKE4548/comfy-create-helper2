# REQ-433-T2: index.css における button および rounded-full の data-radius-exempt 保護対応

## 1. 概要と目的
`frontend/src/index.css` の `@layer utilities` 内にある一律角丸補正規則で、`button` セレクタおよび `[class~='rounded-full'][class*='px-']` セレクタに `:not([data-radius-exempt])` を追加し、トグルスイッチやステータスランプが `data-radius-exempt` によりピル型・正円を保持できるようにする。本カードが本タスクの唯一の意味仕様である。

## 2. ターゲット識別
- **対象ファイル**: `frontend/src/index.css`
- **対象箇所**: L169–187（`@layer utilities` 内の一律 `border-radius` 上書き規則）
- **UI Archetype**: `Generic / Custom`（グローバル CSS 基盤）

<constraints>
- `!important` の新規追加は禁止（`verify_ui_invariants.py` の `rule-no-indiscriminate-important` に抵触するため）。
- 既存の `Modal`（`data-radius-exempt` 付き `rounded-t-2xl`）および一般ボタン（`--ux-radius-control`: 8px）・チップ（`--ux-radius-chip`: 6px）の挙動を破壊しないこと。
</constraints>

## 3. コンテキスト (Surgical Context)
```css
  /* frontend/src/index.css L169-186 */
  button,
  input,
  select,
  textarea,
  [class~='rounded']:not([data-radius-exempt]),
  [class~='rounded-sm']:not([data-radius-exempt]),
  [class~='rounded-md']:not([data-radius-exempt]),
  [class~='rounded-lg']:not([data-radius-exempt]),
  [class~='rounded-xl']:not([data-radius-exempt]),
  [class~='rounded-2xl']:not([data-radius-exempt]),
  [class~='rounded-3xl']:not([data-radius-exempt]),
  [class~='rounded-full']:not([data-radius-exempt]) {
    border-radius: var(--ux-radius-control);
  }

  [class~='rounded-full'][class*='px-'] {
    border-radius: var(--ux-radius-chip);
  }
```

## 4. 実装要件
- [ ] `frontend/src/index.css` L169 の `button,` を `button:not([data-radius-exempt]),` に変更する。
- [ ] `frontend/src/index.css` L184 の `[class~='rounded-full'][class*='px-']` を `[class~='rounded-full'][class*='px-']:not([data-radius-exempt])` に変更する。
