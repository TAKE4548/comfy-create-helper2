## 判定
T0 の改修前値と同じブラウザ設定・空キャッシュ・初期 `/`・画面幅・圧縮/HTTP 条件で、プロンプトが編集可能になるまでの JS 実転送量を比較する。Network の URL・バイト・取得時刻と編集可能時点を記録する。JS チャンクの警告がなく、初回転送合計が小さく、AC-3〜6 と LoRAs/Tags 回帰が PASS の場合のみ完了。いずれか失敗なら FAIL として原因となる静的 import / chunk を記録し、設計改訂へ戻す。単なる `manualChunks` による 500 kB 警告消失では PASS にしない。

**検証コマンド**: `cd frontend; npm run typecheck`、`cd frontend; npm run build`、`cd frontend; npm test`。本番配布物を用いた Gate 3 操作は `docs/design/REQ-309-test-plan.md` に従う。
