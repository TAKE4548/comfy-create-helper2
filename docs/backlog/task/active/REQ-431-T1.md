# REQ-431-T1: MobileImageSheet の左右スワイプ画像送りおよびスワイプダウン閉じる対応

## 1. 概要と目的
`MobileImageSheet.tsx`（ボトムシートおよび全画面ビューア）に以下を実装し、`MobileImageSheet.test.tsx` に単体テスト（AC-1〜AC-6）を追加する。
- ボトムシートおよび全画面ビューア共通の**3枚ウィンドウ・指追従カルーセル**（`prev`/`current`/`next` 最大3枚のみマウント、水平ドラッグ中 `translateX` 追従、閾値未満スナップ復帰、閾値/フリック時スライド切替、左=古い画像 `index + 1`、右=新しい画像 `index - 1`、端点減衰抵抗＋非ループ停止）
- 全画面表示中の `image` 切替時に `viewMode === 'fullscreen'` を維持する修正
- REQ-408 統一のスワイプダウン閉じるジェスチャー（閾値 `80px` または速度 `> 0.5px/ms` かつ移動量 `> 30px`、上方向 `0` クランプ、閾値未満 `translateY: 0` 復帰、`window.innerWidth < 768` のみ）
- 方向ロック（`|deltaX| > |deltaY|` vs `|deltaY| >= |deltaX|`）および `scrollTop > 0` 優先（縦スクロール中は両スワイプ抑止）、全画面表示中の下スワイプ閉じ無効化

## 5. 実装要件 (Implementation Logic)
- [ ] `MobileImageSheetProps` に `images?: string[]` と `onSelectImage?: (imageUrl: string) => void` を追加する。
- [ ] `useEffect` を分離し、`[isOpen]` 変更時のみ `viewMode` を `'sheet'`・`translateY` を `0`・ジェスチャー状態をリセットし、`[isOpen, image]` 変更時は `hasError` のみを `false` にリセットする（全画面表示中の画像切替で `sheet` に戻らないようにする）。
- [ ] `isScrolledDown(target, boundary)`（`el.scrollTop > 0` を `sheetContentRef.current` まで遡り判定）を実装する。
- [ ] 単一タッチ（`touches.length === 1`）向け状態機械（`gestureLockRef`: `'none' | 'horizontal' | 'vertical' | 'blocked'`）を実装する。
  - `touchStart`: `sheet` モードで `isScrolledDown === true` なら `'blocked'`。
  - `touchMove`: `DIRECTION_LOCK_SLOP = 5` を超えた時点で主方向ロック。`|deltaX| > |deltaY|` なら `'horizontal'`（`translateY` は動かさず、`dragOffsetX` を更新。端点方向へは `deltaX * 0.25` の減衰抵抗を適用）。それ以外は `fullscreen` モードまたは `window.innerWidth >= 768` なら `'blocked'`、モバイル `sheet` モードなら `'vertical'` として `translateY = Math.max(0, deltaY)` を適用。
  - 10px 超の移動で `didSwipeRef.current = true` とし、直後の `onClick`（全画面遷移／解除）を無視する。
  - `touchEnd`: `'horizontal'` なら `Math.abs(deltaX) >= 40` または `(velocityX > 0.4 && Math.abs(deltaX) > 20)` かつ有効な隣接画像がある場合にスライド完了後（幅 `0` 環境では即時）`onSelectImage` を呼び出し、`dragOffsetX` を `0` に戻す。閾値未満または端点時は `dragOffsetX = 0`（`transition: transform 0.2s cubic-bezier(0.16, 1, 0.3, 1)`）で中央へスナップ復帰。`'vertical'` なら `deltaY >= 80` または `(velocity > 0.5 && deltaY > 30)` で `handleSheetClose()`、未満は `translateY = 0` にスナップ復帰。
  - `touchCancel` / マルチタッチ時は `translateY = 0`、`dragOffsetX = 0` にリセットして中断。
- [ ] ボトムシート画像領域および全画面ビューアの両方に `overflow-hidden` と3枚ウィンドウトラック（`data-testid="mobile-image-carousel-track"`）を配置し、隣接画像には `alt=""` `aria-hidden="true"` を付与して既存 `alt` 検索の一意性を維持する。
- [ ] `mobile-image-sheet-content` に `ref={sheetContentRef}`、ドラッグハンドル表示、タッチハンドラ、`style={{ transform, transition }}` を設定し、`mobile-fullscreen-viewer` にも左右スワイプ用のタッチハンドラを設定する。
- [ ] `MobileImageSheet.test.tsx` に `[REQ-431/AC-1]`〜`[REQ-431/AC-6]` および Red Team ケース（`translateX` 指追従、閾値未満スナップ復帰、3枚ウィンドウ最大描画数、端点減衰抵抗、`scrollTop > 0`, 斜めスワイプ, 上ドラッグクランプ, 単一画像, `touchCancel`, エラー後スワイプ復帰, 幅 `>= 768px`）を追加する。
