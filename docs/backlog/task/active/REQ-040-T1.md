### 2.2 既存の状態、インポート、クエリ
```typescript
  // ストアからの状態のインポート
  const {
    filterOwnSession, setFilterOwnSession,
    batchImages, selectedImg, setSelectedImg,
    comfyHistoryImages,
    selectedWorkflowId,
  } = useGenerationStore() as GenerationStoreState

  // スナップショットのクエリ取得
  const { data: snapshots } = useQuery<SnapshotSummaryWithParams[]>({
    queryKey: ['snapshots', selectedWorkflowId],
    queryFn: () => snapshotsApi.list(selectedWorkflowId!) as Promise<SnapshotSummaryWithParams[]>,
    enabled: !!selectedWorkflowId,
  })

  // 既存のプレビューインデックス用状態定義
  const [thumbnailTab, setThumbnailTab] = useState<'history' | 'snapshots'>('history')
  const [isModalPreviewOpen, setIsModalPreviewOpen] = useState(false)
  const [modalPreviewIndex, setModalPreviewIndex] = useState(0)

  // displayImages の定義 (displayImages: string[])
  const displayImages = filterOwnSession ? batchImages : comfyHistoryImages

  // 既存の snapshotIdsForDisplay 計算ロジック
  const snapshotIdsForDisplay = displayImages.map((img) => {
    const found = snapshots?.find((s) => s.image_path === img)
    return found ? found.id : null
  })
```

## 3. 実装要件 (Implementation Logic)
- [x] **状態管理の追加**
  - `GeneratePage.tsx` 内に並び順を表す状態 `sortOrder` を追加する。
    - `const [sortOrder, setSortOrder] = useState<'desc' | 'asc'>('desc')`
- [x] **ソート処理の追加**
  - `displayImages` (History) をソートした `sortedDisplayImages` を定義する。
    - `sortOrder === 'desc'` の場合は `displayImages` のまま。
    - `'asc'` の場合は `[...displayImages].reverse()` で反転。
  - `snapshots` (Snapshots) をソートした `sortedSnapshots` を `useMemo` で定義する。
    - `const sortedSnapshots = useMemo(() => { if (!snapshots) return []; const copy = [...snapshots] as SnapshotSummaryWithParams[]; return sortOrder === 'desc' ? copy.sort((a, b) => new Date(b.created_at).getTime() - new Date(a.created_at).getTime()) : copy.sort((a, b) => new Date(a.created_at).getTime() - new Date(b.created_at).getTime()) }, [snapshots, sortOrder])`
  - `snapshotIdsForDisplay` の計算ロジックを `sortedDisplayImages` をマップし、かつ `sortedSnapshots` から探すように変更する。
  - サムネイル一覧のレンダリング、モーダルプレビュー (`HistoryModalPreview`) へのインプット画像配列 (`images={sortedDisplayImages}`, `snapshotIds={snapshotIdsForDisplay}`) などをすべて `sortedDisplayImages` と `sortedSnapshots` に置き換える。
- [x] **UIの追加 (Mobile / Desktop 両対応)**
  - サムネイルストリップのヘッダー（モバイルおよびデスクトップ）に、「新しい順」「古い順」を切り替えるセグメントトグルボタンを設置する。
  - トグルボタンのHTML/CSS構造は、以下のクラスを付与したインラインHTML要素とする。
    ```typescript
    <div className="flex rounded-lg overflow-hidden border border-[rgba(255,255,255,0.08)] bg-zinc-950/20">
      {(['desc', 'asc'] as const).map((order) => (
        <button
          key={order}
          type="button"
          onClick={() => setSortOrder(order)}
          className={`px-2.5 py-1 text-[10px] sm:text-xs font-medium transition-colors ${
            sortOrder === order ? 'bg-surface-2 text-zinc-200' : 'text-zinc-550 hover:text-zinc-350'
          }`}
        >
          {order === 'desc' ? '新しい順' : '古い順'}
        </button>
      ))}
    </div>
    ```
    - PC版：自セッション表示トグルの左側に配置（`flex items-center gap-3` の中に含める）。
    - モバイル版：ヘッダー右側（「自セッションのみ」トグルがある場合はその左側に並べる）。
