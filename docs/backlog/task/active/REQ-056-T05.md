## 3. 実装要件 (Implementation Logic)
- **`frontend/src/pages/GeneratePage.tsx`**:
  - `selectedWorkflowId` が変更された時、およびプリセットの保存・削除時に、そのワークフローに紐づくプリセット一覧を API 経由で取得し状態として保持する。
  - 新規に「プリセット」管理用の UI（ポップオーバー、またはドロップダウンメニュー）を「新規セット」ボタンの隣に配置する。
  - **プリセット読み込み (AC-3)**:
    - ユーザーがプリセット一覧から項目を選択し「読み込む」をクリックした際、現在アクティブなセットに対してプリセットの内容（`paramValues`, `appliedAssets`, `batchSize`, `seedMode`, `seed`）を反映する。
    - ストアの値に同期させ、`localStorage` にも自動保存されるようにする。
  - **プリセット保存 & 更新 & 削除 (AC-1, AC-4)**:
    - 「現在の設定をプリセットとして保存」する入力フォームを追加。名前を入力して「保存」をクリックすることで `POST` API を呼び出し保存する。
    - リスト上の各プリセットに「上書き保存」と「削除」のボタンを配置し、それぞれ `PUT` および `DELETE` API を呼び出す。
