### 3.2 `LlmSettingsSection.tsx` 仕様
- **Props**:
  ```typescript
  export interface LlmSettingsSectionProps {
    isExpandedModel: boolean
    onToggleModel: () => void
    isExpandedPrompts: boolean
    onTogglePrompts: () => void
    isExpandedParams: boolean
    onToggleParams: () => void
  }
  ```
- **機能**:
  - LLMモデル選択（`llmPromptsApi.getCurrentModel()`, `llmPromptsApi.getModels()`, `updateCurrentModel()`）
  - 翻訳用モデル (`translation_model`), セリフ下書きVLM (`speech_draft_vlm_model`), セリフ下書きLLM (`speech_draft_llm_model`), 翻訳デバウンス (`translation_debounce`: 300ms〜2000ms) の更新
  - プロンプト一覧アコーディオン（`PROMPT_LABELS` に基づく編集・保存・変更取り消し）
  - パラメータ調整スライダー（`PARAM_LABELS`, `PARAM_FIELDS`, `DEFAULT_PARAMS` に基づくスライダーと保存）
