## 3. 実装要件 (Implementation Logic)
- [ ] `frontend/src/components/LoraStackEditor.tsx` (新規作成)
  - LoRAスタックを編集する専用UIコンポーネントを作成する。
  - プロパティ: `role: string`, `paramValues: Record<string, string>`, `setParamValues: (values: Record<string, string>) => void`, `loras: Lora[] | undefined`。
  - `lorasApi.getComfyModels` を `useQuery` で呼び出し、ComfyUIで利用可能な物理モデル一覧を取得する。
  - スロット数（`lora_count`）の取得と増減管理、各行の削除ボタン押下時のインデックス繰り上げ（詰め直し）処理（設計書3-1節のロジック）を実装する。スロットの最大登録数は10件とし、10件に達した場合は「+ Add LoRA」ボタンを非活性化（disabled）する。
  - モデル名選択のセレクトボックスオプションには、`loras`（登録済み一覧）と突き合わせ、`description` が存在するものは `description` を表示名に使用し、存在しないものは `file_path` をそのまま表示する。選択時の `value` は `file_path` とする。
  - 各スロットに、LoRA名選択、`lora_wt`、`model_str`、`clip_str` の入力フィールドを配置する。
- [ ] `frontend/src/pages/GeneratePage.tsx`
  - `ParamPanel` の `paramMappings` のループ処理内、またはその直下で、`m.input_type === 'lora_stack'` の場合に `LoraStackEditor` をレンダリングするように変更する。
  - 汎用の入力フィールド描画（`m.input_type === 'select'` や `input`）は、`m.input_type !== 'lora_stack'` の場合のみ実行されるようにする。
