# タスクカード: REQ-172-T1

## 目的
`SpeechBubblePreset` にオプションの `text` 列（NULL許容）を追加し、プリセット作成・更新・取得時にテキスト情報を含められるようにする。また、既存データベースに対する自動マイグレーションを追加し、フロントエンドの API 型定義を同期する。

- [x] AC-2: `backend/app/schemas/speech_bubble_preset.py` の Base/Create/Update/Read に `text` フィールドが定義され、シリアライズされること。
- [x] AC-3: `backend/app/routers/speech_bubble_presets.py` で `text` の登録・更新（`text: null` によるクリアを含む）が正常に処理されること。
- [x] AC-4: `backend/app/main.py` の `run_migrations` に `speech_bubble_presets` テーブルへの `text` カラム追加処理が追加されていること。
- [x] AC-5: `frontend/src/api/types.ts` の `SpeechBubblePreset`, `SpeechBubblePresetCreate`, `SpeechBubblePresetUpdate` に `text?: string | null` が定義されていること。
- [x] AC-6: `backend/tests/test_speech_bubble_presets.py` にテストケースが追加され、全テストがパスすること。
