## 3. 実装要件 (Implementation Logic)
- [x] `frontend/src/components/TagChipEditor/index.tsx`
  - `@dnd-kit/core` から `PointerSensor` のインポートを取り除き、`MouseSensor`, `TouchSensor` をインポートする。
  - `sensors` 定義を以下のように置き換える：
    - `MouseSensor` で `distance: 8` のアプライを設定。
    - `TouchSensor` で `delay: 500, tolerance: 5` のアプライを設定。
    - `KeyboardSensor` はそのまま維持。
- [x] `frontend/src/components/TagChipEditor/TagChip.tsx`
  - `isDragging` が `true` の場合、`style` オブジェクトの `transform` プロパティの末尾に `scale(1.05)` を結合する（`transform` が存在する時：`${CSS.Transform.toString(transform)} scale(1.05)`、存在しない時：`scale(1.05)`）。
  - `isDragging` が `true` の場合、`zIndex: 50` および `boxShadow: '0 10px 15px -3px rgba(0, 0, 0, 0.3)'` を適用する。
  - `opacity` を `isDragging ? 0.8 : 1` に緩和（既存の `0.3` だと薄すぎるため、浮き上がりが見えにくくなるのを防ぐため）。
