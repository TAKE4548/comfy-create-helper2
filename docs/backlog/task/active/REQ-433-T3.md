# REQ-433-T3: 全 ON/OFF トグルスイッチのピル型標準デザイン・Hit-Slop・ARIA 統一

## 1. 概要と目的
アプリ内の全 ON/OFF トグルスイッチ（`ParamPanel.tsx`, `ParamFieldControl.tsx`, `VramGuardSection.tsx`）に対し、`data-radius-exempt`・`data-tap-target-exempt`・44×44px 以上 Hit-Slop・`role="switch"`・`aria-checked` を適用し、モバイル・デスクトップ双方でピル型トラック＋正円ノブと操作性を保証する。本カードが本タスクの唯一の意味仕様である。

## 2. ターゲット識別
- **対象ファイル**:
  - `frontend/src/components/ParamPanel.tsx`（L287–304, L326–343, L461–474, L516–529）
  - `frontend/src/components/ProfileBulkEditModal/tabs/ParamBulkEditTab/ParamFieldControl.tsx`（L72–88, L108–124）
  - `frontend/src/pages/SettingsPage/components/VramGuardSection.tsx`（L425–436）
  - テスト: `frontend/src/pages/GeneratePage/components/__tests__/ParamPanel.test.tsx`, `frontend/src/pages/SettingsPage/components/__tests__/VramGuardSection.test.tsx`
- **UI Archetype**: `Archetype 3: Forms & Controls`

<constraints>
- トラック `<button>` およびノブ `<span>`（`VramGuardSection` はトラック `<div>`）の双方に `data-radius-exempt` を付与すること。
- `<button role="switch">` には `data-tap-target-exempt` と `touch-manipulation` を付与し、モバイルでの `min-height: 44px` 正方形化を防ぎつつ、Hit-Slop で 44×44px 以上を確保すること:
  - `h-5 w-9`（36×20px）: `before:absolute before:-inset-x-2 before:-inset-y-3 before:content-['']`（52×44px）
  - `h-4 w-7`（28×16px）: `before:absolute before:-inset-x-2 before:-inset-y-3.5 before:content-['']`（44×44px）
- `role="switch"` と `aria-checked`、および `aria-label`（または関連ラベル）を必須とする。
- 押しボタン型トグル（`seed-toggle`, `audit-toggle`, `TagChipEditor` 等）は変更しないこと。
</constraints>

## 4. 実装要件
- [ ] `ParamPanel.tsx` の 4 箇所のスイッチ `<button>` に `role="switch"`, `aria-checked`, `aria-label`（`m.display_name || m.role!` / `g.name` / `p.name`）, `data-radius-exempt`, `data-tap-target-exempt`, `touch-manipulation`, 規定 Hit-Slop クラスを付与し、ノブ `<span>` に `data-radius-exempt` を付与する。
- [ ] `ParamFieldControl.tsx` の 2 箇所のスイッチ `<button>` に同様に `role="switch"`, `aria-checked`, `aria-label`, `data-radius-exempt`, `data-tap-target-exempt`, `touch-manipulation`, `before:-inset-x-2 before:-inset-y-3 before:content-['']`、ノブ `<span>` に `data-radius-exempt` を付与する。
