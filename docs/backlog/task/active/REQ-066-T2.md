# TASK-REQ-066-T2: 各ページのドラッグ＆ドロップ（カード移動）感度対応

## 1. ターゲット識別
- **対象ファイル**:
  - `frontend/src/pages/HistoryPage.tsx`
  - `frontend/src/pages/LoRAsPage.tsx`
  - `frontend/src/pages/TagsPage.tsx`

## 2. 密閉コンテキスト (Hermetic Context)
<hermetic_context>
### 2.1 HistoryPage.tsx における TouchSensor 設定
```typescript
    useSensor(TouchSensor, {
      activationConstraint: isAnyMultiSelect
        ? { distance: 8 }
        : {
            delay: 500,
            tolerance: 5
          }
    })
```

### 2.2 LoRAsPage.tsx および TagsPage.tsx における TouchSensor 設定
```typescript
    useSensor(TouchSensor, {
      activationConstraint: isMultiSelectMode
        ? { distance: 8 }
        : {
            delay: 250,
            tolerance: 5,
          },
    })
```
</hermetic_context>

## 3. 実装要件 (Implementation Logic)

### 3.1 TouchSensor Delay 値の動的取得化
各ファイルにおいて、`LS_KEYS` をインポートし、`TouchSensor` の `delay` 設定値を以下のように動的化する。
- `localStorage` から `LS_KEYS.LONG_PRESS_DELAY_CARD_MOVE` の値を取得する。
- 値が存在する場合は、秒単位からミリ秒単位（`秒数 * 1000`）に変換して設定する。
- 設定値が存在しない場合は、デフォルト値の `500` ms（0.5秒）を使用する。

### 3.2 既存の delay ハードコードの書き換え
- `HistoryPage.tsx` の 153行目付近の `delay: 500` を動的に取得した値に修正。
- `LoRAsPage.tsx` の 86行目付近の `delay: 250` を動的に取得した値に修正（デフォルトは 500 ms）。
- `TagsPage.tsx` の 77行目付近の `delay: 250` を動的に取得した値に修正（デフォルトは 500 ms）。

## 4. 検証手順 (AC)
- モバイルビュー（Chrome DevTools等）でのドラッグ並び替え操作が、`localStorage` の設定値に連動して待機時間が変化することを確認。
