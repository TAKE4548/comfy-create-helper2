# タスクカード: REQ-082-fix

## 目的

`RescanModal.tsx` の候補ノード選択ドロップダウンにおいて、
オプションのラベルを `ID` のみから `ID - [タイトル] (クラスタイプ)` 形式に変更する。

## Acceptance Criteria

- [ ] AC-1: `RescanModal.tsx` の候補選択ドロップダウンにおいて、オプションのラベルが `ID - [タイトル] (タイプ)` の形式で表示されること。
- [ ] AC-2: `workflowJson` に該当するノード情報が存在しない、または一部不足している場合もフォールバック表示（`ID` のみ表示、または空文字処理）が正しく機能し、クラッシュしないこと。

## 変更対象

| ファイル | 変更内容 |
|---|---|
| `frontend/src/components/RescanModal.tsx` | `getNodeLabel` 関数の追加 + `<option>` ラベル変更 |

## 実装手順

### Step 1: `getNodeLabel` 関数を追加

コンポーネント関数 `RescanModal` の内部、`buildRows()` の呼び出しの直後（L51付近）に以下を追加する:

```tsx
const getNodeLabel = (id: string) => {
  const node = workflowJson?.[id] as Record<string, any> | undefined
  if (!node) return id
  const title = node._meta?.title || ''
  const classType = node.class_type || ''
  return `${id} - [${title}] (${classType})`
}
```

### Step 2: `<option>` のラベル変更（mainRows セクション）

**対象箇所**: `RescanModal.tsx` L215–L217（`row.candidates.map` の `<option>`）

**変更前:**
```tsx
{row.candidates.map((id) => (
  <option key={id} value={id}>{id}</option>
))}
```

**変更後:**
```tsx
{row.candidates.map((id) => (
  <option key={id} value={id}>{getNodeLabel(id)}</option>
))}
```

> **注意**: `value={id}` は変更しない。表示ラベルのみの変更。

## 型コンテキスト

- `workflowJson`: `Record<string, unknown>` （`RescanModalProps` で定義済み）
- `workflowJson[id]`: ComfyUI ノードオブジェクト。構造例:
  ```json
  {
    "_meta": { "title": "positive" },
    "class_type": "KSampler",
    "inputs": { ... }
  }
  ```
- `_meta` や `class_type` は省略可能なフィールドのため、フォールバックが必須。
