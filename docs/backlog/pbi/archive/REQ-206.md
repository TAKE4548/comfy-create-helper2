### REQ-206: セリフ編集のしっぽ詳細調整の改善（吹き出し移動時の設定保持、頂点・接点の内側入り込み防止ガード、2接点独立操作化）
- **Type**: enhancement
- **Status**: open
- **Current step**: Step 1: Requirements Clarification
- **Date**: 2026-08-30
- **Priority**: P2
- **Surface**:
  - セリフ編集のしっぽ詳細調整が、吹き出し位置を動かすと無効化されてしまう。
  - また、しっぽの頂点・接点共に吹き出し内部まで入れられてしまい、崩れるので、吹き出し外周以上に中に入り込まないようにしたい。
  - また、しっぽの接点調整が1点＋幅での指定になっているが、2か所の接点を独立して動かせる方が調整しやすい。
- **Root Cause**:
  - **State Mutation Bug (Property Loss during Move/Duplicate)**: SpeechBubbleEditorModal.tsx の吹き出しドラッグ移動および複製処理において、tail オブジェクト生成時にスプレッド展開（...initB.tail）を行わず { x, y } のみで再生成しているため、微調整関連パラメータ（isFineTuning, baseAngleOffset, baseSpreadRatio 等）が消失・初期化される。
  - **Interaction / Geometry Boundary Gap (Lack of Penetration Clamping)**: しっぽ頂点（先端）および接点のドラッグ操作時、およびレンダラー描画時において、吹き出し外周境界（楕円または角丸矩形外周）より内側に座標が侵入することを防ぐ幾何的クランプ制限が存在せず、自己交差パスによる描画破綻が発生する。
  - **Data Model & Control Limitation (Coupled Base Points)**: しっぽ接点が「単一の中心角オフセット＋幅倍率」という1点基準のデータモデルになっているため、キャンバス上で2箇所の接点を個別にドラッグ・直感配置できない。
- **Requirement**:
  - 吹き出し本体をキャンバス上でドラッグ移動または複製した際、しっぽの微調整モードおよび調整済みの接点設定が失われず完全に維持されること。
  - しっぽの先端（頂点）および接点をドラッグ操作する際、吹き出し外周（楕円の外周・角丸矩形の枠線境界）より内側に入り込まないように幾何的クランプガード（境界制限）を適用し、内部進入による自己交差・描画破綻を防止すること。レンダラー側でも安全補正を行うこと。
  - しっぽ微調整モードにおいて、吹き出し外周上の2か所の接点（始点側・終点側）をキャンバス上でそれぞれ独立してドラッグ操作・微調整可能とすること。後方互換性を維持し、既存のデータやプリセットも正しく描画・移行できるようにすること。
  - モバイル表示およびPC表示の両方において、2接点および先端のドラッグ操作が快適に行えること。
- **Acceptance criteria**:
  - [ ] AC-1: 吹き出し本体をドラッグ移動または複製しても、しっぽの微調整モード設定および各接点・頂点パラメータが保持されリセットされないこと。
  - [ ] AC-2: しっぽの頂点（先端）を吹き出し中心方向へドラッグした際、吹き出し外周境界より内側に入らないようクランプされ、描画が破綻しないこと。
  - [ ] AC-3: しっぽの接点をドラッグした際、常に吹き出し外周境界上に吸着・拘束され、内部にめり込まないこと。
  - [ ] AC-4: しっぽ微調整モードにおいて、外周上の2つの接点ハンドルが独立してドラッグ可能であり、非対称な接点配置や任意の幅・位置調整が直感的に行えること。
  - [ ] AC-5: 楕円（oval）および角丸（rounded-rect）などの各吹き出し形状において、2接点独立操作としっぽ描画が破綻なく正しく連動すること。
  - [ ] AC-6: 従来の baseAngleOffset / baseSpreadRatio を持つ既存データやプリセットが読み込まれた場合でも、互換性を保って正常に描画・編集可能であること。
