### REQ-149: アルバム一覧画面におけるアルバムの任意並び替え機能およびアルバム名編集（リネーム）機能の追加

- **Type**: enhancement
- **Status**: ready
- **Current step**: Design Complete
- **Priority**: P2
- **Design doc**: docs/design/REQ-149.md
- **Surface**: アルバム一覧画面で、アルバム自体の表示順を任意に変えられるようにしたい。また、アルバム名が生成時から変更できないため、編集できるようにしたい。
- **Root Cause**:
  - **Interaction / Information Design (Fixed Ordering)**: アルバム一覧の並び順が固定（作成日時等）となっており、ユーザーの作業頻度や整理方針に合わせた任意の順序変更（並び替え）機能が提供されていない。
  - **Functional Gap (Missing Mutability)**: アルバム作成時に設定した名前を後から変更する編集インターフェースが存在せず、誤字修正やアルバムの用途変更に対応できない。
- **Requirement**:
  1. アルバム一覧画面において、アルバム自体の表示順序をユーザーが自由に並び替え可能にし、その順序を永続化・復元する。
  2. 既存のアルバムに対して名前の編集（リネーム）を行えるようにし、関連するUI全体に即座に変更を反映する。

#### Acceptance Criteria (AC)

##### 1. アルバムの任意並び替え（順序管理）
- [ ] AC-1-1: アルバム一覧画面において、ユーザーがアルバムの表示順序を任意に変更できる操作（D&Dまたは並び替えUI）が提供されること。
- [ ] AC-1-2: 変更されたアルバムの並び順が永続化され、画面のリロードや再訪問時にも指定した並び順が維持・復元されること。
- [ ] AC-1-3: スナップショット保存時やセリフ編集後のアルバム選択ダイアログ等、アルバム一覧を参照する各UIでも指定した並び順が反映される（または整合した順序で表示される）こと。

##### 2. アルバム名の編集（リネーム）
- [ ] AC-2-1: アルバム一覧画面（またはアルバム詳細画面等のアルバム管理UI）から、対象アルバムの名前編集（リネーム）を開始・保存できること。
- [ ] AC-2-2: アルバム名変更時に不正な入力（空文字や極端に長い名前など）に対するバリデーションが行われ、無効な場合は変更が防止され適切な案内が表示されること。
- [ ] AC-2-3: アルバム名を変更した後、アルバム一覧、アルバム詳細、保存先選択モーダル等のすべての表示箇所で新しいアルバム名が正しく反映・永続化されること。

##### 3. 既存機能との整合性
- [ ] AC-3-1: アルバムの新規作成、スナップショット追加・削除、アルバム削除などの既存機能が正常に動作し続けること。
- [ ] AC-3-2: 新規作成されたアルバムが適切な初期順序で追加され、並び替え機能と競合しないこと。
