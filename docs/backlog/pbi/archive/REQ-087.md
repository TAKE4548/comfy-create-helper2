### REQ-087: LoRA・タグセット管理UIの高度化と詳細・編集モーダルの統合

- **Status**: done (2026-08-26)
- **Description**: 
  1. 一覧画面等の適用LoRA・タグセットフィルタで、選択肢がパス表記（例：`/path/to/lora`）になっている箇所について、管理登録済みのものは登録されたdescriptionを表示し、未登録のもののみパス表記でフォールバック表示する。
  2. タグセットにおいて、1つのタグセット（例：「教室」）の中に、用途や差分（例：「ベース」、「日中の授業中」、「放課後」など）に応じた複数のサブセット（バリエーション）を任意の名称とタグの組み合わせで登録・管理できるようにする。
  3. LoRAおよびタグセットのカバーサムネイル設定にて、画像のアップロードに加え、クロップ範囲（切り抜き位置）や拡大・縮小（スケール）を直感的に調整できるプレビュー/編集機能を導入する。
  4. LoRA・タグセットの詳細確認モーダルと編集モーダルを統合し、詳細モーダルのすっきりしたレイアウトのまま、モーダル内で直接、またはシームレスに編集状態へ移行して保存できるようにする。

#### Acceptance Criteria (AC)
- [ ] AC-1: フィルタ選択肢等のLoRA表記が、管理データベースに登録済みのものは `description` で表示され、未登録のものはパス表記で表示されること。
- [ ] AC-2: タグセット詳細/編集画面にて、同一のタグセットに対して複数のサブセット（名称＋タグ文字列）を追加・編集・削除できること。また、生成ページ等でこのサブセットを選択して適用できること。
- [ ] AC-3: カバーサムネイル設定UIにて、アップロードした画像の位置調整（ドラッグによるクロップ位置変更）やスケール調整（スライダー等）ができ、意図した範囲が切り抜かれてサムネイルとして保存されること。
- [ ] AC-4: 詳細表示モーダル内に「編集」ボタンが配置され、モーダルを閉じずにその場で編集入力欄に切り替わり、保存またはキャンセルができること。
