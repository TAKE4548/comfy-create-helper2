### REQ-315: タグチップ編集時の和訳プレビュー自動表示・確定時更新

- **Type**: feature
- **Status**: done (2026-10-04)
- **Surface**: タグチップのサブメニューでタグ文言を編集し、その意味を和訳プレビューで確認する操作。
- **Desired outcome**: 翻訳ボタンを毎回押さず、サブメニューを開けば現在のタグの和訳を確認できる。文言を確定した後は、その確定内容に対応する和訳へ自動で更新され、編集と意味確認を続けられる。
- **5 Whys / Operational need**:
  1. なぜ変更したいか: タグの意味を確認するたびに翻訳ボタンを押す必要があるため。
  2. なぜその操作が負担か: タグを開いて編集する作業と訳を確認する作業が分断され、複数タグの見直しで操作が繰り返されるため。
  3. なぜ編集後の訳の更新が必要か: タグの文言を変えると、それまで表示していた訳では現在の意味を確認できないため。
  4. なぜ確定時に更新するか: ユーザーが Enter 等で編集を確定した内容を、次に確認すべきタグとして扱いたいため。
  5. 根底の業務ニーズ: 画像生成用タグを整える流れの中で、現在のタグの意味を余計な操作なく確かめ、意図した文言で確定できること。
- **UX Classification**:
  - **Interaction**: サブメニューを開くと和訳プレビューも開き、タグ文言の確定を契機に訳が自動更新される。
  - **Information Design**: プレビューが現在の確定済みタグに対応する訳であること、取得中や失敗時の状態が分かる。
- **Requirement**:
  - タグチップのサブメニューを開くと、そのタグの英日和訳プレビューが自動的に表示される。
  - サブメニュー内の文言編集を Enter またはフォーカス移動で確定すると、確定したタグ文言の和訳が自動取得され、プレビューが更新される。
  - 入力途中の未確定文言は翻訳更新の対象とせず、編集のキャンセルでは確定済みタグとその訳を維持する。
  - 翻訳の取得中・失敗時も、編集中のタグ文言が失われず、プレビュー上で状態を判別できる。

- **Acceptance criteria**:
  - [x] AC-1: Given 英語文言を持つタグチップが表示されている, When そのチップのサブメニューを開く, Then 翻訳ボタンの操作なしに和訳プレビューが表示され、そのタグの現在の文言に対応する日本語訳が表示される。
  - [x] AC-2: Given サブメニューと和訳プレビューが開いている, When 文言入力欄を編集して Enter で確定する, Then 確定後のタグ文言に対応する日本語訳が追加の翻訳操作なしにプレビューへ表示される。
  - [x] AC-3: Given サブメニューと和訳プレビューが開いている, When 文言入力欄を編集した後、その入力欄から別の操作対象へフォーカスを移して確定する, Then 確定後のタグ文言に対応する日本語訳が追加の翻訳操作なしにプレビューへ表示される。
  - [x] AC-4: Given サブメニューと和訳プレビューが開いている, When 文言入力欄へ文字を入力してまだ確定していない, Then 確定前の文言による和訳更新は開始されず、プレビューは最後に確定した文言の訳を表示する。
  - [x] AC-5: Given 文言入力欄に未確定の変更がある, When Escape で編集を取り消す, Then タグ文言は編集前の値を保ち、取り消した文言の訳がプレビューへ反映されない。
  - [x] AC-6: Given タグ文言を確定して和訳取得中である, When その取得が失敗する, Then タグの確定文言は維持され、プレビューに翻訳失敗を識別できる状態が表示される。
  - [x] AC-7: Given 同じサブメニューで異なる文言を順に確定した, When 先に確定した文言の訳が後から到着する, Then 最後に確定した文言の訳だけが現在のプレビューとして表示される。
  - [x] AC-8: Given タグ A の和訳取得中にタグ B のサブメニューを開いた, When タグ A の訳が後から到着する, Then 表示中のタグ B の和訳プレビューがタグ A の訳で置き換わらない。
  - [x] AC-9: Given 確定済みタグ文言の和訳取得が進行中である, When 和訳がまだ返っていない, Then プレビューは取得中であると判別できる状態を表示し、旧文言の訳を新文言の訳として表示しない。
  - [x] AC-10: Given 確定済みタグ文言の和訳取得がタイムアウトまたは空の結果で終わる, When プレビューの取得状態が更新される, Then 確定したタグ文言を維持したまま、訳を表示できない状態をプレビューで判別できる。
- **Inferred points**:
  - 「リアルタイムで同期」はユーザー回答に従い、入力中の逐次翻訳ではなく Enter またはフォーカス移動による編集確定後の自動更新を意味する。
  - 初回表示でも、編集前の既存タグ文言を翻訳してプレビューに示す。
  - 和訳は既存のタグチップ翻訳と同じ英語から日本語への意味確認を対象とする。
  - 既存の翻訳ボタンを残すか表示から外すかは、翻訳操作を不要にするという体験要件を満たす範囲で後続の設計判断とする。
  - 空欄確定時のタグ自体の扱いは既存のタグ編集規則に従う。本 PBI は文言が確定したタグの和訳表示を対象とする。
