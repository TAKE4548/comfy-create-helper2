### REQ-108: Scene GeneratorへのAnima用モードおよびシーン名保存機能の追加

- **Type**: enhancement
- **Status**: ready
- **Current step**: none
- **Priority**: P2
- **Surface**:
  - scene generatorにAnima用のモードを追加したい。
  - Animaは自然言語で文脈理解してくれる（Qwen系CLIP）ので、日本語で記述したシーンの内容を具体化して英訳してもらうイメージ。
  - 推論より英訳の側面が強くなり、シーン概要文が長くなることが想定される。
  - シーン名を別途入力でき、それをプロファイル名にして保存できるようにしたい（これは共通仕様とする）。
  - シーンごとの概要欄に日本語で入力し、推論時に文脈理解しつつAnimaに解釈されやすそうな表現で英訳する。
  - Anima用のシステムプロンプトを設定画面で設定できるようにしたい。
- **Root Cause**:
  - Scene Generatorにおいて、プロファイル名を手動設定して保存する仕組みがなく、自動生成された名前や既存の固定名になっていた。
  - AnimaなどのQwen系CLIP搭載のcheckpointモデルに対して、文脈理解しやすい（説明的な）英語プロンプトを生成するための専用のシステムプロンプト設定がSettingsに存在しない。
  - シーン記述からAnimaに適した解釈表現で英訳するための「Animaモード」がScene Generatorに存在しない。
- **Requirement**:
  - **UI/UX (共通)**: Scene Generatorモーダルの各シーン入力行に「シーン名（プロファイル名）」を設定できる入力フィールドを追加する。
  - **UI/UX (モード追加)**: Scene Generatorモーダルに「Animaモード」の切り替え（チェックボックスやトグル等）を追加する。
  - **API/推論ロジック**:
    - Animaモードが有効な場合、LM Studioにリクエストを送信する際、設定画面で登録された「Anima用システムプロンプト」を使用する。
    - 入力された日本語（英語混じり可）のシーン概要から、コンテキストを維持したまま、Anima（Qwen系CLIP）に解釈されやすい表現で英訳したプロンプトを生成する。
  - **プロファイル保存機能**:
    - 「プロファイルとして保存」をクリックした際、各シーンに入力された「シーン名」をプロファイル名として個別プロファイルを作成・保存する。
  - **設定画面の拡張**:
    - 設定画面（Settings）の「Scene Generator設定」に、Animaモード用のシステムプロンプトを入力・永続化するテキストエリアを追加する。
- **Acceptance criteria**:
  - **AC-1**: 設定画面の「Scene Generator設定」エリアに、Animaモード専用のシステムプロンプト入力エリアが表示され、保存・永続化できること。
  - **AC-2**: Scene Generatorモーダルにおいて、各シーン入力行（行の順序入れ替え時も含め）に「シーン名」を入力するためのテキストフィールドが追加されていること。
  - **AC-3**: Scene Generatorモーダルに「Animaモード」のON/OFF切り替え用UIが表示されること。
  - **AC-4**: AnimaモードをONにして推論（Draft生成）を実行した際、設定画面で保存されたAnima専用のシステムプロンプトおよび選択されたLM Studioのモデルを使用してLLMリクエストが送信され、日本語のニュアンスを汲み取った解釈しやすい英語表現に翻訳されて結果が各項目にマッピングされること。
  - **AC-5**: 「プロファイルとして保存（Save as Profiles）」を実行した際、各シーンに入力した「シーン名」がプロファイル名として設定され、それぞれ独立したプロファイルとして正常に保存されること。
- **Design doc**: none
