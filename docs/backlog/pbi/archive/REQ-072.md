### REQ-072: スナップショット一覧およびアルバム詳細での画像個別・一括ダウンロード機能の追加

- **Status**: done (2026-08-26)
- **Type**: enhancement
- **Priority**: P2
- **Current step**: none
- **Surface**: 
  アルバム含めたスナップショット一覧ページで、画像のダウンロードを可能にしたい。
  複数選択状態での一括ダウンロードもサポートしたい。一括の場合はzipにまとめてダウンロードできるように。
  zipのファイル名は、アルバムの場合はアルバム名、一覧画面からの場合はダウンロード時の日時にする
- **Root Cause**: 現状、スナップショット一覧画面（History ページ）やアルバム詳細画面において、生成した画像をフロントエンドから直接ダウンロードする機能が提供されていないため、画像の保存や他への共有のワークフローに摩擦が生じている。
- **Requirement**: 
  1. スナップショット一覧画面（およびアルバム詳細画面）の各画像カードにおいて、ホバー時に個別で画像を直接ダウンロードできるボタンを提供すること。
  2. 複数画像が選択されている状態（一括選択モード）において、選択中の画像をまとめてダウンロードできる一括ダウンロード機能を提供すること。
  3. 一括ダウンロードの際は、選択された画像を1つのZIPファイルにまとめ、クライアント側でダウンロード処理が行われること。
  4. 一括ダウンロード時のZIPファイル名は以下の通りとする：
     - アルバム詳細画面からの一括ダウンロードの場合：`[アルバム名].zip`
     - スナップショット一覧（全体）画面からの一括ダウンロードの場合：`[ダウンロード実行日時(YYYYMMDD_HHmmss)].zip`
  5. ZIP内に同一名称の画像ファイルが複数含まれる場合、上書きを防止するためにファイル名に自動で連番を付与する等の重複防止制御を行うこと。
  6. ダウンロード対象は画像ファイルのみとする。

#### Acceptance Criteria (AC)
- [ ] AC-1: スナップショット一覧またはアルバム詳細の画像カードにホバーした際、ダウンロードボタンが表示され、クリックすると対象の単一画像ファイルがダウンロードされること。
- [ ] AC-2: 複数選択状態（Multi-select）の際、画面上部に表示される共通ツールバー（`MultiSelectToolbar`）に「一括ダウンロード」ボタンが表示されること。
- [ ] AC-3: 一括ダウンロードボタンをクリックすると、選択されたすべての画像がZIP形式にまとめられ、ダウンロードされること。
- [ ] AC-4: アルバム詳細画面で一括ダウンロードを行った場合、ZIPファイルの名前が「`[アルバム名].zip`」となること。
- [ ] AC-5: スナップショット一覧画面（全体）で一括ダウンロードを行った場合、ZIPファイルの名前が「`YYYYMMDD_HHmmss.zip`」（例：`20260623_160741.zip`）となること。
- [ ] AC-6: ZIP内に同名のファイルが存在する場合、ファイル名が上書きされず、連番等が付与されてすべての画像がZIP内に保存されること。
- [ ] AC-7: ダウンロード処理は画像データのみを対象とすること。
