### REQ-066: アプリ全体の長押し感度設定機能の追加

- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: none
- **Priority**: P2
- **Surface**: 生成ページの履歴複数選択に遷移するときの長押しの感度が良すぎるので調整したい。長押し感度は、ハードコードではなく、設定ページで調整できるようにしておきたい
- **Root Cause**: 履歴リストの複数選択モードへの遷移に使用する長押し判定時間（秒）がハードコードされており、ユーザーの好みに合わせた調整ができない（Interaction上の課題）。
- **Requirement**: 設定画面から操作タイプ別（履歴の複数選択、カード移動）に長押し判定時間を個別に調整可能にし、調整された値がアプリ全体の該当する長押し操作に適用されるようにする。
- **Acceptance criteria**:
  - AC-1: 設定画面に、操作タイプ（「履歴の複数選択」「カード移動」）ごとに長押し判定時間を設定できる個別のスライダーを追加すること。
  - AC-2: 各スライダーは 0.1秒単位で、0.1秒 から 5.0秒 の範囲で調整可能であること。
  - AC-3: デフォルト値は以下の通りとすること。
    - 履歴の複数選択: 0.8秒
    - カード移動: 0.5秒
  - AC-4: 設定したそれぞれの判定時間がアプリ全体に適用され、該当する長押し操作（履歴の複数選択遷移時、およびカード移動開始時）に反映されること。
  - AC-5: 設定値が永続化され、アプリ再起動後も設定された値が維持されること。
- **Design doc**: none
