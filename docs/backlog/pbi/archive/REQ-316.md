### REQ-316: 生成画像メタ情報の表示とアセット関連付け編集

- **Type**: feature
- **Status**: done (2026-10-04)
- **Current step**: archived after acceptance review
- **Priority**: P2
- **Surface**: 生成画像プレビューおよび保存済み画像詳細。プロンプト、生成パラメータ、アセット関連付けを二分する情報パネル。
- **User wish**: メタ情報にQuality欄のプロンプトだけが表示され、他の入力欄の内容を確認できない。全欄のプロンプトを確認できるようにしたい。
- **Operational need**: 画像ごとの生成条件と現在の編集可能なアセット関連付けを区別して確認し、タグセット関連付けを編集できること。

#### 5 Whys / 要望の背景

1. なぜ全欄を見たいか: Quality以外の欄へ入力した内容をメタ情報で確認できないため（ユーザー申告）。
2. なぜQualityだけでは足りないか: 複数の入力欄があり、一部の表示では入力内容の全体を確認できないため（文書と申告に基づく整理）。
3. なぜ全体を確認する必要があるか: 生成結果と、その結果に使われたプロンプトを対応付けて振り返るため（推論）。
4. なぜ現在の入力欄を見るだけでは足りないか: 生成後の編集によって現在値と過去の画像に使われた値が異なる場合があるため（既存仕様に基づく整理）。
5. なぜ画像に紐づく全文表示が必要か: 当該画像の生成条件を欠落や取り違えなく確認するため（推論）。技術的な原因は未調査。

#### UX Classification

- **Information Design（情報設計）**: 各欄の名前と、その画像に使われたプロンプト全文を対応付けて提示する。
- **Interaction（操作）**: 長い内容もメタ情報表示から末尾まで確認できる。
- **Visual（視覚）**: 参照ワイヤーフレームの情報構造を採用する。仮データ・フォント・装飾・mock controls等の実装値は採用しない。

#### Requirement

- 対象画像の生成時に存在した全プロンプト欄を対象とする。ネガティブ欄が存在する場合も含める。固定の欄数・欄名を仮定しない。
- 各欄の生成時の有効プロンプト全文を、元の入力欄が識別できる名前とともに確認できる。
- 長文の末尾まで確認できる。折りたたみ・スクロール等の方式は設計で決める。
- 新規生成画像では、生成時の全欄の全文が後日の閲覧でも確認できることを要求する。現在の保存形式や保存の完全性は前提にせず、必要な変更範囲は設計で評価する。
- 既存画像は記録されている欄を表示し、記録のない内容を現在の入力値から補完しない。「空欄」は生成時の空の値が記録されている状態、「未記録」は生成時の値が記録されていない状態を表す。
- 対象欄は生成時点のワークフローに存在した欄のみ。後日追加された欄を過去画像の未記録欄として扱わない。生成時の欄構成や記録の完全性を判定できない既存画像では、全体に「未記録の項目がある可能性があります」と表示して完全な記録と誤認させない。
- 保存済み画像も対象とし、既存のQualityおよびその他の生成パラメータも確認できる。

#### Acceptance Criteria (AC)

- [x] AC-1: Given QualityとQuality以外の全プロンプト欄それぞれに異なる有効文字列を入れて新規生成した画像がある, When その画像のメタ情報を開く, Then 全プロンプト欄について生成時の有効文字列と元の欄を識別できる名前が対応付けて表示される。
- [x] AC-2: Given ネガティブプロンプト欄に有効文字列を入れて新規生成した画像がある, When その画像のメタ情報を開く, Then ネガティブ欄の名前と生成時の有効文字列が確認できる。
- [x] AC-3: Given 一つの欄に日本語・改行・括弧・重み表記を含む2000文字以上の有効文字列を入れて新規生成した画像がある, When その欄のメタ情報を末尾まで閲覧する, Then 表示された全文は生成時の有効文字列と一致し、末尾も確認できる。
- [x] AC-4: Given 画像Aの生成後に全プロンプト欄の入力を別の文字列へ変更している, When 画像Aのメタ情報を開く, Then 各欄は画像Aの生成時の値を表示する。
- [x] AC-5: Given Quality以外の欄にも有効文字列を入れて新規生成した画像を保存している, When 保存済み画像の詳細からメタ情報を開く, Then 生成直後と同じ全欄の名前と有効文字列が確認できる。
- [x] AC-6: Given 新規生成時に値が空だったプロンプト欄がある, When その画像のメタ情報を開く, Then その欄は名前と「空欄」の表示により空の値として識別できる。
- [x] AC-7: Given 既存画像の記録にはQualityの値だけがあり他欄の値が記録されていない, When その画像のメタ情報を開く, Then 未記録のプロンプト欄がある旨の「未記録」表示を確認できる。
- [x] AC-8: Given AC-7の既存画像があり現在の入力欄には別の値が入っている, When その画像のメタ情報を開く, Then 現在の入力欄の値は当該画像の生成時プロンプトとして表示されない。
- [x] AC-9: Given 有効タグと無効タグを含む欄で新規生成した画像がある, When その画像のメタ情報を開く, Then その欄のプロンプトには無効タグが含まれない。
- [x] AC-10: Given Qualityの有効文字列とシード値などの既存生成パラメータが記録されている画像がある, When その画像のメタ情報を開く, Then 記録されたQualityの文字列と既存生成パラメータの値が従来どおり確認できる。

- [x] AC-11: Given ワークフローに新しいプロンプト欄を追加する前に生成した画像があり生成時の欄構成が確認できる, When その画像のメタ情報を開く, Then 後から追加された欄は当該画像の未記録欄として表示されない。
- [x] AC-12: Given 生成時のプロンプト欄構成も記録の完全性も判定できない既存画像がある, When その画像のメタ情報を開く, Then 「未記録の項目がある可能性があります」と表示される。
- [x] AC-13: Given メタ情報を表示できる画像がある, When 情報パネルを開く, Then 画像とメタデータの並列表示、画像識別ヘッダー、Prompts と Parameters & Assets の切替領域を示す。画面幅に応じて配置を変え、固定desktop幅を狭い画面へ強制しない。ワイヤーフレームの仮データ、固定件数、フォント、装飾用コントロール、mockシナリオ操作は仕様値にしない。
- [x] AC-14: Given 対象画像に記録された全プロンプト欄がある, When Prompts を開く, Then 欄名・全文・文字数・コピー操作を欄ごとに提供し、非空欄は初期展開、空欄は初期折りたたみとする。個別開閉と全開閉で長文末尾まで確認できる。タブ/開閉/コピーをキーボードおよび支援技術から識別・操作できる。空欄と未記録の区別およびAC-7〜12を維持する。
- [x] AC-15: Given 対象画像に通常パラメータが記録されている, When Parameters & Assets を開く, Then 寸法/解像度、sampler、scheduler、CFG、steps、その他すべての記録済みmapping値をラベル付きで表示する。既知の表示順を尊重し、保存済みparamsにある未分類キーもキー名で表示する（workflow graphの任意ノード全件を無差別に収集する意味ではない）。false/0/空文字、配列/オブジェクトを欠落・truthy判定・暗黙の文字列化で失わず、内部予約キーはユーザー項目に出さない。画像ファイルから取得可能なら実画像の幅・高さ・形式も表示する。
- [x] AC-16: Given ランダムseedまたは固定seedで生成した画像がある, When seedを表示またはコピーする, Then 注入された実使用seedを対象画像ごとに表示/コピーする。実使用値が記録されない既存画像には現在値や入力seedを代入せず「未記録」とする。
- [x] AC-17: Given workflow、Prompt ID、キュー登録時刻、保存時刻、アルバム関連付けの一部が記録された画像がある, When ヘッダーを表示する, Then 値とその意味（キュー登録と保存を別項目）を表示する。時刻を生成完了時刻と呼ばない。未記録のworkflow名やアルバム名を現在の可変マスター値から生成時事実として補わない。
- [x] AC-18: Given LoRAおよびTagSet関連情報がある, When Parameters & Assets を開く, Then LoRAと汎用適用TagSet、LoRA付属trigger setを区別し、各区分で記録できているモデル/target role/strength等を示す。model strengthとclip strength等の別値を一つへ統合しない。起源を特定できない既存レコードは推定で分類しない。
- [x] AC-19: Given 保存済みsnapshotでタグセット関連付けの編集を開始した, When Applied TagSetsとLoRA付属trigger setsをそれぞれ追加/削除後に保存する, Then 二つのリストを別種の関連付けとして永続化し、対象画像の生成時prompt・実使用seed・生成パラメータ・使用LoRA/strength等の不変生成事実を変更しない。trigger set IDをTagSet IDとして保存しない。未保存の生成プレビューでは関連付け編集を提供しない。
- [x] AC-20: Given 保存済みsnapshotのタグセット関連付け編集に未保存変更がある, When キャンセルする, Then 変更を破棄して最後に読み込んだ保存済み関連付けへ戻す。保存失敗時はdraftを保持してエラーを示し、成功と誤認させない。
- [x] AC-21: Given snapshotのタグセット関連付けを保存した, When 対象snapshotを再取得する, Then LoRA association、positive/negative role、各strength等の未編集項目は保持される。TagSet編集により他associationを暗黙の既定値で置換しない。
- [x] AC-22: Given 画像ファイルから寸法を取得できる, When メタ情報を開く, Then 実画像の幅×高さをピクセル単位で示し、比率は実寸から導出する。取得できない場合は架空の寸法や近似比率を表示しない。
- [x] AC-23: Given promptの文字数や表示項目数を表示する, When 欄の開閉や表示データの読込が完了する, Then 件数は対象画像の現在の記録から正確に再計算され、wireframeの仮件数を表示しない。文字数は表示本文から都度算出し、Unicode書記素クラスタ単位で数える。絵文字や結合文字も表示上の1文字として扱う。false/0/空値を件数判定で欠落扱いしない。
- [x] AC-24: Given promptまたはseedのコピー操作を行う, When clipboard書き込みが拒否/失敗する, Then コピー成功表示を出さず失敗を通知する。失敗通知に成功を誤認させる文言を使わない。

#### Inferred points

<inferred_points>

- 2026-10-04の追加指示により、初回の「プロンプト中心」解釈を画像に紐づく生成条件とアセット関連付けの確認・編集へ拡張した。プロンプト・seedの個別コピーと折りたたみ操作は参照ワイヤーフレームに含まれる。再生成操作は要求されていない。
- 「全欄」は対象画像のワークフローの全プロンプト欄（存在する場合のネガティブ欄を含む）と解釈した。
- 表示対象は生成に使われた有効プロンプトと解釈した。無効化したタグは含めない（SPEC_GENERATEの既存仕様）。
- 生成ページの画像プレビューと保存済み画像詳細の双方を対象と仮定した。
- 既存画像でも取得可能な記録は表示する。未記録の内容の復元は要求せず、空欄と未記録を区別する。未記録の具体的な欄名まで分からない場合は全体への「未記録」表示を許容する。
- 初回intake時点では技術原因未調査だった。以後の設計調査で確認した記録/表示/編集経路は改訂設計書に根拠付きで整理する。

</inferred_points>
