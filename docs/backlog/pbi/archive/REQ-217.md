### REQ-217: LLM Audit 物理・構図整合性診断 (audit_physical) のフロントエンド結果表示UI実装
- **Type**: feature
- **Status**: abandoned（2026-10-26 ユーザー判断で廃止・アーカイブ）
- **Current step**: none
- **Priority**: P3
- **廃止決定（2026-10-26）**:
  - 物理・構図整合性診断の評価・日本語の理由・代替案を表示する要求を説明した上で、ユーザーが「いらないかな」と判断したため、本PBIを廃止する。
  - 元の要求・旧ACは経緯として保存し、今後の実施対象から外す。既存のLLM Audit機能やAPIを削除する指示ではない。
  - 現在の結果表示実装やバックエンドの完成状況は再検証していない。廃止は不要との判断によるもので、実装完了・代替済み・受入PASSを意味しない。
- **Surface（以下は廃止前の記録）**:
  - `frontend/src/pages/GeneratePage/components/AuditPanel.tsx` において、`auditTypes` に `physical` が選択可能になっているものの、API から返却される `auditResult.physical` の描画処理が実装されていない。
  - バックエンド（`backend/app/routers/audit.py`、`backend/app/seed_data.py`）では `<evaluation><rating>...</rating><reason_jp>...</reason_jp><alternatives>...</alternatives></evaluation>` の XML 出力を解析して JSON で返却するロジックが完成しているが、フロントエンドに表示部がないため実行結果が不可視となっている。
- **Root Cause**:
  - LLM Audit 機能の初期実装フェーズにおいて、干渉タグ診断（`interference`）および語彙サジェスト（`vocabulary`）の UI 連携のみが先行実装され、`physical` の結果表示コンポーネントの実装が後回しのまま保留されていた。
- **Requirement（廃止前の経緯・適用終了）**:
  - `AuditPanel.tsx` に `physical` 診断結果の描画領域を追加する。
  - 評価レーティング（OK / Warning / Conflict）に応じたバッジ・カラーリング（緑 / 黄 / 赤）を表示する。
  - 診断理由（`reason_jp`）および代替推奨タグ・構図案（`alternatives`）を一覧表示する。
- **旧Acceptance criteria（適用終了）**:
  - 旧AC-1: `AuditPanel.tsx` において、`auditResult.physical` が返却された際に評価レーティング（OK/Warning/Conflict）、理由（日本語）、代替案が適切にレンダリングされること。
  - 旧AC-2: レーティングに応じて視覚的な強調（OK=緑、Warning=黄、Conflict=赤）が行われること。
  - 旧AC-3: `auditTypes` に `physical` を含めて監査を実行した際、UI 上で即座に結果を確認できること。
- **Design doc**: docs/design/REQ-217.md
