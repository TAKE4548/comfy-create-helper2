### REQ-180: セリフ・吹き出し編集機能の強化およびモーダルUIの最適化

- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Priority**: P2
- **Surface**: 
  1. セリフ修飾のパスやスケール変化などの屈折方向を反転できるようにしたい
  2. セリフ編集モーダルのプレビューエリアの余白が無駄に広いので、余白を減らして画像を大きく表示したい
  3. プリセットの表示が、テキストあり⇒なしの順になっているが逆にしたい
  4. 吹き出しのしっぽが頂点しか調整できないが、本体との接点も調整できるようにしたい(現在のをデフォルトに、微調整モードとしてトグルできるオプションに)
- **Root Cause**:
  1. **修飾の屈折方向反転欠如**: セリフ修飾機能（パス沿い配置・文字スケール変化・円弧や波形等の屈折変形）の増減・凸凹方向が一方向に固定されており、反転スイッチが存在しない。
  2. **モーダルプレビュー余白過多**: `SpeechBubbleEditorModal` 内のプレビュー領域周囲に過度な余白が確保されており、編集対象の画像やキャンバスが縮小され視認性・ドラッグ操作性が低下している。
  3. **プリセット一覧順序**: セリフプリセット一覧がテキストあり優先（または現在のソート順）となっており、スタイル用途で選びたいテキストなしプリセットが埋もれている。
  4. **しっぽ接点調整の制約**: しっぽの編集において先端頂点ハンドルしか提供されておらず、本体接点（基部幅・位置）が自動計算固定のため、自由な形状調整ができない。
- **Requirement**:
  1. **セリフ修飾の屈折方向反転**:
     - セリフ修飾設定パネルに変形方向を反転（Flip / Invert）するトグルスイッチまたは反転オプションを提供する。
     - 反転設定のON/OFFがプレビュー表示およびセリフキャンバス描画に即座に反映され、プリセット保存・読込時にも保持されること。
  2. **プレビューエリアの余白削減と拡大表示**:
     - セリフ編集モーダルのプレビューエリア周囲の余白（padding/margin）を見直し、無駄なスペースを削減する。
     - コンテナの利用可能領域を最大限活用してベース画像およびセリフキャンバスを大きく表示する。
  3. **プリセット一覧の表示順序変更**:
     - セリフプリセット一覧のデフォルト表示順序を「テキストなし → テキストあり」の順に変更し、テキストなしプリセットを優先表示する。
  4. **しっぽ本体接点（基部幅/位置）調整と微調整モード**:
     - 吹き出しのしっぽ編集に「微調整モード」のトグルオプションを追加する（デフォルトOFF：従来の頂点のみ操作）。
     - 微調整モードON時、しっぽ先端ハンドルに加え、本体との接点ハンドル（基部位置/幅）を個別にドラッグ操作可能にする。
     - 調整した接点情報がセリフデータとして保存・復元されること。
- **Acceptance criteria**:
  - [x] AC-1: セリフ修飾パネルに反転スイッチが表示され、ON/OFF切替時にプレビュー上の文字配置・スケール増減方向・屈折の凸凹方向が正しく反転して描画されること。
  - [x] AC-2: セリフ編集モーダルを開いた際、プレビューエリア周囲の余白が削減され、画像がモーダル領域内で従来よりも大きく拡大表示されること。
  - [x] AC-3: セリフ編集画面のプリセット一覧において、「テキストなし」プリセットが「テキストあり」プリセットよりも先頭/上位に表示されること。
  - [x] AC-4: しっぽ編集UIに「微調整モード」トグルが追加され、デフォルトOFF（頂点のみ操作）、ON時に本体接点（基部）の調整ハンドルが表示されドラッグで位置・幅を微調整できること。
  - [x] AC-5: 反転設定およびしっぽ微調整状態を含めて、セリフプリセットやスナップショットとして正常に保存・復元・描画されること。
