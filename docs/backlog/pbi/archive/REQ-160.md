### REQ-160: セリフの口調・言い回しLLM再生成および口調プロンプトプリセット管理機能

- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: none
- **Priority**: P2
- **Surface**: セリフ付与して保存した画像に対して、セリフの内容は変えずに口調や言い回しなどを、指定の特徴に合わせてLLMなどで再生成できるようにしたい。同一シチュエーションのプリセットで、キャラ差分などを生成した際に、画像差し替えは現行機能でできるが、差し替えるキャラに応じてセリフの言い回しを変えるのは手動になってしまうのを補助する機能という位置付け。恐らくLLMを使うと思うが、口調などの特徴を与えるプロンプトなどは、プリセット的に管理できるようにして、再利用できるようにする。
- **Root Cause**: 同一シチュエーションでキャラクター差分を展開する際、画像差し替えは容易に行えるものの、セリフの骨子（意図や状況）を保ったまま各キャラクターの口調・言い回し・語尾に合わせて変更する作業が手動入力となっており作業負担が大きい。また、キャラクター特有の口調指示プロンプトを保存・再利用するプリセット管理の仕組みが存在しない。
- **Requirement**: キャラクターごとの口調や話し方の特徴を定義する「口調プロンプトプリセット」の管理機能を提供し、セリフ編集画面（SpeechBubbleEditor等）において既存セリフと指定した口調プリセットに基づきLLMでセリフの骨子を保ったまま口調を再生成・プレビュー・適用できるようにする。

#### Acceptance Criteria (AC)

##### 1. 口調プロンプトプリセット管理機能
- [ ] AC-1-1: 口調プリセットの新規作成、一覧取得、更新、削除（CRUD）ができること（プリセット名、口調・キャラクター特徴プロンプト、説明等）。
- [ ] AC-1-2: 設定画面またはセリフ編集画面から口調プリセットを登録・管理・選択できること。

##### 2. セリフ口調LLM再生成機能（UI/UX）
- [ ] AC-2-1: セリフ編集画面（吹き出し編集モーダル等）において、対象吹き出しのテキストに対して口調プリセットを選択（または直接指示を入力）して「口調変換・再生成」を実行できること。
- [ ] AC-2-2: LLM再生成中のローディング状態およびエラー時の適切なフィードバックが表示されること。
- [ ] AC-2-3: 再生成されたセリフ候補をプレビュー確認でき、ワンクリックで吹き出しテキストに反映、または元のテキストを保持/再試行できること。

##### 3. バックエンドAPIおよびLLM変換ロジック
- [ ] AC-3-1: 口調プリセット管理用のCRUD APIエンドポイントが提供されていること。
- [ ] AC-3-2: セリフ変換用APIエンドポイント（元のセリフテキスト + 口調指示/プリセット）が提供され、意味や文脈を崩さずに口調・語尾・言い回しを変換したテキストを返すこと。
- [ ] AC-3-3: LLM未設定時やAPI呼び出し失敗時に適切なHTTPエラーレスポンスが返されること。
