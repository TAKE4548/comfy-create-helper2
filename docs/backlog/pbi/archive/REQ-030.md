### REQ-030: スナップショット一覧のアルバム表示不具合の修正

- **Status**: done (2026-08-30)
- **Type**: defect
- **Priority**: P1
- **Current step**: none
- **Surface**: スナップショット一覧のアルバム（Albums）ページが空で何も表示されない。404エラーになるわけではない。

- **Root Cause**:
  バックエンドの `GET /api/albums` が `schemas.AlbumSummary` スキーマを返却しているのに対し、フロントエンドが `Album` スキーマ（`items` フィールドを含む）を期待しているため、フロントエンドで `album.items` が `undefined` となり、`album.items.slice(0, 3)` 呼び出し時にレンダリング例外が発生して描画が停止する。

- **Requirement**:
  `GET /api/albums` のレスポンススキーマを変更し、`items`（およびそれに含まれる `image_path` など）が返却されるように修正する。

- **Acceptance criteria**:
  - [ ] AC-1: **アルバム一覧の正常表示**: 「History」画面の「Albums」タブを選択した際、保存済みのアルバム一覧がカード形式で正常に描画されること。
  - [ ] AC-2: **サムネイル画像の描画**: 各アルバムカードのサムネイルグリッド（最大3枚）に、アルバムに含まれるスナップショット画像が正しく表示されること。
  - [ ] AC-3: **件数表示の整合性**: アルバムカード内に、登録されている画像枚数（例: "3 images"）が正しく表示されること。
  - [ ] AC-4: **エラーのない動作**: コンソールに `Cannot read properties of undefined (reading 'slice')` などのJSレンダリングエラーが出力されないこと。

- **Design doc**: none
