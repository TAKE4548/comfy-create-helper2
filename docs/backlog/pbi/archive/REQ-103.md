### REQ-103: Scene Generator 機能の追加

- **Type**: enhancement
- **Status**: done (2026-08-26)
- **Current step**: none
- **Priority**: P2
- **Surface**: 
  - `tmp/Scene Generator 機能仕様書.md` の機能を追加したい。生成画面からのプロファイル生成の拡張機能のイメージで、専用のモーダルを追加するイメージ。
  - 現状は差分毎に手動でプロファイルをコピー生成し変更部分を手動で変えているが、何を消して何を追加するか逐一考えて編集するのが手間なので、ドラフトを一気に作ってもらって微調整だけ手動でやりたい。
  - 既存のプロファイル追加ボタンの近くに、scene生成ボタンを追加するイメージ。
  - ベースとして指定するプロファイルを元に抽出して、対象をチェックボックスで選択するのがいい。シーンの概要は対象を気にせず短文で書きたいので、対象で選択された中でどこの入力欄の内容を編集するかもLLMに考えて欲しい。
- **Root Cause**: 連続したシーン（動画やアニメーション等）を生成する際、共通設定をベースとしつつシーンごとに異なる一部パラメータ（ポーズ、表情等）を切り替えたプロファイルを、手動で逐一複製して個別編集してキュー投入しなければならず、作業の認知負荷と操作コストが高いこと。
- **Requirement**: 既存の「プロファイル追加」ボタン付近から「Scene Generator」の専用モーダルを起動し、ベースとなるプロファイル情報から編集対象パラメータを選択した上で、シーンごとの日本語の概要指示（短文）を入力するだけで、LLMが自動的に各フィールドへの割り当てと英語プロンプトのドラフトを生成し、ユーザーが手動で編集・確認した上で、シーンごとに個別のプロファイル（プリセット）を一括作成できること。ComfyUIへの直接キュー投入はスコープ外とし、生成されたプロファイルは既存の生成フローから通常通り使用する。
- **Acceptance criteria**:
  - **AC-1**: 生成画面のプロファイル追加ボタンの近傍から、Scene Generator 機能を起動するモーダルを表示できること。
  - **AC-2**: モーダル内で、ベースとなるプロファイル（現在のパラメータ値）から編集対象とするパラメータをチェックボックスで選択できること。
  - **AC-3**: モーダル内で、複数のシーン概要（日本語のテキスト指示）を動的に追加、削除、並び替えできること。
  - **AC-4**: ドラフト生成を実行すると、指定されたシーン概要をもとに、LLMが選択された対象パラメータのうちどれをどのように編集するべきかを自動で判断し、それぞれのパラメータに対応する英語プロンプトのドラフトを生成して、シーンごとのカード形式で一覧表示すること。
  - **AC-5**: 生成されたドラフト結果を、シーンごとのカード内のテキスト入力欄から手動で個別に編集・微調整できること。
  - **AC-6**: 確定を実行すると、ベースとなるパラメータとシーンごとの差分パラメータをマージした結果が、シーンの概要文をプロファイル名として、各シーンごとに個別の新規プロファイル（プリセット）として保存されること。
