### REQ-063: LoRA管理・タグセット管理でドラッグ＆ドロップによりカードのクリック・タップ操作が動作しなくなる不具合の修正

- **Status**: ready
- **Description**: 
  LoRA管理画面（`LoRAsPage.tsx`）およびタグセット管理画面（`TagsPage.tsx`）において、ドラッグ＆ドロップによる並び替えが有効になっている状態で、カードのクリック（詳細表示）や、編集・削除ボタンのクリック/タップ操作がドラッグイベントによって無効化されている（吸い取られている）問題を修正する。
  ドラッグイベントとしきい値（`activationConstraint`）を設定し、クリック操作とドラッグ操作を明確に判別できるようにする。

#### Acceptance Criteria (AC)
- [ ] AC-1: LoRA管理画面において、カードのドラッグ＆ドロップによる並び替え移動ができること。
- [ ] AC-2: LoRA管理画面において、カード全体のクリックで詳細モーダルが開くこと。
- [ ] AC-3: LoRA管理画面において、カード上の「編集（鉛筆アイコン）」および「削除（ゴミ箱アイコン）」ボタンが正常にクリックでき、期待されるモーダルや確認ダイアログが表示されること。
- [ ] AC-4: タグセット管理画面において、カードのドラッグ＆ドロップによる並び替え移動ができること。
- [ ] AC-5: タグセット管理画面において、カード全体のクリックで詳細モーダルが開くこと。
- [ ] AC-6: タグセット管理画面において、カード上の「編集」および「削除」ボタンが正常にクリックでき、期待されるアクションが動作すること。
