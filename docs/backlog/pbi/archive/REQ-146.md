### REQ-146: セリフ編集画像の上書き保存オプションおよび保存時アルバム選択・登録機能

- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: none
- **Priority**: P2
- **Surface**: セリフ付きで保存した画像を再編集したとき、新規だけでなく上書き保存もできるようにしたい。また、保存時に保存先アルバム選択をできるようにして、編集⇒保存⇒アルバム登録をシームレスに実行できるようにしたい
- **Root Cause**: **Interaction Friction (Workflow Disruption & Redundant Data Creation)**: セリフ編集保存時に「新規保存」しか選択肢がなく、再編集時に元スナップショットの更新（上書き）ができないため不要な複製が蓄積する。また、保存後にアルバムへ手動で再登録する別手順が必要であり、編集からアルバム整理までの一連のワークフローが分断されている。
- **Requirement**: セリフ編集画面からの画像保存時に、「新規保存（新規スナップショット作成）」と「上書き保存（元スナップショットの画像・情報を置換更新）」を選択可能にする。さらに、保存ダイアログ/UI上で保存先アルバムを選択（または未指定）できるようにし、保存完了と同時に指定アルバムへの登録をシームレスに実行できるようにする。

#### Acceptance Criteria (AC)

##### 1. 保存方法の選択（新規保存 / 上書き保存）
- [x] AC-1-1: セリフ編集画面での保存操作時、保存モードとして「新規保存（別画像として追加）」と「上書き保存（元のスナップショットを更新）」を選択できること。
- [x] AC-1-2: 「上書き保存」を選択して実行した場合、元のスナップショットの画像データおよびセリフ情報が更新され、新規スナップショットが無駄に増殖しないこと。
- [x] AC-1-3: 新規に作成・生成された画像など元スナップショットが存在しない/上書き対象がない場合は「新規保存」のみが有効となるか、適切にハンドリングされること。

##### 2. 保存先アルバムの選択と同時登録
- [x] AC-2-1: セリフ編集画面の保存設定において、保存先アルバムをドロップダウンまたは選択リストから指定できること（既存アルバム一覧、新規アルバム作成、登録なし）。新規アルバム作成選択時はアルバム名入力欄が表示されること。
- [x] AC-2-2: アルバム初期選択の優先順位として、常に前回保存先アルバム（`LS_KEYS.LAST_SAVE_ALBUM_ID`）が最優先で初期選択されること。
- [x] AC-2-3: 前回保存先情報が存在しない（または該当アルバムが存在しない）場合のフォールバックとして、アルバム詳細画面からの起動時は開いているアルバム（`initialAlbumId`）、履歴画面からの起動時は「新規アルバム作成」が初期選択されること。
- [x] AC-2-4: 保存実行時、選択されたアルバム（既存または新規作成）へのアイテム追加（新規作成時はアルバム作成＋登録）が自動実行され、保存先アルバムIDが `localStorage`（`LS_KEYS.LAST_SAVE_ALBUM_ID`）に永続化されること。

##### 3. 保存完了後のUIフィードバックと状態更新
- [x] AC-3-1: 保存（上書きまたは新規）およびアルバム登録が完了した際、適切な成功通知が表示され、モーダルが閉じること。
- [x] AC-3-2: 保存完了後、スナップショット一覧および関連アルバムの表示（クエリキャッシュ等）が即座に最新状態へ更新・反映されること。
