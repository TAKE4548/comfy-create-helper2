### REQ-188: セリフ編集のパス軌道およびスケール変化カーブの不具合修正

- **Status**: ready
- **Description**: セリフ編集モーダルの漫画演出機能において、パス軌道（直線・階段・円弧・S字波）の縦書き/横書き制御点同期不備、パス反転が無効化される不具合、およびスケール変化カーブ・パス軌道時に文字間隔（字間ギャップ）の見た目が崩れる問題を解消する。

#### Acceptance Criteria (AC)
- [ ] AC-1: 吹き出しが縦書き設定の際、パス軌道タイプを「直線」「階段」「円弧」「S字波」のいずれに変更しても、縦方向の軌道に沿って文字が配置されること。
- [ ] AC-2: 「パス反転 ⇄」ボタンを押下した際、選択中の軌道タイプ（円弧・S字波・階段・直線）に応じた制御点が正しく反転・ミラーリングされ、画面上のパスレイアウトおよび文字配置に即座に反映されること。
- [ ] AC-3: スケール変化カーブ（linear, ease-in, ease-out, bezier）適用時、文字ごとの拡大・縮小倍率に応じて文字送り位置が動的に計算され、文字同士の重なりや不自然な過剰隙間が生じないこと（Proportional Character Advancement）。
- [ ] AC-4: パス軌道適用時、各文字のサイズおよび `letterSpacing` を考慮した弧長ベースの位置決めが行われ、軌道変化やスケール変化時にも破綻のない自然な字間配置が維持されること。
- [ ] AC-5: 縦書き設定でパス軌道を有効にした際にも、長音符（ー）や括弧などの縦書き用グリフ置換（`verticalCharMap`）が正しく適用されること。
- [ ] AC-6: 既存のユニットテストおよび描画レンダラーのテストが全てパスすること。
