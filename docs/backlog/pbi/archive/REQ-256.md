### REQ-256: タグチップサブメニューでの強度直接入力時Backspaceキー誤削除の防止

- **Type**: defect
- **Status**: done (2026-09-13)
- **Current step**: dev-design
- **Priority**: P1
- **Surface**:
  - タグチップのサブメニューを開き、「強度 (Weight)」の数値入力欄で直接数値を編集しようとして `Backspace` キーを入力すると、入力欄の数値ではなくタグチップ自体の削除が優先されてタグチップが消滅してしまう。
- **Root Cause**:
  - `TagChip.tsx` において、最外周コンテナに設定された `handleKeyDown`（`Delete` / `Backspace` 押下時に `onDelete(id)` を呼び出すショートカット）が存在する一方で、サブメニュー内の強度数値入力欄の `handleWeightKeyDown` およびサブメニューラッパーコンテナにてキーイベントの伝播停止（`e.stopPropagation()`）が行われていない。
  - そのため、数値入力中に `Backspace` を押下した際のキーイベントが親要素までバブリングし、親のチップ削除ハンドラが発火してブラウザ既定の文字削除がキャンセルされ、チップが誤削除される。
- **Requirement**:
  - タグチップのサブメニュー内（特に強度数値入力欄）においてキーボード操作を行った際、そのキーイベントが親のタグチップショートカットハンドラにバブリングして意図しないチップの削除・複製・トグルが発生することを防止し、数値入力欄内での `Backspace` / `Delete` 操作による数値編集が正常に行えるようにすること。
- **Acceptance criteria**:
  - [ ] AC-1: タグチップのサブメニュー内にある「強度 (Weight)」数値入力欄にフォーカスし、`Backspace` キーを押下した際、タグチップが削除されず、入力欄内の数値が正常に削除・編集できること。
  - [ ] AC-2: 強度数値入力欄にフォーカス時、`Delete`、`Space`、`Ctrl+D` などのショートカットキーを押下しても、親タグチップの削除・トグル・複製が誤って発火しないこと。
  - [ ] AC-3: サブメニューが閉じておりタグチップ本体にフォーカスがある通常のキーボードショートカット（`Space` でトグル、`Delete` / `Backspace` で削除、`Ctrl+D` で複製）は引き続き正常に動作すること。
