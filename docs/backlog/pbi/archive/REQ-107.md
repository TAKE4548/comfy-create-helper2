### REQ-107: タブレット等のフルスクリーン表示時、下部メニューGAPが適用されて最大化されない問題

- **Status**: done (2026-08-26)
- **Description**: タブレットやモバイルデバイス（画面幅1024px未満）において、画像プレビュー（HistoryModalPreview等）をフルスクリーン表示した際、下部のナビゲーションメニュー用余白（GAP）が考慮されたままとなり、表示領域が最大化されない問題を解決する。

#### Acceptance Criteria (AC)
- [ ] AC-1: 画面幅1024px未満の端末でプレビューモーダル（`HistoryModalPreview`）をフルスクリーン表示した際、下部のナビゲーションメニュー分のパディング（`padding-bottom`）が `0` にリセットされ、画面全体に画像表示領域が最大化されること。
- [ ] AC-2: 通常のモーダル表示時（非フルスクリーン時）は、モバイル向けに下部ナビゲーションメニューを避けるパディング（`padding-bottom: calc(...)`）が正しく適用され、操作性やレイアウトが崩れないこと。
