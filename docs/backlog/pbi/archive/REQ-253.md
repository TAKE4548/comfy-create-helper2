### REQ-253: 生成画面リロード後の履歴表示消失とジョブ完了時の一括同期バグの修正

- **Type**: defect
- **Status**: done (2026-09-12)
- **Current step**: none
- **Priority**: P1
- **Surface**:
  - 生成画面（GeneratePage）でブラウザをリロードすると、過去の ComfyUI 生成履歴がギャラリー/ストリップに表示されず空白になる。
  - 新しい生成ジョブを実行し、画像生成が完了した瞬間に、過去分も含めて画像が一気に表示される。
- **Root Cause**:
  - `useGenerateDisplayState.ts` のマウント時 `useEffect` において、`comfyHistoryImages` の非同期取得前に `rawImages.length === 0` で `return []` が実行され、`PersistQueryClientProvider` で復元された永続化キャッシュを即座に消去してしまう。
  - `fetchHistory()` 完了時に発火する `history-fetched` イベント内で `queryClient.invalidateQueries` が呼ばれるが、React 再レンダリングとの競合（Race Condition）により古い空のクロージャを再参照してキャッシュが空配列に上書きされる。
- **Requirement**:
  - 生成画面をリロードした際、永続化キャッシュおよび `fetchHistory()` によって取得された ComfyUI 履歴画像が正しくギャラリー/ストリップに表示されること。
  - 新規ジョブ完了を待つことなく、リロード直後から履歴が正常に復元・閲覧できること。
- **Acceptance criteria**:
  - [x] AC-1: 生成画面（GeneratePage）をリロードした直後、永続化キャッシュまたは取得済みの履歴画像一覧が正常に表示されること（空白にならない）。
  - [x] AC-2: `fetchHistory()` 完了時において、キャッシュが空配列で破壊・上書きされることなく、正しく全件の履歴画像が反映されること。
  - [x] AC-3: 新規ジョブ生成完了時（`executed`）に新規画像が先頭に追加され、既存履歴が正常に維持されること。
