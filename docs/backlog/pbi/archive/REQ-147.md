### REQ-147: ワークフロープリセット新規作成時の並び順（sort_order）末尾自動設定

- **Status**: done (2026-08-26)
- **Description**: ワークフローの生成プリセット新規作成時、`sort_order` が指定されていない場合にバックエンド側で対象 `workflow_id` の既存プリセットにおける `max(sort_order) + 1` を自動設定し、常にリストの末尾に追加されるように修正する。

#### Acceptance Criteria (AC)
- [x] AC-1: `POST /api/workflow-presets` において `sort_order` が指定されていない場合、該当 `workflow_id` の既存プリセットの最大 `sort_order` + 1 が自動設定されて登録されること（既存プリセットが存在しない場合は 0 とする）。
- [x] AC-2: 並び替え（リオーダー）操作を行った後でも、新規作成したプリセットがリストの先頭や2番目ではなく、常に最末尾に追加されること。
- [x] AC-3: 既存のプリセット一覧取得、更新、削除、リオーダー機能が正常に機能すること。
