### REQ-012: プロンプトのタグチップ化とLoRA/タグセットのトグル適用

- **Status**: done (2026-08-30)
- **Type**: enhancement
- **Priority**: P1
- **Current step**: none
- **Surface**: 長文テキストエリアでのタグ抜き差しや、カンマ消し忘れ等の試行錯誤のストレス。入力を「チップUI」化し、末尾からの自由入力（Enter追加）を実現。また、適用したLoRAやタグセットもチップとして展開し、クリックひとつで有効/無効をシームレスに切り替え（APIペイロードからの除外）できるようにする。
- **Root Cause**: プロンプト入力欄が単純な複数行テキストエリアであるため、大量のカンマ区切りタグ（Danbooruスタイルなど）を編集する際、カンマの消し忘れや重複などのミスが発生しやすい。また、適用中のLoRAやタグセットを一時的に外して生成結果を比較する際、テキストを退避・削除し、試行後に再コピーして貼り直す必要があり、生成時の試行錯誤（プロンプト・アセットの比較検証）に多大な手間がかかっている。
- **Requirement**:
  - プロンプト入力欄を、カンマで区切られたタグを視覚的な「タグチップ」として表示・管理するチップUIにリプレイスする。
  - チップUIの末尾で自由なテキスト入力ができ、カンマ `,` または Enter キーで即座にチップとして確定追加されること。
  - LoRAモデルやタグセットを適用した際、プロンプトエリア（または隣接エリア）に「アセットチップ」として視覚的に別デザインで表示されること。
  - 各アセットチップには個別に「有効/無効」を切り替えるトグルボタンがあり、無効化時はチップが非アクティブ表示（グレーアウト等）になり、画像生成時のAPIペイロード（プロンプトテキストやLoRA適用パラメーター）から自動で除外されること。
- **Acceptance criteria**:
  - [ ] AC-1: プロンプト入力欄（Positive/Negative等）がタグ単位でチップ表示され、各チップの削除（×）ボタンで個別に削除できること。また、コピペ入力時にカンマ区切りの文字列が自動で複数チップに分割されて展開されること。
  - [ ] AC-2: チップUIの末尾にテキスト入力フィールドがあり、文字入力中にカンマを入力するか、またはEnterキーを押下することで、新たなタグチップが末尾に追加されること。
  - [ ] AC-3: LoRAやタグセットを追加した際、プロンプト編集領域に紐づく形で「LoRAアセットチップ」または「タグセットアセットチップ」が展開され、一目で現在適用中アセットが確認できること。
  - [ ] AC-4: アセットチップ上に「有効/無効」の切り替えスイッチ（またはトグルアイコン）が存在し、無効化されたLoRAやタグセットは、生成ボタン押下時に送信されるAPIリクエストパラメータ（およびプロンプト）から一時的に除外されて生成処理が走ること。
  - [ ] AC-5: 無効化されたアセットチップを再度有効化すると、即座に生成対象パラメータとして再適用されること。
- **Design doc**: none
