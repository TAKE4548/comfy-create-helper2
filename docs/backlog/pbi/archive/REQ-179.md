### REQ-179: プロンプト翻訳実行時のTypeError解消および非公式Google無料翻訳の廃止・正規API化

- **Type**: defect
- **Status**: done (2026-08-26)
- **Priority**: P1
- **Surface**: Generate画面のプロンプト翻訳モーダルにおいて「翻訳する」ボタンをクリックしても翻訳が実行されず無反応となる。また、Google無料翻訳（非公式エンドポイント）は規約違反（スクレイピング）にあたるため廃止し、正規のGoogle Cloud Translation APIをデフォルトにする。
- **Root Cause**:
  1. **イベントオブジェクトの不正代入**: `frontend/src/pages/GeneratePage/hooks/usePromptTranslation.ts` の `executeTranslate` において、Reactのクリックイベント（`MouseEvent`）が第1引数 `customText` に渡り、`customText !== undefined` により `textToTranslate` にオブジェクトが代入され、`textToTranslate.trim()` で `TypeError` が発生して処理がクラッシュしている。
  2. **非公式エンドポイントの規約違反**: `backend/app/services/translation_service.py` の `translate_google_free` は非公式Webエンドポイント（`translate_a/single?client=gtx`）に依存したスクレイピング実装であり、利用規約違反・遮断リスクがある。
- **Requirement**:
  1. `usePromptTranslation.ts` の `executeTranslate` で引数の型チェック（文字列型判定）を行い、クリックイベント等の非文字列が渡された場合でも `sourceText` を正しく翻訳対象として処理する。
  2. 翻訳失敗時・エラー発生時にUI上で適切にエラーメッセージ（`error` state）を表示し、ユーザーに失敗を通知する。
  3. 非公式の `google_free` プロバイダをバックエンドおよびフロントエンドから完全に廃止・削除する。
  4. 正規の `google_cloud`（Google Cloud Translation API）をデフォルトプロバイダに変更し、サポート対象を `google_cloud` / `deepl` / `llm` の3種類に整理する。
  5. 設定画面（`TranslationSettingsSection.tsx`）から `google_free` を削除し、特定プロバイダへの「推奨」バッジも排除してフラットな選択肢とする。
- **Acceptance criteria**:
  - [x] AC-1: プロンプト翻訳モーダルで「翻訳する」ボタンをクリックした際、`TypeError` が発生せず正常に翻訳処理が開始され、ローディング表示および翻訳結果が表示されること。
  - [x] AC-2: `executeTranslate` に引数なし / クリックイベント / 明示的な文字列が渡されたいずれのケースでも安全に動作すること。
  - [x] AC-3: `google_free` プロバイダが削除され、サポートプロバイダが `google_cloud` / `deepl` / `llm` に整理されていること。
  - [x] AC-4: 設定画面で `google_cloud` がデフォルトとなり、APIキー未設定時のテストや実行で適切なエラーが返ること。
  - [x] AC-5: フロントエンド・バックエンドの単体テスト（Vitest / Pytest）が全件Passすること。
