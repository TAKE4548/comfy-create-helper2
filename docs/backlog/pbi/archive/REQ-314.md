### REQ-314: Prompt Surgeon: 設定ページ 水平タブ化レイアウト刷新・機能構造化

- **Type**: feature
- **Status**: done (2026-10-05)
- **Current step**: closure（2026-10-05 ユーザー「確認完了」により手動確認・受入完了）
- **Current task references**: T1〜T19は完了。承認範囲内のatomicity再分割を反映。型チェック、全117ファイル・1,137テスト、配信用ビルド成功。最新のQA結果・AC確認状況・手動チェックリストは `docs/design/REQ-314-walkthrough.md` を参照。
- **Priority**: P2
- **Surface**: Prompt Surgeon の設定ページ (`SettingsPage`) において、現状13セクションが縦1列のアコーディオンで配置されており、スクロール負荷の高さ、グローバル左ナビとの二重サイドバー懸念、機能の分散（翻訳・セリフ設定の散在）、および粒度の不揃いが発生しているため、仕様書 (`tmp/settings_layout_redesign_spec (2).html`) に沿って水平5タブ構成（ワークフロー・モデル、プロンプト支援、セリフ支援、翻訳、システム・一般）へのレイアウト刷新と構造化を実施したい。
- **5 Whys / Root Cause**:
  1. なぜ変更が必要か: 現状の設定ページでは13個のセクションが縦1列に並び、設定項目を探すスクロール負荷が非常に高く、操作効率が低下しているため。
  2. なぜスクロール負荷が高いのか: 利用頻度の高い「ワークフロー・モデル」と低頻度の「接続・システム」が同列に並び、さらに11種類の長大なプロンプトや多数のスライダーが常時展開されていたため。
  3. なぜ関連設定が探しにくいのか: 翻訳設定が3箇所、セリフ・マンガ設定が4箇所に分散しており、吹き出し検出のようなスライダー2本の設定が独立した巨大セクションとして扱われていたため。
  4. なぜ水平タブ形式を採用するのか: AppShellに既にグローバル左ナビが存在するため内部サイドバーを設けると「二重サイドバー」となり画面幅を圧迫するが、直交する水平タブを採用することで横幅を100%活用しつつ目的別に明快に分類できるため。
  5. 根本原因: 機能追加に伴い設定項目が目的に応じた階層構造（情報設計）なしにフラットに追加され、利用頻度やワークフロー工程に応じたグルーピングと断捨離（折りたたみ・条件付き表示）が行われていなかったこと。
- **UX Classification**:
  - **Information Design (情報設計)**: 13セクションをユーザーの利用頻度・作業工程に応じた水平5タブ（ワークフロー・モデル、プロンプト支援、セリフ支援、翻訳、システム・一般）に再編。分散していた翻訳設定・セリフ設定を完全集約し、技術的内部キー名称（VLM/LLMプロンプト等）をパイプライン役割に即した直感的なラベル・補助説明へ改善。
  - **Interaction (インタラクション)**: 水平タブ切り替え、URLハッシュおよびLocalStorageを組み合わせたタブ選択状態の双方向永続化。プロンプト詳細やパラメータの折りたたみ展開、および翻訳プロバイダー選択に応じたローカルLLM詳細設定の即時リアクティブ表示切替。
  - **Visual (視覚デザイン)**: 二重サイドバーを回避した横幅100%活用のカード＆タブUI。モバイル表示（768px未満）における横スクロールスナップタブバー、短縮ラベル、AppShell固定ボトムナビ干渉回避パディング（pb-24 + safe-area）、テーブルの縦積みカード型フォールバック、およびタップターゲット44px確保。
- **Requirement**:
  - **水平5タブ構成への移行**:
    - 設定ページ上部に水平タブバーを配置し、以下の5タブで構成する:
      1. `ワークフロー・モデル` (Workflows & Models)
      2. `プロンプト支援` (Prompt Assist)
      3. `セリフ支援` (Dialogue Assist)
      4. `翻訳` (Translation)
      5. `システム・一般` (System & Display)
    - デスクトップ表示（>= 768px）では5つのタブが横幅全体に均等・整然と配置され、モバイル表示（< 768px）では横スクロール（CSSスナップ付き）で表示される。
    - 選択中のタブ状態はURLハッシュ（例: `#workflows`, `#prompt`, `#dialogue`, `#translation`, `#system`）およびLocalStorageに保存され、URLハッシュ直接指定またはリロード時に直前のタブ状態が正確に復元される。
    - WAI-ARIA（`role="tablist"`, `role="tab"`, `aria-selected`, `aria-controls`）に準拠し、キーボード（Tab / 矢印キー）によるタブ操作が可能であること。
  - **Tab 1: ワークフロー・モデル (Workflows & Models)**:
    - ワークフロー管理カード: ワークフロー一覧、名前変更/複製/新JSONスマート差分置換/直前復元/削除アクション、展開式スロットプリセット管理。
    - ベースモデル設定カード: ベースモデル定義一覧（SDXL, Anima, Illustrious, Noob, Flux等）のCRUD、およびチェックポイントマッピング管理・再取得。
    - ノードマッピングマスターカード: ノード入出力定義（Positive/Negativeプロンプト、Seed、Steps、CFG、Sampler等）のマスターCRUD。
  - **Tab 2: プロンプト支援 (Prompt Assist)**:
    - メインLLMモデル選定カード: 使用モデル選択ドロップダウンおよびモデル一覧再取得ボタン。
    - プロンプト診断・生成設定カード（折りたたみ詳細）: 6種類のシステムプロンプト編集（干渉タグ診断SDXL/Anima、語彙サジェスト、物理・構図整合性チェック、Scene Generatorプロンプト通常/Anima）および詳細パラメータスライダー（Temperature, Top_P, MaxTokens等）をデフォルト折りたたみで格納。
  - **Tab 3: セリフ支援 (Dialogue Assist)**:
    - セリフ口調プリセットカード: プリセット一覧（名前、指示プロンプト、表示順）および作成・編集モーダル。
    - セリフ下書き＆吹き出し検出設定カード: 画像状況認識モデル(VLM)選定、セリフ生成モデル(LLM)選定、および吹き出し自動検出フィルタ（min_area / min_brightness）のサブ設定。
    - セリフ用プロンプト・パラメータカード（折りたたみ詳細）: 3段階パイプラインの役割に応じた改善ラベル（①画像シチュエーション読み取りプロンプト[VLM]、②セリフ自動生成プロンプト[LLM]、③キャラクター口調変換プロンプト[LLM]）と詳細パラメータをデフォルト折りたたみで格納。
  - **Tab 4: 翻訳 (Translation)**:
    - 翻訳基本設定カード: 3箇所から集約した翻訳プロバイダー選択（FuguMT / DeepL / Google Cloud / ローカルLLM）、API認証情報（API選択時のみ表示）、および翻訳デバウンス間隔(ms)。
    - テスト翻訳カード: 原文入力 ↔ 即時翻訳プレビュー。
    - LLM翻訳詳細設定カード（条件付き表示）: プロバイダーで「ローカルLLM」を選択した時のみ即座に出現する翻訳用LLMモデル選択、翻訳システムプロンプト（日→英 / 英→日）、およびパラメータ。他プロバイダー選択時はリロードなしで即座に非表示となる。
  - **Tab 5: システム・一般 (System & Display)**:
    - 外部サービス接続カード: ComfyUIの既存URL編集・保存・疎通確認、Backendの同一origin接続先表示・疎通確認、LM StudioのBackend経由疎通確認・環境設定案内。Backend/LM StudioのURL編集や新規設定APIは本PBI対象外。
    - VRAM安全ガードカード: ガード有効/無効トグル、生成前最小空き容量スライダー (vram_min_free_gb)、およびリアルタイムVRAMメーター。
    - 表示・操作感設定カード: サムネイル表示アスペクト比選択＋ライブプレビュー、長押し判定感度スライダー。
  - **モバイルレスポンシブ対応 (768px未満)**:
    - タブバーの横スクロール（Snap付き）＋短縮ラベル（「① モデル」「② 呪文」「③ セリフ」「④ 翻訳」「⑤ システム」）＋両端フェード表現。
    - AppShell固定ボトムナビとの干渉を防ぐ余白設定（`pb-24` + `env(safe-area-inset-bottom)`）。
    - 多列テーブル（口調プリセット一覧等）のカード型縦積みレイアウトへの自動切り替え。
    - タップ領域44px以上の確保。
