### REQ-322: Fix LoRA Studio API path double prefix (405 Method Not Allowed)

- **Status**: done (2026-10-07)
- **Description**:
  Dataset Studio (LoRA Studio) において直交マトリクス再計算やプロジェクト操作を行うと、APIリクエスト先が `/api/api/...` となり `405 Method Not Allowed` が発生する障害を修正する。
  詳細は [`docs/incident_report.md`](docs/incident_report.md) を参照。

#### Background & Root Cause
- `frontend/src/api/client.ts` の共通ヘルパー `request` は内部で `BASE_URL = '/api'` を自動付与する仕様である。
- しかし `settingsApi`, `datasetApi`, `trainingApi`, `benchmarkApi` のエンドポイント定義で誤って先頭に `/api` が付与されていたため、ブラウザから `/api/api/...` への不正なリクエストが発生していた。
- FastAPI に該当ルートが存在せず、フォールバックの SPAStaticFiles (GET/HEADのみ許可) に到達して 405 エラーが返されていた。

#### Acceptance Criteria (AC)
- [ ] AC-1: `frontend/src/api/client.ts` 内の `settingsApi`, `datasetApi`, `trainingApi`, `benchmarkApi` の全エンドポイント定義から余計な `/api` プレフィックスが除去され、他 API と同様の相対パス（例: `/dataset/projects`）に統一されていること。
- [ ] AC-2: `frontend/src/api/__tests__/client.test.ts` に `settingsApi`, `datasetApi`, `trainingApi`, `benchmarkApi` の各 API 呼び出し先 URL（`/api/...`）が正しくフォーマットされることを検証するユニットテストが追加され、全件 PASS すること。
- [ ] AC-3: `frontend` の型チェック (`npm run typecheck`) および全ユニットテスト (`npm test`) がエラーなくパスすること。
