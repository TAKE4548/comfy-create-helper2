### REQ-184: モバイルモード生成画面のセクション順序およびUndo/Redo配置の最適化
- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: none
- **Priority**: P2
- **Surface**: モバイルモードの生成画面でレイアウトを修正したい。プログレスバー→プリセットタブ→履歴ビュー→プロンプトエリア となっているが、プログレスバー→履歴ビュー→プリセットタブ→プロンプトエリア の方が自然。また、プリセットタブの下にundo/redoがあって隙間が出るので、undo/redoを管理ボタンのあるセクションに持っていって配置を最適化したい（※Undo/Redoは管理機能の中に入れるのではなく、プリセット管理ボタン群があるバー/行の空いている左側スペースに配置するイメージ）
- **Root Cause**: モバイル画面において、生成進行・結果確認領域（プログレスバー、履歴ビュー）と入力設定領域（プリセットタブ、プロンプトエリア）の視覚的・操作的グルーピングが分断されている。また、プリセットタブ直下に単独配置されたUndo/Redoボタンにより不要な余白（縦の隙間）が生じ、モバイルの限られた表示領域を圧迫している（情報設計・横並び配置の最適化不足）。
- **Requirement**: モバイルモードの生成画面において、上から「プログレスバー → 履歴ビュー → プリセットタブ → プロンプトエリア」の順にセクションを再配置し、自然な操作フローを確保する。また、Undo/Redoボタンをプリセット管理ボタン群が並ぶ行の空きスペース（左側）に収めることで縦方向の不要な隙間を排除し、画面領域を最適化する。
- **Acceptance criteria**:
  - [x] AC-1: モバイル表示モード時、生成画面のセクション配置順が「プログレスバー → 履歴ビュー → プリセットタブ → プロンプトエリア」の順序で表示されること
  - [x] AC-2: モバイル表示モード時、プリセットタブ直下に独立していたUndo/Redoボタンが移動され、不要な縦方向の余白・隙間が解消されていること
  - [x] AC-3: Undo/Redoボタンがプリセット管理ボタン群と同じ行（左側の空きスペース）にインライン配置され、タップによるUndo/Redo操作が正常に機能すること
  - [x] AC-4: デスクトップ表示モードや他機能に意図しない表示崩れや動作のデグレーションが発生しないこと
