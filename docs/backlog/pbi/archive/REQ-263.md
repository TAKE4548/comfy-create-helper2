### REQ-263: モバイル・LAN外部アクセス対応と各種起動・管理スクリプトのハードコード網羅是正

- **Type**: enhancement
- **Status**: done (2026-09-16)
- **Current step**: Step 3 (Design)
- **Priority**: P2
- **Surface**:
  - allow firewallの後ってサービス再起動だけじゃダメなんだっけ？ モバイルからアクセス出来ない
  - config書き換えてBEリブートしたが変わらないな。ログ的にconfigの書き換えが起動引数に反映されてない感じか？ 他も網羅的に確認したいから別のPBIにしよう
  - なんでかアーカイブにあるけど、この内容の不具合があるんだが、各種バッチを網羅的に確認し、同様のハードコード問題が潜在していないか確認したうえで修正するPBIにしたい
- **Root Cause**:
  - **Configuration & Startup Architecture**:
    - Backend（uvicorn）の起動スクリプト（`backend/run_server.bat`）をはじめとする各種起動・管理バッチ/スクリプトにおいて、`--host 127.0.0.1` や固定ポート等のハードコードが潜在している可能性があり、`tools/server-manager/config.json` や外部設定の変更が実際の起動引数・ランタイムに反映されない。
    - そのため、ファイアウォールを開放しても自PC以外のLAN/モバイル端末からの通信が拒絶されたり、設定変更が無効化される。
    - また、React フロントエンドが参照する `comfy_url`（ComfyUI 接続先）が `localhost:8188` 固定であるため、外部LAN端末からアクセスした際にクライアント自身を参照してしまい接続エラーとなる。
    - リポジトリ内の主要スクリプト（起動、マネージャ、ComfyUI連携等）におけるバインドホスト、ポート待受、ファイアウォール許可、外部アクセス設計が一貫して網羅的に整備・検証されていない。
- **Requirement**:
  - 起動・サーバー管理・環境設定に関する主要スクリプト群（`backend/run_server.bat`、`tools/server-manager/*`、ComfyUI起動連携関連など）を網羅的に調査し、ホスト・ポート・接続先URL等のハードコード箇所を特定・是正すること。
  - `tools/server-manager/config.json` や設定引数が各種起動スクリプトに確実に反映され、LAN・外部端末（`0.0.0.0`）からのアクセスを正常に受け付けられるようにすること。
  - Windows ファイアウォール（Port 8000, 8188, 8899等）の許可状態およびネットワークプロファイルの整合性を検証・一括設定できるスクリプトを提供すること。
  - モバイル等のLAN端末からアクセスされた際、ComfyUI 接続先が自動的にサーバーマシンの LAN IP へ動的解決され、外部ブラウザ上でも画像生成・ステータス更新が正常動作すること。
- **Acceptance criteria**:
  - [x] AC-1: 主要な起動・サーバー管理スクリプト群（Backend、Server Manager、ComfyUI連携等）において、ホスト(`127.0.0.1`等)やポート等のハードコードが網羅的に排除され、設定ファイルや引数が一貫して反映されること。
  - [x] AC-2: `backend/run_server.bat` および `tools/server-manager/server-manager.ps1` が `0.0.0.0` 待機（または config.json 指定ホスト）で正常起動し、LAN 内の別端末・モバイルからアクセス可能なこと。
  - [x] AC-3: `tools/server-manager/config.json` のホスト・ポート設定変更が、起動スクリプトおよび各サービスに確実に反映されること。
  - [x] AC-4: Port 8000 を含む必要なファイアウォール受信許可を一括適用・検証できる管理者スクリプトが整備されていること。
  - [x] AC-5: モバイル等の外部端末からアクセスした際、バックエンドの `/api/config`（またはフロントエンド側）がサーバーマシンの LAN IP を ComfyUI 接続先として動的に解決し、モバイルブラウザ上から画像生成・ステータス更新が正常に完了すること。
