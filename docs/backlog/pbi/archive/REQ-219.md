### REQ-219: 生成プロンプト各入力欄および個別タグのコピー＆ペースト・履歴・タグセット連携
- **Type**: enhancement
- **Status**: done (2026-09-05)
- **Current step**: Phase 1: Requirement Analysis
- **Priority**: P2
- **Surface**:
  - 生成プロンプトの各入力欄（背景や衣装など）において、設定されたプロンプト内容を別のプリセットやタグセットへ転用・共有する手段がなく、手動で再入力または再選択する必要がある。
  - 個別のタグを別の欄やプリセットへ複製・移動する操作が煩雑である。
  - 入力欄で作成・調整したプロンプトを、既存のタグセットや新規タグセットとして反映・改修する直接の導線がない。
- **Root Cause**:
  - Interaction: プロンプト入力欄および個別タグ単位でのクリップボード操作（コピー＆ペースト）、複数件のコピー履歴保持、および入力欄からタグセットへの直接登録・更新機能が提供されていないため。
- **Requirement**:
  - 生成プロンプトの各入力セクション単位で、設定されたプロンプト全体をOSクリップボードおよびアプリ内履歴へコピーし、他の入力セクションや別プリセットへペースト（上書き／追加の選択が可能）できること。
  - ペースト時に直近でコピーした複数件の履歴から対象を選択して適用できること。
  - 個別のタグに対してもコピー操作が可能であり、各入力欄へのペースト対象として利用できること。
  - 入力セクションの内容から直接、新規タグセットの登録または既存タグセット（サブセット含む）への上書き更新が行えること。
- **Acceptance criteria**:
  - [x] AC-1: プロンプト入力セクション単位で全プロンプトをコピーした際、OSクリップボードにカンマ区切りのテキストとして格納されること。
  - [x] AC-2: セクションへのペースト実行時、既存のタグ群に対して「上書き（全置換）」または「末尾への追加（マージ）」を選択して反映できること。
  - [x] AC-3: コピーしたプロンプトの履歴が複数件保持され、ペースト操作時に履歴一覧から過去のコピー内容を選択して反映できること。
  - [x] AC-4: 個別タグのサブメニューからタグ単体をコピーでき、セクションへのペースト機能を通じて他の入力欄やプリセットに反映できること。
  - [x] AC-5: 入力セクションの現在の内容をもとに、新規タグセットとして登録、または既存のタグセット／サブセットを選択して上書き更新できること。
