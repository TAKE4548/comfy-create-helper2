### REQ-041: アルバム内表示・編集機能

- **Type**: enhancement
- **Status**: ready
- **Current step**: none
- **Priority**: P2
- **Surface**: アルバム表示で、アルバムの中を表示・編集できるようにしたい。各アルバムをクリック・タップでアルバム内の確認ページに遷移し、画像クロップなしの一覧表示、画像ごとの削除（複数選択含む）オーバーレイ、ドラッグ＆ドロップによる順序入れ替え（永続化）、ソート機能（カスタム・登録順昇順・降順）、クリックでの拡大ビューワー表示（左右ボタン・キー・スワイプ送り）を可能にする。
- **Root Cause**: アルバムに登録した画像を一覧で確認したり、その順序を並べ替えたり、アルバムから削除したりする機能が不足しており、アルバムの管理・活用が困難である。
- **Requirement**: アルバムの管理・閲覧性を向上させるため、アルバム内の画像確認・編集ページを追加し、画像の並び替え、削除、カスタムソートの永続化、およびスライドショー機能を備えた拡大ビューワーを提供する。
- **Acceptance criteria**:
  - AC-1: アルバム一覧画面（アルバムページ）の各アルバムをクリック・タップすると、そのアルバムの詳細確認ページへ遷移すること。
  - AC-2: 詳細確認ページでは、アルバムに登録された画像が、画像の切り抜き（クロップ）を伴わずにアスペクト比を維持したまま一覧表示されること。
  - AC-3: 一覧の各画像に、アルバムから削除するためのアイコン（削除ボタン）がオーバーレイ表示され、個別削除ができること。
  - AC-4: 画像を複数選択して、選択した画像をアルバムから一括で削除できること。
  - AC-5: 画像一覧において、ドラッグ＆ドロップ操作により任意の順番に画像を入れ替え可能であり、入れ替えた順番（カスタム順）がデータベース等の永続化領域に保存されること。
  - AC-6: 画像一覧のソート条件として、「カスタム順（ドラッグ＆ドロップ順）」「登録順（昇順）」「登録順（降順）」を切り替えることができること。
  - AC-7: 画像一覧の画像をクリック・タップすると、ウィンドウ全体に広がる拡大表示（Lightboxビューワー）が表示されること。
  - AC-8: 拡大表示中、画面上の左右ボタン、キーボードの矢印キー、またはスワイプ操作によって、現在一覧で選択されているソート順に従って前後の画像に切り替え（画像送り）ができること。
- **Design doc**: none
