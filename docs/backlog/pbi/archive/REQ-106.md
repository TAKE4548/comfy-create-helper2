### REQ-106: ノードマッピングにおけるBoolean型のサポート

- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: none
- **Priority**: P2
- **Surface**: ノードマッピングのtypeでBooleanを扱えるようにしたい
- **Root Cause**: ノードマッピングの設定において「Boolean」データ型が選択肢になく、トグルスイッチのような直感的なON/OFF操作のUIで入力を行えない。
- **Requirement**: ノードマッピングのデータ型（type）として `Boolean` をサポートし、Boolean型が選択された場合にはトグルスイッチによる直感的なON/OFF入力を可能にする。
- **Acceptance criteria**:
  - [ ] AC-1: マッピング編集UIのタイプ（データ型）選択肢において、新たに「Boolean」を選択可能にすること。
  - [ ] AC-2: データ型「Boolean」が選択された項目は、設定画面上でテキストフィールド等の代わりにトグルスイッチ（ON/OFFスイッチ）として表示され、直感的に操作できること。
  - [ ] AC-3: トグルスイッチのON/OFF操作が、対応するノードパラメータの `true`/`false` 値として正しくマッピング定義へ保存・反映されること。
- **Design doc**: none
