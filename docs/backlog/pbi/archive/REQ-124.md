### REQ-124: ノードマッピング追加時のカスタムパラメータ型追加およびComfyUIからの自動取得機能

- **Type**: enhancement
- **Status**: done (2026-08-26)
- **Current step**: none
- **Priority**: P2
- **Surface**: ノードマッピングに追加する時、既存の型かcomboしか選択できないので、追加したいパラメータの任意の型も適宜追加できるようにしたい。型の定義は既存のワークフローから任意のノードとパラメータを選択して、ComfyUIから自動で取得できるようにしたい。
- **Root Cause**: ノードマッピングのマスタ設定において選択可能な型定義が固定（既存型/combo）されており、任意の型およびcombo選択肢リストの手動追加やComfyUIサーバーからの型情報自動補完機構が存在しないため。
- **Requirement**: 
  1. ノードマッピングマスタ追加時、手動（マニュアル）で任意のカスタム型（型名やcombo選択肢等）を新規定義し保存・再利用可能にする。
  2. ComfyUIサーバー接続時は、指定されたノードとパラメータの型情報（データ型やcombo選択肢リストなど）を自動取得して入力フォームを補完できるようにする。
  3. ComfyUIサーバー未起動時であっても手動入力で任意の型を作成・保存できるフォールバック構成とする。

#### Acceptance Criteria (AC)
- [x] AC-1: ノードマッピング追加画面において、手動で新しいパラメータ型（型名、combo選択肢等の属性）を定義・保存してマスタで再利用できること。
- [x] AC-2: ComfyUIサーバー接続時、ノード・パラメータの指定によりComfyUIから型情報（combo選択肢含む）を自動取得しフォームに入力補完できること。
- [x] AC-3: ComfyUIサーバー未起動状態でも、手動入力でエラーなくカスタム型を作成・保存できること。
