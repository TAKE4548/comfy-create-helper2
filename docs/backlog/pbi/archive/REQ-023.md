### REQ-023: Thumbnail Hover Zoom and Wheel Horizontal Scroll

- **Type**: enhancement
- **Status**: abandoned（2026-10-26 ユーザーレビューにより廃止・アーカイブ）
- **Current step**: none
- **Priority**: P2
- **廃止決定（2026-10-26）**:
  - 現行のメインプレビューリール・クリック拡大の仕様と、本PBIの履歴サムネイルに対する追加要求を説明した上で、ユーザーが「廃止でいいかな」と判断したため、本PBI全体を廃止する。
  - ホバー拡大と履歴サムネイルのホイール横スクロールを本PBIの今後の実施対象から外す。既存の表示・操作を削除する決定ではない。
  - 元の要求とACは経緯として保存する。実装済み・後続対応で完全代替済み・受入PASSを意味しない。
- **Surface（旧要求の経緯）**: 生成ページの履歴サムネにカーソルをフォーカスすると、拡大プレビューが表示されるようにしたい。また、履歴サムネのエリアにカーソルを置いてホイールスクロールした際、横方向にスクロールできるようにしたい
- **Root Cause**:
  - 生成ページ（DesktopLayout）の履歴サムネイルは、画像の詳細（テクスチャ、表情、ノイズなど）を細かく視認するにはデフォルトサイズ（サムネイル）のままでは小さい。クリックして選択画像（selectedImg）を切り替えることなく、ディテールを確認したいというUXニーズがある。
  - 履歴数が増えるとサムネイルエリアが横スクロール可能になるが、標準のマウスホイール操作（縦回転）は横スクロールに変換されないため、スクロールバー操作や Shift + ホイール を強いる課題がある。
- **Requirement（廃止した要求・経緯として保存）**:
  - **履歴サムネイルのホバー拡大表示（ポップアッププレビュー）**:
    - デスクトップ環境において、生成ページの履歴サムネイル上にマウスカーソルをホバーした際、選択画像を変更することなく、前面にポップアップオーバーレイで拡大画像がプレビュー表示されること。
    - ホバーが外れたら即座にプレビューが非表示になること。
    - 複数選択モード（`isMultiSelectMode`）や長押しドラッグ操作（`useMultiSelect`）と競合しないこと。
  - **ホイール横スクロール機能**:
    - 履歴サムネイルが表示される横スクロールコンテナ上でマウスホイールを上下回転させた際、それを横方向（左右）のスクロールに変換し、滑らかに横スクロールすること。
    - ページ全体の縦スクロールを防止（`preventDefault`）すること。
- **Acceptance criteria（廃止により適用終了・旧ACの記録）**:
  - 旧AC-1: 生成ページ（DesktopLayout）の履歴サムネイル上にマウスカーソルをホバーさせた際、そのサムネイル画像の拡大プレビューがポップアップ（オーバーレイ）として前面に表示されること。
  - 旧AC-2: サムネイル画像からマウスカーソルが外れた際、表示されていた拡大プレビューが速やかに消去（非表示化）されること。
  - 旧AC-3: 拡大プレビュー表示中、現在の選択中画像（`selectedImg`）やパラメータ入力値に意図しない変更が発生しないこと。
  - 旧AC-4: 履歴サムネイルが並ぶ横スクロールコンテナの上にマウスカーソルを置き、マウスホイールを回転（上下スクロール）した際、コンテナがその回転方向に応じて左右（横方向）にスクロールすること。
  - 旧AC-5: マウスホイールでの横スクロール時、ブラウザ標準のページ全体の縦スクロールが発生せず、履歴コンテナ内の横スクロールのみが発生すること。
  - 旧AC-6: タッチデバイス・モバイルビュー（MobileLayout）ではホバープレビューが誤作動せず、既存のスワイプスクロールおよび長押し複数選択操作が正常に維持されること。
