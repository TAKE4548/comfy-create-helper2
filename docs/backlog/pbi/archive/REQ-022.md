### REQ-022: ワークフローごとの過去画像生成履歴スナップショットからの設定ロード機能

- **Status**: done (2026-08-30)
- **Type**: enhancement
- **Priority**: P2
- **Current step**: none
- **Surface**: 生成ページの開いてるワークフローに対応する過去のスナップショットを選択して、プロンプトやパラメータの設定をロードできるようにしたい
- **Root Cause**:
  - 過去に生成した画像と同じパラメータ設定やプロンプトを再利用したい場合、履歴から内容を手動でコピー＆ペーストするか、再入力する必要があり、時間と手間がかかる。
  - 現在開いているワークフローに関連付けられた過去の画像生成履歴（スナップショット）だけをフィルタリングして表示し、ワンクリックでプロンプトやパラメータの設定値のみを入力フォームに復元（ロード）する簡易なインターフェースが存在しない。
- **Requirement**:
  - **ワークフロー連動の履歴フィルタリング**: 生成ページで現在開いている（選択されている）ワークフローに対応する、過去の画像生成履歴（スナップショット）を特定する（保存時にワークフローとプロンプト・パラメータがすでに紐づいている情報を使用）。
  - **履歴選択UI（案2）**: ワークフロー選択エリアの横に、対応する過去のスナップショットを選択できるドロップダウンメニュー（またはセレクトボックス）を配置する。
    - ドロップダウンには、生成日時や識別用テキスト（プロンプトの冒頭など）を表示する。
  - **プロンプト・パラメータのロード機能**: スナップショットを選択した際、そのスナップショットに含まれるテキストプロンプトおよびパラメータ（シード、ステップ数、CFG、モデルなど）の入力値のみを現在の生成画面の入力フィールドへ反映（上書きロード）する。この際、ワークフローのノード構成（接続）自体は変更（上書き）しない。
  - **空の履歴ハンドリング**: 現在のワークフローに紐づく過去のスナップショットが存在しない場合、ドロップダウンは非活性化（disabled）とする。
- **Acceptance criteria**:
  - [ ] AC-1: 生成ページのワークフロー選択エリアの横に、現在選択されているワークフローに紐づく過去の画像生成履歴（スナップショット）を選択できるドロップダウンUIが配置されていること。
  - [ ] AC-2: ドロップダウンには、該当ワークフローで生成された過去スナップショットの一覧が時系列（新しい順）で表示されること。
  - [ ] AC-3: ドロップダウンからスナップショットを選択すると、そのスナップショットに保存されていたテキストプロンプトおよび各種生成パラメータ（シード値やステップ数など）の値が生成画面の対応する入力フォームに自動的にロード（反映）されること。
  - [ ] AC-4: スナップショットのロードを実行した際、ワークフローのノード接続構造自体は上書きされず、現在の状態が保持されること。
  - [ ] AC-5: 現在のワークフローに紐づく過去のスナップショットが存在しない場合、ドロップダウンが適切に非活性（disabled）または「履歴なし」表示になること。
