### REQ-029: 生成画面のデザイン修正および旧REQ-019の統合

- **Status**: done (2026-08-30)
- **Type**: enhancement
- **Priority**: P2
- **Current step**: none
- **Surface**: 生成画面のUI/UX向上を目的とした以下のデザイン・レイアウト修正：
  1. ワークフロー設定（ComfyUI接続設定等）のセクションを、ワークフロー選択の脇に配置した設定アイコンをクリックしたときに表示されるサブメニュー/ポップオーバー形式に移行し、メイン画面の省スペース化を図る。
  2. 生成中のプログレスバー表示がプレビュー画面全体を覆う仕様を廃止し、プレビュー領域の一部（上部または下部の境界部など）に細いバーとして表示されるようにし、生成中であってもメインプレビューおよび履歴の操作を行えるようにする。
  3. 過去のスナップショット選択において、名前だけでなくスナップショットの画像を見ながら選択できるサムネイル付きUIに刷新し、履歴（History）エリアに統合または隣接する形で配置する。
  4. "Save Snapshot" の保存ボタンのアイコンを、現在のフロッピーディスクからカメラ等の直感的なアイコンに変更する。
  5. 既存の `REQ-019`（プレビューサイズの70%縮小、パディング・枠線・影の適用、ホバー時の左右ナビゲーションボタン、フォーカス時のキーボード左右矢印キーによる履歴画像切り替え）を統合する。

- **Root Cause**:
  1. ワークフロー設定セクションが常時展開されており、頻繁に変更しない割に画面スペースを圧迫している。
  2. 生成中に画面全体がプログレスバー表示で覆われてしまい、生成中のプレビュー確認や過去履歴の参照・比較ができない。
  3. スナップショットの選択がテキストベースの名前のみで行われており、過去に作成した構成が視覚的にわかりにくい。
  4. 保存アイコンがフロッピーディスクであり、現代的なスナップショット（カメラで捉える瞬間）のメタファーと乖離している。
  5. 旧REQ-019で指摘されていたメインプレビューの画面密着や画像比較の操作コストの高さが未解決のまま残っている。

- **Requirement**:
  - **ワークフロー設定のサブメニュー化**: ワークフロー選択ドロップダウンのすぐ右隣に設定ギアアイコン（Lucideの `Settings` 等）を配置。クリックでポップオーバー（Popover）やドロップダウンを開き、そこでComfyUI URLやその他の設定項目を変更・保存できるようにする。
  - **控えめなプログレスバーの採用**: 生成実行中の進捗表示を、プレビュー画像領域の枠線（上部または下部）に重ねる薄型プログレスバー（高さ4px〜6px程度）またはスキャン線風のインジケーターに変更。プログレス中もメインプレビュー画像が覆い隠されず表示され続けるようにする。
  - **スナップショット選択のサムネイルUI化**: 履歴（History）エリアに「生成履歴」と「スナップショット一覧」を切り替えるタブ（Tabs）を設置。スナップショットタブ内では、登録されているスナップショットがサムネイル画像付きでカード状に並び、視覚的に探してワンクリックでワークフローやパラメータを読み込めるようにする。
  - **カメラアイコンへの変更**: スナップショットの「Save Snapshot」ボタンのアイコンを、フロッピーディスクからカメラアイコン（Lucideの `Camera` 等）に変更する。
  - **メインプレビューのサイズ調整と装飾 (旧REQ-019)**: プレビューエリア内の画像表示サイズを約70%程度にし、上部に十分な余白を設定。カード風の外枠（ボーダー）と影（ボックスシャドウ）を付与する。
  - **左右切り替えボタンとキーボードショートカット (旧REQ-019)**: メインプレビュー画像へのホバー時に左右ナビゲーションボタン（`<` / `>`）を表示し、クリックで履歴画像を切り替える。プレビュー部がフォーカスされている時のみ左右矢印キーでの切り替えをサポートする（テキスト入力中は無効）。

- **Acceptance criteria**:
  - [ ] AC-1: **ワークフロー設定のポップオーバー化**: ワークフロー選択ドロップダウンの脇に配置されたギアアイコンから設定ポップオーバーが開くこと。設定項目（ComfyUI URL等）の編集・保存が正常に動作すること。
  - [ ] AC-2: **非ブロッキングなプログレスバー**: 生成中のプログレスバーがメインプレビュー画像全体を覆い隠さず、プレビューエリアの端部（上辺または下辺など）に控えめなバーとして表示されること。生成中も現在表示されているプレビュー画像の参照や履歴操作が可能なこと。
  - [ ] AC-3: **スナップショットのビジュアル選択**: 履歴（History）エリアに「History」「Snapshots」を切り替えるタブが実装され、「Snapshots」タブ内にサムネイル画像付きのスナップショット一覧が表示されること。スナップショットカードの選択により、対象のスナップショットが正常にロードされること。
  - [ ] AC-4: **保存アイコンの更新**: 「Save Snapshot」ボタンのアイコンがカメラアイコンに変更されていること。
  - [ ] AC-5: **プレビューサイズとカードデザイン**: メインプレビューの画像サイズが適切な余白を伴う約70%サイズに調整され、ボーダーとボックスシャドウによってカード状に浮き上がってデザインされていること。
  - [ ] AC-6: **ホバー切り替えボタン**: メインプレビューへのホバー時に左右の切り替えアローボタンが表示され、クリックで履歴の前後画像へスムーズに遷移できること。
  - [ ] AC-7: **キーボード操作**: プレビューエリアにフォーカスがある状態で `←` / `→` キーを押すことで履歴画像が切り替わること。テキスト入力エリア（プロンプト等）にフォーカスがある場合は矢印キーによる切り替えが動作しないこと。
