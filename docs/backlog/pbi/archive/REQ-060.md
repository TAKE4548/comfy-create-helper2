### REQ-060: ワークフローアップロード時のマッピング機能の改善

- **Type**: enhancement
- **Status**: ready
- **Current step**: none
- **Priority**: P1
- **Surface**: 新規ワークフローをアップロードしたときの、マッピング周りを改修したい。現状、マスタに定義した順番にマッピングを行うため、登録した時の順番によって同一系統がバラバラになり認知負荷が高い。また、自動検知されたものと警告（不一致・複数候補・未検出）が重複表示され、どちらかを無効化する必要があり作業負荷が高い。自動検出されたID主体の構成からマッピングマスタの項目主体の構成に変更し、候補をドロップダウンや自由入力で選べるようにしたい。
- **Root Cause**: 
  1. マッピング確認UIが「検出されたノードID」を基準にマッピング先ロールを選択する設計になっているため、ロール側で重複が発生した際の手動調整や除外操作の作業負荷が高い。
  2. マッピングマスタの項目（役割）ベースではなく、スキャン結果のノードベースで一覧が生成されるため、同一系統（サンプラーとDetailerなど）の役割がマスタの登録順で散らばって表示され、視認性が悪い。
  3. マッピングマスタの表示順を制御する仕組み（並び替え機能）がマスタおよびDBに存在しないため、関連する役割を近くにまとめて表示できない。
- **Requirement**: 
  1. **マスタ表示順の制御（D&D並び替え）**: 
     - データベースの `mapping_master` に並び順（`sort_order`）カラムを追加し、API経由で取得・更新できるようにする。
     - 設定画面（`SettingsPage`）のノードマッピングマスタ管理UIにおいて、D&Dによる項目の並び替え機能を実装し、並び替えた順序を永続化する。
  2. **マッピング確認UIの構成変更**:
     - ワークフローアップロード時（`UploadWorkflowModal`）および再スキャン時（`RescanModal`）のマッピング確認UIを、自動スキャン結果のノード基準ではなく、**「マッピングマスタに定義された役割（項目）」を主とし、マスタの `sort_order` 順に並んだ構成**に刷新する。
  3. **コンボボックス形式でのノードID紐付け**:
     - 各役割に対してマッピング対象ノードをドロップダウンかつ自由入力も受け付けるコンボボックス形式（入力した値がそのままノードIDになる）で選択・入力できるようにする。
     - 1:1で自動マッチングしたものは初期選択、複数候補がある場合は候補一覧から選択可能にする。
  4. **完全に未検出（not_found）の項目の分離**:
     - 自動マッピングで候補が完全に未検出（not_found）だった役割項目は、メインのリストとは分離され、画面下部に「未検出の項目」としてまとめて表示する。未検出項目についても同様にコンボボックスでノードIDを紐付け可能とする。
- **Acceptance criteria**: 
  - [ ] AC-1: **データベース・APIの対応**: `mapping_master` テーブルに表示順を管理する `sort_order`（整数値）カラムが追加され、API（`GET /api/mapping_masters`, `PUT /api/mapping_masters/reorder` 等）で順序の取得と一括更新ができること。
  - [ ] AC-2: **設定画面での並び替え機能**: 設定画面のノードマッピングマスタ管理UIで、ドラッグ＆ドロップ（`@dnd-kit`等を使用）によって項目を並び替えることができ、並び替え完了時にバックエンドへ順序が保存されること。
  - [ ] AC-3: **マスタ主体のマッピング確認UI**: 新規登録（`UploadWorkflowModal`）および再スキャン（`RescanModal`）で、マッピングリストが「マッピングマスタ（役割）」を主軸として `sort_order` 順に並んで表示されること。
  - [ ] AC-4: **コンボボックスによる選択と入力**: 各役割の入力欄がコンボボックス（自動検出されたノードID候補を選択でき、任意のノードIDの直接入力も可能）になっており、1:1マッチング時は初期値が自動設定されること。
  - [ ] AC-5: **未検出項目の下部配置**: スキャンで完全に候補が未検出（not_found）の役割のみ、リスト下部の「未検出の項目」セクションに初期状態空欄でまとめられて表示され、ユーザーが必要に応じて手動で紐付けできること。
  - [ ] AC-6: **保存と適用**: 確定・保存ボタンを押下した際、各役割に対して選択・入力されたマッピング情報が正しく収集され、ワークフローが正常にDBに登録・更新されること。
- **Design doc**: none
