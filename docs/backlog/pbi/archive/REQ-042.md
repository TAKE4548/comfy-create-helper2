### REQ-042: タッチ操作時における並び替えドラッグの誤動作防止（ロングタップ化）

- **Type**: enhancement
- **Status**: done (2026-08-26)
- **Current step**: none
- **Priority**: P2
- **Surface**: アルバム画面など、画像の順番を入れ替えられる画面で、スマホやタブレットだとスクロールしたいときに順番入れ替えが暴発することがある。タップ系の時はロングタップで順番入れ替え発動にしたい
- **Root Cause**: モバイル・タブレット等のタッチ操作において、通常のスクロールとドラッグ＆ドロップ（並び替え）のトリガーが区別されにくく、スクロール操作の開始時に意図せずドラッグ操作が暴発してしまう。
- **Requirement**:
  - タッチ操作時（スマートフォン、タブレット等のタッチデバイス）のみ、画像/アイテムのドラッグによる並び替えの開始条件を「500msのロングタップ（長押し）」とする。
  - PC等の非タッチデバイス（マウス操作）については、従来どおりクリック＋ドラッグで即時に移動可能とする。
  - ロングタップ中にドラッグ可能状態になった際、対象の画像/アイテムが少し浮き上がるような視覚効果を適用する。
  - 画像やアイテムの並び替えができるすべての画面（アルバム画面など）でこの挙動を統一する。
- **Acceptance criteria**:
  - AC-1: タッチ操作対応デバイスにおいて、画像/アイテムをタップしただけ、あるいはタップ直後にスクロール（スワイプ）した場合は、並び替えのドラッグが発生せず、ページスクロールが正常に行えること。
  - AC-2: タッチ操作対応デバイスにおいて、画像/アイテムを500ms以上長押し（ロングタップ）した後に指を動かすことで、ドラッグ＆ドロップによる並び替えが開始されること。
  - AC-3: 非タッチデバイス（マウス操作）においては、ロングタップの必要がなく、画像/アイテムをドラッグし始めた時点で即時に並び替えが開始されること。
  - AC-4: タッチ操作でロングタップ（500ms）が成功しドラッグ可能状態になった際、対象の画像/アイテムが少し浮き上がる（例: スケールアップや影の追加など）視覚効果が発生すること。
  - AC-5: 画像やアイテムの並び替え機能が存在するすべての画面（アルバム画面等）において、このタッチ操作時のロングタップ挙動が適用されていること。
- **Design doc**: none
