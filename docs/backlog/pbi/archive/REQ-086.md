### REQ-086: タッチデバイス操作時のスクロール阻害問題の解消

- **Status**: done (2026-08-30)
- **Description**: 
  アルバムページ一覧などでスクロールを行おうとした際、画像のタッチ領域を触ると画像タップなどの他のイベント判定が優先されてしまいスクロールできない問題を解消する。隙間以外の画像領域をスワイプしてもスムーズに縦スクロールが行えるように、タッチ検出系イベントの処理順やバブリング制御を修正する。

#### Acceptance Criteria (AC)
- [ ] AC-1: モバイル・タッチデバイスにおいて、アルバムページの画像領域を指でスライド（スワイプ）した際、ページがスムーズにスクロールすること。
- [ ] AC-2: スワイプによるスクロール開始時には、画像のタップイベント（詳細モーダルを開くなど）が誤発火しないこと。通常の短いタップ操作時には正しく画像タップイベントが機能すること。
