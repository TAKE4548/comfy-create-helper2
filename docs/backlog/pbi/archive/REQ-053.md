### REQ-053: 全画面表示のクラッシュ修正およびモバイル表示時のレイアウト修正

- **Type**: defect
- **Status**: done (2026-08-26)
- **Current step**: none
- **Priority**: P1
- **Surface**: 全画面表示にしたとき、真っ黒の画面になって表示されない。リロードしないと戻らない。また、レスポンシブでサイドバーが下のメニューバーになった際、メインコンテンツの上にオーバレイして操作できない領域がある
- **Root Cause**:
  1. `HistoryModalPreview.tsx` の `getParamValue` 内で `Object.keys(snapshot.params).find` のコールバック実行時に未初期化の `matchKey` 自体を参照しているため、JavaScript の TDZ (Temporal Dead Zone) 違反による `ReferenceError` が発生し React レンダリングがクラッシュしている。
  2. `AppShell.tsx` でモバイル表示（幅 1024px 未満）のボトムナビゲーションバーが固定配置（`fixed bottom-0`）されているが、メインコンテンツを表示する `main` 要素または各ページにメニューバーの高さ分の下部パディングが確保されていないため、コンテンツの下部が裏側に潜り込んでいる。
- **Requirement**:
  1. `HistoryModalPreview` を開いたときに例外が発生せず、画像とメタデータが正常に表示され、閉じることができること。
  2. モバイル等のレスポンシブ表示において、すべてのメインコンテンツが下部メニューバーに覆われずに正常に表示・操作できること。
- **Acceptance criteria**:
  - [ ] AC-1: 履歴画像をクリックして拡大プレビュー（`HistoryModalPreview`）を開いたとき、クラッシュせずに画像とメタデータ（LoRAスタック含む）が正常に描画され、閉じるボタン・背景クリック・エスケープ等で正常に閉じることができること。
  - [ ] AC-2: 画面幅を縮小してモバイル表示（幅 1024px 未満）にした際、メインコンテンツ領域の最下部までスクロールでき、下部メニューバーに重なって操作できなくなるボタンや要素が存在しないこと。
- **Design doc**: none
