### REQ-203: 複数画像・複数吹き出しに対するLLMセリフ一括変換（BEジョブキュー管理・バックグラウンド実行復帰・個別/全体キャンセル・順次確認・完了後再生成・微調整）機能
- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: Phase 2: Detailed Design (Approved)
- **Priority**: P2
- **Surface**:
  - LLMを使ったセリフ変換機能を複数の画像・吹き出しに対して、まとめて実行出来るようにしたい。
  - セリフ付与されてる画像群から対象を選択し、更にその画像に含まれる対象の吹き出しを任意の数選択するのを、任意の画像数実施して、同一のプリセットでセリフ変換をバッチ的に実施するイメージ。
  - 結果が気に入らず、再生成したい場合もあるので、変換完了したものから順次確認が出来、再生成にするとまた変換キューに送られるイメージ。
  - 変換中はもちろん、全件完了後であっても任意の吹き出しを何度でも再生成（キューへ再投入）でき、再生成されたセリフをその場で確認・再試行できるようにしたい。
  - 生成されたセリフを微調整するケースもあるので、反映後シームレスに編集が出来、その上で最終的な保存が出来るようにしたい。
  - 入口のUIは既存の複数選択とは別に独立して設け、セリフ付与されている画像のみが自動フィルタリングされた一覧から選べるようにしたい。また候補群の選択をやりやすくするため、履歴ページと同様のフィルタ・ソート機能も欲しい。
  - 確定前にページ遷移やモバイル端末でのアプリ切り替え・画面ロック等が発生しても、モーダルが閉じたり強制キャンセルされず裏で処理が継続し、再度開いた際に変換結果や進行状態がそのままシームレスに復帰できるようにしたい。
  - バックエンド主導のバッチジョブキューとすることで、モバイル画面ロック時でも安定して裏で処理が完了し、画像生成同様に単一ジョブキャンセルおよび全体キャンセルを行えるようにしたい。
- **Root Cause**:
  - **Interaction Design (Workflow Friction / Missing Batch Capability, Resumption, Cancellation & Post-Completion Regeneration)**: 現行のセリフ口調変換は単一画像の単一吹き出し編集モーダル内での個別実行に限定されており、セリフ付与済み画像のみを自動抽出してフィルタ・ソートし、複数画像・複数吹き出しにまたがる対象選択、同一口調プリセットの一括適用、変換完了中および全件完了後の個別再生成キュー再投入、変換後テキストのインライン微調整と確定保存を一元的に行う専用バッチ処理ワークフローが存在しない。さらに、モバイル画面ロックやページ離脱時でもサーバー側で確実に進行・復帰させ、任意にキャンセル・再生成できるバックエンド主導のジョブ管理機構が欠落している。
  - **Information Design (Progress, State Visibility & Control)**: 複数項目のLLM変換キュー処理における全体の進行状況、各吹き出しの変換ステータス（待機中・変換中・完了・失敗）、変換前後の差分確認と再生成待ち状態、バックグラウンド進行状態、およびキャンセル・再生成可能状態を視覚的に把握・制御するUIが欠落している。
- **Requirement**:
  - バックエンドにバッチセリフ変換ジョブ管理API（`POST /api/speech-batch/jobs`, `GET /api/speech-batch/jobs/{id}`, `cancel`, `regenerate/retry`）を実装し、モバイル画面ロック中やページ離脱時でもサーバー側で安全・確実にLLMバッチ変換を実行・復帰可能とすること。
  - 履歴ページに専用の起動エントリーポイントを設け、セリフ（吹き出し）が付与された画像のみを自動抽出・フィルタリングした専用選択画面を提供すること。
  - 候補画像一覧において、ワークフロー絞り込み、アルバム絞り込み、日付ソート（昇順/降順）、キーワード検索等のフィルタ・ソート機能が動作し、目的の画像を容易に探して複数画像および任意の吹き出しを選択できること。
  - バッチジョブの実行中において、全体の進捗状況および各吹き出しのステータスをリアルタイム表示し、単一ジョブの個別キャンセルおよび実行中キューの全体キャンセルができること（完了済み結果は保持）。
  - 変換完了したものから順次差分プレビュー（元セリフ vs 変換後セリフ）を確認でき、変換中および全件完了後の任意のタイミングで、特定の吹き出しを何度でも再生成キューへ再投入できること。
  - 変換後のセリフテキストをその場で直接微調整・編集でき、最終確認後に各画像へ反映・一括保存（上書きまたは新規作成）できること。
- **Acceptance criteria**:
  - [ ] AC-1: バックエンドにセリフ変換バッチジョブ管理API（ジョブ作成、進捗・結果取得、単一/全体キャンセル、単一/複数再生成・リトライ）が実装され、サーバー側で非同期に変換が進行すること。
  - [ ] AC-2: 履歴ページヘッダー等に専用の「セリフ一括変換」エントリーポイントが配置され、起動時にセリフ（吹き出し）が付与されている画像のみが自動抽出された一覧が表示されること。
  - [ ] AC-3: 候補画像一覧において、ワークフロー絞り込み、アルバム絞り込み、日付ソート（昇順/降順）、キーワード検索等のフィルタ・ソート機能が動作し、目的の画像および任意の吹き出しを選択できること。
  - [ ] AC-4: 指定した口調プリセットを適用してバッチジョブを作成・実行でき、進捗状況（件数/%）および各吹き出しの変換ステータス（待機中・変換中・完了・エラー）がリアルタイムに表示されること。
  - [ ] AC-5: 一括変換の実行中において、特定の吹き出しジョブを個別にキャンセルでき、該当ジョブがキューから除外されること。
  - [ ] AC-6: 一括変換の実行中において、「全体キャンセル」操作により実行中および待機中の全ジョブを即座に停止できること（既に完了したセリフ変換結果は保持されること）。
  - [ ] AC-7: 変換が完了した項目から順次、元のセリフと変換後のセリフをプレビュー確認できること。
  - [ ] AC-8: 変換中および全件完了後の任意のタイミングで、特定の吹き出しの「再生成」ボタン押下により、該当項目がサーバー側の変換キューへ再投入され、バックグラウンドで再変換が実行・更新されること。
  - [ ] AC-9: 変換されたセリフテキストをプレビュー・確認画面上で直接編集・微調整できること。
  - [ ] AC-10: バッチ変換中または編集途中にモーダルを閉じる・他ページへ遷移する・画面ロック等の事象が発生しても、サーバー側で処理が継続し、再訪時に完了結果・微調整内容が完全に復帰・保持されること。
  - [ ] AC-11: 確認および微調整が完了したセリフを、対象の各画像（スナップショット）の吹き出し情報へ一括で反映・保存（上書きまたは新規作成）できること。
