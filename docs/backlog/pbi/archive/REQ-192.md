### REQ-192: LLMプロバイダー選択時の翻訳疎通テスト・プロンプト翻訳エラー修正

- **Status**: done
- **Description**: 翻訳設定でプロバイダーとして `llm`（ローカルLLM）を選択した場合に、疎通テスト（`POST /api/translate/test`）やプロンプト翻訳（`POST /api/translate/prompt`）を実行すると `TypeError: call_llm() got an unexpected keyword argument 'db'` が発生して失敗する問題を修正する。`translation_service.py` 内の `translate_llm` において、`call_llm` の関数シグネチャに合わせた呼び出し（`system_prompt` と `user_prompt` の分離、不要な `db` キーワード引数の削除）を行うように改修する。

#### Acceptance Criteria (AC)
- [x] AC-1: `translation_service.py` の `translate_llm` が `call_llm` のシグネチャ（`system_prompt`, `user_prompt`）に合致した形式で呼び出され、`TypeError` が発生しないこと。
- [x] AC-2: `provider="llm"` 指定時に `POST /api/translate/test` エンドポイントで疎通テストが正常に成功（`success: true`）すること。
- [x] AC-3: `provider="llm"` 指定時に `POST /api/translate/prompt` エンドポイントでプロンプト翻訳が正常に動作すること。
- [x] AC-4: `test_translation_proxy.py` または関連テストに `provider="llm"` の疎通テスト・翻訳テストケースが追加され、自動テストがパスすること。
