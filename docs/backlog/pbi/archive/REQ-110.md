### REQ-110: プロファイル選択状態の永続化と新規作成時の自動選択

- **Status**: done (2026-08-30)
- **Type**: enhancement
- **Priority**: P2
- **Current step**: none
- **Surface**: 生成画面のプロファイルを選択するとタブとして開くことができるが、開いている状態を保存できず、リロードしたりブラウザを開きなおすと先頭プロファイルになってしまう。編集中にちょっと開きなおすような状況が発生した後、うっかりそのまま先頭プロファイルを編集してしまって手戻りになることがある。同様に、新規でプロファイルを作成した際も、作成したプロファイルは明示的に開く必要があり、うっかりすると作成前にアクティブにしていたプロファイルをそのまま編集してしまうことがあるので、作成後に自動的に開くようにしたい。
- **Root Cause**:
  1. 生成画面のアクティブプロファイル状態がクライアント（ブラウザ）側で永続化されておらず、マウント時に常に最初のプロファイルがデフォルトとして選択されている。
  2. 新規プロファイルの作成処理が完了した際、新しく作成されたプロファイルをアクティブプロファイルとして設定する状態遷移が行われていない。
- **Requirement**:
  1. **アクティブプロファイルの永続化**:
     - ユーザーがプロファイルのタブ（選択状態）を切り替えた際、そのプロファイルIDをクライアント側の永続ストレージ（`localStorage`等）に保存する。
     - 画面マウント時に、永続ストレージから最後に選択されていたプロファイルIDを取得し、存在しかつ有効なプロファイルであればそのプロファイルタブを選択状態にする。
     - 該当するプロファイルが存在しない（削除された等）場合は、従来通り先頭のプロファイルをアクティブにする。
  2. **新規プロファイル作成時の自動アクティブ化**:
     - プロファイル新規作成の成功時、作成されたプロファイルを自動的にアクティブ状態（選択タブ）にする。
     - これに伴い、保存されているアクティブプロファイルIDも新規プロファイルIDに更新される。

#### Acceptance Criteria (AC)
- [ ] AC-1: プロファイルタブを切り替えた際、切り替え先のアクティブなプロファイルIDが `localStorage` 等に保存されること。
- [ ] AC-2: ページをリロードした際、最後に `localStorage` に保存されていたアクティブプロファイルが自動的に選択された状態で画面が表示されること。
- [ ] AC-3: `localStorage` に保存されたIDに該当するプロファイルが存在しない場合（削除等）、フォールバックとして先頭のプロファイルが自動的に選択されること。
- [ ] AC-4: プロファイルを新規作成した際、作成成功後に作成された新規プロファイルが自動的にアクティブタブとして選択され、表示が切り替わること。
- [ ] AC-5: 新規作成による自動選択時にも、選択された新規プロファイルIDが `localStorage` 等に保存されること。
