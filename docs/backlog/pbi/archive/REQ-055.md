### REQ-055: Generateページ マルチセット一括生成

- **Type**: enhancement
- **Status**: ready
- **Current step**: none
- **Priority**: P2
- **Surface**: ワークフローに対し、複数のプロンプト・パラメータ設定（セット）をタブ的に切り替えて編集し、選択したセットをまとめて「セット数×セットあたりバッチ数」で一括生成したい。従来の単セット生成（current表示中セットのみ）も維持したい。
- **Root Cause**: Generateページの状態（`paramValues`/`appliedAssets`/`seedMode`/`seed`）が単一構成しか持てず、衣装違い・構図違いなど複数バリエーションを生成する際に都度手動で設定を上書き・再生成する必要があり、作業効率が悪い。
- **Requirement**: ユーザーが複数の生成設定（セット＝プロンプト・パラメータ・適用アセット・Seedモードを完全に独立して保持）を作成・複製・編集でき、チェックボックスで選択した任意の複数セットを一括生成できる。一括生成は「失敗したセットのみスキップし、他は継続」する。
- **Design doc**: none（`/dev-design` で store 配列化リファクタと同一スコープで設計）

#### Acceptance Criteria (AC)
- [x] AC-1: プロンプト入力パネルの上部に、現在表示中のセットを示す軽量なセットチップ（番号/名前表示）が並び、クリックで表示中セットを切り替えられる。既存のMain/Face等フィールドタブは維持される
- [x] AC-2: 各セットは、プロンプト全フィールド・パラメータ・適用LoRA/TagSet・Seedモード/Seed値を、他のセットと独立して保持する
- [x] AC-3: 「+ 新規セット」操作で、現在表示中セットの内容を複製した新規セットが追加される
- [x] AC-4: 各セットチップにチェックボックスがあり、一括生成対象として選択/解除できる。「全選択」「全解除」操作が可能
- [x] AC-5: 各セットは「セットあたりのバッチ数」を個別に設定できる
- [x] AC-6: 「一括生成」実行時、選択された全セットが順次キュー投入され、各セットの結果が合計枚数（選択セット数×各セットのバッチ数）分生成される
- [x] AC-7: 一括生成中、あるセットの生成がエラーになった場合、当該セットのみ結果に反映されずスキップし、他の選択セットの生成は中断せず継続する
- [x] AC-8: サムネイルストリップの各画像に、生成元セットを識別できるバッジ（セット名）が表示される
- [x] AC-9: 従来通り「Generate Batch」ボタン単体で、currentで表示中の1セットのみを対象に単セット生成できる（チェックボックス選択状態に関わらず動作する）
- [x] AC-10: 「Save Snapshot」は変更なし。プレビュー中の1枚 of 画像と、その画像が属するセットのparamsのみを保存する
- [x] AC-11: セットの名称はユーザーが編集可能（自由入力テキスト）
- [x] AC-12: 本機能の対象範囲はデスクトップのみとする。モバイル（`/mobile`）は対象外とするが、セットのデータ構造（配列ベース）は将来モバイル簡易版を追加できる形で設計する
