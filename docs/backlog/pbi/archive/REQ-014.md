### REQ-014: 紐づきスナップショットを活用したアセットの自動・複数サムネプレビュー

- **Status**: done (2026-08-30)
- **Type**: enhancement
- **Priority**: P2
- **Current step**: Step 3
- **Surface**: LoRAやタグセットの手動サムネ登録は面倒で、視覚的な一覧性が低い。アセットと紐づいたスナップショットを、LoRA・タグセットカードのサムネイルとして自動表示する。複数ある場合はカード上で複数枚 of the preview (carousel) to make it look visually rich.
- **Root Cause**: LoRAやタグセットのアセット一覧カードにおいて、サムネイル表示はユーザーがアセット作成・編集時に手動で登録した単一の画像パスのみに依存している。サムネイルの手動登録は運用コストが高く、多くのカードがサムネイル未設定のデフォルト状態のままとなり、カード一覧としての視認性・デザイン性が大幅に損なわれている。
- **Requirement**:
  - LoRAカードやタグセットカードを表示する際、手動サムネイルの有無に関わらず、そのアセット（LoRA ID / タグセット ID）と紐づいているスナップショット画像を自動的に検出・取得し、カードのサムネイルとして機能させる。
  - 紐づくスナップショットが複数ある場合、カード内にカルーセル等の表示UIを搭載し、カード上で複数枚の生成結果プレビューを切り替え表示できる、自動構築されるリッチなカタログUIを提供する。
- **Acceptance criteria**:
  - [ ] AC-1: LoRAおよびタグセットの取得API（`GET /api/loras`, `GET /api/tag-sets` 等）が、該当アセットが適用された状態で保存されたスナップショット画像パス（最新の複数件、上限5件程度）をメタ情報に含めて返すこと。
  - [ ] AC-2: LoRAカード・タグセットカードにおいて、手動サムネイル画像（`thumbnail_path`）が設定されていない場合、自動的に紐づいているスナップショットの第1画像をサムネイルとしてレンダリングすること。
  - [ ] AC-3: 紐づくスナップショットが複数（2枚以上）存在する場合、カード内にカルーセルUI（ホバーでの切り替え矢印、インジケーター等）が表示され、カードから離れることなくプレビュー画像を巡回できること。
  - [ ] AC-4: 紐づくスナップショットが全く存在しない、かつ手動サムネイルもない場合は、プレースホルダーとしてシステム既定の統一デザイン画像が表示されること。
- **Design doc**: none
