### REQ-177: タッチ操作時のタグチップ移動・並び替え不能不具合の解消

- **Status**: ready
- **Description**: タッチ操作端末において、タグチップエディタ（`TagChipEditor`）やその他 D&D 対応UI（`PresetManagerPanel`, `TagsPage`, `LoRAsPage`, `HistoryPage`, `SettingsPage`）の `TouchSensor` に設定された `activationConstraint: { distance: 5, tolerance: 5 }` が原因で、ドラッグ開始前に即時キャンセルされる不具合を解消する。

#### Acceptance Criteria (AC)
- [ ] AC-1: `TagChipEditor` のタグチップ（ドラッグハンドル等）をタッチ端末でドラッグした際、即座にキャンセルされず正常に並び替え（D&D）操作が開始・完了できること。
- [ ] AC-2: `PresetManagerPanel`, `TagsPage`, `LoRAsPage`, `HistoryPage`, `SettingsPage` においても、タッチ操作でのドラッグ＆ドロップ並び替えが正常に機能すること。
- [ ] AC-3: PC（マウス操作）環境での既存のドラッグ＆ドロップ動作およびクリック/長押し等の各種操作が引き続き正常に動作すること。
- [ ] AC-4: ユニットテストおよびE2E/ブラウザテストがすべてパスすること。
