### REQ-065: 複数選択後のアクション（並び替え・一括編集・マッピングマスタ並び替え）が機能しない問題

- **Type**: defect
- **Status**: done (2026-08-30)
- **Current step**: Phase 3: Walkthrough & SSoT Sync
- **Priority**: P1
- **Surface**: 複数選択はできるが、選択後のアクションができない
- **Root Cause**:
  1. 並び替えグループ移動: 選択されたカードをドロップした際、ドロップ先のカード自身が選択されていると `nonSelected.findIndex` が `-1` を返し、挿入位置が先頭（0）になってしまう問題。および上下移動のオフセット判定不備。
  2. 一括編集: フロントエンドから部分的な更新オブジェクトを送信しているのに対し、バックエンドの `PUT` APIは必須フィールドを含めたフルモデルスキーマを要求しているためのスキーマ不一致。
  3. マッピングマスタ並び替え: 複数選択時に `useSortable` で並び替えが無効化（`disabled: isMultiSelectMode`）され、さらにグリップアイコンが非表示にされドラッグできない問題。
- **Requirement**: 複数選択中のアイテムのドラッグ並び替えと一括編集が正常に動作し、かつマッピングマスタも複数選択中にグリップアイコンを使用して並び替えができること。
- **Acceptance criteria**:
  - [x] AC-1: LoRAページ / Tagセットページで複数選択時にカードをドラッグした際、選択したアイテム全体が直感通りのドロップ位置に順序正しく移動し保存されること。（選択中のカード上にドラッグドロップしても先頭に誤ジャンプしないこと）
  - [x] AC-2: LoRAページ / Tagセットページ / 設定ページで複数選択したアイテムに一括編集モーダルから変更を適用した際、正しく反映されること。
  - [x] AC-3: 設定ページのマッピングマスタ管理で複数選択モードの時でも、グリップアイコンが表示されドラッグで並び替えができること。
