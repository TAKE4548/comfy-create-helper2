### REQ-004: 生成画面からワークフローのマッピングを再スキャン・手動修正して保存する機能

- **Status**: done (2026-08-26)
- **Type**: enhancement
- **Priority**: P1
- **Current step**: none
- **Surface**: ワークフロー登録後にマッピング（node_id↔役割）が誤っていた場合、UIから再スキャン・確認・修正・保存できる手段がない
- **Root Cause**: ワークフロー登録時のスキャンが不正確だった場合や、ワークフローJSONを後から差し替えた場合に、現在はUIから正しいマッピングに修正する手段が存在しない。データベースを直接操作するしか方法がなく、利便性・安全性ともに問題がある。
- **Requirement**:
  1. 生成画面のワークフロー選択ドロップダウン横に「再スキャン」ボタンを追加すること。ワークフロー未選択時は無効化すること。
  2. ボタン押下時、選択中のワークフローJSONを既存の `/api/workflows/scan` APIで再スキャンし、結果（検出されたnode_idと役割の対応一覧）をモーダルダイアログで表示すること。
  3. モーダル内で各マッピング（node_id・役割・param_name）を確認でき、ドロップダウンによる役割の変更、または行の削除が手動で行えること。
  4. スキャンで見つからなかった役割（warnings）もモーダルに表示し、ユーザーが任意でnode_idを手動入力して追加できること。
  5. 「確定」ボタン押下で `PUT /api/workflows/{id}` を呼び出し、既存マッピングを全て削除したうえで新しい内容で上書き保存すること。
  6. 「キャンセル」ボタンまたはモーダル外クリックで変更なくモーダルを閉じられること。

#### Acceptance Criteria (AC)
- [x] AC-1: 生成画面のワークフロー選択ドロップダウン横に「再スキャン」ボタンが表示され、ワークフローが選択されていない場合は無効化（disabled）されていること。
- [x] AC-2: 「再スキャン」ボタン押下時、`POST /api/workflows/scan` が呼び出され、スキャン結果（matchedリストとwarningsリスト）がモーダルダイアログに表示されること。
- [x] AC-3: モーダル内の各matchedアイテムにて、node_id・役割（Roleドロップダウン）・param_nameが表示され、ドロップダウンで役割を変更できること。また行を削除してマッピングから除外できること。
- [x] AC-4: warningsリスト（スキャンで未検出の役割）もモーダルに表示され、ユーザーが手動でnode_idを入力して追加マッピングとして指定できること。
- [x] AC-5: 「確定」ボタン押下で `PUT /api/workflows/{id}` が呼び出され、マッピングが上書き保存されること。成功後はモーダルが閉じ、生成画面の入力欄が正しく再描画されること。
- [x] AC-6: 「キャンセル」ボタンまたはモーダル外クリックでモーダルが閉じ、DBへの変更が行われないこと。
