### REQ-080: 新規プロファイル作成時にワークフローのデフォルト設定を選択すると全パラメータが空欄になる問題の修正

- **Status**: done (2026-08-30)
- **Description**: 新規プロファイル作成（Add Set）モーダルにて、「ワークフローのデフォルト設定」を選択して作成した際、プロファイルのパラメータ（`paramValues`）および適用アセット（`appliedAssets`）が全て空欄（`{}`）になってしまうバグを修正する。ワークフロー定義から得られるデフォルトのパラメータおよび適用アセットを設定するように修正する。

#### Acceptance Criteria (AC)
- [ ] AC-1: `useWorkflowParams.ts` から `getInitialParams` 関数をエクスポートする。
- [ ] AC-2: `useGeneratePageState.ts` の `handleCreatePreset` 内で、「ワークフローのデフォルト設定」が選ばれた場合に、空の `{}` ではなく `getInitialParams(workflow)` を用いて初期パラメータを取得し、適用アセットも `workflow.default_applied_assets` から復元して設定する。
- [ ] AC-3: 作成された新規プロファイル（セット）を選択した際、正しく初期値が入力欄および適用アセットに反映される。
- [ ] AC-4: 既存のテストおよび新規に追加する単体テストがすべて合格すること。
