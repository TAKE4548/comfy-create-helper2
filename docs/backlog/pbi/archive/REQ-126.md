### REQ-126: パラメータ同期グループ設定と主従ノード項目連動機能

- **Type**: enhancement
- **Status**: ready
- **Priority**: P2
- **Surface**: パラメータ（CFGやSchedulerなど）を複数のノードで同じ設定にする際、現状はそれぞれのノードの項目を手動で同じ値に変更する必要があり手間がかかる。あえて別設定にするケースもあるため、個々のノードマッピング状態は保持しつつ、特定のパラメータを主従関係で同期できるセットを登録・アクティブ化/非アクティブ化できるようにしたい。
- **Root Cause**: 複数ノード間におけるパラメータ項目の主従同期グループ（Master-Slave Sync Group）定義および実行時連動の仕組みが存在しないため。
- **Requirement**: 
  1. 主項目（Master）1つと従項目群（Slaves）で構成されるパラメータ同期セットを管理（作成・編集・削除）する専用モーダル画面を提供する。
  2. メイン画面/設定画面上に同期セットごとの有効/無効を切り替えるトグルスイッチ（Bypass設定と同等のUIスタイル）を提供する。
  3. 同期セットが有効（Active）の場合、従項目群の入力欄は画面上で無効化（グレーアウト）され、見た目上はその時点の設定値を維持しつつも、生成実行時には主項目の最新値が送信される。
  4. 同期セットが無効（Deactive）の場合、従項目群の入力欄は有効化され、従来通り各ノード個別のパラメータ設定・編集が可能となる。

#### Acceptance Criteria (AC)
- [ ] AC-1: パラメータ同期セット管理モーダルから、主項目（1項目）と同一型の従項目群（複数項目）を指定した同期セットの追加・編集・削除ができること。
- [ ] AC-2: Bypass設定に準拠したUIセクションで、各同期セットのActive/Deactiveをトグルスイッチにより個別に切り替えられること。
- [ ] AC-3: 同期セットがActiveな場合、UI上の従項目入力欄がグレーアウト（手動編集不可）となり、生成実行要求時に従項目のパラメータ値が主項目の現在値に動的に置き換わって送信されること。
- [ ] AC-4: 同期セットをDeactiveにした場合、従項目のグレーアウトが解除され、同期有効化前の個別設定値（または最新の入力値）をそのまま編集・維持できること。
