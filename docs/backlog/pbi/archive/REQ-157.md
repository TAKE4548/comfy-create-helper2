### REQ-157: 生成画面の各設定セクション（Parameters, ParamSync, Bypass等）の折りたたみ対応

- **Type**: enhancement
- **Status**: ready
- **Priority**: P2
- **Surface**: 現在の生成画面にプロンプト・パラメータ・ParamSync・Bypassのセクションがあるが、プロンプトエリア以外も折りたたみを可能にしたい。特にモバイルモードで多いが、編集するときにパラメータはいじらず、プロンプトとBypassだけ調整してTry&Errするときに移動が多くて大変な為。
- **Root Cause**:
  - 生成画面における各設定セクション（Parameters, ParamSync, Bypass 等）において個別折りたたみに対応していないセクションが存在するため、特定のコントロール（PromptとBypassなど）のみを集中的に調整・試行錯誤したい場合に、不要なセクションが画面縦幅を占有し、頻繁なスクロール移動が発生して操作効率が低下している（Interaction Friction）。
- **Requirement**:
  1. 生成画面の各設定セクション（Parameters、ParamSync、Bypass 等）を個別に折りたたみ（Collapse）・展開（Expand）可能にする。
  2. 各セクションのヘッダーをクリック/タップすることで、ワンアクションでコンテンツの表示/非表示を切り替えられるようにする。
  3. モバイル画面・デスクトップ画面の双方で省スペース化と素早いアクセスを両立できるようにする。
  4. セクションの開閉状態（折りたたみ状態）を保持し、操作中や再訪時にも好みのワークスペース構成を維持できるようにする。

#### Acceptance Criteria (AC)

##### 1. 各セクションの個別折りたたみ・展開
- [ ] AC-1-1: 生成画面の「Parameters」「ParamSync」「Bypass」（および対象の関連セクション）に、折りたたみ/展開を切り替えるトグル操作が備わっていること。
- [ ] AC-1-2: 折りたたみ操作を実行すると対象セクションの内部コントロールが非表示になり、セクションヘッダーのみのコンパクトな表示となること。
- [ ] AC-1-3: 展開操作を実行すると対象セクションの内部コントロールが再び表示され、正常に設定変更・操作ができること。

##### 2. モバイル・デスクトップでの操作性と視認性
- [ ] AC-2-1: モバイル端末・狭小幅画面において、不要なセクション（例: Parameters）を折りたたむことで、PromptとBypass間のスクロール移動距離を大幅に削減できること。
- [ ] AC-2-2: 各セクションの折りたたみ状態（開いているか閉じているか）が視覚的に明確に判別できること（アイコンや矢印等のインジケータ）。

##### 3. 開閉状態の永続化・保持
- [ ] AC-3-1: ユーザーが設定した各セクションの開閉状態（折りたたみ/展開）が保持され、生成実行や画面切り替え時等にも意図せずリセットされないこと。
