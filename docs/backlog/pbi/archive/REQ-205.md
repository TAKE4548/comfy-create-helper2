### REQ-205: セリフLLM変換の構造化出力・思考可視化および前回結果フィードバック付き再生成機能（思考漏れ防止・解釈/推論の補助情報表示・ダメ出し付きリトライ）
- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: Step 4: Verification Complete
- **Date**: 2026-08-30
- **Priority**: P2
- **Surface**:
  - セリフのLLM変換で、変換過程の思考が漏れ出たり、変換結果が期待に添わないケースが多い。
  - そのため、LLMの出力を構造化させ、パースしてセリフ部分を取り出すようにしたい。
  - また、ヒントの調整をしやすくするため、画像・ヒントテキストの解釈と、変換思考を補助情報として確認できるようにして、調整をかけやすくできるようにしたい。
  - 再生成で同じ結果が出てくる事も多いため、前回の変換結果とどこが意にそわないかを追加で指示に混ぜられるようにしたい。
- **Root Cause**:
  - **Information Design (Unstructured Output & Concealed Reasoning State)**: LLMの出力形式がプレーンテキストであり思考過程と出力セリフが未分離なため、思考内容の吹き出しテキストへの混入（思考漏れ）が発生しやすい。また、LLMが入力画像や場面ヒントをどのように解釈し、なぜその口調を選択したかの推論・解釈情報がユーザーから不可視なブラックボックスとなっており、場面ヒントの調整方針を判断しにくい。
  - **Interaction Design (Regeneration Without Feedback Context)**: 再生成（リトライ）時に前回の変換結果に対する不満点や修正指示（ダメ出し）をフィードバックする入力機構が存在せず、同一または類似した期待に添わない結果が繰り返されてしまう対話的微調整の摩擦が存在する。
- **Requirement**:
  - セリフLLM変換（単体変換・一括バッチ変換）において、LLMの出力を構造化フォーマット（または明確なタグ付け）で受け取り、思考過程・場面解釈と最終的なセリフ本文を分離・パースして、吹き出しには思考が混入しないクリーンなセリフのみを反映できるようにすること。
  - LLMが画像・場面ヒントテキストから読み取った「状況・表情の解釈」および「セリフ変換の思考・推論過程」を補助情報・診断情報としてUI上で閲覧・確認可能にし、場面ヒントやプロンプトの調整を支援すること。
  - セリフの再生成時に、直前の変換結果に対する「意にそわない点」や「追加の修正指示・ダメ出し」を入力できるようにし、前回の変換結果とユーザーのフィードバックをコンテキストとしてLLMへ渡して、不満点を解消したセリフを再生成できるようにすること。
  - セリフ変換用のシステムプロンプトを設定画面（SettingsPage）で調整可能にしつつ、構造化出力タグなどのシステム必須指示はバックエンドで自動埋め込み・保護される構成とすること。
  - LLMの応答が構造化タグ形式に違反していた場合、即時フォールバックするのではなく、フォーマット違反の指摘を含めた自動リトライ（最大2回等）を行い、それでも違反する場合に安全にフォールバックすること。
  - 思考補助情報の表示や修正指示付き再生成はスムーズに統合され、修正指示なしでの通常の再生成や初回変換、一括変換時にも破綻なく直感的に利用できること。
- **Acceptance criteria**:
  - [x] AC-1: セリフLLM変換実行時に、LLMからの応答が構造化されてパースされ、思考過程や状況解釈が混入することなく、最終的なセリフ本文のみが対象吹き出しテキストに正確に反映されること。
  - [x] AC-2: 単体セリフ変換および一括変換において、LLMによる「画像・場面ヒントの解釈内容」および「変換思考・推論」を補助情報（診断情報）としてUI上で確認・展開表示できること。
  - [x] AC-3: セリフの再生成（リトライ）操作において、前回の変換結果に対する「意にそわない点・追加修正指示（ダメ出し）」を入力できる領域が提供され、そのフィードバックを反映した再生成が実行できること。
  - [x] AC-4: 修正指示が未入力の場合や初回生成時でも、従来のパラメータ（画像・ヒントテキスト・口調プリセット等）に基づいて正常にセリフ変換・再生成が完了すること。
  - [x] AC-5: 一括変換（バッチ処理）のジョブ結果においても各画像ごとの解釈・思考情報が保持され、一括結果一覧または個別画像の再生成時において思考の確認や個別フィードバック付き再生成が行えること。
  - [x] AC-6: 設定画面（SettingsPage）の「LLM System Prompts」一覧にセリフ口調変換用のシステムプロンプト項目が提供され、内容の調整・保存ができること。かつ構造化出力タグの必須指示はシステム側で自動付加されて機能が保護されること。
  - [x] AC-7: LLM出力が指定タグ形式を満たさない場合に、タグ形式違反を指摘した自動再送（リトライ）が実行され、規定回数以内に構造化出力を得られた場合は正常にパース完了すること。また最大リトライ後もタグが得られない場合は安全にフォールバックすること。
