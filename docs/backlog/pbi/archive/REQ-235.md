### REQ-235: 未カバー画面・主要モーダルのテスト新設 (Phase 2)

- **Type**: enhancement
- **Status**: done (2026-09-09)
- **Current step**: Phase 4: Implementation & Verification
- **Priority**: P2
- **Surface**:
  - `LoRAsPage.tsx` および `TagsPage.tsx` の画面統合テストが0件であり、また `LoraModals.tsx`, `TagSetModals.tsx`, `CategoryManagerModal.tsx`, `BypassSettingsModal.tsx`, `ParamSyncModal.tsx` 等の主要モーダルコンポーネントに対する統合テストが未作成となっている。
  - 画面全体の描画やフィルタリング複合条件、一括操作、モーダル内の動的リスト追加・削除などのUIインタラクションに対する自動テストが存在せず、リファクタリングや機能追加時のデグレ検出が手動確認に依存している。

  - `TagsPage` のコンポーネント統合テストを新設し、タグセット一覧描画、絞り込み、複数選択・D&D並び替え呼び出しを検証する。
  - 主要モーダル（`LoraModals`, `TagSetModals`, `CategoryManagerModal`, `BypassSettingsModal`, `ParamSyncModal`）の統合テストを新設し、入力・自動補完・動的追加/削除・ストア同期等の各フローを検証する。
  - 前提: REQ-234（Phase 1: MSW v2基盤）を利用してAPI通信をモックする。
