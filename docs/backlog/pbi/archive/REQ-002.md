### REQ-002: LoRA情報の編集機能

- **Status**: done (2026-08-30)
- **Type**: enhancement
- **Priority**: P2
- **Current step**: none
- **Surface**: LoRA管理画面で登録済みのLoRA情報を編集したい
- **Root Cause**: 現在のLoRA管理画面では、一度登録したLoRAのメタデータ（名前、トリガーワード、推奨ウェイト、説明など）を後から編集する機能が存在せず、誤って登録した場合や設定を調整したい場合に再登録やデータベースの直接編集が必要となり、利便性が著しく低い。
- **Requirement**:
  1. LoRA管理画面（一覧）において、登録済みの各LoRAに対して「編集」アクションを提供すること。
  2. 編集ボタンを押した際、対象のLoRA情報が入力された状態で編集モーダル（ポップアップ）が表示されること。
  3. モーダル内で「名前」「トリガーワード」「推奨ウェイト」「説明（メモ）」を編集し、保存できること。
  4. 過去の生成履歴データは変更せず、今後の新規生成や編集時のみ新しい設定値を適用すること。
- **Acceptance criteria**:
  - [ ] AC-1: LoRA管理画面（一覧）の各項目に「編集」ボタンが表示され、クリックすると編集モーダルが表示されること。
  - [ ] AC-2: 編集モーダルには、対象LoRAの「名前」「トリガーワード」「推奨ウェイト」「説明（メモ）」が初期値として入力されていること。
  - [ ] AC-3: モーダルで「保存」を押した際、適切なバリデーション（名前の必須チェック、推奨ウェイトの数値チェックなど）を行い、API経由でデータベースのLoRA情報が更新されること。
  - [ ] AC-4: 更新が成功した際、モーダルが閉じ、一覧の表示が最新情報に更新されること。
  - [ ] AC-5: モーダルで「キャンセル」を押した、またはモーダル外をクリックした場合は、データは更新されずにモーダルが閉じること。
  - [ ] AC-6: LoRA情報を更新しても、過去にそのLoRAを使用して生成された履歴データが保持する情報には影響を与えないこと。
- **Design doc**: none
