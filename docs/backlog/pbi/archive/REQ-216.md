### REQ-216: モバイルモードにおけるセリフ一括変換モーダル下部被り解消および履歴ヘッダーレスポンシブレイアウト修正（根本対策導入版）
- **Type**: bugfix / architecture-enhancement
- **Status**: done (2026-08-30)
- **Current step**: Phase 1: Requirement Analysis
- **Priority**: P1
- **Surface**:
  - `frontend/src/components/common/Modal.tsx` (新規): 共通モーダルラッパーコンポーネント。`.modal-backdrop` クラス（`z-index: var(--z-modal)` [100]、モバイル下部ナビセーフエリアパディング）、Escキーハンドリング、背景クリックハンドリング、内部伝播防止を一元管理。
  - `frontend/src/components/common/PageHeader.tsx` (新規): 共通レスポンシブページヘッダーコンポーネント。ヘッダーの `flex-wrap` や余白・アクション配置を共通化。
  - `frontend/src/components/BatchSpeechTransformModal.tsx`: モーダル外枠に共通 Backdrop 規約を適用し、モバイルボトムナビとの重なりを解消。
  - `frontend/src/pages/HistoryPage.tsx`: ヘッダーにレスポンシブ構造を適用し、モバイル幅でのアルバム遷移ボタン（Albums タブ）のはみ出しを解消。
- **Root Cause**:
  - **Lack of Reusable Component Primitives**: 共通モーダルラッパーおよび共通ヘッダーコンポーネントが存在せず、各画面で `fixed inset-0 z-50` や固定幅 `flex` を手動記述していたため、新機能追加時に不整合・オーバーフローが発生していた。
- **Requirement**:
  - 共通 `<Modal>` および `<PageHeader>` コンポーネントを新設し、モーダルおよびヘッダーのレスポンシブ・スタッキング規約を根本的に統一すること。
  - `BatchSpeechTransformModal.tsx` および `HistoryPage.tsx` に適用し、モバイル表示時の操作不能・はみ出しバグを完全解消すること。
- **Acceptance criteria**:
  - [x] AC-1: 共通 `<Modal>` コンポーネントが `.modal-backdrop`（`z-index: var(--z-modal)` [100]、モバイル下部ナビパディング）を適用し、Esc/背景クリック/イベント伝播防止を担保すること。
  - [x] AC-2: 共通 `<PageHeader>` コンポーネントが `flex-wrap` とレスポンシブ余白を提供し、要素のはみ出しを防止すること。
  - [x] AC-3: モバイル画面幅（< 1024px）において、「セリフ一括変換」モーダルがボトムナビの前面に表示され、下部アクションボタンが完全に操作可能であること。
  - [x] AC-4: モバイル画面幅（375px〜414px）において、履歴ページのヘッダー要素（Albums タブ含む）が画面外にはみ出さず正常にタップ・遷移できること。
  - [x] AC-5: デスクトップ表示（>= 1024px）において、既存のレイアウトやモーダル表示に崩れ・デグレが発生しないこと。
