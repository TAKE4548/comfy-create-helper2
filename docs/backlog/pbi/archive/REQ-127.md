### REQ-127: ComfyUI自動取得でcomboパラメータがtext認識される問題の修正

- **Type**: bug-fix
- **Status**: ready
- **Priority**: P2
- **Parent**: REQ-124
- **Surface**: `ParamTypeMasterModal.tsx` の ComfyUI 自動取得機能

- **Root Cause**:
  `paramList` が `Object.keys(targetNode.inputs)` で構築されており、ワークフローJSONの `inputs` にはウィジェットパラメータとリンク接続パラメータ（`model: ["4", 0]` 等）が混在している。ユーザーがリンク接続パラメータを選択して自動取得を実行すると、object_info が `"MODEL"`, `"CONDITIONING"` 等を返すため combo 検出に失敗し、フォールスルーで `widget_type: 'textarea'` が設定される。

- **Requirement**:
  1. `paramList` からリンク接続パラメータ（JSONで配列値のもの）を除外し、ウィジェットパラメータのみ表示する。
  2. または、ComfyUI の `object_info` を直接参照して paramList を構築し、全ての combo パラメータを正確に表示・自動検出できるようにする。
  3. パラメータ選択時に object_info から即座にタイプ情報を表示する UX を検討する。

#### Acceptance Criteria (AC)

- [ ] AC-1: `paramList` にリンク接続型パラメータ（`model`, `positive`, `negative`, `latent_image` 等）が表示されないこと。
- [ ] AC-2: ComfyUI サーバー接続時、`sampler_name` や `scheduler` 等の combo パラメータを選択して自動取得を実行すると、`widget_type: 'select'` かつ選択肢が正しく設定されること。
- [ ] AC-3: ComfyUI サーバー未起動時は、`paramList` が空になるか、ワークフローJSONから取得したウィジェットパラメータのみ表示されること。

#### 調査根拠

- **インシデントレポート**: `incident_report.md`
- **影響ファイル**: `frontend/src/components/ParamTypeMasterModal.tsx` L82-87（paramList）、L120（combo検出）
- **正常動作確認**: `handleAutoFill` の `Array.isArray(entry[0])` 判定は正しく実装済み。問題は paramList の仕様設計。
