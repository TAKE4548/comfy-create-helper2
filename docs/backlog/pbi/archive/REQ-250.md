### REQ-250: プリセット一括編集適用時におけるアクティブプリセットおよび開いているタブセットのプロンプトチップ同期適正化

- **Type**: bugfix
- **Status**: done (2026-09-12)
- **Current step**: none
- **Priority**: P1
- **Surface**:
  - `frontend/src/pages/GeneratePage/hooks/usePresetState.ts` 内の `handleBulkEditApply` において、プリセットの一括編集を適用した際、一括編集の対象に現在アクティブなプリセットが含まれていても、プロンプトのチップ表示（`TagChipEditor`）や生成プロンプト（`getEffectiveParamValues`）に編集後のプロンプトが即時反映されない。
  - 別のプリセットタブを一度アクティブにしてから再度戻ると、`loadPresetData` が実行されて最新のプロンプトチップが読み込まれる。
  - また、一括編集対象に含まれる他の開いているタブ（`sets` 内のプリセット）のメモリ内データも同期されない。
- **Root Cause**:
  - `usePresetState.ts` の `handleBulkEditApply` でアクティブプリセットのローカル状態を更新する際、`paramValues` のみ更新し、UI表示および画像生成で最優先される `promptChips` のパースおよびストアへの設定（`setPromptChips` / `setAllPromptChips`）が欠落している。
  - 加えて `updateActiveSet` に `promptChips` が渡されておらず、開いているタブセットコレクション（`sets`）内の他の一括編集対象プリセットに対しても更新が伝播していない。
  - さらに `presetUpdatedAtRef` の先行代入により、サーバー最新値との自動同期エフェクト（`loadPresetData`）がバイパスされている。
- **Requirement**:
  - `handleBulkEditApply` において、一括編集適用後にアクティブプリセットのプロンプト文字列から `parseToChips` を用いて `promptChips` を構築し、Zustand ストアの `promptChips` および `activeSet` に即時反映すること。
  - 開いている全タブ（`sets`）のうち一括編集の対象となったプリセットについても、`paramValues`, `appliedAssets`, `batchSize`, `promptChips` 等の最新状態を同期更新すること。
  - `TagChipEditor` のチップ表示および画像生成時のプロンプト（`getEffectiveParamValues`）が一括編集完了直後に即座に最新状態となり、プリセット再選択を必要としないこと。
- **Acceptance criteria**:
  - [x] AC-1: アクティブプリセットを含む複数プリセットを一括編集（プロンプトの追加・置換・削除）した直後、GeneratePage の `TagChipEditor`（チップ表示）に編集後のプロンプトが即時反映されていること。
  - [x] AC-2: 一括編集直後に「生成」ボタンを押下した際、`getEffectiveParamValues()` によって一括編集後の最新プロンプトで生成リクエストが送信されること。
  - [x] AC-3: 一括編集対象となった他の開いているタブ（`sets`）についても、タブ切り替え時に編集前の古いプロンプトやチップが残存せず、編集後の最新状態が維持されていること。
  - [x] AC-4: `useGeneratePageState.test.tsx` および `multiSetSlice.test.ts` に一括編集時の一連のチップ同期テストが追加され、全テストがパスすること。
