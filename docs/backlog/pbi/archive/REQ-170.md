### REQ-170: 吹き出し自体の回転および吹き出し複製・コピー機能

- **Type**: enhancement
- **Status**: done (2026-08-26)
- **Current step**: Step 3 (Design)
- **Priority**: P2
- **Surface**: セリフの修飾で、吹き出し自体の回転と、吹き出し自体のコピーができるようにしたい。SE系の吹き出しは、同一の内容を複数配置したいことがあるため、任意の吹き出しをコピーできると作業性が上がる。
- **Root Cause**: 現状のセリフ編集機能では吹き出し全体の回転制御および既存吹き出しの複製（コピー＆ペースト）操作が存在せず、SE（効果音）などの同一テキスト・スタイルの吹き出しを複数配置する際やダイナミックな角度表現を行う際に、毎回新規作成と同一設定の再入力を繰り返す必要があり作業負荷が高い。
- **Requirement**: セリフ編集画面において、選択中の吹き出し全体（形状・テキスト・装飾）を指定角度に回転できる機能、および選択中の吹き出しをワンアクションで複製（スタイル・テキスト・サイズ・回転状態を完全引き継ぎ）できる機能を提供する。
- **Design doc**: docs/design/REQ-170.md

#### Acceptance Criteria (AC)

##### 1. 吹き出し自体の回転機能 (Rotation)
- [ ] AC-1-1: 選択中の吹き出しに対して回転角度（角度指定スライダー / 数値入力、またはキャンバス上での直感的ハンドル操作）を設定・変更できること。
- [ ] AC-1-2: 吹き出しの回転が適用された際、吹き出し形状・内包テキスト（縦書き/横書き/エフェクト）・枠線・背景色が一体として指定角度でプレビューキャンバスに反映されること。
- [ ] AC-1-3: 画像保存（派生スナップショット作成）時にも、指定された回転角度が維持された状態で画像に合成描画されること。

##### 2. 吹き出しの複製・コピー＆ペースト機能 (Duplicate / Copy & Paste)
- [ ] AC-2-1: 選択中の吹き出しに対して、UI上の「複製」ボタン押下に加え、PCキーボード操作での `Ctrl+C`（コピー）および `Ctrl+V`（ペースト）による吹き出しのコピー＆ペーストが実行できること（※テキストエリア等の入力フォーカス時を除く）。
- [ ] AC-2-2: `Ctrl+C` でコピーされた吹き出し情報は内部クリップボードに保持され、複数回 `Ctrl+V` を押すことで同一吹き出しを連続ペースト配置できること。
- [ ] AC-2-3: 複製・ペーストされた吹き出しは、元の吹き出しのテキスト内容、形状、サイズ、装飾スタイル（フォント・文字色・背景色・枠線・効果等）、回転角度を完全に引き継いだ状態で生成され、一意な新規IDが割り振られること。
- [ ] AC-2-4: 複製・ペーストされた吹き出しは元の吹き出しと重なって見失わないよう適切なオフセット位置（例: +20px）に配置され、生成直後に自動的にフォーカス（選択状態）となって即座に移動・編集可能であること。

##### 3. メタデータ保存と再編集の整合性
- [ ] AC-3-1: 回転角度を含む複数配置・複製された吹き出し情報が、スナップショットメタデータ（`speech_bubbles`）に欠落なく保存されること。
- [ ] AC-3-2: セリフ保存済み画像から再度セリフ編集モーダルを開いた際、回転角度および複製された各吹き出しが元の状態のまま復元され、個別に再編集できること。
