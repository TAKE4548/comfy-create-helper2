### REQ-116: 生成画面へのAnima特化モード（リアルタイム双方向翻訳付き）の追加

- **Type**: enhancement
- **Status**: done (2026-08-26)
- **Current step**: none
- **Priority**: P2
- **Surface**:
  - 生成画面にAnima特化モードを追加したい。
  - Anima特化モードでは、プロンプトエリアのデフォルトモードをテキスト入力モードにする（手動でのタグチップモードとの切替は可能）。
  - 翻訳機能を追加し、プロンプトエリアでの入力内容を日↔英翻訳されるようにしたい。翻訳用のサブウィンドウが開かれ、入力中のプロンプトエリアの内容をリアルタイム翻訳し確認できる用にしつつ、サブウィンドウ側で入力すると逆翻訳されてプロンプトエリアに反映される。
  - 翻訳にはローカルLLM（LMStudioのAPIを想定）を使用し、使用するシステムプロンプト・モデルは設定画面で編集・選択できるようにしたい。
  - 任意に切り替えられるトグルボタンは用意する（ワークフロー選択の横など）が、ワークフロー自体にベースモデルの設定があるので、ページのロード時及びワークフローを切り替えた際、その設定がAnimaだったらAnimaモードにする。
  - 翻訳サブウィンドウはフローティングウィンドウのイメージ。
  - リアルタイム翻訳はデバウンスを挟む（デフォルトは一般的なWebの間隔とし、設定画面でミリ秒単位で調整可能にする）。
  - 接続先はBEと同じ端末前提で設定変更できなくてもよいが、モバイル端末などからFEを使うことはあるため、それが通るようにバックエンドプロキシ経由などでの接続を想定する。

- **Root Cause**:
  - 自然言語主体でプロンプトを入力するモデル（Anima等）において、従来のタグチップ形式がデフォルトだと入力操作に摩擦（Interaction Friction）が生じる。
  - 日英翻訳を外部サービスで行いコピペする作業によるコンテキストスイッチの手間。
  - クローズドな環境かつ個人の翻訳品質チューニングのために、ローカルLLM（LMStudio）をプロキシ経由で柔軟に活用したい。

- **Requirement**:
  - 生成画面での「Anima特化モード」トグルの提供、およびワークフローのベースモデル設定に基づく自動切り替えロジック。
  - モードON時にプロンプトエリアのデフォルトを入力テキストモードに切り替える処理。
  - ドラッグ移動等が可能なリアルタイム翻訳フローティングウィンドウのUI実装。
  - バックエンドを介したLMStudio API（OpenAI互換）との通信処理（日本語⇔英語の双方向翻訳）。
  - 設定画面における、翻訳用モデル選択・システムプロンプト編集・デバウンス間隔調整機能。

#### Acceptance Criteria (AC)
- [ ] AC-1: **Anima特化モードトグル**: 生成画面のワークフロー選択の横に「Anima特化モード」のON/OFFを切り替えるトグルボタンが表示されること。
- [ ] AC-2: **ベースモデル連動**: ページの初回ロード時およびワークフロー切り替え時、選択されたワークフローのベースモデルが「Anima」である場合はトグルが自動的にONになり、それ以外の場合は自動的にOFFになること。
- [ ] AC-3: **デフォルトモード制御**: Anima特化モードがONのとき、プロンプト入力エリアのデフォルト状態が「テキスト入力モード」になること。また、モードONの状態でも手動で「タグチップモード」に切り替え可能であること。
- [ ] AC-4: **フローティング翻訳ウィンドウ**: プロンプトエリア周辺に「翻訳ウィンドウ」を開閉するボタンがあり、開くと画面上にドラッグ移動が可能なフローティング形式のサブウィンドウが表示されること。
- [ ] AC-5: **リアルタイム翻訳（日→英）**: 翻訳ウィンドウが開いているとき、メインプロンプトエリアに入力すると、設定されたデバウンス時間（デフォルト設定値）の経過後にバックエンド経由でローカルLLMに翻訳リクエストが送信され、翻訳結果（英語）がサブウィンドウにリアルタイム反映されること。
- [ ] AC-6: **逆翻訳（英→日）**: 翻訳ウィンドウ内の入力エリアで直接テキストを入力・編集すると、設定されたデバウンス時間経過後に逆翻訳（英語→日本語）が実行され、結果がメインプロンプトエリアに反映されること。
- [ ] AC-7: **バックエンドプロキシ通信**: モバイル端末等からのアクセスに対応するため、フロントエンドから直接LMStudioに通信するのではなく、バックエンド（Python/FastAPI等）に設置した翻訳プロキシエンドポイントを経由してLMStudio API（OpenAI互換）を呼び出す構成になっていること。
- [ ] AC-8: **設定画面の追加**: 設定画面に「翻訳LLM設定（Animaモード用）」等のセクションが追加され、以下の項目を設定・保存できること。
  - 翻訳デバウンス間隔（ミリ秒単位。例: 300〜2000ms等の入力またはスライダー）
  - 使用するモデル名（LMStudioで起動しているモデルを指定する自由入力欄）
  - 日英翻訳用のシステムプロンプト（編集用テキストエリア）
  - 英日翻訳用のシステムプロンプト（編集用テキストエリア）
- [ ] AC-9: **設定の適用**: 設定画面で保存したデバウンス間隔やシステムプロンプト、モデル名が、実際の翻訳および逆翻訳機能の動作に正しく適用されること。
