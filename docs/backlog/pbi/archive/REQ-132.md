### REQ-132: 画像保存のWebP化・サムネイル軽量化・ダウンロード形式選択および既存画像マイグレーション機能

- **Status**: ready
- **Description**: アプリ内のストレージ消費削減および一覧表示・サムネイル読み込みパフォーマンス向上のため、アプリ保存画像をWebP形式へ統一圧縮し、サムネイル用低解像度画像の分離生成、ダウンロード時の形式変換機能、既存データのマイグレーション機能を提供する。

#### Acceptance Criteria (AC)
- [ ] **AC-1 (WebP自動変換)**: アプリ内で生成・保存される元画像は、品質を保持しつつWebP形式に自動変換・圧縮されて保存されること。
- [ ] **AC-2 (サムネイル分離化)**: 各種一覧画面・サムネイル表示用として軽量な低解像度サムネイル画像が別途生成・保存され、プレビュー・拡大表示時のみ高解像度元画像が使用されること。
- [ ] **AC-3 (ダウンロード形式選択)**: 画像ダウンロード時に、ユーザーが任意のエクスポート形式（PNG / JPEG / WebP 等）を選択して変換ダウンロードできること。
- [ ] **AC-4 (既存画像マイグレーション)**: 既存の保存画像を一括でWebP化およびサムネイル生成するマイグレーション機能（スクリプト/処理）が正常に完了できること。
