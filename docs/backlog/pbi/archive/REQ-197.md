### REQ-197: サムネイルのアスペクト比設定およびパン・ズームクロップ調整機能
- **Type**: enhancement
- **Status**: done (2026-08-29)
- **Current step**: Phase 2: Detailed Design (Approved)
- **Priority**: P2
- **Surface**:
  - 各所のサムネ表示が正方形だが、生成画像は縦長が多いので、サムネのアス比も縦長(3:4など)にしたい。
  - 生成する画像のアス比が異なる場合もあるので、クロップ範囲をD&Dで位置とズーム・パン調整もできるようにしたい。
  - 標準のアス比を設定画面側で調整できるようにし、ComfyUIでよく使う代表的なアス比の選択を基本に、任意の入力も可能とする。
- **Root Cause**:
  - UI全体のサムネイル表示（LoRA、タグセット、プリセット、ワークフロー、アルバム、スナップショット/ギャラリー等）が正方形（1:1）固定となっており、縦長画像等の被写体が見切れてしまう（Visual Design）。
  - サムネイル/カバー画像の表示位置・焦点（パン）や拡大率（ズーム）をインタラクティブに調整・保持する機能が存在しないため、任意の構図に合わせられない（Interaction）。
  - サムネイルのアスペクト比を用途に応じて変更するグローバル設定が存在しない（Information/Visual Design）。
- **Requirement**:
  - 設定画面において、サムネイルの標準アスペクト比を選択・カスタム入力できる設定項目を提供すること（代表的なプリセット: 1:1, 3:4, 4:3, 9:16, 16:9, 2:3, 3:2等 + 任意比率入力）。
  - アプリケーション全体（LoRA, タグセット, プリセット, ワークフロー, アルバム, ギャラリー等）のサムネイル表示が、設定されたアスペクト比に従って一貫して描画されること。
  - カバー画像やサムネイルの設定・編集時（詳細・編集モーダル等）に、ドラッグ＆ドロップによる位置調整（パン）および拡大縮小（ズーム）を行えるクロップ調整UIを提供し、調整結果（オフセット・ズーム値等）を保存・各サムネイル表示に反映できること。
- **Acceptance criteria**:
  - [ ] AC-1: 設定画面においてサムネイルの標準アスペクト比を変更でき、代表的なプリセット（1:1, 3:4, 4:3, 9:16, 16:9, 2:3, 3:2等）の選択および任意の比率（例: W:H）の入力・保存ができること。
  - [ ] AC-2: アプリケーション内のサムネイル表示（LoRA一覧、タグセット一覧、プリセット一覧、ワークフロー一覧、アルバム一覧、スナップショット/ギャラリー一覧等）が、設定されたアスペクト比に連動して表示されること。
  - [ ] AC-3: 詳細・編集モーダル等でサムネイル/カバー画像を設定・編集する際、ドラッグによる位置（パン）移動およびホイール/スライダー等によるズーム調整ができるクロップエディタUIが表示されること。
  - [ ] AC-4: クロップエディタで調整したパン（X/Yオフセット）およびズーム倍率が保存され、一覧やカード等のサムネイル表示時にそのクロップ・拡大状態が正しく反映されること。
  - [ ] AC-5: クロップ情報が未設定の既存画像や新規画像についても、設定アスペクト比の中央寄せ等で破綻なく表示されること。
