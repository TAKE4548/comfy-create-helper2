### REQ-285: SpeechBubbleEditorModal の Canvas 操作分離とセクション部品化

- **Type**: refactoring
- **Status**: done (2026-09-26)
- **Current step**: none
- **Priority**: P3
- **Surface**: プロジェクト最大規模のモーダル（SpeechBubbleEditorModal.tsx, 1,552行）に、30個超のState、約450行のマウス/タッチ座標計算（ROI・回転・ドラッグ・拡大縮小）、下書きAPI通信、保存バー、デバッグ候補表示が混在している（リファクタ計画 PBI-REF-04）。
- **Root Cause**: Canvasの対話的操作ロジック（座標変換、イベントリスナー、レンダリングループ）と、ビジネス操作（下書き保存、アルバム登録、候補フィルタリング）が同一コンポーネント内にインラインで実装されていること。
- **Requirement**:
  - Canvasのマウス・タッチ操作およびROI矩形計算を専用カスタムフック（`useBubbleCanvasInteraction.ts`）に分離する。
  - 画像合成・下書き生成・アルバム保存処理を永続化フック（`useSpeechBubblePersistence.ts`）に分離する。
  - Canvasビューポート、保存バー、候補デバッグテーブルをそれぞれ独立セクションへ部品化する。
  - 【目標構成】:
    ```
    frontend/src/components/SpeechBubbleEditorModal/
    ├─ index.tsx                         # モーダル枠・全体State統合（約150行）
    ├─ types.ts                          # 型定義（MobileTab, SpeechBubbleEditorProps等）
    ├─ hooks/
    │  ├─ useBubbleCanvasInteraction.ts  # Canvasマウス/タッチ操作・ROI描画（約450行）
    │  └─ useSpeechBubblePersistence.ts  # 画像合成・下書きAPI呼出・保存処理（約120行）
    └─ sections/
       ├─ CanvasViewportSection.tsx      # Canvas本体とROI選択オーバーレイ（約180行）
       ├─ BubbleSaveExportBar.tsx        # 下部保存バー（保存モード・アルバム選択）（約110行）
       └─ CandidateDebugDrawer.tsx       # 自動検出候補のフィルタ・ソートテーブル（約130行）
    ```
- **Acceptance criteria**:
  - [ ] AC-1: PCマウス操作およびモバイルタッチ操作で、フキダシの移動・拡大・回転・ROI選択が滑らかに正常動作すること。
  - [ ] AC-2: セリフ下書き生成およびスナップショット保存が正常に完了し、アルバムへ登録できること。
  - [ ] AC-3: `cd frontend && npm run typecheck`（tsc -b --noEmit）がエラー0件でPASSすること（REQ-001の型検査Gate 1）。
  - [ ] AC-4: `cd frontend && npx vitest run` で既存テストが全件PASSすること。
