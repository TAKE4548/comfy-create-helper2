### REQ-038: LoRAトリガーワードセットのCRUD管理機能追加

- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: none
- **Priority**: P2
- **Surface**: LoRA管理で、登録済みのトリガセットを編集する方法がないので追加したい。セットごとCRUD管理できるようにしたい。また、生成画面のプロンプト入力と合わせるため、タグチップへの変換形式がいい。
- **Root Cause**: LoRA登録・編集モーダルにおいて、トリガーワードセット（`LoraTriggerWordSet`）を新規追加、編集、削除するためのUIコントロールが実装されておらず、表示・編集が行えない。
- **Requirement**: LoRAの登録および編集モーダルにおいて、登録されているトリガーワードセットの一覧を表示し、動的にトリガーワードセットの追加・編集・削除ができるようにする。また、トリガーワードの入力・編集インターフェースには、生成画面と同様のタグチップ形式のエディタ（`TagChipEditor`）を使用する。
- **Acceptance criteria**:
  - [ ] AC-1: LoRA登録モーダルおよびLoRA編集モーダルに、トリガーワードセットを管理するセクションが表示されること。
  - [ ] AC-2: トリガーワードセットの「追加（新規作成）」ボタンがあり、クリックすると新しいトリガーワードセット（セット名入力欄とトリガーワード入力欄）が動的に追加されること。
  - [ ] AC-3: 各トリガーワードセットのトリガーワード入力欄に、タグチップ形式のエディタ（`TagChipEditor`）が適用されており、Enterやカンマで入力文字がチップ化されること。
  - [ ] AC-4: 各トリガーワードセットの右側に「削除」ボタンがあり、クリックするとそのセットがフォーム上から削除されること。
  - [ ] AC-5: 編集モーダルでトリガーワードセットの編集や追加・削除を行い、保存した際、データベースに変更内容が正しく同期・保存され、一覧や詳細モーダルに正しく反映されること。
- **Design doc**: none
