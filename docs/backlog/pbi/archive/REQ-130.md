### REQ-130: Add Set 実行時に追加されたセットがアクティブ化されないバグの修正

- **Status**: done (2026-08-30)
- **Description**: 生成画面のプロファイルタブ行にある「+ Add Set」から新規プロファイル作成モーダルを開き「作成」を実行した際、追加された新しいセットがアクティブ（選択状態）にならず、作成前の既存セットがアクティブなまま維持されてしまう不具合を修正する。

#### Acceptance Criteria (AC)
- [ ] AC-1: 「Add Set」モーダルで新規プロファイル（セット）を作成した直後に、追加されたセットが自動的にアクティブ状態（選択タブ）になり、フォームパラメータ値も新セットの値に即時同期されること。
- [ ] AC-2: presets の再取得（Query Invalidation 等）が発生した際、`localStorage` に保存されたアクティブIDが正しく優先評価され、新セットがアクティブのまま維持されること。
- [ ] AC-3: 既存のセット追加・切り替え・削除機能およびオートセーブ機能に副作用や回帰が発生しないこと。
