### REQ-115: 生成画面のLoRALoaderでのLoRA管理・タグセット管理に基づくフィルタと検索機能の実装

- **Type**: enhancement
- **Status**: ready
- **Current step**: none
- **Priority**: P2
- **Surface**: 生成画面のLoRALoaderの選択肢を、LoRA管理とタグセット管理の登録状況に基づくフィルタ・検索をかけられるようにしたい。
- **Root Cause**: 現状は全LoRAが出るため、ベースモデルに非対応のものも表示されたり、単純に数が多くて探すのが大変。
- **Requirement**: 生成画面のLoRALoaderにて、ドロップダウンの最上部にスクロール固定の検索・フィルタヘッダを設け、ベースモデル、カテゴリでのフィルタや、フリーワード（名称、パス、説明）での絞り込みを可能にする。
- **Acceptance criteria**:
  - [ ] AC-1: 生成画面のLoRALoaderの選択肢ドロップダウンの最上部に、スクロールしても位置が固定される検索・フィルタヘッダUIが表示されること。
  - [ ] AC-2: 検索・フィルタヘッダにて、ベースモデル（Base Model）によるフィルタができること。
  - [ ] AC-3: 検索・フィルタヘッダにて、カテゴリ（Category）によるフィルタができること。
  - [ ] AC-4: フリーワード検索入力エリアにテキストを入力した際、LoRAの「名称（name）」「モデルパス（path）」「説明（description）」のいずれかに部分一致するLoRAのみが絞り込まれて選択肢に表示されること。
- **Design doc**: none
