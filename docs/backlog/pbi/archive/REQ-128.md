### REQ-128: 吹き出しセリフ保存時の解像度低下・ガイドオーバーレイ混入バグ修正

- **Status**: done (2026-08-30)
- **Type**: Bug (Type A — Implementation)
- **対象ファイル**: `frontend/src/components/SpeechBubbleEditorModal.tsx`

#### 背景・問題

吹き出しセリフ編集モーダルで「保存して履歴へ追加」を実行すると、以下の2件のバグが発生する。

**Bug-1: 解像度低下**  
保存される画像が元画像の解像度ではなく、表示用キャンバスのサイズ（最大500×500px）に制限される。  
- 原因: `handleSave()` が表示用の縮小キャンバスを直接 `toBlob()` しているため。

**Bug-2: ガイドオーバーレイの混入**  
吹き出し検出ボーダー（緑枠）、デバッグ候補ボックス、ROI選択矩形など、編集時専用のUIガイドが保存画像に描き込まれる。  
- 原因: Drawループが全オーバーレイを同一の表示用キャンバスに描画しており、`handleSave()` がその全描画済みキャンバスから `toBlob()` しているため。

#### 修正方針

`handleSave()` 内でオフスクリーンキャンバスを生成する。
- キャンバスサイズ: `imageObj.naturalWidth × imageObj.naturalHeight`（元画像解像度）
- 描画内容: 背景画像 + セリフテキストのみ（ガイド類は一切描画しない）
- 座標計算: 元画像座標系（scaleX/Y不適用）でテキストを配置

#### Acceptance Criteria (AC)

- [ ] AC-1: 保存された画像の解像度が元画像（naturalWidth × naturalHeight）と一致すること
- [ ] AC-2: 保存された画像に吹き出し検出ボーダー（緑枠）が含まれないこと
- [ ] AC-3: 保存された画像にデバッグ候補ボックス（薄緑・赤の破線枠）が含まれないこと
- [ ] AC-4: 保存された画像にROI選択矩形が含まれないこと
- [ ] AC-5: セリフテキストは元画像の吹き出し領域（boundingBox座標）に正しく描画されること
- [ ] AC-6: フォントおよび縦書きレイアウトは元画像スケールで正しく機能すること
