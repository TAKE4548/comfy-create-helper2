### REQ-081: ワークフローアップロード時のノードIDマッピング機能の改善

- **Status**: done (2026-08-30)
- **Description**: ワークフローアップロード時のノードIDマッピングロジック、ドロップダウン表示、マッピングマスタの登録UIを改善し、複数候補が存在する場合の紐付けの正確性と登録時の利便性を向上させる。

#### Acceptance Criteria (AC)
- [ ] AC-1: **【情報設計】同目的の別名パラメータのマスタ管理**
  - パラメータマスタ等の設定において、パラメータ名としてカンマ区切り（例: `seed, noise_seed`）などで複数の候補を登録可能とする。
  - ワークフローアップロード時の探索処理において、アップロードされたノードのパラメータ名がマスタ側の候補名のいずれかに一致し、かつノードタイプが一致する場合にマッチ判定を行う。
- [ ] AC-2: **【インタラクション】マスタのコピー作成機能**
  - マッピングマスタの一覧画面の各行アクションに「コピーして新規作成」ボタンを追加し、既存レコードのデータを引き継いだ状態で新規作成フォームが開くこと。
  - 新規作成フォーム内にも「既存レコードからコピー（コピー元選択）」のドロップダウンを設置し、選択したレコードの内容がフォームに即座に反映されること。
- [ ] AC-3: **【インタラクション/情報設計】複数候補時のスマート初期値選択**
  - アップロードされたワークフローに同一タイプのノードが複数ある場合、マスタに登録されている「ノードタイプ」と「タイトル」の組み合わせが完全に一致し、一意のIDが特定できる場合は、そのIDを初期値として自動選択し、「複数候補」バッジを表示しない。
  - ただし、ノードタイプのみが一致する他のノードIDも、ユーザーが手動で変更できるようにドロップダウンの選択肢には含めておくこと。
- [ ] AC-4: **【情報設計】候補ドロップダウンの表示改善**
  - マッピング候補の選択ドロップダウンにおいて、選択肢の表示形式を「ID」のみから「ID - [タイトル] (ノードタイプ)」のように、ID・タイトル・ノードタイプをセットにした形式へ改善する。
- [ ] AC-5: **品質要件**
  - 変更前後の機能整合性を保証する自動テストまたは手動テストを行い、既存の動作が壊れていないこと。
