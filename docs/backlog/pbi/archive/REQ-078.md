### REQ-078: 全画面プレビュー機能の実装

- **Status**: done (2026-08-26)
- **Description**: モバイル（タブレット等を含む）端末におけるプレビュー画像の表示領域を最大化し、詳細を確認しやすくするため、ブラウザ標準の Fullscreen API を活用した完全全画面表示プレビュー機能を「一覧画面」および「生成画面」に導入する。

#### Acceptance Criteria (AC)
- [ ] AC-1: 通常プレビュー（モーダル）表示時に、画像をタップ/クリックすることでブラウザ標準の `Fullscreen API` を起動し、ブラウザUIやタスクバーを非表示にした完全全画面プレビューへ移行する。
- [ ] AC-2: 全画面プレビュー中も、全画面状態を維持したまま、左右スワイプやナビゲーション操作（キーボードの左右矢印等）でシームレスに前後の画像をめくることができる。
- [ ] AC-3: 全画面プレビュー中に閉じるボタンを押す、Escキーを押す、またはブラウザ標準の解除操作を行った場合、全画面表示を終了すると同時に、プレビューモーダルも閉じて元の画面（一覧画面/生成画面）に直接戻る。
- [ ] AC-4: 一覧画面と生成画面の両方において、同一の全画面切り替えおよび解除挙動が一貫して動作する。
- [ ] AC-5: モバイル・タブレット端末（タッチデバイス）でもアスペクト比を維持しつつ、画面内に最大限大きく画像が表示される（`object-fit: contain` 等）。
