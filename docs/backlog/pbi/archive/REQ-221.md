### REQ-221: REQ-220適用後の生成ページ無限再描画エラー（真っ黒画面）の解消

- **Type**: defect
- **Status**: done (2026-09-05)
- **Current step**: none
- **Priority**: P1
- **Surface**:
  - 生成ページが真っ黒の画面になる。サーバをrebootしても変わらない。req220をやって以降起きた。
- **Root Cause**:
  - `TagChipEditor` の `useEffect` 依存配列に `onChipsChange` が含まれており、親コンポーネント（`DesktopLayout` / `MobileLayout`）からインライン無名関数として渡されたコールバックがレンダー毎に新参照となるため、マウント時に Effect が発火して親ストアを更新し、親の再描画によってさらに新しいコールバックが渡されるという無限再レンダリングループ（`Maximum update depth exceeded`）が発生している。未捕捉の例外によってルートの React ツリー全体がアンマウントされ、ダーク背景のみの真っ黒画面となる。
- **Requirement**:
  - 生成画面および TagChipEditor が無限再レンダリングループを起こすことなく安定して描画され、プロンプトの編集や無効化タグ保持機能が正常に動作すること。
- **Acceptance criteria**:
  - [x] AC-1: 生成画面（`/`）にアクセスした際、画面が真っ黒にならず正常にUI（プロンプト入力欄、パラメータ設定パネル等）が表示されること。
  - [x] AC-2: 生成画面のプロンプト入力欄（TagChipEditor）において、タグチップの無効化・有効化、追加、削除等の操作を行っても画面クラッシュや無限ループが発生しないこと。
  - [x] AC-3: デスクトップ表示およびモバイル表示の両方において、プロンプトタブ切替やアコーディオン開閉を行っても生成画面が正常に表示・操作できること。
  - [x] AC-4: `src/pages/GeneratePage/components/__tests__/MobileLayout.test.tsx` などの回帰テストがエラーなくすべてパスすること。
- **Design doc**: docs/design/REQ-221.md
