### REQ-306: Animaモードにおけるタブ切替時のタグチップ結合状態先祖返り不具合の修正

- **Type**: bug
- **Status**: done (2026-10-02)
- **Current step**: none
- **Priority**: P1
- **Reference**: [docs/incident_report.md](../../../docs/incident_report.md)
- **UX Classification**:
  - **Interaction Design**: プリセットタブ切替や画面遷移復帰時におけるタグチップ状態および表示モード（チップ/テキスト）の整合性維持
  - **Information Design**: グローバルストア（useGenerationStore）とプリセット同期（usePresetStoreSync / multiSetSlice）における isAnimaMode 伝播とチップ構造保護
- **Surface**:
  - Animaモード（isAnimaMode: true）において、テキストモードからチップモードへ切り替えた際は正常にピリオド（.）区切りでタグチップが複数に分割されるが、プリセットタブ切替や画面遷移、別ブラウザタブ（ウィンドウフォーカス外れ）から復帰すると、分割されたタグチップが単一のチップに再結合（マージ）される、またはテキストモード（textarea）へ先祖返りしてしまう。
  - ピリオド区切りのタグ（例: `1girl.`）に対して強度指定を行うと、末尾のピリオドが括弧の内側に巻き込まれて `(1girl.:1.2)` となり、さらにピリオド終端判定が崩れて後続タグとの区切りが `, ` になって `(1girl.:1.2), ` のようにフォーマットされてしまう（本来は `(1girl:1.2). ` となるべき）。
- **Root Cause**:
  1. multiSetSlice.ts の loadPresetData (L312) で initialPromptChips を生成する際、parseToChips(val) に isAnimaMode が渡されておらず、通常モード（カンマ区切り専用）で再パースされ単一チップで sets および promptChips が上書きされる。
  2. useWorkflowManagement.ts で検知した isAnimaMode がフックローカルな useState に閉じており、useGenerationStore.setIsAnimaMode に同期されていないため、ストア内部の isAnimaMode が恒常的に false となっている。
  3. usePresetState.ts の一括編集 (L498, L523) でも parseToChips に isAnimaMode が渡されていない。
  4.  - DesktopLayout.tsx (L552) および MobileLayout.tsx (L614) において defaultTextMode が isAnimaMode に固定されており、コンポーネント再マウント時（キー変更やタブ切替）にユーザーのチップモード選択状態が破棄されテキストモードにリセットされる。
  5. useChipParser.ts の formatTagWeight においてベーステキスト末尾のピリオドが括弧内側に残存し、`(${baseText}:${weight})` となるため `(tag.:x)` が生成される。これによりチップ文字列がピリオド終端でなくなり、chipsToString で後続区切りがカンマ `, ` にフォールバックする。
- **Requirement**:
  - multiSetSlice.ts の loadPresetData において parseToChips 呼び出し時に isAnimaMode を渡し、Animaモード時はピリオド区切りによるタグチップ分割を正常に維持すること。また、既存の有効な promptChips が保持されている場合は不要に上書きしないこと。
  - useWorkflowManagement.ts およびUIのAnima切替処理から useGenerationStore.getState().setIsAnimaMode を呼び出し、ワークフローのモデル変更やユーザーの切替に応じてグローバルストアの isAnimaMode を常に最新状態に同期すること。
  - usePresetState.ts の parseToChips 呼び出し箇所にも isAnimaMode を伝播すること。
  - Animaモードを含む全モデルにおいて、初期表示のデフォルトをタグチップモード（defaultTextMode: false）に統一し、ユーザーが手動でテキストモードへ切り替えた場合はその選択状態をタブ切替や再マウントを跨いで維持すること。
  - Animaモード時およびピリオド付きタグの強度指定において、括弧の前に末尾ピリオドを除去し、括弧の外側にピリオドを付与した `(tag:x). ` 形式として正しくフォーマット・文字列化すること。
- **Acceptance criteria**:
  - [ ] AC-1: Given: Animaモードが有効であり、ピリオド区切りのタグチップ（例: 1girl., solo., red dress.）が設定されている / When: 別のプリセットタブ（Set 2 等）に切り替えた後、元のプリセットタブに戻る / Then: タグチップが単一チップに結合されず、元の分割された状態（3つのチップ）が維持されていること。
  - [ ] AC-2: Given: Animaモードが有効であり、ピリオド区切りのタグチップが設定されている / When: History画面など別画面へ遷移した後、Generate画面へ復帰する / Then: タグチップが単一チップに結合されず、分割されたチップ状態が維持されていること。
  - [ ] AC-3: Given: Animaモードが有効なワークフローが選択されている / When: グローバルストアのステートを確認する / Then: useGenerationStore.getState().isAnimaMode が true に同期されていること。
  - [ ] AC-4: Given: Animaモードのワークフローが選択された場合 / When: Generate画面が初期表示される、またはプリセットタブ切替や画面遷移が行われる / Then: デフォルトでタグチップモード（チップ表示）として表示され、ユーザーが手動でテキストモードへ切り替えた場合もその選択状態が維持されること。
  - [ ] AC-5: Given: 通常モード（非Animaモード）のワークフローが選択されている / When: プリセット読込やタブ切替が行われる / Then: 従来通りのカンマ区切り動作およびチップ復元が行われ、既存の動作に副作用を与えないこと。
  - [ ] AC-6: Given: Animaモード（`.`区切り）においてタグ（例: `1girl.` または `1girl`）に強度指定（例: 1.2）が適用された場合 / When: プロンプト文字列へ変換またはチップ表示が行われる / Then: `(1girl.:1.2), ` ではなく `(1girl:1.2). ` の形式で整形され、後続タグとの区切りも空白区切りとして維持されること。
