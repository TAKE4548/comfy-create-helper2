### REQ-006: LoRAのサムネイル画像登録・管理機能

- **Status**: done (2026-08-30)
- **Type**: enhancement
- **Priority**: P2
- **Current step**: none
- **Surface**: LoRAのサムネを登録する手段がない
- **Root Cause**: ユーザーがLoRAモデルのサムネイル画像を登録・管理するUIおよびAPIが存在しない。また、登録された画像を保存してLoRA情報と紐付けるストレージ設計がないため、一覧画面等でビジュアル的にモデルを識別することが困難になっている。
- **Requirement**:
  1. **サムネイル画像のアップロード/更新機能**:
     - LoRAモデルの登録モーダルおよび編集モーダル内に、サムネイル画像のアップロード領域を追加する。
     - アップロード領域は、ドラッグ＆ドロップとクリック（ファイルダイアログ）の両方に対応する。
     - 一般的な画像フォーマット（PNG、JPEG、WebP等）を受け付ける。
     - クロップ（切り抜き）は行わず、ファイルサイズ節約のためにアスペクト比を維持したまま最大解像度（例：長辺512pxなど）へのリサイズ処理を行って保存する。
  2. **ストレージとデータ紐付け**:
     - アップロードされたサムネイル画像ファイルは、モデルファイルディレクトリ（LoRAフォルダ）を汚さないよう、アプリケーション専用のストレージ領域に保存する。
     - データベース上の各LoRAレコードと保存されたサムネイル画像を紐付ける。
  3. **表示機能**:
     - LoRAの一覧画面（カード表示）や詳細表示にて、登録されたサムネイル画像を表示する。サムネイルが未登録の場合は、デフォルトのプレースホルダー画像を表示する。

#### Acceptance Criteria (AC)
- [x] AC-1: LoRA登録モーダルにおいて、ドラッグ＆ドロップまたはファイル選択によってサムネイル画像をアップロードできるUI領域が存在し、画像プレビューが表示されること。
- [x] AC-2: LoRA編集モーダルにおいて、ドラッグ＆ドロップまたはファイル選択によってサムネイル画像を新規アップロード・変更でき、既存のサムネイルのプレビューができること。
- [x] AC-3: PNG、JPEG、WebP形式の画像ファイルをアップロードした際、アスペクト比を維持しつつ長辺をリサイズ（例: 512px等）した状態で、ツール専用のストレージに保存されること。
- [x] AC-4: アップロードされたサムネイル画像の情報（ファイル名やパス等）が該当するLoRAモデルのデータと紐付けて保存・管理されること。
- [x] AC-5: LoRA一覧画面の各カードおよび詳細モーダルにおいて、登録済みのサムネイル画像が正しく表示されること。未登録の場合はプレースホルダー画像が表示されること。
- [x] AC-6: 編集モーダルにおいて、登録済みのサムネイル画像を削除（クリア）して未登録状態へリセットできる機能が提供されていること。
