### REQ-043: LoRA・タグセットの紐付け編集およびフィルタ機能

- **Status**: done
- **Description**: 保存済みのスナップショットに対して、関連付けられている LoRA およびタグセットを後から追加・削除（編集）できるようにするとともに、スナップショット一覧画面において紐付いている LoRA やタグセットによるフィルタリングを可能にする。

#### Acceptance Criteria (AC)
- [x] AC-1 (Backend - Patch API): スナップショットの関連情報（LoRA、タグセットのリレーション）を更新するためのエンドポイント `PATCH /api/snapshots/{snapshot_id}` を実装する。
  - リクエストボディで更新後の `lora_ids` (IDの配列) および `tag_set_ids` (IDの配列) を受け取り、既存のリレーションを安全に更新できること。
- [x] AC-2 (Backend - Filter API): スナップショット一覧取得 API `GET /api/snapshots` を拡張し、クエリパラメータとして `lora_id` (数値) および `tag_set_id` (数値) によるフィルタリングが行えるようにする。
- [x] AC-3 (Frontend - Relation Edit UI): 履歴 (History) 画面のスナップショット詳細表示（`HistoryModalPreview` 内）において、紐付いている LoRA とタグセットを後から編集（追加・削除）できるUIを提供する。
  - ユーザーは登録済みの LoRA やタグセットを選択して追加、または既存の紐付けを削除でき、保存ボタン等で変更が永続化されること。
- [x] AC-4 (Frontend - Filter UI): 履歴 (History) 画面のスナップショット一覧において、紐付いている LoRA またはタグセットでフィルタリングできるUI（フィルタ用プルダウンなど）を実装し、選択されたアセットが紐付くスナップショットのみを表示できるようにする。
- [x] AC-5 (Data Sync): スナップショットのリレーションが更新された後、LoRA管理画面やタグセット管理画面でのサムネイル表示が、更新後のリレーションに基づいて正しく同期・表示されることを確認する。
