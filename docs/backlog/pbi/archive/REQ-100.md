### REQ-100: 生成画面におけるプロファイルの自動保存とタブ管理の改善およびUndo/Redo機能の実装

- **Status**: done (2026-08-26)
- **Description**:
  生成画面におけるプロファイル（WorkflowPreset）の保存とタブ（Zustandストアの `sets`）の同期について、以下の問題を解消しUXを改善します。
  1. 個別の上書き保存ではなく自動セーブを基本とし、編集内容とプロファイルが常に一致する仕様とする。
  2. 端末切替時などに「タブ未選択状態での編集」ができてしまう状態を防ぎ、常に何かしらのプロファイルに紐付いて自動セーブされるようにする（存在しない場合はデフォルトプロファイルを自動生成する）。
  3. タブの「×」ボタンは「タブを閉じる（非表示にする）」だけであり、DBからの削除は行わない。閉じられたプロファイルは、生成ページのプロファイル選択リストから容易に再表示できるようにする。プロファイルの実削除はプロファイル一覧（プリセットマネージャーなど）からのみとする。
  4. 誤操作時の対応用に、タブ（プロファイル）ごとに独立したUndo/Redo機能（タブを切り替えて戻ってきても有効な履歴）を実装する。
  5. モバイルモードでも同様の挙動を保証し、デバイス間で無意識に最後の編集内容が自動同期されるようにする。

#### Acceptance Criteria (AC)
- [ ] AC-1: **タブの「閉じる」と「削除」の分離**
  - タブの「×」ボタンを押した際、DBからの削除は行わず、画面上（Zustand `sets` 及び UI）から非表示（閉じる）にするだけとする。
  - 表示中のタブ（開いているプロファイル）のIDリストは `localStorage` に保持され、リロード時や再訪問時にも再現される。
  - 生成ページのプロファイル選択ポップオーバー等に、閉じられたものも含めて全プロファイルがリスト表示され、選択すると容易にタブとして再表示される。
  - プロファイル自体の実削除は、プリセットマネージャー（Preset Manager）内の削除ボタンからのみ実行可能とする。
- [ ] AC-2: **プロファイル未選択状態での編集防止**
  - 生成画面表示時やワークフロー切り替え時に、常に「最後にアクティブだったプロファイル」または「最初にみつかったプロファイル」が自動的にアクティブ（選択状態）になるように制御する。
  - プロファイルが1つもない場合は、デフォルト設定を持つ初期プロファイル（例: `Default`）を自動的に新規作成してアクティブにする。
- [ ] AC-3: **自動セーブの徹底**
  - パラメータ値、適用アセット、バッチサイズ、シード、シードモードの変更は、すべてアクティブなプロファイルに対して自動セーブ（デバウンスを伴うDB更新）が行われ、ユーザーの手動による上書き保存アクションを不要にする。
- [ ] AC-4: **タブごとのUndo/Redo機能**
  - タブ（プロファイル）ごとに独立したパラメータ編集履歴（Undo/Redoスタック）を保持する。
  - 別のタブに切り替えて戻ってきた場合でも、そのタブでの過去の変更履歴（Undo/Redoスタック）が維持され、Undo/Redo操作が行えること。
- [ ] AC-5: **モバイルモードとの共通挙動とデバイス間同期**
  - モバイルモード（`/mobile`）でもデスクトップ同様に自動セーブ、タブ（プロファイル）選択の保証、Undo/Redo等の挙動を同一仕様で提供する。
  - 自動保存（DB更新）により、端末によらず最後の編集内容が最新状態として維持され、別デバイスで画面を開いた際に無意識に同期がとれるようにする。
