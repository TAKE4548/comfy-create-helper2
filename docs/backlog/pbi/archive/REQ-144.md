### REQ-144: セリフ編集のベース画像差し替えにおける全履歴対応・履歴フィルタおよびアルバム選択機能

- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: none
- **Priority**: P2
- **Surface**: req143のベース画像差し替えで、選択する画像に全部出てこない。また、履歴は膨大な為、履歴ページ同等のフィルタおよび、アルバムからの選択も可能にしたい
- **Root Cause**: **Information Architecture & Interaction Friction (Scalability / Discovery)**: セリフ編集画面内のベース画像差し替えセレクターが簡易的な一覧表示にとどまっており、全件アクセス機能や、履歴ページ同等の高度な検索・フィルタリング、およびアルバムからの選択手段が備わっていないため、大量の履歴データから目的のベース画像を探索・選択することが困難になっている。
- **Requirement**: セリフ編集モーダルの「ベース画像差し替え」機能において、全履歴スナップショットを閲覧・選択可能（無限スクロール/ページネーション等）にするとともに、履歴ページと同等のフィルタ・検索機能（キーワード検索、お気に入り、ワークフロー種別、ソート等）を統合する。さらに、アルバム一覧およびアルバム内画像から選択できるタブ/UIを提供し、整理された画像群からもスムーズにベース画像を差し替えて再編集・保存できるようにする。
- **Design doc**: [docs/design/REQ-144.md](docs/design/REQ-144.md)

#### Acceptance Criteria (AC)

##### 1. 全履歴スナップショットの読み込みと閲覧
- [x] AC-1-1: ベース画像差し替えセレクターにおいて、上限件数で打ち切られることなく、履歴内のすべてのスナップショットにアクセス（スクロールに応じた追加読み込み等）して一覧表示できること。

##### 2. 履歴ページ同等の検索・フィルタリング機能
- [x] AC-2-1: ベース画像差し替えセレクターにおいて、履歴ページと同等の検索バー（キーワード検索）およびフィルタ（お気に入り絞り込み、ワークフロー種別、ソート順など）が提供され、条件に応じた絞り込みが行えること。
- [x] AC-2-2: フィルタ条件を変更・クリアした際、即座に対象スナップショット一覧の表示が正しく更新されること。

##### 3. アルバムからのベース画像選択
- [x] AC-3-1: ベース画像差し替えセレクターにおいて、アルバム（Album）から画像を選択するためのタブまたはモード切り替えが提供されること。
- [x] AC-3-2: アルバム一覧から任意のアルバムを選択し、そのアルバムに登録されているスナップショット一覧からベース画像を直接選択できること。

##### 4. 差し替え実行とセリフ編集の継続
- [x] AC-4-1: フィルタ検索結果やアルバムから選択した画像でベース画像が正しく差し替えられ、配置済みの吹き出し・セリフ設定を保持したまま編集および保存が正常に行えること。
