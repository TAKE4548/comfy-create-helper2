### REQ-194: モバイル（Android/タッチ操作）での長押し複数選択の操作性改善・不具合修正

- **Status**: done (2026-08-27)
- **Description**: 
  Android/モバイル端末において、生成履歴画面等の画像カードを長押し（ロングタップ）しても複数選択モードに遷移しない不具合を修正する。
  タッチ直後の微小な指の揺らぎ（接触面積変化）によるタイマー破棄閾値の見直し、および画像カードに対するネイティブ長押しジェスチャ・コンテキストメニュー干渉の抑制を行い、モバイル端末で快適に長押し複数選択が行えるようにする。

#### Acceptance Criteria (AC)
- [x] AC-1: モバイル端末（Android / タッチスクリーン）で画像カードを長押しした際、指の微細なブレがあっても判定時間経過後に安定して複数選択モードへ遷移すること。
- [x] AC-2: 長押し判定中の移動許容閾値（移動許容ピクセル数 / スロップ値）がモバイルタッチ操作に適した値（例: 10〜15px 程度）に調整され、不要な即時キャンセルが発生しないこと。
- [x] AC-3: 生成履歴画面（HistoryPage）のスナップショット画像カードにおいて、ブラウザネイティブの画像長押しコンテキストメニューや不要なドラッグ・選択挙動が抑制されていること。
- [x] AC-4: 長押し成立後に指を離した際、クリックイベントとの競合によって選択が意図せず解除・誤動作しないこと。
- [x] AC-5: 既存のデスクトップ操作（Ctrl/Shift クリック、マウスでの長押しドラッグ等）および設定画面の長押し時間変更機能が正常に動作すること。
