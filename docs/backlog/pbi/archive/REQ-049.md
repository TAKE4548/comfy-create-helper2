### REQ-049: JobManagementModal を開くと画面が真っ黒になる問題の修正

- **Status**: done (2026-08-26)
- **Priority**: high
- **Type**: bug (Type A: Implementation Bug)

#### 背景・現象

生成ページの「Queue: N」をクリックしてジョブ管理モーダル（`JobManagementModal`）を開こうとすると、モーダルが表示されず画面全体が真っ黒になる。

#### 根本原因

`frontend/src/components/JobManagementModal.tsx` において、`useMemo` フック（L25–26）が条件付き早期リターン `if (!isOpen) return null`（L20）の**後**に配置されており、React Rules of Hooks に違反している。

- `isOpen=false` 時: フック 1個のみ実行（`useGenerationStore`）
- `isOpen=true` 時: フック 3個が必要（+ `useMemo` × 2）
- 同一インスタンスで `false → true` に遷移 → React がクラッシュ → 黒画面

REQ-047 でネストした `function Modals()` を廃止したことにより、`JobManagementModal` が安定インスタンス化され、REQ-039 から潜在していた本バグが顕在化した。

- [ ] AC-1: 「Queue: N」クリック時に `JobManagementModal` が正常に表示される
- [ ] AC-2: モーダルを開いた際に React エラー（Hooks order violation）がコンソールに出ない
- [ ] AC-3: モーダルを閉じて再度開いた際も正常に表示される
- [ ] AC-4: 生成進行中（progress 更新あり）にモーダルを開いても黒画面にならない

#### 修正対象ファイル

- `frontend/src/components/JobManagementModal.tsx` — `useMemo` フックを早期リターンより前に移動
