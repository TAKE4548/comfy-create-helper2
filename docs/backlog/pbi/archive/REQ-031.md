### REQ-031: ComfyUIキュー内のジョブ数表示機能の追加

- **Status**: done (2026-08-30)
- **Type**: enhancement
- **Priority**: P2
- **Current step**: none
- **Surface**: 生成ページで、ComfyUIのキューに残っているjobの数を表示できるようにしたい。”自セッションのみ"のフィルタに連動させ、未チェックならセッション問わずキューに溜まってるjobの数、チェックが入ってれば自セッションの分のみ表示するようにしたい。キューが空でも0件であることを明示し続けておきたい。プログレスバー表示エリア付近に進捗のパーセンテージも一緒に表示し、未生成時は0%状態でジョブ数と一緒に常時表示しておきたい。

- **Root Cause**:
  現在のUIには、自他セッションを含めたComfyUI全体のキュー待機状態（待機中のジョブ数）を視覚的に把握するインジケーターが存在せず、自分が投入したジョブの進捗度合い（パーセンテージ）も生成中でない時は表示されないため、全体のサーバー負荷や待機列状況を確認できない。

- **Requirement**:
  - **キュー数と進捗の常時表示**: 生成画面のプログレスバー表示エリア付近に、ComfyUIのジョブ件数を `Queue: {件数}` 形式で、また進捗率（パーセンテージ）を `0%` や実際の進捗率で常時表示する。
  - **ジョブ件数の定義**: 表示対象のジョブ数は、現在実行中のジョブ（Running）と実行待ち（Pending）の合計件数とする。
  - **セッションフィルタの連動**: 「自セッションのみ」チェックボックスのオン/オフと連動し、オンの時は自セッション（`clientId` 一致）のジョブ数のみをカウントし、オフの時はComfyUI内の全ジョブ数をカウントする。

- **Acceptance criteria**:
  - [x] AC-1: **キュー件数と進捗率の常時表示**: 未生成時・生成中・生成完了後に関わらず、プログレスバー表示エリア付近に `Queue: 0` （キューが空の時）および `0%` のように、ジョブ件数と進捗率が常時表示され続けていること。
  - [x] AC-2: **合計件数の集計**: キュー件数のカウントは、現在実行中のジョブと待機中のジョブの合計値（`queue_running.length + queue_pending.length`）に基づいていること。
  - [x] AC-3: **フィルタ連動表示**: 「自セッションのみ」チェックが有効な場合、ジョブ内に含まれる `client_id` が現在のフロントエンドの `clientId` と一致するもののみを集計して表示すること。チェックが無効な場合は、すべてのクライアントのジョブを集計すること。
  - [x] AC-4: **リアルタイム性**: 生成開始時や終了時、また他セッションがジョブを投入した際などに、キュー件数および進捗パーセンテージが遅延なく追従・更新されること。
  - [x] AC-5: **控えめなデザイン統合**: REQ-029で導入された控えめなプログレスバー（プレビュー領域の端部など）の付近に、視認性を損なわずに自然にレイアウトが統合されていること。
