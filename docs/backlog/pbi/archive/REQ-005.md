### REQ-005: LoRAカード詳細モーダルの追加とメイン表示のDescription化

- **Status**: done (2026-06-11)
- **Type**: enhancement
- **Priority**: P1
- **Current step**: none
- **Surface**: LoRAのトリガセットが全部確認できない。カードをクリックしたら、メタ情報と登録したトリガセットがそれぞれ詳細に確認・コピーできるようにしたい。ついでに、カードのメインの表示をモデルのパスでなく、descriptionの方にしたい。
- **Root Cause**: 現状、LoRAカードには限られた情報（登録された一部のトリガなど）しか表示されておらず、長文や多数 of トリガセットを持つLoRAの全容を確認できない。また、クリックによる詳細確認やコピー機能がなく、モデルを識別するためのメイン表示がファイルパス（または物理パス）になっているため、一目でどのモデルかを識別しづらい。
- **Requirement**:
  1. LoRAカードのメインの表示（タイトル）を、モデルの物理パスではなく、モデルに登録されている `description` に変更すること。`description` が登録されていない（空欄またはnull）の場合は、フォールバックとしてモデルのパスを表示すること。
  2. LoRAカードをクリックした際に、そのLoRAのすべての情報（詳細なメタ情報、登録されたすべてのトリガセット）を確認できるモーダルダイアログ（Dialog/Modal）を表示すること。
  3. モーダル内では、モデルの基本メタ情報（パス、説明など）および登録されたトリガセットの一覧を詳細に表示すること。
  4. 登録されたトリガセットの一覧において、**各トリガセットの横にコピーボタンを配置**し、クリック時にそのトリガセット文字列をクリップボードにコピーしてトースト通知などで完了を示すこと。メタ情報（モデルパス等）についてはコピー機能は不要。
- **Acceptance criteria**:
  - [ ] AC-1: LoRAカードのメイン表示部（タイトル）に、LoRAの `description` が表示されること。`description` が未設定の場合は、モデルのパスが表示されること。
  - [ ] AC-2: LoRAカードをクリックした際、詳細モーダルダイアログが表示されること。
  - [ ] AC-3: モーダル内には、LoRAのメタ情報（モデルパス、説明等）と、登録されているすべてのトリガセットが一覧表示されること。
  - [ ] AC-4: モーダル内のトリガセット一覧において、各トリガセットごとにコピーボタンが配置され、クリックするとクリップボードに対象のトリガセットがコピーされ、コピー完了のトースト/フィードバックが表示されること。メタ情報の項目にはコピーボタンが配置されていないこと。
  - [ ] AC-5: モーダルの「閉じる」ボタン、またはモーダル外のクリックでモーダルが正常に閉じられること。
- **Design doc**: none
