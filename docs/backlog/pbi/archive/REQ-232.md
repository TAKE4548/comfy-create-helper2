### REQ-232: server-managerにおけるWSLディストリビューション未検出不具合の修正
- **Type**: defect
- **Status**: done (2026-09-09)
- **Current step**: none
- **Priority**: P2
- **Surface**:
  - 「server-managerでwslのディストリビューションが見つからないと言われる。手動ではディストリビューションは特に指定していないが、必須なのか？」
- **Root Cause**:
  - `tools/server-manager/server-manager.ps1` において、`$cfg.wsl.distro` が未設定または空文字の場合でも固定値 `"Ubuntu"` にフォールバックし、常に `wsl -d $distro ...` として実行される実装になっている。実際の環境では `Ubuntu-24.04` 等のバージョン付き名称で登録されている場合があり、`Ubuntu` 完全一致のディストリビューションが存在しない環境で `WSL_E_DISTRO_NOT_FOUND` エラーとなり起動・停止・ログ参照に失敗する。
- **Requirement**:
  - `server-manager` において、ディストリビューションが明示的に指定されている場合はそのディストリビューションを対象とし、指定されていない（空または省略された）場合は `-d` オプションを付与せず WSL の既定ディストリビューション（default）を自動利用できるようにする。
  - 初期設定やエラー発生時にもユーザー環境に適合しやすい構成とする。
- **Acceptance criteria**:
  - [x] AC-1: `config.json` の `wsl.distro` が空文字または未定義の場合、`-d` オプションなしで `wsl` コマンドが実行され、システムの既定ディストリビューションで ComfyUI の起動・停止・ログ取得が行えること。
  - [x] AC-2: `config.json` の `wsl.distro` に明示的なディストリビューション名（例: `Ubuntu-24.04`）が指定されている場合は、指定されたディストリビューションに対して `-d` を付与して動作すること。
  - [x] AC-3: ディストリビューションが見つからない場合や起動失敗時に、原因が分かりやすいメッセージを出力すること。
- **Design doc**: docs/incident_report.md
