### REQ-148: 生成画面およびセリフ編集画面における前回保存先アルバムの個別管理とアルバム選択モーダルのサイズ拡張

- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: none
- **Priority**: P2
- **Surface**: 生成画面からのスナップショット保存時と、セリフ編集後の保存時に、前回の保存先アルバムを保持しているが、前回の保存先を共用ではなく、それぞれの画面毎に別で管理したい。生成してから素材として保存するアルバムと、セリフを付与した後のアルバムは別で扱うことがほとんどで、生成とセリフ付与を並行して作業することがあるため。また、ついでに保存先アルバムのモーダルが縦に小さく、選択がやりにくいのでサイズを拡張したい。
- **Root Cause**:
  - **State Conflict (Context Pollution)**: 生成画面のスナップショット保存とセリフ編集画面の保存で同一の保存先アルバム履歴（共通キー）を参照・更新しているため、並行作業時に互いの選択状態が上書きされ、保存ごとの再選択摩擦が発生している。
  - **UI Ergonomics (Viewport Restriction)**: 保存先アルバム選択モーダル（またはリスト表示領域）の縦方向の高さ制限が小さく、アルバム一覧の視認性および選択操作性が低下している。
- **Requirement**:
  1. 生成画面（画像生成結果のスナップショット保存）とセリフ編集画面（セリフ追加/編集後の保存）において、直前に選択した保存先アルバムの保持・復元を画面（コンテキスト）ごとに分離して独立して管理する。
  2. 保存先アルバム選択モーダル（ダイアログ）の縦サイズ（高さ・最大高さ）を拡張し、複数アルバムが存在する場合でも一覧しやすく選択しやすいUIにする。

#### Acceptance Criteria (AC)

##### 1. 前回保存先アルバムの画面別（独立）永続化・復元
- [ ] AC-1-1: 生成画面からのスナップショット保存時、生成画面専用の「前回保存先アルバム」が参照・初期選択され、保存実行時に生成画面用の前回保存先として更新・永続化されること。
- [ ] AC-1-2: セリフ編集画面からの保存時、セリフ編集専用の「前回保存先アルバム」が参照・初期選択され、保存実行時にセリフ編集用の前回保存先として更新・永続化されること。
- [ ] AC-1-3: 生成画面で保存先アルバムを変更・保存してもセリフ編集画面の前回保存先には影響せず、セリフ編集画面で保存先アルバムを変更・保存しても生成画面の前回保存先には影響しないこと（相互独立性）。
- [ ] AC-1-4: それぞれの画面において前回保存先が存在しない（または対象アルバムが削除等で存在しない）場合のフォールバック（初期表示ルール）が正常に機能すること。

##### 2. 保存先アルバム選択モーダルのサイズ拡張
- [ ] AC-2-1: 保存先アルバム選択モーダル（または保存ダイアログ内のアルバム選択・一覧領域）の縦幅（max-height等）が拡張され、より多くのアルバムが一覧・選択しやすくなること。
- [ ] AC-2-2: 各画面サイズや解像度（レスポンシブ）においてモーダルが画面外にはみ出さず、適切に収まるレイアウトであること。

##### 3. 既存機能の整合性
- [ ] AC-3-1: 生成画面からのスナップショット保存およびアルバム追加機能が正常に機能すること。
- [ ] AC-3-2: セリフ編集画面からの新規保存・上書き保存およびアルバム追加機能が正常に機能すること。
