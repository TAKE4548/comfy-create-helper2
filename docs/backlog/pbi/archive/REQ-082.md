### REQ-082: 既存の再マッピングモーダルにおける候補ノード情報の表示改善

- **Status**: done (2026-08-26)
- **Description**: 
  現在、生成画面のワークフロー選択の脇から操作する「再マッピングモーダル（`RescanModal.tsx`）」において、役割に対する候補ノードを選択するドロップダウン（`<select>`）にはノードID（例：`10`）のみが表示されている。
  これを、PBI-081（新規アップロード時の `UploadWorkflowModal.tsx`）で実装した形式と同様に、ノードIDに加えてタイトルとタイプ（クラス名）も併記する形式（例：`10 - [positive] (KSampler)`）に改善し、ノードの選択ミスを防ぐ。

#### Acceptance Criteria (AC)
- [x] AC-1: `RescanModal.tsx` の候補選択ドロップダウンにおいて、オプションのラベルが `ID - [タイトル] (タイプ)` の形式で表示されること。
- [x] AC-2: `workflowJson` に該当するノードの情報が存在しない、または一部不足している場合もフォールバック表示（`ID` のみ表示、または空文字処理）が正しく機能し、クラッシュしないこと。
