### REQ-025: スマホモード時の生成・スナップショットボタンが押せない不具合およびレイアウト崩れの修正

- **Status**: done (2026-08-26)
- **Description**: スマホモード（画面幅768px未満、または `/mobile` パス）において、PC用の2カラムレイアウトが表示されてボタン操作やプレビューの確認ができなくなる問題を修正し、仕様書通りのスマホ専用レイアウト（タブ切り替え式共用プロンプト入力欄および縦並び1カラム）を実装します。

#### Acceptance Criteria (AC)
- [ ] AC-1: 画面幅768px未満または `/mobile` パスのとき、動的にスマホ用1カラムレイアウト（縦並び）に切り替わること。
- [ ] AC-2: スマホ用レイアウトにおいて、画像プレビューエリア（WebSocket進捗・履歴画像）が適切に表示され、はみ出しや消失が発生しないこと。
- [ ] AC-3: スマホ用レイアウトにおいて、「生成（Generate Batch）」ボタンと「Save Snapshot」ボタンが画面下部に正しく配置され、隠れたり崩れたりせずに押せること。
- [ ] AC-4: スマホ用レイアウトにおいて、複数のプロンプト入力欄が「横スクロール対応タブ ＋ 共用テキストエリア」の構成になり、タブ切り替えによって入力内容がスムーズに反映・編集できること。
- [ ] AC-5: ブラウザウィンドウのリサイズ時（デスクトップ⇔スマホ）に、ページをリロードすることなく動的にPC用レイアウトとスマホ用レイアウトが切り替わること。
