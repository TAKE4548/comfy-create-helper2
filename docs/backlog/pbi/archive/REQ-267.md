### REQ-267: 外部クライアント端末からのスナップショット保存時における画像永続化不全および端末間画像表示不具合の是正

- **Type**: defect
- **Status**: done (2026-09-16)
- **Current step**: none
- **Priority**: P1
- **Surface**:
  - 生成画像を保存した端末と、異なる端末でhistoryページを見るとサムネ・プレビュー共に実画像が表示されない。
  - 保存した端末では正常に見える。
  - 生成履歴の方では同事象は見られない。
- **Root Cause**:
  - **Backend ComfyUI Image Ingestion Failure**:
    - `SnapshotService.create_snapshot` (`backend/app/services/snapshot_service.py`) がクライアント端末（LAN IP: `192.168.3.10` 等）から送信された外部 ComfyUI URL（`http://192.168.3.13:8188/view?...`）をそのまま `urllib.request.urlopen` に渡している。
    - サーバーホスト内部から自身の外部 LAN IP（`192.168.3.13:8188`）への通信が Windows / WSL2 のヘアピン NAT ルーティング制約によりタイムアウトし、画像ダウンロードが失敗する。
  - **Silent Exception Swallowing & Corrupt Record Persistence**:
    - 画像ダウンロード失敗時、例外をキャッチしてエラーログを出力するのみで処理を中断せず、外部 URL をそのまま `image_path`、`thumbnail_path` を `None` として DB に永続化している。
    - そのため `db/snapshots/` に画像実体（WebP）およびサムネイルが保存されない。
  - **Cross-Device URL Reachability Discrepancy**:
    - 保存端末ではブラウザキャッシュまたは直接 LAN 接続により表示可能であるが、別端末（`127.0.0.1` やポート 8188 に直接到達できない環境）では画像の取得に失敗する。
    - 一方、「生成履歴」はバックエンドのサムネイルプロキシ（`/api/comfy/thumbnail?...`）を経由するため、サーバーの内部設定 `settings.comfy_url`（`http://localhost:8188`）により全端末で正常に表示されていた。
- **Requirement**:
  - クライアント端末から渡された `image_path` が ComfyUI の `/view` URL である場合、バックエンド内部の `settings.comfy_url`（`http://localhost:8188` 等）に正規化して実画像を取得し、確実に `db/snapshots/` へ WebP 永続化およびサムネイル生成を行うこと。
  - 画像取得失敗時のサイレントフォールバックを排除し、永続化に失敗した不正なレコードが DB に登録されないようにすること。
  - 既存の不全レコード（68件）に対して、ComfyUI 一時領域から実画像を取得・WebP 永続化・サムネイル生成を行い、DB のパスを正常な相対 URI（`/api/snapshots/images/...`）へと復旧するマイグレーションスクリプトを提供・実行すること。
  - どの端末（保存端末・他端末）からアクセスしても、History ページ（一覧サムネイル・モーダルプレビュー・アルバム詳細）で実画像が確実に表示されること。
- **Acceptance criteria**:
  - [x] AC-1: 外部 LAN クライアント端末からスナップショット保存を実行した際、バックエンドが内部 ComfyUI URL を通じて実画像を確実にダウンロードし、`db/snapshots/` に WebP 画像およびサムネイルが永続化保存されること。
  - [x] AC-2: 作成されたスナップショットレコードの `image_path` および `thumbnail_path` が、サーバー配信の相対 URI（`/api/snapshots/images/...`）として正常に DB に登録されること。
  - [x] AC-3: 既存の影響レコード（ID: 4108〜4177）がマイグレーションにより修復され、`thumbnail_path` が付与され、`image_path` が正規の相対 URI に更新されること。
  - [x] AC-4: スナップショットを保存した端末とは異なる端末（およびサーバーローカルブラウザ）から `/history` ページを閲覧した際、一覧サムネイルおよびモーダルプレビューの実画像が正常に表示されること。
  - [x] AC-5: アルバム詳細画面においても、異なる端末間でスナップショットのサムネイルおよび実画像が正常に表示されること。
