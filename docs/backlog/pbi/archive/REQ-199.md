### REQ-199: ImageCropper操作時におけるイベント伝播制御とモーダル誤クローズ防止（D&D後の保存不能解消）
- **Type**: bugfix
- **Status**: done (2026-08-29)
- **Current step**: Phase 1: Intake & Triage (Completed)
- **Priority**: P1
- **Surface**:
  - LoRA またはタグセットの編集・詳細モーダル等でサムネイル画像のクロップ調整を行う際、クロップ枠内をマウスドラッグでパン移動してマウスボタンを離す（mouseup / D&D終了）と、クロップモーダルおよび親モーダル全体が予期せず閉じてしまい、「切り抜いて保存」ができずに編集内容が破棄される。
- **Root Cause**:
  - `ImageCropper` コンポーネントおよび各種モーダルにおいて、ドラッグ終了時にブラウザからディスパッチされる `click` イベントが上位の `<div className="modal-backdrop" onClick={onClose}>` までバブリングし、親モーダルの `onClose` が誤発火して画面全体が強制アンマウントされる。
- **Requirement**:
  - `ImageCropper` の表示中および操作時（ドラッグ、ズーム調整、ボタンクリック等）に、親モーダル（`.modal-backdrop`）へのクリックイベントの伝播（バブリング）を確実に防止すること。
  - クロップ調整枠内でのマウスドラッグ操作終了時（mouseup / drop）に親モーダルが誤って閉じることがなく、正常に「切り抜いて保存」または「キャンセル」ボタンを押下して処理を完了できること。
  - クロップモーダルのオーバーレイ（背景部分）をクリックした場合の閉じる挙動（またはクローズ制御）と、親モーダルのバックドロップ挙動が正しく分離・排他制御されること。
- **Acceptance criteria**:
  - [x] AC-1: LoRA 詳細/編集モーダルおよびタグセット詳細/編集モーダルにおいて、「クロップ調整」または画像アップロードにより `ImageCropper` を起動した際、クロップ枠内の画像をドラッグしてマウスボタンを離してもモーダルが閉じないこと。
  - [x] AC-2: `ImageCropper` 内でのズームスライダー操作やパン操作完了後に「切り抜いて保存」ボタンを押下することで、トリミングされた画像がアップロードされてサムネイルとして正しく反映・保存されること。
  - [x] AC-3: `ImageCropper` の「キャンセル」または「✕」ボタンを押下した際、親モーダルは開いたまま維持され、クロップモーダルのみが正常に閉じられること。
