# REQ-114: 既存タグセットの編集が保存（Save）できない不具合の修正

- **Type**: defect
- **Status**: in-progress
- **Current step**: Phase 4
- **Priority**: P1
- **Surface**: 既存タグセットの編集でsaveが出来ない。
- **Root Cause**: 
  1. `openEdit` にて `editForm` の初期値に `target_base_model_ids` を設定していないため、FastAPI スキーマの validation にて 422 エラーが発生する。
  2. `TagSetDetailModal` の `handleStartEdit` にて、フォーム初期値に `subsets` を設定していないため、サブセット情報が消去されてしまう。
  3. `updateTagSet.onSuccess` 時のモーダルクローズ処理の欠落。
  4. API エラーハンドリングの欠落。
- **Requirement**: 既存タグセットの編集モーダルおよび詳細モーダルから正しくタグセットの更新（Save Changes）ができ、API 成功時にモーダルが閉じて一覧が更新されること。またエラー時には適切にユーザーにエラーが表示されること。
- **Acceptance criteria**:
  - `TagsPage` から既存タグセットを編集し「Save Changes」を実行した際、API (PUT `/api/tag-sets/{id}`) が 422 などのエラーにならず正常終了すること。
  - API成功後、編集モーダルが自動的に閉じること。
  - 詳細モーダル (`TagSetDetailModal`) から編集を開始して保存した際、既存の `subsets` (サブセット情報) が消えずに正しく維持・更新されること。
  - API呼び出しがエラーになった場合、何も起きないのではなく、ユーザーにエラーダイアログやトースト等で失敗した旨が伝わること。
- **Design doc**: none
