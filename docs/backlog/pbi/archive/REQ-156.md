### REQ-156: 生成画面の履歴複数選択時の画像追加に伴う選択ズレ不具合の修正

- **Type**: bug
- **Status**: ready
- **Priority**: P1
- **Surface**: 生成画面の履歴から複数選択をして保存する際、保存確定までの操作中に生成が完了した画像が増えると、その分履歴の選択画像がずれてしまい、意図しない選択で保存されてしまう。
- **Root Cause**:
  - `useGeneratePageState.ts` において、`useMultiSelect` の識別子（`id`）に配列の添字（インデックス `idx`）を使用しているため、生成完了時に `sortedDisplayImages` の先頭に新画像が追加されて要素インデックスが繰り下がった際に、`selectedIds` 内のインデックス値と実際の画像との対応がずれてしまう。
- **Requirement**:
  1. 履歴サムネイルの複数選択において、配列インデックスではなく画像の一意な識別子（URL等）を用いて選択状態を管理・追跡する。
  2. 複数選択中または保存モーダル操作中にバックグラウンドで新規画像が生成完了・追加された場合でも、ユーザーが選択した画像の選択状態が保持され、選択位置が新着画像へずれないようにする。
  3. 保存確定時に、選択されていた意図通りの画像一覧が正しく保存APIに送信されるようにする。

#### Acceptance Criteria (AC)

##### 1. 一意識別子による選択状態の管理
- [ ] AC-1-1: 履歴サムネイルの複数選択（マルチセレクト）において、配列インデックスではなく各画像の一意識別子（画像URL等）に基づいて選択状態が管理されること。
- [ ] AC-1-2: `useMultiSelect` または履歴選択管理が文字列型等の識別子に対応し、正しく選択・選択解除・範囲選択・全選択が行えること。

##### 2. 新規画像生成完了時の選択維持
- [ ] AC-2-1: 複数画像を選択した状態でバックグラウンドにて新たな画像生成が完了し履歴に追加された場合でも、選択されていた画像の選択状態が維持され、新着画像に選択がシフトしないこと。
- [ ] AC-2-2: 新規画像が追加された後に「選択した N 枚を保存」を実行した際、元々選択していた画像群のパスが保存処理に渡されること。
