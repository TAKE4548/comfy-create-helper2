### REQ-054: 全画面表示で真っ黒の画面になる問題（再発）

- **Status**: new
- **Type**: Bug (Type A - Implementation)
- **Priority**: High
- **Reported**: 2026-06-20
- **Root Cause**: `HistoryModalPreview.tsx` L117 の `loraStacks = useMemo(...)` が L71 の早期リターン（`if (!isOpen || images.length === 0) return null`）より後に配置されており、React Rules of Hooks 違反が発生している。

#### 背景

REQ-052 (LoraStack対応) にて `useMemo(loraStacks)` が `HistoryModalPreview.tsx` に追加された際、早期リターンの後に配置されてしまった。  
REQ-053 では `matchKey` TDZ バグを修正したが、`useMemo` の位置問題は対象外だったため、本バグが残存した。

#### 影響ファイル

- `frontend/src/components/HistoryModalPreview.tsx` — L71（早期リターン）、L117（`useMemo` 位置違反）

#### Acceptance Criteria (AC)

- [ ] AC-1: 全画面プレビュー（`HistoryModalPreview`）を開いたとき、画像が正常に表示される
- [ ] AC-2: 全画面プレビューを閉じる（×ボタン / 背景クリック）と、正常に閉じる
- [ ] AC-3: `isOpen` が `false → true` に遷移しても React Hooks エラーが発生しない（コンソールにエラーなし）
- [ ] AC-4: LoRA スタック情報（`loraStacks`）は引き続き情報パネル（viewMode='info'）で正しく表示される
