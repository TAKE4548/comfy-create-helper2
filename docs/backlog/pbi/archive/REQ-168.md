### REQ-168: セリフ編集における漫画演出修飾パラメータ拡張およびプリセット対応

- **Type**: enhancement
- **Status**: ready
- **Current step**: none
- **Priority**: P2
- **Surface**: セリフ付与の機能で、編集可能な修飾項目を増やしたい。漫画的な表現をより様々なパターンを表現できるようにしたいため。パスによる文字の流れ反映も含まれるが、より単純なケースとして、選択した文字を縦・横90度向き変更できるようにしたい（縦書きで!?などだけを横にしたいケースの簡易指定）。また今回追加する項目もプリセット保存対象とし、既存プリセットはデフォルト値でマイグレーションしたい。
- **Root Cause**: 
  - **[Visual / Interaction]**: 現行のセリフ編集機能では表現可能な文字装飾（タイポグラフィ変形、多重フチ、グラデーション/トーン、スケール変化、パス軌道など）が限定されており、漫画特有の叫び・動揺・描き文字・SE等の多様な視覚的演出を再現しづらい。
  - **[Interaction Design]**: 縦書きセリフ内の約物（`!?`など）の向き変更（縦中横表現）を行う際に、大掛かりなパス指定やテキスト分割を強いられ操作コストが高い。
  - **[Information Design]**: 新たな修飾パラメータがプリセット管理スキーマに統合されておらず、既存プリセットとの後方互換性（デフォルト値補完）を保ちつつ一括適用する仕組みが必要である。
- **Requirement**: セリフ編集機能において漫画的な表現力を高める各種修飾パラメータ（フォント変形、文字単位の90度回転/縦中横、サイズ揺らぎ・スケールカーブ、パス・ステップ配置、グラデーション・トーン・中抜き、多重フチ・輪郭スタイル）を拡充し、これらをプリセットとして保存・読み込み可能にするとともに、既存プリセットを自動マイグレーションできるようにする。

#### Acceptance Criteria (AC)

##### 1. タイポグラフィ変形および文字単位の簡易回転（縦中横）
- [ ] AC-1-1: セリフテキスト内の特定の文字または記号（`!?`や数字など）を選択し、縦書き・横書きの向きを90度回転（縦中横）できること。
- [ ] AC-1-2: 字間（Letter Spacing）、行間（Line Height）、傾斜変形（Shear / Skew 角度）を数値またはスライダーで指定・編集できること。
- [ ] AC-1-3: 横書き / 縦書きの切り替えがスムーズに行えること。

##### 2. ダイナミックスケールおよびサイズ揺らぎ（感情演出）
- [ ] AC-2-1: 文字単位の連続的なスケール変化（先頭から末尾への拡大・縮小、イージングカーブ指定）を設定できること。
- [ ] AC-2-2: 文字ごとにランダムなサイズ揺らぎ（Jitter振幅）を付与し、感情の動揺や叫びを表現できること。

##### 3. パス・軌道レイアウト制御
- [ ] AC-3-1: プリセット軌道（直線、斜め、階段状ステップ、波型、円弧等）に沿ってテキストを配置できること。
- [ ] AC-3-2: パス追従時の文字回転（接線方向追従 vs 水平/垂直一定角度固定）を選択できること。
- [ ] AC-3-3: 文字ごとのオフセット（ベースラインシフトによるガタつき表現）を調整できること。

##### 4. カラー・塗り・テクスチャ制御
- [ ] AC-4-1: 単色塗りの透明度（Alpha）を含むカラーピッカー指定ができること。
- [ ] AC-4-2: 線形および放射グラデーション（複数カラーストップ、角度、比率）による文字塗りつぶしができること。
- [ ] AC-4-3: スクリーントーン風の網点パターンやノイズテクスチャを文字に適用できること。
- [ ] AC-4-4: 中抜きモード（塗りを透明化し輪郭線のみ描画）に切り替えられること。

##### 5. 多層アウトライン（多重フチ）および輪郭スタイル
- [ ] AC-5-1: 複数のフチ取りレイヤー（多重アウトライン）を追加・並び替え・削除でき、各レイヤーの線の太さ・色・透明度・オフセット（影/立体表現）を個別に設定できること。
- [ ] AC-5-2: 輪郭の角処理（Round / Miter / Bevel）および線種（実線 / 破線）を選択できること。
- [ ] AC-5-3: 輪郭にラフ・かすれ（手描き風ジッター）処理を適用できること。

##### 6. プリセット保存・読み込みと後方互換マイグレーション
- [ ] AC-6-1: 新規に追加された全修飾パラメータがプリセット保存時に漏れなくシリアライズされること。
- [ ] AC-6-2: 既存の旧形式プリセットを読み込んだ際、新規追加パラメータがデフォルト値で安全に補完（マイグレーション）され、エラーなく正常に適用できること。
- [ ] AC-6-3: 登録済みプリセット一覧からワンクリックで漫画演出スタイルをセリフに適用できること。

##### 7. 演出パラメータ連動の吹き出しサイズ・フォント自動調整
- [ ] AC-7-1: `calculateFitBubbleDimensions` において、字間・行間倍率・スケールカーブ（最大倍率）・シアー傾斜・パス軌道オフセット・多重フチ幅などの修飾パラメータを加味してテキストがはみ出さない適切な吹き出しサイズ（幅・高さ）が算出されること。
- [ ] AC-7-2: `calculateFitFontSize` において、演出パラメータ適用後の実描画サイズを考慮して吹き出し枠内に収まる最大フォントサイズが算出されること。
- [ ] AC-7-3: セリフ編集UIで修飾パラメータを変更した際、サイズ自動フィット有効時に吹き出しサイズが追従して適切に再計算されること。
