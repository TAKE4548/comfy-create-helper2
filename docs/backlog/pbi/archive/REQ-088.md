### REQ-088: 生成中の詳細プログレスバー表示機能

- **Status**: done (2026-08-26)
- **Description**: 
  1. 生成実行時、バッチ全体の進捗（全体版）と、現在実行中のノードごとの進捗（詳細版）の2本のプログレスバーをUI上に表示する。
  2. バッチ全体の進捗表示は、生成予定総数（n）と完了済み数（m）に基づき「m/n枚目 (xx%)」のように表示する。
  3. 詳細な進捗表示は、現在ComfyUIで実行中のノード名（例: KSampler, Load Checkpoint等）およびそのノード内の進捗率「ノード名 xxx%」を表示する。
  4. 生成開始からの経過時間を秒単位（例: `経過時間: 12秒`）でリアルタイムにカウントアップして表示する。
  5. 生成完了までの残り予測時間（ETA）を「残り約xx秒」として計算・表示する（簡易予測ロジックで可）。

#### Acceptance Criteria (AC)
- [ ] AC-1: 生成画面において、「全体の進捗」と「実行中のノード進捗」の2本のプログレスバーが独立して表示されること。
- [ ] AC-2: 全体の進捗バーに、バッチ枚数に基づく分数値（m/n）とパーセンテージ（%）が表示されること。
- [ ] AC-3: ノード進捗バーに、現在実行中のComfyUIノードの名称（例: KSampler）と、そのノードの進捗状況（%）がリアルタイムに表示されること。
- [ ] AC-4: 進捗領域に、生成開始時からの経過時間（秒単位）がリアルタイムにインクリメントされて表示されること。
- [ ] AC-5: 生成進捗速度から簡易的に算出された残り時間（ETA）が表示されること。
