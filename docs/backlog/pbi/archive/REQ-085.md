### REQ-085: Asset (LoRA/タグセット) 追加UIの探索・複数適用機能の強化

- **Status**: ready
- **Description**: 
  1. 生成ページの「Add Asset」機能において、アセット数が多くても探索が容易になるよう、LoRAとタグセットでタブ分類し、フィルタおよび検索（キーワード検索）機能を提供する（専用のモーダルUIを導入）。
  2. 「Add Asset」画面で複数のLoRAトリガセットを複数選択し、一回の操作でプロンプトに一括追加できるようにする。
  3. 複数選択時に、アセット選択肢に含まれる「LoRAロードタグ」を他のトリガセットと同様にユーザー自身が選択肢から明示的に選択して適用できるようにする（選択されていれば挿入し、選択されていなければロードタグなしでトリガのみを挿入する）。

#### Acceptance Criteria (AC)
- [ ] AC-1: Add AssetのUI（またはモーダル）にて、LoRAとタグセットがタブ等で分類され、名前やタグでのテキスト検索・フィルタができること。
- [ ] AC-2: アセット一覧にて、チェックボックス等を用いて複数のLoRA/タグセットを複数選択できること。
- [ ] AC-3: 複数選択した状態で「追加」を実行すると、選択されたすべてのトリガセットおよびタグがプロンプトエリアに一括で挿入されること。
- [ ] AC-4: 選択肢にある「LoRAロードタグ」を選択した場合のみ、ロードタグ（例：`<lora:...>`）がプロンプトに挿入され、選択していない場合はトリガ単体のみが挿入されること。
