### REQ-355: 残存履歴20ページ同期テストの全体実行時waitFor期限競合を解消

- **Type**: bug
- **Status**: done (2026-10-13)
- **Priority**: P3
- **Surface**: frontend/src/pages/GeneratePage/hooks/__tests__/useGenerateDisplayState.residual.test.tsx
- **5 Whys / Root Cause**:
  1. なぜ改修が必要か: 既定の全体テストで残存履歴同期ケースが `checking` のまま失敗し、REQ-344の受入を停止させるため。
  2. なぜ失敗するか: 初回20ページ同期の `partial` 反映をRTLの既定 `waitFor` 1000ms以内に要求しているため。

  5. 根本原因: テストが有限非同期処理の完了を明示的にflushせず、負荷依存の既定待機期限へ依存している。
