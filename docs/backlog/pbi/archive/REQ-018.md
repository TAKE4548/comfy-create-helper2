### REQ-018: スナップショット一覧での拡大プレビューとキーボード/クリックによる前後ナビゲーション機能

- **Status**: done (2026-08-30)
- **Type**: enhancement
- **Priority**: P1
- **Current step**: none
- **Surface**: スナップショット一覧ページで、サムネイルをクリックした時に詳細を拡大プレビュー表示できず、また前後のスナップショットへの切り替えをキーボードやクリック操作で行えない。
- **Root Cause**: HistoryPageにスナップショット拡大プレビュー（ライトボックス）機能がなく、キーボードやクリックによるナビゲーション機能も実装されていない。
- **Requirement**:
  1. **拡大プレビュー（ライトボックス）表示**:
     - サムネイルをクリックした際、画面全体を覆う暗い半透明のオーバーレイ（プレビューモーダル）が表示され、その中央に拡大されたスナップショット画像が表示されること。
     - モーダル内右上に閉じる（×）ボタンを配置する。また、プレビュー画像外のオーバーレイ領域をクリックすることでもプレビューが閉じられること。
  2. **前後ナビゲーションのクリック操作**:
     - モーダル内の左右に、モダンなデザインの「前へ」「次へ」の矢印ボタンを配置する。
     - 矢印ボタンをクリックすると、現在のスナップショットから前後のスナップショットへプレビュー表示が切り替わること。
  3. **キーボードによる前後ナビゲーション操作**:
     - 拡大プレビュー表示中にキーボードの `←`（左矢印キー）を押すと前のスナップショット、`→`（右矢印キー）を押すと次のスナップショットへ切り替わること。
     - `Esc`（エスケープキー）を押すとプレビュー表示が閉じられること。
  4. **ループ移動のサポート**:
     - 先頭のスナップショット表示中に「前へ」（または `←`）を押すと、末尾のスナップショットにループ移動すること。
     - 末尾のスナップショット表示中に「次へ」（または `→`）を押すと、先頭のスナップショットにループ移動すること。
     - スナップショットのフィルタリング（特定のワークフローでの絞り込みなど）が行われている場合は、そのフィルタリングされたリストに基づいて前後・ループ移動が行われること。
  5. **プレビュー内のアクションおよびメタデータ表示**:
     - プレビューモーダル内に、現在表示中のスナップショットの「ダウンロード」ボタンと「削除」ボタンを配置し、プレビューを閉じることなくそれらのアクションを実行できること。
     - スナップショットの作成日時（フォーマットされた日付）などのメタ情報をプレビュー内に表示すること。

#### Acceptance Criteria (AC)
- [x] AC-1: **[Interaction]** スナップショットのサムネイルをクリックすると、画面中央に拡大されたスナップショット画像を含むプレビューモーダルが表示されること。
- [x] AC-2: **[Visual/Interaction]** プレビューモーダルには半透明の黒オーバーレイ背景、右上の「×」ボタン、左右のモダンな矢印ナビゲーションボタンが表示され、右上の「×」または画像外のオーバーレイ領域をクリックするとモーダルが閉じること。
- [x] AC-3: **[Interaction]** プレビュー表示中にキーボードの `←` キーで前へ、`→` キーで次へ切り替わり、`Esc` キーでモーダルが閉じること。
- [x] AC-4: **[Interaction]** プレビュー内の左右の矢印ボタンをクリックすることで、それぞれ前後のスナップショットへ表示が切り替わること。
- [x] AC-5: **[Interaction]** フィルタ（All Workflows または特定ワークフロー）適用中の場合、フィルタリングされたスナップショットリストを対象として正しく前後移動およびループ移動が行われること。
- [x] AC-6: **[Interaction]** プレビューモーダル内に「ダウンロード」および「削除」ボタンが配置され、正常に機能すること（削除時は確認ダイアログを挟み、削除成功時はモーダルを閉じるか次の画像に切り替わること）。
- [x] AC-7: **[Info]** プレビューモーダル内に、スナップショットの作成日時が表示されていること。
