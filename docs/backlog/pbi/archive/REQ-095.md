### REQ-095: snapshots.py及びloras.pyの例外エラー応答テストの追加

- **Status**: new
- **Description**: `snapshots.py` や `loras.py` において、存在しないIDへのリクエストや無効なアセットIDの送信に対して適切に `HTTP 404` や `HTTP 400` を返すロジックが実装されていますが、pytest による検証コードが存在しません。これらの例外系・異常系に対するテストを追加します。

#### Acceptance Criteria (AC)
- [ ] AC-1: `PATCH /api/snapshots/{snapshot_id}` において、存在しない Lora ID または TagSet ID を送信した際に `HTTP 400 Bad Request` が返されることを検証するテストを追加すること
- [ ] AC-2: `PUT /api/loras/{lora_id}` において、存在しない ID にリクエストした際に `HTTP 404 Not Found` が返されることを検証するテストを追加すること
- [ ] AC-3: `DELETE /api/loras/{lora_id}` において、存在しない ID に対して削除を試みた際に `HTTP 404` が返されることを検証するテストを追加すること
