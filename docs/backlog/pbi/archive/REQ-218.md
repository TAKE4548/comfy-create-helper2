### REQ-218: 生成プリセット一括編集におけるプロンプト先頭・末尾追加時のデリミタ付与不具合の修正

- **Status**: done (2026-09-03)
- **Description**: 
  生成画面のプロファイル一括編集（`ProfileBulkEditModal`）において、プロンプトタブから操作種別「先頭に追加（`prefix`）」または「末尾に追加（`suffix`）」を指定して適用した際、既存プロンプトと追加プロンプトがデリミタなしで文字列結合されタグが破損する問題を解消する。
  既存プロンプトと追加値の境界に適切なカンマ区切り（`, `）を付与し、余分な先頭・末尾のカンマや空白を正規化して結合する。

#### Acceptance Criteria (AC)
- [ ] AC-1: 操作種別「先頭に追加（`prefix`）」を一括適用した際、既存プロンプトが空でない場合は追加テキストと既存テキストの間にカンマ区切り（`, `）が付与され、既存の先頭タグと結合しないこと。
- [ ] AC-2: 操作種別「末尾に追加（`suffix`）」を一括適用した際、既存プロンプトが空でない場合は既存テキストと追加テキストの間にカンマ区切り（`, `）が付与され、既存の末尾タグと結合しないこと。
- [ ] AC-3: 既存プロンプトが空文字（または空白のみ）の場合、余分なカンマや空白が付与されず追加テキストのみが正しく設定されること。
- [ ] AC-4: 既存プロンプトまたは追加テキストの末尾・先頭に既にカンマや空白が存在する場合でも、重複したカンマ（`, , `）にならず正しく正規化されて結合されること。
- [ ] AC-5: 関連する単体テスト（`usePresetState` / `useGeneratePageState` 等）がパスすること。
