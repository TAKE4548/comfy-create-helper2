### REQ-255: プリセットのプロンプト編集反映保証とタブ切り替えキャッシュ保護（TagChipEditorテキスト同期適正化・Multi-Set状態維持）

- **Type**: bugfix
- **Status**: done (2026-09-12)
- **Current step**: dev-design
- **Priority**: P0
- **Surface**:
  - プリセットのプロンプト（`Prompt_Pose_Action` など）を編集しても、生成ボタン押下時に編集内容がComfyUIへ反映されず、過去のプロンプトや古いDB保存値で生成が実行されてしまう。
  - テキスト入力モードでプロンプトを入力中に、末尾のカンマやスペースを入力した瞬間に文字が巻き戻される・消去される不具合が発生する。
  - Multi-Set タブバーでプリセットタブを切り替えた際、メモリ内の最新編集値が破棄され、古いサーバーキャッシュ（DB値）で上書き消去される。
- **Root Cause**:
  - (TagChipEditor 内部の自己同期循環ループ):
    - テキスト入力モード時、入力のたびに親ストアへ `onChipsChange` が通知され、更新された `chipsProp` が渡される。`useEffect([chipsProp])` が `setTextValue(chipsToString(chipsProp))` を呼び出すため、末尾スペースやカンマが切り捨てられて即座に巻き戻される。
  - (タブ切り替え時のサーバーキャッシュ強制再ロード):
    - `DesktopLayout.tsx` および `MobileLayout.tsx` のタブクリックハンドラが、メモリ内の `sets` を保持する `setActiveSetId` ではなく、古いサーバークエリキャッシュを再ロードする `handleLoadPreset` を呼び出しているため、未コミットの編集内容が古いDB値で上書き破棄される。
- **Requirement**:
  - `TagChipEditor` のテキスト入力モードにおいて、入力途中の文字列が外部 `chipsProp` の再通知によって勝手に巻き戻されないようにし、生の入力テキストが即座に `onChange`（`paramValues`）へ安全に反映されるようにすること。
  - Multi-Set タブバーのクリック時に、`handleLoadPreset` ではなく `setActiveSetId` を使用してメモリ内のセット編集状態を維持し、サーバーキャッシュによる意図しない上書きを防止すること。
  - 単一プリセット選択時およびバッチ生成時に、現在編集中のプロンプトパラメータが確実に ComfyUI および `prompt_metadata` に送信されることを保証すること。
- **Acceptance criteria**:
  - [ ] AC-1: `TagChipEditor` のテキストモードでカンマやスペース、任意の文字列を入力した際、文字が勝手に消去・巻き戻されず、`onChange` に最新のテキストが即座に伝播されること。
  - [ ] AC-2: `TagChipEditor` のテキストモードとチップモードを相互に切り替えた際、入力内容が正確にチップ化／文字列化され、データが欠落しないこと。
  - [ ] AC-3: Multi-Set タブバーで別プリセットのタブをクリックした際、`handleLoadPreset` による古いサーバーキャッシュ上書きが発生せず、各タブで編集中の値がメモリ内に維持されること。
  - [ ] AC-4: プリセットのプロンプトを編集して「Generate Batch」を押下した際、編集後のプロンプトが ComfyUI に確実に送信され、生成パラメータ（`prompt_metadata`）に記録されること。
