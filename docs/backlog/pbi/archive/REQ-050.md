### REQ-050: 設定画面におけるワークフローの削除・一覧表示機能

- **Type**: enhancement
- **Status**: done (2026-08-26)
- **Current step**: none
- **Priority**: P2
- **Surface**: 設定画面でワークフローの削除・一覧表示ができない
- **Root Cause**: バックエンドに削除エンドポイントがあるにもかかわらず、フロントエンドの SettingsPage にそれらを表示・操作するUIが欠落している。
- **Requirement**: 設定画面（SettingsPage）に「ワークフロー管理」セクションを追加し、登録済みワークフローを一覧表示するとともに、個々のワークフローを削除できるようにする。
- **Acceptance criteria**:
  - [x] AC-1: 設定画面に「ワークフロー管理」セクションが表示され、登録済みの全ワークフロー名が一覧で取得・表示されること。
  - [x] AC-2: 各ワークフローの横に削除ボタンが表示されること。
  - [x] AC-3: 削除ボタン押下時、削除の確認を求めるダイアログが表示されること。
  - [x] AC-4: 確認ダイアログで削除を承認した際、バックエンドAPI（`DELETE /api/workflows/{id}`）が呼び出され、正常に削除されること。
  - [x] AC-5: 削除完了後、一覧が再読み込みされ、Generate ページの選択リストからも該当ワークフローが除外されること。
- **Design doc**: docs/specs/SPEC_SETTINGS.md
