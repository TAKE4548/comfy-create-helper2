### REQ-136: 任意位置へのセリフ手動追加および吹き出し・テキスト装飾機能

- **Type**: enhancement
- **Status**: done (2026-08-26)
- **Current step**: none
- **Priority**: P2
- **Surface**: セリフ追加を吹き出し検出以外に、任意の位置に付与できるようにしたい。吹き出しの形状と、フォント・文字色・サイズなどの装飾もいじれるようにしたい。カラーピッカーは10件程度、直近に使った色を登録しておいて、”最近使用した色"として再利用できるように。
- **Root Cause**: 吹き出し自動検出では拾いきれないセリフの手動追加や、シーン・感情に合わせた吹き出し形状やフォント・色彩等の細やかな表現を画像上で行う手段が存在しないため、直感的なセリフ配置・スタイリング機能が必要である。
- **Requirement**: 画像上の任意位置にダブルクリック/ダブルタップでセリフを追加・配置・移動し、吹き出し形状（楕円・角丸・叫び・思考・枠なし等）の選択、尻尾ドラッグ調整、縦横書き切り替え、フォント・文字色/背景色/枠線色（RGBA）・サイズ・太さ等の装飾を個別設定でき、直近使用色（10件）を再利用できるエディタ機能を提供する。
- **Design doc**: docs/design/REQ-136.md

#### Acceptance Criteria (AC)

##### 1. 任意位置へのセリフ追加・移動・削除（インタラクション）
- [ ] AC-1-1: プレビュー/画像上の任意位置をダブルクリックまたはダブルタップすることで、その位置に新規セリフ吹き出しを追加できること。
- [ ] AC-1-2: セリフ追加時、モーダルまたは連携するテキスト入力エリアが表示され、セリフテキストを入力・編集できること。
- [ ] AC-1-3: 画像上で吹き出しをドラッグ＆ドロップして任意の位置へ移動できること。
- [ ] AC-1-4: 編集中の吹き出しはフォーカス表示され、キーボードの `Delete` キーまたはテキスト入力エリアの削除ボタン押下で削除できること。
- [ ] AC-1-5: 吹き出しの尻尾（突起）に調整ハンドルが表示され、画面上のドラッグ＆ドロップで尻尾の位置・向きを調整できること。

##### 2. 吹き出し形状のカスタマイズ
- [ ] AC-2-1: 以下の吹き出し形状を選択・切り替えできること：
  - 通常の楕円 (Oval)
  - 角丸四角 (Rounded Rectangle)
  - 叫び・トゲトゲ (Shout / Burst)
  - 思考・モコモコ (Thought / Cloud)
  - 枠なし / テキストのみ (Plain Text / No Bubble)
- [ ] AC-2-2: 各形状に応じてテキスト領域が適切に内包され、はみ出しなく配置されること。

##### 3. テキスト装飾・タイポグラフィ設定
- [ ] AC-3-1: テキストの配置方向として「縦書き」（デフォルト）および「横書き」を切り替え可能であること。
- [ ] AC-3-2: フォントファミリの選択、およびフォントサイズの変更ができること。
- [ ] AC-3-3: 文字色について、RGB値に加えて透明度（Alpha）を含むRGBAカラーを指定・変更できること。

##### 4. 吹き出しスタイル装飾設定
- [ ] AC-4-1: 吹き出しの背景色について、RGBおよび透明度（Alpha）を含むRGBAカラーを指定・変更できること。
- [ ] AC-4-2: 吹き出しの枠線色（RGBA）および枠線の太さ（Border Width）を指定・変更できること。
- [ ] AC-4-3: 設定した吹き出し形状および装飾スタイルがプレビュー画面上に即座に反映されること。
- [ ] AC-4-4: カラーピッカーにおいて、直近に使用した色（RGBA）を最大10件保持し、「最近使用した色」パレットからワンクリックで再利用できること。
