### REQ-064: 複数選択と一括操作機能の導入

- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: Phase 2 (Detailed Design) 完了 → Phase 3 (Task Decomposition) 完了
- **Priority**: P2
- **Surface**: 生成ページの履歴からの保存や、各種一覧画面でのD&Dでの並び替えなど、複数の個体へ同等のアクションを行う系は、複数選択して一括で操作できるようにしたい。よくある形式で、ctrl押しながらで任意の複数選択、shift押しながらで範囲選択という感じのイメージ。長押しで複数選択モードに遷移できること。
- **Root Cause**: 大量のアイテムに対する操作（保存、並び替え、編集、削除、アルバム追加など）を1つずつ行う必要があり、UIの操作摩擦が発生している（Interactionの課題）。
- **Requirement**: 各種一覧画面における共通の複数選択UIパターンを定義・導入し、一括アクション（ドラッグ＆ドロップでの塊移動、一括編集、一括削除、一括アルバム追加・保存）を実装する。
- **Acceptance criteria**:
  - [ ] AC-1: **【複数選択インタラクション】** 対象のリスト項目に対し、`Ctrl + クリック`で個別追加/解除、`Shift + クリック`で範囲選択ができること。
  - [ ] AC-2: **【複数選択モードへの遷移・解除】** 対象項目を長押し（ロングタップ/ロングプレス）することで「複数選択モード」に移行し、チェックボックスなどの選択状態を示すUIが表示されること。画面右上等に「複数選択モード解除」ボタンを配し、クリックで選択解除およびモード終了できること。
  - [ ] AC-3: **【生成履歴の一括保存】** 生成ページの履歴一覧から、複数選択した項目を一括でスナップショットとして保存できること。
  - [ ] AC-4: **【LoRA管理の一括操作】** LoRAカード一覧で複数選択し、(1) D&Dで選択アイテム群をひとかたまりとして一括で並び替えること、(2) 一括でカテゴリ設定および強度設定を編集できること。
  - [ ] AC-5: **【タグセット管理の一括操作】** タグセットカード一覧で複数選択し、(1) D&Dで一括並び替え、(2) 一括でカテゴリ設定を編集できること。
  - [ ] AC-6: **【スナップショット一覧の一括アルバム追加】** スナップショット一覧から複数選択し、一括で指定アルバムに追加（「アルバムに追加」ダイアログでの一括登録）ができること。
  - [ ] AC-7: **【アルバム詳細の一括操作】** アルバム内の画像一覧で複数選択し、(1) D&Dでの一括並び替え、(2) アルバムからの一括削除ができること。
  - [ ] AC-8: **【設定画面のパラメータ一括操作】** 設定ページのマッピングマスタ項目一覧で複数選択し、(1) D&Dでの一括並び替え、(2) 一括でParam NameやInput Typeを設定・編集できること。
