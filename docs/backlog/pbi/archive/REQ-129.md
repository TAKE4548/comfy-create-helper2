### REQ-129: モバイル環境におけるパラメータ同期設定モーダルの表示・連動不具合の修正

- **Type**: defect
- **Status**: done (2026-08-26)
- **Priority**: P2
- **Surface**: モバイル画面（画面幅1024px未満）において、パラメータパネル（`ParamPanel`）からパラメータ同期設定モーダル（`ParamSyncModal`）を開くボタンを押してもモーダルが表示されない。
- **Root Cause**: `frontend/src/pages/GeneratePage/components/MobileLayout.tsx` 内で `ParamSyncModal` コンポーネントおよびその開閉状態（`isParamSyncSettingsOpen`）、Storeからの同期グループ情報（`paramSyncGroups`, `toggleParamSyncGroup`）、`<ParamPanel />` への各種プロパティ伝達が実装漏れしているため。
- **Requirement**: モバイル画面環境においても、デスクトップ環境と同様に `ParamSyncModal` を開いてパラメータ同期グループの追加・編集・削除およびトグル操作を行えるようにする。

#### Acceptance Criteria (AC)
- [ ] AC-1: モバイル画面（`MobileLayout`）で `ParamPanel` のパラメータ同期設定管理ボタンを押下した際、`ParamSyncModal` が正常に表示されること。
- [ ] AC-2: モバイル画面上で `ParamSyncModal` を操作し、パラメータ同期グループの追加・編集・削除および有効/無効トグルを正常に行えること。
- [ ] AC-3: `ParamSyncModal` を閉じた際、または背景・キャンセルボタンを押した際にモーダルが正常に閉じられること。
