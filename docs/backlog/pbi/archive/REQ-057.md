### REQ-057: LoRA Stack設定の反映不具合および表示名改善

- **Type**: defect
- **Status**: done (2026-08-30)
- **Current step**: none
- **Priority**: P2
- **Surface**:
  - LoraStackに対応したが、Jsonアップロード時にワークフロー側の設定値が反映されない。値はモデル・強度共に一切が未反映で手入力で追加からしないといけない。ブラウザコンソールに "The specified value '889,0' cannot be parsed, or is out of range" などのパース警告が発生。
  - また、品質UP系Loraとキャラ・服装系などで複数のLoraStackを分けるケースがあるが、パラメータ欄のタイトルがどちらも”LoRA Stack"で判別できない。
- **Root Cause**:
  - JSONワークフローのアップロード時におけるLoRA Stackノードのデータバインド処理に不具合があり、設定値（モデル名や強度）が正常に読み込まれていない。また、カンマ区切り値やフォーマットの相違によりパース警告が生じている。
  - パラメータ表示欄のタイトルが固定文字列 "LoRA Stack" になっているため、ワークフロー内の複数ノードを個別のカスタムタイトル（title）で識別できない。
- **Requirement**:
  - JSONワークフロー読み込み時に、LoRA Stackで設定されているモデル名および強度が正しく復元され、パラメータ入力欄に反映されること。
  - パラメータ入力欄におけるLoRA Stackの表示名を、ComfyUI側で設定したノードのカスタムタイトル（title）にし、複数存在する場合でも識別可能とすること。
- **Acceptance criteria**:
  - [ ] AC-1: LoRA Stackを含むJSONワークフローを読み込んだ際、設定済みのLoRAモデルおよび強度がパラメータ欄に自動で復元されること。
  - [ ] AC-2: JSON読み込みおよびパラメータ反映時に、「The specified value ... cannot be parsed, or is out of range」などのパースエラーが発生しないこと。
  - [ ] AC-3: ワークフロー内に複数のLoRA Stackノードがある場合、パラメータ欄の表示名として、それぞれのノードのカスタムタイトル（title）が表示されること。カスタムタイトルがない場合はデフォルト名「LoRA Stack」が表示されること。
