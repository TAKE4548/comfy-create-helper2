# REQ-028: バッチ数に基づく複数画像生成および生成中のキューイング対応

- **Type**: defect
- **Status**: done (2026-08-30)
- **Current step**: none
- **Priority**: P1
- **Surface**: バッチ数を設定しても生成が1リクエストしか飛ばない。また、現在は生成待機中、生成ボタンが押せないが、ComfyUI側のQueueに積まれるので、生成中でもリクエストを飛ばせるようにしたい。
- **Root Cause**: GeneratePage.tsx において batchSize が handleGenerate に渡されているが、ループして queuePrompt を呼ぶ処理が実装されていない。また、生成ボタンの無効化（disabled）条件に自セッション生成中（isGenerating && activeClientId === clientId）が含まれているため、キュー追加がブロックされている。
- **Requirement**:
  1. 生成画面の「Generate Batch」ボタン押下時に、指定された「Batch Size」の数だけ生成要求（queuePrompt）がComfyUIへ送信されること。
  2. 生成要求ごとに、シードモードが「random」の場合は新しい乱数が生成され、「fixed」の場合はシード値が順次インクリメントされて送信されること。
  3. 自セッションが生成中（処理中・待機中含む）であっても、「Generate Batch」ボタンは無効化されず、追加の生成リクエストを ComfyUI のキューに順次投入できること。
- **Acceptance criteria**:
  - AC-1: 生成画面で「Batch Size」を 2 以上の値に設定して「Generate Batch」をクリックした際、ComfyUI への `/prompt` 送信（`queuePrompt`）が設定されたバッチサイズ数だけ連続して呼び出されること。
  - AC-2: 送信されるプロンプトに含まれる `seed` が、シードモード「random」時には各回ごとに異なるランダムな数値になっており、「fixed」時には指定したシード値から 1 ずつインクリメントされた数値になっていること。
  - AC-3: 自セッションが生成実行中（プログレス表示中など）でも、「Generate Batch」ボタンが非活性（disabled）にならず、再度クリックすることで追加のジョブを ComfyUI のキューに追加できること。
- **Design doc**: none
