### REQ-047: 生成中の進捗更新によるモーダル再生成・操作不能問題の修正

- **Status**: done (2026-08-30)
- **Description**: 画像生成処理の進行中に WebSocket 経由で progress 情報が送られて画面が再レンダリングされる際、モーダル（スナップショット保存、ジョブ管理等）が毎回の進捗更新ごとにアンマウント・再マウントされるため、フォーカス喪失や入力内容リセットが発生して操作できなくなる問題を解決する。

#### Acceptance Criteria (AC)
- [ ] AC-1 (Modal Behavior): 画像生成進行中（進捗 percentage が更新されるタイミング）であっても、スナップショット保存モーダルやその他のモーダルのフォーカスが失われたり表示状態がリセットされることなく、正常に入力・操作を行えること。
- [ ] AC-2 (Code Implementation): `GeneratePage.tsx` 内で定義されているネストされた `Modals` 関数コンポーネントを廃止し、モーダルを描画する JSX が適切にインライン化、または別個の独立したコンポーネントとして外出しされていること。
