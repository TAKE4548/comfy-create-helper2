### REQ-077: バックエンド schemas.py のリソース単位分割リファクタリング

- **Status**: done (2026-08-26)
- **Description**: バックエンドの `backend/app/schemas/` フォルダ配下、または単一ファイルとして肥大化している Pydantic スキーマ定義をリソース（Snapshot, Lora, TagSet, Album など）ごとに分割整理し、保守性を向上させる。

#### Acceptance Criteria (AC)
- [ ] AC-1: `backend/app/schemas/` ディレクトリ内に各リソースに対応する Pydantic モデル定義ファイル（例: `snapshot.py`, `lora.py`, `tag_set.py` 等）を物理的に分割する。
- [ ] AC-2: `backend/app/schemas/__init__.py` において分割されたスキーマ定義を re-export し、既存のインポート参照コード（routers 等）を破壊しないようにする。
- [ ] AC-3: リファクタリング前後で既存のバックエンド単体テストがすべてPASSすること。
