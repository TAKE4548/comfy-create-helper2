### REQ-254: 生成ワークフロー差分推測・スマート置換（トポロジー解析とプリセット維持）

- **Type**: enhancement
- **Status**: done (2026-09-12)
- **Current step**: none
- **Priority**: P1
- **Surface**:
  - ComfyUI 側でワークフローの改善・編集（ノード再生成、配線変更、Detailer 追加等）を行った際、Prompt Surgeon 側の既存ワークフローの JSON（json_body）のみを安全に差し替える仕組みがない。
  - 単純なワークフロー再登録や ID / タイトルによる単純一致では、ComfyUI の仕様（ノード再生成に伴う ID 変更、ID 再利用、リネーム）によりノードの誤同定が発生し、既存のプロファイル（プリセット群）、バイパス設定、ParamSync 等の独自アセットが切断・消失する課題がある。
- **Root Cause**:
  - (Interaction & Information Design / 差分可視化および対話的移行機構の欠如):
    - DAG（有向非巡回グラフ）の入出力トポロジーに基づく高精度な新旧ノード同定エンジンが存在しない。
    - 新旧ノードの役割引き継ぎ状態や配線差分をユーザーが視覚的に確認・調整できる対話型 UI（Master-Detail インスペクター）が提供されていない。
    - ワークフロー更新時に既存アセット（プリセット・マッピング）を不可逆破壊しない安全な置換トランザクションおよびロールバック機構が未整備である。
- **Requirement**:
  - 新旧ワークフロー JSON のクラス型、入出力接続（上流・下流トポロジー）、タイトル、ID を総合評価し、新旧ノードの対応関係（Renamed / Re-indexed / Substituted / False Reuse / Added / Removed）を高精度に自動推測する解析エンジンを提供すること。
  - 解析結果を提示し、ユーザーが役割（Role）引き継ぎの確認・手動補正を行える上下配置型モーダル（上段: 役割移行表、下段: 局所トポロジー差分インスペクター）を提供すること。
  - 既存プロファイル（プリセット値）やパラメータ同期設定（ParamSync）を維持したまま、新ワークフロー JSON と新マッピングを一括・アトミックに確定置換できること。
  - 必須ロール消失時のバリデーション（確定抑止）および、直前スナップショットへのロールバック手段を提供し、安全性を担保すること。
- **Acceptance criteria**:
  - [ ] AC-1: 新規 JSON 投入時に、ノード再生成による ID 変更やリネームがあっても、上流・下流トポロジーから高精度に新旧ノードの役割が自動推測・マッピング候補として提示されること。
  - [ ] AC-2: 偶発的なノード ID 再利用（False Reuse）がトポロジー不一致として正しく検知され、誤ったマッピング引き継ぎが防止されること。
  - [ ] AC-3: 差分レビューモーダルにおいて、上段の役割一覧と下段の配線対比インスペクターが連動し、ユーザーが手動で割当先ノードの修正・確認ができること。
  - [ ] AC-4: 確定置換を実行した際、既存のプロファイル（プリセット値）および ParamSync 設定が維持され、画面遷移・再読み込み後も正しく機能すること。
  - [ ] AC-5: 必須ロール（プロンプトやサンプラー等）が未割当のままでは置換を確定できないバリデーションが機能すること。
  - [ ] AC-6: 置換実行直前に旧状態が自動退避され、操作ミス時に直前のワークフローおよびマッピング状態へ復元（ロールバック）できること。
