### REQ-093: TagChipEditorドラッグ＆ドロップ並び替えテストの追加

- **Status**: done (2026-08-26)
- **Description**: `TagChipEditor` のうち、未テストであった `@dnd-kit` を使用したドラッグ＆ドロップによるチップ並び替え動作のテストを追加します。また、状態管理履歴（Undo/Redo）の安定性や、`Math.random()` による非決定論的 ID 生成の改善を含めたリファクタリングを実施します。

#### Acceptance Criteria (AC)
- [ ] AC-1: ドラッグ終了イベント（`handleDragEnd`）をモックまたはDOM操作で発生させ、チップの順序が更新され `onChange` コールバックに正しい文字列が渡されるテストを追加すること
- [ ] AC-2: Undo/Redo（`Ctrl+Z` / `Ctrl+Y`）の実行時、履歴スタックが正常に維持されることを検証するテストを追加すること
- [ ] AC-3: チップ生成時の ID を `Math.random()` から、インクリメンタルカウンターやタイムスタンプを組み合わせた決定論的・衝突耐性のある方式に変更すること
- [ ] AC-4: コンポーネントのアンマウント時にグローバルカスタムイベント（`tag-chip-editor:disable-tag`等）のリスナーが正常に解除されるテストケースを追加すること
