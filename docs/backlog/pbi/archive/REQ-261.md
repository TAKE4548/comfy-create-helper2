### REQ-261: 生成プリセット一括編集モーダルでのサンプラ・スケジューラ選択肢の正常表示

- **Type**: defect
- **Status**: done (2026-09-15)
- **Current step**: none
- **Priority**: P1
- **Surface**:
  - 生成プリセットの一括編集で、スケジューラ・サンプラのセレクタに選択肢が表示されない。checkpointは正常に表示される。
- **Root Cause**:
  - `frontend/src/pages/GeneratePage.tsx` の `ProfileBulkEditModal` 呼び出し部において、`comfyObjectInfo` の Props 伝達が漏れており `undefined` となっていた。
  - `frontend/src/components/ProfileBulkEditModal.tsx` において、`comfyObjectInfo` 不在時・オフライン時の定数フォールバック（`DEFAULT_SAMPLERS` / `DEFAULT_SCHEDULERS`）が実装されておらず、選択肢リストが空配列となっていた。
- **Requirement**:
  - 生成プリセット一括編集モーダルにおいて、サンプラおよびスケジューラのドロップダウンに最新の選択肢候補が正常に表示されること。
  - オフライン時や定義未取得時でも定数フォールバックにより選択肢が表示されること。
  - 選択したサンプラおよびスケジューラが一括編集の適用処理で正しくプリセットに反映されること。
- **Acceptance criteria**:
  - [ ] AC-1: 生成プリセット一括編集モーダルのパラメータタブにおいて、サンプラ選択ドロップダウンに利用可能なサンプラ候補一覧が表示され、任意の値を選択できること。
  - [ ] AC-2: 生成プリセット一括編集モーダルのパラメータタブにおいて、スケジューラ選択ドロップダウンに利用可能なスケジューラ候補一覧が表示され、任意の値を選択できること。
  - [ ] AC-3: ComfyUI からの定義取得ができないオフライン時や待機時でも、サンプラおよびスケジューラの選択肢が定数フォールバックによって表示されること。
  - [ ] AC-4: 一括編集モーダルで選択したサンプラ・スケジューラの設定が、対象プリセット群に正常に反映・適用されること。
- **Design doc**: none
