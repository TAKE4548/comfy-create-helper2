### REQ-036: LoRA登録時のモデルパス選択機能の追加

- **Status**: ready
- **Type**: enhancement
- **Priority**: P2
- **Current step**: none
- **Surface**:
  LoRA管理画面で新規LoRAを登録する際、パスを手入力だけでなく、ComfyUIで登録済みのモデルをセレクタ的に選択するようにしたい。
  未だLoRA管理に未登録のものが優先的に上位に表示されるようにし、登録済みのものは非表示ではなくグレーアウトなどで差別化するとともに選択できないようにして、参照エラーではないことがわかるように。
  また、レアケースだがComfyUIに先行して登録する場合用に、直接入力も可能としておきたい。
  仕様の詳細として、
  1. 入力はコンボボックス形式とし、候補から選択もできれば、手入力で任意のパス指定することも可能とする。
  2. ComfyUIのLoRAフォルダ内のサブフォルダ構造（相対パス）を含めて候補リストに表示・検索可能とする。
  3. 登録済みのモデルはグレーアウトされ選択不可とし、さらに「登録済み」バッジを表示する。

- **Root Cause**:
  現在のLoRA登録フォームでは、ファイルパスを完全に手動で入力する必要があり、タイポによる参照エラーが発生しやすい。また、ComfyUIに存在するモデルのうちどれが既にシステムに登録済みであるかをフォーム上で確認する術がなく、重複登録や確認の手間が発生している。

- **Requirement**:
  - **コンボボックスによるパス入力**: LoRA登録・編集フォームのファイルパス入力フィールドを、ComfyUI側で認識されているLoRAモデルファイル一覧を選択・検索できるコンボボックス（セレクトボックスかつ直接入力可能な入力フィールド）に変更する。
  - **ComfyUIモデル情報の取得**: ComfyUI側のLoRAディレクトリ（サブディレクトリ含む）から利用可能なモデル一覧（例: 相対パス `subdir/model.safetensors`）を取得し、フロントエンドに提供する。
  - **リスト内の順序とステータス制御**:
    - **未登録モデル優先表示**: データベースに登録されていないComfyUI内のLoRAモデルを上位に優先して並べる。
    - **既登録モデルの差別化**: 既にデータベースに登録されているLoRAモデルはリスト内で非活性（グレーアウト・選択不可）にし、二重登録を防ぐ。
    - **視覚的バッジの表示**: 既登録モデルの選択肢の横に「登録済み」などのバッジ（バッジ/チップ）を配置し、ステータスを明示する。
  - **直接入力の許容**: リストに存在しないファイルパスであっても、直接キーボード入力を行って新しいパスを登録できるようにする。

- **Acceptance criteria**:
  - [ ] AC-1: **コンボボックス型パス入力UI**: 新規登録および編集時のパス入力欄が、ComfyUI上のモデルパス一覧を表示するドロップダウン付きの入力フィールド（コンボボックス形式）になっており、手動入力と選択の両方に対応していること。
  - [ ] AC-2: **相対パスの階層構造表示**: 候補リストには、ComfyUIのLoRAディレクトリ配下のサブフォルダ構造を含んだ相対パス（例: `folder/subfolder/model.safetensors`）が表示されること。
  - [ ] AC-3: **二重登録防止と視覚的差別化**: 既にDBに登録されているLoRAモデルパスは、ドロップダウンリスト内で非活性（グレーアウト・クリック選択不可）になっており、かつ「登録済み」であることが視覚的にわかるバッジやラベルが表示されていること。
  - [ ] AC-4: **未登録モデルの優先ソート**: ドロップダウンリスト内で、未登録のモデルパスが、登録済みのモデルパスよりも上部に優先してソートされて表示されること。
  - [ ] AC-5: **先行手動入力機能**: リスト内に該当するモデルが存在しない場合（ComfyUIに置く前の先行登録時など）でも、任意のパス文字列を直接入力してそのまま登録フォームを送信・保存できること。

- **Design doc**: none
