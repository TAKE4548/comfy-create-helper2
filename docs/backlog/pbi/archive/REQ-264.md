### REQ-264: 生成プレビューの最新自動追従と固定（ロック）のトグル切り替え

- **Type**: enhancement
- **Status**: done (2026-09-24)
- **Current step**: none
- **Priority**: P2
- **Surface**:
  - 現状、生成画面のプレビューはフォーカスしてると、新しい生成画像が追加されても保持されるが、連動して自動的に画像が更新される設定と現状同等のプレビュー対象をロックする設定を手軽にトグルで切り替えれるようにしたい。
  - PCだとプレビューエリアが広いのでフォーカスしなくても見やすいが、モバイルではフォーカスしないと見えないため、フォーカス状態で生成毎に自動で更新してもらって確認したいときに、いちいち閉じて完了を確認して明示的に次の画像をまたフォーカスしないといけないのが割と手間。
  - 現状のロックしてじっくりみるユースもあるので、簡単にトグルできるボタンなどがあるといい。
- **Root Cause**:
  - **Interaction Design (Workflow Friction & Mode Inflexibility)**:
    - プレビュー画面（フォーカス表示）において、表示対象画像が常に「選択中画像に固定（ロック）」される仕様のみとなっており、ユーザーのタスク（「連続生成した最新画像の即時確認」vs「特定画像の詳細観察」）に応じた表示追従動作の切り替え手段が提供されていない。
    - 特にモバイル等の画面サイズが制約されるデバイスでは、生成画像を詳細確認するためにフォーカス表示が必須となるが、新規生成のたびに「フォーカスを閉じる → 完了確認 → 新規画像をタップして再フォーカス」という反復的な画面遷移・操作負荷が発生している。
- **Requirement**:
  - 生成画面のプレビュー表示（特にフォーカス表示状態）において、新規生成画像が追加された際に自動的に最新画像へ表示を更新する「自動追従モード」と、現在表示中の画像を維持する「固定（ロック）モード」を素早く切り替え可能にすること。
  - モバイル環境を含む各デバイスにおいて、フォーカス画面を閉じることなくワンタップでモードを切り替えられるアクセシビリティを確保すること。
  - 現在どちらのモード（自動追従かロックか）が有効であるかが直感的に判別できるインジケータまたはトグルUIを提供すること。
- **Acceptance criteria**:
  - [ ] AC-1: プレビュー画面（フォーカス表示含む）において、「最新画像への自動追従」と「現在画像の固定（ロック）」を切り替えられるトグル操作UIが提供されること。
  - [ ] AC-2: 「自動追従」が有効な場合、フォーカス表示中であっても新規生成画像が追加された際にプレビュー/フォーカス表示対象が自動的に最新の生成画像に切り替わること。
  - [ ] AC-3: 「固定（ロック）」が有効な場合、新規生成画像が追加されても現在フォーカス・プレビューしている画像が維持され、意図しない画像切り替えが発生しないこと（従来の挙動が保持されること）。
  - [ ] AC-4: 現在有効なモード（自動追従かロックか）がユーザーに一目でわかるよう、アイコンやラベル等の視覚的フィードバックが提供されること。
  - [ ] AC-5: モバイル等の狭小画面においてもフォーカス状態を維持したまま容易にトグル切り替えが可能であり、連続生成時にモーダル等の開閉や手動の再選択操作を行わずに最新画像を連続確認できること。
  - [ ] AC-6: 切り替えた追従/ロック設定の状態が、意図しないタイミングでリセットされず、操作セッションを通じて適切に維持されること。
- **Design doc**: none
