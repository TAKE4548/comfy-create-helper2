### REQ-337: Prompt Surgeon: ComfyUI /object_info 連動 ClassType 動的オートコンプリート・ノード検索

- **Type**: feature
- **Status**: done (2026-10-11)
- **Priority**: P2
- **Surface**:
  - frontend/src/api/domains/comfy.ts
  - frontend/src/hooks/useComfyNodeTypes.ts
  - frontend/src/components/MappingMasterEditModal.tsx
- **Background / Motivation**:
  - REQ-336（ワークフローマッピング新アーキテクチャ）において、マッピングマスタ編集時の Class Types 入力は静的候補パレットと手入力で実装された。
  - カスタムノードの追加や未知のノードクラスに対応するため、接続中の ComfyUI の /object_info API から利用可能な全ノードクラスを動的に取得し、インクリメンタルなオートコンプリート候補として表示・追加できるようにする。
- **Requirement**:
  1. ComfyUI 接続時に /api/comfy/object_info から利用可能なノードクラス一覧を取得し、フロントエンド側でセッションキャッシュすること。
  2. マッピングマスタ編集モーダルの Class Types 入力欄において、入力文字列に応じたインクリメンタル検索・オートコンプリート候補ドロップダウンを表示し、キーボード（Enter/矢印）またはクリックでチップ追加可能とすること。
  3. ComfyUI 未接続時やAPIタイムアウト時であっても、通常の手入力や静的候補チップの利用を阻害しないノンブロッキング・グレイスフル設計とすること。
- **Acceptance criteria**:
  - [ ] AC-1: Given ComfyUI 接続状態, When マッピングマスタ編集モーダルの期待 Class Types 入力欄にキーワードを入力する, Then ComfyUI のノード定義から合致するクラス名がリアルタイムに候補表示され、選択追加できること。
  - [ ] AC-2: Given ComfyUI 未接続状態またはAPIエラー発生時, When Class Types を入力する, Then エラーで画面がブロックされず、通常の手入力および既存の静的候補パレットによる追加が可能であること。
  - [ ] AC-3: Given オートコンプリートからクラス型を追加したとき, Then 重複追加が防止され、正規のチップとして登録されること。
