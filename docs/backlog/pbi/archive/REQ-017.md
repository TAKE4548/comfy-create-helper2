### REQ-017: キャラクターLoRA用の詳細プロンプト入力欄の追加

- **Status**: done (2026-08-26)
- **Type**: enhancement
- **Priority**: P1
- **Current step**: none
- **Surface**: キャラクターLoRA系の詳細プロンプト（Face/Other）を入力・設定するための欄が画面上にない。
- **Root Cause**: マッピングマスタ（`mapping_master`）に `Prompt_Char_Lora_Face`（キャラクターLoRA用顔プロンプト）および `Prompt_Char_Lora_Other`（キャラクターLoRA用その他プロンプト）の役割（Role）が定義されていない。このため、ワークフロー内の対応するノードを正しくマッピングできず、Generate画面上に入力欄を表示させることができない。
- **Requirement**:
  1. **マッピングマスタ定義の追加**:
     - データベースの `mapping_master` に、`Prompt_Char_Lora_Face` と `Prompt_Char_Lora_Other` の役割を定義するシードデータを追加する。
     - 初期シードスクリプト（`backend/app/main.py`）を更新し、新規DBセットアップ時にこれらが追加されるようにする。
     - 既存のDBに対しても、起動時またはマイグレーション時にこれらのマスタが自動的に挿入されるように更新する。
  2. **自動スキャンの対応**:
     - `workflow_scanner.py` において、`Prompt_Char_Lora_Face` および `Prompt_Char_Lora_Other` のタイトルパターンを正しくマッチングできるようにする。
  3. **マッピングの紐付けと画面表示**:
     - スキャンまたは手動設定でこれら2つのノードがマッピングされた際、Generate画面に「Character LoRA Face」および「Character LoRA Other」として独立したプロンプト入力テキストエリア（TagChipEditor）が動的に表示されること。
     - 入力されたプロンプトが、ComfyUIの生成実行時（`handleGenerate`）に該当ノードへ正しく送信されること。

#### Acceptance Criteria (AC)
- [ ] AC-1: マッピングマスタ（`mapping_master`）テーブルに `Prompt_Char_Lora_Face` および `Prompt_Char_Lora_Other` の役割（Role）定義が正しく存在すること。
- [ ] AC-2: 生成画面のワークフロー再スキャン（RescanModal）において、`Prompt_Char_Lora_Face` と `Prompt_Char_Lora_Other` のノードが自動的にそれぞれの役割にマッチングされること。
- [ ] AC-3: マッピング完了後、Generate画面の左カラムに「Character LoRA Face」および「Character LoRA Other」のプロンプト入力エリア（TagChipEditor）が動的に生成され、入力が可能であること。
- [ ] AC-4: 生成実行時、入力されたキャラクターLoRA用のプロンプト値が、ComfyUIワークフローJSONの該当するノードのインプット値に正しく差し込まれて送信されること。
- [ ] AC-5: ワークフロー `ume_` に設定されていた誤ったマッピング（`Prompt_Composition` や `Prompt_Background_Environment` への割り当て）が、正しいノードマッピングに修正され、保存できること。
