### REQ-172: セリフ生成（吹き出しエディタ）の作業性・操作性向上

- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Priority**: P1
- **Surface**: セリフ生成の作業性を向上させたい
  - プリセットに修飾だけでなく、テキストも保存して再利用できるようにしたい。テキストまで欲しいケースはSE系の吹き出しで、キャラ特性とかではテキストなしで登録したくなるので、プリセットの保存・上書き時にテキストエリアを含めるか選ぶオプション形式で欲しい。テキストエリアを登録しないパターンのプリセットは、ロード時にテキストエリアを上書きしないように。
  - 吹き出しサイズの自動調整と回転が頻出するが、テキストエリアからの導線が遠く、分散もしていて使いにくいので、都度調整する系をテキスト入力エリア付近に集約したい。フォントサイズ・フォント・色などは一度作ったらプリセットで切替ることが多く、回転・文字方向・枠サイズは画像ごとに調整が入りやすい。
  - 吹き出しの回転をプレビューエリアでのドラッグ&ドロップでも設定できるようにしたい(よくある回転用ハンドルのイメージ)
  - 各所パラメータ系(フォントサイズや回転など)は、スライダーに加えて単位ごとに増減するボタンも欲しい(微調整用)
- **Root Cause**:
  1. **情報設計・データモデルの制約**: プリセット保存・適用においてテキスト内容の包含可否を選択できず、SE（効果音）などの定型テキストの再利用と、キャラごとのスタイル適用（テキスト保持）を両立できない。
  2. **情報設計・導線の分散**: 生成画像ごとに頻繁に変更・調整する「枠サイズ自動調整」「回転」「文字方向」の操作コントロールがテキスト入力エリアから離れた場所に散在しており、操作時の視線移動とマウスポインタの移動距離が大きい。
  3. **インタラクション設計（直感操作の欠如）**: 吹き出しの回転調整が数値入力やスライダーのみに依存しており、画像プレビュー上での直感的なドラッグ操作（回転ハンドル）が提供されていない。
  4. **インタラクション設計（微調整性の不足）**: スライダー主体のUIでは1単位刻み（ステップ単位）での細かな微調整が難しく、操作ストレスが生じている。
- **Requirement**:
  1. プリセット保存・更新時に「テキストを含める」可否を選択可能にし、ロード時はテキストが未保存のプリセット適用時に既存テキストを保護（非破壊）する。
  2. 都度調整頻度が高いパラメータ（枠サイズ自動調整、回転、文字方向）をテキスト入力エリア周辺に集約・再配置し、作業導線を最適化する。
  3. プレビューエリア内の吹き出し上に回転用ドラッグハンドルを設け、キャンバス上の直接操作で角度調整を可能にする。
  4. フォントサイズや回転角度などの主要数値調整コントロールにおいて、スライダーと連動するステップ増減（+/-）ボタンを提供する。
