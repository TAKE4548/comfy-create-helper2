### REQ-035: 生成ページでseedをランダムにしても、ランダムになっていないバグの修正

- **Type**: defect
- **Status**: done (2026-08-26)
- **Current step**: none
- **Priority**: P1
- **Surface**: 生成ページでseedをランダムにしても、ランダムになっていない
- **Root Cause**: `useGenerateAction.ts` 内のシード注入ロジックにおいて、パラメータ名が `'seed'` にハードコードされているため、プリミティブノードなどの `'value'` キー等でマッピングされている場合にランダムシード値が反映されず、固定値のまま送信されてしまう。
- **Requirement**: シードランダム設定時に、マッピング対象のシードパラメータ名（`m.param_name` または `'value'` 等の動的なキー）に対して適切にランダム値が設定されるようになること。
- **Acceptance criteria**:
  - AC-1: シード設定を「Shuffle（ランダムモード）」にした場合、画像生成実行ごとに異なるシード値（ランダムな整数値）が ComfyUI へのリクエストパラメータ（対象ノードの対応キー）に代入されて送信されること。
  - AC-2: シード設定を「Lock（固定値モード）」にした場合、指定したシード値（およびバッチインクリメントされたシード値）が適切に ComfyUI へのリクエストパラメータに代入されて送信されること。
  - AC-3: 画像生成処理が正常に終了し、クラッシュ等のエラーが発生しないこと。
- **Design doc**: none
