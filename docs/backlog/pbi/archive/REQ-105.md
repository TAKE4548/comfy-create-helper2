### REQ-105: Scene Generatorの追加調整

- **Type**: enhancement
- **Status**: ready
- **Current step**: none
- **Priority**: P2
- **Surface**:
  - 使うLLMのモデルを切り替えたい。後述の設定画面で選択できるようにしたい。
  - ベースのプロファイルを選択できない
  - 生成がいまいち&適用先の入力欄も適切でない
  - 上記も含めたLLM挙動の調整をコード以外でできるように、これ用のシステムプロンプトを設定画面で設定できるようにしたい
- **Root Cause**:
  - Scene GeneratorでLM Studioを使用する際、利用可能なモデルが動的に取得されず、モデルの切り替えが不可能であること。
  - ベースとなるプロファイルが現在のパラメータ値に固定されており、保存済みプロファイルから選択して開始できないこと。
  - LLMの抽出精度やプロンプトマッピングの精度が不足しており、またそれを微調整するためのシステムプロンプトが固定されているため、コードを変更せずに挙動を制御できないこと。
- **Requirement**:
  - 設定画面で、LM Studioに登録されているモデルの一覧をAPI経由で動的に取得してリスト表示し、そこから使用するモデルを選択・保存（永続化）できること。
  - 設定画面で、Scene Generator用のシステムプロンプトをテキストエリアで編集・保存（永続化）できること。
  - Scene Generatorモーダル起動時、ベースとなるプロファイルを保存済みのプロファイル一覧からドロップダウン等で選択できるようにすること（デフォルトは現在のパラメータ値）。
  - LLMでのドラフト生成時に、ユーザーが設定したシステムプロンプトと選択したモデルを使用してAPIを実行し、指定されたパラメータ欄（ポーズ、構図、表情等）へ正しくマッピングされること。
- **Acceptance criteria**:
  - **AC-1**: 設定画面（Settings）に「Scene Generator設定」エリアが追加され、LM Studioから取得したモデル一覧の選択ドロップダウン、およびシステムプロンプト入力用テキストエリアが表示されること。
  - **AC-2**: 設定画面で選択したモデルおよび入力したシステムプロンプトが保存（永続化）され、次回読み込み時にも保持されること。
  - **AC-3**: Scene Generatorモーダルにおいて、ベースとするプロファイルを「現在のパラメータ値」または「保存済みのプロファイル一覧」から選択できること。
  - **AC-4**: ドラフト生成実行時、設定されたLM Studioのモデルとシステムプロンプトが使用されてLLMリクエストが送信されること。
  - **AC-5**: 設定したシステムプロンプトに基づき、生成された英語プロンプトが適切なパラメータフィールド（ポーズ、構図等）にマッピングされ、タグの数や表現がシーン指示内容を適切に反映していること。
- **Design doc**: none
