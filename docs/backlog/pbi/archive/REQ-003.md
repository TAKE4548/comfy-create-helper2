### REQ-003: サイドバーの折り畳み機能

- **Status**: done (2026-08-26)
- **Type**: enhancement
- **Priority**: P2
- **Current step**: none
- **Surface**: サイドバーを折り畳み可能にしたい
- **Root Cause**: 画面サイズが狭い際や、メインの生成ワークスペースに集中したい場合に、サイドバーが常に固定幅で表示されているため、画面の実表示領域が狭められ、操作やワークフローの確認時に画面が狭く感じられる。
- **Requirement**:
  1. サイドバー上部に、折り畳み（Collapse）および展開（Expand）を行うためのトグルボタン（スイッチ）を提供すること。
  2. トグルボタンを押した際、サイドバーが「ミニバー（アイコンのみの表示状態）」に縮小し、メインコンテンツ領域が自動的に横方向に拡大すること。
  3. ミニバー状態の時、トグルボタンを再度押すと、通常の展開されたサイドバーに戻り、メインコンテンツ領域が元の幅に戻ること。
  4. サイドバーの折り畳み状態（展開/折り畳み）をブラウザの `localStorage` に保存・保持し、画面のリロードや再アクセス時にも前回の状態が引き継がれること。
- **Acceptance criteria**:
  - [ ] AC-1: サイドバー上部（ヘッダー部分等）に折り畳み状態を切り替えるトグルボタンが表示されること。
  - [ ] AC-2: トグルボタンをクリックすると、サイドバーが通常幅からアイコンのみを表示するミニバー状態（幅が狭まった状態）にスムーズに切り替わること。
  - [ ] AC-3: ミニバー状態のときにトグルボタンをクリックすると、通常の展開されたサイドバーにスムーズに復元すること。
  - [ ] AC-4: サイドバーの開閉状態（通常 / ミニバー）が切り替わった際、メインのコンテンツ表示領域（レイアウト）の幅が連動して自動調整されること。
  - [ ] AC-5: サイドバーの状態がブラウザの `localStorage` に保存され、ページをリロードしてもリロード前の開閉状態が維持されること。
- **Design doc**: none
