### REQ-034: Fix blank screen on mobile access to generation main page

- **Type**: defect
- **Status**: done (2026-08-26)
- **Current step**: none
- **Priority**: P1
- **Surface**: スマホから開くと、生成のメインページが表示できない(404ではなく空)
- **Root Cause**: GeneratePage.tsxのモバイルレイアウト（isMobile === true）表示中に、未ハンドリングのJavaScript実行時エラーが発生してReactアプリがクラッシュしている。
- **Requirement**: モバイルレイアウトでの表示時にエラーでクラッシュせず、正常にメインページが表示され、PCと同様に操作ができること。
- **Acceptance criteria**:
  - [ ] AC-1: スマホ（またはPC上のモバイル表示）でアクセスした際、画面が真っ白にならずに生成のメインページが正常に表示されること。
  - [ ] AC-2: 他のルート（/loras, /tags 等）に遷移した後、再度メインページに戻っても正常に表示・操作できること。
- **Design doc**: docs/incident_report.md
