### REQ-247: DesktopLayout / MobileLayout 間のギャラリー・サムネイル操作ロジック共通化（useGalleryInteraction）

- **Type**: refactor
- **Status**: done (2026-09-12)
- **Current step**: none
- **Priority**: P2
- **Surface**:
  - `DesktopLayout.tsx` と `MobileLayout.tsx` において、履歴サムネイルのクリック選択、拡大プレビュー連携、複数選択操作（`useMultiSelect` 連動）、コンテキストメニュー呼び出しなどのイベントハンドラが各コンポーネント内に個別に記述されている。
  - REQ-023（サムネイルホバー拡大・ホイール横スクロール）や REQ-240（複数端末リアルタイム同期）の導入に伴い、レイアウトごとに類似のコードを追加する必要があり、UI挙動の差異や二重修正が発生しやすい。
- **Root Cause**:
  - (UX分類: Interaction / Component Coupling Anti-Pattern): 表示レイアウト（JSX配置）とUIステートマシン・操作ハンドラが密結合しており、デバイス差分（タッチ vs マウスホバー）を吸収する中間フック層が不足している。
- **Requirement**:
  - ギャラリー・サムネイルインタラクション（選択切り替え、ホバー拡大、ホイール横スクロール、複数選択、キーボードナビゲーション）を統括するカスタムフック `useGalleryInteraction` を新設すること。
  - `DesktopLayout.tsx` および `MobileLayout.tsx` から操作ロジックを排出し、プレゼンテーションコンポーネントとして純化すること。
  - デスクトップ特有のマウスホバー・ホイール操作と、モバイル特有のタッチ・スワイプ操作が同一のステートモデル上で競合なく共存できる構造にすること。
- **Acceptance criteria**:
  - [x] AC-1: `useGalleryInteraction.ts` が新設され、サムネイル操作関連のハンドラおよび状態が一元管理されていること。
  - [x] AC-2: `DesktopLayout.tsx` および `MobileLayout.tsx` の重複コードが削減され、共通フック経由で操作が行われていること。
  - [x] AC-3: REQ-023（ホバーズーム・ホイール横スクロール）を実装する際、`useGalleryInteraction` の拡張のみで安全に組み込める設計となっていること。
  - [x] AC-4: 既存の GeneratePage 関連テストおよびコンポーネントテストがすべてパスすること。
