### REQ-096: snapshots.pyにおけるビジネスロジックのサービスレイヤー分離

- **Status**: done (2026-08-30)
- **Description**: `snapshots.py` のルーターハンドラ内に、画像のダウンロード・保存、トランザクション内の複数リレーション作成・削除などのビジネスロジックが集中しています。これらをサービス層（`app/services/snapshot_service.py` など）へ移譲し、ルーターの役割をHTTPハンドリングのみに限定するリファクタリングを実施します。

#### Acceptance Criteria (AC)
- [ ] AC-1: スナップショットの作成、更新、画像ファイル保存に関するロジックをサービスレイヤーに移動すること
- [ ] AC-2: ルーターハンドラ（`snapshots.py`）からはサービスメソッドを呼び出し、レスポンスのスキーマ変換を行うのみの構造に簡素化すること
- [ ] AC-3: データベーストランザクションのスコープがサービス層内で正しく管理され、エラー時のクリーンアップが正しく動作すること
- [ ] AC-4: リファクタリング前後で既存の pytest テストが全て正常にパスすること
