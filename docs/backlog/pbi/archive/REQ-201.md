### REQ-201: 生成プリセット一括編集機能の強化（範囲選択・型安全パラメータ入力・共通タグ抽出削除・タグチップ対応）
- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: Phase 3: Verification & Closure (Completed)
- **Priority**: P2
- **Surface**:
  - 生成プリセットの複数選択時に、全選択・全解除または1件ずつの個別選択しかできず、連続した範囲の選択（Shift+クリック等）ができない。
  - 一括編集モーダルでのパラメータ編集がすべてプレーンテキスト入力となっており、各パラメータの属性（数値、セレクタ等）に応じた直感的な入力や選択ができない。
  - プロンプトの一括編集において、選択された複数プリセットに共通するタグを抽出・列挙し、特定のタグを選択して一括削除する手段がない（例: 共通ベースプロンプトから一部プリセット群のみ特定の服装タグ等をまとめて除去したい）。
  - 一括編集モーダルのプロンプト入力・編集欄がタグチップ形式に対応しておらず、単一編集画面との操作体験に差異がある。
- **Root Cause**:
  - プリセット一覧の選択ロジックに直前選択インデックスを保持した範囲選択（Shiftキー連動）が実装されていない（Interaction Design）。
  - 一括編集モーダルのパラメータ入力フォームが汎用テキストフィールドで構成されており、単一編集時のような型特化（数値スライダー/スピン、サンプラー/スケジューラーセレクタ等）のコントロールが適用されていない（Information / Interaction Design）。
  - 選択中の複数プリセットのプロンプトトークンを解析して共通タグを算出・提示し、差分削除（特定タグの除外）を適用するデータ処理およびUIが存在しない（Information / Interaction Design）。
  - 一括編集モーダル内のプロンプト入力エリアにTagInput / タグチップコンポーネントが組み込まれていない（Visual / Interaction Design）。
- **Requirement**:
  - プリセット一覧において、Shiftキーを押しながらアイテムを選択することで、直前に選択した項目からクリックした項目までの連続した範囲を一括選択できること。
  - 一括編集モーダルにおけるパラメータ編集欄が、各パラメータの型・属性（サンプラーやスケジューラーのドロップダウン、ステップ数やCFG等の数値入力コントロール等）に応じた適切な入力UIで提供され、変更対象のみを直感的に一括適用できること。
  - 選択されている全プリセットのプロンプトから共通して含まれるタグを自動集計・列挙し、ユーザーが不要なタグを選択して一括削除（プロンプトからの除外）できること。
  - 一括編集モーダル上のプロンプト編集欄（追加・削除対象タグ等）がタグチップ形式で表示・操作可能であり、視覚的な確認と個別操作ができること。
- **Acceptance criteria**:
  - [x] AC-1: プリセット一覧画面において、任意の項目を選択した状態でShiftキーを押しながら別の項目をクリックした際、その間の全プリセットが一括で選択状態になること。
  - [x] AC-2: 一括編集モーダルを開いた際、各パラメータ（サンプラー、スケジューラー、ステップ数、CFG、解像度等）がそれぞれの型に応じた専用コントロール（ドロップダウン選択、数値入力フィールド等）で表示され、入力・変更した値が選択中の全プリセットに一括適用されること。
  - [x] AC-3: 複数プリセットを選択して一括編集モーダルを開いた際、選択対象の全プロンプトに共通して含まれるタグの一覧（共通タグ）が表示されること。
  - [x] AC-4: 共通タグ一覧から削除したいタグを選択・指定して適用した際、選択中の各プリセットのプロンプトから該当タグのみが一括で削除（除外）され、その他の固有タグや順序が保持されること。
  - [x] AC-5: 一括編集モーダル内のプロンプト入力および共通タグ表示部において、タグがチップ形式で描画され、タグ単位での追加・個別削除等の直感的な操作ができること。
