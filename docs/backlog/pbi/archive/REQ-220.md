### REQ-220: 生成プロンプト（TagChipEditor）の無効化タグ状態永続化およびライフサイクル保持
- **Type**: defect
- **Status**: done (2026-09-05)
- **Current step**: none
- **Priority**: P1
- **Surface**:
  - 生成画面（GeneratePage）のプロンプト入力欄（TagChipEditor）でタグを無効化（グレーアウト）にした後、画面遷移やアコーディオン開閉、モバイルでのプロンプトタブ切替など再描画・再マウントが走ると、無効化したタグが消失してしまう。
- **Root Cause**:
  - SSoT（`SPEC_COMMON.md`）の契約上、`TagChipEditorProps` の `onChange` が「有効チップのみをカンマ連結した文字列を返す」と定義されており、親ストア（`paramValues`）には無効タグが除去された平文文字列のみが保存されている。
  - 無効タグの状態が `TagChipEditor` 内部のローカルステート（`useChipHistory`）にしか存在しないため、コンポーネントがアンマウント・再マウントされると、親の平文文字列から再パース（全件 `enabled: true`）され、無効タグが永久に喪失する。
- **Requirement**:
  - プロンプトタグを無効化（enabled: false）した状態が、画面遷移、アコーディオン開閉、タブ切替、Multi-Set切替などの画面操作・再描画を跨いでも消失せず、無効化状態のまま保持・復元されること。
  - ComfyUIへのAPI投入時およびスナップショット生成時には、従来通り有効タグのみが送信されること。
- **Acceptance criteria**:
  - [ ] AC-1: 生成画面のプロンプト欄でタグを無効化した後、別画面（History/Tags/LoRAs/Settings等）へ遷移して再度生成画面に戻った際、無効化したタグが無効状態のまま保持されていること。
  - [ ] AC-2: プロンプトセクションのアコーディオンを閉じて再度開いた際、無効化したタグが無効状態のまま保持されていること。
  - [ ] AC-3: モバイル表示でプロンプトタブ（Positive/Negative等）を切り替えて戻った際、無効化したタグが無効状態のまま保持されていること。
  - [ ] AC-4: Multi-Set（Set 1 / Set 2）の切替を行って戻った際、各セットで無効化したタグが無効状態のまま保持されていること。
  - [ ] AC-5: 画像生成（ComfyUIへのワークフロー送信）実行時には、無効化されたタグはプロンプトに含まれず、有効なタグのみが送信されること。
