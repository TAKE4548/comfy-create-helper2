### REQ-102: スナップショット保存時の重複LoRAによるユニーク制約エラーの修正

- **Type**: defect
- **Status**: done (2026-08-30)
- **Current step**: none
- **Priority**: P1
- **Surface**: スナップショット保存が出来ない
- **Root Cause**: スナップショットの保存時、アセット選択データ（`appliedAssets`）の中に同一の `lora_id` かつ同一の役割（`role`）を持つLoRAが重複して存在する場合、`snapshot_loras` テーブルのユニーク制約 `UNIQUE(snapshot_id, lora_id, role)` に反するため、データベース保存時に `IntegrityError` （500 Internal Server Error）が発生する。
- **Requirement**: 重複するLoRA/タグセットの登録処理が行われても、一意制約エラーを回避してスナップショットが正常に保存されること。
- **Design doc**: none

#### Acceptance Criteria (AC)
- [ ] AC-1: スナップショット保存時に重複するLoRA（同じ `lora_id` かつ同じ `role`）が含まれていても、一意制約エラー（500）にならず保存に成功すること
- [ ] AC-2: 重複するLoRAはデデュープされてデータベースに安全に登録されること
- [ ] AC-3: タグセットに関しても同様に、重複するタグセット（同じ `tag_set_id` かつ同じ `role`）が含まれていても一意制約エラーにならず保存に成功すること
