### REQ-145: セリフ編集の修飾設定プリセット登録・再利用およびDB永続化機能

- **Type**: enhancement
- **Status**: done
- **Current step**: none
- **Priority**: P2
- **Surface**: セリフ編集の修飾設定のプリセットをいくつか登録して、再利用できるようにしたい。複数キャラの画像などで、文字色などでセリフを区別するため、数件プリセット登録して再利用できると効率的になる。プリセットはデバイスを跨いでも使用したいので、DBで永続化したい
- **Root Cause**: **Interaction & Workflow Friction (Repetitive Manual Configuration / Lack of Reusability)**: セリフ編集画面において、複数キャラクターのセリフ差別化（文字色・フォント・吹き出し装飾等の変更）を行う際、編集のたびに各パラメータを手動で設定し直す必要があり操作コストが高い。また、修飾設定をプリセットとして保存・共有する機能およびバックエンド（DB）での永続化機構が存在しないため、デバイスを跨いだ再利用や定型スタイルの効率的な適用ができない。
- **Requirement**: セリフ編集モーダルにおいて、セリフ修飾設定（文字色、フォント、背景色、枠線、吹き出しスタイル等の装飾パラメータ群）を名前付きプリセットとして登録・選択適用・更新・削除できるプリセット管理機能を提供する。プリセットはサーバー（DB）側で永続化し、異なるデバイスやブラウザ環境でも共通してプリセットを活用できるようにして、複数キャラクターのセリフ制作・編集作業を大幅に効率化する。
- **Design doc**: [docs/design/REQ-145.md](docs/design/REQ-145.md)

#### Acceptance Criteria (AC)

##### 1. プリセットの新規保存・命名
- [x] AC-1-1: セリフ編集画面において、現在設定されている修飾パラメータ（文字色、背景色、枠線、フォント関連、吹き出し形状等）に任意の名前を付与して新規プリセットとして保存できること。
- [x] AC-1-2: プリセット保存時に、入力された名前の重複や不正な入力を適切にハンドリングできること。

##### 2. プリセットの一覧参照とワンクリック適用
- [x] AC-2-1: セリフ編集画面上で登録済みプリセットの一覧を素早く確認・選択できるUIが提供されていること。
- [x] AC-2-2: プリセットを選択した際、対象のセリフ/吹き出しにプリセットの修飾設定が一括で即座に反映されること。
- [x] AC-2-3: プリセット適用後も、個別の修飾項目を通常通り手動で微調整・変更できること。

##### 3. プリセットの更新・削除管理
- [x] AC-3-1: 登録済みの既存プリセットに対して、名前の変更や現在の修飾設定での上書き更新ができること。
- [x] AC-3-2: 不要になったプリセットを削除できること。

##### 4. DB永続化とデバイス間共有
- [x] AC-4-1: プリセット情報がバックエンドのデータベースに永続化保存されること。
- [x] AC-4-2: ページの再読み込み時や、異なるブラウザ・別デバイスからアクセスした際にも、保存されたプリセットがロードされ同一に利用できること。
