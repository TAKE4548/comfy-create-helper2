### REQ-071: 並び替え操作時と長押し複数選択操作の競合不具合の修正

- **Type**: bug
- **Status**: done (2026-08-30)
- **Current step**: none
- **Priority**: P1
- **Surface**: アルバム画面などでの並び替え操作時に、長押しの複数選択が誤爆してしまって、並び替えができない。
- **Root Cause**: `useMultiSelect.ts` の `getLongPressHandlers` において、`onMouseMove`/`onTouchMove` によるドラッグ（移動）検出が行われておらず、押下（`MouseDown`/`TouchStart`）から時間が経過すると、移動中であっても無条件に長押しタイマーが実行されて複数選択モードになってしまう。
- **Requirement**: ドラッグ操作が検出された場合、長押しタイマーをキャンセルし、並び替え操作を優先する。また、手のブレで意図せず長押し判定がキャンセルされるのを防ぐため、開始地点からの移動距離がしきい値（例: 10px）を超えた場合のみタイマーをキャンセルする。
- **Acceptance criteria**:
  - AC-1: アイテムを押下後、長押し判定時間が経過する前にドラッグ（移動）を開始した場合、複数選択モードは起動せず、通常の並び替え/ドラッグ操作が継続できること。
  - AC-2: アイテムを押下後、ドラッグ（移動）せずに長押し判定時間以上経過した場合は、複数選択モードが起動すること。
  - AC-3: ドラッグによる移動距離がしきい値（10px）未満（手ブレ範囲内）である場合は、移動とみなさず長押し判定を継続すること。
- **Design doc**: none
