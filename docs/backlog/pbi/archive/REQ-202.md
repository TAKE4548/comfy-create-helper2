### REQ-202: 生成プリセット一括編集における共通タグの編集・強度調整機能
- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: none
- **Priority**: P2
- **Surface**:
  - プリセット一括編集モーダルにおいて、抽出された共通タグは削除（除外）しか行えず、強度の調整やタグ名の変更ができない。
  - 通常のタグチップのサブメニューで可能な操作（タグ名変更、強度数値の指定・増減、有効/無効切り替えなど）を一括編集の共通タグに対してもまとめて行いたい。
- **Root Cause**:
  - 一括編集モーダルの共通タグ領域が「削除対象タグの選択」専用のUI/ロジックとなっており、TagChipコンポーネントが持つサブメニューや強度・タグ名変更の一括反映機能が統合されていない（Interaction / Information Design）。
- **Requirement**:
  - 生成プリセットの一括編集モーダルにおいて、選択中の複数プリセットに共通するタグに対し、削除だけでなく通常のタグチップサブメニューと同等の編集操作（タグ名変更、強度指定・増減、有効/無効トグル）を行えること。
  - 編集または強度変更された共通タグの内容が、選択されているすべてのプリセットの該当タグに対して一括で反映・更新されること。
- **Acceptance criteria**:
  - [ ] AC-1: 一括編集モーダルの共通タグ一覧において、各タグチップをクリックした際に通常のTagChipと同等のサブメニュー（タグ名編集、強度数値入力、ステップ増減ボタン等）が表示されること。
  - [ ] AC-2: サブメニューを通じて共通タグの強度（Weight）を変更・指定した場合、一括保存時に選択中のすべてのプリセットの該当タグの強度が更新されること。
  - [ ] AC-3: サブメニューを通じて共通タグの名称（単語）を変更した場合、一括保存時に選択中のすべてのプリセットに含まれる該当タグ名が一括で置換・更新されること。
  - [ ] AC-4: 共通タグの個別削除および有効/無効トグルが機能し、選択中の全プリセットに対してその変更が一括適用されること。
