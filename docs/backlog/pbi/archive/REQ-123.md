### REQ-123: プロファイル同期不具合修正

- **Status**: done (2026-08-26)
- **Type**: bug
- **Root Cause Reference**: `docs/incident_report.md`

#### 問題の概要
複数デバイス間、または同一デバイスでの新規タブ作成操作において、プリセット編集内容が正しく同期・永続化されない。

**発生パターン:**
1. クロスデバイス: リロード後に localStorage の古い値が優先され、バックエンドの最新値が反映されない
2. 新規タブ作成後に元プロファイルに戻ると、作成直前の未保存編集が消失している
3. 新規タブ作成操作後、UIが新タブへ正しくフォーカスしない

#### Acceptance Criteria (AC)
- [ ] AC-1: 別デバイスで保存されたプロファイル編集が、リロード後に正しく表示されること
- [ ] AC-2: 既存プロファイルを元に新規タブを作成した後、元のプロファイルタブに戻った時に作成直前の編集状態が保持されること
- [ ] AC-3: 新規タブ作成操作が完了した後、UIが正しく新規タブにフォーカスすること
- [ ] AC-4: オートセーブ後の invalidateQueries による再フェッチで、未保存の編集中内容が失われないこと
