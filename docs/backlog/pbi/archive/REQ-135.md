### REQ-135: プリセット一括編集へのアセット（LoRA・タグセット等）適用機能の追加

- **Status**: done (2026-08-30)
- **Description**: プリセットの一括編集モーダルにおいて、単体編集の Add Asset と同等のアセット（LoRA・タグセット等）選択モーダルからアセットを選択し、複数プリセットに対して一括で「追記」または「置換」適用できるようにする。

#### Acceptance Criteria (AC)
- [ ] AC-1: **アセット選択UIの統合**: プリセット一括編集画面のプロンプト編集エリアにおいて、単体プリセット編集時と同じアセット選択モーダル（Add Asset）を呼び出し、単体時と同様にアセット（LoRA・タグセット等）を選択できること。
- [ ] AC-2: **追記・置換モード選択**: 一括編集プロンプトエリアにて、選択したアセットを対象プリセット群に「追記（Append）」するか「置換（Replace）」するかをユーザーが選択できること。
- [ ] AC-3: **一括確定時の反映処理**: 一括編集画面でアセットを設定後、「確定（保存）」ボタンを押下した時点で、選択されていた全対象プリセットに対して指定モード（追記/置換）で一括適用が行われること。
- [ ] AC-4: **重複・サブセットハンドリング**: プリセットへの一括適用時、まったく同じアセットが既に登録されている場合は自動スキップし、同一アセットであっても異なるサブセット（選択項目違い等）の場合は維持・追加されること。
