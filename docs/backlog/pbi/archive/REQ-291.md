### REQ-291: Prompt Surgeon: 2系統参照型セリフ・SE一括自動生成 (Qwen3.5-9B-Claude連携・即時VRAM解放・並行オンボーディング)

- **Type**: enhancement
- **Status**: done (2026-09-28)
- **Current step**: none
- **Priority**: P1
- **Surface**: Prompt Surgeonのセリフ付与において、ゼロショット生成ではキャラらしさや場面の熱量が安定せず、また1画像内に主役・モブ・SEが混在する実態に対応しきれていない。さらに16GB VRAM環境下でComfyUI画像生成とVLM推論のGPUメモリ競合を回避し、推論完了直後にVRAMを全量即時解放する厳格なライフサイクル管理と、初出キャラでも待たせないUI/UXが求められている。
- **Root Cause**: 吹き出し単独推論による会話の噛み合わなさ、過去ログや類似シーン演出を活用するコンテキスト参照機構の欠如、推論後の自動アンロード（VRAM解放）API呼び出しおよび初出キャラ時の非同期並行オンボーディング（レース防止・先行キャンセル救済）機構の未実装。
- **Requirement**:
  - 詳細設計書（`tmp/Prompt_Surgeon_セリフ・SE一括生成_構想・詳細設計書_Rev14_最終確定版.pdf`）に基づき、以下の3フェーズで「2系統参照型セリフ・SE一括自動生成」機能を実装する。設計フェーズ（dev-design）では本設計書を一次情報（SSoT）として参照し、設計作業の重複をスキップしてタスクカード生成・検証計画へ迅速に移行可能とする。
  - **Phase 1: DB構造拡張＆マイグレーション**:
    - `SpeechBubblePreset` に `tag_set_id` (FK) および `is_default` (bool) を追加。
    - `snapshots.params['speech_bubbles']` のネスト構造（REQ-285準拠）に `speaker_tag_set_id` と `is_se` を対応。
    - オノマトペカタカナ誤判定を是正した正規表現 `([!?！？〜～ッっ…・]|^[ァ-ヴーぁ-ん]{2,6}$)` による過去データ一括バックフィルスクリプト配備。
  - **Phase 2: 推論・VRAM解放・配置足回り**:
    - 系統A（直近50件走査・同キャラ確定セリフ抽出／TonePresetフォールバック）および系統B（SnowballStemmer単語類似度スコアTop-1抽出）の2系統リファレンス選定。
    - Qwen3.5-9B-Claude投入用プロンプト構築と `<think>` タグ除去・マークダウンJSONパース堅牢化。
    - `finally` 句でのリトライ（1回）付き即時アンロード（`POST /v1/models/unload`）と `vram_unloaded` フラグ返却。
    - sub話者キャラ同定（TagSet.name照合）およびSE装飾（枠なし・黄色テキスト）の自動解決。
    - VLM粗判定方角から1024×1024px実ピクセル絶対座標への「80点ハイブリッド配置」変換。
    - エンドポイント `POST /api/speech/scene-draft` および `GET /api/speech-bubble-presets/by-tagset/{id}`（未登録時 200 OK null 返却）の実装。
  - **Phase 3: UI・同期合流統合**:
    - 通常ルートのワンクリック完全自動展開。
    - 初出キャラ時の並行オンボーディング（色選び裏での先行推論）と、`isCancelledRef` / `createdPresetIdRef` / `pendingDraftResultRef` による合流レース防止および先行キャンセル時の標準色救済描画フック（`useSceneSpeechGeneration`）。
- **Acceptance criteria**:
  - [ ] AC-1 (DB & マイグレーション): `SpeechBubblePreset` に `tag_set_id` / `is_default` カラムが追加され、バックフィル実行後に過去スナップショットの文字色からキャラIDが付与され、短文オノマトペのみが `is_se=True` と判定されること (TEST-MIG-05)。
  - [ ] AC-2 (推論 & VRAM即時解放): VLM推論完了直後（正常系および例外発生時の双方）に LM Studio の `POST /v1/models/unload` が発火し、レスポンスの `vram_unloaded` が正常に返却され、GPUメモリが初期状態に解放されること (TEST-VRAM-01)。
  - [ ] AC-3 (2系統参照 & パース): 過去50件走査からのキャラ口調抽出（0件時TonePresetフォールバック）および名詞・動詞類似度による演出見本抽出が正常に動作し、`<think>` タグやマークダウン付きJSONが堅牢にパースされること (TEST-DUAL-02)。
  - [ ] AC-4 (マルチ話者 & SE装飾 & 座標変換): sub話者が TagSet と紐づいて専用プリセットまたは白黒に解決され、SEが枠なし黄色文字に装飾され、VLMの定性方角が1024px基準の実ピクセル座標に正しくマッピングされること (TEST-STYLE-04)。
  - [ ] AC-5 (並行オンボーディング & レース防止): `GET /api/speech-bubble-presets/by-tagset/{id}` が未登録時 HTTP 200 OK (null) を返し、初出キャラ時にモーダル先行確定・推論先行完了・先行キャンセルの全ケースでセリフが消失・欠損なく描画されること (TEST-PAR-03)。
  - [ ] AC-6 (品質検証): バックエンド Pytest およびフロントエンド Vitest の新設テスト群が全件 PASS し、Gate 1 型検査（`npm run typecheck`）および Gate 2 全体テストがエラー0件であること。
