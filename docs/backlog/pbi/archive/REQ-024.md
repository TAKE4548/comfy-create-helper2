### REQ-024: スマホなどの外部デバイスからBEに接続できない問題の修正

- **Type**: defect
- **Status**: ready
- **Current step**: none
- **Priority**: P1
- **Surface**: スマホなどからアクセスした場合、FEはアクセスできるがBEに繋がらない。FE側でBEへの接続がlocalhostになっていると思われるため、viteのproxyなどを使ってデバイスによらずFEさえリッスンして受け付けていれば各種BEに繋がるようにしたい。
- **Root Cause**: FEコード内にBE（APIサーバーやComfyUI）への接続先が `localhost` や `127.0.0.1` などのローカル接続に固定されてハードコードされており、外部デバイス上のブラウザからホストマシンのBEにリクエストが届かないため。また、Vite開発サーバーが外部リッスンおよびプロキシ設定されていないため。
- **Requirement**: 外部デバイスからフロントエンドにアクセスした際に、Vite開発サーバーがプロキシとして機能し、APIやComfyUIへのリクエストがプロキシ経由で適切にホストPC内のバックエンドにルーティングされることで、デバイスによらず正常に接続・機能できるようにする。
- **Acceptance criteria**:
  - AC-1: ホストPCのIPアドレスを使用して、外部デバイスのブラウザからフロントエンド（Vite開発サーバー）にアクセスできること。
  - AC-2: 外部デバイスからのアクセス時、フロントエンドからバックエンドAPI（FastAPI）へのリクエスト（ワークフロー一覧の取得等）がエラーなく正常に通信できること。
  - AC-3: 外部デバイスからのアクセス時、フロントエンドとComfyUIのWebSocket接続およびAPI通信が正常に確立され、生成進捗やプレビュー画像が正しく表示されること。
  - AC-4: ローカルホスト（`http://localhost:5173`）からのアクセス時も、従来通りバックエンドおよびComfyUIとの接続が正常に動作すること。
- **Design doc**: none
