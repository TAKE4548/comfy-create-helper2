### REQ-282: GeneratePage レイアウト重複の解消と共通オーバーレイ抽出

- **Type**: refactoring
- **Status**: done (2026-09-24)
- **Current step**: none
- **Priority**: P2
- **Surface**: DesktopLayout (1,086行) と MobileLayout (944行) において、末尾のモーダル群（Bypass, ParamSync, Translation, SaveAsTagSet, AddAsset）やトースト通知、エラーハンドラが完全にコピペ重複しており、更新漏れや保守性の低下を招いている（リファクタ計画 PBI-REF-01）。
- **Root Cause**: PC表示とモバイル表示の画面配置の違い（2カラム分割 vs 縦積み）以外のモーダル管理・トースト・タブ管理等のロジックおよびJSXが両レイアウトコンポーネントに重複して直接記述されていること。
- **Requirement**: 
  - 共通モーダル群およびトースト通知を `GenerateModalsOverlay` コンポーネントに集約・外出しする。
  - セットタブ一覧バー（`SetTabsBar`）および生成画像ギャラリー（`GenerationGallerySection`）を閉じたセクションとして部品化する。
  - 各レイアウトコンポーネント（`DesktopLayout`, `MobileLayout`）を配置責務のみに特化させ、合計約500行以上の重複コードを削減する。
  - 【目標構成】:
    ```
    frontend/src/pages/GeneratePage/
    ├─ components/
    │  ├─ DesktopLayout.tsx           # PC用画面分割配置のみ（約250行）
    │  └─ MobileLayout.tsx            # モバイル用縦積み配置のみ（約200行）
    └─ sections/
       ├─ GenerateModalsOverlay.tsx   # 全モーダル・トースト集約（約160行）
       ├─ SetTabsBar.tsx              # セットタブ一覧・追加・全選択/解除（約140行）
       └─ GenerationGallerySection.tsx # 生成画像グリッド・スクロール（約180行）
    ```
- **Acceptance criteria**:
  - [ ] AC-1: Desktop / Mobile 両画面で全モーダルの開閉、トースト通知、セット切り替えが同一挙動で正常動作すること。
  - [ ] AC-2: レイアウト側ファイル（DesktopLayout, MobileLayout）から重複モーダルJSXが完全に除去され、合計行数が約500行以上削減されること。
  - [ ] AC-3: 【REQ-264 プレビュー制御維持】ギャラリー部（GenerationGallerySection）の切り出し後も、`useGenerateDisplayState` の `previewAutoFollow`（自動追従）およびトグルによる最新画像ジャンプ・ロック制御が正常にバインドされていること。
  - [ ] AC-4: `cd frontend && npm run typecheck`（tsc -b --noEmit）がエラー0件でPASSすること（REQ-001の型検査Gate 1）。
  - [ ] AC-5: `cd frontend && npx vitest run` で既存テストが全件PASSすること。
