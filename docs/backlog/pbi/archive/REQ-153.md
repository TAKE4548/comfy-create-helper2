### REQ-153: タッチ操作端末における並び替えドラッグ操作とOS標準挙動の競合解消

- **Type**: bugfix / enhancement
- **Status**: done (2026-08-26)
- **Priority**: P1
- **Surface**: 各種画面（TagsPage, LoRAsPage, HistoryPage, PresetManagerPanel, SettingsPage, TagChipEditor）の並び替え機能
- **Root Cause**: カード全体に対する相反するジェスチャー（タップ、長押しD&D、長押し一括選択、スクロール）の多重割り当てによるOS標準ロングタップとのタイマー競合、およびドラッグ対象要素に対するCSS `touch-action: none` の欠落により、Android端末等でドラッグ判定より先にネイティブ縦スクロールが発動してしまう問題。
- **Requirement**:
  1. タッチ操作環境において、カード全体での曖昧な長押しドラッグを解消し、ドラッグハンドルまたは明確なジェスチャー境界を確立する。
  2. ドラッグ操作の起点となる要素・ハンドルに `touch-action: none` を常時適用し、Android/iOSブラウザのネイティブスクロールによる誤奪取を防止する。
  3. ドラッグ可能領域におけるOS標準のロングタップ（`-webkit-touch-callout: none`、`user-select: none`、`contextmenu` 抑止等）による誤爆を防止する。
  4. `@dnd-kit` のセンサー定義（`PointerSensor` / `TouchSensor` / `MouseSensor`）およびアクティベーション制約を整理し、PC（マウス）とモバイル（タッチ）の両方で破綻しない操作性を実現する。

#### Acceptance Criteria (AC)

##### 1. Android/iOSタッチ環境でのドラッグ＆ドロップ動作保証
- [ ] AC-1-1: Android端末（Blink/Chrome）およびiOS/iPadOS端末（Safari/WebKit）において、並び替え操作時に画面スクロールに誤奪取されることなくコンポーネントのD&D並び替えが実行できること。
- [ ] AC-1-2: ドラッグ操作の起点となる要素に `touch-action: none` が確実に適用されていること。

##### 2. OS標準ロングタップメニューおよび他ジェスチャーとの競合解消
- [ ] AC-2-1: タッチ端末での長押し・ドラッグ操作中にOS標準のコンテキストメニューやテキスト選択、画像ポップアップが誤発火しないこと。
- [ ] AC-2-2: 一括選択機能（`useMultiSelect`）が存在する画面（TagsPage, LoRAsPage, HistoryPage等）において、並び替えドラッグ操作と一括選択モードの突入が意図せず同時に誤爆しないこと。

##### 3. PC（マウス操作）との互換性・操作性の維持
- [ ] AC-3-1: デスクトップ環境（マウス/キーボード）における従来のクリック、ドラッグ＆ドロップ、複数選択等の操作性が損なわれていないこと。
- [ ] AC-3-2: `PresetManagerPanel`、`SettingsPage`（マッピングマスター）、`TagChipEditor` を含むすべての並び替え対応画面で一貫した操作感が提供されていること。
