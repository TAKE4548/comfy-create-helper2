### REQ-091: ComfyUIワークフローにおける任意ノード・サブグラフのバイパス機能およびエラーのトースト表示の追加

- **Type**: enhancement
- **Status**: done (2026-08-26)
- **Priority**: P1
- **Surface**: /wish ワークフローに対して、任意のノードを選択してバイパス(無効化)できるようにしたい。ノードマッピングのような形で、ブリッジ対象のノードを選択すると、対象ノードの入出力が矛盾しないように接続先を変更してComfyUIにPostするイメージ。ブリッジ対象は複数ノードを対象に撮ることがあり得て、サブグラフも対象にできるようにしたい。また、現状はComfyUIへのPOSTでエラーになってもツール上では気づけないが、本機能で指定するノードによってはエラーが不可避になるため、エラーを表示できるようにもしたい。
- **Root Cause**: 特定のノード処理（重い生成処理やVAEデコード等）を一時的にスキップした状態でComfyUIへリクエストを送信し、結果を確認したいというニーズがあるが、現状はワークフロー全体をそのまま送信するしかない。また、無効化により接続矛盾（型不一致等）が生じてComfyUI側でエラーになった場合に、ツール側でそのエラーを検知・表示する仕組みがない。
- **Requirement**: UI上で任意のノードまたはサブグラフを選択してバイパス（無効化）指定できるようにし、送信時にそれらのノードの入出力を同一データタイプ同士で直結（ブリッジ）したAPI用ワークフローJSONを動的に生成してComfyUIに送信する。送信時のAPIエラー（型不一致等含む）はフロントエンド上でトースト通知として表示する。

#### Acceptance Criteria (AC)
- [ ] AC-1: UI上で任意のノード（単一、複数、またはサブグラフ）を選択して「バイパス（無効化）」対象に指定できること
- [ ] AC-2: 送信時のワークフローJSON生成処理において、バイパス対象ノードの入力端子と出力端子のうち、同一のデータタイプ（`MODEL`、`LATENT`、`IMAGE`等）を持つ接続関係を自動的に直結（ブリッジ）して送信JSONを構成すること
- [ ] AC-3: 複数ノードまたはサブグラフ全体をバイパス対象とした場合も、そのサブグラフへの外部入力と外部出力の同一データタイプを同様に直結すること
- [ ] AC-4: ComfyUIへのPOST送信時にAPIエラー（バリデーションエラー、型不一致等）が発生した場合、そのエラーレスポンスをキャッチし、フロントエンドにトースト通知としてエラー内容を表示すること
