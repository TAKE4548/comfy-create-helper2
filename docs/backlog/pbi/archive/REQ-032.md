### REQ-032: 生成画面での新規ワークフローアップロード・登録機能の追加

- **Status**: ready
- **Type**: enhancement
- **Priority**: P1
- **Current step**: none
- **Surface**: 生成画面（Generate ページ）

- **Root Cause**:
  システム仕様書（`spec_and_migration.md`）には、新規ワークフローのJSONをアップロードして登録・マッピングする仕様が記述されているが、フロントエンドUIにアップロード用のボタンやファイル選択機能、マッピングの初期設定フローが欠落している。

- **Requirement**:
  1. 生成画面のワークフロー選択ドロップダウン付近に、新規ワークフローを追加（アップロード）するためのボタンを配置する。
  2. ボタン押下時にJSONファイルを選択するダイアログを表示する。
  3. ファイルロード後、バックエンドAPI `POST /api/workflows/scan` を利用してマッピングの自動検出を行い、結果を登録確認モーダル（新規登録用）に表示する。
  4. 登録確認モーダルにて、ワークフロー名の設定、マッピング（役割とnode_idの対応）の確認・編集（変更/追加/削除）を行えるようにする。
  5. 確定時に `POST /api/workflows` APIを呼び出してワークフローを新規登録し、登録成功後は生成画面の選択状態を新規追加されたワークフローに切り替える。

#### Acceptance Criteria (AC)
- [ ] AC-1: **アップロードUIの配置**: 生成画面のワークフロー選択エリア付近に、新規ワークフローをアップロードするためのボタン（例: アップロード用のアイコン等）が分かりやすく配置されていること。
- [ ] AC-2: **ファイル選択ダイアログの表示**: ボタン押下時にファイル選択ダイアログが開き、`.json` ファイルのみを選択可能に制限できること。
- [ ] AC-3: **自動スキャンの実行と結果表示**: ロード完了時に自動的に `POST /api/workflows/scan` が呼び出され、検出結果（マッピング候補および未検出の役割（警告））を含む登録確認モーダルが表示されること。
- [ ] AC-4: **ワークフロー名の設定とマッピング調整**: モーダル内で、登録用のワークフロー名（デフォルトはファイル名等）を入力・編集でき、各マッピング（node_id、役割、パラメータ名）をプルダウン等で手動修正したり、行を追加・削除できること。
- [ ] AC-5: **新規登録の保存と反映**: モーダルの「登録」ボタン押下時に `POST /api/workflows` が呼び出され、DBに新規保存されること。保存成功時にモーダルが閉じ、生成画面のワークフロー選択状態が新規登録されたワークフローに切り替わって入力欄が正常に生成されること。
- [ ] AC-6: **バリデーションと重複防止**: すでに存在するワークフロー名で登録しようとした場合、バックエンドの409エラー等を適切に処理し、ユーザーにエラー（「すでに同名のワークフローが存在します」など）を通知して再入力を促すこと。
