### REQ-293: HistoryPage 経由で開いた SpeechBubbleEditorModal「シーン一括生成」ボタン無反応修正

- **Status**: done (2026-09-28)
- **Classification**: Type-A Implementation Defect
- **Incident**: docs/incident_report_REQ-293.md
- **Description**:
  `HistoryPage` から `SpeechBubbleEditorModal` を開くと「シーン一括生成」ボタンが完全無反応になる。
  根本原因は 2 点：
  1. `HistoryPage/index.tsx` が `generateDraftApi` prop を渡していない
  2. `SpeechBubbleEditorModal/index.tsx` の fallback が空スタブ `() => Promise.resolve({ bubbles: [] })` のため、API 呼び出しが発火しない

#### Acceptance Criteria (AC)
- [ ] AC-1: HistoryPage から SpeechBubbleEditorModal を開き「シーン一括生成」ボタンを押下すると `POST /api/speech/scene-draft` が発火する
- [ ] AC-2: `generateDraftApi` prop を明示的に渡さない呼び出し元（将来的な用途）が fallback を通じて同エンドポイントを呼び出せる
- [ ] AC-3: 既存ユニットテスト TEST-UI-01〜04 がすべて PASS し続ける（破壊的変更なし）
- [ ] AC-4: TypeScript 型チェックがエラーなしで完了する (`npm run typecheck`)
