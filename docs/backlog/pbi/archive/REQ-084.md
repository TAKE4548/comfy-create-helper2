### REQ-084: 生成ページにおける不要機能廃止と履歴複数選択操作の改善

- **Status**: done (2026-08-30)
- **Description**: 
  1. 生成ページのワークフロー選択部に存在する、古い機能の名残である「過去スナップショットからの反映用ドロップダウン」を廃止する。
  2. 生成履歴エリア内で通常の画像選択と同様に複数選択および範囲選択（Shiftキー併用など）が可能となり、単一画像のスナップショット保存と同じボタン（もしくは同一導線）から、選択された複数の画像を対象にスナップショット保存を実行できるようにする。
  3. 履歴で複数選択を行っている状態でも、メインプレビューエリアには最後に選択（アクティブに）した画像が継続して表示されること。

#### Acceptance Criteria (AC)
- [ ] AC-1: ワークフロー選択エリアから「過去スナップショットからの反映用ドロップダウン」が非表示（削除）されていること。
- [ ] AC-2: 生成履歴一覧で、Ctrlクリックによる複数選択、およびShiftクリックによる範囲選択ができること。
- [ ] AC-3: 複数選択されている状態で「スナップショット保存」ボタンを押すと、選択されたすべての画像がスナップショットとして保存されること。
- [ ] AC-4: 履歴を複数選択した際、プレビューエリアには最後にクリックした画像が表示され、選択順や選択解除に応じて表示が追従すること。
