### REQ-045: ワークフローデフォルト設定とスナップショットのLoRA・タグセットリンクの永続化とロード

- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: none
- **Priority**: P1
- **Surface**: ワークフローデフォ設定・スナップショットとのlora・タグセットリンクの永続化、ロードできるようにしたい。
  - 1. ワークフローを切り替えてもLoRA・タグセットの適用状態のバッジが引き継がれ、実体のプロンプトとずれてしまって修正の手間がかかっている
  - 2. プロンプトやパラメータなどのワークフローの初期値として保存される設定
  - 3. スナップショット保存で、画像と合わせて生成条件・プロンプトが保存されているもののこと。現状スナップショットからのロードでパラメータ・プロンプトは復元されるので、それと同様にしたい
  - 4. DBに保存
- **Root Cause**:
  - ワークフロー切り替え時にUI上のLoRA・タグセットの適用状態（バッジ表示など）がリセットされず、前回のワークフローの状態がそのまま表示されてしまい、実体のプロンプトと乖離する。
  - ワークフローごとにプロンプト・パラメータのデフォルト値（初期設定）をDBに永続化し、ロードする仕組みが存在しない。
  - スナップショットの保存・ロード処理において、プロンプトとパラメータのみが対象になっており、LoRA・タグセットの適用状態（リンク状態）がDBに保存・ロードされない。
- **Requirement**:
  - ワークフロー切り替え時にLoRA・タグセットの適用状態が正しくリセット、あるいは該当ワークフローの設定に基づいて更新されること。
  - ワークフローごとにプロンプト・パラメータの初期値をデフォルト設定としてDBに保存でき、それをロードできること。
  - スナップショット保存時に、適用されているLoRA・タグセットのリンク情報をDBに保存し、スナップショットロード時にそれらの適用状態（バッジ表示や内部状態）が復元されること。
- **Acceptance criteria**:
  - **AC-1 (ワークフロー切り替え時のUIリセット)**: ワークフロー切り替え時、UI上のLoRA・タグセットの適用バッジなどの状態が、前回のワークフローから引き継がれず、切り替え先ワークフローの適用状態（または未適用）に適切に更新されること。
  - **AC-2 (ワークフローデフォルト設定の保存と復元)**:
    - ユーザーが現在のプロンプトやパラメータを、そのワークフローのデフォルト設定（初期設定）としてDBに保存できること。
    - 該当ワークフローのロード時、またはデフォルト設定のロード指示の際に、保存されたデフォルト設定がDBからロードされて反映されること。
  - **AC-3 (スナップショットとLoRA・タグセットの関連付け保存)**:
    - スナップショット保存時に、適用中のLoRAやタグセットの情報（およびその設定パラメータ）がスナップショットデータと紐づいてDBに保存されること。
  - **AC-4 (スナップショットロード時のLoRA・タグセット復元)**:
    - スナップショットをロードした際、パラメータやプロンプトが復元されるのと同時に、保存されていたLoRA・タグセットの適用状態（UIのバッジ表示含む）が復元されること。
