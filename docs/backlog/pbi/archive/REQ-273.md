### REQ-273: LoRA・タグセット管理における詳細・編集画面のタグチップ/テキスト切替および操作仕様の統一

- **Type**: enhancement
- **Status**: done (2026-09-17)
- **Current step**: none
- **Priority**: P2
- **Surface**:
  - タグセット側も同様にしたい。
  - メインのエリアと、サブセットのエリア両方とも対応させたい。
  - また、動きで見るとLoRA側は詳細モーダルは非チップで、編集モーダルがチップ(切替可)に対して、タグセット側は詳細モーダルがチップ化されてて、編集モーダルが非チップとなっている。
  - LoRA・タグセットで合わせるとともに、詳細モーダルもチップと通常を切替可能(ただし並び替えふくめた編集操作は不可)、編集モーダルは当然切替・編集可能(生成画面のプロンプトエリアと同等)に整えたい。
  - 切替可能にするけど、デフォルトはチップ側で。
- **Root Cause**:
  - **Interaction Design (Operational Inconsistency Across Asset Management)**:
    - LoRA管理モーダルとタグセット管理モーダルでタグ/トリガーワードの表示・編集インタラクションが不統一となっており、一方では詳細が非チップ・編集がチップであるのに対し、他方では詳細がチップ・編集が非チップという逆転・チグハグな体験になっている。
  - **Information & Interaction Design (Missing Read-Only Chip View & Uniform Editor Experience)**:
    - 詳細表示では「チップによる視覚的認知」と「通常テキストによる一覧・コピー性」の両方が求められるにもかかわらず切替機能がなく、登録・編集画面ではタグ単位での直感的な編集・並び替え（生成画面プロンプトと同等）がタグセット管理（メイン及びサブセット）で欠落している。
- **Requirement**:
  - タグセット管理の登録・編集モーダルにおいて、メインタグ入力部およびサブセット（バリエーション）入力部の双方でタグチップ表示と通常テキスト表示を切替可能とし、デフォルト表示を「チップ表示」とすること。
  - タグセット管理の登録・編集モーダルにおいて、チップの編集・並び替え・追加・削除等（生成画面のプロンプト領域と同等の操作）を可能にすること。
  - LoRA管理の登録・編集モーダルにおいて、トリガーワード入力部がチップ表示（デフォルト）と通常テキスト表示の切替および編集操作（並び替え・追加・削除・編集）に対応していることを担保すること。
  - タグセット管理およびLoRA管理の詳細表示モーダルにおいて、タグ/トリガーワード表示部で「チップ表示」と「通常テキスト表示」をシームレスに切替可能とし、デフォルト表示を「チップ表示」とすること。
  - 詳細表示モーダルにおけるチップ表示は閲覧専用（Read-only）とし、並び替えや追加・削除・内容編集などの破壊的・変更操作は行えないように制御すること。
  - LoRA管理とタグセット管理の間で、詳細表示・登録編集画面のタグUIの振る舞い・デザイン・初期表示（デフォルト：チップ表示）を完全に統一すること。
- **Acceptance criteria**:
  - [ ] AC-1: タグセットの登録・編集画面（新規作成・編集）において、メインタグ領域およびサブセット領域の双方が初期表示（デフォルト）でチップ表示となり、通常テキスト表示との切替が可能であること。
  - [ ] AC-2: タグセットの登録・編集画面において、チップ表示時にチップの編集・並び替え・追加・削除（生成画面のプロンプトエディタと同等の操作）が行えること。
  - [ ] AC-3: LoRAの登録・編集画面（新規作成・編集）において、トリガーワードセット入力領域が初期表示（デフォルト）でチップ表示となり、通常テキスト表示との切替が可能であること。
  - [ ] AC-4: タグセットの詳細表示画面において、メインタグおよびサブセットのタグについて初期表示（デフォルト）でチップ表示となり、通常テキスト表示との切替が可能であること。またチップ表示時は並び替えや内容編集等の変更操作が不可（閲覧専用）であること。
  - [ ] AC-5: LoRAの詳細表示画面において、トリガーワードセットのタグについて初期表示（デフォルト）でチップ表示となり、通常テキスト表示との切替が可能であること。またチップ表示時は並び替えや内容編集等の変更操作が不可（閲覧専用）であること。
  - [ ] AC-6: 詳細画面および登録・編集画面において、LoRAとタグセットで切替トグルUIおよびチップ/テキストの初期状態（デフォルト：チップ表示）が統一されていること。
