### REQ-048: LoRA・タグセット管理のカバー画像設定機能

- **Type**: enhancement
- **Status**: done (2026-08-26)
- **Current step**: none
- **Priority**: P2
- **Surface**: LoRA管理・タグセット管理で使用して生成した画像でサムネが表示できるが、カバーにするサムネを設定できるようにしたい。また、現状は上位5件が登録されるが、スナップショットの関連しているものはすべてサンプルとして見れるようにして、その中から任意のスナップショットをサムネとして登録できるようにしたい。また、現状編集・詳細モーダルを開いたとき、サムネが表示されないので、サンプルがあるものは表示して左右で切り替えて閲覧できるようにしたい。
- **Root Cause**: スナップショットの取得制限（最新5件）およびモーダル内でのサムネイル（サンプル）画像の表示・カバー設定機能の不足。
- **Requirement**: 関連するすべてのスナップショットから任意の画像をカバー画像として選択・設定でき、編集・詳細モーダルでそれらをプレビュー・切り替え閲覧できるようにする。
- **Acceptance criteria**:
  - [ ] AC-1: LoRA管理およびタグセット管理の一覧（リスト）ビューに、設定されたカバーサムネイル画像が表示されること。カバー画像が未設定の場合は、適切なプレースホルダーが表示されること。
  - [ ] AC-2: LoRA・タグセットの編集および詳細モーダルにおいて、関連付けられているすべてのスナップショット画像が一覧（グリッド形式など）で確認できること。最新5件の制限がなく、すべて表示できること。
  - [ ] AC-3: モーダル内の画像プレビューエリアで、設定されているカバー画像や選択された画像が表示され、左右のナビゲーション（左右ボタンなど）で画像を切り替え閲覧できること。
  - [ ] AC-4: スナップショット一覧またはプレビューエリアから、任意のスナップショット画像を「カバー画像」として設定・保存できること。設定内容は即時および次回表示時に正しく反映されること。
  - [ ] AC-5: 画像表示エリアおよびスナップショット一覧が十分に視認できるよう、モーダルのレイアウト（スペース配分）が適切に調整・拡大されていること。
- **Design doc**: none
