### REQ-109: タブレットやスマホから Scene Generator を開くと画面が真っ黒になる問題の修正

- **Type**: defect
- **Status**: done (2026-08-30)
- **Current step**: none
- **Priority**: P1
- **Surface**: scene generatorがタブレットやスマホからだと真っ黒の画面になって使えない。モバイルモードでなくても同じ。PCでは使える
- **Root Cause**: 非セキュアコンテキスト環境で `crypto.randomUUID()` が呼び出され、例外スローにより React のレンダーツリーがクラッシュするため。
- **Requirement**: 非セキュアコンテキスト環境（実機スマホ・タブレット等の HTTP 接続）でも Scene Generator が例外スローせず正常に開いて使用できること。
- **Acceptance criteria**:
  - [ ] AC-1: `crypto.randomUUID` が利用できない環境でも Scene Generator モーダルを開く際にエラーとならず、正常に表示されること。
  - [ ] AC-2: モーダル内でシーンを追加、削除、移動する際にも ID 生成エラーでクラッシュせず、正常に動作すること。
- **Design doc**: docs/design/REQ-109.md
