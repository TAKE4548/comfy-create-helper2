### REQ-236: 異常系・耐障害性（Red Teaming）テストの実装 (Phase 3)

- **Type**: enhancement
- **Status**: done (2026-09-09)
- **Current step**: none
- **Priority**: P2
- **Surface**:
  - ComfyUI や LM Studio、外部翻訳API等の外部サービスとの連携において、ネットワーク切断、タイムアウト、HTTP 502/503エラー、不正JSON等の障害発生時のハンドリングや復旧処理の自動テストが不足している。
  - チップ構文解析やワークフロースキャナーに対して、ランダム入力や極端な破損データを用いた境界値・ファジングテストが存在せず、予期せぬ入力によるクラッシュリスクがある。
- **Root Cause**:
  - 正常系レスポンスを前提としたベタ書きモックに依存しており、通信断や遅延等の障害シナリオ（フォールトインジェクション）やプロパティベーステスト（Property-based Testing）が設計・自動化されていなかった。
- **Requirement**:
  - フロントエンドにおいて、MSW を活用した障害注入テスト（ComfyUIキュー投入エラー、翻訳APIタイムアウト、LLMシーン生成タイムアウト等）を新設し、UI復旧とトースト通知を検証する。
  - バックエンドにおいて、respx を活用した障害注入テスト（ComfyUIプロキシおよびLLMサービスの接続タイムアウト、読み取りタイムアウト、不正JSON）を新設し、適切なエラーハンドリングとHTTPException(503等)の送出を検証する。
  - fast-check（フロントエンド）および hypothesis（バックエンド）を活用したプロパティベーステストを新設し、任意のランダム文字列や破損ノード定義に対する堅牢性を検証する。
  - 前提: REQ-234（Phase 1: テスト基盤セットアップ）で導入したライブラリ群を使用する。
- **Acceptance criteria**:
  - [ ] AC-1: `frontend/src/pages/GeneratePage/hooks/__tests__/useGenerateAction.fault.test.ts` が新設され、ComfyUI キュー投入時の HTTP 503 / ネットワーク断において、トースト通知が表示され `isGenerating: false` に安全に復旧することが検証されパスすること。
  - [ ] AC-2: フロントエンド翻訳処理において、外部APIの10秒タイムアウト発生時に原文テキストが保持され安全にフォールバックすることがテストで検証されパスすること。
  - [ ] AC-3: フロントエンドLLMシーン生成/監査処理において、30秒タイムアウト発生時に操作ブロックが解除され警告が表示されることがテストで検証されパスすること。
  - [ ] AC-4: `backend/tests/test_comfy_proxy_fault.py` および `test_llm_service_fault.py` が新設され、`httpx.ConnectTimeout`, `httpx.ReadTimeout`, 不正JSON受信時に適切な HTTPException(503等) が送出されることが検証されパスすること。
  - [ ] AC-5: `frontend/src/components/TagChipEditor/__tests__/useChipParser.property.test.ts` が新設され、fast-check を用いて任意のランダム文字列をパースしても例外クラッシュせず、構文の可逆性が維持されることが検証されパスすること。
  - [ ] AC-6: `backend/tests/test_workflow_scanner_property.py` が新設され、hypothesis を用いて破損した node JSON に対してもワークフロースキャナーが安全に `warnings` を返却することが検証されパスすること。
