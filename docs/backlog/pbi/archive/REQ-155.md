### REQ-155: タグチップサブメニュー内でのタグ単語編集機能の追加

- **Type**: feature
- **Status**: done (2026-08-30)
- **Priority**: P2
- **Surface**: タグチップのサブメニュー内で、タグチップの単語自体の編集を行えるようにしたい（例: `looking back` を `looking away` へ編集）。現状はタグの削除・再入力やテキストモード切替が必要で手間がかかる。
- **Root Cause**:
  - **Interaction / Workflow Friction**: タグチップの操作メニューにおいて、重み変更や削除などのメタ操作は可能だが、単語テキストそのものを直接修正・置換するインタラクション導線が存在しないため、単語変更のワークフローに不要なステップ（削除→再入力、またはテキストモード切替）が発生している。
- **Requirement**:
  1. タグチップのサブメニュー内にタグ単語を直接編集できる導線（編集項目またはインライン入力UI）を提供する。
  2. 単語の編集確定時に、タグに設定されている重み（weight）等の属性を維持したまま単語文字列が更新され、プロンプトへ即時反映される。
  3. 編集のキャンセルや空入力等のエッジケースに対して安全な操作体験を提供する。

#### Acceptance Criteria (AC)

##### 1. タグ編集導線の提供と入力
- [x] AC-1-1: タグチップのサブメニューに「タグを編集」などの単語編集導線が存在し、選択することでテキスト入力可能な状態に遷移すること。
- [x] AC-1-2: 編集開始時に現在のタグ単語が初期値として入力欄に設定されていること。

##### 2. 編集確定とプロンプト反映
- [x] AC-2-1: 新しい単語を入力して確定（Enterキーや確定ボタン）した際、タグの単語が更新され、プロンプトおよびタグ表示に反映されること。
- [x] AC-2-2: 重み（weight）等のタグ設定が存在する場合、単語の更新後もその属性値が保持されること。

##### 3. キャンセル・入力検証ハンドリング
- [x] AC-3-1: 編集操作をキャンセル（Escキー、キャンセル操作、外部クリック等）した場合、元の単語が維持されること。
- [x] AC-3-2: 空文字等の不正な入力で確定された場合、安全にキャンセルされるか、適切なフォールバック（または削除）が行われること。
