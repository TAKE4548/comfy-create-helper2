### REQ-015: タグチップエディタの導入（LLM連携除く）

- **Type**: enhancement
- **Status**: ready
- **Current step**: none
- **Priority**: P1
- **Surface**: タグチップ化についてかなり詳細の仕様を詰めたので、これに沿って改修したい。LLM連携関連の部分は、オプション的な扱いで別のPBIとしたい
- **Root Cause**: 現状のプロンプト入力は textarea による生文字列編集であるため、タグの干渉確認のための一時的な削除・戻し操作や、サジェスト適用時の不可逆な削除、試行錯誤中の変更履歴の可視化が困難である。
- **Requirement**: `input_type = "textarea"` のフィールドをタグチップ列（TagChipEditor）に置き換え、有効/無効トグル、削除、D&D並び替え、インライン編集、テキスト入力モード切替、診断・サジェスト連携、Undo/Redoショートカットを提供し、試行錯誤の効率を向上させる。ただし、モバイル表示およびLLM補完オプション・履歴ベースサジェストは対象外とする。
- **Design doc**: docs/spec_tag_chip_editor.md

#### Acceptance Criteria (AC)
##### 1. 表示および適用対象
- [ ] AC-1-1: モバイル表示を除き、`mapping_master.input_type === "textarea"` である入力フィールドにタグチップエディタが表示されること。
- [ ] AC-1-2: モバイル表示（`/mobile` ページなど）では、従来どおり `textarea` によるテキスト入力が維持されること。

##### 2. チップのステート管理と出力変換
- [ ] AC-2-1: チップは「有効（enabled）」と「無効（disabled: グレーアウト、テキスト取り消し線付き）」の2つの表示状態を持ち、テキスト部分のクリックで切り替えできること。
- [ ] AC-2-2: 生成実行（ComfyUIへの送信）やスナップショット保存時には、有効なチップのみをカンマと半角スペース（`, `）で連結した文字列が出力値として使用されること（無効なチップは送信・保存されないこと）。

##### 3. チップの個別操作
- [ ] AC-3-1: 各チップには削除ボタン（×）があり、クリックで即時に削除されること。
- [ ] AC-3-2: チップにキーボードフォーカスがあるとき、`Delete` または `Backspace` キーでチップが削除され、`Space` キーで有効/無効がトグルすること。
- [ ] AC-3-3: チップにキーボードフォーカスがあるとき、`Ctrl+D` でそのチップが複製されること。

##### 4. ドラッグ＆ドロップによる並び替え
- [ ] AC-4-1: チップをドラッグ＆ドロップして任意の順序に並び替えられること（`@dnd-kit/sortable` 等を使用）。
- [ ] AC-4-2: ドラッグハンドルにアクセシビリティ用のツールチップ（例:「ドラッグで並び替え / キーボード: Space → ←→」）が表示されること。

##### 5. インライン編集
- [ ] AC-5-1: チップをダブルクリックするとインライン入力フィールドに変化し、直接テキストを編集できること。
- [ ] AC-5-2: インライン編集中に `Enter` / `Tab` の押下、またはフォーカスアウトで編集が確定され、`Escape` でキャンセル（元の状態に復元）されること。空文字列で確定した場合はチップが削除されること。

##### 6. 新規タグ入力
- [ ] AC-6-1: チップ列の末尾に常時新規タグ入力用のフィールドが表示されていること。
- [ ] AC-6-2: 入力フィールドでカンマ（`,`）または `Enter` / `Tab` を入力した際、入力内容がトリミングされて新たな有効チップとして確定し、入力フィールドがクリアされること。
- [ ] AC-6-3: カンマ区切りのテキスト（例: `"tag1, tag2, tag3"`) をペーストした際、複数のチップに自動で分割されて一括生成されること。
- [ ] AC-6-4: 入力フィールドが空の状態で `Backspace` を押したとき、直前のチップが削除されること。

##### 7. テキスト入力モード（エスケープハッチ）
- [ ] AC-7-1: エディタ右上に「テキスト入力モードに切替」ボタンが存在し、押下すると従来の `textarea` 入力に切り替わること。切り替え時は有効チップのみがカンマ連結された文字列が `textarea` に初期値として入ること。
- [ ] AC-7-2: `textarea` 入力から「チップモードに切替」ボタンを押した際、テキストがカンマ区切りでパースされてチップ列に戻ること。

##### 8. サジェスション連携
- [ ] AC-8-1: 干渉タグ診断結果（`suggestedDisables`）に基づき、該当するタグの「無効化候補」ボタンをクリックすると、削除ではなくチップの有効状態（`enabled`）が `false`（無効）に変更されること。
- [ ] AC-8-2: 語彙サジェスト結果（`suggestedAdds`）の `[+ タグ名]` ボタンをクリックすると、該当タグがチップ列の末尾に有効チップとして追加されること。すでに存在するタグの場合は追加されないこと（冪等性の担保）。

##### 9. Undo/Redo の実装
- [ ] AC-9-1: チップエディタコンテナ内において、`Ctrl+Z` で直前のチップ操作（追加・削除・無効化・並び替え・編集）が Undo され、`Ctrl+Shift+Z` または `Ctrl+Y` で Redo されること。
- [ ] AC-9-2: Undo/Redo の履歴は最大50件まで保持され、それを超える場合は古いものから破棄されること。
