### REQ-070: モバイル・タブレットでの全画面プレビュー時の画像縮小およびナビゲーションバーのオーバーレイ問題

- **Status**: done (2026-08-30)
- **Description**: モバイルおよびタブレット環境において、履歴や生成結果の画像を全画面でプレビューした際、縦横比を維持しながら画面内に収まるように（長辺基準で）スケーリングされること。また、モバイル時の下部ナビゲーションバーがプレビュー画像の上に重なって表示されないようにすること。

#### Acceptance Criteria (AC)
- [x] AC-1: モバイル・タブレット環境（縦長画面）で全画面プレビューを開いた際、縦長の画像が画面幅いっぱいに拡大されて上下が見切れることなく、画像の全体が画面内に収まるように長辺基準でスケーリングされて表示されること。
- [x] AC-2: モバイル表示時に画面下部に表示されるボトムナビゲーションバーが、全画面プレビューモーダルの前面に表示されず、プレビューモーダルによって完全に覆われること（プレビューの z-index がナビゲーションバーより高いこと）。
