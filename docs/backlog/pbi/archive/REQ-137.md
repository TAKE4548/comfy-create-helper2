### REQ-137: SpeechBubbleEditorModal モバイルモード対応UIおよびタッチ操作の実装

- **Status**: done (2026-08-26)
- **Description**: `SpeechBubbleEditorModal`（REQ-136）において、画面幅が狭いモバイル端末（ビューポート 768px 未満）利用時にキャンバスとコントロールパネルが横並びで表示崩れを起こす課題を解消するため、レスポンシブな縦積み構造およびプレビュー・編集コントロールの切り替えUIを実装する。併せて、スマホ実機でのタッチ操作（Touch dragging）をキャンバス操作に対応させる。

#### Acceptance Criteria (AC)
- [x] AC-1: モバイル表示時（画面幅 768px 未満）に `SpeechBubbleEditorModal` がレスポンシブ配置（縦積み/タブ切替）で正しく表示され、コントロールパネルの全項目（テキスト入力、カラーピッカー等）がはみ出さずに操作可能であること。
- [x] AC-2: モバイル画面においてキャンバス描画領域が画面幅に合わせて自動縮小・アスペクト比維持でフィット表示されること。
- [x] AC-3: キャンバス上の吹き出し移動・尻尾調整・ROIドラッグ操作がタッチ操作（`Touch` イベント）で動作すること。
- [x] AC-4: デスクトップ表示（768px 以上）では従来の横並びレイアウトおよびマウス操作が維持されること。
