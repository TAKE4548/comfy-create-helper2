### REQ-010: 生成ワークフローのプロンプト、パラメータ初期値更新

- **Status**: done (2026-08-30)
- **Type**: enhancement
- **Priority**: P2
- **Current step**: none
- **Surface**: 自分好みのデフォルト値を保存し、ロード時の初期状態を最適化する。
- **Root Cause**: ワークフローを新規にロードした際、各入力パラメータ（プロンプト、シード、ステップ数、CFG等）はマスタ上の固定された定義値または空で初期化される。ユーザーが特定のワークフローに適合した好みの初期プロンプトや最適パラメータ設定を「ワークフロー単位の初期値」として保存し、次回ロード時にその最適状態から開始する機能が存在しない。
- **Requirement**:
  - ワークフローごとに、現在入力されているプロンプトやパラメータ（シード、CFG、Denoise、ステップ数等）の値を「デフォルト初期値」として保存する機能を提供する。
  - 新規にDBテーブルやカラムを追加するのではなく、現在設定されているパラメータ値に基づいて、ワークフローの `json_body`（ComfyUIのワークフローJSON構造）の該当する各ノードウィジェット値（`widgets_values` 等）を直接上書き更新し、ワークフロー情報（`PUT /api/workflows/{id}`）としてDBに保存・更新する方式を採用する。
- **Acceptance criteria**:
  - [ ] AC-1: 生成画面のパラメータ入力・編集エリア周辺に「現在のパラメータをデフォルトとして保存」できる操作UI（ボタン等）が提供されていること。
  - [ ] AC-2: 保存操作実行時、現在入力されている全パラメータ値（プロンプト、CFG、Denoise、ステップ数等）を反映させた形式で、ワークフローの `json_body` 内の該当するノードのウィジェット値を上書きし、FastAPIのワークフロー更新APIを通じてDBに永続化されること。
  - [ ] AC-3: ワークフロー選択時、localStorageにセッション履歴が存在しない場合、あるいはユーザーが「ワークフローのデフォルト値にリセット」するボタンをクリックした際に、DBからロードされた `json_body` に基づいて、各入力欄（プロンプト、CFG、Denoise、ステップ数等）の初期値が最適化されてセットされること。
- **Design doc**: none
