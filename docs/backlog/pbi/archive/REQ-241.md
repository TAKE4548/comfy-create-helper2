### REQ-241: Web Appからのサービス停止・再起動の不整合および競合バグの解消

- **Type**: defect
- **Status**: done (2026-09-09)
- **Current step**: Step 2: dev-design
- **Priority**: P1
- **Surface**:
  - Web UI（ポート 8899）から個別・一括の停止・再起動を実行した際に、反映されない、プロセスが起動しない、あるいは連打等で再起動ループに陥る
- **Root Cause**:
  - (実装・競合不具合) 
    1. Web UIとPowerShell間のサービス識別子の不一致（fe/be vs frontend/backend）
    2. server_api.pyのシングルスレッド同期ブロッキングおよびUI側の操作中ロック欠如
    3. 再起動時のポート解放待ち抜けによる二重起動防止ロジックの誤判定
    4. Web経由呼び出し時の-Backgroundフラグ欠落
    5. WSL2 ComfyUI停止コマンドとポート監視の不整合（WSLプロキシの誤爆kill）
- **Requirement**:
  - Web UIおよびPowerShellスクリプト（server-manager.ps1）において、個別・一括の起動・停止・再起動が確実に実行され、競合や多重実行による不整合が発生せず安定して動作すること
- **Acceptance criteria**:
  - [x] AC-1: Web UIの各カード（Frontend, Backend, ComfyUI）から個別に停止・再起動を実行した際、対象サービスが確実に停止・再起動されること。
  - [x] AC-2: 「全サービス再起動」を実行した際、既存プロセスの終了とポート解放完了を待ってから再起動が行われ、サービスが停止したまま脱落しないこと。
  - [x] AC-3: アクション実行中はUI上の操作ボタンが非活性（disabled）となり、二重送信や連続クリックによる多重リクエスト投入が防止されること。
  - [x] AC-4: アクション実行中であっても、ステータス取得ポーリングがサーバー側で詰まらずに応答すること。
  - [x] AC-5: Web UIからサービスを起動・再起動した際、対話コンソールウィンドウのポップアップを伴わずバックグラウンドで正常に起動すること。
  - [x] AC-6: ComfyUI停止時にWSL2のネットワーク仲介（プロキシ）が破損せず、再起動後もポート導通が正常に維持されること。
  - [x] AC-7: PCのローカルIPアドレスが自動検出され、サーバー起動コンソールおよびWeb UIヘッダーに同一LANアクセス用URLが表示されること。
