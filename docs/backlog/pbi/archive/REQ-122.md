### REQ-122: ワークフロー内プロファイルの一括削除および一括編集機能

- **Status**: ready
- **Description**: ワークフロー複製時や既存構図セットの再利用において、複数プロファイルの編集・調整の手間を削減するため、指定プロファイル群に対する一括削除、およびプロンプト・生成パラメータ（LoRA, サンプラー, スケジューラ, CFG, ステップ数, バッチ数等）の一括編集機能を実装する。

#### Acceptance Criteria (AC)

##### 1. 対象プロファイルの選択UI (Profile Target Selection)
- [ ] AC-1-1: ワークフロー編集／プロファイル一覧画面において、各プロファイルに一括操作対象を選択するためのチェックボックスが表示されること。
- [ ] AC-1-2: 「全選択」および「全解除」ボタン／チェックボックスが提供され、一括で選択状態を切り替えられること。

##### 2. プロファイルの一括削除機能 (Bulk Delete Profiles)
- [ ] AC-2-1: 選択された1つ以上のプロファイルを一括で削除できる機能を提供すること。
- [ ] AC-2-2: 削除実行前に確認ダイアログ（誤削除防止）を表示し、承認後に一括削除処理が行われること。

##### 3. プロンプトの一括編集機能 (Bulk Edit Prompts)
- [ ] AC-3-1: **文字列の検索・置換**: 選択した全プロファイルのプロンプト（Positive/Negative等）に対し、指定した文字列を検索して置換できること（例: 特定のキャラLoRAタグや記述の置き換え）。
- [ ] AC-3-2: **全置換・追加**: 選択した全プロファイルのプロンプト全体の上書き、または先頭（Prefix）・末尾（Suffix）へのテキスト追加・挿入ができること。

##### 4. パラメータの一括編集機能 (Bulk Edit Parameters)
- [ ] AC-4-1: **LoRA設定**: 選択した全プロファイルに対し、追加・変更するLoRAモデルおよびウェイトを一括設定・適用できること。
- [ ] AC-4-2: **生成パラメータ**: 選択した全プロファイルに対し、サンプラー、スケジューラ、CFG Scale、ステップ数、バッチ数などの各設定値を一括変更・上書きできること。
- [ ] AC-4-3: 指定したフィールド（パラメータ）のみを部分的に一括変更でき、変更対象として指定しなかった他の項目は既存の値を保持すること。
