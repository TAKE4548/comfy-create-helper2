### REQ-310: 設定画面における FuguMT プロバイダ統合

- **Status**: done (2026-10-03)
- **Description**: FuguMT（CPU軽量和訳）を設定画面の翻訳プロバイダ選択肢として追加する。これにより、ユーザーはUIからFuguMTを選択可能になり、不要なLLM経由の翻訳によるレイテンシ（30-40秒）やVRAM競合を回避し、完全CPU常駐・20-30msの超低レイテンシで翻訳を実行できるようになる。

#### Acceptance Criteria (AC)
- [ ] AC-1: Given ユーザーが設定画面を開いたとき、When 「翻訳設定」セクションを確認すると、Then 翻訳プロバイダの選択肢に「FuguMT」が固定の「推奨 (CPU)」バッジ付きで表示されていること。
- [ ] AC-2: Given FuguMTを選択したとき、When UIを確認すると、Then APIキー入力欄およびAPI URL入力欄が非表示になり、保存時に `provider: "fugumt"` （apiKeyやurlを含まない）ペイロードで設定がDBに永続化されること。
- [ ] AC-3: Given FuguMTを選択した状態で、When 「接続テスト」ボタンを押下すると、Then `provider: "fugumt"` のペイロードがバックエンドに送信され、エンジンが正常にロードされた場合はテスト翻訳が返却され、モデルがない場合は明確なエラーメッセージが返却されること。
- [ ] AC-4: Given 設定画面でFuguMTを保存したとき、When Generate画面で翻訳を実行すると、Then ローカルLLMへのリクエストが発生せずFuguMTサービスへ直接ルーティングされ、100ms以内のレイテンシで和訳結果が返却されること。
