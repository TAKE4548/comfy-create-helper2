### REQ-139: 画像保存時のアルバム選択状態の保持

- **Type**: enhancement
- **Status**: ready
- **Current step**: none
- **Priority**: P2
- **Surface**: 生成画像を保存するとき、保存先のアルバム選択を前回保存時の選択状態を維持できるようにしたい
- **Root Cause**: 生成画像の保存時（またはアルバム保存ダイアログ/セレクタ等）において、保存先アルバムの選択状態が保存完了後や次回起動時に保持・復元されず、連続して同じアルバムに画像を保存する際に毎回選択し直す手間が発生している。
- **Requirement**: 画像保存処理や保存先アルバム選択UIにおいて、前回選択された保存先アルバムを記憶・保持し、次回保存時や次回モーダル/セレクタ表示時に自動的に前回選択したアルバムが初期値として選択されているようにする。

#### Acceptance Criteria (AC)

##### 1. 前回選択アルバムの記憶と初期選択
- [ ] AC-1-1: 画像保存処理でアルバムを選択して保存（または選択変更）を行った際、選択されたアルバムが次回保存操作時の初期値として保持されること。
- [ ] AC-1-2: モーダル/セレクタの再オープン時や画面遷移後も、前回保存時のアルバム選択状態が正しく復元・初期選択されていること。

##### 2. 状態更新と例外ハンドリング
- [ ] AC-2-1: ユーザーが別のアルバムを選択、または「アルバムなし/未選択」を選択して保存した場合は、その選択内容で記憶状態が更新されること。
- [ ] AC-2-2: 記憶されていたアルバムが削除されているなど無効な状態の場合、エラーとならず適切にフォールバック（未選択またはデフォルト状態）されること。
