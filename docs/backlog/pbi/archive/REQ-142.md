### REQ-142: セリフ編集における新規吹き出し作成時の装飾設定（フォント等）の直前設定引き継ぎ

- **Type**: enhancement
- **Status**: done (2026-08-26)
- **Current step**: none
- **Priority**: P2
- **Surface**: セリフ編集のフォント選択状態などの装飾設定を、吹き出し新規作成時に直前の設定を引き継ぐようにしたい。既存の吹き出しを選択切替する場合は、既存の設定を優先するが、新規生成時は設定を統一しつつ局所的に編集できるようにしたい。
- **Root Cause**: **Interaction Design (Workflow Friction)**: 吹き出し新規作成時に常に固定の初期デフォルト値が適用されるため、同じフォントや装飾スタイルで複数の吹き出しを連続作成する際に毎回同一の設定を再選択・再調整する手作業が発生していた。
- **Requirement**: セリフ編集画面において、吹き出しを新規作成する際に直前に選択・編集されていた装飾設定（フォント種類、フォントサイズ、文字色、吹き出しスタイル等）を自動的に初期値として引き継ぐ。既存の吹き出しを選択した際はその吹き出し独自の個別設定を忠実に反映し、新規生成時の一貫性と個別吹き出しの柔軟な編集性を両立する。
- **Design doc**: [docs/design/REQ-142.md](docs/design/REQ-142.md)

#### Acceptance Criteria (AC)

##### 1. 新規吹き出し作成時の直前設定引き継ぎ
- [ ] AC-1-1: セリフ編集画面で新規吹き出しを追加した際、直前に編集または選択されていた吹き出しの装飾設定（フォントファミリー、フォントサイズ、テキスト色、背景色、枠線色/太さ等のスタイル設定）が初期値として引き継がれること。
- [ ] AC-1-2: 編集開始直後（直前の編集履歴がない初回追加時）は、標準の規定デフォルト設定で吹き出しが作成されること。

##### 2. 既存吹き出し選択時の個別設定保持
- [ ] AC-2-1: 既に存在する吹き出しを選択・切り替えた際、直前の設定で上書きされることなく、選択された吹き出し固有の設定値がエディタUIおよびキャンバスに正しく読み込まれ表示されること。
- [ ] AC-2-2: 既存吹き出しを選択して装飾設定を変更した場合、その変更内容が最新の「直前設定」として保持され、以降に新規追加される吹き出しに反映されること。

##### 3. 局所的な個別編集の独立性
- [ ] AC-3-1: 直前の設定を引き継いで新規作成された吹き出しに対して装飾設定を変更しても、過去に作成された他の吹き出しの設定内容には影響を与えず、独立して編集可能であること。
