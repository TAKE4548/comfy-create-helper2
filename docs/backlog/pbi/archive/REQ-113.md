### REQ-113: プリセット管理モーダルからタブを開く機能の配線漏れ修正

- **Status**: done (2026-08-26)
- **Root Cause**: REQ-112 実装時に `openPreset` ストアアクションの UI 配線が欠落した
- **Description**: プリセット管理モーダル（`isPresetManagerOpen=true`）の一覧でプリセット行をクリックしても、タブバーにタブが追加されない。ストア側の `openPreset(id)` は実装済みだが、`PresetManagerPanel` コンポーネントに対する Props 配線と UI 要素が未実装。

#### Acceptance Criteria (AC)

- [ ] AC-1: プリセット管理モーダルの各プリセット行をクリックすると、タブバーにそのプリセットがタブとして追加され、モーダルが閉じる
- [ ] AC-2: 既にタブとして開かれているプリセットをクリックした場合は、そのタブをアクティブにしてモーダルが閉じる（重複タブを作らない）
- [ ] AC-3: `SortablePresetRow` の既存操作（ドラッグ、チェックボックス、鉛筆ボタン、削除ボタン）が引き続き正常動作する（リグレッションなし）
