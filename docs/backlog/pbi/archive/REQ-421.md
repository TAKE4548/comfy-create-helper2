- **Type**: chore
- **Status**: new
- **Priority**: P2
- **Surface**: docs/backlog/task/active/REQ-413-T3.md
- **Origin**: REQ-419 クローズ時の後続対応事項
- **5 Whys / Root Cause**:
  1. なぜ必要か: REQ-413-T3 カードが対象セクションとして「SPEC_SETTINGS.md §4-1-1『登録・リマッピングの基本方針』」を指定しているが、その見出しは SPEC_SETTINGS.md に存在しない（現在の §4-1-1 は「REQ-358 ノード候補とworkflow slot状態」）。
