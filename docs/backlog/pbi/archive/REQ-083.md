### REQ-083: レイアウトおよび設定画面の共通UI操作性改善

- **Status**: done (2026-08-26)
- **Description**: 
  1. 左右ペインやセクションの境界をドラッグ＆ドロップ（D&D）して任意の幅や高さに調整できるようにする。これは生成ページだけでなく、他ページでも再利用可能な共通レイアウト仕様とする。
  2. 設定画面において、各大項目（セクション）ごとに折り畳み（アコーディオン）可能にし、設定項目の見通しを改善する。

#### Acceptance Criteria (AC)
- [ ] AC-1: 左右ペインおよび上下セクションの境界線にドラッグ可能なハンドルが表示され、D&Dで幅・高さを任意に変更できること。
- [ ] AC-2: リサイズ領域の最小幅/最小高さの制限が適切に設定されており、UIが崩れないこと。
- [ ] AC-3: 変更したリサイズ幅・高さの情報がブラウザ（LocalStorage等）に保持され、再読み込み時も維持されること。
- [ ] AC-4: 設定画面の各大項目ヘッダーをクリックすることで、その配下の設定項目を折り畳み/展開できること。デフォルトは展開状態であること。
