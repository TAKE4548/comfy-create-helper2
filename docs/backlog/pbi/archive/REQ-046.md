### REQ-046: プレビューのウィンドウフルサイズ対応

- **Type**: enhancement
- **Status**: ready
- **Current step**: none
- **Priority**: P2
- **Surface**: 
  - プレビューのウィンドウフルサイズ対応したい。
  - Height・Widthどちらかの長辺方向をウィンドウ端まで拡大する。左右のボタンクリックで画像送り、右上に通常プレビューに戻るボタンを設ける。
  - 生成画面のメインプレビューと、スナップショット一覧画面(アルバム含む)に適応する。
  - 一覧画面の方では、画像クリック・タップでフルサイズプレビューを標準にし、右下に情報表示用アイコンを設け、それをクリック・タップでメタ情報を出す現行のプレビューと切り替えたい。
  - タッチ操作時は左右スワイプでの画像送りもサポートする。
- **Root Cause**:
  - 現状のプレビュー表示は固定サイズまたは縮小されたサイズであり、縦横の長辺をウィンドウサイズいっぱいに拡大表示して細部を確認する手段がない。
  - 画像の一覧（スナップショット一覧・アルバム）において、画像を順番に確認する（画像送り）手段がなく、1枚ずつ閉じて開き直す必要がある。
  - 一覧画面で画像をクリックするとメタ情報表示がデフォルトで開くが、画像そのものを大きく見たいニーズが強く、画像閲覧とメタ情報閲覧を柔軟に切り替えられる仕組みが不足している。
- **Requirement**:
  - 生成画面のメインプレビューおよびスナップショット一覧画面（アルバム含む）において、ウィンドウの長辺に合わせたアスペクト比維持のフルサイズプレビュー表示に対応する。
  - フルサイズプレビュー時は、暗めの半透明背景でオーバーレイし、左右の画像送りボタンおよび右上に戻るボタンを提供する。タッチデバイスではスワイプによる画像送りも可能にする。
  - 一覧画面（アルバム含む）では、画像クリック・タップ時のデフォルト動作をフルサイズプレビューとする。右下にメタ情報表示用のアイコンを設け、クリック・タップによって「現行のメタ情報表示＋縮小画像プレビュー」モードとトグル切り替え（パターンB）ができるようにする。
- **Acceptance criteria**:
  - **AC-1 (フルサイズプレビューの基本UI・レイアウト)**:
    - 生成画面のメインプレビューおよびスナップショット一覧画面（アルバム含む）で、画像をアスペクト比維持したまま、縦または横の長辺がウィンドウ端に接するまで拡大して表示するフルサイズプレビュー（暗い半透明のモーダルオーバーレイ背景）が表示されること。
  - **AC-2 (プレビューナビゲーションと操作)**:
    - プレビュー画面の右上に通常表示に戻るボタン（閉じるボタン）が表示され、クリック・タップでプレビューを終了できること。
    - プレビューの左右に送り戻しボタンが表示され、クリック・タップで前後の画像に切り替えられること。
      - 生成画面メインプレビューの場合：生成履歴の画像を対象とする。
      - スナップショット一覧画面（アルバム含む）の場合：現在一覧（フィルタリング後）に表示されている画像を対象とする。
    - タッチスクリーン環境において、左右のスワイプ操作で前後の画像へ切り替え可能であること。
  - **AC-3 (一覧画面におけるデフォルトプレビューとトグル切り替え)**:
    - スナップショット一覧画面（アルバム含む）で画像をクリック・タップした際、デフォルトで上記のフルサイズプレビューが開くこと。
    - フルサイズプレビューの右下に「情報表示用アイコン」が表示され、クリック・タップすることで、現行の「メタ情報表示＋縮小画像」モード（パターンB：レイアウト切り替え）へと相互にトグル切り替えできること。
- **Design doc**: none
