### REQ-021: アセット追加時のプロンプト直接挿入およびLoRAトリガー選択モーダル機能

- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: Step 1
- **Priority**: P2
- **Surface**:
  add assetの動きが想定と違う。
  適用しているか否かのバッジはあっていいが、プロンプト入力欄にトリガセット・タグセットが追加される想定。
  LoRAに関してはトリガセットが複数種登録されている場合があるので、一度モーダルでどのトリガセットを適用するか選択するフェーズを設けたい
- **Root Cause**:
  - 現在の「アセット追加（Add Asset）」は、選択したアセットをプロンプト入力欄とは別の「適用中アセット」という独立したリスト（チップ）として管理し、生成時に裏でプロンプトテキストと結合する仕様になっている。
  - しかしこの挙動では、追加されたアセット（LoRAトリガーワードやタグセットの内容）がエディタ上で直接可視化・編集できないため、ユーザーがプロンプトの構成や順序を微調整しづらいという不便さがある。
  - また、LoRAアセットに複数の異なるトリガーセットが登録されている場合があるが、現在はどのトリガーセットを適用するか選択するインターフェースが存在しない。
- **Requirement**:
  - **プロンプト入力欄（TagChipInput）への直接追加**:
    - アセット追加（Add Asset）メニューからタグセットまたはLoRAを追加した際、そのアセットに関連するトリガーワードやタグ群が、対象のプロンプト入力欄（TagChipInput）へカンマ区切りのタグチップとして直接挿入されること。
  - **LoRAトリガーセットの選択モーダル**:
    - LoRAアセットを追加する際、登録されているトリガーセットの数にかかわらず、どのトリガーセットを適用するかを選択するモーダル（ダイアログ）を常に表示すること。
    - モーダルで選択したトリガーセットのタグ（およびLoRA埋め込み文字列 `<lora:filename:strength>`）がプロンプト入力欄に挿入される。
  - **適用中バッジ（インジケータ）の維持**:
    - アセットが適用されていることを示すバッジ（適用中インジケータ）は、プロンプト欄の周辺に引き続き表示し、どのアセットが現在有効か視覚的に確認できるようにする。
- **Acceptance criteria**:
  - [ ] AC-1: 各プロンプトヘッダーの「+ Add Asset」からタグセットを選択したとき、タグセットに含まれるすべてのタグが、対象のプロンプト入力欄（TagChipInput）に直接チップとして追加されること。
  - [ ] AC-2: 「+ Add Asset」からLoRAを選択した際、登録されているトリガーセットの数にかかわらず、どのトリガーセットを適用するか選択できるモーダルが表示されること。
  - [ ] AC-3: LoRAトリガーセット選択モーダルでトリガーセットを決定したとき、選択されたトリガーセットのワード（および `<lora:filename:strength>` 形式のLoRAタグ等）が、対象のプロンプト入力欄に直接追加されること。
  - [ ] AC-6: LoRAにトリガーセットが登録されていない、もしくは空の場合でも、モーダル上でデフォルトの適用（あるいはトリガーなしでの適用）を選択・決定できること。
  - [ ] AC-4: アセットの追加後も、そのアセットが適用（あるいは読み込まれている）状態を示すバッジ（インジケータ）が、プロンプト入力エリアの周辺（または下部など）に表示され続けること。
  - [ ] AC-5: 追加されたタグチップは、プロンプト入力欄（TagChipInput）内で通常のタグチップと同様に削除・編集ができること。

- **Design doc**: none
