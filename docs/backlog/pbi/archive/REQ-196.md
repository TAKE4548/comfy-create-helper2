### REQ-196: LoRA管理・タグセット管理の編集モーダルおよびサムネ操作の不具合改修
- **Type**: bugfix
- **Status**: done (2026-08-29)
- **Current step**: Phase 3: Verification & Closure
- **Priority**: P1
- **Surface**:
  - モバイルモードで編集モーダルを開いたら、保存・キャンセルボタンが下部メニューにかぶって操作できない
  - 詳細モーダルから遷移する編集モーダルと、サムネ上のアイコンから遷移する編集モーダルが異なり、詳細モーダルから遷移する方は編集項目が不足している
  - サムネ上の編集・削除アイコンが、カーソルホバーでの表示になるため、モバイルモードでは視認できないままタップしなければならない
  - カバーサムネを設定する際の、詳細モーダル上で候補画像のサムネが表示されず、目的の画像へ画像送りでしかたどり着けない
- **Root Cause**:
  - TagsPage.tsx の独自モーダルが z-50 かつ共通 modal-backdrop クラス未使用のためモバイルナビバー（z-50）と重なって操作不能。
  - タグセット編集コンポーネントが TagsPage.tsx と TagSetModals.tsx で二重管理されており、TagSetDetailModal の編集フォームで target_base_model_ids と subsets の実装が欠落。
  - サムネイル上の編集・削除アイコンが opacity-0 group-hover:opacity-100 固定のためタッチデバイス環境で不可視、かつドラッグハンドルと配置が重複。
  - LocalTagSetEditModal で候補画像一覧（Related Snapshots）が未実装、および詳細モーダル（TagSetDetailModal/LoraDetailModal）でモバイル表示時に縦幅圧迫・レイアウト制約により一覧が見切れ/不可視。
- **Requirement**:
  - モバイルモードでも編集モーダルの保存・キャンセル等のアクションが下部メニューに被らず操作可能であること。
  - タグセットの編集フォームを一元化し、詳細モーダル経由でもサムネイルアイコン経由でもすべての項目（ベースモデル、サブセット含む）が編集・保存できること。
  - モバイル環境でサムネイル上の操作アイコンが視認可能であり、ドラッグハンドルと競合せずに操作できること。
  - LoRAおよびタグセットの詳細・編集モーダルにおいて、候補画像サムネイル一覧が確実に表示・選択できること（モバイル表示時もプレビューと一覧が適切にスクロール可能であること）。
- **Acceptance criteria**:
  - [x] AC-1: モバイル画面幅においてLoRA・タグセットの編集モーダルを開いた際、保存・キャンセルボタンが下部ナビゲーションバーの前面に正しく表示され、スクロールおよびタップ操作ができること。
  - [x] AC-2: タグセット詳細モーダルからの編集時において、「Target Base Models」および「Subsets（バリエーション）」を含むすべての設定項目が表示され、編集・保存が正常に動作すること。
  - [x] AC-3: タグセット編集のコンポーネント定義が一元化され、サムネイル上の編集アイコン経由と詳細モーダル経由で編集機能・UIの差異・欠落がないこと。
  - [x] AC-4: モバイル（タッチ）環境において、カードサムネイル上の編集・削除アイコンが視認でき、ドラッグハンドルとの誤操作・重複なく操作できること。
  - [x] AC-5: タグセットおよびLoRAの詳細・編集モーダルにおいて、候補画像サムネイル一覧（Related Snapshots）が表示され、クリック/タップでカバー画像として選択・設定できること（モバイル表示時もプレビューと一覧が切断されず操作可能であること）。
