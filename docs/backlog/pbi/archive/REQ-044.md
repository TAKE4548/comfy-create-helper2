### REQ-044: アルバム追加機能の改善（既存アルバムへの追加・検索）

- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: none
- **Priority**: P2
- **Surface**: スナップショット一覧で、既存のアルバムに追加する手段がない。New Albumの代わりに、アルバムへの追加か新規アルバム作成かを選択できるようにしたい。
- **Root Cause**: アルバムへの追加UIにおいて、新規作成のみが提供されており、既存アルバムの一覧表示や検索による追加を行う機能（Interaction）が不足している。
- **Requirement**: アルバムへの追加操作を行う各画面（スナップショット一覧、履歴詳細など）において、既存アルバムの検索・選択と新規アルバムの作成を同一UI上でシームレスに切り替えて実行できる共通コンポーネントを導入する。
- **Design doc**: none

#### Acceptance Criteria (AC)
- [ ] AC-1 (Existing Album Selector): アルバムへの追加操作を行うダイアログにおいて、既存のアルバム一覧から追加先を選択できるセレクト/ドロップダウンUIが表示されること。
- [ ] AC-2 (Select Options & Top Action): セレクト/ドロップダウンの選択肢の最上部に「新規アルバム作成」のオプションが配置されており、これを選択した場合は新規のアルバム名を入力するフォームが表示・活性化されること。
- [ ] AC-3 (Search/Filter Function): 既存アルバムの選択肢が多い場合に対応するため、ドロップダウン内でアルバム名をキーワードでインクリメンタル検索（フィルタリング）できること。
- [ ] AC-4 (Shared Implementation): スナップショット一覧（Snapshot list）および生成履歴（History）など、スナップショットをアルバムに追加するすべての機能箇所でこの改善された共通のアルバム追加UI/UXが適用されていること。
