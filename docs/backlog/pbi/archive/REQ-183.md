### REQ-183: 生成プリセットのタブ切り替え高速化・多重レンダリング解消
- **Type**: defect
- **Status**: ready
- **Current step**: none
- **Priority**: P2
- **Surface**: 生成プリセットのタブ切り替えが重たく、クリックしてからアクティブになるまで2~3秒かかる
- **Root Cause**: handleLoadPreset 内での多重・非バッチ Zustand 更新、activeSetId 連動の presets 同期 useEffect 発火、TagChipEditor での毎描画パースおよび onChange 逆流ループ、コンポーネントメモ化不足による連続再描画
- **Requirement**: 生成プリセットのタブ切り替えを瞬時（100ms以内）に完了させ、不要な多重再描画やステート逆流を防止する
- **Acceptance criteria**:
  - [ ] AC-1: 生成画面の Multi-Set Tab Bar でタブをクリックした際、200ms以内にアクティブタブのハイライトおよび入力値が切り替わること
  - [ ] AC-2: プリセット切り替え時に不要な多重再描画や自動保存の誤発火が発生しないこと
  - [ ] AC-3: 既存のプリセット読み込み・編集・保存・パラメータ同期機能が正常に動作すること
- **Design doc**: none
