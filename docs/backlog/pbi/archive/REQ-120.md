### REQ-120: 吹き出しセリフの縦書き化とフォントサイズ自動調整機能

- **Status**: ready
- **Description**: 吹き出し編集機能において、セリフテキストを縦書き表示（日本語マンガの標準形式）に変換し、さらに文章量と吹き出し矩形サイズ（Bounding Box）に合わせてフォントサイズを自動計算・調整し、常に吹き出し内にセリフが綺麗に収まるようにします。ユーザーによる手動のフォントサイズ指定操作を不要とすることで、UI操作の摩擦を軽減し、レイアウト調整を自動化します。

#### Acceptance Criteria (AC)
- [ ] AC-1: 吹き出しプレビューおよび出力画像に重畳されるセリフテキストが、縦書き方向（上から下、右から左の改行）で表示・描画されること。
- [ ] AC-2: 入力テキスト量と吹き出しの矩形サイズ（幅・高さ）を検知し、文字が吹き出しの矩形外にはみ出さない最適なフォントサイズが自動計算されて適用されること。
- [ ] AC-3: 手動でのフォントサイズ設定欄（スライダー等）は不要となるため、UIから非表示または削除されること。
- [ ] AC-4: 長文や手動の改行（`\n`）が含まれる場合でも、縦書きにおける複数行の折り返しと行揃えが崩れず、正しく描画されること。
- [ ] AC-5: 吹き出し編集モーダルでのプレビュー画面と、実際に保存したスナップショット（派生画像）の双方で、上記縦書きと自動フォントサイズ調整が同一のレイアウトで反映されること。
