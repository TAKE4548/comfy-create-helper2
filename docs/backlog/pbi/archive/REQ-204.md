### REQ-204: セリフLLM変換における画像コンテキストおよび画像別場面ヒント付与・反映機能（マルチモーダル対応・単体/一括での画像別シーン説明入力）
- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: Phase 4: Implementation & Verification (Completed)
- **Priority**: P2
- **Surface**:
  - セリフのLLM変換で、画像も渡して場面解釈のヒントにしてもらい、変換するセリフのトーンに反映されるようにしたい。
  - 口調変換に用いるプロンプトはプリセットとして共通保存できるが、画像ごとにシチュエーションや文脈（「照れて強がっている」「敵に追い詰められて焦っている」など）が異なるため、画像単位で任意の「場面のヒント・説明テキスト」を付与できるようにしたい。
  - 単体変換（単一画像の吹き出し編集）および一括変換（複数画像のバッチ変換）のいずれにおいても、画像データ（ビジョン）と合わせて画像ごとに個別の場面ヒントテキストを入力・付与し、LLMの場面解釈および口調トーンの決定に反映させたい。
- **Root Cause**:
  - **Information Design (Missing Multimodal Context & Per-Image Scene Hint Integration)**: セリフ口調変換の入力データが口調プリセットとセリフテキストのみに限定されており、対象画像（スナップショット）の視覚情報（表情、姿勢、シチュエーション）および画像ごとの個別文脈（場面説明テキスト）をマルチモーダルLLM等へ連携して場面解釈を補助させるデータモデル・プロンプト連携機構が存在しない。
  - **Interaction Design (Per-Image Context Input & Control in Single/Batch Workflows)**: 単体セリフ編集画面および一括変換画面において、画像ごとの場面ヒントテキストを任意入力・編集・確認できるUI、および画像参照のON/OFFやモデルに応じたフォールバック制御機構が提供されていない。
- **Requirement**:
  - セリフのLLM口調変換（単一吹き出し編集および一括バッチ変換）において、対象画像データ（ビジョン）および画像ごとに任意の「場面ヒント・説明テキスト」をLLMに連携し、場面・表情・コンテキストを解釈させた上で適切なトーン・ニュアンスのセリフに変換できるようにすること。
  - 単体セリフ編集画面において、対象画像に対する場面ヒントテキストを任意入力でき、画像参照ON/OFFとともにセリフ変換を実行できること。
  - 一括セリフ変換画面において、選択された各画像に対して個別に場面ヒントテキストを入力・編集でき、画像ごとに異なる文脈を持たせて同一または指定の口調プリセットによる一括変換を実行できること。
  - 場面ヒントテキストが未入力の場合や画像参照OFF時、またはマルチモーダル非対応モデル使用時でも、従来のテキストのみによるセリフ変換処理にスムーズにフォールバック・互換動作すること。
  - 入力された場面ヒントテキストはスナップショットやバッチジョブ情報として適切に保持され、再生成や微調整時にも再利用できること。
- **Acceptance criteria**:
  - [x] AC-1: 単体セリフ編集画面において、対象画像の画像参照（ON/OFF）とともに、任意の「場面ヒント・説明テキスト」を入力でき、LLM変換時に画像情報およびヒントテキストが反映されたトーンでセリフが生成されること。
  - [x] AC-2: 一括セリフ変換画面において、選択した各画像に対して個別の「場面ヒント・説明テキスト」を入力・編集する領域が提供され、画像単位で異なる場面文脈を付与して一括変換を実行できること。
  - [x] AC-3: セリフ変換実行時に、画像データ（ビジョン）および場面ヒントテキストがLLMへの入力コンテキスト・プロンプトに適切に組み込まれ、キャラクターの表情やシチュエーションに応じたセリフ変換結果が得られること。
  - [x] AC-4: 場面ヒントテキストが未入力（空文字）の場合や画像参照OFF時、またはマルチモーダル非対応モデル使用時でもエラーとならず、従来のテキスト口調変換として正常に動作すること。
  - [x] AC-5: 一括変換時のジョブキューや単体編集時において、画像ごとに設定した場面ヒントテキストが保持され、再生成やリトライ時にも同じヒント情報を用いて再変換できること。
