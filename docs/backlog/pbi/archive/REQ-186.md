### REQ-186: 生成画面のプリセット管理モーダルにおけるモーダル継続表示と複数タブ開閉操作性の改善
- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: Phase 3: Task Decomposition & Planning
- **Priority**: P2
- **Surface**: 生成画面のプリセット管理モーダルで、プリセット選択後に自動で閉じるが、そのまま開きっぱなしにしておきたい。また、管理モーダルからも閉じられるようにして、複数タブの開く・閉じるを連続的に作業できるようにしたい
- **Root Cause**: 
  1. 【Interaction/自動クローズ】プリセット選択時に管理モーダルが自動的に閉じる仕様となっており、複数プリセットの適用確認やタブの整理・切り替えを連続して行いたいユーザーの操作フローを中断させている。
  2. 【Interaction/タブ管理】管理モーダル内から各プリセット/タブを直接閉じる（または非表示・整理する）操作導線が不足しており、モーダルを開いたまま複数タブの開閉・整理を一括して行えない。
- **Requirement**: 生成画面のプリセット管理モーダルにおいて、プリセット選択後もモーダルが自動で閉じずに開いたまま維持され、モーダル内から直接タブ（プリセット）の開閉操作を行えるようにすることで、複数タブの開く・閉じるを連続して効率的に作業できるようにする。
- **Acceptance criteria**:
  - [ ] AC-1: プリセット管理モーダル内でプリセットを選択（ロード・適用）しても、モーダルが自動で閉じずに開いた状態が維持されること
  - [ ] AC-2: プリセット管理モーダル内から各プリセット/タブを閉じる（非表示化・整理）操作が直接実行可能であること
  - [ ] AC-3: プリセット管理モーダルを開いたまま、複数タブの「開く（選択）」および「閉じる」操作を連続して実行できること
  - [ ] AC-4: プリセット管理モーダル自体を閉じる明確な操作（閉じるボタンの押下等）により、作業完了時にユーザーが意図してモーダルを閉じられること
  - [ ] AC-5: 既存のプリセット保存・更新・適用等の基本機能にデグレーションが発生しないこと
