### REQ-033: スマートフォン接続時のスナップショット画像非表示バグの修正

- **Status**: done (2026-08-30)
- **Description**: スマートフォンや外部端末から IP アドレス等でフロントエンドにアクセスした際、過去のスナップショット画像が localhost への直参照となっており非表示になる問題を解決するため、バックエンド側で画像をダウンロードして `db/snapshots/` に保存し、相対パス `/api/snapshots/images/<filename>` で配信するよう修正する。

#### Acceptance Criteria (AC)
- [ ] AC-1: バックエンドの `POST /api/snapshots` において、`image_path` が外部 URL（`http://` または `https://`）の場合、自動的にその画像をダウンロードして `db/snapshots/` ディレクトリ配下にユニークなファイル名で保存すること。また、DB には配信用相対パス `/api/snapshots/images/<filename>` を保存すること。
- [ ] AC-2: バックエンド（FastAPI）の起動時に `db/snapshots` が `/api/snapshots/images` パスへ静的ファイルとしてマウント・配信されるよう設定すること。
- [ ] AC-3: `POST /api/snapshots` で保存した画像が、スマートフォン等の他端末からホストPCのIPアドレス経由でアクセスした際にも正常に表示できること（Vite のプロキシを通じて配信されること）。
- [ ] AC-4: テスト（`backend/tests/test_snapshots.py` 等）で snapshot 保存・取得APIの挙動が壊れていないこと。
