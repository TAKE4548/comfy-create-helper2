### REQ-243: Web Manager 自体の再起動バッチ (restart_web_manager.bat) の追加

- **Type**: enhancement
- **Status**: done (2026-09-10)
- **Current step**: none
- **Priority**: P2
- **Surface**:
  - manager自体のreboot用batを作って、不調時や更新時にワンクリックでWeb Manager（ポート8899）を再起動できるようにしたい。
- **Root Cause**:
  - (UX分類: Interaction / Workflow Friction) 現状はWeb Manager（ポート8899）専用の停止・再起動スクリプトが存在せず、Manager自体のプロセス更新やトラブルシューティング時に手動でポート解放やプロセス終了を行う必要があり、運用操作上の摩擦が生じている
- **Requirement**:
  - Web Manager（ポート8899）の稼働プロセスを自動検知して安全に終了し、ポートの解放を確認した後に自動で再起動を行うワンクリックバッチファイル（`restart_web_manager.bat`）を提供すること
- **Acceptance criteria**:
  - [x] AC-1: `restart_web_manager.bat` を実行した際、ポート 8899 を占有している既存の Web Manager プロセスが自動検知され、安全に停止（プロセス終了）されること。
  - [x] AC-2: 停止処理後、ポート 8899 が完全に解放されたことを確認（または待機）してから新規 Web Manager プロセスが起動されること。
  - [x] AC-3: すでに Web Manager が停止している状態から実行した場合でもエラーで停止せず、正常に新規 Web Manager が起動されること。
  - [x] AC-4: 再起動完了後、自動的にブラウザで `http://localhost:8899` が開かれる（またはアクセス可能な状態となる）こと。
  - [x] AC-5: 管理対象の他サービス（ComfyUI, Backend, Frontend）の稼働状態を誤って強制終了せず、Web Manager のみを選択的に再起動できること。
- **Design doc**: docs/design/REQ-243.md
