### REQ-228: 画像プレビュー表示時のReactフックルール違反によるクラッシュ不具合の修正

- **Type**: defect
- **Status**: done (2026-09-08)
- **Current step**: none
- **Priority**: P1
- **Surface**: 16:9をはじめとするアスペクト比で生成した画像をプレビューしようとしたらエラー画面（システムエラーが発生しました）になった
- **Root Cause**: `HistoryModalPreview.tsx` において、条件付き早期リターン（`if (!isOpen || images.length === 0) return null`）の直後に `useCallback` フック（`getParamValue`）が配置されている。これによりモーダルが閉じた状態（`isOpen === false`）と開いた状態（`isOpen === true`）でレンダリング時に実行されるフック数が変動し、Reactの「フックのルール（Rules of Hooks）」違反（`Rendered more hooks than during the previous render.`）が発生して画面全体がクラッシュする。
- **Requirement**: `HistoryModalPreview` 内のすべてのReactフック（`useCallback` 等）が早期リターン（`return null`）よりも前に呼び出されるよう配置を是正し、任意の画像（アスペクト比問わず）のプレビューを開いた際にクラッシュせず正常にモーダルが表示されること。
- **Acceptance criteria**:
  - [x] AC-1: 生成画面および履歴画面において、任意の画像をクリックした際に画像プレビューモーダル（`HistoryModalPreview`）がクラッシュせず正常に開くこと。
  - [x] AC-2: `HistoryModalPreview` コンポーネント内のフック呼び出し順序がRules of Hooksに準拠し、モーダルの開閉時にフック不整合エラー（`Rendered more hooks than during the previous render.`）が発生しないこと。
  - [x] AC-3: プレビューモーダル内の既存機能（画像の拡大表示、前後送り、ダウンロード、メタデータ情報閲覧・編集等）が正常に利用可能であること。
