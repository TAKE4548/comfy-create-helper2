### REQ-193: 翻訳設定（プロバイダー・APIキー・URL）の保存不具合修正

- **Status**: done
- **Description**: 設定画面の翻訳設定（TranslationSettingsSection）において、翻訳プロバイダーやAPIキー、API URLを変更して保存ボタンを押下しても設定が保存されない問題を修正する。フロントエンド側での `llmPromptsApi.update` 呼び出しペイロード形式（`{ content: string }`）への修正と、バックエンド側での未登録キーに対するアップサート対応およびシードデータ追加を行う。

#### Acceptance Criteria (AC)
- [x] AC-1: `TranslationSettingsSection.tsx` の `saveSettingsMutation` において、`llmPromptsApi.update` に `{ content: ... }` のオブジェクト形式でペイロードが渡され、422エラーが発生しないこと。
- [x] AC-2: `backend/app/routers/llm_prompts.py` の `update_llm_prompt`（または `PUT /api/llm-prompts/{key}`）において、キーが存在しない場合に自動生成（アップサート）されること。
- [x] AC-3: `seed_data.py` に `translation_provider` / `translation_api_key` / `translation_api_url` がシードとして登録されること。
- [x] AC-4: フロントエンドおよびバックエンドの関連単体テストが追加・修正され、すべてのテストが PASS すること。
