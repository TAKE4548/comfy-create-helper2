### REQ-151: タグチップのサブメニュー展開による強度調整および有効・無効切替機能

- **Type**: enhancement
- **Status**: ready
- **Current step**: Requirement Analysis Complete
- **Priority**: P2
- **Design doc**: docs/design/REQ-151.md
- **Surface**: タグチップ状態での強度設定をできるようにしたい。現行はタグチップ自体のクリック・タップで有効・無効切替だが、これをサブメニューを開くようにして、強度の調整と有効・無効のトグル操作を両方できるようにしたい。これによってトグル操作は操作ステップが増えることになるが、トグル操作よりも強度調整の方が頻度が高いため、両方の操作ステップを揃えて強度調整もできるようになる方が有用。強度調整のUIは数値の直接入力に加えて、0.1,1.0ずつの増減用ボタンが欲しい。なお、強度が未設定のタグチップに対して操作した際は、1.0と見なしてUI反映する。
- **Root Cause**:
  - **Interaction**: タグチップのクリック/タップ操作が直接の有効/無効トグルに専有されており、頻繁に行われる強度（Weight）調整がタグチップ上で直接行えない。
  - **Information Design**: 強度未設定（暗黙の等倍/デフォルト）のタグチップにおける基準値（1.0）の明示と調整インターフェースの欠如。
- **Requirement**:
  1. タグチップをクリックまたはタップした際に、サブメニュー（ポップオーバー/ポップアップメニュー）を展開する。
  2. サブメニュー内に、タグチップの「有効/無効の切り替えトグル」および「強度（Weight）の調整UI」を提供する。
  3. 強度調整UIには、数値の直接入力欄に加え、`+0.1` / `-0.1` および `+1.0` / `-1.0` のステップ増減ボタンを備える。
  4. 強度が未設定（または明示的な強度値を持たないデフォルト状態）のタグチップに対して強度操作を行った場合、基準強度を `1.0` として扱い、UIおよびプロンプトデータに反映する。

#### Acceptance Criteria (AC)

##### 1. サブメニュー展開と基本操作
- [ ] AC-1-1: タグチップをクリック/タップした際、直接のトグル切替ではなくサブメニュー（ポップオーバー等）が表示されること。
- [ ] AC-1-2: サブメニュー内にタグの「有効/無効（Enabled/Disabled）」を切り替えるトグル操作が存在し、現在の有効状態が正しく表示・変更できること。
- [ ] AC-1-3: サブメニュー外のクリックやEscキー押下等でサブメニューが閉じられること。

##### 2. 強度調整インターフェース
- [ ] AC-2-1: サブメニュー内にタグの強度（Weight）の数値を直接入力・編集できる入力欄が存在すること。
- [ ] AC-2-2: 強度調整用として、`+0.1` / `-0.1` の増減ボタンが提供され、押下により強度が0.1刻みで増減すること。
- [ ] AC-2-3: 強度調整用として、`+1.0` / `-1.0` の増減ボタンが提供され、押下により強度が1.0刻みで増減すること。
- [ ] AC-2-4: 強度を変更した際、プロンプトテキストおよびタグチップの表示にリアルタイムまたはサブメニュー確定時に正しく反映されること。

##### 3. 強度未設定タグチップの初期値ハンドリング
- [ ] AC-3-1: 強度表記のないデフォルト状態（未設定）のタグチップに対してサブメニューを開いた際、強度値として `1.0` が初期表示されること。
- [ ] AC-3-2: 未設定状態から強度増減ボタン（例: `+0.1`）を押下した場合、`1.0 + 0.1 = 1.1` として計算・反映されること。
