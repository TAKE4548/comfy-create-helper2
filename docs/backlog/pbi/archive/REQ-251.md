### REQ-251: セクションタグコピー履歴サブメニューのスクロール表示化と項目潰れ解消

- **Type**: defect
- **Status**: done (2026-09-12)
- **Current step**: Step 4 (Verification Complete)
- **Priority**: P2
- **Surface**:
  - セクションのタグコピーをペーストするサブメニューが、コピー履歴が多くなると潰れて見えなくなる。履歴の数が増えても縦幅に押し込むのではなく、スクロール可能にして各履歴が視認できるようにしたい。
- **Root Cause**:
  - `PromptSectionClipboardMenu.tsx` の履歴一覧表示コンテナにおいて `flex flex-col` が指定されているが、子要素の各ボタン要素に `shrink-0`（`flex-shrink: 0`）が指定されていない。そのため、履歴件数が増加して合計高さが親コンテナの `max-h-40`（160px）を超過した際に、Flexboxの縮小アルゴリズム（`flex-shrink: 1`）によって各ボタンの縦幅が均等に押し潰され、スクロールではなく要素の圧縮（`truncate` による文字の欠落）が発生する。
- **Requirement**:
  - コピー履歴の件数が増加しても、各履歴アイテムの縦幅・パディングが正常に維持されること。
  - 履歴コンテナ（`max-h-40`）の表示領域を超過した場合は縦スクロール可能となり、各履歴のテキストが潰れずに視認およびクリック選択できること。
- **Acceptance criteria**:
  - [x] AC-1: コピー履歴が複数件（最大件数含む）存在する場合でも、各履歴項目の縦幅が圧縮されず、テキストが正常に視認できること。
  - [x] AC-2: コピー履歴の合計高さがコンテナの最大高さを超える場合、コンテナ内で縦スクロールが可能であること。
  - [x] AC-3: スクロールされた状態でも各履歴項目をクリックしてプロンプト入力欄への貼り付けが正常に動作すること。
  - [x] AC-4: `PromptSectionClipboardMenu.test.tsx` に複数履歴表示時のスタイル・表示検証テストが追加され、既存のテストを含めすべてパスすること。
