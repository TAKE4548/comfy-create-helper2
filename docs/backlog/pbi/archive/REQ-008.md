### REQ-008: WSL環境におけるComfyUI WebSocket接続および画像取得エラーの修正

- **Type**: defect
- **Status**: ready
- **Current step**: none
- **Priority**: P1
- **Surface**: 生成を実行すると、ComfyUI側で動きはするがtool側で進捗が確認できず、生成された画像も表示されない
- **Root Cause**: WebSocketの接続先ホスト（localhostなど）がフロントエンド側で固定されている、もしくは、WSL環境のようにComfyUIが動作しているIPアドレスとフロントエンドが動いているホストのIPアドレスが異なる場合に、設定された接続先IP/ホスト名がWebSocket接続および画像リクエスト（API）に正しく反映されていない。これにより、useComfyWebSocket等において接続が失敗し、進捗管理および生成画像表示が行えない。
- **Requirement**: ComfyUIの接続先ホスト名/IPアドレスおよびポートが設定可能であり、WebSocket接続および画像取得APIの接続において設定されたホスト情報が正しく反映・使用されること。
- **Acceptance criteria**:
  - - [ ] AC-1: ComfyUIの接続先ホスト名/IPアドレス（例: WSLのIPアドレス）を設定可能（環境変数、設定画面、または設定ファイルのいずれか）であること。
  - - [ ] AC-2: 設定されたホスト/IPおよびポートを用いてWebSocket接続（ws://{host}:{port}/ws）が確立され、生成の進捗ステータスが「Processing」から正常に進捗表示に更新されること。
  - - [ ] AC-3: 生成完了後、設定されたホスト/IPおよびポートを用いて画像リソースURLが解決され、生成された画像がUI上に正常に表示されること。
- **Design doc**: none
