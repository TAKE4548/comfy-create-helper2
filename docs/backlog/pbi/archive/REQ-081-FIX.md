### REQ-081-FIX: ワークフローアップロード時のスマートノードマッピング（一意判定）の漏れ修正

- **Type**: defect
- **Status**: done (2026-08-26)
- **Current step**: none
- **Priority**: P1
- **Surface**: /triage 081で実施したマッピング時にノードタイプで複数候補があっても、タイトルまで含めてみると一意に決められるやつが出来てないように見える
- **Root Cause**: バックエンドの `workflow_scanner.py` における一意判定（競合時）のフォールバック先が、タイトル一致するノード（`perfect_matches`）の中からではなく、無関係なノード（`candidates[0]`）が初期値に選ばれてしまっていること。
- **Requirement**: クラスタイプとタイトルが両方一致するノードが複数存在する場合（競合時）に、それらの一致したノードの中（`perfect_matches[0]`）から初期値が選択されるようにする。
- **Acceptance criteria**:
  - [ ] AC-1: タイトルまで一致するノードが2つ以上存在し（競合）、かつタイトルが一致しない同一タイプのノードが存在する場合に、タイトルが一致しているノードの中の最初のノードが初期値として自動選択されること。
  - [ ] AC-2: タイトルまで一致するノードが0件の場合のみ、従来の全候補の先頭ノードにフォールバックすること。
- **Design doc**: docs/design/REQ-081-FIX.md
