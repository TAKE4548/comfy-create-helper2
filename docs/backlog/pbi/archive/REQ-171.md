### REQ-171: 縦書きセリフにおけるパス軌道レイアウトの縦方向追従および接線回転補正

- **Type**: bugfix
- **Status**: ready
- **Current step**: none
- **Priority**: P2
- **Surface**: REQ-168のセリフ修飾ができるようになったが、縦書きの時にパスの経路を設定すると横書きのパスになっているように見える。
- **Root Cause**: `frontend/src/utils/speechBubbleRenderer.ts` において、パスプリセット（直線・円弧・S字波・階段）のデフォルト制御点が横書き基準（X軸: 0.1 → 0.9）で固定されており、`bubble.orientation === 'vertical'` の場合に上から下（Y軸: 0.1 → 0.9）への進行軌道への切り替えや、パス接線回転角（`tangentAngle`）の縦書き補正が行われていない。
- **Requirement**: セリフが縦書き（`orientation === 'vertical'`）の場合、パスプリセット（直線・円弧・S字波・階段）のデフォルト軌道が上から下（Y方向進行）に自動適応され、パス追従回転有効時にも縦書きテキストとしての進行方向および文字姿勢と自然に整合するようレンダリング処理を修正する。
- **Design doc**: none

#### Acceptance Criteria (AC)

##### 1. 縦書き時のパスプリセットデフォルト軌道 (Vertical Path Presets)
- [ ] AC-1-1: 縦書き（`orientation === 'vertical'`）セリフにおいて「直線（line）」プリセットを選択した際、文字が上から下（Y軸: 0.1 → 0.9）へ直線状に配置されること。
- [ ] AC-1-2: 縦書きセリフにおいて「円弧（arc）」プリセットを選択した際、縦方向に弓なりに曲がる軌道（上から下へ進行しつつ左右に湾曲）に沿って文字が配置されること。
- [ ] AC-1-3: 縦書きセリフにおいて「S字波（wave）」プリセットを選択した際、縦方向に波打つ軌道（上から下へ進行しつつ左右にS字振動）に沿って文字が配置されること。
- [ ] AC-1-4: 縦書きセリフにおいて「階段（stepped）」プリセットを選択した際、縦方向に階段状にステップしながら上から下へ文字が配置されること。

##### 2. 横書き時のパスプリセット互換性維持 (Horizontal Compatibility)
- [ ] AC-2-1: 横書き（`orientation === 'horizontal'`）セリフにおいては、既存通り左から右（X軸: 0.1 → 0.9）の水平進行軌道としてレンダリングされ、後方互換性が維持されること。

##### 3. パス接線回転追従の整合性 (Path Follow Rotation)
- [ ] AC-3-1: 縦書きセリフで「パス接線方向に文字を回転追従させる（`pathFollowRotation`）」を有効にした際、上から下への進行ベクトルに応じた自然な文字の傾き（縦書き基準角からの接線角オフセット）が適用されること。

##### 4. レンダラー単体テストの追加・更新
- [ ] AC-4-1: `speechBubbleRenderer.test.ts` に縦書き設定時の各パスプリセット（line, arc, wave, stepped）および接線回転の計算結果を検証するテストケースが追加され、すべてパスすること。
