### REQ-178: モバイル表示時のプロンプトエリアにおけるタグチップモードの有効化

- **Type**: enhancement
- **Status**: ready
- **Current step**: none
- **Priority**: P2
- **Surface**: モバイルでプロンプトエリアはテキストモード限定になっているが、タグチップモードを使えるようにしたい。元々は強度や部分変更をテキストモードでしか出来なかった為限定していたが、タグチップにサブメニューを導入したため、スマホでもチップモードの方が編集しやすくなったはず。
- **Root Cause (Interaction)**: 過去の実装において強度変更や部分編集がテキストモード依存であったため、モバイル画面（画面幅制限時など）ではプロンプトエリアがテキストモード固定に制限されていた。タグチップへのサブメニュー導入等によりモバイルでもチップ単体での編集操作が可能になったため、モバイル環境でのモード制限が不要となり、利便性を損なう要因となっている。
- **Requirement**: モバイル表示（スマートフォン・狭小画面等）においてもプロンプトエリアでのタグチップモード利用制限を解除し、タグチップモードとテキストモードを自由に切り替えて使用できるようにする。モバイル表示時のタグチップモードにおいてもサブメニュー起動やタグ編集・削除・強度変更等の操作が破綻なく動作することを保証する。

#### Acceptance Criteria (AC)

##### 1. モード切り替えの有効化
- [x] AC-1-1: モバイル表示時（レスポンシブ画面幅、またはモバイルデバイス環境）において、プロンプトエリアのタグチップモード / テキストモード切り替えUIが利用可能であり、タグチップモードへの切り替えが行えること。
- [x] AC-1-2: モバイル表示でページ読み込み・リロード・プロンプト変更が行われた際にも、タグチップモードがテキストモードへ強制的に戻されないこと（ユーザー設定や選択状態を維持）。

##### 2. モバイルタグチップ操作とサブメニューの動作
- [x] AC-2-1: モバイル表示時のタグチップモードにおいて、各タグチップのタップおよびサブメニュー表示が正しく動作し、強度変更・部分編集・タグ削除等の機能が実行できること。
- [x] AC-2-2: モバイル幅のレイアウトにおいて、タグチップ一覧およびサブメニューが画面外にはみ出さず、適切にレスポンシブ表示されること。

##### 3. プロンプト同期と状態維持
- [x] AC-3-1: モバイル表示下でタグチップモードにて追加・編集・削除したタグが、テキストモードおよび実際のプロンプト生成・送信処理に正しく同期・反映されること。
