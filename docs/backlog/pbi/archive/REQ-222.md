### REQ-222: TagChipEditorの外部プロンプト文字列同期不全およびプリセット切替時の消失バグ解消

- **Type**: defect
- **Status**: done (2026-09-05)
- **Current step**: none
- **Priority**: P1
- **Surface**:
  - アクティブなプリセットの入力欄のプロンプトが消える（空になる）。
  - 別プリセットからセクションのコピペ機能（PromptSectionClipboardMenu）を使って貼り付けを行っても、入力欄にペースト内容が反映されない。
- **Root Cause**:
  - `TagChipEditor`（`frontend/src/components/TagChipEditor/index.tsx`）において、`chips` prop が渡されている場合（`chipsProp !== undefined`）、`value`（文字列プロンプト）の変更検知・同期 Effect が完全にスキップされる設計となっていた。そのため、セクションコピペ機能等で親の `paramValues`（`value`）が外部から更新されてもチップが再パースされず、直後の通知 Effect により未更新の古いチップ文字列で親の `onChange` が上書き発火されてペーストがキャンセルされていた。
  - `DesktopLayout.tsx` および `MobileLayout.tsx` の `TagChipEditor` の `key` が `role` のみ（例: `key={m.role!}`）となっており、`activeSetId`（プリセット・セットID）の変化でコンポーネントが再マウントされないため、プリセット切り替え時に `chipsProp` と新プリセットの `paramValues` の同期が崩れ、空チップ配列で上書きされてプロンプトが消失していた。
- **Requirement**:
  - `TagChipEditor` が外部からの文字列（`value`）変更（コピペ機能や翻訳適用、クリア操作など）と `chips` 配列変更の双方を整合性を保ちながら正しく反映すること。
  - プリセットやセットを切り替えた際、選択したプリセットのプロンプトが入力欄に正確に表示され、消失しないこと。
- **Acceptance criteria**:
  - [x] AC-1: セクションのコピペ機能（`PromptSectionClipboardMenu`）から「クリップボードから貼り付け」または履歴選択を行った際、プロンプト入力欄（TagChipEditor）に貼り付けテキストが即時反映されること。
  - [x] AC-2: プリセットを切り替えた際、各プリセットに保存されているプロンプト文字列が正しくタグチップとして入力欄に表示され、消失や空欄化が起きないこと。
  - [x] AC-3: `TagChipEditor` において、`chips` prop が指定されている状態でも、親コンポーネントから渡された `value` 文字列が変更された場合（`chipsToString(state) !== value`）に、正しく新しいタグチップへと再パース・更新されること。
  - [x] AC-4: 関連する単体テスト（`TagChipEditor.test.tsx`、`GeneratePage.test.tsx`、`MobileLayout.test.tsx` 等）がすべてパスすること。
