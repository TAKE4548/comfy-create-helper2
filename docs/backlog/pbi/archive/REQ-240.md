### REQ-240: 別端末で生成した画像の履歴リアルタイム同期

- **Type**: enhancement
- **Status**: done (2026-09-12)
- **Current step**: none
- **Priority**: P2
- **Surface**:
  - 現行は別端末で生成した画像が履歴に表示されるには、リロードが必要だが、リロードを挟まずシームレスに同期したい
- **Root Cause**:
  - (UX分類: Interaction / Information Design) 別端末等で完了した生成イベントや新規履歴データがリアルタイムにクライアント側へ同期されず、手動でページリロードを行わないと最新の生成結果が一覧に反映されない
- **Requirement**:
  - 別端末で画像生成が完了した際、ユーザーが手動で画面リロードを行わなくても、履歴一覧に新規生成画像が即座に自動挿入され、複数端末並行時でも順序整合性および現在のUI操作コンテキスト（スクロール・詳細プレビュー・編集中プロンプト）が安全に保持されること
- **Acceptance criteria**:
  - [x] AC-1: 別端末で画像生成が完了した際、画面を手動リロードすることなく、履歴一覧の先頭に新規生成画像が即座に自動挿入・表示されること。
  - [x] AC-2: 複数端末から並行してジョブが投入・生成された場合でも、生成完了順（時系列）の順序が正しく保たれて履歴一覧に表示されること。
  - [x] AC-3: 履歴一覧をスクロールして過去画像を閲覧中、あるいは詳細プレビュー等を開いている最中に新規画像が自動挿入されても、スクロール位置の不意なジャンプやプレビュー状態の破棄・リセットが発生しないこと。
  - [x] AC-4: 履歴のリアルタイム同期によって、現在入力・編集中のプロンプトやパラメータ等のクライアント側作業状態が破棄されたり過去の状態へ巻き戻ったりしないこと。
