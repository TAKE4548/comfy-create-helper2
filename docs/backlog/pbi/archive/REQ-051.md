### REQ-051: タグセット管理におけるカテゴリ追加・削除機能

- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: none
- **Priority**: P2
- **Surface**: タグセットのカテゴリを動的に追加・削除できない
- **Root Cause**: バックエンドにはタグセットカテゴリの CRUD エンドポイントが存在するが、フロントエンドの TagsPage にはそれらを表示・編集・削除するUIが不足している。
- **Requirement**: タグセット画面（TagsPage）にカテゴリ管理用のUIを配置し、カテゴリの新規登録および削除を行えるモーダルダイアログを実装する。
- **Acceptance criteria**:
  - [x] AC-1: タグセット画面に「Manage Categories ⚙」ボタンが表示され、クリックすると管理モーダルが開くこと。
  - [x] AC-2: カテゴリ管理モーダル内で、登録済みの全タグセットカテゴリ一覧が表示されること。
  - [x] AC-3: モーダル内で、新しいカテゴリ名を入力して登録した際、バックエンドAPI（`POST /api/tagset-categories`）が呼び出され、即座に一覧に反映されること。
  - [x] AC-4: 各カテゴリの横に削除ボタンが表示され、クリックするとバックエンドAPI（`DELETE /api/tagset-categories/{id}`）経由で削除されること。
  - [x] AC-5: カテゴリ削除時、それに属していた既存のタグセットのカテゴリが「未設定（NULL）」に自動的に変更され、画面上で正常に表示が更新されること。
- **Design doc**: docs/specs/SPEC_TAGS.md
