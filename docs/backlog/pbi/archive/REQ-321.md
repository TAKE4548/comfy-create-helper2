### REQ-321: Fix Dataset Studio Node Remapping Save Failure and Incomplete State Update

- **Status**: done (2026-10-07)
- **Type**: Bug (Type A)
- **Reference**: docs/incident_report.md
- **Description**:
  LoRA Dataset Studio (/dataset-studio) の NodeRemapModal において、Positive または Negative のプロンプト注入先ノードを変更して「マッピングを保存」を実行しても、マッピングがバックエンドに保存されない、または画面上のバッジおよびワークフロー状態に反映されない不具合を改修します。

#### Acceptance Criteria (AC)
- [ ] AC-1: NodeRemapModal において、mappingMastersApi.list() から Main_Positive_Prompt および Negative_Prompt の master_id を正しく特定し、既存マッピングに対象ロールが存在しない場合でも新規マッピングとして workflowsApi.update のためのペイロードに含めて保存できること。
- [ ] AC-2: workflowsApi.update の保存完了後、最新のワークフロー情報（workflowsApi.get または完全な WorkflowRead）を取得して onSaved に渡し、親コンポーネント（MatrixGenerationStep）の currentWorkflow およびノードバッジ・プロンプト注入処理に即時反映されること。
- [ ] AC-3: MatrixGenerationStep.test.tsx または NodeRemapModal.test.tsx において、マッピングが存在しない初期状態からのノード再割当・保存フロー、および最新ワークフロー再取得のテストケースが追加されパスすること。
