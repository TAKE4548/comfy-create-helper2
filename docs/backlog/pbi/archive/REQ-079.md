### REQ-079: モバイルモードのタブ・プロファイル同期およびコピー作成対応

- **Status**: done (2026-08-30)
- **Type**: enhancement
- **Priority**: P2
- **Surface**: モバイルモードの時、生成画面でのタブ切り替えやプロファイル切り替えが使えないのを使えるようにしたい。また、端末・セッションを跨いでもワークフローに対するタブを同期できるようにしたい。実質プロファイルとタブは1:1で作ることが多いので、プロファイルがそのままタブになるだけでいい。任意のプロファイルから編集することはあるので、タブの追加時にベースとするプロファイルを選んでコピー生成できるようにして、現行の使い勝手を維持する。
- **Root Cause**: モバイルモードで生成画面のタブ切り替えおよびプロファイル選択UIが制限されており使用できない。また、タブとプロファイルの概念が別で管理されているためセッションを跨いだ同期が困難であり、コピー生成の仕組みもない。
- **Requirement**:
  1. モバイル画面サイズにおいて、生成画面のタブ切り替えおよびプロファイル切り替えが機能するUIを実装する。
  2. プロファイルとタブの概念を1:1に統合し、タブ＝プロファイルとして動作させる。
  3. 端末・セッションを跨いでタブ（プロファイル）が同期されるよう、サーバー側での永続化データを利用・連携する。
  4. タブ追加時、ベースとするプロファイル（既存プロファイル、またはワークフローのデフォルト）を選択してコピー生成できるUI/機能を提供する。

#### Acceptance Criteria (AC)
- [ ] AC-1: モバイル表示時、生成画面にてタブ（プロファイル）の切り替え・選択UIが表示され、操作可能であること。
- [ ] AC-2: タブを選択した際、対応するプロファイルの設定情報が正しく適用・表示されること。
- [ ] AC-3: タブ（プロファイル）情報がサーバーで同期・永続化され、異なる端末・セッションからアクセスしても同じタブ状態が維持されること。
- [ ] AC-4: タブ追加時に「コピー元プロファイル（またはワークフローデフォルト）」を選択するダイアログ等のUIが表示され、選択したベース設定を引き継いだ新規タブが生成されること。
