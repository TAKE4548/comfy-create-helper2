### REQ-150: プロファイル新規作成時のコピー元選択に基づく名称自動補完（サフィックス連番付与）

- **Type**: enhancement
- **Status**: done (2026-08-26)
- **Current step**: Requirement Analysis Complete
- **Priority**: P2
- **Design doc**: docs/design/REQ-150.md
- **Surface**: プロファイルの新規生成時、コピー元を指定した場合に、新しいプロファイルの名前をコピー元の名前+数値で自動補完するようにしたい。同一シーンの差分生成用に既存プロファイルをコピーするケースが多く、サフィックスの数値だけで別名にすることで、同一の名前を再入力する手間を減らしたい。
- **Root Cause**:
  - **Interaction / Usability Gap**: プロファイル新規作成時にコピー元を選択しても、名称入力欄はデフォルト値（「set N」等）または空のままであり、コピー元の名称を引き継いだ連番付与が行われないため、ユーザーが毎回ベース名を手動で再入力・編集する必要がある。
- **Requirement**:
  1. プロファイル新規作成UIにおいて、コピー元プロファイルが選択された際、コピー元プロファイルのベース名（末尾の数値サフィックスを除外した名称）を特定する。
  2. 既存の全プロファイルの中から同一ベース名を持つプロファイルを走査し、付与されている数値サフィックスの最大値を特定した上で、`最大値 + 1` の数値を付与した名称を新しいプロファイル名入力欄に自動補完（プレフィル）する。
  3. 自動補完された名称はユーザーが自由に編集可能とし、プロファイル作成実行時に名前入力欄に入力されている文字列を正式なプロファイル名として保存する。

#### Acceptance Criteria (AC)

##### 1. コピー元選択時の名称自動補完ロジック
- [x] AC-1-1: プロファイル新規作成モーダル/UIでコピー元プロファイルを選択した際、プロファイル名入力欄に「コピー元ベース名 + 連番数値」が自動的に入力されること。
- [x] AC-1-2: コピー元プロファイル名にすでに末尾数値が付与されている場合（例: `SceneA 1`, `SceneA_2` 等）、その数値部分を除いたベース名をもとに同名グループ内の最大数値を探索し、`最大値 + 1` のサフィックスを付与すること。
- [x] AC-1-3: コピー元プロファイル名に末尾数値が存在しない場合（例: `SceneA`）、既存に同名派生（`SceneA 1` 等）が存在すればその最大値+1、存在しなければ適切な初期連番（例: 2 または 1）を付与した名称が補完されること。

##### 2. ユーザー編集の自由度と確定
- [x] AC-2-1: 自動補完された後も、ユーザーがプロファイル名入力欄の文字列を自由に編集・変更できること。
- [x] AC-2-2: プロファイル作成ボタン押下時、名前入力欄に現在入力されているテキストがそのまま新しいプロファイル名として登録されること。
- [x] AC-2-3: コピー元を未選択（新規白紙作成）に戻した場合は、従来のデフォルト命名規則（`set N` 等）にフォールバックすること。

##### 3. 既存機能との整合性
- [x] AC-3-1: コピー元プロファイルの設定・パラメータ複製処理がこれまで通り正常に動作すること。
- [x] AC-3-2: プロファイル名の重複バリデーションや空文字バリデーション等の既存チェックが正常に機能すること。
