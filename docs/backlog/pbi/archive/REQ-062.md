### REQ-062: LoRA・タグセット管理画面の改修および並び順永続化、カテゴリ管理機能の追加

- **Status**: done (2026-08-30)
- **Description**: LoRA管理およびタグセット管理の画面を改修し、カードデザインの統一、ドラッグ＆ドロップによる表示順の並び替えと永続化、カテゴリの明確な分離、およびカテゴリ自体のCRUD/インライン追加機能を実現する。

#### Acceptance Criteria (AC)
- [ ] AC-1: タグセット管理画面のカードデザインを、LoRA管理画面のデザイン（上部にアスペクト比1:1の画像カルーセル、カルーセル内にホバー表示される編集・削除ボタン、下部に詳細情報）と統一する。
- [ ] AC-2: LoRA管理およびタグセット管理の両画面において、カードをドラッグ＆ドロップ（D&D）することで任意の順番に並び替えることができる。
- [ ] AC-3: 並び替えた結果（順序情報）がバックエンドのデータベースに永続化され、ページをリロードしても並び順が維持される。
- [ ] AC-4: LoRAカテゴリとタグセットカテゴリが、管理上およびUI上で完全に分離されていることを保証する（混同しないようにする）。
- [ ] AC-5: カテゴリ自体のCRUD（作成・読み取り・更新・削除）を行うことができる管理UIを提供する。
- [ ] AC-6: LoRAおよびタグセットの新規登録/編集モーダルにおいて、カテゴリ選択欄から直接新しいカテゴリを追加（インライン追加）し、即座に選択状態にできる。
- [ ] AC-7: カテゴリを削除した際、そのカテゴリに紐づいていたカード（LoRA / タグセット）のカテゴリが「未設定（null）」に安全に更新される。
