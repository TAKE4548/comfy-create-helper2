### REQ-143: セリフ編集におけるメタデータ保存・再編集およびベース画像差し替え・新規保存機能

- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Current step**: none
- **Priority**: P2
- **Surface**: セリフ編集済み画像のベース画像を入れ替えて、再編集・新規保存ができるようにしたい。ベース画像の差分作成などする場合があり、再利用しつつ吹き出し位置や一部セリフのみの再編集といったことがしたい。また、現状セリフ付与保存画像は単一の合成画像になっており再編集ができないため、セリフメタ情報をリンクして保存・再編集できるようにしたい。
- **Root Cause**: **Interaction Design (Workflow Friction / Missing Capability)**: セリフ保存時に吹き出しのメタ情報やクリーンな元ベース画像への参照が保存されておらず単一のラスタライズ画像となっていたため、保存後の再編集ができず、表情や構図などの生成差分画像に同じ吹き出し構成を流用する手段も欠落していた。
- **Requirement**: セリフ合成画像の保存時に、配置された吹き出し情報（位置、サイズ、テキスト、フォント・スタイル）および元ベース画像への参照をスナップショットのメタデータ（`params`）として保存する。セリフ保存済み画像から再度エディタを開いた際には、クリーンな元ベース画像と吹き出しメタ情報を復元して再編集可能とし、さらにエディタ内から生成履歴の別スナップショットへベース画像を差し替えて新規保存できるようにする。
- **Design doc**: [docs/design/REQ-143.md](docs/design/REQ-143.md)

#### Acceptance Criteria (AC)

##### 1. セリフメタ情報の保存と再編集復元
- [ ] AC-1-1: セリフ編集完了時の保存において、合成画像とともに吹き出しメタデータ（`speech_bubbles`）およびベース画像情報（`base_snapshot_id`, `base_image_path`）がスナップショットパラメータに保存されること。
- [ ] AC-1-2: セリフメタ情報を持つスナップショットに対してセリフ編集モーダルを開いた際、焼き付けられた合成画像ではなく元のクリーンなベース画像が読み込まれ、保存されていた吹き出し（位置・テキスト・スタイル等）が編集可能な状態で正しく復元されること。

##### 2. 生成履歴からのベース画像差し替え
- [ ] AC-2-1: セリフ編集画面において、配置済みの吹き出し（位置、サイズ、テキスト、装飾設定など）を保持したまま、生成履歴（スナップショット一覧）から別のスナップショットを選択してベース画像を差し替えられること。
- [ ] AC-2-2: ベース画像を差し替えた際、既存の吹き出しレイアウトが破綻することなくプレビューキャンバス上に維持・表示され、位置の微調整やテキスト変更などの再編集が継続して行えること。

##### 3. 新規保存（差分保存）
- [ ] AC-3-1: ベース画像を差し替えて編集した画像を、元のセリフ編集済み画像とは別の新規スナップショットとして保存できること。
- [ ] AC-3-2: 新規保存後も元の画像のデータおよび新規保存された画像データがそれぞれ独立して保持され、相互に再編集可能であること。
