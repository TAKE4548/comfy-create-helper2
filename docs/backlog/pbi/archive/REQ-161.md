# REQ-161: モバイル端末におけるGenerate Batchキュー投入失敗の修正

- **Type**: defect
- **Status**: done (2026-08-26)
- **Current step**: Step 5（実装計画承認済み）
- **Priority**: P1
- **Surface**: PCからはキュー投入できるが、モバイル端末から実行すると「[Set X] のキュー投入に失敗しました」エラーが表示され失敗する。リロードしても改善しない。かなり待てば成功する。
- **Root Cause**: ① モバイルOSはバックグラウンドタブをキルするためReact Queryのin-memoryキャッシュが毎回消え、`workflow`データのAPIフェッチ完了前にWebSocket接続（`isConnected=true`）のみで判定してボタンが活性化してしまう。② REQ-154で追加された`visibilitychange`→`fetchHistory`（LAN通信）が初回ロード時の通信負荷を増加させ、`workflow`フェッチ完了までの待ち時間が延伸した。
- **Requirement**: モバイル端末から待ち時間なしにGenerate Batchボタンを押してもキュー投入に成功すること。
- **Acceptance criteria**:
  - AC-1: `workflow`データのロードが完了していない間、Generate Batchボタンが非活性（disabled）状態であること（MobileLayout・DesktopLayout共通）
  - AC-2: モバイル端末で初回アクセス後、ページをリロードし直ちにGenerate Batchボタンを押してもキュー投入に成功すること（localStorageキャッシュから即復元）
  - AC-3: PCブラウザでのGenerate Batch動作が従来通り正常に動作すること（退行なし）
  - AC-4: localStorageに永続化されたキャッシュ（キー:`prompt-surgeon-rq-cache`）のサイズが5MB未満であること
- **Design doc**: `docs/design/REQ-161-test-plan.md`
