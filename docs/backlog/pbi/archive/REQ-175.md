### REQ-175: セリフプリセット上書き時のモーダルダイアログ化（プリセット名編集・テキスト包含切替）

- **Type**: enhancement
- **Status**: done (2026-08-30)
- **Priority**: P1
- **Surface**: プリセットの上書き保存時、現在はブラウザ標準の `window.confirm` による簡易確認のみとなっており、「テキストを含めるかどうか」のオプション選択や「プリセット名の変更」ができない。上書き時にも新規保存と同様にモーダルダイアログを表示し、プリセット名の編集やテキスト包含オプションの再選択・切替を行えるようにしたい。
- **Root Cause**:
  1. **上書き時UIの制約**: `handleOverwritePreset` が `window.confirm` で確認するのみで、上書き時のペイロード生成において既存の `preset.text` の有無に基づき自動判定（`preset.text ? bubble.text : undefined`）していたため、上書きのタイミングで「新しくテキストを含める」「既存プリセットからテキストを除去してスタイル専用にする」「名前を変更する」といったユーザーの意図を反映するUIコントロールが存在しない。
- **Requirement**:
  1. プリセット一覧の「💾（上書き保存）」ボタンをクリックした際、`window.confirm` の代わりに専用の「プリセット上書き・編集モーダル（ダイアログ）」を表示する。
  2. モーダル内で、プリセット名（`name`）の変更・編集ができるようにする。
  3. モーダル内で、「テキストを含める」チェックボックスを提供し、現在の吹き出しテキスト（プレビュー付き）をプリセットに保存するか、スタイル専用（テキストなし）にするかを自由に選択・変更できるようにする。
  4. モーダル内の「上書き保存」を実行した際、変更されたプリセット名、現在の装飾スタイル、および選択されたテキスト（または `null`）でバックエンド API を呼び出し、即座に一覧へ反映する。
- **Acceptance criteria**:
  - AC-1: プリセットの「💾（上書き）」アイコンをクリックした際、`window.confirm` ではなくプリセット上書きモーダルが表示されること。
  - AC-2: 上書きモーダル内でプリセット名を編集でき、変更した名前で上書き保存できること。
  - AC-3: 上書きモーダル内で「テキストを含める」チェックボックスをオン/オフでき、オンの場合は現在の吹き出しテキストが保存され、オフの場合は `text: null` としてスタイル専用プリセットに更新できること。
  - AC-4: テキストを含まない状態で作成された既存プリセットであっても、上書きモーダルで「テキストを含める」にチェックを入れて保存することで、テキスト付きプリセットへ昇格・更新できること。
  - AC-5: モーダルをキャンセルした場合、プリセットは更新されず元の状態が維持されること。
  - AC-6: フロントエンドの単体テスト（`SpeechBubbleControls.test.tsx`）において、上書きモーダルの表示、名前変更、テキスト包含切替の各フローが網羅され 100% PASS すること。
