### REQ-330: Dataset Studio マトリクス生成投入における ComfyUI 直接 fetch を comfyApi.queuePrompt へ変更

- **Type**: bug
- **Status**: done (2026-10-08)
- **Priority**: P1
- **Surface**: frontend/src/pages/DatasetStudioPage/components/MatrixGenerationStep.tsx
- **Incident Report**: docs/incident_report.md
- **5 Whys / Root Cause**:
  1. なぜ新設・改修が必要か: Dataset Studio Step 1 で「ComfyUIに20件直接投入」を押下すると「ComfyUI直接投入エラー: Failed to fetch」が発生し投入に失敗するため。
  2. なぜその課題が発生するか: MatrixGenerationStep.tsx がブラウザから直接 http://127.0.0.1:8188/prompt へ fetch() しているため。
  3. なぜ現状の仕組みで不十分か: ComfyUI はデフォルトで CORS ヘッダーを返さず、ブラウザの同一生成元ポリシーによって通信が遮断されるため。また、ComfyUI の接続先設定がハードコードされているため。
  4. なぜこのアプローチを採用するか: アプリケーション標準のバックエンドプロキシ comfyApi.queuePrompt (/api/comfy/prompt) を経由することで、CORS 制限を完全に回避し、設定された ComfyUI URL と一貫した通信を行えるため。
  5. 根本原因: 初期設計書（REQ-319.md）の「Port 8188 直接投入」という記述に引きずられ、SPEC_SUMMARY.md で定義された /api/comfy プロキシを通さずクライアント側 fetch で直叩きするコードが混入した実装不具合（Type A）。
- **UX Classification**:
  - **Information Design (情報設計)**:
    - ComfyUI へのキュー投入進捗・結果メッセージの整合性維持。
  - **Interaction (インタラクション)**:
    - 「ComfyUIに20件直接投入」ボタン押下時、バックエンドプロキシ経由で正しく20件のキューが投入され、完了トースト/ステータスが表示されること。
  - **Visual (視覚デザイン)**:
    - 既存のプログレスバーおよび成功・失敗ステータスバナーの表示を維持。
- **Requirement**:
  - **1. バックエンドプロキシ経由でのキュー投入**:
    - MatrixGenerationStep.tsx において comfyApi.queuePrompt を使用し、/api/comfy/prompt 経由で ComfyUI へジョブを投入すること。
  - **2. ハードコードされた ComfyUI URL の撤廃**:
    - http://127.0.0.1:8188 のハードコードを排除し、バックエンド設定に委譲すること。
  - **3. テストの追従**:
    - MatrixGenerationStep.test.tsx の直接 fetch モックを comfyApi.queuePrompt のモックに移行し、AC を満たすこと。
- **Acceptance criteria**:
  - [x] AC-1: Given 直交マトリクス（20件）が算出された状態で, When 「ComfyUIに20件直接投入」ボタンをクリックした時, Then comfyApi.queuePrompt が20回呼び出され、各プロンプト（正・負プロンプトおよびシード値注入済み）が /api/comfy/prompt 経由で投入されること。
  - [x] AC-2: Given キュー投入が進行中の時, Then バッチプログレス（0%〜100%）が順次更新され、完了後に成功ステータス（「ComfyUIへの20件の直接バッチ投入が完了しました！」）が表示されること。
  - [x] AC-3: Given comfyApi.queuePrompt がエラーを返した時, Then エラーメッセージ（「ComfyUI直接投入エラー: ...」）が適切にステータス表示され、ローディングが解除されること。
  - [x] AC-4: Given 全ての単体テストを実行した時, Then MatrixGenerationStep.test.tsx を含む関連テストが 100% PASS すること。
- **Inferred points**:
  - 今回の修正スコープは Step 1 の投入経路の正常化（comfyApi.queuePrompt への置換）に限定し、生成後画像の自動フェッチ（WebSocket画像同期）等の新機能は別PBIとして扱う。
