### REQ-287: TagSetModals & LoraModals の 1 コンポーネント 1 ファイル化と共通セレクター抽出

- **Type**: refactoring
- **Status**: done (2026-10-01)
- **Current step**: none
- **Priority**: P3
- **Surface**: TagSetModals.tsx (844行) と LoraModals.tsx (696行) は、それぞれ FormFields, Create, Edit, Detail が1ファイルに混載されている。また、ベースモデル選択やカテゴリ選択でほぼ同一のフォームロジックが重複している（リファクタ計画 PBI-REF-06）。
- **Root Cause**: モーダル種別ごとの責務分離がなされておらず、かつTagSetとLoRA間で共通利用できるセレクターコンポーネントが抽出されていないこと。
- **Requirement**:
  - `TagSetModals` を Create / Edit / Detail / FormFields の独立ファイル群に分割する。
  - `LoraModals` を Register / Detail / FormFields の独立ファイル群に分割する。
  - カテゴリセレクター（`CategorySelect.tsx`）およびベースモデルセレクター（`BaseModelSelect.tsx`）を共通部品として抽出し、両モーダルから再利用する。
  - 【目標構成】:
    ```
    frontend/src/components/
    ├─ TagSetModals/               # TagSetCreate / Edit / Detail / FormFields に分割
    ├─ LoraModals/                 # LoraRegister / Detail / FormFields に分割
    └─ common/
       ├─ CategorySelect.tsx       # 共通カテゴリセレクター（TagSet / LoRA 共通）
       └─ BaseModelSelect.tsx      # 共通ベースモデルセレクター（TagSet / LoRA 共通）
    ```
- **Acceptance criteria**:
  - [ ] AC-1: TagSet および LoRA の新規作成、編集、詳細表示、スナップショット紐付けが正常に動作すること。
  - [ ] AC-2: `TagSetModals.test.tsx` および `LoraModals.test.tsx` が全件 PASS すること。
  - [ ] AC-3: `cd frontend && npm run typecheck`（tsc -b --noEmit）がエラー0件でPASSすること（REQ-001の型検査Gate 1）。
  - [ ] AC-4: `cd frontend && npx vitest run` で既存テストが全件PASSすること。
