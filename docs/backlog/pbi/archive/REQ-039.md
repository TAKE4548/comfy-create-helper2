### REQ-039: 生成ジョブのキャンセル機能

- **Type**: enhancement
- **Status**: done (2026-08-26)
- **Current step**: none
- **Priority**: P2
- **Surface**: 生成開始したジョブをキャンセルできるようにしたい。生成中だけでなく、キューに入っているものもキャンセル可能としたい。実行中・キューにストックされているJOBともに、任意のjobを選んでのキャンセルと、全部一括でのキャンセルを両方実施できるように。
- **Root Cause**: ジョブを送信した後にプロンプトやパラメータの編集漏れに気づくケースがあり、不要なジョブの生成によってリソースが無駄に消費されたり、不要な待ち時間が発生するのを防止したい。
- **Requirement**: 実行中の生成ジョブの中断、およびキュー待機中のジョブの削除を個別または一括で行える操作モーダルと、それを制御するAPI・フロントエンドロジックの実装。
- **Acceptance criteria**:
  - [ ] AC-1: 進捗表示の「Queue待機数」のラベル部分をクリックすると、ジョブ管理用のモーダルウィンドウが表示されること。
  - [ ] AC-2: ジョブ管理モーダル内に、現在生成中のジョブ（1件）と、キューに待機しているジョブの一覧（複数件）がそれぞれ順番に表示されること。
  - [ ] AC-3: 各ジョブに対して個別のキャンセルアクションが実行できること。
    - [ ] AC-3-a: 生成中のジョブをキャンセルした場合、ComfyUI側での生成処理が即座に中断されること。
    - [ ] AC-3-b: キュー待機中のジョブをキャンセルした場合、キューからそのジョブが削除されること。
  - [ ] AC-4: モーダル内に「一括キャンセル」ボタンが配置され、クリックすると生成中のジョブの中断およびキュー待機中ジョブの全削除が同時に実行されること。
  - [ ] AC-5: キャンセルされたジョブは生成履歴に残らず、一覧および履歴から完全に消去されること。
  - [ ] AC-6: キャンセル処理（個別・一括）が成功した際、モーダルのジョブ一覧およびメイン画面の「Queue待機数」などの進捗状態が即座に最新状態へ更新されること。
- **Design doc**: none
