### REQ-131: アルバムページでの複数選択画像の一括D&D順番入れ替え機能

- **Type**: enhancement
- **Status**: ready
- **Current step**: none
- **Priority**: P2
- **Surface**: アルバムページで複数選択モードにした後、選択した画像をまとめて順番入れ替えできるようにしたい。順番の変更は複数選択前同様にD&Dで行いたい。
- **Root Cause**: 複数選択モード時に複数画像をまとめてD&Dで並び替える視覚フィードバックおよび一括挿入ロジックが未実装であるため。
- **Requirement**: アルバムページの複数選択モードにおいて、選択した複数画像をD&D操作で一括して任意の目標位置へ並び替えられるようにする。

#### Acceptance Criteria (AC)
- [ ] AC-1: 複数選択モード時、選択された画像群をドラッグ開始した際に「束になったプレビュー（重ね合わせ表示）」が表示されること。
- [ ] AC-2: ドロップ位置のターゲット画像に対して、選択されていた複数画像が「元の相対的な順序を維持」したまま連続して配置されること。
- [ ] AC-3: ドロップ完了後も、移動された複数画像の「選択状態が維持」されていること。
- [ ] AC-4: ドロップ完了時に、新しい並び順が即座に画面に反映され保存されること。

- **Design doc**: none
