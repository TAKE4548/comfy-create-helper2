### REQ-346: 共通ヘッダーの展開アクションをヘッダー下へ展開する共通仕様に統一する

- **Type**: feature
- **Status**: done
- **Priority**: P2（仮置き）
- **Surface**: 共通ヘッダーの展開アクション全般（生成ページのワークフロー設定を含み、同じ高さ制限がある全箇所）、共通ヘッダーの仕様書
- **Operational need**: 設定一覧を十分な高さで操作し目的の設定に到達する。
- **5 Whys / 業務上の課題整理**（ユーザー報告からの要約。実装原因の断定ではない）:
  1. 展開メニューが極端に短く操作しづらい。
  2. ヘッダー内に表示領域が制限されているように見える。
  3. 短い一覧では探索とスクロールが増える。
  4. 既存キャッシュ展開と同じ下方向展開なら項目を見渡せる。
  5. 一覧の必要高さと表示領域が合っていないことが課題である。
- **UX Classification**: Interaction / Visual
- **Requirement**:
  - 共通ヘッダーの展開アクションでヘッダー内の高さ制限により内容が切り詰められる全箇所を対象とする。生成ページのワークフロー設定に限定しない。
  - 展開は既存ブラウザキャッシュメニューと同様にページ内容へ重ね、ヘッダー下へせり出して表示する。ページ内容の高さやヘッダー高さを押し広げず、ヘッダー高さで切り詰めない。
  - 画面下端を超える項目にもメニュー内で到達可能にする。
  - 開発時にdocs/specs/SPEC_COMMON.mdの共通ヘッダー仕様へこの展開契約を反映し、将来共通ヘッダーへ追加する展開アクションにも同じ契約を適用する。起票段階では仕様書を実装済みの仕様として書き換えない。
- **Acceptance criteria**:
  - AC-1〜6は共通ヘッダーの対象展開アクション全箇所で個別に検証する。設定項目は各アクションの展開内容を指す。
  - [ ] AC-1: Given ヘッダーより高い一覧と下に十分な空間, When 設定展開ボタンを押す, Then メニュー下端がヘッダー下端より下に表示されること。
  - [ ] AC-2: Given 設定メニューが展開されている, When ヘッダー下端より下の設定項目を押す, Then 対象設定の操作が実行されること。
  - [ ] AC-3: Given 一覧が画面の利用可能な高さを超える, When メニューを末尾までスクロールする, Then 最後の設定項目が画面内に表示され押下できること。
  - [ ] AC-4: Given メニューが開いている, When 展開ボタンを再度押す, Then メニューが閉じること。
  - [ ] AC-5: Given サポート対象のdesktop/tablet/mobile画面幅でメニューが開いている, When メニューの全項目を操作する, Then 項目が背景内容に隠れず画面内で到達して押下できること。
  - [ ] AC-6: Given 設定メニューが開いている, When サポート対象の範囲内で画面幅・高さを変更する, Then 最後の設定項目へ引き続き到達して押下できること。
  - [ ] AC-7: Given 本PBIの開発成果がレビュー対象である, When docs/specs/SPEC_COMMON.mdの共通ヘッダー仕様を確認する, Then ヘッダー下への重なり展開・高さでの切り詰め禁止・画面内の末尾到達性・将来追加する展開アクションへの適用が記載されていること。
  - [ ] AC-8: Given 共通ヘッダーへ新しい展開アクションを追加しヘッダーより高い内容を表示する検証例がある, When そのアクションを開く, Then ヘッダー下端より下まで内容が表示され末尾項目へ到達できること。
- **Reference docs**:

  - SPEC_COMMON.md 共通ヘッダー
