### REQ-026: スマホモード時の画像生成進捗表示改善および履歴画像のモーダルプレビュー実装

- **Status**: in-progress
- **Current step**: Phase 2: Detailed Design
- **Description**: スマホモード（画面幅768px未満）において、画像生成中の進捗確認と生成完了後の履歴画像の確認体験を向上させます。具体的には、生成中にヘッダーとボディの間に細いライン状の進捗バーを表示し、履歴サムネイルタップ時にスワイプ切り替えやメタ情報のスクロール表示が可能な全画面プレビューモーダルを提供します。

#### Acceptance Criteria (AC)
- [ ] AC-1: スマホモードでの画像生成中に、ヘッダーとメインコンテンツ（ボディ）の間に細いライン状のプログレスバーが表示されること。
- [ ] AC-2: プログレスバーの付近に進行状況のパーセンテージ（例: `70%`）が表示されること（表示スペースが極端に狭い場合は非表示にするなど、レスポンシブに適応すること）。生成完了後または中断時にはバーが非表示になること。
- [ ] AC-3: スマホモードで生成履歴のサムネイルをタップした際、画面全体を覆うプレビューモーダルが表示されること。
- [ ] AC-4: プレビューモーダルにおいて、左右のスワイプ操作で履歴の前後画像を切り替えられること。
- [ ] AC-5: プレビューモーダルの右上に控えめな「閉じる」アイコンボタンが配置され、それを押すか、あるいはモーダル画像外の背景エリアをタップすることでモーダルを閉じられること。
- [ ] AC-6: プレビューモーダル内をスクロールすることで、その画像を生成した際のプロンプトやシード値などのメタ情報が表示されること。プレビュー画像自体の表示領域が阻害されないよう考慮されたスクロールレイアウトであること。
