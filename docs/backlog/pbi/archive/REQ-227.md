### REQ-227: 生成パラメータのアスペクト比変更反映の修正および生成時パラメータの可視化
- **Type**: defect
- **Status**: done (2026-09-07)
- **Current step**: none
- **Priority**: P1
- **Surface**:
  - 「生成パラメータのアス比変更が反映されない 他のパラメータが反映できてるのかもよくわからない」
  - 「マッピングしてて明示的に設定変えたにも関わらず変化しないのが問題。」
  - 「プロンプトは変更反映されてるように見えるのだが、古いプリセットのまま送信されているというのは、パラメータだけの話か？」
- **Root Cause**:
  - **State Desynchronization & Overwrite**:
    - パラメータパネルでアスペクト比を変更した際、オートセーブやクエリ再取得の同期タイミングによって `sets` 内のパラメータがワークフロー初期値（デフォルト `9:16`）に巻き戻された状態でキューへ投入される不具合が存在する。
  - **Missing Generation Metadata & Invisible Execution Parameters**:
    - バッチ生成時に生成パラメータのメタデータキャッシュ保存がスキップされているため、スナップショット保存時に現在UI値で誤保存される。
    - 履歴プレビューモーダルにおいて、スナップショット未保存の画像に対してパラメータ情報表示（`<Info />`）ボタンが非表示となっており、実際にComfyUIでどのパラメータが実行されたかを画面上で確認できない。
- **Requirement**:
  - パラメータパネル上で明示的に変更されたアスペクト比などのパラメータが、巻き戻りや競合なく確実にComfyUIの生成キューへ反映されること。
  - 生成実行時に各画像の実行時メタデータ（パラメータ、プロンプト、シード値等）が確実に保持され、スナップショット保存時にも正しく反映されること。
  - 生成履歴およびプレビューモーダルにおいて、スナップショットの保存有無にかかわらず、実際にその画像を生成したパラメータを確認できるUI導線を提供すること。
- **Acceptance criteria**:
  - [x] AC-1: パラメータパネル上でアスペクト比を変更して生成を実行した際、ComfyUIノード入力に指定したアスペクト比が正しく伝搬し、該当アスペクト比の画像が生成されること。
  - [x] AC-2: オートセーブやプリセットの再取得が発生しても、編集中のパラメータがデフォルト値に巻き戻されないこと。
  - [x] AC-3: バッチ生成時に各プロンプトの実行メタデータが破棄されず保持されること。
  - [x] AC-4: 生成履歴プレビューモーダルにおいて、スナップショット未保存の画像であっても実際に生成に使用されたパラメータ（アスペクト比、シード値、ステップ数等）を確認できること。
  - [x] AC-5: 生成画像をスナップショット保存した際、保存時点のUI状態ではなく「実際にその画像を生成したパラメータ」が正確に保存されること。
