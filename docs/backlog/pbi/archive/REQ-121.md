### REQ-121: 生成画面のプロファイルタブおよびアコーディオン展開状態の永続化・保持機能

- **Status**: done
- **Description**: 生成画面において、プロファイルタブ（Multi-Set / プリセットタブ）の選択状態（`activeSetId`）および各プロンプトカードの展開・折りたたみ状態（`collapsedRoles`）・モバイルの選択中プロンプトタブ（`activePromptTab`）がリロード時に正しく保持されるように修正・強化する。

#### Acceptance Criteria (AC)
##### 1. プロファイルタブ (Multi-Set / プリセットタブ) の状態維持 (Profile Tab Persistence)
- [x] AC-1-1: ユーザーが生成画面でプロファイルタブ（Current / Set 1 / Set 2 等）を切り替えた際、選択中の `activeSetId` が `localStorage` に保持されること。
- [x] AC-1-2: ページをリロードした際、保存された `activeSetId` のタブが復元され、アクティブ表示および設定・パラメータが正しくロードされること。先頭のタブに勝手にリセットされないこと。

##### 2. モバイルプロンプトタブの選択状態維持 (Mobile Prompt Tab Persistence)
- [x] AC-2-1: モバイル環境でプロンプトタブ（Positive, Negative, キャラクター等）を切り替えた際、選択されたタブの識別子（`activePromptTab`）が `localStorage` に保持されること。
- [x] AC-2-2: ページをリロードした際、直前に選択していたプロンプトタブが選択状態で復元されること。

##### 3. プロンプトカードのアコーディオン展開状態維持 (Accordion Collapse State Persistence)
- [x] AC-3-1: PCおよびモバイル環境で各プロンプトカードのアコーディオンを開閉した際、その展開状態（`collapsedRoles`）が `localStorage` に確実に保存されること。
- [x] AC-3-2: ページをリロードした際、各プロンプトカードがリロード前の展開・折りたたみ状態を維持して正しく表示されること。
