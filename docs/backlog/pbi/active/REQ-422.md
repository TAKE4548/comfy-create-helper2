### REQ-422: マッピングマスタ作成時のクラス名入力で全角カンマ（、，）を拒否する

- **Type**: bug
- **Status**: new
- **Priority**: P3
- **Surface**: frontend/src/components/MappingMasterEditModal.tsx（作成モードの初期RuleSetクラス名入力）
- **Origin**: REQ-419 クローズ時の後続対応事項
- **5 Whys / Root Cause**:
  1. なぜ必要か: マスタ作成時の「初期RuleSetのクラス名」は1つだけ入力する仕様で、カンマを含むと「クラス名は1つだけ入力してください（カンマは使えません）」と表示して保存を止める。
  2. なぜ発生するか: 判定が ASCII カンマ（,）だけを見ており、日本語入力で入りやすい全角カンマ（，）や読点（、）は通過する。
  3. なぜ不十分か: 全角区切りで複数名を入力すると1つのクラス名として保存され、どのノードにも一致しないマスタができる。
  4. なぜこのアプローチか: 判定対象の区切り文字を広げるだけで、既存の警告表示と保存抑止をそのまま使える。
  5. 根本原因: 入力検証が日本語入力環境の区切り文字を考慮していなかった。
- **UX Classification**:
  - Interaction: 誤入力時に保存前に気付ける
- **Requirement**:
  - **1. 全角区切りの拒否**:
    - クラス名入力に ASCII カンマ・全角カンマ（，）・読点（、）のいずれかが含まれる場合、既存と同じ警告を表示し保存ボタンを無効にする。
- **Acceptance criteria**:
  - [ ] AC-1: Given マスタ作成モード, When 初期RuleSetのクラス名に「KSampler，CLIPTextEncode」（全角カンマ）を入力する, Then 「クラス名は1つだけ入力してください（カンマは使えません）」の警告が表示され保存できないこと
  - [ ] AC-2: Given マスタ作成モード, When クラス名に「KSampler、CLIPTextEncode」（読点）を入力する, Then 同じ警告が表示され保存できないこと
  - [ ] AC-3: Given マスタ作成モード, When クラス名に「KSampler」のみを入力し他の必須項目も埋める, Then 警告は表示されず保存できること
  - [ ] AC-4: Given マスタ作成モード, When クラス名に「KSampler,CLIPTextEncode」（ASCII カンマ）を入力する, Then 従来どおり警告が表示され保存できないこと
- **Inferred points**:
  - 警告文言は既存のまま変えない。
  - backend 側（create_master の expected_class_types）での同等検証は本 PBI の対象外。
