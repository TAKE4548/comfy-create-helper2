### REQ-023: Thumbnail Hover Zoom and Wheel Horizontal Scroll

- **Status**: ready
- **Type**: enhancement
- **Priority**: P2
- **Current step**: none
- **Surface**: 生成ページの履歴サムネにカーソルをフォーカスすると、拡大表示されるようにしたい。また、履歴サムネのエリアは数が増えると横方向にスクロールできるようになるが、カーソルを置いてホイールスクロールで横方向にスクロールできるようにしたい
- **Root Cause**:
  - 生成ページの履歴サムネは、生成画像の詳細（テクスチャ、表情、ノイズなど）を細かく視認するにはデフォルトサイズ（サムネイル）のままでは小さすぎる。クリックしてロード等の破壊的操作を行わずに、画像ディテールを確認したいというニーズがある。
  - 履歴数が増えるとサムネエリアが横スクロール可能になるが、標準のマウスホイール操作（縦方向回転）は通常のブラウザ挙動では横スクロールに対応しておらず、スクロールバーをドラッグするか Shift + ホイール を強いるため、履歴選択のユーザー体験（UX）を損ねている。
- **Requirement**:
  - **履歴サムネイルのホバー拡大表示（ポップアッププレビュー）**:
    - 生成ページの履歴サムネイル（画像）にマウスカーソルをホバー（フォーカス）した際、その場または前面にポップアップ（ツールチップやオーバーレイ等）で拡大された画像がプレビュー表示されること。
    - プレビューはテキスト情報などのメタデータは含まず、画像自体が綺麗に拡大されたものとする。ホバーが外れたらプレビューは非表示になること。
  - **ホイール横スクロール機能**:
    - 履歴サムネイルが表示される横スクロールエリアにおいて、ユーザーがそのエリア上にカーソルを置いた状態でマウスホイールを上下に回転させたとき、それを横方向（左右）のスクロール操作に変換し、エリアが横に滑らかにスクロールすること。
- **Acceptance criteria**:
  - [ ] AC-1: 生成ページの履歴サムネイル上にマウスカーソルをホバーさせた際、そのサムネイル画像の拡大プレビューがポップアップ（オーバーレイ）として前面に表示されること。
  - [ ] AC-2: サムネイル画像からマウスカーソルが外れた際、表示されていた拡大プレビューが速やかに消去（非表示化）されること。
  - [ ] AC-3: 拡大プレビューには、テキスト情報やメタデータは表示されず、画像のみが拡大表示されること。
  - [ ] AC-4: 履歴サムネイルが並ぶ横スクロール可能なコンテナ（エリア）の上にマウスカーソルを置き、マウスホイールを回転（上下スクロール）した際、コンテナがその回転方向に応じて左右（横方向）にスクロールすること。
  - [ ] AC-5: マウスホイールでの横スクロール時、ブラウザ標準のページ全体の縦スクロールが発生せず、履歴コンテナ内の横スクロールのみが発生すること（イベントの伝播やデフォルト挙動が適切に制御されていること）。
