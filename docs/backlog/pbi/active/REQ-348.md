### REQ-348: Settingsのスマート置換と対応付けを複数ステージへ対応させる

- **Type**: feature
- **Status**: ready
- **Priority**: P2（仮置き）
- **Surface**: Settingsのスマート置換・ワークフロー対応付け
- **Operational need**: 生成ページと同じ複数工程構成を設定ページでも追加し保存する。
- **5 Whys / 業務上の課題整理**（ユーザー報告からの要約。実装原因の断定ではない）:
  1. 必要な工程のロールを追加・対応付けできない。
  2. スマート置換候補が既存設定に限られ対応付けで工程が欠ける。
  3. 設定済み候補だけでは未設定工程を追加できない。
  4. 有効なロールと工程の組み合わせを選べば構成を完成できる。
  5. 画面間で編集可能な多段構成の範囲が揃っていないことが課題である。
- **UX Classification**: Information Design / Interaction
- **Requirement**:
  - 未設定でも有効ロール×対象ステージをスマート置換で選択し追加可能にする。
  - 対応付けで対象ワークフローの全有効ステージを編集・個別保存可能にする。
- **Acceptance criteria**:
  - [ ] AC-1: Given Main/Rough/Detailが有効でRough/Steps未設定, When Settingsのスマート置換追加候補を開く, Then Rough/Stepsをステージ名付きで選択できること。
  - [ ] AC-2: Given 未設定Rough/Stepsと候補ノード, When スマート置換で追加し保存して再表示する, Then そのステージとノードの組み合わせが保持されること。
  - [ ] AC-3: Given Main/Rough/Detailとユーザー定義の第四ステージがワークフローに存在する, When Settings対応付けを開く, Then 4ステージ全てを編集できること。
  - [ ] AC-4: Given Main/StepsとRough/Steps, When 各々別ノードへ対応付けて保存し再表示する, Then ステージ別の対応付けが保持されること。
  - [ ] AC-5: Given 特定ステージのロールが不要, When その組み合わせを未設定のまま保存する, Then 保存でき未設定を保持すること。
- **Reference docs**:

  - REQ-343（完了済み関連要求）
