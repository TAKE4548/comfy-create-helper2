### REQ-237: 巨大テストのリファクタリングと隔離性検証 (Phase 4)

- **Type**: enhancement
- **Status**: ready
- **Current step**: none
- **Priority**: P2
- **Surface**:
  - `frontend/src/store/__tests__/useGenerationStore.test.ts` が65KB超と巨大化しており、WebSocket接続、ジョブキュー、Multi-Set、バイパス等複数のドメインが同居して認知負荷が高く、保守が困難になっている。
  - テスト間の実行順序依存性（Order Dependency）やグローバル状態（モジュール変数、WebSocketインスタンス等）のリーク検証が未実施であり、テストの決定性が保証されていない。
- **Root Cause**:
  - ストアの機能拡張に伴い単一のテストファイルにテストケースを追加し続けた結果、スライス構成とテスト構造が乖離し、ファイル分割と隔離検証が行われていなかった。
- **Requirement**:
  - `useGenerationStore.test.ts` をZustandスライス構成（`connectionSlice`, `jobQueueSlice`, `multiSetSlice`, `bypassSlice`）に沿って独立したテストファイルに分割・整理する。
  - バックエンドテストにおいて、`pytest-randomly` によるランダムシード（`--randomly-seed=auto` および異なる固定シード）で実行し、順序依存のない決定的なテスト実行を検証する。
  - フロントエンド全テスト連続実行時において、モジュール変数やWebSocketインスタンス等のリーク・状態汚染がないことを検証する。
  - 前提: REQ-234（Phase 1: テスト基盤セットアップ）の隔離設定およびプラグインを使用する。
- **Acceptance criteria**:
  - [ ] AC-1: `useGenerationStore.test.ts` が以下のドメイン別テストファイルに分割・整理されていること:
    - `frontend/src/store/__tests__/slices/connectionSlice.test.ts` (WebSocket / 接続)
    - `frontend/src/store/__tests__/slices/jobQueueSlice.test.ts` (バッチジョブ / キュー)
    - `frontend/src/store/__tests__/slices/multiSetSlice.test.ts` (Multi-Set / チップ抽出)
    - `frontend/src/store/__tests__/slices/bypassSlice.test.ts` (バイパス解決)
  - [ ] AC-2: 分割後の各ストアテストが既存と同等以上の網羅性を維持し、全てパスすること。
  - [ ] AC-3: バックエンドテストにおいて、`pytest --randomly-seed=12345` および `pytest --randomly-seed=54321` など異なるシード値で実行しても100%成功し、順序依存性がないこと。
  - [ ] AC-4: フロントエンド全テスト連続実行時において、テスト間の状態汚染やモジュール変数リーク（`ws` 等）による失敗がゼロであること。
