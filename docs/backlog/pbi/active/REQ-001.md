### REQ-001: メインの生成画面でワークフローをロードした後、入力欄が生成されない

- **Status**: done
- **Type**: defect
- **Priority**: P1
- **Current step**: none
- **Surface**: メインの生成画面でワークフローをロードした後、入力欄が生成されない
- **Root Cause**: 移行データの不備やマスタ定義の違いにより、データベースの `workflow_mappings` に存在しない `master_id`（22, 23, 24など）が含まれる場合、バックエンドAPI（`/api/workflows/{id}`）がシリアライズ処理中に `AttributeError: 'NoneType' object has no attribute 'role'`（500エラー）を発生させ、フロント側でワークフローの読み込みに失敗する。また、フロント側には無効なマッピングやノードの異常をユーザーに通知し、手動で修正する手段がない。
- **Requirement**: 
  1. バックエンドAPIは、紐付け先マスタが存在しない無効なマッピングが含まれる場合でも、エラーにならず正常なマッピングのみを返却すること。
  2. メインの生成画面において、マッピングエラーがあるノードを検出した際、ユーザーにエラー内容（対象ノードのIDやクラス名）を表示し、マスタと再紐付けできる専用の手動修正UIを提供すること。
  3. 手動修正完了後、入力欄が正しく生成され、画像生成が正常に実行可能になること。

#### Acceptance Criteria (AC)
- [ ] AC-1: バックエンドAPI（`GET /api/workflows/{workflow_id}`）が、無効なマッピングが含まれている場合でも500エラーにならず、有効なマッピング情報のみを含めてステータス200を返すこと。
- [ ] AC-2: 生成画面（Generate）において、ワークフローロード時に無効なマッピング情報（APIで返却されないか、エラーが検出されたノード）が存在する場合、エラーがあるノード（ノードID、本来のノードタイトルやクラス名など）を知らせる警告エリアが画面上に表示されること。
- [ ] AC-3: 警告エリアに、エラーノードを正しいマスタ定義（マッピングマスタのRole）と手動で紐付け直すためのドロップダウンまたは修正用UIが表示され、修正を確定できること。
- [ ] AC-4: 手動で紐付けを修正（または無効なマッピングを修正・削除）し、保存した後は、正常に入力欄（プロンプト/パラメータ）が動的生成され、画像生成リクエストを正しくComfyUIに送信できること。
- [ ] AC-5: 修正内容がDBの `workflow_mappings` に反映され、再ロード時にも正常に読み込まれること。
