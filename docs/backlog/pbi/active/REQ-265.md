### REQ-265: スナップショットからのプリセット復元導線の分離とプレビューモーダル化による誤反映防止

- **Type**: enhancement
- **Status**: ready
- **Current step**: none
- **Priority**: P2
- **Surface**:
  - 生成画面のスナップショットプレビューと反映を見直したい。
  - スナップショットからのプリセット複製はたまにユースがあるものの、頻発するものではない。その割に現状は導線が短く、プレビューと連動してプロンプトなども反映されてしまうため、誤操作で不用意な書き換えが起こるリスクの方が高い。
  - スナップショットからの複製は、ボタンを設けて、押下したらモーダルを開いてそこで大きめサムネで並べつつ選択して簡易プレビュー、更にそこから明示的にアクティブプリセットに復元のアクションを設けた上で反映くらいにしていい。
- **Root Cause**:
  - **Interaction Design (Inadequate Safety Barrier & Accidental Side Effects)**:
    - スナップショットの「閲覧・簡易プレビュー（参照）」と「現在のアクティブプリセット・プロンプトへの復元（破壊的変更）」の導線が密結合しており、プレビュー操作に伴って自動的に編集中の設定が上書きされる仕様となっているため、低頻度な復元操作に対して誤操作リスクが過大になっている。
  - **Information Design (Visual Preview Constraints)**:
    - スナップショットを一覧・プレビューする領域において、十分な視認性を持つサムネイルと詳細な確認ステップが提供されておらず、意図したスナップショットであるかを安全に確認した上で反映する二段階のフロー（モーダル等）が存在しない。
- **Requirement**:
  - スナップショットの参照・プレビュー操作と、現在のアクティブプリセットへの復元・反映処理を明確に分離し、単なるプレビューや選択で現在編集中のプロンプトやプリセットが自動上書きされないようにすること。
  - スナップショットからのプリセット復元を専用のトリガー（ボタン等）によるモーダル画面へ移行し、大きめのサムネイルによる一覧表示と選択による簡易プレビューを提供すること。
  - モーダル内でスナップショットを確認後、明示的な復元アクションを実行して初めてアクティブプリセットへ内容が反映される二段階の安全なインタラクション設計とすること。
  - キャンセルまたはモーダルを閉じた場合には、現在のアクティブプリセットやプロンプトの状態が確実に保護され、不用意な書き換えが発生しないこと。
- **Acceptance criteria**:
  - [ ] AC-1: スナップショットの参照・プレビュー操作によって、現在編集中のアクティブプリセットやプロンプトが自動的に上書き・反映されないこと。
  - [ ] AC-2: スナップショットからプリセットを複製・復元するための専用導線（呼び出しトリガー）が提供されること。
  - [ ] AC-3: 専用導線から開く画面（モーダル等）において、過去のスナップショットが大きめのサムネイルで一覧表示され、選択して簡易プレビューを確認できること。
  - [ ] AC-4: スナップショットのプレビュー確認後、明示的な「アクティブプリセットに復元（反映）」のアクションを実行して初めて、対象スナップショットの設定値がアクティブプリセットに適用されること。
  - [ ] AC-5: 復元アクションを実行せずにモーダルを閉じた場合やキャンセルした場合は、編集中のプロンプトおよびアクティブプリセットの状態が一切変更されず保護されること。
  - [ ] AC-6: 誤操作リスクを抑制しつつ、過去のスナップショットを視覚的に特定して安全に再利用できる導線が保たれていること。
- **Design doc**: none
