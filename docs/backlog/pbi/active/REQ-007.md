### REQ-007: タグセット一覧画面のカード型レイアウト化

- **Type**: enhancement
- **Status**: ready
- **Current step**: Step 3: Refinement
- **Priority**: P2
- **Surface**: タグセット一覧画面でのリストっぽいレイアウトをLoRA管理側と同じようなカード型レイアウトにしたい
- **Root Cause**: タグセット管理画面のUIがリスト形式であり、LoRA管理画面（カード型レイアウト）と一貫性がなく、一覧の視認性やグリッド上の表示効率、および管理操作（詳細確認、カード上でのサブアクションによる編集）の利便性が低いこと。
- **Requirement**: タグセット一覧画面を、LoRA管理と同様のテキスト主体カード型レイアウトに変更する。セット名をタイトル、その他のメタ情報をサブ要素として配置し、タグ一覧プレビューを掲載する。デスクトップ表示では横並びに複数配置できるグリッドレイアウトとし、カードクリックで詳細モーダル、カード上のサブボタンで編集画面を開けるようにする。
- **Acceptance criteria**:
  - [ ] AC-1: タグセット一覧画面（TagsPage）が、リスト形式からグリッド配置のカード型レイアウト（テキスト主体）に変更されていること。
  - [ ] AC-2: 各タグセットカードのタイトルに「タグセット名」が表示され、サブ要素としてその他のメタ情報が整理されて配置されていること。
  - [ ] AC-3: 各カード内に、そのタグセットに含まれるタグの一覧がプレビュー形式（チップ表示など）で表示されていること。
  - [ ] AC-4: デスクトップ環境などの十分な画面幅がある場合、カードが横並びに複数配置されるレスポンシブグリッドレイアウトになっていること。
  - [ ] AC-5: タグセットカード自体をクリックした際に、詳細情報（タグセット内の全タグ等）を表示する詳細モーダルが表示されること。
  - [ ] AC-6: 各タグセットカード内に編集用のサブボタン（アイコン等）が配置されており、クリック時にタグセットの編集操作が行えること。
- **Design doc**: none
