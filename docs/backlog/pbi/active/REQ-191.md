### REQ-191: anima特化モードに応じたタグチップ重み増減量の動的切り替え
- **Type**: enhancement
- **Status**: done (2026-08-26)
- **Current step**: Phase 4: Pre-Audit & Hand-off
- **Priority**: P2
- **Surface**: 生成画面のタグチップサブメニューで重みを増減するボタンがあるが、anima特化モードとそれ以外で、増減量を変えたい。animaは、重みを多めに振る必要がある為、±0.5と±1.0とし、それ以外では、±0.1と±0.3としたい
- **Root Cause**:
  - 現在のタグチップサブメニューにおける重み増減ボタンの刻み幅は単一の固定値（または標準モデル向けの刻み幅）となっており、モデル/モードごとの最適な重み調整幅に対応できていない。
  - 特に anima 特化モード（Animaモデル）では、プロンプトタグの重み付けを大きく変動（0.5〜1.0単位）させるユースケースが多い一方、標準モデル（SDXL / SD1.5 / Illustrious等）では微小な調整（0.1〜0.3単位）が適しており、現在の刻み幅では anima モード時に何度もボタンを押下する必要がある。
- **Requirement**:
  - タグチップのサブメニュー（または重み調整UI）において、anima特化モードの有効/無効状態に応じて重み増減ボタンの刻み幅（ステップ値およびラベル表示）を動的に切り替える。
  - **anima特化モード有効時**: 重み増減ボタンの刻み幅を **±0.5** および **±1.0** とする。
  - **anima特化モード無効時（通常モード等）**: 重み増減ボタンの刻み幅を **±0.1** および **±0.3** とする。
  - モード切り替え時にUI表示および実際の加算・減算処理が即座に連動すること。
- **Acceptance criteria**:
  - [x] AC-1: anima特化モードが有効な場合、タグチップのサブメニューにおける重み増減ボタンが「±0.5」「±1.0」の刻み幅で表示・動作すること。
  - [x] AC-2: anima特化モードが無効（通常・その他モード）な場合、タグチップのサブメニューにおける重み増減ボタンが「±0.1」「±0.3」の刻み幅で表示・動作すること。
  - [x] AC-3: 増減ボタン押下時に、対象タグの現在の重みに対して正確なステップ値で加算・減算が行われ、プロンプトテキストおよびタグチップ表示に正しく反映されること。
  - [x] AC-4: 設定やトグル等でanima特化モードのON/OFFが切り替わった際、ページリロードなしで即座に増減ボタンの表示と挙動が追従すること。
  - [x] AC-5: 既存の直接数値入力やその他のタグ操作（削除・移動・ネガティブ移動等）にデグレーションが発生しないこと。
