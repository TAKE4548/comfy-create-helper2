### REQ-117: LLMパラメータの設定・永続化機能

- **Status**: ready
- **Description**: LLM系の機能を使用する際のパラメータ（temperature, top_p, max_tokens, presence_penalty, frequency_penalty等）を設定画面から機能（翻訳、シーン生成、プロンプト診断）ごとに変更・永続化できるようにする。

#### Acceptance Criteria (AC)
##### 1. 設定画面での編集UI (Frontend Settings UI)
- [ ] AC-1-1: 設定画面（SettingsPage）に、機能ごと（「翻訳」、「シーン生成」、「プロンプト診断」）のLLMパラメータ設定セクションを追加すること。
- [ ] AC-1-2: 編集可能なパラメータとして以下を提供すること：
  - `temperature` (スライダー UI、値の範囲: 0.0 ~ 1.0)
  - `top_p` (スライダー UI、値の範囲: 0.0 ~ 1.0)
  - `max_tokens` (数値入力、未指定または 1 ~ 8192)
  - `presence_penalty` (スライダーまたは数値入力、値の範囲: -2.0 ~ 2.0)
  - `frequency_penalty` (スライダーまたは数値入力、値の範囲: -2.0 ~ 2.0)
- [ ] AC-1-3: 変更した設定は「保存」または自動保存によってバックエンドAPIに送信され、永続化されること。

##### 2. バックエンドAPIおよびデータベース永続化 (Backend API & DB Persistence)
- [ ] AC-2-1: `llm_prompts` テーブル（または新規設定テーブル）に、各機能・パラメータごとの設定値を格納できるスキーマを定義すること。
- [ ] AC-2-2: 機能ごとのLLM設定（JSON形式等）を取得・更新するAPIエンドポイントを実装すること。
- [ ] AC-2-3: データベースに設定が存在しない場合は、標準的なデフォルト値（例: `temperature=0.2`等）をフォールバックとして使用すること。

##### 3. LLM呼び出しへの適用 (Feature Integration)
- [ ] AC-3-1: 翻訳機能の実行時、設定した翻訳用パラメータがLLMリクエストに適用されること。
- [ ] AC-3-2: シーン生成機能の実行時、設定したシーン生成用パラメータがLLMリクエストに適用されること。
- [ ] AC-3-3: プロンプト診断（Interference, Vocabulary, Physical）の実行時、設定したプロンプト診断用パラメータがLLMリクエストに適用されること。
