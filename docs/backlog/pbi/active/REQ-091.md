### REQ-091: useAuditAction.tsテスト実装とマルチ監査タイプ仕様の修正

- **Status**: new
- **Description**: 現在ユニットテストが存在しない `useAuditAction.ts` にテストを追加します。さらに、仕様書 `SPEC_GENERATE.md` に記載されている3つのプロンプト監査タイプ（interference, vocabulary, physical）を正しくサポートし、UIおよびフックでマルチ選択可能な状態に修正します。

#### Acceptance Criteria (AC)
- [ ] AC-1: `useAuditAction.ts` の状態変化、API呼び出し、エラーハンドリングをカバーするユニットテストを追加すること
- [ ] AC-2: 監査タイプとして `interference` だけでなく `vocabulary`, `physical` も含めたマルチ選択（配列）の初期化および更新が可能なこと
- [ ] AC-3: API送信時に選択されたすべての監査タイプと、正しく抽出された positive_prompt / negative_prompt が送信されることをテストで検証すること
- [ ] AC-4: APIコールのモックテストにおいて、ローカル状態（loading, error, auditResult）の遷移が正しく検証されること
