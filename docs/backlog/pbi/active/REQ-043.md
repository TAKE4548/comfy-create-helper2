### REQ-043: LoRA・タグセットの紐付け編集およびサムネイル連動

- **Status**: ready
- **Description**: 保存済みのスナップショットに対して、関連付けられている LoRA およびタグセットを後から追加・削除できるようにし、LoRA/タグセットの管理画面でのサムネイル表示（スナップショット画像連動）をリアルタイムに更新できるようにする。

#### Acceptance Criteria (AC)
- [ ] AC-1 (Backend API): スナップショットの関連情報（LoRA、タグセットのリレーション）を更新するためのエンドポイント `PATCH /api/snapshots/{snapshot_id}` が実装されていること。
  - リクエストパラメータとして、更新後の `lora_ids` (LoRAのID配列、強度は 1.0 固定で登録) および `tag_set_ids` (タグセットのID配列) を受け取り、既存のリレーションを安全に更新できること。
- [ ] AC-2 (Frontend UI): 履歴 (History) 画面のスナップショット詳細表示において、紐付いている LoRA とタグセットを後から編集（追加・削除）できるUIが表示されること。
  - ユーザーは任意の LoRA またはタグセットを選択してスナップショットに紐付けることができ、不要な紐付けを削除できる。
  - 保存ボタンを押すことで、バックエンドAPI経由でデータベースにリレーションの変更が永続化されること。
- [ ] AC-3 (Thumbnail Sync): リレーションを変更すると、LoRA管理画面 (LoRAsPage) とタグセット管理画面 (TagsPage) でのサムネイル表示 (関連スナップショット画像の履歴カルーセル) が即座に更新され、同期されること。
