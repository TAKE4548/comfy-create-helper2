### REQ-258: タグチップ強度入力欄のスピンボタン刻み幅を0.1ステップに固定化

- **Type**: improvement
- **Status**: ready
- **Current step**: none
- **Priority**: P2
- **UX Classification**: Interaction Design (操作粒度の不整合と役割競合の解消)
- **Surface**:
  - タグチップの強度を直接入力する欄（数値入力フィールド）において、PCで上下矢印（スピンボタン）を操作した際、Anima等のモデル特化ステップ設定（0.5等）が反映されてしまい、0.5刻みで増減してしまう。
  - 0.5刻み等の粗い調整（マクロ調整）は専用のステップボタンが別途提供されているため、数値入力欄のスピンボタン操作では常に細かな0.1刻み（ミクロ調整）で直感的に調整したい。
- **Root Cause**:
  - (Interaction Design / 役割の重複と操作粒度の不整合): マクロ調整（プリセットごとの粗い刻み幅）用の設定値が、ミクロ調整を担うべき数値入力欄（スピンボタン / ステッパー）のステップ幅にも共有・反映されており、入力欄本来の細かな微調整機能が損なわれている。
- **Requirement**:
  - タグチップの強度直接入力欄におけるスピンボタン（上下矢印）による増減操作は、モデルやプリセットの特化ステップ（0.5等）に依存せず、独立して0.1ステップ固定で増減できるようにすること。
  - 専用のステップボタン（0.5刻み等）によるマクロ調整操作と、入力欄のスピンボタンによるミクロ調整（0.1刻み）が明確に役割分担され、併用できること。
- **Acceptance criteria**:
  - [ ] AC-1: タグチップの強度直接入力欄において、PCの上下矢印（スピンボタン）をクリックした際、値が0.1刻みで増減すること。
  - [ ] AC-2: Anima等のプリセット設定が有効な場合であっても、直接入力欄のスピンボタンのステップ幅は0.5等に引っ張られず、0.1ステップが維持されること。
  - [ ] AC-3: 既存の専用ステップボタン（0.5刻み等）の動作には影響を与えず、マクロ調整とミクロ調整（入力欄スピン操作）が両立して機能すること。
- **Design doc**: none
