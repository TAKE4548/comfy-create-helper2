### REQ-214: Python 3.12 / Pydantic V2 互換性対応（datetime.UTC標準化・ConfigDict移行）による非推奨警告の一掃
- **Type**: refactor
- **Status**: ready
- **Current step**: Phase 1: Requirement Analysis
- **Priority**: P2
- **Surface**:
  - `models.py` の各テーブル定義（`created_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.utcnow)`）および各ルーター（`presets.py`, `llm_prompts.py`, `seeder.py`）において、Python 3.12で非推奨となった `datetime.utcnow()` が多用されている。
  - テスト実行時に **414件** の `DeprecationWarning` が出力されており、将来のPythonバージョン（3.13以降）へのアップグレード時にランタイムエラーとなる潜在リスクがある。
  - また、タイムゾーン情報を持たないナイーブな日時オブジェクト（Naive Datetime）とタイムゾーン付きオブジェクト（Aware Datetime）の混在により、フロントエンドへのISO文字列返却時に時差ズレが発生しやすい。
  - `app/config.py` において Pydantic V1形式の `class Config:` が残存しており、`PydanticDeprecatedSince20` 警告が発生している。
- **Root Cause**:
  - **Outdated Standard Library & Pydantic Patterns**: Python 3.11以前の旧作法（`datetime.utcnow()` / `class Config:`）がコードベース全体に残存している。
- **Requirement**:
  - すべての `datetime.utcnow()` を Python 3.12標準の `lambda: datetime.now(timezone.utc)` または timezone-aware な日時に統一すること。
  - `app/config.py` を Pydantic V2 の `model_config = SettingsConfigDict(...)` へ刷新すること。
  - pytest 実行時の DeprecationWarning を 0 件にすること。
- **Acceptance criteria**:
  - [ ] AC-1: `models.py`, `routers/`, `seeder.py`, `tests/` 内のすべての `datetime.utcnow()` が `datetime.now(timezone.utc)` または適切な代替関数に置換されていること。
  - [ ] AC-2: `app/config.py` が Pydantic V2 の `SettingsConfigDict` に移行されていること。
  - [ ] AC-3: `pytest` 実行時に `DeprecationWarning` が 0 件となり、全204テストがクリーンにパスすること。
