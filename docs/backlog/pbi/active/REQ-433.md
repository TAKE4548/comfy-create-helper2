### REQ-433: モバイル表示におけるステータスランプ・トグルスイッチの標準デザイン定義およびUI改善

- **Type**: feature
- **Priority**: P2
- **Surface**: Frontend (全画面共通UI・共通デザイン仕様)
- **5 Whys / Root Cause**:
  1. なぜ新設・改修が必要か: モバイル表示（幅768px未満）において、ステータスランプやトグルスイッチ周辺が角丸正方形になっており、視覚的に不自然で視認性・一貫性を損ねているため。
  2. なぜその課題が発生するか: モバイル表示時の一律角丸補正や個別スタイルの差異により、本来円形・ピル型であるべきインジケータやトグル要素まで角丸正方形として描画されてしまうため。
  3. なぜ現状の仕組みで不十分か: `docs/specs/SPEC_COMMON.md` の共通UIルール（§1-3等）にはモーダル・ボタン・入力・カード・チップ等の角丸規定はあるが、ステータスランプおよびトグルスイッチの標準デザイン仕様と一律角丸補正からの保護規定が定義されていないため。
  4. なぜこのアプローチを採用するか: 共通デザイン仕様（`SPEC_COMMON.md`）にステータスランプとトグルスイッチの標準デザインルールを明文化し、アプリ全体（Settings・Generate・その他全画面）の該当コンポーネントを標準デザインへ統一することで、再発防止と画面横断の視覚的一貫性を両立できるため。
  5. 根本原因: 共通デザイン仕様におけるステータスランプおよびトグルスイッチの標準形状・状態表現・モバイル角丸保護ルールの未定義。
- **UX Classification**:
  - **Information Design (情報設計)**:
    - ステータスランプおよびトグルスイッチの状態（稼働中／停止中／エラー、ON／OFF等）を形状と色の双方で直感的に識別でき、既存の「色だけで伝えない（名称・状態テキスト併記）」原則と整合する。
  - **Interaction (インタラクション)**:
    - トグルスイッチは視覚的なピル型外形を保ちつつ、モバイル表示時（768px未満）でも既存の最小タップ領域（44×44px、Hit-Slop等による判定領域確保）およびキーボード・スクリーンリーダー操作性を維持する。
  - **Visual (視覚デザイン)**:
    - ステータスランプを正円（ドット）、トグルスイッチをピル型（カプセル型）トラック＋正円ノブのモダンな標準デザインに統一し、モバイル表示時の角丸正方形化（不自然な角丸上書き）を解消する。
- **Requirement**:
  - **1. 共通デザインルール（`SPEC_COMMON.md`）への標準仕様追加**:
    - `docs/specs/SPEC_COMMON.md` に、ステータスランプおよびトグルスイッチの標準デザイン仕様（形状、角丸、状態表現、モバイルでの角丸保護およびタップ領域要件）を追加定義する。
    - モバイル表示時の一律角丸ルール等によって正円・ピル型が角丸正方形に上書きされない保護原則を明記する。
  - **2. ステータスランプの標準デザイン適用（アプリ全体）**:
    - アプリ全体（Settings画面のサービス死活ランプ、ヘッダー等の接続ステータスランプ等）のステータスランプについて、モバイル・デスクトップを問わず正円（縦横比1:1の完全な円形）で描画されるように統一する。
    - 状態に応じた色分けに加え、既存の名称・状態テキスト等による識別性を維持する。
  - **3. トグルスイッチの標準デザイン適用（アプリ全体）**:
    - アプリ全体のトグルスイッチ（Settings、Generate、その他全画面のON/OFFスイッチ）について、モバイル・デスクトップを問わずピル型（両端半円）のトラックと正円のノブで構成された標準デザインに統一する。
    - ON/OFF状態でノブの位置とトラックの色変化が明確に視認でき、かつモバイル表示時でも有効タップ領域44×44px以上を維持する。
- **Acceptance criteria**:
  - [ ] AC-1: Given `docs/specs/SPEC_COMMON.md` を参照するとき, When デザインシステムおよび共通UIルールの節を確認する, Then ステータスランプ（正円形状・状態表現）およびトグルスイッチ（ピル型トラック＋正円ノブ・状態表現・タップ領域・モバイル角丸保護）の標準デザインルールが明文化されていること。
  - [ ] AC-2: Given モバイルビューポート（幅768px未満）でアプリ内のステータスランプ（Settingsのサービス死活ランプ、ヘッダー接続ステータス等）を表示したとき, When 該当要素の描画形状とスタイルを検証する, Then すべての対象ステータスランプが角丸正方形ではなく正円（縦横比1:1かつ境界半径が幅・高さの50%以上）で表示され、周囲に不自然な角丸正方形の枠や背景崩れが生じないこと。
  - [ ] AC-3: Given モバイルビューポート（幅768px未満）でアプリ内のトグルスイッチを表示したとき, When 該当要素の描画形状・状態変化・タップ領域を検証する, Then すべての対象トグルスイッチがピル型（両端が半円）のトラックと正円のノブで表示され、ON/OFF切替に応じてノブ位置とトラック色が変化し、有効タップ領域が44×44px以上確保されていること。
  - [ ] AC-4: Given デスクトップビューポート（幅768px以上）および既存のUI不変条件・アクセシビリティ要件（色のみで状態を伝えない、キーボード操作・aria属性の維持）に対して, When ステータスランプおよびトグルスイッチの画面表示と操作を行う, Then 既存の機能・状態同期・保存挙動・UI不変条件を損なうことなく標準デザインで一貫して動作すること。
- **Inferred points**:
  - モバイル表示で角丸正方形に見えている原因として、共通CSS等の一律角丸補正や個別コンポーネントの角丸指定・ラッパー要素のスタイルが想定されるが、具体的な原因特定と対象コンポーネントの全量棚卸しは設計フェーズ（アーキテクト）にて調査・確定する。
  - トグルボタン（例: チップ表示/テキスト表示切替などの押しボタン型トグル）とON/OFF切り替え用の「トグルスイッチ」のうち、本PBIの標準ピル型＋正円ノブの対象はON/OFFスイッチ型トグル（およびそれに類するスイッチUI）とし、一般の押しボタン（角丸8pxルール対象）とは設計フェーズで明確に区分する。
