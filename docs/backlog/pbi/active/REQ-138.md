### REQ-138: アルバム詳細画面からのセリフ編集モーダル起動および即時反映

- **Type**: enhancement
- **Status**: ready
- **Current step**: none
- **Priority**: P2
- **Surface**: セリフ編集をアルバムページからも遷移できるようにしたい。
- **Root Cause**: 履歴ページ通常表示のスナップショット一覧からは各カードのボタンより `SpeechBubbleEditorModal` を起動できるが、アルバム詳細表示画面（Album Items一覧）にはセリフ編集の起動ボタンが存在せず、アルバム内の画像を編集するために一度通常スナップショット一覧に戻る必要があった。
- **Requirement**: アルバム詳細画面内の各画像カード（非一括選択モード時）にセリフ編集ボタン（`MessageSquarePlus` アイコン）を追加し、クリック時に該当画像のスナップショット情報を渡して `SpeechBubbleEditorModal` を起動できるようにする。編集・保存完了時にはアルバム詳細およびスナップショットのクエリキャッシュを更新し、変更結果が即時反映されるようにする。

#### Acceptance Criteria (AC)

##### 1. アルバムアイテムカードへのセリフ編集ボタン配置
- [ ] AC-1-1: アルバム詳細画面の各画像カードにおいて、一括選択モードでない通常時に「セリフ編集・吹き出し追加」ボタン（`MessageSquarePlus` アイコン）が表示されること。
- [ ] AC-1-2: 画像パス（`image_path`）が存在するアイテムでのみセリフ編集ボタンが有効/表示されること。

##### 2. セリフ編集モーダルの起動と連携
- [ ] AC-2-1: アルバム詳細画面のセリフ編集ボタンをクリックした際、カードの選択・詳細表示等のイベント伝播（`stopPropagation`）を防ぎつつ、対象アイテムのスナップショット情報で `SpeechBubbleEditorModal` が正しく開くこと。
- [ ] AC-2-2: セリフ編集モーダル上でセリフ追加・編集および画像保存が行えること。

##### 3. 保存後のキャッシュ更新と反映
- [ ] AC-3-1: モーダルでセリフ保存が完了した際、スナップショット一覧（`['snapshots']`）および現在のアルバム詳細（`['album', selectedAlbumId]`）、アルバム一覧（`['albums']`）のクエリキャッシュが無効化・再取得されること。
