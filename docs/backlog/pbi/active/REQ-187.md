### REQ-187: アルバム詳細画面におけるカスタム順・降順でのドラッグ＆ドロップ並び替え対応
- **Type**: enhancement
- **Status**: ready
- **Current step**: Phase 3: Task Decomposition & Planning
- **Priority**: P2
- **Surface**: req185でアルバム画面でカスタム順での降順にできるようになったが、降順状態だと並び替えができない。カスタム順ではあるので、降順でも並び替え可能であってほしい。
- **Root Cause**: 
  1. 【Interaction/仕様制限】REQ-185 において DnD の有効条件が昇順（`asc`）のみに制限されており、降順（`desc`）表示時の DnD 操作・ドラッグハンドルが無効化されている。
  2. 【Logic/順序同期】降順表示状態でドラッグ＆ドロップした際の画面上の並び順と、バックエンドで永続化する `sequence_order`（昇順）との整合性を維持するインデックス変換・同期処理が未実装である。
- **Requirement**: アルバム詳細画面において、ソート基準が「カスタム順」であればソート方向が「降順」の場合でもドラッグ＆ドロップによるアイテムの並び替え（単一移動および複数選択時のグループ移動）を可能とし、画面上の配置順序通りの永続化・オプティミスティック更新を実現する。
- **Acceptance criteria**:
  - [ ] AC-1: アルバム詳細画面において「カスタム順」かつ「降順」選択時にも、アイテムカードに並び替えハンドルが表示され、ドラッグ＆ドロップ操作が可能であること
  - [ ] AC-2: 「カスタム順」かつ「降順」表示時にアイテムをドラッグ＆ドロップで移動した際、画面上の並び順通りに順序が更新・永続化され、再読み込み後も意図した順序が維持されること
  - [ ] AC-3: 複数選択モード時（グループ移動）においても、「カスタム順」かつ「降順」で選択アイテム群のドラッグ移動が正常に動作すること
  - [ ] AC-4: 「カスタム順・昇順」時の既存の並び替え動作および「登録日時」ソート時の動作にデグレーションが発生しないこと
