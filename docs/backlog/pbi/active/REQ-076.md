### REQ-076: RescanModal.tsx および TagChipEditor/index.tsx のモジュール化・分割

- **Status**: new
- **Description**: フロントエンドのモーダルコンポーネント `RescanModal.tsx` および `TagChipEditor/index.tsx` はドラッグ＆ドロップやスキャン表示などのロジックが集中しているため、機能ごとにサブコンポーネントまたはフックとしてモジュール化・分割を行う。

#### Acceptance Criteria (AC)
- [ ] AC-1: `RescanModal.tsx` の進捗ステータス表示や、アセット比較テーブルなどの再利用可能な部分をサブコンポーネントへ物理分割する。
- [ ] AC-2: `TagChipEditor/index.tsx` から、ドラッグ制御、編集インタラクション、Undo/RedoロジックなどをサブコンポーネントやカスタムHooksに切り出す。
- [ ] AC-3: リファクタリング前後で既存の自動テストがすべてPASSすること。
