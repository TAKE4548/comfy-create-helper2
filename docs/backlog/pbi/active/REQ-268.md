### REQ-268: リポジトリ全体（root/docs/tmp）のレガシードキュメント・一時ファイル整理およびGit除外設定

- **Type**: enhancement
- **Status**: ready
- **Current step**: none
- **Priority**: P2
- **Surface**:
  - レガシードキュメントのクリーンアップと、サムネキャッシュがgitignoreから漏れてるのを整理したい。
  - docs直下以外（特にリポジトリrootやtmp配下）にも古いドキュメントや一時生成物が残っているため、対象範囲を広げて一括整理したい。
- **Root Cause**:
  - **Information Design / SSoT Disorganization (Multi-Directory)**:
    - リポジトリ root 直下に重複・旧仕様ファイル（`Prompt Surgeon FEデザイン・実装仕様書.md`, `api_spec_draft.md`, `spec_and_migration.md`）が配置されている。
    - `docs/` 直下に過去の調査レポート、外部スタブ（`.gdoc` / `.gsheet`）、下書き仕様書が散在し、SSoT ルール（静的仕様書は `docs/specs/` に集約）と整合していない。
    - `tmp/` ディレクトリに過去の調査 PDF、一時ログ、役目を終えた検証スクリプト、古い仕様ドラフトが大量に蓄積している。
  - **Operational / Repository Noise Leakage**:
    - 自動生成されたサムネイルキャッシュディレクトリ（`db/thumbnails/`）や作業用ディレクトリ（`scratch/`）が `.gitignore` に適切に定義されておらず、未追跡ファイルとして Git ワーキングツリーに露出している。
- **Requirement**:
  - **Git 除外・クリーン化**:
    - `db/thumbnails/` や `scratch/` など、Git 管理不要な成果物・キャッシュ・作業ディレクトリを `.gitignore` に定義し、Git ワーキングツリーの未追跡ファイルを解消すること。
  - **SSoT 統合 & root/docs ドキュメント整理**:
    - リポジトリ root および `docs/` 直下のドキュメント群を精査し、維持すべき現行仕様を `docs/specs/`（SSoT）へ集約・一元化すること。
    - root 直下の重複ファイルや不要な古い下書き・外部スタブファイルを整理（削除またはアーカイブ）し、root および `docs/` 配下をガバナンス基準に準拠した構成にすること。
  - **tmp 配下のクリーンアップ**:
    - `tmp/` 配下に残留している一時検証スクリプト、ログファイル、過去の PDF レポート、不要な要件ドラフトを精査し、クリーンアップすること。
- **Acceptance criteria**:
  - [ ] AC-1: `db/thumbnails/` および `scratch/` が `.gitignore` に定義され、Git ワーキングツリーで未追跡ファイルとして露出しないこと。
  - [ ] AC-2: リポジトリ root 直下に存在する仕様書ドキュメント（`Prompt Surgeon FEデザイン・実装仕様書.md`, `api_spec_draft.md`, `spec_and_migration.md` 等）が精査され、現行仕様として必要な情報が `docs/specs/`（SSoT）に統合された上で root から適切に整理（削除または移設）されていること。
  - [ ] AC-3: `docs/` 直下の過去レポート、下書き仕様書、外部スタブファイル（不要な `.gdoc` / `.gsheet` 等）が整理され、`docs/` 配下が SSoT ガバナンス基準に適合した構造になっていること。
  - [ ] AC-4: `tmp/` 配下の滞留ファイル（古い PDF、一時ログ、不要スクリプト等）が精査され、整理されていること。
  - [ ] AC-5: ドキュメントおよびリポジトリ全体の整理・`.gitignore` 設定変更後も、既存のビルド・自動テスト・システム稼働に悪影響を及ぼさないこと。
- **Design doc**: none
