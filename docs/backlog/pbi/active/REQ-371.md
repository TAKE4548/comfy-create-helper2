### REQ-371: モバイルGenerate：固定生成バーの前面にタグチップが描画される不具合の修正

- **Type**: bug
- **Status**: ready
- **Priority**: P2
- **Surface**: モバイルGenerate（幅767px以下）のプロンプト領域と固定生成バー。共通 `TagChipEditor` が関与する可能性あり（原因は設計フェーズで特定）
- **Reference**:
  - docs/design/mobile-ui-redesign/mobile-generate-redesign-proposal.md（§10 追加修正対象）
  - docs/design/mobile-ui-redesign/mobile-common-ui-redesign-proposal.md（COMMON-03 / COMMON-07 / C-AC-03）
  - docs/specs/SPEC_GENERATE.md（§3 モバイルレイアウト：アクションバー維持・下部余白）
  - docs/specs/SPEC_COMMON.md（§3 TagChipEditor、§1-5 モバイル アンチパターン）
- **5 Whys / Root Cause**:
  1. なぜ修正が必要か: モバイルGenerateでプロンプト欄をスクロールすると、タグチップが画面下部の固定生成バーより手前に描画され、生成・保存・キューのボタンが見えない／押しにくいため（ユーザーによる実画面での報告）。
  2. なぜその課題が発生するか: 固定生成バーとタグチップ（ドラッグ中・選択中を含む）の描画の前後関係が、スクロール時に意図どおりに保たれていないため（推定。具体的な原因は未特定）。
  3. なぜ現状の仕組みで不十分か: 既存仕様は「固定バーに内容が隠れない下部余白」を定めるが、チップが固定バーを覆う重なり順は検証対象になっていない。
  4. なぜこのアプローチを採用するか: 生成操作は主要導線であり、重なり順の不具合は操作不能に直結するため、UI全面刷新（REQ-372/373）とは独立して先行修正できる単位にする。
  5. 根本原因: 未特定。実画面・DOM・CSSの照合で設計フェーズに特定する（BAはコード非参照のため断定しない）。
- **UX Classification**:
  - **Information Design (情報設計)**:
    - 固定操作（生成・保存・キュー）が常に視認できる階層を保つ。
  - **Interaction (インタラクション)**:
    - 固定バーのタップをタグチップが奪わない。タグ編集サブメニュー・ドラッグ・入力を維持する。
  - **Visual (視覚デザイン)**:
    - スクロール中の重なり順（固定バーが手前）。
- **Requirement**:
  - **1. 固定生成バーの優先表示**: 通常・選択中・ドラッグ中のタグチップは固定生成バーの領域を覆わない。
  - **2. 既存機能の維持**: タグ編集サブメニュー、ドラッグ並べ替え、入力、ソフトキーボード表示中の挙動を維持する。
  - **3. 共通部品の扱い**: 原因が共通 `TagChipEditor` やドラッグ／ポップオーバー基盤にある場合は、Generate専用の無根拠な例外を作らず、他の利用画面（Tag Set作成・編集など）を含めて影響を確認する。
- **Acceptance criteria**:
  - [ ] AC-1: Given 幅767px以下のGenerateでプロンプト欄に固定生成バーの位置まで届く量のタグチップがある, When プロンプト領域を上下にスクロールし、チップの描画領域の一部でも固定生成バーの領域（上端から下端まで）に入る位置を通過させる, Then いずれのチップも固定生成バーの背面に描画され、生成・保存・キューの各ボタンが全面視認できること。
  - [ ] AC-2: Given AC-1と同じ状態, When 固定生成バーの各ボタン（生成・保存・キュー）の上をタップする, Then タップは常にそのボタンが受け取り、背面のタグチップの操作は発火しないこと。
  - [ ] AC-3: Given タグチップをドラッグ中, When ドラッグ中のチップを移動し、チップの描画領域の一部が固定生成バーの領域に入る位置まで持っていく, Then ドラッグ中のチップが固定生成バーの前面に描画されず、ドラッグ並べ替えは従来どおり完了できること。
  - [ ] AC-4: Given 固定生成バーの近くにあるタグチップ, When チップのサブメニュー編集を開く, Then サブメニューの操作項目が固定生成バーに隠れて押せなくなることがなく、従来どおり編集・削除・入力フォーカス・ソフトキーボード表示中の入力ができること。
  - [ ] AC-5: Given 幅360px、セーフエリアあり、ボトムナビ表示の状態, When AC-1〜AC-4を実行する, Then 同じ結果になり、固定生成バーとボトムナビの相互の重なり・隙間が既存仕様（SPEC_COMMON §2-4 / SPEC_GENERATE §3）から変化しないこと。
  - [ ] AC-6: Given 修正が共有の `TagChipEditor` またはドラッグ／ポップオーバー基盤に及ぶ, When Tag Set作成・編集画面を開く, Then チップの表示・サブメニュー編集・ドラッグ・削除・入力・折返しが従来と同等に動作し、影響した画面の一覧が設計に記録されていること。
  - [ ] AC-7: Given 幅768px以上（PC）またはGenerate以外の画面, When 同様に操作する, Then 表示と操作が修正前から変化しないこと。
